\vspace{0.2em}
\centering\scriptsize
\textbf{Protocol.}\;
\texttt{STRICT}=runtime monkey-patch (\texttt{patches/run\_pure.py}) that rebinds
every PyRAT falsification entry point to a no-op stub before \texttt{pyrat.main()} is
invoked; \texttt{look\_random(nb=1)} is replaced with a \emph{passive} shim that
returns \texttt{True} \emph{without} calling \texttt{model.infer}, so the UNSAFE
witness path preserves the analyzer's verdict but invokes \textbf{no} concrete-point
evaluation. CLI flags \texttt{--check skip --nb\_random 0 --attack bounds
--batch\_attack False --exhaustive False} are forced. Audited (sweep
\texttt{grep} for \texttt{pgd|deepfool|[CEX]|counter[\_ ]ex|infer\_counter}
over all 3\,453 \texttt{.log} files returns 0 matches). The \texttt{.ini}
configs are taken from competition commit \texttt{4a9a4f0:vnn\_config/} with
two semantic-identity parser renames (see \texttt{patches/}).
