# C47: source-associated half HZ and composed witness contract

This is an isolated, default-off correctness bridge in the same S0 campaign.
It is not native admission, a full LIVE transaction, a benchmark witness, or
permission to use any other structure/family. All score/representation/resource
constraints of the unchanged charters remain in force.

## Authority and equivalence

`build` takes only an issued C32 SplicedState and a budget, not user-supplied
degrees, target hashes, success flags or an iid. It validates the complete
original expression/HZ/maps/phase-event proof association and executes the
unchanged complete C39/C40 cohort transaction. The new object keeps the
original source fields, exact old lineage and independent proof bytes, but
does not keep the old post HZ, old state or old receipt. A new private weakly
registered receipt belongs to this exact object and cannot be pickled/replayed.

On every validation, the original C24/C31/C32 source proof chain is checked
again. The old post hash is taken from that independently associated transfer
proof. Selected original incidence degrees are derived via the authenticated
old lineage and phase overlay; the caller never supplies a degree vector.
Complete inverse hashing of the new predicates reconstructs the original
post image and every selected occurrence. Source maps keep their original
shared identities, all CSR shapes match the global frame, actual row ordering
and indices are checked rather than trusting cached flags, numeric owners are
known ndarray allocations, and selected factors are absent from all new value
and predicate matrices. A source hash alone does not bind all CSR shapes; C47
explicitly closes that gap, with a regression demonstrating unchanged hash
under an otherwise invalid binary-predicate column-width mutation.

The C40 identity is unchanged: z=s*u/2, binary-free homogeneous defining
row (-s*p/2)*u+p*z=0; multiply every affected EQ/INEQ row by positive2,
replace q*z with s*q*u, keep other continuous/binary coefficients and RHS
scaled by2, and delete the defining row. All-parent isolation, original
cohort completeness, coefficient window/exactness and degree coverage remain
the original C40 gates. Global factor widths, binary factors and latent ids
are not renumbered or convexified.

For reconstruction, the C46 old-row oracle and original C32 lineage are
composed using the independently derived hash/degrees and paired lineage
seal. The entire inherited continuous prefix stays unchanged. The receipt
does NOT associate that prefix with an original benchmark INPUT/ASSERT or
prove a native solver point feasible. Complete feasible toy points check the
conditional theorem; an actual _HZMILP/input/property callback, original
network validation and full replay still require their own gates.

## What remains conditional

The original C32 independent proof is the inherited trust anchor. C47 does not
turn arbitrary self-authored proof JSON into authority. In this qualification
the actual public C32 toy pipeline uses its explicitly test-only independent
dense oracle and original C31/source proof checker. The test-only marker is
reported. No private C32 permit or receipt is fabricated. No actual C34 pickle
or large model is loaded, and no source/global-geometry claim is transferred
to Tiny143 merely by using the same code.

All C47 source/HZ/metadata/owner/reconstruction checks are metered, including
conservative repeated original-source authentication allowances. Legacy C32
authentication still has its original separate counters; this bridge has not
proved a single affordable fresh C34 execution. Full source/geometry/inverse
checks are intentionally repeated here. Proof reuse or first-write fusion
requires a changed, independently checked authority and ownership protocol,
not a cached success boolean. Numeric-owner metrics cover every field of the
bound object but not the native model/caches/caller roots. The complete source
factory-to-publication transient window is not claimed.
