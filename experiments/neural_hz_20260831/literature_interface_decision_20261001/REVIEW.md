# 从跨领域研究确定 Neural HZ 的关系接口

需要借鉴 HZ 之外的研究。当前重点不是再扩大书单，而是从其他领域找出适合神经网络的关系语言、组合规则和成本控制方法。本次复核已有综述及一手文献，得到一个明确判断：只共享激活相位还不够，下一步必须检验同一相位内部的共同连续源关系能否被后继使用。

这是一轮有范围的机制综述，不是完整系统性综述或新颖性认证。此前已经研究过 reduced product、析取优化、控制 QC、热带表示及约束消元；不将本轮重读算作首次发现。直接前序见[机制综述](../literature_mechanism_test_20261001/REVIEW.md)、[跨层接口](../definition_first_20260928/d059_cross_layer_interface_20261001/THEORY.md)及[综合研究](../definition_first_20260928/d060_cross_domain_synthesis_20261001/RESEARCH.md)。

## 借鉴哪些机制

### 程序分析帮助定义组件如何交换关系

论文事实：Cousot、Cousot、Mauborgne 的 [observational reduced product](https://pcousot.github.io/publications/CousotCousotMauborgne-FoSSaCS11-LNCS6604-proofs.pdf)，2011，§4.1，通过具名观察及约化交换信息。仅并列组件、共享名字，并不自动得到足够精确的信息传递。

项目推断：Neural HZ 的元素必须说明共同输入、原相位与原读出的语义，以及 Conv、ReLU、Add 如何消费关系。仅给原 HZ 附上一份关系列表，不足以宣称定义创新。原 HZ 已能表达这些非凸集合；目标是更有效、可组合的抽象语言与变换，不是宣称发现原 HZ 无法表达的 ReLU。

论文事实：[ASTRÉE 的 PLDI 2003 论文](https://arxiv.org/pdf/cs/0701193)，§7.2.1，按线性赋值中的共同变量形成 packs，允许重叠。线性数量、常数大小的 packs 在文中是针对其程序族的猜测，不是任意程序的复杂度定理。[Gange 等](https://jorgenavas.github.io/papers/ACM_TOPLAS_zones_octagons.pdf)，§8.5、§9.2，区分稀疏表示与分包丢关系，实验中分包也不总能加速。

项目推断：小相位包不等于小共同源作用域。当前归档宽层每个消费者有576个原slot，同窗64消费者；不能因为每次只选两个锚相位，就把其余共同源独立区间化后声称没有代价。可借结构固定的局部组织方式，但不移植按上轮成绩挑包重跑或逐分支分析。

### 图模型与约束消元帮助审查合流一致性

论文事实：[Dechter 的 Bucket Elimination](https://ics.uci.edu/~dechter/publications/r76A.pdf)，1999，§2.1与§2.3，以关系联合及投影组织消元，并指出连续线性不等式消元不能仅凭 induced width 得到相同的复杂度界。

项目推断：残差两路必须指向同一原赋值。相位一致、源坐标均值一致、各局部关系分别可行，均不能自动代替一个共同的连续见证。接口维数小也不自动保证投影行、填充和decoder便宜。这不是否定普通网络可利用的稀疏性，也不把极端最坏情形研究变成主线。

### 混合整数表述提供强对照与成本参照

论文事实：[Tsay 等的分组表述](https://arxiv.org/pdf/2102.04373)，2021，§3、Proposition 1，按输入项分组保留贡献；线性数量辅助变量的扩展表述，投影后可以对应指数数量的约束。这里的变量分组不同于切分输入空间。

项目推断：可以借鉴同一原相位下共享部分贡献，但不能把复制已有 lift 叫作新域。少变量与低成本不能画等号；也不迁入 OBBT、LP点驱动分离或搜索。已有四状态共享delta属于经典Cayley/RLT机制，其价值和新颖性要另行证明。

### 控制理论提供关系内容及健全性边界

对于同一赋值中的原门 q=ReLU(g)、p=ReLU(h)，单调性和斜率限制给出 d*((g-h)-d)>=0，其中d=q-p。它可以作为跨门关系的比较对象，不需要把整个验证器改成SDP。

论文事实：[Pauli 等](https://arxiv.org/pdf/2005.02929)，§II-C，指出一种将非对角耦合直接用于两个向量基点增量的LipSDP推广不正确。这不推翻上面的同赋值标量关系。[Noori 等2024 v2](https://arxiv.org/pdf/2407.06888v2)，§III-D、Proposition 2与Theorem 4，又给出不同矩阵结构的合法增量耦合。因此也不能反向概括为所有耦合都不合法。

项目推断：借鉴经核对的关系内容，研究能否形成固定、有限、可计费的前向EQ/LE后果；不直接移植SDP、共正性搜索或指数相位构造。无法在当前边界内实现的关系作为比较证据，不伪装成可执行能力。

## 相位完全一致仍可能缺共同源

下面是对既有[D062普通混权控制](../definition_first_20260928/d062_mixed_block_support_20261001/THEORY.md)的纸面补充，不是新实验、网络ADV或新颖性主张。

该控制中 x、y、z 属于[-1,1]，三个门为

```text
q1 = ReLU(x+y+1/10)
q2 = ReLU(y+z+1/10)
p  = ReLU(x+z+1/10).
```

已存假点为源均值零、q1=q2=17/20、p=1/8、三位相位均值1/2。每个完整两门带相位凸包都有自己的真实源见证；各对相位都可以是00与11各半，因而连完整的三位相位分布也能一致地选为000与111各半。

但这仍不能给出共同连续源见证。假设存在这样的联合分布，三位相位几乎处处等于同一个b。令 mx=E[b*x]、my=E[b*y]、mz=E[b*z]。原门等式迫使

```text
mx+my = 4/5
my+mz = 4/5
mx+mz = 3/40
my = 61/80 > 1/2.
```

另一方面，y<=1且b属于{0,1}给出my<=E[b]=1/2，矛盾。这里的分布是审查凸松弛一致性的数学见证，不是运行时采样或概率化网络语义。

结论范围很明确：即使完整相位分布一致，也不足以取代相位内部的共同连续源关系。这不否定D066已证的共享delta收益，也不证明原精确HZ遗漏了关系；它限制的是局部松弛及接口的充分性。可以复用已有控制检查后续候选，不需要为此新建测试框架。

## 下一步收敛到一个可反证问题

优先研究普通混权 Conv或Affine→ReLU→混权后继→ReLU，以及共享残差合流。研究假设是：保留宽的共同源背景，并用有限、原身份绑定的相位与幅值关系接口，能够给后继提供独立标量界之外的有效信息，同时支付完整构造、传播、终端编码和输入重构成本。

定义交付应明确域元素、具体化及各算子的健全变换；说明哪些连续信息不可遗忘、哪些仅在等价证明后可消去。所有原bits、零点两相位、EQ/LE、共享frame与decoder均保留。仅把原计算图或完全相同的约束换一种包装，归类为支撑成果，不称新域。

已有[D066结果](../definition_first_20260928/d066_wide_phase_interface_20261001/RESULTS.md)是3809项数学测试通过，尚未取得真实模型绑定、native非冗余、GPU或正式增益资格。因此最近的实证任务仍应是评估现有接口在已保存真实宽层上的效果，区分表系统加强与原HZ查询收益；不因本轮文献阅读再开一个同类组件原型。其[NEXT_EVALUATION](../definition_first_20260928/d066_wide_phase_interface_20261001/NEXT_EVALUATION.md)尚未执行，新版本仍须先解决绑定与全成本计费再预注册。

这不是新增全网ideal、必须战胜完整QC或必须降低nnz的硬门。既有默认关闭、数学到真实结构到shadow到逐家族再到完整回放的顺序不变；研究以常见结构中的可复现收益判断，不承诺满分或PLDI新颖性已经成立。
