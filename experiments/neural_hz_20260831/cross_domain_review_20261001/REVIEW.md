# 从跨领域关系研究推进 Neural HZ

需要把研究范围扩到 HZ 之外，但综述应回答具体定义问题，而不是继续积累论文名。本轮核对抽象解释、混合整数表述、多神经元分析、ImageStar 和控制理论的原文。最直接的新收获是：经典重复非线性关系也能排除上一轮的解析假点，因而既有有限对照不能作为跨领域领先的证据。

这是一轮有范围的机制复核，不是完整系统性综述或新颖性认证。已有跨领域记录见[机制综述](../definition_first_20260928/d058_cross_domain_definition_review_20260930/RESEARCH.md)和[综合研究](../definition_first_20260928/d060_cross_domain_synthesis_20261001/RESEARCH.md)；不把重读记作首次发现。

## 先分清构造成本和关系传播

旧表示优化阶段不能简单归因为 ReLU 膨胀。一个已保存的[真实谓词审计](../C10_PREDICATE_CENSUS_AUDIT_20260908.md)记录了 255298 个连续因子，其中 243162 个属于 MAIN 构造中间量，后来 native ReLU 的连续量仅 400。所有 MAIN 因子对最终值都已不可见，却仍滞留在谓词中。这是该检查点的事实，不代表所有网络的占比。

定义研究的主要问题则是：ReLU 之后，混权 Conv/Affine 如何使用多个门来自同一输入的关系，下一 ReLU 如何继承这些信息，Add/Concat 如何保持同一个赋值。原 HZ 已能精确表达这些依赖；不能宣称原 HZ 没有非凸性或共同源。要改进的是适合神经结构的关系语言、可计算变换和完整精度与成本表现。

## 值得借鉴的机制与不能直接采用的部分

| --- | --- | --- |

这些判断不是说只能使用上述方法。热带表示、互补系统、稀疏多项式和约束消元也在既有综述中有价值；只是不能为每条支线再启动一个没有明确结构命题的实现。

## 重复非线性给出的具体对照

令 q=ReLU(g)、p=ReLU(h)，d=q-p、delta=g-h。由 ReLU 单调且斜率位于零和一之间，经典增量关系为：

```text
d * (delta - d) >= 0.
```

这是上述 Fazlyab 等论文式15在 ReLU 上的实例，并非我们的新定理。它可以联系同层或跨层的实际原门，但所有量必须属于同一个网络赋值。

将[上一轮解析控制](../definition_first_20260928/d061_multiway_rectifier_relation_20261001/THEORY.md)中的 g1、h1 门代入，仅作纸面核算：

```text
g1 = 19/400, h1 = -1/20, q1 = 7/20, p1 = 0
delta = 39/400, d = 7/20
d * (delta - d) = (7/20) * (-101/400) = -707/8000 < 0.
```

所以经典的原始非凸二次关系也拒绝这个点。上一轮“严格强于列明的完整单门及有限线性 pair 生成器”的结论仍然有效，但该点不能证明强于增量 QC、所有多神经元关系或其他领域方法。这也不是对整个 DeepSDP 实际求解能力的比较：这里检查的是原始 QC，不是已经运行其 SDP 松弛。

不能因为该假点的 delta 为正，就将 d<=delta 当作全域有效线性行。实际共同源上的 delta 区间为 [-13/20,17/20]，跨过零；按当前假点或求解状态挑选一个分支会违反限制。这次核查没有给出合规的线性前向构造，没有引入 SDP、相位分支或新求解器。

这个结果的价值是校准研究：外部理论能检验我们是否只是在重新发现已知关系，并帮助把贡献定位到可组合、可靠且成本可控的构造上。

## 下一项定义问题

当前优先研究假设仍是普通结构 q=ReLU(Wx+a)、r=ReLU(Vq+Ux+c) 的共同源关系接口。保留原连续因子、全部原二元相位、EQ/LE、共享 frame、所有消费者和输入 decoder；原门零点的两种相位均保留。

要检验的不是“HZ 加几条约束是否更紧”，而是能否定义有限的神经块关系对象，使混权仿射、ReLU 和残差变换统一复用这些关系，并在包含构造、传播、终端编码和见证重构的账单上有优势。若最终只是原 HZ 加完全相同的事实或未简化的原计算图，就如实归为算子或支撑成果，不能靠命名声称新域。

现有固定多门残余构造是可研究的算子候选，而非已经完成的定义创新。它仍缺实现资格、真实网络非冗余证据、完整端到端成本与正式回放。本轮新增的 QC 对照不把全局 ideal 凸包变成新硬门，也不修改原晋级标准；更强关系允许有成本，但不能隐藏它。

综述下一阶段的具体产物应是：明确的域元素与具体化、一个普通神经块上的可反证传播或简化命题，以及相对原 HZ 加同样信息的贡献说明。之后才在新的预注册下开展默认关闭实现和既定回放，不以文献阅读替代能力验证。
