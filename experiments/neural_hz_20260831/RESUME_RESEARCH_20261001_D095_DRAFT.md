## D095未验证草稿交接

隔离目录为`definition_first_20260928/d095_phase_birth_20261001`，[phase_birth.py静态草稿](definition_first_20260928/d095_phase_birth_20261001/phase_birth.py)已落盘。当前工作是可信ReLU出生及实际谓词绑定的支撑算子，不单独构成Neural HZ新定义，也尚未与D093消费者接通。没有freeze、测试RUN、实际网络执行或GPU任务；未进行候选AST、import、compile、collect或数值试验。

候选针对实际存储的仿射预激活`g = c + g_nonconstant`。从完整连续和二元系数的单位盒范数推导精确有理界，再向外舍入，不能接收未经证明的调用者界。稳定正行复制，稳定负行归零；不稳定行使用`L = lower/2 < 0`、`Q = upper/2 > 0`，半值必须精确可表示。

引入两个不同的连续常量列`rho_c = rho_Q = 1`，各有实际EQ约束。同一构造链可复用这两个列，但必须认证其实际EQ，并拒绝预激活对这两个列的非零引用。每个不稳定门新增连续`s, eta`及原signed二元`b`，拟存储：

```text
L*s - Q*eta + L*b - g_nonconstant - c*rho_c + Q*rho_Q = 0
-s - b <= 0
-eta + b <= 0
q = Q*(1 - eta)
```

目的在于避免将`round(c-Q)`误当成实际存储c和Q的精确差；新行只使用系数拷贝、符号变换和经证明的精确半值。此为普通构造的统一模板，不是数值特殊实例菜单。依然必须证明原谓词逐字保留、所有原状态共同扩展、共享身份和具体输入重构不变。

对允许的旧状态与新相位`(theta,b)`，使用D094的规范扩展：`q=max(0,g)`，`s=2*(q-g)/(-lower)-b`，`eta=1-2*q/upper`。正值允许b=-1，负值允许b=+1，零值必须同时保留两种标签；不能用固定挑选一个零点相位的单值函数冒充覆盖。

拟议接口为`relu_birth`、`verify_gate`以及`CarrierBinding`、`BornGate`、`BirthResult`。`BornGate.lower/upper`保存向外界，不是L/Q。`verify_gate`须认证实际两条常量EQ、本门出生EQ和两个guard，并核对记录的g/q与界；不能只信owner或seal。出生时的output_row仅是历史位置，后续Affine改变输出后不能要求它仍绑定当前同一输出行。现有D064通用提取器直接看到的是额外常量列，不能未经商化证明就当成原预激活。
