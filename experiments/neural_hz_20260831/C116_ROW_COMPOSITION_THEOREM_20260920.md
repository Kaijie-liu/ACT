# C116: complete row composition and exact factor reconstruction

This theorem changes the independent proof representation, not the candidate
Neural-HZ domain or C115 simplification. All experimental claims require the
recorded native proof, physical/resource gates and original source prerequisites.

## Equation identity

Let x denote every original continuous coordinate and b every original binary
coordinate. Old auxiliary variables z lie in [-1,1] and have triangular unique
equations p_j z_j + a_j w = r_j, where p_j > 0 and w contains only original or
earlier auxiliary coordinates. An independently checked bound
|r_j| + sum |a_ji| <= p_j makes each such auxiliary box redundant for every
normalized parent point. The untouched source predicates P(x,b), value maps,
latent identities and original-input inverse remain prerequisites, not inputs
invented by a native-only certificate.

Partition removed factors into input roots R and output-only sinks S. For each
root, prove z_r = lambda_r z_rep from the complete normalized old defining
equations, with a retained representative and 0 < |lambda_r| <= 1. Representatives
need not be earlier than the removed root in the old coordinate numbering.

Complete old incidence must establish that every s in S occurs only in its
own defining equation and the enumerated output equations. No deleted sink may
be consumed by another auxiliary equation. Substituting root identities into
the unique definition gives z_s = c_s + sum d_si w_i, where every w_i is an
original coordinate or a retained auxiliary. No unresolved deleted factor is
permitted. Store this recipe directly in candidate coordinates.

For each retained auxiliary, compare the complete actual new equation with
its original equation after root substitution and compact-coordinate renaming.
For each original output, independently substitute all removed roots and sinks
into the original equation and compare with the complete new equation. Read
every actual native coefficient, pivot, RHS and positive dyadic gauge. Undo
gauge exactly before comparison. C116 requires unit identity of retained factor
values; proportional equations with an unproved factor rescaling are rejected.
Producer grouping, candidate intermediate rows and projected support alone
are never proof of these equalities.

## Both directions

An old feasible point restricts to the retained coordinates. Checked identities
imply every retained/output candidate equation, and the retained boxes already
hold. Conversely, extend a candidate point with each checked root and sink
recipe. Retained defining equations imply all corresponding old definitions;
root equation identities imply removed root definitions; the sink recipes imply
removed sink definitions. Complete incidence and output comparisons imply all
remaining old equations. Redundant old boxes bound every reconstructed factor.
Thus old and new projected original-coordinate sets coincide. Since x and b
are unchanged, this argument composes with the same P(x,b), EQ/INEQ rows and
original-input inverse without convexifying or deleting a binary phase.

The proof is algebraic and universal, not empirical sampling. The focused tests
also independently expand both small graphs into original-coordinate rational
polynomials and reconstruct full points in both binary phases, including signed
and fractional root scales, late representatives and nonzero sink offsets.

## Admission and cost boundaries

A certificate over all four authenticated C90 native packets can establish the
complete native equation identity, but it cannot manufacture absent original
real-HZ/binary numeric roots, new source ownership, or a source-generation bill.
The complete C90/C98/C100/C107 source proof chain is authenticated separately.
There is no new real-source identity, original-source execution, solver result,
formal gain or default promotion from this theorem alone.

All full-row traversals, both comparison supports, incidence entries, exact
substitution terms and serialized inverse scalars are prepaid at preregistered
rates. Work is linear in traversed row entries plus actual sink-composition
contributions; it need not expand retained intermediates recursively to x.
No old fee or resource cap is reduced. Native packet, coordinate map, complete
inverse and original proof roots remain held for the complete numeric ledger;
inverse Python metadata is reported separately. Both 1GiB transient gates and
the 64M-entry/256M-work diagnostic gates still apply.

Runtime inverse storage and source construction are distinct from diagnostic
certificate storage. A smaller candidate packet alone is not a complete HZ
physical reduction or evidence that source construction fits 200M branch work.
