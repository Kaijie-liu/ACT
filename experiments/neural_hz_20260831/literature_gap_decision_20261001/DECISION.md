# 跨领域文献如何推进 Neural HZ 定义

需要借鉴 HZ 以外的研究，但当前缺口不是没有书单，而是尚未形成一个能在普通神经块间组合、成本可承担并经真实网络验证的新域定义。本次核对已有综述并补查一手论文，结论是优先研究关系接口及其可计算变换；不再把重读论文、增加标量界或扩充组件测试当作定义突破。

## 已有研究与当前缺口

[既有机制综述](../cross_domain_review_20261001/REVIEW.md)已覆盖抽象解释、析取优化、多神经元分析、控制、ImageStar；更早记录还包括多项式、热带语言、消元与知识编译。因此这些方向不是本轮首次发现。

[跨层研究](../definition_first_20260928/d059_cross_layer_interface_20261001/THEORY.md)已经说明：下一 ReLU 的一个输出不足以免费重构所有旧条件观察；只匹配局部凸包的 source 坐标均值也不保证共同混合见证。[完整成本研究](../definition_first_20260928/d060_cross_domain_synthesis_20261001/THEORY.md)中的精确共排序投影，直接编码反而由 3 个变量和 41 nnz 增到 8 个变量和 63 nnz。这些是特定构造的边界，不是所有候选的不可能性定理。

刚结束的 [原生谓词绑定测试](../definition_first_20260928/d064_native_predicate_binding_20261001/RESULTS.md)通过 3805 项检查，但安装的仍是标量上下界。它没有解决多个后继共同利用关系及跨下一激活传播的问题，也没有完成实际模型接入。

## 按机制选择文献

**组合验证与抽象解释，优先用于定义接口。** [CoVeNN，NeurIPS 2025](https://proceedings.neurips.cc/paper_files/paper/2025/file/5ca2e240108d09e213859ea7ef2324bb-Paper-Conference.pdf) §3.1 用真实计算图 cut 和中间保证串联子网络证明。§3.2至3.3及 Appendix C 的实际流程含底层 BaB 验证器、采样与 refinement，不能直接移植。项目推断是：接口覆盖残差旁路等全部穿越边，并指向同一原赋值；用已证前向规则产生可被后继消费的关系。这里切分网络模块不等于切分输入或相位；仍不启动独立搜索路径，也不新增全局 ideal 凸包要求。[Cousot 等的 reduced product](https://pcousot.github.io/publications/CousotCousotMauborgne-FoSSaCS11-LNCS6604-proofs.pdf) §4 为具名观察和信息交换提供已有理论基础，组合本身不能算创新。

**控制理论，优先用于确定需要保留的关系。** [Fazlyab 等的 QC 研究](https://arxiv.org/pdf/1903.01287) §III-C 把重复激活、单调性及斜率限制写成神经元之间的二次关系。对 ReLU，令 d=ReLU(g)-ReLU(h)，已有关系是 d*((g-h)-d)>=0。项目推断是研究其中哪些关系能通过统一前向规则变成可用的 Neural HZ 保证，而不是仅各算一个区间。不引入 SDP 或 dual rescue；不能根据某个松弛点的符号选择全域线性分支。该经典关系不是我们的新定理。

**混合整数表述，作为关系精度和代价的强对照。** [Tsay 等，NeurIPS 2021](https://arxiv.org/pdf/2102.04373) §3 按输入变量分组保留部分贡献，形成大小与紧致度的表述层级；Proposition 1 显示辅助量与投影行数存在代价交换。静态变量分组不是输入空间 split。项目可借鉴同一相位下的部分贡献，但复制现有 lift、优化式界收紧或只少算几个变量都不能被称作新域创新。

**热带代数，作为激活原生语言与精确改写的对照。** [Zhang 等，ICML 2018](https://proceedings.mlr.press/v80/zhang18i/zhang18i.pdf) Props.5.1和5.6 给出差分凸递推，实权重对应 rational signomial；ReLU(P-Q)=max(P,Q)-Q 保留同一输入上的抵消。[Kordonis 和 Maragos，2023预印本](https://arxiv.org/html/2306.15157) Prop.2 区分精确商余式与凸下包络：只保留商、丢弃余式一般不精确。其区域构造与近似压缩流程不直接采用。项目推断是只研究带可核验证书、保留全部原 guards 的局部重写。已有 D011 已包含共同因子思想，不把它重新命名成突破；保留整张 DAG 或展开为巨大平面列表也未解决目标。

**数据库和图模型，约束对紧凑表示的成本承诺。** [Functional Aggregate Queries](https://arxiv.org/pdf/1504.04044v7) §8.1 显式依赖因子的查询操作及其代价；§8.3 说明简洁输入表示下，图无环也不自动使查询容易。该离散理论不能直接给连续 HZ 投影提供复杂度保证。项目推断是每种关系对象都要声明前向组合、有限查询、终端编码及 decoder 的实现与成本，不能把未实现的精确投影当免费操作。全部原 bits 保持具名身份，不通过消元或枚举隐藏成本。

## 新颖性与主线边界

[Combastel 的 typed polynotopes](https://arxiv.org/abs/2009.07387) 已包含连续、signed/Boolean 符号和混合多项式依赖。因此“给生成元加相位多项式”“共享符号”或 eager/lazy 组合本身不足以证明新颖性。原 HZ 已能精确表达相关非凸关系，目标不是声称发现了此前不可表达的 ReLU 集合。

[egg，POPL 2021](https://arxiv.org/pdf/2004.03082) §4 的带分析条件改写可作为可靠化简的配套思路，但 e-graph 是已知等价式组织机制，不是所需抽象域；表达式节点少也不证明终端约束或求解更便宜。本轮不实现新编译器。

## 下一项可反证的研究问题

研究对象限定为普通混权、非零偏置、共享输入的 Conv 或 Affine→ReLU→两个混权后继及 Add 合流，不依赖精确反对称权重等特殊抵消。保留连续源、全部原二元相位、EQ/LE、共享 frame 和具体输入 decoder。

候选必须写出域元素及具体化，说明同一个原赋值怎样同时满足各神经块关系，并给出至少一个跨下一激活或残差合流的健全变换。要检验的是：在提供相同首块标量界的对照下，有限联合关系是否仍能改善后继判断；再与原 HZ 加相同关系、适用的分组 lift 或多神经元规则比较。无需证明任意深度精确闭包，也不新增必须减少 nnz 的普遍硬门。

若最终只是相同线性行的另一种存储、旧计算图重编码，或成本转移到未付费投影，就归档为支撑成果并修改假设。形成明确命题后再预注册默认关闭实现，依次做数学、真实同结构、shadow、逐家族及完整回放；不先启动另一轮泛化组件实现。
