## Common neural structure and exact rule

The default-off writer consumes a complete topological source program, before
constructing its predicate matrices. Complete output maps determine protected
continuous factors. Each incoming definition is translated through already
proved signed roots; exact coalescing preserves shared-factor identity.

If an output-dead fresh factor's defining equality becomes z=+x or z=-x,
with no binary term or constant, retain its signed root and inverse record
without storing the defining predicate. Both factors have the same [-1,1]
box. Chains flatten immediately to an older retained root. Ordinary shared Add
coalescing can expose a new unit relation even when the original row had more
than two coefficients. Non-unit, binary-bearing, nonzero-offset and directly
output-observed definitions stay explicit.

The representation remains a nonconvex continuous-plus-binary HZ, with all
surviving EQ/INEQ predicates and a complete original UID partition. No binary
pivot or removal, interval/Zono/CZ replacement, IID menu, sampling/attack,
BaB/split, backward/dual or LP-status rescue is used.

The result is a compact HZ plus explicit retained global IDs, full signed inverse,
retained EQ/INEQ UIDs, removed UID/column records, source hash, report and seal.
This is a source-program prototype, NOT a proved C31 original-operator adapter.
The compact raw matrices must not enter existing global-frame/native consumers.

The independent audit uses Fraction dictionary induction rather than the
writer's floating sort/coalescing. It checks every selected identity, original
predicate image, binary coefficient, RHS, output, global map, inverse and UID,
and recomputes nnz counters. Forward projection and reverse signed extension
preserve all boxes, predicates and outputs. This is executable exact checking
for the admitted source format, not a claim of formalization in a proof assistant
or world-first/PLDI-level novelty.
