# 从复合抽象与关系交换研究 Neural HZ

应当从 HZ 之外借鉴方法。本文把程序分析、自动微分分析、混合整数表述和约束消元中的机制，映射到 Neural HZ 的定义问题：怎样让共同输入产生的非凸关系，以可承担的成本穿过混权仿射、ReLU 和残差合流。优先研究普通神经块的联合关系及前向变换，不把矩阵压缩或换一个名称当作新域。

这是一轮定向文献核查，不是完整系统性综述，也不是新颖性认证。已有[关系接口综述](../literature_interface_decision_20261001/REVIEW.md)与[跨领域综合研究](../definition_first_20260928/d060_cross_domain_synthesis_20261001/RESEARCH.md)涵盖了多数基础路线。本轮的阅读增量是复合表达式抽象、约化积变换的协同设计，以及对共同符号关系的具体复核；不把旧工作重复计为发现。

## 文献提供的机制与迁移边界

### 复合表达式可以成为抽象变换的设计单位

论文事实：Laurel 等的 [Pasado，OOPSLA 2023](https://ece.is/assets/pdf/Pasado.pdf)，§§1、4.1、4.4，直接抽象自动微分中的链式、乘积及商规则，而非依次组合各原语的抽象。其具体实现包含网格采样回归，再以有证明依据的误差界保证健全性；论文并没有提出适用于任意 ReLU 块的精确算法。

迁移判断：借鉴的是根据常见计算模式选择抽象粒度。我们的候选应共同定义神经块的源、原相位和读出关系，使跨算子依赖在抽象语言里可用，而不只是把几个 CPU/GPU 内核合并。不能照搬其采样拟合流程、凸载体或将其定理直接用于非光滑 ReLU；新规则须独立推导。程序分析的复合变换本身也已有先例，不能作为我们的新颖性主张。

### 组件的关系必须参与彼此的变换

论文事实：Kalita、Reps、Roy 的 [Synthesizing Abstract Transformers for Reduced Product Domains，SAS 2024](https://arxiv.org/html/2408.04040v1)，§§3.2、3.5、4.2，允许组件变换读取其他组件的抽象信息。在受限变换语言下，独立选择各组件的最优变换不一定得到最优组合。其可扩展算法采用固定其他组件时的 1-precision 检查，不应误称全局最佳组合保证。

迁移判断：检查一个 Neural HZ 候选时，不只问它是否保存了相位或条件观察，还要问这些信息是否实际改变了后继关系的生成。不能用各组件测试通过替代组合证明。本轮不部署其 CEGIS 或为每个验证实例动态合成规则；所借机制是预先设计统一、可证明的跨组件前向规则。

论文事实：Ghorbal、Goubault、Putot 的 [A Logical Product Approach to Zonotope Intersection，CAV 2010](https://kghorbal.github.io/assets/pdf/papers/cav2010.pdf)，§2.2、§3.1 Example 2，区分原输入符号与误差符号；其例子显示，只收紧符号区间会遗失等式，而在相关表达式中一致地代换可以保留该关系。

迁移判断：共同 latent 身份是必要条件，不是充分的有效传播机制。我们可以学习关系如何作用于表达式，但不整体替换成 constrained affine set、CZ 或 zonotope。原 HZ 本就能够保存共同源；这里不是证明原 HZ 集合语义遗漏了依赖。

### 扩展表述帮助选择应保留的条件贡献

论文事实：[Anderson 等的强混合整数表述](https://arxiv.org/pdf/1811.01988)，§1.1、§2，区分整数表述正确与松弛的 sharp、ideal 性质；单个标量 ReLU 的紧表述，与仿射输入直接组合后不自动保持紧度。[Tsay 等的分组表述](https://arxiv.org/pdf/2102.04373)，§3、Proposition 1，以分组贡献的辅助量表达一族投影约束，存在辅助量和约束数量之间的交换。

迁移判断：按完整消费者结构保留必要的条件部分和，而不是为每个神经元复制所有条件源，是值得比较的方向。索引分组不等于输入区域切分，但部分和、RLT 和条件提升已经是已知机制。不能把相同的 HZ 加行改名为新域，不迁入 OBBT、LP 点驱动分离或 BaB。

### 消元研究约束完整性而非保证免费压缩

论文事实：[Dechter 的 Bucket Elimination，1999](https://ics.uci.edu/~dechter/publications/r76A.pdf)，§2.3，将相关约束合并后消元，也明确连续 Fourier 消元的复杂度不能仅由 induced width 给出同样的指数界。

迁移判断：删除连续辅助量前必须覆盖它的全部谓词和消费者，保留共同见证及回构；不能逐消费者独立投影后假定它们仍对应同一输入。原二元因子不 pivot、不删除，论文的 conditioning search 不采用。这是辅助方法，不重新把通用消元设为定义研究的主线，也不围绕极端最坏情形拖延普通结构实验。

## 下一项定义问题及可反证条件

优先结构是普通混权块及其后继：

```text
q = ReLU(Ax + a)
h = Bq + Cx + c
r = ReLU(h)
```

这里的 x、q、r 及所有原相位均属于同一个输入赋值；残差、旁路和全部消费者都在范围内。研究对象不是一个未经简化的计算图包装，而是有限的块关系语言、具体化以及 Affine/Conv、ReLU、Add/Concat 如何统一产生和消费这些关系。

[现有条件观察草案](../definition_first_20260928/d089_observation_relay_20261001/THEORY.md)提供了一个待检验起点：保留完整非凸 HZ，并对实际线性读出 v=Wq 保存共同条件观察。它已有纸面健全关系，但约化积框架、同斜率包络和条件提升均有先例，不能据此宣称新域已经成立。

下一项可反证问题是：在结构固定的两个普通混权块之间，能否用同一有限源接口传递有用的条件关系，而不为每个消费者重新复制全部源。记 pi_s 为原相位槽的指示量，D_s 为已证 ReLU 包络斜率的对角矩阵。若槽内 h_s=A x_s+a*pi_s，所需共同核心是 W D_s A x_s，偏置另行保留。一个充分的复用条件是找到结构认证的 T_s、B_s，使 W D_s A=B_s T_s；完整残余和所有其他读出同样必须覆盖。这个矩阵因式分解本身不是创新，也不假定真实卷积天然低秩。需要验证的是统一选择规则、跨块消费和完整费用能否一起有收益。

比较应包括原 HZ、原 HZ 加同样的已知关系、完整逐门条件提升与有限观察方案。相同的终端约束不会凭名称获得更强逻辑精度。可接受的研究贡献可能是新的有限关系语言或组合定理，以及同预算下可复现的精度与成本优势；不要求它表达原精确 HZ 无法表达的 ReLU，也不新增全局 ideal 或任意深度精确闭包要求。

若关系只在第一个块有效、下一块必须重新展开全部源，或必须丢掉旁路/原相位才便宜，就记录该候选的适用或成本边界。先用普通结构及既有解析控制证伪，再进入原先的数学、真实同结构、shadow、逐家族和全量回放顺序，不以继续扩大书单替代验证。
