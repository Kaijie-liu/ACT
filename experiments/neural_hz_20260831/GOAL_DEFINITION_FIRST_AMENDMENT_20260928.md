## 目标正文

从 Hybrid Zonotope 的数学定义出发，设计面向神经网络验证的新型非凸抽象域
Neural-HZ。利用仿射、卷积、激活、残差和共享依赖结构，改进域元素的定义、
具体化语义、约束关系和抽象变换，而不只是压缩现有 HZ 的存储、生成矩阵、
降低构造计费或替换求解器。研究应有可检验的定义与定理创新，以达到高水平
程序语言/验证研究的质量为目标，不预先声称新颖性或论文录用水平。

在保持真正非凸混合因子和健全性的前提下，按常见网络结构逐类获得可复现的
验证能力提升。正式长期终点仍为单一候选路径上的 2413/2413；近期必须先保住
1870 个旧解及全部 13 家族成绩，再增加新的 CERT 或具体网络确认的 ADV。
CIFAR100、TinyImageNet 是优先的大规模网络目标，其独立 E0 口径不能与正式
分数相加。其他家族的泛化收益单独建账。

## 核心交付与判断

1. 给出域元素、具体化映射、语义包含偏序，以及与原 HZ 的嵌入/精确对应关系。
   不假定一定存在可计算的最佳抽象或完整格；若这些性质未证，明确写出范围。
2. 定义仿射/卷积、ReLU、共享残差/Add/Concat 的变换，证明其精确性或明确的
   健全近似关系；初始主线优先精确、分段仿射的普通网络。
3. 说明非凸性从何而来，为什么不是 CZ/Zonotope 的改名、已有 HZ 的矩阵重排、
   或未简化的网络计算图包装。对照已有 HZ、ImageStar、混合符号/多项式域。
4. 至少提出一条域定义所支持的实质性结构定理/简化规则，并完整计算转换、
   终端查询和反例重构代价。减少前端自由变量不等于降低最终求解代价。
5. 在同类型的普通结构及真实网络上验证价值，随后按旧晋级流程验证零回退。
   数学候选、静态证明、组件测试、真实网络收益、正式成绩必须分开报告。

## 不变的限制

- 正式基线 1870/2413 = 1063 CERT + 807 validated ADV；每个旧解和每家族
  solved 数均不得下降。invalid ADV/SAT 为零；UNKNOWN/ERROR/TIMEOUT 不计收益。
- 保留连续因子、显式二元非凸相位语义、等式/不等式、共享 latent/frame 身份
  和具体输入重构。不通过删除/pivot 二元因子或放宽成连续因子来压缩。
- 不整体替换/退化为 Zono、CZ、box 或其他凸域；不以 attack/PGD、BaB、
  输入/相位 split、backward/dual rescue、LP 状态/对偶信息修复冒充域创新。
- 统一按数学结构执行；不使用实例/模型/家族身份、公开标签、历史结论、margin
  或求解状态作为表示选择菜单。比较对象仍是一条固定候选路径。
- 重点研究常见结构，不以极端数值特例和测试框架扩张取代主线。未证情形
  fail closed，不牺牲健全性；不减少既有验证人口或偷偷提高冻结预算。
- 所有候选默认关闭。原数学测试 -> 真实目标 -> 同结构 shadow -> 家族回放 ->
  全 2413 回放的晋级流程不变。没有全量保旧增益不能改变正式成绩/生产默认。
- 能力与纯速度晋级仍分离：能力须通过原四并发不回退门，不能重新把翻倍提速
  作为能力晋级条件；原纯速度 1.5x/2.0x/1.8x 口径仍只用于速度声明。
- E0 仍为 CIFAR100 25、TinyImageNet 36，共 61/400；它们是已验证历史来源
  ADV，不是此前 Neural-HZ 新增的 61 解。新方案须保留全部 61，完成独立回放。
- `/data1/Kane/HyZor`、历史模型、数据、日志和结果只读；新工作仅写入本实验
  树的新文件/目录并带 provenance，不覆盖旧源文件、冻结清单和失败结果。
- 旧资源、完整物理存储、证据、见证和测试要求保持原作用范围；本修订不授权
  未预注册数值实验、真实网络执行或生产集成。纸面定义/文献研究不是数值过门。

就免除新组合的完整验证。
