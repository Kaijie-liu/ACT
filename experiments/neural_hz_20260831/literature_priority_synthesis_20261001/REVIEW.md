# 跨领域文献对 Neural HZ 定义研究的优先级

应当跨出 HZ 借鉴研究，但下一步不应再扩大泛书单。当前最值得研究的是：让共同输入产生的非凸关系成为可操作的域对象，并让下一神经块真正使用这些关系。原 HZ 已能精确表示分段仿射网络；目标不是声称它不能表达依赖，而是设计有证明的关系语言与变换，在完整成本约束下获得更有效的验证。

本轮按用户要求核查原始论文和项目记录，只做文献综合。已有综述已经涵盖抽象解释、析取优化、控制、符号多项式、知识编译和约束消元。本文件的增量是明确优先级、移植边界和下一项可证伪问题，不把这些机制重复记为发现，也不是完整系统性综述或新颖性认证。

## 优先借鉴的机制

### 复合变换决定研究粒度

论文事实：[Pasado，OOPSLA 2023](https://ece.is/assets/pdf/Pasado.pdf)，§1、§4，直接为自动微分的复合表达式设计抽象变换，而非仅顺序组合原语变换。其具体实现含采样回归和有证明的误差包络。

项目推断：把普通 Conv 或 Affine → ReLU → 混权 Affine → ReLU 作为关系设计单位；这与融合计算内核不同。借鉴抽象粒度，不迁入采样流程、不复制其凸载体，也不声称其光滑表达式定理已经覆盖我们的 ReLU。这个设计原则已知，不能单独算新域贡献。

### 约化积要求关系参与后继变换

论文事实：[Synthesizing Abstract Transformers for Reduced Product Domains，SAS 2024](https://arxiv.org/html/2408.04040v1)，§3.2，允许一个组件的变换读取其他组件的信息；在受限变换语言下，分别选择组件的最优变换不自动得到最优组合。其 §4 算法采用 1-precision，不是全局最佳组合保证。

项目推断：连续幅值、原二元相位和共同观察不能只是三个并列缓存。下一 ReLU 生成约束时应使用它们在同一原输入上的关系。现有共同规范实现证明提供一个组合合同，但“约化积加辅助量”仍是已知框架；需要进一步形成具体关系语言、前向变换和可检查的适用定理。不部署论文的逐实例动态合成流程。

### 函数摘要区别相同值域和相同对应关系

论文事实：[Goubault、Putot、Védrine 的 Modular Static Analysis with Zonotopes，SAS 2012](https://www.lix.polytechnique.fr/Labo/Sylvie.Putot/Publications/sas12.pdf)，§2.2、Example 2，区分几何值域和输入输出关系。两个表达式 (epsilon1, epsilon2) 与 (epsilon2, epsilon1) 覆盖相同方形，但保持原输入身份时是不同函数摘要。

项目推断：Neural HZ 的观察必须说明“哪个共同输入产生了这些值”，而不只保存各自值域。这个原则尤其适用于同源分支经过不同混权映射后在 Add 合流。借鉴函数摘要语义，不借其凸域载体或动态上下文分区。共同 Gamma(theta) 与该已知原则相符，不能独占为我们的新理论。作者 PDF 经只读网络流提取复核，浏览器工具对此地址返回 403，没有修改或下载到历史目录。

### 扩展表述帮助选择条件贡献

论文事实：[Tsay 等的 Partition Based Formulations，2021](https://arxiv.org/pdf/2102.04373)，§3、Proposition 1，以分组条件部分和的辅助量表达一族投影约束，展示辅助变量数量与无辅助约束数量的交换。[PRIMA](https://arxiv.org/pdf/2103.03638)，§3.1、§5，通过神经元组构造联合输入输出约束，其 Split Bound Lift 算法包含区域切分和递归合并。

项目推断：优先保存实际消费者需要的共同贡献，而非给每个神经元复制全部条件源。索引分组与在线输入 split 不同；但 PRIMA 的具体切分算法不迁入。Tsay 的优化式界收紧或搜索流程也不迁入。保留完整原非凸 HZ 可以使用已证有效关系，不代表这种扩展表述本身是新抽象域。

### 控制与非线性可达性提供语义对照

论文事实：[Aydinoglu 等的互补系统研究](https://arxiv.org/pdf/2011.07626)，§3.1、Lemmas 1–2，将 ReLU 和多层网络写成线性互补问题；单门对应 y≥0、y−g≥0、y(y−g)=0。[Sparse Polynomial Zonotopes](https://arxiv.org/pdf/1901.01780)，§II、§III，以具名 dependent factors 保留符号之间的依赖。

项目推断：可以从这些语言中学习怎样直接表达非线性关系、怎样在合流时识别同一来源；不能把 HZ 整体替换成 LCP 或多项式域，不能删除原二元标签。共享 ID 和 ReLU 的互补等价式本身均不是我们的创新。暂不另开 SDP 或多项式升阶路线，以免分散当前可执行问题。

用户最早提到的 [ImageStar](https://arxiv.org/pdf/2004.05511)，§3、§4，同样应作为重要对照：图像形状的生成元和共享谓词适合 CNN 操作；但仅将生成元张量化不足以完成定义创新，其精确分析中的集合切分也不能照搬。

## 把阅读收敛到一个结构问题

建议维持当前主线：研究普通混权块中，实际线性读出 v=Wq 的共同条件观察。对全部观察使用同一个原状态 theta，语义为 v_s=pi_s Wq(theta)，其中 pi_s 来自固定小组原相位的代数指示量；不枚举全网相位，不生成分支子问题。后继预激活分解为 h=Cv+r 时，完整残余 r、偏置、旁路与其他消费者均须保留。

这里的研究对象必须是观察语言、具体化和生成及消费观察的统一变换。若实现最终只是原 HZ 加一批已知有效行，就如实归类为表述强化，不以改名宣称新域。原 HZ 加完全相同行应当作为对照；相同终端约束不会因名称获得不同逻辑精度。

下一项检验先落实现有共同观察的混号权重、完整残余和可靠浮点实现，不另开无关候选。其后可优先考察普通双分支 Add → 混权 Conv → ReLU：在分支对相关后继确实只通过合流值 Z 读出的结构中，能否共享 Z_s，少于逐分支建立条件输出的辅助开销，同时保住下一 ReLU 的严格增强。若还有其他消费者，就必须覆盖，不能为节省删去。这个后续结构假设尚未预注册或执行，不替代当前资格顺序。

这个问题有明确的否证方式：下一层不能消费该关系；收益完全由已有相同行解释而没有新的变换或成本贡献；或计入源展开、舍入、谓词、终端及重构后成本优势消失。GPU 可批处理只是待测实现方向，不是已取得的加速结果。不把全网低秩、任意深度无损闭包或全局理想凸包新增为前提。
