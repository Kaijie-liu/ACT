Registered before C113 tests or measurements. C112 mathematical qualification
passed, but neither a real source bound nor global allocation was established.
This candidate implements the missing preparation/allocation/consumption in
the actual complete C107 source producer, not only a standalone row wrapper.

the original transform/output maps, full raw forms and exact routes in one
local preparation object tied to the same work pool. No factor is allocated
until every selected tile has an exact retained-factor count. Consume each
object exactly once; no second topology/key computation and no persistent
input-dependent cache. Keep the same full quotient, including partial overlap.

Add a fixed 64+8*original_retained_V preparation inventory bill per tile before
computing omission counts, omitted raw defining nnz and routed consumer count.

cap or C99 credit is silently changed to manufacture a passing real bound.

source rows and complete dense transformed kernels before final auxiliary,
UID, ownership and inverse allocation. The already-owned source maps and
transforms remain reachable through local preparation until consumption; no
oversized old owner array is retained behind a slice. Exact factor omission
decreases the original auxiliary/row/nnz upper populations, while all alias
consumers and the new inventory work are included. Changed native packets
must fit the complete revised bound and retain the old positive-pivot and
literal finite/window checks. One source/branch work pool spans all tiles.
