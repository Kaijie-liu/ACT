# C52 source-first signed congruence contract

## Set identity and source induction

Use the original global continuous frame xi in[-1,1]^N and the SAME binary
frame beta in{-1,+1}^B. Every fresh source definition has a positive pivot
and references only previously declared factors. Output maps are complete;
their nonzero continuous support protects directly observed factors.

Inductively, every already eliminated coordinate satisfies xi_j=s_j*eta_r
with s_j in{-1,+1}; every retained coordinate is a distinct original global
coordinate. Translate a new row through these identities and combine equal
roots exactly. If a value-dead fresh defining equality becomes
p*xi_k - s*p*eta_r=0, p nonzero and s in{-1,+1}, set xi_k=s*eta_r.
Its[-1,1] box is exactly redundant, not approximately contained. Otherwise
retain the complete translated predicate. All binary terms remain explicit.

The translated root r is older and permanently retained. Thus even long
signed chains have a direct root, no changing future representative, no
recursive witness search and no need to assume a future product check.
Later constraints and outputs are translated through the same shared root.
Positive/negative copies in different branches never become independent
convex factors. Ordinary same-root Add coalescing may reveal a new unit
definition that was not a raw two-entry row.

Forward: by induction, every original feasible point satisfies each selected
signed identity; projecting to retained global coordinates satisfies every
translated predicate and gives the same outputs. Reverse: extend a compact
point by the recorded signs. All original boxes hold, every removed definition
holds, and every retained EQ/INEQ predicate and output agrees exactly. Binary
coordinates and their nonconvex choices are unchanged in both directions.

This is not the old reverse-greedy independent frontier. Its sufficient
admission condition is exact signed-unit congruence AFTER established source
identities. Non-unit definitions remain explicit: the prototype does not assume
their future products, discard their boxes or repair them from solver status.

## Realization and scope

Source commands have unique original predicate UIDs, exact canonical f64 rows,
global integer columns and a complete topological definition sequence. The
continuous coefficient window remains[2^-20,2^40] in magnitude. Sign changes
are exact; collisions use the existing exact_sum guard. Any unsupported
arithmetic or malformed source rejects the whole unpublished transaction.
Zero-hit programs remain exact with an empty inverse and no reduction credit.

Only retained predicates reach the writer's row collection/CSR construction.
Inspecting a candidate definition still needs a row-sized temporary; the rule
does not pretend that source rows, temporary normalization, root maps or source
program data vanish. The output retains every kept global coordinate, a full
signed compact-to-original inverse, retained EQ/INEQ UIDs and removed UID/
coordinate pairs. All original continuous coordinates are reconstructible.

The state wraps a compact SparseHZ with explicit frame maps. Existing consumers
must NOT use its raw matrix indices as original global indices. A source/native
frame adapter and original network/INPUT/ASSERT binding remain unimplemented;
the prototype is default-off and never reaches a solver or a production path.
