# 宽层活幅值支付与相位容量的有限关系

本研究把 D246 仅处理共同尾项的关系推广到全部未选同层输入，保留这些输入的实际幅值，不再把全部差项提前变成常数区间支付。得到一个固定系数规则、该规则在明确支付类内的最优性证明，以及四个新增尾项产品的精确消元。它是原非凸 HZ 内的候选关系演算，不是新域已经成立或真实模型取得新解。

主要研究决定是：不实现四个仅作支付用途的尾项产品；也不把一个比廉价 Lipschitz 界更强、却已被旧完整单门关系排除的假点当作创新证据。本轮只有纸面证明和独立复核，没有数值候选执行。

## 保留同一个非凸状态

H 保留连续因子、全部原 signed binary bits、EQ/LE、共同 latent 和 frame、全部消费者及原输入 decoder。alpha_i 是原位的 0/1 仿射视图，不是新的或放松后的域因子。下面的分数 alpha 只用于有限终端松弛的代数比较。

沿用 [D245 合同](../d245_mixed_source_component_20261005/CONTRACT.md)的两个已归一化原父门 x_i、q_i=ReLU(x_i)、原位 alpha_i，x_i 在 [-1,1]。令 p_i=alpha_i-q_i。两实际子门完整写为

~~~text
g1 = z0+d0 + sum_k a_k Q_k,
g2 = z0-d0 + sum_k b_k Q_k,
d0 = tau*(q1-q2)+e0,  tau>0,
z0 = A1*x1+A2*x2+B1*q1+B2*q2+r0.
~~~

Q_k 是剩余同层的实际非负幅值，包含全部未选项，不是独立新输入。相同来源先按身份合并，稳定门忠实折叠，偏置、skip、区间参数 carrier 和其他活来源全部保留在完整式中。系数须有可靠绑定；不能把不确定参数的中点当成实际网络。

固定 core 条件仍为 D245 的混合相位界：在 alpha1 不等于 alpha2 时有 |z0|<=tau。完整 e0 有可靠 [Le0,Ue0]。六个原 core 观察及其完整 MC、三条 X 容量定义 K0=(alpha1-alpha2)*(z0+tau)，该等式在原整数语义下成立。这里不删除任何 core 条件，只将已显式列出的所有 Q_k 从 core 移到下面的精确分解。

记 D=ReLU(g1)-ReLU(g2)。空关系嵌入 H，追加有证关系仍投影到同一个原整数 H；全部旧坐标与 decoder 保留。没有声明新集合表达力、最佳抽象或完整格。

## 全部未选项的唯一固定分解

对每个原系数对固定取

~~~text
m_k = median(a_k,b_k,0),
u_plus  = sum_k max(m_k,0)*Q_k,
u_minus = sum_k max(-m_k,0)*Q_k,
R_plus  = sum_k max(a_k-b_k,0)*Q_k,
R_minus = sum_k max(b_k-a_k,0)*Q_k.
~~~

四个量都是同一个 H 的实际线性读出。用完整同源证据得到 0<=u_plus<=U_plus、0<=u_minus<=U_minus。R_plus、R_minus 保持活幅值表达式，不预先换成各自上端点。零组按同一个公式退化为零，不是根据成绩选择另一条路径。

该分解只依数学系数，不读实例身份、公开标签、性质方向、margin、LP 状态或对偶信息。它不寻找相位、运输矩阵或最优支持点。

## 健全的双侧关系

在原整数语义下，统一加入

~~~text
D-K0 <= 2*tau*p2 + 2*max(Ue0,0)
        +alpha1*u_plus+alpha2*u_minus+R_plus,
-D+K0 <= 2*tau*p1 - 2*min(Le0,0)
        +alpha2*u_plus+alpha1*u_minus+R_minus.       (T)
~~~

证明分两步。先给两个子预激活同时加 u_plus-u_minus。D246 对共同均值移位的单调性证明，配合 core 条件和 d0 的 2-Lipschitz 支付，给出 (T) 去掉 R 项的版本。再加入剩余读出

~~~text
v1=sum_k(a_k-m_k)*Q_k,
v2=sum_k(b_k-m_k)*Q_k.
~~~

ReLU 的单调及 1-Lipschitz 性使上侧增量至多 (v1)_+ +(-v2)_+，下侧至多 (-v1)_+ +(v2)_+。因 Q_k>=0、m_k 在 a_k 与 b_k 之间，逐项支付分别恰为 R_plus 和 R_minus；求和前不丢任何来源项。得到 (T)。这只使用前向标量不等式，没有运行相位 split 或辅助验证算法。

与 D246 不同，所有未选差系数均由 R_plus/R_minus 同源消费，不能又漏回 e0 或在账本中重复、遗漏支付。未选 Q 的上界不再进入 core 混合守卫，但仍进入尾项产品范围、原 H 和最终查询；很宽的 R 项依然可能使结果毫无用处。此结论不保证宽层有精度收益。

## 固定中位数在这一支付类内同时最优

对一个 Q>=0、任意实共同移位系数 m，以及任意 0<=alpha1,alpha2<=1，定义

~~~text
P_plus(m) = alpha1*m_+ + alpha2*(-m)_+
            +(a-m)_+ +(m-b)_+,
P_minus(m)= alpha2*m_+ + alpha1*(-m)_+
            +(b-m)_+ +(m-a)_+.
~~~

同一个 m*=median(a,b,0) 同时全局最小化这两个支付函数。证明令 I=[min(a,b),max(a,b)]，有恒等式

~~~text
(a-m)_+ +(m-b)_+ = (a-b)_+ + dist(m,I).
~~~

f(m)=alpha1*m_+ +alpha2*(-m)_+ 非负、在零处最小且 1-Lipschitz。对 p=proj_I(m)，f(m)+dist(m,I)>=f(p)>=f(proj_I(0))。于是 m* 最小化上侧；交换 a、b 及两个 alpha 后同理得到下侧。等号可能不唯一，但固定中位数始终有效，包含系数零和相位端点。

这是“逐个非负原幅值、共同移位、逐项单调和 Lipschitz 支付”这一明确类的最优性，不是全 H、聚合 MC 后的投影、任意相关源残余、终端方向或所有 Neural-HZ 的最优性。它否定在这个固定类里继续调共同移位系数寻找更强支付的必要性；不禁止利用真正额外的共同源信息。

后一个限制有普通严格反例。取两个未选 Q 在 [0,1]，两子系数均为 (a_k,b_k)=(1,1)，alpha1=1/2，当前 Q=(1/10,9/10)。中位数 (m1,m2)=(1,1) 给共同 u=1、Uu=2，其聚合 MC 上支付为 min(u,Uu*alpha1)=1。另一个事前固定分解 m=(0,1) 将第一项按两侧 Lipschitz 单独支付，上侧为 Q1+min(Q2,alpha1)=3/5，反而更紧。整数点态上 alpha1*(Q1+Q2)<=Q1+alpha1*Q2 始终成立；反转来自聚合 MC 遗忘分项来源，不是中位数定理失效。这里不授权按当前查询点选择分解。

更直接地，Q=(1/10,9/10) 与 Q=(1/2,1/2) 都给同一个 (u,Uu,alpha1)=(1,2,1/2)，逐项 MC 上端之和却分别为 3/5 和 1。只保留这三个聚合数不能精确保留所有分项条件容量。逐项产品或更多容量行可以恢复这部分信息，但须支付真实 O(k) 观察/谓词支持；四个聚合尾项产品不是完整宽源条件信息的无损替代。

## 无其他消费者时精确消去四个尾项产品

若 alpha1*u_plus、alpha2*u_plus、alpha1*u_minus、alpha2*u_minus 只出现在各自完整 MC 和 (T) 中，四者可以精确存在量投影，不新增连续列。固定保留变量后，w=alpha*u、0<=u<=U 的 MC 区间是

~~~text
max(0,u-U*(1-alpha)) <= w <= min(u,U*alpha).
~~~

四个产品各只在一条支付的右侧出现，故其上端可以同时取到。这没有改变共同 u 或 alpha，只是在该有限线性系统中构造辅助变量的可行扩展。上侧令

~~~text
A=D-K0-2*tau*p2-2*max(Ue0,0)-R_plus,
~~~

则精确投影为四条

~~~text
A <= u_plus+u_minus,
A <= U_plus*alpha1+u_minus,
A <= u_plus+U_minus*alpha2,
A <= U_plus*alpha1+U_minus*alpha2.
~~~

下侧用 B=-D+K0-2*tau*p1+2*min(Le0,0)-R_minus，并交换两个 alpha，生成同样四条。一个非零尾组时每侧仅两条不同的行；两个组为零时恢复原两条 core defect。全部行同时生成，不按求解结果择优。

该消元对所列有限线性关系精确，但不是原非线性四产品图的连续相位精确凸包声明。原位整数时产品本来唯一，故原 H 的整数投影和具体输入重构都保留。如果产品已被其他谓词、共同观察一致性或后继消费者引用，就不能逐处消元或删除它们。

## 强度审查排除了一个假阳性

投影版严格强于只用 u_plus+u_minus 的廉价支付，但这不足以证明新域能力。取 tau=1、z0=-9/10、e0=0、u_minus=0、u_plus 在 [0,7/5]。在分数点

~~~text
alpha=(3/5,0), q=(3/5,0), x=(1/5,-1/2),
u_plus=7/5, (Y1,Y2)=(11/10,0), K0=3/50
~~~

上侧廉价界为 73/50，无守卫饱和 cap 为 6/5，都接受 D=11/10；相位尾项投影却给 D<=9/10。因此有有限弱参照分离，不需要在终端人为减去尾项。

然而原父 q1=ReLU(x1)、x1 在 [-1,1]，在 q1=alpha1=3/5、x1=1/5 时，其真实混合被强制为质量 3/5 的 x1=1 和质量 2/5 的 x1=-1。u_plus 在真实上端也迫使每个原子保持该值。完整第一 child 前缀给 Y1=11/10，完整第二 child 前缀给 Y2=1/5，故差为 9/10；显示点的 Y2=0 已被旧参照排除。相位尾项规则并未在这个控制上超过强单门来源参照，不能把它登记为新增强能力。尾项可由普通的多个未选非负 Q 相加实现，不改变这个反证。

另外，仅在上述两子尾系数相同、没有剩余活差项的共同尾控制中，单独饱和参考可写成 4 条 0 新列行：上侧 D<=2*tau*(alpha1+p2)+2*max(Ue0,0) 及 D<=2*tau*(1-q2)+2*max(Ue0,0)，下侧对称。这是 D239 自由 clip 投影已经含有的容量，不重新计作本轮创新。若一般 a_k 不等于 b_k，必须使用完整 e=e0+sum_k(a_k-b_k)*Q_k/2 的可靠界，或另给足额的活差支付；不能只用 e0 套用这四行。

## 完整成本和研究选择

保留 D245 六个 core 观察。完整 24 MC、3 条 X 容量、至多 8 条投影 defect，共 35 LE；六观察显式范围另 12 LE，因此至多 6 新连续列、47 LE，不新增原位。这里的“新”相对原 H，不是再向已建 D245 对象重复分配六列。

沿 D245 的已有单列 x/q/Y 合同，令 r0、u_plus、u_minus、R_plus、R_minus 的实际内联非零支持为 sr、splus、sminus、sRplus、sRminus，关系 nnz 安全上界为

~~~text
164+4*(sr+splus+sminus+sRplus+sRminus),
~~~

显式产品范围再加 12 nnz。R_plus 在四个上行重复消费，R_minus 在四个下行重复消费，不能只付一次支持费用。实际相消、零系数和重复行可按精确身份减少计数，但不预扣尚未实现的节省。原 x/q/Y 若为多项视图，还须支付它们的实际展开。

全部系数读取、同列合并和四组形成至少按实际输入与支持规模付账；来源展开、core Gram、可靠界、参数误差、原 H、EQ/LE、全部消费者、终端转换和求解、证据、decoder 及 CPU/GPU 共存另计。四产品版可能列更多但行更稀疏，所以零额外列不等于整体更快。

单调残余组合已有 [D061](../d061_multiway_rectifier_relation_20261001/THEORY.md)，共同尾项已有 [D246](../d246_source_tail_transfer_20261005/THEORY.md)，自由 clip 投影及其强参照边界已有 [D239](../d239_phase_supported_reference_20261005/THEORY.md)。本轮新增的项目推导是完整活差项的固定分解、该支付类的统一中位数最优性、适用边界和完整费用，而非首次发现单调性、MC 或线性投影。

当前没有通过完整强来源参照的新物理阳性，也没有三个真实模型的可靠全源适用率；不为弱控制新建数值 runner，不默认启用。下一数学突破应利用原共同源与相位的额外不等式容量，或证明同信息下的完整精度与成本优势，而不是继续调本支付类中已证明最优的移位系数。
