# 共同源在标量消费中的精度损失

本分析定位已完成来源试验的两处保守投影，并给出一个改善确实能穿过跨零后继的严格纸面对照。它解释为何不能用该试验的零收益否定完整仿射关系，也明确这不是新的曲率公式或真实网络收益。没有修改、导入或重跑已冻结代码。

## 被丢弃的信息

`source_query.py` 的 `_bounds` 在计算端点项时，对同源 f 和 h 分别求范围后相加；其 residual 补偿又将每个 ReLU(w_i r_i) 分别取常数上界。`census.py` 传入的是 residual 区间，之后还把不同组的标量区间相加。因此该来源实验测到的是合同所声明的保守标量后果，不是 `mixed_transfer.py` 的全部共同仿射包络强度。

原 BN 区间也可能丢失固定参数相关性，但本轮没有归因实验，不把它断定为主因。下面仅证明上述两处源信息损失可以实质影响结果，不对 1600 个真实读出预测收益数。

## 一个有偏置和非零残余的完整对照

令 x,y,z 均在 [-1,1]，R 为 ReLU，所有门保留自己的原 signed phase，零点两个标签均合法。定义

```text
f = x + y/5 + 1/10
h = -x/4 + y + 1/5
g0 = f
g1 = (3f+h)/4 + z/20
g2 = (f+h)/2
g3 = (f+3h)/4 - z/20
g4 = h
w = (-1/2, 1, -2, 1, -1/2)
F = sum_i w_i R(g_i)
child = R(F+1/2).
```

等距 knots 为 0、1/4、1/2、3/4、1。共同核 K 的最小值 L=-1/4，最大值 U=0；可直接在五个 knots 上计算得到 K=(0,0,-1/4,0,0)。两端加权系数都是 -1/2。上包络中的 R(f)、R(h) 系数因此精确抵消，得到

```text
F <= -(f+h)/4 + R(z/20) + R(-z/20).
```

来源算法分别取 f∈[-11/10,13/10]、h∈[-21/20,29/20]，端点上界为 11/40+21/80=43/80；两个独立 residual 上界各为 1/20，总上界为 51/80。

共同源版本先合并两条可靠割线：R(z/20)≤(z+1)/40、R(-z/20)≤(-z+1)/40，合计只有 1/20。再利用 f+h=3x/4+6y/5+3/10，其负四分之一的盒上界为 33/80。因此 F≤37/80，比前一算法严格小 7/40。

原逐门区间的 F 上界为 47/20，不会截掉两种上界的差异。经过同一个原 child，两个上界分别为 91/80 和 77/80。child 确实跨零：在 x=y=-1,z=0 时预激活为 1/2；在 x=y=1,z=0 时为 -5/8。这不是靠稳定负门制造不可消费的改善，也不是新 ADV。

这是同一已知共同曲率公式的两种消费方式的比较，不是与完整 HZ、完整 group hull 或全部已知有效关系的分离。非零有界残余、偏置和严格差都在例中保留；有限表达式的连续性使足够小扰动仍保留某个正差，但未认证通用扰动半径。

## 可以精确保留什么

给定同源 residual r_i=a_i·theta+b_i，两向可靠仿射割线记为 U_i^+ 和 U_i^-。任意真实混权 w 的已选补偿可以写成

```text
sum_i max(w_i,0) U_i^+(theta)
  + sum_i max(-w_i,0) U_i^-(theta).
```

若所有这些割线的系数行 V 都满足已认证分解 V=D P，则共同观察 z=P theta 可以对所有 w 精确保留这些已选仿射表达式。必须同时保留 z=P theta、原 HZ、全部二元因子和 decoder；把 z 再独立盒化通常不保留消费结果。在具有内点的源区域上，所有行能这样恢复的充要条件是 ker(P)⊆ker(V)：必要性由同一 P 纤维上的可见方向得出，充分性为普通线性因式分解。

这是一条观察语言的商条件，不是新的非线性抽象域。低秩 residual 源也不意味着其 ReLU 响应低维：一维源上的不同偏置门已有任意多个不同折点。下一激活引入新方向时，必须重新给出可靠关系或误差合同。
