# 端点关系的线性外包与完整成本边界

本页给出可以继续检验的实数合同，不是实现、预注册实验或浮点资格。终端仍为普通原 LP/MILP；不迁入非线性、SOC、SDP、dual rescue、BaB 或 split。

## 认证输入和四条乘积外包

在保持同一源绑定的前提下，若已有正概率盒，则由对数均值的单调性得到：

```text
L(p_lower_i,q_lower_i) <= lambda_i <= L(p_upper_i,q_upper_i).
2 lambda_i <= p_i+q_i.
```

全部 lambda 的和≤1 已由最后一式和两端 simplex 推出，不再把它当成独立新收益。有限 logits 的真实概率为正，不等于浮点盒一定能认证正下界；不满足可靠前提时不安装此块，不能据此宣称 SAFE。对数均值的可靠区间计算尚未实现。

逐赋值有 min_i d_i≤c≤max_i d_i。注意这不是对所有 i 同时 c≥d_i 且 c≤d_i。外包先使用认证的全域标量区间 c∈[c_lower,c_upper]，再为 h_i=d_i−c 取得有效区间 [a_i,b_i]。

记 lambda_i∈[l_i,u_i]，z_i=p_i−q_i。直接对 z_i=lambda_i h_i 施加四条 McCormick 行：

```text
z_i >= l_i*h_i + a_i*lambda_i − l_i*a_i
z_i >= u_i*h_i + b_i*lambda_i − u_i*b_i
z_i <= u_i*h_i + a_i*lambda_i − u_i*a_i
z_i <= l_i*h_i + b_i*lambda_i − l_i*b_i.
```

这里 z_i 可以是已有概率列的差，h_i 可以是已有 score 读出减 c，不必再创建一个独立乘积列。但实际 HZ latent 支撑展开与舍入仍要付费，不能把每个读出视为单一物理列。

lambda 盒、上述四行及算术平均界只是精确关系的外包，并不证明其中每个伪赋值的 lambda 都等于真实 logmean。例如 p=q=(1/2,1/2)、d=0、c=0、lambda=(2/5,2/5)，放在有效盒 p,q,lambda∈[1/4,3/4]、h∈[−1,1] 中，满足四行与算术平均界，但真实 lambda 应为 (1/2,1/2)。这仅证明辅助语义不精确，不是无效网络输出或 ADV 的例子。

更直接的非蕴含例为 p=(3/5,2/5)、q=(2/5,3/5)、s=log(p)、t=log(q)、c=0、lambda=(2/5,2/5)，仍取上述宽盒。令 ell=log(3/2)，有 1/3<ell<1/2；四 MC 全通过，但 zᵀd=(2/5)ell<1/5，而 (2/S)‖z‖²=1/5。因此依赖当前松弛 lambda 的加强关系并非四行的逻辑后果，甚至不能仅由两端各自为真实 Softmax 推出。真实原状态仍有规范 lambda 扩展；若另加有效约束，应重新用共同扩展证明健全性，而不是要求所有伪 lambda 都保留。这里不添加二次求解器，也不把该例记作网络 ADV。

## 任意动态 value 的实际费用

若两端的 PV 乘积已经保留，可重用相同身份并取差。当前 inspected fused 不能免费提供这些乘积，直接方案可以新建 T_ik=(p_i−q_i)V_ik，使用完整 signed McCormick，再安装 Delta_Y_k=Σ_i T_ik。需要 NC 个而非 2NC 个产品；两端 Delta_Y 必须来自原同源输出读出。

若 V 是固定常量，这一步退化为线性映射；真实 D107 图的动态 V 不能未经认证按常量处理。若用 V 的中心及剩余范围消去部分产品，余项仍须完整保留，不能在本账单中预先抹去。

每个端点对的基础账单为 N 个 lambda、一个 c、4N 条割线乘积行、N 条算术平均行。直接动态 value 方案另加 NC 个产品、4NC 条乘积行和 C 条输出等式。概率若未保留，还需两个 N 维概率接口及其全部来源、simplex、界和有效图外包；重复锚的概率必须按身份复用，不能计成免费。

## 两个真实布局上的纸面计数

仅为核算一种固定日程：每个已认证 batch/head/layer 组按原 query 顺序取第一 query 为锚，连接其余 m−1 个 query。该日程统一依赖结构，不读取实例身份或终端状态；不是已选择或已预注册的候选算法，也不等于全部 query 对闭包。

同结构张量操作原则上可批处理，但可靠 transcendental 界、稀疏源展开和终端求解仍未实现；没有 GPU 或速度证据。

## 决定

不启动这个直接全乘积实现。首先需要真正 PV 读出的强参考正控制，以及不隐藏动态 value 成本的统一生成和消费规则。若新的行已被完整旧参考蕴含，或必须靠额外大规模产品才有作用，记录该具体否定结论并调整定义。当前没有证据否定所有割线模块，也没有证据授权默认启用或更新成绩。
