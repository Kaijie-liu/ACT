# 联合容量消元的物理控制与适用边界

本页验证新增结构定理保留了真正的多门物理关系，而不只是标签一致性。正控来自旧三门关系的私有输入扩展，不重记为新发现或正式收益；反控说明 COVER 和标量 private 接口的限定都不能删除。

## 非平行偏置三门的联合物理控制

沿用 [D175 的 K、共同源点与源矩](../d175_joint_phase_physical_projection_20261004/THEORY.md)：

```text
K=[[1,1,1],[1,1,-1],[1,-1,0]], z in [0,1]^3,
b=(-1,1/100,1/100), h=Kz+b,
R=(3,3,2), p_i in [-R_i,R_i] independent,
g_i=p_i+h_i, q_i=ReLU(g_i).
```

h 的三个范围为 [-1,2]、[-99/100,201/100]、[-99/100,101/100]，所以 COVER 有严格余量。全部门非平行、偏置非零，源维数及 private 范围非退化。

任意共同自由源与相位混合满足旧 I3322 关系

```text
sum_(i,j) K_ij*E[beta_i*z_j] <= beta1+2*z1+z2.
```

由每门两个容量上界取平均，得到 q_i<=p_i/2+R_i/2+B_i，故整个联合接口满足

```text
F=sum_i q_i - (sum_i p_i)/2 -2*z1-z2
 <= 4+(beta2+beta3)/100 <= 201/50 = 4.02.
```

后继为一个真实混权且有 private/shared live skip 的门

```text
r=ReLU(F-161/40),   161/40=4.025.
```

新接口证明其恒为零。读出可同时保留整个 q 向量及任意其他混权消费者，不需丢掉旁路或降低消费者秩。

旧假点仍通过每一对门的完整 source-labelled joint hull。取

```text
z=(2/5,2/5,1/2), beta=(3/5,3/5,1/2),
p=(3/5,3/5,0),
q=(93/40,1153/500,241/200).
```

对 [D175 的每对真实见证](../d175_joint_phase_physical_projection_20261004/PAIR_HULL_STRICTNESS.md)，将所选门的 private 值设为 R_i*(2*s_i-1)。因为 COVER，所选门的真实符号严格正确；其幅值就是原 D175 幅值加 R_i*s_i。均值恢复上述 p、q，所有共享源矩与 pair phase 共现保持原值。未选的 private 输入可逐原子取该坐标的目标均值，故完整原输入 z,p 也被所选 pair 的见证恢复。

这些 pair 的原相位边缘还兼容同一个纯三相位分布，但没有共同神经源混合。假点 F=1009/250=4.036、r=11/1000。联合物理行排除它，重新选择未观察辅助矩也无法绕过该行。这是查询层分离，不是原生整数点、具体反例或实测 CERT。

此控制使用已知 I3322，且本质精度分离已经存在于 D175。这里新增的是它确实位于 COVER 类，从而新消元在有用的联合物理例子上不丢精度。完整三门 hull 和拥有同一有效行的旧 HZ 也能证明后继恒零；本轮没有超越它们。

## 有回路且可线性扩展的结构类

有界宽度并非只能处理已经被单门 hull 解决的树。考虑周期邻接源，每个共享标量只进入相邻两个门，且 private 区间满足 COVER。相位关联是一个环；固定 bags {1,i,i+1}，i=2..k-1，给宽度2的 running intersection 分解。因此完整的一层联合神经 hull 有线性规模扩展，而不需2^k全表。它不是一般二维卷积的小树宽证明。

一个明确四环为 x in [-1,1]^4，private p_i in [-3,3]，

```text
h=(x1-x4, x2+x1, x3+x2, x4+x3)+(1,2,3,4)/10,
g=p+h, q=ReLU(g).
```

共享线性矩阵满秩4：零像先给 x2=-x1、x3=x1、x4=-x1，再由 x1=x4 得全零。故不是靠某条零 affine circuit 制造的精度例子。COVER 具有至少3/5余量。无偏置部分的绝对值和在整个盒上不超过6：在每个盒顶点，四项各为0或2，不可能全为2，因为后三项要求所有相邻符号相同，而第一项要求相反；凸性将顶点界延伸到全盒。加偏置后 sum|h_i|<=7。

所以同一完整父接口有

```text
J=sum q_i-(sum g_i)/2 = sum|g_i|/2 <= (12+7)/2=19/2.
r=ReLU(J-39/4)=0.
```

完整 singleton hull 的交却允许 x=p=0、所有 beta_i=1/2，并取 q_i=(49+i)/20。每个所选门单独使用等权真实两点：private 为正负59/20；令其两个共享坐标取符号适当的正负39/40，使 h 的线性部分为正负39/20；其余源取零。这些源和 private 都严格在盒内，active/inactive 均有严格符号余量；混合给 q_i=(49/10+i/10)/2。此旧点 J=49/5、r=1/20。完整 q、任意混权读出及原 g/source skip 均可保留。

两组 bags {1,2,3} 与 {1,3,4} 的共同关系及四容量给完整联合 hull，因而拒绝旧点。一般周期结构的关系费用见 COST_AND_NEXT.md。但这一单项性质也可由相同源信息的旧绝对值预算证明；不能把它当作比所有已有关系更强的新能力。它验证的是“有回路且有真实联合精度的普通结构类”落在精确线性扩展定理内。

## 没有覆盖条件就不能宣称理想

取 x,y in [-1,1]，三个相互独立 private p_i in [-1/10,1/10]，并设

```text
h1=x+y+1/10, h2=x+1/20, h3=y+1/20,
g_i=p_i+h_i, q_i=ReLU(g_i).
```

该普通结构不满足 COVER。考虑一个真实自由源与标签混合：质量各半，源分别为 (9/20,9/20) 和 (-11/20,-11/20)，标签分别为 100 和 000。它的共同源均值为 (-1/20,-1/20)，beta=(1/2,0,0)，B=(1/2,0,0)。取 private 均值 p=0、q=(1/2,0,0)。全部四容量成立：h 均值为零，第一门两个上界均为11/20，另两门至少允许零。

但在真实神经图上，h1=h2+h3，所以

```text
q1 <= q2+q3+ReLU(p1-p2-p3),
q1-q2-q3 <= 3/10.
```

假点给1/2。因此 ReLU(q1-q2-q3-2/5) 在真实图上恒零，却在这个未覆盖的查询外包中可为1/10。它说明不带 COVER 的 CAP 仍是健全外包和整数精确图，却不是一般的联合凸包。该反控只界定定理前提，不开辟需要特调的新实验族。

## 私有原像问题不会被覆盖条件修复

[D194 的原像控制](../d194_sparse_crossing_source_fiber_20261005/CONDITIONAL_FIBER.md)已经足够：xi1,xi2 in [0,1]，p=xi1+xi2，g=p-1/2。把 p 看作 [0,2] 标量 private 时，COVER 成立。均值 xi=(1/10,9/10)、beta=1/2、q=3/4 通过标量 CAP，却违反完整像素图的有效行 q<=xi1+beta/2=7/20。

故保留原像素均值和 decoder 不等于保留它们的全部条件分布。应用于真实卷积时，所有原源和关系继续存在；本轮定理只授予声明的 scalar-private 投影理想性，不能宣称完整 75 像素或全网络理想性。

## 与定义主线的关系

D198 否定的是仅聚合一阶系数与源纤维就超越完整单门 hull。本轮明确引入共同多相位表及其源条件矩，并证明一个允许删除其私有部分的神经结构条件，因此不属于被该包含定理排除的对象。但它没有绕过代价：关联宽度、完整 source、条件矩、全部父谓词和 terminal 都要付费。

没有把示例、一次后继恒零或辅助量下降当成域研发完成。需要继续验证同一规则在普通真实结构上的覆盖率、同信息强参照、完整成本与递归范围，才可能推进默认关闭的候选。
