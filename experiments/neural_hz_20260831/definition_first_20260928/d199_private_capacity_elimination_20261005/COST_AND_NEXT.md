# 联合纤维的完整局部费用与后续研究条件

新定理减少指定联合查询接口的扩展费用；没有证明整个网络更小或更快。公平比较须先让旧完整条件源表示也使用同一个 COVER 条件，不能把旧通用版本的全部费用都记为本轮节省。

## 指定的有限线性编码

共享源已可靠规范到 [0,1]^d。设相位 bags 为 C，树边 separator 为 S，令

```text
L=sum_C 2^|C|,
M=sum_j 2^|I_j|.
```

不物化相位边缘和 B，不删除表格冗余：新连续量为 L+M；LE 为 L+2M+4k；EQ 为 1+sum_edges 2^|S|+k+d。EQ 使用一个 root 归一化、每条树边完整 separator 一致性、每个 bit 一次边缘和每个 source 一次均值。原 z,p,q,beta、private/source 界、原 guards、旧谓词、全部输出读出与 decoder 是公共保留接口，不包含在此增量内。

I_j 是实际非零结构；每个 I_j 必须包含于某个 bag。给定 bag 宽度 w 的表费仍指数于 w，不声称寻找最优树分解免费。没有实际生成全局 phase 表或求解子相位；四门中心覆盖四个 bits 时，本例仍须保留16个相位质量，不能借局部术语隐去。

对 CONTROL_AND_SCOPE.md 的周期局部带，k>=3、d=k，每个源 incidence 大小2，给定 bags {1,i,i+1} 有 k-2 个三元表和 k-3 个二元 separator。因此指定编码有12k-16新连续量、20k-16 LE、6k-11 EQ。这个完整一层 joint hull 的线性扩展结论不同于无回路 singleton 已足够的情形；但仍是结构定理，不是新颖性、执行复杂度或实际网络命中的认证。nnz、原源和全部公共关系仍按实际展开另付。

## 四门真实形状的符号账

[D194 已有只读几何](../d194_sparse_crossing_source_fiber_20261005/REAL_TARGET.md)为同通道相邻 2x2 首层 crossing 门：27 个共享原输入中，24 个关联两门、3 个关联四门。每门15个声明共享系数，私有12像素只形成一个 scalar p_i；COVER 尚未获得实际系数证据。这里仅代入这份形状，不能说真实网络已通过定理前提。

用一个四 bit bag，L=16，M=24*4+3*16=144。两种保持同一局部精度的确定编码比较如下：

| 表示 | 新连续量 | LE | EQ | 矩阵 nnz 上界 |
| --- | ---: | ---: | ---: | ---: |
| COVER 后完整条件源，B 内联 | 448 | 896 | 32 | 2875 |
| 稀疏关联条件源，B 内联 | 160 | 320 | 32 | 1435 |
| COVER 后完整条件源，B 物化 | 452 | 896 | 36 | 2411 |
| 稀疏关联条件源，B 物化 | 164 | 320 | 36 | 1259 |

这些不是测量，不含公共原输入、原 private 读出定义、其他消费者、原 guards、旧父谓词、RHS、metadata、证据或 slack。nnz 按声明系数非零且无消项计上界，不能冒充实测稀疏度。

稀疏 B 内联账可复核如下。lambda 非负16 nnz；mu 非负144；pair 源的96个上界各含 mu 与4个 lambda，计480；四相位源的48个上界各2项，计96，核心 LE 共736。核心 EQ 为归一化16、bit 边缘36、源和171，共223。每门 B 含48个 mu；四容量的 nnz 分别为1、17、50、51，四门共476。总和1435。物化 B 的四定义共200 nnz，四容量共100，合计1259。

完整条件源核心有16 lambda、432 z_s。其核心 LE 为1312 nnz，EQ 为511。B 内联后的四容量共1052，合计2875；物化 B 的定义488加容量100，合计2411。准确归一化会改变 b、L/U 和读出，不能只删系数而不做这些转换。

[D196 通用容量](../d196_joint_guard_capacity_20261005/COST_AND_REFERENCE.md)原为512新连续量、1088 LE、32 EQ；COVER 使其64个 epigraph 与192条单元行本来就可删除，得到上表公平的448/896/32。之后的稀疏关联投影才进一步变为160/320/32。不把512到160全部称为一个新发明，也不称160是最小扩展。

已有 [D035 二相位投影](../d035_cross_phase_source_20260930/THEORY.md)还允许在部分二相位源因子上交换辅助变量与行数；消去四格源联合量会增加行和 nnz。它也是公平对照，不能忽略后宣称本表示全局最优。若大量只需要单条物理行，直接旧有效行可能比本联合扩展更便宜。

## 全局存储和 GPU 边界

完整75个局部像素以及全局3072原输入并未变成31个独立 latent。128误差、32源、512谓词等旧小组件门都不因此扩大；局部160个辅助量也不是自动进入既有128 errors组件的许可。实际分类、物理共存、完整父域和矩阵人口必须在新执行合同中明列，不能用别名绕限。

完整账还包括：原模型与 BN 系数精确绑定、source 提取和归一化、COVER 认证、结构分组与 bag 生成、全部消费者、历史 bank、条件表、读出展开、LE 到 EQ 的有界 slack、位长、输入重构、证据、host/device 共存以及原终端 LP/MILP。局部变量或 nnz 下降不证明四并发不回退，更不证明全 GPU。

可研究的 GPU 工作是固定稀疏 gather/reduction、相位边缘关联和矩阵行生成。这里没有实现，也没有宣称求解与可靠数值已在 GPU 完成；终端下降不能移回 CPU 后隐去这部分费用。

## 后续的具体证据问题

下一项不是继续扩大玩具测试，也不是重新实现 junction-tree helper。需要先在既有真实同结构人口上可靠绑定 private/shared 系数，并检查 r_private>=r_shared+abs(center) 是否成立，公开全部适用和不适用记录。固定同层同通道相邻2x2结构只能由数学布局、crossing外包及可靠证据触发，不按实例历史挑选。

若成立，比较完整原像与全部消费者保留时，该局部精度能否带来后继新界，以及完整线性系统相对旧四行、完整单门输入 hull、旧已知多门行和同精度联合参照的代价。如果不成立，记录当前结构的适用性失败，不缩小 private 界、改偏置或把较弱查询称为理想。一般 CAP 的健全性不是自动推进这一创新目标的理由。

之后才决定是否值得另立默认关闭的实现预注册；本轮不是执行授权清单或冻结数值候选。任何未来执行仍须先冻结全部源码与配置，保留4056测试/213文件的既有人口及全部资源门，依序开展真实目标、shadow、逐家族和同一路径完整2413回放。外部400人口独立保61和计新解。

## 文献与新颖性边界

有限条件源与单门 perspective 本已有明确先例；[Anderson 等2.2节](https://arxiv.org/html/1811.08359v2)同时展示其理想性及输入副本开销。[Tsay 等3.2节](https://arxiv.org/pdf/2102.04373)讨论按输入组权衡单门 formulation 的精度和规模。这里的四容量单门形式、稀疏 Boolean/source 提升和 junction-tree 胶合均不是新原理，也没有移植这些工作的分支、动态 cuts 或 bound-tightening 算法。

本轮明确补上的项目内定理，是 COVER 下私有输入允许将自由共同源见证同步延拓为完整神经见证，再作稀疏或有界宽度表示。有限检索没有建立外部新颖性；旧 HZ 装入相同扩展具有相同终端关系。未来贡献必须落到适合 NN 的可组合关系定义、真实完整费用和能力，而不能仅以此 MILP 配方改名。
