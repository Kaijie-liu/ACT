# 同一 HZ 来源上的 padding 公平参照

本研究检验真实残差结构中的相位关系信号是否仅来自普通 padding 范围收紧。它不是新抽象域，不安装新关系，也不将普通区间传播记为 Neural-HZ 能力。研究主线仍是保留非凸相位及共同来源的定义创新；公平参照是严格强化证据的必要条件。

## 比较对象保持不变

原状态 H 的连续因子、全部原二元相位、EQ/LE、共享来源和 frame、完整消费者及输入 decoder 均不变。继承 D259 的三个完整真实前缀、全部 97532 个登记位置和 2853 个 pair/mask 类。parent 归一化、差分系数、tau、完整差分余项 e 及其界不变。仅为旧普通 child 上界加入相同空间 mask 的可靠上界。

原 Conv 后 BN 声明为 g_o = a_o C_o + b_o + E_o epsilon_o，epsilon_o 属于 [-1,1]。这里 a_o、b_o 和 E_o 必须沿用原 carrier；每个物理输出的原误差身份仍各自保留。不得按更紧 mask 范围重新调用 bn_carrier 或缩小 E，否则改变了所比较的 H。此模块只是求 H 上的可靠界，不用 box 或 CZ 替换 H。

## 固定结构公式

设原 Add 每通道范围为 [L_k,U_k]，不能用为 padding 扩到包含零的范围替换它。对外 Conv 的每个输出 o 和偏移 t 一次计算

~~~text
Tlo[o,t] = sum_k min(W[o,k,t]*L_k, W[o,k,t]*U_k)
Thi[o,t] = sum_k max(W[o,k,t]*L_k, W[o,k,t]*U_k)
C[o,M]  = ConvBias[o] + sum_{t valid in M} [Tlo[o,t],Thi[o,t]]
G[o,M]  = a_o*C[o,M] + b_o + [-E_o,E_o]
Ufair[o,M] = min(Uold[o], max(0, upper(G[o,M])))
~~~

以上运算使用向外可靠舍入。原 Conv 常数、负 BN scale、全部有效 tap 和原 E 均不可省略。一个有效 tap 使用原通道盒；无效 tap 为实际 padding 零。区间支持函数和可靠求和给出 C 上界；原 BN 仿射及误差给出 G 上界；两个都有效的上界取 min 仍有效。公式对所有输出和九类空间 mask 统一执行，不按模型身份、margin 或旧验证结论选择。

数学比较采用 D258 的充分冗余条件：支付 Bplus=2 max(Ue,0)、Bminus=-2 min(Le,0)，阈值分别为 U1+2 tau u2 和 U2+2 tau u1。以 Ufair 替代 Uold 后阈值只会下降，故已经排除的关系不得重新变成未排除。保留原比较与公平比较两个结果；未被该充分条件排除仍不代表存在严格增益。

所有输入检查、广播结果、临时数组、归约、mask 组合、BN 运算、结果转存、比较及证据均付费。保留原统一 work、entries、位长、墙钟及双宿主观察边界。额外算术预计约 5M work，旧完整来源实际为 249898475，但这不是通过保证；新数学工件认证和双比较也产生增量，实际超过原 256M 必须保留失败终态，禁止重试降人口或提高门槛。
