# 共同真实来源上的 D240 差关系：最小绑定定理与未取得的资格

本文保存 D240 数学组件通过之后的来源适配研究，不创建或执行新候选，不读取新的原模型数值。它给出可实现的接口及证明义务，不声称已取得 actual-H、原始模型绑定、真实 guard、原模型界、shadow 或新增解资格。D240 的已通过结果仍限于其声明图数学合同。

本轮拟进行的数值阶段仅为三个既定原始模型的完整 residual-prefix 参数提取、原始 BN 参数的可靠外包及 source graph/全部消费者审计。这个阶段不执行 D240，不传播神经网络界，不产生相位作用范围判据通过数，也不能当作真实能力运行。阶段的完整人口、文件身份、预算、冻结和输出合同由单独的预注册定义；本文不替代它。

## 1. 真正需要绑定的对象

设原非凸 HZ 状态为 H，包含同一 frame 中的所有连续 latent、原 signed binary latent、EQ/LE 谓词、物理读出以及原输入 decoder。设 property 给出原输入集合，已有共同来源证书保证：每个 property 内的真实输入，其全部已构造网络读出和原相位能同时扩展为 H 中的一个赋值。不能用四个互不相容的局部门证书替代这个共同存在量词。

拟绑定两父门及两个实际子门：

```text
Q_i = ReLU(f_i),  i=1,2,
Y_j = ReLU(g_j),  j=1,2.
```

f_i、Q_i、g_j、Y_j 均是 H 中已有、来源明确的完整仿射读出；每个门沿用原有相位列及其 active 方向。H 可以含其他门、共享源、skip、额外二元因子和任意原谓词。绑定不删除它们，也不把它们改成局部盒。以下定理要求这些四门图在原二元位整数时成立，含零预激活的所有合法原标签。

来源身份至少同时包括：原模型字节、原 property/输入盒、张量 port 和索引、实际 H 的生命周期/frame、原门位的方向、完整仿射表达式、所有被保留消费者以及原 decoder。相同名称、相同区间或 Python frame 对象相同，都不能单独证明这些语义事实。

D240 的 make_block 只是拥有自己声明图的数学对象。不能重新声明独立的 x1、x2、余项输入并据其 frame 声称完成真实绑定。本节的 actual H 必须由已有完整来源路径建立，或者在后续独立阶段建立并认证。局部声明图可作为关系证明的坐标模板，其列最终必须精确代回同一个 actual H。

## 2. 一般父门区间的零点保持归一化

假设已有全 H 可靠有理界 L_i < 0 < U_i。取

```text
s_i = max(-L_i,U_i) > 0,
x_i = f_i / s_i,
q_i = Q_i / s_i.
```

ReLU 的正齐次性给出 q_i=ReLU(x_i)，且 x_i 在 [-1,1] 中。原实际范围 [L_i/s_i,U_i/s_i] 可更窄；它及原 H 谓词继续存在，不因局部定理使用 [-1,1] 而被替换。缩放既不增加相位位，也不改变 f_i 的符号。原 active 指示记 alpha_i；若 native signed bit 的 -1 表示 active，则本组件的 signed bit 是其负值，alpha_i=(1-b_native_i)/2。

不能用 (f_i-center)/radius 代替 x_i 后沿用 Q_i 或原相位：这会移动 ReLU 的零点。也不能用负比例交换正负支而不改原图语义。stable 父门可以留在其他完整来源中；本合同选定的两父门属于上述 crossing 类型，不靠篡改其可靠界使之入选。

令 p_i=alpha_i-q_i、n_i=1-alpha_i-q_i+x_i。原图给出 p_i,n_i>=0，包括 x_i=0、q_i=0、alpha_i 任取0或1的零标签。因此 D240 的缺额关系不需要额外规定零点相位。

## 3. 从完整后继系数固定 Q-anchor 和 tau

在同一来源坐标中，保留实际后继的完整结构分解

```text
g_j = C_j1*q1 + C_j2*q2 + R_j(H),  j=1,2.
```

若原算子的系数乘的是未归一化 Q_i，则 C_ji 必须包含比例 s_i。Conv、BN、Add、实际偏置、padding、所有其他父输出与 skip 均必须反映在 C 和 R 中。系数选择来自预注册的实际算子分解，不从 terminal 方向或 LP 状态倒推；相同源列先合并，不把完整余项拆成互相独立的盒。

这里的点系数属于已认证的精确有理 H 读出；若它以有理系数加共同误差 carrier 外包原 BN，则模型系数差也留在 R_j(H) 中。只有原始 BN 区间、尚无这种完整 H 时，不能把区间中点当作这里的 C_ji 后遗漏误差。第6节明确区分这两种资格。

定义

```text
A=(C_11-C_21)/2,  B=(C_12-C_22)/2,
tau=(A-B)/2,
a=(C_11+C_21)/2,  b=(C_12+C_22)/2.
```

当前固定规则要求 tau>0。方向及候选对的次序事先按结构确定；不能在 guard 失败后重选方向、tau 或 anchor。该取法不是优化器，也不宣称最佳 tau。A>0、B<0 是一种普通适合结构，但定理仅需 tau>0；不满足反向主系数的额外代价会完整进入 e。

完整的四个读出为

```text
z=(g1+g2)/2 = a*q1+b*q2+r,
d=(g1-g2)/2 = tau*(q1-q2)+e,
r=(R1+R2)/2,
e=(R1-R2)/2 + (A+B)*(q1+q2)/2.
```

特别是 (A+B)*(q1+q2)/2 不得省略。只有经过实际系数恒等验证 A+B=0 才会消失。先在完整 H 的共同 sparse 来源中合并 R1+R2、R1-R2，再从完整表达式和可靠源范围求界；不能分别对两个已丢相关性的余项盒作代数相消。若源表达式不能精确认证，不能用一个 reliable=True 标记跳过。

设得到 r 属于 [Lr,Ur]、e 属于 [Le,Ue]。Q-anchor 的静态充分条件是

```text
[Lr+min(0,a,b), Ur+max(0,a,b)] subset [-tau,tau].
```

在 alpha1!=alpha2 时至多一个 q_i 非零，故该条件保证 |z|<=tau。它不要求全 H 上 z 稳定，也不要求全 H 上 z 不跨 clip 折点。令 S=clip(z+tau,0,2*tau)，于是整个 H 上有

```text
(alpha1-alpha2)*(S-z-tau)=0.
```

这是共同差的别名，不是各 alpha_i*S 的逐项别名。相位相同而 z 跨折点时，两个逐项别名可以同时错误，共同差仍为零。无须引入 S 的新门位或查询其支持函数。

单调 2-Lipschitz 差函数的 D239/D240 证明随后给出

```text
-2*tau*p1+2*min(Le,0)
 <= Y1-Y2-(alpha1-alpha2)*(z+tau)
 <= 2*tau*p2+2*max(Ue,0).
```

判据不通过仅说明这个充分合同尚未建立，不证明原 property 安全或不安全；也不授权截断 residual、缩小旧来源人口或增加其他算法路径。

## 4. 同 H 精确代换定理

定义四个新连续观察列

```text
c12=alpha1*q2, c21=alpha2*q1,
v1=alpha1*r(H), v2=alpha2*r(H).
```

四个产品分别使用完整四行 McCormick 包络；alpha_i 二元时包络精确。r(H) 是同一实际 sparse 表达式，不能复制成两个只有相同范围的私有变量。共同差的参考读出恰为

```text
K=tau*(alpha1-alpha2)+a*(q1-c21)+b*(c12-q2)+v1-v2.
```

将上节两条缺额行中的共同差替换为 K，得到 D240 Q 的十八条新增 LE。所有 x/q/Y/r 局部读出都精确替换为原 H 的原连续/二元列上的仿射式；所有 signed bit 也映回已有原列。保持原 H 的每条 EQ/LE 和全部物理读出不动，仅追加四个连续产品及这些有效行。

**定理。** 在第1—3节的条件下，扩展状态 H+ 在原二元位整数时投影回旧坐标恰等于 H；每个旧点具有四个产品的唯一 canonical 扩展。其连续查询松弛只可能加强，不能删去任何真实原输入的共同见证。

**证明。** 对任意 H 中整数相位赋值，按上式计算四个真实产品。原幅值范围和 r 的全 H 界使所有产品包络成立；守卫证明和缺额引理使两条新增行成立，故每个旧点可扩展。反向投影仍满足未改动的全部原 H 谓词，故不新增原整数点。四个原 alpha 已二元，每个产品的 McCormick 包络将新列夹为唯一乘积。零预激活的不同原合法相位分别代入同一证明，未被删去。原输入 decoder 只读取旧坐标，因此扩展见证解码为同一个原输入。证毕。

该定理不说 H 的 LP 松弛已经理想，也不说新增关系在任意实际样例严格有效。它不证明新的集合表达力或 PLDI 新颖性。若 H 本身只是原网络的 sound 外包，H+ 仍是该外包上的加强，不会自动变成原网络精确图。

X-anchor 也可以同样 pullback，但必须以实际 x_i 系数定义 r，并通过 D240 的 X 判据；它额外保留 T 的两个源容量行和 U<=D。不能在 Q 失败后临时借 X 路径，也不能把 X 专属容量免费赋予 Q 产品。原全部消费者、共享 latent 身份、其他原位、skip 与 decoder 都保留；这不是局部窗口替代整网。

## 5. 稀疏增量账及证明

记 S_qi、S_Yj、S_xi、S_r 为各个最终、已规范化原 H 仿射读出的非零列数，不含常数。下列上界允许读出含原连续与原二元列；相同列合并只会降低 nnz。每个原相位指示是一个 signed binary 列加常数。只统计新 LE 的 sparse 系数，不把 RHS、列界元数据或来源证据算成免费对象。

Q 四个产品新增四个连续列、十六条 MC；两条缺额 LE 不新增列，共十八 LE。费用逐项为：

| 新行组 | nnz 上界 |
| --- | ---: |
| alpha1*q2 与 alpha2*q1 的八条 MC，q 在 [0,1] | 2*(S_q1+S_q2)+12 |
| 两个 alpha_i*r 的八条 MC | 4*S_r+16 |
| 两条共同差缺额行 | 2*(S_q1+S_q2+S_Y1+S_Y2)+12 |
| 总计 | 4*(S_q1+S_q2)+2*(S_Y1+S_Y2)+4*S_r+40 |

第一行每个非负 q 产品的四行分别最多含 1、2、S_q+2、S_q+1 个系数。第二行每个有界 r 产品分别最多含 2、2、S_r+2、S_r+2 个系数。最后每条缺额行最多含四个新产品列、两个旧相位列和四个 q/Y 读出。偏置进入 RHS，不丢失。故表中上界成立。物理 q/Y/r 本来就是独立命名列时，S 都为1，恢复 D240 的56 nnz上界。

X 的两个交叉源产品每个为 2*S_x+8 nnz，两个残差产品仍为4*S_r+16；缺额两行同上；三条容量合计最多为

```text
3*(S_q1+S_q2)+2*(S_x1+S_x2)+6.
```

因此 X 新增四列、二十一 LE 的总上界为

```text
4*(S_x1+S_x2)+5*(S_q1+S_q2)
 +2*(S_Y1+S_Y2)+4*S_r+50.
```

所有相关读出各一列时恢复76 nnz；对称控制也按同样二十一行付账。真实宽 residual 的 S_r 不能用1替代，除非确有另行支付的显式读出列及完整绑定等式。

以上没有把原 H、normalize/form 构造、全来源扫描、重复项合并/排序、有理位宽、原输入/property 身份、存储共存、native row 安装、decoder 与查询消费算进增量行数。实现时它们全部另计，共用同一预算，不能借新对象重置。直接代换可不新增读出等式；若运行时额外分配物理 slots，则实际新增列/EQ/nnz必须额外报告。不得将精确有理行直接舍入成 native 浮点行而仍声称本定理已认证其数值语义。

## 6. BN 与原子 ReLU 图所需的共同数值见证

D015 的 source_packet_v1._Reader.conv 保留原始 Conv 权重、偏置、stride/pad/dilation/group 和 port；_Reader.bn 保留原始 gamma、beta、mean、variance、epsilon，不执行平方根折叠。source_binding_v2.extract_model 只显式绑定 batch1，并保留原模型字节身份。census_worker_v2.post_affine 利用 shield_kernel_v1.sqrt_interval 给出可靠有理区间；区间端点或中点不等于原 BN 的精确实数系数。

因此对真实来源有两种必须区分的状态：已有完整实际 H 的精确有理、sound 图外包，可直接按前述接口读取；或者只有 raw 参数及区间系数，尚不足以向 D240 声明精确图。后者不可用中点网络替代原模型。

一个普通的充分构造条件如下。对完整共同父状态，证明实际门预激活与有理仿射读出满足

```text
|g_true-Hat_g(H)| <= E,  E>=0.
```

若 E>0，追加一个连续 error carrier epsilon 属于 [-1,1]，定义同一个门的读出 g=Hat_g(H)+E*epsilon，并在这个 g 上使用原 atom 的精确 ReLU 图及原相位。对每个真实输入选 epsilon=(g_true-Hat_g)/E 即得共同扩展。E=0 时必须有恒等式，不能用除零或遗漏残差代替；无需该自由 carrier。

关键是每一个原门只有同一份供后续所有消费者使用的 g、输出与误差 carrier；不能按查询、支路或产品重取误差。按拓扑逐门构造且前驱共同见证完整保留时，可对同一真实输入同时选择全部 carrier，得到整个前缀的共同存在证书。真实固定 BN 常数间的相关性可能因外包而变松，但不能因此反向声称理想性或原参数独立；所有 guard 必须在这个较大的 H 上仍有效。

这只是充分的来源构造定理，不是本文已实现的数值框架。实际 E 必须覆盖全部系数、偏置、BN 平方根和声明数值语义要求的误差；所有 carrier、界、谓词、来源证据和成本均要计费。若 native 原子图的存储模板经有理解读并不精确对应同一个 g，也不能借 graph_error=0 或局部输出名字代替检查。D230 SOURCE_PATH 保存的 centered carrier 提案仍需独立实现及资格，本文不自动授予它。

## 7. residual-prefix 的真实拓扑及 padding

依据已冻结的来源拓扑和只读研究，large 的目标链不是简单的相邻两个 ReLU：

```text
A = Q127 = Relu2(...),
Q = Q130 = Relu5(BN4(Conv3(A))),
S133 = BN7(Conv6(Q)) + A,                 # Add8
g11 = BN10(Conv9(S133)),
Q136 = Relu11(g11).
```

A 同时保留 Conv3 与 Add8 的消费者；S133 还被后续 Add14 消费。Add8 不是 ReLU。选取两个 g11 的实际位置时，完整 residual 包含 Conv6/BN7、Add8 的 A 支路、Conv9/BN10 的全部贡献，不能只取 Conv6 的后继读出。此处符号中的编号用于已认证 large 拓扑，不能套用 medium 的节点编号。

具体端口链为 Relu5 的129->130、Conv6的130->131、BN7的131->132、Add8的(132,127)->133、Conv9的133->134、BN10的134->135、Relu11的135->136。这是既有拓扑的读取结果，不是本文件新执行的模型证据。

medium 的既有 D230 路径则是 Relu2/port121 同时供 Conv3 与 Conv8，主支经 Relu5/port124、Conv6/BN7，与 Conv8/BN9 在 Add10 合流，再经 Conv11/BN12 才进入 Relu13。两个网络都必须审计完整 consumer fanout，而不是在局部合流边界停止后声称已到达下一真实 ReLU。

即使两层都是 stride1 的 3x3 Conv，中间无 ReLU，也不能在边界把完整来源天真替换为一个全位置通用的5x5卷积。设第一层有效空间集合为 I，中间有效输出集合为 J，第二层位置 p 的窗口为 N2(p)。组合的源线性项是

```text
sum_{u in N2(p) intersect J}
  W2[p,u] * sum_{v in N1(u) intersect I} W1[u,v] * input[v].
```

中间 u 不在 J 时，第二层取的是对中间张量的零 padding，不是“把第一层公式延伸到该位置后再算一次”。朴素5x5合核可以错误纳入路径 p->u->v：u 在中间外部、v 却重新落回原输入内部。第一层/BN偏置也只在实际存在的 u 上加，第二层的边界偏置因此通常依赖 p。Add 的 skip 路径另有自己的映射，不能随主路合核丢失。

最小纸面反例是一维长度2输入(x0,x1)，连续两次 same-padding 的核[1,1,1]、偏置0。第一次两个输出都为 x0+x1，第二次首输出为2*x0+2*x1。若先将核合成[1,2,3,2,1]再作一次 padding2，首输出却为3*x0+2*x1，多出的 x0 正来自越界中间位置的回流。这不是数值极端情况，而是有效路径集合不同。

严格展开可以按上述有效路径求和、合并同一 source ID；这仍是同源仿射代数，不是 phase/input split。原模型真实几何由读取器解析并审计，不能在新数值提取前假设某个网络满足这些示例尺寸或用5x5模板替代解析。

## 8. 本轮可推进的来源审计与明确止步

下一来源阶段固定沿用 D179 的三个原模型人口：CIFAR100_resnet_large、CIFAR100_resnet_medium、TinyImageNet_resnet_medium。应从同一份原始字节解析所需完整 residual-prefix，各模型完整保留节点/port、shape、所有原参数、BN原始量与可靠区间、跳连及全部消费者；不以五窗口缓存代替完整源图，也不因某模型不匹配而缩小人口。

该阶段只补缺失参数与来源结构。允许审计 BN 的 variance+epsilon 正性、参数范围及运算几何等来源事实；不由此声称已有完整父门 L/U、不建立已认证 actual H、不运行 D240 attach、不传播网络界、不测试 tau/guard 的真实通过率、不优化参数或方向。后续实际实例、shadow、逐家族及全量回放仍独立存在。

本研究不改变正式1870/2413，也不改变独立 E0 的61/400；不把 source extraction、声明图4169项数学测试或本文定理记为新增 CERT/ADV。没有执行新候选，没有新真实模型收益，没有默认启用，没有修改历史模型、日志、结果或已冻结源码。
