# 逐门范数替换的强参照与共同幅度缺口

本轮得到一个改变后续行动的负结论：当前 D150 逐门有损范数替换，在相同父状态、因子、读出和范数预算下，有一个更精确且线性行数与系数数量更少的标准 ReLU 参照。因此不继续将该版本移植到完整 CNN 来寻找所谓表示优势。保留其数学组件，但需要修改域定义假设，不能只加差分边或优化存储。

这里证明的是局部语义包含和声明坐标下的表示费用，不是实测速度、不涉及所有抽象域的下界，也不意味着研究目标被阻塞。所有推导为纸面代数；本轮未执行候选或数值实验。

## 相同坐标下四行精确参照支配五行候选

固定同一个完整父域和可靠 crossing 界 l<0<u。记预激活 g=c+a^T z，其中 z 包含原源、旧相位和旧误差，不含本门新相位 gamma 与新误差 e。D150 新读出为

```text
q = g/2 + (gamma-1/2)*gbar + e.
```

原 gamma 为整数 0/1 视图；原 signed bit 身份不变。D150 保留五条行：

```text
g <= u*gamma
g >= l*(1-gamma)
q >= 0
q >= g
q <= u*gamma.
```

它还保留父谓词、源 decoder、全部 shared identities 和 whole/local 范数，混合稳定层还保留代入后的 affine norm。现在构造仅用于比较的关系 E：维持所有这些对象和 q 的同一仿射式，只将上面两条 sign guards 换成一条 active upper 行。

```text
q >= 0
q >= g
q <= u*gamma
q <= g-l*(1-gamma).
```

这四行对 gamma=0 强制 q=0、l<=g<=0；对 gamma=1 强制 q=g、0<=g<=u。g=0 时两个 gamma 均合法，不删二元身份。即使只为比较而把 gamma 放到 [0,1]，也有 g<=q<=u*gamma，及 0<=q<=g-l*(1-gamma)，所以原两 guards 仍被蕴含。

因此 E 包含于同父状态的 D150 关系；原 q、e、源、相位和 decoder 不变，不新增变量。原范数对每个真正父域成员的 ReLU 图都有效，故 E 仍包含完整父域的精确 ReLU 像。稳定门和 D150 的稳定坐标投影可保持不变；本比较只改新 crossing 门。

包含可以严格：取 x∈[-1,1]、g=x+1/2，原参考 gbar=1/2，半径为 1/2。D150 允许 x=0、gamma=1、e=3/8、q=7/8；精确四行要求 q=g=1/2。源和误差均严格在各自界内，不是分数相位或数值边界产生的区别。

## 行数和系数数量并不需要支付更多

令 s=nnz(a)。两条旧 guards 的变量系数合计 2s+2 项，因为 l<0<u 且新 gamma 不在 g 中。新增 active upper 写为

```text
(-a/2)^T z + (gbar-l)*gamma + e <= -l+(c+gbar)/2.
```

其变量系数至多 s+2 项。因此在其余行和范数完全不变时，每个 crossing 门少一条线性行，至少减少 s 个变量系数。两旧 guards 的 RHS 是 -c 与 c-l，二者不可能同时为零；新 RHS 至多一项非零。把 RHS 也计入，nnz 仍不增加。常规恒定宽度 dense 槽数也随行数减少；不能把这个计数当成真实峰值内存测量。

所有 D150 范数支持证书在 E 上仍然有效，因为 E 是子集且所用读出、半径和共享坐标均相同。这里没有证明现有生产 HZ 已经生成这些证书、采用同一查询实现，或一定更快。也没有证明独立多层实现由于不同 bounds、引用中心和资源行为而自动支配。结论足以否定当前版本已有的“删掉精确行能在此布局下降低表示费用”设想；它不禁止其他有实质状态压缩或查询优势的域定义。

E 本身保留精确门图，故也不能将它另取名称作为新的 Neural-HZ。它是强参照，而不是本轮提出的新域。

## 完整普通混权结构中的共同幅度反例

取共享源 x,y∈[-1,1]，两个非平行门：

```text
g1 = x-y/4+1/4
g2 = x+y/4+1/4
qi = ReLU(gi).
```

二者都 crossing，可靠界为 [-1,3/2]，参考均为 1/4。原 source Gram 对角项为 2 和 1/8；whole 误差半径在外向平方根舍入前的平方预算为 17/32，实际有理认证半径不小于该理论半径；每个 singleton 半径为确切的 5/8。

在同一个内部源点 x=y=0，取原 gamma=(1,1)、e=(1/2,1/2)。D150 读出为 q=(3/4,3/4)。所有五行成立，误差平方和为 1/2<17/32，各 singleton 也严格在界内。所以即使两门所有可能子集都加上相应坐标范数，这个点仍被接受。真实输出却是 (1/4,1/4)。

给它一个普通混权与活源 skip 读出：

```text
J = q1+q2-5*x/4
r = ReLU(J-11/8).
```

真实网络有 J<=5/4。证明：固定任意 y，J 对 x 是凸函数，因此不超过端点最大值。x=-1 时两门输出为零，J=5/4；x=1 时两门均激活，其和为 5/2，J 也为 5/4。这覆盖整个源盒，故真实 r 恒为零。

候选假点给出 J=3/2、r=1/8。它也可合法延拓到第二层：新 g 的仿射式是 -x/4+(gamma1+gamma2)/4+e1+e2-11/8，新参考为 -7/8；取新 gamma=1、新误差 1/2，读出即为 1/8。新 whole 半径在该父相位下至少为 (1+sqrt(17))/8>1/2；cover 半径不更小。新门的 guards、epigraph 和上界 mask 也通过可靠父域界。这是纸面合法延拓，不是已执行的反例或 ADV。

问题出在同一个源位置允许两个输出共同变大，而不是重复门、零点或极端系数。标准四行在原 gamma=(1,1) 处立即强制 qi=gi，排掉该状态。

## 只加差分边不能修复共同幅度

对真实 ReLU，定义 h=2q-g，则 h=|g|。逐边有

```text
|hi-hj| <= |gi-sign*gj|,  sign in {-1,1}.
```

因此固定结构边、非负权重的平方和也给出健全联合范数；原共享源可用于求右侧预算，不能各自复制 patch。D150 的 crossing 图表中 h=(2gamma-1)*gbar+2e，是原 phase/error 的稀疏仿射式。这条关系可以加强当前弱域，但单边机制已被 [D074 的余项反代](../d074_shared_remainder_audit_20261001/THEORY.md) 和 [D020 的原相位差分关系](../d020_phase_difference_20260930/D020_PHASE_DIFFERENCE.md) 覆盖，不能重新记作定义创新。

更根本地，这些左侧差分算子 D 都满足 D*1=0，故 h 增加共同常数不会改变 Dh。上节假点 h1=h2=5/4，所有这些差分边均通过，甚至不把右端取上界、直接保留同源绝对值也不能排除它。增加邻接边、右端带符号的 gi-sign*gj 或联合差分能量，单独都不能绑定这一共同幅度；这里没有把左端换成 hi+hj。

一个相对方向的正控不改变此结论：g1=x+y/4+1/8，g2=-g1+y/8，在源 (1/8,0)、gamma=(1,0)、q=(1/2,0) 时，D150 的 e=(5/16,1/16) 通过 whole 和 singleton 范数；但 |h1-h2|=1/2 超过 |g1+g2| 的全盒界 1/8，边关系将其拒绝。它只说明已有有效关系能修正一种误差，不能说明新的完整域已经成立。

外部工作也已用单调性、有界斜率和重复激活性质的二次约束表达神经元关系，例如 [Fazlyab、Morari 与 Pappas](https://arxiv.org/abs/1903.01287)。本轮只核对该思想的已有归属，不引入其 SDP 或 S-procedure。文献没有替本候选证明完整成本优势。

## 对下一定义的具体约束

当前五行加逐门误差加范数的构造，退出待生产化能力候选；D149/D150 的已通过数学件不修改、不撤销、不重跑。它们可作为源相关范数、稳定投影和见证处理的支撑库。不是退回全精确图后再声称新域，也不是继续累加边关系补齐旧图成本。

下一候选必须同时面对共同幅度与相对方向，明确在哪个普通神经块上真正替换了非线性状态或关系，并与上述同坐标强参照比较完整代价。只改变 q/e 坐标或取得相同证书不够。若考虑按消费者压缩，必须纳入所有活 skip、原 guards、旧谓词和 decoder；已有 [D147 核空间检查](../d147_source_affine_norm_fiber_20261004/OTHER_CHECKS.md) 说明 identity skip 不能被当作免费消失。当前还没有通过这项比较的新定义，不用候选名称填补这一缺口。

这不改变目标：强大的非凸 Neural-HZ、GPU、smooth/Transformer、完整 13 家族和外部家族提升仍全部保留。正式收益为零，完整研究 goal 继续 active。
