# 三门相位增强在真实记录中的适用范围

本轮有一个会改变实现选择的结果：不能把上一版三门数学正控直接实现成固定相邻通道组件。在已存档的第二个 ReLU bank，两个 CIFAR 模型均没有三个连续通道同时相位未定的窗口。可靠稳定事实安装后，这些三门相位圈行已被原双门关系包含。

这不是 CIFAR 无法提升的结论，也不是否定整个 Neural HZ。它排除的是一个具体结构选择及其中的纯 phase-cycle 增益。所有旧 bits 保留，零点相位未固定，Tiny 缺失证据不补作成功。

## 冗余命题为何适用

[PLAN.md](PLAN.md) 给出原三角增强的六种固定相位情形：其新上界等于旧三个完整双门投影上界之和，再加一个非负项。因此当任一原门相位已被可靠严格界确定时，全部新增仿射行均为冗余。独立数学审查确认这一结论，以及至多两未定相位且同一 overlap 的上侧消费者同号时的推广。

原门严格正的预激活下界推出原 active bit 为 1；严格负的上界推出其为 0。上下界触零则不能据此固定 bit，零点合法选择仍全部保留。本轮 zero_touch 恰为零，不是把它们排除在查询外。

这是具体语义中的稳定性结论。生产 LP 是否实际保留、正确绑定这些稳定事实尚未验证；本轮不能声称已经对 production 做了冗余安装试验。即使补齐稳定绑定能提分，也应如实记作绑定/已有事实利用，而不是新定义定理。

同一 overlap 的异号消费者、额外 source 条件关系、守卫产生的强化不受此无增益命题否定。原 HZ 的共享来源仍可能提供信息；不能将该三门规则的冗余扩大成整个网络没有研究空间。

## 参数和身份边界核对

只读复核 seed_relation.py 的原循环：source_bounds 先经过 nonnegative_part，再与 second-bank 的真实区间权重相乘并累加 bias，ordinary_h 与 ordinary_w 是接收 ReLU 的预激活界，没有误把第一层预激活当成激活值。BN 的上游区间复合继续使用原可靠平方根方法，不是中点网络。

根代理和独立审查者读回了该计算链；原位于源档的 bound、参数和 hash 均未修改。实际 phase 列、原 frame 生命周期及 decoder 的 native 绑定仍未获得资格。

更后 Conv 的参数也是独立缺项：旧 extractor 读取 first Conv 和第一 ReLU 的 immediate Conv 分支；后面的 Conv、BN、Add 虽有图端口记录，尚不能当作后继参数已经解码认证。要检验新关系被下一混权层利用，必须在新的完整预注册中补齐这段实际参数及身份，不拿前一 bank 的证据代替。

## 下一候选需要改变的结构规则

不实现已被本记录否决的“固定相邻三门”增强。候选规则应先遍历原完整模型、分支、窗口、通道和 canonical slots，支付全部可靠普通界，再仅按上述严格稳定冗余定理决定哪些三元组无需生成。其余三元组包括 zero-touch 全部保留，不依据标签、margin、LP 状态或实例身份选择。

这条建议不会删除原二元因子或缩减源人口；省略的是已经证明被旧关系包含的新增行。每个被省略组的范围和理由也必须计数。原两门比较系统及稳定事实的实际绑定是前提，不能假定免费存在。

对余下组，仍要计算已认证的共同源系数和三边证书，再判断是否存在上一版机制能利用的冲突；全部无改善组同样记录。列表构建、全 receiver 普通界、未定组数增长、系数 bit length、证据和完整终端开销都需要预注册支付。该规则按可观察数学结构统一执行，不给 Medium 单独路径，也不因 Large 此局部为零而跳过它的完整研究人口。

目前这是下一候选的结构要求，不是已经实现或执行的三源程序；没有为通过而重跑旧失败版、提高预算或减少测试人口。GPU、真实验证收益及完整回放仍缺。
