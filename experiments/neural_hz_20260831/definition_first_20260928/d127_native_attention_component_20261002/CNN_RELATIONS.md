# 共同幅值抵消与联合能量的适用边界

普通 CNN 主线本轮得到一条可生成的相位抵消证书和一个下一 ReLU 控制，但其 lowering 使用已有机制；共同椭球也不能自动修复此前的共同幅值反例。以下是纸面推导与独立核查，没有 CNN 候选执行或新增解，不启动新的适配框架。

## 先合并共同幅值再支付正负项

同源父幅值 e_j∈[0,u_j]，真实目标端口满足 y_i=δ_i(h_i+Σ_j A_ij e_j)，其中 δ_i 为原 active bit 的0/1视图。未经过目标 ReLU 的 raw residual 端口用常量 δ_i=1。原 bits、零点两种合法标签、源谓词和 decoder 全部保留。

对一个真实后继读出 w，先形成 c_j(δ)=Σ_i w_i A_ij δ_i。对每个 j 将正负系数分别记为 p_i,n_k≥0，按固定源/端口身份顺序构造非负匹配 M_ik，满足 row sums≤p_i、column sums≤n_k。记 P=Σp_iδ_i、N=Σn_kδ_k、S=ΣM_ikδ_iδ_k。因为 δ∈[0,1]，S≤P 且 S≤N，因此

```text
[c_j(δ)]_+ = P-min(P,N) <= P-S,
w^T y <= Σ_i w_i δ_i h_i + Σ_j u_j(P_j-S_j).
```

对 -w 使用同一构造给下界。不同源之间不能借相同数值抵消。该证书保留一个方向内多个相位的共同幅值信息，但不同方向分别取外包不等于保留共同像。原二元非凸语义没有被连续替换；上述 cube 上的额外不等式只是证明其有效性。

## 可以穿过下一真实激活的控制

使用 [共同像反例](../d126_joint_phase_closure_20261002/JOINT_IMAGE_BOUNDARY.md)的 e1,e2∈[0,1] 与

```text
r1=R(1/4+e1-e2/2),  r2=R(1/4-e1/2+e2),
s=R(2r1+r2-9/4).
```

对后继方向 (2,1)，上述匹配给

```text
2r1+r2 <= (5/2)β1+(5/4)β2-(3/2)β1β2.
```

这恰可用 [已有双相位投影](../d052_static_source_certificates_20260930/THEORY.md)的负乘积两行表示：

```text
2r1+r2 <= (5/2)β1+(5/4)β2,
2r1+r2 <= 3/2+β1-β2/4.
```

两行在原 binary 上与该上界等价；fractional 时只是所选 McCormick 提升的精确投影，不等于原乘积关系本身。例如β1=β2=1/2时，原二次右端为3/2，两行右端均为15/8。每行四个坐标 nnz，没有新辅助或替代 bit。利用原 binary 语义得到 s≤β1/4 和 s≤(1-β2)/4；保留 s 本来的原门 bit 与四行，不在运行时枚举相位。这两条新 cap 共四个 nnz。

后继预激活的真实范围为 [-3/2,1/4]，分别在 e=(0,0)、(1,0) 达到，所以不是稳定门专例。此前 fake β1=β2=1、r1=11/10、r2=1/10 的后继可满足其精确标量图 s=1/20，却违反新 cap s=0。完整保留共同 e 的旧 HZ 本来就排除此 fake；这里不是胜过旧 HZ 的能力证据。

## 去重与完整代价

双相位负乘积的两行 lowering 已在 D052；[多相位正部上包络](../d046_multiphase_envelopes_20260930/THEORY.md)也已有固定 prefix 机制。本次得到的是具体共同幅值 certificate generator，不是新的非凸原语。没有证明旧 P/N 自动生成器必然产生本次所有匹配式，也不能因此反过来声称创新性已经成立。

一个读出的 coefficient occurrences 为 E=Σ_j #{i:w_i A_ij≠0}。认证并排序的支持上，形成表和双指针匹配可用 O(E) 运算、至多 E 个 pair terms；跨列同一相位乘积须合并，排序、身份、位长和 h_i 的全部源支持另计。一般两层 Conv 的 E 可按两层 fan-in 乘积增长。

多个负 pair terms 不能总共降成两行：保留所选 McCormick 提升通常需要每个 overlap 的连续量与行；完全消去可能产生组合数量的 facets，只选部分行则更弱。单固定匹配也不是完整解：c=β1+β2-β3，若 m13=t、m23=1-t，则在(1,0,1)、(0,1,1)真实正部都为零，而界分别为1-t、t，至少一个不小于1/2。这是普通三相位限制。

## 非对角图能量能保什么

非负边权和 grounding 系数定义 E(v)=Σ_(ij)w_ij(v_i-v_j)^2+Σ_i c_i v_i²。逐边用 ReLU 的1-Lipschitz性、逐点用 |R(v_i)|≤|v_i|，得到 E(R(v))≤E(v)。这是经典 Dirichlet normal-contraction 的有限图情形，不是新定理；原文第2节给出图能量和收缩定义。[Haeseler等的论文](https://ems.press/content/serial-article-files/33480)

[D009](../d009_bounded_phase_energy_20260928/D009_DOMAIN_AND_RESULTS.md)只排除了任意非对角 Q 不加条件地穿过 ReLU，并没有排除以上特定图形式。但绝对图能量收缩不推出任意参考中心的差能量收缩：单边 E(v)=(v1-v2)^2，a=(1,0)、b=(0,-1)，E(a-b)=0，而 E(R(a)-R(b))=1。不能把它直接套到通常的名义输入扰动。

一个明确的完整联合投影是：固定 m 节点树和原 anchor q0，令边差 z=Dq、z^T Wz≤B、B≥0、W正对角，q=1q0+Pz。完整 Conv和raw residual 前沿为 Y=d(x)+Cq，则 t=Y-d-(C1)q0 属于 F=CP 所成的共同椭球像。令 K=F W^-1 F^T，像是 t∈range(K)、t^T K†t≤B。这是线性代数的精确椭球投影，不是原神经图的精确投影，也不是新几何。

对 k 个完整端口，显式形成 F 可需 O(km+nnz C)，形成 K 可需 O(k²m) 与 O(k²) 的K输出存储。显式F还占O(km)，输入C、可用树隐式存储的P、源/读出及分解workspace另计，不能把K大小当完整峰值。分解另有 O(k³) 及认证位长费用。方向查询可以用 O(k²) 或 matrix-free O(km)，平方根亦须认证。anchor及common mode不能省；有 identity residual 时完整端口可能保留全部旧幅值自由度。数学上仍可能删父列，但这不证明维数或净成本下降。只看窄 head 不代表完整消费者低秩。

## 自然联合椭球仍放过此前伪点

在 D126 的共同幅值 P 上，(e1-1/2)^2+(e2-1/2)^2≤1/2 是紧的，(0,0)、(1,1) 均取等。此前 fake 唯一反解为 e=(31/30,11/30)，其能量为68/225<1/2。因此连完整共同椭圆像也放过该 fake，后继 s仍可为1/20。

加权版本以(w1+w2)/4为界时，只有31w1>209w2才排除该点。这需要定向强调原e1 cap的信息，不能把balanced joint energy说成自动恢复共同幅值像。全部正权能量族能恢复盒的各坐标限制，也不意味着免费降维。

当前没有超过同信息强参考、又覆盖完整普通消费者的精度成本正控。下一候选仍需要一个可计算的非独立关系及完整费用；不由这些负结果推断新域不可能，也不转去实现未经证明的 oracle。无新的 solver、split、backward/dual rescue 或运行时菜单。
