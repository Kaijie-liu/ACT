# 三相位共同源关系的物理投影

本轮得到一个比独立单门及 D035 两两源接口更强的纸面关系，且差异能传到下一 ReLU。它不需要新增九个相位—源乘积坐标。不过，核心不等式来自已知 Boolean quadric polytope；目前是 Neural-HZ 定义研究的支撑结果，不是已经提出新域，更不是正式验证收益。

比较范围必须完整写出：同源完整单门 ReLU hull 的交、各相位对跨全部源坐标共享的 D035 盒源因子，以及一个一致的三 bit 概率分布。随后同轮纸面复核还给出了每对神经元包含联合 guards 的完整 NN joint hull 延拓，见 PAIR_HULL_STRICTNESS.md。不能把这些局部联合 hull 的交等同于整个上游网络的全局理想凸包。

## 保留原 HZ 的非凸具体化

设原 HZ 保留连续源 xi、全部原二元相位 beta、EQ/LE 谓词 P、共享 source/frame 和原输入 decoder。真实预激活 g 与幅值 q 均在同一赋值上定义，q_i=ReLU(g_i)=beta_i*g_i，且保留原 guards，包括零点两种合法标签。

以下关系是这个原集合的推论。向谓词加入它，不删除、替换或连续化任何原 bit；每个原点仍满足新增行，投影后的非凸具体化不变。分数点仅用于比较终端查询松弛，不是将域退化成凸域，也不是具体 ADV。

这一点同时限制创新声明：本轮改变的是可直接消费的关系及查询松弛，不是精确 HZ 的集合表达力。只将已有 HZ 加上一条已知有效不等式，不能宣称完成定义创新。

## 已知关系与新的项目内投影推导

固定

```text
K = [[1, 1, 1],
     [1, 1,-1],
     [1,-1, 0]]。
```

对 beta_i in {0,1}、共同 z in [0,1]^3、Z_ij=beta_i*z_j，有

```text
-beta1-2*z1-z2 + Z11+Z12+Z13+Z21+Z22+Z31-Z23-Z32 <= 0。   (B)
```

这是已知 I3322，不是本项目的新不等式。其自由乘积域与连续盒一侧的关系见 Sripratak、Punnen、Stephen 的 Theorem 2.3、式 (2.1) 和 Corollary 2.11；四环见 §3.2。[作者全文](https://www.sfu.ca/~tstephen/Papers/bbqp.pdf)

下面给出一个对任意三个同源预激活统一适用的静态换元，而不是按模型或实例寻找特制系数。令

```text
w1=(g1+g2+2*g3)/4,
w2=(g1+g2-2*g3)/4,
w3=(g1-g2)/2，                     即 w=K^-1*g。
```

从当前同源父域健全认证 ell<=w<=u；允许保守的前向盒支持，不使用终端 margin、LP 状态、对偶、攻击或分裂。取

```text
t=max_j(u_j-ell_j)>0,
z=(w-ell)/t,
b_star=K*ell。
```

于是同一真实赋值满足 z in [0,1]^3 和 g=t*K*z+b_star。用 q_i=beta_i*g_i 代入 (B)，得到

```text
sum(q)-b_star^T*beta-t*beta1-t*(2*z1+z2) <= 0。             (P)
```

实际消费可直接内联 z，不创建 Z、z 或 w 坐标：

```text
sum(q)-3*(g1+g2)/4-g3/2
 <= (b_star1+t)*beta1+b_star2*beta2+b_star3*beta3
    -2*ell1-ell2。                                       (F)
```

证明只使用同源恒等式和健全盒界，因此对整个父域、所有原合法相位同时成立；零激活无需打破标签对称。t=0 时三预激活均为已认证常量，应走已有常量结构规则，不执行除法。无法认证有限界时不生成本行，不引入替代求解路径。

这是一条统一的前向关系生成规则，但不是高效选取全部三元组的完整算法，也不是新域定义的充分答案。

## 明确的物理分离：不只排除自由辅助量

先取共同源 z in [0,1]^3、g=K*z+(-1,0,0)、q=ReLU(g)。考虑以下查询松弛点：

```text
beta=(3/5,3/5,1/2), z=(2/5,2/5,1/2),
Z=[[3/8, 7/20, 2/5],
   [7/20,7/20, 1/5],
   [3/10,1/10, 1/4]],
q=(21/40,1/2,1/5)。
```

它可由 (B) 的二十个整数等号顶点的均值，将 Z11 从 7/20 增加 1/40 得到。以下直接给完整旧端延拓，不依赖执行顶点枚举或数值求解。

每门的完整 source-labelled 单门 hull 都有两点实际见证；两点均在盒内严格内部：

| 门 | active 质量 | active 源 | inactive 源 | 两源处 g_i |
| --- | ---: | --- | --- | --- |
| 1 | 3/5 | (5/8,7/12,2/3) | (1/16,1/8,1/4) | 7/8, -9/16 |
| 2 | 3/5 | (7/12,7/12,1/3) | (1/8,1/8,3/4) | 5/6, -1/2 |
| 3 | 1/2 | (3/5,1/5,1/2) | (1/5,3/5,1/2) | 2/5, -2/5 |

各行按对应质量混合，均还原同一个 z，以及该门 beta、Z 行和 q。见证不只是预激活区间内的点，而是实际原源向量；因此比较不止于普通四行 big-M。

对每个相位对，D035 在全部三个源方向上共用同一个 delta 的可行区间为

```text
delta12 in [13/40,16/40],
delta13 in [11/40,14/40],
delta23 in [10/40,14/40]。
```

取 (delta12,delta13,delta23)=(14,12,12)/40，全部 McCormick 与 D035 四类共同三角行成立，故所有两乘二四环也成立。三个 delta 还可由同一个纯 phase 分布实现：

```text
P111=7/40, P110=7/40, P101=P011=5/40,
P100=P010=5/40, P001=P000=3/40。
```

所有质量严格为正。这里不声称它与各源条件矩共同来自一份真实 NN 分布；缺失的正是这种共同源相容性。

然而 (P) 已投影为 sum(q)<=2*z1+z2，旧点违反 1/40。左侧只含实际 q 与原源读出；为同一个物理点重选自由 Z 无法消除违反。

## 非零偏置和下一层的实际读出

取 epsilon=1/100，改为

```text
g=K*z+(-1,epsilon,epsilon)。
```

全部三门偏置非零，含普通正负混权，原两点见证仍有严格相位余量。相同 beta、z、Z 给出

```text
q=(21/40,253/500,41/200)=(0.525,0.506,0.205),
F=sum(q)-2*z1-z2=9/250=0.036。
```

新行则对整个输入盒证明

```text
F <= epsilon*(beta2+beta3) <= 1/50。
```

因此，含一个真实 live source skip 的下一门

```text
r=ReLU(sum(q)-2*z1-z2-1/40)
```

在新关系下恒为零；旧抽象父域上的同一个分数点给 h=11/1000、r=11/1000，可取下一原相位为 1。这是下一 ReLU 在当前旧抽象父域上的真实图点，故其完整单门 hull 也包含它。不能将此句换成“整个上游具体网络的完整 child hull”，后者已经知道 r=0。

在这个例子中，K^-1*g 的精确盒下界为 (-97/400,-101/400,-101/200)，三宽度均为 1；统一规则自动得到 t=1、b_star=(-1,epsilon,epsilon)，不需要按反例选择规则。

小的普通系数扰动也有开放余量：单门见证的源坐标和 guards 严格可行，两两因子的 delta 也严格位于允许区间；精确盒支持、t 和内联行的系数均连续。因此存在一个非零系数扰动邻域保留分离，可打破 K33=0 等特定等式。这不是训练权重分布上的适用率证明，也不据此宣称实际 CNN 已收益。

## 完整费用、组合边界和资格

若 g、q 和原 beta 已有物理坐标，一个三元组至多添加一条 LE、九个变量系数，不新增连续量或原 bit。若 g 只是 source readout，必须支付三次 K^-1 源合并、六个有向支持界、临时与证据存储、ell/u/t 的可靠算术，以及最终行在全部源因子上的展开。全矩阵稠密时不能按“九个非零”记源展开费用。

三个共同源读出是线性关系，不要求额外 LP。但若认证器内部调用既有终端求解器或额外优化，费用与边界必须单独声明；本轮没有实施这种调用。固定 K 的有理系数避免矩阵求逆的不确定性，真实模型系数及区间端点仍须可靠 outward 处理，不能以中点替代原模型。

宽度 m 的层包含 O(m^3) 个有序或无序三元组；排列和补相位变体还会扩大集合。没有授权全面枚举，更没有证明 GPU batching 抵消这些费用。挑选机制必须按统一可观察结构预注册，不能看实例身份、标签、历史结论或终端结果。

新增行可作为共同谓词经 affine/Add 继续保留；本例证明一个后继 ReLU 能消费它。若随后把全部源幅值或原相位相关观察删除，仅保留若干独立界，则本例不证明仍有同等强度。任意跨层精确闭包需要另证；参见同目录 CLOSURE_BOUNDARY.md。

本轮没有新的域表示、实现资格、GPU 实测、真实网络匹配、shadow 或正式回放。下一步要解决的是这个共同相容性如何进入可组合、代价可付的 Neural-HZ 定义，并与已有 RLT/k-ReLU/输入分组方法作实质区别；不是将 Bell cuts helper 接到旧验证器后改名。
