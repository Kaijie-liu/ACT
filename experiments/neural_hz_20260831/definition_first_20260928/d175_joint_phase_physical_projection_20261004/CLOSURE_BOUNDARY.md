# 原相位能继续消费什么样的线性商

本文件记录一个精确但范围有限的支撑命题，避免将共同观察压缩后，免费声称下一原相位仍可无损消费。它是线性代数闭包条件，不是新 Neural-HZ 能力阳性，也不是所有表示的指数下界。

## 固定线性商的必要充分条件

令 v 为共同源的有限 phase-cell 观察载体，M_i 为乘原 beta_i 的对角算子，w=Qv 为固定线性商。存在商空间上的线性 T_i，使

```text
Q*M_i=T_i*Q
```

当且仅当 ker(Q) 对 M_i 不变。

必要性：若 Qv=0，则 Q*M_i*v=T_i*Qv=0。充分性：在 image(Q) 上定义 T_i(Qv)=Q*M_i*v；不同原像之差位于 ker(Q)，不变性保证定义良定，再按需要延拓至外围坐标。对一组原 masks 同时成立，等价于 row(Q) 对这些对称对角算子共同不变。

若 row(Q) 包含常数观察 1，且对 k 个所有组合均可达到的原相位乘法普遍闭合，那么反复乘 beta_i 或 1-beta_i 会得到每个 phase-cell indicator。它们线性独立，标量观察函数空间至少为 2^k 维。若还要求每个 d 维原源的全部 affine 观察这样闭合，并且每个 cell 有源空间内部，则各 cell 上独立的 affine 函数给出至少 (d+1)*2^k 维。

这是对固定、精确、纯线性 observation quotient 的函数空间结论，不是所有有损域、非线性商、因子化电路或 extended formulations 的物理存储下界。对已知有限后续算子集可能有很小的不变子空间；尚未找到本轮普通 CNN 的适用结构。保留逐门因子化图可以避免显式全表，但必须支付相应终端关联，不能把原图换名当创新。

## 普通混权源上的摘要不足

在 x in [-1,1]^3 上，令

```text
A=[[1,1/10,0],[0,1,-1/10],[-1/10,0,1]],
q_i=ReLU((A*x)_i+1/10)。
```

对 alpha in {0,1}^3 取真实源 x=A^-1*(alpha-3/5*ones)。A=I+E 且 ||E||_infinity=1/10，因此 ||x||_infinity<=2/3，所有源点严格在输入盒内部。各预激活为 alpha_i-1/2、幅值 q_i=alpha_i/2，原相位非零点处恰为 alpha_i。

取下一门

```text
r=ReLU(q1+q2-(2/5)*q3-3/4)，原相位 gamma。
```

在这八个真实点上，gamma=alpha1*alpha2，且

```text
r=gamma/4-gamma*alpha3/5。
```

分别在偶 parity 的四点及奇 parity 的四点取等权。两分布的全部一、二阶父 source/phase/幅值 moments 相同；E gamma 也同为 1/4。但

```text
E_even r=1/16，E_odd r=1/80；
E_even(gamma*alpha3)=0，E_odd(gamma*alpha3)=1/4。
```

保留新 bit 的均值本身，不能代替它与原共同源的交叉观察。以上是证明中真实点的凸组合，不是运行时采样、phase split 或验证搜索。

这两个分布都是真网络分布，故都在完整 source-labelled 单门 hull 的交内。本例只证明摘要不能唯一恢复后继均值，不证明排除任何假点，更不冒充比该强参照更强的验证器。

在这八点上补 E(gamma*alpha3) 足够，但整个连续输入盒还需新相位对实际源及余项的关系。不能把八点上的离散公式替换为整个网络的定义。显式全闭包表最多需要相应的指数 observation 与谓词提升；若改为有损或保因子化定义，须重新证明健全性、精度和完整代价。
