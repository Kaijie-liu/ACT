# 联合见证投影的进展与未解决问题

本轮从 D154 丢失共同见证的反例继续，完成了精确联合投影及跨层组合证明。
结果没有达到强大 Neural-HZ 的能力突破：修复精度后的直接终端代价明显增加，
而一个省行的正控需要真正的区间自由度，不能直接归给精确确定性 CNN。
[完整定理、计数及反例](THEORY.md) 已保存，没有新增正式解。

## 改变下一行动的证据

四门控制不再独立处理 max 图和相位乘积，而是把全部旧幅度投影到三个共同
读出。一个共同标量区间可重构全部幅度，所以保原 LP，也能接 mixed affine、
残差和下一 ReLU。直接展开后的账是4→3幅度，但16→52行、32→178谓词nnz；
52行还要求顺序对整个比较 LP 源有效，否则是56行/192nnz。更强 D018 chain
的精确消元另给64行直接上界，不能偷用前一个账。

普通固定分数切片中，投影像确有12个必要面，而原box是8面；这是限定在该
切片、无额外连续提升的事实，不是52行极小性或所有 Neural-HZ 的不可能定理。
因此不把小的点值 max/min 检查冒称免费全局终端，更不据此报 GPU 验证。

一般共同区间纤维的多子门消元也已证明，并给出少1幅度、6→4行、20→12nnz
的有偏置混权正控。但主代理指出并证明：若保留完整输入、隐藏量是真实网络
中间值，精确整数纤维必须是单点。该正控只能代表一般 HZ 或已有有损余项，
不能据此启动“真实 CNN 中宽自由幅度”的普查。另一个双子门反例说明分别
投影各自合法仍可能没有共同见证，不能删除交叉约束。

这些证据否决了当前两个具体实现入口，而不是整个研究目标。当前没有选定
新的数值候选，不需要用户提供额外权限，不是外部 blocker。下一工作继续
面向实际源关联状态的联合域定义与算子，不扩大存档或测试框架来替代创新。

## 共同分母支线已查重

本轮也检查了正共同分母形式 y=n/d：仿射偏置可进入分子 Wn+b*d；正齐次
ReLU 可在分子处理；固定线性性质 Ay<=b 可直接写 An-b*d<=0。随后完整读取
D104 的 DEFINITION.md 与 PRIOR_ART_AND_DECISION.md，确认共同分母、仿射/
ReLU闭包、偏置缩放、原 bits×scale 及未归一化 residual 的障碍早已归档。
因此不重新立项、不称新域。延迟归一化的接口也没有解决分母的生成或不同
分母的合流，更没有给 d=1 的普通 CNN 带来新机制。

本轮核查了 [Boyd 与 Vandenberghe 作者教材](https://www.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf)
第2.3.3节的线性分式/齐次表示背景。这里的神经规则仍是自行推导及既有项目
记录，不把教材当成新颖性证明。其他搜索结果未用于未经核实的技术主张。
