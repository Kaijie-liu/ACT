# 从共同松弛量生成源相位关系

上一轮证明了带共同尺度的双神经元关系，但没有给出普通父域上自动产生尺度的规则。本轮补上这个缺口：对完整共享因子的可靠盒，存在一个线性费用、无优化器的规范构造；在精确盒合同下还可以完整刻画其适用边界。新正控比仅比较固定耦合系数更强：它通过完整的无源双门联合凸包与各单门带源凸包，却被新源相位关系排除。

这仍是 Neural-HZ 的候选演算，不是已经完成的新域、真实网络新增解或新颖性证明。研究目标仍是域定义、组合传播和实际验证能力；不将旁接 helper、密集小原型或存储优化当作本体突破。本轮没有新候选代码或数值执行。

## 同父状态上的构造

保留全部连续因子、原二元相位、EQ/LE、共同身份、消费者及原输入重构。对同父预激活 f1、f2，按预先固定的 a,b>0、ab<1 形成两个完整差分。用当前父域全部相关 latent 的可靠盒归一化后写成

```text
r1=f1-a*f2=d1+p1^T*xi,
r2=f2-b*f1=d2+p2^T*xi,
xi in [-1,1]^n,
c_i=d_i+sum_j |p_ij| > 0.
```

这个盒只用于有效性证书，不替换原非凸父域。对已有二元因子使用其区间外包作界计算，也不改变其整数类型。共享坐标先合并系数，不能为两门复制 latent。固定坐标只在该证书中代入常数，原身份与谓词不删除。

在两个系数非零且同号的坐标上定义

```text
v_j=sign(p1j)*min(|p1j|/c1, |p2j|/c2),
```

其他坐标取零。令 omega0=sum|v_j|。若 omega0>0，按固定公式

```text
tau=min(1,1/(4*omega0)),
w=tau*v, omega=sum|w_j|,
s=1-omega+w^T*xi,
l=1-2*omega, u=1, k_i=c_i.
```

则 0<omega<=1/4，且 1/2<=l<=s<=1。若 omega0=0，直接取 s=1，不虚构源变化，也不改用另一个策略。c_i<=0 等未满足本定理前提的结构不由本原语覆盖；仍保留原有网络关系，不能制造可行性、删除相位或把未覆盖误记成收益。

证明来自逐坐标的非负余量：

```text
c_i-r_i=sum_j |p_ij|*(1-sign(p_ij)*xi_j),
1-s=sum_j |w_j|*(1-sign(w_j)*xi_j),
c_i-r_i >= c_i*(1-s).
```

所以整个盒、因而整个父域上 r_i<=c_i*s<=c_i。没有依赖实例身份、属性、公开标签、LP 状态或相位枚举。它给 D204 的尺度前提，同时不放大原 D203 的两个盒常数上界。

## 最大共同仿射松弛量定理

在上述精确盒合同下，考虑所有仿射 t 满足

```text
0<=t(xi)<=min((c1-r1(xi))/c1, (c2-r2(xi))/c2)
```

且覆盖整个 [-1,1]^n。未缩放的

```text
t_star=sum_j |v_j|*(1-sign(v_j)*xi_j)
```

是它们的点态最大者。

证明：任何在盒上非负的仿射函数都可以写成 t_min 加若干 |z_j|*(1-sign(z_j)*xi_j)，其中 t_min>=0。每个 r_i 的最大面上，其松弛量为零，所以 t 也必须为零。由于每一项非负，这强制 t_min=0，且每个非零 z_j 必须在两个 p_i 中都非零同号。在某个 r_i 的最大面上只翻转该坐标，就得到 |z_j|<=|p_ij|/c_i。两个界共同给出 |z_j|<=|v_j|；反向逐项比较即充分。故 t<=t_star，且 t_star 自身满足所有要求。

这个结论不只是“找到一个尺度”。它给出了在不放大精确盒 caps 的仿射合同中，何时可能有非恒定共同尺度。如果没有公共同号坐标，唯一可行的是 t=0、s=1。固定 tau 是保证正尺度的安全缩放，不宣称解决另一种最优化问题。

一个普通负控是 a=b=1/2，x,y 属于 [-1,1]，

```text
f1=(2/3)*x+1/2,
f2=-(2/3)*x-2*y+1/2.
r1=x+y+1/4,      c1=9/4,
r2=-x-2*y+1/4,   c2=13/4.
```

两门非平行、有偏置、均跨零，但两个差分没有公共同号坐标。因此不能在该合同下声称仍可提取非恒定仿射尺度。结论仅针对全盒、精确 caps、仿射 s 且 s<=1 的合同；更强父谓词或宽松 caps 的情形不受此不可能性结论约束。

## 关系生成与查询组合

D204 的十行关系在这里直接使用 k_i=c_i、u=1。它保留 D203 的原四条幅值和相位耦合上界，并补充源相关上界。因此有限关系只会收紧；原整数图保持不变。

设原门可靠下界为 -ell_i，ell_i>0。把新源相位行与旧图上行作固定正系数组合，得到

```text
q_i<=h_i+M_ij*q_j,
h_i=c_i*(l*f_i+ell_i*s)/(c_i*l+ell_i),
M_ij=a_ij*ell_i/(c_i*l+ell_i).
```

在合法父域上 h_i>=0，局部 M12*M21<ab<1。对该 pair 的共同方向，使用 D138 的闭式系数，再将 v1*h1+v2*h2 与其余完整父仿射式合并，继续向更早的 bank 消去，最后才对根源求界。这是表示内部的查询演算，不读取失败 LP 或启动第二个验证器。

这里有一个重要组合结论：h_i 中更早幅值的系数可以为负。每一步的有效性来自对每个合法父赋值成立的局部不等式，以及 h_i 只引用出生前的坐标；因此逐 bank 递推仍健全，不要求整个跨 bank 系数矩阵非负。但这只证明最终上界健全，不能把 D138 某个选中 fiber 的精确 support 外推成整个非凸交集的精确 support。

另一个边界不能省略：保留旧有限行，并不自动证明一个只使用新 h 的便宜查询逐方向支配旧查询。如果需要组件层面的查询不退，必须保留旧证书并按预先固定规则共同计算、计费，或者另证查询支配性；不能用原生整数集合相同来代替这个证明。任何双证书方案都不是本轮已经实现的能力。

## 强于全部无源常数关系的普通盒正控

令 x,y 属于 [-1,1]，固定 a=b=1/2，取

```text
f1=x+3*y+1/4,       q1=ReLU(f1),
f2=3*x+4*y+1/4,     q2=ReLU(f2).
```

规则得到

```text
r1=-x/2+y+1/8,          c1=13/8,
r2=(5/2)*x+(5/2)*y+1/8, c2=41/8,
v_y=20/41, tau=41/80,
s=(3+y)/4, l=1/2, u=1.
```

s 是算法唯一生成的，不是为后继或显示点手选。门一的全域下界是 -15/4。新行与原图上行合并证明整个父盒上

```text
J=(73/16)*q1-(15/8)*q2-(13/16)*f1-(195/32)*s<=0,
child=ReLU(J-1/16)=0.
```

比较点取

```text
x=0, y=-1/3, s=2/3,
q=(41/40,23/40), beta=(1/2,1/2).
```

它通过每一门的完整 source-labelled 凸包：第一门使用源 (19/20,17/60) 与 (-19/20,-19/20) 各半，预激活为 41/20 和 -71/20；第二门使用源 (3/10,0) 与 (-3/10,-2/3) 各半，预激活为 23/20 和 -199/60。两门的源均值都严格等于显示的 (0,-1/3)，且所有见证源严格位于盒内部。

更强的是，显示的 (q,beta) 本身属于真实双门联合投影的完整凸包：取两个共同源 (-9/10,9/10)、(-9/10,-9/10) 各半。前者两门均激活，输出为 (41/20,23/20)；后者两门均不激活，预激活为 (-67/20,-121/20)。因此输出和标签均值正是显示值，只是这个联合见证的源均值为 (-9/10,0)。

所以该点通过所有只涉及 (q,beta) 的联合凸包关系，不限于两个固定 eta、任意 eta 的相位常数行或某一个有限菜单。它也通过新 source plain feedback：第一行给上界 329/240，第二行为 943/240。

但新 source-phase 行对 q1 的上界是 463/480，小于显示 q1=492/480，违反量为 29/480。显示 J=93/640，所以精确后继允许 child=53/640>0。新规则则已在全父盒证明 child=0。

这隔离出了实质信息：分别知道完整单门源关系，以及完整的无源双门联合关系，仍不足以恢复源与共同相位之间的耦合。它是严格数学分离，不是网络 ADV 或新增 CERT。完整带源双门 hull 或旧 HZ 加同样源相位行也能证明新结论；没有宣称胜过它们或已建立外部新颖性。

## 可靠系数与原生父域边界

若实际系数由同一个参数 theta 决定，且有可靠区间，可取

```text
c_i=d_i.upper+sum_j maxabs(p_ij.interval).
```

共同项只从符号确定且同号的区间中提取，用保证的 minabs/c_i 代替精确 |p_ij|/c_i。对任一同一个 theta，偏置余量、maxabs 与实际绝对值之差，以及余下逐坐标 deficit 都非负，因此同一构造仍认证 r_i(theta,xi)<=c_i*s。它不需要把 BN 的真实系数取中点，也不允许不同消费者选择不同 theta。

但是，对原网络所有 theta 有效不等于对一个已经有损的抽象父域有效。例如真实 f1=f2=(1+theta)*x，|theta|<=1/10，a=1/2，差分 cap 为 11/20。若某个父表示已将误差独立化成 f1=x+e1、f2=x+e2，|e_i|<=1/10，则 x=1、e1=1/10、e2=-1/10 给 r1=13/20，已经超过该 cap。不能把原参数证书移植到更大的父域。

因此实际接入必须对完整 owned 父表达式认证，包括旧幅值、误差、二元项与所有源关系。以它们的可靠盒作保守证书是合法的；只恢复原模型系数而忽略抽象父域中的额外自由量不合法。区间推广尚未在实际 BN bridge 上执行。

## 完整费用与实现选择

已给定两个差分和其可靠源盒时，合并、共同项提取与归一化只需 O(nnz(p1 union p2)) 运算。这个费用不含选择 pair、读取父表达式、可靠范围计算、系数位数增长或终端转换。

若尺度含 d 个父坐标，将 s 内联进 D204 十行后有 10 LE 和 22+4d 个 nnz，不含已有源和 bit 边界。若另物化 s，则须支付一个新连续别名、一条等式以及 d+1 个等式 nnz，不能把 s 当免费标量。完整原图、原 bits、历史谓词、读出、decoder、证据、全部内存和两种查询证书的成本均另计。

当前 D149 的 owned API 可作为代数参考，但没有已通过实现同时覆盖这些 pair 关系、完整 ReLU 出生、递归查询、membership 和 cost。估计新增小型参考需数百行，并且其 64-phase/128-coordinate 上限不能容纳已经找到的真实 200 门 bank。因此本轮不为数学门单独再造一个不能直接承载目标的密集 reference，也不扩大冻结上限；下一接入对象见 [真实目标记录](NATIVE_TARGET.md)。
