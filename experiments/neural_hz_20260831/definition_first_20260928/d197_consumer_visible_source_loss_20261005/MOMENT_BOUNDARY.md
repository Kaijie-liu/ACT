# 共同二阶摘要的能力边界

二阶摘要可以给出共同误差关系，但它仍不能替代相位与来源的混合关系。本文只做纸面比较，不引入 SOCP、SDP、采样或额外验证器。

## 共同来源的 pair 关系

同一有限非负源测度的总质量为 pi，令 M_i=integral g_i、Q_i=integral ReLU(g_i)，且 T_ij>=integral(g_i-g_j)^2 是可靠上界。使用 2 ReLU(g)-g=abs(g)、反三角不等式与 Cauchy，得到

```text
abs(2(Q_i-Q_j)-(M_i-M_j)) <= sqrt(pi T_ij).
```

对预先固定 kappa>0，Young 不等式给出两条线性关系

```text
±[2Q_i-2Q_j-M_i+M_j] <= (kappa pi + T_ij/kappa)/2.
```

已有这些共同读出变量时，两行合计至多 12 nnz，无新增 phase。但 T 的可靠产生、来源绑定、更新与终端读取并非免费；完整 covariance 可为二次规模，固定 pair 的二阶量也需独立计费。不能从数据样本方差推断整个验证域的可靠 T，也不能偷加均匀或高斯假设。pi=0 时实际测度为空，M=Q=0。

若记 Jensen gap J_i=Q_i-ReLU(M_i)，则同式等价于 abs(2(J_i-J_j)+abs(M_i)-abs(M_j))<=sqrt(pi T_ij)。非单位质量不影响该式，因为 ReLU 正齐次。

普通非平行偏置例子：取总质量 pi=1，共同 X、Y 均值零、各方差 1/4、协方差零，g_1=X+Y/10+1/4，g_2=X-Y/10+1/4。此时 M_1=M_2、T_12=1/100，得 abs(Q_1-Q_2)<=1/20；固定 kappa=1/10 的两条线性行达到同一界。它保留独立 gap 盒丢掉的抵消，但拥有同一二阶信息的已有 absolute-value/pair-sector 推导也能得到，不能报新颖性。

## 一二阶矩与全相位分布仍不足

取 X 属于 [-1,1]，g_1=X-1/4。以下两个真实源分布均无零 guard：

```text
mu: X=-1/4, 3/4, each with mass 1/2;
nu: X=3/20, 7/20, -9/20, 19/20, each with mass 1/4.
```

二者 E[X]=1/4，E[X^2]=5/16，第一门 active 质量均为 1/2；但 E[ReLU(g_1)] 分别为 1/4 和 1/5。

再独立加入等权 Y=±1/2，第二门 g_2=Y-1/5。两门非平行且有偏置，所有源点严格内部、符号严格。两个二维分布的全部一、二阶源矩一致，全部两 bit 联合质量也都等于 1/4，且 E[q_2]=3/20。带 live skip 的混权读出 L=q_1-2q_2+X/10，其均值却分别为 -1/40 与 -3/40。

它们不具有相同的 phase-source 混合矩；恰恰说明不能用一二阶摘要加纯相位表代替那些关系。这是两个真实混合的不可辨识性，不是排除虚假查询点的能力分离，也不是新增 CERT。D117 已研究更一般的有限观察损失，本例只具体化当前二阶提案的缺口。

## 文献与后继算子范围

关于分段线性函数在矩信息不确定性下的期望界，可参见 Natarajan、Sim、Uichanco 的 [Asymmetry and Ambiguity in Newsvendor Models](https://optimization-online.org/wp-content/uploads/2008/07/2042.pdf)。本轮只读题名、摘要和引言背景，没有用其定理为本项目认证，也不采用其中 SOCP 路线。上面的 pair 关系和反例均为直接推导，不把它们归为论文新定理。

固定源摘要上的平均预激活为负，不推出下一 ReLU 恒零；需要对整个实际父状态集合的点态可靠界。本文不提供后继非线性的闭包或全局支持算法，因此二阶辅助路线没有晋级为新的 Neural-HZ 候选。
