# Neural-HZ 本体与查询精度研究边界

本轮推导没有形成新的强 Neural-HZ 域。得到的是条件源压缩的精度合同，以及这些合同为何不能冒充非凸定义创新的明确边界。依据用户“重点是提出强大的 Neural-HZ”的要求，将本轮保存为辅助理论，不晋级为实现候选，不以 helper、查询松弛或表示压缩代替主线。

## 本轮结论

[消费者可见损失](CONSUMER_QUOTIENT.md)证明：源观测压缩是否精确，不能只看预激活秩；完整消费者是否还读取被遗忘的源方向才是关键。它给出盒源普适重构条件和一个共同误差集合。该结论细化 D019 与 D117/D142 的边界，不构成新域。

[守卫缺陷](CANONICAL_DEFECT.md)给出稀疏源关联接口的精确误差恒等式、局部可评估上界和一个合法混合反例。非负读出与非正读出各有精确支持结论，真正尚未闭合的是混合正负权读出。关键检查是：共同相位质量若绑定原生整数 bits，就集中于单个相位；保留 guards 时缺陷为零。因此这些有损状态属于分数查询层，不能宣称新增了原生非凸能力。

[二阶摘要边界](MOMENT_BOUNDARY.md)记录一个保留共同误差的 pair 关系，以及一、二阶源矩加完整相位分布仍不足的普通反例。这不支持用二阶摘要替代相位与来源的混合关系，也不产生新的求解路径。

## 主线决策

不把本轮三条辅助路线单独包装为 Neural-HZ 候选。下一份本体提案必须明确写出域元素、具体化、共享源与原始相位的关系，以及穿过下一非线性时保留什么；必须在同一完整消费者接口上与拥有相同关系的旧 HZ 公平比较。只在查询层更换表示、给旧关系换名、只减少前端变量，均不足以进入实现阶段。

这不是宣称辅助理论无用，也不是要求不可能地“比精确 HZ 的真实集合更精确”。目标是有实质意义的精度与完整代价改进，并保持非凸语义与统一结构规则。D175 已有强于指定全部两门接口的物理关系和后继控制，不能重复当作新发现。D196 的完整联合见证仍有不可忽略的相位表与终端费用。本轮没有解决可付的递归表示、全 GPU 查询、smooth/Transformer 或真实 CIFAR/Tiny 的能力问题。
