# 条件源压缩的消费者可见损失

本文给出两个纸面结论：盒源上普适条件重构的精确分类，以及源观测商在完整消费者上的共同误差界。它们解释什么信息可以安全遗忘，不是一个已完成的 Neural-HZ 定义。

## 盒源普适重构条件

设 P=[0,1]^d，A 为固定线性观测。考虑以下普适性质：对任意有限质量 lambda_s>=0、sum lambda_s=1、t_s 属于 A(P)，以及任意 z 属于 P 且 Az=sum lambda_s t_s，都存在 z_s 属于 P，使

```text
A z_s = t_s,        sum_s lambda_s z_s = z.
```

零质量项忽略。该性质成立，当且仅当 A 的全部非零列线性无关。即其核只包含完全不可见的坐标方向。

充分性：非零列线性无关时，每个 t_s 唯一确定所有可见坐标；选择盒内原像后，其加权均值由 Az 唯一确定，故等于 z 的可见坐标。零列坐标在所有单元设为 z_j 即可。

必要性：若非零列相关，存在非零 h 属于 ker A，支撑仅含非零列。选盒顶点 v，使 h_j>0 时 v_j=1，h_j<0 时 v_j=0；其余坐标任取顶点。充分小 epsilon>0 给出 p=v-epsilon h 属于 P。选 h_j 非零的坐标 j，则 A_j 非零，p_j 严格在盒内。再取充分小 delta>0，使 p±delta e_j 均在盒内，定义

```text
t_plus  = A v + delta A_j,
t_minus = A v - delta A_j.
```

二者属于 A(P)、不同且均值为 Av。但是两个盒内点均值为顶点 v，必然都等于 v，不可能分别映射到这两个不同观测。矛盾。

这并非只能在顶点发生：将 z=v 及两个上述原像分别与盒中心按同一小比例 eta>0 混合，得到严格内部的 z 和观测原像，仍满足均值观测条件。如果任意接近零的 eta 都存在所需重构，由盒紧性取极限即可重构被否定的顶点例子。因此充分小 eta 仍失败。此论证仅说明结构性限制，不开展极端数值测试。

范围：该定理量化任意条件表，不是声称某个固定网络的守卫表一定失败，也不排除有效的有损近似。一般盒可按坐标仿射归一化。D019 已给出纤维插值充分条件与普通残差反例；这里是对盒源普适条件的细化，不宣称外部新颖性。

## 精确投影图的共同误差集合

现在 P=[ell,u] 为紧盒。局部网络图的 source 依赖仅通过 Az，记

```text
G = { (z,beta,q) : z in P, (Az,beta,q) satisfies the actual local graph },
K = conv G.
J = conv { (Az,beta,q) : (z,beta,q) in G },
Khat = { (z,beta,q) : z in P, (Az,beta,q) in J }.
```

原相位、零点标签均保留。这里 K、J 是查询强度参照，不用它们整体替换原生非凸域。

每个 (z,beta,q) 属于 Khat，都有 (z_prime,beta,q) 属于 K 且 A z_prime=Az。证明：把投影图点写为实际图点的有限凸组合，逐项取 P 内源原像，再以同一权重平均即可。因此

```text
K subset Khat subset K + { (h,0,0) : h in (P-P) intersect ker A }.
```

对全部实际线性消费者组成的向量 Y=Cq+Bz，额外输出差属于同一个集合

```text
E = B((P-P) intersect ker A).
```

若 B=T A，K 与 Khat 在 (Az,beta,Y) 上的投影完全相同。一般取预先固定的结构矩阵 T，则任意固定读出方向 w 的误差满足

```text
abs(w^T (Y-Y_prime)) <= epsilon_w,
epsilon_w = sum_j (u_j-ell_j) * abs([w^T(B-TA)]_j).
```

因为 h 属于 ker A，Bh=(B-TA)h，且 abs(h_j)<=u_j-ell_j。计算此宽度不需要查询求解器、LP 对偶或 margin 驱动选择。全部消费者共享同一 h；独立误差盒可作更弱外包，但不得声称仍保持同一联合精度。

相同论证适用于完整物理线性关系 c^Tq+d^Tz+f^Tbeta<=r，其松弛只需支付 d 对源核方向的共同误差。不能把每条关系分开选择互不一致的源见证后声称联合精确。

## 不能省略的前提与费用

必须使用真实 A(P)。以独立预激活盒代替 A(P) 会另增损失，本定理没有为它付款。原源、输入 decoder 仍然保留；并不要求为了 decoder 而在每个相位条件单元复制全部源。但旁路、残差、其他通道和实际谓词读取了哪些源，必须完整计入。

存在非盒父谓词、上游相位或额外非线性消费者时，不能仅保留其均值就套用上述图假设。若要使用一般父集合，须重新明确完整 source 对象与投影图，而非把丢失的约束隐去。

费用包括 A(P) 的表示、所有条件单元、共享表、原 source、BN/别名、父谓词、消费者与 decoder。真实四门 patch 的 27 个共享源与四个预激活别名，不因此自动成为可精确互换的接口；完整 B 的残差宽度尚未实测。

ReLU 的点态 Lipschitz 性可以转移已证物理误差，但不会保持下一层相位标签或建立整个网络凸组合闭包。只有负平均预激活也不足以断言下一 ReLU 恒零。本文没有证明新的统一递归算子或完整验证增益。
