## 共同源对称能量预算

在 D180 的同一共同见证 Kt=Kd 上，K=[C; C D_tau]，同时要求
||t||^2<=E 和 ||2d-t||^2<=E。
置 n=t-d，等价于 Kn=0 及 ||d||^2+||n||^2+2|d^T n|<=E。
真扩展 t=d 在整个父域成立。新的共同关系严格包含于原球纤维，但不是新的球几何。

严格的普通固定源控制是 A=I-2uu^T/9、u=(1,2,2)、x in [-1,1]^3、d=Ax，
b=-ones/4，C 的两行为 (1,-1,0) 与 ones，E=3。A 是正交矩阵，故预算可靠。
取 x=-39*ones/40，d=(13,143,143)/120，原相位为 011、固定参考为 000。
旧代理 t=d+(1,1,-2)/10 满足 Ct=Cd、严格代理符号及原 branch caps，
||t||^2=12937/4800<3；但 ||2d-t||^2=15017/4800>3。
C 与 C D_011 堆叠满列秩，因此给定这个 packet 后不能另换 t 绕过排除。

记 v_beta=D_beta C^T lambda+(I-D_beta)C^T mu、L=v_beta^T t。
对固定 rho,eta>0 和固定 h，两球给出有效有限行

```text
2L+2h^T d <= (rho+eta)E
             + ||v_beta+h/2||^2/rho + ||h||^2/(4eta).
```

证明将左侧写成 2(v_beta+h/2)^T t+h^T(2d-t)，分别使用 Young 界。
因原 beta 为整数且按坐标选择固定系数，右侧平方可展开为原 bits 的仿射式，
不需要新增 beta*d 产品。但方向数、源展开、可靠范数和证书费用仍须支付。

这个候选尚无整盒强旧参照优势，有限 LP 也不精确表达两球。原逐门图在控制中
只有 12 行，而旧 D180 口径已有 46 行；追加关系不会自动减少费用。因此不选它
实施，不继续围绕这个固定源点调整方向。它是内部细化证据，不是新域能力收益。

## 循环和互补约束的排重

对同一状态的 q_i=ReLU(g_i)、n_i=q_i-g_i，置换 pi 满足恒等式

```text
sum_i q_i*(g_i-g_pi(i)) - 1/2*sum_i(q_i-q_pi(i))^2
    = sum_i q_i*n_pi(i) >= 0.
```

右侧非负 rails 乘积已解释全部该类循环，项目 D140 已存档。它可加强遗漏这些
乘积的弱 moment 松弛，但不能据此宣称超越同信息强参照。并行文献复核也确认
[Noori 等 Theorem 7](https://arxiv.org/html/2407.06888v2) 的相应 Zames–Falb
冗余范围；这不表示原四行 LP 已自动拥有全部二次信息。

同一状态的 repeated-activation sector 不能直接套到不同基点的增量。
ReLU 在 (1,-1) 与 (0,-2) 上给 delta_g=(1,1)、delta_q=(1,0)，错误的跨增量
sector 得 (1-0)*(1-1-1+0)=-1。共同固定激活不等于这些增量来自同一标量函数。

另外，标量 sector 给 e_i=s_i*d_i、0<=s_i<=1，因此
(d1-d2)^2+4*e1*e2>=0：d1*d2>=0 时直接成立；否则 e1*e2>=d1*d2，
左侧不小于 (d1+d2)^2。取两个增量都在 active 区域且 d1=-d2，系数 4 已达边界。
这只是已有标量 sector 的推论，没有强参照分离，未选为下一域候选。
