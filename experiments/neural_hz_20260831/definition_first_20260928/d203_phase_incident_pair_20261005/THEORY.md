# 原相位参与的共同幅值块与精确局部查询

本轮得到一项正向数学结果：二点非负反馈幅值块的完整带标签凸包，可以直接用
原幅值和原相位的六条不等式表示，不需要共现乘积量或相位枚举。一个普通两源、
有偏置、非平行权重的混权后继例子，证明这些关系比完整单门凸包加旧反馈关系更强。

这不是已经完成的新 Neural-HZ。它是可作为域生成关系的局部原语和精确 lowering
定理；其整数集合仍可由原 HZ 表示，基本 indicator 推理已有先例。整个共同源网络
的理想性、真实模型收益、新颖性、GPU 与完整代价尚未取得资格。不能把两条新行
或一个新容器名字直接包装成 PLDI 级域创新。

## 非凸载体与保留语义

沿用同一父元素 H 的连续源、全部原 signed bits、EQ/LE、共享 latent/frame 身份、
全部活消费者和原输入 decoder。beta=(signed_bit+1)/2 只是原 bit 的认证视图。
原生具体化中 beta 仍为整数，预激活零点的两个原标签均保留。

研究的关系块定义为

```text
P = { e in R_+^2 : e1 <= c1+a*e2, e2 <= c2+b*e1 },
F = { (e,beta) : e in P, beta in {0,1}^2,
                  beta_i=0 implies e_i=0 },
c1,c2>0, a,b>0, a*b<1.
```

这是真正带原相位的非凸共同幅值关系。两个消费者不能分别选择 e。
可将有限个这种块与 H 的原谓词相交，全部读出对同一状态仿射；没有块时精确嵌入 HZ。
身份对齐后的具体化包含定义精度顺序，不主张可计算最佳抽象或完整格。

这一步没有删除原激活的精确源绑定。若保留原网络图再加入块，整数具体化不变，
收益来自更强的有限线性查询。如果未来要用块替换原图，必须另证 whole-parent
健全性与损失，不能从本页推导出“可以删除原源等式”。

## 顶点支撑与原相位的共同生成关系

先给出一般几何事实。对任意非空有界多面体 P 属于 R_+^m，设其全部顶点为 v^k，定义
F(P)={(e,beta): e in P, beta binary, e_i=0 whenever beta_i=0}。
则完整带标签凸包恰为下述系统的投影：

```text
lambda_k >= 0, sum_k lambda_k = 1,
e = sum_k lambda_k*v^k,
sum_{k:v_i^k>0} lambda_k <= beta_i <= 1, for every i.
```

必要性：每个给定整数标签允许 P 的一个坐标面；因为 e 非负，该面的顶点都是
P 中在对应坐标为零的顶点。对一个合法点作顶点分解时，只能使用其标签允许的顶点。

充分性：记 r_i 为上式中正支撑顶点的总质量。在各顶点上，v_i>0 时固定 beta_i=1；
剩余质量 1-r_i 上，以共同概率 (beta_i-r_i)/(1-r_i) 补充该标签。各自由标签可独立
补充，形成有限合法标签分布，且所有标签均值正确。r_i=1 时 beta_i=1，不需除法。
这是存在性证明，不建议运行时列举标签、顶点或输入区域。

一般 P 的顶点数可能巨大；此事实本身不是廉价算法，也不是新颖性声明。
关键是下面的二点结构允许全部生成质量在纸面上精确消去。

## 二点块的六行理想表述

记 D=1-ab，U1=(c1+a*c2)/D，U2=(c2+b*c1)/D。P 的四个顶点是
0、(c1,0)、(0,c2)、(U1,U2)。完整凸包 conv F 恰为

```text
0 <= beta1,beta2 <= 1,
e1,e2 >= 0,
e1 <= U1*beta1,
e2 <= U2*beta2,
e1 <= c1*beta1+a*e2,
e2 <= c2*beta2+b*e1.                              (A)
```

六行计数不包括原 bit 的四条端点界。原生域仍将两原 bit 作为整数；只有普通
终端外包才用 [0,1]。在整数标签上 (A) 与 F 完全相同。

证明：以 t 表示全正顶点 (U1,U2) 的质量。其余两个非零顶点质量分别是
(e1-U1*t)/c1、(e2-U2*t)/c2。上一节的共同生成关系等价于

```text
t >= 0,
t <= e1/U1,  t <= e2/U2,
t >= (e1-c1*beta1)/(U1-c1),
t >= (e2-c2*beta2)/(U2-c2),
t >= (e1/c1+e2/c2-1)/(U1/c1+U2/c2-1).
```

所有分母为正。两个相位下界分别与两个上界比较，恰给出 (A) 的四条上界，
使用 U1-c1=a*U2、U2-c2=b*U1。最后一个质量下界与两个上界比较，只给出
原两条 plain feedback；它们由 (A) 与 beta<=1 蕴含。故所有下界不超过所有上界，
可取它们的最大值作为 t，完成共同见证重构。没有新增 theta=beta1*beta2。

相对旧 e>=0、e_i<=U_i*beta_i 和 plain feedback，行数不变，连续/二元列数不变，
只增加两个原 bit 的非零系数：6 LE/10 nnz 变为 6 LE/12 nnz。
例如 c1=c2=1、a=b=1/2、U1=U2=2 时，旧 LP 接受
beta=(1/2,1/4)、e=(4/5,1/5)；新第一条关系要求 e1<=3/5，排除该点。

## 从普通 ReLU 共同源中生成

设当前同一父域上有 q_i=ReLU(f_i)，原 active 标签为 beta_i。若已认证

```text
f1-a*f2 <= c1,
f2-b*f1 <= c2,
c1,c2>0, a,b>0, a*b<1,
```

则 f1<=c1+a*q2，故

```text
q1=beta1*f1 <= c1*beta1+a*beta1*q2
                         <= c1*beta1+a*q2.
```

另一行同理。证明同时包括两个原零点标签。界须覆盖整个当前抽象父域，不能仅
在原网络样本上成立。可先合并共享源系数，再用可靠盒支持认证差分；把两门各自
区间独立相减往往使新行冗余，不声称那样也有增益。

Affine、Conv、同源 Add/Concat 保持共同幅值身份和全部已有谓词；下一 ReLU
仍对整个当前父域作健全变换。这些行可被下一层直接消费，如下例所示。
它不是一个独立反馈支持器，不读取 LP 状态，不进行 backward/dual rescue。
多块相交仍健全，但本页不声称整网线性外包理想。

若 c_i 是源函数而不是常数，则 c_i*beta_i 不再是免费线性项。不能把点值 c_i
代入常数定理后当全域证明。本页只选择常数合同；保守常数化的精度代价必须实测。
零耦合、零 cap 或接近 ab=1 的专门数值处理不是本轮研究目标。

## 完整后继的严格正控制

对 x,y in [-1,1]，取 D138 已有的普通非平行有偏置两门：

```text
f1=x+y/10+1/4,       q1=ReLU(f1),
f2=x/2+y/10+1/4,     q2=ReLU(f2).
```

源差分给 a=1、b=1/2、c1=1/2、c2=7/40。U1=27/20、U2=17/20，
恰与各门源盒上界一致；下界为 L1=-17/20、L2=-7/20。
新行 q1<=beta1/2+q2，与原行 q1<=f1+(17/20)(1-beta1) 合并，得到

```text
J=(27/20)*q1-(17/20)*q2-f1/2 <= 17/40.
s=ReLU(J-9/20) = 0.                              (B)
```

这是全源盒结论，后继输入上界为 -1/40，不是固定源/固定相位结论。
混权 q1,q2 与活源 f1 同时保留，不分别支付独立最坏界。

强参照保留完整 source-labelled 单门凸包、同一 x,y、两原 bits、两条旧 plain
feedback，以及后继的精确图。它仍允许

```text
x=y=0, q=(13/20,1/4), beta=(1/2,1).
```

第一门的单门图见证是源 (24/25,9/10) 与 (-24/25,-9/10) 各半；两源均严格
在盒内，f1 分别为 13/10、-4/5，故 q1 均值 13/20、beta1 均值 1/2。
第二门采用源 (0,0) 的真实值 q2=1/4、beta2=1。两门显示源均值完全相同。
旧 feedback 也成立：13/20<=1/2+1/4，1/4<=7/40+(13/20)/2。
但 J=27/50，因此精确后继允许 s=9/100>0。

这是一项严格的局部查询/后继分离，不是实际网络反例或新增 CERT。
完整双门联合 hull 或加入同样两条 phase-scaled 行的旧 HZ 当然也能证明 (B)。
这种强参照不能省略；“两个已知行”本身还不足以证明新域创新。

## 不能从局部理想性推出全图理想性

三点普通无环关系已经反驳直接推广。设

```text
P={e>=0: e2<=1, e3<=1, e1<=1+e2+e3},
U=(3,1,1).
```

自然扩展 e_i<=U_i*beta_i、e1<=beta1+e2+e3，接受
beta=(1/2,9/10,1/10)、e=(7/5,17/20,2/25)。全部显示量严格为正且未取上界。
但所有合法整数成员满足 e1<=2*beta1+e3：beta1=0 时 e1=0；beta1=1 时使用
e2<=1。显示点左边 7/5，右边 27/25，违反该有效行。

因此一般 DAG 即使无环也需要额外共同容量信息。此例不否定逐块健全 strengthening，
但禁止将双神经元原语宣称为任意 CNN 的精确闭包或用它删除其他源关系。

## 完整局部费用与真实规模缺口

前述两个父门加后继，连续坐标为 x,y,q1,q2,s，三原 bits 不变。若内联 f1、f2
且后继共用安全范围 [-2,2]，排除两臂共同的源箱和 bit 端点行：

| 部分 | 旧关系 | 新关系 |
| --- | --- | --- |
| 两父门原四行图 | 8 LE 和 20 nnz | 相同 |
| 两条反馈关系 | 2 LE 和 4 nnz | 2 LE 和 6 nnz |
| 后继原四行图 | 4 LE 和 14 nnz | 相同 |
| 合计 | 14 LE 和 38 nnz | 14 LE 和 40 nnz |

这张费用表计实际四行单门编码，不是上节完整 source-labelled 单门 hull 的显式
表述价格。后者用于更强的精度反控，不能把它的全部 facets 假算成每门四行。

完整共同读出可取 (q1-q2, q2-q1/2, x, y, s)，共 7 个读出 nnz；原输入 decoder
仅选择 x,y，为 2 nnz，两者不能混称。省略的共同源箱有 4 行，三 bit 端点有 6 行。
在这些 physical 坐标上没有新列；转成实际 HZ 因子时仍需计全部别名/系数展开。

对一个已选 pair，认证两个同源差分及生成行是源支持规模的线性工作；寻找 pairs、
规范化、原模型/BN 参数绑定、可靠浮点证书、历史谓词、终端矩阵、输入重构、
host/device 共存、证据和查询本身都另计。不能由两行常数规模宣称端到端加速。
差分合并与行生成适合 GPU 批处理，但没有 GPU 实现或终端速度资格。

原 D067 的完整旧 global-even pairing 已证明在其 CIFAR large 来源人口中没有
双未定 pair。本轮只读其结果，没有重算或改变配对；不能复用该失败人口宣称新原语
已适用，也不能只挑两个未知门来做阳性展示。任何新配对策略必须统一依赖数学
结构，先冻结完整来源人口与费用，不能按实例、标签或终端状态挑选。

## 与已有理论的区别和下一行动

一般 on/off 凸包与 perspective 是既有机制。[Hijazi 等第 2 节 Lemma 1 与
Theorem 2](https://optimization-online.org/wp-content/uploads/2009/10/2442.pdf)
给出单个 on/off 集合的扩展凸包和坐标单调情形下的投影；后一表述包含全部子集行。
它并不宣称多个局部 hull 相交后自动成为完整联合 hull。
本轮的六行结论有单独的共同顶点证明，但尚未完成其外部新颖性检索。

本项目 D027/D052 已有相位加权关系机制，D138 已有常数反馈块。
因此本轮新增项目证据是这个特定共同块的精确 labelled hull、无辅助量消元、
强单门参照下的完整后继分离和明确费用，而不是首次发现 indicator 不等式。

下一项研究选中这个正向共同生成关系，暂不实现独立反馈支持器、循环 QC 或更多
球外包。需先解决真实全接口上的统一 pair 生成与源资格，比较原 HZ、同信息显式
关系参照和原生块的完整代价；再判断它能否组成有实质优势的 Neural-HZ 算子。
不要求有损域战胜精确原网络图，但必须证明其实际可消费的信息与可付成本。

本页不是运行预注册，也未启动候选。任何后续数值工作仍须独立 prereg/freeze，
保留最后已通过的 D180 完整 4056 tests/213 files 人口和适用的既有资源门，
再按真实结构、shadow、逐家族及全 2413/独立 400 流程晋级。
