# 共同谓词余量作为跨层关系的研究假设

本页是两层闭包反例之后的纸面假设，不是实现、预注册执行或新颖性结论。目标是让 Neural HZ 后续算子能复用自己已证明的关系。不能只把旧 HZ 加一份证书字典就宣布新域；此假设还必须通过原生组合、精度和完整成本比较。

## 从自由盒 deficit 到共同谓词余量

当前 D205 规则从共享源盒的 1-xi、1+xi 提取非负余量。对经过 ReLU 的父域，这个盒可能忽略已经由相位和旧谓词保证的关系。本轮反例正好展示了这种损失。

设 S 是完整的、不可变的 owned 父元素。保留原连续变量、原 signed bits、全部 EQ/LE、共同身份、消费者和 decoder。令 theta_j 是在 S 上已认证非负的仿射余量，例如原盒端点余量、原 ReLU 图行的 RHS-LHS 或更早出生的有效关系行余量。所有消费者必须引用同一个 theta_j 身份；不能将其复制成独立的任意非负数。

假设固定的域内演算已经对两条差分 r_i 给出有限正 cap c_i>0，并保留证书

```text
c_i-r_i = sum_j lambda_ij*theta_j + sum_k nu_ik*e_k,
lambda_ij>=0, theta_j>=0 on S, e_k=0 on S.
```

e_k 是原有 producer EQ 或其他已认证等式残差；nu 可正可负。等式部分不能被遗漏，也不能假定所有 alias 回代都自动化为非负 LE 组合。证书来源仅限预先固定的域内代数传播；不调用 LP dual、不可行证书、失败后 rescue 或系数优化搜索。

按共同 theta 身份定义

```text
mu_j=min(lambda_1j/c1,lambda_2j/c2),
t0=sum_j mu_j*theta_j.
```

若同一个先于新关系的父域已认证 0<=t0<=B<infinity，则 B>0 时取 tau=min(1,1/(2B))；B=0 时取 tau=1。再令

```text
s=1-tau*t0, l=1-tau*B.
```

由逐项系数比较，c_i-r_i>=c_i*t0。在 tau<=1 下得到 r_i<=c_i*s，且 1/2<=l<=s<=1。B=0 时父域上 t0=0，s=l=1，没有除零或额外精度。这允许 c 来自比自由盒更强的原生证明，而不是把更紧数字错误代入旧盒公式。

## 与原规则及已有原理的关系

若 theta 只是同源盒的端点余量，lambda 是展开后的对应系数，此构造恢复共同 deficit 思路。若 theta 来自非线性历史谓词，新的机会是跨层保留相位信息，但是否真的产生可消费的共同部分尚待证明和实测。

上述不等式属于非负线性组合原理，不能据此宣称新 Farkas 定理、新集合类或已超越 HZ。潜在贡献必须是这种关系表示与统一出生、消费和化简规则的整体，而非证书容器。原二元相位不能被连续松弛后替代整个域。

这里的 mu 也不是语义上的最大共同余量。它依赖所选择的两张证书和 slack 身份；同一余量若有两个未识别的副本，而两证书各用一个副本，交集会假性为零。不能继承 D205 特定自由盒合同下的点态最大性。精确 producer EQ、正比例归一化和共同身份如何构成稳定的本原表示，是需要检验的问题，不是已解决的 canonical form。

## 非正 cap 与本轮反例

当前反例对 g1-g2/2 的原生 cap 为 -1/4，不满足上述 c_i>0。不能说新尺度公式已经修复它。

对非正 cap，已有统一单调性关系 q_i<=a*q_j+max(0,c) 给出精确的顺序后果；它同样需进入同一候选的原生查询，而不能只在反例末端外挂补证。若下一候选采用它，应对全部预先结构配对统一处理，不只补第二个有利 pair，也不按性质、实例或终端结果选择。

这条已知顺序闭包和正 cap 的共同余量构造是否能形成一个费用可承受的统一域，是待证命题。任何实现仍须新目录、新 prereg/freeze、完整既有数学人口及原晋级流程。

## 完整费用与可反证条件

必须支付两张 lambda/nu 证书、共享证据 DAG、等式回代、t0 的真实稀疏展开、B 查询、比例位数、所有新行、旧谓词和全部读出/decoder。B 查询只能在新关系生成之前完成，不得循环使用待证行。

在已有规范证书向量上，系数交集本身是支持并集规模的线性运算；这不包括获得证书、跨层传播或终端转换。证书支持可能随深度填满，B 也可能很松。GPU 可以批量处理交集和稀疏归约只是实现方向，未提供可靠 device arithmetic 或性能证据。

若普通异质多层结构下证书展开比旧图更贵，或共同余量始终为零，或相同信息的旧 HZ 用更少费用取得同样查询，则应记录失败并改变定义假设，不继续堆叠框架。下一正控必须包含混权、活残差及跨层消费，随后才是真实结构；不能再次只重复单对神经元。

## 保留的普通算术风险

另有一个未执行但可解析验证的支撑风险，不作为本轮研究中心。D207 的 200 门控制重复同一 pair，不能代表异质 pair 的 Fraction 规模。

取 100 个不同素数 p_i>100、n_i=floor(7p_i/10)，共享 x,y 属于 [-1,1]，定义

```text
a_i=(15n_i-9p_i)/(4(p_i-n_i)),
f1=x+1/4, f2_i=a_i*y+1/4.
```

有 1<a_i<=5/4，每对均非平行且有偏置。该固定 pair 的共同尺度为 1，方向 (1,-2) 的反馈证书为 (n_i/p_i)*(x+1)。跨 100 对合并同一个 x 后，系数分母约分仍为各 p_i 的乘积：模任一 p_i，其余项均消失而 n_i 与其余素数乘积非零。因此分母超过 2^600，超过当前 512-bit 限制。

这是普通异质系数组合可出现的全局分母增长，不是对真实 Tiny/CIFAR 已触发的断言。可靠定向舍入可以研究为支撑算术，但不能悄悄提高旧上限、漏掉误差或跳过失败证书，更不能把算术修复记作定义创新。当前纸面假设没有给出新算术实现或 GPU 资格。
