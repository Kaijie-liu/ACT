# 联合容量的终端费用与强参照

联合幅值容量给出精确的局部查询对象，但短公式没有自动减少最终线性系统。本轮因此不将它晋级为数值候选，也不建立新的 helper 框架。

## 明确的线性化账

采用 THEORY.md 的全部 N=2^k 个 lambda 和 dN 个共同源量 z_s，不消去任何质量单元。对每个 (i,s) 引入一个连续 epigraph e_i,s：active 时

```text
e_i,s>=0,
e_i,s>=L_i*lambda_s+H_i,s,
U_i*lambda_s+H_i,s>=0;
```

inactive 时使用 -U_i*lambda_s-H_i,s 的下界和 -L_i*lambda_s-H_i,s>=0。再以这些 e 的组和作 (C) 的两个下界，上界保持原容量和。这是精确的存在量化线性化，因为 e 可取对应正部的实际值。

| 项目 | 新连续量 | LE | EQ |
| --- | ---: | ---: | ---: |
| lambda 及原 bit 边缘 | N | N | k+1 |
| 共同 z_s 及其总和 | dN | 2dN | d |
| 正部 epigraph 及单元 guards | kN | 3kN | 0 |
| 两组幅值总量上下界 | 0 | 4k | 0 |
| 合计 | (d+k+1)N | (2d+3k+1)N+4k | d+k+1 |

这里 q、p、z 和全部原 beta 是两边共有的物理接口；n=q-G 和 H 都内联。未把输出、原源或原 bit 删除来支付辅助量。

以 D194 的四门结构计，d=27、k=4、N=16，得到 512 个新连续量、1088 LE、32 EQ。它只适用于 27 个共同源加四个私有标量的投影接口；全局 3072 个原输入、75 个真实原像坐标及全部其他消费者继续存在。

公平参照是同一投影接口的直接 perspective：用 kN 个 private 条件量 p_i,s 替换上述 kN 个 epigraph，保留 private 两侧界及相应 guard，并汇总 p 和 q。它同样有 512 个新连续量，只需 1072 LE、40 EQ。因此新写法实际是用 16 LE 替换 8 EQ，未减少辅助变量，未证明更快。不能拿全原像素的更强 joint hull 来作不公平的费用比较。

## 系数与未计成本

设每个 a_i 有 t_i 个声明共享源系数，H 内联，未进行跨行消项。一个保守 nnz 账为

```text
共同源盒行:              4dN
lambda 非负行:          N
全部 EQ:                d(N+1)+N+k(N/2+1)
单元 guard 和 epigraph: N*sum_i(2t_i+4)
四个聚合行:             sum_i[6+2t_i+N(t_i+2)].
```

四个聚合行逐门的 nnz 上界分别是 1+N/2、1+(N/2)(t_i+1)、2+t_i+N/2、2+t_i+(N/2)(t_i+1)。这避免把包含正部之和的一条纸面关系误记为一条廉价 LP 行。

本 patch 每门至多使用 15 个共同坐标；代入 t_i=15 得 5663 nnz。若真正将全部共同源规范到 [0,1] 并同步重写读出与身份，共同源下界行可减少 dN=432 项，得 5231；不能直接在未规范化原源上删掉 lambda 系数。

这只是声明前缀的符号上界，不是实际物理共存或速度。原输入盒、私有原像绑定、其他通道与消费者、历史谓词、BN、认证界、源展开、输入 decoder、证明记录、LE 到 EQ 的 slack、终端及 CPU/GPU 搬运都另计。仅此前缀已有 1120 条 EQ/LE，超过 [D180 小组件](../d180_reference_observed_component_20261004/CONTRACT.md) 的 512 谓词门；没有提高门槛或用局部别名绕过原全局源人口。

## 两条旁路假设的排重结论

第一条是把 affine circuit 加权到共同载体。若 g=Wz+b、Cg=d 由父 EQ 的可靠线性组合证明，且某相位权 rho 已有同一个 Lambda=E rho、Z=E(rho*z)、G=WZ+bLambda，并保留父 EQ 的同权副本，则

```text
C G=d Lambda
```

已被蕴含。只添加这些 circuit 加权等式不改变完整物理投影，采用同一后继变换也不会得到新精度；删掉完整源连接、只保留 circuits 则只能放宽。这个结论不覆盖幅值不等式、整性容量或新的联合守卫，不能扩大成“circuits 无用”。D007/D009 已研究前两类；D142 已有保物理谓词的有损替换合同，均不重报为本轮创新。

第二条是严格负旁路下的单父链：q=ReLU(g)、r=ReLU(aq+v)，若 a>0 且整个父域 v<=-delta<0，则 r=ReLU(ag+v)，原 child bit gamma 满足 gamma<=alpha、gamma*alpha=gamma。两门仍可 crossing，v 也可含活旁路；但这是旧正阈值链和 max/min 恒等式的特化，不是新域。仅 v<=0 时不能不加检查地复用同一 child 标签：g<0、v=0 的原 child 零点允许 gamma=1，而扁平后的负预激活不允许。未从真实 patch 的 crossing 计数推断这种强条件成立。

这些排重决定本轮不实现额外 circuit 等式、链规则或全相位容量 helper。下一值得实现的定义必须减少或健全近似共同条件源载体，同时保留已经取得的物理行，并能用完整可付代价产生后继所需的新联合关系。仅保存旧行、给公式改名或隐藏 terminal 费用，都不足以构成创新。
