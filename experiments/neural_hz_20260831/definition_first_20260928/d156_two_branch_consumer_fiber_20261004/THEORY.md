# 保留共同源投影的双分支 Neural HZ 候选

本轮提出一个有损的域定义候选：在一个完整神经消费者接口上，用少量联合幅度替代逐门幅度，同时让激活部分与未激活部分共享同一个源投影。它不是在完整旧门图上附加 helper。本文证明健全的块变换、精确情形、可递归的预算、有限线性消费及其损失边界。

候选尚未实现。16 门到 2 个联合幅度的纸面正控保留了已有共同能量关系，并可证明下一门恒零；普通两门反例同时说明它没有保全原 HZ 的精度。没有真实网络、速度、GPU 或正式新增解。这里的 matrix perspective 和 parallel sum 均是已知数学，不能把它们称作新理论。

## 域元素与完整消费者

一个元素保留原连续源 xi、原二元相位 beta、共享 frame 和因子身份、既有 EQ/LE 谓词 P、原输入 decoder，以及下面定义的共同幅度块 a_k。读出是所有这些保留坐标的仿射式。各幅度块带双分支能量谓词；所有谓词同时成立，不是选择菜单。

具体化是同一个满足全部谓词的赋值所产生的输入与活读出集合；不同消费者不能独立选择见证。语义精度顺序为这些集合的包含，不声称存在廉价的最佳抽象或完整格。源 xi 标准化到 [-1,1]；非标准盒通过保持身份的仿射归一化处理并计费。

原 HZ 以零个新幅度块精确嵌入。signed bit sigma 与本文 0/1 记法之间使用 beta=(sigma+1)/2 的双射，不删除、pivot 或连续化任何实际二元语义。固定相位切片可以是凸的，整个域仍保留离散相位的非凸并。它不是把整个状态替换为 CZ、zonotope 或一个连续椭球。m=p=1 时下面的原生关系已经能精确表达 ReLU 图，故也不是只有无效标签的凸输出盒。

在当前完整父状态上，令 g 是原预激活，q=ReLU(g)，可靠界为 L<=g<=U。C 是本块选择的消费者载体矩阵。所有继续使用 q 的实际读出必须能写成 Cq 的仿射组合；旧谓词、skip 和 decoder 对 q 的使用也必须计入。可以使用明确计费的结构性辅助读出作为载体，不能只保一个有利性质方向而遗漏其他消费者。本文没有删除任何旧父状态坐标，只替换这次新生 q 的幅度。

完整 packet 中的输入旁路 h 保持同一源身份。写

```text
y = h + C q
gbar 为本块固定的结构参考，不要求可达
d = g-gbar,       s = C d
a = y-h-C diag(beta) gbar
T(beta) = C diag(beta) C^T
U(beta) = C diag(1-beta) C^T.
```

一般实际消费者可再对 y 作固定线性变换。C 的行数 p 是新幅度数，不一定小于 m；identity q skip 会迫使完整 packet 保留足够的秩，不能在这种情况下承诺压缩。原源 decoder 不依赖被替换的新幅度，抽象可行点仍只能通过原输入在原具体网络上验证 ADV。

选对整个当前父域有效的相位仿射预算 E>=||d||2^2，E 非负。双分支谓词为

```text
a in range(T),       s-a in range(U)
a^T T^dagger a + (s-a)^T U^dagger(s-a) <= E.        (1)
```

伪逆与 range 是数学语义，不授权在线 QP、SOCP、SDP 或新的解码优化器。保留每个原门的 guards：crossing 情形为 L_i(1-beta_i)<=g_i<=U_i beta_i。稳定和零界也必须按原合法相位语义处理；尤其 g_i=0 的两个原标签不能被任意固定。

任何完整消费者、共享身份、预算、参数误差、可靠舍入或输入重构前提未认证，以及数值或资源失败，均须 fail closed；不得把失败或不完整分析计成 CERT/ADV，不接入其他算法补救。新增候选保持默认关闭。

## 健全性与准确的近似边界

对每个真实父状态和其原相位，取

```text
u=diag(beta)d,       v=diag(1-beta)d.
```

它们支撑不交，Cu=a、Cv=s-a，且 ||u||2^2+||v||2^2=||d||2^2<=E。固定支撑上的最小范数提升给出式 1，因此新状态包含父域的完整真实 ReLU 像，两个零标签均成立。

对整数 beta，式 1 等价于存在一份共同代理偏差

```text
dhat in d+ker(C),       ||dhat||2^2<=E,
a=C diag(beta) dhat.                                      (2)
```

证明的反向取两个最小范数提升并相加；正向取 dhat 的两个互补支撑。这是一份所有 packet 消费者共用的 dhat，不是每个输出独立选幅度。

式 2 也准确暴露损失：原源仍在状态中，但 dhat 可以在 ker(C) 内偏离 d。因此它不是保留逐坐标 u+v=d 的 centered perspective 的精确投影，甚至 E=||d||2^2 也不保证恢复这条等式。不能把共同源投影 Cd 偷换成完整共同源。

实际有限候选还加入下文的有证幅度行；这些行对真实图有效，却未必由裸式 1 蕴含。加强后的域是明确的交，不在比较时隐去这项差别。

## 精确情形和误差方向

固定一个整数 beta 和源赋值，真实 a_star=C diag(beta)d。两个 range 条件蕴含

```text
a-a_star in range(C_active) intersect range(C_inactive).
```

反过来，交空间中的任意偏移都保持两个 range 条件，但还要满足能量及其他谓词。因此这里描述的是可能误差的线性空间，不是宣称其中所有点都能通过预算。

若两子空间的交为零，则 s=a+(s-a) 的分解唯一，a=a_star。全 active、全 inactive 是其中两种情形；这不需要 g 在整个父域上稳定，也不按相位枚举另开路径。一般混合相位不满足该条件。

当 Q=T+U=CC^T 正定时，令

```text
c=T Q^-1 s,       K=T-T Q^-1 T.
```

两个 range 条件等价于 a-c in range(K)，并有

```text
a^T T^dagger a+(s-a)^T U^dagger(s-a)
 = s^T Q^-1 s+(a-c)^T K^dagger(a-c).                       (3)
rank(K)=rank(T)+rank(U)-p.
```

一种直接证明是令 R=Q^-1/2 T Q^-1/2。R 对称且 0<=R<=I；在它的正交特征基上，式 3 化成标量完成平方。特征值 0 或 1 正好给相应 range 限制。K 是已有的 parallel sum；其 range 为两个分支 range 的交。若 C 非满行秩，先把数学陈述限制到其已认证行空间；不要在实现中用未经认证的数值秩假设。

两侧都满行秩时 rank(K)=p，可能的输出误差方向并未减少。该指标说明候选何处容易失真，不是免费相位检测或按身份选择的运行规则。

## 与旧范数关系的比较范围

相同父状态、C、参考和 E 下，保留完整逐坐标 u+v=d 的 centered individual perspective 的投影包含于式 1。对 beta in [0,1]，以闭包意义处理零分母，广义 Cauchy 又给

```text
(2a-s)^T (CC^T)^dagger(2a-s)
 <= a^T T^dagger a+(s-a)^T U^dagger(s-a).                    (4)
```

所以裸式 1 包含于 D148 反射球本身的精确 C 像。不能据此说它包含于 D148 加全部逐门 epigraph、mask 等约束后的投影；被删 q 的那些条件尚未全部投影。不同有限线性 lowering 也不自动继承式 4 的原生包含关系。

精确 HZ 本来就能表达真实图。本候选的机会是用更小的非线性接口承载有用的联合精度，不是集合精度超过精确图。它与强参照的整网代价及真实能力仍待实验。

## 有限线性消费和端点相位

固定有理向量 lambda、mu，两个配平方分别给出

```text
2(lambda-mu)^T a+2 mu^T s
 <= E+lambda^T T lambda+mu^T U mu.                         (5)
```

右侧为原相位的仿射式，因为

```text
lambda^T T lambda=sum_i beta_i (c_i^T lambda)^2,
mu^T U mu=sum_i (1-beta_i) (c_i^T mu)^2.
```

c_i 是 C 的第 i 列。式 5 可直接由原 LP/MILP 消费，无需在线优化 lambda、mu，无需求伪逆。方向和尺度必须事先按数学结构固定，不在失败后从对偶、margin 或 LP 状态选择。有限行只定义外包，不等于式 1；特别是有限尺度不能一般恢复零特征方向的 range 条件。

另外，对每个固定 v，令 A_i^-、A_i^+ 是 (v^T c_i)d_i 在 active 支持上的可靠下上界，I_i^-、I_i^+ 是 inactive 支持上的可靠界。安装

```text
sum_i beta_i A_i^- <= v^T a <= sum_i beta_i A_i^+
sum_i (1-beta_i) I_i^- <= v^T(s-a) <= sum_i(1-beta_i) I_i^+.
                                                               (6)
```

这些是四条真实图有效线性行。可以使用全父域 d_i 界，也可以使用原 sign guard 与该界的交：crossing 时 active 的 g_i 在 [0,U_i]，inactive 在 [L_i,0]。乘以固定系数时正确交换上下界。不可把这些标量必要条件说成共同 dhat 的完整可行性。

取 p 个坐标方向，共 4p 行。全 active 时第二对行强制 s-a=0；全 inactive 时第一对强制 a=0。故这两种原生精确情形在该有限终端中确实保留。一般混合相位的全部 range 条件不因此免费获得。

## 可递归的前向变换

Affine、Conv、Add、Concat 对共享坐标的仿射读出精确作用；Add 必须先按身份合并系数，不能给 skip 重新采样。旧幅度块及其谓词仍保留，不能未经证明丢掉它们。

设某个后继预激活的偏差可写为

```text
d_new=D xi+sum_j v_j(beta_j-tau_j)+sum_k M_k a_k,
```

tau in {0,1} 为在查询前固定的原相位参考。对每个旧块，式 2 给出

```text
||M_k a_k||2^2 <= ||M_k C_k||2^2 E_k.
```

这里右侧第二个范数是矩阵谱范数平方，可由固定、可靠的 Frobenius 或其他证书上界替代，不调用支持求解 oracle。设 K0>=sup_box ||D xi||2^2，Kj>=||v_j||2^2，Kk>=||M_k C_k||2^2。对上述非零项预先选正权 w，权重和为 1，则加权 Cauchy 给

```text
E_new=K0/w0
      +sum_j (Kj/wj)|beta_j-tau_j|
      +sum_k (Kk/wk)E_k.                                   (7)
```

忽略不存在的零项并相应定义权重；所有项为零时取 E_new=0。beta 与 tau 均二元，所以 (beta_j-tau_j)^2=|beta_j-tau_j|，且绝对相位差为仿射式，因此 E_new 仍相位仿射、非负。对标准化 xi in [-1,1]，源盒项可用 sum_i(sum_j |D_ij|)^2 认证，虽可能很松。固定均分权重也是合法规则，不声称它有实用精度。

式 7 对整个当前扩大后的父域成立，所以新原 ReLU 块可再次按式 1 和式 6 构造。不能只对原具体网络的窄集合求界，再拿来传播已经放宽的父域。终端有限多面体通常大于原生域；数学递推保持原生语义，不能把该多面体冒充原能量谓词。

这是闭包存在性与可计算的有损预算，不是固定宽度、精度不衰减或低成本定理。旧块、旧相位、源系数和预算系数仍可能逐层增长或填充。平滑激活、Softmax、LayerNorm 及整个 Transformer 尚无本候选资格。

## 两个幅度保留十六门联合证书的正控

沿用已归档的 [D148 控制](../d148_phase_centered_norm_fiber_20261004/CONTROL.md)，避免把旧能量关系重新认作新发明。令 n=16，

```text
A=I-11^T/8,       A^T A=I,
x in [-1,1]^16,   g=Ax-(1/2)1,
gbar=-(1/2)1,     E=16,
L=-13/4,          U=9/4.
```

全部首层门 crossing、非平行且有非零偏置。取载体 C=[1^T;e_16^T]，只保留 Qout=sum_i q_i 与 t=q_16 两个幅度。全部实际后继读出是

```text
Xsum=sum_j x_j,   N=sum_i beta_i,
J=Qout-(5/4)t+(9/22)Xsum,
z=ReLU(J-33/5).
```

这里 t 必须计入，不能只保 Qout 后假装混权消费者仍完整。载体的 Qout 是结构性聚合坐标，不是额外验证器。所有原输入、原 16 bits 和 guards 保留。

有

```text
T=[[N,beta_16],[beta_16,beta_16]],
CC^T=[[16,1],[1,1]],
a=(Qout+N/2,t+beta_16/2),
s=(-Xsum,x_16-Xsum/8).
```

固定 lambda=(1,0)、mu=(-1,0) 的式 5 给

```text
2Qout+N+Xsum<=16.
```

坐标版式 6 含 Qout<=(9/4)N 和 t>=0，因而

```text
J<=Qout+(9/22)Xsum<=72/11<33/5.
```

原终端线性行已足以证明 z 恒零。普通逐门四行 LP 则允许 x=0、beta_i=1/2、q_i=9/20，给 J=531/80、z=3/80。该点不是具体 ADV。新 packet 在同物理输出上也无相位延拓：Qout=36/5 要求 N>=16/5，而能量行要求 N<=8/5。

这是全盒纸面能力分离，不是运行过的 CERT。有效行已存在于 D148/centered perspective；本轮新增的是用两个共享幅度承载它及上面的域语义。正交矩阵仅提供可手核的预算，不是实际 CNN 适用性证据；严格性质间隙使充分小参数扰动有保持空间，但本轮没有扰动实验或真实权重统计。

## 普通混合相位仍有源绑定损失

取 x in [-1,1]^2，

```text
A=[[1,1/4],[-1/3,1]],   g=Ax+b,
b=gbar=(1/4,-1/4),     C=(1,-1).
```

在严格内部源 x=(0,-1/4)，g=(3/16,-1/2)，原 beta=(1,0)，

```text
d=(-1/16,-1/4),  s=3/16,  T=U=1,
a_true=-1/16,   a_fake=1/16.
```

即使额外授予此源点上的精确预算 E=17/256，假点能量也只有 5/256。真实全父域预算只会更大；此处没有把一个点的预算错误地用作整盒证书。假点对应 q=(5/16,0)，通过原 guards、epigraph、mask，以及由全界或 guard 细化所得的坐标式 6；原精确四行却要求 q1=3/16。

加同源 live skip x1/5-x2/7，真实 y=25/112，假 y=39/112。后继 ReLU(y-1/4) 在这个同输入上真实为零，假状态却允许 11/112。这不是整盒性质回退证明，而是原生域在普通内部混合相位上的严格不精确性。

这个反例不否决一切健全近似域，也不新增“必须包含旧 LP”的硬门；它阻止宣称已保旧或无损。真正晋级仍要按原预算完整回放保住全部 1870 并获得新解。

## 完整成本与下一项决定

必须保存 C、全部原源映射、m 个原 bits、2m guards、新 p 个幅度、旧块、能量证书、幅度界及输入 decoder。若逐相位系数物化 Gram，通常需 O(mp^2)；以 C 因子保存可以避免这一存储，但不能把伪逆、range 或 Gram 查询当免费。

固定 k 对 lambda、mu 可不物化 Gram，每对需计算 C^T lambda、C^T mu 及原源 s 的系数，约 O(nnz(C)) 的算术外加源展开、相位系数、可靠舍入和写出。4p 坐标幅度行也有相应的 C 扫描与相位系数费用。源 s 可以内联或物理化：后者另外增加 p 个连续量及 p 条定义，前者可能填充。不能只报 p 个逻辑幅度而省掉这笔账。

在上面的 16 门正控，采用源 x 物理坐标、Qout/t 两个幅度、s/a 内联，原 guards 为 32 行/544 个变量系数非零项。八条 guard 细化的坐标式 6 为 8 行/106 nnz，一条式 5 为 1 行/33 nnz，共 41 行/683 nnz。普通四行参照是 64 行/608 nnz；若另加同一能量行则 65 行/656 nnz。这是本块的明确口径，未计共同源 bounds、下游读出、RHS、证据、位长和峰值存储。因此有幅度与行数下降，但没有总 nnz 下降，更没有实测加速。

式 7 的历史块和相位项会继续增多；dense mixing 可能消灭收益。GPU 潜力在固定稀疏乘法、列内积平方和归约，不等于已经 GPU 化，向外误差、数据搬运和终端费用都未测。

下一步应先冻结有限方向与载体的统一选择规则，检验在普通完整 packet 上是否仍有精度与完整代价优势。不能先套实际网络、再按结果调方向。只有这个定义和执行规则足够明确，才进入新默认关闭组件及保留 4000 项/210 文件的完整数学测试；之后仍是实际同结构、shadow、逐家族和完整回放。本轮不以纸面正控跳过任何一级。

## 已有数学和本轮证据等级

[Won 的 Matrix Perspective 论文](https://papers.neurips.cc/paper_files/paper/2020/file/45f31d16b1058d586fc3be7207b58053-Paper.pdf) 第 1 页已经定义伪逆加 range 的闭 matrix perspective，并给出仿射函数上确界表示。本文式 1 和式 5 使用这一已有原理，不采用该论文的 proximity 算法。Indicator perspective 的背景亦见 [Günlük 与 Linderoth](https://jlinderoth.github.io/papers/Gunluk-Linderoth-09-TR.pdf) 第 3 至 4 节；有限平面与完整非线性关系的区别不能忽略。

[Anderson 与 Duffin 的原论文摘要](https://www.sciencedirect.com/science/article/pii/0022247X69902005) 已给出 parallel sum 及其 range 交集性质；式 3 同时在本文直接证明，不把该旧恒等式算作创新。外部来源没有替本候选证明神经闭包、预算实用性、真实网络优势或 PLDI 新颖性。

本轮明确的新研究对象是保原相位与完整 packet 的有损替换，以及共同源商纤维的精确性/失真刻画。其新颖性尚未成立。证明由主代理和独立代理纸面复核，非机器证明、非数值测试。
