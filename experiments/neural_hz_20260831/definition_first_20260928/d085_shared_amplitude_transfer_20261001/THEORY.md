# 共享条件幅值的前向变换与精确商化条件

本轮将跨领域操作合同落实为可构造的关系变换，得到三项纸面结果：两个父门的共同幅值可生成统一 ReLU 上行；任意异号两父读出的该上行只消费一个幅值和；要跨越下一混权块，则需保留可共同消费的条件输出，而不能只保存各门的独立上界。真实宽卷积的只读核查表明，其余输入不能自动折叠为原输入上的仿射残余，因此不将两输入结论冒充 CIFAR100 或 TinyImageNet 的适用性。

这些结果使用已知 RLT、透视包络和线性投影，不宣称完成新抽象域或 PLDI 新颖性。新的项目证据是明确的前向公式、异号消费结构的商化与完整计数、同号负控，以及宽层接入所需的关系。当前没有候选实现或数值资格。

## 原非凸语义与关系元素

沿用[共同见证合同](../d078_shared_witness_contract_20261001/DEFINITION_AND_BOUNDARIES.md)，元素保留原 HZ 的连续因子、全部原二元因子、EQ/LE、原门守卫、共享 frame 及 decoder。附加一个有限观察集合，每个观察绑定同一个原赋值的确切读出，而非为每个消费者各建一个自由源。

选两个原父门，经已有可靠正上界归一化为 u、v，其原 active bits 为 alpha、beta，满足

```text
0 <= u <= alpha, 0 <= v <= beta.
```

这是原门的0/1标签视图，不删除或固定生产中的原二元列。零输出时所有原合法标签仍保留；没有有限正上界时不能使用本归一化。新增 delta、zu、zv 的整数含义分别为 alpha*beta、beta*u、alpha*v，编码为

```text
0 <= delta, delta <= alpha, delta <= beta,
delta >= alpha + beta - 1;
0 <= zu <= delta, 0 <= u - zu <= alpha - delta;
0 <= zv <= delta, 0 <= v - zv <= beta - delta.
```

原 bits 为整数时，这些量唯一等于指明的乘积；每个原状态都可扩展，投影精确恢复原 HZ。所有原谓词保持，decoder 继续重构同一原输入。放松 bits 仅用于比较查询外包，不改变具体化的非凸定义。

定义四个代数质量及幅值：

```text
pi00=1-alpha-beta+delta, pi10=alpha-delta,
pi01=beta-delta, pi11=delta;
u10=u-zu, u11=zu, u00=u01=0;
v01=v-zv, v11=zv, v00=v10=0.
```

四槽是对两个已有 bits 的固定代数编码，全部行进入同一个原混合系统；不创建分裂子问题，不枚举求解相位，不调用LP状态或对偶信息。它是 D035 的两相位盒接口在原父输出面上的应用，而非新的乘积原语。

## 统一的两父 ReLU 上行

对原 child q=ReLU(c+a*u+b*v)，保留其原 bit 和全部原图约束。对 s,t in {0,1}，由完整矩形 0<=u<=s、0<=v<=t 得到

```text
L_st = c + min(a,0)*s + min(b,0)*t
U_st = c + max(a,0)*s + max(b,0)*t.
```

每槽用同一规则构造 secant：U<=0 时 k=d=0；L>=0 时 k=1,d=0；L<0<U 时 k=U/(U-L)、d=-k*L。令 e_st=k_st*c+d_st。没有除以零；稳定点区间用前两种规则。

共同上行是

```text
q <= e00 + (e10-e00)*alpha + (e01-e00)*beta
     + (e11-e10-e01+e00)*delta
     + a*k10*u + b*k01*v
     + a*(k11-k10)*zu + b*(k11-k01)*zv.
```

证明是将每槽有效行 ReLU(h)<=k_st*h+d_st 乘以该槽质量，使用同一组槽内幅值相加。在原 bits 整数时只有一个槽有质量，所得行对原 child 精确图有效。对任意真实状态的凸组合也有效；不声称该一条上行是共同图的完整凸包。所有消费者必须共用同一 zu、zv，不能分别重选幅值。

在已有 u,v 和 bits 的物理坐标上，共同源因子需要3个连续辅助量、12 LE、26 nnz；每个 child 上行至多8 nnz。因此 M 个后继共享时是一次源因子加 M 行，不是复制 M 份源因子。归一化、源定义、原容量行、原图、native 展开、slack、证据及重构另计。

### 已知分叉控制上的严格改善

对 r=ReLU(u+v-9/10)、t=ReLU(u-v+1/10)，令 W=zu+zv，上式给出

```text
r <= (u+v)/10 + 9*W/20
t <= 1/10 + 9*delta/20 + u - v/10 - 9*W/20
r+t <= 11*u/10 + 1/10 + 9*delta/20.
```

D078 证明的独立局部凸包可行点取 u=v=1/4、alpha=beta=1/2、delta=1/4、r=1/4、t=11/40。共同上行左侧21/40、右侧39/80，排除间隙为3/80。它在此例上排除了各消费者完整局部见证仍允许的点；不是宣称仅这些上行在所有方向上支配完整局部凸包。

但 D052 的已知联合关系已排除同一控制。该点不是实际网络 ADV，也不能作为超越完整 native HZ 或已有联合方法的新能力证据。不因这个局部正控就启动另一轮小组件测试。

## 异号消费结构的精确标量商

若 a>0、b=-B<0，则对任意 c，secant 斜率满足

```text
a*k10 = ReLU(c+a) - ReLU(c)
B*k01 = ReLU(c) - ReLU(c-B)
(a+B)*k11 = ReLU(c+a) - ReLU(c-B).
```

所以 a*(k11-k10)=-B*(k11-k01)，两个幅值系数相等。交换父门得到另一异号情形。因此异号两父上行总是只通过 W=zu+zv 消费这两个量，不要求权重等幅，也不依赖选定的偏置或实例身份。

如果所有其他消费者同样只经 W 使用 zu、zv，则可精确投影到下列四下界和四上界：

```text
max(0, u-alpha+delta, v-beta+delta,
       u+v-alpha-beta+2*delta)
    <= W <=
min(2*delta, u+delta, v+delta, u+v).
```

反向扩展取

```text
lu=max(0,u-alpha+delta), uv=min(delta,v)
zu=max(lu,W-uv), zv=W-zu.
```

原父容量与 delta 行保证 zu 的原下上界相容，zv 同理；八个 W 行恰保证两个区间的和包含 W。因此该回构同时恢复全部原幅值行和所有 W 消费者。它是已知线性投影的具体神经消费条件，不是改变原输入或删除原 bit。

物理账必须直接比较，不先人为添加一个 W 定义等式再算收益：

| 表示 | 连续辅助量 | LE | 源因子 nnz |
| --- | ---: | ---: | ---: |
| delta、zu、zv | 3 | 12 | 26 |
| delta、W | 2 | 12 | 34 |

每条规范化后含非零系数乘以 zu+zv 的消费行，改成 W 后省1个 nnz。若这种行数为 M，则总 nnz 差为8-M；M>=9才严格下降，少1个连续量，LE数不变。若有任何未纳入的行单独使用 zu 或 zv，该商化条件不成立。这里的 M 是实际非零消费行数量，不是随便数下游神经元；latent 展开和实际规范化后仍需重新计费。

特别是，下节携带到下一 ReLU 的逐槽输出接口一般会分别消费 zu、zv，不能只因汇总上行满足异号条件就擅自应用 W 商。

## 同号负控划清商的范围

取原输入 x,y in [-1,1]、u=ReLU(x)、v=ReLU(y)。两组真实点均按父相位00、10、01、11各占1/4：

| 父相位 | 组A的 x,y | 组B的 x,y |
| --- | --- | --- |
| 00 | -1/2,-1/2 | -1/2,-1/2 |
| 10 | 1/5,-1/2 | 4/5,-1/2 |
| 01 | -1/2,4/5 | -1/2,1/5 |
| 11 | 4/5,1/5 | 1/5,4/5 |

两组都有 Ex=Ey=0、Eu=Ev=1/4、Ealpha=Ebeta=1/2、delta=1/4、W=1/4。但 A 的 zu,zv 为1/5、1/20，B为1/20、1/5。

对普通同号 child q=ReLU(2*u+v-1/2)，A输出为(0,0,3/10,13/10)，均值2/5；B输出为(0,11/10,0,7/10)，均值9/20。两组 child bit 均值都是1/2，但联合相位模式不同。全部原预激活非零，输入在盒内，不靠极端数值。

统一 secant 行是 q<=3*u/2+v/2+zu/6+zv/3，A、B右侧分别11/20和23/40。因此相同 W 既不能确定真实 child 均值，也不能原样恢复这条向量上行。它不证明 W 无法健全外包，不否定另外支付成本的完整联合投影。

审查纠正了一个最初过强的论断：异号 child ReLU(4*u/5-v/5+1/50) 虽然在同两组上均值分别41/200和7/40，但其 secant 行只依赖 W，两组界均43/200。它只能否定精确恢复真实均值，不能用来否定异号上行的 W 商。最终采用上述同号控制，并保留本纠正记录。

## 宽残余及可继续传播的条件输出

真实后继应写成 h_j=c_j+a_j*u+b_j*v+sum_k C_jk*z_k。z_k 是同一原 HZ 赋值的具名残余读出，可以含其他原 ReLU 的输出；除非另证，不称它为原输入的仿射函数。若没有可认证的共同线性因子分解，可以每个残余一个 z_k，必须支付完整数量。这里不假设低秩免费成立。

每个 z_k 保存00、10、01三槽幅值 z_ks，11槽由 z_k 减去前三槽恢复。若原槽内有认证界 l_ks<=z_k<=u_ks，添加

```text
l_ks*pi_s <= z_ks <= u_ks*pi_s   对全部四槽。
```

可保守使用原全局界作为四槽界，不需要解相位限制子问题。整数父 bits 时非活动槽被迫为零、活动槽等于原 z_k，所以这是精确扩展。仅加逐坐标界不保留全部跨残余相关性；有证的共同关系 A*z<=d 可按槽加入 A*z_s<=d*pi_s，原 EQ 同理。不能把这种选择性外包称为整个源图的理想凸包。

每个后继用共同槽值形成 h_js=c_j*pi_s+a_j*u_s+b_j*v_s+sum_k C_jk*z_ks。若要继续供下一层共同消费，只加一条汇总上行不够；还应保存该原输出 q_j 的三槽幅值，第四槽由总和恢复，并在每槽加入

```text
q_js >= 0
q_js >= h_js
q_js <= k_js*h_js + d_js*pi_s.
```

L_js、U_js 必须覆盖真实该槽的预激活，k、d使用同一 secant 规则。为让所声明的槽区间参与后续传播，应从现有槽约束推出这些界；若采用额外认证的更强界，则显式加入 L_js*pi_s<=h_js<=U_js*pi_s 并另计两行费用，不能假装旧矩约束已经蕴含。整数父 bits 时，旧幅值在非活动槽为零，上式迫使新幅值也为零；活动槽的新幅值由原 q_j 的求和身份确定为真实输出，原图使包络成立。由此逐块归纳，每个原真实状态都有共同扩展，保留原 child bits 的所有合法标签。连续查询外包未被证明全局精确。

下一 Affine、Conv、Add、Concat 对共享 q_js 作相同线性组合；下一 ReLU 再用上述合同。若所有槽强行用相同 k、d，汇总上行就变回 q<=k*h+d，共同幅值完全消掉。因此统一的是生成规则，而不是让四槽斜率强行相同。

### 完整的局部费用上界

假设 r 个残余 z_k 都有独立物理坐标，M 个原 child q_j 也已有物理坐标。残余需要3r新连续量、8r LE、至多30r nnz；00、10、01、11每个残余的双边行分别至多8、6、6、10 nnz。物理 z_k 的定义若尚不存在，新增等式或内联源展开另计。若直接内联其仿射读出，总支持数为 S_z，则残余行的保守账为28r+2*S_z，而不能仍记作30r。

每个 child 需要3个新连续量和12 LE。令 n_js 为 h_js 完整内联后的实际变量支持数，pi_s 的支持数为3、2、2、1；q_js的支持数为1、1、1、4。因此十二行保守 nnz 为29+2*sum_s n_js。若 C_j 行有 d_j 项且均使用上述独立残余坐标，则 sum_s n_js<=14+7*d_j，故上界为57+14*d_j。M个child与r个残余总增量为

```text
continuous = 3*r + 3*M
LE         = 8*r + 12*M
nnz       <= 30*r + 57*M + 14*sum_j d_j.
```

这些数在已有 delta、zu、zv 上计，不把它们再免费删除；共同源因子另加3连续量、12 LE、26 nnz。每个child独有一个至多三支撑的内联残余时，一个安全总上界为6M连续量、20M LE、109M nnz；不能同时内联残余又按免费物理坐标计费。一个含d项的残余联合谓词，直接四槽提升还需4行、至多7d+8 nnz；已有全局EQ时第四槽EQ可由前三槽和总和恢复，不要求材料化冗余行。额外更强槽界、原谓词、原 bits、源定义、界认证、位长、临时对象、slack、decoder与终端转换均在全路径费用中。

如果所有层的全部节点都保留三槽副本，就会退回原图的多份条件提升。上述递推是健全可构造的对照，不是证明这种全保留方案便宜。下一候选必须说明有限活跃观察为何足够、何处可以已证投影，以及真实块上的实际收益，不能只给新的图包装。

设备形式可以固定为四槽乘观察的幅值张量，使用相同稀疏 C 对各槽作批量仿射作用，再按认证端点的符号掩码生成 secant 系数。共同源行及其转置作用可用 gather、分段求和与 scatter 实现；这只是普通谓词算子形式，不引入反向分析或对偶救援。四槽张量、稀疏索引、主机设备共存、可靠舍入证书及最终终端求解仍须付费。当前未实现或运行设备核，不能据此声称完整GPU验证或绕过既有地址空间门。

## 真实宽卷积不能省略的接入缺口

本轮重新核对 D067 指向的 D025 完成档哈希，并只读原字段。其实际链是127到Conv128到BN129到ReLU130，权重形状64乘64乘3乘3，即每接收行576个槽。中心窗口原记录的槽4、481、516分别对应三个 crossing 源，receiver0在这三处保存的系数区间严格正、负、负，均非零。因此选择两个原父门不能证明其余574槽都是稳定仿射贡献。

这里 crossing 是已有可靠外包跨零，不证明两种相位实际可达。源编号仅用来定位证据，绝不是候选选择菜单。全部其余门仍需保留；有可靠严格正/负界的门可以作已证值代换，但原 bits 不删除。BN参数是非点区间，不能以中点当作实际网络。

现有归档缺少实际 HZ 连续读出、原二元列及编码、原EQ/LE和decoder的一致绑定。ONNX的[端口,通道,行,列]身份不是native列号；D081的3817项旧测试只授予合成来源组件资格，不补齐这些材料。本轮未把这些旧测试报告为本候选测试。

研究决定是保留本轮公式与符号商为支撑，下一次实现以完整宽残余及全部消费者为对象，不单独实现更容易的纯两父玩具来替代目标。优先补齐同一真实块的native读出和残余认证合同，再预注册默认关闭的数学与源级评估。保留已有五窗口320接收行的完整范围；不得改写旧固定配对实验或少报消费者，也不凭本轮纸面结果启动生产安装。
