# 共同实现关系的组合传递与相位出生

本草案服务于定义优先的非凸Neural HZ：把共同状态、相位语义及有效关系随算子传递，而非每到一个边界都从扁平谓词重新发现整张图。以下是数学引理和所需前提，没有新的可执行候选或实际网络资格。证明携带与增量认证本身是已知机制，不能单独宣称新抽象域或PLDI级新颖性。

## 语义对象

原状态theta包含连续因子xi∈[−1,1]^n和显式signed二元相位b∈{−1,+1}^m，满足原HZ的EQ与LE。输出为原坐标及必要辅助坐标的仿射读出。所有坐标都带共享latent身份，不只依赖整数列号。

沿用D091共同实现：新增连续量z有函数解释Gamma(theta)，每个原整数可行theta均能以同一个Gamma同时满足全部已安装关系。存储可行的任意z不必都是精确函数值，故关系可以收紧松弛；不能因此删除原整数状态。新增行的可靠编译仍用系数误差的完整单位盒补偿，不把浮点重算等同于精确拷贝。

候选接口携带原HZ、当前输出映射、共享因子身份、原门关系及共同实现证明。它不是把旧HZ重命名便完成域定义；尚缺完整算子实现、可靠编译、组合费用及真实收益。这里不声称最佳抽象、完整格或新的表达能力。

## 原门关系的前缀传递引理

设H中的原Graph已证明实际latent公式g和q满足扩展ReLU关系且graph_error=0。H′满足：

1. 存在明确的旧因子身份嵌入，旧连续盒、二元取值域与共享身份不变。
2. 原Graph使用的EQ、LE、RHS和行身份保留；旧系数的原始数值逐位相同，新列在这些行中精确补零。
3. 原证明所用前提继续成立，调用期间相关状态不被并发或未记录地修改。

则原Graph在H′中仍成立，g与q只作零列嵌入。证明直接由任一H′可行状态投影后满足同一组原方程和guard得到。新增约束只可能缩小满足集合，不会使原等式推论失效；不必再次逐系数提取同一数学关系。

此结论仅是原关系有效性的传递，不是投影等价。要证明H′没有丢失H的旧整数状态，还必须为每个旧状态构造满足全部新增行的共同Gamma扩展。D092与D093的小块证明承担的是这一额外义务，不能只用前缀保留替代它。

仿射或卷积只更新输出读出且保留谓词时，原latent门关系继续成立，但旧物理输出行位置未必继续代表q，输出绑定必须更新。Add和Concat仅在共享frame及共同谓词身份一致时可直接使用此引理；独立frame即使列号相同也不能合并，必须有显式注入、重命名及联合语义证明。

行重排需要认证的一一行映射；删除原证书行、重新求和、阈值删零、dtype转换、改变RHS或重新舍入均不属于直接前缀传递。对象id、seal或“没有发现变化”不是抗伪造内容证明。外部snapshot仍需完整来源、schema和初始关系认证；可信构造链的证明复用不能给未经检查的外部数据开入口。

## ReLU出生必须覆盖零点的两种标签

前提为同一个真实仿射f(theta)∈[l,u]，l<0<u。新signed相位b的允许集合为：f>0时{−1}，f<0时{+1}，f=0时{−1,+1}。这是符号约束语义，不执行相位分支、不枚举子问题。

令q=max(0,f)，并在允许的(theta,b)上定义：

    s = 2(q − f)/(−l) − b
    eta = 1 − 2q/u

则s、eta都在[−1,1]内，并满足：

    (l/2)(s + b) − (u/2)eta = f − u/2
    −s − b ≤ 0
    −eta + b ≤ 0
    q = (u/2)(1 − eta)

前向证明分f正、负、零的代数情形即可。反向，b=+1时guard与单位盒强制eta=1，故q=0且f=(l/2)(s+1)≤0；b=−1时强制s=1，故q=f≥0。因此投影精确为ReLU图，而不是凸包。

f=0时，两种标签分别对应s=−b、eta=1，都必须保留。因此在线出生的连续Gamma定义在扩大后的允许状态(theta,b)上；不能用仅依赖旧theta、固定挑选一个新相位的单值Gamma，声称已经覆盖零点两种原标签。D091闭合H0里的theta已含全部原相位，不能未经说明把那个表述直接搬到在线出生。

连续因子、二元非凸因子和EQ与LE均显式存在，没有退化为CZ、Zonotope或纯区间。后续共同关系需要对全部允许(theta,b)有效，不按margin或求解状态选其中一种。

## 数值与实现义务

出生证明针对理想系数及同一个f。若实现仅存round(f.bias−u/2)作为等式RHS，再从存储行解出一个g，则g未必等于f；“存储行内部graph_error=0”不能替代与实际网络前激活一致的证明。必须单独证明可靠lowering和来源对应；本草案不豁免这一步，也不为数值特殊情形删除旧相位或牺牲已证能力。

若采用可信构造链，仍须认证新出生的全部行及其数值前提，记录所有旧因子与新坐标分配，证明Add或残差共享身份和输入decoder不变，并保留完整费用。GPU批处理应覆盖整组确定算子并提供可靠舍入或误差证书；这里没有GPU执行或加速证据。
