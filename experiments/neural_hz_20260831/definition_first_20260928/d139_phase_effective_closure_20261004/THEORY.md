# 相位关系实际参与传播的闭包边界

本记录直接检验定义优先的 Neural-HZ 主线：保存原二元相位还不够，新域的统一传播必须实际利用它们与源、幅值的共同关系。一个普通二维有偏置残差网络证明，即使前层的全部线性支持都精确，凸化后接下一精确 ReLU 图仍会产生伪状态。另一个推导明确了相位条件反馈界尚未解决的乘积和活旁路问题。

这些是纸面证明与反例，不是候选执行、机器证明、真实网络收益或新颖性认证。原 HZ 的全部连续因子、原 signed bits、EQ/LE、共享 frame 和输入 decoder 保持原义。下文 beta 为原 bit 的 0/1 视图，分数 beta 仅用于松弛对照；不允许在候选具体语义中把原 bit 连续化。零门保留两个合法标签。

## 全部线性支持仍不能替代非凸跨层传播

令 x,y 属于 [-1,1]，使用同一源及全部原门：

```text
q = R(x+y/10),
r = R(x-q/2-1/4),
J = q-x/4-2r,
s = R(J-3/5),              R(t)=max(0,t).
```

这是含两个真实源、混合正负权、非零偏置和仍被读取的源/幅值旁路的小块，不要求相反或重复神经元、零偏置抵消、极小参数或近奇异矩阵。

真实网络恰有 sup J=11/20。证明如下，符号讨论只用于证明，不是运行相位分裂：

- 若 q=0，则 x<=-y/10<=1/10，第二门输入小于零，J=-x/4<=1/4。
- 若 q>0，则 q=x+y/10。第二门输入为 x/2-y/20-1/4。
- 在第二门不激活时，x<=1/2+y/10，故 J=3x/4+y/10<=3/8+7y/40<=11/20。
- 在第二门激活时，x>=1/2+y/10，故 J=1/2-x/4+y/5<=3/8+7y/40<=11/20。

x=3/5,y=1 时 q=7/10,r=0，达到 11/20；第二门零点的两个原标签均合法。因此真实 s 恒为零，且其输入上界为 -1/20。

现在给予比较方法非常强的前层接口：完整的 (x,y,q,beta) 带标签图凸包，而不是若干坐标界或有限模板。以下两个真实前层点的凸组合属于该凸包：

```text
weight 3/4: (x,y,q,beta)=( 1,0,1,1),
weight 1/4: (x,y,q,beta)=(-1,0,0,0),
mean:       (x,y,q,beta)=(1/2,0,3/4,3/4).
```

该均值因此满足前层所有有效线性不等式，包括带原标签的线性方向支持。在这个均值上，下一门输入为 -1/8，精确门图允许 r=0、其原 bit 为 0。于是 J=5/8，再下一精确门允许 s=1/40、其原 bit 为 1。伪点不依赖后两门的三角松弛或零相位歧义。

这否定的是“先保存前层全部线性支持，再接精确非线性即可保持联合精确”的主张。它不是说某个尚未测量的实际 ACT 路径允许此点，也不是对完整整数 HZ 的反例：原 beta=3/4 在完整整数关系中当然非法。保留整数 HZ 可维持整体健全性，但一个忽略该非凸关系的查询不能借此自称已经消费了相位。

与旧 D027 的局部凸包拼接控制、D117 的有限观察损失相比，本例给出一个更直接的递归查询判别：全部前层线性支持也不足以支撑通用精确 ReLU 闭包。这个现象是凸化与非线性组合的基本边界，不宣称为新数学原理。它可作为后续候选的完整共同状态检查，不能变成仅对此例定制的规则。

## 相位条件反馈界的自身消项不构成闭包

D126 已有原目标相位约束共同误差的例子。保留原父门 e1=R(x)、e2=R(y)，以及原目标门：

```text
g1=1/4-x-e1/10+e2/2,      r1=R(g1), 原 bit beta1,
g2=1/4-y+e1/2-e2/10,      r2=R(g2), 原 bit beta2.
```

在同一完整原关系上，有效反馈行是

```text
e1 <= 1-3 beta1/4+e2/2,
e2 <= 1-3 beta2/4+e1/2,
e>=0.
```

它们从添加前的源/门语义推出，不利用拟加入行循环认证自己。应用 D138 的支持公式到方向 w=(-1/10,1/2)，得到 k=(1/5,3/5)，故

```text
-e1/10+e2/2 <= 4/5-3 beta1/20-9 beta2/20,
g1 <= 21/20-x-3 beta1/20-9 beta2/20,
r1=beta1*g1 <= beta1*(9/10-x-9 beta2/20).
```

最后一步使用 beta1^2=beta1，确实消费了原整数门身份。但是 beta1*beta2 仍在；下一门的原 bit 再乘此式，会引入新的依赖。把 beta2 提前取最坏值可以得到健全较弱界，但丢掉的正是所需联合信息。该消项属于 D001、D124 已有的 guard-aware Boolean 代数，不能重新计为新定义突破。

而且共同反馈幅值不等于真实共同源幅值。固定 x=y=1/4，父 bits 和目标 bits 全为 1，反馈子系统允许 e1=e2=1/2，两行均取等。父符号守卫、全局幅值 caps、e>=f 以及以这些 e 计算的精确目标图均成立，目标 r1=r2=1/5，上述 absorbed bound 也成立。但真实父幅值应为 1/4，真实目标输出均为 1/10。

再保留活旁路 v=1/8+e1-e2/2，读出 J=r1+v。这个假点给 J=23/40 和 R(J-1/2)=3/40；同一真实源给 J=7/20 和后继零输出。完整原父图会排除该假赋值；仅保留共同 e、目标相位和反馈行不会。这是固定源诊断，不是全源安全性质、普通整数 HZ 的失效或可计分 ADV。

## 活旁路要求在相位条件内先合并共同方向

一般设同源后继 r=gamma*(h+w^T e)，活旁路 v=t+d^T e。完整联合读出是

```text
r+v = gamma*h+t+(d+gamma*w)^T e.
```

对原相位条件下的选定反馈 fiber，正确的共同包络使用

```text
gamma*h+t+k(d+gamma*w)^T c(beta).
```

支持映射及 k 不是线性的。分别使用 k(d) 和 k(w) 后相加通常只是较弱上界，不能称为同一个共享幅值的精确联合支持。多个活后继将方向变为 d+sum_j gamma_j*w_j；于是 k 本身含原相位依赖的 max 表达。

若 c 还依赖源，k^T c 仍需认证的共同源处理。给定单一数值相位后的低成本不等于整个未知相位集合的低成本。自身 gamma*(1-gamma)=0 没有解决这两个问题，也没有授权枚举所有相位或另加 rescue 路径。

此式把下一研究问题精确化：需要一种能保留这类联合方向与相位源关系的可查询表示，或明确且足够强的有损变换；不能再以“共同 e/P/bits 仍在”替代传播证明。

## 普通全相位开纤维不能提供新的等式商

这项检查针对 D001 的 Boolean-affine 等式商化，不针对所有 Neural-HZ 可能的改进。设原源 z 属于 R^p，原 bits 为 b，且每个 b 的合法源纤维 S_b 都包含非空开集。若 A(b)+B(b)z 在所有合法赋值上恒为零，固定任一 b 后，它是一个在开集上为零的仿射函数，故 A(b)=0、B(b)=0。每个 b 均如此。

因此，在已经代入 q_i=b_i*f_i 等定义别名后，没有超出 Boolean 恒等式的额外此类恒零形式。不同相位可以有不同系数，结论不要求它们相同。若源含预存仿射等式，应先在共同仿射包内解释开集。非满维或不可行相位不受这一前提覆盖。证明逐个固定 b，不是建议运行时枚举相位。

普通的两父门、混权后继及活源旁路已经能满足前提。取 x,y,t 属于 [-1,1]：

```text
f1=x+y/4+1/8,             q1=R(f1),
f2=-x/3+y-1/6,            q2=R(f2),
g=3q1/4-2q2/3+3t/4+x/8+y/10+1/12,
r=R(g).
```

两父法向非平行、偏置非零。令 g0=g-3t/4，以下都是严格内部的纸面见证：

| x,y | f1,f2 | 父相位 | g0 |
| --- | --- | --- | --- |
| 1/2,1/2 | 3/4,1/6 | 11 | 233/360 |
| 1/2,-1/2 | 1/2,-5/6 | 10 | 113/240 |
| -1/2,1/2 | -1/4,1/2 | 01 | -21/80 |
| -1/2,-1/2 | -1/2,-1/2 | 00 | -7/240 |

所有 abs(g0)<27/40。因此每行分别取 t=9/10 与 -9/10，就使后继门严格正、严格负。八个原相位各有开邻域，没有利用零标签或点状可行集。

这不是一般神经网络上禁止所有化简的定理。它说明不能依赖“所有门共享源”就期待出现新的相位恒等式；在这个普通结构上，潜在收益须来自源与守卫的联合不等式、可付查询或明确有损的变换，而不是重新命名旧等式商。数学原理是仿射函数在开集上的唯一性，不宣称为独创定理。

## 对候选的研究决定

D138 的常数-cap 正控没有读取原 bits/P，因此仍归为支撑查询候选。上述相位消项不足以改变这个定位。本轮不启动原计划中的 D139 小反馈块实现，不增加一个脱离域贡献的测试/适配框架；D136 已执行的 3965 项数学测试仍是最近人口，没有新运行结果。

后续优先检验保留原标签的共同源方向包络及其跨非线性组合。已有 D027/D091 的相位条件跨层正控不重做；新候选必须明确相较这些规则多了什么，以及宽 Conv 的全部消费者和存活 skip 的费用。不要求强于加入相同证据的精确 HZ；需要的是有实质能力和可付完整代价的统一域运算。若只能重新交给完整原图求解，必须如实认定尚未完成目标。
