# 一个后继激活与活旁路的联合支持原语

本页保留本轮另一个建设性纸面结果：D135/D138 的相关凸 fiber 可以支持任意带符号的“活旁路加一个新 ReLU”联合查询，且其一维参数曲线有线性数量的共同断点。它不是通用非凸 Neural-HZ 闭包，不是新优化原理，也未被选择为下一实现；主线限制由同目录 THEORY.md 的普通跨层反例给出。

## 精确公式及作用范围

令 F 为非空紧凸集，h_F 为其线性支持函数。所有消费者使用同一个 e 属于 F。新增原门 r=R(a^T e+b)，保留原 bit、精确守卫及两个合法零标签；活旁路与任何联合线性方向合并为 w^T e。记

```text
H(w,tau)=sup_{e in F} [w^T e+tau*R(a^T e+b)].
```

tau>=0 时，正部的点值恒等式直接给出

```text
H(w,tau)=max(h_F(w), tau*b+h_F(w+tau*a)).
```

正系数公式不需要 F 凸；这是对同一完整源的两个支持查询，不建立相位限制的源子问题，也不把两个最大化点拼成一个见证。下面负系数的极小极大交换才实质使用凸性。

tau=-d<0 时，利用 -d*R(g)=min_{0<=lambda<=d}(-lambda*g)，得到

```text
H(w,-d)=min_{0<=lambda<=d} [h_F(w-lambda*a)-lambda*b].
```

交换 sup 和 min 使用凸性、紧性与双线性连续性，是经典极小极大定理的直接特例；参见 [Sion 1958，Theorem 3.4](https://msp.org/pjm/1958/8-1/pjm-v8-n1-p14-s.pdf)。本轮实际阅读该定理及其假设，不把这个交换当作新推理原则。

当 F 为本页所选的多面体 fiber 时，负 tau 的结果也等于同一个 F 上的普通 LP 最优值：最大化 w^T e-d*r，约束 r>=0、r>=a^T e+b。目标的负 r 系数会使最优 r 取真实正部；添加有效上界不改变最优值。因此该原语不能宣称比相同 F 的原生单门 LP 更精确。一般紧凸 F 不一定有有限 LP 表示。该原语的可检验价值是不用通用求解器的显式查询和完整算术代价。

lambda 在数学上是一个对偶参数，必须如实命名。这里没有实际搜索、LP 状态反馈、失败修复或新验证路径；也不因它写在域内就自动给任何未来运行授予权限或资格。当前不实现这条旁支。

## 三角和二点反馈的有限参数曲线

专门取已认证的 D138 常数-cap fiber：

```text
F={e>=0 : e<=c+M e}, c>=0, M>=0,
```

整个 M 的 strongly connected components 为单点或二点，已经按 D138 合法归一化和排序，二点内部 [[0,A],[B,0]] 满足 A*B<1。所有原谓词 P、原源/phase 关系若另行相交，不能假称被此公式精确求解。

固定方向直线 w(lambda)=w-lambda*a，lambda 属于 [0,d]。三角单点的逆序支持递推是

```text
u_i(lambda)=w_i-lambda*a_i+sum_{j later} M_ji*k_j(lambda),
k_i(lambda)=max(0,u_i(lambda)).
```

每个 u_i、k_i 都是凸分段仿射函数，因为后继系数非负。求和不会产生输入曲线以外的断点；取正部只会新增零水平进入/离开处，至多两个。零平台的两个端点包括在此计数中，不要求严格正负或非退化导数。因此 n 个单点的整个共享曲线银行最多新增 2n 个不同内部断点，而非每层指数扩张。

二点块令 u,v 为已合并后继贡献的两条凸曲线，D=1-A*B>0。D138 给出

```text
k1=max(0,u,(u+B*v)/D),
k2=max(0,v,(v+A*u)/D).
```

各候选凸，故 k1,k2 凸。候选切换只可能发生在 u、v、u+B*v、v+A*u 的零点或已有断点：例如 (u+B*v)/D-u = B*(v+A*u)/D。四条曲线均凸，其正负区间边界各至多两个。A 或 B 为零时，某些候选一致，不增加断点。因此每个二点块至多新增八个共同断点。

若有 s 个单点、p 个二点块，整个银行的不同内部断点数不超过 2s+8p<=4n，其中 n=s+2p。该结论针对单个给定数值方向直线，不是未知原相位所产生的全部方向同时拥有这个界。

支持曲线 h_F(w-lambda*a)=sum_i c_i*k_i(lambda) 在这张共同网格上分段仿射。其减去 lambda*b 的最小值必在端点或断点取得，常值段也由端点覆盖。可以按精确系数求零点和合并网格，不需要运行神经相位子问题。

## 完整费用和未解决项

直接保存每条 k 曲线在最终共同网格上的斜率/截距或节点值，需要 O(n^2) 标量存储。逆序合并各实际边的曲线、加入至多常数个新根并补齐共同网格，可以按 O(n*(n+nnz(M))) 次标量算术实现；最后扫描目标另需 O(n^2)。每个根的有理分母、排序、所有中间系数的位长以及证据都要计费，不能把这个算术界等同于有界字长或 GPU 时间。

形成完整方向 w,a、认证 F、构造/归一化/SCC、源支撑、P、原 phases、全部消费者、终端 lowering 与 decoder 仍需支付。多个方向一般有不同网格，不能免费复用。宽实际 CNN 可能使这里的二次存储不可接受；没有真实费用或 GPU 加速声明。

相较 D068 的独立盒和一个负 hinge，本页扩展到指定的相关 causal/feedback fiber 并给出共同断点计数。它只计算 (e,r) 的线性方向，不含原 bit 作为任意联合查询系数，也不证明未知相位/source-dependent cap 的全集合查询。已有 bits/P 在完整载体里存在，不会自动进入该计算。

尤其不能递归将非凸前缀替换为其支持函数后继续套凸极小极大公式：支持函数与凸包相同，而下一非线性可以区分两者。THEORY.md 的二维普通残差反例已经给出这种严格损失，并将其传到下一门。保持原整数 P 会维持整体语义，但若还靠完整旧图决策恢复信息，就不能把这个内核称为完成的非凸定义创新。

本原语仅归档为纸面支撑。没有实现、运行、数值冻结、数学测试、源模型、GPU、正式新增解或默认启用。
