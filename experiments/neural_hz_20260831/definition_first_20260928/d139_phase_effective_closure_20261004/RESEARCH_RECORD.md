# 非凸 Neural HZ 主线的下一研究判据

用户再次明确要求研究强大的 Neural-HZ，而不是优化现有 HZ 或加入 helper。前一回合主要核对和汇报方向，按 Goal 的标准归为 no progress。本回合完成了新的具体闭包反例、相位消项与活旁路的完整推导，以及普通全相位开纤维的等式边界。这些证据改变下一行动：不执行 D138 文档中原定的小反馈块组件计划。

## 本轮实际交付

[数学记录](THEORY.md)给出普通二维残差小块的精确界 11/20，以及完整父层带标签凸包允许的 5/8 伪值。其后真实 ReLU 恒为零，但该接口允许 1/40。这里没有针对实例身份选择规则，也没有数值攻击、模型运行或计分。该反例比“几个模板丢信息”更直接：前层全部线性支持仍不能替代跨层非凸关系。

原相位反馈分析保留共同幅值并利用 beta^2=beta，但在具体 D126 控制上仍留下 beta1*beta2；活旁路要求先用 d+gamma*w 合并共同方向。分别求支路界再相加不能声称同样精确。源—幅值假点则证明仅有这些反馈行仍不等于原父门图。它们否决一个看似直接的 D138 升级，不否决完整原 HZ 的健全性。

全相位开纤维引理进一步排除了某种空转：在其明确前提下，D001 的 Boolean-affine 等式商没有额外可发现的守卫恒等式。普通三源、两父门及混权后继提供全部八个开相位的见证。它不排除联合不等式、非满维情况或其他结构上的化简，不把特殊反例扩大成整个目标不可能。

同时保留一个[联合支持原语](SUPPORT_LEMMA.md)：指定相关凸 fiber 上，一个新 ReLU 与全部活旁路的 signed 方向支持有显式公式；小反馈结构的一维参数曲线有 O(n) 个共同断点，朴素支付为 O(n*(n+nnz(M))) 算术和 O(n^2) 标量存储。这是一个有范围的建设性推导，不是任意未知原相位的闭包。负系数查询还等强于同一 F 的原生单门 LP，不能称新增非凸逻辑能力，不因本原语另建实现。

独立只读审查确认 D001/D014/D018/D027/D091/D114/D126 已覆盖许多容易重命名的方向。旧证明仍有价值，但重读、重新给第三层小例或扩大单元测试不能再记成域创新。文献搜索只用于核对候选原理；没有从搜索摘要推出新颖性，也没有引入论文中的 BaB、训练改变或其他验证路径。

三项独立纸面审查分别核对先前覆盖、相位源条件及公式/复杂度。最终复核确认 11/20 的精确上确界、全部伪点、八相位表格，以及共同断点计数。根代理在读回时将“普通 LP”对照明确限定为多面体 F，避免推广到任意紧凸集。这些不是机器证明或数值过门。

## 下一项可执行研究问题

需要回答的是：一个保留原标签和同源幅值的表示，能否用固定结构规则，对整个实际混权消费者及存活 skip 生成可由下一原激活继续消费的相位条件关系，并给出明确精度与完整成本？不是再问“能否保留 bits”，也不是再求一个更好的凸 fiber 支持公式。

下一步先推导相位依赖方向 k(d+sum gamma_j*w_j) 与共同源守卫的处理合同，或以新的有损定义明确量化所丢信息。必须与 D027/D091 的既有条件传播及相同证据 HZ 对照。没有此合同前，不实现独立 M-matrix 优化器、全图 wrapper、phase table 适配框架或新测试框架。这个研究选择不改变用户的长期目标，不给整体难题自行宣布 blocked。

普通 CNN 的完整前沿仍以 D137 的图证据为准：large 有活 identity skip；medium/Tiny 有 projection skip；一个五窗口或单门纸面控制不能代替全部消费者。GPU、smooth/Transformer、其他家族、shadow、完整 2413 与独立 400 的范围继续有效且未完成。
