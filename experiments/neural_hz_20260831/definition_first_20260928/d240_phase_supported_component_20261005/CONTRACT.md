# 相位作用范围关系的有限行组件

本候选把 D239 的相位作用范围线性化实现为默认关闭的非凸数学组件。它保留完整声明的源图和原二元位，只追加由同源表达式证明的有限关系，不采用点池、phase split、支持函数搜索、LP/dual rescue 或其他验证算法。这个阶段不是 ACT/ONNX adapter，不把调用者声明的数学图、ID 或 frame 当成真实模型来源证书。

## 明确的数学输入与原非凸图

make_block 构造 owned Block。其 n>=2 个源坐标有明确有理上下界，前两坐标 x1,x2 的界必须为 [-1,1]，父门 qi=R(xi)。其余源可有连续或显式 signed binary 类型；额外原 EQ/LE 谓词也保留。实际两个子预激活 g1,g2 为 (全部 n 源,q1,q2) 上的完整输入仿射式，包括偏置，原子门 yi=R(gi)。所有四个原 signed bits、物理读出和源谓词都在旧图中。

物理列顺序为 n 个原源、q1,q2,y1,y2，之后是四个原 signed bits。这个声明图固定使用 alpha=(b+1)/2，不宣称这是 ACT native 的相位方向。原输入 decoder 返回完整 n 个源；它是声明图的输入，不是已经认证的原 ONNX 输入见证。与原 HZ 的嵌入通过有界连续坐标的仿射归一化、原二元位和线性谓词完成，保留非凸性；不是用凸域替换原图。

make_block 自己从输入界和完整仿射式计算可靠的子门界，生成原 ReLU 的四行精确混合整数图及相位范围，保留零点全部合法相位。额外约束只加强此图，故已有外包界继续有效。数学输入可以用源谓词表达相关性，但没有资格声称任意真实网络前沿已被提取到这里。

这刻意区分数学源构造与 native 来源认证：后续 adapter 必须从实际原图模板取出预激活、输出和位，核验完整原 H 的每一消费者与 decoder，并只做保持零点的正比例归一化。不得中心化输入后沿用旧 ReLU 输出或位，不得凭名字相同或 reliable=True 声称完成绑定。本轮没有该 adapter。

## 原相位作用范围上的共同关系

attach 接受同一个 owned Block、同一对象身份的 frame、结构预先指定的 anchor_kind 和正有理 tau。它完整重算

```text
z=(g1+g2)/2,
d=(g1-g2)/2,
e=d-tau*(q1-q2).
```

anchor_kind=x 时，a,b 是 z 在 x1,x2 上的实际系数，r=z-a*x1-b*x2；anchor_kind=q 时，a,b 来自 q1,q2，r 同样由完整 z 相减。两种是同一相位作用范围证明在两类已声明原坐标上的代数实例；不得在一种失败后根据 terminal/LP 状态改选另一种。e、r 的偏置和所有剩余项都必须保留。

可靠区间由完整合并表达式及 owned 源/父幅值范围静态计算，不接受任意可靠性标志或外来数值界，不调用支持查询。X 判据取 M=max(a_positive+b_negative,a_negative+b_positive)，要求 [Lr-M,Ur+M] 包含于 [-tau,tau]。Q 判据要求 [Lr+min(0,a,b),Ur+max(0,a,b)] 包含于同一区间。失败即拒绝，不产生部分因子。

令 S=clip(z+tau,0,2*tau)、h=alpha1-alpha2。两个判据分别凭原输入弱异号或最多一个父幅值非零，证明

```text
h*(S-z-tau)=0.
```

只消去这个共同差观察，不逐项替换 alpha_i*S。没有新增 S 的位或逐项 clip 因子，也不删除其他原消费者。令 pi=alpha_i-qi，结合单调 2-Lipschitz 差函数，增加

```text
-2*tau*p1+2*min(Le,0)
 <= y1-y2-h*(z+tau)
 <=2*tau*p2+2*max(Ue,0).
```

X 中用 c12=alpha1*x2、c21=alpha2*x1、v_i=alpha_i*r 四个连续产品。共同差精确改写为

```text
tau*h+a*(q1-c21)+b*(c12-q2)+v1-v2.
```

Q 中将 c12,c21 换成 alpha1*q2、alpha2*q1，保持同一式。所有产品保留完整四行包络，在原 alpha 为二元时精确；不复制 r 成私有独立源。

X 实例统一追加三条源容量，而不是按控制或目标选择：记 T=q1-q2+c12-c21、U=q1+q2-c12-c21、D=2q1-x1+2q2-x2、ni=1-alpha_i-qi+xi，则 -p1-n1<=T<=p2+n2、U<=D。它们由完整原父图有效，包含零标签。Q 不含相同 c 产品，不免费追加这些 X 专属容量。

## 输出与完整费用

结果持有原 Block 对象和新增四个连续产品及新增行，原源、原 EQ/LE、四个原位、其余源二元类型及 decoder 不动。satisfied 是有理线性行检查，允许分数位以测试查询；canonical_extension 必须先检查完整原图和所有原位整数性，再计算唯一真实产品。它不把查询的分数可行点当成输入 ADV。

原物理列和 r 坐标已存在时，X 基础为 4 列、21 LE，D239 主控制为 76 nnz；对称控制也按同一规则支付全部三条容量，不用纸面最小 70 nnz 冒充实际计数。Q 为 4 列、18 LE，坐标级上界 56 nnz。实际编译内联完整 r，必须报告真实行与 nnz；长源展开可能显著增加费用。原图的界、原相位行、源谓词和所有输出都另计，不将增量账当全组件账。

所有构造、静态求界、编译、真值重构与查询共用一个 D228 Budget。只复用 Budget/Limits、精确有理数操作及稀疏 Row 规范化；不调用 D228 Bank、几何、support 或其 Compiled，不调用 D229 bind，不继承 D214 的查询菜单。不存在第二个可重置的工作账本。work256M、单次操作200M、entries64M、512位上限不扩大，资源失败锁定；输入读取、排序、系数合并和结果存储均须收费。

这些仍是逻辑预算，不是 Python/native/GPU 完整物理资格。外部输入对象的构造、宿主/设备共存、终端接口、证据、源认证和实际 decoder 成本仍须在后续完整路径付费。没有固定宽度或任意深层无损闭包结论；通用 Affine/Add 读出可消费当前完整坐标，任意新 ReLU 接入尚非本候选资格。

## 必须验证的精度与不健全反例

非对称 D239 固定控制为 z=(19/25)x1+(37/50)x2+t/10，d=q1-q2。令 F=(249/250)D+(2/5)(y1-y2-(x1-x2)/2)。编译的有限行必须给精确证书 F<=51/25，并排除强比较点 F=25641/12500 的所有辅助扩展，而非只否定一组猜测产品。真实 (1,-1,1) 取等；后继 R(F-41/20) 的安全证明不能改称执行过的网络 CERT。

强比较点的两个完整单子门前缀见证及 joint child-over-convexified-parent 见证、原标签、全域真实 clip 尾及非对称参数族按 D239 原分数独立核对。候选不能读取这些测试见证来构造关系，也不做支持搜索。

z=2*x1 或 z=2*q1、tau=1 的不支持合同必须拒绝。x1=x2=t=1 时，两原相位同为1、真实 S=2 而各 alpha_i(z+1)=13/5，必须仍保留真状态，不能逐项错误线性化。完整 residual、偏置、extra source predicate、t 与 -t 的身份、外来 frame、非法数值、原零位和 sticky resource failure 都属于固定测试，不靠放松边界使测试通过。
