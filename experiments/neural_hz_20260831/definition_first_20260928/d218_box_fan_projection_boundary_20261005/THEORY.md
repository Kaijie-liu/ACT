# 共同盒源上常数相位关系的输出投影边界

本轮证明：对任意维共同盒源上的两个仿射 ReLU，完整单门源凸包加全部已注册单行相位关系，已经具有 D216 联合常数幅值块相同的物理投影。D217 的三源搜索因此应停止；增加盒源维数、改变偏置或取消共同 dominant 坐标，都不能逃离这个结论。

这是一个限定机制的负定理，不是所有多神经元方法无用。它尤其不覆盖随源变化的 cap、只在非盒父谓词下有效的更紧 cap、三门以上共同关系或额外历史相位耦合。实际 ACT 若只保留较弱的单门外包，也不由本定理断言绝无数值收益。

本文是纸面研究；不实现辅助验证器，不删除原 HZ 连续源、二元相位、EQ/LE、共同身份、活消费者或输入 decoder。分数相位只分析终端外包，原非凸具体化仍保留原 bits。

## 比较对象与前提

设 X 是有限维共同盒，f1、f2 是其上跨零的仿射式，q_i=ReLU(f_i)，beta_i 为原 active bit 的视图。每个门的完整 source-labelled hull 保留同一物理 x、q_i、beta_i，但两门的内部凸组合见证可以不同。

注册有限个前向和反向关系

```text
f1-a_i*f2 <= c_i,  f2-b_j*f1 <= d_j,
a_i,b_j>0, c_i,d_j>0, every a_i*b_j<1.
```

所有 cap 必须在整个 X 上有效，允许保守大于精确盒界。两方向均非空。定义

```text
P={e>=0: e1-a_i*e2<=c_i, e2-b_j*e1<=d_j},
C=min_i c_i, D=min_j d_j,
V1=max_P e1, V2=max_P e2.
```

old 外包是完整单门源 hull 的交，再加所有旧单行相位行

```text
q1-a_i*q2<=c_i*beta1,
q2-b_j*q1<=d_j*beta2.
```

加上各 D203 块的单坐标界也不改变下面的论证。new 外包进一步加入 D216 的完整 labelled hull conv F(P)，其中 F(P) 要求原整数 beta_i=0 时 e_i=0。

定理：old 与 new 投影到 (x,q1,q2) 完全相同。可以附加只涉及物理变量的相同谓词；不能额外假定任意跨门相位谓词也被共同修复保留。新增关系包括

```text
q1-a_i*q2<=C*beta1+(c_i-C)*beta2,
q2-b_j*q1<=D*beta2+(d_j-D)*beta1,
q1<=V1*beta1, q1<=C*beta1+(V1-C)*beta2,
q2<=V2*beta2, q2<=D*beta2+(V2-D)*beta1.
```

与旧行及非负界合起来，这正是 D216 已证的联合 hull。不是只证明一个选择出来的新行冗余。

## 最大可延拓相位

固定一个 old 可行的物理点 (x,q1,q2)。单门相位纤维为非空闭区间，记最大端点 B1、B2。所有旧相位行对两个相位单调放松，所以把旧相位同时提高到 B1、B2 后仍然满足 old。

为了分析 B1>B2 的情形，对源坐标按 f2 系数符号翻转并归一化，写成

```text
z in [0,1]^n,
f2=sum_j v_j*z_j-t, v_j>=0, 0<t<sum_j v_j,
f1=sum_j w_j*z_j+h.
```

固定源坐标只在本证明中代入常数，原身份不删除；其余坐标按正宽度归一化。v_j=0 的坐标仍保留；不同门不拥有独立源副本。对固定 z 和相位 b，完整 active source-mass 盒是

```text
K_b={d: max(0,z_j-1+b)<=d_j<=min(b,z_j)}.
```

定义两个在此盒上的最大 active 仿射值

```text
U2(b)=sum_j v_j*min(b,z_j)-t*b,
U1(b)=h*b+sum_(w_j>0) w_j*min(b,z_j)
             +sum_(w_j<0) w_j*max(0,z_j-1+b).
```

完整单门 hull 给 q_i<=U_i(B_i)。D217 的完整纤维判据还给出：若 B2<1，则

```text
q2=U2(B2),
U2'_+(B2)=sum_(z_j>B2) v_j-t<=0.                 (1)
```

否则可以稍微增大 B2 而仍满足 U2>=q2，与最大性矛盾。这一右导数包含 breakpoint 处的严格 z_j>B2，不把等号坐标错误纳入。

## 相同相位时的共同盒界

任取注册前向斜率 a>=0。对任何 d∈K_b，b>0 时 d/b∈[0,1]^n，故盒 cap 给

```text
sum_j w_j*d_j+h*b
 <= a*(sum_j v_j*d_j-t*b)+c(a)*b
 <= a*U2(b)+c(a)*b.
```

在 d 上取最大，得到

```text
U1(b)-a*U2(b)<=c(a)*b.                           (2)
```

两门不需要在同一个 d 上达到各自最大值；a>=0 正是第二步所需的符号。b=0 时 K_b={0}，等式直接成立。

## 较大相位的增量由最小 cap 控制

现在取 r=B1>s=B2，Delta=r-s>0。对 w_j>0 令

```text
n_j=(min(r,z_j)-min(s,z_j))/Delta,
```

其他坐标取 n_j=0。于是 0<=n_j<=1，n_j>0 只能发生在 z_j>s。由 (1)，

```text
sum_j v_j*n_j<=t.
```

负 w_j 项的 lower endpoint 随相位增加，所以其增量非正。因而

```text
U1(r)-U1(s)<=Delta*(h+sum_j w_j*n_j).             (3)
```

对任意注册前向斜率 gamma>=0，

```text
h+sum_j w_j*n_j
 <= h+gamma*t+sum_j max(w_j-gamma*v_j,0)
 = max_(z in box) (f1-gamma*f2)
 <= c(gamma).
```

每个 cap 都控制同一个增量，因此可以取全部注册 cap 的最小值 C：

```text
U1(r)-U1(s)<=C*(r-s).                            (4)
```

零 v_j 不消耗容量，其正 w_j 贡献仍被 max(w_j-gamma*v_j,0) 覆盖。s=0 时 (1) 及本证明仍成立，没有除以 s。

## 全部新行同时可满足

把 (2)、(4) 与 q1<=U1(r)、q2=U2(s) 合并：

```text
q1-a_i*q2<=c_i*s+C*(r-s)
          =C*B1+(c_i-C)*B2.
```

这给出全部前向 mixed 行。若 B1<=B2，则同一行已经由旧 q1-a_i*q2<=c_i*B1 及 c_i>=C 蕴含。交换门次序给出全部反向行。因此不用分别为各新行选择不同相位，唯一共同选择 (B1,B2) 同时通过。

再令 u1=max_X ReLU(f1)。每个真实输出对属于 P：正 cap 与 a_i,b_j>=0 使真实 ReLU 保留反馈上界。因此 V1>=u1，V2>=u2。完整单门 hull 蕴含 q1<=u1*B1<=V1*B1。

若 B1>B2，由 (4) 及 U1(B2)<=u1*B2，

```text
q1<=C*(B1-B2)+u1*B2<=C*B1+(V1-C)*B2.
```

若 B1<=B2，则 V1>=C（P 包含 (C,0)），新的 mixed 坐标行由 q1<=V1*B1 蕴含。第二坐标对称。故 D216 全部行成立。new 包含于 old 的方向来自联合 hull 本来就加强旧块，完成投影相等证明。

## 研究决策与不能外推的结论

这个证明覆盖普通任意维盒、任意混号 affine 系数和偏置，允许没有共同 dominant 坐标。它比 D217 的二维特殊族严格更广。继续调整三源 alpha、增加第四个源或增加常数斜率，不会在所述强参照上产生输出阳性。

D216 的 labelled 分离仍然真实，只是可通过重新选择合法相位修复；旧档无需撤改。相位参与其他历史关系时，最大端点不再必然可同时采用，本定理不适用。较弱的实际单门编码也可能被常数块改善，不能把对强参照的定理误写为 ACT 在所有情形绝无收益。

下一主线需要真正改变缺失的信息：保留 source-dependent cap 的共同变化，或利用普通深层非盒父谓词得到严格更紧的 cap。D205 已有源依赖尺度正控，证明本轮负结论没有封死该方向；但共同尺度、独立产品包络或源仿射反馈本身也不是新贡献。

上述推导没有新 numerical qualification、域实现、GPU、smooth/Transformer 或正式能力结果。两位独立数学复核者确认主要证明及零相位、零系数、保守 cap 的边界；这不是外部新颖性认证，也不是完整 Neural-HZ 的完成证明。
