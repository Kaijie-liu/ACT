# 非比例源界的后继输出正控制

普通四维盒上，一个随两个共同源变化的 cap 能取得新的物理分离：参照保留完整单门源 hull、D205 固定规则生成的全部共同尺度行，以及新增 cap 的无相位反馈行；新源相位行仍能证明一个后继 ReLU 恒为零，而参照允许正输出。

这个结果逃离本轮常数 fan 负定理，因为 cap 不是常数。不过，所用 source-phase 不等式本身已有 D204/D205 先例，源仿射反馈也已有 D138 先例。本例不构成完整新域或新颖性证明，也没有证明两个 cap 的联合条件兼容性强于分别加入相同有效行。

## 同一源状态上的非比例 cap

令 x,y,z,t∈[-1,1]，保留同一份源、两原相位、原 guards 和所有消费者：

```text
f1=x+y+3*z/4+t/4+1/8,
f2=x-y+z/4+3*t/4-1/8,
q_i=ReLU(f_i), a=b=1/2.
```

只对 x,y 取盒支持、保持 z,t 活跃，得到

```text
c1(z,t)=35/16+5*z/8-t/8,    23/16<=c1<=47/16,
c2(z,t)=29/16-z/8+5*t/8,    17/16<=c2<=41/16,
f1-q2/2<=f1-f2/2<=c1,
f2-q1/2<=f2-f1/2<=c2.
```

两个 cap 在全盒上严格正。它们在 (z,t) 上的系数矩阵为

```text
[[5/8,-1/8],[-1/8,5/8]], determinant=3/8.
```

所以 P(z,t)={e>=0:e1<=c1+e2/2,e2<=c2+e1/2} 不是一个固定 P 乘单个共同尺度：两轴截距的比例在 (0,0) 为35/29，在(1,-1)为47/17。这里只证明该 family 的非同比例形状，不排除用多个旧尺度块表达或外包相同信息。

一般地，若 c_i>=m_i>0 且 f_i-a*q_j<=c_i，则原整数图满足

```text
q_i-a*q_j<=beta_i*c_i
          <=c_i-m_i*(1-beta_i).                 (S)
```

第一步还使用 q_i=beta_i*f_i、a>=0、q_j>=0；零预激活的两个原标签均合法。(S) 是有效的线性源相位行，不需要新乘积列、相位枚举或求解器。它不是完整 conv{(source,e,beta):e∈P(source),off=>e=0} 的理想表述证明。

## 完整单门参照与原共同尺度

本例两方向的精确全盒常数 cap 为 k1=47/16、k2=41/16。D205 的规范共同 deficit 规则只发现 x 为两个差分的公共同号坐标，生成

```text
w_x=8/47, s=(39+8*x)/47, l=31/47, u=1,
U1=(k1+k2/2)/(1-1/4)=45/8,
U2=(k2+k1/2)/(1-1/4)=43/8.
```

参照保留这同一固定 a=b=1/2 规则的全部十行：非负、q_i<=U_i*beta_i、q_i<=U_i*(s-l+l*beta_i)，以及两方向的常数相位反馈与共同尺度相位反馈。还保留同一四源、完整单门 source-labelled hull，及 q1-q2/2<=c1(z,t)、q2-q1/2<=c2(z,t) 两条 source plain 行。

不声称比较了任意配对、任意尺度选择、全部可能的多尺度块或完整带源双门 hull。

取物理点

```text
x=y=z=t=0,
q1=49/32, q2=11/128.
```

两完整单门的最大可行相位为

```text
B1=47/92, B2=373/400.
```

中心点上，归一化后的容量在 beta>=1/2 一侧分别为 3-(23/8)*beta 和 3-(25/8)*beta。令其等于给定 q 即得这两个最大值；q>=max(0,f) 及完整两点见证同时成立。

具体单门见证是：

| 门 | active 权重 | active 原源 | inactive 原源 | 两点预激活 |
| --- | --- | --- | --- | --- |
| 1 | 47/92 | (45/47,45/47,45/47,45/47) | (-1,-1,-1,-1) | 1127/376, -23/8 |
| 2 | 373/400 | (27/373,-27/373,27/373,27/373) | (-1,1,-1,-1) | 275/2984, -25/8 |

每行源均值均为零，输出均值分别49/32、11/128，guards严格满足。见证用于证明完整单门可行，不把两个不同的源分布冒充共同两门分布。

## 旧行全部通过而新行排除物理点

在 B=(B1,B2) 上，原共同尺度 s=39/47，令 R_i=s-l+l*B_i。因为 B_i>1/2，R_i=1/2+l*(B_i-1/2)>1/2。

十条旧行及两条 source plain 参照行可按以下精确余量检查：

| 旧行 | 右侧减左侧 |
| --- | --- |
| 两非负界 | 49/32、11/128 |
| 门1两幅值界 U1*B1 和 U1*R1 | 各大于41/32 |
| 门2两幅值界 U2*B2 和 U2*R2 | 各大于333/128 |
| 门1常数相位反馈 | 73/5888 |
| 门1共同尺度相位反馈 | 9/5888 |
| 门2两种相位反馈 | 各大于251/128 |
| 条件 cap 的两条 source plain 行 | 179/256、319/128 |

其中 q1-q2/2=381/256；门1的两个旧相位上界分别为2209/1472、2193/1472。反向 q2-q1/2=-87/128，因此该方向有大余量。

新门1行 (S)，取 m1=23/16，要求

```text
q1-q2/2<=c1-(23/16)*(1-B1)=95/64=380/256.
```

违反量是1/256。因为 B1 是完整单门允许的最大相位，任何更小相位只使右侧更小；重新选择相位不能挽救同一物理点。它不是任意固定标签上的假阳性。

## 无辅助查询的后继分离

门1原全盒下界为 -23/8=-2*m1。原图上行是 q1<=f1+(23/8)*(1-beta1)。把它与两倍 (S) 相加，直接消去相位：

```text
J=3*q1-q2-f1-2*c1(z,t)
 =3*q1-q2-x-y-2*z-9/2 <=0.                      (T)
```

这是全父盒的有效关系，没有 LP、优化权重或反向救援；t 的系数因同源合并精确抵消。在真实源 (1,1,1,1) 上，两门激活且 J=0，所以这个界可达。

旧物理点给 J=1/128。因此实际后继

```text
child=ReLU(J-1/256)
```

在新行下恒为零，旧参照上的同一父点却允许 child=1/256。该下一门的实际图点也属于其在旧父域上的完整单门 hull。这里不是具体原网络 ADV，也不是已验证真实 CIFAR/Tiny 的 CERT。

## 定义研究意义与费用

本例证明：把两个不同源依赖压到 D205 这一固定规则产生的一个共同尺度，会丢失可被后继消费的信息。它不证明方向独立的两条 source-phase 行不够；事实上 (T) 只使用第一条新增行。因此还不能据此声称建立了不可约的多源联合新域。

若这些物理坐标已存在，加入两条 (S) 是2 LE、10个变量系数，无新连续列或 bit；加入已消元的 (T) 则另为1 LE、5个变量系数，不能免费重复计入。若只需下一门健全推理，可直接以固定的正组合证明 (T)，但完整传播、源展开和全部消费者仍需计费。

生成一般条件 cap 可对统一选定的 source 坐标子集保留系数，对其余坐标取可靠盒支持。给定子集时是差分支持大小的线性工作；本例的子集 (z,t) 仅是纸面正控，尚无冻结的全人口结构选择算法。不能将这个选择按实例身份硬编码后宣称已统一接入。所有历史谓词、原位、证据、输入重构、可靠区间和终端费用仍保留。

下一项真正需要证明的是：在原生非凸域中共同保存这些不同 cap 的源相容性，能否比独立已知行或多个旧尺度块产生额外可消费能力，并有统一可付的组合规则。没有这项证据，当前正控只能作为支撑结果，不能另造 helper 或给现有 cuts 换名。
