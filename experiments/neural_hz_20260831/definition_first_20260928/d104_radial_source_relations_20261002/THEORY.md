# 同源 LayerNorm 残差的方向支持定理

本页给出一族统一、前向、无搜索的有效线性关系，并构造相对明确强参考的严格纸面分离。它不依赖 LP 状态、margin、公开标签或实例身份。保留原输入、全部原 bits 与 decoder；没有执行程序、求解器或网络。

## 方向支持

设 z 为同一原非凸 HZ 源的中心化读出，sum z=0，epsilon>0，||z||<=R，并且

~~~text
rho=(epsilon+||z||^2/d)^(-1/2)
v=rho*z.
~~~

令 a0 为消费者方向，a=a0-mean(a0)*1，A=||a||。因此 a0^T z=a^T z，a0^T v=a^T v。取预先由结构选定且认证的 0<=lambda<=rho_min=(epsilon+R^2/d)^(-1/2)。已知可靠上界 a^T z<=T_raw，令 T=max(0,min(T_raw,A*R))。

当 A>0 时，定义 k=d*A^2 及

~~~text
f(t)=t/sqrt(epsilon+t^2/k)-lambda*t.
~~~

则共同源线性关系成立：

~~~text
a0^T v-lambda*a0^T z <= M
M=max_{0<=t<=T} f(t).
~~~

证明：设 t=a^T z。t<0 时 rho-lambda>=0，所以左侧<=0。t>=0 时 Cauchy 给出 ||z||^2>=t^2/A^2，因此左侧<=f(t)。T_raw<0 时全体 t 为负，安全上界 0 仍成立，但不称精确。A=0 时读出恒为零。

f 的导数为 epsilon/(epsilon+t^2/k)^(3/2)-lambda，二阶导数为 -3*epsilon*t/k*(epsilon+t^2/k)^(-5/2)<=0。由此：

~~~text
lambda=0:     M=f(T)
lambda>0:     t0=sqrt(k*((epsilon/lambda)^(2/3)-epsilon))
              M=f(min(T,t0)).
~~~

临界点落在区间内部时，M=sqrt(d)*A*[1-(lambda*sqrt(epsilon))^(2/3)]^(3/2)。这只是解析计算，不启用优化器、分支或求解后分离。lambda 超过 rho_min 时，负半轴论证不成立，不得继续套用。

该上界不要求源凸、不要求原点可行，故适用于保留原二元相位的非凸共同源。只有最优 t 的最小范数见证 z=(t/A^2)*a 在真实源内时，才可称精确支持。普通对称坐标盒与中心超平面的交集，在坐标方向上满足这个额外条件。

gamma／beta 存在时，对实际下一仿射行 w 取 a0=diag(gamma)*w，输出行写为 w^T y-lambda*a0^T z<=w^T beta+M，不需要按坐标除以 gamma。lambda 的选择须在未来预注册中固定为结构规则或实际消费者系数，不能事后挑选有利实例。

## 范数版本与局部源界

若还可靠知道 R_low<=||z||<=R，则整个共同余项满足

~~~text
||v-lambda*z|| <= max_{R_low<=r<=R}
  r*(1/sqrt(epsilon+r^2/d)-lambda).
~~~

证明为共同非负标量 rho-lambda 的直接代入。该标量函数同样凹；lambda=0 取 R，lambda>0 将临界点 sqrt(d*((epsilon/lambda)^(2/3)-epsilon)) 截到 [R_low,R]。这比仅以 (rho_max-lambda)*R 独立乘界至少不差，但不保证胜过来源相同的所有 Taylor／联合余项方法。R_low 可以是可靠弱下界 0；不能以采样最小值认证。

这给出了无需展开 d*d Gram 矩阵的共同径向信息，但方向行若只使用宽泛 R 和 T，仍可能很松。新定义不等于已解决宽深网络精度。

## 普通三维强控制

取 d=3，epsilon=1，P={z:sum z=0, |z_i|<=1}。这是中心平面上的二维六边形，不涉及浮点极端情形。

真实界如下：

~~~text
||z||^2<=2
sqrt(3/5)<=rho<=1
|v_i|<=sqrt(2/3)
||v||^2<=6/5.
~~~

源范数上界在 (1,-1,0) 的置换取等。给定 z_i=t，由中心化得 ||z||^2>=3*t^2/2，故坐标界也可取等。该源的精确输出集合为

~~~text
sum v_i=0
v_i^2+||v||^2/3<=1    (i=1,2,3).
~~~

反向证明：上述不等式保证 ||v||^2<3；令 rho'=sqrt(1-||v||^2/3)，则 |v_i/rho'|<=1，解码 z'=v/rho' 正好在 P，且给出真实归一化输出。这里重构的是某个 z'，不保证等于残差支路保留的原 z。

考虑以下松弛点：

~~~text
z=(4/5,-7/10,-1/10)
rho=19/20
v=(19/25,-133/200,-19/200).
~~~

它满足 v=rho*z、真实 rho 区间、全部真实坐标界、零和、全局范数界，甚至上述精确输出集合；三条输出椭球不等式的最大左侧为 18411/20000<1。但是

~~~text
rho^2*(1+||z||^2/3)=24909/20000>1.
~~~

因此它不是同一源的真实 LayerNorm 图点，更不是具体网络 ADV。

### 不只是打败宽区间

在原点的一阶展开为 v=z+e，因为 LayerNorm Jacobian 在中心子空间上是单位映射。每个坐标的最紧余项界恰为

~~~text
|e_i|<=E=1-sqrt(3/5).
~~~

有效性来自 |z_i|<=1 和 rho>=sqrt(3/5)；源 (1,-1,0)、置换与取负达到每个坐标的两个端点。

松弛点的 e=(-1/25,7/200,1/200)，严格满足这些最紧余项界及 sum e=0。所以公平参考明确包含：

1. 同一个原源 P；
2. 共享原源的一阶展开 v=z+e；
3. 每个坐标真实最紧的双侧余项界及余项零和；
4. 完整精确输出像；
5. 共同 rho、真实 rho 界及 v=rho*z，但不把 rho 与原源范数耦合。

这个参考仍允许该点。它甚至含非线性输出信息，不能被描述成“只用了松盒”。但它不包含完整源绑定径向等式；没有证明优于所有联合余项域、全部 Taylor 方法或 ZonoGPT 完整实现。

### 残差行与非稳定后继 ReLU

令 F=v_1-(3/4)*z_1。因 3/4<sqrt(3/5)，可用上述定理。松弛点 F=4/25。对真实源，设 t=z_1：

- t<0 时 F<=0；
- 0<=t<=1 时 F<=t/sqrt(1+t^2/2)-3*t/4。

在 [0,1] 有 (1+t^2/2)^(-1/2)<=1-t^2/6，因为
(1-t^2/6)^2*(1+t^2/2)-1=t^2*(12-10*t^2+t^4)/72>=0。
因此 F<=t/4-t^3/6<=1/(6*sqrt(2))<1/8。

于是有保守有理线性行 F<=1/8，排除松弛点的幅度为 7/200。没有数值程序或近似小数参与该证明。

再接 q=ReLU(F-1/16)，保留真实原生 child bit。真实输出满足 q<=1/16，松弛点可取 active bit=1、q=39/400，仍保留 7/200 的分离。两相位均真实出现：z=(-1/2,1/4,1/4) 给负 preactivation，z=(1/2,-1/4,-1/4) 给正 preactivation；后者 rho=sqrt(8/9)>7/8。因此该消费并非只有稳定相位，也未删除零点的任一合法标签。

这是明确参考下的纸面严格分离，formal_gain=0；不是既有模型新 CERT、攻击反例、GPU 成绩或全量回放结果。
