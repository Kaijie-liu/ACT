# 保留共同源的径向 Neural-HZ 候选定义

本轮从 HZ 的具体化语义增加一种受限、可认证消费的径向关系，而非只重排矩阵。LayerNorm 的输入与输出必须指向同一个源；即便输出集合精确，丢掉这种关联仍会损害残差验证。这里给出候选定义、原 HZ 嵌入及局部精确变换；它尚未被证明是新的通用抽象域贡献，也没有实现或正式收益。

## 域元素与具体化

保留原 HZ 的全部连续因子 theta、原二元相位 b、线性 EQ/LE 谓词 P、共享 frame 与具体输入 decoder。允许额外连续坐标，并附加有限个有类型、有来源的径向关系块 R_r：

~~~text
z_r 是当前 theta 及先前 v 的可靠仿射读出
1^T z_r = 0, epsilon_r > 0
rho_r >= rho_lower_r > 0
v_r = rho_r*z_r
epsilon_r*rho_r^2 + ||v_r||^2/d_r = 1.
~~~

rho_lower 必须由可靠有限的 ||z_r|| 上界证明；不能用未经认证的浮点估计。各 v、rho 有有限界，数学上可以仿射归一化为连续单位盒因子，但实现必须支付系数、界和数值补偿。原 bits 不 pivot、不删除、不连续化，原 P 不因引入关系而丢弃。

中心化轴、宽度 d、方差所用分母以及 epsilon 在平方根内的位置都必须绑定实际模型的标准 LayerNorm；不能将 no_var、RMSNorm 或其他变体默认为同一合同。若 ||z||<=R，可可靠取 0<rho_lower<=(epsilon+R^2/d)^(-1/2)，并取 rho_upper>=epsilon^(-1/2)。epsilon=0 不在本定理内，不能未经另证正方差界继续使用。

域元素由 P、共享源标识、径向块列表和仿射输出读出组成。具体化取满足全部线性和径向谓词的同一赋值，再读出输出。不同消费者不能给同一个块重新选择 rho 或源。块来源按前向拓扑认证，不允许无证循环或把两个不同 frame 当成同源。

v=rho*z 与曲面等式推出 rho^2*(epsilon+||z||^2/d)=1；rho>0 给出唯一的真实倒标准差。因此该关系精确表达实数 LayerNorm 的归一化部分。gamma、beta 是随后的点仿射变换，不需要除以 gamma，也不借此忽略 gamma 为零的合法模型语义。

空径向列表且不增加其他坐标时，具体化恰为原 HZ。这是显式嵌入。含径向图的联合集合一般不是有限多面体并，因此不是 Zonotope、CZ 或纯线性 HZ 的改名。它是带结构化多项式谓词的混合非凸关系域候选；CPZ 已有更一般的代数表达能力，所以“增加曲面谓词”本身不成立新颖性主张。

目前只定义具体化及其语义包含关系，没有证明可计算最佳抽象、完整格或一般多项式时间决策。

## 精确局部变换

- Affine／Conv：作用于当前共同赋值的仿射读出；不独立复制径向块。
- Add／Concat：共享祖先按同一身份合流，保留原输入与 v；残差 x+Wv 不需要更换原输入坐标。
- LayerNorm：增加一个 d 维 v、一个 rho 和上述 d 个双线性等式及一个二次曲面等式。采用 v 提升后所有新增代数等式的次数均为 2，不把 rho^2*||z||^2 展成四次多项式。
- ReLU：当前输出仍是扩展连续坐标和原 bits 的仿射读出，因而可使用原有有证界及精确线性相位图；保留新原生 bit 及零预激活两种合法标签。径向谓词同时保留，不能用独立输出盒代替。
- 下一 LayerNorm：其中心化源可以是此前 v 和 ReLU 输出的仿射读出，再附加新块；联合实数语义成立，但不据此声称深层费用小或余项不增长。

以上是实数模型的关系变换，不自动认证 ONNX 的浮点语义、舍入或 loader。已有 CERT／ADV 仍按原全部资格与具体网络复核要求保留。

Softmax 的指数和 GELU 的 erf／tanh 尚不在本代数片段内。为它们随意加一个“精确函数节点”不能冒称已完成定义创新；需另有有证近似与关系消费规则。

## 终端边界

本项目仍只使用原普通 LP/MILP 和独立具体见证检查，不新增 SOC／非线性求解器，也不做 split、BaB、backward／dual rescue。

径向语义可以导出可靠线性外包：有界乘积的有效行、可靠范数支持，以及 [本轮同源方向行](THEORY.md)。这些行只是语义的必要条件；有限行通常不能精确表示曲面。CERT 须基于健全外包，外包可行点不能直接计 ADV。原输入 decoder 保持原身份，解码后仍需原具体网络和性质验证；失败返回 UNKNOWN，不拼接不同源或改写结果。

不能仅把每个原计算节点附上一个关系再称为创新。后续要证明的价值是：一个块的共同径向信息能在残差及下一非线性中被统一消费，严格强于公平对照，并且完整传播、线性 lowering、证据、见证与 GPU 费用可支付。本轮只完成其中的纸面定义与局部分离。

## 与纯分母重参数化的区别

共同正仿射分母可用 Charnes–Cooper 和原 bit 乘缩放的线性化精确改写，见 [先行研究和边界](PRIOR_ART_AND_DECISION.md)。那种方法把原连续坐标改成缩放坐标，decoder 是除以缩放量；未归一化残差需要再次加入连续乘积。

本定义不靠更换原输入坐标获得虚假的残差闭包。保留原 theta 和 v 的双线性共同关系确实增加了非线性表达，也带来真实求解外包成本。不能把这些关系的保存量少直接当成完整验证更快。
