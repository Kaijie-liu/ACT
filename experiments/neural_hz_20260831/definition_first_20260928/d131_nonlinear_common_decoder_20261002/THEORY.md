# 共同激活幅值的非线性充分统计

本研究从非凸域的共同生成元出发，回答多个消费者如何使用同一组真实幅值，而不是将独立界放进同一个容器。结论是：对一个共同仿射到 ReLU 块，梯度统计量能够唯一决定全部激活幅值；核空间一维时，其共享解码有闭式。但源绑定和终端降级目前没有净成本优势，所以不据此实现新适配层或宣布完整 Neural-HZ 域成立。

全文为纸面推导，根代理和独立代理核对；没有机器证明、数值程序、模型执行或测试资格。已有 HZ 保留连续因子、全部原二元身份、原零点标签、EQ/LE、共享 frame 和具体输入 decoder。后文的 beta 是原 signed bit 的 0/1 视图，不是新的因子或实际域中的连续松弛。

## 共同统计量确实决定全部幅值

设同一个源状态给出 x，固定已认证实系数 A 和 b，定义

```text
A in R^(m by d),  g=Ax+b,
q=ReLU(g),        y=A^T q.
```

不同消费者可以有任意混权 Cq、旁路 Sx，以及共享的旧源谓词。不要求 C=A^T，也不要求实际网络是梯度网络。

对实数 u,v，ReLU 单调且 1-Lipschitz，故

```text
(ReLU(u)-ReLU(v))^2 <= (u-v)(ReLU(u)-ReLU(v)).
```

逐坐标求和，对任意两个真实源状态得到

```text
||q-q'||^2 <= (x-x')^T A^T(q-q') = (x-x')^T(y-y').
```

因此 y=y' 必有 q=q'。它保证所有 Cq 使用同一个 q，不是为每个输出选择不同最优见证。无需源独立、满维、相位枚举或 rank(A)=d；原源可以有额外谓词。

这不推出相同 y 决定 x，也不推出 y 到 q 是仿射函数。若原源必须保留，则 x 本来也是 q 的充分输入；新统计量的价值只能来自更有用的推理或完整成本，不能仅凭充分性自封创新。

标量证明是经典 firm nonexpansiveness 的 ReLU 特例。[Parikh 与 Boyd 的 Proximal Algorithms 第 2.3 节](https://web.stanford.edu/~boyd/papers/pdf/prox_algs.pdf)给出一般 proximal 算子的同类不等式。本记录的神经接口解释不是新的凸分析原理。

## 唯一共同解码及其直接证明

定义域为可行集合非空的 y，令

```text
D_A,b(y) = argmin_r J(r),
J(r)=||r||^2/2-b^T r,
r>=0, A^T r=y.
```

目标严格凸且 coercive，可行集闭凸，所以非空时存在唯一最小点。对于某一实际 q=ReLU(Ax+b)，设 s=q-Ax-b。逐门有 s>=0、q>=0 和 s^T q=0。任何具有相同 y 的可行 r 满足

```text
J(r)-J(q)
 = ||r-q||^2/2 + (q-b)^T(r-q)
 = ||r-q||^2/2 + x^T A^T(r-q) + s^T(r-q)
 = ||r-q||^2/2 + s^T r
 >= ||r-q||^2/2.
```

故 D_A,b(A^T q)=q。这个证明不调用求解器、对偶反馈或源可行性 oracle。解码器的数学定义用了一个 QP，并不等于实现中免费拥有该 QP 的解。

等价地，令 Psi(x)=||ReLU(Ax+b)||^2/2，则

```text
Psi(x)=sup_(r>=0) [(A^T r)^T x + b^T r - ||r||^2/2].
```

在固定 y 上最小化 J 是这个势的共轭 infimal projection。其值函数闭性可由 J 的 coercivity 和有界最小化序列证明，因此没有暗中依赖某个未认证的严格可行点。Fenchel 表述用于数学辨认，不授权新的 dual rescue 或 QP 求解路径；直接差值证明已经足够建立本轮结论。

## 域元素必须绑定原源而不只是保留源名称

一个候选关系元素可保存原源 theta、所有原 bits、原谓词、实际 x 读出、A/b、共同 y 和上述非线性 decoder。针对本块，精确关系至少包含

```text
g=Ax+b,
beta_i=0 => g_i<=0,   beta_i=1 => g_i>=0,
y=A^T diag(beta) g,
q denotes D_A,b(y).
```

由原 guards，diag(beta)g 就是真实 ReLU(g)，包括 g_i=0 时的两个原标签；充分性定理再保证 decoder 得到同一个 q。全部消费者和未被替换的谓词必须使用这个 q；原 q bounds、外部 EQ/LE、残差和 decoder 检查不能因 q 不再物理存储而丢掉。

仅保存 x、其 guards 和一个任意 y 的解码器是不够的：解码器的隐含源可能是另一个 x'。上述 y 绑定不可省略。它是 phase-source 乘积关系，不是普通线性 HZ 免费拥有的新等式。若终端逐项线性化全部 beta_i*g_i，原 m 个幅值通常就重新出现。

在覆盖全部读出和谓词的前提下，替换本块是对旧精确 labelled 图的重新参数化，前后按 q/y 互相构造，保留具体输入。语义包含可给出预序，按具体化相等取商后得到偏序；未证明可计算最佳抽象或完整格。没有块时保留原 HZ。非凸性及原标签没有被换成凸 QP 可行域；QP 只定义唯一函数，不能用其整个可行集代替函数图。

Affine、Conv、Add、Concat 可在共享 decoder 的同一输出向量上组合，不能为每个消费者复制独立 decoder 状态。下一 ReLU 仍须保留其原 bit、可靠界及守卫。以上给出精确语义，不提供任意深度廉价查询或完整 GPU 算法。

## 一维核空间给出非枚举的闭式解码

若 ker(A^T)=span(n)，n!=0，选择一个在 range(A^T) 上认证的固定线性右逆 p(y)，使 A^T p(y)=y。所有满足该等式的 r 都写成

```text
r=p(y)+n*t.
```

非负条件给出

```text
L(y)=max_(n_i>0) -p_i(y)/n_i,
U(y)=min_(n_i<0) -p_i(y)/n_i.
```

若 n_i=0，必须另查 p_i(y)>=0；空的下侧或上侧集合分别给 -infinity 或 +infinity。y 不在 range、零系数条件失败或 L>U 时，该 decoder 不可行，不能继续发布界或见证。

因为 J(p+n*t) 的二阶导数为 ||n||^2>0，唯一最优参数是

```text
t0(y)=n^T(b-p(y))/||n||^2,
t*(y)=min(U(y),max(L(y),t0(y))).
```

可行时 t0 有限，即使一侧无界也得到有限解。这里是系数与区间端点上的 max/min 归约，不是输入/相位 split。所有输出共享一次 t*，不是各自选择 clamp 分支。原 beta 的零点双标签另外保留，不按 clip 分支合并或删除 bits。

形成 p(y) 若稠密需 O(md) 算术与对应存储，随后区间扫描和重构为 O(m)。right inverse/kernel 的精确认证、填充和有理位长必须计费。只报告 O(m) 而略过 p 的形成是错误的。该闭式来自经典一维严格凸二次最小化，不宣称新的优化方法。

## 三个非平行门的共同非线性解码

在 [-1,1]^2 上取

```text
g1=x1+1/5, g2=x2-1/7, g3=x1+x2-1/2,
qi=ReLU(gi), y1=q1+q3, y2=q2+q3.
```

三条门超平面都在盒内单独穿越，法向不平行，偏置非零。取 p=(y1,y2,0)、n=(-1,-1,1)，得到

```text
q3=clip((y1+y2-39/70)/3, 0, min(y1,y2)),
q1=y1-q3, q2=y2-q3,   y1,y2>=0.
```

任意混权消费者例如 v=q1-q2/2+q3/3，以及重复输出或 residual Sx+Cq，都能使用同一个 q3。这里的正证是共同实现和可计算 decoder，不是新网络 CERT。

这不是一个固定仿射 decoder 的改名。假设在全 labelled 图上存在 q=T y+B x+U beta+c。每个门的合法零点双标签先迫使 U 的对应列为零。在只跨门 i 的两个相邻开区域，左侧 Jacobian 差为 e_i*a_i^T，右侧为 T*a_i*a_i^T，因此 T*a_i=e_i。对三个 i 得 T*A^T=I_3，与 rank(A)<=2 矛盾。B*x 不改变 Jacobian 的跳跃，不能修复此矛盾。

此结论仅否决固定仿射 decoder，并不否决上面的非线性 clip。旧 D004/D051 的线性摘要下界不能直接用来否定这个候选。

## 共同统计量不能取代原输入和实际解码

原源反例取 A 的两行为 (1,1/4)、(-1,1/5)，b=(1/5,-1/10)。源 (1/2,0) 和 (19/40,1/10) 都给 q=(7/10,0)、y=(7/10,7/40)、原 bits=(1,0)，但第二输入 residual 不同。因此原输入、所有 raw source 消费者以及输入 decoder 不能从 y 中删除。

另取 A 的三行为 (1,0)、(0,1)、(-1,-1)，b=(1/4,-1/4,1/8)。源均值为 (0,0) 时真实 q=(1/4,0,1/8)、y=(1/8,-1/8)。伪幅值

```text
r=(3/8,1/8,1/4)=q+(1/8)(1,1,1)
```

仍有 A^T r=y。若仅保留所有独立单门 source-labelled hull、共同源均值、统计量线性等式和此 y 数值，它也可行：各门采用等权两点，分别为 (+/-1/2,0)、(0,+/-1/2)、(+/-3/16,+/-3/16)，各门自己的 bit 均值为 1/2，恰好产生对应 r_i。每组只证明其单门 hull，不假称三个组来自同一源分布。

混权 v=r1-r2+r3 的伪值为 1/2，实际源 (0,0) 的值为 3/8；接 ReLU(v-7/16) 得伪值 1/16、实际值 0。唯一 decoder 可排除这个共同幅值错误，但该例只分离指定松弛和一个固定 source fiber，不是全输入盒的性质证明，也不是完整 labelled 统计量图或所有强旧 HZ 的比较。实际整数 HZ 不接受这个伪点；它永远不计 ADV。

## 不能把任意实际混权输出当作势梯度

共同统计量 y 是 grad Psi(x)。实际网络输出 F(x)=Bx+c+sum_i c_i ReLU(a_i^T x+b_i) 通常不是它。若每个门都有其余门不跨越的双侧开邻域，而且 F 是同维 C1 势的梯度，则相邻 Jacobian 差 c_i*a_i^T 必须对称，故 c_i=lambda_i*a_i；再由任一 cell 的对称 Jacobian 得 B 对称。反向由

```text
Phi(x)=x^T Bx/2+c^T x+sum_i lambda_i ReLU(a_i^T x+b_i)^2/2
```

给出势。B positive semidefinite 且所有 lambda_i>=0 是无需相位枚举的凸性充分条件，不声称是必要条件。

普通 mixed weights 不满足该对齐时不能借用势的单调性。沿前节两门，取 F=(q1-q2/2+x1/10,q1/4+q2+x2/10)。源 P=(-1/2,0)、Q=(-2/5,1/10) 给 Delta F=(1/20,-7/100)、Delta x=(1/10,1/10)，内积为 -1/500，连单调性都不成立。

这是作用域证明，不否定通过真正 y 和共享 nonlinear decoder 处理任意 Cq。不得把二者混为一谈。

## 单调 smooth 激活的有限推广

若每个坐标 phi_i 单调不减且 L_i-Lipschitz，0<L_i<infinity，令 q_i=phi_i(a_i^T x+b_i)，仍取 y=A^T q，则

```text
sum_i (q_i-q_i')^2/L_i <= (x-x')^T(y-y').
```

证明逐坐标使用同号性及 |Delta q_i|<=L_i|Delta g_i|。因此相同 y 仍唯一决定全部 q。这是一个精确关系事实；不自动得到 ReLU 的二次目标或上述一维 clip decoder。有限区间内的单调性与常数必须在实际来源上认证，不能直接外推非单调激活或 input-dependent value Attention。

它保留 smooth 方向的共同语义研究机会，但当前没有 sigmoid/tanh/其他 smooth 模型执行、数值认证或查询资格。已有势、Fenchel 和互补图研究及其准确适用范围另见[原始文献对照](SOURCES.md)。

## 完整成本和本轮实施决定

一般 decoder 的 QP 有 m 个幅值变量、rank(A) 个独立等式和 m 个非负条件；A 的系数、全部消费者、源约束和实际输出都仍需存储和处理。将最优性写回互补关系会恢复原 ReLU 图。未知 bits 不能通过预存全部相位逆、输入切分或一个未付费 oracle 获得便宜解码。

一维核空间虽然以 m-1 个 y 坐标和一个函数表达全部 q，但终端若物化一个 t，连续幅值宽度就是 (m-1)+1=m；源绑定、guards 和可能的填充另加。不能据此宣称实际压缩、速度或显存收益。若原 d>rank(A)，压缩 y 坐标还需精确基变换，不能用数值近似 rank 代替证明。

Conv 每位置的 A 为 c_out by (kernel_area*c_in)。只有 rank(A)<c_out 才有这个意义上的幅值坐标减少。首层或通道扩张可能满足；一般不扩张层并不保证。这里没有新读模型系数或真实 rank census，不把教科书 shape 观察冒充 CIFAR/Tiny 的实际统计。重叠 patch 和全部 residual 消费者仍须用同一原源绑定。

GPU 上的矩阵作用、max/min 扫描和批量 clip 有实现可能；固定值解码可并行不等于不确定集合的支持查询便宜，也不等于端到端全面 GPU。有限精度认证、模型/BN 系数、物理共存、证据、原终端和具体输入重构仍全部计费。

因此本轮保留新数学问题：能否在普通通道扩张结构上，给这个共同非线性接口一个比原 HZ 更有用的前向关系算法，并在不恢复所有旧幅值成本的条件下完成终端？当前答案未证，不创建实现、不注册额外数值运行，也不因一个三门闭式特例扩张适配框架。
