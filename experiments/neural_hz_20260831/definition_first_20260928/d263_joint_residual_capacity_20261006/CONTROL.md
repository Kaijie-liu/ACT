# 联合残余严格超出旧六产品系统的普通控制

本页给同一个完整显示点：旧六产品 MC、三条 X 和两条常数付款 QG 接受它，新的共同残余物理行排除它。既有完整单子门前缀凸包、凸化父域上的联合双子门参照及 D052 首四门全部固定匹配也接受它。全部为精确有理数纸面证明，没有执行 LP、测试或模型；虚假显示点不是 ADV。

## 声明网络

原源 A in [0,1]^4、s,t in [-1,1]，全部原位及源身份保留。定义

```text
x1=A1-A2, x2=A3-A4, qi=ReLU(xi),
a=17/20, b=3/50, tau=1,
r=(s-t)/20, e=nu*(s+t),
z=a*(x1+x2)+b*(q1+q2)+r, d=q1-q2+e,
Y1=ReLU(z+d), Y2=ReLU(z-d),
Dabs=2*q1-x1+2*q2-x2,
F=Dabs+(2/5)*(Y1-Y2-(x1-x2)/2),
Rout=ReLU(F-207/100).
```

先取 nu=1/40。真实 r、e 共用 s,t，不能改成两个独立自由残余。两者的边际为 [-1/10,1/10]、[-1/20,1/20]，mu=0。

## 联合付款与新物理证书

旧独立付款 R+2*max(Ue,0)=1/5。共同源上却有

```text
rho+2*e=s/10, -rho+2*e=t/10,
U(rho)=U(-rho)=1/10,
Jraw=J=1/10.
```

两个守卫 eta_minus 为0、eta_plus 为1/100；D262 的 M=47/20、s0=M，abs(B)=3/50、Hc=0。因此新物理行是

```text
(47/20)*Dabs+Y1-Y2-(x1-x2)/2 <= 487/100.
```

取2/5倍并加3/50倍的 Dabs<=2 得 F<=517/250=2.068。后继阈值207/100=2.07，故预激活不超过-1/500，Rout=0。

## 共同旧显示点

取 u=99/100，

```text
A=(1/2,1/2,1/2,1/2), s=t=0, x1=x2=0,
alpha1=alpha2=gamma1=gamma2=1/2,
q1=q2=99/200,
Y1=u*(163/200), Y2=u*(113/200).
```

显示点保留 r=e=0 的实际源等式。其 Y1-Y2=99/400，Dabs=99/50，F=2079/1000=2.079，后继精确图允许 Rout=9/1000及 active 标签1。新物理行左端9801/2000=4.9005，超过487/100恰61/2000；这是同一物理点的严格分离。

## 完整旧六产品延拓

旧比较保留上述原源、全部原图和相位的 LP 松弛、共同 r/e 恒等式及范围，并加入 D252 的六产品完整 MC、三条 X 和两条独立常数付款 QG。没有另外加入 alpha_i*s、alpha_i*t 或把 e 与这些条件源共同提升的关系；这种更强比较可能已经蕴含新行，不在本结论内。

同一显示点取六个辅助值

```text
c12=1/200, c21=-1/200,
d12=99/200, d21=0,
v1=1/20, v2=-1/20.
```

两个 c 的 MC 可行区间为 [-1/2,1/2]，两个 d 为 [0,99/200]，两个 v 为 [-1/20,1/20]，所以全部24条 MC 成立。p_i=n_i=1/200，

```text
T=1/100=p2+n2,
U=99/100<=Dabs=99/50,
-T<=p1+n1,
V=99/200,
K=(17/20)*(1/100)+(3/50)*(99/200)+1/10
 =691/5000.
```

QG 上行左端 Y1-Y2-K=1093/10000，右端为

```text
2*p2+eta01plus*alpha2+2*Ue
=1/100+1/200+1/10=23/200.
```

余量57/10000严格为正。下行左端为-1093/10000、右端同为23/200，也成立。旧系统因此确有完整辅助延拓；不能再说新 JP 只是这个旧系统的投影推论。它新增的是旧系统未消费的 r/e 共同来源信息。

## 其他明确的强参照

D252 CONTROL 的两个完整单子门前缀分布及凸化父域上的联合双子门分布，都可令 s=t=0 原样使用。所有来源均值及标签保持；它们不是某一次真实网络输入。D262 CONTROL 已详细列出对应四父角和 A/C 分布，本页不将这些历史构造重记为新模型证据。

D052 固定匹配的共同前沿为 (A1,A2,A3,A4,q1,q2,s,t)，采用原盒及全部原谓词，对首四门的12个有序不同门对生成两行并保留单门上界。对于 Y1 到 Y2，原算法得到

```text
P=a*(x1+x2+2)+(s+1)/40+(1-t)/40,
N=(1-b)*(q1+1-q2),
(kappa0,kappa1,U)=(-16/25,49/50,-16/25).
```

这里 f 的独立共同源盒上界为143/50，不误用非凸真实图上的更紧上界。显示点 P=7/4，Y1+Y2-P=-1919/5000，两条右端均17/100，余量2769/5000。反向相同。父子方向每个 child 的剩余源范围仍为 [-1/10,1/10]，其固定匹配与 D262 的 nu=0 表相同；两父关系仍为 q1+q2<=alpha1+alpha2。所有单门行也由完整单前缀见证认证。

没有比较包含 Rout 的门对、多轮 D052/D029/D062 组合、完整四门联合源凸包或完整 RLT，不能升级为胜过所有已有方法。

## 不依赖精确相消的开区间

保持 r 和其余网络不变，让

```text
943/40000 < nu < 21/800.
```

其两端约为0.023575和0.02625。共同付款为 J=max(1/10,4*nu)。旧同一辅助延拓的上行要求

```text
1093/10000 <= 3/200+4*nu,
```

整个开区间严格满足。新 F 上界为

```text
2+(2/5)*(7/100+max(1/10,4*nu)) < 207/100.
```

因此新 Rout 恒零、旧显示值9/1000同时保持。区间跨过 nu=1/40，故不是依靠该点系数刚好相消的数值特例。

在该区间 nu<1/20，D052 child 对的 P 改为 a*(x1+x2+2)+(1/20-nu)*(s-t+2)，kappa0=U=-37/50+4nu、kappa1=49/50。显示左端为-2169/5000+2nu，右端3/25+2nu，余量仍2769/5000。其他方向和完整前缀见证仍保持。

这证明了普通结构家族上的严格抽象强化，不证明真实 CIFAR/Tiny 命中率、终端时间或正式新增解。也不能据此覆盖尚未研究的 smooth/Transformer 结构。
