# 联合残余的真实来源程序与未完成接口

共同残余规则必须在原来源尚未被分别求界之前执行。本页给出保留全部实际项的提取合同及成本边界；没有模型执行、原生安装或来源资格。旧三个完整前缀与全部97532位置、2853个pair及mask记录仍是后续来源人口，不能只保留此前未排除的通道。

## 从实际子门读出直接形成四个方向

设实际子门预激活为g1、g2，z=(g1+g2)/2、d=(g1-g2)/2，沿用完整父归一化、固定Gram提取的a、均值中选中q的完整b和原tau。对sigma属于{-1,1}、k属于{0,1}，共同读出为

```text
sigma*rho+2*k*e
 =(sigma/2+k)*g1+(sigma/2-k)*g2
  -sigma*(a1*x1+a2*x2)
  -(sigma*b1+2*k*tau)*q1-(sigma*b2-2*k*tau)*q2-sigma*mu.
```

应先按原来源键合并这些系数，再计算支持上界。k=0的两个方向可共享rho的一个区间；它们不是两次独立声明源。这里的有限方向来自一个固定恒等式，不读取性质、标签、margin或求解状态，不运行相位子问题。

原外层BN误差分别为E1*epsilon1、E2*epsilon2。rho+2e中的系数是(3E1/2,-E2/2)，-rho+2e中的系数是(E1/2,-3E2/2)，不能先把均值误差和差分误差分别改成两个独立噪声。中间每个实际BN输出位置也有自己的原epsilon；不同位置即使通道相同也不能合并。父BN误差、projection skip的BN误差、偏置及全部未选Q均保留。

## 可实现的共同分组而非完整稠密展开

对每个实际中间输出通道k和外层tap t，令Crest[k,t]为原中间Conv读出减去两个选中Q项后的完整标量。如果原Conv含bias，bias继续属于Crest，不能再另加一次。

同一Crest在rho/e中的均值及差分系数分别保存。对每个方向先合并系数，再用该Crest的可靠区间求界；原中间BN名义scale乘入系数，BN bias和原epsilon各自另保留。各Crest可以共享未选Q：将它们用于分组盒支持只会丢精度，不改变原H，也不把组复制成新的真实自由变量。不能因此称其为整个H的精确支持。

skip展开到共同Relu2输出A，在同一A键上减去a1*x1+a2*x2；父自己的BN误差独立保留。这样无需为所有未选Q物化完整二层卷积合成矩阵。固定Gram五个和只需父支持并集，支持外的完整残余仍须支付。九个旧mask只认证外层空间几何；内部共享系数若另有padding区别，必须证明统一分组界覆盖全部位置，不能把代表位置的精确式自动转授整个类。

不能为省提取成本把a统一置零。这样虽仍可生成健全式，却破坏本研究的已知正控：在CONTROL的例子中，a=0使r半径变成1.8、两守卫总和1.66、联合付款1.8，行右端6.52；旧显示点左端仅3.2175。因此这个简化没有保留所需严格性。此为纸面反证，不是实际模型失败率。

## 旧标量记录不能恢复联合信息

D259 source_bounds.py的fused_offset在求和前已把剩余Conv、BN误差和skip收缩到单标量范围；D261 source_observer.py随后记录的是各方向独立界。即使这些记录全部正确，也不足以构造联合支持。

例如共同源xi、eta属于[-1,1]，r=xi+eta。e=(xi-eta)/2和e=(xi+eta)/2都具有相同r范围[-2,2]及e范围[-1,1]，但max(|r|+2e_+)分别为2和4。因此不能只从旧e_bounds或边际区间重新命名出一个联合块。

## 成本核查和下一执行边界

D261完整来源实测255549650/256000000 work，余450350。邻对tap与中间通道乘积人口T=328896，完整相关卷积核人口P=331776。即便已有两个scaled输出，直接追加均值add和half的657792次基本算术也超过余量；这是对简单追加实现的否定，不是所有共享算法的下界。

静态代码审查找出可删除的重复主项：完整核只借用认证一次为5(2T-P)=1630080；scaled输出中间值复用为3(2T-P)=978048；认证h视图免重复外部扫描为4T=1315584；选中Q的min/max贡献缓存为7(2T-P)=2282112。合计6205824只是可删除主项，新缓存、索引、身份及数组费用尚未扣除，不是已实现净节约。原BN提取本来每节点只执行一次，不能另记BN构造节约。

旧单方向支持收尾为13n+12的乘积角点核、6n+256的两个有向归约及标量尾费。四方向照搬为76n+1072及四份尾费。THEORY的重叠公式允许一次共同系数遍历和四个有向统计归约；其中归约主项12n+512，逐元素核、常数中心、不确定系数、临时数组和最终max仍另计。它只替代支持收尾，不免费产生完整mean/r来源。

因此先验证带系数区间的共同支持算术，再完成共享来源程序和总成本证明；当前不冻结未知总成本的来源worker。下一版本仍保留原256M全阶段、200M单模型、40M一次预付证据、64M累计entries、512位、240秒和完整来源人口。不得同时删除旧e路径又未经证明声称结果与D261逐位相同。

实际原相位列、输入decoder、完整消费者、正常终端和GPU接入依然未完成。最终只有同一路径全2413及独立400回放保旧增解，才能更新成绩。

## 新行收益的统一否定筛

令bJP=2M+Qjoint，psi(A,B;v,u)=max(0,u(A+B),-v*A)。若旧参照确含父门[-v_i,u_i]的完整hull，则

```text
Sbox=psi(-s0-c/2,2*s0;v1,u1)
    +psi(-s0+c/2,2*s0;v2,u2)+U_Y1-L_Y2
```

是新行左端的旧有效上界。Sbox<=bJP即证明新行冗余。只有较窄输出界时不能借用较窄hull，可统一使用原[-1,1]hull。

若旧子门单门上侧为Y1<=theta*g1+beta、下侧有Y2>=0和Y2>=g2，则固定k=0,1给旧有效读出

```text
Wk=s0*Dabs-c*(x1-x2)/2+(theta-k)*z+(theta+k)*d+beta.
```

将完整同源系数合并后取得旧坐标盒上界S_k，也可证明冗余。任何只在原整数图成立、旧LP尚不蕴含的界，不能免费用于此比较。设S为这些有证旧上界的最小值，G=Jsep-J，则必要条件为G>2M+Q0+Jsep-S，其中Q0=abs(B)+Hc_plus+eta10minus+eta01plus。正重叠信用不足以跨过旧方向余量时仍无收益；通过此筛也仅是未证冗余，不是新解。
