# 共同激活函数候选的定义审查

本轮检查两种可能的 Neural-HZ 生成关系：共同未知函数，以及 GELU/SiLU 相对 ReLU 的共同折叠缺陷。前者对所声明函数类精确等价于全部两两斜率约束；后者有严格 smooth 正控，但同信息的已有差分原理给出相同证书。两条路线均没有证明新的定义或完整代价优势，本轮不进入实现。

## 共同函数候选的语义

保留原 HZ 状态 H 的连续源、全部原二元身份、EQ/LE、共享 frame 和输入 decoder。设当前神经块的预激活 g_i 是这个共同状态上的已绑定读出。候选用一个函数 latent phi 共同生成 q_i=phi(g_i)，其中 phi 属于全实轴上的非降、1-Lipschitz 函数类。仿射、Conv、Add 和 Concat 都读取同一 q，不为每个消费者复制 phi。

这是明确的函数类外包，不是已知实际激活函数的精确图。量词是对每个保留状态存在一个共同 phi；它不强制不同源状态使用同一个未知 phi。真实非降 1-Lipschitz 激活属于该类，因此这种替代可以健全，但是否保住旧证明能力是另一个问题。GELU/SiLU 在全轴并非该函数类，不能直接使用此替代。

没有函数块时 HZ 原样嵌入。语义次序可按对齐身份后的具体化包含定义；本轮不声称最佳抽象或完整格。这个候选即便携带旧二元相位，也不能只因有非凸标签就称为新的有用域。

## 有限样本插值的精确消去

对有限个实数对 (g_i,q_i)，存在上述共同 phi 的充要条件是：

```text
(q_i-q_j) * (g_i-g_j-q_i+q_j) >= 0       for every i,j.
```

必要性来自两输出差与输入差同号，且前者绝对值不超过后者。

充分性：当 g_i=g_j 时该式变为 -(q_i-q_j)^2>=0，故输出相同。将不同输入值排序为 t_1<...<t_k，相邻输出差满足 0<=v_(r+1)-v_r<=t_(r+1)-t_r。相邻点间作分段线性插值，每段斜率在 [0,1]，两端作常值延拓，即得全轴非降 1-Lipschitz 函数。排序是存在性证明，不是在验证时枚举源区间或相位。

所以，在这个函数类中，“来自同一个函数”的声明没有超出完整 pair sector 的高阶信息。它可能强于只保少数 pair 的实现，但不能据此宣布新的联合语义。这个等价结论不适用于任意更窄类，例如固定 GELU、已知导数值或指定曲率密度的函数类。

共同凸函数还要满足割线斜率次序，确实可增加三点关系；D118 已有共同段曲率、tent hull 和 smooth Peano 研究。不能把那个更窄函数类与本定理混同，也不能把既有曲率理论重复记为新域。

## ReLU 下回到旧图或损失幅值

给共同函数加锚点 (0,0)，并保留 ReLU 的 q_i>=0、q_i>=g_i。锚点 sector 为 q_i(g_i-q_i)>=0。g_i>=0 时要求 0<=q_i<=g_i，结合 epigraph 得 q_i=g_i；g_i<0 时结合 q_i>=0 只能 q_i=0。于是重新得到全部精确 ReLU 图。g_i=0 时输出为零，原两种合法相位标签仍须各自保留。

若删除 active epigraph 而只保原 sign guards、非负、off-mask、共同函数和可靠上界，则 phi(t)=ReLU(t)/2 已被允许。例取 x,y in [-1,1]：

```text
g_1=x+1/2, g_2=y-1/4
r=ReLU(-q_1+q_2+x/8+3/8)
```

在 x=y=0、原父标签 (1,0) 时，真实 q=(1/2,0)、r=0；共同函数外包允许 q=(1/4,0)、r=1/8。若采用子标签，真实为 0，伪点为 1，分别满足各自图。此为同一源点的幅值损失，不是整盒性质失败、实际回归实验或 ADV。保留完整原 active equality 会排除此点，但也恢复旧精确图。

## 共同函数查询不能免费变成 LP

显式全部 pair 表述含 N(N-1)/2 个二次 sector，仍保留 N 个幅值和完整源关系。这个数量是所列直接编码的费用，不是所有可能表示的复杂度下界。未知 g 的排序不能当作已知常数排序；保留因式形式也没有把二次关系变成原终端 LP 的线性行。新增乘积、线性外包、源系数展开、舍入和证据均须计费。

若已在整个源域上认证固定顺序 g_1<=...<=g_N，则相邻的 2(N-1) 条线性关系 0<=q_(i+1)-q_i<=g_(i+1)-g_i 足够。它是已知有序插值结构，不是无条件 CNN 闭包。点值排序可在 GPU 批量完成，不意味着不确定集合上的查询已获得同样算法或加速。

## 精确 GELU 与 SiLU 的折叠缺陷

以下 phi 分别指精确 erf-GELU G(t)=t Phi(t)，或 SiLU S(t)=t/(1+exp(-t))。Phi 为标准正态 CDF，varphi 为其密度。不要把 erf-GELU 与 tanh 近似混同。

```text
phi(t) = ReLU(t) - d(|t|)
d_G(a) = a Phi(-a)
d_S(a) = a/(1+exp(a))                 a>=0
```

两种 d 都非负，但不是全局单调。其导数为：

```text
d_G'(a) = Phi(-a)-a varphi(a)
d_S'(a) = 1/(1+exp(a))-a exp(a)/(1+exp(a))^2
```

两者上界为 1/2。第一种下界不低于 -1/sqrt(2*pi*e)>-1/2；第二种不低于 -a exp(-a)>=-1/e>-1/2。因此两种 d 均为 1/2-Lipschitz，由绝对值反三角关系得到：

```text
|d(|f|)-d(|h|)| <= (1/2) min(|f-h|,|f+h|).
```

这是本轮直接微分推导。不能由 |f|<=|h| 推出缺陷次序；两种导数在足够大 a 均为负。共享源上的和/差界须先合并实际仿射系数再认证，不得把近相反输入的缺陷直接视为相等。

基本偶性是已有结果：D109 已记录 phi(t)-phi(-t)=t；[Expand-and-Cluster 第 4 节](https://arxiv.org/pdf/2304.12794)也明确讨论 ReLU、GELU、SiLU 的 linear-plus-even 对称。原函数定义见 [GELU 原文第 2 节](https://arxiv.org/html/1606.08415v5#S2)。这里未采用参数恢复、训练、聚类或网络替换算法。

## 非平行三源 smooth 正控

取 x,y,z in [-1,1]，两个实际 smooth 门和一个 live affine skip：

```text
f=x+y/4+1/4, h=-f+z/100
q=S(f), p=S(h), J=q-p-f
r=ReLU(J-1/32)
```

两预激活并非精确相反；z 是真实变化的第三源坐标。SiLU 满足 S(t)-S(-t)=t，并且 |S'|<3/2：S'=sigmoid(t)+t sigmoid(t)(1-sigmoid(t))，第二项绝对值至多 |t|exp(-|t|)<=1/e，第一项在 [0,1]。于是对整个盒：

```text
J = S(-f)-S(-f+z/100)
|J| <= 3/200 < 1/32
r = 0.
```

这不使用输入采样、相位 split 或求解器，是直接共同源增量证明。

比较对象是两个完整 source-labelled 单门凸包的交，保留同一个显示源均值 (-1/4,0,0)。第一门用源 (1/4,0,0)、(-3/4,0,0) 各半，得到 f=+/-1/2；第二门用源 (-3/8,0,0)、(-1/8,0,0) 各半，得到 h=+/-1/8。四个源点都严格在盒内，预激活均非零。每个 pair 只证明对应一个 smooth 门的 hull，不假定两种分布相同。若另有合法 sign 标签，两者显示均值都为 1/2，但 smooth 本身不自带 ReLU bits。

共同显示 f=0，允许伪读出：

```text
J = (1/4)tanh(1/4) - (1/16)tanh(1/16)
  >= 11/192 > 1/32.
```

不等式使用 tanh(t)<=t、tanh(t)>=t-t^3/3，t>=0。后一式可由导数 1-tanh(t)^2>=1-t^2 积分得到。因此旧父集合允许后继真实图 r=J-1/32>0。这个比较没有给旧 child 一个免费的真实全网络最优标量界，也不比较完整两门联合 hull。它是严格解析控制，不是 benchmark CERT/ADV。

## 强参照已经能证明同一结果

上述证书直接来自原输出的反射恒等式和共同增量界，不需要物化 d 或 ReLU(f)。已有 D074 的余项反代原则及 D109 的 smooth 偶性已提供这种比较思路。若原 q、p 和源坐标已存在，|J|<=3/200 仅需两条线性行，每行内联本例后为 q、p、x、y 四个 nnz；只证明上界需要其中一条。其他原源谓词和全部输入/输出边界仍计费。

独立理想 smooth hull 一般不是四条线性行，不能虚报它的完整 LP 成本。精确保留每个 d 的图只是原标量图的重参数化；近相反时“共同锚缺陷加增量”仍需两个连续坐标才能保留两输出，尚无减维证明。纯 smooth 网络里分解使用的 ReLU 只是证明函数：若物化，它的幅值、原本不存在的选择位、守卫及绑定必须另付，不能冒充原网络免费节点或原 bit。

仿射/Conv/共享 Add 的系数可先在同一缺陷上合并，但下一任意 mixed 非线性会出现新的自变量，未证明仍由固定宽度的同一函数块闭合。因此本控制不足以启动 folded-defect 域实现。

## 对主线的实际决定

关闭这两个具体创新主张：共同未知 monotone-Lipschitz latent 自带高阶强度；共同折叠缺陷的小正控已经超越已有同源差分。不是关闭全部 shared-function 或 smooth 研究，也不是以“可编译成 HZ”作为拒绝理由。所有 PWA 表示最终可以有精确旧编码，真正需要证明的是有用的结构、传播和同口径代价优势。

下一候选不能只增加函数名称、对称恒等式或另一组有效行。它须明确固定真实非线性的哪些联合信息被有限共享因子保留，怎样被多个真实消费者使用，以及在下一非线性后如何控制费用。单门参考、完整同源 pair 参考和已知可直接生成的结构关系应在设计时就比较。普通结构适用性、GPU 数值、真实网络净增益仍待证，不能用本轮两个正负控制代替。
