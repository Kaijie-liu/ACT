# 共同源多门关系的固定构造与前向传递

本轮得到一个可直接构造的神经块关系：将负向贡献均分给全部正向项，保留残余的共同源仿射形式，再统一求 ReLU 上界。它不寻找最优匹配、不调用求解器、不展开相位乘积。一个普通四门例子严格强于本文列出的现有单门和成对比较，而且信息能进入下一原 ReLU。

基础不等式是已知的次可加性；D049已记录一般残余形式。本轮不是新凸性理论或已完成的新域。新交付限定为固定生成规则、强有限对照、有限前向传递及完整代价规格。尚无代码、数值执行、真实网络收益或GPU资格。

## 非凸载体和关系的含义

保留原HZ的连续因子xi、全部原二元因子b、EQ/LE谓词、共享frame、原输出及输入decoder。若原bit用正负一编码，只通过认证的仿射视图取得active bit，不删除或替换原因子。原门预激活为零时，两种合法相位都保留。

设z是同一原frame上的已认证物理frontier，带可靠盒界。它可以是更早的非线性输出，不要求它是原输入的仿射函数。下面g_i(z)、h_j(z)须确为这个frontier上的仿射式，q_i=ReLU(g_i)、p_j=ReLU(h_j)是原网络已有门，包含各自原bits及门谓词。

关系记录保存实际读出F、同源仿射上下式L和U，以及其构造证书。候选元素N=(H,relations)的具体化是在同一个原赋值上满足H及全部L<=F<=U的输出集合。空关系嵌入原HZ；下文健全性保证有证关系不改变原整数集合和decoder。查询LP保留全部旧行并增加有效行，因而外包不扩大。这里的非凸性来自原二元谓词，不来自仿射包络。

这个接口可由既有D049混合观察语言表达，不能仅凭新名称称为定义创新。可能值得检验的贡献是整个神经块的可构造抽象变换，而不是原HZ无法表达的集合。

## 无需寻找运输矩阵的统一构造

对一个实际混权读出，先把权重正负分开：

```text
F = sum_i a_i*q_i - sum_j d_j*p_j,  a_i,d_j>0.
m = 正向项数量
A(z) = (sum_j d_j*h_j(z))/m
e_i(z) = a_i*g_i(z)-A(z).
```

这里按数学系数符号分组，不按实例、家族、性质、margin或求解状态。不同原门不能因数值相同就合并身份。m=0时F<=0直接成立；无负项时A=0。所有原消费者和原门仍保留。

由ReLU的正齐次与次可加性，逐i有

```text
a_i*q_i = ReLU(A+e_i) <= ReLU(A)+ReLU(e_i).
m*ReLU(A) = ReLU(sum_j d_j*h_j) <= sum_j d_j*p_j.
```

相加并取消同一负向贡献，得到

```text
F <= sum_i ReLU(e_i).                                      (1)
```

这等价于固定非负运输系数T_ij=d_j/m，但实现不需要存m乘n的矩阵。证明不用输入或相位枚举。原门零点照样满足次可加关系。

对每个实际仿射e_i先在共同盒上取得可靠[l_i,u_i]，统一选其上包络：u_i<=0取0；l_i>=0取e_i；其余取u_i*(e_i-l_i)/(u_i-l_i)。记为S_i(z)，则

```text
U_F(z) = sum_i S_i(z),          F <= U_F(z).                 (2)
```

关键是先在同一z上合并这些仿射式，再对所需读出求界；不能先分别把S_i变成标量上界。下界对-F执行完全相同规则，得L_F=-U_(-F)。这是上、下界的同一构造，不是多个候选路径中挑选成绩。

既有[D049的一般残余式](../d049_mixed_source_envelopes_20260930/ALTERNATIVES.md)已经蕴含(1)的逐项逻辑。当前增加的是无需oracle的固定共同A和一个明确的整块使用方式；没有声称超出任意D029残余观察或所有多神经元表述。

## 可靠区间参数的保守版本

不能把BN参数中点当作实际网络。若接收权重w_k只知可靠区间，固定中点wbar_k仅用于确定上述构造。对实际原非负激活v_k及可靠上界M_k，设rho_k包住|w_k-wbar_k|，则实际F与参考加权读出Fbar满足

```text
|F-Fbar| <= epsilon_w = sum_k rho_k*M_k.
```

原v_k仍是实际网络的原输出，不是参考网络的激活。用wbar构造的残余，其预激活参数若也为区间，直接在共同源上形成残余系数区间。令其中心仿射式为ebar_i，系数和偏置半径为rho_it、rho_i0，则

```text
Delta_i = rho_i0 + sum_t rho_it*max(|L_t|,|U_t|)
e_i(z) <= ebar_i(z)+Delta_i.
```

利用单调性，对ebar_i+Delta_i求上面的可靠secant，最后增加epsilon_w，即为实际F上界。下界仍对-F同样处理。忽略参数间相关性可能放宽，但不能缩小真实集合。全部区间来源、浮点外向误差及每步资源检查尚须实现认证；本段是数学规格，不是已有GPU实现。

## 前向传递和范围

同源Affine或Conv的读出，按权重正负合并已有上下式；偏置只计一次。Add在同一个赋值上合流，Concat保持原身份。这里不会把残差分支复制成独立输入。

对下一原门t=ReLU(v)，若已得到v<=B(z)，则t<=ReLU(B(z))；对B使用相同可靠上包络即可得到t的仿射上界。保留t的原bit、门行和旧界，不新建残余门或替代相位。如果B在盒上非负，直接t<=B。

这给出健全而非无损的有限前向闭包。并未证明任意深度保持固定支持宽度；更深层可以在新的原frontier重新构造关系，但必须支付实际系数、共享身份和原谓词。仅保存F和A也不足以恢复任意后继混权，此点仍受D049已有反例约束。

## 普通四门控制

设x,y属于[-1,1]，全部四门保留不同的原bits：

```text
h1=x,                    p1=ReLU(h1)
h2=-y,                   p2=ReLU(h2)
g1=(13/20)x-(2/5)y+1/10,  q1=ReLU(g1)
g2=(2/5)x-(57/100)y+1/5,  q2=ReLU(g2)
F=q1+q2-p1-p2.
```

正向两个项使用固定A=(x-y)/2。因此

```text
e1=3x/20+y/10+1/10,     [l1,u1]=[-3/20,7/20]
e2=-x/10-7y/100+1/5,    [l2,u2]=[3/100,37/100].
```

固定secant给ReLU(e1)<=21x/200+7y/100+7/40，而ReLU(e2)=e2。合并共同源后得到

```text
F <= 3/8+x/200.                                           (3)
```

若先分别取残余标量上界，则只得F<=7/20+37/100=18/25；正是提前丢掉共同源取消使这一界更弱。这里无需准确系数抵消来保证健全性：残余本身均非恒定，第二项严格正，第一项严格crossing，结论及下述严格比较有扰动余量。精确行系数随实际参数变化，不固定声称扰动后仍是(3)原数值。

最终比较点为

```text
x=-1/20, y=1/20
q1=7/20, q2=137/400, p1=p2=0
alpha_g1=alpha_g2=1/2, alpha_h1=alpha_h2=0.
```

各预激活均非零，g1=19/400、g2=303/2000、h1=h2=-1/20。每个门分别属于保留完整源和原标签的单门凸包：

- g1门以源(4/7,-4/7)和(-47/70,47/70)各半混合，预激活为7/10和-121/200，给出q1=7/20及相同源均值。
- g2门以(1/2,-1/2)和(-3/5,3/5)各半混合，预激活为137/200和-191/500，给出q2=137/400及相同源均值。
- 两个h门使用该均值上的真实不激活点。

所有分量严格位于输入盒内部，相关门的预激活严格有符号。这是解析松弛反例，不是采样、攻击或具体ADV。

## 下一原门上的安全性质分离

接普通混权残差门

```text
s=ReLU(2F+x/10-y/10-1/2), 原bit gamma保留.
```

由(3)，其预激活不超过B=1/4+11x/100-y/10，且B在整个盒上属于[1/25,23/50]，严格非负。因此

```text
s <= B <= 23/50 < 1/2.
```

旧比较点可取精确child输出s=7/8、gamma=1。这不是给child另造松弛：只要其输入域就是上述旧父多面体，该点本就在child真实图上，也在该域上的child完整凸包中。不能外推为生产ACT已经允许此点；其他未列出的真实前提可能排除它。

此child不是稳定门。真实源(1/2,-1/2)给预激活11/50>0，真实源(-1,1)给-7/10<0。故这个局部网络的安全性质s<=1/2由新关系证明，而所列强旧比较不能证明。仍是解析控制，不是2413或400回放中的新CERT。

## 完整成本与设备形式

对一个k项读出，m个正项、n个负项，d为实际共同source支持并集大小，原forms总非零出现数为S。构造A需O(S_neg)合并；形成m个残余及求界需O(S_pos+m*d)，不能写成只需O(k)。最后合并secants再需实际残余支持总数。无需m*n运输矩阵、线性规划或相位遍历。

上述是单上方向的算术拆账；全输入检查和epsilon_w还需O(k)。上下两方向合计为O(k+S+(m+n)*d)，稀疏规范化、精确系数位复杂度、来源验证及证据保存另外计入，不能把有理运算当成常数时间GPU指令。

逐残余流式处理时，除只读原参数和forms外，A、当前残余、U三个source形式可用O(d)工作存储；全部端点、证书、区间误差、引用及输出保存仍另计。若实现选择物化m*d张量以便GPU并行，峰值也必须按m*d计，不能同时声称流式峰值。

每个方向产生一条F<=U行，物理坐标支持至多k+d；上下两方向最多两条。若F已经是已有接收预激活减偏置，可复用该坐标而不展开k个父输出，但其原等式及support不能免账。控制(3)为一条5nnz；child上界一条3nnz；没有新增连续量或bits。真实latent展开、EQ后端slack、所有原谓词、A与A转置、终端决策及见证验证完整计费。

卷积上可按同一原receiver的全部canonical fan-in统一执行；也可以研究另行预注册的固定结构分组，但不能看到结果后挑组。本轮没有选择或执行新的分组实验。每个receiver的source并集可能很宽，当前不声称足以通过四并发门。

算术形式是同源稀疏加权归约、广播残余、盒支持、secant和再次归约，适合研究GPU批处理。但Fraction证明不是浮点/GPU资格；参数外向误差、归约、CPU设备共存、传输及原终端成本尚未实现或测量。

## 研究决定

保留这条规则作为已知关系语言中更具体的神经块算子候选，不立即部署或为其创建“新域已完成”的名称。它比仅改存储多出了可证明的查询信息；但定义新颖性、普通结构频率、相对native非冗余和完整成本仍待证明。

下一步若实现，须新预注册默认关闭组件，覆盖共同源身份、区间参数、零相位、强控制和全部继承人口；数学资格之后才可进入完整真实同结构研究。D057及其他已消耗版本不重跑，不缩人口或放宽冻结预算。正式1870/2413和独立61/400不变。
