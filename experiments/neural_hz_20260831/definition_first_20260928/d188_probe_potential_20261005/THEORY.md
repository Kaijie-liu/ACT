# 输出探针势函数与共同校正关系

本轮从完整激活读出定义出发，检查能否不用 D187 的逐源乘积矩阵而保留联合关系。得到精确恒等式及一个排除廉价实现的比较定理；没有得到可晋级的新 Neural-HZ。原网络仍使用原 ReLU，不以平滑激活替换被验证网络。

## 数学对象与边界

令 P 是当前整个抽象父域，S 属于 P 表示其中一个成员，g(S) 是新一组预激活，C 包含这些新激活的全部实际消费者。保留父状态的连续源、全部原有 signed bits、EQ/LE、frame 身份、输入 decoder，以及新门的原二元相位与符号 guards。下文 beta=(signed_bit+1)/2 仅为记号，不放松或删除原 bits。零点允许原来的两个合法标签。

固定 S，定义辅助输出探针 v 上的凸函数：

```text
phi(t) = ReLU(t)^2 / 2
Psi_S(v) = sum_i phi(g_i(S) + (C^T v)_i)
grad_v Psi_S(0) = C ReLU(g(S)) = y.
```

凸性发生在探针变量 v 上，不是声称混权输出 y 是原源上的凸梯度；因此没有重复 D170 已反证的源梯度假设。所有方向和尺度必须按结构固定，不能按标签、实例、margin、求解状态或对偶选择。这里的探针不是输入采样或攻击。

上述等式本身只是准确描述真实输出，尚不是可执行抽象域定义：若把梯度或势函数求值交给免费 oracle，就把原有非线性查询隐藏起来了。有限可构造的谓词、终端降级、递归健全性及完整费用仍是必要部分。

仿射读出 y_new=B*y+r(S) 有精确代数变换：

```text
Psi_new(v) = Psi_S(B^T v) + r(S)^T v.
```

多组读出相加可在同一个父状态上相加这些势函数。已有有限探针集合通常不包含新的 B^T v，故不声称有限表示免费仿射闭包。后继 ReLU 必须覆盖整个新抽象父域，包括额外非具体轨迹成员，不能只在真实网络轨迹上证明。

## 固定方向的精确中心恒等式

固定 u、tau>0，记 c=C^T u；c_i=0 的项直接省略。凸性先给出普通割线界：

```text
L = [Psi(0)-Psi(-tau*u)]/tau <= u^T y
U = [Psi(tau*u)-Psi(0)]/tau  >= u^T y
U-L <= tau * ||c||_2^2.
```

最后一项由沿该方向的一维二阶导数几乎处处处于 [0,||c||²] 得到。需要同一个 S 上的势函数值；若只知道上下包络，差值的减项必须使用相反方向的包络，不能混用不同存在见证。

中心差商有更具体的精确式。令 a_i=tau*|c_i|：

```text
D_tau(u) = [Psi(tau*u)-Psi(-tau*u)]/(2*tau)
D_tau(u) - u^T y
  = sum_(c_i!=0) sign(c_i)/(4*tau) * (a_i-|g_i|)_+^2.
```

证明只需逐项对照以下分段式，再乘 c_i 求和：

```text
S_a(g) = [phi(g+a)-phi(g-a)]/(2*a)
       = (1/(2*a)) * integral_(-a)^a ReLU(g+t) dt
       = 0                 if g<=-a
         (g+a)^2/(4*a)     if |g|<=a
         g                 if g>=a
S_a(g)-ReLU(g) = (a-|g|)_+^2/(4*a).
```

因此一个不再追踪校正依赖的健全外包是：

```text
D_tau - tau/4 * sum_(c_i>0)c_i^2 <= u^T y
u^T y <= D_tau + tau/4 * sum_(c_i<0)c_i^2.
```

这个区间的统一最坏宽度为 tau*||c||²/4，是前述最坏宽度上界的四分之一，但不逐点支配普通割线界。例如 g=-1,c=1,tau=1/2 时，割线界是 [0,0]，中心规则加全局误差盒是 [-1/8,0]。可相交，但 Psi(0) 及两套关系的费用都须计入。

若整个父域认证每项 |g_i|>=a_i，则该项中心误差恒零；只在一个点满足不够。此处不建议靠 tau 趋零或极端数值调参推进研究。

## 已知原理与可构造的带内情形

S_a 正是已有的 SmeLU：其分段式和 ReLU 的均匀卷积解释见 Shamir、Lin 的[原论文第5.1节、式7](https://arxiv.org/html/2202.06499v1#S5.SS1)。因此不能把该平滑函数本身宣称为 Neural-HZ 创新。

若统一认证 a_i>=sup_S |g_i(S)|，则整个父域处于上述二次段，不需要未知的 shifted-ReLU 相位求值：

```text
D_tau(u) = (c^T g)/2
         + (1/(4*tau))*sum_(c_i!=0) sign(c_i)*g_i^2
         + (tau/4)*sum_(c_i!=0) sign(c_i)*c_i^2.
S_a(g)-a/4 <= ReLU(g) <= S_a(g).
```

这是可以直接构造的平方能量关系，与 |g|<=(g²+a²)/(2a) 的常规上界一致。共享源的二次项必须先合并再取界，不能丢弃抵消；也不声称这些联合平方界都被 D156 的任意有限行集支配。原理已知不等于所有可组合实现都无价值，但本轮没有取得这种实现优势。

一般情形每个不同 (原预激活身份, a_i) 都可能需要一个平滑值。相同宽度与身份可以共享；例如本轮两个绝对值全为1的消费者方向，共用 m 个平滑值即可，不是2mp个独立 shifted gates。对于 t 个一般方向，记方向矩阵为 U_probe=[u_1,...,u_t]，去重前数量可达 nnz(C^T U_probe)。不能只计 p 个读出而不计这些内部值。

二次段在非退化区间上的精确曲线，不可能由有限二元变量和有限线性 EQ/LE 的投影精确表示：后者是有限个多面体的并。可以研究原生非线性谓词，但普通终端需要健全、可付的降级；本轮不授权增加 QP、非线性优化器或另一个验证器。

完整费用还包括源系数展开、Gram 填充、校正与相位关系、全部消费者、继承谓词、可靠浮点界、host/device副本、GPU终端及具体输入重构。矩阵算术能上GPU不等于查询已上GPU或验证已加速。

## 决定下一步的限制

只有跨门、源与校正之间的共同关系可能产生此路线的额外价值。将它们拆成逐门凸包和独立误差盒，连旧 triangle 投影都无法加强，证明与普通后继失败控制见 [比较记录](COMPARISON.md)。因此本轮不实施该廉价版本，也不扩大探针数量来替代新的联合语义。
