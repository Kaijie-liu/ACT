# 独立校正不能加强旧凸包

本文件区分旧单门连续凸包、保留整数相位的精确 HZ，以及仅保留分组关系的候选，避免把弱比较对象偷换成旧精确图。

## 对任意区间和宽度的投影包含定理

令 R(g)=ReLU(g)，源区间为 [L,U]，L<U；ell_R 是端点弦。旧单门 triangle 是：

```text
R(g) <= q <= ell_R(g), L<=g<=U.
```

取任意 a>0，S_a 如 [势函数定义](THEORY.md)，ell_S 为其端点弦。即使免费提供平滑图的精确标量凸包，考虑以下廉价校正表示：

```text
S_a(g) <= h <= ell_S(g)
0 <= e <= a/4
q_new = h-e.
```

则每个旧 triangle 点 (g,q) 都能扩展到该表示。取

```text
h=max(q,S_a(g)), e=h-q.
```

证明：S_a 是凸函数且 S_a>=R，所以 ell_S>=ell_R。由 q<=ell_R 与 S_a<=ell_S 得 h<=ell_S。若 h=q 则 e=0；否则 e=S_a-q<=S_a-R<=a/4。因此 q_new=q，所有新行成立。L=U 的退化区间也直接成立。

这个构造可对所有门同时进行，保留同一个源、原输出、混权读出及 skip。任何只依赖原 g、q、beta 的已保留关系都不改变。相同身份和宽度复用同一个 h,e；对任意有限个不同宽度分别添加这种独立外包，也能同时扩展同一个 q。故不能靠增加这类探针来加强旧 triangle 投影。

限定：此定理不涉及额外的跨门或跨宽度共同谓词，不涉及精确势函数等式，也不否定与源/相位相关的更强校正关系。beta 符号 guards 可以原样保留，但 fractional triangle 点不是整数精确 HZ 的成员。若完整逐门精确 beta-amplitude 图也保留，平滑扩展不改变其整数集合精度；不能把保留旧图的费用漏掉。这不等于否定所有冗余关系的计算价值：原生有效关系仍可能改善某个有限 LP 外包或有预算查询，本定理只排除明确指定的独立平滑凸包加误差盒。

## 普通四门、混权和后继 ReLU

使用两个连续源 x,y 属于 [0,1]²；所有四门 crossing，无极端系数、零点标签争议或输入采样搜索：

```text
g1=2*x+y-11/10       in [-11/10,19/10]
g2=x/2+y-11/10       in [-11/10,2/5]
g3=3*x/4+y-23/20     in [-23/20,3/5]
g4=3*x/2+y-21/20     in [-21/20,29/20]
q_i=ReLU(g_i)
R_plus=q1+q2, R_minus=q3+q4
Q=R_plus+R_minus, B=R_plus-R_minus
h_child=ReLU(R_plus-23*x/10-1/100).
```

完整消费者为 C 的两行 (1,1,1,1)、(1,1,-1,-1)。R_plus/minus 是 (Q±B)/2 的缩写。比较的弱分组候选保留原 g/beta guards，以及每组的四种聚合后果：

```text
R_group >= 0
R_group >= sum_group g_i
R_group <= sum_group U_i*beta_i
R_group <= sum_group [g_i-L_i*(1-beta_i)].
```

不额外保留每门幅值及其精确相位绑定。若保留后者，下面伪点立即被旧精确图排除，必须照实计费。

全父域的强旧对照很简单：q1<=19*x/10、q2<=2*x/5。因为 x>=0，而且 g1-19*x/10=g2-2*x/5=x/10+y-11/10<=0。故 R_plus<=23*x/10，真实后继恒为0。这是一条源相关前向证明，不是 helper 或对偶救援。

在严格普通点 x=1/5,y=9/10：

```text
g=(1/5,-1/10,-1/10,3/20), beta=(1,0,0,1)
true: R_plus=1/5, R_minus=3/20, Q=7/20, B=1/20
fake: R_plus=49/100, R_minus=3/20, Q=16/25, B=17/50
fake h_child=1/50.
```

伪点通过上述 guards 和四行分组外包；它不是具体反例或正式 ADV。

## 中心规则的局部加强与普通尺度失败

在同一个点使用固定方向 e_Q,e_B，Psi(0)=1/32。tau=1/2 时：

```text
Psi(+tau*e_Q)=493/800, Psi(-tau*e_Q)=0
Psi(+tau*e_B)=13/40,   Psi(-tau*e_B)=233/800
ordinary secants: Q in [1/16,117/100], B in [-13/25,47/80]
central: Q in [93/800,493/800], B in [-173/800,227/800].
```

普通割线允许伪点，中心规则排除它；中心界还给该点 R_plus<=9/20。这只是局部的有限关系加强，不能当作整个父域新 CERT，更不能忽略获得 Psi 精确共同值的费用。

同一个伪点在普通固定尺度 tau=1 的中心外包中仍通过：

```text
D_Q=1753/1600, D_B=47/1600
Q in [153/1600,1753/1600]
B in [-753/1600,847/1600].
```

更重要的是，tau=2 对整个父盒认证 a_i=2>=|g_i|，进入无需 shifted oracle 的显式二次构造。仍在同一点：

```text
D_Q=6673/3200, D_B=87/3200
Q in [273/3200,6673/3200]
B in [-3113/3200,3287/3200].
```

伪点仍通过。两个方向可以共用每门校正 e_i 属于 [0,1/2]，这个共享也不足：plus 组所需校正为453/800，minus为2813/3200，均在组总盒 [0,1] 内。可将各组所需量均分给两个门，得到共同校正见证。此处只有组幅值与原符号 guards；没有额外声称每个 S_2(g_i)-e_i 都满足原逐门 beta-amplitude 等式。

因此失败不依赖隐含势函数 oracle、小尺度数值极限或特殊极端输入。该便宜联合盒对普通完整后继仍弱于已知的一条源关系。另一方面，这也不证明所有共同平方/相位谓词都无用；被排除的是本文件精确定义的便宜版本。
