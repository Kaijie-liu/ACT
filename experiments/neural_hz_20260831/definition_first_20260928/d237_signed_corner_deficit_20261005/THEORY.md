# 混号残差下的共享相位参考与幅值缺额

本轮得到一个不要求子幅值受单个父相位支配的有限关系。它在普通混号、非零共同残差结构上，排除了“各局部完整凸包相交”仍接受的物理伪状态，并能由有限行证明一个实际后继为零。它扩展了D235的适用合同，但仍使用已知的条件乘积、ReLU单调性和Lipschitz性质；不能据此宣布新的完整抽象域或外部新颖性。真实适用性由独立预注册诊断决定。

## 域元素和统一参考规则

保留完整原HZ H的连续源、全部原signed bits、EQ/LE、共享latent/frame、所有读出与输入decoder。alpha_i是原父相位的0/1视图。对原父幅值用可靠正上界规范化，记0<=q_i<=alpha_i，p_i=alpha_i-q_i>=0。规范化不改变原源或bits。实际接收门为

```text
y=R(a*q1+b*q2+z).
```

a,b可混号；z是同一个H上的真实仿射读出，完整保留其来源和其他消费者。要求全父域上可靠的四个参考 `z,z+a,z+b,z+a+b` 各自符号稳定。令F_uv(z)=R(z+a*u+b*v)，u,v属于{0,1}；每个F在此合同下是已知仿射式或0。这里没有创建四个源子域、相位搜索或点池，仅生成固定四项代数式。零参考值可用任一相同幅值表达式，但不固定或删除原门的零标签。

定义共享delta=alpha1*alpha2及需要的条件残差观察，得到

```text
Ystar=F00+(F10-F00)*alpha1+(F01-F00)*alpha2
      +(F11-F10-F01+F00)*delta.
```

原整数赋值下，Ystar恰为R(a*alpha1+b*alpha2+z)。delta及alpha1*z、alpha2*z、delta*z均作为连续观察，以可靠界的四行乘积约束编码；delta由原整数bits唯一决定为0或1，所以delta*z在原整数语义下同样精确。必须按相同源/事件身份共享，不允许每个消费者选一个副本。空观察精确嵌入原HZ，加入正确关系不改变原整数图；语义包含可定义偏序，不声称最佳抽象或完整格。

令a_plus=max(a,0)、a_minus=max(-a,0)，b同理，统一增加

```text
-a_plus*p1-b_plus*p2 <= y-Ystar <= a_minus*p1+b_minus*p2.       (C)
```

证明：实际预激活与参考预激活之差为-a*p1-b*p2。ReLU单调且1-Lipschitz，因此负向变化至多由正系数缺额支付，正向变化至多由负系数缺额支付。证明覆盖全父域，包括q=0但原alpha=1的合法零标签，不要求参考角可由原输入达到，也不要求任何child bit蕴含父bit。

本式可继续乘已登记的原事件，但必须新增并支付所需观察，不能从已有均值恢复高阶乘积。全整数语义不变，连续查询的收紧仍须明确与哪一组有限关系比较。

## 无单父支配的普通跨层控制

令x1,x2,t属于[-1,1]，保留原父门qi=R(xi)，定义

```text
z=1/4+t/20,
y1=R(q1-q2+z),  y2=R(q2-q1+z),
D=2*q1-x1+2*q2-x2,
F=D+(y1-y2-(5/8)*(x1-x2))/2,
r=R(F-61/30).
```

所有旧源、两个父、两个child及最后门均被完整读出使用。z属于[1/5,3/10]，四参考z、z+1、z-1、z均严格稳定。两个child在alpha1=alpha2=0时仍等于正z，所以没有任一父相位支配其正幅值；两门在完整源上也确实跨零。

记w_i=alpha_i*z、v=delta*z，则共同参考为

```text
Y1star=z+alpha1-delta-w2+v,
Y2star=z+alpha2-delta-w1+v,
-p1<=y1-Y1star<=p2,
-p2<=y2-Y2star<=p1.                                      (P)
```

这些是本统一规则直接生成的四条行，不是看到终端F后才选择的答案。它们保留两个独立child的完整读出；下面的差分中delta和v恰好相消，不据此声称其他消费者也能免费删除它们。

令n_i=1-alpha_i-q_i+xi。原父四行图给n_i>=0、p_i>=0，并有

```text
xi=2*alpha_i-1-p_i+n_i,
D=2-p1-n1-p2-n2.
```

由(P)的第一门上界和第二门下界，有

```text
y1-y2<=alpha1-alpha2+w1-w2+2*p2.
```

只用同一z上的两个完整McCormick产品包络即可推出

```text
w1-w2-(alpha1-alpha2)/4<=1/20.
```

具体证明为：将w1<=U*alpha1、w1<=z-L*(1-alpha1)、w2>=L*alpha2、w2>=z-U*(1-alpha2)相加，除以2，代入L=1/5、U=3/10。这是有限线性系统的后果，不假定当前松弛赋值来自某个真实分布。

代入F，得到完整有限证书

```text
F <=81/40-11*p1/16-21*n1/16-5*p2/16-11*n2/16 <=81/40.
```

真实(x1,x2,t)=(1,-1,1)达到81/40。因此该方向精确，实际后继预激活至多-1/120，r恒为0。只有查询松弛在比较中允许分数bits；原生域所有bits仍为整数。

## 同时通过多个完整局部凸包的物理伪状态

取u=99/100，显示点为

```text
x1=x2=t=0, alpha1=alpha2=1/2, q1=q2=u/2,
z=1/4, y1=28/75, y2=1/4, gamma1=5/6, gamma2=1.
```

gamma是两个原child bits的0/1查询视图。该点F=49/24，故在只接下一门自身图时允许r=1/120。这不是具体输入、ADV或新验证解。

比较集合同时保留以下因子的全部有效线性关系，并共享所有列出的物理坐标和原bits：完整父联合带标签图；每个“两个父真图、原输入和该child及原bits”的完整凸包；以及两个child在完整(q1,q2,z)盒上的联合带标签图凸包。下列真点混合分别证明成员资格，没有运行采样或求解器。

对第一child的完整前缀，原x四角为(±u,±u)，t=0；令00、11的质量各为1/3，10、01的质量各为1/6。其共同源均值0，q均值u/2，y1均值28/75，gamma1均值5/6。对第二child前缀，用00、11各半，得到同样源/父均值，y2=1/4、gamma2=1。两者的父联合二阶事件质量不同，正是只共享一阶列不能恢复的关系。

对两个child的联合feature因子，取5/6质量在(q1,q2,z)=(3u/5,2u/5,1/4)，另1/6在(0,u,1/4)。第一点两门严格active，幅值为56/125和13/250；第二点幅值为0和31/25，原bits为0、1。均值正是上述q,y,gamma。全部child预激活非零，原输入见证也非极端数值病态。

还可以把child比较加强为“先取完整父带标签图凸包，再对两child同时接精确图，最后取完整凸包”。上面的第一feature原子可配父状态 `alpha=(3/5,2/5), x=(u/5,-u/5)`，它由父真角10、01以3/5、2/5混合得到；第二原子就是父真角01。再按5/6、1/6混合，其全部父源、相位、幅值与child均值都是显示点。因此即使同时交入这个更强因子及两个完整单child前缀因子，点仍存在。

所以该比较集合的物理上界至少49/24，严格超过新有限证书81/40，差1/60。比较不是只让辅助矩不同；同一个实际F和下一r受影响。所有仅在某一个完整parent-to-child前缀中有效的幅值关系也不能排除它，因为该前缀的完整hull已经接受。但比较不包括跨两个完整前缀的所有共同条件矩、递归生成的全部新事实或完整跨层RLT，不能声称击败这些更强参照。

## 完整费用及组合范围

单一一般残差z已具有独立物理坐标时，共同delta及三个残差产品至多4个连续列。标准乘积包络共16LE、至多38个左侧nnz，(C)两行各至多10nnz，所以局部上界为4列、18LE、58nnz。数目采用0/1记法，原signed bits只做仿射代换；原H、原门和bits、RHS、后端slack、可靠界、身份认证和decoder另计。z若内联有s项，须计每次展开，或另付一个连续别名、一条EQ和s+1nnz；不能把长残差当免费标量。

上述双child控制共享同一个delta、w1、w2、v：4列、16LE/38nnz，加四条缺额行共28nnz，即4列、20LE、66nnz。规范化、全部源和消费者、原关系、终端矩阵和求解、证据、host/device共存与输入重构都另外计费。没有实测内存或速度资格。

Affine/Conv/Add/Concat对同一身份的观察作线性组合，精确消费当前元素；新增ReLU可以对其整个父域重复同一出生规则，不能只在原网络真轨迹上认证参考符号。新pair、不同残差及后续条件化会新增乘积和来源费用；没有固定宽度或无损深层闭包定理，也不证明完整全网查询单调不退。

可靠参数区间可以认证四参考符号，但实际系数仍是同一模型参数；不能在不同参考项中任选区间值，或将区间中点当精确系数。当前实际诊断只检查充分条件，没有生成生产可用精确行或native绑定证书。

## 新颖性与实现决定

ReLU单调性、二元多线性展开和条件产品均是已知数学。Sharp Hybrid Zonotopes第二节与第四节已将RLT用于HZ并保持原整数集合；本研究没有采用其完整层级、分支流程或增加求解器。[原论文](https://arxiv.org/html/2503.17483v2)

包含同样有效缺额行及其条件化的强RLT参照会覆盖本规则。仅有D236的全局L/U四条件门行，不自动包含更紧的参考符号和幅值缺额关系；不能混淆这两种参照。当前控制也能由(P)相减后的直接源相位行追平，因而完整四列因子不是唯一可能的高效实现。新颖性仍需要证明统一演算在真实结构中的完整精度与成本优势，而非靠多存几个产品变量。

与D235相比，具体新增证据是任意混号系数的有限参考合同、真实残差绑定、无需单父正幅值支配的强物理控制及其全源线性证书。它既不是存储优化，也不是成熟新域的完成证明。若真实前提诊断不命中跨零接收行，不为该人口实现这条单独规则；不得用稳定行数量替代能力。原数学门、真实同结构、shadow、逐家族、2413及独立400回放均仍待履行。
