# 完整神经接口与源条件纤维的定义边界

本轮审查当前 Neural-HZ 候选是否适合真实普通残差结构，而不是继续改进一个小型控制上的 support helper。结论是：D157 的字面完整消费者规则在三个已存 CNN 首块上均不减少幅度数；large 的 identity skip 还使原生关系退回精确旧门图。medium 和 Tiny 存在无需数值秩判定的完整接口因子化，但它是可复用支撑，不是新域定义。把预算改成当前源的精确能量也不是新候选，且没有解决源绑定与线性终端之间的缺口。

以下是静读旧工件后的纸面证明，经独立审查；不是新模型执行、机器证明、组件资格、速度结果或新增 CERT/ADV。没有实施新候选。所有原连续源、原二元相位、EQ/LE、共享 frame、输入 decoder、零点双标签与 fail-closed 边界保持不变。

## 完整消费者决定当前候选的实际规模

直接来源是 D120 已完成的 [large](../../results/d120_mixed_consumer_source_20261002_v1/complete_0.json)、[medium](../../results/d120_mixed_consumer_source_20261002_v1/complete_1.json)、[Tiny](../../results/d120_mixed_consumer_source_20261002_v1/complete_2.json)，以及已归档的 [D149 来源边界](../d149_overlap_phase_fiber_20261004/SOURCE_BOUNDARY.md)。本轮只读其中的形状、stride、padding 和消费者身份，不重新解码模型或计算新网络界。

设 m 为新 ReLU 的门数，r 为全部当前线性消费者输出数。冻结 D157 规定 C=[B;ones]，只复用字面相同的 ones 行；其新增行数为 2m+10p+2r，其中 p=rows(C)。一个 Conv3 行最多涉及 576 个原 q 坐标，shortcut 行最多涉及 64 个，identity 行只涉及一个。三者 m 均大于 576，因此没有这些局部行可以等于全层 ones，mass 行必须新增。

| 首块 | m | 全部消费者 r | 字面接口 p | D157 新增行数 |
| --- | ---: | ---: | ---: | ---: |
| CIFAR100 large | 65536 | 131072 | 131073 | 1703946 |
| CIFAR100 medium | 14400 | 16384 | 16385 | 225418 |
| TinyImageNet medium | 46656 | 50176 | 50177 | 695434 |

这些是冻结公式的结构代入，不是现有小型 API 已经运行过这些规模，也不是实际分配字节或时间。旧谓词、原源、各 bank、读出、重构和终端费用仍在表外，不能据此宣称物理资格。原 source worker 的预算和完整内存边界没有修改。

large 的原 ReLU_2 输出127同时进入 Conv_3 和 Add_8，后者直接保留全部 q。因此 B 包含 I_m，C 满列秩。D156 的共同代理满足

```text
C dhat = C d,   ||dhat||^2 <= E,
a = C diag(beta) dhat.
```

这里 ker(C)=0，故 dhat=d。原生语义回到精确 gated graph，不能再以联合幅度替代带来有损压缩。这个结论只针对该活 q 接口；Add_8 的后继 Add_14 保留旧源133，不能偷换成 ReLU_11 输出136的 identity skip。

更强的是，显式 identity 行在 D157 的有限 lowering 中也保留旧图。对 crossing 门，写 s_i=g_i-gbar_i、a_i=q_i-beta_i*gbar_i。四条 phase-refined caps 等价于

```text
0 <= q_i <= U_i beta_i,
L_i(1-beta_i) <= g_i-q_i <= 0.
```

这正是原四行 ReLU；两边即使放到相同分数相位外包中也相同。额外的 guards、mass 和 energy 行叠在其上，不能把此情形叫作已经移除了旧门图的新关系替换。一般只有 C 注入、但不显式含 I 的情况，不能自动套用这项逐行有限等价结论。

## 投影 shortcut 仍有完整的因子化机会

medium 与 Tiny 不是 large 的同一种结构。它们的首 ReLU 有主 Conv3 和 stride-2 的 1×1 shortcut Conv8。令 S 选择 shortcut 几何读取的全部64通道位置，W_s 是这些位置上的通道映射，则 shortcut 的线性部分为 W_s S。BN 缩放可在认证后并入 W_s，偏置必须另留在常数或同源仿射读出中。

medium 的 S 有 64×8×8=4096 行，主 Conv 有8192行；Tiny 的 S 有64×14×14=12544行，主 Conv 有25088行。因此不需要任何数值权重或秩假设，就有

```text
rank([B_main; W_s S; ones]) <= rows(B_main)+rows(S)+1,
medium: rank(C) <= 12289 < 14400,
Tiny:   rank(C) <= 37633 < 46656.
```

核维至少分别为2111和9023。这是几何结构上界，不是实际秩、实际源误差或精度回退的测量；“矩阵较高”不能在这里推出注入。

可以选择完整载体

```text
C0 = [B_main; S; ones],
B = [B_main; W_s S] = F_B C0,
F_B = [[I,0,0], [0,W_s,0]].
```

该载体保留全部原消费者，不把不同 patch 的源重新编号，不遗漏 shortcut。它适用于一般的“某消费者由显式选择再仿射映射构成”的结构，不按模型身份择路。若图还有其他活 q 使用，必须继续加入完整载体；这里使用的是上述已绑定首块的消费者。

| 首块 | 因子化接口 p | 相对 m 少的幅度数 | 沿用指定行公式的数目 |
| --- | ---: | ---: | ---: |
| medium | 12289 | 2111 | 184458 |
| Tiny | 37633 | 9023 | 569994 |

最后一列仍对每个 C0 坐标计10行，对每个原 B 消费者计两条 dominance，并计2m guards。原 B 的 dominance 必须通过 F_B 作用于载体读出，不能假设 B 行仍是新幅度的坐标。它不含可能增加的系数填充、矩阵应用和认证成本。

这符合 D156 的一般载体定义，但不是冻结 D157 的 C=[B;ones] 实现；不能修改旧源码后继承旧资格。仅减少幅度并没有证明精度、速度或新颖性，也不意味着必须以幅度压缩作为 Neural-HZ 创新的唯一途径。

## 完整接口细化的原生包含关系

可以证明上述机会不限于“少存几行”的直觉。设 C1=F C0，同一父状态 d、原相位 beta、参考及预算 E 下，以共同代理定义裸原生纤维。任何 C0 成员的代理同时满足

```text
C1 dhat = F C0 dhat = F C0 d = C1 d,
a1 = F a0 = C1 diag(beta) dhat.
```

能量不变，故映射后的 C0 裸纤维包含于 C1 裸纤维。若两者行空间相等，则存在 G 使 C0=G C1，同理得到反向包含，投影后的裸原生语义等价。即使行空间严格包含，也不能保证每个源、相位和预算上都有严格增益。

对于 shortcut 因子化，C1=[B_main;W_s S;ones] 从 C0 精确恢复。C0 可以用更少、但不少信息的行表示接口，因为 C1 有很多冗余输出行。若 shortcut 通道矩阵已经注入于所选坐标，可能只是等价重参数化；当前没有认证其数值秩。

此证明不自动覆盖加强版的 coordinate caps、dominance 或固定有限 energy 方向。改变坐标后，有限外包可能改变；必须推送旧行或另证所保精度，并支付费用。因而它是一个可复用的结构定理，不是本轮已经提出了更强新域。

## 精确源能量只保留长度而非方向

另一个被检查的想法是将 D156 的全域预算 E 改为当前源点值 ||d||^2。它已在 D156 的源绑定反例中讨论，D158 的 contraction 子族也已满足这个界。本轮只补全几何，不把查重结果重命名为新候选。

固定原相位，记

```text
D = diag(beta), P=C^dagger C, N=I-P,
c = C D P d, K = C D N D C^T.
```

P 是 row(C) 的正交投影，N 是 ker(C) 的正交投影。由 C dhat=C d，可写 dhat=Pd+n，n 属于 ker(C)。正交性给出

```text
||dhat||^2 <= ||d||^2  iff  ||n|| <= ||Nd||,
a = c+C D n.
```

因此裸纤维恰为

```text
a-c in range(K),
(a-c)^T K^dagger(a-c) <= ||Nd||^2.
```

真实值 a_star=CDd=c+CDNd 属于它，但 n=-Nd 也允许。除非输出看不到这项变化，否则它只保留核分量的长度，没有绑定其方向。裸纤维为单点的充要条件是 Nd=0 或 CDN=0；加入 caps 等其他谓词后可以有额外单点情形，不能继续援引这个必要条件。

若所谓“核预算”是先从总能量中扣除必需的 ||Pd||^2，得到的正是这个式子。若直接将原总能量 RHS 换成 ||Nd||^2，却不处理 ||Pd||^2，则一般不健全。

固定 d、beta、方向 v 的裸纤维支持确有闭式：

```text
sup v^T a = v^T C D P d + ||Nd|| * ||N D C^T v||.
```

这是核球上线性函数的支持，沿 N D C^T v 可达界。加额外谓词后仍为有效上界，但未必精确。它不是对整个源域、全部未知原相位的已实现支持，也不是 phase-affine certificate；没有理由把这个点值公式当成快速全集合 verifier。

## 线性终端仍丢失该源点值修复

D158 已保留的 contraction 为 dhat=Pd+theta Nd、theta 属于[0,1]，所以它是上述源点值核球的子集。D158 的两个严格同原相位成员及其凸组合仍直接适用：两个成员都在此域内，平均源为0、平均幅度为非零的 v/32；点值域在 d=0 强制 a=0，而任何覆盖这些成员的同整数相位 LP 扩展都接受平均点。这不是六个有限方向太少，而是固定相位凸化本身的损失。旧见证不重新执行、不重新计作新实验。

一般的裸关系理由也很直接：若某严格相位源区域允许 d=±epsilon k，k 属于 ker(C)，且 CDk 不为0，两源均可选同一个代理 dhat=epsilon k。平均源为0、平均幅度却为epsilon CDk。源区域可达性和额外 caps 必须单独检查；该论证不是所有 Neural-HZ 的不可能性定理。

有限能量方向现在给出

```text
2(lambda-mu)^T a + 2 mu^T C d
 <= ||d||^2 + lambda^T T lambda + mu^T U mu.
```

右侧关于源是二次的。若以区间[ell_i,u_i]上的有效割线替代平方，d_i^2 <= (ell_i+u_i)d_i-ell_i*u_i；对称区间马上退成常数界。乘积提升也要计费，不能借一个新变量名保留未编码的点值语义。

数学上可以对整个当前扩大后的父域再保存 ||d_new||^2，因此没有健全性闭包障碍；尚缺的是跨层可付的有效查询。展开会出现源、旧相位、旧幅度间的交叉项；不展开则必须保存并消费其共享表达，不能藏成免费 decoder。使用旧 Cauchy 界可以健全，但不自动保留这里的点值精度。GPU 计算一个给定点的平方也没有解决全集合查询。

## 文献比较与研究决定

矩阵伪逆、range 条件及仿射上确界是已有 matrix perspective 数学，本轮核读 [Won 2020 原文第1页](https://papers.neurips.cc/paper_files/paper/2020/file/45f31d16b1058d586fc3be7207b58053-Paper.pdf)。本记录中的几何专化和接口包含证明不据此声称外部新颖性。

神经输入输出二次关系已有 IQC 的 LMI/SDP 认证路线；本轮核读 [Hashemi 等2021会议摘要](https://proceedings.mlr.press/v144/hashemi21a.html)，只作先例定位，不采用其优化路径。[Constrained Polynomial Zonotopes 的作者摘要](https://arxiv.org/abs/2005.08849)也明确已有非凸表示及多项式映射闭包；其集合操作复杂度不等于本项目的低成本验证查询，更不是建议将 HZ 整体替换为 CPZ。

当前决定是：不为点值能量变体启动实现，不再扩展 D158 的 helper/support 正控作为主线，不把上述接口因子化包装成新域。D156–D158 的数学和组件成果保持只读、默认关闭并可复用，但没有真实 CNN 资格。

下一定义仍须面向完整普通 Conv—激活—残差关系，同时解释源与原相位怎样共同参与前向传播。可以保持完整幅度宽度，也可以改变有证接口；“必须更少变量”不是用户新增的硬门。要突破的是可验证的关系与完整查询代价，而非再发明一个核球名称或单纯扩大观测行。任何实施仍先提交具体定义、普通结构分离、健全跨层规则与完整费用，再新预注册冻结；没有放宽原测试和回放要求。

正式成绩仍1870/2413，独立E0仍61/400，新增0。GPU、smooth/Transformer、全量保旧增益和新家族目标未完成、未缩小，也未据此宣布阻塞。
