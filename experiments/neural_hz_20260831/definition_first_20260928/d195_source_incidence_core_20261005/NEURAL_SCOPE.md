# 缺失的是共同源上的联合神经守卫

完整的自由盒源与相位关系，即使再与全部两门源标记图凸包相交，也未必得到完整神经图的带标签联合凸包。下面用普通非平行三门作纸面控制，明确下一定义问题，不将它误报为物理性质收益。

## 同一完整自由核心

取 x,y 属于 [-1,1]，三个 ReLU 的预激活为

```text
g1 = x - 1/15,
g2 = y - 1/15,
g3 = -x - y - 1/15.
```

三门均 crossing，偏置均非零。保留三个原 bits beta_i，记 sigma_i=2 beta_i-1。令全部八个完整标签质量为 1/8，A=3/10，sigma_bar=(sigma1+sigma2+sigma3)/3。为每个标签赋予盒源点

```text
x_sigma = A*(sigma1 - sigma_bar),
y_sigma = A*(sigma2 - sigma_bar).
```

于是 -x_sigma-y_sigma=A*(sigma3-sigma_bar)，且 |x_sigma|,|y_sigma|<=2/5。它给出了全部自由盒源与三相位混合矩的一个共同见证。其均值为 x=y=0，beta_i=1/2，定义 q_i=E[beta_i*g_i] 时 q_i=1/15。

这不是原生神经轨迹；它是将来查询松弛必须识别的分数接口点。原生 beta 的整数要求从未撤销。

## 每个两门图接口都精确可行

固定任意 pair (i,j) 的标签，对上述完整分布取条件源均值；余下 sigma 的均值为零。所选预激活为

```text
E[g_i | sigma_i,sigma_j] = A*(2*sigma_i-sigma_j)/3 - 1/15.
```

四种标签下，所选第一门的值如下；第二门交换 i,j 即可。

| (sigma_i,sigma_j) | 条件 g_i |
| --- | ---: |
| (+,+) | 1/30 |
| (-,-) | -1/6 |
| (+,-) | 7/30 |
| (-,+) | -11/30 |

均严格满足所选门的符号，条件源点仍在盒内。四个条件点各取质量 1/4，就得到真实两门图的见证。条件期望的塔式性质保证：源均值、所选 pair 的所有源条件矩、beta_i/beta_j 及其乘积、q_i/q_j 和相应所选相位输出矩，都与同一个自由核心匹配。

这里“全部 pair 凸包”的精确定义是：每个 pair 消费完整 x,y 及所选两个门的标签、输出和源条件矩，然后在共同接口上相交。不能把它改称每个 pair 还同时消费全部其他门的输出及所有高阶条件矩，并有同一个完整神经见证。

## 完整联合神经图拒绝该标签关系

对于每一个实际源点，g1+g2+g3=-1/5。因此三个门不可能同时具有 active 标签；即使保留零点的双标签，111 仍不可能。任何真实完整神经图的凸组合必有 lambda_111=0，而上述自由核心给 lambda_111=1/8。缺失的是同一条件源上的联合符号守卫，不是相位边缘之间没有共同分布。

这个反例不能被记为物理均值分离。事实上 x=y=0、beta_i=1/2、q_i=1/15 本身可由六个真实神经点的均匀混合实现：三种 one-active 点的 active g=1/5、其余 g=-1/5；三种 two-active 点的两个 active g=1/10、其余 g=-2/5。它们都满足 sum g=-1/5，映回盒内 x=g1+1/15、y=g2+1/15。六点混合得到上述物理均值，但不匹配候选高阶相位及源矩。

所以结论仅是带标签联合关系的严格缺口。没有新的网络上界、下界、性质证书、反例或验证成绩。

## 对 Neural-HZ 定义的要求

自由源关联核心解决“源矩如何共享”的一个子问题，没有解决“这些共享源条件见证能否同时满足全部神经元守卫”。把完整源复制到每个标签并添加全部条件守卫可以给出已知的全分区/perspective 参照，但可能指数昂贵，不能包装成新定义突破或通过实际相位 split 实现。

下一问题是按普通重叠卷积结构，寻找一种原生共同源—相位—幅值关系：保留原 bits 和父域身份，能够排除联合守卫伪见证，并向所有 affine/Add/Concat 消费者及下一激活传递可检验的物理精度。它需要定义级的具体化和组合定理，不是失败后调用 helper 或另一验证算法。

最低反证标准是：若候选只消除了标签伪见证，却在同一父域、相同可靠信息和完整预算下没有物理查询或后继激活的严格改进，就不能视为能力突破。若必须恢复全部源的全部相位副本才能证明组合，则应如实记录代价与已有方法等价，不借别名隐藏全局源、谓词和 decoder 成本。

更具体的待研究接口是结构固定的非负相位权 rho_r(beta)，及共享源矩 Lambda_r=E[rho_r]、Z_r=E[rho_r*x]。当 rho_r 的支撑固定门 i 的符号为 sigma_i 时，必要条件为

```text
sigma_i * (a_i^T Z_r + b_i Lambda_r) >= 0.
```

同一个 Z_r 必须服务于所有相关守卫与消费者，不能逐行选择新源见证。此式本身仍是已知条件化/perspective 原理，不是新颖性。真正待解的是：下一 ReLU 引入原 bit gamma 后，怎样更新 rho_r*gamma 与 rho_r*(1-gamma)，或给出明确健全且有用的有损替代，而不展开全部相位表。

这一接口尚未形成候选合同或取得健全闭包。下一控制应是普通四门块接完整混权读出、活旁路和下一 ReLU；比较双方须使用相同父域和已知有效关系、完整计费。只有实际源、原 bits、消费者和子激活的物理界出现严格改善，才有继续实现与预注册执行的能力依据。
