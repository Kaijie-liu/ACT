# Neural-HZ 源关联与联合守卫研究记录

本轮仍从非凸 Neural-HZ 的定义问题出发：哪些原源、相位与神经输出关系必须共同存在，才能支持更强的后继查询？没有转向 helper、存储压缩或恢复旧剪枝。上一轮 D194 属于 progress：真实四门共同源结构及条件纤维的边界决定了本轮研究对象。

## 本轮增量与研究决策

[源关联定理](INCIDENCE_CORE.md)证明：在同一个完整相位分布下，自由盒源接口可以按实际相位关联稀疏保留；对目标四门，只有三个中心源需要四相位源关系。另一个严格有理控制说明，全部三阶接口加共同相位分布仍不能替代四阶源关系。这是一个可用的局部化结论，不是完整神经图的理想凸包，也没有新颖性认证。

[三门神经反例](NEURAL_SCOPE.md)进一步说明：即使完整自由源核心与全部两门图接口一致，仍可能违反同一源上的联合神经守卫。物理均值却可由六个真神经点实现，故本轮特别排除了把高阶见证分离当作验证能力提升的错误。下一定义研究须同时解决联合守卫和可组合的物理精度，不能只堆更高阶标签量。

[完整局部费用](GEOMETRY_COST.md)给出低维源像的精确边界、稀疏自由核心及加回输出后的符号代价。稀疏核心比同阶全源提升小，但仍远大于普通四门 HZ 图，且下一激活可能扩大关联阶数。因此不启动该提升的数值实现，不把它列为已取得能力或速度资格的候选。

下一项可反证问题是：对同源重叠的普通 crossing 小组，能否用原生联合守卫关系支持所有消费者及下一激活，在相同父域和信息预算下产生严格物理查询收益，同时避免退回完整指数条件源复制？关系需要统一按结构触发；只改标签凸包、仅对弱旧候选变强、或者把费用移到终端，均不足以过关。已知完整分区/perspective 作为强参照，不冒充新域。
