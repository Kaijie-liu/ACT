# 共同相位分布下的稀疏源关联核心

本轮证明一个有用但范围有限的结论：自由盒源与原相位的混合关系，可以按源坐标实际关联的相位保留，不必把每个源都提升到最高阶。该结论不包含完整神经守卫，也不单独构成新抽象域。它用于区分下一 Neural-HZ 定义真正需要的信息与不必要的全源提升。

## 对象与非凸边界

原连续源为 xi 属于 [0,1]^d，原二元相位为 beta 属于 {0,1}^k。beta=(sigma+1)/2 只是原 signed bit 的记号变换，不删 bit、不改变零点标签。每个源坐标 j 的关联集合 I_j 包含它实际参与乘积的相位。整个父域仍保留全部原源、bits、EQ/LE、共享 frame、历史关系、所有消费者及输入 decoder。

下面的凸包是一个查询接口的参照对象，不是把原生域替换为凸域。在原生扩展中 beta 仍为整数。原生具体化仍是保留父关系的存在量化；新增变量须有与原因子一致的产品含义。不能把这份自由乘积定理套到任意带谓词父域上宣称精确。

令 s 遍历 {0,1}^k。一个共同相位分布 lambda 满足

```text
lambda_s >= 0,  sum_s lambda_s = 1,
beta_i = sum_s s_i lambda_s.

lambda^I_t = sum_(s restricted to I = t) lambda_s,
mu_(j,t) = E[xi_j * 1{beta restricted to I_j = t}].
```

这里的 E 是有限凸组合的数学记号；没有采样、攻击、分支搜索或逐相位求解。2^k 个相位单元是显式代价，不能因使用代数记号而不计。

## 定理：自由盒源上的精确局部接口

共同 lambda 加上以下局部条件，恰好描述所声明接口的自由乘积凸包：

```text
0 <= mu_(j,t) <= lambda^(I_j)_t,
sum_t mu_(j,t) = xi_j.
```

不要求 I_j 构成树或无环超图；关键是它们共享同一完整 lambda，且原源集合是坐标独立的盒。

必要性由对盒内确定点及标签的凸组合直接得到。充分性如下。对每个 lambda_s>0 的完整标签定义

```text
xi_j(s) = mu_(j,s|I_j) / lambda^(I_j)_(s|I_j).
```

分母至少为 lambda_s，因此严格正；每个坐标在 [0,1] 内。盒的乘积性允许把所有坐标组装成同一个合法 xi(s)。以 lambda_s 为权重混合这些点，就同时复现全部 mu、xi、beta 和 lambda。零质量单元任取盒内点，不参与除法。由此得证。

当原 beta 为整数时，其边缘条件迫使 lambda 仅在该标签上为 1；局部 mu 随之成为 xi_j 或 0。因此这个接口是自由乘积的精确扩展，并未删除原非凸性。加回父谓词和神经守卫时，原生确定点仍有规范扩展，但“先取自由乘积凸包再相交”一般不等于完整父域或神经图的凸包。[神经作用域反例](NEURAL_SCOPE.md)给出普通三门证据。

独立凸源块也可用 mu_(block,t) 属于 lambda_t P_block 作相同构造，但不同块之间若有未条件化的谓词或消费者，则不能凭局部块几何恢复完整父域定理。

## 真实四门结构中的局部化

[D194 的只读真实结构](../d194_sparse_crossing_source_fiber_20261005/REAL_TARGET.md)是同通道相邻 2x2 的四个首层 crossing 门，源引用类型为：

| 源坐标类型 | 数量 | 关联相位数 | 除源均值外的独立混合矩数 |
| --- | ---: | ---: | ---: |
| 私有角块 | 48 | 1 | 48 |
| 两门共享边条 | 24 | 2 | 72 |
| 四门共享中心 | 3 | 4 | 45 |
| 合计 | 75 | — | 165 |

若全部 75 个源都与四个相位提升，则对应数量为 75*15=1125。在保留同一个四相位分布的前提下，自由乘积接口的高阶源关系只需集中到三个中心坐标。这不是说完整神经关系的所有高阶耦合只发生在中心：神经守卫会把私有、边条与中心同时联系起来。纯相位分布本身也须支付；除四个原 beta 外有 11 个独立高阶相位量。

## 四阶确有必要：全部三阶一致仍不足

取一个盒源 z 属于 [0,1]、四个原 bits，完整相位分布固定为均匀 lambda_s=1/16。规定所有不同下标的源矩为

```text
E[z] = 1/2,
E[z beta_i] = 9/25,
E[z beta_i beta_j] = 47/200,
E[z beta_i beta_j beta_k] = 47/400.
```

每个三相位子集都有精确可行见证：其八个标签均匀，至少两个 bit 为 1 时 z=47/50，否则 z=3/50。直接加和得到上述全部均值；重叠矩一致，且三相位边缘都来自同一个均匀四相位分布。所有源值严格在盒内，所有质量严格正。

但不存在共同四相位源矩扩展。令 v=E[z beta_1 beta_2 beta_3 beta_4]。单元 1110 的源质量为 47/400-v，必须不超过 1/16，故 v>=11/200。单元 1000 的源质量为

```text
9/25 - 3*(47/200) + 3*(47/400) - v = 3/400 - v,
```

必须非负，故 v<=3/400。矛盾。这严格区分了共同四相位源关系与“全部三相位源凸包加共同相位分布”，但不是网络物理性质、CERT 或 ADV 收益。

## 与已有方法的边界

布尔产品、连续源与布尔产品的提升、条件质量和 RLT/perspective 都是已有工具。[Sharp Hybrid Zonotopes, §IV](https://arxiv.org/html/2503.17483v2)给出了相关产品提升及其 HZ 表达；本轮不采用其分支求解路线。内部 [D035](../d035_cross_phase_source_20260930/THEORY.md) 已研究二相位源关系。

这里的新增研究证据是：对已定位的普通卷积结构证明稀疏接口的确切作用域，并用四阶控制及神经守卫反例确定其不足。没有据此声称新颖性、优于精确 HZ、完整网络精度提升或 PLDI 级创新。
