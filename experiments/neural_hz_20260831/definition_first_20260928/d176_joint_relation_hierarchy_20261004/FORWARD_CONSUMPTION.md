# 防止共同关系在下一神经层丢失

保留上一层联合行仍不够：若下一层重新将所有输入看作独立盒，其关系可能不再参与下一 ReLU 的构造。本文件给出一个具体的固定前向消费规则，以及第二层确实跨零的严格正控。它属于已有模板关系传播，不是新域原则。

## 静态系数规则

共同状态 theta 包括保留的源、原幅值和原 beta 视图；每个坐标都有可靠盒界。已有同源有效行 a^T*theta<=b，下一实际读出 h=c+v^T*theta。统一选

```text
lambda = min { v_j/a_j : a_j*v_j>0 }，集合空时取0。
```

lambda 只由已知系数决定，非负；不优化 b，不读取求解器、对偶解、性质 margin、实例身份或历史结论。令 r=v-lambda*a，则恒等式直接给出

```text
h <= c+lambda*b+BoxUpper(r^T*theta)。                  (U)
```

无需其他坐标也同号：任意非负 lambda 都健全，余项的全部正负系数由盒支持支付。对每条已选关系统一生成 U，保留原界与这些新界的最小值。下界对 -h 应用相同规则。可靠实数算术的区间系数处理仍需另行实现；不能用未认证比值符号决定有效性。

此式在数学上也可解释为一个显式可行的 LP 对偶证书，但算法只是固定的前向行代数，没有求解或优化对偶，也没有失败后的 rescue。不能以措辞回避这一数学对应，更不能据此授权动态 dual search。

Affine、Conv、Add、Concat 必须先在同一 latent/frame 上合并各读出，再计算余项。将两个残差分支先分别盒化再相加，不是同一个规则。每条界的来源必须保持可核验，包括已经不在当前查询矩阵中的祖先证据。

## 两层混权结构的正控

沿用 D175 的第一层：z in [0,1]^3，g=Kz+(-1,1/100,1/100)，q=ReLU(g)，保留全部原标签。定义

```text
F=sum(q)-2*z1-z2。
```

已证共同关系为 F<=(beta2+beta3)/100。下一真实层与 live skip 为

```text
h=F+(q1-z3)/20+1/4，r=ReLU(h)，原相位 gamma；
J=r+z3/10，s=ReLU(J-1/2)，原相位 eta。
```

将共同关系写成 F-(beta2+beta3)/100<=0。固定系数规则自动取 lambda=1，余项为 (q1-z3)/20+(beta2+beta3)/100。使用普通 q1<=2、z3>=0 和原 bit 盒界，可得

```text
h<=1/4+1/10+1/50=37/100，
r<=37/100，J<=47/100，s=0。
```

第二层并非稳定门特例。真实源 z=(9/10,9/10,1/10) 给 q=(9/10,171/100,1/100)、第一层 beta=111、h=21/100>0；真实源 z=(3/20,1/10,4/5) 给 q=(1/20,0,3/50)、beta=101、h=-31/400<0。

## 比较到完整下一门盒源 hull

参考系统已安装第一层 Bell 行，但构造下一门时只使用 q 与 z 的独立盒：

```text
q1 in [0,2]，q2 in [0,201/100]，q3 in [0,101/100]；
z in [0,1]^3。
```

即使它采用这个盒源上下一门的完整带 gamma 的 hull，仍允许下列均值。取两个盒内严格内部源点，各占 1/2：

| 标签 gamma | q | z | h | r |
| --- | --- | --- | ---: | ---: |
| 1 | (6/5,2,3/200) | (81/100,81/100,1/10) | 109/100 | 109/100 |
| 0 | (3/5,71/50,1/200) | (99/100,99/100,1/10) | -67/100 | 0 |

均值正是上面那个真实父图点 q=(9/10,171/100,1/100)、z=(9/10,9/10,1/10)、h=21/100，但盒源 child hull 允许

```text
gamma=1/2，r=109/200，J=111/200，eta=1，s=11/200。
```

第一层父均值是真实点，故满足第一层所有有效关系。两个子门条件源点却无需分别满足整个共同父图；这正是重建独立盒造成的损失。不能把此参照说成完整共同父域上的 child hull，后者也会知道 h<=37/100。

本例证明需要让已有联合证据真正参与前向边界，而不仅把行留到最后终端。它不证明新域，也不是具体 ADV 或已执行 CERT。

## 组合合同及成本

若每一步只从当前共同状态的已证行和有效盒界按 (U) 推导，所得界对所有真实状态有效；归纳经过下一 ReLU、Affine、Conv 和 shared-frame Add 仍健全。原 HZ 的全部整数 guards、幅值及输入 decoder 保留，新增结果只是它们的后果。

每个方向对 B 条已选关系扫描实际系数并集，费用为 O(B*S)，其中 S 是展开支持量而非名义门数。对多方向及多层还要累加，不能声称恒定总宽度。原界保留防止局部弱化，不代表四并发性能或全部旧解已经回放保住。

若域元素只写成 (原HZ,有效行,证书)，具体化仍是原 HZ；D052、D078 已覆盖其基本证书思想。本轮把合同变成明确的静态系数规则和可失败的两层对照，尚未解决创新非凸载体或便宜的任意跨层闭包。
