## 研究问题

给定原激活幅值 q、原二元事件 beta，以及条件幅值 r = beta q，是否可以仅保留
消费者 Y = C r，在跨层混权仿射、ReLU 和残差中同时保住共享源信息，避免恢复
完整幅值表？此处 beta 的整数语义必须保留。下述分数 beta 仅用于检查终端
线性查询的强弱，不是把原域的二元相位改为连续相位。

原生整数恒等式 Y = beta Cq 成立，但把它替换成各输出独立的乘积包络不保证
与完整共同幅值关系等强。需要同时比较域语义、查询精度和完整实现成本。

## 完整输出投影仍可能丢失共同源

取各 q_i 属于 [0,1]，保留全部原 q。令

```text
C = [[1, 1, 2],
     [1,-1, 0]]
q = (9/10, 1/10, 1/10)
beta = 1/2
Y = (17/20, 9/20).
```

令 K = C[0,1]^3。即使同时保存完整的 Y 属于 beta K，以及 Cq-Y 属于
(1-beta)K，仍然会接受这个点。证明：把二维坐标 (Q,B) 换成
(u,v)=((Q+B)/2,(Q-B)/2)，K 恰为 0<=u,v<=2 且 |u-v|<=1。
Y 对应 (13/20,1/5)，Cq-Y 对应 (7/20,0)，两者都在半尺度的 K 中。

但共同源条件幅值必须满足

```text
max(0, q_i + beta - 1) <= r_i <= min(q_i, beta).
```

于是 r1<=1/2、r2<=1/10、r3<=1/10，故 Y1=r1+r2+2r3<=4/5，
与 17/20 矛盾。两个完整输出像可以各自选择不同的源核分量；它们不是同一
原 q 的共同条件分解。这个反控是普通内部点，不是数值极端情形。

结论只涉及查询关系失真，不是网络 ADV，也不是一般有损域不可能有用的证明。

## 森林接口的正向消元与边界

若所有 r 消费者都通过森林 incidence 接口 y=Br，且这些独立差分本来就是
完整的真实活输出，则每个连通分量只需一个共同锚 t：

```text
r_i = t_component(i) + path_i(y).
```

把此式代入全部幅值包络、差分行及全部消费者，前后可双向重构，在分数 beta
下也精确。原 q、二元相位、源身份和输入 decoder 不变。星形接口可减少辅助量
与别名等式；长路径会产生填充。不能为使计数好看而额外制造原先不存在的
差分输出。这是精确坐标消元，不是新的域精度。

即使图为路径、消费者只有一个端点差，消掉全部中间幅值仍可能很贵。
取 n 条边、0<=q_i<=4n、|q_i-q_(i-1)|<=1。在切片

```text
beta = 1/2, q0 = 2n,
delta_i = q_i-q_(i-1) in (-1/4,1/4)
```

上，同时施加事件及补事件的差分约束，得到

```text
-1/2 + max(0,delta_i) <= r_i-r_(i-1)
                            <= 1/2 + min(0,delta_i).
```

唯一读出 Y=r_n-r0 的精确上界因此为

```text
Y <= n/2 + sum_i min(0,delta_i).
```

取 r0=n，所有边区间选择均使 r_i 位于 [n/2,3n/2]，同时
q_i 位于 [7n/4,9n/4]，所以节点自身的条件包络不限制这些选择。
该上界确为投影，不是漏约束的假象。每个 delta 符号正交区域对应一个不同的
开放仿射面，共 2^n 个。因此原坐标中无辅助量的有限线性精确描述可能指数大。
保留线性数量的中间幅值仍然可行；这个结论不否定紧凑扩展或健全有损域。

## 差分域和有序幅值能提供什么

一般混权仿射不对只保差分的表示精确封闭。例如 r 属于 [0,1]^2，
y1=r1+r2、y2=r1-r2。最佳个体界和差分界仍接受 (y1,y2)=(2,1)，
但共同像满足 y1+y2<=2。因此后继 ReLU(y1+y2-2) 的真值恒零，
只保这些差分信息却不能证明它。保留共同 latent r 可避免此损失，但成本仍在。

一个受限正结构是可靠父域保证 0<=q1<=...<=qm<=U。令
a_i=q_i-q_(i-1)、z_i=r_i-r_(i-1)，且 q0=r0=0。对这个有序多面体的
单事件乘积图，事件与补事件 perspective 恰等价于

```text
0 <= z_i <= a_i,
q_m - U(1-beta) <= sum_i z_i <= U beta.
```

所有消费者必须共享同一 z，并同时表示为 C S z，S 为前缀和矩阵。
这是 m 个增量和 2m+2 条不等式，无新增 bit。C S 可能变稠密；如果保留
前缀别名来维持稀疏，必须支付相应变量和等式。固定 q、beta 的标量查询可化为
连续背包，但不是自由源上的完整终端查询。普通 CNN 尚未验证这种幅值顺序。
这是已知条件乘积机制的结构实例，本轮不将其记为独立域创新。

## 对后续主线的约束

这些正负结论保留作支撑材料，不据此启动一轮仅变量消元或 helper 扩展工程。
用户要的是 Neural-HZ 自身更强：下一项候选必须明确域元素和具体化语义，
说明相位、生成元和谓词的新关系怎样经过普通混权 ReLU、卷积和残差传播，
并给出相对强参照的可反证优势，而不是只同弱区间参照比较。

优先问题仍是普通 PWA/CNN 的跨层共同相位与幅值关系；CIFAR100 和 TinyImageNet
是实际能力检验对象。本轮没有选定新的 attention 路线，也没有以其他家族替代它们。
健全近似可以研究，但必须明确丢失什么、保留什么，不能暗称完整闭包。

普通终端 LP/MILP 与独立具体见证验证仍在原授权边界内；它们是实现和检查域查询
的工具。额外 attack、PGD、BaB、split、backward/dual rescue 或其他证明路径的
收益不能归到 Neural-HZ 本体。GPU 和构造优化应服务于已明确的域语义，不替代它。
