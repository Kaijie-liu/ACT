前序研究记录将跨领域综述归为 progress：新增了可用于筛选的原文依据和边界，确定研究跨原相位的共同源关系。本记录完成[局部凸包构造、联合投影及正负对照](THEORY.md)，并核对其真实结构人口。这是数学与文献进展，不是数值资格或新域完成；Goal 服务状态见文末的最终核查。

## 本轮决定

不把功能余项换元、只增加相位共现计数，或两层 max/min 恒等式加独立求界立为能力创新。纸面证据分别说明其信息不足或已被既有规则覆盖。

保留“两原相位与共同条件源观察”作为有明确强对照的研究接口：它能严格强于各自完整的单相位盒接口，但属于已知 BQP/RLT。全源乘积提升仍不启动；创新问题是哪些真实神经观察能够统一构造、怎样利用已有门恒等式、以及如何跨真实残差低成本组合。

后续首先检查实际 q、r 与余项条件乘积之间的精确等式，避免不必要的重复变量，同时不得仅凭局部变量少宣称收益。源条件证书、全部消费者与终端重构仍须一起证明。数学支持组件和正式能力候选继续分开。

最终核对补入一个可构造强对照：利用 alpha*q=q 与 r=a*beta*q+beta*v，在指定两个观察上消去共同相位乘积，得到四条交叉行；含两套源乘积及内联门乘积包络时为两个辅助量、16 LE/56 nnz，其他原门与证书成本另计。它是已知二乘二 bipartite BQP 的面和投影，不是创新或物理输出增益。多观察不能分别消去各自共享量后直接组合。正文给出证明、准确文献定位及限制，没有启动实现。

## 全边结构的规模不能沿用旧配对人口

依据 [D025 原诊断](../../results/d025_interval_capacity_20260930_v1/diagnostic.json:40)，以下是旧计数的纸面乘法，不是新 census：

| 五个固定窗口的结构人口 | 数量 |
| --- | ---: |
| canonical slots | 2880 |
| 有原相位的有效 slots | 1600 |
| padding slots | 1280 |
| 每窗口接收通道 | 64 |
| 所有 slot 与接收通道的出现数 | 184320 |
| 有效源与接收通道的潜在边数 | 102400 |

实际非零权重边数最多 102400，但旧档没有该统计。旧 92160 是通道配对人口，不能用作这里的全边人口。此处仍只涉及原五个固定窗口，不代表整网。

设实际边数 E，每条边生成 t 条、每条最多涉及已有 (g,q,z,r,alpha,beta) 六坐标的行，则条件性上界为 tE 行、6tE nnz。若单独定义每条边的 v=z-a*q，另有最多 E 个连续坐标、E 条定义等式和 3E nnz。物理坐标若尚不存在，还要计算 readout 展开或定义成本，不能将这些坐标视为免费。

上述六坐标公式不适用于另增 t_k、u_k、delta 的完整条件源接口；该接口还需按 THEORY.md 中的实际观察维数逐项加账。对全部 102400 潜在边复制全源乘积不是已证明可承担的方案。

旧档 727 个严格正、863 个严格负、10 个 crossing 源只说明认证区间与整数语义。未核实原 terminal LP 的相位绑定时，不能自动将全边人口缩为 640；新增固定相位等式也须计费、且原 bit 不删。语义 phase ID 还不等于生产 HZ 二元列绑定证明。

## 系数与 GPU 边界

存档中的 BN 折叠接收系数是认证区间，不能将中点作为精确 a 做乘积消元；BN 前原 Conv 的确切系数也不能替代实际 ReLU 前的 BN。需要保持原模型系数、误差、source/frame 和 decoder 语义。

可共享一次真实消费者计算 z=Wq+b，再按边计算 v_e=z_c-a_e*q_j。算术形式为 O(WCK+E) 的消费者作用加逐边运算，可用 gather、scatter 与分段归约组织作用和转置。若每边展开剩余 K-1 项则可能为 O(EK)。这些只是数学算术账，不是认证 GPU 实现或测得速度。

共同源支持、条件观察的合法界、所有原 HZ 数据、临时量、证据、设备传输、终端转换与求解须额外计入。独立区间 all but one 的低算术成本并不能绕过 D032 的冗余结论。没有重试冻结 GPU 失败版本，也没有提高资源预算。
