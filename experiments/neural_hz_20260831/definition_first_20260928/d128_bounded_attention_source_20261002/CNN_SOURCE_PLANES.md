# CNN 共同源斜面：可计算的导数证书、强对照与未完成边界

日期：2026-10-02；分支 `redu-hz`；commit
`f1bc0f16612bd3f2112f2970174ec2f7cc3bf5ac`。配置仅为纸面推导、
只读历史去重与独立数学复核。本文是 D128 目录中的独立 CNN 研究记录，
不属于 D128 attention 组件的数学执行合同，也不借用其任何执行资格。
没有为本文导入、AST/compile、执行候选、数值脚本、LP/MILP、模型或测试。

结论：共同源导数可以产生被混权残差和下一原 ReLU 消费的输入斜面；
正系数高阶相位单项式的一类导数上界可以编译为有限最大闭包查询。
这不是新单调性或新 maxflow 数学，也尚未建立新的完整 Neural-HZ。
下面两个普通正控均有必须保留的强旧对照：三门例被 D018 包含；两层例
能由 D052 的既有前向规则和廉价、显式构造的源证书推出更强关系。
因此本轮没有证明新的关系精度优势或真实网络收益。

## 1. 语义、证据与比较对象

所有讨论保留原 HZ 的连续源、全部原二元相位、EQ/LE、共享 latent 身份、
所有消费者及原输入 decoder。没有把网络定义成区间域、CZ 或凸域。
二元变量的连续放松只用于指定参考的查询比较，不替换原非凸语义。
原门预激活为零时，原合法的两种标签都保留。

须区分三个对象：

1. 原精确 HZ 图已经表达真实网络。有效斜面不可能在真实集合精度上
   “超过精确图”；加入它不改变整数具体化。
2. 某个指定的低成本前向外包或逐门 LP 不一定自动得到该斜面。
   其分离例必须说明保留的信息、共同 bounds 与付费的源关系。
3. “旧语言可以表达证书”不等于“现有自动算法以相同费用找到证书”。
   有价值的贡献仍可能是统一的前向发现、编译、有限消费者表示或传递算法，
   但需要算法、适用结构、强对照及完整成本，而不能只给一个手选证书。

本文不删除幅值、不宣称低内存、不提供完整多层闭包。
若未来使用这些查询替换表示，删除的幅值、全部消费者与重构义务仍需另证。

## 2. 从共同源导数到可消费的斜面

令完整输入盒为 `X=prod_j [l_j,u_j]`，`F:X->R` 为同一真实前向网络的
连续分段仿射读出。若在整个 X 上几乎处处有

```text
m_j <= partial_j F <= M_j,
```

逐坐标选 `s_j=m_j` 或 `s_j=M_j`。前者取 `v_j=u_j`，后者取 `v_j=l_j`。
则

```text
F(x) <= F(v) + sum_j s_j (x_j-v_j).                     (1)
```

使用逐坐标相反的角点 `v^-`，得到同一斜率的下界

```text
F(v^-) + sum_j s_j (x_j-v^-_j) <= F(x).                (2)
```

证明：`G=F-s*x` 在选择 m 的坐标非减、在选择 M 的坐标非增。
分段仿射函数沿轴平行线段绝对连续，在几乎所有平行线段上积分导数即可
比较各坐标端点；恰落在折面上的路径再由连续性取极限。
不可导折点不影响积分，也不要求删除任何原零点标签。
这是普通单调性/导数界定理，不是新的数学原语。

更有用的单面版本是：若 `partial_x F<=M`，则

```text
F(x,z) <= F(l,z) + M(x-l).                             (3)
```

当原网络在固定面 `x=l` 上可经静态界证明相关门稳定，并得到确切仿射
`F(l,z)=A(z)` 时，右边是保留其他源坐标的线性斜面。
这是一次固定边界代入和认证；不是运行时输入切分、相位搜索或免费的 face oracle。
一般网络在面上仍可能非线性，不能假设 A 总能低成本取得。

### 非凸源的路径限制

若导数或相位偏序仅在非凸上游集合 S 上成立，而轴平行路径离开 S，
则不能直接应用 (1)--(3)。可靠充分条件是在覆盖 S 的整个源盒上证明
所用导数事实，同时继续保留 S 的原谓词；或独立证明使用的路径留在 S。
不能把内部物理值自动当成独立输入，也不能隐含调用源可行性 oracle。

对原输入盒上的真实网络可以沿原输入路径积分，但多层导数会包含原相位
的乘积，不能继续假设导数只对“当前层 bits”线性。这正是第 5--7 节的边界。
若完全独立地把所有相位放到 `[0,1]`，同角点的逐项 majorant 只是常规
仿射/导数界组合，不自动构成共同非线性关系。

## 3. 三门普通正控，以及 D018 的同信息强对照

取 `x,y in [-1,1]`，所有父门均不稳定且法向不成比例：

```text
f1=x+y/4+3/5;     q1=ReLU(f1)
f2=x-y/5+1/10;    q2=ReLU(f2)
f3=x+y/10-3/5;    q3=ReLU(f3)
F=q1+q2-2q3
s=ReLU(F+3y/20-39/20).
```

同一源盒直接给出 `f1-f2=1/2+9y/20>=1/20` 与
`f2-f3=7/10-3y/10>=2/5`。几乎处处的激活序列为前缀，
故 `partial_x F` 取 `0,1,2,0`，`partial_y F` 取
`0,1/4,1/20,-3/20`。这是证明中的有限模式说明，不是候选运行时枚举。
`F+3y/20` 对两个坐标均非减，在 `(1,1)` 等于 `19/10`，从而

```text
F <= 19/10-3y/20,
F+3y/20-39/20 <= -1/20,
s=0.                                                    (4)
```

真实 output-only 最优上界为 `F<=41/20`，在 `(1,-1)` 达到。
仅独立合并此界与 `3y/20` 得到后继预激活上界 `1/4>0`，不能证明 s 稳定。
这一差别说明源斜面相对输出标量界的价值，但不是新的联合关系优势。

具体强对照是 [D018 的 ordered-sector 关系](../d018_order_relations_20260930/D018_THEORY.md)：

```text
F=(q1-q2)+2(q2-q3)
 <= (f1-f2)+2(f2-f3)=19/10-3y/20.
```

因此 (4) 已被相同源事实上的旧关系包含。这里未检查生产代码是否自动发现
这两条次序，但三条稀疏源形式作两次差分和盒扫描即可认证，不能把它们
作为旧对照的昂贵 oracle，同时在新查询中免费使用。

在物理坐标 `x,y,q1,q2,q3,s`、4 个原 bits 上，不物化 F，标准四行门表示
使用 16 行、44 个系数 nnz；bounds/bias 存储在双方另计。
计数采用共同继承的四行门界，例如后继 `[-31/10,27/20]`，不免费提供 (4)
才能发现的稳定性。该界由父门原盒直接得到，所有所计系数非零。
显式 (4) 为 1 LE、4 nnz；保留原门再添加 `s<=0` 另加 1 LE、1 nnz。
D018 链替换父门 6 条下侧行：nnz 从 12 变 14，原上侧行保留，
因此为 16 行、46 nnz，并已蕴含斜面。无幅值删除或实测速率结论。

## 4. 相位偏序上的最大闭包：精确查询但不增加新集合信息

若已认证的原相位先决关系为 `beta_j=1 => beta_i=1`，记为边 `j->i`。
仅依赖这些关系的查询域是

```text
P={z in [0,1]^m: z_j<=z_i for every prerequisite j->i}.
```

`max_P c*z` 等于所有满足这些关系的二元闭集合上的最大权值。
自包含证明：`z_i=int_0^1 1[z_i>=t] dt`；每个 level set 都闭合，
所以 `c*z` 是闭集合权值的平均，不超过最大值。二元点也在 P 中，故相等。
这与 [Stanley 的 order polytope](https://math.mit.edu/~rstan/pubs/pubfiles/66.pdf)
中顶点为 filter 指示向量的经典结论一致。

计算图含原节点权 c_i：正权接 `source->i` 容量 c_i，负权接
`i->sink` 容量 -c_i，先决边容量取 `H=1+sum_i abs(c_i)`。
最小割不会割断先决边；割值为正权总和减选中闭集合权值。
这是经典 maximum closure/mincut，不是新算法；参见
[Hochbaum 2004, §2.1--2.2](https://hochbaum.ieor.berkeley.edu/html/pub/MS-50-anniversary-selection.pdf)。

必须保留四个限制：

- 此查询与加入全部已给定 order cuts 的 LP 有相同支持值，不是更强的凸包。
- 非严格 `f_i>=f_j` 在二者都为零时不必蕴含原标签顺序。导数可以使用
  几乎处处的真实激活顺序，但不得据此删除原零点标签或擅自加 bit-order 行。
  严格间隔是足够的标签蕴含条件；其他情况需另证。
- 次序允许的模式可能在真实源上不可达。得到的是导数外包，不是网络见证；
  不同读出最优化选出的模式不能拼成一个共同源状态。
- diamond 偏序使用全部已认证边可能强于任意删边的森林，但多用了信息和费用。
  本轮没有证明它超越同全部 order 信息的 LP 或 D018 所有可用关系。

发现/认证这些边必须计费；不允许把任意真实源蕴含当作免费 oracle。

## 5. 下一层为何出现真正的相位乘积

普通两层结构

```text
q=ReLU(x),  g=y+q/2-x/10+1/5,  r=ReLU(g),
x,y in [-1,1]
```

有原 bits alpha、gamma，且
`partial_x r=gamma*(alpha/2-1/10)`。
四种严格相位分别由

```text
(-1/2,-1/2): 00, g=-1/4
(-1/2, 1/2): 01, g= 3/4
( 1/2,-3/4): 10, g=-7/20
( 1/2, 1/2): 11, g= 9/10
```

实现。其二元混合差为 `1/2`，不能在这四种可达模式上等于只含
`1,alpha,gamma` 的仿射形式。保留原 bits 并不自动使线性闭包查询跨层闭合。
某些已证明相位恒等式可约简乘积，但这个例子没有这样的逻辑约简。
这不是所有低成本非凸表示的不可能定理。

## 6. 一个有限的正单项式查询类

设归并相同原 bit 身份、使用 `beta_i^2=beta_i` 后，某个真实源偏导写成

```text
P(beta)=c0+sum_i l_i beta_i
              +sum_A a_A prod_(i in A) beta_i,   a_A>=0.       (5)
```

所有高于一次的系数非负；一次系数可有正有负。相位还可有已付费认证的偏序。
对每个正单项式新建一个查询奖励节点 z_A，权为 a_A，加入
`z_A->beta_i`（所有 i in A）。原 bit 节点权为 l_i，再加入原先决边。
则 `max P = c0 + maximum_closure_weight`。

证明：固定一个可行 beta，奖励节点只有在全部先决 bits 为 1 时才允许选中；
权非负，所以最优解选中所有允许的奖励。反之任意闭集合的奖励不超过同一
beta 的真实单项式和；将允许奖励补齐就达到相等。由此精确最大化的是
给定相位外包上的 (5)，而不是真实源的完整最优导数。

奖励节点是支持查询的临时算法节点，不是新增网络相位或新域二元因子。
这也等价于相应 lifted order LP 对该最大化目标的支持，不能把它误称
为乘积图的精确连续表示。数学原语仍是已知最大闭包；未证明整个编译方法新颖。

负高阶项不能直接这样处理。例如
`P=beta1+beta2-2 beta1 beta2` 的真最大值为 1；若把乘积奖励节点设为
负权 -2 而仍只有先决边，选择两个原 bits、拒选该节点就得到错误值 2。
丢弃负项可以给更松的健全上界，但不再是此精确支持定理；不能将其隐去
后仍声称相等，也不能把最大值结论取负用于不满足条件的最小值。
因此下导数界不自动可用；下一层乘法可能产生负高阶项或大量不同单项式。
共享 circuit 也不自动等价于线性大小的精确闭包图。

## 7. 混权、残差、下一原 ReLU 的两层正控

取 `x,y in [-1,1]`：

```text
f1=x+y/4+1/5;       q1=ReLU(f1), bit alpha1
f2=-x+y/5-1/10;     q2=ReLU(f2), bit alpha2
g=q1-q2-7x/10-1/10; r=ReLU(g),  bit gamma
F=r-3q1/5+7q2/10
s=ReLU(F-7y/50-13/20),          bit delta.
```

父门界分别为 `[-21/20,29/20]`、`[-13/10,11/10]`，均跨零。
`g(1,1)=13/20>0`，而 x=-1 面上 g 严格为负，故中间门也确实不稳定。
原 q1、q2 同时进入 g 与 F；没有隐去它们的真实 side consumers。
原四个 bits 和原门守卫全部保留，最终 delta 即使证明稳定也不删除其原零点语义。

几乎处处有

```text
partial_x F = gamma*alpha1 + gamma*alpha2
              -3alpha1/5-7alpha2/10-7gamma/10 <=0.            (6)
```

它有两个正二次单项式，符合 (5)，不需要相位偏序。直接核验：gamma=0
时非正；gamma=1 时为 `2alpha1/5+3alpha2/10-7/10<=0`。
这段证明分情况不是运行时 split。
闭包图有 3 个原 bit 节点、2 个奖励节点、source/sink，共 7 个节点；
4 条奖励先决边、2 条正权 source 边、3 条负权 sink 边，共 9 条原始有向边。

在固定面 x=-1 上，完整源界认证

```text
q1=0,
q2=9/10+y/5 in [7/10,11/10],
g=-3/10-y/5 in [-1/2,-1/10],
r=0,
F=A(y)=63/100+7y/50.
```

由 (3)、(6) 得到

```text
F<=63/100+7y/50,
F-7y/50-13/20<=-1/50,
s=0.                                                        (7)
```

真实 F 的最佳标量上界为 `77/100`，在 `(-1,1)` 达到；独立合并该上界
与残差 `-7y/50` 只能给后继上界 `13/50>0`。因此 (7) 确实是一条
能被下一原 ReLU 消费的共同源关系，不只是减小未被使用的负上界。
但它是纸面普通控制，不是任何 CIFAR/Tiny 实例新解。

### 指定逐门强参考仍允许的点

参考为：各父门完整同源单门 hull，与目标门在其声明物理输入盒上的
完整单门 hull 相交，共享源均值；不包含整个前缀的联合 disjunctive hull。
取 `x=-1,y=0,q1=0,alpha1=0,q2=9/10,alpha2=1`，父门完全确切。
取 `r=6/55,gamma=2/11`。这是目标单门如下两个确切图点的凸组合：

```text
weight 2/11: x=-1,y=0,q1=0,q2=0,    g=3/5, r=3/5,gamma=1
weight 9/11: x=-1,y=0,q1=0,q2=11/10,g=-1/2,r=0,  gamma=0.
```

两点都落在所声明物理坐标盒；即使另用 `g in [-1/2,13/20]`，
它们也满足这个限制。其均值满足父门的确切图，故该逐门 hull 交允许它。
但组合中的目标源点不是完整前缀的可行状态；绝不能把它们冒称真实网络点，
也不能声称此点存在于完整联合前缀 hull 或原整数 HZ 中。
在均值处，后继预激活为 `6/55-1/50=49/550>0`，可取原 delta=1、
`s=49/550`。参考必须使用双方共同的可靠继承界，而非免费提供 (7)
已证明的精确后继上界。例如共同继承 `g in [-19/10,41/20]`、
`r in [0,41/20]` 和后继预激活 `[-83/50,231/100]`，均由声明盒直接得到，
足以容纳这个点；两种方法在此比较中使用相同这些界。

父门之间没有全盒顺序：`f1-f2=2x+y/20+3/10` 跨零。
因此这个对照不是第 3 节 D018 链的直接复用；但下面的 D052 对照更强。

## 8. D052 强对照：证书自动构造的费用不能省略

[D052 的前向 residual 规则](../d052_static_source_certificates_20260930/THEORY.md)
已证明：若 `u-psi<=c0`、`u+g-psi<=c1`，则原
`r=ReLU(g)` 满足 `u+r-psi<=c0+(c1-c0)*gamma`。
该定理本身不免费提供所有 u/psi 或源前提；必须实际构造并认证。

对第 7 节例子，取如下直接由网络 readout 系数构出的量，不做优化搜索：

```text
t=x+1>=0, Q=9/10+y/5 in [7/10,11/10],
u=q1, v=Q-q2,
P=3u/5+7v/10.
```

完整源扫描给出 `f1=t-4/5+y/4<=t-11/20`，所以 `0<=u<=t`。
又 `f2=Q-t`，由 Q、t 非负及原 ReLU 得 `0<=v<=t`。
这些都是单门源事实，不需要解 LP、枚举相位或查找未知 source support。
设 `g_face=-3/10-y/5<=-1/10`，则

```text
g=u+v-7t/10+g_face,
P>=0,
g-P=2u/5+3v/10-7t/10+g_face<=-1/10.
```

将 D052 规则用于 `u_old=-P,psi=0,c0=0,c1=-1/10`，得到

```text
r-P<=-gamma/10,
F-A(y)<=-gamma/10.                                        (8)
```

(8) 严格强于未带标签的 (7)。零点 gamma 的原合法标签仍全部满足证明。
本例的 P 由实际残差系数 `-3/5,+7/10` 直接给出；构造/认证工作是
两条父源行和面上仿射形式的支持合并、盒扫描与常数次线性组合，
即在已排序支持上 O(d1+d2) 标量工作，排序、精确位长、证据输出另计。
这不是“人工提供任意 P 后再声称旧算法免费做到”：本例明确提供了
可自动执行的有限公式和其成本。但也没有检查或宣称现有生产生成器
已经实现这套选择，或 D052 能自动找到所有其他结构所需的 P。

物理成本：原 `x,y,q1,q2,r,s` 共 6 连续、4 原 bits；标准门 16 行、
46 nnz（两父门 20，g 门 12，s 门 14），双方原 bounds/源谓词另计。
单独发出 (7) 是 1 LE、4 nnz；`s<=0` 若另存是 1 LE、1 nnz。
若源证明也需要作为行安装，`q1<=x+1` 与 `q2<=Q` 共 2 LE、4 nnz；
`q2>=Q-t` 已是原下侧门行；展开 (8) 为 1 LE、5 nnz。
故全显式额外为 3 LE、9 nnz，或在前提已经存在时仅 1 LE、5 nnz。
但双方均可把中间前提当作已支付的证明而不永久安装，不能只让新算法
使用 proof-only 前提，却强迫旧规则保留中间所有行以制造成本优势。

因此，本控制没有证明 maxclosure 相比 D052 的精度或发现成本优势。
一般 (5) 的闭包图仍可能是统一的自动证书算法，但尚未证明它一般
等价于自动寻找某类 P；由导数证书到幅值证书还要支付积分/面界的证明。
不能仅因旧 HZ 能表示正确行就否定所有未来定义/算法创新，也不能把
已知 maxflow 和两个成功手算实例直接命名为新域。

## 9. 完整查询费用与多消费者限制

对 (5)，设 m 为参与查询的原 bit 数，H 为正高阶项数，
R 为这些项支持长度之和，e 为已有认证先决边数。
闭包图有 `V=m+H+2` 节点，至多 `E=e+R+m+H` 原始边；
残量反向边和容量存储也计入 O(V+E)，原网络 bits 并未被删。
给定已归并的系数后，建图 O(m+H+R+e)。

一次精确最大流查询不是免费 oracle。例如普通最短增广路径实现可用
O(V E^2) 次图/容量算术操作、O(V+E) 图存储作保守上界；有理容量的
位长、分母表示/缩放、算术与比较费用另计，不宣称该界为 GPU 或物理耗时。
实际实现也可选其他已知算法，但必须如实记录完整成本。

在建图之前必须支付原 Conv/Linear/残差链式法则、所有路径贡献、相同
原 bit 的归并、单项式支持排序和精确系数形成。H/R 随深度可能爆炸，
“bounded width”或“保存共享 circuit”本身不能证明它们小。
有限度数和实际 H/R 预算是可研究范围，不要求任意深度精确闭合。

若 k 个完整消费者、d 个源方向分别需要上界，最多 k*d 个此类查询；
上下界都满足系数条件时最多 2*k*d。不能只给一个容易消费的方向计费，
忽略同时活跃的混权 Conv、residual、head 和其他外部读出。
多个查询可共享静态图结构和已认证源事实，但这不保证它们的极点由同一
真实源实现，也不保证重用后的实际加速。合法输出是各条全局有效的关系，
不是把各自最大化的虚构相位值合成共同见证。

角点/面值的可靠获取、完整原输入路径的适用性、边认证、证据和 decoder
全部在费用内。若 F 是已有物理坐标，一条斜面含 `1+nnz(s)` 个系数；
若 F 内联为宽读出，则必须计完整合并后的支持，而不是假称只有一个系数。
原 HZ、bounds、全部 bits 和消费者继续存在，本文没有内存减少、物理
终端减少、全 GPU、native shadow 或 end-to-end 时间结论。
