# 源相关距离预算的共同前向闭包与精度边界

本轮得到一个可线性编译的非凸关系候选：中心可以保留连续源，半径可以依赖原二元相位，混权、ReLU 和仍被读取的旁路共同消耗一个预算。与 D146 的纯相位中心不同，这里不必将中心中的连续源乘上新相位；与 D161 的平方距离不同，终端不必另加二次求解器。

然而，一个普通、有偏置、全局 crossing 的两门块已经证明这条闭包会丢掉旧 HZ 单门行保留的关系。因此本记录是建设性定理及其否决证据，不是新颖性认证、已实现的新域或能力突破。本轮不为该候选增加 helper、测试框架或生产集成。

## 保留的状态与域元素

theta 表示同一受保护连续环境，包含原输入身份和仍被原谓词读取的历史连续量；sigma 是全部原二元身份的 0/1 视图，不是新的替代位。P 保存原 EQ/LE、共享 frame 和输入 decoder。语义比较只在身份对齐的共同状态上进行。

当前共同前沿为 y。指定其中的 ReLU 坐标集合 G，其他坐标集合 S 是仍被读取的线性旁路。每个 i in G 对应一个原 bit beta_i。中心 c(theta,sigma) 为仿射式，正权重为 w，R(sigma) 为在整个允许父域上非负的相位仿射式。定义：

```text
i in G:
  y_i >= 0; beta_i=0 implies y_i=0;
  d_i(y_i,c_i,beta_i) = |y_i-c_i|  if beta_i=1,
                         max(c_i,0) if beta_i=0.
j in S:
  d_j(y_j,c_j) = |y_j-c_j|.

sum_i w_i d_i <= R, together with theta, sigma, P and their original types.
```

原 HZ 通过 G 为空、R=0、c 等于原仿射读出精确嵌入。有限有界的这些关系可回编到一般 HZ 的连续因子、原 bits 和 EQ/LE；不是 CZ 或 Zonotope 的整体替换。可回编到 HZ 也不等于已建立新的域贡献，仍须证明有用的算子、完整成本与真实收益。

这个载体确实可以保留物理非凸性，而非只把无用 bits 附在凸集上。例如两维中心 c=(-1,-1)、权重全为 1、R=3/2 时，输出 (1/2,0) 和 (0,1/2) 可行，而中点 (1/4,1/4) 要付 5/2，不可行。这只说明几何，不是用于突破网络的特殊目标或新颖性正控。

## 一个共同 L1 纤维的精确 ReLU 投影

假设待消去 t 的完整条件恰为：

```text
sum_i w_i |t_i-c_i(theta,sigma)| <= R(sigma),
q_i = ReLU(t_i), with the original integral phase beta_i.
```

则其在共同 theta、sigma、beta、q 上的精确投影就是上述 G 为全部坐标的距离预算。必要性逐坐标成立：active 时 t_i=q_i；inactive 时 q_i=0、t_i<=0，最小距离为 max(c_i,0)。充分性统一取：

```text
t_i = q_i          when beta_i=1,
t_i = min(c_i,0)   when beta_i=0.
```

这一向量是所有坐标共用的一份见证，不是分别给每个消费者选输入。原 t_i=0 的两种合法标签都保留；q_i=0 本身不意味着两种标签都可行。

任何额外 t 的消费者、谓词、bounds 或 decoder 使用都须共同投影。不能在旧关系 t=A theta+b 仍被保留时把它悄悄删除，再把结果称为原网络精确像。

### 没有新相位乘积的整数编码

令 M_i>=sup max(-c_i,0)，U_i 是声明的球像的有效非负输出上界。每个门引入一个 cost rho_i：

```text
q_i >= 0, q_i <= U_i beta_i,
rho_i >= 0,
rho_i >= c_i-q_i,
rho_i >= q_i-c_i-M_i(1-beta_i),
sum_i w_i rho_i <= R.
```

beta_i=1 时最小 rho_i 为 |q_i-c_i|；beta_i=0 时 q_i=0，最后一个下界不大于 0，最小 rho_i 为 max(c_i,0)。因此整数编码精确，无 beta*c、二次项、新 bits 或优化 oracle。

分数 beta 仅是终端 LP 外包，不能当作域成员。这里的 M 是中心负部上界，不是实际预激活下界的另一名称。

若只想给真实算子像增加更紧的 q 上界，可以作为有证的额外约束加入，但须承认它已不是整个自由球像的原始定义。若把自由 t 球先与 [L,U] 相交且 L<=0<=U，inactive 距离应改为 dist(c_i,[L_i,0])；当 c_i<L_i 时不能继续使用 max(c_i,0)。一般区间的 inactive 分支为 [L_i,min(U_i,0)]，active 输出须在 [max(L_i,0),U_i] 内；空分支不可行。

## 原四行 LP 也有精确投影但须使用不同参数

另考虑一个明确的扩展 LP：0<=beta<=1，L_i<=0<=U_i，rho_i>=|t_i-c_i|，以及原四行：

```text
q_i>=0, q_i>=t_i, q_i<=U_i beta_i,
q_i<=t_i-L_i(1-beta_i).
```

门行等价于 q_i>=0、q_i<=U_i beta_i 和区间：

```text
q_i+L_i(1-beta_i) <= t_i <= q_i.
```

精确消去 t 后，保留前两行、共同预算，并写：

```text
rho_i>=0,
rho_i>=c_i-q_i,
rho_i>=q_i+L_i(1-beta_i)-c_i.
```

证明是标量到上述非空区间的距离。充分性的共同见证为逐坐标 clip(c_i, interval_i)，其距离不超过 rho_i。因此该版本对分数 beta 也精确保持被声明 LP 的投影。不能把这一结论转授给使用任意中心 M 的另一编码。

局部物化账单是从 t、q、rho 共 3m 个连续量降为 q、rho 共 2m；原绝对值两行已隐含 rho>=0，故 6m+1 行变为 5m+1 行。身份、源中心展开、bounds、bits、旧 P、decoder 和证据另计。普通精确仿射 ReLU 可以直接内联 t=A theta+b，本来只需 m 个输出量与四行门约束，不能拿人为物化的 t 作为对旧 HZ 的收益。

## 保留连续源的共同 mixed ReLU 与旁路闭包

对当前整个原生父域，不仅对原网络真实轨迹，有：

```text
sum_i w_i |y_i-c_i| <= Rbar,
Rbar = R + sum_(i in G) w_i M_i(1-beta_i).
```

active 和 identity 坐标由原成本支付；inactive 时 y_i=0，|c_i|=max(c_i,0)+max(-c_i,0)，第二项由 M_i 支付。这就是把相位有关的定向位移外包成球所付的代价。

下一完整共同读出包括实际预激活和所有声明保留的旁路：

```text
g = W y + A theta + b,
z = T y + B theta + d,
K = [W; T],
c' = [W c + A theta + b; T c + B theta + d],
kappa = max_j (sum_i v_i |K_ij|)/w_j,
R' = kappa Rbar,    v_i>0.
```

同一身份的系数必须先合并。由加权 L1 诱导范数，整个栈的同一残差 K(y-c) 满足 v 加权预算 R'。这里只做固定矩阵计算，不搜索乘子，不查询 LP 状态，也不做 backward/dual rescue。

对第一段施加新原 gamma 的 ReLU，第二段保留线性读出，可用部分投影：

```text
sum_gate v_i d_i(r_i,c'_i,gamma_i)
  + sum_skip v_j |z_j-c'_j| <= R'.
```

所有项共同消费 R'，不能给每个坐标各一份完整半径。保留父状态时，必须仍保 z=T y+B theta+d 的同身份精确关系，以及所有旧 P。新 gamma 同时保留实际 g 的可靠 sign guards。真实子状态的统一见证就是 t=g、r=ReLU(g)、原 z，所以该变换覆盖完整当前父域的真实像。递归应用同一推导得到有限次组合健全性。

中心仍是原共同环境的仿射式，半径仍是相位仿射式，没有新相位乘积。但新 r 可以是 proxy 幅值，不等于每个父赋值上的实际 ReLU(g)；原 sign guards 不足以恢复 active-value 等式。若保留整个旧图等式，候选又变成给旧 HZ 添加冗余预算，而非该替换。

Affine/Conv 的仿射读出本身可精确组合；上面回到单个预算正规形的步骤一般有损。历史 y/P 保留时宽度持续增长；若删除旧 y，必须另证全部原 P、guards、消费者与 decoder 的共同投影，不能通过 metadata 忽略它们。仅有该闭包并未解决固定宽度、实际 CNN 的有用预算、GPU 舍入或完整成本。

若新门数为 a，实际保留的线性 skip 坐标数为 s，则直接编码新增 a 个门幅值、a+s 个成本量；skip 若另外物化还增加 s 个量及其定义行。门成本为 5a 行、skip 绝对值为 2s 行、另有一行共同预算；实际 g 的 2a 条 sign guards、所有旧行和真实系数非零项另计。中心系数的矩阵乘法可能填充，不能仅以行数小证明便宜。

## 一个全局 crossing 块否决当前能力候选

用共同 x,y in [-1,1]，父状态精确为：

```text
c = (x+1/4, y-1/4), R=0,
q1=ReLU(x+1/4), q2=ReLU(y-1/4),
g=q1-q2+1/4,     z=(q1,q2),
r=ReLU(g),      J=r-q1+q2-1/4 = r-g.
```

两个父门和 g 都全局 crossing；g 的紧界是 [-1/2,3/2]。不存在只靠精确 stable substitution 就排除本例的理由。

对完整 K=[1 -1; I2]、权重全为 1，kappa=2，中心和半径为：

```text
c'_gate=x-y+3/4,
c'_skip=(x+1/4,y-1/4),
R'=2[(3/4)(1-beta1)+(5/4)(1-beta2)].
```

在严格内部源 x=y=0，父 bits=(1,0)，真实 q=(1/4,0)、g=1/2。新 gamma=1。候选允许 r=3/2、z=q：距离成本为 |3/2-3/4|+|1/4-1/4|+|0+1/4|=1，低于 R'=5/2。它同时满足所有实际 sign guards、紧输出上界、同身份 live skip；即使额外保留 r>=g 也不排除它。

真实全盒关系却是：

```text
J=ReLU(g)-g=ReLU(-g)<=1/2,
ReLU(J-3/4)=0 everywhere.
```

假状态给 J=1、后继输出 1/4。旧 HZ 的一条上侧行 r<=g+(1/2)(1-gamma) 就证明 J<=1/2。故这是相对低成本旧关系的明确损失，不是未击败完整精确 HZ 就否定一切有损域。

错误来源是信息丢失，而不是错误算术：inactive 时确定的位移 y_i-c_i=-c_i 被改成无方向的半径。源相关中心与原 bits 虽仍存在，后继算子却不能再利用位移方向。全局稳定坐标的精确代入可以处理部分情况，但不能消除这里的 crossing 反例。

## L 版精确消元何时不可能增加 LP 精度

本节只指使用 L 参数、精确投影旧四行门的版本，不适用于前面的原生 M 编码。设旧父 LP 状态集合为 P_LP，原 t=A theta+b。如果对 P_LP 的全部赋值已证：

```text
sum_i w_i |A_i theta+b_i-c_i(theta)| <= R(theta),
```

则每个旧仿射加四行门 LP 点，都能取同 t、q、beta，并取 rho_i=|t_i-c_i| 延拓到 L 版的消元前纤维系统。精确消去 t 后，L 版 LP 投影仍包含旧 LP 投影。同 L/U 下不能仅凭这项 L 版替换得到更紧 LP 界。

重要量词：若预算仅覆盖原生整数父域，不能据此断言包含旧 LP 的全部分数父状态。预算可能切去旧 LP 伪点；这种收紧来自新的联合预算证书，不来自消元。整数侧只需预算覆盖整个原生父域，健全外包包含始终成立。上述结论也不是对所有新域、所有预算或所有有限时间求解优势的不可能性定理。

## M 版的整组像可以严格强于逐门 LP

不能把上节结论扩大到 M 版。取一个共同三维父域，其完整预算就是 sum_i |t_i-1/4|<=1。中心 c_i=1/4、R=1、M_i=0，各坐标紧界 L=-3/4、U=5/4。旧四行 LP 容许：

```text
t_i=1/4, beta_i=1/2, q_i=5/8 for i=1,2,3.
```

父预算在中心取零，两条门上侧都给 5/8，所以上述点满足旧 LP。L 版消元也允许 rho_i=0。M 版却要求每个 rho_i>=3/8，总和至少 9/8>1，故排除此点。

此处分离来自对整个共同球先取 ReLU 像，再作该原生编码；不是旧逐门 LP 的相同投影。在非负中心上，它包含 ReLU 到该中心的 L1 非扩张性，属于已有范数原理，不宣称新数学。父域本来就给出了共同 L1 预算，不能把它当作真实 CIFAR/Tiny 输入盒已经具备的免费证书，也没有证明胜过完整组凸包。

这个正例值得与 crossing 负例一起保留：局部联合编译确有区别，但所给便宜递归会重新丢掉关键方向信息。它不能证明当前完整闭包有实际净收益，也不应被错误的 L 版包含定理提前排除。

## 重复路线与研究决定

另查的正负绝对值束 P=T N+e、列收缩 sum_i |T_ij|<=1，直接给 ||P||1<=||N||1+||e||1。但这是 [D007](../d007_conservation_bundles_20260928/D007_DOMAIN_AND_RESULTS.md) 已有逐行三角证书的非负组合；[D061](../d061_multiway_rectifier_relation_20261001/THEORY.md) 也已有固定正负 ReLU 运输。没有为它新增实现。

本轮保留的数学增量是 source-affine 距离预算的完整共同前向闭包、两种不同投影编码、L 版包含定理的精确量词、M 版局部分离和普通 crossing 反例。不能把范数换名、精确投影、旧三角行或无方向预算称作新抽象域突破。

下一实质问题是保留相位位移的方向及其共同源关系，并让完整混权和活旁路实际消费；不能继续仅更换 L1/L2 半径或重新跑相同小控件。该结果不要求未来必须精确、不要求胜过加入相同证据的完整 HZ，也不授权 helper 补解。新颖性、GPU、真实网络能力与正式晋级仍全部待证。

本记录仅纸面推导与三位只读协作者审查。没有候选执行、模型运行、数值试验、shadow 或 replay；最近完整数学测试仍为 D158 的 4032 项。正式 1870/2413 和独立 E0 61/400 均零新增。
