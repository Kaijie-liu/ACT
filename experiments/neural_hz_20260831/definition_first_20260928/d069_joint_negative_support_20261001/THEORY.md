# 共同负项支持对相位关系接口的增强

本轮得到一条可用于宽混权层的统一关系生成规则。在相同源盒、原锚、参考系数、误差与传播日程下，它逐槽不弱于 D066 的四状态界，并保持该接口的终端 LP 包含关系。所需支持可由 D068 的原始排序算法构造；共享前缀树避免为每个锚对重新排序整个源维度。

这是关系接口的数学增强与待实现算法，不是已经完成的新 Neural HZ 域、真实网络收益或 GPU 资格。旧 HZ 加入同样关系具有相同逻辑强度；本轮不把经典次可加性、连续背包或平衡树宣称为新数学。所有结论为纸面推导及独立复核，没有执行候选或数值测试。

## 原非凸载体和共同负项

保留完整原 HZ H：连续因子、全部原二元相位、EQ/LE、共享 frame、原物理读出和输入 decoder。关系接口沿用 D066 的有限条目 (E,alpha,beta,L,U)，具体化要求同一个原赋值同时满足 H 和相应原相位条件下的读出界。有效观察不改变原整数具体化；空观察嵌入 H。语义包含序及 Affine、Conv、ReLU、Add、Concat 的范围也沿用原接口，不另声称最佳抽象或完整格。

令 z 位于可靠盒 D，所有 g_k、v 为同一 z 上的已认证仿射式，q_k=R(g_k) 是原网络门，R(t)=max(0,t)。实际读出为

```text
F = v + sum_k w_k*q_k
w_k_plus = max(w_k,0), w_k_minus = max(-w_k,0).
```

S_k 是 D066 已使用的相同点态仿射上界，S_k>=R(g_k)。不改原分组或按求解状态选择参数。准备两个共享底式

```text
B = v + sum_k w_k_plus*S_k
Hminus = sum_k w_k_minus*g_k.
```

对于两个不同的原锚 i,j，原 bits 为 alpha,beta，四个槽 s,t in {0,1} 统一定义

```text
A_st = B - w_i_plus*S_i - w_j_plus*S_j
         + w_i*s*g_i + w_j*t*g_j
Hrest = Hminus - w_i_minus*g_i - w_j_minus*g_j
Unew_st = sup_{z in D} [A_st(z)-R(Hrest(z))].       (1)
```

证明：在原锚状态 s,t 下，锚贡献恰为 w_i*s*g_i+w_j*t*g_j；非锚正项由 S_k 上包。非锚负项的幅度 Nrest 满足

```text
Nrest = sum_{k not i,j} w_k_minus*R(g_k)
Nrest >= 0, Nrest >= Hrest, hence Nrest >= R(Hrest).
```

因此 F<=A_st-R(Hrest)，再取完整盒支持得到式1。四次查询使用同一个完整 D，不求解相位子域、划分输入或运行四个子网络。R(Hrest) 只是证明中的聚合函数，不创建新网络门或 bit，也不替换任何原负项。零预激活的全部原合法 bit 选择仍满足证明。

式1支持任意锚权重符号；非锚门可以很多。相位条件只来自原门身份，不能把聚合 Hrest 的符号当作新的原相位。对 -F 使用同一规则并取负得到下界。

若 D 只是相关原源的外盒，支持对盒函数精确，但对原 HZ 通常只是可靠外界。支持最大点不能因此当作原输入见证或 ADV。区间模型参数沿用 D066 的实际原 bit 误差证明：锚参考项为 s*g_mid，不假设 s 是中点门的相位；非锚用 Lipschitz 误差。使用完全相同的已认证误差 E 扩大各槽，才有下面的数值界比较。省略模型误差、原生浮点图误差或 receiver 残差均不在本定理内。

## 逐槽和跨层不回退定理

D066 的旧上槽为

```text
Uold_00 = sigma_D(A_00)
Uold_10 = sigma_D(A_10)
Uold_01 = sigma_D(A_01)
Uold_11 = sigma_D(A_11-Hrest).
```

最后一个式子展开后正是 D066 的 B-Hminus 及正锚修正式。因为 R(Hrest)>=0,Hrest，所以对所有四槽都有 Unew<=Uold；对 -F 同理得到 Lnew>=Lold。这是对所列旧生成器的统一支配，不要求某个点或模型阳性。

编译时，同一原相位对的全部读出仍共用一个连续 delta，保留四个原 McCormick 行。在 0<=alpha,beta<=1 下，令

```text
omega00 = 1-alpha-beta+delta
omega10 = alpha-delta
omega01 = beta-delta
omega11 = delta.
```

四个 omega 非负且和为1。编译的上下侧就是 sum omega_st*L_st <= E <= sum omega_st*U_st。因此逐槽嵌套使新表系统的可行点必满足旧表系统，包含所有消费者共用同一个 delta 的情形。整数时 delta=alpha*beta，原相位仍为二元，不将上述 LP 比较误称域已凸化。

不能通过比较展开后的 alpha、beta、delta 系数是否变小来判断这个性质；交互系数 kappa 可以改变符号。正确依据是共同的非负 omega。

在相同锚和固定日程上，混权 Affine/Conv 的逐槽区间组合对区间包含单调，ReLU 对两个端点分别应用 R 也保持包含；Add/Concat 维持原 frame 和身份。所以采用相同消费规则的所有后继表仍逐槽嵌套。原值重复项必须先按身份合并，与 D066 相同。

这只证明这一关系接口及其 LP 编译的精度不回退。它不证明全网精确、真实端口已绑定、构造开销不增加、超时不增加或旧1870解已被保住；原测试和全量回放门仍完整适用。有限精度下分别向外舍入后的新旧端点仍须证明嵌套，不能直接继承实数结论。若新运行数值超限或来源不明，仍须 fail closed，不能据纸面包含定理把 UNKNOWN 记为通过。

## 普通三门的严格收紧

在 x,y,z in [-1,1] 上，取三个非比例原门及非零偏置：

```text
h = x+1/10,               p=R(h)
f1 = 4*x/5+y+1/10,       q1=R(f1)
f2 = 4*x/5+z+1/5,       q2=R(f2)
F = h/2+q1/2+q2/2-p.
```

锚为 q1、q2 的原相位。这里没有非锚正项，所以不涉及改变 secant。新支持函数为

```text
-abs(x+1/10)/2 + s*f1/2 + t*f2/2.
```

| 槽 | D066 旧完整盒平面界 | 新完整盒支持 |
| --- | ---: | ---: |
| 00 | 11/20 | 0 |
| 10 | 3/2 | 51/100 |
| 01 | 31/20 | 14/25 |
| 11 | 7/5 | 7/5 |

前三个新支持在 x=-1/10 取得：无正项时目标为 -abs(h)/2；有单个正项时 x 的左右斜率为9/10和-1/10。分别选择 (y,z)=(-1,-1),(1,-1),(-1,1)，即同时满足对应实际锚状态。最后一槽两个 x 斜率为13/10和3/10，所以最大在 (1,1,1)，F=7/5。三个原门在整个盒上都跨零。

故四个新条件上界本例都是真实条件支持，而旧表最大为31/20，新表最大为7/5。kappa 从 -11/10 变为33/100；交互没有被独立区间替代。这些精确数字是纸面解析值，不是执行结果。

下一原门 r=R(F-1/4) 的真实上界为23/20，旧标量表传播仅给13/10。原源 (0,0,0) 给 F=1/10，故后继预激活负；(1/2,1/2,1/2) 给 F=3/4，后继预激活正。后一层不是靠恒定相位制造的控制。

本例只证明新生成器相对列明旧表的收紧。没有证明完整原 HZ/全部 pair hull 加其他旧事实仍允许某个假点，也没有在本例证明共享 delta 相对独立 delta 的额外严格收益；D065 的多消费者控制仍是独立已有结果。不能将表精度差直接记为新 CERT、ADV 或定义新颖性。

## 可构造支持与共享排序成本

每个式1都是 D068 已证明的 sup_D(A-R(H))，无需免费支持 oracle。记 A=A0+sum c_l*z_l，H=H0+sum a_l*z_l。非固定、a_l!=0 的坐标取使 H 最小的端点 e_l，定义

```text
capacity_l = abs(a_l)*(upper_l-lower_l)
rho_l = c_l/a_l
t_l = a_l*(z_l-e_l).
```

把固定坐标与 a_l=0 坐标正确折入常数：后者独立贡献 max(c_l*lower_l,c_l*upper_l)。于是 H=h0+sum t_l，A=b0+sum rho_l*t_l。rho 降序下

```text
P1 = sum_{rho_l>1} capacity_l
P0 = sum_{rho_l>0} capacity_l
Tstar = min(P0,max(P1,-h0))
U = b0 + K(Tstar) - R(h0+Tstar),
```

K(T) 为按降序填充总量 T 的加权前缀和。D068 的交换证明覆盖稳定、跨零和阈值并列情况；这是经典连续背包机制的应用，见 [Stefanov 2023 第3节](https://tarupublications.com/journals/jios/volume/44/issue/5/continuous-linear-knapsack-problems-revisited/pdf)。

对一个实际消费者、一个上下方向，令d为base与全部锚可触及的共同源坐标并集大小，而非仅base中非零分母的数量。共享底式 (B,Hminus) 先建立按rho降序、并列按原坐标ID排序的平衡树，节点存子树 capacity 总和及 rho*capacity 总和。P1/P0 是阈值前缀查询；按累计 capacity 定位 Tstar，连同至多一个部分项即可求 K，均为 O(log(d+2)) 次树访问，空树直接计算常数。

每个锚对仅在 support(g_i)并support(g_j) 中改变 A、H，以及常数项。S_i 与 g_i 使用同一源支持。对每个改变坐标，先扣除旧 h0/b0 补偿并删除旧节点，再按新 a_l、c_l 重新计算端点、capacity、rho 或独立项，最后插入。这包括分母改变、符号翻转、变零及从零变非零，不能只更新 numerator 而复用旧排序。

四个槽各从同一个 base 派生并恢复；可用持久平衡树或经过证明的回滚，不逐槽复制 d 维字典。对固定互不交原锚对，总触及原系数出现数为 O(S)，所以一次建树后，全部四槽为 O((S+k)*log(d+2)) 次精确算术/比较。建树另付 O(d*log(d+2))，准备 B/H 付完整原门数和源项数；若 S 包含这些有效 base 支持，才可将它们合入同一式子。上下两方向是固定倍数，多个消费者的不同 B/H 树必须逐个计费，不能免除输出通道因子。

持久树的共享 base 占 O(d)，单槽新增节点最坏 O(s_pair*log(d+2))，四槽完成后才可释放相应暂存；保留每个版本则会累计，不能声称仍为 O(d)。坐标索引、稀疏规范化、原 source forms、原 HZ、证明记录、端点、临时峰值和终端编码另计。完整 D 维最大点解码仍需 O(D)，不能给每槽输出完整见证却只计 log d。本支持本来不是原网络 ADV；实际反例由保留的原 decoder 和具体网络验证负责。

同人口终端的共享 delta 数及表行数上界不变，但新系数可能从零变为非零，实际nnz未必不增。原读出展开、RHS、slack、证据和decoder的完整账单仍须核验，不能将新增支持构造之外的费用全部算作零。

512位限制覆盖有理数及必要中间运算；比较、除法和子树和不按固定成本硬件数对待。输入有界不保证所有中间乘积有界，超限必须拒绝。重复支持值、树证明与独立验证的完整账单尚未实现，不宣称新算法已经通过200M、256M、40M证据或内存门。

## GPU 与新颖性边界

共享负项及正上界聚合、不同消费者和锚对查询可批量组织；支持树也可使用显式索引数组而非 Python 对象。但这不是已经设计完成的可靠 GPU kernel。设备排序或前缀误差可能给出低估，不能把近似最大点的函数值当作健全上界。精确比较或可靠外包、并行更新、主机设备共存、传输、原生终端与并发门均仍待证明和实测。

这个候选改进的是可组合非凸相位关系的构造，而非仅减少存储；但其载体仍是已有 HZ 与条件观察接口，原 HZ/ImageStar 配上相同事实并不会在逻辑上更弱。定义级创新还需完整操作体系及真实普通结构上的实质收益。本轮不要求候选胜过不可计算的完整 hull 才能继续，也不把强对照审查变成新的晋级门。

下一项可执行候选是将这个支持生成器接入既有共同相位接口，显式 opt-in，先完成新的数学预注册及完整继承测试，再验证真实同结构、native 绑定、GPU、shadow 与原全量回放。当前文档不是执行预注册；没有导入候选、测试、模型或 GPU。纯标量 D068 不另包装成一个新域。
