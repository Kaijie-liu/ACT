# 支持算法的强对照和不采用的消元捷径

本页保存本轮先于宽层构造的两项审查。它们用于防止把较弱比较或已有单调消元误报为 Neural HZ 创新，不否定 D068 的构造价值，也不增设必须超越所有无限关系族的运行门。

## 常数残差的缩放关系闭包已经精确

令 Q=R(a*f)=a*R(f)，p=R(g)，a,d>0，f、g 在完整盒 D 上仿射，alpha 是 f 的原相位。设盒内存在 g<=0 的点。记

```text
K = sup_D [a*f-d*R(g)].
```

逐点 Q-dp=max(-dR(g),a*f-dR(g))，第一项支持为0，因此真实支持是 max(0,K)。D068 的原始排序最大点 zstar 还保证存在 lambda in [0,d]，使 sigma_D(a*f-lambda*g)=K。

若 g(zstar)>0，取 lambda=d；若小于0，取0；若等于0，填充断点的左右边际之间存在一个属于[0,d]的 lambda，因为 Tstar 位于[P_d,P_0]。部分填充时可取该坐标的 rho；恰在容量断点时取相邻边际之间的合法值。已填项满足 rho>=lambda，未填项满足 rho<=lambda，所以同一源点最大化 a*f-lambda*g。这是排序交换证明的结果，不运行对偶优化或相位子问题。

已有非负缩放残余关系为

```text
Q-lambda*p <= sigma_D(a*f-lambda*g)*alpha.
```

alpha=0时左侧非正，alpha=1时由p>=g成立；原零点两种标签都有效。它与p>=0推出

```text
Q-d*p <= K*alpha <= max(0,K).
```

因此全部非负缩放关系的逻辑闭包已经给出这个标量支持。若使用截零的 D020 上界，结论仍成立。若 g 全盒严格正，上述 max(0,K) 不再成立；此时 p=g，完整带源 Q 单门 hull 对该线性读出已精确。常数残差只平移结果。

无限关系族不是免费算法；D068 的有限原始构造仍可能更直接。结论不能外推到一般仿射残差、全部联合读出或完整双门 hull。是否所有符号和缩放关系加完整单门源 hull 足以覆盖任意仿射残差，本轮未证明。

## 两个看似阳性的点被旧符号关系排除

第一例在[-1,1]^2上取 f=x+y/10+1/10、g=-x+y/5+1/10、F=q-p-3f/4，q=R(f)、p=R(g)。真实上界为3/10：F是 -3f/4-p 与 f/4-p 的最大值，前者不超过3/40，后者不超过3/10，且(1,1)取等。

假点源均值(0,0)、q=11/20、p=3/20、alpha=beta=1/2给F=13/40。f的完整带源 hull 用正负(19/20,1/2)各半；g的用(-1/5,0)、(1/5,0)各半。相关源严格内部、预激活非零。

它确实通过所有 lambda>=0 的未互补 scaled D020。令 delta=f-lambda*g，中心 b=(1-lambda)/10、半径 N=1+lambda+abs(1/10-lambda/5)。四行在此点等价于 abs(1/2-lambda/10)<=N/2，由三角不等式成立。

但原 deficit q-f=R(-f) 的原相位为1-alpha，且 -f-g<=1/10，所以旧关系

```text
(q-f)-p <= (1/10)*(1-alpha)
```

立即排除该点：左侧3/10，右侧1/20。这个互补使用原读出与原 bit，不创建新门或 bit。故此例不是对完整符号对照的新能力。

第二例在[0,1]^2上取 f=x-y+1/5、g=x+y-3/5、F=q-p/3-x+y/3。若f>=0，F=1/5-2y/3-p/3<=1/5；若f<=0，由p>=g得F<=1/5-4x/3<=1/5，且存在取等源。点 x=1/10、y=9/20、q=39/200、p=0、alpha=1/2、beta=0给F=49/200。

f hull 的两点为(39/200,1/200)、(1/200,179/200)，各半；g直接用均值处真实inactive点。但 -f-g=2/5-2x<=2/5，因此旧行 (q-f)-p<=(2/5)*(1-alpha) 要求69/200<=1/5，排除它。本轮没有继续搜索更小间隙或特殊点来把这两个失败控制救成阳性。

## 私有门的单侧投影不是普通跨层定义

另检查了单调消元：q=R(g(s))只有同极性的LE消费者 a_i(s)+c_i*q<=0，c_i>=0，没有外部EQ、输出或输入decoder依赖。保留q>=0,g及原相位符号guards，删去q上侧图行后，任意新见证可取q'=R(g)<=q，仍满足所有消费者，且原bit不变。得到的是隐藏q后的精确存在性投影，不是完整(s,q)关系相同。

对标准crossing四行，额外保留 g<=u*alpha、g>=l*(1-alpha)，相同修复还保持其fractional LP边界投影。这两个可行性guard如果原来未显式存储，就要付替换行和展开成本，不能当免费删除两行。多个相互依赖的门不能各自独立修复。

这是已有[D024单调容量电路](../d024_local_phase_capacity_20260930/INTERFACE_LIMITS.md)的对偶机制，与[D004门区间可行性](../d004_observable_interface_20260928/D004_RESULTS.md)相邻。普通后继仿射EQ已违反前提；代入下一ReLU后，图两侧和保留guards又通常出现两种系数方向。即使纯正权网络也不自动满足，更不能宣称普通混权Conv/Add普遍适用。

跨领域对照[Amos等2017](https://proceedings.mlr.press/v70/amos17b/amos17b.pdf)第3.1节依靠隐藏权重非负等条件证明输入凸性，第4节讨论ReLU/linear ICNN的LP推理。这里不改变待验证网络权重、不迁入其梯度/优化路径，也不以凸域替换原HZ。该消元仅作为已有支撑数学保存，不启动另一套组件实现。
