# 共同残余支持的可靠算术核心

本默认关闭组件实现D263联合残余的区间系数支持计算，使纸面共同来源规则能使用向外舍入的实际系数。它不是新抽象域、HZ适配器或验证helper，不安装关系，不改变原H，不执行求解器。调用者仍须证明两行使用相同原源轴、保留全部残余和原BN误差；单独给两个同shape数组不构成来源绑定证明。

## 输入和统一语义

输入是同shape一维float64 Interval a、b，以及零维Interval delta、e0；含义是固定实际系数被这些区间覆盖，且

```text
rho=delta+sum_j a_j*xi_j,
e=e0+sum_j b_j*xi_j,  xi_j in [-1,1].
```

xi是同一原H前沿或同一Crest分组的共享轴。来源半径须已乘入系数、来源中心须已移入常数。这只是给原H上的表达式求上界，不以独立盒替换原非凸H。允许来源组相互相关；此时盒支持可能更松，但仍健全。

唯一入口joint_support(a,b,delta,e0,budget=...,enabled=False)默认不运行。输入完整验证、维度匹配、常数shape、有限有序范围及固定支持宽度65536均检查；不得原地修改输入或把调用者对象变成内部owned证书。所有实际操作共用调用者预算。旧D259可靠归约、向外dyadic编码及512位数值范围沿用，非法值或资源失败不给结果。

## 区间系数的重叠下界

设A_j为a_j实际绝对值的上界，B_j为b_j实际绝对值的上界。分别有Ra>=sum|a_j|、E>=sum|b_j|，二者向上归约。只有a_j、b_j区间均严格定号，才将

```text
credit_j <= min(inf|a_j|, 2*inf|b_j|)
```

计入确定同号或异号的组，否则该项信用为零。两组分别向下归约并截到非负，得到Lsame、Lopp。这里少算信用只会使上界更保守，不存在把近零系数猜成零或猜其符号的容差。

对区间内任意固定真实系数，逐项L1恒等式给

```text
||a+2b||1 <= Ra+2E-2Lopp,
||-a+2b||1 <= Ra+2E-2Lsame.
```

因此以下三个方向上界的最大值可靠地覆盖|rho|+2*max(e,0)：

```text
raw=max(Ra+maxabs(delta),
        delta_hi+2*e0_hi+Ra+2E-2Lopp,
       -delta_lo+2*e0_hi+Ra+2E-2Lsame).
sep=Ra+maxabs(delta)+2*max(e0_hi+E,0),
upper=min(raw,sep).
```

加减乘及归约全部以可靠方向执行；减项使用已证下界，不能对浮点计算出的经验信用直接相减。两支各自有效，固定min不是按实例或求解状态选择算法。delta不必为零，不允许静默重新选择D263的mu。

结果记录upper、independent_upper、raw_upper、radius_a_upper、radius_b_upper、credit_same_lower、credit_opp_lower、constant_abs_upper及dimension。四个长名称分别对应Ra、E、Lsame、Lopp；这些均为不可变的已计算统计，而非原H或原生来源凭据。新原生行的系数舍入及右端补偿不由本组件自动完成。

## 成本与使用边界

核心在一个共同统计阶段处理a/b，形成四列统计后用一次sum(axis=0)归约，不构造四套完整方向系数。当前NumPy的逐操作仍有多次数组遍历，不声称已实现单个融合设备kernel。检查、所有numpy临时数组、掩码、保守舍入、标量合成和返回元数据均在操作前计费；只说O(n)不等于完整网络费用。输入来源构造、规范化、共享身份、原H、证据写出、终端转换、设备传输及GPU归约必须在后继完整消费者合同中另外计入。

按实际预付语句逐项静态求和，支持宽度n<=65536的成功调用至多68*n+2279 work、26*n+1676累计entries，包括原公共输入扫描和标量tiny编码路径。这是本算术核心的固定计费上界，数学测试逐调用核对；不是完整来源、Python对象内存或硬件时间上界。

支持核心使用冻结D259可靠算术作为库，不调用其来源worker或旧验证流程。旧标量r/e记录缺乏相关性，不能作为输入来源替代物。固定Gram提取不得为省成本改成a=0；其会损坏D263已知正控。D263的部分共同Crest分组为后续接入路线，但总费用尚未证明，所以本版本不注册真实来源worker。
