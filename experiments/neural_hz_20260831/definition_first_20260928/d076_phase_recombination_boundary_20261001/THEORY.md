# 相位条件支持与联合重组合的严格区别

共同负项支持在固定原相位纤维上可能只是直接计算已隐含的上界，但这不意味着四状态表在分数相位处冗余。本次纸面推导给出一个普通混权两层结构：分别完整的源标记单门凸包及D066旧表都允许一组联合取值，而D070新表排除它；排除关系继续经过下一ReLU。不过，两条由已知次可加性直接得到的两门关系也排除该点。它补充了D069尚未给出的强单门对照，同时明确这个控制还不能证明超出已有联合关系，不是生产native非冗余、定义新颖性或正式能力证明。

## 固定纤维的蕴含不能代替联合松弛比较

沿用[D069](../d069_joint_negative_support_20261001/THEORY.md)的点参数情形。所有读出和界在同一源盒D上，F=v+sum w_k*q_k。固定两个原锚的状态s,t，且被比较的原LP已经蕴含所用正项上包q_k<=S_k。非锚负项幅度N=sum w_k_minus*q_k，原逐门行q_k>=0和q_k>=g_k推出N>=0、N>=Hrest。于是该纤维中逐式有

```text
F <= A_st - N <= A_st - ReLU(Hrest)
  <= sup_D (A_st - ReLU(Hrest)).
```

这是该纤维上已隐含界的直接算法，不是新增的逻辑公理。四槽编译则要求

```text
F <= U00*(1-alpha-beta+delta) + U10*(alpha-delta)
     + U01*(beta-delta) + U11*delta,
max(0,alpha+beta-1) <= delta <= min(alpha,beta).
```

原逐门LP的分数点不一定具有满足这些条件上界的共同四状态解释。因此“每条纤维界都是原LP的推论”不能直接推出这条未固定相位的编译行冗余。该观察属于已知析取关系加强的范畴，不自动产生新的抽象域。

## 普通三父门及下一激活的完整对照

源盒为x,y,z in [-1,1]，使用D069同一非比例、非零偏置结构：

```text
h=x+1/10,                p=ReLU(h),
f1=4*x/5+y+1/10,         q1=ReLU(f1),
f2=4*x/5+z+1/5,          q2=ReLU(f2),
F=h/2+q1/2+q2/2-p,
r=ReLU(F-1/4).
```

alpha、beta为q1、q2的原bits；另保留p和r的原bits。三个父预激活在完整源盒上都跨零，真实网络中的后继门也跨零。源盒给出h in [-9/10,11/10]、f1 in [-17/10,19/10]、f2 in [-8/5,2]。

比较系统P包括共同原源、全部仿射和readout等式、各个父门分别完整的source-labelled图凸包（连同其原bit）、后继门的图松弛，以及所列D066旧F/r表和同一个delta。各父门的凸包共享同一个源坐标，但允许各自的凸组合；P不是三个父门的联合图凸包。其他已知多门关系不被假定包含在P中。

取下列LP联合取值：

```text
x=-1/20, y=z=0,
h=p=1/20,       p的bit=1,
f1=3/50,        q1=91/100, alpha=1/2,
f2=4/25,        q2=24/25,  beta=1/2,
F=91/100,
r=33/50,        r的bit=1.
```

主要取值处的父预激活与后继预激活均非零。q1的完整单门凸包见证是原源(9/10,1,0)和(-1,-1,0)各半：其预激活分别91/50和-17/10，图输出分别91/50和0，原bits分别1和0。q2的见证是原源(9/10,0,1)和(-1,0,-1)各半：预激活分别48/25和-8/5，图输出分别48/25和0。两组都复现完整源均值(-1/20,0,0)，分别给出上述q1、q2和半相位。

p使用平均源上的真图点，r使用这个放松父元组上的真后继图点。这证明该联合取值通过各单门完整图凸包的交；不是仅通过scalar big M。上述凸组合见证包含盒边界，不能称它们都严格处于内部，也不能合并成一个共同网络见证。

## 新关系严格强于所列旧表并传递到下一门

D069已经解析求得同一完整盒上的四槽上界，顺序为00、10、01、11：

| 读出 | D066旧表 | D070新表 |
| --- | --- | --- |
| F | (11/20, 3/2, 31/20, 7/5) | (0, 51/100, 14/25, 7/5) |
| r | (3/10, 5/4, 13/10, 23/20) | (0, 13/50, 31/100, 23/20) |

第二行是同一偏置-1/4和逐槽ReLU变换。旧表取delta=0满足所有McCormick行，给F上界61/40、r上界51/40，均允许上述取值。下表不造成隐藏拒绝：同源点(-1/10,-1/50,-3/25)使全部父预激活为0；保留原零点的全部相位标签后，四种锚标签都可取且F=0。因此每槽任何可靠的F下界均<=0，旧r下表经clamp全为0。这里不假定D066的dyadic正项上包恰等于精确secant。

新F上行化为

```text
F <= (51/100)*alpha + (14/25)*beta + (33/100)*delta.
```

alpha=beta=1/2时，对任何合法delta<=1/2，右侧至多7/10，严格小于91/100，差21/100。新r上行化为

```text
r <= (13/50)*alpha + (31/100)*beta + (29/50)*delta.
```

右侧至多23/40，严格小于33/50，差17/200。所以F行和后继r行各自均能排除该点；不是仅因父行已经拒绝而称子行有独立作用。

即使允许为固定物理元组重新选择锚bits，也无法恢复它。原inactive-side行q1<=f1+(17/10)*(1-alpha)及q2<=f2+(8/5)*(1-beta)，代入上述物理值即强制alpha,beta<=1/2。新两条上行对alpha、beta、delta的系数全非负，delta<=min(alpha,beta)，仍有同样上限。这是固定完整物理元组在LP投影上的严格排除；7/10和23/40不是全网络的无条件真上界，F=91/100这个标量也可能由其他真实输入实现。

## 已知两门关系也排除这个控制

本控制必须继续面对更强的关系对照。重写f1=(4/5)*h+y+1/50、f2=(4/5)*h+z+3/25，由ReLU的正齐次性和次可加性，以及原y,z in [-1,1]上的secant，得到

```text
q1 <= (4/5)*p + ReLU(y+1/50)
   <= (4/5)*p + (51/100)*(y+1),
q2 <= (4/5)*p + ReLU(z+3/25)
   <= (4/5)*p + (14/25)*(z+1).
```

这些是涉及同一p与一个q的普通线性有效关系，不需要新bit、输入或相位split，也不删除原约束。在上述物理元组上，它们分别要求q1<=11/20、q2<=3/5，各比候选点小9/25。因此该点虽通过全部所列单门hull，却不能证明超过这些已知两门关系。由于这些行对每个相关两门真图点成立，完整的相应两门图凸包也会排除它。

这是对本控制的确定限制，不只是“可能存在更强cut”。不因此声称生产当前已经安装这些行，也不由一个控制断言D070对全部结构都冗余。下一项定义研究需要区别尚未由这类共同源两门关系覆盖的联合依赖，或者证明新的跨块组合与完整成本优势；不能把本控制当作已完成的新颖性证据。

## 参数误差和后继重约束的限定

固定纤维的LP蕴含前提不能直接从真实图误差证明继承。令参考g=x、实际g=x+epsilon*y，D为x in [-1,2]、y in [-1,1]，epsilon>0。参考secant S=2*(x+1)/3，真实图确满足q<=S+epsilon。但实际门的scalar hull用界[-1-epsilon,2+epsilon]，在x=-1,y=1允许

```text
q = 2*epsilon*(2+epsilon)/(3+2*epsilon)
  > epsilon = S+epsilon.
```

所以D066/D070对真实图的统一误差E不自动是分数LP的误差界。要声称某条关系在生产LP中冗余，必须另外证明majorant与全部实际残差在该LP中成立；这不影响原整数健全性证明。这个小型界限说明仅用于防止错误推理，不建立极端参数的独立实现路径。

后继重约束也须区分已有知识与已有编码。即使父LP已蕴含h<=1，仍按旧范围[-1,2]编码的ReLU会允许h=1、原bit=2/3、r=4/3；使用已知上界1的r<=bit可排除它。D066的relu目前只传播表端点，不自动更改生产门，不能把上述可能性宣称为已经发生的native收紧。

## 研究定位与完整费用

本结果把候选定位为“同源条件支持加共同相位重组合，并经前向表变换消费”，否决的是笼统的LP冗余推断，不是证明新颖性。逐门完整凸包的交不是联合凸包；上述两门关系已经足以排点，D020及生产中究竟覆盖哪些关系仍未认证。旧HZ加入完全相同的关系在逻辑上等强。下一有效强度比较必须明确生产原约束和既有联合关系，而不能反复只胜过独立单门后就宣布新域。

在读出已有物理坐标时，这一个原相位对新增一个连续delta和4条McCormick行，8个非零项；F及r各两条表行，至多16个非零项，共至多8行、24个非零项。全部原bits均保留，两个读出共享同一个delta。实际latent展开、RHS/slack、全部上下端点生成与原支持器费用、源认证、证据及decoder成本必须另算；此常数接口账不是全网成本。GPU实现、可靠舍入及速度均未完成。
