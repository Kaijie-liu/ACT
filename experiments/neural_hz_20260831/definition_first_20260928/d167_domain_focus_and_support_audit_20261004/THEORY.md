# Neural-HZ 域能力主线与表示候选边界

本轮按用户再次强调的重点收束：目标是从 HZ 数学定义研发强大的非凸 Neural-HZ。表示压缩、接口替换及查询实现可以支撑它，但不能冒充定义创新或实际验证收益。下述系数编码和载体替换仅作纸面支撑归档，不实施，不修改生产路径。

## 当前域能力的准确位置

[D157](../d157_consumer_fiber_component_20261004/CONTRACT.md) 用共同消费者幅度和原二元相位构成非凸纤维，替换新生逐门幅度；并非保留完整新门图再外挂一个求解 helper。连续源、所有原相位、EQ/LE、共享身份及 decoder 都保留。其共同代理只保留 C d，可能丢失 ker(C) 中的源方向；三门普通反例已经证明这种损失，不能称为精确新域。

[D158](../d158_joint_forward_support_20261004/THEORY.md) 的统一域内前向查询，已在小型控制中自动把共享源、带符号相位、共同幅度关系传过混权消费者和 skip，得到下一预激活上界 -3/55，下一 ReLU 界为 (0,0)。它没有外部优化器或人工提供该查询的组合权重；但这是查询实现进展，不是新的域定义、真实模型提升或相对强旧路径的已证优势。

[D159](../d159_full_interface_definition_boundary_20261004/THEORY.md) 排除了字面载体在部分完整接口上的压缩主张，没有排除所有共同纤维定义。不能以此宣布 D157 全面失败，也不能只靠接口变量减少继续宣称主线推进。

下一项可反证的能力命题是：在完整、普通、预注册的混权残差结构上，以相同输入集合、共享源、原相位和资源预算，新域通过统一前向变换，自动证明强旧同源路径未证明的后继稳定性或最终性质，同时保住被比较的已有结论。旧参照必须保留现有共享谓词、能量和次序关系，不能只比较独立区间。完整精确 HZ 是语义参照，不声称新域比精确图更精确。

这个命题尚未取得真实结构证据。如果强参照也能证明，或增益只有变量、构造时间和测试数量，不能记为域能力突破。普通终端 LP/MILP 消费新域自动生成的健全谓词仍符合原边界；禁止的是额外算法、状态修复或答案拼接替代域本身，而不是禁止终端求解。

## 相位系数的二进制编码

以下是精确表示候选，不是已经提出的新抽象域。设有界共同父坐标 x、完整保留父状态 H，g=A x+b，原相位 beta，q=diag(beta)g。所有被消去 q 的后续读出、谓词和重构使用必须完整包含于 Y=Bq；遗漏一个使用即不满足前提。若需要完整 q，就须加入相应 identity 消费者，不能只选窄读出。

对每个输出 k 和源坐标 j，以实际精确有理系数选正整数分母 D_kj，使 alpha_i=D_kj B_ki A_ij 均为整数。定义

```text
s_kj(beta) = sum_i alpha_i beta_i,
L_kj = sum_i min(0,alpha_i), U_kj = sum_i max(0,alpha_i),
K_kj = ceil(log2(U_kj-L_kj+1)),
s_kj = L_kj + sum_(t=0..K_kj-1) 2^t eta_kjt.
```

保留所有原 beta，新增二元 eta。对每个 eta 和 x_j 引入 z=eta*x_j，用 x_j 在 [ell_j,u_j] 下的四行编码：

```text
ell_j eta <= z <= u_j eta,
x_j-u_j(1-eta) <= z <= x_j-ell_j(1-eta).
Y_k = sum_j [L_kj*x_j+sum_t 2^t z_kjt]/D_kj
      +sum_i B_ki b_i beta_i.
```

原相位 sign guards 保留。整数侧正反证明直接成立：原状态确定 s 的唯一二进制展开，四行强制真实乘积；反向由原 guards 恢复 q=ReLU(g)，输出代入相同。原源 decoder 不变，零值原门的两个合法标签均保留。此证明不把 nominal 系数当作真实有误差系数，也不免除下一层源界、全部历史谓词或输出物化成本。

整数乘连续量的二进制展开与四行线性化是已有方法，不能包装为本项目的新域基础。这里仅将其用于相位系数聚合；新颖性未证。[Gupte、Ahmed、Cheon、Dey，2013，摘要及第 2 节](https://www.pure.ed.ac.uk/ws/files/137476899/110836183.pdf) 研究了这种 MILP 重构及其松弛强度。这里只用论文核对先例，不采用其搜索算法。

## 整数等价不能保证原有 LP 强度

普通同源反例取 (x,y) 在 [-1,1]^2：

```text
g1=x+y/4+1/4, g2=x-y/4+1/2,
Y=2q1-q2, x=y=0, beta=(1,1).
```

原四行精确强制 q=(1/4,1/2)，Y=0。新表示的 x 系数为 2 beta1-beta2，范围 [-1,2]，位权等式允许

```text
1=-1+eta0+2eta1, (eta0,eta1)=(1,1/2),
(z0,z1)=(0,1/2).
```

这些 z 通过 x=0 下的全部四行。y 系数取真实 digits，乘积为零；偏置相消，故新 LP 允许 Y=1。原 beta 已整数，两个实际 g 严格为正，问题仍然存在；不是零标签或极端数值问题。

再保留共同源 skip J=Y-x-3y/4，真实 beta=(1,1) 图上 J 恒为零，该 LP 点却有 J=1。因此后继 ReLU(J-1/2) 的有限外包可允许 1/2。它是同源同原标签的松弛反例，不是全输入盒 CERT、实际 ADV 或 integer-side 不健全。

完整加法电路可能修复“原 beta 整数而新 digits 分数”的漏洞，但不能由此推出分数原 beta 下的完整旧 LP 包含；新增 carry bits、行和乘积耦合均须收费。个别聚合补行排除一个假点，也不证明普遍不退。没有为此开展实现或测试。

## 编码完整成本的限制

令 m 为门数，S=nnz(A)，R 为非常数系数寄存器数，K=sum K_kj，Nalpha 为全部寄存器 alpha 的非零数。在一般 crossing、非零源界且无额外消项的逐行存储口径下：

| 新块谓词部分 | 原四行表示 | 系数编码 |
| --- | ---: | ---: |
| 新连续幅度 | m | K |
| 原 m 个相位以外的新 bits | 0 | K |
| 谓词行 | 4m | 2m+R+4K |
| 谓词 nnz | 2S+6m | 2S+2m+Nalpha+11K |

因此 K<m 远不足以说明总收益。还须计输出定义、全部父状态、位界、系数构造、实际有理位宽、重构、临时对象和终端工作。普通浮点网络的精确 dyadic 系数不等于低位宽量化。窄低精度消费者可能有账面窗口；没有证据把它推广为普通 CIFAR/Tiny 网络优势。此候选归入支撑，不作为下一轮主线。

## 因子化载体如何严格保留旧有限关系

设完整旧载体 C1=F C0，F 是可靠固定线性因子。比较使用同一父状态 d、预算 E、原 beta、参考及原界。新 native C0 纤维的共同代理 dhat 满足 C0 dhat=C0 d。令 a1=F a0，则

```text
C1 dhat=C1 d,
a1=C1 diag(beta) dhat.
```

因此新裸 native 成员映射到旧裸 native 成员。现在把每一条旧 finite EQ/LE，包括 caps、dominance、全部固定方向 energy 及任何相关继承谓词，精确代入 a1=F a0。旧行 A a1+H theta<=b 变成 A F a0+H theta<=b。任何新 finite 点都映射到旧 finite 点；此证明独立于 native 能量、位积分性及 F 的数值秩。所有真实图点都有 a0=C0 diag(beta)d，故依然可扩展。

全部消费者和后继谓词必须同步映射；新增 C0 有效行必须另证。不能忽略 W_s 或 BN 转换误差。保留旧行意味着旧行数不减少，费用为 nnz(A F)，加 F、读出、源展开和临时量；不能同时套用 D159 中只生成新坐标方向的减行公式。

更重要的是，finite 包含不保证当前自动前向查询不退。D158 的 kappa 逐载体行取 extrema，改变坐标会改变这个数。例如旧行 (2,1)、系数 1 得 kappa=2；改用两条 selector 行和权重 (2,1)，同一线性读出直接按新行算却得 kappa=3。可通过保留虚拟旧载体行及原查询权重来传递旧证书，但须明确构造、收费并重新取得资格。

所以这是一条可复用的接口保真桥，不是新域能力定理。它不能优先于共同源相位幅度关系、跨层精度及真实结构能力的研究。
