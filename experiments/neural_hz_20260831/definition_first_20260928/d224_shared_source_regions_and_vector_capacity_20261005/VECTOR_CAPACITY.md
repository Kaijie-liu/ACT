# 两个神经读出共享原像素的条件容量

真实卷积的六像素边条同时影响两个门，不能用两个互相独立的标量容量代替。本页给出保留原像素均值的两事件二维精确投影，并给普通严格对照。它是已有盒像几何与条件源界的具体组合，不是新抽象域；直接展开为全部静态行还可能比保留原源矩更贵。

## 真实结构锚点

[D194](../d194_sparse_crossing_source_fiber_20261005/REAL_TARGET.md) 的 CIFAR100 medium 四门块有四条边条，每条为六个原像素到两个预激活读出。顶边条中 channel0 的两个输入 (26,28)、(27,28) 已由 [D217](../d217_source_phase_capacity_20261005/REAL_SOURCE_CERTIFICATE.md) 认证二阶子式 Delta_T>3/2000；两个输入宽度严格正，同通道 BN 缩放严格正。所以该边条确有二维像，不是根据形状或近似 rank 推测。

这只继承历史只读结构证据，不是本轮网络执行，也不能继承旧部分工件的 native 资格。所有原像素、其他窗口、Conv3 的全部 128 个声明通道、Conv8 shortcut、Add10 与 decoder 都必须保留。下面归一化的 C 是源块可靠 affine 系数，不允许分别为两个门选择独立 BN 值。

## 两事件的保源精确关系

给定原 x∈[0,1]^m、一个共同事件及其补事件，事件质量为 lambda∈[0,1]。若它对应原相位或相位合取，原 bits 和其身份仍保留；这里只证明此接口的局部源关系，不授权任意拆相位表。令 C∈R^(2×m) 的秩为 2，列为 c_j，t 是两个读出在该事件中的共同贡献。

存在同一份完整原源分配，当且仅当存在 m_j 满足

    L_j=max(0,x_j+lambda-1) <= m_j <= U_j=min(x_j,lambda),
    t=C*m.

必要性来自事件与补事件上的盒源矩；充分性在正质量事件上取 m/lambda，在正质量补事件上取 (x-m)/(1-lambda)，零质量处任取合法盒值。两份完整原向量同时恢复 x、t 和 Cx-t，不是每个读出另找源。

取每个不同非零列方向的垂直法向 n，并保留正负两侧。精确投影为

    n^T*t <= sum_(a_j>0) a_j*min(x_j,lambda)
              +sum_(a_j<0) a_j*max(0,x_j+lambda-1),
    a_j=n^T*c_j.                                               (V)

证明：固定 x、lambda 后，允许 m 构成盒 [L,U]。其二维 affine 像的边方向只能来自 C 的非零列，各法向的最大值正是 (V) 右端。完整法向集合描述这个多边形。若某些宽度为零，保留原完整列法向仍描述相应线段或点，不能按一次查询点删除零宽列的法向。等价地，可用严格正宽度的盒趋近并取闭集极限。原 rank2 保证法向覆盖两个独立方向。

这不是把六个原像素降为两个新独立噪声：x 保留在每条容量右侧，原域与所有消费者都仍在。原生整数事件时 lambda 为 0/1，关系分别退化为 t=0 或 t=Cx，恢复原产品身份。一般原父谓词、其他事件或 joint guards 的精确性不能由这个两事件盒定理继承。

## 分别精确的标量关系仍会丢失向量耦合

取四个原像素和普通满秩矩阵

    C=[[1,0,1,1], [0,1,1,-1]],
    x=(1/10,9/10,1/2,1/2), lambda=1/2,
    t=(99/100,79/100), Cx=(11/10,9/10).

共同 m 的区间为 L=(0,2/5,0,0)、U=(1/10,1/2,1/2,1/2)。逐读出的完整标量源容量都接受：第一行使用 m=(9/100,45/100,45/100,45/100)，第二行使用 m=(5/100,45/100,44/100,10/100)。两份都严格在各自允许区间内，分别产生 99/100、79/100，却不是同一份 m。

即使另外要求完整二维事件像和补事件像，也仍接受：t∈lambda*C[0,1]^4 的见证是 (40/100,40/100,49/100,10/100)；Cx-t=(11/100,11/100) 的见证是 (6/100,11/100,25/1000,25/1000)。所有这些像内源量都严格位于 (0,lambda)，但两份像见证并不相加为原 x。

共同容量的 n=(1,1) 行则给

    t1+t2 <= min(x1,lambda)+min(x2,lambda)+2min(x3,lambda)
            =8/5.

所列点 t1+t2=89/50，违反 9/50。这说明原像素均值如何参与跨读出的条件关系，严格超过所列两个标量接口及两个独立二维像的交。

这是条件源接口的对照，不是原网络的 CERT/ADV，也未证明超过完整共同 FREE 源提升。C 的方向不是按 terminal margin 选取；完整列法向是统一结构生成的强参照。

## 静态费用与不能采用的捷径

(V) 对固定 x、lambda 的成员检查只需至多 2m 个法向、每法向 O(m) 算术。但 terminal 中 x、lambda 仍是变量；不能把非线性 min/max 当作免费的 LP 行，更不能在求解返回后调用容量 oracle 救援。

每个非零项都可写为两个 affine 式的 min：a>0 时为 min(a*x,a*lambda)，a<0 时为 min(0,a*(x+lambda-1))。于是无辅助列的精确静态展开要对这些选择取所有组合。令 D 为去重的无向法向集合，r_n 为 n 非正交的列数，行数上界是

    2*sum_(n in D) 2^r_n.

对 m=6，|D|<=6、r_n<=5，至多 384 LE；每行至多 m+3 个变量系数，所以至多 3456 nnz，零新增源矩列。此上界未去冗余，不声称实际权重达到它，也不是必要的行数下界。

强参照直接保留六个 m 列则只需 24 LE、2 EQ：约束 48 nnz，读出至多 14 nnz，共至多 62 nnz，原 x、lambda、t 及原域成本另计。若 t 也新物化，还须计其两个列。少六列而多出成百上千系数，不能称为简化或性能突破。共享 endpoint 辅助量、显式 min 电路也要完整计费，不能隐藏在前端对象里。

因此本轮不为 (V) 建候选 runner、helper 或 GPU kernel，不授权无预注册执行。它提供一个有限、精确、可反证的二维条件容量参照；真正有用的候选仍需更好的组合规则或完整成本优势。
