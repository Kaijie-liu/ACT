# 跨 query 共享 Softmax 关系研究记录

本记录补存 D108 之后、用户要求检查归档之前开展的文献、源码与纸面研究。结论是：跨 query 循环关系具有明确数学依据，但已有直接先行研究；尚未得到通过强参考对照的正控制，更没有新域、真实网络、GPU 或正式成绩突破。以下推导没有实现或数值执行。

## 研究问题和已知先例

考虑同一标准 Softmax 的多次调用 p_r=softmax(s_r)，循环下标以 k 为周期。令 C=Σ_r p_rᵀ(s_r−s_{r+1})。logsumexp 的凸性给出 C≥0；其梯度的欧氏 Lipschitz 常数 1/2 进一步给出 C≥Σ_r ‖p_r−p_{r+1}‖²。

这是已知平滑凸插值条件的应用，不是新 IQC。[Taylor、Hendrickx、Glineur 原文](https://arxiv.org/pdf/1502.05666) §2.5、Theorem 4、Corollary 1、Remark 3 明确讨论消去函数值后的循环条件，长度 2 的条件不足以代替所有长循环。先前讨论中临时写成 §2.4 末，此处更正为 §2.5 的 Remark 3。借鉴这些数学关系，不迁移论文的 SDP 或 dual 求解流程。

其他已核对的关联来源：[Fazlyab 等](https://arxiv.org/pdf/1903.01287) §III-C.3、Eq.15、Lemma 2 已使用重复非线性的跨节点二次约束；[Hendrycks 与 Gimpel](https://arxiv.org/pdf/1606.08415) §2 给出 GELU 与 SiLU 的门控定义。因此共享非线性本身不是新颖性。由 Φ(−x)=1−Φ(x)、σ(−x)=1−σ(x)，项目纸面推论为 G(x)−G(−x)=S(x)−S(−x)=x，即减去 x/2 后的余项为偶函数；仅精确相反输入可由此共享余项，不能扩展成附近输入余项相同。未开展该方向实验。

## 真实 attention 的共享范围

依据 D107 已冻结原图与算子语义手推，每层 Q 的布局是 [B,3,N,16]，Kᵀ 为 [B,3,16,N]，P=softmax(κQKᵀ) 沿 axis 3，Y=PV，V 为 [B,3,N,16]。同一个 batch、head、layer 内的不同 query 共享 K、V；两条已检查链中未见 mask 或 dropout。这里是图级推导，不是运行形状推断或原生 HZ 绑定认证。

| 原图 | tokens N | 层数 | 共享映射组数 | query 调用数 |
| --- | ---: | ---: | ---: | ---: |
| ibp_3_3_8 | 17 | 3 | 9B | 153B |
| pgd_2_3_16 | 5 | 2 | 6B | 30B |

B 保持符号 batch。IBP 的链为 51→53→54→55、107→109→110→111、163→165→166→167；PGD 有前两条。标量 κ 的具体浮点值没有在 D107 解码，不能猜测其值或符号。不能只凭同形状、同 frame 或相似名字认定共享映射；还需要完整 K 行身份、温度／缩放、支持集及同一原 latent 状态。不同头、层和 batch 不自动共享。

对每个固定原状态 θ，令 s_rj=κq_rᵀk_j，B_r=Σ_j p_rj k_j，则 C=κΣ_r(q_r−q_{r+1})ᵀB_r。K 可以随 θ 变化；只需循环内在同一 θ 共享 K，不要求整个输入域内 K 为常量。必须保留 κ。

一般实际输出 Y_r=Σ_j p_rj v_j 不是这个梯度。普通两 key 反例 K=(−1,+1)、V=(+1,−1)、κ=1 给出 Y(q)=−tanh(q)，而加权 key 为 +tanh(q)。所以不能把 PV 输出直接代入循环单调关系。若希望约束真实读出，仍须证明 K 与 V 的连接及完整残余。此反例经独立纸面复核，没有网络运行。

## 旧 Taylor 参考可能已经蕴含裸循环

以下是一个条件性冗余证明，而非对现生产实现的断言。假设所比较的旧系统确实保留共同参考 c、p⁰=softmax(c)、J₀=diag(p⁰)−p⁰(p⁰)ᵀ，并有：

```text
p_r = p⁰ + J₀(s_r − c) + e_r
1ᵀp_r = 1,    ‖e_r‖₂ ≤ E_r
d_r = s_r − s_{r+1},    P = I − 11ᵀ/N
```

由循环望远镜消去和 J₀ 对称性，精确得到：

```text
C = (1/2) Σ_r d_rᵀ J₀ d_r + Σ_r e_rᵀ d_r.
```

simplex 和 J₀1=0 给出 1ᵀe_r=0。令 m₀=min_i p⁰_i>0，有 J₀≽m₀P：因为加权方差 min_a Σ_i p⁰_i(x_i−a)² 至少为 m₀ min_a Σ_i(x_i−a)²。因此令 D_r=‖Pd_r‖₂，可得：

```text
C ≥ Σ_r [(m₀/2) D_r² − E_r D_r].
```

若旧参考还给出认证区间 ℓ_r≤D_r≤u_r，右侧每项的最小值在 D*_r=clip(E_r/m₀,ℓ_r,u_r) 处取得。各最小值之和非负，就已证明裸循环 C≥0 冗余。每边 ℓ_r≥2E_r/m₀ 是更简单的充分条件。下界未能非负只说明此冗余判据不成功，不代表新行有收益。该判据也没有证明加强的平方差循环冗余。

推导已由独立代理纸面核对。没有真实 E_r、ℓ_r、u_r 的数值人口，未得到通过 Softmax 专属强 Taylor／ratio 对照的正控制；一般旋转算子的反例不能充当真正 Softmax 的成功控制。

## 已检查的生产实现边界

本节依据当前工作树的只读源码，身份由本目录清单绑定。

- `tf_transformer.py` 的 `_sparse_simplex` 为每个 query 的概率组建立质量等式；`_softmax_ratio_inequalities` 仅在同组列之间建立 ratio 行。
- `_attention_score_differences` 的结果是每 query 的 key 差值矩阵。key_cache 复用 key 差值计算，不等于建立跨 query 循环关系。`_softmax_score_contexts` 保留 Q/K HZ、bounds、rows、scale 和 shift，但没有已认证的跨 query 映射身份。
- `solver_hz.py` 的 `_sparse_hz_softmax_value_fused` 以共享源仿射项和输出余项构造结果；constraint_parts 没有保留独立概率 HZ 的完整主体。因此不能把上一节假设的 p 图直接说成现有 fused 一定具备。

在这些检查到的构造点中未找到跨 query 循环生成器；这不是对全系统的完备性证明。现有共享原因子与谓词仍可间接保留跨 query 关系，不能把旧系统贬称为独立区间。

## 费用草算和未完成工作

一个朴素全展开方案为所有有序 query 对保存 T[r,t,j]=p[r,j]s[t,j]，每组 m²N 个乘积；所有有向三循环为 2·组合数(m,3)。由上表手算，IBP 是 44217B 个乘积和 12240B 个三循环，PGD 是 750B 和 120B。这些数是特定朴素布局的计数，不是成本下界、实际分配或认证资源预算；加强平方差还需要其他项。按需展开或借助函数值辅助量可能减少某些成本，但不能直接声称免费或新颖。

当前不实现这个全循环包装。继续研究前应找到真正 Softmax 和完整真实读出上的强对照分离，证明共享映射来源、原二元因子保留、可靠 lowering 与完整支付；若只是加入已有有效行，应归类为已知表述强化。也不把此研究问题强制指定为下一轮必须坚持的路线。
