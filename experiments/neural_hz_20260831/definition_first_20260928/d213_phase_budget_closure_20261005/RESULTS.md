## 下一步必须处理的域定义问题

候选不能仅定义一个精确的非凸集合，再将任意有限查询模板的改善称为抽象域突破。需要同时说明共同赋值的具体化、神经算子变换，以及哪些关系在后继中仍可被域自身消费。三者必须区分：集合包含的精化、算子是否保留这种精化、实际支持演算是否保住旧完整读出证书。

本轮失败提供一个可验证的最小要求：在相同source、原bits、decoder及认证关系身份下，父域精化应允许已有完整读出证书迁移为不更差的证书；后继出生也应保持这种可迁移性。若每个旧证书都包含在新可消费证书族内，且支持规则返回完整证书的最小界，则支持不退。若每次出生也保持此包含，可按网络组合归纳。当前五模板尚不满足这个要求。

本例的局部问题可以纸面定位得更精确。固定同一k、s、l、a，令

```text
r0 = ell_new / (k*l + ell_new),
S_r = (1-r)*f + r*k*s + r*a*q_j - q_i.
```

在严格crossing、k*l>0时，0<r0<1。对任意r属于[r0,1]，有精确恒等式

```text
S_r = (r/r0)*S_r0 + (r/r0 - 1)*(q_i-f_i) >= 0.
```

两项均是已有原图/关系的非负组合。ell降低会降低r0，所以新关系加原图下界q_i>=f_i已蕴含旧ell对应的关系。没有必要保存实例专用旧ell或并跑旧网络；不足的是固定消费规则没有封闭于该组合。

这提示研究在域元素中保留参数化有效关系族，而非在出生时仅保留一个消费斜率。对固定赋值，S_r关于r仿射，整族的局部集合约束等价于保留两个端点；但分别计算两个端点的完整父域上界再取最小，不等价于消费整族，不能交换最小化与父域上确界。

本失败还有一个限定的纸面恢复式。若完整查询的两门权重w1>0>w2，且r*=−w2/(a*w1)属于[r0,1]，选用该有效关系会恰好消去q_j，得到上界表达式(w1+w2/a)*f_i−(w2/a)*k*s。旧固定W中w=(E+p,−E/2)、a=1/2，因新ell小于E，该r*仍合法；所得表达式恰为p*f_i+E*k*s，纸面上恢复W<=0及child<=-1/32。这按完整方向的代数结构得到，不注入旧实例参数作为执行规则。

不过以上只证明同cap/scale下的局部证书族嵌套及特定混权抵消，不能推出cap或共有证明支撑集变化时的整体单调性，也没有给出免费可执行的全族最优支持算法。闭式clip一个参数不能保证所有方向不退；“对所有参数优化”更不能偷换成新增LP dual/优化器。后续必须先给出统一、可组合、可计费的支持定义，再预注册下一候选。本轮没有实施或执行该修正。

此恒等式是已有行的线性证明组合，不据此宣称新集合类或PLDI新颖性。真正待证明的贡献仍是：保留非凸相位与共同潜变量的神经关系闭包，能在一般重复结构上以可承受完整成本取得真实验证净收益。
