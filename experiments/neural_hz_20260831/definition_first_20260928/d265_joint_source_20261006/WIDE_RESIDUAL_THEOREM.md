# 宽残差普通结构中的联合付款假阳性

本页给出一个带共享卷积来源和 live skip 的普通参数族：共同残余支持严格变紧，但新的 JP 关系仍被原父单门 hull 和子门普通坐标界蕴含。结论否定“联合付款下降即可推出能力提升”，不否定 D263 的小残差正例，也不声称所有真实来源均冗余。以下为精确纸面推导，不是三模型或全网络实验结果。

## 原来源与非凸语义

保留两个父输入 x1,x2∈[-1,1]、qi=ReLU(xi) 及其原二元相位。另有原未选 ReLU 输出 Q3,Q4,Q5∈[0,1] 和两个仍被使用的 skip 来源 S1,S2∈[0,2/3]。它们仍带原来源身份、谓词和相位；不把整个 H 换成独立盒。以下区间仅用于支持上界。这个族允许这些端点同时实现。

```text
u = (2/3)*(Q3+Q4) + S1 - 1,
v = (2/3)*(Q4+Q5) + S2 - 1,
r = kappa*(u-v),
e = (kappa/2)*(u+v),
z = a*(x1+x2) + b*(q1+q2) + r,
d = q1-q2+e,
Y1 = ReLU(z+d), Y2 = ReLU(z-d).
```

参数为 a≥0、0≤b≤1、kappa≥3/2，tau=1。这是两个重叠局部卷积读出再加不同 skip 的形式，u、v 真正共享 Q4；不是令 a=0 的退化比较，也不依赖极小数值或单个精确相消才能保持结论。

## 严格共同支持改进

u,v∈[-1,1]，且

```text
u-v = (2/3)*(Q3-Q5) + S1-S2,
R = sup |r| = 4*kappa/3,
sup e = kappa,
Jsep = R + 2*max(sup e,0) = 10*kappa/3.
```

对任意 u,v∈[-1,1]，有 |u-v|+max(u+v,0)≤2：若 u+v≥0，左边等于2*max(u,v)；若 u+v<0，左边等于|u-v|。这只是证明中的恒等式，不是算法运行时的分支搜索。

令 Q3=Q4=Q5=1、S1=S2=2/3，可取 u=v=1，故上界可达。mu=0，联合支持恰为

```text
J = sup(|r|+2*max(e,0)) = 2*kappa,
Jsep-J = 4*kappa/3 > 0.
```

因此，保留共同来源的数值改进是严格而且幅度可观的，不是舍入噪声。

R的正端点可由Q3=1、Q5=0、S1=2/3、S2=0实现，Q4任取；交换两侧得到负端点。因此R和J使用的可达性都来自声明的同一来源族，而不是捏造两个独立残余。

## 新关系仍被旧约束蕴含

D263 的常数在此族满足 M=s0=a+3/2，c=1。两个残余守卫已同时为正：

```text
eta10minus = R+a-1,
eta01plus = R+a+b-1.
```

代入 JP 后得到

```text
s0*(2*q1-x1+2*q2-x2)+Y1-Y2-(x1-x2)/2
    <= Bnew = 4*a+1+2*b+14*kappa/3.
```

只用原 ±1 父单门物理三角包络，这一左端的父部分支持为2*a+4；这里计算三角形三个顶点的线性支持，是旧约束蕴含证书，不把原 H 的二元因子连续替换。

旧比较状态明确要求已包含 Y1≤U1（或更紧的普通输出界）以及 Y2≥0，其中 U1=2*a+b+1+2*kappa。其普通界来源是g1=a*(x1+x2)+(b+1)*q1+(b-1)*q2+(3*kappa/2)*u-(kappa/2)*v，不偷用新联合残余证书。不能仅凭真实图上g1≤U1就推定任意宽松旧ReLU松弛自动拥有这个输出界。在此明确前提下，旧状态蕴含左端≤

```text
Sold = 4*a+b+5+2*kappa,
Bnew-Sold = b-4+8*kappa/3 >= 0.
```

新的 JP 行在整个族上都冗余。kappa>3/2 时仍成立，故不是卡在某个孤立边界上的反例。

## 数学测试中的精确成员

新增定向测试使用 a=7/8、b=1/16、kappa=3/2，全部输入均可精确表示为 binary64。此时 R=2、J=3、Jsep=5、U1=93/16。新右端93/8、旧支持185/16，冗余余量1/16。该测试只检查标量证书，不把该手工族称为原始 benchmark。
