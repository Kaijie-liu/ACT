# 从真实卷积源建立多相位关系

本候选检验 D046 多原相位关系在既有三个原模型的普通第一激活块上是否适用。它解决的缺项是原参数含 BatchNorm 区间时如何认证关系种子，不用参数中点、不依赖特殊权重等式。它不是新的最佳包络定理，也不是完整 native HZ 接入或 GPU 实现。

## 共同源和相位语义

保持原 HZ 的连续输入、全部二元因子、EQ/LE、共享 frame、原网络读出和 decoder。每个源 q_j=ReLU(g_j) 使用原输入坐标上认证的 g_j 界 [l_j,u_j]。严格跨零源的 alpha_j 是该原门的 active 指示；不是新引入的独立误差或替代 bit。观察系数可以不再引用某个稳定源的 bit，但不删除原 backbone 中的任何 bit；g_j=0 时两种原合法相位均保留。

若 l_j<0<u_j，则 0<=q_j<=u_j alpha_j。若 l_j>=0 或 u_j<=0，则只使用可靠数值界 q_j∈[max(0,l_j),max(0,u_j)]，不由含零界断言原相位必须取某一个值。Padding 是预处理之后的原零值，没有原相位。

实际同一源的两个消费者为 h=a0+Σa_j q_j、w=b0+Σb_j q_j。认证区间包含原固定系数和偏置，但不是添加可自由选择的新网络参数。先按共享源身份形成 c_j=a_j-b_j 的区间 [a_lo-b_hi,a_hi-b_lo] 和偏置差；等值但不同来源的区间不允许精确相消。相同原消费者自配对时才直接使用 h-w=0 的身份事实。

## 区间参数种子定理

设实际 c_j∈[cl_j,cu_j]。对严格跨零源，非负性与幅度给出

```text
min(0,cl_j) u_j alpha_j <= c_j q_j <= max(0,cu_j) u_j alpha_j.
```

证明逐符号成立：负系数的最负贡献在最大幅度处，正系数的最大贡献也在最大幅度处；其余方向由 q_j>=0 给出零。该结论同时覆盖两种原相位，在零输入处不丢掉任何合法赋值。稳定源和 padding 用区间乘积得到常数贡献。对所有源和偏置端点求和得到同一赋值上的多相位仿射界 L_delta<=h-w<=U_delta，以及 L_w<=w<=U_w。

它们都是精确 Fraction 系数的可靠界，不是把非点模型参数取中点。每个源输入仿射形式由原 ONNX 和性质、padding/stride/dilation/NCHW 规则、已有向外 BN sqrt 区间重构；本候选不主张精确保留不确定系数之间的全部代数依赖。

将上述四界交给 D046 固定结构顺序的正部包络，得到 r=ReLU(h)、t=ReLU(w) 的

```text
lower(r-t) = -G_plus(-L_delta), upper(r-t) = G_plus(U_delta),
lower(t)   =  G_minus(L_w),    upper(t)   = G_plus(U_w).
```

顺序为原源 NCHW 展平坐标的递增顺序，跨窗口相同原门仍具有同一语义身份。没有逐锚乘消费者的笛卡儿展开，也没有相位枚举、条件 LP、求解点排序或公开标签选择。候选按原消费者通道 (0,1)、(2,3) 固定配对；奇数尾通道与自身配对，不能丢弃。所有接收通道仍计算普通界并保留诊断。

## 比较和可证伪结果

报告完整人口、实际跨零源数、四个生成包络的支持数、非恒定关系数、相位仿射 hinge 是否跨零、接收节点普通界是否跨零、物理坐标行 nnz 上界以及成本。这些仅是适用性和关系规模，不是终端非冗余、CERT 或 ADV。

特别注意，本种子产生的 U_delta 和 -L_delta 的相位系数非负。固定链在全一顶点取等，所以再次对 phase cube 求全局常数界一般不会超越相同种子的普通常数 clamp。保留下来的条件关系才是本候选研究对象，不能把共享系数相减带来的独立区间改善误记为多相位 ReLU 增益。

对任意正部输入 V，先转成非负 literal 形式 c+Σa_i z_i。固定最后一个 literal 的单锚上界为 F(P_(k-1))+(F(P_k)-F(P_(k-1)))z_k；与 D046 G_plus 的差为 Σ_(i<k)m_i(1-z_i)>=0。因此前 k-1 个边际和严格为正是条件改善该明确单锚比较对象的充分证据；它不是对所有单锚闭包或原 HZ 谓词的严格性证明。下包络相对于只保留最后 singleton 的下界也有类似非负差。本次可报告这种限定指标，但不据此筛掉其余记录。

## 完整成本和原 HZ 桥梁

每个真实源仿射形式实际构造、求界和计费一次。数值 census 只需源界，不需要此前逐源配对差值证书；源形式在取界后释放，认证的原模型/性质和冻结重构公式仍能恢复它。每个接收权重及偏置区间按原参数实际计算，所有 canonical slots 包含 padding。输出保存每个窗口的完整源引用、界和每个固定消费者对的四条稀疏包络；不省略失败或无改善记录。

传播、排序、共享系数差、D046 算术及临时容器都须在执行前预付或逐项计费。D046 无内置 budget，调用方须先按有限支持和排序比较的保守操作上界预付。保存并测量 raw bytes、packet、输入盒、源界缓存、接收系数、关系、认证 roots、最后临时形式及序列化相关的实际共存。输出可引用冻结 raw bytes 与重构器以免复制全部参数，但这些参数在内存 ledger 中不是免费。后续 native 原谓词、正向和转置查询、终端求解及 decoder 成本均未由 census 支付或获得资格。

原稀疏 exact 与 compact ReLU 均编码 z=-1 active、z=+1 inactive；因此 alpha=(1-z)/2。对已认证真实同-frame读出 X_i=c_i+Gc_i xi+Gb_i z，观察行 Σv_i X_i+Σs_j alpha_j<=d 对应 Auc=Σv_i Gc_i、Aub=Σv_i Gb_i-Σ(s_j/2)e_col_j、ub=d-Σv_i c_i-Σs_j/2。该代换不增减原因子；但 ONNX 门标签不证明 ACT 层或实际 slot 列身份。原 frame rebase 与 consumer GC 的生命周期必须另行绑定，终端列压缩与 z=2t-1 映射也必须跟随原 decoder。本次不安装这些 native 行。

## 研究定位和边界

D046 的固定链来自已知超模仿射上界，关系组合也有差分验证与 reduced-product 先例。本次是该定义候选的真实源种子与适用性检验，不因 census 通过就宣布定义创新完成。GPU 分段扫描、可靠舍入、全局峰值和终端路径仍未完成。

原测试、数值、资源、默认关闭、全量保旧门全部保留。正式 1870/2413 及独立 CIFAR100 25、TinyImageNet 36 不变。没有 attack、BaB、split、backward/dual rescue 或身份/LP状态菜单。旧三模型研究的失败保持失败，不覆盖旧存档。
