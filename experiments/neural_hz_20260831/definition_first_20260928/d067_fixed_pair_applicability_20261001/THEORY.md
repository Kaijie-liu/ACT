# 稳定锚对共享相位关系的作用

保留原HZ的连续因子、全部原二元相位、EQ/LE、共同frame和输入decoder。不删除或pivot任何bit。本页仅给已有关系接口的一项精确适用性判断，不是新抽象域或新晋级门。

两个原bit为alpha、beta，辅助连续delta满足四条McCormick行：

```text
delta >= 0
delta <= alpha
delta <= beta
delta >= alpha+beta-1.
```

B1中每个消费者各有自己的delta_j，同一消费者上下侧共用delta_j；B2中全部消费者共用delta。这里比较的是允许未固定原bit取[0,1]的终端表松弛，两个系统的其他表、原坐标及stable-bit事实完全相同。原非凸域仍保留整数bits；在全部bits都为整数时，所有delta本就唯一，不论是否稳定，B1与B2都等价。

如果已证alpha=0，则每个delta_j=0；如果已证alpha=1，则每个delta_j=beta。beta固定时对称。因此只要任一原bit由全源可靠严格界固定，全部delta_j已唯一相等；将它们合为一个delta在投影到全部原读出和bits后不改变可行集合。这对任意消费者数量、表上下两侧及已证明的后继传播均成立，不要求某张表非空，也不额外断言输出界相等。

lower>0或upper<0是充分条件；这必须是与该alpha对应的同一个原ReLU前激活的可靠界。触零不能据此固定bit，原零点两种标签均保留。源严格界通过完整归档输入盒上的仿射区间和重算，不使用前向网络之外的性质、原标签、margin、LP状态或对偶信息。

范围限制很重要：原native LP未必显式编码这些stable-bit事实。因此本定理不证明未经检查的native LP中共享delta冗余，也不把严格语义事实默认为任何分数松弛已知。它同样不否定四状态表自身的收紧、共同源支持算法或其他实际网络中的双未定锚。

此次审计对所有1440固定pair检验上述充分条件，不根据结果重新配对。若全部真实pair均满足条件，原计划在该归档上寻找共享delta额外收益的证据将不成立；这将改变下一实验选择，而不是隐去负结果继续构造相似组件。
