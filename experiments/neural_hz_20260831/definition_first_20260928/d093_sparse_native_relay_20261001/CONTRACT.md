# 原生谓词驱动的稀疏跨层关系接入

本候选把D091和D092的共同规范实现推进到自动结构绑定。数学语义沿用已冻结证明，不把稀疏矩阵接口称为新的抽象域或独立新颖性。目标是使真实H0中的后继门直接消费前级关系，而不是由调用者按实例手填有利观察。所有原连续列、二元相位、EQ与LE、输出、frame、exact及输入decoder前缀保留。

## 数学语义和稀疏等价

对于固定子门银行q，规范稀疏W行由严格递增的整数索引及非零Fraction系数组成；C行同理。空行表示完整全零行。索引必须在相应全银行范围内，bool、重复、乱序、显式零、非Fraction和超过512位系数均拒绝。调用期间H0不变；默认关闭在严格bool检查后不读取其他输入。

省略系数精确为零。将稀疏行补零，得到D092的固定稠密矩阵；每个读出、共同残余、四槽上下界、理想行及可靠舍入结果均相同。证明逐有限和进行：零项对精确有理加法、合并后范数、符号加权上下界及截距和没有贡献；规范索引顺序与原稠密遍历一致。D086基础系统和D092原来的次序、零尺度规则、共同Gamma实现与行舍入全部保持。使用65536局部支持限制和512位算术，不以更改预算取得通过。

在整数原状态theta上，全部新增变量仍是同一个theta的函数Gamma(theta)。D092的共同扩展证明直接适用，包括零ReLU的两种原相位标签。增加约束可以排除松弛中的伪辅助赋值，但不排除任何原整数theta。原行完整保留，故投影回原坐标不改变原H0。不能据此宣称H0本身已与外部网络完成认证。

## 原始门目录驱动的统一绑定

planner只接受冻结D088在同一闭合、静止H0上返回的Discovery及其完整catalog和groups。对象身份和内部seal用于防止误配，不是可对抗的内容认证或并发修改保护。planner再次认证实际门关系，不能把新辅助行当作原门，也不能使用模型名称、实例身份、标签、margin或LP状态。

沿D088固定父门配对及消费者顺序，对每一组检查全部原catalog后继。后继相位不能与该组父门或子门相位相同；后继g中至少包含两个不同子门的eta列。任一catalog eta有多个解释时拒绝整个计划，不挑选有利解释。没有适用关系时返回空计划及完整人口计数，不返回UNSAT或收益。

从实际认证输出q_j = Q_j(1 − eta_j)、Q_j > 0出发，若g中的eta_j系数为c_j，取W_j = −c_j/Q_j。每个后继对应一条完整稀疏W及单位稀疏C行。其余偏置、连续和二元系数不由planner丢弃：内核重新计算完整g − Wq。因此即使存在其他来源，变换仍用同一规则。父门归一化幅值系数−2c_j不能误用在物理子门读出上。

只依据闭合谓词可证明该代数绑定；不宣称认证了ONNX拓扑、在线分配器、全局相位可达性或所有网络算子。本版不恢复旧snapshot后继续forward。

## 成本边界

K个子门、P个观察、J个后继时，稀疏参数数为2K + nnz(W) + nnz(C)，另收费显式索引和容器访问。每个后继对应一个观察时J=P、nnz(C)=P，不再遍历P²个隐式零。每次实际仿射组合仍按合并前支持收费；不能用最终nnz掩盖出现次数。D092原稠密实现保留只读。

前级非零余项R、非零观察Pn、后级非零余项Rn时，新增连续列为3+3R+3Pn+3Rn，新增LE为12+8R+K+8P+8Rn+J。新旧EQ、二元数量不变。全部组的行列上界可求和；这不是完整nnz或端到端费用证明。

planner需要调用者拥有的单调硬计费pool，在完整schema检查、门认证、索引和组扫描之前收费；planner的根保留预估只涉及该计划构造，并不沿用D088针对D086的apply预算。输出计划不自动授予整银行执行资格。内核仍生成D086中间HZ及最终HZ，输入、中间、输出与精确证据均可能共存。全部Fraction临时、Python元数据、CSR缓冲、源对象、终端与decoder、host/device及证据成本仍需完整真实阶段证明。未执行的费用不能计零。

## 固定数学控制

新增四项测试，完整继承D092的3829项旧测试，不删除、不预跑、不另开收集。

1. 稀疏与补零稠密接口在普通、混号宽残余和全零观察上逐理想行、舍入、数组及共同扩展等价；保留原零相位标签。严格排除能力由与D092同一正控行的精确一致性承接，不挑辅助赋值。
2. 64个不同原后继门共享两子门读出，完整生成64个观察和后继关系，参数人口只计显式非零。覆盖原状态和完整行列数量，不将局部人口下降称为实际GPU或运行时加速。
3. D088发现到自动planner，再到稀疏内核；在物理子门尺度不等于父归一化尺度及混号余项时检查正确W、完整组人口与原状态扩展。用人工密集公式作独立对照。
4. 默认关闭、非规范稀疏行、坏门、资源和owner错误、eta歧义及无适用关系均fail closed，原H0不变。
