# 共同均值与神经元差异的输出纤维

本轮针对 D172 中标量近负转置证书过弱的问题，研究任意混权消费者上的共同差异关系。结果是一条保留全部原相位、共同源和输入重构的有损输出纤维，以及可直接形成前向查询行的证书。它无需消费者有相反列，也不要求 U 接近 −λVᵀ。

普通三门控制中，新证书可关闭一个后继门；同人口的全局预算双分支矩阵透视松弛仍允许正值。但更强的同源点态能量参照已经包含本关系，加入共同均值并不是新几何原理。本文不宣称新颖性、组件资格、真实模型提升或完整代价通过，不据此接入生产。

## 具体化与健全块变换

父域 H 保留连续因子、原二元因子、EQ/LE、共同 latent/frame、所有旧谓词及原输入 decoder。q 是 H 中的共同读出，g=Vq+c∈R^m，可靠界为 ℓ≤g≤u。真实新输出 r=ReLU(g) 的全部活消费者必须通过 y=Ur∈R^n 表达，原隐藏 r 无其他读出、旧谓词或 decoder 消费者。旁路 z=Sq+y+d 保留原 q，不复制源。

令

```text
P=I−11ᵀ/m, μ=mean(g), t=mean(r),
G=UPUᵀ,
e=y−tU1−(1/2)UPg.
```

重复 ReLU 的 firm 单调性给每一对 i,j：

```text
(r_i−r_j)² ≤ (g_i−g_j)(r_i−r_j).
```

对所有 pair 等权相加，再完成平方，得到

```text
||P(r−g/2)||² ≤ ||Pg||²/4.                         (1)
```

这一不等式是已有 repeated-nonlinearity QC，不是新定理，参见 [Fazlyab 等第三节 C3 与 Lemma 2](https://arxiv.org/html/1903.01287v3#S3.SS3.SSS3)。本研究借用其数学关系，不采用 SDP 或乘子优化。保持共同 t 后，单独关系 (1) 连同 y=Ur 的精确投影为

```text
e∈range(UP),      eᵀG†e≤||Pg||²/4.                (2)
```

证明：写 r=t1+Pg/2+h，h∈1⊥，则 e=Uh。给定 e，满足这些等式的最小范数 h 的平方恰为 eᵀG†e；存在范数不超过右侧的 h 当且仅当 (2) 和 range 条件成立。所有消费者和 t 用这同一个 h，不能各自选择见证。

新块只保留 y、t 共 n+1 个新连续量，原 m 个 γ 全部保留，采用原 sign guards ℓ_i(1−γ_i)≤g_i≤u_iγ_i。本文讨论普通 crossing ℓ_i<0<u_i，不以此排除真实零点的两种合法标签。

再对完整载体 C=[U;1ᵀ/m]、v=(y,t)，保留 active/inactive 两侧四组 aggregate caps。对每行 a=C_j，定义

```text
A_i^−=min(0,a_i u_i),   A_i^+=max(0,a_i u_i),
I_i^−=min(a_i ℓ_i,0),   I_i^+=max(a_i ℓ_i,0).

Σ_i γ_i A_i^− ≤ v_j ≤ Σ_i γ_i A_i^+,
Σ_i (1−γ_i) I_i^− ≤ aᵀg−v_j ≤ Σ_i (1−γ_i) I_i^+.
                                                               (3)
```

mean 行的两项下侧条件同时给 t≥0 和 t≥μ，其余给相位容量。所有 γ=0 或所有 γ=1 时，(3) 分别强制 v=0 或 v=Cg；不是仅给一个凸输出球贴无效标签。

具体化取同一个满足 H、guards、(2)、(3) 的赋值；仿射读出按共享身份作用。原 HZ 以没有这种新块的元素精确嵌入。该域保留连续量和原二元非凸并，不替换成 CZ、zonotope 或纯区间。

真实 ReLU 像取其真实 t,y 即满足全部条件，所以这是整个父域上的健全替换。它不保留旧 m 个隐藏 r，也不是旧完整图外加 helper。但“单 QC 的精确投影”不等于“ReLU 图与全部 caps 的精确投影”；后者在本文没有成立。

## 不恢复隐藏幅值的前向消费

对固定方向 w，令 a=Uᵀw、κ=1ᵀa、v=Pa。对固定 g,t，裸式 (2) 的精确方向上界为

```text
wᵀy ≤ κt+(1/2)vᵀg+(1/2)||v||·||Pg||.             (4)
```

这是球的支持公式，不调用优化器。对整个当前父域已有可靠 ||Pg||≤R，则可发布线性行

```text
wᵀy−κt−(1/2)vᵀg ≤ (R/2)||v||.                   (5)
```

负向同理。须先把源项和旁路的同一 q 系数合并，再求父支持；不能先分别取区间再声称保留同源抵消。向量 P 不需物化：减去 mean 即可，||Pa||²=||a||²−κ²/m。可靠算术不能直接用未认证的浮点相减结果作为非负平方范数。

Affine/Conv/Add/Concat 精确消费当前共同 y,t 和旧源。下一个 ReLU 可在整个当前域的读出上重新构造此关系，并认证其新的全父域 R；不需恢复上一块的 r。所有历史纤维、父谓词和源仍存在，不能宣称固定存储或半径不增长。若已把原生关系替换为有限行的更大 LP 外包，后续只能使用对该外包仍有效的预算，不能冒用原生预算。

## 普通三门控制与全局预算强参照

令 x,s,h∈[-1,1]，

```text
g=(x+s/4+1/4, x−s/4+1/4, x+h/4+1/4),
U=(1,−2,11/10), y_out=Ur,
J=y_out−3s/8−2h/15.
```

三个法向非平行、偏置非零，全部门 crossing，界为 [−1,3/2]。U 的三列没有相反配对，U1=1/10 非零。共同源上的代数归约给

```text
||Pg||²=s²/8+h²/24≤1/6,
||PUᵀ||²=931/150,
UPg=3s/4+4h/15,    0≤t≤3/2.
```

故由式 (5)，

```text
J≤3/20+sqrt(931)/60 < 3/20+31/60 = 2/3 < 7/10.
```

因此整个父盒的后继 ReLU(J−7/10) 恒为零，使用有理证书 2/3 时仍有 1/30 间隙。此严格间隙不依赖极端数值；按相同共同源 Gram 上界和可靠系数运算，足够小的系数/偏置扰动仍保留严格性。这里没有计算该扰动邻域的生产数值证书。

完整保留输入的单门理想 hulls 均允许同一个分数点：

```text
x=s=h=0,   γ=(1/2,1/2,1/2),
r=(5/8,3/10,5/8),   t=31/60,   y_out=57/80.
```

各门分别由严格内部源 ±(4/5,4/5,0)、±(7/20,0,0)、±(4/5,0,4/5) 的等权混合实现其 retained-source 单门元组。它们不是同一个共同混合；这正是旧放松允许该点的原因。该点给 J=57/80，后继允许 1/80；这不是真实反例。

比较还可加强到完整 C=[U;mean] 的 D156 双分支矩阵透视松弛。使用同一源、参考 gbar=(1/4)1 和可靠全父域预算

```text
d_g=g−gbar,
||d_g||²=3x²+xh/2+s²/8+h²/16≤59/16=:E.
```

该分数点有 a=C(r−diag(γ)gbar)、s_C=Cd_g=0。把 packet 改写为 output−(1/10)mass 和 mass 两个正交行，

```text
Q=CCᵀ在此坐标中为diag(931/150,1/3),
a_contrast=793/1200, a_mass=47/120,
T=Q/2, Ibranch=Q/2.
```

完整双分支透视能量是

```text
4(793/1200)²/(931/150)+12(47/120)²
 < 3/10+19/10 = 11/5 < 59/16.
```

故该点不仅通过单门 hull，还通过这份完整的全局预算相位耦合二次松弛及全部 range 条件。原 sign guards 和 t≥max(0,mean g) 成立；其相对 d_g 的 active/inactive output-cap 区间分别为 [−121/80,25/16] 与 [−17/16,79/80]，包含 a_output=7/10 和 −a_output。mass-cap 区间分别为 [−1/8,5/8] 与 [−5/8,−1/8]，包含 ±47/120。

还可直接给出同源 lift：u_c=(1/2,7/40,1/2)、v_c=−u_c，u_c+v_c=d_g=0、Cu_c=a、Cv_c=−a。γ_i=1/2 时其完整逐坐标 centered-perspective 能量为4||u_c||²=849/400<59/16；每个 active/inactive scaled bound 也满足。这里没有偷偷让两分支使用不同的 source。

因此新对比关系不是只击败人为弱的独立输出区间，也不是从一个非法放松点得到分离。它排除了这份明确同人口、全局预算的双分支透视放松允许的分数点。所有仅由该连续放松蕴含的有限线性行仍接受该点；γ_i=1/2 仍不是原整数域的合法原生赋值，不能混淆。

但它不能被外推为超过全部 D158 查询或完整 HZ，更不是真实网络新增 CERT。下面的点态强参照恰好说明关键增益来自保留源的对比预算，而不是增加一个均值变量本身。

## 共同 grounded 关系的冗余定理

若同一个 r 还满足已有 grounded sector

```text
||r−g/2||²≤||g||²/4,
```

令 h_c=P(r−g/2)，则完全等价于

```text
||h_c||²≤||Pg||²/4 + m t(μ−t).                    (6)
```

由 t≥0,t≥μ，有 t(μ−t)≤0。因此 (6) 自动蕴含 (1)。在这些共同条件下，等权全对 repeated QC 不是额外增强。

共同投影只需把式 (2) 的右侧换成式 (6) 的右侧。最小范数 h_c 同时见证两项：这里可以精确胶合，是因为两个约束的中心和度量相同、半径嵌套；不是任意多项 QC 都可以独立投影后相交。

若没有 Jensen 下界，则一般必须同时保留

```text
eᵀG†e≤||Pg||²/4,
eᵀG†e+m(t−μ/2)²≤||g||²/4.
```

这一共心情形仍有同一个最小范数见证。不能遗漏 range 条件或把负半径当成零。

## 与点态双分支参照的包含与严格损失

取同一 C=[U;mean]、零参考、点态 E=||g||²，并保同一 mass 下界和 phase caps。D156 的共同代理 ĝ 满足 Cĝ=Cg、||ĝ||≤||g||，保留输出 C diag(γ)ĝ。定义

```text
r'=[g+(2diag(γ)−I)ĝ]/2.
```

则 Cr'=C diag(γ)ĝ，且 ||r'−g/2||≤||g||/2。故这份点态 D156 语义包含于 mean+grounded 投影；后者又满足 contrast 关系。双方和同一 caps 相交仍保持包含。这里点态 E 不是 D157 实现的全局相位仿射预算，不能混用。

严格损失可出现在普通混合相位，不能靠全 on/off 例混淆已保留的 caps。固定

```text
g=(1,2,−1), γ=(1,1,0), U=(1,−1,1/2),
r'=(21/20,39/20,0), t=1, y_out=−9/10.
```

有 ||r'||²−gᵀr'=−9/200≤0，t≥max(0,mean g)=2/3，所以共同 grounded 与 contrast 均通过。该源点可嵌入三门均 crossing 的普通父盒：

```text
g=(x+s/4+1, −x/4+s+2, x/2−s/3+h−1),
x,s,h∈[−4,4],
ℓ=(−4,−3,−25/3), u=(6,7,19/3).
```

在源零点，上述 y,t 通过完整 active/inactive caps。inactive mean 为 −1/3，inactive output 为 −3/5，均在相应第三门范围内。

相反，这个 y 的任何 D156 共同代理必须为 ĝ=(23/20,41/20,−6/5)，其平方范数1393/200>6=||g||²。因此即使不固定 t，这份点态 D156 也拒绝 y；真实 y=−1。附加旁路 x/10 和后继 ReLU(y+x/10+19/20) 后，同一源处真实值0而新域允许1/20。这是固定源物理损失，不是整个盒的安全结论。

## 完整费用与本轮决策

新幅值 n+1 对比旧 m；只有 n+1<m 才有这一项局部数量优势。原 bits、父源、历史 P 和 decoder 不减少。2m 原 guards、4(n+1) caps、k 个正负方向的2k行合计

```text
2m+4(n+1)+2k.
```

axis k=n 且 m=2n 时为10n+4行，旧逐门四行是8n；即使尚未降任何球，8n+4也已更多。三门一输出控制为2个新幅值、3个原bits、16行，对比旧3幅值、3bits、12行；源盒与bits的显式边界均另计于两侧。未知的冗余合并、稀疏布局或求解速度不假定为零成本。

每方向支付 Uᵀw、均值/平方和、vᵀV、源展开、R及可靠算术。显式 G 需要约 O(mn²) 稠密工作和 O(n²) 存储；只发布方向行可以不物化 G，但不能据此宣称免费 native membership。构造共同源 Gram 预算一般也需计费；本控制若只用每行绝对和再平方，会得到1/4而非1/6，丢掉当前后继门的分离。

矩阵乘法、分组均值与平方归约适合设计 GPU 算子，但本轮没有 GPU 运行、向外舍入资格或端到端速度证据。CNN 同宽块 m=n 还多一个 mean；ViT48→96→48局部可49替96，但完整token人口和历史接口均未计价。不能因此把主目标缩成一个容易的小例。

本轮保留这条“源对比预算如何穿过完整消费者”的正向证书及精确适用边界，不建立新组件框架、不重跑旧版、不修改生产，也不宣布已得到 PLDI 级新域。新颖性、实际参数上的精度及完整代价仍须分别突破。
