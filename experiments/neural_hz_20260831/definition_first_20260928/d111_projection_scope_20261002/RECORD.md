# 端点投影支撑成果与定义主线边界

用户询问 Neural-HZ 进展及是否跑偏。本轮核实：目标仍是定义级非凸域、GPU 和真实净能力，但近期产出偏重已知关系与局部消元。D111 只证明 D110 一个有限 LP 块的精确投影，不增加该块的数学强度，必须归为支撑成果，不能当作 Neural-HZ 新定义突破。

此前 D110 提供精确端点传递、不能当通用 Jacobian 的反例和费用证据，属于纸面研究 progress；它没有实现或新增资格。本轮不为投影另建候选、不扩大同类消元研究。以下记录保留可复用结论、未成功的控制及真实接口问题，防止下次重复。

## 保留概率相关上界的精确投影

考虑 a<0<b、0<l≤u，令 D=b−a、Delta=u−l。原系统是 a≤h≤b、l≤lambda≤u、2lambda≤r，及 z=lambda*h 的四 McCormick 行。消去 lambda 后，精确得到：

```text
a <= h <= b,    r >= 2l
D*z >= (b*l−a*u)*h + a*b*Delta
D*z <= (b*u−a*l)*h − a*b*Delta
z >= l*h + (a/2)*(r−2l)
z <= l*h + (b/2)*(r−2l).
```

证明：原系统给 lambda 的下界为 l、l+(z−lh)/a、l+(z−lh)/b，上界为 u、u+(z−uh)/a、u+(z−uh)/b、r/2。所有下界不超过所有上界化简为上述行；反向取三个下界的最大值，即可同时满足全部原行。任何不消费 lambda 的其他约束仍原样保留。不能额外要求 r≤2u；r≥2u 时最后两行本来就是冗余的。

对 h∈[−H,H]，这等价于两条带状约束：

```text
|z−(l+u)*h/2| <= H*(u−l)/2
|z−l*h| <= H*(r−2l)/2.
```

代入 h=d−c、z=p−q、r=p+q，全部坐标继续共享 c。若 l 是概率下端点的 logmean，r≥2l 已由概率下界和算术均值性质蕴含，不重复记为收益。

只要局部 lambda 没有其他消费者或非冗余联合约束，就可以逐坐标消去；若还有精确 logmean 图、lambda 产品或跨坐标关系，不能套用这份局部投影删除它们。这里仅覆盖 a<0<b，不声称其他符号情形已经实现。精确 LP 等价是实数／有理数定理，向外舍入后需重新证明健全性，不能自动声称仍完全等价。

这属于经典线性消元的具体化。旧 [D029](../d029_conditional_observations_20260930/THEORY.md)、[D035](../d035_cross_phase_source_20260930/THEORY.md) 已有相关上界和共同消费者投影，不能把消元原理重新记成发明。

## 未完成的普通结构控制

检查过四 token 结构 t=(x,−x,y,−y)、s=t+epsilon*(1,1,−1,−1)，其中 |x|,|y|≤delta、epsilon≥0。令 eta=tanh²(delta/2)，共同归一化差有精确范围：

```text
c_minus = log(cosh(epsilon)) + log(1−eta*tanh(epsilon))
c_plus  = log(cosh(epsilon)) + log(1+eta*tanh(epsilon)).
```

证明：cosh(x),cosh(y)∈[1,cosh(delta)]，c 是 log[(exp(epsilon)cosh(x)+exp(−epsilon)cosh(y))/(cosh(x)+cosh(y))]，对 cosh(x)/cosh(y) 单调。两端分别由 (|x|,|y|)=(0,delta)、(delta,0) 达到。故统一 |d_i−c| 上界为 epsilon+max(|c_minus|,|c_plus|)，小半径下为 epsilon+O(epsilon*delta²+epsilon²)。

一般 sector 的切向伪误差可能与两带约束分离，但尚未完成该结构的真实 Softmax 概率盒、全部指定 Taylor／ratio／增量关系、共同动态 PV 与不稳定后继的严格控制。尤其在参考中心放入非零伪误差，会被到中心的已知增量关系排除，不能当强阳性证据。没有数值搜索、实验或网络 ADV。该控制扩展在本轮收束，不为维持候选而转向特殊构造。

## 当前生产接口的具体事实

只读检查 `tf_transformer.py`、`solver_hz.py`、`tf_mlp.py` 和 frame 分配器，发现：

- Softmax 原本已按概率输出分配连续槽。如果原对象和列身份可认证复用，就不能把全部 p/q 重新算成新列；但旧列已分配不等于其谓词仍在后继。
- `logsumexp`／`log_denominator` 仅用于数值 bounds，没有共同 logZ latent 可免费复用。HZ 的输出中心字段 c 不是 D110 的归一化差 c。
- `sparse_hz_lift_bounds` 返回新的输出 EQ/LE，没有在该函数合并输入 HZ 谓词；dense lift 则保留。不能仅凭相同 frame 断言 sparse 概率对象携带全部原源谓词。
- PV 外层能读取概率对象，但内部 `_sparse_hz_softmax_value_fused` 不接收完整概率 HZ；它合并的是 score／QK／value 谓词。安装端点关系必须显式认证并接回需要的概率和来源约束，不能假设自动消费。

这不是全系统不健全或应立即修补生产的结论；丢失约束通常是保守精度损失，而且其他原源约束可能从 Q/K/V 路径保留。这里确定的是新模块的接入合同尚未完成，生产保持不变。

消去 lambda 也没有消掉共同 c 或动态 (p−q)V 的费用：D110 锚日程仍需 144B／24B 个 c，直接动态 value 产品仍为 39168B／1920B。这些仍是纸面特定展开计数，不是最低成本或资源资格。
