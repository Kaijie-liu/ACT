# 保留共享源方向的非凸 Neural-HZ 候选

本轮改变的是域定义，不是给旧完整门图添加查询 helper：用同一个代理同时约束源方向、完整消费者读出与原二元相位，再将消费者的激活余项作为共享坐标。固定中心化读出使原源仿射部分继续参与下一层。纸面证明覆盖整个当前原生父域，而不只是真实网络轨迹。

结论仍有限：新关系严格细化 D156/D157 的环境空间代理，但唯一完成核对的有损普通控制只恢复了旧逐门 HZ 已有的信息。没有证明实际费用优势、外部新颖性或新增验证能力。因此本轮不启动组件实现，不扩充 helper 测试，不宣称 CIFAR/Tiny 已提升。以下均为纸面推导与独立核对，非机器证明或实验结果。

## 元素、共享赋值与具体化

保留原 HZ 的物理连续源 x、全部显式二元相位 beta、原 EQ/LE 谓词、共同 frame/latent 身份及输入 decoder。新增 bank 坐标 r_k 具有唯一身份；所有消费者与后继约束引用同一赋值。域元素的读出为这些共享坐标的仿射式，具体化是满足全部原生 bank 关系及线性谓词的赋值的读出集合。

原 HZ 通过零个新 bank 精确嵌入；原 signed bits 与 beta=(sigma+1)/2 只是可逆编码。新 bank 具有相位条件的二次/值域关系，因此不是通常仅有线性谓词的 HZ；表达不同本身不能当创新性证明。保留原 bits 的整数语义，不将整个域改成 CZ、zonotope 或区间。零点的两个原相位标签都保留。

这一候选没有保存新层的全部逐门输出 q 再附加球约束；它保存完整消费者包 Cq。设所有活线性消费者为 B，必须有已认证的 B=F C，其他活使用也必须包含。若 C 包含活 identity skip，不能删除它以制造压缩。可采用 D157 的 C=[B;ones]，但不授权事后换成少数有利方向。D159 的完整接口反例和真实规模限制继续有效。

## 新 bank 的定义

设当前 preactivation 为 g，固定结构参考为 gbar。以当前规定的 canonical 坐标写出

~~~text
d = g-gbar = A(x-xref)+e,
S = range(A), s = C d, D_beta = diag(beta).
~~~

A 只取原 source 的显式仿射系数；e 是同一个父赋值中所有旧 bits、旧 bank 和常数余项的精确仿射读出，不能重新取盒、独立重采样或省略。参考按固定 nominal bits、源中心与零 bank 幅度代入，不要求参考可达。若系数来自带误差的模型转换，误差必须已经有同源认证表示；仅用浮点中心矩阵的 range 不健全。

可靠的 E(beta_old) 必须覆盖整个当前原生父域的 ||d||^2，且保持规定的 phase-affine 形式。新增 p=rows(C) 个共享余项 r，定义

~~~text
exists dhat:
  dhat-e in S,
  C dhat = s,
  ||dhat||^2 <= E,
  r = C(D_beta-I/2)dhat.

Cq = (1/2) Cg + C(D_beta-I/2)gbar + r.
~~~

原 guards 仍约束同一个 g 和全部原 bits。D157 的 branch caps、mass dominance 及有限行若保留，都必须同步代入 a=r+s/2；a 不再是另一份独立幅度。那些 caps 是有效加强条件，不断言它们由裸范数纤维推出。

健全性见证为 dhat=d。父赋值不变，新 bits 取该 g 的合法原标签，便有 r=C(D_beta-I/2)d，读出恰为 C ReLU(g)。零值两标签给出相同真实读出。这个证明对每个当前原生父成员成立，因此可以递归；它不是只沿具体原网络样本成立的证明。

单个 bank 的 a=r+s/2 是三角仿射双射。按出生顺序同步变换全部旧行、消费者和后继式后，不改变该 bank 的集合。下一层的 A/e 分解则明确采用上述 canonical 形式，不能声称对任意重参数化不变。

## 代理的几何与确切损失

记 W=S intersect ker(C)，R_W 为其正交投影。因为 d-e 属于 S，代理的前两项等价于

~~~text
dhat in d+W.
~~~

所以最小范数代理是 h0=(I-R_W)d，剩余半径平方为 E-||h0||^2。对 a=r+s/2，裸包的中心和形状矩阵为

~~~text
a0 = C D_beta h0,
K  = C D_beta R_W D_beta C^T,
a-a0 in range(K),
(a-a0)^T K^dagger(a-a0) <= E-||h0||^2.
~~~

这是源平移空间与消费者核的交，而不是只约束环境空间长度。取相同 E 和相同附加 caps 时，新原生域包含于 D156/D157；当旧代理沿 S 以外的方向偏移时，可以严格排除它。但旧精确逐门 HZ 仍精确描述真实激活图，新有损域不可能在集合精度上优于那个精确图。

若 W 被 C D_beta 消去，固定该相位的包是精确的；若 W=0，则所有相位都精确。特别是 rank(CA)=rank(A) 足以令 W=0。这个情形是精确门关系的压缩坐标表达，不能仅凭表达改变宣称新能力。即使 W 非零，预算刚好耗尽等特定赋值也可能为单点；不以这些特殊情况作为主线。

一个不依赖新代理显式存储的数学等价式如下。令 Pi 是 S 的正交投影，p0=(I-Pi)e，H_beta=[C D_beta; C(I-D_beta)]，则

~~~text
z = [a; s-a] - H_beta p0,
G_beta = H_beta Pi H_beta^T,
z in range(G_beta),
z^T G_beta^dagger z + ||p0||^2 <= E.
~~~

必须使用正交投影 Pi，不能在同一能量预算下换成 AA^T。一般交叉块 C D_beta Pi(I-D_beta)C^T 非零，不能沿用 D157 的两块独立 Gram。中心 H_beta p0 含新相位与旧幅度的乘积；此原生等价式不是线性 MILP 编码，也没有给出便宜的完整查询。

每个 bank 的代理是该共同包的存在见证，不是新的替代原输入；不同 bank 没有被证明共享同一个代理源。共享的是原 x、全部旧状态身份及持续保留的原生关系。

## 跨层闭包与预算

直接使用旧读出 Cq=C D_beta gbar+a，会让普通下一层的显式原 source 系数变成零。如果仍按“只取原 source”定义 A，那么 S=0，下一层代理强制 dhat=e=d，回到精确相位与旧幅度乘积图。这不是省去费用的闭包。

上述固定中心化形式保留 (1/2)CA 作为包的显式原 source 系数。经过实际消费者 F 后为 (1/2)BA；Conv/Affine 左乘、Add/Concat 按同一身份合并或堆叠，旧关系全部保留。代数抵消仍可能使 A 为零，不能保证每层非零；也不能保证较深网络仍然紧。

因为 D_beta-I/2=(1/2)diag(2beta-1)，每个整数相位原生成员都满足

~~~text
||M r_k||^2 <= (1/4) ||M C_k||_2^2 E_k.
~~~

将下一层偏差拆成一个源/常数项、各旧相位列 b_j(beta_j-tau_j) 与各旧 bank 项 M_k r_k。对非零项用预定等权 Cauchy；若共 n 项，则

~~~text
E_new = n * [K_source
             + sum_j ||b_j||^2 |beta_j-tau_j|
             + sum_k (1/4) K_k E_k],
K_k >= ||M_k C_k||_2^2.
~~~

源项与矩阵范数用可靠、向外的固定证书，n=0 时为0。因为 E_k 是旧相位的仿射式，这个预算仍 phase-affine。1/4 只作用于对应 bank 项；n、源项、相位项、历史 bank 数和矩阵范数都可能增长，绝不据此声称总半径收缩。

这是 D147/D148 已知的中心化反射与新的平移源纤维结合，不把 1/2 恒等式重命名为新原理。若最终只保留这一范数界而丢掉 C dhat=Cd 与 dhat-e in S，就又退回旧范数外包。

## 不新增相位乘积的固定线性后果

原生关系不能免费精确降为旧线性终端，但有两类统一生成的线性必要条件。它们仅使用结构和固定参考，不查询性质方向、margin、LP 状态或模型身份，不引入 backward/dual rescue。

第一类是固定源正交方向。对固定 lambda、mu，令

~~~text
v_beta = D_beta C^T lambda + (I-D_beta) C^T mu,
L = (lambda-mu)^T a + mu^T s.
~~~

任取已认证的固定 h in S-perp。由于 h^T dhat=h^T e，平方非负给出

~~~text
2L <= E + ||v_beta-h||^2 + 2h^T e.
~~~

对整数原 bits，平方项逐坐标为 beta_i((C^T lambda)_i-h_i)^2+(1-beta_i)((C^T mu)_i-h_i)^2，因此 RHS 对原 bits 和旧状态仿射，没有新 beta*e 项。固定 h=(I-Pi)v_tau 是结构性选择，tau_i=1 当且仅当 gbar_i>0；tau 不需可达。

在 tau 处，相对 h=0 仅平方项降低 ||h||^2；包含平移项后，完整 RHS 的变化是 -||h||^2+2h^T e，故即使在参考相位也不保证更强。因此若要继承 D157 的有限行，应对其原六方向一并保留 h=0 行和 h_tau 行，不能择优删掉旧行。这是一条固定生成规则，不是第二条求解路径。

第二类是固定参考相位的完整值域关系。令

~~~text
J_tau = [C A; C D_tau A].
~~~

按确定的坐标顺序，对 J_tau^T 做可靠的精确 RREF，取整个左核基 z=(u,v)，不由 caller 选择有利方向。每个基向量给出 h_tau=C^T u+D_tau C^T v in S-perp。于是

~~~text
|u^T s + v^T a - h_tau^T e|
 <= R sum_i |(C^T v)_i| |beta_i-tau_i|,
R >= sqrt(Emax).
~~~

证明是将左侧写成 |sum_i(C^T v)_i(beta_i-tau_i)dhat_i|，再用每个 |dhat_i|<=R。R 必须是固定可靠的 Boolean-box 上界；不能用依旧相位变化的 R 偷带乘积。每个绝对值式发出两条线性 LE，|beta-tau| 对原 bits 仿射。

在 beta=tau 时，这些行保留完整参考 chart 的平移值域；其他相位只给固定宽度外包，不声称恢复全部原生关系。不枚举相位、不生成新标签，也不假装 RREF、源映射或左核系数免费。

## 原生语义不能被有限 lowering 偷换

下一层的预算和健全变换以完整 native 为父域，有限行只是在普通终端 LP/MILP 上的健全外包。终端的分数 bits 不是原生成员；终端产生的输入也必须经过具体原网络与性质验证，才能计 ADV。

可以从 native 定理推出下一层的约束，再统一向线性终端降级；不能丢掉 native 后把较大的有限多面体当父域，却继续使用只对 native 成立的 1/4 范数预算。保存未被终端精确编码的语义不等于已经消费了其全部精度，全部历史 bank 及其证明依赖仍须收费。

没有新增 QP、SOCP、SDP、相位搜索、attack、split 或 dual helper。给定赋值下的 Gram/range 检查也不是全域验证器。GPU 可以承担将来的仿射、Gram 等批量算术，但目前没有设备实现、向外误差认证或速度证据；终端的困难并未因此消失。

## 普通有损控制：确有细化，但不超过旧 HZ

以下是固定纸面控制，不是模型样本或新增 CERT。取 x in [-1,1]^3，g=A x+gbar：

~~~text
A = [[1,    1/4, 0],
     [-1/3, 1,   0],
     [1/2, -1/2, 0],
     [1/4,  1/3, 1]],
gbar = (1/4,-1/4,1/4,-1/4),
B = (1,-1,1/2,-1/4), C=[B;ones], tau=(1,0,1,0).
~~~

声明 Bq 与 Q=sum(q) 都是实际后继消费者，质量行直接复用，因此 p=2、消费者数 r_B=2。可靠全源能量证书为 E=397/72，R=5/2；原 bounds 为

~~~text
L=(-1,-19/12,-3/4,-11/6),
U=(3/2,13/12,5/4,4/3).
~~~

S 的正交方向为 (-8,15,26,0)，rank(A)=3，而 rank(CA)=2。W 的生成向量 k_S=(123,154,-51,-226)，C D_tau k_S=(195/2,72)，非零。因此新 native 真正有损，不是全相位精确旧图。

在原 x=0、beta=tau，代理 k_S/1024 合法，能量46261/524288<E，a=(195/2048,9/128)。对应代理源为 (39/512,45/256,-611/2048)，active proxy q=(379/1024,0,205/1024,0)，inactive preactivation 为 -51/512、-241/512。全部相应 caps、mass 和原 guards 仍成立；原源的真实 a 却为0。这个剩余损失必须保留为负控制。

旧环境空间代理 k/32，k=(3,1,-4,0)，给出 a=(1,-1)/32、s=0，也通过旧分支 bounds 与能量，但不满足新的源空间关系。J_tau 秩为3，其标准左核基为

~~~text
(-4/13,-1/13,-48/65,1)
  = (-20,-5,-48,65)/65.
~~~

所以统一的完整左核规则会自动生成方向，而非手工挑出。写

~~~text
Lstar = -48a_1+65a_2-20s_1-5s_2,
|Lstar| <= (5/2)[17(1-beta_1)+113beta_2
                         +41(1-beta_3)+77beta_4].
~~~

在 tau 左侧必须为0；旧伪点却为 -113/32。还有一条可手工推导的有效能量后果也能排除它：

~~~text
-2Lstar <= E+289(1-beta_1)+12769beta_2
                +1681(1-beta_3)+5929beta_4,
113/16 > 397/72.
~~~

这一额外能量行对应 lambda=(68,-60)、mu=(20,5)，不属于 D157 每坐标六方向，因此不计入下述固定46行，也不是其自动生成正控。自动排除来自完整左核两行，无需扩充方向规则。

后继普通仿射读出可写为

~~~text
j=(48Bq-65Q+20s_1+5s_2+29/2)/113.
~~~

在参考相位 j=-Lstar/113；新关系强制 j=0，旧伪点有 j=1/32，故下一 ReLU(j-1/64) 在该旧伪点取1/64。到这里仅证明相对 D157 的同源同相位细化，尚不是全盒性质结论。

更强的比较否定了把它称为新验证收益：由源关系直接得到

~~~text
113j = 17(g_1-q_1)+41(g_3-q_3)-113q_2-77q_4 <= 0.
~~~

最后一步只需旧逐门 epigraph 的 q>=g、q>=0。旧四行 ReLU 的线性外包已经对整个源盒证明后继恒零，无需这里的新球、chart 或 helper。因此不能用这个正控晋级，不能作为超越旧 HZ 的证据。

## 全部费用与研究决定

若固定保留 D157 行、每个原能量方向增加一个 h_tau 行，并增加完整左核的两侧行，新增行数为

~~~text
2m + 16p + 2r_B + 2k,
k = 2p-rank(J_tau).
~~~

四门控制为46行，D157为32行，而原四门完整图为16行；这里没有费用优势。这个公式也不包含全部旧行、bounds 构造、源矩阵 A、完整 C/B/F、稠密 e 读出、Pi/基、CA/CD_tau A、RREF 及有理系数增长、native range 检查、各历史 bank、终端降级、见证与 decoder 费用。不能将存在代理的消去、惰性引用或少数幅度宣称为净节省。

精确 projector 不需要真的存成 m×m，但任何因子化及其算术必须计费；允许结构化实现不等于已经实现。宽源、高秩接口和深层旧 bank 增长都仍是普通网络问题，未被解决。当前小型组件的原资源门不改变，不外推到 CIFAR/Tiny 全层。

决定：归档为定义与健全递归的纸面候选，不实施该版，不重复扩充其 helper 正控。下一次推进须在完整普通结构上给出相对旧强参照的可用收益：同精度更低完整费用，或同预算更强的实际可消费关系；不可能要求一个真实外包在集合精度上胜过精确旧图。若继续这个候选，必须具体解决完整接口/终端费用，而不能只调 toy 系数或重复证明原生关系更紧。

Smooth/Transformer、新家族、GPU、同结构实测、13家族保全与全量回放仍是未完成目标，不因本轮局限被缩小。正式1870/2413与独立E0 61/400不变，新增0。

## 先例与创新边界

项目内 D147/D148 已有源仿射中心化，D156–D158 已有共同代理与源绑定缺口；本轮新增组合是平移源空间限制、固定 canonical 递归、源正交有限行及完整 nominal-chart 左核规则。它们的外部新颖性未证。

混合连续/二元乘积可提升为线性约束并非新发现。[Sharp Hybrid Zonotopes 的 RLT 部分](https://arxiv.org/html/2503.17483v2#S4)已研究相关提升；其变量与行数费用不能在这里省略，也没有采用它作为额外求解路径。[Hybrid Polynomial Zonotopes 的定义](https://arxiv.org/html/2506.13567v1#S3)已组合连续多项式与二元生成元、约束；不能把本候选仅有非凸或乘积表达说成首创，也不能不核对其精确定义就宣称完全等价。

这两项只核读相关定义/定理范围，不是完整文献综述。论文级贡献仍需实际定义优势、健全且可付的算子、完整比较与真实验证结果共同支持。
