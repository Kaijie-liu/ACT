# 三 token 双通道 Attention 的严格比较

这是普通有界输入上的手推控制，不是采样、求解器实验、实际网络 ADV 或新正式分数。根代理和数学代理独立检查了公式。比较对象明确如下，不能扩大为全部已有抽象域。

## 同源模型

取独立源 t,u∈[-1,1]：

```text
s=(t,u,0), p=softmax(s)
V_1=(t,−2t), V_2=(−2u,u), V_3=(0,0)
Y_1=p_1*t−2*p_2*u
Y_2=−2*p_1*t+p_2*u.
```

两个输出的混权矩阵为 [[1,−2],[−2,1]]，行列式 −3，不是两个复制输出或零和恒等式。原源、概率、所有六个产品 T_it=p_i*t、T_iu=p_i*u 均共同保留。

## 被比较的加强参考

参考同时具有：原源盒；同一个 s,p；每个概率的真实最紧边际界；simplex；六个产品的完整逐项 McCormick；两列守恒 Σ_i T_it=t、Σ_i T_iu=u；两个 Y 的共同线性读出；原点完整一阶核心；每个输出真实最紧的标量 Taylor 余项区间；跨消费者共享同一余项身份。

额外允许参考具有原 s,p 图的任意有效约束，乃至该图本身，以及真实联合 Y 输出像的任意有效约束。下述点在这两个投影内分别是真实点，所以仍通过。这里没有给参考完整 (t,u,p,T,Y) 联合图或完整联合余项图；它们当然会排除该点。也不声称所列参考包含所有生产浮点前处理与所有 PZ/IQC 规则。

## 一个同时通过这些条件的伪赋值

记 η=1/100。取：

```text
t=u=0, p=(1/3,1/3,1/3)
T_:t=(−η,η,0), T_:u=(η,−η,0)
Y_1=Y_2=η.
```

源和概率是原点的精确 Softmax 图，概率比例等有效约束都成立；两列质量均为零，与 t=u=0 一致。对 p_i 的最紧区间 [l_i,U_i]，在 t 或 u 为零、p_i=1/3 时 McCormick 允许：

```text
max(l_i−1/3, 1/3−U_i) ≤ T_ij
T_ij ≤ min(1/3−l_i, U_i−1/3).
```

p_1、p_2 的最紧界为 l=1/(1+e+e²)、U=e²/(1+e+e²)，p_3 的界为 l_3=1/(1+2e)、U_3=e/(e+2)。由 e>2，全部 l_i<1/5、U_i>1/2，所以六个 ±η 或零产品均在上述区间内。即使使用最紧概率边际而非松盒，伪赋值仍通过。

完整一阶核心是 ((t−2u)/3,(-2t+u)/3)。真实标量余项为：

```text
r_1=Y_1−(t−2u)/3
r_2=Y_2−(−2t+u)/3.
```

在 (t,u)=(1,0)，r_1=e/(e+2)−1/3>1/6，r_2=−2*r_1<−1/3；在 (0,1) 两者交换。因此两个真实最紧余项区间均包含 η，也都包含负数。伪点在源零点的余项恰为 (η,η)，不是靠削弱成对称的任意大误差盒才通过。

真实联合 Y 输出像也包含 (η,η)：取 t=u=−a，则 Y_1=Y_2=a/(2+exp(a))。该函数在 [0,1] 连续，零点值为0，一点值大于1/5，因为 e<3；故存在 a∈(0,1) 使其等于 η。这里仅是存在性证明，没有执行根搜索。该真实输出使用的是另一源；参考遗漏的正是输出与当前源之间的共同约束。

## 联合行严格排除该点

[源单调性行](DEFINITION.md)给出 E=p_1*t+p_2*u−(t+u)/3≥0。因此：

```text
F=Y_1+Y_2+(t+u)/3=−E≤0.
```

伪点 F=2η=1/50，严格违反。这个比较比“独立输出盒”强：连全部所列共享产品、列守恒、真实概率图、最紧坐标余项和真实输出像都不能单独消除它。

但真实联合余项满足 r_1+r_2=−E≤0，所以如果参考已经保留完整联合余项像，差距就消失。精确共享乘积关系 T=p*z 也会在当前源零点强制 T=0；不能声称本控制战胜了它。新增联合行是已有数学机制在本候选坐标中的显式保留，尚非新颖性证据。

## 经过真正不稳定的后继 ReLU

再取独立 v∈[-1,1]，令 R=ReLU(F+η*v)，保留它的原 signed 相位和完整 guard。真实状态 F≤0，故 0≤R≤η，且上界在 t=u=0,v=1 达到。t=u=0,v=−1 为严格非激活点，v=1 为严格激活点，v=0 保留零点两标签；不是靠删稳定相位取得结论。

在伪点取 v=0、R=2η 及激活相位，满足该伪预激活的精确 ReLU 图，却被新推得的 R≤η 排除。传到此输出的差为 η=1/100。

边界：若参考已经免费继承真实全局后继预激活上界 η，该假点会先被旧门排除，不能再主张此处严格优势。本节证明的是源联合行能生成该更紧后继界，以及它可穿过一个两相位均出现的门；不是对具有同一全局信息的所有算法的优势。
