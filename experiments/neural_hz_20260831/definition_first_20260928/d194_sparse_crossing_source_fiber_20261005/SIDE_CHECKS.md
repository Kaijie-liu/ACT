# 共同源绑定的两个补充核查

## anchor 的实际幅值不能省略

在 D192 的同 anchor 误差中，保留原 anchor 相位 b 和 q_a=ReLU(g_a)，记 a=2q_a-g_a=abs(g_a)。若整个父域有 abs(g_i-g_a)<=R_i，则真实 e_i=(beta_i-b)*g_i 满足

```text
0 <= e_i <= (R_i-a)*abs(beta_i-b).
```

同相位时 e_i=0；异相位时两个预激活异号，abs(g_i)+abs(g_a)=abs(g_i-g_a)，立即得到该界。合法异相位因此还要求 a<=R_i。此关系比仅用 R_i 的距离半径更强，D193 点 g_a=-1/2、e_2=9/10、R_2=11/10 被它排除，因为新上界为3/5。

令 Z=C*e。对完整消费者方向 n，令 w_i=max(n*C_i,0)，W=sum w_i，B=sum w_i*beta_i，A=sum w_i*R_i*beta_i，K=sum w_i*R_i，各和只取非 anchor 项。由 a*b=q_a 可推得

```text
n*Z + W*q_a <= g_a*B + A + b*(K-2*A).
```

这明确找回了实际 anchor 幅值，而非只收紧常数。但 B 是加权多 bit 量，不是一个 bit；g_a*B 不能用“二元四行精确”蒙混。共同乘积、所有方向相关性及 q_a 的真实绑定仍须付费。旧逐门相位差关系也能推出这些界，因此没有新颖性、整体后继收益或成本资格；不启动新 helper。

## 复制源不等于保留源与输出的真实关系

本轮核读 [Mao 等 ICLR 2026 原文](https://proceedings.iclr.cc/paper_files/paper/2026/file/8b7d8779c020fa3671ad267152362d56-Paper-Conference.pdf)第 2.2 节和 G.1，并由协作者核对[作者 arXiv v4](https://arxiv.org/html/2410.06816v4#A7.SS1)。其 G.1 用逐层复制输入来论证完整性。按第 2.2 节的逐层凸包语义，下述自包含反例表明“复制本身足够”这一步不成立；这不是对所有等价变换或其存在性定理的否定。

取 x in [-1,1]，第一激活层保留

```text
u=ReLU(x), v=ReLU(-x), c=ReLU(x+1)=x+1.
```

两个端点输出为 (1,0,2) 和 (0,1,0)，因此完整联合凸包包含 (u,v,c)=(1/2,1/2,1)，且源副本仍准确对应 x=0。后继网络是

```text
F=ReLU(u-1/2)+ReLU(1/2-u)
  +ReLU(v-1/2)+ReLU(1/2-v).
```

它在该抽象点的实际输出为零，所以任何在上一凸域上健全的逐层图凸包都必须保留这一延拓；c 继续通过稳定副本也不改变结论。真实网络却有 F=1/2+abs(abs(x)-1/2)>=1/2。

同一函数也可写成另一结构 -x+2ReLU(x+1/2)-2ReLU(x)+2ReLU(x-1/2)，完整单层联合图的线性读出可给出精确界。这再次限定反例只反驳给出的复制构造及相应证明步骤，不能宣布不存在其他有效变换。

本项目已有共同见证反例与此一致。这里不导入论文算法、不修改网络、不请求外部作者行动，也不把检查文献证明当成 Neural-HZ 能力成果。它只防止后续把“输入身份还在”误当作“联合非凸关系已经保住”。
