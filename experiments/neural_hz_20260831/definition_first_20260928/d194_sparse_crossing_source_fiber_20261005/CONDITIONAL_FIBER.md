# 固定共同源时的私有幅值条件凸包

这份纸面推导用于真实小 crossing 块的定义研究。它给出精确的条件对象，也说明廉价线性化仍属于已知分区关系，不能将其命名为已完成的新 Neural-HZ。没有实现、数值实验或资格晋级。

## 对象和精确性范围

设 z 为共同源，p_i 属于 [L_i,U_i] 为互不重叠私有输入块的标量仿射像，h_i(z) 为实际共同源的仿射读出，g_i=p_i+h_i(z)。只在本局部投影中，固定 z 后各 p_i 可独立取其完整区间。

所有原源、原 signed bits、EQ/LE、共享身份和 decoder 均保留。下面 beta 是原 bit 的 0/1 记法；仅讨论查询凸包时临时允许 beta 在 [0,1]，不把原生相位改成连续量。零值 g=0 的两个原标签都合法。

固定 z，以下四行加 p、beta 的界，给出单门带标签图的凸包：

```text
q >= 0,
q >= p+h,
q <= (U+h)*beta,
q <= p-L+(L+h)*beta.                         (1)
```

当 L+h<0<U+h，令 t=p+h，将 t 分成 inactive 和 active 两个区间的带权值，q 是 active 部分，即可得到标准两段图的理想四行。反向令 active 值为 q/beta、inactive 值为 (t-q)/(1-beta)，四行确保各在相应区间，零质量项取任一合法端点。若 L+h>0，后两行与 q>=p+h 强制 beta=1、q=g；若 U+h<0，则第三行与 q>=0 强制 beta=0、q=0。等号边界保留合法零标签；若 L=U，则直接为固定源值的标签图。无需除以未认证的区间宽度，也不执行相位子问题。

固定同一个 z 时，独立私有块的凸包可以按乘积胶合：conv(product_i G_i(z))=product_i conv(G_i(z))。证明取各有限凸组合的乘积权重，得到一个共同混合；反向由投影立即成立。这里是集合论证明，不是运行时枚举相位的算法。

但联合对象 union_z {z}×product_i conv(G_i(z)) 一般非凸；不能再把 z 凸化并声称条件信息没有损失。将 beta 保持整数时，式 1 是原图的另一种准确写法，不产生比精确 HZ 更强的集合表达力。

私有性相对于声明接口而非整个模型成立。若其他消费者读取私有原输入的其他线性组合，p_i 的独立区间投影就不能替代完整父关系；必须保留源定义与其他读出。本轮真实四门只取得几何接口，不取得全模型条件独立性。

一个严格内部控制说明区别：x1,x2 属于 [0,1]，p=x1+x2，g=p-1/2。在 x1=1/10、x2=9/10、beta=1/2、q=3/4，p 属于 [0,2] 的标量四行均成立；但完整原输入图的有效行 q<=x1+beta/2 给上界7/20。这条行对 inactive 标签由 x1>=0 保证，对 active 标签由 x2<=1 保证。因此不能把标量 p 凸包说成保留所有私有像素后的理想凸包。即使支持图不重叠，历史谓词或其他已保留非线性关系也可能重新耦合私有块。

## 可付线性参照恰为已知两分区关系

若可靠 h 在 [l,u]，保留 v=beta*h 并用四行二元产品编码，可把式 1 两个上界写成

```text
q <= U*beta+v,
q <= p-L+L*beta+v.
```

beta 整数时乘积编码精确。在放松查询中，v 的两条上界为 v<=u*beta 和 v<=h-l*(1-beta)。当 v 无其他消费者时，精确消去 v 得到四个 q 上界：

```text
q <= (U+u)*beta,
q <= h-l+(U+l)*beta,
q <= p-L+(L+u)*beta,
q <= p+h-(L+l)*(1-beta).                    (2)
```

产品的两个下界与 h、beta 盒界相容，所以没有遗漏其消去条件。式 2 加 q>=0、q>=p+h 共六行；原四行的全局 L+l、U+u 上界包含在其中，另两行为分区界。对四门，在未计共同 source、bounds、guards/readout 的同口径下是 24 行对 16 行，不增加 q 数量。若 v 被跨门关系消费，这个独立消元就不再合法。

双方都已有物理 p、h 时，非零通用系数的逐门行 nnz 为旧10、新16；四门增加8 LE及至多24 nnz。若 h 直接内联本 patch 每门15个共享输入系数，两条新增行每门至多17及3 nnz，四门增加至多80 nnz。每条 p 定义 EQ 还有至多12个原源系数和一个输出系数。这是符号上界，非实测存储或速度；两方同等物化 h 的收益属于共享表示，不属于新域能力。

这些是已有两分区/Anderson subset 类型关系，不是新的凸化原理。[Anderson 等原论文](https://optimization-online.org/wp-content/uploads/2018/11/6911.pdf)第 5.2 节给出了更广的单门输入相关 formulation。将六行装到旧 HZ 上，不能据此宣布定义创新；反过来，未来候选也不能删掉这些廉价强参照来制造优势。

共同 z 的不同 h_i 仍然关联；对每门分别做产品包络，不是整个共同源图的理想凸包。完整费用还包括 p 定义、共享 z 和 BN、读出系数、所有主支路/shortcut、继承谓词、界认证、终端、重构及 host/device 共存。31 个局部读出不能绕过原小组件或真实来源的资源门。

## 下一项需要证明的内容

有用的下一定义必须让小 crossing 块共享的源与相位关系在混权、skip 和下一 ReLU 后仍可查询，且不能只是保留同一计算图、独立六行或已知 RLT helper。这里没有提供免费条件凸包 oracle，也没有引入 QP、SDP、非线性优化或新的求解器。

固定 z 的胶合证明和真实重叠 patch 提供了具体研究对象；联合查询、非凸近似的可控损失、与强旧参照的实际精度/费用差异、新颖性、GPU 和深层闭包仍未解决。故不将本轮推导转为默认实现或扩大测试框架。
