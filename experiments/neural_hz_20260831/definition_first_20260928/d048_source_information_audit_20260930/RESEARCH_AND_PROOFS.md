# 共同源信息与多相位包络的适用边界

本轮把 HZ 外的研究机制与已经封存的真实证据对照，得到一个影响下一步的结论：继续精修只读取逐门幅度的包络生成器，不能恢复它已丢掉的共同输入信息。下一定义候选应改进关系种子及其跨算子组合，而不是把稳定性化约、更多包络计数或预算调整作为创新主线。

这是一份纸面数学审计与定向文献核验，不是新实现或完整文献综述。两项待查真实信号被进一步分类，但没有证明它们在 production LP 中均冗余，也没有否定整个多相位方向。正式成绩与所有门槛不变。

## 一个信号实际只有单个祖先相位

已存 medium 的位置 (0,0)、通道 38/39 的 companion lower，完整非零支持只有原源 ordinal 5850。其形式精确为

```text
t >= C (1 - alpha_5850),  C > 0.
```

JSON 中常数 C 的分子为
`66454792489322476589894940905776300445450438778206195385808379999510222184811571`，分母为
`6582018229284824168619876730229402019930943462534319453394436096000000000000000000`；唯一相位系数的分子为上述分子的相反数，分母相同。源 w_lower 的四个支持为 451、5850、12826、12840，系数均为负。本轮核对的是封存字面系数及原公式，不是另跑巨整数 prefix 认证。

一般地，设原种子为 `Lw=c-sum d_i alpha_i`，`d_i>=0`，且其 phase cube 下界严格为负、上界严格为正。D046 singleton minorant 为

```text
G_minus(Lw) = sum_i max(0, c - sum_{j!=i} d_j) (1-alpha_i).
```

证明：补 literal `z_i=1-alpha_i` 后常数为 `c-sum d_i<0`，故空集正部为零，第 i 个 singleton 边际正是上式系数。若只有一个系数为正，就严格退化为单锚行。alpha_i=0 时，其余 bits 的最大贡献给出 w>=C；alpha_i=1 时 t>=0。因此这属于已知关断面下界及原 D036 的单锚机制，不是本次多相位输出支持的新增证据。

这不表示该行无能力价值。取 `q=ReLU(x), x in [-1,1]`，`w=1/2-q`，`t=ReLU(w)`。点

```text
x=1/20, q=2/5, alpha=1/2, w=t=1/10
```

属于父门的完整带标签凸包：它是 `(x,q,alpha)=(4/5,4/5,1)` 与 `(-7/10,0,0)` 的等权平均。此点还满足真实子门 t=ReLU(w)，却违反 `t>=(1-alpha)/2=1/4`。可另加原稳定负门 `h=-1,r=0` 而不改变这个事实。故“已有单锚机制”与“被 native 原约束蕴含”必须分开。

## 另一个信号与完整单门源接口的关系

已存位置 (0,7)、通道 126/127 的 difference upper 保留四个原相位支持；它不是单锚退化。其 w 普通下界严格为正，h 外包跨零。delta_upper 的七个相位系数均正、常数负；输出 upper 常数为零。以下结论不依赖这些系数的具体大小。

设连续比较前沿 P 保留共同坐标 h、w、原 alpha 的查询视图 `0<=alpha<=1`，以及线性后果

```text
h-w <= U(alpha),  w >= 0.
```

令原子门 `r=ReLU(h)`，稳定门保持 `t=w`。若仿射 G 满足 `G(alpha)>=max(0,U(alpha))` 于整个 continuous cube，则

```text
r-t = max(h-w,-w) <= max(U(alpha),0) <= G(alpha).
```

所以该行对完整 graph over P 有效；它是保留坐标上的仿射不等式，因而对这个图的凸包仍有效。D046 G_plus 具有所需全 cube 性质；D047 的种子由 `q>=0,q<=u alpha` 和稳定源盒的线性组合得到，因此在保留这些事实的连续 P 上也成立。

该结论只说明，这条行被“带完整共同源接口及相位的单个不稳定接收门凸包”吸收。不能把 P 换成逐坐标盒、丢弃 alpha 的投影、scalar big M 或任意现有 Anderson 实现。理论凸包可能难以计算；本轮没有构造它，也不把胜过它新增为资格门。

一个非边界纸面反例说明不能声称 scalar gate 行已经蕴含它。取两父门 `q_i=ReLU(x_i), x_i in [-1,1]`，

```text
h=-1/2+q1+q2,  r=ReLU(h),  w=t=1/2.
U_delta=-1+alpha1+alpha2,  G_plus(U_delta)=alpha2
```

其中固定顺序为 1 后 2。旧松弛点为

```text
x=(3/4,-1/2), q=(4/5,1/20), alpha=(9/10,1/10),
h=7/20, r=31/50, receiver_bit=21/50.
```

两个父门的完整 scalar labelled hull 均满足：`q>=0,q>=x,q<=alpha,q<=x+1-alpha`。接收门使用真实区间 `h in [-1/2,3/2]`，其两个上界分别为 `63/100`、`64/100`，均大于 r=62/100，下界也满足。但是 `r-t=3/25>alpha2=1/10`。因此该已知生成机制仍可能强化普通单门松弛；实际封存那条 native 行的非冗余性尚未验证。

两个此前直接冗余信号的结论保持不变。四个 hinge 中没有两接收门同时外包跨零的记录，但这只是已存首块的有限证据，不证明所有其他非 hinge 关系无效，更不证明完整网络不可能受益。

## 幅度统计量不足的普通结构族

下面的整个参数区间说明为何只改 clamp 不够。令 `x,y in [-1,1]`，`1/2<a<1`，两个网络都保留原门和各自原 bits：

```text
q1 = ReLU(x)
A: q2 = ReLU( a*x + (1-a)*y )
B: q2 = ReLU(-a*x + (1-a)*y )
h = q1-q2.
```

两个源门预激活的逐门精确区间都是 `[-1,1]`，没有相等门、比例门或极端数值前提。若生成器只消费这些区间、相位身份和消费者权重，两个网络按节点身份对应得到完全相同的幅度种子

```text
-alpha2 <= h <= alpha1.
```

由相同种子决定的后续包络也相同；frame hash 不同不能成为按模型身份选择公式的理由。然而真实上界是

```text
sup_A h = 2(1-a),   sup_B h = 1.
```

A 的证明：固定 x 时取 y=-1 最大化 h。x<=0 时 h<=0；x>=0 时 `h=x-max(0,a*x-(1-a))` 的两段斜率为 1 和 1-a，均正，故最大在 x=1，值为 2(1-a)。B 有 h<=q1<=1，并在 (x,y)=(1,-1) 取到 1。整个开区间 a>1/2 都有严格差异，不只依赖一个系数恒等点。

取 `2(1-a)<tau<1`，追加普通原门 `r=ReLU(h-tau)`。A 恒有 r=0，B 可有 r=1-tau>0。a=3/4、tau=3/4 时分别为 0 和 1/4。这里没有数值运行、网络攻击或 benchmark 计分；这是对所选统计量不充分的解析证明。

重要边界：原精确 HZ 仍然保存 `g2=±a*x+(1-a)*y`、共享 x/y、原 bits 和谓词；丢失只发生在新增关系生成器的输入摘要中，不是 HZ 的集合表达力缺陷。一个读取原共同源差式的既有方法已经能识别这个例子：A 中 `g1-g2=(1-a)(x-y)<=2(1-a)`，ReLU 的增量界给出同样上界。故该例也不是本项目的新域正控，而是下一生成器必须避免过早边际化的必要条件。

## HZ 外文献怎样改变选择

[ReluDiff](https://arxiv.org/pdf/2001.03662) 的 §4.1 同时传播差值和一侧值，§4.2 明确利用门的稳定状态。项目判断：恢复稳定门恒等式是正确的支撑修正，但已有先例；保留共同源差式也不能单独算创新。只借前向关系推导，不导入其反向细化和输入分裂流程。

[PRIMA](https://ggndpsngh.github.io/files/PRIMA.pdf) 的 §§3.1、5 使用联合神经元约束，其 Split Bound Lift 会切分输入多面体。项目判断：应研究共享源小组关系，而不是仅增加边际精度；联合约束的启发可用，但分裂流程不进入本项目。

[Sparse Polynomial Zonotopes](https://arxiv.org/html/1901.01780v2) 的 §II D3、Proposition 10 区分保留 dependent factor 身份的 exact addition 与 Minkowski addition。项目判断：残差合流必须是同一赋值上的关系组合；可以借这个语义要求，不能用多项式域替换原 HZ，也不能把身份管理本身称作新颖性。

[Vielma 的 Cayley embedding 研究](https://juan-pablo-vielma.github.io/publications/Small-and-Strong-Formulations.pdf) 在 §6、Definition 5 区分只在输出投影上 sharp 和在带标签联合空间中 ideal。项目判断：只证明输出常数界变好，不足以证明祖先相位和共享源关系得到保留；但原文的凸分支假设不能直接套到仍有其他 bits 的 HZ，也不据此展开相位组合。

[Repeated ReLU quadratic constraints](https://arxiv.org/html/2407.06888v2) 给出完整 QC 语言的共正条件，同时说明计算时使用松弛。项目判断：关系语言强度与可计算性须分别评价。旧 D009 已研究无 SDP 的 Gram 与幅值行，不能把能量或 Cauchy Schwarz 再包装成新发现；本轮没有引入二次终端、SDP 或全网两两关系。

以上是对相关原文机制的定向复核，不是穷尽式新颖性调查。共同源 reduced product、差值加伴随、固定超模链、稳定分支和单锚关断面都已有先例。创新应落在有明确适用范围、可构造且能跨普通神经算子组合的关系语言，而非重命名这些成分。

## 下一候选的研究入口和完整成本

保留 D046 与 D047 数学组件为支撑库，暂不继续以首块 hinge 数量推动 native 或 GPU 集成。也不围绕上述两个坐标选择下一批实例。它们只用于诊断同一规则的机制类别。

下一纸面候选应保留实际共同源的仿射关系，并研究如何与原多个相位一起形成有限前向观察；作用范围按原 Conv ReLU 与共享 Add 结构固定。先给出域元素、同赋值具体化、受支持算子的变换，以及普通混权结构上超过已有单锚和源差分规则的明确证据。若只重复 D009 能量或 D042 差分闭包，则归入支撑，不扩建实验包装。

这不是新增全局理想凸包门，也不承诺免费共同源支持。实际 source 构造、身份检查、稀疏组合、所有原 bits 和谓词、证据、终端转换、共享存储及 decoder 均要计费。零预激活处两种原合法相位均保留；全文讨论连续查询凸包不改变原域的二元语义。GPU 方向应由这一关系语言的固定 gather、稀疏组合和可靠向外 reduction 支持；这些只是设计要求，本轮没有设备执行或速度结论。

任何实现仍须新的独立预注册、默认关闭、完整既有数学人口、真实同结构目标、shadow、逐家族及单一路径全部 2413 回放。失败版不重跑，既有冻结预算不放宽，能力和纯速度晋级继续解耦。不使用 attack、PGD、BaB、输入或相位 split、backward/dual rescue、LP 状态或实例身份菜单。
