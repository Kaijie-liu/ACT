# 保留原相位兼容关系的跨层激活变换

本候选补上共同真图因子的一个明确缺口：下一原 ReLU 仍跨零时，如何直接消费旧非凸图，而不是先凸化再接一个独立门。变换保留共同源坐标、全部旧物理量及原二元相位。它是默认关闭的数学组件候选；通用顶点几何不是原创集合类，真实网络、GPU、完整物理成本及正式收益尚未取得资格。

## 元素和强不变量

完整原 HZ H 保留连续因子、原 signed binary bits、EQ/LE、共享 frame 和原输入 decoder。关系因子保存共同的完整物理坐标 z，包括声明的基础源及此前全部局部门输出；每个原预激活是 z 的已绑定仿射式。局部真实图 G 在每个完整原相位内是有界凸多面体 P_sigma。集合 V 必须包含每个非空 P_sigma 的所有顶点，而且 V 的每个点必须属于真实图。允许额外真图点，禁止仅留下 conv(G) 的凸包极点。原预激活的严格正、严格负及零标签随点保存。

此不变量由未修改 D228 的完整真面交点构造提供，后续只能通过本文证明的变换递推。组件不接收任意用户提供的顶点表作为合格完整图。D228 的一般余项矩阵可保留 D230 的共同坐标；不经过 D229 的独立余项单位矩阵替代。理想性仅相对于构造 V 时的声明局部源域，不包括后来只在均值上接入的任意 H 谓词。

N=(H,V,原相位关联) 的具体化沿用共同 lambda、全部物理读出等式和原相位 mask 行；所有原 bits 仍是二元。空附加因子嵌入原 HZ；语义包含按具体集合解释，不声称存在最佳抽象或完整格。原图已经存在于 H 时，附加正确因子不改变整数具体化。数学组件中的 frame 和原 ID 只证明接口身份，不自动证明这些 ID 已连接某个真实 ONNX 或 native H。

## 统一的下一激活规则

设下一实际预激活 h(z)=a·z+b，输出 r=ReLU(h)，使用它的原 bit，不创建选择相位。统一执行：

1. 保留每个旧点 v 的提升 (v,ReLU(h(v)))。
2. 遍历每个无序旧点对 u,v。仅当对每个旧门，其两个预激活没有严格相反符号时，称该对兼容；零与任意一侧兼容。
3. 对兼容且 h(u)、h(v) 严格异号的点对，计算唯一线段交点 p=(1-t)u+t v，其中 t=-h(u)/(h(v)-h(u))。追加 (p,0)。同号、零端点不需求新交点，原提升已经保留零端点。
4. 保留全部原预激活符号并附加 h 的符号。新交点严格位于兼容弦内部，其旧符号等于两端共有的非零符号，只有两端都为零才仍为零；可对已认证的旧预激活值作同一 t 的精确插值，两者均与重新计算原仿射预激活等价。精确相同的完整点可以去重；不得以凸包冗余为由删除点。后续调用保持同一规则，不依性质、margin、实例或求解状态选择。

这不是枚举相位赋值、生成输入子域、运行分支验证或调用 LP/BaB。运行时对象只有一个共同点池与全部原 bits；点对过滤是原图关系的代数检查。证明可以谈论原相位多面体，但实现不得据此创建逐相位子任务或额外 selector bits。

## 完整性与非凸语义证明

兼容点对共享至少一个合法旧相位向量；在该相位中原神经图及所有声明源域谓词均为线性，P_sigma 凸，故整条线段是真图。新交点因此不会引入伪图点。

固定任何旧相位多面体 P_sigma。新门的两侧为 P_sigma 与 h>=0 或 h<=0 的交。单半空间截断的每个新顶点，要么是旧顶点，要么在一条旧边与 h=0 的交上；旧边端点均在 V 且相位兼容。规则包含所有这样的交点，不必识别哪些兼容弦恰为边。新门在两侧分别仿射，提升后的池遂包含每个新相位多面体的全部顶点，并且只含真图点。这同时证明强不变量递归保持。

全部物理量共用 lambda>=0、sum lambda=1、z=sum lambda V。对每个原 logical bit beta=(sigma+1)/2，保留

```text
sum_{g(V)>0} lambda <= beta <= 1-sum_{g(V)<0} lambda。
```

零预激活的两种合法标签均保留，沿用 D228 的零标签共同分配证明。于是连续查询视图是声明局部完整带标签图的凸包；原 bits 取整数时，正质量点都属于同一原相位多面体，平均仍在真实图中。这里没有将原非凸 HZ 替换为 CZ、Zonotope 或凸域。仿射、Conv 读出及共享 Add/Concat 在同一物理坐标上精确消费；新跨零 ReLU 由上述规则接续。

任何有效额外 H 谓词保留后，附加局部因子仍健全，但全输入理想性不自动成立。不得要求每个旧局部点单独有原输入见证；D228 已有反例。原输入重构仍由完整 H 的 decoder 和独立具体网络检查负责，支持最大点不是 ADV。

## 普通混权残差控制

令 x1,x2 属于 [-1,1]，q_i=ReLU(x_i)，使用两个非平行混权子门：

```text
y1=ReLU(q1+q2/2-3/4)
y2=ReLU(q1/2-q2-1/4)
h=y1-y2/2+x1/4+x2/8-1/8
r=ReLU(h)
D=2q1-x1+2q2-x2=|x1|+|x2|
F=D+h/4-r/2=D-|h|/4。
```

每个原门在整个源盒上都跨零，y1、y2 和 live source 均被实际消费。h 对两个源坐标的 Lipschitz 常数可取3/2和9/8；各乘1/4严格小于1。因此沿任一源坐标向保持其符号的端点移动，D 增加的量严格超过 |h|/4 的可能增加量，F 严格上升。最大值必在原四角。按 --、-+、+-、++ 顺序，h 为 -1/2、-1/4、1/8、1，所以真实 sup F=63/32，在 (+1,-1) 达到。

强比较 Q 先保留四个旧门的完整共同源、完整原标签联合凸包，再在其上接下一门的精确图，甚至允许对该组合再取完整凸包。旧真图 -- 与 ++ 两点以2/3和1/3混合得到

```text
x=(-1/3,-1/3), q=(1/3,1/3), y=(1/4,0), D=2, h=0。
```

旧父 bits 和 y1 bit 的 logical 均值均为1/3，y2 bit为0；下一门取 r=0 及任意合法零标签。因此 Q 允许 F=2，超过真实上界1/32。这个点不是原整数图、具体反例或 ADV。

所有仅涉及旧坐标的有效线性事实，包括旧图完整凸包，均不能排除这个混合。将 h 和 live affine 部分交给完整物理前沿盒上的 D068 同样至少得到2，因为该混合就在盒中。这里不把 D062/D068 擅自推广成免费跨层精确优化器，也不声称超过完整跨层 RLT、完整五门 hull 或所有旧规则。新点池的上界必须在唯一冻结运行中实际核验；上述数字当前为解析结论。

严格 Lipschitz 余量、四角非零 h 及其正负两侧均对充分小的系数扰动稳定。因此反例不是依赖重复门、rank1、零标签别名或极端数值的孤立构造。此局部强对照不是新 benchmark 解或发表级新颖性证明。

## 完整局部账单和设备边界

令旧池N点、D个完整物理坐标、B个原 bits，h 的实际支持s。除去重外，一次变换付 O(Ns+N²B+K D) 算术，K<=N_positive*N_negative<=floor(N²/4)，故 N'<=N+floor(N²/4)。一般稠密输入验证还付 O(ND)；保存并插值旧预激活值付 O(NB) 存储及 O(KB) 算术，后者包含在 N²B 中。从 D228 首次认证四个旧预激活的源公式另付 O(NBD)，此入口 B=4 固定。用精确排序去重时另付 O((N+K)log(N+K)D) 有理比较，不能漏计非最终点。实现若采用其他去重机制必须按实际机制计费。这些是按整数/有理数算术计的上界，不将512位数当免费硬件操作。必须计全部旧预激活认证、插值、符号检查、去重、临时和证据；兼容非边弦会产生额外点。

本次实现还保存 B 个稠密旧预激活形式，每次追加物理列付 O(BD) 元数据复制；完整原 ID 唯一性检查使用至多 O((D+B)^2) 次字符串比较，字符串长度、切片和比较也计逻辑工作。点池及预激活值占 O(N'(D+B)) 标量，形式本身 O(BD)，去重时保留全部候选及排序暂存。不存在只计最后一个输出的免费历史。

最终因子编译使用 N' 个 lambda、D+2 EQ、N'+2(B+1) LE；若旧物理坐标及原 bits 已有，新增 lambda 列之外还需实际新输出的原读出位置。左侧 nnz 的通用上界为 (D+B+4)N'+D+2B+3，RHS、lambda归一化、等式后端slack、原H、decoder及连接长源式另计。旧点池若因其他消费者仍存活，必须与新池同时计存储，不能声称整体替换即可免费回收。新旧各因子同时编译则两套费用都付。

实现使用 D228 共享终身 Budget，限制仍为 work256M、单操作200M、entries64M、算术512位；新输入也只接受 int/Fraction，拒绝 bool/float。未证身份、位限、资源或证明失败均拒绝，不返回半成品。逻辑账不是完整物理内存或并发性能资格。重复变换的点数上界快速增长，不承诺宽 CNN 或任意深度可付，更不缩小真实人口来掩盖成本。

点对兼容可用旧正负 mask 的交集，插值及读出可批处理；这是 GPU 实现方向，不是已实现加速。设备符号/零点及交点必须可靠认证，不能随便用浮点epsilon。当前没有 GPU 执行，也没有 smooth/Softmax/attention 的同类有限顶点闭包：它们不直接继承分段仿射定理。

## 与已有工作的区别及资格

顶点交点传播早有研究；Zago 等的 EPNM 在§3.3与算法11使用顶点、边及正交区域分离，其§3.2算法2用可行性模型识别边。本规则的限定差异是用保留原神经相位的兼容弦覆盖边，避免单独识别邻接以及生成正交子域列表。它可能多产生很多点，尚未证明同预算性能优势。[原论文](https://arxiv.org/pdf/2301.12001)

ImageStar §4.6 已有精确 ReLU 可达性，但其逐像素分裂流程不是本项目采用的运行时路径。[原论文](https://arxiv.org/pdf/2004.05511) 通用 V-to-HZ 与多神经元 hull 也都有先例；不把点池、mask 或共同 lambda 自身称为新的抽象域。项目推进是为已保留原相位的非凸因子补充可反证的下一激活算子，而非宣称扩大原精确 HZ 可表达集合。
