# 共同源联合关系的纸面正控和投影路线否决

本记录与同目录 REVIEW.md 使用相同日期、分支、commit 和限制。以下为手工代数及独立纸面复核，无代码、模型或求解器执行。结论是已知机制的具体正控及负结果，不是新域资格或正式收益。

## 共同分量和带符号残差

设原门 r=ReLU(f)、p=ReLU(h)，保留各自原 bits。任意固定 a,b>0，令 A=(af+bh)/2、B=(af-bh)/2。经典绝对值恒等式给出

```text
ar+bp = A + (|af|+|bh|)/2 = A + max(|A|,|B|).
```

因此同源证书 |A|,|B|<=M 给出 ar+bp<=A+M。这里 A 仍是有符号的同源表达式，不能先分别求其各项绝对值再声称保留了抵消。a,b 可不相等，公式也适用于有 bias 的 f,h；源证书计算不是免费 oracle。

若后续原门 q=ReLU(g)、原 bit alpha，实际前向残差为 q+v，且当前事实已证明 v<=B0、g+v<=B1，则有

```text
q+v <= B0 + (B1-B0) alpha.
```

证明：alpha=0 时原门令 q=0，alpha=1 时 q=g；在 g=0 时两个界分别成立，全部原零点 bit 选择保留。这是单条统一有效行的证明，不是运行时相位切分。v 必须来自前向网络消费者，不能从待证性质或 terminal margin 反向挑选。

这些原语已属于联合 ReLU 约束和 indicator 条件支持界的范畴。k-ReLU §1 的共同源例子已给出总幅值联合行；不将本节恒等式称为新几何。[k-ReLU 原文](https://papers.nips.cc/paper_files/paper/2019/file/0a9fdbb17feb6ccb7ec405cfb85222c4-Paper.pdf)

## 一个混合权重和非零 bias 的正控

取 x,y in [-1,1]，使用原 gates 和全部原 bits beta,eta,alpha：

```text
f = x+y/4, h = x-y/4, r=ReLU(f), p=ReLU(h)
g = 1/10+r-p/2, q=ReLU(g)
v = 3p/2-x, z=q+v.
```

f,h 梯度不平行且均跨零。共同分量为 A=x、B=y/4，故 r+p<=x+1。单门有效源 facet p<=5(x+1)/8 可由 p<=max(0,x+1/4) 在 [-1,1] 上的割线推出。因此

```text
v <= 15(x+1)/16-x = 15/16-x/16 <= 1
g+v = 1/10+r+p-x <= 11/10
z <= 1+alpha/10 <= 11/10.
```

在 x=1,y=0 达到 z=11/10。只加 parent 联合行未必自动使 child 的 LP 得到该界；最后一条残差传递行须显式生成并付账。

考虑旧松弛点

```text
x=y=0, r=p=41/80, beta=eta=1/2
g=q=57/160, alpha=1, z=9/8.
```

它超过新界 1/40，但不是真实网络点或 ADV。每个父门各自的完整源图凸包都允许它：f 门用源点 (41/50,41/50) 和其相反数各半混合；h 门用 (41/50,-41/50) 和其相反数各半混合。正点激活值均为 41/40，平均源为零，平均 bit 为 1/2；两门混合的源点并不相同。

在该点 f-h=r-p=0，既有 D020 差分四行成立。D025 当前 child 配对容量为

```text
q <= 1/10+(7/8) beta,
q-g <= eta/4,
```

也均成立。设旧父投影 Q 为 0<=r,p<=5/4、|r-p|<=1/2，child 在此 Q 上的完整图凸包仍允许它，因为该点本来满足 q=g>0、alpha=1。故对照不是只用弱单门 big-M。加入共同源行与残差行之后该分数点被排除；原 HZ 的整数精确性从未被反驳。

独立复核确认以上算术和见证，并指出比较范围：该旧点已经违反共同源行 r+p-x<=1，因此只证明整组强化严格有效，不能单独证明加上共同源行之后残差传递行还有额外收益。后者需要另外的消融对照，本轮未给出。

若 inline f,h,g,v，pair 行 r+p-x<=1 有 3 个非零项，残差行 q+3p/2-x-alpha/10<=1 有 4 个。没有因为这两行新增连续变量，但原 gates、全部 bits、源谓词、已有 facet 及其获取成本一项不删；这不是净成本优势的证明。

适用公式不要求父权重精确成比例或净系数恰好相等，但本记录不把这一点升级为真实 CNN 出现率或统一小扰动鲁棒性定理。尚未给出可跨任意后续层保持精度的有限关系语言。普通 HZ 加同一批事实有相同终端逻辑强度。

## 共同抵消量只是换元

对 f=P-N、P,N>=0，设 m=min(P,N)、r=P-m、n=N-m。原 gate 四行在 m=P-r 下恰变为

```text
m<=P, m<=N,
m>=P-u beta,
m>=N+l(1-beta).
```

在全部源谓词、消费者与 decoder 一致代换后，这对整数关系和 LP 都是仿射双射，没有新增强度。额外 m>=0 不是旧 LP 自动蕴含，它等价 r<=P，属于已有次可加容量。故不能把该额外约束的收益归因于换坐标。本结论复核并延伸已有 D020 的 overlap 否决，不记成全新的发现。

## 耦合投影通常改变 ReLU

Moreau 分解把向量分解为锥及其极锥投影；正交象限的欧氏投影给出逐坐标正部。这是凸分析中的成熟先例。[Combettes 和 Reyes 原文，Proposition 1.2](https://arxiv.org/pdf/1103.3178v2)

本项目纸面推断：令 M 为对称正定矩阵，并试图用

```text
T_M(f) = argmin_{r>=0} (r-f)^T M (r-f)/2
```

吸收共享源耦合。若要求在各坐标可独立跨零的开 box 上始终等于逐坐标 ReLU，则 M 必须为正对角矩阵。取 f_i>0、所有其余 f_j<0；在声称的解 r=ReLU(f) 上，第 i 个自由坐标的一阶条件要求 sum_{j!=i} M_ij(-f_j)=0。各负坐标可独立变化，故所有非对角项为零。反向充分性由可分离目标直接成立。

普通反例 M=[[1,1/2],[1/2,1]]、f=(1,-1)，有 T_M(f)=(1/2,0)，不同于 ReLU(f)=(1,0)。因此不能通过换一个耦合 metric 免费保留原网络语义。这不排除在受限相关源集合上的其他结构定理，但本轮没有获得这样的定理。

## 研究结论

保留上述正控作为未来关系语言的比较用例；否决共同抵消换元和任意耦合投影作为独立新域方向。下一项贡献必须解释关系如何重复组合及其完整成本，而非再次只添加这两条已知性质。所有数学材料均未形成默认启用候选，正式新增 CERT/ADV 为零。
