# 封闭原生 HZ 的门关系发现与统一应用

本候选从封闭 SparseHZono 的实际谓词发现可认证的 extended ReLU 数学关系，自动构造 D086 的父对和消费者组，避免依赖缺失的历史slot表或另建通用前向adapter。它是现有关系变换的真实结构入口，不是新的非凸域定义，不声称恢复了原模型全部门或真实执行DAG。

## 结构合同与健全性

只接受规范有限的原连续、二元、EQ/LE及输出。对所有LE，识别零RHS、恰一个连续系数-1及一个二元系数-1或+1的两类guard。相同guard重复时固定取最低行号；同一bit存在不同s/eta候选时明确计为歧义，不无界组合候选。对全部EQ寻找s与原bit系数同为L<0、eta系数为-Q<0的模板，再调用D064的shape、guard和完整行认证，要求graph_error=0。所有扫描按数学结构而非实例身份、历史结论或solver状态执行。

当前发现器明确覆盖extended模板；compact关系及未匹配bits不冒充已发现门，保留在原HZ并计入未覆盖范围。合成测试核对该范围，不通过删除原bits或恢复已消去谓词扩大覆盖。发现的关系是实际HZ行推出的数学事实，即便图端口名未知仍可用于D086；模型来源资格另立。

每个认证child的完整g中，寻找非零eta项所对应的认证父读出，按原eta/bit等固定顺序选择最早两个不同原bit父，并排除自身bit。父u=(1-etaA)/2、v=(1-etaB)/2，因此a=-2*g_etaA、b=-2*g_etaB，差的完整连续/二元项及常数仍交给D086作为残余。各child只按这一规则处理一次；相同父对共享一组转换，少于两个父的关系明确计数，不试第二套效果菜单。

D086已证明每个原整数状态同时拥有新辅助量扩展，所有原谓词保留。对固定多个组归纳应用，每次追加的原列前缀和旧EQ/LE保持，所以最终系统投影到全部最初的连续、二元和输出坐标仍是原HZ。舍入后辅助量不被冒认为精确乘积。这里不做W投影，因此健全性不要求全世界每个消费者纳入；完整发现人口是本次实验的覆盖和成本合同，不能因某组贵而偷偷只运行少量组。

输入在整个发现和应用期间必须保持不变。对象身份检查不证明内容版本，也不证明跨运行frame身份。封闭snapshot上没有后续原列分配，故避免中途追加的列冲突；若恢复前向执行或把新状态塞回生产缓存，必须另证frame同步，本合同不授权该操作。

## 与已有实现的关系

只增加结构发现及统一分组，复用冻结D064模板和D086共享上行，不改它们的源码。原HZ本来能表达非凸ReLU关系，模板恢复及RLT本身不构成定义创新。本候选的目的，是用真实原生结构判定这些关系是否有适用人口、是否能在完整预算下构造，继而决定主线定义假设是否值得继续。
