# 常数容量链的完整相位凸包与共同源关系的边界

本轮证明：非负单后继链的全部传递相位行，已经给出完整的带原标签凸包，不需要辅助流变量。最初推导的二次规模流图因而只是更贵的等价表示，不推进实现，也不记为 Neural-HZ 新能力。另证明一个任意源维数下的符号平衡条件：在该条件下，仅把全部源与相位乘积共同化，不能改善完整单门关系的物理投影。两项结果约束下一定义应保存什么信息，尚不是完整新域或真实网络收益。

## 非凸载体和链关系

同一父元素 H 保留全部连续源、原 signed bits、EQ/LE、共享 latent/frame、所有消费者和原输入 decoder。beta 是原 signed bit 的仿射 active 视图，原生具体化仍要求其为整数。预激活零点的原两种合法标签均保留。

令 c_i>0（i<=n），a_i>0（i<n），取以下常数容量关系；为统一公式，约定哑系数 a_n=1、末端 e_(n+1)=0：

```text
P = { e>=0 : e_i<=c_i+a_i*e_(i+1), i<n; e_n<=c_n },
F(P) = { (e,beta) : e in P, beta in {0,1}^n,
                     beta_i=0 implies e_i=0 }.
V_ij = sum_(k=i..j) c_k * product_(r=i..k-1) a_r,
A_ij = product_(r=i..j) a_r.
```

末端乘零项在物化时直接省略。该类不要求低秩共同源，却只捕获指定的常数链关系，不捕获完整原神经图。将它与 H 相交并保留原整数标签，是原 HZ 可表达的非凸关系；没有块时嵌入 HZ。不能把局部查询凸包误称为以凸域替换原生 HZ，也不能凭此称为已完成新抽象域。

若 e_i=ReLU(f_i) 来自同一完整父域，认证 f_i-a_i*f_(i+1)<=c_i 和 f_n<=c_n 足以生成 P。原相位还直接给出 e_i<=c_i*beta_i+a_i*e_(i+1)。认证必须覆盖整个父域；顺序和系数规则须结构性冻结，不能看标签、实例或 LP 状态挑选。源认证、可靠参数、系数位长和消费者账单都另计。本轮没有计算真实网络上的这些常数。

## 无辅助量的完整凸包定理

conv F(P) 恰为下列系统 Q：

```text
e>=0, 0<=beta<=1,
e_i <= V_ij*beta_i + A_ij*e_(j+1), 1<=i<=j<=n.
```

j=n 时最后一项为零。这些行逐条都是原链传递闭包的 on/off 加强，已有 [D203 关系机制](../d203_phase_incident_pair_20261005/THEORY.md)能够表达。本轮新增的是它们在整个常数链上已足够的证明，不是新发现相位缩放。

必要性直接成立：beta_i=0 时 e_i=0，右侧非负；beta_i=1 时使用原链传递上界。

充分性给出一份共同混合，而不是分别匹配每门。固定任意 (e,beta) in Q，对 t in [0,1] 取原标签 b_i(t)=1[t<=beta_i]。从末端向前作以下仅用于证明的构造：

```text
y_(n+1)(t)=0,
y_i(t)=(c_i+a_i*y_(i+1)(t))*1[t<=tau_i],
0<=tau_i<=beta_i, integral_0^1 y_i(t) dt = e_i.
```

末端解释为 y_n=c_n*1[t<=tau_n]。需要证明每个 tau_i 可选。已构造的 y_j 为非负、非增阶梯函数，令 H_j(s)=integral_0^s y_j(t)dt，则

```text
H_j(s)=min(e_j,
           c_j*min(s,beta_j)+a_j*H_(j+1)(min(s,beta_j))).
```

这是因为 tau_j 之后 y_j 为零，而其此前就是所示容量函数。第 i 步总可用容量为 R_i=c_i*beta_i+a_i*H_(i+1)(beta_i)。令 k 为首个 j>i 满足 beta_j<=beta_i 的位置；若不存在则 k=n+1。此前 beta_j>beta_i，而若 k<=n，H_k(beta_i)=e_k。因此逐次展开上式恰得到

```text
R_i = min_(r=i..k-1) (V_ir*beta_i+A_ir*e_(r+1)).
```

不存在 k 时展开到 n，末项为 V_in*beta_i。Q 的全部对应行保证 e_i<=R_i。容量积分在 [0,beta_i] 连续、由零达到 R_i，故 tau_i 存在。beta_i=0 时末端传递行强制 e_i=0，取 tau_i=0。

每个 t 的 (y(t),b(t)) 都属于 F(P)：幅值满足原链，且 b_i=0 时 t>beta_i>=tau_i，使 y_i=0。共同积分恢复每个 e_i 和 beta_i。所有函数的断点只来自 n 个 tau_i 和 n 个 beta_i，因此可写成至多 2n+1 个合法点的有限凸组合。这证明 Q subset conv F(P)，涵盖任意混合正负消费者，不只是坐标上界。

这份反向索引构造是存在性证明，不是提议运行时 backward、相位切分、条件求解或 helper。原查询只需同一静态行集合；未实施任何查询算法。独立复核还给出按正负目标质量匹配的支持函数证明路线，但主证明不依赖它。

## 完整局部代价和不能外推的范围

记 A=n(n+1)/2。上述闭包有 A 条 LE、3A-n 个变量 nnz、零新增连续列和零新增 bits。若另计 e>=0 和 beta 的盒界，加 3n 行及 3n nnz。已有相邻行、上界行与闭包重叠时须去重，不能把完整账单与增量账单混为一谈。

V 和累计乘积可用 O(n²) 次算术生成，但系数位长、认证舍入、原 HZ 规范化、全部源和 guard、输出读出、decoder、终端物化与查询、host/device 同存均不包含在这个局部数目内。没有由该计数推出端到端速度或 GPU 资格。

该定理只对所列常数容量单后继链成立。它不宣称 source-conditioned c_i、分叉、反馈、多个块的相交、完整网络 guards 或原像素条件纤维的理想性。c_i 若依赖源，c_i*beta_i 就不再是同一常数线性项。不能删除原图，再靠本定理恢复它。

## 流图推导及其淘汰原因

本轮先得到了一个静态 O(n²) 扩展，现完整保留其账单以免以后重复实现。P 的每个顶点恰对每个坐标选择零或饱和上界；严格正 c_i 保证两行不能同时取紧，三角结构保证对应顶点存在。连续饱和段 [l,r] 上 e_i=V_ir，其他位置为零。

建节点 0,...,n+1，零弧 k-1 到 k（k=1,...,n+1），以及每个区间 [l,r] 的弧 l-1 到 r+1。区间弧表示该饱和段及其后的强制零，最后一零为哑节点。每个饱和选择与一条路径对应。令区间流为 lambda_lr，保持非负单位流，并引入

```text
W_ir=W_(i-1),r+lambda_ir, W_0r=0,
e_i=sum_(r=i..n) V_ir*W_ir,
sum_(r=i..n) W_ir<=beta_i.
```

流分解与 D203 顶点支撑定理证明其投影同样为 conv F(P)。保留全部 n+2 条流守恒行（含冗余末行）时，账单是：2A+n+1 个新连续列，A+2n+2 条 EQ，A+2n+1 条 LE，8A+4n+3 个 nnz，零新 bits。nnz 由流守恒 2(A+n+1)、前缀 3A-n、幅值读出 A+n、相位支撑 A+n、弧非负 A+n+1 组成。

n=4 时流扩展为 25 新列、20 EQ、19 LE、99 nnz；同一完整凸包的传递行仅 10 LE、26 nnz、零新列。共同源等额外账单两边都不能省略。故流图不是更强候选，不为它建实现或资格测试。

路径流扩展是已有多面体方法，不作外部首创声明；本轮查阅了 [Fiorini 与 Pashkovich 第 3 节](https://arxiv.org/pdf/1306.3119)。这里使用的是纸面表述与精度比较，没有调用网络流求解器或安装外部算法。

仅胜过相邻关系也不够。n=3、c=a=1 时，beta=(1/2,1,0)、e=(3/2,1,0) 满足各相邻二门完整局部关系，却违反 e1<=2*beta1+e3。该行已属于传递闭包，所以这个例子不能记为流图的新能力阳性。

## 符号平衡时完整乘积共同化不增强物理投影

本节独立于链定理。令原源 x in [0,1]^d，原标签 beta，f_i=b_i+sum_j B_ij*x_j。独立 McCormick 表述为每个非零边引入 Z_ij，满足

```text
0<=Z_ij, Z_ij<=beta_i, Z_ij<=x_j,
Z_ij>=beta_i+x_j-1,
q_i=b_i*beta_i+sum_j B_ij*Z_ij.
```

完整 FREE 表述则要求全部 Z_ij=beta_i*x_j 来自同一真实分布的凸包，但尚不施加联合神经 guard。假设存在行、列符号 r_i,c_j in {−1,1}，使每条非零边 sign(B_ij)=r_i*c_j。此条件不要求低秩、同权重、无偏置或同一支持。

结论是两种表述的 (x,beta,q) 投影完全相同。固定 x,beta 及任意目标 sum_i w_i*q_i，将源按 c_j 翻成 1-x_j，将 beta 按 sign(w_i*r_i) 选择自身或补标签。双线性系数于是全部非负；翻转产生的线性项在固定均值时是常数。独立 McCormick 的最优值使每个转换后乘积取两个均值的最小值。一份共同 U in [0,1] 均匀阈值分布同时实现所有这些最小值。因此完整共同分布也取得相同支持值；固定物理纤维的所有方向支持相等，投影相等。符号翻转只用于证明，不替换原 bit 或网络。

每门再加入 q_i>=0、q_i>=f_i，便得到该门完整的 source-labelled ReLU hull：Z/beta 与 (x-Z)/(1-beta) 给出两臂源均值，两个物理不等式分别保证其 guard，端点按零质量解释。由于附加条件只依赖投影量，投影等价在加入全部这些单门条件后仍保持。因此在符号平衡盒上，完整 FREE 加完整单门 hull 不比完整单门 hull 的交集更强。

这是充分结构条件，不是任意源多面体、任意符号图或完整 joint ReLU guard 的等价定理。真正的神经联合 guard 仍可提供新信息。[D061 四门控制](../d061_multiway_rectifier_relation_20261001/THEORY.md)在翻转 y 后各权重非负，满足本条件；其已有共同关系分离因而也胜过这里的完整 FREE 加单门参照，但不能把旧控制重新算作新增阳性。

符号一致性可在非零二部图上以 O(E+d+m) 工作检查，E=nnz(B)。独立产品表示本身支付 E 列、4E 条 LE、8E nnz，另有原源和 bit 界、读出、guard 等。没有在真实人口上运行符号检查，也没有把该检查当成新能力算法。

## 其他简化尝试的记录

单纯源 packing 不能提供所需新信息。对 x_i>=0、t_i>=0、q_i=ReLU(x_i-t_i)，原整数图已满足 q_i+t_i*beta_i<=x_i；完整单门 hull 因而包含它。任何 a>=0 的源行 a·x<=b 都已推出 a·q+sum_i a_i*t_i*beta_i<=b。不将这个求和换名为新联合域。

符号平衡也不表示混权后继天然超模。取 x in [1/10,3/10]、y in [7/20,9/20]，F=ReLU(x+y-1)-ReLU(x+2y-1)。按左下、右下、左上、右上四角，F=(0,0,0,−1/5)，违反超模四角不等式。该纸面例子只否定用统一同向阈值最大化所有混权 ReLU 读出的快捷论证，不是新能力、真实模型或全域不可能性。

上述两项均未进入候选实现。下一研究须保留同一完整源、原相位和多门 guard 的共同可行性，并被全部实际混权消费者及后继非线性利用；只扩充 FREE 产品、常数链流图或改名已有行不足以完成该目标。
