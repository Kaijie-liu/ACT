# 多目标相位条件下的有限误差消元

本记录给出一个可用于联合外包的静态证书：多个原目标相位共同限制父门误差，有限次展开后可以不保留误差变量而安装源与相位之间的有效行。普通有偏置混权例证明它严格强于文中固定仿射盒证书族的全部 D124 逐目标参考选择和有限合法乘子；普通重复目标反例则证明它仍不保证多个输出具有共同幅值实现。它是支撑定理，不是完成的新域或真实网络收益。

全部结果是纸面推导，根代理与独立代理逐式核对；没有执行候选代码、测试、模型、求解器或 GPU。保留原连续源、所有原二元身份及零点标签、EQ/LE、共享 frame 和输入 decoder。下面以原 signed bits 的 0/1 视图记相位，不放松实际域中的整数语义。

## 同源的联合误差前提

设所有父门及其全部受影响消费者使用同一个源关系 S。固定结构参考 tau_i，写

```text
q_i = R(f_i),           R(t)=max(0,t)
t_i = (1-2 tau_i) f_i
e_i = R(t_i),           q_i=tau_i f_i+e_i
g_j = h_j + sum_l A_jl e_l
r_j = R(g_j),           原目标相位 beta_j.
```

这里 e 是真实同源轨迹上的函数，不是各消费者可独立选择的新输入。按结构固定锚 j(i)，用同一完整源认证

```text
h_j(i) + kappa_i t_i <= rho_i,
kappa_i>0, rho_i>=0,
L_j<=h_j,              0<=e<=u.
```

证书不能偷用尚未成立的目标守卫，也不能按终端状态、margin 或标签选择。具体锚选择和预算仍需在实现前预注册；本文没有给任意真实网络授予来源资格。

首先，源证书和 rho_i>=0 给出

```text
kappa_i e_i <= rho_i + R(-h_j(i)).
```

当原 beta_j=1 时，g_j>=0，因此 -h_j<=sum_l A_jl e_l<=sum_l A_jl^+ e_l。beta_j=0 时使用全局 R(-h_j)<=max(0,-L_j)。两者合并为

```text
e <= a + M e + B delta,
delta_j=1-beta_j,
a_i=rho_i/kappa_i,
M_il=A_j(i),l^+/kappa_i >=0,
B_i,j(i)=max(0,-L_j(i))/kappa_i,
其余 B 项为零.
```

证明覆盖 g_j=0 时两个合法 beta_j。该不等式确实利用目标相位对源误差的限制，应如实描述；它不是失败后求解器反馈、反向优化或对偶修复。

## 无需收缩条件的有限展开

令 c(beta)=a+B delta>=0，并预先固定有限整数 K>=0：

```text
H_0=u,
H_(k+1)=c(beta)+M H_k,
H_K=sum_(j=0..K-1) M^j c(beta)+M^K u.
```

由 e<=u、e<=c+Me 和 M>=0 直接归纳，得到 e<=H_K。它不需要矩阵求逆、谱半径小于一、LP、神经状态枚举或相位搜索。因为 H_K>=0 且 e_i=R(t_i)，每个真实轨迹都满足

```text
t_i<=H_K,i(beta).
```

所以即使在一个已经证明健全的父幅值外包中删去 q/e，也可以安装这些保留源与原目标 bits 的线性行。源谓词、原父守卫和原可靠 caps 的已证明投影后果仍须保留。必要条件不能替代完整联合图，也不单独授权删除任何尚有未覆盖消费者的幅值。

不能声称 H_K 在所有相位下随 K 递减：F(u)=c+Mu 可能大于 u。若需要各阶嵌套，可以显式保留各阶行的交，但必须支付全部行数和 nnz；本候选只讨论最终 H_K 及原 cap 后果。经典正矩阵 small-gain 的无限 Neumann 逆不是新数学，[原始论文的 Corollary 7 证明](https://arxiv.org/pdf/math/0506434)已明确给出该逆。本记录仅推导与原神经相位关联的有限证书，不据此主张代数新颖性。

## 线性端口必须另装关系

若真实 raw 端口是 v=d(z)+c^T e，则还能认证

```text
d(z)-(c^-)^T H_K(beta) <= v <= d(z)+(c^+)^T H_K(beta).
```

这里 c^+=max(c,0)、c^-=max(-c,0)，逐项定义。若投影后 v 是独立连续读出，必须显式安装相应行；仅有 t_i<=H_K,i 不会自动约束它。端口可以同时使用原 u 的更紧方向界，但其显式交与费用不能省略。

对多个 v 分别装这些行仍是外包，未保证它们共用某个同一 e。把原完整 e polytope 留下来可以保留更强相关性，但重新保留所有 e 通常只是原 q 的可逆仿射换元，不能凭新名字宣称压缩。

## 普通混权严格对照

取 x,y 属于 [-1,1]，保持两个父相位和两个目标相位：

```text
e1=R(x), e2=R(y),
g1=1/4-x-e1/10+e2/2,
g2=1/4-y+e1/2-e2/10,
rj=R(gj).
```

每个目标含正负权、非零偏置，两个父门与目标门均实际跨零。原目标紧界均为 [-17/20,7/4]。tau=(0,0)，两个误差分别锚在 h1=1/4-x、h2=1/4-y，kappa=1。此时

```text
a=(1/4,1/4),      u=(1,1),
M=[0 1/2; 1/2 0], B=(3/4)I,
H2=(5/8)1 + [(3/4)I+(3/8)Swap] delta,
H4=(17/32)1 + [(15/16)I+(15/32)Swap] delta.
```

考虑比较点 x=2/3、y=1/4，全部原 bits 激活，r1=1/120、r2=1/3。它不是原网络点：真实 g1 为负，因此 beta1=1 非法。下面仅用它检查两种外包的分离，绝不是 ADV。

这个点通过每个目标的全部 D124 逐目标四行族，不靠选择较差参考。对任意 tau1,tau2 属于 {0,1} 及正边的任意合法有限 kappa>1/2，目标一的正边证书为

```text
h1=1/4-(1+tau1/10)x+(tau2/2)y,
rho_plus=1/4+1+tau1/10+|tau2/2+kappa(1-2tau2)|,
E_plus=(1/2)rho_plus/(kappa-1/2)>1/2.
```

目标二交换 x,y 及两个 tau，完全对称。负边的合法乘子不改变 E_plus，且只使 E_minus>=0。在比较点处 h1 属于 [-29/60,-7/24]，h2 属于 [-1/40,1/3]。因此 r1=1/120、r2=1/3 满足 beta=1 时的全部上下行，原 U_r=7/4 也不排除它；父门符号守卫满足。这个结论甚至覆盖所有上述标量外包的交，而不只是共同乘子子族。

联合源行 x<=H2,1 在 beta1=beta2=1 时要求 x<=5/8，故以 1/24 的差排除该点。再考虑带偏置混权的真实端口

```text
v=1/8+e1-e2/2.
```

在比较源点其值为 2/3，而共同 active 预算给出 v<=1/8+17/32=21/32，差为 1/96。此端口行必须另外安装。这里是原目标相位条件下的排除，不是整个输入盒上的全局 v<=21/32，也没有推出一个新真实性质 CERT。

所有目标 inactive 时 H4 的两项均为 31/16>u=1，具体见证了非嵌套性。该正控尚未与旧 HZ 加相同有效行、完整 input-aware 或适用的多神经元联合包络作完整精度成本比较。

## 普通反例仍然否决完整共同纤维的主张

重复目标取 x 属于 [-1,1]，q=R(x)，r1=r2=R(1/4+q/4)。在 tau=0、kappa=1 下，a=5/4、M=1/4、u=1，且 L_h=1/4，所以 B=0。得到

```text
H_K=5/3-(2/3)4^(-K)>1, K>=1.
```

与原 u 取交后没有改进。x=1/2、全部原 bits 激活、r1=1/4、r2=1/2 的 D125 不一致点仍然通过；真实两输出都应为 3/8。增加更多 H_K 阶数不能修复这个例子。

另一个先前提出的三角耦合例也不用于正证：g1=1/4-x+e2/2、g2=1/4-y-e1/2。它只超过 tau=0 的弱比较；把负边参考改为 tau1=1 后，第二目标 h2=1/4-y-x/2 且 E_plus=0，已经排除 x=1/2、y=1/4、r2=0 的伪点。因此该例被放弃，而不是隐藏较强参考。

## 完整费用和实施决定

若 n 个误差、p 个原目标 bits，H_K 的相位系数最多是 n 乘 p 矩阵，稀疏 M 的幂也可能填充。按显式仿射系数银行计算，朴素上界是 O((K+1)(nnz(M)+n)(p+1)) 次算术及初始化，而非对单一 beta 赋值的 O((K+1)(nnz(M)+n))。位长、中间乘积、源证书、全部端口方向、行展开、原 guards/caps、证据、decoder、主机设备共存和终端降级另计。

这些固定稀疏矩阵作用具有批处理潜力，但尚无实现或 GPU 结果。有限证书没有解决重复目标，故不为它单独再建适配框架或宣称共同域完成。下一研究必须说明完整多消费者共享关系如何保留或健全近似，并给出可计算查询及完整费用。旧 HZ 加相同关系保持为强参考；可编译回 HZ 本身并不否定算法价值，但这里的真实价值尚未验证。
