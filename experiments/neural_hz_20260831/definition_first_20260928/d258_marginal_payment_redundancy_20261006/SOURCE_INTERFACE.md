# 差分余项必须先保持共同来源再求界

本页落实本轮冗余定理对下一来源接口的影响。只计算两个完整子门的独立channel范围已不能回答当前QG的能力问题；下一次真实观察必须给出同一个H中完整差分余项e的证书，才能决定是否值得安装关系。本文是已完成的合同分析，不是执行预注册或已可启动的worker。

## 不展开完整子行也能保持原提取定义

固定D255同一规范化后的全局因子坐标zeta，不另换独立输入盒，也不忽略已有rebase link。设父读出x_i=c_i+w_i*zeta，J=supp(w_1)并supp(w_2)，m=(g1+g2)/2，t=m-b1*q1-b2*q2。Gram系统为

~~~text
G_ij=<w_i,w_j>, h_i=<w_i,coeff(t)>, G*a=h.
~~~

因为两个w在J外为零，h只需t在J上的精确系数，G只需两个父行。b/tau另需D255规定的两个父幅值私有列上的四个子系数。只要局部读取器返回的值确实等于完整同源规范化后的系数，所得a/b/tau就与完整展开完全一致；这是支撑限制的直接点积恒等式。

r=m-a1*x1-a2*x2-b1*q1-b2*q2以及e=(g1-g2)/2-tau*(q1-q2)仍必须保留完整读出。局部取系数不授权删J外的未选父、skip、偏置或误差，也不免除后续产品行和终端真正消费这些完整读出的费用。D255现有实体Affine API尚未实现这个惰性来源接口，不能称为现成替换。

仅有逻辑port相同、相似权重或相同范围不足以认证坐标。例取f1=u、f2=v、z=u+u'、原EQ为u'=u。若忽略EQ，用三列(u,v,u')的单位度量会得到a1=1、r=u'；合并真实link后得到a1=2、r=0。两个表示的真实网络相同，未规范化的Gram判定不同。D255的认证rebase规范化正是不能跳过的前提，而不是本例已发现了其实现缺陷。

## 下一次界必须覆盖哪个集合

用于整数投影等价的r/e界必须覆盖所声明H的每个整数可行赋值，不只是原ONNX真实输入产生的状态。尤其原BN被nominal仿射项加独立有界误差载体外包后，原BN的较紧输出范围不自动覆盖所有载体赋值。

一个普通精确例子是x在[0,1]、原值y=x/3，载体为t=3*x/8+epsilon/24、epsilon在[-1,1]。每个原值均有epsilon=-x的延拓，但x=0、epsilon=-1给t=-1/24，不属于原y的[0,1/3]。因此不能把原模型范围直接当成该载体的完整范围。这里不是当前模型的实测反例，也不要求为极端舍入特例追加路径；它明确了两份证书的量词不同。

可以对实际nominal加误差的完整表达式传播可靠界，或另证明更强范围是新域的健全谓词；后一种做法不能同时声称保留了旧外包H的每个整数点。对旧LP新增范围所产生的收紧也须与QG收益分账。

## 实际差分合同

下一接口必须在同一来源图中形成e，再对e求界；不能先得到g1和g2的独立区间再相减。共同skip、共同幅值及BN误差只有在身份和系数均已认证时才可抵消。两层带padding卷积必须按真实有效路径复合，不能以无边界的5乘5核替代。

这不是重新提出一种尚不存在的代数机制：D242 THEORY第7节已要求保留完整其余父、skip、误差以及可能非零的(A+B)*(q1+q2)/2；D245 mixed_relation.py的共同child_memo、按列合并和_bound_terms也已实施该顺序。当前缺口是把它以完整可支付成本用于实际三前缀。按D242的BN外包，每个实际标量拥有自己的epsilon_s，其全部消费者必须复用同一身份；不能强制整通道空间位置共享一个加性误差来制造抵消。

真实审计仍是原固定三来源的输入至第三个ReLU完整前缀、全部通道和空间位置，并保留截止后的消费者。它不等于要求枚举所有父对乘所有子对：旧合同尚未冻结真实pair生成器。新生成器可以按统一结构定义有限邻接族，但必须事前冻结、覆盖该族所有成员，不能事后只保留有利窗口或把该族阴性称为all-pair阴性。

第一项有判别力的观测是完整登记人口中哪些成员满足本轮冗余充分条件(1)。全部满足时关闭该求界实现的QG能力推进；有成员不满足时，才值得检验相对同范围、同来源参照的严格收紧。仍不能把“未被证明冗余”算成阳性或正式新解。D255原全批失败语义不因诊断分类而改成只安装成功子集。

## 原来源和资源边界

真实来源记录仍为D241的source_0/1/2.json。完整前缀所需initializer为20、25、25个，共875072标量，其中869440为Conv权重、5632为BN参数；全部记录为FLOAT/raw_data/4字节。不是三个全模型全部initializer数量。新packed reader可以精确提升这些float32参数，但必须独立计入完整解析、扫描、身份和临时存储，不能调用旧Fraction reader后删去其64*N收费。

原完整残差身份保持：large的Add_8为132+127到133，未来133用于Add_14的slot1、136用于Conv_12的slot0；medium/Tiny的Add_10为126+128到129，shortcut从121经Conv_8和BN_9得到128，未来129用于Add_16的slot1、132用于Conv_14的slot0。Add后直接进入下一Conv，不补插ReLU。完整输入人口15552，三个前缀的ReLU标量人口总324224。

BN记录保留原参数和向外A/B包络。A经过2^-64网格向外处理；B=beta-A*mean继续精确区间运算，不能声称B也固定在该网格。共同物理参数的身份与每个独立数值误差载体必须分别说明，不能将区间中点当成原实数BN系数。

旧reader加已分析标准F4路线仍关闭：含一次40M证据的F4小计207421184，加旧解析53703433已为261124617，超过256M，尚未包括旧Fraction解码等费用。新packed reader本身没有被这一结论否定，但reader加独立子门channel界、再相减构造e的组合已被本轮精度定理否定为QG增益路线。合并后的共同源项仍可使用channel范围。两种否定的原因不同。

完整新算法仍要支付参数、可靠共同范围、局部系数访问、完整差读出、关系/消费者、普通终端、decoder、证据及host/device共存。保持256M整体work、200M单模型、一次40M evidence、64M entries、512-bit、240秒、CPU0单线程、AS16GiB和双1GiB宿主门。不继承D257的组件计数为完整前向费用，不调整权限或重试D247失败的ptrace通道。
