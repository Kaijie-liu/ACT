# 独立子门范围会使相位关系失去投影收紧能力

本页证明当前定量守卫关系的一条精度边界：如果差分余项的支付大到覆盖两个子门各自的完整幅值范围，那么六个新产品、三条源容量和两条QG关系合在一起，仍不改变原LP在旧变量上的投影。特别地，仅从两个子门的独立区间相减得到差分余项界，必然进入这条边界。因此本轮关闭“传播完整三来源的独立子门边界，然后相减构造e来测试QG收益”的拟议路线；没有执行该路线，也不把这一结论扩写为真实模型不可验证或全部Neural-HZ无效。先合并共同来源系数，再对剩余项使用channel界的方案不在这项否定之内。

这是针对D252现有有限关系的纸面定理与研究决策，不是新的集合类、机器证明、已执行数学组件或正式能力收益。原非凸域的连续因子、原signed binary、EQ/LE、共享来源和decoder均不改变。下面的分数相位只出现在普通终端LP的数学分析中。

## 同源参照和完整关系

固定一个旧LP可行点。两个父门的三元组(x_i,q_i,alpha_i)分别属于相同范围下原ReLU图的完整单门凸包，其中x_i在[-1,1]、q_i=ReLU(x_i)是原整数图语义，0<=q_i<=u_i<=1。alpha_i为原相位的0/1视图，零点的两个合法标签都允许。旧LP还可含任意其他共同来源、EQ/LE、残差及消费者约束；这些变量的当前值全部保持不动。

两个子门的预激活、输出满足原单门松弛，尤其有0<=Y_j<=U_j，L_j<=0<=U_j。范围是两条路径共同采用的已登记参照，不能把本次新获得的普通范围证书暗算成关系收益。完整仿射来源恒等式为

~~~text
z = (g1+g2)/2 = a1*x1+a2*x2+b1*q1+b2*q2+r,
d = (g1-g2)/2 = tau*(q1-q2)+e,  tau>0.
~~~

偏置、未选门、skip及所有数值载体均在原r/e中保留。使用Lr<=r<=Ur构造关系，且被比较的旧LP点本身满足该范围。若该范围只对整数H有效、尚未被旧LP保证，结论比较的是旧LP加同一范围行之后的投影；新范围排除旧LP点的收益须单列，不能归因于QG。

新增六个新鲜连续产品及各自完整McCormick行：

~~~text
c12=alpha1*x2, c21=alpha2*x1,
d12=alpha1*q2, d21=alpha2*q1,
v1=alpha1*r,   v2=alpha2*r.
~~~

它们只由D252的产品行、三条X容量与两条QG消费，不另加未经本定理覆盖的联合矩约束。定义

~~~text
p_i=alpha_i-q_i,
n_i=1-alpha_i-q_i+x_i,
K=tau*(alpha1-alpha2)
  +a1*(q1-c21)+a2*(c12-q2)
  +b1*(q1-d21)+b2*(d12-q2)+v1-v2.
~~~

eta仍严格按D252的Lr/Ur及a/b计算。令

~~~text
Bplus  = 2*max(Ue,0),
Bminus = -2*min(Le,0).
~~~

两条QG就是

~~~text
 Y1-Y2 <= K+2*tau*p2+eta_10_minus*alpha1+eta_01_plus*alpha2+Bplus,
-Y1+Y2 <=-K+2*tau*p1+eta_10_plus*alpha1+eta_01_minus*alpha2+Bminus.
~~~

## 大支付投影冗余定理

如果

~~~text
Bplus  >= U1+2*tau*u2,
Bminus >= U2+2*tau*u1,                                  (1)
~~~

则上述整组新增约束对旧LP投影冗余。每个满足上述共同范围的旧LP点，都有一个六产品辅助延拓；旧变量、全部原约束和读出不变。结论不要求r界很松，也不要求a/b为零，因此继续改进Gram投影或只收紧r界，不能单独摆脱(1)。

### 辅助延拓的构造

取当前旧LP点各坐标的普通实数乘积：

~~~text
c12=alpha1*x2, c21=alpha2*x1,
d12=alpha1*q2, d21=alpha2*q1,
v_i=alpha_i*r.                                          (2)
~~~

这些是证明存在性的数值，不是向验证程序加入双线性约束或修改原位。每项真实乘积都满足其矩形上的完整MC行。

为证明三条X行，把每个父三元组写成其单门整数图点的有限凸组合，再将两个组合独立耦合。它们的交叉产品均值正好给出(2)的c/d。每个整数父对满足D252的三条X容量，取均值后仍成立。r在这份证明分布中取当前常值，属于[Lr,Ur]，故v_i的均值也为(2)。

这个凸组合可直接写出，不依赖求解器或运行时相位枚举。对0<alpha_i<1，以质量alpha_i取active点(x,q,bit)=(q_i/alpha_i,q_i/alpha_i,1)，以其余质量取inactive点((x_i-q_i)/(1-alpha_i),0,0)。原四条单门行保证两点在原预激活区间内；alpha_i为0或1时只保留对应一项。这里的有限分布仅用于纸面证明辅助延拓，未执行输入采样、BaB或split。

这份证明分布不声称满足旧H的所有跨父关联。它仅证明新增局部行在(2)处成立；原H本身只取原先那个可行点，从未改动或重新采样。因此任意额外旧线性约束不影响这一延拓证明。若新增关系另外要求更强共同分布容量，则不在本定理范围内。

### 两条QG的检验

在上述每个整数父对上，令r仍为当前常值，构造仅用于证明的

~~~text
z'=a1*x1+a2*x2+b1*q1+b2*q2+r,
Y1'=ReLU(z'+tau*(q1-q2)),
Y2'=ReLU(z'-tau*(q1-q2)).
~~~

对任意z'，ReLU单调且1-Lipschitz，所以

~~~text
Y1'-Y2' >= -2*tau*q2,
Y2'-Y1' >= -2*tau*q1.
~~~

对这个人工二子图使用D252已经证明的e=0关系，得到

~~~text
K+2*tau*p2+eta_10_minus*alpha1+eta_01_plus*alpha2 >= -2*tau*q2,
-K+2*tau*p1+eta_10_plus*alpha1+eta_01_minus*alpha2 >= -2*tau*q1.
~~~

这里不需要人工子图另有原子门的L/U；D252的点态clip证明仅要求父图、r界和tau>0。再取独立父分布的均值，左侧恰为(2)处的线性表达式。由(1)，原上行的右侧至少为U1+2*tau*(u2-q2)>=U1，而旧子门已有Y1-Y2<=Y1<=U1。原下行同理至少为U2，旧点已有Y2-Y1<=U2。两行都成立，证明完毕。

各新关系使用自己的六列且没有额外跨关系新约束时，可对有限完整关系人口同时应用(2)，所以整个人口的旧LP投影仍不变。并不声称额外行的实际求解时间不变，也不声称所有其他有效关系或联合容量冗余。

## 独立子界相减必然满足冗余条件

如果只用g_j在[L_j,U_j]、q_i在[0,u_i]得到

~~~text
Le=(L1-U2)/2-tau*u1,
Ue=(U1-L2)/2+tau*u2,                                   (3)
~~~

则L1,L2<=0使

~~~text
Bplus  >= U1-L2+2*tau*u2 >= U1+2*tau*u2,
Bminus >= U2-L1+2*tau*u1 >= U2+2*tau*u1.
~~~

所以(1)自动成立。这与子界按channel还是按位置计算无关；只要最后对两个子门采用独立差界(3)，同一结论成立。提高各子门的独立界精度本身可能提升旧参照，但关系相对同一新参照仍无投影增益。

相反，g1=z+tau*(q1-q2)、g2=z-tau*(q1-q2)按同源系数合并后给e=0。只要两个子门的U为正，零支付不满足(1)。即使后续仍使用channel范围认证其他源项，本定理也不能将其关闭；这只说明未被本冗余条件排除，不重新证明其一定有收益。

单独登记tau>0、Gram rank2、有限eta、原非凸整数延拓或更多命中关系，都不能反驳本结论。它也不是“所有宽残差都无效”：对同源e先做代数抵消再求界，可能不满足(1)，本定理就不再给出冗余判断。不满足(1)仅表示未被该充分条件排除，绝不等于一定收紧。

## 与旧结果的关系

D250的来源覆盖下界用于旧零支付hard guard，不能继续当作QG的结构拒绝证书。QG会支付超出部分。例如D250第一例的r范围为[-8/5,41/20]，tau=5/4，a=b=0；两事件均有eta_minus=7/20、eta_plus=4/5。旧guard确实不成立，但新公式仍有定义。这里是对已给纸面例子的分数运算，不是新模型执行。

一般而言，D252两事件还满足

~~~text
eta_10_minus+eta_10_plus >= max(0,Ur-Lr+abs(a1+b1)+abs(a2)-2*tau),
eta_01_minus+eta_01_plus >= max(0,Ur-Lr+abs(a1)+abs(a2+b2)-2*tau).
~~~

这是区间超出[-tau,tau]的长度下界，只是支付压力，不是另一条QG拒绝定理。不能把它与(1)混为一谈。
