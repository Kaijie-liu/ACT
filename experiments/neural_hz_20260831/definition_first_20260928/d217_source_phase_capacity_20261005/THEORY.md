# Neural HZ 关系增强的物理投影判据

本轮研究怎样区分真正改变输出的神经关系与只改变分数相位延拓的关系。得到一个最大相位容量判据，以及比 D216 更广的普通双门无增益定理；没有得到新的物理输出阳性。结论用于筛选 Neural-HZ 定义候选，不把固定点 membership 计算或已有单门凸包包装成新域。

原生 HZ 的连续源、原 signed bits、EQ/LE、共同身份和原输入 decoder 全部保留。本文只分析指定连续查询外包的投影；消去分析变量 beta 不授权删除或连续化原生位。没有新 helper、候选代码、数值实验或运行预注册。

## 从完整源相关单门 hull 得到相位容量

对一个普通盒输入上的仿射预激活，按系数符号翻转并归一化坐标，可以写成

```text
f(z)=sum_j v_j*z_j-t,
z in [0,1]^d, v_j>0, 0<t<sum_j v_j.
```

这里只处理 crossing 结构；零系数不参加该局部公式，原身份不删除。归一化和源谓词均须保留，不把不同门的坐标视图当作独立源。

固定物理坐标 (z,q)。令 a_j 为开启事件中的第 j 个源质量，beta 为原 bit 的均值。完整 source-labelled 单门凸包要求

```text
max(0,z_j-1+beta)<=a_j<=min(beta,z_j),
q=sum_j v_j*a_j-t*beta,
q>=0, q>=f(z), 0<=beta<=1.
```

上述条件也是充分的：开启和关闭质量归一化后分别在源盒内，q>=0 及 q>=f 保证各自守卫。零质量和零预激活保留原弱标签语义。

由于 a=beta*z 总在源质量区间中，下端点不超过 beta*f(z)<=max(0,f(z))。所以在 z∈[0,1]^d、q>=max(0,f(z)) 前提下，完整可行相位纤维恰为

```text
I(z,q)={ beta in [0,1] : U_z(beta)>=q },
U_z(beta)=sum_j v_j*min(beta,z_j)-t*beta.
```

U_z 是凹的分段仿射函数，I 是闭区间或空集。这是已有单门理想凸包的另一种消元写法，不是新的凸化原理。[Anderson 等第 2.2 节与第 2.3 节 Proposition 1](https://arxiv.org/html/1811.08359v2)

## 不枚举全部 facets 的固定点公式

记 A_S=sum_(j in S) v_j*z_j、D_S=t-sum_(j not in S) v_j，则

```text
U_z(beta)=min_S (A_S-D_S*beta).
Bhat=min(1, min_(S:D_S>0) (A_S-q)/D_S).
```

候选 Bhat 必须通过 0<=Bhat<=1 和 U_z(Bhat)>=q。通过时，它是精确最大可行相位 B(z,q)；否则 I 为空。证明：所有 D_S>0 的行给 beta 的上界，其他行给下界或常量条件。如果整个纤维非空，其最大端点必为这些上界的最小值；直接代入检查同时覆盖所有下界和常量条件。

q>=max(0,f) 本身不保证非空。例如 d=1、v=1、t=z=1/2、q=2/5，有 Bhat=1/5，但 U_z(Bhat)=1/10<q，必须拒绝该物理点。

固定 z 后，不需要 2^d 个子集。按 z_(1)<=...<=z_(d) 排序，定义

```text
A_k=sum_(j<=k) v_(j)*z_(j),
W_k=sum_(j>k) v_(j),  k=0,...,d.
U_z(beta)=min_k (A_k+(W_k-t)*beta).
Bhat=min(1, min_(k:t>W_k) (A_k-q)/(t-W_k)).
```

每个固定 beta 的逐项 min 由阈值前缀 z_j<=beta 实现，因此前缀公式精确。排序用 z_j 本身，不是 v_j 或二者比值。费用为 O(d log d) 排序和 O(d) 前缀运算，另计精确数位与证据。并列值不改变结论。

这是一个固定物理点的数学 membership 判据。若 z、q 是终端优化变量，其排序随点变化；不能据此声称完整网络支持查询只需 O(d log d)，或全变量 hull 只有 d 条线性行。本文不实施动态 cut generation、LP 状态救援或另一个验证器；也没有把这个判据计为能力收益。

## 单调相位关系的精确物理投影

设各完整单门 hull 在一个给定物理点 x 上产生相互独立且非空的相位区间 I_i(x)，最大端点为 B_i(x)。额外神经关系全部形如

```text
g_r(x)<=sum_i a_ri*beta_i, a_ri>=0.
```

则存在合法相位延拓，当且仅当把全部 beta_i 取为 B_i(x) 后通过所有关系行。

必要性来自逐坐标单调放松；充分性来自 B_i 本身可行且各相位纤维为区间乘积。只涉及物理源的额外谓词不破坏这个固定点论证；额外相位耦合、带负相位系数的关系或相位等式则可能破坏它。不能把该定理直接套到整个深层 HZ 的全部历史谓词上。

D203 和 D216 在其正 cap 合同下满足该单调形式。因此两者的物理投影比较无需猜分数相位：必须先算出单门真正允许的最大相位，再检查联合行。若 B_i=min_k L_ik(x) 是完整单门的 affine 上界族，例如新行

```text
q1-a*q2<=C*B1+(c-C)*B2, c>=C>=0,
```

就精确等价于全部 phase-free affine 行

```text
q1-a*q2<=C*L_1k(x)+(c-C)*L_2l(x), for all k,l.
```

这说明真正需要证明的分离发生在哪里，也说明把新相位行存入谓词不等于得到可消费输出收益。一般 affine 上界族可以很大，原坐标全消元没有免费规模保证；固定点前缀公式不消除这一成本。

## 更广的普通双门不增益定理

取

```text
f1=A*x+B*y+h1, f2=C*x-D*y+h2, x,y in [-1,1],
A>B+abs(h1), C>D+abs(h2), A,B,C,D>0.
```

两门可以非对称，偏置和横向权重可以不同。任意注册前向斜率 a>0 的紧差分 cap 为

```text
c_raw(a)=abs(A-a*C)+B+a*D+h1-a*h2.
```

只注册满足 D216 正 cap 和两向收缩前提的行，特别是每个前向/反向交叉组合都须满足 a_i*b_j<1，而不只检查各旧块曾经配对的组合。正的保守 cap c>=max(0,c_raw) 也适用；不能把负 raw cap 静默纳入 D216 的正幅值块。反向对称。

比较完整 source-labelled 单门 hull 加各注册 D203 块，与同一单门 hull 加全部行的 D216 hull，两者的 (x,y,q1,q2) 投影相同。注册斜率不要求小于一，只要满足前述双向块 admission。

证明先记 K1=A-B-h1、L1=A+B-h1，K2=C-D-h2、L2=C+D-h2，均正。第一门完整单门 hull 的最大相位是

```text
M1=min(1, (A*(x+1)-q1)/K1, (f1+L1-q1)/L1),
```

第二门同理。这是前述完整单门消元的二维特例。每个门的每个物理点都允许 beta0=(x+1)/2：x=-1 的整个面关闭，x=1 的整个面开启；凹包上端可由盒顶点实现，下端可固定 y 用零点与同侧点混合实现。详尽构造与 D216 相同，只须将各门预激活除以自己的正 x 系数。

取共同 r=min(M1,M2)>=beta0。若 M1=M2，旧行逐坐标放松即可；r=1 同理。只须考虑 M2=r<M1，第一门用 q1<=A*(x+1)-K1*r，令 T=A-a*C。

若第二门的 x-facet 紧，即 q2=C*(x+1)-K2*r，则

```text
q1-a*q2-c_raw(a)*r
 <= T*(x+1)-(T+abs(T))*r-2*a*D*r <= 0.
```

若第二门 graph facet 紧，即 q2=f2+L2*(1-r)，则

```text
q1-a*q2-c_raw(a)*r
 <= T*(x+1)-(T+abs(T))*r-a*D*(1-y) <= 0.
```

T>=0 时使用 r>=(x+1)/2；T<0 时使用 x+1>=0。把 raw cap 换成更大的 c 只会放松。第二门全部旧行因其旧相位不超过 r 而成立，交换门次序对称。两个相位相等时 D216 两种反馈行重合；联合 P 的坐标最大值至少为真实各门上界，所以其坐标行也由完整单门 hull 蕴含。反向包含由联合 hull 加强各单行 hull 得到。

因此只改变 kappa、偏置或横向比例并不是逃离 D216 负结论的办法。该定理不覆盖失去共同 dominant 坐标、不同横向符号布局或额外相位源耦合的结构，不声称所有双门盒族都无收益。

## 下一类结构的可反证条件

三源候选 f1=x+y+alpha*z+h1、f2=x-y+alpha2*z+h2 的紧 cap 是

```text
c(a)=abs(1-a)+1+a+abs(alpha-a*alpha2)+h1-a*h2.
```

当 alpha,alpha2>0 且 0<=a<=min(1,alpha/alpha2)，它为 2+alpha+h1-a*(alpha2+h2)。若全部注册前向行的最小 cap 由同段内 a_star>a 达到，C=c(a_star)，并记旧行松弛 delta=C*beta1-(q1-a_star*q2)>=0，则新 mixed 行违反量为

```text
(a_star-a)*q2-(c(a)-C)*beta2-delta.
```

所以在最大可延拓相位上，若要由这条前向 mixed 行取得新物理分离，至少需要 beta1>beta2、q2>(alpha2+h2)*beta2，且 delta 足够小；beta2=0 时不会产生这个违反。若 c(a)=C，该 mixed 行就是旧行，不可能新增分离。这不是全部反向行或坐标行的统一必要条件。只是增加第三个源仍不保证成功。该条件是下一项纸面研究的筛选信息，不是本轮取得的三源阳性或新实验预注册。

## 研究资格

本页给精确判据和更广负定理，不是完整 Neural-HZ 定义创新。原 HZ 能保存相同有效关系；完整单门 hull 属于既有理论。没有新域实际能力、GPU、smooth、Transformer 或正式增益声明。下一实现仍须沿原数学资格、真实同结构、shadow、逐家族和完整回放门推进，不降低验证人口或预算。
