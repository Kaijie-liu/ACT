## 四阶子式和可靠余量

忽略相同通道的共同 BN 缩放时，所选四源的系数子矩阵是

```text
[ K02 K12  0   0  ]
[ K00 K10  0   0  ]
[  0   0  K12 K22 ]
[  0   0  K10 K20 ].
```

所以其行列式是 Delta_T*Delta_B，其中

```text
Delta_T=K02*K10-K12*K00,
Delta_B=K12*K20-K22*K10.
```

用粗有理界即可纸面认证：

```text
abs(K02)>1/4, abs(K10)>9/100,
abs(K12)<7/40, abs(K00)<3/25,
abs(K20)<1/50, abs(K22)>13/100.
```

这些比较分别由下列整数不等式核对：

```text
17053452>16777216,
1233303500>1207959552,
7309800<7340032,
97798075<100663296,
499012250<536870912,
225884900>218103808.
```

六个核系数都负，因此

```text
Delta_T > (1/4)*(9/100)-(7/40)*(3/25) = 3/2000,
Delta_B < (7/40)*(1/50)-(13/100)*(9/100) = -41/5000.
```

未缩放四阶行列式的绝对值因而大于 123/10000000。没有用近似 determinant 或数值 rank 阈值。

BN1 的同通道原字段为

```text
gamma[44]=5545495/8388608,
variance[44]=13544833/33554432,
epsilon=2748779/274877906944.
```

共同系数 kappa=gamma/sqrt(variance+epsilon)>0，故只是把四阶子式乘 kappa^4，非零性保留；不需要把 sqrt 取中点。偏置不影响线性秩。

## 对 Neural HZ 定义的含义

D194 的四 patch 共有 27 个共享输入身份。固定四个 private 块及其他输入后，四个共同读出 h=A*u+b 的像含一个四维开集。若一个表示试图让全部共享依赖只通过 h=c+G*eta、eta∈R^r 传递，则精确性要求 r>=4；即使 eta 本身是源的非线性函数，最终 affine 像仍至多 r 维。有限个原 bits 选择不同的 G，也不能用有限个低于四维的 affine 像覆盖这个开集。

该结论只针对所述 affine 读出接口，不否定有损域、非线性读出或其他尚未研究的表示。若继续保留额外共同源，自然可以保持精确性，但不能再说全部共享依赖已被一个标量代替。

尤其这不反驳 D205/D214 在完整源状态上额外保留一个有效尺度 s：它们没有声称 s 替代全部源。这里排除的是拿一个尺度或 rank-one separator 整体取代实际共同依赖的路线。

保留四个 h 作为别名也不消掉27个源。四门各有15个共享结构位置，四条定义 EQ 有至多60个源系数位置及4个 alias 系数；实际 nnz 未由本页认证，后续仍须全量计费。全部原输入、其他消费者、Conv3、shortcut 和 decoder 仍保留。不能把四个读出当成四个独立区间而继承精确共同源语义。

这份真实证据使下一定义问题更具体：保留多维共同源与相位的联合依赖，同时证明它能被混权后继实际消费。它没有给出完整新域，也不构成运行资格或新增分数。
