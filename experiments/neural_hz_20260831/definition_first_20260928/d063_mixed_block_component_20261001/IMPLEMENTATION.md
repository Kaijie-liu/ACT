# 四平面组件的语义和实现边界

本组件实现[D062数学规格](../d062_mixed_block_support_20261001/THEORY.md)，不是新的求解器或生产验证路径。generate(v,gates,receiver,enabled=True)中v为同源区间仿射剩余项，gates保存每个原预激活、原输出、归属于该输出的原相位及接收权重区间。按严格递增原相位ordinal给定固定slot顺序，不按得分重排。

receiver必须是同frame的既有消费者读出，不是当前门或当前源的循环别名。每个预激活不能直接引用自身输出；其他原门输出可作为同一个前沿的具名源，不把它复制成独立噪声。真实网络来源、拓扑、读出等式和数值界由调用者认证，形式身份检查并不授予native资格。

默认关闭时不检查任务输入。启用后先检聚合出现数，再验证类型、上下界、同源身份、原相位归属及重复项。参考中点只用于支持构造，完整Lipschitz误差覆盖原参数，原模型与原bits不被替换。所有有理输入和运算结果检查512位。

每方向缓存v/G和(v-Hminus)/G两个底式，在同源合并稀疏增量后更新盒支持；各组只保留2或4个支持标量，不保存G份负项或底式。空正项方向记单一残余支持，避免除零；奇数尾不造dummy。两方向参考界由同一规则生成，再扩张参数误差E。

证书保留输入引用、上下界、E、组支持证据及原receiver上的两个LE行。观察使用既有D049的readout/observe/compile_rows，不能将F<=max平面通过自由epigraph变量假装安装，也不逐条强加F<=各平面。返回行并未安装进生产HZ。

保留旧整数集合和原decoder的结论来自有效界定理；添加线性行不扩大旧LP，但仍可能增加时间成本。这里没有实际网络的非冗余、四并发速度、全物理存储或GPU舍入认证。原HZ加同样行与此观察逻辑等价，不能据此把已知机制重新命名为创新域。

本目录的四项数学测试提供独立直接展开和解析对照。运行资格只由冻结监督器的完整3801/177结果决定，静态审查不算通过；失败保持原版本和日志，不事后修改冻结文件。
