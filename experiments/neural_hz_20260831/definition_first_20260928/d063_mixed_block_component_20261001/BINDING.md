# 共同源观察进入原神经块的绑定条件

数学组件已经通过资格，但它的形式token不能证明原网络语义。本说明限定下一次真实接入必须认证的共同见证，并指出标量界进入下一ReLU时不能省略的LP传递步骤。以下是静态代码审查与纸面推导，不是新增数值实验、native资格或已实现的新域。

## 所有关系必须属于同一个原赋值

令omega=(xi,b)是原HZ的一个可行连续及二元赋值。需要原native状态认证每个source读出z_j(omega)、实际门g_i(omega)与q_i(omega)=ReLU(g_i(omega))、原相位归属，以及接收等式F(omega)=v(omega)+sum_i w_i q_i(omega)。不能让几个局部组件分别选择自己的输入或原相位赋值。

最低记录包含原状态版本、frame及latent身份，源读出与可靠盒界，全部预激活的参数包络，gate输出与原二元列映射、active方向，实际receiver的仿射等式，以及保持不变的原谓词与输入decoder。Conv布局、BN、bias、padding、残差其他臂和全部消费者都在等式范围内。参数可以相互依赖，误差定理不要求参数独立；但包络必须覆盖同一个实际模型。

D049/D053/D063只检查形式身份、区间与声明一致性，不认证上述native映射。D063返回的两行仅含receiver，原phase用于归属检查和固定分组，没有输出新的跨层phase关系。若receiver不是显式物理坐标，两行必须展开其真实latent读出，不能按两个非零项估算全部终端成本。

## 稳定门和原相位方向

当前原稀疏ReLU路径在[tf_mlp.py](../../../../act/back_end/hybridz_tf/tf_mlp.py:433)按lb>=0复制实际仿射读出，仅对lb<0<ub的门分配原slot。稳定门可能没有原二元列，不能伪造phase token以符合D063接口。

稳定门可依据已证q=g或q=0把其贡献并入v；这是同一个实际读出的精确代数重写，不删除原网络门、既有bits或合法零点相位。若原门有bit，即使新界判定它稳定，也必须保留该bit及原守卫。此重写的来源认证、稀疏合并、区间误差与完整成本需要另行实现资格；当前D063并未实现自动native适配。

现有[compact稀疏编码](../../../../act/back_end/hybridz_tf/tf_mlp.py:576)明确使用原signed bit b=+1表示inactive，active指示量a=(1-b)/2；不应把ordinal当作列号，或默认a=(1+b)/2。两连续量编码也具有相同方向，但必须以实际走过的路径、原slot与谓词为准，不能凭网络节点名称猜测。

原slot注册表以(frame_id, layer_id, flattened neuron)为键，返回的三元组含实际binary列，见[注册实现](../../../../act/back_end/hybridz_tf/hybridz_tf.py:417)。shared或signed-sharing路径可能只给代表门分配slot；因此从ONNX逐门名称制造独立own-phase token既不认证原列，也可能复制原来共享的相位。后续适配必须明确实际路径和别名等式，不能把现成slot表误报为完整逐门语义证书。

## 前层界不会自动收紧旧后继LP

考虑原门r=ReLU(h)，原active指示量a，旧预激活界[-1,2]。旧标量big-M行是r>=0、r>=h、r<=2a、r<=h+1-a。仅添加h<=1后，点h=1、a=2/3、r=4/3仍满足全部旧行：两个上侧右端均为4/3。这个点不满足真实ReLU图，也违反由新界可得的r<=1。

因此D062中F<=11/10推出ReLU(F-1/2)<=3/5，是精确图上的数学推论；仅安装D063的F界并保留旧宽门行，不足以保证终端LP获得后继界。此纸面反例不涉及运行相位分支，也不是具体ADV。

对已认证的L<=h<=U及原门图，可显式追加以下已知有效行，并保留旧行和全部原bits：

```text
max(0,L) <= r <= max(0,U)
r <= U*a
r <= h-L*(1-a).
```

整数健全性直接由原门语义给出：a=0时r=0、h<=0且h>=L；a=1时r=h、h>=0且h<=U。h=0时两种原相位均满足这些行，不固定或删除任何bit。该证明是全体原赋值上的逻辑证明，不是枚举网络相位的计算算法。

在上述实际signed编码a=(1-b)/2下，后两行的降级形式为：

```text
r + (U/2)*b <= U/2
r - h + (L/2)*b <= -L/2.
```

若r、h分别含s_r、s_h个latent非零项，追加这两行前的支持上界为2*s_r+s_h+2；实际重复列可合并，但不能提前假设抵消。标量输出界、原F界、RHS、证据、临时合并、可靠数值转换与全物理存储另计。这些行是经典ReLU表述的可靠界更新，不是本项目的新数学优先权，也尚未包含在已冻结D063测试或实现中。

## 不能直接复用一般界相交来声明精确接入

现有[sparse_hz_intersect_bounds](../../../../act/back_end/solver/solver_hz.py:772)可以把输出界展开成原latent上的LE，但返回对象无条件exact=False；其一般用途不携带D063已证冗余的证书。直接调用再声称保持exact HZ资格不成立，也不能随后无证明地把flag改回true。

需要独立认证的追加过程将已证行降级到原读出，保留全部旧谓词、因子与decoder，并可靠处理Fraction到float的向外转换、常数移项和latent系数。原状态若非exact，不得凭新界把它提升为exact；原状态exact且追加行被证为其整数语义的推论时，才有相同具体化的依据。这是本轮确认的实际接入缺口，不修改生产函数。

最小可检查接入位置是在[_sparse_apply_relu](../../../../act/back_end/hybridz_tf/tf_mlp.py:1264)仍持有原预激活、界和slots时捕获对应关系，再在真实Affine/Conv接收读出生成处使用。不能到终端才按名字猜回映射：前沿重基会清理旧slot。原[sparse_hz_linear](../../../../act/back_end/solver/solver_hz.py:742)及[同frame残差](../../../../act/back_end/solver/solver_hz.py:1833)提供保留latent身份的实际读出；源坐标本身含旧二元因子是允许的，它们的盒界只用于保守证书，不能替换原共享集合。此定位只覆盖已读稀疏路径，不认证所有dense、lazy或共享模式。

## 残差和后续定义问题

若下一预激活为h=tF+u，应先认证同一个原读出等式并处理t的符号，不能漏掉u的偏置或另一残差臂。将F与u分别取区间再相加是健全的，却可能丢失共同源抵消；单个标量观察不提供任意Add或跨层关系闭包。

真正仍待研究的定义贡献是：哪些共同源及原相位关系应成为神经块的原生接口，使其后继组合能保留有用信息，并在完整传播、查询、GPU可靠算术和decoder成本下带来新解。当前组件可作为该研究的已测支撑，不把两条标量界或保留整张图换名为Neural-HZ定义创新。

下一次数值工作须新预注册并保留原人口、预算和完整范围。已有source证据只能按其完成范围使用，不能把D025或D057失败的三模型普查重记为通过；此说明不授权缩小目标集、重跑消费版本或提高预算。生产集成、GPU及正式回放仍未执行。
