# 共享源支持的构造与单门强化边界

本记录为纸面推导及独立复核，没有执行测试、网络或求解器。所有源表达式共享同一 frame；原相位、源谓词与输入重构保留。盒 B 包含真实源集；在 B 上精确的支持值，对额外谓词限制的源集一般只是安全上界。

## 先线性化其他门不能产生新的联合强度

设 q_j=ReLU(f_j(x))，原 bit 为 beta_j，实际前向消费者为

```text
z = c + S*x + sum_j w_j*q_j.
```

为每个 j 选择有效仿射上界 w_j*q_j <= m_j*f_j+d_j，并令

```text
T = c+S*x+sum_j (m_j*f_j+d_j),
O_k = T-m_k*f_k-d_k,
B0_k = sup_B O_k,
B1_k = sup_B (O_k+w_k*f_k).
```

候选行 z <= B0_k+(B1_k-B0_k)*beta_k 是有效的。然而它已由完整的单门源凸包和其他仿射上界推出：其他门上界给出 z<=O_k+w_k*q_k；在第 k 门的精确带标签图上，beta_k=0 时该右侧为 O_k，beta_k=1 时为 O_k+w_k*f_k。因此该右侧的候选上界在线性凸包上也成立。f_k=0 时两种原合法 bit 都保留。w_k 的符号不影响证明。

所以它可能胜过较弱的标量 big-M，但不提供超过该强单门对照的新联合关系。将其他非线性全部替换为一个仿射 O_k 后，没有强制不同门使用一致的源混合。该路线不作为新域创新启动实现。

形式上，缓存 sigma_B(T) 后，对稀疏 f_k 的支持作局部绝对值修正可以减少重复扫描；但目前内核没有此接口。直接重复调用现有构造与求界可能达到 O(K*nnz(T))。这仍是独立的工程问题，不改变上述精度结论。

## 固定正系数双门的共同支持

设 f、h、v 是同一 x 上的仿射式，a,b>=0。逐点有

```text
v+a*ReLU(f)+b*ReLU(h)
  = max(v, v+a*f, v+b*h, v+a*f+b*h).
```

由有限 max 与 supremum 的交换，对同一个完整盒 B 有

```text
sup_B [v+a*ReLU(f)+b*ReLU(h)]
  = max(sigma_B(v), sigma_B(v+a*f),
        sigma_B(v+b*h), sigma_B(v+a*f+b*h)).
```

若 B=m+[-d,d]，sigma_B(k0+k*x)=k0+k*m+sum_i |k_i|*d_i。证明分别来自非负系数下 ReLU 的 max 分配律，以及每个坐标的盒上线性支持公式。盒外加的原谓词不删除，只是此项求界暂时未充分利用它们。

这是固定四个完整盒支持归约，没有限制到相位区域，没有固定原 bits，也没有新增求解子问题。代数上四项确实对应两门的四个激活组合；本记录不靠更名绕过 split 禁令，不推广成 k 门的 2^k 展开，也不据此启动运行。若未来实现规则被解释为禁止一切固定组合求值，应在预注册时明确处理，不能擅自扩大授权。

在共同坐标已经正确合并、输入为固定系数时，工作是四次稀疏支持归约，算术操作量线性于共同支持大小。排序、身份核验、有理数位长、向外舍入、证据和终端成本另计，不能推为现有 GPU 性能。区间系数版本至多得到经认证外包，不直接继承点系数的精确性声明。

## 补上已有跨层例子的支持前提

沿用 D027 的 x,y in [-1,1]，f=x+y/4，h=x-y/4，r=ReLU(f)，p=ReLU(h)。其两个所需常数可以直接构造：

```text
B0 = sup_B (3p/2-x)
   = max(sigma_B(-x), sigma_B(x/2-3y/8))
   = max(1,7/8) = 1.

B1 = 1/10 + sup_B(r+p-x)
   = 1/10 + max(sigma_B(-x), sigma_B(y/4),
                    sigma_B(-y/4), sigma_B(x))
   = 1/10 + max(1,1/4,1/4,1) = 11/10.
```

因此这里不需要把 B0、B1 当免费 oracle。它构造出 D027 的共享源残差行，但不解决任意混合符号读出，也不证明真实宽卷积能以同样代价覆盖。

该联合支持不是两个独立单门完整源凸包的简单重复。例如 x=y=0、r=p=3/5、beta=eta=1/2，各门分别可用源 (24/25,24/25) 及其负值、源 (24/25,-24/25) 及其负值各半混合实现。故点属于两个带标签单门源凸包的交集，却违反 r+p-x<=1。两个门使用的源混合不同，正是缺失的联合条件。

上述事实不能宣称新颖性：支撑函数、max 分配律与多神经元联合关系都是已知机制。它只给出一个明确的构造性组件及适用范围。跨层有限接口的定义、一般组合规则、完整成本和真实网络净收益仍待研究。
