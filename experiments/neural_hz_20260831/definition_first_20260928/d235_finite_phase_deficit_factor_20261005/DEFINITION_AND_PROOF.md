# 共享相位缺额的有限非凸关系因子

本研究把上一轮依赖完整共同图凸包的能力比较，改成一套可直接生成、共享和消费的有限谓词。两个受不同父相位支配的混权子门，只需五个连续观察和八条核心容量行，即可保留相位与幅值的共同限制；在跨层控制中，加上有明确费用的源观察及消费行，直接证明精确物理上界 125/64。证明不依赖完整顶点池、联合相位表、求解器返回点或完整旧 observer hull。

这是一项 Neural-HZ 关系演算的定义片段，不是已经完成的创新抽象域。底层使用已有的单调性、Lipschitz、条件乘积与 RLT。新成立的项目结论是有限结构生成合同、常偏置情形无需更高阶观察的消元、可消费物理证书及其完整局部费用；实际残差扩展所需的联合事件观察另行登记并计费。不声称击败包含相同信息的完整 RLT，也不把数学控制计为 benchmark 新增解。

## 具体化和原始身份

令 H 是当前完整非凸 HZ 元素，包含原连续源、全部原 signed binary bits、EQ/LE、共同 latent/frame、全部活物理读出及原输入 decoder。下文 alpha=(sigma+1)/2 只是原 bit 的 0/1 视图。原神经门须由拥有的实际仿射式及原图约束认证，不能由数组 shape 或一个外部数值界冒充。

关系元素可以写为 N=(H,M,C)：M 是按共同 frame、原 bit 身份及原读出身份唯一登记的有限条件观察，C 是本文固定结构生成的容量行。具体化使用同一个 H 赋值，M 的含义为其登记的实际乘积；所有 C 必须由该整数状态的真实门语义推出。全部原 bits 仍是整数，空 M、C 嵌入 H。

对有界原读出 z，m=alpha*z 的四条 McCormick 行在原整数 alpha 下精确；delta=alpha1*alpha2 同理。因此每个旧整数状态有唯一的观察扩展，投影回 H 完全不变。语义偏序可按具体集合包含解释，但不假设最佳抽象或完整格。容量行改善的是查询表示的连续松弛，不是假装精确 HZ 原来不能表示这个神经图。

条件观察不得在不同消费者处各建一个不相容副本。同一原事件、同一读出必须复用同一变量；delta 也按无序父事件对共享。新增行有 source/frame、producer 和前提证据，未证界、身份或资源失败均 fail closed。原图、原 guards、零点全部合法标签及 decoder 不删除。

## 普通双输入结构

先将两个原非负父幅值按已证上界规范化为

```text
0 <= q1 <= alpha1, 0 <= q2 <= alpha2,
y1=R(a*q1+b*q2-t1),  0<=b<=t1<a,
y2=R(c*q1+d*q2-t2),  0<=c<=t2<d,
a,b,c,d>=0.
```

R 是 ReLU。规范化来自原幅值除以认证正上界，不是把原输入或源替换成独立盒；实际所有源谓词仍保留。若上界为零，不可除法，应沿原稳定图处理，不删除原相位。

这两个结构条件分别保证 alpha1*y1=y1、alpha2*y2=y2。严格 b<t1<a、c<t2<d 给一个开放参数族，不要求重复门、平行法向或低秩。定理也允许 b=t1 或 c=t2，但此时仅有幅值支配，不能推断子门 bit 蕴含父 bit：子门值为零时的另一原标签必须保留。

定义五个共同观察

```text
delta=alpha1*alpha2,
t21=alpha2*q1, t12=alpha1*q2,
v21=alpha2*y1, v12=alpha1*y2.
```

新量都是连续变量，以原整数 bits 精确约束，不增加事件选择 bit。记

```text
p1=alpha1-q1, p2=alpha2-q2,
p21=delta-t21, p12=delta-t12.
```

保留四条源容量 `0<=p21<=p1`、`0<=p12<=p2`。p21 是 alpha2*p1，p12 是 alpha1*p2；它们的两个界同时记录共同源的幅值缺额，不能只保留一个独立上界。

## 八条相位容量行

四个以下表达式仅是仿射缩写，不引入独立误差变量：

```text
e21=(a+b-t1)*delta-v21,
e10=(a-t1)*(alpha1-delta)-y1+v21,
e12=(c+d-t2)*delta-v12,
e01=(d-t2)*(alpha2-delta)-y2+v12.
```

统一生成各自的非负行及上界行：

```text
0 <= e21 <= a*p21+b*p2,
0 <= e10 <= a*(p1-p21),
0 <= e12 <= c*p1+d*p12,
0 <= e01 <= d*(p2-p12).                         (K)
```

这是全部八条行，不能只保留对一个终端方向有利的子集。生成条件来自实际系数、已证幅值界和神经支配结构，不读取模型/实例身份、标签、terminal margin、LP 状态或对偶信息。

证明以原整数赋值为起点。因 q<=alpha，ReLU 单调和 1-Lipschitz 给出

```text
0 <= R(a*alpha1+b*alpha2-t1)-y1 <= a*p1+b*p2.
```

结构条件使首项精确等于 `(a-t1)*alpha1+b*delta`。将这个共同缺额分别乘原 alpha2 及其补事件，利用 alpha2*q2=q2、alpha2*delta=delta、(1-alpha2)*q2=0，得到前两组 (K)。第二门对称。证明中使用原 bit 的恒等式，不产生运行时相位子问题、区域列表、顶点池或辅助求解器。

也可直接从以下四条原生有效行生成第一门的四条 (K)：

```text
y1 <= (a+b-t1)*alpha1,
y1 >= a*q1+b*q2-(t1-b)*alpha1-b,
y1 <= (a-t1)*alpha1+b*q2,
y1 >= a*q1-t1*alpha1.
```

前两条乘 alpha2，后两条乘其补事件，再按共同乘积身份归并。四条原生行在 alpha1=0 时由 q1=y1=0、q2<=1 保证，在 alpha1=1 时由 q1<=1、原 ReLU 上下关系保证。这里不需要构造 degree-3 中间量或完整相位分布。

## 实际残差可以保留但不能免费忽略

前述偏置允许推广成同一个原 H 上的实际残差读出：

```text
y1=R(a*q1+b*q2+z1),   -a<L1<=z1<=H1<=-b,
y2=R(c*q1+d*q2+z2),   -d<L2<=z2<=H2<=-c.
```

z1、z2 可以相关，并可含其他活源；原表达式、source/frame 和所有消费者必须保留。区间只作为完整 H 上的已证前提，不将残差替换成两个独立盒变量。条件是否在实际卷积出现尚未认证。

额外登记 w1=alpha1*z1、w2=alpha2*z2、theta1=delta*z1、theta2=delta*z2。delta 在原整数语义下由父 bits 唯一决定为 0 或 1，因此 theta 的四条乘积行仍精确，不需要新增 binary 类型。它在 LP 查询时分数化只是外包，不能宣称整体局部 hull 理想。

将四个缺额换成

```text
e21=(a+b)*delta+theta1-v21,
e10=a*(alpha1-delta)+w1-theta1-y1+v21,
e12=(c+d)*delta+theta2-v12,
e01=d*(alpha2-delta)+w2-theta2-y2+v12.
```

其上下界仍恰为 (K)。证明在同一实际 z1、z2 值上使用相同单调与 Lipschitz 不等式；角值分别是 `(a+z1)*alpha1+b*delta` 和 `(d+z2)*alpha2+c*delta`。这里保留了联合事件对活残差的观察，而不是把 theta 当免费已知量或通过不相容均值恢复它。

这给一个保留实际混权残差的有限接口，不覆盖任意符号卷积、任意残差区间或任意深度闭包。若条件不成立，不生成本因子；不能删除不利的剩余项让一个宽卷积伪装成双输入门。

## 下一实际激活的统一消费

下面给出消费行的生成式，不能只在看到控制性质 F 后才加入一条特定答案。对于原父 qi=R(xi)、xi 属于 [-1,1] 的接口，设实际下一预激活为

```text
h=cx1*x1+cx2*x2+cq1*q1+cq2*q2+cy1*y1+cy2*y2+c0,
r=R(h).
```

所有系数都是原前向图给定的常数，允许混号。登记 u21=alpha2*x1、u12=alpha1*x2，令

```text
T=cy1*v21+cy2*v12+cq1*t21+cq2*t12
  +cx1*(x1-q1-u21+2*t21)
  +cx2*(x2-q2-u12+2*t12)
  +c0*(1-alpha1-alpha2).
```

由幅值支配及 alpha_i*xi=qi，XNOR 事件乘 h 恰为 `J=T+2*c0*delta`。令 `d2=1-2*q2+x2`，源容量给 `t12<=delta<=t12+d2`。于是固定按第二父源消去 delta，统一生成

```text
C=T+2*c0*t12+2*min(c0,0)*d2,
r>=C.
```

它来自同一个实际 r 的条件下界 r>=J，按系数符号选取已证代数端点，不依性质、标签或求解状态。参考中所有原图行继续存在。对不满足此来源合同的额外活残差，不能直接漏掉：一般需要其两个单事件观察和联合事件观察，或另给可靠消元证明。本文不把这部分视为免费闭包。

## 跨层控制的有限物理证书

沿上一轮的完整控制，令 x1,x2 属于 [-1,1]，qi=R(xi)，

```text
y1=R(q1+q2/2-3/4),
y2=R(q1/4+q2-3/4),
h=2*y1-y2-7*x1/16-x2/16-5/16,
r=R(h),
D=2*q1-x1+2*q2-x2,
F=D+h/4-r/2.
```

加入原事件对源的两个观察 u21=alpha2*x1、u12=alpha1*x2，并记

```text
n1=1-alpha1-q1+x1, n2=1-alpha2-q2+x2,
d1=p1+n1, d2=p2+n2,
n21=alpha2-delta-t21+u21,
n12=alpha1-delta-t12+u12.
```

原父图保证 p_i、n_i 非负以及 D=2-d1-d2。n21=alpha2*n1、n12=alpha1*n2，因此保留四条额外源容量 `0<=n21<=n1`、`0<=n12<=n2`。

令 J 为 XNOR 事件乘 h 的下列仿射展开式，不新增 J 列，也不假定当前 LP 点有一个真实联合分布：

```text
J = 2*v21-v12
    -7*(x1-q1-u21+2*t21)/16
    -(x2-q2-u12+2*t12)/16
    -5*(1-alpha1-alpha2+2*delta)/16.
```

对任意满足这些线性定义的赋值，都有代数恒等式

```text
h-2*J+3/16
 = 2*e21-2*e10+e01-e12
   +7*d1/16+d2/16
   -7*(p21+n21)/8-(p12+n12)/8.                 (I)
```

使用 (K) 的 e21 上界、e01 上界以及 e10,e12>=0，右侧不超过

```text
9*p21/8+2*p2-9*p12/8
 +7*d1/16+d2/16-7*n21/8-n12/8
 <=25*d1/16+33*d2/16.
```

因此，仅靠有限系统即可推出

```text
D+h/4-J/2 <=125/64-39*d1/64-31*d2/64.          (B)
```

再使用上一轮已推导、按实际下一 h 生成的消费行 `r>=C`：

```text
C = 2*v21-v12
    +7*u21/16+u12/16-7*t21/8-3*t12/4
    -7*x1/16-11*x2/16+7*q1/16+21*q2/16
    +5*(alpha1+alpha2)/16-15/16.
```

精确有 `C=J-(5/8)*Delta`，其中 `Delta=d2-p12`，源容量给 0<=Delta<=d2。结合 (B) 得到

```text
F <=125/64-39*d1/64-11*d2/64 <=125/64.          (F)
```

这是所列有限行的代数后果，对任何共同 delta 与观察赋值都成立，不能通过改选隐藏变量恢复 F=2。真实源四角均给 F=125/64，并有它们的唯一真实乘积扩展，故此方向的有限松弛最优值恰为 125/64。

上一轮的真实四角均匀混合在完整旧观察 hull 中满足 x=0、q=(1/2,1/2)、y=(1/4,3/16)，旧单事件 h 矩全为零。只附下一门自身图与单事件 Jensen 时可取 r=0，允许 F=2。新增有限系统消除了这个物理投影缺口，差为 3/64。该假点不是原输入 ADV；也不声称本文系统在其他方向支配完整旧 observer hull。

特别重要的是：(K) 是实际新增容量生成，不能说普通双 slice 或几个 McCormick 包络自动已经包含它。只加固定事件模块而没有这些关系及 C，不足以构成上述比较。

## 完整局部费用

以下都从已有独立物理 q/y 坐标、原 bits 和可靠有效界起算；没有把这些前提的来源与成本抹掉。按未去重、系数通用非零计，归一化 0/1 的数目如下。

普通偏置版需要五个连续量。四个 binary 与非负幅值的乘积为 16 LE、32 nnz；delta 的四行是 4 LE、8 nnz；两组 p 容量是 4 LE、12 nnz；(K) 是 8 LE、至多34 nnz。总共 **5 个连续量、32 LE、至多86 nnz**。

上面的完整跨层证书还需要 u21、u12 的 8 LE/20 nnz，四条 n 容量的 4 LE/22 nnz，以及 C 的 1 LE/13 nnz。合计 **7 个连续量、45 LE、141 nnz**。若所有六个观察与 delta 已经存在，增量是17 LE/81 nnz，但不能将这些已存观察本身免计。

实际残差版相对五量偏置版增加 w1、w2、theta1、theta2，共16个乘积 LE和至多40 nnz；八条容量行增加至多8 nnz。合计 **9 个连续量、48 LE、至多134 nnz**，假定 z1、z2 已有独立物理坐标。否则再付两条实际残差定义 EQ、相应连续列和全部源支持的展开。它不自动继承特定常偏置控制的125/64结果。

所有版本都另计原 H、原门与全部 bits、幅值规范化、真实 source/parameter 证据、RHS、等式型后端 slack、全部活读出、终端矩阵作用与求解、具体输入重构和独立网络验证。逻辑行数不是完整 RSS 或 GPU 费用。为 K 个结构实例生成因子可有 O(K) 个局部关系，但发现结构、认证前提、展开 source/readout、共享观察的实际 incidence 和全部消费者并不免费。

## 前向组合与尚未解决的部分

Affine、Conv、同框架 Add/Concat 对已经登记的同一事件观察按线性组合传播；完整原读出也继续保留。对于满足本文结构前提的新 ReLU，增加新的实际幅值观察并生成 (K)，保持旧所有因子和共享身份。事件互斥或幅值支配的精确别名可以统一代换，但必须覆盖它的所有消费者与谓词，不能只在某条查询中删除观察。

这些规则构成有限结构上的健全前向组合。它们没有证明有限维观察对任意新门无损闭包；既有 D035/D175 反例仍有效。更一般门继续保留其原非凸图，但不能声称凭本因子自动保住所有跨层精度。若未来实际 residual 使 theta 或更多观察新增，必须登记并支付，而非从均值免费恢复。

同信息的标准 HZ 加上这些行具有同样的数学查询强度。因此下一层创新义务是结构发现、共享表示与可组合演算的完整精度/成本优势，以及真实验证增益，不能只把这里改名为新域。保持原 bits 并不等于已经满足这项义务。

## 已有研究与验证状态

Sharp Hybrid Zonotopes 已明确把 RLT 应用于 HZ，其 Theorem 7 保持 HZ 表示与原二元因子。本文的条件乘积及容量行属于这一已有机制的结构化实例；包含相同原容量及相应事件提升的强参照会覆盖本因子。我们不用完整层级、相位穷尽或动态分离算法。[原论文第二节与第四节](https://arxiv.org/html/2503.17483v2)

已有 D029/D035/D201 的单事件、共同乘积与神经消元仍是直接参照；D234 是消费行 C 的来源。本文新增的是无需完整 V 或旧 observer hull 的有限上界证书，以及其参数族和实际残差接口，不声称首次发现条件化原理。

本轮只有精确纸面推导和独立复核。没有实现、candidate import、AST、compile、collection、数值求解、GPU、真实模型前向、shadow 或全量回放；没有冻结一个可执行候选。以上规模是展开公式的局部计数，不是实验测量。正式 1870/2413 与独立 E0 61/400 的新增均为0。
