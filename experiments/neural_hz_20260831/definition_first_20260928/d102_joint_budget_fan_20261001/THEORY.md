# 两个共同预算读出的精确联合投影及组合边界

本轮补齐一个本项目此前未记录的具体步骤：不再要求多个消费者具有同一排序，而是用固定输出方向覆盖全部相关排序，从同一个盒加预算中获得两个读出的完整联合像。正负方向都保留时，可以精确传递任意混号仿射读出；只保留联合上界则不能。这里精确的是指定预算子模块，不是原网络全部谓词的投影。

该步骤是经典连续背包与多面体边方向理论的组合应用，不是新的通用定理或已完成的 Neural-HZ 定义。全展开方案有明显行数和系数膨胀风险；尚无强神经网络对照或完整成本优势。本轮只做纸面推导、原始文献阅读及独立复核，没有创建实现或启动候选测试。

## 研究状态及语义范围

上一轮是 progress：按用户要求补齐 D101 归档、目标快照与恢复入口，不是能力增长。本轮重读该入口和状态，重验其 15 项清单通过。分支 redu-hz，commit f1bc0f16612bd3f2112f2970174ec2f7cc3bf5ac，原 tracked binary diff SHA256 为 29baf0c0fcc19070a97a5ddf0fea3d1591ff937d00abca28689e9a871a530bc5。

完整原 HZ 仍含连续因子、全部原二元相位、EQ/LE、共享 frame 和原输入 decoder。本轮不删除或连续化原相位，不替换成 Z/CZ，也不新增求解路径。已知预算是同一原赋值的可靠后果，而不是为每个消费者单独选择输入。

设原 active bits 的认证视图为 b，给定固定可靠 A_j>=0、a_j>0，以及关于保留参数的仿射 B(b)。定义：

```text
K_b = { n : 0<=n_j<=A_j*(1-b_j), sum a_j*n_j<=B(b) },
P_b = c + W*K_b,                         W has exactly two rows,
D_b = { y : exists n in K_b, y<=c+W*n }.
```

P_b 是两个物理读出的完整联合像；D_b 是其向下闭包，只表示共同上侧见证。要求容量非负、B(b)>=0，以保证 K_b 非空。b 在域语义中保持整数；公式对分数 b 的适用性只说明该指定查询外包，也不删除原整数语义。

这里的二维是两个保留的共同观察，不是说任意 m 个消费者只要代数秩为 2，就能用两个独立界取代。若完整银行 W_all=C*W，必须保留全部实际消费者 y_all=C*y 的精确关联、旁路和源身份；先取二维向下闭包再允许任意混号 C，不具有该等价性。

若原 n 还出现在其他谓词、原门、残差或消费者中，K_b 只是它的外包。本结论仅授权生成健全观察，不授权删除 n 或那些关系。只有全部外部依赖确实经过 W*n、且局部全部条件就是该 K_b 时，才是这个完整子模块的精确存在量消去。真实神经结构尚未证明满足这个消去条件。

## 固定方向覆盖不同消费者排序

令 v_j=W[:,j]/a_j。对一个输出支持方向 t，连续背包利润为 w_j=t'W[:,j]，排序依据 w_j/a_j=t'v_j。

预先构造这些经过原点的方向边界：

```text
t'v_j = 0,
t'(v_i-v_j) = 0,  i<j,
t1=0, t2=0.
```

恒零式不是一条边界，可静态略过；这不删除任何原因子。第一类不能省：即使所有利润的相对顺序不变，某项穿过零也会改变是否应该填容量。坐标轴既给出正象限边界，也令全平面的每个锥都是尖锥，避免退化方向的线性子空间被遗漏。

这些边界只由 W、a 决定，不读相位取值、LP 点、终端 margin、标签或模型身份。它们划分的是输出查询方向，不是输入域或原相位；不存在按方向启动网络子问题的步骤。

在任一个闭方向锥内，采用固定 tie 顺序后，利润的正负和降序一致。对每个固定可行 b，按该顺序填充容量直到预算耗尽，得到 n_star(b)。它同时最大化该锥内所有目标 t'W*n；边界零利润及并列利润仍可用同一个见证。因此支持函数在每个锥上线性。

任意锥内方向都可写成其两条极射线的非负组合。由于同一个 n_star 达到这两个及中间方向的支持，射线上的支持不等式推出锥内全部支持不等式。所有锥合起来覆盖目标方向空间，这就是有限方向足够的原因；仅保留各消费者坐标轴和它们的总和一般不够。

## 编译成原相位仿射行

对每条固定非零射线 t，令 w=W'*t，沿用 D101：

```text
Lambda_t = {0} union {w_j/a_j : w_j>0},
phi_t_lambda(b) = lambda*B(b)
               + sum max(w_j-lambda*a_j,0)*A_j*(1-b_j).

t'(y-c) <= phi_t_lambda(b), for every lambda in Lambda_t.
```

右侧是关于原 b 的仿射式，全部系数、正部和断点在生成时固定。所有断点都保留，不通过对偶优化、分离 oracle 或运行中的点来选行。其最小值是 K_b 在 w 方向的精确支持。

只取正象限中的射线，有限行组恰好描述 D_b。因为 D_b 是闭凸的向下集合，具有有限支持的分离方向必须非负；上一节已覆盖这些方向的全部支持。

取全平面射线及其反向，则有限行组恰好描述紧凸集 P_b。若一个点不在 P_b，凸分离给出某个全符号支持方向；该方向所属锥的射线行已排除它。两个结论都在同一个固定 b 下成立，且整个行系统保持 b 为原离散变量，所以并未把不同 b 的集合混成一个凸域。

这是对子模块的联合投影，不是分别给两个坐标各挑一个 n。原 HZ 安装同样预算、读出和静态后果行具有相同逻辑信息；单独投影不会凭空提高原整数表达力。

## 一个跨排序且混号的普通控制

取 K={0<=n_j<=1, n1+n2+n3<=1}，定义：

```text
h1 = 1/10 + 3*n1 + 2*n2 - n3,
h2 = 1/5 - n1 + n2 + 3*n3.
```

两个消费者均有混号系数、非零偏置，排序相反。它们的真单独上界分别为 31/10、16/5；总和的真上界为 33/10。点 h=(13/5,7/10) 同时满足这些界，包含总和取等。

但静态方向 t=(2,1) 对前两项给出相同利润 5，第三项利润 1，因此：

```text
2*h1+h2 <= 2/5+5 = 27/5.
```

假点左侧 59/10，违反 1/2。另一个交叉方向 t=(2,3) 给出 2*h1+3*h2<=39/5。这些方向由系数自动产生，不是预先只选两个单界和总和。

控制证明完整联合预算关系强于列明的边际和总和摘要，并覆盖 D060 单一共同排序之外的情况。它只是预算接口例子，不是从实际原网络提取的完整块，不是 validated ADV，也没有证明超过 D066、D091 或原 HZ 加同预算。不得把这个局部严格性计为定义级或正式验证收益。

## 前向组合与不能省的相位

完整 P_b 可与新读出 z=T*y+d 的精确等式共同保存。对任意符号 T，这恰好表示 z=T*c+d+T*W*n 的同一预算像；只要仍是两个需要保留的观察，也可以直接以 T*W 重新生成完整方向集。Add 和 Concat 必须是同一 n、同一 b 的关联操作。来自不同且相互依赖预算的两个输入不能无证明地合并成一个独立预算。

仅有 D_b 时，非负 T 的上側读出可以通过单调性健全消费，但它不是一般混号读出的完整值域。要得到相应下闭包，应写成 exists y in D_b: z<=T*y+d，而不是自动将 T*D_b 认作一个对全部输出坐标向下闭的集合。

ReLU 不能在这里被偷偷凸化。一个普通两变量预算反例为：

```text
K = {n>=0, n1+n2<=1},
y1 = -1 + 2*n1 + n2/2,
y2 = 1/10 - 3*n1/5 + 9*n2/10.
```

W 满秩且混号，两个原预激活均跨零。n=(1,0) 和 (0,1) 分别得到 y=(1,-1/2) 和 (-1/2,1)，ReLU 输出为 (1,0)、(0,1)。但整个 P 满足 y1+y2<=1/2；输出中点 (1/2,1/2) 要求两原预激活都等于 1/2，故不可能。ReLU 像是非凸的，不能仍当作固定旧条件键下的一个凸预算像。

保留下一层原 child bits gamma、可靠界和准确 ReLU 图约束，可以精确描述这个抽象输入集合的整数图，而不创建子域。零预激活的两种合法标签必须照旧保留。但这并没有证明消去旧 y 后仍属于相同单预算族，也不保证新 LP 松弛理想、所有连续源仍有原网络见证，或跨任意深度低增长。该反例仅否定省掉新增原相位的凸闭包，不否定所有扩充的相位条件表示。

## 子模块反向见证的构造与限制

对于固定可行 b 且满二维的 P_b，可以给出显式存在性重构，不把支持点冒充任意 y 的见证。全平面相邻射线锥内取一个内部方向，并按其静态排序生成预算贪心点 n_k。所得 y_k=c+W*n_k 覆盖 P_b 的全部顶点，可能重复；这是有限方向构造的同一支持论证。

保留这些共同顶点见证，按多边形顺序去重后作三角剖分。任意 y in P_b 可落在某个闭三角形，解其重心坐标 theta_i>=0、sum theta_i=1，令 n=sum theta_i*n_i。由 K_b 凸性有 n in K_b，且 c+W*n=y。这里是预算子模块的代数重构，不是输入或相位分割验证策略，也不运行攻击或求解器搜索。

需要完整支付各 n_k 和几何计算；这不是免费 decoder。低维、精确算术超限、身份缺失或任何未证前提的实现策略尚未定义，不能据纸面算法删除原 n。尤其原 HZ 的其他谓词若未纳入 K_b，这个 n 不保证满足它们；因此本研究保留原 decoder，不将子模块见证送作网络 ADV。

## 完整成本和一个必要增长例子

设有 n 项，H=n*(n-1)/2+n 条可能的非零利润边界。正象限最多 H+2 条射线；全平面加入坐标轴后最多 2*(H+2) 条。重复或不穿过所需象限的边界可少计，但完整的统一生成账单不能只按有利例子计。

每射线至多 n+1 条断点行，因此该直接编译的行数上界为 O(n^3)。若 B 的完整保留参数支持为 p，每条行展开需 O(n+p+2) 个系数，整体为 O(n^3*(n+p))；p=O(n) 时为 O(n^4)。这些是该构造的保守上界，不是所有表示的必要下界或实测费用。生成、去重、排序、精确比值、512 位上限、可靠舍入、原谓词、证据和终端转换均另计。

若显式生成 R 个方向锥的重构见证，每方向重新排序的直接算法还需 O(R*n*log n) 工作、最多 O(R*n) 见证存储。三角查找和重心系数也必须可靠。只输出少量维度，不能据此宣称完整代价已小于保留原共享 n。

作为不能取常数行的普通例子，令 K 为 n-simplex，W 第 j 列为 (j/n,1-(j/n)^2)，j=1..n。这些有理列位于严格凹下降曲线上，联合上边界有 n-1 条不同的正法向边，相邻法向为 ((2*j+1)/n,1)。所以不使用辅助量、只在两个消费者坐标里写完整联合上像的一般方案，需要至少线性多的行。这个 Omega(n) 下界不证明上面的三次上界紧。

对于必须覆盖全部相位参数、系数法向固定且无辅助量的模板，方向数量还可达到二次下界。令 N=n+1，取：

```text
t_j = j/N + j^2/(10*N^3),
W[:,j] = (t_j, 1-t_j^2),
K_b = {0<=n_j<=1-b_j, sum n_j<=1}.
```

这些 t_j 在 (0,1) 中，系数位长为 O(log n)。所有不同无序对的 t_i+t_j 均不同：i+j 不同时主项差至少 1/N，扰动总差小于 1/(5*N)，不可能抵消；i+j 相同时，平方和相等又会固定乘积，因此固定同一个无序对。

对任意 i<j，仅令 b_i=b_j=0，其余 b 为 1，固定纤维的二维像是 conv{0,W[:,i],W[:,j]}。其上边具有正法向 (t_i+t_j,1)，支持值 1+t_i*t_j。有限半空间表示若精确包含这条非退化边，就必须至少有一条与此法向平行的约束。不同对要求不同方向，因此统一模板至少要有 n*(n-1)/2 个法向。

这说明 O(n^2) 的方向数量在上述模板类中不能普遍降为线性；不证明 O(n^3) 总行数或 O(n^4) nnz 是必要的。它不约束保留共同 n、引入其他辅助量或采用相位依赖系数的表示，也不声称真实网络中的这些相位模式都可达。这里只划定代价主张的范围，不把稀有相位或数值特例作为新实验目标。

相对地，保留共同 n 的原扩展式仅有 n 个共同幅值、2n+1 条盒和预算 LE，以及两条读出 EQ；相位容量、B 和 W 的实际支持另计。其规模按输入支持线性增长。当前不能声称消去幅值一定优于这个完整对照。

## 先行工作及项目内区别

[Onn 与 Rothblum 的 Convex Combinatorial Optimization](https://arxiv.org/pdf/math/0309083)，第二节第一小节 Lemma 2.3 和 2.4，给出已知边方向对法向扇的细化及线性投影的边方向性质。本轮根代理已读取这两个引理。归一化 t_j=a_j*n_j 后，盒加单预算的边方向是坐标方向或两坐标差；映射到输出后正是 v_j 和 v_i-v_j。这是本文有限方向构造的直接已有背景。文献使用的辅助 zonotope 只用于描述方向排列，不在本项目中替换非凸 HZ，也不移植其优化 oracle。

每个方向的支持继续使用 D101 已核查的 [Bertsimas 与 Sim 预算支持公式](https://www.mit.edu/~dbertsim/papers/Robust%20Optimization/The%20price%20of%20Robustness.pdf)，不是新的背包算法。全文的神经接口、具体控制及预算参数化是本项目的推导，不能因这里没有运行对偶就声称数学原语新颖。

档案窄查未见本次完整二维方向构造。D060 已有一个共同排序的联合上侧见证；D089 是槽容量运输的子集割及展开代价；D100 限制独立标量字典，不否定完整联合像。D014 已研究层次化幅值预算、贪心、交叉预算失败和共同源拼接问题，因此本轮不另起一个 laminar 重命名方案。窄查不是全面新颖性证明。

## 研究决定和下一项实质问题

保留本构造作为低维联合关系的精确对照工具，不把它直接铺到宽卷积，也不为经典构造新增包装器或测试套件。它改变下一步判断：跨排序不是联合投影的绝对障碍，但低维也不保证便宜；在固定法向、无辅助量的全参数模板内，方向数的二次增长有明确必要例子。真正尚缺的是普通神经结构产生的 source-bound 联合关系，以及穿过原相位 ReLU 后可组合且不爆炸的表示。

下一候选需要与同预算、全部相关源、真全局界和已有共同相位关系公平比较，并证明完整成本或关系生成有非重复贡献；不能只比两个独立界。不要求每个候选达到全网理想凸包，也不因尚未达到这个研究目标就宣称阻塞或放宽限制。

本轮没有代码、freeze、RUN、候选数值、测试、模型解析、GPU、shadow 或全量回放。最新实际测试仍为 D098 的 3845/188；D099 草稿不启动，D100/D101 的限定不撤回。正式 1870/2413（1063 CERT 加 807 validated ADV）及独立 CIFAR100 25、TinyImageNet 36 共 61/400 不变，formal_gain=0。
