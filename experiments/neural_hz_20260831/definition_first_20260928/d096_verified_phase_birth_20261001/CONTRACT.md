# 非凸ReLU出生与共同关系传递的算子合同

本候选把D094的在线相位出生引理实现为实际SparseHZono上的默认关闭算子，供后续共同关系域使用。它不是新域定义已完成的声明，也不把常量提升或证明携带机制当作独占创新。D095未执行草稿原样保留；本目录是独立修订，补严格索引认证及完整数学测试。

## 语义与精确对应

输入H由连续xi的单位盒、原signed二元b、原EQ/LE及共享frame组成。每个输出是实际存储binary64系数解释为精确二进制有理数的仿射g。所有输入整数可行状态theta都在范围内；不用实例身份、标签、margin、LP状态或外部未证界筛选。调用期间输入必须静止，外部来源认证不由本算子替代。

对完整g求r为全部连续及二元系数绝对值之和，精确界为c-r和c+r。界下端非负的稳定行复制，界上端非正的稳定行归零；恒零按稳定正处理，不新增相位。其他行向外舍入lower和upper，并验证L=lower/2、Q=upper/2可精确存为有限非零binary64且L<0<Q。运算不满足512bit等前提即拒绝，不改用另一条算法路径。

第一次存在不稳定门时追加两个不同连续因子rho_c和rho_Q，各以实际EQ固定为1。后续调用可以复用，但必须重新核对这两条字面EQ，并要求当前全部输出不引用这两个列。这样偏置c和Q无需相减、相加或合并到同一个浮点系数。每个不稳定输出完整追加两连续s、eta和一个signed二元b，存储：

```text
L*s - Q*eta + L*b - g_nonconstant - c*rho_c + Q*rho_Q = 0
-s - b <= 0
-eta + b <= 0
q = Q*(1-eta)
```

两个常量EQ、出生EQ与guard只用实际系数的字面拷贝、符号变换或经证明的精确半分。所有新行中原非零项、s、eta及两个常量角色均不发生同列合并；原二元项和新b也不同列。因此实际存储等式恰好等于所声明理想式。输出q的中心及单系数同样精确。不把十进制1/10误称为精确binary64；对应的是原实际c。

## 共同扩展与反向证明

将rho_c=rho_Q=1代入后，出生EQ是`L*(s+b)+q-g=0`。若b=+1，guard与eta单位盒强制eta=1，故q=0且g=L*(s+1)≤0。若b=-1，guard与s单位盒强制s=1，故q=g≥0。因此任何整数可行扩展的读出都是ReLU(g)，不只证明某个好辅助赋值。

反之，对每个原可行theta，q=max(0,g)。正g取b=-1，负g取b=+1；g=0时两种b均允许。连续量的共同解释为`eta=1-q/Q`、`s=(q-g)/(-L)-b`，由lower≤g≤upper可知s和eta均在单位盒内，且满足全部新行。对所有新门同时使用同一个theta与允许的新bit向量，构成共同Gamma(theta,new_bits)，而非逐消费者选择互不相容的原输入。恒零稳定行从未创建新bit，不删除已有任何原bit。

旧连续与二元坐标以恒等前缀嵌入；所有旧EQ、LE、RHS逐字保留，新列补零。因此原状态投影精确，输入decoder仍读取原前缀。代码保留frame及exact标志，exact=False不会被升格。这里证明原生状态与读出的对应，不宣称原模型浮点执行、ONNX端口或现有在线allocator已接通。

## 实际谓词认证与传递边界

BornGate记录原预激活、原读出、实际Graph行列和向外端点。verify_gate检查carrier两EQ、出生EQ及两guard的实际内容，覆盖界与读出，不凭owner或seal接受。该接口只认证所选关系，不扫描整个外部HZ、验证整个网络来源或证明未读旧行的历史。未认证外部snapshot仍需原全入口检查。

保持旧谓词、坐标域及身份的后续Affine或出生变换可保留原latent g/q关系；出生时output_row不是当前输出位置承诺。全网络Add/Concat、独立frame注入、实际decoder来源与allocator生命周期尚未认证。D064通用提取器直接看到的是含carrier项的另一种表达，D093尚未消费本证书；不能跳过商化证明直接把旧parser接上。

## 工作量和存储范围

令P为输入六个CSR矩阵的nnz与rowptr数、三个向量长度之和；T为全部输出连续及二元项数；U为不稳定输出数；K为首次两个carrier列的数量，否则0；M为max(1,max(row_support+8))。先付费再执行的批次包括：常数header；完整schema的32*(P+nc+nb+1)；所有输出header的64*(n_out+1)；每行读出与界的128*(support+8)；字面构造的128*(T+n_out+16U+8)*(1+bit_length(M))；完整复制、输出及receipt的32*copy_population*(1+bit_length(M))。copy_population按源码包含旧人口、新旧宽度、新输出与谓词nnz、全部新增行和输出元数据。carrier及所选行认证另预付固定header和完整局部支撑。

此批次工作由调用者硬pool限制，任何批次付费失败即停止，不选小子集继续。每个NativeAffine支撑上限65536，包括生成行在合并前的出现项；不把整个普通门组误限为65536项。完整批次仍有硬pool。每个精确有理数限512bit。代码报告输入和输出数值缓冲及nnz，不把它们误称为Python临时、峰值、来源根、GPU或终端总存储。

新增连续数K+2U、原signed二元数U、EQ数K+U、LE数2U。它没有减少原bit，也未声称构造条目下降。自推单位盒界可能比相关性界松；当前不承诺真实13家族零回归或能力提升。D094已厘清island费用范围，不能把改收费范围当作优化；真实前向、终端及重构仍须完整预注册计费。
