# 让共同观察消费实际预激活证书

本记录是D096成功后的只读源码审查与数学推导，没有新增候选执行。下一步应把已认证的实际预激活接入共同观察及后继变换，使定义研究回到关系的生成和消费；不继续单独优化常量存储，也不把下面已知的等式代换当新抽象域创新。

## 原提取器健全但可能丢失精度

D064 native_binding.py的_extract_graph将出生EQ剩余项取负并加Q。对D096模板得到：

```text
g_raw = g_actual + c*(rho_c-1) - Q*(rho_Q-1)
```

由于实际HZ保留rho_c=rho_Q=1，g_raw与g_actual对全部可行状态相等。D086和D093若沿用原提取器，其共同扩展关系仍健全；但把这两个固定列按自由单位盒计算余项范数会使界变松。不能把“不是同一形式”误报为关系必然不健全，也不能把actual g的认证省略成一张未验证缓存。

一个普通混权例子可直接展示影响。令u=(1-eta_u)/2、v=(1-eta_v)/2，g=u+v-3/4，向外精确上界5/4，Q=5/8，实际仿射中心c=1/4。正确余项g-u-v是常数-3/4，非恒定半径0。原提取器的余项却是`-3/8 + (1/4)*rho_c - (5/8)*rho_Q`，单位盒半径7/8。在父相位均关闭的条件槽中，前者g精确为-3/4，后者的粗盒为[-5/4,1/2]。这是精确代数推导，不是新的模型运行或已测的终端收益；原rho等式依然使实际可行值相等。

## 最小对接合同

首次认证保留Graph、实际g/q及两条carrier EQ依据。每一条代换必须能由实际行推出上述g_raw-g_actual恒等式；所有原因子、bits、EQ/LE和decoder都保留。不能通过删除常量列或改旧EQ获得表面节省。

在同一静止且已来源认证的H0上，完整人口的实际关系认证可以由共享接口供D086基础关系、D093观察及后继消费者使用。跨增广的复用只能依据已证明的原谓词前缀保持及明确列身份嵌入；可变对象id或seal不是证明，外部snapshot首次进入仍须完整来源/schema和关系绑定。现有接口没有这种共享证书入口，不能修改冻结全局提取器来偷偷接入。

carrier列还须有明确专用角色，不能被自动结构选择误认为另一个原门的eta。结构选择仍覆盖完整原人口，不按实例或求解状态分流。后续可证伪控制应在一个普通有偏置、混权多层块上，同时检查商化g逐项等于出生证书、所有旧整数状态及零点标签共同扩展，以及原D092严格观察收益可否保留。仅商化通过不授予这些组合结论。

## 接实际网络前的必要接口

已只读核对hybridz_tf.py的_sparse_relu_slots_for：生产按frame全局高水位与(frame,layer,neuron)复用槽，而D096从当前HZ宽度追加。隔离adapter必须对齐完整已预留宽度，保持旧同层槽，成功后原子登记新slots和宽度；不得造成同一frame列身份冲突。carrier需要独立frame级生命周期，不能覆盖_sparse_aux_slots已有的固定数量合同。

现有rebase会修改宽度并清理对应frame的ReLU及辅助槽登记，旧证书不能未经映射证明继续复用。共享缓存根、具体输入重构和发布顺序同样必须纳入。只在tf.apply返回后替换输出，已经错过出生和相关预计算，并非可信接入。

tf_cnn.py的deferred路径可只物化非负候选行，再发布分离表达式；这种partial HZ不是D096所要求的完整输出人口。不能直接传入冒充全层，也不能仅关闭lazy/deferred来隐藏缺口。完整实际人口、可靠界、费用及存活状态都需新预注册，目前不启动旧大pickle或照搬已失败的D090包装器。

## GPU后续范围

最早可独立验证的批量步骤是完整CSR行绝对值和的可靠外向求界，以及分类后的prefix-scan和模板行装配。必须证明并行舍入相对精确CPU参考的包含关系，计入数据传输、CPU与GPU矩阵共存、所有谓词及终端转换。D096目前仍是CPU/Fraction实现，这一建议不构成GPU结果，更不等于终端求解已GPU化。
