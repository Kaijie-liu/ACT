# Neural-HZ 完整消费者压缩的精度条件

本轮直接检验 D178 定义是否值得在真实 CNN 上实现，不另造验证 helper。核心问题不是能少存多少幅值，而是压缩后哪些原相位仍能精确消费共同源，以及这个损失能否在相同资源下换来更强的验证能力。以下推导是纸面证据；一次元数据诊断只绑定结构和尺寸，不验证该能力。

## 固定参照与具体化

沿用 [D178 定义](../d178_reference_observed_fiber_20261004/THEORY.md)。完整消费者为 B，C 包含 B 与共享 mass，H=C D_tau，F=[C;H]。给定同一父赋值 d、整数原相位 beta 和可靠 E，共同见证满足 Ft=Fd、||t||²<=E。新读出为 C D_beta b+H d+delta，其中 delta=C(D_beta-D_tau)t。全部 guards、branch caps、mass dominance、旧谓词、共享源及输入 decoder 仍保留。

真实图取 t=d。新旧读出之差精确为 C D_beta(t-d)，因为 H(t-d)=0。这不是独立噪声，也不是每个消费者各选一个代理。

比较的强参照是同一父域和信息下的原逐门 HZ，不仅是更松的 D157。原 HZ 若精确表示这一 ReLU 图，任何健全外包都不可能在集合精度上超过该图；可能的价值是同等完整资源下更有效的传播或查询。若只恢复 D157 的损失，则不得记作超过原 HZ 的能力。

## 精确相位与失真方向

令 P 为 ker(F) 的正交投影，h=(I-P)d，rho²=E-||h||²。真实 d 可行，故 rho²>=0。裸球切片恰为

```text
t=h+w,   w in ker(F),   ||w||<=rho.
```

因此在固定 beta 和方向 v 上，裸球允许的输出误差上界精确为

```text
-v^T C D_beta P d + rho ||P D_beta C^T v||.
```

不能漏掉第一项，把真实 d 当成球切片的最小范数中心。该公式由正交分解与 Cauchy Schwarz 等号条件得到，是 [D160 已有几何](../d160_source_subspace_fiber_20261004/THEORY.md) 在 F 上的应用，不是新颖性声明，也不是搜索未知相位的算法。

当 rho>0，裸球包对该 beta 精确当且仅当 C D_beta P=0，等价于 row(C D_beta) 包含于 row(F)。充分性不需要 rho>0。加入原 caps 等加强条件后，充分性仍成立；必要性仅在这些附加条件保留相应局部自由方向时成立。故不能只凭秩不足断言完整 native 或某个实际样例一定有伪点。

## 压缩不能免费保全所有相位

F 与 [C D_tau;C(I-D_tau)] 行等价。两块支撑在互不相交的列组上，所以

```text
rank(F)=rank(C[:,tau=1])+rank(C[:,tau=0])<=2p,
p=rows(C).
```

若裸球规则要对所有整数 beta 保持精确，则在非退化球切片下必须 ker(F)=0。证明只需与 tau 相差一个 bit 的各相位：C D_beta P=±C_i e_i^T P，而 C 的 mass 行使每个 C_i 非零，因而 P 的每一行必须为零。这是全相位条件命题，不宣称这些相位在真实父域都可达，也不枚举相位运行验证。

D178 的仅行数节省窗口为 m>9p+rows(B)，必然有 m>2p。因此同一个窗口不能同时被称为这种裸球压缩的无条件全相位精确区间。可达相位、附加强约束、误差方向及实际查询仍可能使它有用；这些必须测，不能由宽度压缩推断。

## 真实结构检查与可反证比较

本轮统一识别全部三份已登记 CNN 中的完整链 ReLU→Conv→BN→Add→Flatten→Gemm→ReLU。原父 skip 必须共享且早于新 q；新 q 及链内中间端口不能有被遗漏的消费者或图输出。所有 ReLU 都报告匹配或拒配原因，不按身份、标签、margin 或历史结果挑选。

一次只读诊断从原 protobuf 解码必要属性，以显式单样本 batch=1 递推尺寸。它不读取权重数值，不计算 B=W F_flat T_BN K_conv，不取得可靠的源/能量界，不绑定 native element，也不运行模型。BN 参数数值有效性、有效矩阵秩、tau、实际可达相位和误差大小均仍未知。

报告 m、r=rows(B)、保守 p=r+1、原 bits=m、旧逐门4m行、新2m+18p+2r行和 C 的 dense entry 上界 p*m。这里4m是未作稳定相位简化的逐门四行图，不是实测生产行数；没有读取输入范围，也未取得不稳定门人口。p=r+1 不假定 mass 已与真实 B 某行相同；只按维数分析，不擅自减去质量行。共同继承谓词、全部源展开、C 的形成/存储、能量、guards 的 nnz、历史 banks、终端 lowering、查询和 decoder 仍须另计。因此这些不是完整成本胜利。

后续真正的反证比较应将原 HZ、D157、D178 放在同一个已经认证的源前沿，使用相同可靠信息、预算与普通终端规则。检查跨下一 ReLU 的性质界或验证结果，并计算上述全部费用。若只比 D157 更紧而不能在强参照下支付代价，不继续给该候选扩大辅助工程。该比较必须先通过原数学人口；本轮诊断不绕过它。
