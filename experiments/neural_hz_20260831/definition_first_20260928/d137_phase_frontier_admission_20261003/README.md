This checkpoint keeps the user's priority explicit: develop a genuinely nonconvex, neural-network-oriented domain from the mathematical definition of HZ. ## What was established

- The constant-cap fiber embeds in an existing triangular affine-bound template. Its new ReLU cap follows from an existing input-aware ReLU inequality. These are specific limitations on the novelty claim, not a proof that the entire nonconvex domain is equivalent to a convex domain. The derivations and primary sources are in [Mathematics](MATHEMATICS.md).
- A phase-gated fiber has an exact fixed-phase support recurrence, but unrestricted phases give the same global support as the all-on fiber. With the original on/off predicates already retained, gating also leaves the full labeled concretization unchanged.
- Original-bit exclusivity can permit an exact shared radial factor without deleting bits. Its cheap linear consumer case is restrictive, its structural nnz increases in the ordinary control, and a same-source, same-phase fractional point proves loss of the old LP inclusion. It is not admitted as a zero-regression replacement.
- Saved CIFAR graphs show that the residual dependency continues beyond the first Add. The complete set of surviving consumers must participate in any elimination theorem. [Real frontier](REAL_FRONTIER.md) records the verified topology and static capacities, including the missing Tiny downstream evidence.

All mathematical conclusions above are paper derivations independently reviewed in this turn. They are not newly executed tests, source-network measurements, timing results or formal solves.

## Next research action

The next definition hypothesis must make the retained source, original phases and shared amplitudes affect a joint query across every live Conv/Add consumer. It must provide a precise concretization, an operator/composition theorem and a fully charged query/lowering path. Merely placing a phase-dependent symbol in a formula does not discharge the optimization cost.

Use the full ordinary residual frontier documented here; do not select artificial equal-column consumers or erase an identity skip to manufacture compression. Compare with both original HZ and HZ supplied with the same valid relations. Identical exact constraints necessarily describe the same set: the latter comparator is for attributing precision and total cost, not an impossible demand that a new encoding beat itself in exact precision.

Only after a substantive hypothesis survives these checks should a successor implementation and execution be preregistered. Keep the original resource and population gates, opt-in default, all source identities and zero labels, fail-closed handling, concrete witness reconstruction and full replay requirements. GPU, smooth activations, Transformer and other families remain part of the active goal; no qualification for them follows from this PWA paper checkpoint.
