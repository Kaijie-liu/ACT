# 有界秩二神经块的共同幅值和相位关系

本轮提出一个范围明确的 Neural-HZ 块候选：在认证的二维共同源和多边形覆盖条件下，用线性规模的连续关系保留全部原相位，得到整个门组的完整 source-labelled 图凸包；原相位为整数时仍精确等价于原非凸神经图。它不是完整新域、真实 CNN 资格或新凸几何原理。相邻曲率、锥分解和有限凸组合均有旧先例；新增项目结果是它们在本结构上同时恢复共同源与全部原标签，并给出全 nnz 线性的编码。

## 非凸元素及适用结构

保留原 HZ 连续因子 xi、全部原 signed bits、EQ/LE 谓词 H、共有 frame、所有活消费者和原输入 decoder。对一个门组，认证两个同源仿射读出 u,v。先以规范形式描述 N=n+1 个原门，n>=2：

```text
f0=v,
fi=u-ti*v,  t1<...<tn,
qi=ReLU(fi), beta_i in {0,1},
M0=2*q0-f0, Fi=2*qi-fi.
```

M0、Fi 是幅值别名，不要求新列。原位 beta_i=(signed_bit_i+1)/2 仍是同一个离散因子。其整数语义是 M_i=(2*beta_i-1)*f_i>=0，等价原 ReLU 和弱 guard；f_i=0 时两个原标签都保留。

一般两两非平行的 rank-2 原仿射读出可选择两个基读出，经可靠非零比例变为上述形式。若 g=c*f，幅值别名为 |g|/|c|；c<0 时用原负幅值 q-g，并以1-beta指同一个原位的补标签，不新增或合并原 bit。全部偏置也须满足该仿射读出恒等式；只对权重矩阵说 rank2 而忽略 bias 不够。零行、重复方向、原相位其他消费者不能静默删除。本定理及计数先限定 N 个不同方向，不授权近似秩判定。

有界定理的父源必须是实际完整二维凸多边形 P，紧、关于原点中心对称（P=-P）且0在其内部。只在某个偏移中心对称而包含原点不够；不能静默平移，因为这可能破坏齐次读出。定义已知射线

```text
r0=(1,0), rj=(tj,1), j=1..n,
aj=gamma_P(rj)>0,
gamma_P(x)=inf{a>=0:x in a*P}.
```

关键覆盖条件：P 的每个顶点方向均属于这些原门零线之一。aj 因而给真实边界点 ±rj/aj。P、源恒等式、正分母与覆盖都必须可靠认证；这不是按实例、性质、margin 或 LP 状态选路径。不能把一个更大 HZ 的二维外投影冒称完整父源。

候选元素是 H 加下述共同关系因子及同一赋值上的输出读出。空因子嵌入原 HZ；具体化按同一 xi 和原整数 bits 满足所有关系求输出，包含偏序按同 frame 的具体化包含定义。没有声称廉价最佳抽象或完整格。

## 无界块的唯一幅值分解

记 Delta_i=t_(i+1)-t_i>0、s_i=(F_(i+1)-F_i)/Delta_i。定义只用于公式及证明的量

```text
mu0=(F1+Fn-(tn-t1)*M0)/2,
mu1=(M0+s1)/2,
mu_i=(s_i-s_(i-1))/2, 2<=i<=n-1,
mu_n=(M0-s_(n-1))/2.                         (CURV)
```

这些量唯一满足

```text
M0=sum_(j=1..n) mu_j,
Fi=mu0+sum_(j=1..n) mu_j*abs(ti-tj).          (MAG)
```

验证：右侧相邻斜率为 sum_(j<=i)mu_j-sum_(j>i)mu_j；端点之和为2*mu0+(tn-t1)*M0。这同时证明公式的逆和唯一性。

因此 mu>=0 等价 N 条三项幅值行：

```text
F1<=F2+Delta1*M0,
Fn<=F_(n-1)+Delta_(n-1)*M0,
Delta_i*F_(i-1)+Delta_(i-1)*F_(i+1)
    >=(Delta_(i-1)+Delta_i)*Fi, 2<=i<=n-1,
(tn-t1)*M0<=F1+Fn.                           (R)
```

加 M0>=|v|、Fi>=|u-ti*v|，这恰为无界图 (u,v,|f|) 的普通连续凸包，不仅是幅值投影。

充分性：固定 mu 后，同幅值的可能源恰为

```text
Z(mu)=mu0*[-r0,r0]+sum_(j=1..n)mu_j*[-rj,rj].
```

这个二维线段和的所有可能边法向就是各原 fi 的法向，各方向支持值为对应 M_i。因此上述全部 strips 恰好给 (u,v)∈Z(mu)，包括退化情形。取 theta_j∈[-mu_j,mu_j] 使 (u,v)=sum theta_j*rj，将每条系数分成(mu_j+theta_j)/2和(mu_j-theta_j)/2，就得到原图正负射线的共同非负组合。齐次性把有限非负和变成有限凸组合。

必要性也可直接由(R)的三角不等式证明。几何线段和只用于充分性证明；实际 Neural-HZ 没有被替换为 Zonotope，原 bits 和非凸图始终保留。N 条(R)来自已知守恒 circuit；本结果是该 rank2 类完整组合的线性描述，不是发现新的三角公理。

## 有界物理图的精确容量

在覆盖条件下，进一步加入

```text
T=sum_(j=0..n) aj*mu_j <= 1.                 (BUDGET)
```

便得到 P 上完整物理图的凸包。证明：原门零线之间的每个扇区内，所有 ReLU 都仿射；覆盖保证 P 与该扇区的交是原点及两相邻真实边界点的三角形。每个真实图点都能在这些同符号端点间分解。反之，给定 mu、theta，将质量 aj*(mu_j±theta_j)/2 放在 ±rj/aj，剩余1-T放原点，就同时恢复全部源与幅值。

这是证明中的几何分解，不是运行时逐扇区验证、输入 split 或 phase 子问题。拟议编码仅使用固定系数公式和一个共同关系系统。不过其经典 fan/vertex 凸组合来源必须明说，不能包装成全新几何。

覆盖不是可省略的技术细节。缺少 P 顶点方向时，(BUDGET)可能排除真实点；具体反例见 CONTROLS_AND_LIMITS。此时不能安装本精确容量，更不能凭经验忽略顶点。补方向的另一种静态扩展本轮仅作为未选择思路记录，不属于这里的编码或执行授权。

## 原标签共同恢复及整数等价

令 theta 为上面的共同有向系数，定义真实端点概率

```text
w_j^+=aj*(mu_j+theta_j)/2,
w_j^-=aj*(mu_j-theta_j)/2.
```

对每门 i，将端点上 fi>0 的概率相加得到 A_i，将 fi<0 的概率相加得到 I_i。使用同一份 w，而非逐门另选分布，施加

```text
A_i <= beta_i <= 1-I_i.                       (PHASE)
```

存在共同 mu、theta 满足(CURV)、|theta|<=mu、源等式、(BUDGET)、(PHASE)，当且仅当 (u,v,q,beta) 属于 P 上完整 source-labelled 神经图凸包。

必要性：将真实图点按上述同符号端点分解，保持原非零门的固定标签；零点的原标签也可保持。相加给同一份 mu、theta 及相位边缘。

充分性：端点的非零预激活已强制相应标签。门 i 剩余需要的 active 质量 beta_i-A_i 位于[0,1-A_i-I_i]，可在该门为零的原子上分配。在同一原子内，各个零门的标签可以独立取合法值，所以各门所需边缘能够同时实现，不能把这一步误写成不同源见证。非原点每条不同方向的端点至多有一个零门，可分成两个标签原子；原点可用一个共同阈值耦合实现所有边缘，至多 N+1 个标签原子。由此得到同一个有限真实图混合，无需物化2^N相位表。

若保留 beta 为原整数值，混合的每个正质量原子必具有该同一 bit 向量；这个相位下各 ReLU 都仿射。因此输出在平均源上仍是原 ReLU，原 guards 与全部零标签精确保留。这证明该因子是原非凸门组的一种等价扩展，不是把原 bits 连续化。普通终端 LP 分数查询得到的恰是已证明的局部理想松弛。

## 一条前缀链的完整编码

采用物化 mu_j、theta_j、T 和 C_i=sum_(j=1..i)aj*theta_j，C_0=0；总共3N个新增连续量。使用 N 条(CURV)定义等式，和

```text
-mu_j<=theta_j<=mu_j,
u=theta0+sum_(j=1..n)tj*theta_j,
v=sum_(j=1..n)theta_j,
T=sum_(j=0..n)aj*mu_j, T<=1,
C_i=C_(i-1)+ai*theta_i.
```

记 D_i=a0*theta0+C_n-C_(i-1)-C_i，则

```text
A0=(T-a0*mu0+C_n)/2, I0=(T-a0*mu0-C_n)/2,
A_i=(T-ai*mu_i+D_i)/2,
I_i=(T-ai*mu_i-D_i)/2, i=1..n.
```

将这些式子代入(PHASE)。每一行只消费常数个 prefix、幅值或相位坐标，无须存N乘N的符号矩阵，也不枚举相位指派。所有门、正负支路及消费者使用同一 mu、theta、C。

## 完整局部费用及算子边界

N>=3、幅值列已有时，这个明确编码新增3N连续列、2N+2条EQ、4N+1条LE、至多28N-13个变量系数 nnz。若幅值内联为2q-f，按已有独立 q,f 列计，上界为31N-13。没有新增原 bit。原图、源/输出定义、P、所有旧谓词和 decoder 均另保留、另付费；等式专用 HZ 所需 slack 与范围证明不能省略。

已有行还蕴含0<=mu_j<=1/aj、|theta_j|<=1/aj、|C_i|<=1和0<=T<=1。将这些辅助连续量规范到 HZ 单位盒是可行的表示步骤，但其比例、边界证书和存储另计；上述谓词 nnz 不是完整字节成本。

排序需要 O(N log N) 比较，固定关系生成和一次向量作用为 O(N) 算术。认证同源 rank2、比例与 bias，构造真实 P、计算所有 aj、检查顶点覆盖、证据、可靠数位和 source 展开均另计；例如 P 有 p 个给定半空间时，直接计算全部 gauge 为 O(Np)，不是免费。也没有证明完整终端 LP/MILP 求解、见证恢复或整网执行是线性的。

Affine/Conv 和 Add/Concat 在同一 frame 合并完整读出，关系及所有 q、bits 保留。新门仍在相同 u,v span 且覆盖保持时，可以把新方向插入排序并构造同一联合因子；相邻曲率只改邻接公式，完整相位前缀仍统一构造和计费。不同因子共享多个接口时不能再各取 hull 后宣称全局精确；一般下一 ReLU 的 preactivation 也未必仍在这个 span 中。

若 u,v 仅为更高维或带旧相位父域的读出，P 须经认证包含全部实际(u,v)读出且满足上述原点对称和方向覆盖前提。此时把本因子与完整旧 H 相交仍健全并保留整数图，但完整原 latent 与新门的 joint hull 不自动理想。完整输入 decoder 必须作用于原源；端点混合证明不是可以直接提交的具体 ADV。未经原网络验证的混合、分数或中间点不计成绩。

前缀及稀疏作用可考虑 GPU 批处理，这是实现方向而非实测速度。没有外部支持 oracle、LP状态修复、attack、BaB、backward/dual rescue 或第二条验证路径。本轮没有候选源码、数值预注册、执行或默认启用。
