# 联合误差的并行筛选结果

本轮并行推导仅作为支撑和排重保存，不与曲率候选拼接成绩，也不另开helper路径。全部为纸面结果。

## 真实子集容量未必次模

取x属于[0,1]、y属于[-1,1]，

```text
f=(1-2x+y/10, 1-2x-y/10, 3x-3/2+y/10)
e_i=ReLU(f_i), g=-f, q=g+e
F(A)=max_parent sum_(i in A)e_i.
```

三门均crossing、非平行、有偏置。凸函数盒最大值可在四角比较；误差向量分别为(11/10,9/10,0)、(9/10,11/10,0)、(0,0,8/5)、(0,0,7/5)。所以F13=F23=F3=8/5、F123=2，次模式左16/5小于右18/5。按3,1,2链的greedy增量产生(0,2/5,8/5)，违反第二、第三项的容量。真实共同源误差不自动是polymatroid，不能免费采用其精确greedy支持。这不否定另有证明的次模外包，但后者须支付源绑定与损失。

## 固定链交叠幅值预算

原精确门有eta_i=2q_i-g_i=|g_i|。结构固定的边(i,i+1)可以认证

```text
B_i=max_(a,b in {+1,-1}) upper_H(a*g_i+b*g_(i+1)).
eta_i+eta_(i+1)<=B_i.
```

四个系数方向是代数恒等式，不是输入或原相位分裂；需要四次同源前向支持，不能把两个单门界相加冒充。取B=max_i B_i、m>=2，独立预算模块K={eta>=0:eta_i+eta_(i+1)<=B}的精确支持为路径最大权独立集递推：

```text
D_0=0, D_1=B*max(w_1,0)
D_i=max(D_(i-1),D_(i-2)+B*max(w_i,0)).
```

一个共同分解证明归一化多面体的整数性：用同一个均匀t，对奇节点事件t<=eta_i/B，对偶节点事件t>1-eta_i/B；相邻事件不交且具有指定边际。B=0单独得到零向量。这是证明而非可执行枚举。递推为2乘2 max-plus矩阵积，可有O(log m)并行深度，但没有GPU运行证据。与源/相位/其他谓词相交后，该支持只作安全上界，优化点不是具体网络见证。

普通正控取(x,y,z)属于[-1,1]^3：

```text
g=(x+y+z+1/10, x+y-z+1/10, x-y+z+1/10)
B12=21/5, B23=4, sum eta<=53/10, ||eta||^2<=1203/100
Y1=eta1+eta2-eta3/10, Y2=eta2+eta3-eta1/10
r_j=ReLU(Y_j-1).
```

两个真实混权消费者均保留，q读出中的共同g项即活源skip。两后继实际crossing；统一B=21/5给r_j<=16/5<13/4。全部同源单门hulls、singleton、精确全局L1/L2预算，再加任意至多一条pair的laminar关系仍不足。仅12或13时，源零点eta=(1/10,11/5,11/5)通过它们，L1=9/2、平方范数969/100，却给r2=339/100>13/4；仅23时交换第一、第三项。eta=11/5的单门见证由权21/29的正负sign角点等权混合，再混8/29的源零真实点，原bit均值37/58；eta=1/10取源零点bit1。不同单门见证只共享显示源均值，不冒充全共同混合。

普通负控为g1=x+y/10+1/10、g2=-x+y/5+1/10、g3=3z+1/10。此时B12=21/10、B23=22/5；统一后丢掉较小边界。零源的eta=(11/10,6/5,1/10)属于各单门hull并满足统一链，却有eta1+eta2=23/10>21/10。

费用：4(m-1)次共同源支持，m-1条新LE；物理q,g时每边至多4nnz，若g=Lz+b内联，则总nnz为2(m-1)+sum_i nnz(L_i+L_(i+1))。每个完整查询另计读出形成和O(m)递推，p个消费者O(pm)，原父域/证据另计。保留原精确图时这只是有效行增强，旧HZ加相同行同样强；删精确关系会损失源绑定。故本轮归为支撑，不包装为新域本体。D014的laminar因子与D009的能量是已有比较，路径DP组织未获外部新颖性认证。

## 全pair仍可留下消费者可见偏移

固定严格mixed原相位，在所有同相位精确差分、跨相位FNE sectors、q>=max(0,g)、mask上界q<=U*beta下，inactive q=0，active q_i=g_i+a，并有

```text
0<=a<=min(min_active(U_i-g_i), min_inactive(-g_i)).
output error=a*C*beta.
```

个体triangle再缩短a上界；额外聚合caps继续截短，但不必消掉。完整读出精确当且仅当最终允许区间为{0}或C*beta=0。这是D011共同offset结论的消费者推论，不是新FNE原理。稀疏pair图则每个active连通分量可有自己的offset。

全父域反例：-2/5<=x,y<=1/2，x+y<=3/5，g=(x,y,-x-2y-1/2)，Q=sum q_i、B=q1-q2+q3，r=ReLU(Q+(x-y)/10-37/50)。真实凸读出在父多边形五顶点的值为7/10、59/100、16/25、14/25、41/100，故r恒0。严格内部x=y=7/25、原bits110时，假q=(3/8,3/8,0)通过全部pair、triangle、guards、mask及完整消费者active/inactive聚合界，却给r=1/100。它不通过原逐门精确上侧行。不能用更多pair或能量helper掩盖这一源—幅值缺口。
