# 共同源一阶矩约束的激活曲率域

本轮提出一个明确的有损 Neural-HZ 候选：将一组内部激活替换为覆盖全部消费者的共同曲率输出，并同时保留曲率总量和由当前源决定的一阶矩。它不是保留全部旧门后另加 helper；也不是把误差独立取盒。共同二次残差可直接进入这个语义，无需另建虚拟激活。

目前资格仅为纸面定义、健全性证明、普通正反对照及局部费用核算。Green 核、凸函数曲率测度和多面体投影均是已知原理，不主张已经形成新的数学原语、PLDI级方法或真实网络收益。

## 原生状态和适用结构

保留当前父域 H 的连续源、全部原 signed bits、EQ/LE、共同 latent/frame 身份、历史谓词及原输入 decoder。原 HZ 以没有新曲率块的元素精确嵌入。语义偏序为对齐身份后的具体化包含，不声称廉价最佳抽象或完整格。

取同一个 H 上的仿射读出 f,h,c。两端原网络门 p=ReLU(f)、q=ReLU(h) 必须作为当前抽象状态自身的精确关系保留；仅在真实网络中存在这两门、而当前幅值已被有损替换，不满足前提。需要新建这两个原门时须支付其全部费用，不能当免费 anchors。

对结构固定、互异的 0<t_1<...<t_m<1，实际内部预激活须认证

```text
g_i=(1-t_i)*f+t_i*h-c*t_i*(1-t_i).
```

本轮不假定普通训练滤波器天然具有该形式。额外残差必须另有共同源合同和费用，不能省略。C 覆盖内部激活的全部消费者、活 skip、其他谓词及重构所需线性读出；若仍有未覆盖的单个内部值消费者，不能删该值。

原内部 bits 及可靠符号 guards 全保留：L_i*(1-beta_i)<=g_i<=U_i*beta_i，beta=(signed_bit+1)/2只是记号。替换本次内部门的幅值与定义行，不改其他历史原谓词。所有保留读出从同一组新变量恢复，不能每个消费者另选曲率见证。原输入 decoder 不变；新 ADV 仍必须在原具体网络重新验证。

## 任意符号共同残差的健全测度

在整个 H 上认证仿射读出 u,v 满足 u,v>=0、u>=c、v>=-c。它们是已收费的源相关上界，不是新增待优化的自由量。若 c>=0 已获认证可取 u=c,v=0；通用保守选择可由可靠 c 的上下界得到常数 u,v。规则须预先按结构确定，不依赖实例、标签、margin 或求解状态。

固定任意一个父成员，对系数参数 t 定义

```text
g(t)=(1-t)f+t*h-c*t*(1-t)
F(t)=ReLU(g(t))+v*t^2.
```

F 是凸函数。ReLU(g) 的二阶分布在 g>0 区域密度为2c，在 g<0区域为0；简单过零处的导数跳跃非负。加2v后，两种密度均非负，切触零点不产生负原子。这不是运行时输入细分或相位枚举。

定义两端导数的统一包络

```text
a_lo=h-p-q-u <= F'(0+)
a_hi=p+q-f+u+2v >= F'(1-).
S=2p+2q-f-h = |f|+|h|
kappa=2p-f = |f|
B=a_hi-a_lo=S+2(u+v)
K=a_hi-F(1)+F(0)=kappa+u+v.
```

理由是 ReLU(g)'(0+)>=min(0,h-f-c)>=h-p-q-u，且 ReLU(g)'(1-)<=max(0,h-f+c)<=p+q-f+u。f 或 h 为0时使用对应单侧导数，上下界仍成立；不选择或删除原零点标签。

令 mu 是 F 在(0,1)上的非负二阶测度，再加端点原子：

```text
nu=mu + [F'(0+)-a_lo]*delta_0 + [a_hi-F'(1-)]*delta_1.
integral dnu=B, integral t dnu=K.
G(t,s)=min(t,s)-t*s.
e_i=(1-t_i)p+t_i*q-ReLU(g_i)
e_i+v*t_i*(1-t_i)=integral G(t_i,s) dnu(s).
```

质量与矩等式由积分分部直接得到；端点原子不改变 Green 核输出。所有消费者使用同一份 nu。B>=0且0<=K<=B；B=0时 f=h=u=v=c=0，所有真实激活与曲率输出均为0，两种原零标签仍合法。

## 有限原生表示与终端

记 t_0=0,t_(m+1)=1，k_i=t_i*(1-t_i)，定义仅依赖固定系数的多面体

```text
P_C=conv{ (t_j, C G(t,t_j)) : j=0,...,m+1 }.
```

曲线 (s,C G(t,s)) 在相邻固定系数 knot 间线性，故以上有限顶点的凸包包含且恰好等于整条曲线的凸包。保留一个共同输出 E，并定义

```text
(K,E) in B*P_C,
Y=C[(1-t)*p+t*q] + v*Ck - E.
Y in C R_+^m.
```

这就是本块的具体化关系，连同 H 和全部原 guards 同时满足。最后一项保留所有内部激活非负所给的完整输出锥，其有限表示必须另外认证和计费，不能隐藏另一个投影oracle。规范扩展取 E=C(e+v*k)，故对整个父域健全，不只是对原具体网络轨迹健全。新域一般有损，不声称保全旧精确图或所有旧证明。

若 P_C 的完整 H-rep 为 A z<=d、R z=b，普通终端直接接收

```text
A*(K,E)<=d*B, R*(K,E)=b*B, B>=0.
```

必须保留 affine-hull/range 等式，不能只列相对 facets。完整有界多面体的 recession cone 为0，所以 B=0的齐次系统强制(K,E)=0。系数凸包构造不是源/相位分割，但其认证、系数位长与完整费用不能免费。没有新的优化器、未知函数 oracle、attack、BaB 或反向/对偶 rescue。

保留 crossing 原 anchor 图使完整状态确实非凸，不是把 HZ 整体替换为凸域。内部 bits 的 guards 则不足以恢复其全部 beta-amplitude 等式，甚至不自动保证所有门同相位时输出精确；[整数反例](CONTROLS_AND_COST.md)对此作了明确检验。

## 组合范围与费用

Affine、Conv、同身份 Add/Concat 对保留状态和 E 作仿射读出，精确消费当前抽象域。后继 ReLU若再次满足结构合同，可在整个当前父域上建立下一块；否则使用原有健全变换。所有旧块及源谓词继续保留。不能只沿真实轨迹计算下一组预算，不能把不同块的可行见证分别选择后当作共同来源。

若完整 C 的有效输出维数为2，P_C至多三维，有m+2个候选顶点；满三维时 facets<=2m。证明由三维多面体Euler关系与每个面至少三条边得到。低维时另付完整范围等式。一般 p 维完整接口没有这个线性 facet 保证，不能把100个真实消费者冒充2维。

生成 C G 可用固定knots的前缀和，计O(pm)系数工作；凸包、完整输出锥、可靠u/v、源展开、原 guards、anchor图、输出读出、历史状态、元数据、终端/slack、证据、GPU与host共存、输入重构全计费。扫描和矩阵算术适合GPU不等于已获GPU资格。

已知理论背景为 [Fass 第1.4节 Theorem1.19](https://www.math.iit.edu/~fass/478578_Chapter_1.pdf) 的Peano核方法，以及项目D118的共同帐篷曲率。该教材的光滑定理本身不直接认证ReLU；上文另给出了分布测度和端点的证明。本轮新增研究内容是明确的共同二次残差合同、来源矩绑定及完整输出替换，尚非外部新颖性认证。
