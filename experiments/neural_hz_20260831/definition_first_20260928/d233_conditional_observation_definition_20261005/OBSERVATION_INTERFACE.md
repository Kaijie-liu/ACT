# 共同神经图上的原相位条件读出

本页给出一个范围明确的表示定理：在已认证的共同图点池上，全部注册的单原相位条件仿射观察，可以共用同一分解；仅零预激活处需要额外分配量。它支持精确局部查询及源条件行的静态表达，不使用外部 helper。它尚不是新的完整 Neural-HZ，也不自动提高物理精度或解决宽网络的点池增长。

## 域元素与具体语义

保留原 HZ H 的全部连续源、原 signed bits、EQ/LE、shared latent/frame、完整消费者和 decoder。一个关系因子保存完整物理向量 z、原相位预激活 g_i(z)、共同真图点池 V，以及按真实消费者结构注册的 affine 观察 ell_ik(z)。原 logical bit beta_i=(sigma_i+1)/2 只是同一个 signed bit 的视图。

V 必须包含声明局部图每个原相位多面体的全部顶点，而且每点都是真图点。不是任意外包点表或 conv(G) 的极点表。沿用已认证构造的身份和完整性条件；不将任意原 H 的源相关性说成已经纳入 V。

观察坐标的原生含义是 m_ik=beta_i*ell_ik(z)。候选元素可记为 N=(H,共同图因子,注册观察)。具体化使用同一原源、原整数 bits 及这些关系，私有分解变量存在量化。空因子嵌入 HZ，语义包含按具体集合定义；不主张最佳抽象或完整格，也不声称扩大原精确 HZ 的分段仿射表达能力。

下面的连续系统描述局部带标签图及全部这些观察的凸包；实际域保留原 bits 的整数语义，没有退化成 CZ、Zonotope 或凸域。

## 单事件观察的共同精确表示

使用 lambda_v>=0、sum lambda_v=1、z=sum lambda_v*v。只对 g_i(v)=0 的 incidence 引入 mu_iv：

```text
0 <= mu_iv <= lambda_v，
beta_i = sum_(g_i(v)>0) lambda_v + sum_(g_i(v)=0) mu_iv，
m_ik = sum_(g_i(v)>0) lambda_v*ell_ik(v)
       +sum_(g_i(v)=0) mu_iv*ell_ik(v)。                  (O)
```

定理：在同一个局部图点处，所有不同原 bits 的零标签组合均同时合法时，(O) 精确表示全部注册单事件观察的联合凸包，而非每个观察分别选一个见证。标准局部 ReLU 图满足此联合自由前提；若局部源谓词另行限制零标签组合，仅逐 bit 允许两个标签不足以应用此定理。额外 H 谓词在下述局部凸包之外保留，不据此声称全 H 理想性。

必要性：固定完整原相位时，z 及 beta_i*ell_ik(z) 都是相位多面体上的仿射观察。任何图点可在同一相位的顶点中分解；保留零点处的原标签即可得到 (O)。

充分性：对 lambda_v>0 的每个顶点，非零预激活的标签已经固定。其零标签 i 的 active 概率取 mu_iv/lambda_v；这些零标签可在同一顶点上条件独立地分配，所以所有单事件边缘及其物理观察能同时实现。lambda_v=0 时所有对应 mu 为零。这里的有限分布只用于存在性证明，运行时不枚举零标签、不采样或创建相位子问题。

若 beta_i 全部取原整数值，每个正质量顶点都兼容同一完整原相位；mu 被迫为零或 lambda。该相位的原图凸，平均仍在图中，且 m_ik=beta_i*ell_ik(z)。故观察与整数非凸语义一致。其他 H 谓词仍全部保留；上述局部凸包不自动等于与 H 相交后的全源凸包。

## 只按完整观察值分组的精确消元

对固定 i，在其零点集合上按整个已注册向量

```text
trace_i(v)=(ell_i1(v),...,ell_iK(v))
```

完全相等分组。每组 G 只留一个 mu_iG，满足 0<=mu_iG<=sum_(v in G)lambda_v；(O) 中的组观察为 mu_iG*trace_i(G)。这是对逐点 mu 的精确投影：给定组总量，可按组内 lambda 比例分配；组质量为零时总量也为零。对各 i 的分配仍能同时实现。

若某门整个零集合的 trace 恒为 kappa，则零辅助量可全部消去：

```text
m_ik = sum_(g_i(v)>0) lambda_v*(ell_ik(v)-kappa_k)
       +kappa_k*beta_i，
sum_positive lambda <= beta_i <= 1-sum_negative lambda。
```

若没有零点，直接使用确定的正号读出。分组不合并物理顶点或 lambda，也不允许按某次 terminal 解选观察。新增消费者若区分旧组，必须重新细分组并保持已有观察关系。两个不同 trace 的点一般不能用一个带固定系数的总量无损合并：固定两点各半质量，active 半质量可分别放在任一点，得到不同观察。这只是该分组方法的边界，不是任意扩展表示的最小规模定理。

一个有实际消费者的校验是：若注册 ell 在该门的所有非正点都为零，则 (O) 自动简化成 m_i(ell)=ell(z)。完整点池保证此点上判据覆盖整个 inactive 相位图，不是有限采样推断。例如[本轮控制](STRONG_REFERENCE.md)的 y1、y2 在原父 alpha1 未激活时均为零，从而原观察 alpha1*y_j 可以直接复用 y_j；结合 alpha1*x1=q1 和 x2 的有效界，恢复那条廉价物理证书。此例证明接口能表达已有的有用关系，不重记新能力或新原理。

## 直接支持查询

对目标 w*z+sum_i a_i*beta_i+sum_ik b_ik*m_ik，令

```text
t_i(v)=a_i+sum_k b_ik*ell_ik(v)。
```

局部精确支持为

```text
max_(v in V) [w*v + sum_(g_i(v)>0)t_i(v)
                  +sum_(g_i(v)=0)max(0,t_i(v))]。          (S)
```

这是对同一个真实顶点上合法零标签的逐项最大化，不是事件逐一取不相容的物理点。给定已计算的 trace，扫描付 O(N(D+B+T)) 算术，T 为注册标量观察数；trace 生成和存储另付。它不是固定 fractional beta 纤维的精确支持，也不是与额外 H 行相交后的免费精确支持；对该更小集合仅保证上界。

这些矩阵读出、符号 mask 与归约可成为 GPU 内核的数学基础，但本轮没有设备实现或可靠数值资格，不能据算子形状宣布加速。

## 源前提如何实际消费这些观察

对同一实际源上已证明有效的线性前提 c*z<=d，可注册 c*z 的观察 m_i(c)，并加入

```text
m_i(c) <= d*beta_i，
c*z-m_i(c) <= d*(1-beta_i)。                            (C)
```

等式可同样提升。若源行在整个声明局部图上有效，(C) 已由 (O) 蕴含；若仅原 H 的真实状态满足，则它们是由原整数语义推出的新有效强化，不能说未条件化 V 已自动蕴含。有限这些行仍不等于将所有源关系逐点纳入真实图。

若某原源坐标不在局部 z 中，本接口不自动提供它的条件观察。不能复制外部源、强迫每个局部顶点都有原输入见证，或只把外部均值接入就宣布完整源关联；此前源绑定反例仍有效。

## 下一激活可以保持什么

Affine、Conv、Add、Concat 在同一物理坐标与同一原 bit 下保持观察的线性组合，须先合并真实共享身份。若继续采用已证明的完整相位兼容跨层出生，新池覆盖新图的全部相位面顶点，则旧 z、beta、m 的联合凸包是新池观察系统的精确投影：旧图的每个真实点都能升为新门真实点，反向投影也仍为旧真实点。

因此，可在保留所有旧物理和观察约束的同时更新因子。前提是 lambda 和 mu 是私有存在见证；若外部已直接约束某个旧 lambda、旧顶点身份或未注册观察，不能静默重建后宣称精确。所有公开消费者都必须被覆盖。原输入 decoder 始终沿完整 H 重构；支持最大点不是 ADV。

本结论保留完整 V 并支付下一次出生，不是仅靠有限单事件摘要递推。[已有普通混权反例](../d175_joint_phase_physical_projection_20261004/CLOSURE_BOUNDARY.md)已经证明，一二阶摘要甚至加新相位均值也不足以确定后继。不能据此删除 V、免费胶合不同块的条件律，或声称任意深度多项式闭包。

## 完整局部账单

令 N 为点数、D 为物理维数、B 为原 bit 数、P 为正号 incidence 数、Z 为零号 incidence 数、K 为分组后的零量数。先按全部 B 均采用上述未进一步消元的分组表示计数，旧 H、来源和 decoder 另计。

已有物理与原 bits 外新增 N+K 个连续量，EQ 为 D+B+1，LE 为 N+2K。变量 nnz 上界为

```text
(D+2)*N + D + B + P + 3*K + Z。
```

分项为 simplex 与 lambda 非负共 2N，物理等式 D(N+1)，phase 等式 B+P+K，mu 下界 K，上界 K+Z。原 signed bit 采用 sigma_i-2sum_positive lambda-2sum_groups mu=-1，不产生新 bit。零集合常 trace 的门可改用原 mask 并进一步消元，上式只是保守统一账单。

若还物化 T 个观察输出，需要 T 个列、T 条 EQ；每个 (i,k) 的等式至多 1+P_i+K_i 个 nnz。内联省列但不免除这些真实系数在全部消费者中的出现。令 s_ell 是不同注册仿射式的真实支持，生成 trace 需 O(N*sum_ell(s_ell+1))；分组的完整精确比较、临时存储、算术位长及全部读出必须支付。

特别是输出全部 B*D 条坐标观察时，正点和零点读出成本最坏为 O(D(P+Z))，不能错报成仅 BN+ZD。如果已认证每点零 guard 数<=d，则 Z<=dN，只约束新增零量部分；不免除正 mask、读出、原图点池或出生增长。

所有局部物理源展开、可靠原模型系数和 BN 误差、原谓词、归一化与 slack、终端求解、旧新池同时存活、证据及 host/device 存储另外计算。没有本轮费用实测。

## 已有研究与准确资格

[原标签恢复证明](../d220_bounded_rank2_phase_factor_20261005/DEFINITION_AND_PROOF.md)和[共同点池证明](../d227_shared_bank_composition_20261005/DEFINITION_AND_PROOF.md)已经包含零标签共同分配。本页将其扩展为注册条件读出、trace 消元、直接支持及观察保持的前向接口；不把所用凸组合原理认作原创。

共同分解与只有均值满足约束的区别，在 [Brown 等的完全正规划研究](https://proceedings.mlr.press/v151/brown22b/brown22b.pdf)中有明确先例；该精确锥本身难解，本项目不接入其 SDP/CP 求解路径。[Berrada 等](https://arxiv.org/pdf/2102.09479)已采用层分布传递及 functional-dual 算法；分布记号本身不是新域，后者不纳入候选。[Lasserre 的 Lemma 6.4](https://optimization-online.org/wp-content/uploads/2006/04/1367.pdf)要求完整边缘测度及 running-intersection 才能胶合，不能用少量矩的一致性代替。

只新增 (O) 后投影回旧 (z,beta) 完全不变；若没有后继或源关系实际消费 m，就没有新增物理能力。因此本轮不为孤立接口创建 runner。下一候选必须明确真实消费者，并证明相对已有条件守卫参照的精度或完整成本优势，或在已注册真实同结构比较中得到相应证据。smooth 与 attention 的有限闭包尚未得到，完整测度能写出它们不等于本接口已覆盖。
