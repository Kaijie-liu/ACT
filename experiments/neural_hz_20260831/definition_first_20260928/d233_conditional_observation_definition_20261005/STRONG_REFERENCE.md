# 跨层控制的廉价物理证书

本轮把最新跨层控制的强参照问题完全闭合：完整旧四门联合 hull 加一条五非零系数的物理行，就能达到新点池的同一精确上界 63/32。新点池的正确性未被否定，但这个控制不能再作为超过已有条件守卫方法的证据。本页是解析推导和独立复核，没有运行求解器或候选。

## 原控制与比较对象

沿用[跨层激活合同](../d231_phase_compatible_birth_20261005/CONTRACT.md)：

```text
x1,x2 in [-1,1], q_i=ReLU(x_i),
y1=ReLU(q1+q2/2-3/4),
y2=ReLU(q1/2-q2-1/4),
h=y1-y2/2+x1/4+x2/8-1/8, r=ReLU(h),
D=2q1-x1+2q2-x2, F=D+h/4-r/2。
```

Q 是旧四门的完整共同源和原标签 hull；不是只保留四个独立三角形。原四门 bits 均保留。比较先在 Q 上接新 ReLU 的图，也允许对该图取凸包，再加所声明的旧有效关系。真实精确上界 63/32 由原合同的角点与 Lipschitz 证明给出。

## 幅值参照单独仍不够

取旧真实角点 (-1,-1) 和 (1,-1)，权重分别 1/5、4/5。其共同凸组合为

```text
x=(3/5,-1), q=(4/5,0), y=(1/5,1/5),
parent logical bits=(4/5,0), child logical bits=(4/5,4/5)。
```

它在 Q 中，h=0，因此在 Q 上接新门允许 r=0 及合法的零点标签。这给 D=2、F=2。

对[旧幅值规则](../d036_descendant_amplitude_20260930/THEORY.md)的两个实际输入边，完整真实旧图的余项界分别为 y1 边的 [-1/2,1/4] 和 y2 边的 [-1/2,1]。前者可由 x1<=0 时 y2=0，以及 x1>=0 时的两段表达式界定；后者 h+y2/2=y1+x1/4+x2/8-1/8 对两个源单调，其极值在同号角。代入规则及其对 r-h 的对称版本：

| 边 | 非平凡 r 下界 | 非平凡 r-h 下界 | r 上界 | r-h 上界 |
| --- | ---: | ---: | ---: | ---: |
| y1 系数 1 | -1/5 | -2/5 | 9/20 | 11/30 |
| y2 系数 -1/2 | -1/2 | -7/10 | 9/10 | 3/5 |

其余下界为零，故 r=r-h=0 全部通过。固定地把 x_i 写成 q_i-(q_i-x_i)，并将 y_j 的负幅值也作为原 bit 的补事件，仍不能排除此点；这不包含任意新别名或任意系数的无限闭包。

上述固定双路幅值的纸面核对如下。令 n_i=q_i-x_i、m_j=y_j-g_j。对非负幅值 p、系数 a 及其原 active 质量 beta，记 tau=-a*p/beta。四个真实源角给出的 h-a*p 的最小与最大值如下；任一健全全源余项界都必须包含这一区间。

```text
(p,a)         角点余项范围          当前点 tau
(q1, 1/4)     [-1/2, 3/4]          -1/4
(n1,-1/4)     [-1/4, 1]             1/4
(q2, 1/8)     [-1/2, 7/8]           beta=p=0
(n2,-1/8)     [-3/8, 1]             1/8
(y1, 1)       [-1/2, 1/4]          -1/4
(m1, 1)       [-5/4, 1]            -3/4
(y2,-1/2)     [-1/2, 1]             1/8
(m2,-1/2)     [-3/8,11/8]           1/8
```

这些区间都跨零，且 tau 位于其中。因此任何包含这些角点值的可靠全源余项下上界 L,H 都有 L<=tau<=H，使 r 和 r-h 的非平凡下界分别 beta*(L-tau)、beta*(tau-H) 不大于零。两者的上界是非负端点值的弦，在 0<=p<=Q 上非负。beta=p=0 的行也直接通过。这证明固定别名参照全部接受，无需假定免费精确余项 oracle。

另一方面，Q 上 D<=2，且 r>=max(0,h)，所以 F<=2。这一明确的幅值参照最优值恰为 2，而不是仅有一个未优化的松弛下界。

## 一条已有条件守卫行追平完整上界

设 alpha 是 q1 的原 logical bit。当 alpha=0 时 q1=0、q2<=1，所以两旧子门的预激活都不超过 -1/4，y1=y2=0。因此在真实旧图上

```text
alpha*y1=y1, alpha*y2=y2, alpha*x1=q1。
```

由 x2>=-1 以及对原事件 alpha 的条件 ReLU 下界，可得

```text
r >= L = y1-y2/2+q1/4-alpha/4。                 (1)
```

也可直接按原整数 alpha 检查：(alpha=0)右端为零；(alpha=1)有 h>=L，故 r>=h>=L。这是[已有条件守卫机制](../d201_static_joint_guard_reference_20261005/RESEARCH.md)的明确实例，不需新增源矩、相位合取或 helper。

原父门负幅值帽 q1-x1<=1-alpha 给 alpha<=1-q1+x1。消去 alpha 后，(1) 蕴含仅涉及物理坐标的行

```text
r >= Lprime = y1-y2/2+q1/2-x1/4-1/4，
4r-4y1+2y2-2q1+x1+1 >= 0。                    (2)
```

它仅有 r、y1、y2、q1、x1 五个非零变量系数。这个计数在物理坐标已经存在的前提下成立；若需展开原 HZ affine readout，其来源、完整 nnz 和终端费用另外支付。

现在只用较弱的物理行 (2) 即可证明整个性质。令

```text
Sprime=D+h/4-Lprime/2
      =(7/4)q1-(13/16)x1+2q2-(31/32)x2-y1/4+y2/8+3/32。
```

F<=Sprime。在真实旧图的 x1<=0 部分，q1=y1=y2=0，因此 Sprime=-13x1/16+|x2|+x2/32+3/32，最大值 31/16，在 (-1,1) 达到。

在 x1>=0 部分，q1=x1，所以

```text
Sprime=15x1/16+|x2|+x2/32-y1/4+y2/8+3/32。
```

它对 x1 的每段斜率至少 11/16>0；对负 x2 半轴的斜率为 -31/32；对正半轴的斜率至少 25/32>0。故最大值只需比较 (1,-1) 与 (1,1)，分别为 63/32 和 15/8。零点的两种原标签不影响此物理证明。

Sprime 是旧物理坐标的仿射式。因此真实旧图上的 Sprime<=63/32 被整个 Q 继承。真实点 (1,-1) 又达到 F=63/32，说明 Q 加 (2) 的最优值恰为 63/32。

## 对下一研究行动的影响

最新控制的比较现在是：幅值关系为 2；增加上述已知机制的一条物理行后为 63/32；完整联合跨层因子同为 63/32。不能继续用同一控制声称新域强于已有条件关系。

本反证不证明联合点池在所有网络上无价值，也不要求候选胜过免费全网精确 oracle。它明确指出当前结构的特殊便利：两旧子幅值都受同一个原父事件支配。后续普通混权残差控制应显式检查这种支配关系，并将可构造的条件守卫行纳入比较，而不是只换一个能绕过幅值规则的假点。
