## 元素和语义

继承D213的原连续因子、signed binary相位、EQ/LE、共享frame/latent身份、完整读出、decoder和全部关系块。beta=(sigma+1)/2仍取0或1。具体化是满足同一原因子界及所有谓词的共同赋值经读出得到的集合；旧HZ以空神经出生历史嵌入。Affine和共享Add/Concat仍是共同赋值上的精确仿射变换；ReLU保留原二元图，不把它松成连续相位。未实现的native Conv、smooth/Transformer和GPU不声明资格。

## 参数化关系定理

对同一完整父域认证的crossing pair，固定a=1/2、k_i>=0、共同尺度s及可靠s>=l>0、f_i>=-ell_i且ell_i>0。原图与closure提供

```text
A_i = f_i+ell_i*(1-beta_i)-q_i >=0,
B_i = k_i*s-k_i*l*(1-beta_i)+a*q_j-q_i >=0.
```

定义r_min=ell_i/(k_i*l+ell_i)。对每个r属于[r_min,1]，

```text
S_i(r) = (1-r)*f_i+r*k_i*s+r*a*q_j-q_i
       = (1-r)*A_i+r*B_i
         +(r*k_i*l-(1-r)*ell_i)*(1-beta_i) >=0.
```

最后一项用原sigma_i<=1，因1-beta_i=(1-sigma_i)/2。所有乘数非负，系数恒等式及身份必须完整认证。k_i=0时r_min=1，不除以k_i。对固定赋值，S_i关于r仿射，局部关系族的交集由两个端点足以描述；消费中间关系不等于分别查询端点再取最小。

固定同一f、k、s、l，ell收紧会降低r_min，旧参数仍合法。若r0>0，还可写S_i(r)=(r/r0)*S_i(r0)+(r/r0-1)*(q_i-f_i)。这证明局部可用关系族的包含，不证明cap、common或证明支撑集改变时的全网络单调性。

## 按读出代数结构消去

先合并完整读出中所有共享坐标与live skip，再按原事件逆序处理；不得每个读出独立取界后再合并。对于pair中w_i>0>w_j，定义r*=−w_j/(a*w_i)。若r*属于上述合法闭区间，固定消费该一条关系，则

```text
w_i*q_i+w_j*q_j
 <= (w_i+w_j/a)*f_i-(w_j/a)*k_i*s.
```

因q_j系数恰为0，无该输出残差被丢掉；返回完整源表达式后才与其他父坐标合并。两种门顺序对称。r不合法或不为异号权重时统一使用原closure pair消费。这是按数学前提定义的一条闭式规则，不读取实例、标签、LP状态、旧性质系数或失败结果，不clip参数、优化乘子或调用外部求解器。

实现为同一域第六个固定完整证书。每次query无条件计算原五证书和新证书，按固定顺序取完整界的最小值；所有后继bounds/caps也使用同一六证书规则。不是旧网络并跑，不允许为保例固定旧ell/cap。保留原五证书只保证同一出生状态的最小界不弱，仍不保证重新出生后的全网络能力不退；定向旧结构必须实际重建验证。

新增模式须处理全部bank、未配对门、稳定门、alias EQ、原源和相位端点。仍是逆出生的域内支持演算，不能宣传没有后向计算；没有失败后backward/dual rescue、LP对偶或搜索优化器。证明使用非负线性组合这一事实不构成创新。

## 非零宽度方向族的精确局部支持

对x,y属于[-1,1]、f1=x+y/12、f2=x-y/12的普通非平行pair，已有k=5/8、s=(3+x)/4、l=1/2、ell=13/12，故r_min=52/67。对所有r属于[52/67,1]与lambda>0，本规则给出

```text
lambda*(q1-r*q2/2)
 <= lambda*((1-r)*f1+r*(5/8)*s)
 <= lambda*(13/12-11*r/24).
```

源表达式中x系数为1-27r/32>0，y系数为(1-r)/12>=0。因此第二步的盒上界在x=y=1取得；此点实际ReLU输出q1=13/12、q2=11/12，又恰达到最终界。故该整段方向族的局部支持是精确的。交换两个门时，以x=1、y=-1作同样见证。正缩放lambda不改变规则。

原五模式在此区间的最小界恒为lambda*195/268，因为源关系模式在r/2>=26/67时取固定二门乘数(lambda,0)，其余四界不更小。在r=52/67相等；所有r>52/67严格分离。这是正宽度普通方向族的定理，不是仅调一个旧性质系数。不过其前提是指定的完整二维父盒及pair，不能据此推广为任意CNN精确支持。

## 先例和新颖性边界

[原HZ神经网络可达性工作](https://arxiv.org/pdf/2304.02755)已经利用混合因子精确表示ReLU网络；保留原相位不是本轮的新贡献。[PRIMA](https://ggndpsngh.github.io/files/PRIMA.pdf)已经系统研究多神经元关系及其凸近似。我们不采用其分解/求解路径，也不能把多神经元不等式本身称为创新。本轮新增假设仅是：带身份的参数关系族在非凸神经元素内可被统一闭式消费，并在普通跨层混权结构中保住关系。它的普适组合性、实际规模与正式能力还必须由后续证据回答。
