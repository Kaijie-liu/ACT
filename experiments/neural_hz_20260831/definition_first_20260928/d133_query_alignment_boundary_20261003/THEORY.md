# 投影对齐 HZ 的精确对应与组合边界

本轮从数学定义继续研究，而不恢复已撤回的 helper 路径。结论是：投影对齐 ReLU 在完整带谓词语义下是旧幅值坐标的可逆仿射变换；其廉价查询可以更好，也可以更差，不能据此声称完整 LP 更强。原稿的通用定义和投影交换定理还缺少条件。下面给出精确对应、普通结构反例、可修复的嵌入和完整代价。

这是精确实算术的纸面推导，经独立代理审查，不是机器证明或候选资格。所有原连续源、原 signed binary 身份、零点标签、EQ/LE、共享 frame、旁路消费者和输入 decoder 都必须保留。放松相位只用于分析既有查询，不是删除或放松域元素中的二元因子。

## 带谓词坐标等价

令旧前缀读出 x=c+g^T w，对一个 crossing ReLU 使用同一冻结界 l<0<u，且该界覆盖精确前缀的 x。定义 a=u/(u-l)，m=-a*l/2>0。比较

```text
幅值坐标  y=u*(1+alpha)/2,        alpha in [-1,1]
对齐坐标  y=a*x+m*(1+eta),        eta in [-1,1]
```

两者保留同一个原相位 d，并满足

```text
y>=0, y>=x, y<=u*d, y<=x-l*(1-d).
```

其中 d 属于 {0,1}；在比较 LP 时才将同一个 d 的查询范围取为 [0,1]。对应变换为

```text
alpha=(2*x-l*eta-u)/(u-l),
eta=((u-l)*alpha-2*x+u)/(-l).
```

固定旧前缀后，这是可逆仿射变换。它映射的是带谓词的可行集，不是两个裸立方体。

证明：整数 d 下四个图约束恰给 y=ReLU(x)，同时在 x=y=0 时保留 d 的两个合法标签。连续 d 存在的充要条件是

```text
max(0,x)<=y<=a*(x-l).
```

该三角形本身蕴含 l<=x<=u、0<=y<=u，以及 0<=y-a*x<=-a*l=2m，所以两个新连续坐标均在各自盒内。反方向代入得到同一组图约束。界若只在精确前缀有效，增加此层也可能排除旧 LP 的部分伪前缀；两种坐标会作出相同排除，仍是最终约束系统的等价变换。

逐层应用此对应形成分块下三角可逆仿射变换。Affine、Conv、Add、Concat 和残差只要替换所有消费者、保持同一源身份，就保持同一个 labelled 图。不能在残差的两条支路各自生成独立的坐标副本。原输入重构也使用同一个对应，而不另找输入。

因此，在相同界、相同谓词和相同目标下，完整 LP 与完整整数查询的数学最优值不变。这不是运行时间相同的定理：条件数、稀疏度、预处理、舍入以及限时求解行为可能改变。也不是对 ACT 任意历史编码的未经检查的逐字节等价证明。

## 廉价视图的真实收益和反方向控制

取 x in [-1,1]，y=ReLU(x)，z=y-x/2。真实 z=abs(x)/2，范围为 [0,1/2]。

幅值坐标丢掉谓词后给 z=(1+alpha)/2-x/2，范围 [-1/2,3/2]。对齐坐标丢掉谓词后给 z=(1+eta)/4，恰为 [0,1/2]。这是一条无需 solver helper 的廉价查询分离。

但它不是所有查询都改善：对 y 自身，幅值盒为 [0,1]，对齐裸盒为 [-1/2,1]。两个联合裸盒也不互相包含：对齐盒含 (x,y)=(-1,-1/2)，幅值盒不含；幅值盒含 (-1,1)，对齐盒不含。是否再利用 y>=0 属于必须说明的查询规则，不能只在有利方向比较。

完整 LP 对 z 的界在两种编码中都为 [0,1/2]。因此该例证明的是坐标选择影响丢弃谓词后的精度，不是精确非凸集合、完整 LP 或新的集合表达力增强。

上述仿射噪声包络系数已见 DeepZ 的 Theorem 3.1；加回精确原相位不会使该廉价公式成为新公式。它可以保留为支撑机制，但不能据此宣布 Neural-HZ 定义创新已经完成。参见 [文献范围](SOURCES.md)。

## 原通用定义不足以保证 LP 身份

Claude 原 Definition 1 允许任意仿射 phase forms，却把删除 phase rows 后的 lambda 视为完整 continuous-phase LP。以下普通有界例说明这不成立：

```text
w in [-1,1], v=w, A为空,
x=w, y=1/2, l=-1, u=1,
y<=d, y<=x+1-d.
```

整数 phase 投影是 w in [1/2,1]；连续 phase 投影是 w in [0,1]；原定义的 lambda 却是 [-1,1]。精确集合非空，数值尺度普通。

正确修订可以要求生成态的对齐和 lower-row 不变量，或直接要求全部 relaxed phase rows 在共同盒与 A 上可延拓。仅有 gamma subset lambda subset sigma 不蕴含 lambda 等于完整 phase LP。没有修改原冻结 THEORY，修订条件只记录在这里。

## Gamma 有效界不保证投影变换交换

取普通两门残差

```text
s in [-1,1], q in [-1/4,1/4],
A=ReLU(s), B=ReLU(-s), r=q+A-B-s.
```

精确图上 A-B=s，所以 r=q，[-1/4,1/4] 是精确有效界。第一层完整 triangle 查询却允许 s=0、q=1/4、A=1/2、B=0，得到 r=3/4。两个对齐坐标给

```text
A=s/2+(1+eta_A)/4,
B=-s/2+(1+eta_B)/4,
r=q+(eta_A-eta_B)/4.
```

所以输入 shadow 中 r 的范围是 [-3/4,3/4]。下一 ReLU 若采用仅在 gamma 上有效的 [-1/4,1/4]，产生

```text
Y=r/2+(1+eta_Y)/16.
```

其输出 shadow 的最大值为 1/2，而 ReLU(input shadow) 含 3/4。因此该步并非对整个输入 shadow 健全的独立 DeepZ 变换。新 lower rows 与 eta 盒也会排除输入 LP 中 r=3/4 的点，所以同样不是对整个输入 lambda 健全的独立 triangle 变换。

这不否定精确 gamma 变换，也不否定最终 shadow 仍包住最终 gamma；它否定的是无条件的逐层交换主张。要按某投影的独立抽象变换解释，界须覆盖该投影，不能只覆盖更小的精确集合。固定界下两种约束编码的代数等价与上述投影变换健全性是不同命题。

这只是一个共同源残差的证明控制，不是针对某模型专门增加一条优化，也不是证明当前保存的某个 CERT 有误。当前代码采用哪一级界仍须单独认证。

## 普通 HZ 的完整嵌入可以修复但有代价

原 HZ 值图和谓词可能含 signed binary beta，而原稿的值图和 A 只允许连续坐标。仅写 beta=2d-1 并没有给出满足其特定 phase 语法的嵌入。

一个精确构造是：对每个原 beta 新增连续副本 rho in [-1,1]，保留原二元身份 d=(beta+1)/2，定义 phase forms x=rho、y=(rho+1)/2、l=-1、u=1。允许的两条上行是

```text
(rho+1)/2 <= d,
(rho+1)/2 <= rho+1-d.
```

两行恰强制 rho=2d-1。值图及原 EQ/LE 用 rho 读出，原 beta/d 没有删除、pivot 或改为连续域；输入 decoder 按该精确链接恢复。每个原 binary 需付一个连续副本、两条 mixed 行及身份/链接证据。下行 y>=0、y>=x 由 rho 的盒界给出，fractional phase 可以延拓任意 rho，所以这个嵌入也满足相应 LP 不变量。

该构造证明的是表达能力可修复，不是“没有额外成本”或已有实现通过了嵌入测试。稳定原门若已有相位记录，其原标签也不能因当前界稳定而从元素删除。

## 完整行数与生成元成本

以下只数一个一般 crossing 标量门，x 在旧连续坐标中有 k 个非零系数，无偶然系数消项，原前缀两边共用。表中显式行不含共同的变量盒边界；每个新连续因子均另需两个边界端点，每个原 phase 的 LP 查询也有两个边界端点。这些不冒充免费删除。

```text
                                      幅值坐标       对齐坐标
新增连续因子                          1              1
原二元相位                            1              1
完整 mixed 图额外显式行                3              4
完整 mixed 图行 nnz                    2k+5           4k+6
投影掉连续 phase 后的显式 LP 行         2              2
上述 LP 行 nnz                         2k+2           2k+2
新增输出值图支持                       1              k+1
```

幅值盒已经保证 y>=0，所以 exact mixed 图只需其他三行；对齐盒不保证非负，必须保留下行。两种 LP 都可只有两条额外行：幅值坐标用 y>=x 和 secant，上述对齐坐标用两个 lower rows、由 eta 盒提供 secant。不能把候选 LP 的两行与旧 mixed 图的三行相比较，声称少一条 LP 行。

这是直接符号展开的成本，不是当前实现的峰值存储或速度测量。对齐读出把旧因子传播到输出，后继 Conv/仿射的系数工作、原全部谓词、全局换坐标的填充、host/device 共存、舍入补偿、终端转换和 decoder 都需付费。反向转换至少处理实际保留的前驱依赖；不能只计新 eta 一列。

GPU 可以批量执行同一系数代数，但纸面矩阵乘法不证明设备认证、端到端速度或求解器完全上 GPU。本轮没有运行任何候选或设备计算。
