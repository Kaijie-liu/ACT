# 共享定向位移的前向闭包及其能力边界

本轮沿着 Neural-HZ 的定义问题，检查共同预算在经过神经非线性后如何保留位移方向。得到一个可证明的修复：保留与原相位绑定的非负连续因子，供混权读出和旁路共同使用，可以去掉上一版闭包中的 inactive padding。在非零预算的普通两门块上，它排除了上一版的反例。

这仍不是强大新域已经成立的证据。修复后的表示增加状态和谓词；同一正控也被旧 HZ 的一条上侧约束证明。它可编译回一般 HZ，没有新的表达能力或实际验证收益认证。本轮只归档数学结论，不实现辅助算法、不修改生产路径、不宣称能力提升。

## 语义边界

保留同一个连续环境 theta、全部原二元身份 beta、EQ/LE 谓词 P、共享输入身份和具体输入 decoder。这里使用原 bit 的 0/1 视图，没有删除、替换或连续化原 bit。原网络零点的两种合法标签均需保留。旧谓词读取的任何历史量不能通过只改元数据删除。

研究起点是 [D162 的原生 M 版距离关系](../d162_source_phase_budget_audit_20261004/THEORY.md)。对 gate 坐标有非负输出 q、off-mask 上界 q_i<=U_i beta_i，以及成本

```text
d_i(q_i,c_i,beta_i) = |q_i-c_i|   if beta_i=1,
                       max(c_i,0) if beta_i=0.
sum_i w_i d_i <= R,       w_i>0, R>=0.
```

c 是共同旧环境的仿射式，R 可以是可靠非负的原相位仿射式，M_i 是整个父域上的中心负部上界，即 c_i>=-M_i。U_i 必须覆盖所声明关系；给真实像另加更紧约束时，要明确区分完整自由球投影与相交后的抽象。

这一关系针对整数 bits。终端对 bits 的连续松弛只是外包，不是域成员定义。它不同于 D162 用实际预激活 L 编译、对分数 bits 也保持旧四行 LP 投影的版本。

## 保留非负位移给出等价的扩展表示

上述 M 版关系等价于存在同一份连续 f 和 e，使

```text
q = c + f + e,
0 <= f_i <= M_i(1-beta_i),
sum_i w_i |e_i| <= R,
q_i >= 0,  q_i <= U_i beta_i.
```

active 时 f_i=0，所以 e_i=q_i-c_i，恰好支付原成本。inactive 时 q_i=0；由 |c_i+f_i|>=max(c_i,0)，任何扩展见证都支付至少原成本。反向统一选

```text
f_i=0                         if beta_i=1,
f_i=max(-c_i,0)                if beta_i=0,
e_i=q_i-c_i-f_i.
```

由于 c_i>=-M_i，该 f 合法，且逐坐标绝对值恰为原成本。这给出完整共同见证；不是为每个消费者各选一份 f。对未做 ReLU 的 identity 坐标，取 f_i=0，保留原绝对值成本即可。

消去 f 会回到 M 版整数关系。不能据此将其终端 LP 称为 D162 的 L 版精确投影。零预算时 e=0，active 得 q=c，inactive 得 q=0、f=-c；此时恢复逐门精确关系，而不是获得新的超越精确 HZ 的能力。

## 混权读出和所有旁路共用位移

对整个当前原生父域，定义实际读出

```text
g = Wq + A theta + b,
z = Tq + B theta + d,
K = [W; T],
h = W(c+f) + A theta + b,
k = T(c+f) + B theta + d.
```

所有同身份系数先合并。取正的新权重 v 和加权 L1 诱导范数

```text
kappa = max_j (sum_i v_i |K_ij|)/w_j.
R_new = kappa R.
```

实际联合误差就是同一份 Ke，故 sum_i v_i |(g,z)_i-(h,k)_i|<=R_new。与 D162 将 inactive 位移加入对称半径不同，这里没有 sum_i w_i M_i(1-beta_i) 的额外 padding。

令 r 是下一 ReLU 的输出代理，gamma 是该门的原 bit。对完整栈做部分 ReLU 投影，保留

```text
r_i >= 0, r_i <= U_new,i gamma_i,
sum_gate v_i d_i(r_i,h_i,gamma_i)
  + sum_skip v_j |z_j-k_j| <= R_new.
```

U_new 必须覆盖整个当前父域的真实 ReLU 子像。若它比自由球像的上界更紧，这是有证的额外相交，不再称完整自由球的精确投影。非负与 off-mask 约束不能省略：inactive 距离项本身不含 r，单靠预算不能推出 r=0。

同时保留父 P、全部原身份、实际 g 的可靠相位 sign guards，以及精确同身份旁路 z=Tq+B theta+d。完整真实子像取 r=ReLU(g)、同一个 z 即满足预算，因此覆盖整个当前父域，而不仅是旧网络的真实轨迹。递归时每一步都重新对完整扩大后的父域保证界和预算，归纳健全。

新 r 一般是有损代理，不能同时声称仍保留完整 r=ReLU(g) 关系。否则只是给旧图添加冗余预算。可以另加健全下侧 r>=g，但此时应称距离投影与实际 epigraph 相交；不是整个自由球的精确投影。以下正控和残余假点在加了 r>=g 后都仍成立。

下一中心的负部上界必须对 h 本身认证，不能拿实际 g 的下界代替。f 成为受保护的共享连续环境，所有读出必须共用它。若要删除 f、旧 q 或旧谓词中的量，仍须证明完整共同投影；当前定理没有给出这种压缩。

## 非零预算下确实修复了前一反例

考虑普通带偏置的共同父域：

```text
x,y in [-1,1],
c=(x+1/4, y-1/4),  R=1/10,  w=(1,1),
M=(3/4,5/4),
q 属于上述原生距离域，并保实际 c 的原 sign guards。
g=q1-q2+1/4,    z=(q1,q2),
J=r-g.
```

对整个父域，可靠且可达到的输出上界为 U=(27/20,17/20)，因此实际 g 的界是 [-3/5,8/5]。两个父门和 g 均可 crossing。完整栈 K=[1 -1; I2] 的 kappa=2，所有新权重取 1。

定向闭包的共同新预算为 1/5。写 h=(c1+f1)-(c2+f2)+1/4。由于 e=q-c-f，始终有 |g-h|=|e1-e2|<=1/10。

- 新相位 active 时，门成本给 |r-h|<=1/5，所以 J=r-g<=3/10。
- 新相位 inactive 时，r=0，实际 g>=-3/5，所以 J<=3/5。

因此整个定向子域都有 J<=3/5，后继 ReLU(J-3/4) 为零。这是非零预算下的跨层结论，不是只在 R=0 时恢复精确图。

旧圆化闭包仍允许假点。取源 x=y=0，父 beta=(1,0)、q=(1/4,0)，实际 g=1/2，新 gamma=1。旧中心为 gate 3/4、skip (1/4,-1/4)，半径

```text
2[R+(3/4)(1-beta1)+(5/4)(1-beta2)] = 27/10.
```

取 r=3/2、z=q，总成本为 |3/2-3/4|+0+|0+1/4|=1，小于 27/10；输出 cap 8/5、实际 sign guards、r>=g 和精确 skip 均满足。但 J=1，后继允许 1/4。因而新闭包确实修复了这个方向丢失。

新闭包仍严格有损：同一源和父 q，取共同 f=(0,1/4)、e=0，则 gate 中心为 1/2、skip 中心为 (1/4,0)。选择 r=7/10，只花预算 1/5，也满足实际 guards、r>=g 和 cap，但真实 ReLU(g)=1/2。这不是实际反例输入或 ADV。

最重要的强参照是旧 HZ 上侧行：r<=g+(3/5)(1-gamma)。它已经直接证明 J<=3/5。故本正控只证明修复了 D162 的损失，不证明在原 HZ 之上增加验证能力；也不能把共同预算的局部分离提升为真实 CNN 已有免费预算。

## 完整状态成本没有随半径一起消失

将 e 内联为 q-c-f，每组 m 个门直接物化 q、f、rho 共 3m 个连续量，约束为

```text
q>=0, q<=U beta                         2m 行
f>=0, f<=M(1-beta)                      2m 行
rho>=q-c-f, rho>=-(q-c-f)               2m 行
sum_i w_i rho_i<=R                      1 行
```

绝对值两行已隐含 rho>=0，总计 6m+1 行。原实际 guards、全部旧 P、中心系数、原 bits、其他消费者、输入 decoder 和证据成本另计。若 skip 有 s 个坐标，其共同绝对值成本还需 s 个 rho、2s 行；物化 skip 自身另付变量和定义行。

消去 f 可得到 q、rho 共 2m 个量及 5m+1 行的 M 编码，但后续若再次用无方向范数闭包，就重现原损失。反之保留 f 递归，历史宽度和中心填充都可能增长。

普通旧 HZ 可以直接内联 affine 预激活，每门只新增一个输出量和四行门约束。不能拿人为物化的预激活、或不计实际 guards 的新账单作为节省。kappa 和中心计算可写成矩阵归约，但本轮没有 GPU 实现、数值舍入证明、速度测试或终端成本优势。

## 两条替代路线属于旧档内容

另一种保方向办法是相位中心 h=diag(beta)c。原距离预算可改写为

```text
q=diag(beta)c+eta,  eta_i=0 when beta_i=0,
sum_i w_i |eta_i| + sum_inactive w_i max(c_i,0) <= R.
```

对完整 K 使用同一个 eta 可以避免 inactive padding。但跨下一门会出现 gamma_i beta_j 的源系数；直接保留这些乘积是 [D001](../D001_GUARDED_GENERATOR_DOMAIN.md) 的相位依赖生成元路线。截断相位级数并支付共同尾项已有 [D121](../d121_source_coherent_definition_audit_20261002/PHASE_SERIES.md)，重新换共同误差关系已有 [D142](../d142_joint_reabstraction_20261004/DEFINITION_AND_LIMITS.md)。本轮不重新命名或重报这些为发现。

Tropical 正负支撑函数、共同 Minkowski 因子抵消、混权 affine 和 ReLU 闭包也已由 [D011 第三节](../d011_phase_value_audit_20260928/D011_RESULTS.md) 直接覆盖。紧凑表达电路不自动减少最终查询费用；同时对正负多面体做外包再相减也不能直接保证健全。没有为这条重复路线新增候选。

## 固定方向的秩障碍不算新发现

一个有用但已覆盖的边界是：在有内点的源域上，q=ReLU(A xi+b)，完整活读出为 y=Bq+T xi+d。假设第 i 个 crossing 零面与域的内部相交、a_i 非零，且不与其他零面重合。若某种健全表示覆盖全部真实状态，且读出形式限制为

```text
y = C xi + h(beta) + S eta,
```

其中 C、S 固定，h 可以是任意相位函数，eta 的相关谓词任意，则 B[:,i] 必须在 range(S) 中。取 ker(Q)=range(S)；在每个开相位区域中，h 恒定，故 Q(B diag(beta)A+T-C)=0。比较只跨第 i 门的相邻开区域，得 QB[:,i] a_i^T=0，进而 QB[:,i]=0。

因此 rank(S)>=rank(B_crossing)，不要求全部 2^m 个相位可达，也不要求门数小于源维数。证明只需覆盖真实图，所以对这一固定加载表示类的有损外包也成立；绝不能扩大为所有有损 Neural-HZ 的下界。

若一组重合零面写成 g_i=alpha_i f，则只能要求该组的 sum_i |alpha_i| B[:,i] 属于 range(S)，不能逐列要求。相位依赖的源系数或加载矩阵、非线性 decoder 和缺少独立可达折面的域都不在该命题范围。未测任何真实模型是否满足前提。

[D152 的完整活读出定理](../d152_live_amplitude_rank_20261004/THEORY.md) 已有这一局部折面与消费者秩结论；本轮只是将相位仿射偏置重述为任意 h(beta)，无需零点比较即可证明。它不计新的下界成果。

## 研究决定

保留共享非负位移的等价表示、无 padding 闭包和非零预算反例修复，作为可复用数学结论。当前版本不进入实现或能力晋级，因为它未解决完整成本，强旧参照也能证明其正控；不能把辅助约束、旧精确图恢复或又一个压缩名字包装成 Neural-HZ 突破。

下一定义候选必须解释如何从普通共同输入盒产生有用联合关系，经过混权、后续非线性和真实旁路后，域自身如何以可支付代价查询它。不能只预先假设一个有利 L1 父球，再把该球局部优于逐门 LP 的现象称为真实网络收益。比较对象是已有实际表示和查询在对齐预算下的能力与费用，不是不可能要求有损域集合精度超越精确原网络图。

本轮全部为纸面推导和只读审查，无候选执行、模型运行、数值测试、shadow 或 replay。正式 1870/2413、独立 CIFAR100 25 加 TinyImageNet 36 共 61/400 均新增 0。
