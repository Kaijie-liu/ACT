# 非零中心且不能精确匹配的严格控制族

本页是自含纸面证明，根代理和数学审查代理分别核对；不是数值实验、网络 ADV 或形式化证明器结果。它检验 D108 的中心化关系在非均匀概率中心、带非零匹配缺陷时，是否仍能保留逐坐标参考遗漏的共同源信息。

## 普通有界结构

取 0<δ≤1/4，t,u∈[−δ,δ]，ε=1/100，η=δ²/100：

```text
s=(log(2)+t, log(2)+u, 0), p=softmax(s)
V_1=(t,−2t), V_2=(−2u,u), V_3=(εt,εu)
Y_1=p_1*t−2*p_2*u+ε*p_3*t
Y_2=−2*p_1*t+p_2*u+ε*p_3*u.
```

参考 t=u=0 有 s0=(log2,log2,0)，p0=(2/5,2/5,1/5)，所有 V0_i=0。取方向 a=(−1,−1)，得到 ρ=(0,0,ε(t+u))。

前两个 token 若要求 `aᵀV_i=Δs_i` 会强制 a=(−1,−1)，而第三个 token 的 aᵀV_3=−ε(t+u) 非恒零。因此并非 score 完全位于 value 方向的零缺陷特例。

## 有证行及二阶误差

Softmax 第 i 行 Jacobian 的绝对行和为 2p_i(1−p_i)≤1/2。沿参考到当前 score 的线段积分，|Δp_3|≤δ/2；同时 |ρ_3|≤2εδ。因此 R=εδ²=η 是有效上界。由中心化引理：

```text
F = Y_1+Y_2+(2/5−ε/5)*(t+u) ≤ η.
```

这是一条只用 Y、t、u 的 LE；没有新增 p 或乘积坐标。δ=1/4 时 η=1/1600；整族结果不是一次小数计算或某个极端点的数值现象。

## 指定的加强参考及伪赋值

参考具有同一 t,u、s,p；概率真实最紧边际；simplex；六个产品 T_it=p_i*t、T_iu=p_i*u 的全部逐项 McCormick；两列质量 Σ_iT_it=t、Σ_iT_iu=u；上面两个 Y 的共同读出；原点完整一阶核心；各输出真实最紧标量 Taylor 余项区间且跨消费者共享其身份。此外允许完整真实 (s,p) 图及完整真实 Y 输出像的约束，分别施加，但不偷偷给予整个共同 (t,u,p,T,Y) 图。

取以下伪赋值：

```text
t=u=0, p=p0
T_:t=(−η,η,0), T_:u=(η,−η,0)
Y=(η,η).
```

score 和 probability 本身恰为真实中心点，两列质量为零。第三 token 产品为零，因此非零 ε 不改变假 Y。

## McCormick 行全部通过

对 |t|,|u|≤δ≤1/4，有 3/4≤exp(t),exp(u)≤4/3。于是整个盒中 1/5≤p_1,p_2≤3/5，故 ∂p_1/∂t=p_1(1−p_1)≥2/25，∂p_2/∂u≥2/25。分别沿自身正负坐标方向移动 δ，可见真实最紧概率区间上下端距离 p0_1、p0_2 均至少为 (2/25)δ。

对 z∈[−δ,δ]、p∈[l,U]，在 z=0、p=p0 的 McCormick 截面允许
`−δ*min(p0−l,U−p0) ≤ T ≤ δ*min(p0−l,U−p0)`。
所以前两个 token 的四个 ±η 均通过，因为 η=δ²/100<(2/25)δ²。第三 token 取 T=0，自动通过包含 p0 的概率区间。没有把 tight 概率界换成更松的 [0,1]。

## 最紧逐坐标 Taylor 余项仍允许伪点

原点的一阶核心是：

```text
C_1=(2/5+ε/5)*t−(4/5)*u
C_2=−(4/5)*t+(2/5+ε/5)*u.
```

因为 V0=0，这确实是完整一阶展开，没有遗漏概率导数乘 V0。真实余项为
`r_1=tΔp_1−2uΔp_2+εtΔp_3`，
`r_2=−2tΔp_1+uΔp_2+εuΔp_3`。

在 (δ,0)，r_1≥(2/25−ε/2)δ²=3δ²/40>η，r_2≤−4δ²/25；在 (0,δ) 交换。由此两条真实最紧标量余项区间都包含 η。伪点在 t=u=0 的余项恰为 (η,η)，所以这些强边际和共享身份仍不排除它。

## 真实联合输出像也包含这个 Y

沿 t=u=−h，0≤h≤δ，两输出相同：

```text
Y_1=Y_2=h*(2−ε*exp(h))/(4+exp(h)).
```

该函数连续且在 h=0 为零。用 exp(δ)≤4/3，可得 h=δ 时值至少为 149δ/400，严格大于 η。介值定理保证存在另一真实源使 Y=(η,η)。因此完整输出像约束也不能独自排除伪点；缺少的是输出与当前 t=u=0 的对应关系。没有运行根搜索。

## 严格排除及非稳定后继

伪点有 F=2η，违反新行 F≤η，间隙为 η。另加原独立 v∈[−1,1] 与原有不稳定 ReLU：

```text
r=ReLU(F−η+2ηv).
```

真实 F≤η 给出 r≤2η。伪点取 v=1 及激活相位，有 r=3η，越过该界 η。真实中心处 v=1 和 v=−1 的预激活分别为 η 和 −3η，故两相位都真实出现；零点也保留两标签。没有删除二元相位来制造收益。

## 同方向强曲率参考得到更紧的界

不能把“可能被强参考包含”留作模糊免责声明：本控制可以明确给出强参考的证明。令 P=I−11ᵀ/3。在整个 score 盒及其到中心的线段上，每个 p_i≥m=3/19。由概率方差形式，对任意 z，
`zᵀJz=min_c Σ_i p_i(z_i−c)² ≥ m*||Pz||²`，所以 J≽mP；同时 J 的谱范数≤1/2且 J1=0。因此

```text
E=ΔpᵀΔs ≥ m*||PΔs||²,
||Δp|| ≤ (1/2)*||PΔs||.
```

本例 ρ=(0,0,ε(t+u)) 满足
`||Pρ||²=(2ε²/3)(t+u)² ≤ 4ε²||PΔs||²`。
故 Δpᵀρ≤ε||PΔs||²，进而

```text
F=−E+Δpᵀρ ≤ −(3/19−1/100)*||PΔs||² ≤ 0.
```

这个基于已知单调性／曲率的同方向参考，严格强于本轮粗缺陷界 F≤η；甚至给后继 r≤η，且中心 v=1 取等。原先 r≤2η 仍健全，但不是最紧真界。此证明不调用新求解器，也没有执行数值。

## 比较范围不能扩大

严格分离的是指定的逐产品、概率图、质量、tight 坐标余项和输出像参考，不是完整联合余项图、精确乘积图、全方向 Taylor 或完整 IQC。上节已证明同方向曲率参考包含更强的界；若后继门免费继承相同全局预激活界，也没有新增后继优势。尚未证明实际生产浮点路径在这个控制上输出上述伪点，更没有证明真实 ViT 新增 CERT。

因此本轮取得的是带非零缺陷的有证关系与代价更小的 lowering 控制，不是完成新颖性、GPU 或正式成绩资格。
