# 中心化门控关系与无显式乘积的输出约束

D108 研究如何把同源 smooth 门控关系直接传给输出，而不先物化全部概率乘源因子。结果是一个健全的中心化 lowering 引理，以及 [不能精确匹配 score 和 value 的严格控制族](CONTROL.md)。它推进的是 Neural-HZ 的关系语言和抽象变换研究，不是新的存储格式；但单调性、门控乘积及下面的有限线性约束本身仍不足以建立新抽象域创新。

前一轮 D107 完成真实图诊断与归档，属于 progress。本轮只有纸面推导、原论文与源码只读审查，没有候选代码、freeze、RUN、数值实验或模型执行。

## 域语义必须保留什么

沿用 D106 的原 HZ 载体 H、全部原连续因子 xi、signed bits b、EQ/LE、共享 frame 和 decoder。候选关系模块记录同一原赋值 theta 上的门控图及其实际输出读出，不能把 score、probability、value 各取一个不相容见证。空关系模块精确嵌入 H；新 ReLU 仍保留原相位和完整 guard，零点两标签不删。

对 Attention，精确语义为同一个 theta 产生 s(theta)、V(theta)，p=softmax(s)，Y=Σ_i p_i V_i。关系可以用于约束当前 HZ 中已有的近似输出坐标；soundness 是每个真实原输入及合法原相位仍有共同扩展，不是保留旧近似 HZ 的全部伪误差赋值。仿射、Conv、同 frame Add/Concat 复用关系及输出读出；不复制或丢弃旁路的输入身份。

这种图语义自身不是贡献。这里检验的可操作部分是：对有限、预先按源结构选择的方向 a，通过认证的差分缺陷，生成可被后继混权和 ReLU 使用的联合线性行，省去为这一行显式建立所有 p_i*xi_j 的必要。并不声称此行等于完整乘积图的投影，也不删除其他原有约束。

## 中心化关系引理

取固定有限参考 s0、V0，p0=softmax(s0)，并记：

```text
Δs_i = s_i − s0_i
ΔV_i = V_i − V0_i
Δp_i = p_i − p0_i
ρ_i  = Δs_i − aᵀΔV_i
Z    = Y − Σ_i p0_i V_i − Σ_i Δp_i V0_i.
```

其中 a 是固定输出方向，不由终端 margin、标签、LP/MILP 状态选择。代数展开给出 Z=Σ_i Δp_i ΔV_i。Softmax 单调性给出 ΔpᵀΔs≥0，故：

```text
aᵀZ = ΔpᵀΔs − Σ_i Δp_i ρ_i ≥ −R,
只要 R ≥ sup_theta Σ_i Δp_i(theta) ρ_i(theta).
```

这是同源的实数定理，不要求 s 对原输入仿射；动态 QK 也可使用，但必须完整认证其 Δs 和 ρ，包括二次项或近似误差。参考不必是域内可行点，恒等式与单调性仍成立；若要主张局部二阶尺度，则须另证明差分的相应界。控制族使用一个实际中心点。

因为 Σ_i Δp_i=0，可先从全部 ρ_i 中减去同一个源函数 r(theta)。若认证 |Δp_i|≤d_i、|ρ_i−r|≤e_i，则 R=Σ_i d_i e_i 有效。无需新增乘积变量来计算这一上界。这里没有假定独立性；独立区间乘界是对同源乘积的保守外包，可能不紧。

若差分 score 为 O(δ)，且去共同项后的缺陷为 O(δ)，则 Softmax 的光滑性给出 d_i=O(δ)，从而 R=O(δ²)。这避免了直接对未中心化 s_i−aᵀV_i 支持界产生的 O(δ) 损失，但不保证常数优于现有 Taylor。同样不能把 O(δ²) 当成有限精度实现或实际速度证明。

## 何时不需新增概率列

令 w_i=aᵀV0_i。上面的行可写成：

```text
aᵀY − Σ_i p0_i aᵀV_i − wᵀΔp ≥ −R.
```

若所有 w_i 相等，则 wᵀΔp=0。此时只需要已有 Y、V 的线性读出，没有新的 p 列或产品列。[控制族](CONTROL.md)满足 V0_i=0，但真实模型未证明满足。

一般 w 不相等时有两种数学表述，尚未选择为执行菜单：保留认证的 p 接口；或者证明一个固定权重 Softmax 下界 `wᵀΔp ≥ betaᵀΔs+L`，直接得到：

```text
aᵀY − Σ_i p0_i aᵀV_i − betaᵀΔs ≥ L−R.
```

后者仍无新 p 或乘积列，但必须支付这条下界的生成、可靠误差和源展开。若以 Taylor 提供它，还要计其有符号余项 L；不能只保留线性项。若最终候选选择这一路，应统一对全部符合结构的组执行，w 常量只是公式的零系数退化，不是第二条求解路径。

当前生产固定权重 Softmax 函数提供类似 affine/intercept/error 接口；本轮不对其浮点实现重新认证，也不把引用旧接口当成新引理的实现资格。

## 与 smooth 激活的可证明联系

同一门控思想也适用于标量单调 gate g 和输出 y=x*g(x)。对固定 r 和 g0=g(r)：

```text
y − g0*x − r*(g(x)−g0)
  = (g(x)−g0)*(x−r) ≥ 0.
```

这里要求 g 单调，不要求 y 本身单调。erf-GELU 的 gate 是标准正态 CDF Φ；SiLU 的 gate 是 sigmoid；这些原函数形式已见 [原始 GELU 论文 §2](https://arxiv.org/html/1606.08415v5#S2)。因此该引理适用于它们的精确实数定义，而不混同 GELU 与其 tanh 近似。ReLU 也可用由原 guard 编码认证的活跃指示 π；不重标或翻转原 bit 的含义，r=0 时两种零点标签仍合法。

这一不等式本身是已知单调性推论，不能算 smooth 突破。一般 r≠0 需要保存 gate 或其有证线性外包；r=0 时消去 gate 得到的简单界通常不够强。尚无 GELU/SiLU 的强比较控制、模型绑定或组件资格；当前两个 ViT 原图也没有这些激活。没有自动覆盖 LayerNorm 或所有 smooth 函数。

## 创新和晋级边界

新增一条有效 LE，终端仍是原 HZ/LP/MILP，不能仅凭改名说已经得到 PLDI 级新域。尚需证明关系模块的统一生成与消费、对强方向性 Taylor/IQC/共享多项式参考的实质区分、完整费用和真实新解。[控制族](CONTROL.md)还明确给出已知同方向曲率参考能推出更紧的 F≤0，故该控制不能支持对它的新颖性或精度优势。

GPU 归约是待实现方向，不是已测性能。所有系数、参考概率、指数/CDF、源界、舍入及 decoder 仍须资格认证；任何失败 fail closed。正式1870/2413和独立61/400不变。
