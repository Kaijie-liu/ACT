# 同一原始输入上的共同 HZ 前缀：构造定理、成本与未取得的资格

本文是 D242 的纸面归档，不是新可执行候选。本轮没有执行模型、候选、数值实验或新测试，没有修改历史文件。它回答 D241 完整原始前缀来源证据之后，怎样建立可承接 D240 关系的同一个非凸 H；不声称已经建立了该实际 H，也不把经典计算图的 HZ 编码称作强 Neural-HZ 创新已经完成。

已读依据为 [D241 来源绑定定理](../d241_residual_source_binding_20261005/THEORY.md)、[D096 非凸门出生合同](../d096_verified_phase_birth_20261001/CONTRACT.md)及其 [接入边界](../d096_verified_phase_birth_20261001/NEXT_INTEGRATION.md)。D240 的数学组件范围见其 [合同](../d240_phase_supported_component_20261005/CONTRACT.md)。D241 运行只取得完整原始参数、原始 BN 外包、property 和消费者来源证据；它没有产生下文要求的 actual H、可靠中间神经界或 D240 guard 通过记录。

## 1. 对象、语义和严格不变项

采用同一个 frame 中的非凸状态

```text
H = { (xi,b) : xi in [-1,1]^n, b in {-1,+1}^m,
                  all original and appended EQ/LE predicates hold }.
```

系数在数学定义中是精确有理数。全部物理读出、输入 decoder、节点及张量索引到原列的映射属于这个状态的来源合同。等式可以由共享稀疏线性算子的完整语义给出；这里的 implicit 只表示未逐元素展开存储，不改变“所有相应线性等式同时成立”的谓词含义。

若从既有 H 扩展，旧连续列、旧二元列、旧谓词及其 RHS、旧物理读出和 decoder 均保持原含义，只在新列补零。不能删除旧谓词，不能将 skip 私有化，不能把相同源名字当作共同输入证明。若完整前缀是首次构造，则它必须从已认证的同一 property 输入开始，而非从几个彼此独立的中间盒开始。

需要同时绑定原模型字节、property 字节、输入排列、实际节点/port/标量索引、相位方向以及 frame 生命周期。一个 Python 身份 token 不能替代这些条件。本文没有通过重新调用 D240 的 `make_block` 来声明这种来源成立。

## 2. 精确输入盒和 decoder

设原 property 的输入为 x_j in [l_j,u_j]，端点解释为原 property 指定的精确有理数。可以用通常的精确有理中心/半径形式表示；也可以选择正的二幂 M_j，满足 M_j >= max(|l_j|,|u_j|)，定义

```text
x_j = M_j*xi_j,
l_j <= M_j*xi_j <= u_j,
xi_j in [-1,1].
```

取 M_j>0，包括恒零坐标。decoder 始终从这份原输入坐标读出 x，不从某个局部 bank 的外包顶点重构输入。若模型入口有实际预处理，该预处理作为同一前缀中的完整算子保留，不能只改变输入盒后丢掉其身份。

原 Conv 浮点载荷是 dyadic，并不意味着 VNNLIB 端点也是 dyadic。上述两个输入不等式必须精确保留。若后续只支持 binary64 原生矩阵，需要逐行证明其精确可存储形式，例如可表示的整数缩放；否则应使用已有合格的精确有理谓词承载或拒绝该接入。不能默默把非 dyadic 端点写成最近浮点数，再声称输入盒精确不变。

## 3. 零中心共享标量载体与完整仿射等式

对一个实际仿射节点的每个标量输出 v，选择可靠正界 M_v >= |v|，引入一个连续载体 zeta_v，并只生成一份定义等式

```text
v = M_v*zeta_v,       zeta_v in [-1,1],
M_v*zeta_v - sum_e w_e*v_pred(e) = c_v.
```

每个实际消费者，包括后续 Conv、BN、Add、skip、登记关系和最终读出，都引用同一个 v。载体并不表示把 v 改成独立盒：上面的完整定义等式始终存在。

若前驱也采用 v_u=M_u*zeta_u，当前等式的非零系数是 w_e*M_u，输出系数为 M_v，RHS 为 c_v。它不递归把 v 展开成全部原输入路径，因此避免路径展开造成的重复，但没有消除当前算子本身的实际连接数。相同前驱列出现多次时，精确合并或保留等价的完整算子项；不能以未认证的浮点求和改变等式。

M_v 可选可靠正二幂。原存储 binary32/binary64 Conv 权重和偏置按其真实载荷解释为精确 dyadic 有理数；在这种实数网络语义下，不必把权重中点化。乘二幂可在有限、无溢出且无丢失的范围内精确表示，但必须核实，不能由“都是浮点数”推出任意算术精确。RHS 独立保存也避免无必要的偏置相消舍入。

可靠界可以按拓扑顺序由完整输入范围、完整前驱范围和精确区间算术获得，不要求额外优化器。它可能很松。所有舍入、范围计算和位长检查仍需付费；本文不保证这种界足以通过后续 D240 的结构判据。

### 3.1 Conv 的 implicit EQ 含义

原 kernel、分组、stride、dilation、padding、张量布局和完整输入/输出形状，共同定义每个实际输出位置的一条等式。零 padding 是无变量的零，不产生可自由取值的边界输入。共享 kernel 只存一份，与等式在各空间位置有不同变量列并不矛盾。

不得把连续两层带 padding 的 Conv 无条件融合为一个到处相同的大核。D241 的普通一维反例仍适用：长度 2、两次 same-pad 核 [1,1,1] 的首输出是 2*x0+2*x1；朴素合成核 [1,2,3,2,1] 再 pad 2 会给 3*x0+2*x1。实际有效中间位置和其 BN 偏置必须被保留。

### 3.2 Add 和分叉

Add 输出同样是一份 EQ，引用两条分支的原载体。若某个节点既供 Add 又供 Conv，不为两个消费者重新创造相互独立的副本。未来尚未构造的消费者至少保留准确的边界端口和原读出身份；不能把完成一个前缀表述成已验证全网络。

## 4. BN：共同系数证据、逐实际标量误差载体

对一个实际 BN 通道，原实数参数确定

```text
a = gamma / sqrt(variance + epsilon),
b = beta - a*mean.
```

须先证明分母定义成立。D241 给出的 [a_lo,a_hi]、[b_lo,b_hi] 是原参数的可靠外包，而非精确点系数。这里优先使用同一份 raw mean、beta，保留 a*(t_s-mean)+beta 的原耦合形式。选取固定精确有理点 ahat（可选 dyadic 以便后续存储），按该实际选中点计算

```text
da = max(|a_lo-ahat|, |a_hi-ahat|),
bhat = beta - ahat*mean.
```

对通道内每个实际位置 s 的输入 t_s，已有同 H 可靠界 L_s<=t_s<=U_s。取

```text
K_s=max(|L_s-mean|, |U_s-mean|),
E_s >= da*K_s,
```

定义

```text
g_s = ahat*t_s + bhat + E_s*epsilon_s,
epsilon_s in [-1,1].
```

g_s 本身仍用第 3 节的一份零中心载体 EQ 定义。同一通道可以共用 ahat、bhat 及统一 E>=da*max_s(K_s)，但 **epsilon_s 必须按每个实际标量分别分配**。不能把同一通道所有位置的加性误差强制成一个 epsilon，因为实际误差依赖 t_s。

一个实际标量的 epsilon_s 及 g_s 必须由其全部消费者共同复用，不能在 Conv 分支和 skip 分支重新选择误差。E_s=0 时必须已证明误差恒零，删除该误差项而不作除零。若把 E_s 向上取为可存储 dyadic 或二幂，界必须覆盖实际选取的值并在 EQ 中一致使用。

对每个真实输入，选择

```text
epsilon_s = (a-ahat)*(t_s-mean)/E_s
```

即可同时实现全部真实 BN 输出。这里没有把 a 与 -a*mean 的误差拆开。独立 epsilon_s 仍会丢掉一部分不同位置共享同一 a 的相关性，因此这是包含原 BN 的非凸共同来源外包，不是 BN 的理想凸包，也不是完整 BN 参数相关性保持定理。

作为较宽的通用备用证明，若只使用 a/b 的可靠区间，也可取 E_s>=max(|a_lo-ahat|,|a_hi-ahat|)*M_s+max(|b_lo-bhat|,|b_hi-bhat|)，其中 M_s>=|t_s|；但本构造不需要无故作这种解耦。bhat=beta-ahat*mean 是精确有理式，未必能直接存为一个 binary64。如果实际使用偏置 bstore，则至少取 E_s>=da*K_s+|bstore-(beta-ahat*mean)|，或采用经证明精确的字面常量载体；不能沿用仅 da*K_s 的界而遗漏偏置舍入。ahat 若改变，也须以实际选定系数重新计算 da。这里只陈述误差条件，不声明浮点存储接入已经完成。

不能只保留 ahat、bhat 而漏 E_s。也不能先用未含全部误差的中点网络证明 D240 guard，再将该 guard 归给完整 H。

## 5. 原 ReLU、相位方向和零标签

每个实际 crossing ReLU 的原 active 指示为 alpha in {0,1}，由其原 signed bit 映射，不另造一个用于替代它的“辅助相位”。令预激活 f、输出 q 已有可靠界 L<=f<=U，其中 L<0<U。以下四行给出精确整数图：

```text
q >= 0,
q >= f,
q <= U*alpha,
q <= f - L*(1-alpha).
```

alpha=0 强制 q=0、f<=0；alpha=1 强制 q=f>=0。反之，真实 q=ReLU(f) 在 f=0 时允许两个标签，均满足四行。正 f 和负 f 的标签分别固定。多个门使用同一原赋值和各自合法标签，不能逐门改变共同输入。

输出也可取 q=M_q*zeta_q，M_q>=U 且 M_q>0；其非负性由图行保证。这使后继继续引用一份零中心物理载体。

稳定正门可别名为 f，稳定负门可别名为 0；若已有原相位列或相关谓词，不能因稳定化删除它们。首次构造的稳定门不必新增本来不存在的相位。若为了统一稀疏布局仍为稳定输出分配物理载体，相应 EQ、列和所有消费者也要计费。

这四行是本纸面构造的一种精确图描述，不表示已经实现了新的原生出生算子。D096 已实现的是另一份经核查的载体 EQ 加两 guard 形式，每个 crossing 门新增两连续因子和一个原 signed bit，首次还需要两个固定为 1 的载体。其完整来源、现有 allocator 和原生解析边界不能由本文自动跨过。若复用 D096，必须按它的真实表示和成本付账；若实现这里的四行版本，则须独立验证实际存储行和整数图对应。

## 6. 整个前缀的共同扩展定理

**假设。** 输入/property 已精确绑定；前缀是有向无环的原算子图；全部原 Conv 点系数和几何真实；每个 BN 区间可靠且采用第 4 节的唯一标量误差身份；ReLU 与 Add 使用上述共同读出。若从既有 H 延伸，必须已有共同来源前提：每个原 property 输入及其允许的原合法相位标签，在旧 H 中已有同一个赋值同时实现全部旧物理读出和 decoder；仅保留旧谓词不能证明这个前提。所有新范围须覆盖完整声明父 H，包括其全部允许的 BN 误差状态，而非只覆盖中点网络或真实输入子集。旧 H 的谓词和身份完整保留。

**结论。** 对 property 内的每个真实输入，以及所有实际零预激活处任取的合法原标签，存在同一个完整 H 赋值，同时实现此前缀所有实际节点、全部已构造消费者和原输入 decoder。

**证明。** 先令原输入因子实现该输入。按原图的拓扑顺序归纳：Conv 和 Add 用实际前驱值计算真实输出，令其 zeta_v=v/M_v，可靠界保证其在单位盒中；BN 按第 4 节选择本实际标量的 epsilon_s，再设置唯一输出载体；ReLU 设置实际输出及合法原相位，四行全部成立。每个共享节点只设置一次，此后所有消费者引用同一值。所有新增谓词由此同时成立。原输入和旧坐标未改，故 decoder 和旧谓词保持。证毕。

反向方向须分开表述：任意整数可行 H 赋值满足所声明的 Conv、Add、ReLU 图以及所声明 BN 误差外包；由于自由 epsilon_s 的存在，它不一定来自原网络的某次真实执行。因此该 H 是原模型的可靠外包，不得把任意 H 点直接记作 validated ADV。原输入重构后仍须具体原网络验证。

若没有 BN 误差且所有算子精确，则这些图等式与整数相位给出相应前缀的精确图扩展。一般误差情形不提升为精确原网络图。若从既有 H 延伸，范围条件对整个旧 H 成立时，每个旧整数可行赋值也能沿这些已声明算子选取一致扩展（例如选择合法的零 BN 误差）；并非只有原真实网络赋值可扩展。因此这种完整追加构造不通过辅助变量隐式删除旧 H 的状态。

## 7. 同 H 上的 D240 Q 关系与完整 r/e

本节只陈述可接入关系，不声明实际前缀已满足判据。对两个实际 crossing 父门 Q_i=ReLU(f_i)，选正比例 s_i>=max(-L_i,U_i)，定义 x_i=f_i/s_i、q_i=Q_i/s_i。于是 q_i=ReLU(x_i)、x_i in [-1,1]，原零点和相位不变。不能以中心平移替代这种归一化。

同 H 中两个实际子门为 Y_j=ReLU(g_j)。以事先固定的真实算子分解写

```text
g_j = C_j1*q1 + C_j2*q2 + R_j(H),
A=(C_11-C_21)/2, B=(C_12-C_22)/2,
tau=(A-B)/2 > 0,
a=(C_11+C_21)/2, b=(C_12+C_22)/2,
r=(R1+R2)/2,
e=(R1-R2)/2 + (A+B)*(q1+q2)/2.
```

这里的 C 已含父比例。R_j 必须保留完整真实其余父输出、偏置、skip、BN 误差载体和原二元项；它是同一 H 上的读出，不是一个新自由 residual 输入。先按共同列身份精确合并，再求完整 r/e 的可靠界。特别不能省略 (A+B)*(q1+q2)/2，除非真实系数恒等式证明其为零。

令 z=(g1+g2)/2=a*q1+b*q2+r，d=(g1-g2)/2=tau*(q1-q2)+e。若整个 H 上 r in [Lr,Ur]、e in [Le,Ue]，并且

```text
[Lr+min(0,a,b), Ur+max(0,a,b)] subset [-tau,tau],
```

则 alpha1!=alpha2 时至多一个 q_i 非零，得到 |z|<=tau。故共同差中有 (alpha1-alpha2)*(clip(z+tau,0,2*tau)-z-tau)=0。这不是各项 alpha_i*clip 的逐项别名，也不需建立虚拟 clip 门或新位。

新增四个连续乘积观察

```text
c12=alpha1*q2, c21=alpha2*q1,
v1=alpha1*r,  v2=alpha2*r.
```

用可靠范围生成其 16 条 McCormick 行，并令

```text
K=tau*(alpha1-alpha2)+a*(q1-c21)+b*(c12-q2)+v1-v2,
p_i=alpha_i-q_i.
```

附加两行

```text
Y1-Y2-K <= 2*tau*p2 + 2*max(Ue,0),
-Y1+Y2+K <= 2*tau*p1 - 2*min(Le,0).
```

它们由共同差别名及 ReLU 对称差对 d 的单调 2-Lipschitz 性得到。对全部原二元位整数的 H，四个乘积由 McCormick 行唯一确定，以上行在每个 H 状态上成立；所以附加关系不删除原整数 H 状态，且保留原相位零标签。相位松弛时可提供额外关系，但不声明它等于整个 H 的凸包。

此处必须将全部行精确代回原列并保留旧 H。不能另建独立 x/q/r 盒后把同名变量当成实际来源；也不能只在原真实执行而非整个误差外包 H 上证明范围。既有 [D241 第 4 节](../d241_residual_source_binding_20261005/THEORY.md)的同 H pullback 和完整 nnz 账继续适用。

## 8. 完整成本：载体阻止路径展开，不消除卷积人口

令 d 为输入标量数，A 为新增仿射标量输出数（含 BN、Add），C 为非零 BN 误差载体数，R 为 crossing ReLU 数。若仿射 EQ 的全部普通前驱出现项数为 M，且物理读出各是一列零中心载体，那么上述四行版从输入首次构造、且不另物化稳定别名时的纸面量为：

| 项目 | 完整量 |
| --- | --- |
| 连续列 | d+A+C+R |
| 原 crossing 相位列 | R；已有原列复用、不重复分配 |
| 输入 LE | 2d，nnz 为 2d |
| 仿射 EQ | A，nnz 至多 A+M+C |
| crossing 图 LE | 4R，nnz 至多 8R |

这里假定 f/q 读出分别为一个载体列，alpha 是一个 signed bit 的固定仿射变换。稳定输出另物化时，逐个追加真实的列、EQ 和至多两个 nnz。旧 H、原 property 其他谓词、rowptr/索引、所有读出、范围及精确有理数对象、consumer/decoder/provenance、source 扫描、临时量和认证费用均在此表之外，不能不计。D096 的不同出生形式不能套用本表较小列数。

对 Q 关系，坐标模板为 4 连续列、18 LE；代回真实稀疏读出后，D241 给出的新行 nnz 上界为

```text
4*(Sq1+Sq2) + 2*(SY1+SY2) + 4*Sr + 40,
```

S 计实际展开前的完整连续/二元出现项，不含 RHS。比例、固定项及产品列要一致处理。原 H 不能从该账中消失，范围的计算与 r/e 生成也不包含在这个新行 nnz 式中。

### 8.1 已足以否决朴素全 CSR 的普通大模型规模

这不是本轮新模型数值运行，而是依据 D241 已确认形状的纸面人口公式。CIFAR100 large 的 Conv3、Conv6、Conv9 都是 32x32 上的 64 到 64、3x3、stride 1、pad 1。每个空间方向的有效输入出现次数为 3*32-2=94，因此按完整 kernel 项逐空间位置物化的单层权重出现数为

```text
64^2 * 94^2 = 36,192,256.
```

这三层已达 108,576,768 个系数出现项，还未包括首层 Conv、索引、BN、Add、ReLU、输入和查询。只按一个系数一个 entry 都超过既有 64M 限额。D241 能读取共享 kernel 参数，不等于能在同一费用内物化所有空间 EQ。

因此当前事实否决的是“把这份完整前缀全部朴素展开为 scalar CSR 就能在原预算内完成”的路径，不是否决共同 H 的数学定义，也不允许截一个局部窗口替代完整来源。

### 8.2 implicit 不免除终端成本

共享 kernel、几何和逐节点 EQ 可压缩表示完整 M 条出现项，但终端、关系编译、界计算、输入重构和认证必须真正支持该表示。若某个消费步骤需要展开，展开人口、实际算术和峰值必须全付；若用不展开的算子消费，也须证明其语义和完整成本。不能把“尚未展开”写成零成本，也不能把未实现的 operator-aware terminal 当成已经可用的能力。

避免逐门复制整个 H 的最低条件是一个受信、拥有自身完整来源的拓扑构造过程、唯一列/节点分配和追加式不可变定义，最终对整个前缀封存。它仍需认证全部参数和生成行、范围及共享身份。外部不可信旧 H 的完整入口检查不能靠这一构造约定省略。本文没有实现这种生命周期或改变旧门。

## 9. 最低接入义务与本轮结论

后续若选择具体实现，至少需要明确：

1. 原 property 的精确输入、输入排列和 decoder；原模型及全部 prefix/consumer 来源身份。
2. 唯一共同 frame、原标量和原 bit 分配、所有 Add/skip 复用；不能复制残差来源。
3. 全前缀可靠范围、真实 Conv dyadic 系数、实际 padding，以及 BN 点加完整误差的共同扩展证据。
4. 实际存储 EQ/LE 与所声明有理式相等；若使用浮点批量算术或 GPU，另外证明舍入的包含方向，不能从数学图自动继承。
5. 完整物理/峰值/查询账和明确的 implicit 消费合同；不能沿已被人口否决的全 CSR 路径隐去条目。
6. D240 只在其完整同 H 判据成立时 opt-in 附加；未通过是资格未建立，不是 SAFE、UNSAFE 或收益。

已有精确 HZ 可以表达这里的有限线性谓词和原二元门；这份构造没有提高集合表达力。它解决的是后续结构关系必须共享真实输入、误差和相位的前置语义条件。是否形成新的可组合 Neural-HZ 抽象变换精度、能否在真实 crossing 结构上通过 guard，以及是否带来新 CERT/validated ADV，仍待后续独立资格和实验。

正式 13 家族基线仍为 1,870/2,413（1,063 CERT + 807 validated ADV）。独立 E0 的 61/400 不并入该基线。本轮没有能力记账变化，没有默认启用，没有实际 H 或 GPU 完成声明。
