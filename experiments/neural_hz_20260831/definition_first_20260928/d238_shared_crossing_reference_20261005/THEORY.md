# 跨零共同参考的神经关系与精度边界

本轮得到一条保留原非凸 HZ 的有限共同差分关系：即使参考 ReLU 跨零，也可以先消去多个子门共享的非线性项，再生成有效关系。一个带真实源依赖的普通控制严格优于明确的多个完整局部凸包参照。一般 clipped reference 版本完成了纸面健全性证明，但尚无该非线性区间上的能力正控、实现或真实网络收益。本记录不是新抽象域已成立或 PLDI 级创新已完成的声明。

## 原非凸语义和查询外包必须分开

原 HZ H 的连续源、全部原 signed bits、EQ/LE 谓词、共享 latent/frame、物理读出及输入 decoder 均保留。alpha_i 是原父相位的 0/1 视图，不是新增位。用可靠正上界规范化实际父幅值后，有 0<=q_i<=alpha_i，记 p_i=alpha_i-q_i>=0。可靠性须在当前整个父域上成立，不能只在原网络某些轨迹上检查。

候选观察语义可以写成 (H,O,C)：O 是同一原赋值上的具名函数，C 是已证明有效的共同关系。具体化要求 O 取其真实函数值；空 O,C 精确嵌入原 H。加入这些定义及有效关系不改变原物理整数集合。它改变的是可保留和消费的有限关系，不增加原精确 HZ 的集合表达力，也不构成完整最佳抽象或可计算格的证明。

下面对非线性观察的线性查询只是外包。即使全部原相位为整数，这个外包中的观察也可能不是唯一真实函数值。每个原 H 状态都有共同的 canonical 扩展，且完整原 H 仍保留，所以投影回原物理状态恰不变；不能反过来将任意可行辅助值当作真实观察或具体反例。输入见证仍须由原 decoder 重构并经过具体网络验证。

## 两个实际子门的一条统一关系

设两个实际子门为 y1=R(g1)、y2=R(g2)，R(v)=max(0,v)，定义同源完整读出

```text
z=(g1+g2)/2,
d=(g1-g2)/2=tau*(q1-q2)+e,  tau>0,
S_tau(z)=R(z+tau)-R(z-tau)=clip(z+tau,0,2*tau).
```

e 必须包含全部未匹配权重、偏置和其他父幅值；z 和 e 都保留在同一个 H 上，不用独立盒替换其真实来源。可靠界记为 Le<=e<=Ue、l<=z<=u。定义共同观察 S=S_tau(z)、m_i=alpha_i*S。

令 Phi(d,z)=R(z+d)-R(z-d)。对固定 z，它关于 d 单调且 2-Lipschitz。参考点 d0=tau*(alpha1-alpha2) 满足

```text
Phi(d0,z)=(alpha1-alpha2)*S_tau(z)
```

对所有 z 成立，不要求四个参考各自符号稳定。又 d-d0=-tau*p1+tau*p2+e，故统一增加

```text
-2*tau*p1+2*min(Le,0)
  <= y1-y2-(m1-m2)
  <= 2*tau*p2+2*max(Ue,0).                         (C)
```

证明只使用上述单调性和 Lipschitz 性，覆盖原零点的所有合法标签。这里没有运行四个相位子问题、建立点池、改变原位或调用辅助求解器。证明分析整数取值不等于授权运行时相位 split。

tau 不是按终端 margin 或 LP 状态选择的参数。未来实际匹配可以按完整 d 的两个异号归一化系数 c_i>0、c_j<0，统一取 tau=min(c_i,-c_j)，并将系数不匹配完整留在 e；固定系数必须有可靠证书。区间系数不能用中点替代原模型，实际匹配人口、误差和费用须另行预注册。当前没有实现该匹配算法。

## 共同 clip 观察的有限降级

如果 l<-tau<tau<u，S 的完整标量图凸包为原 z 界加上

```text
0<=S<=2*tau,
S<=2*tau*(z-l)/(tau-l),
S>=2*tau*(z+tau)/(u+tau).                          (H)
```

这是四个折线端点 (l,0)、(-tau,0)、(tau,2*tau)、(u,2*tau) 的凸包公式，不在运行时建立四个 HZ 子域。若只跨一个折点，则用相应单三角包络；若整个区间在中段，S=z+tau；若整个区间在两侧，S 分别为 0 或 2*tau；退化点区间直接取常数。结构公式必须覆盖边界而不作除零。

两个 m_i 用 S 属于 [0,2*tau] 的完整四行原二元乘积包络。在原整数 alpha_i 下它们等于 alpha_i*S，但 (H) 不强制 S 取真实 clip，所以不能宣称整个线性降级仍是辅助函数的精确图。

z,y1,y2,q1,q2 已有独立物理列且完整跨两折点时，局部增量为 3 连续列、14 LE、34 左侧 nnz：clip 的 4 LE/6 nnz，两个产品的 8 LE/16 nnz，(C) 的 2 LE/12 nnz。若 z 内联为 s 项，变为 32+2s nnz；所有可靠界、e 的完整来源与求界、原图、终端转换和消费者另计。中段仿射别名可精确消去 S 列，但不消去其他消费者或其费用。

## 真实源相关且参考跨零的控制

令 x1,x2,t 属于 [-1,1]，原父门 qi=R(xi)，并保留它们的原相位 alpha_i。定义

```text
z=(x1+x2)/4+t/20,
y1=R(q1-q2+z),  y2=R(q2-q1+z),
D=2*q1-x1+2*q2-x2,
F=D+(y1-y2-(x1-x2)/2)/2,
r=R(F-51/25).
```

z 属于 [-11/20,11/20]，确实跨零，两实际子门也跨零。共同参考 R(z) 不能按旧 D237 的逐项稳定前提替换成仿射式，但它在差分里相消。这里 tau=1、e=0，故 S=z+1 全域仿射。这一点非常重要：本例证明跨零参考的组合消去，不是通用 clip 跨越正负折点时也有收益的证据。

定义

```text
p_i=alpha_i-q_i,
n_i=1-alpha_i-q_i+x_i,
d_i=p_i+n_i=1-2*q_i+x_i,
c12=alpha1*x2, c21=alpha2*x1,
s1=alpha1*t,  s2=alpha2*t,
T=q1-q2+c12-c21.
```

原父图给 p_i,n_i>=0，并有 xi=2*alpha_i-1-p_i+n_i。原整数赋值下 alpha_i*xi=qi，故 T=(alpha1-alpha2)*(x1+x2)。以下源容量直接有效：

```text
-d1<=T<=d2.                                         (B)
d2-T=(1-alpha2)*p1+alpha2*n1+alpha1*p2+(1-alpha1)*n2,
d1+T=alpha2*p1+(1-alpha2)*n1+(1-alpha1)*p2+alpha1*n2.
```

右侧各项非负，展开时 alpha1*alpha2 抵消，因此 (B) 不需要新增共现变量 delta。它们是额外有效源容量行，不能说四个彼此独立的 McCormick 产品包络自动蕴含它们。

将 (C) 中 m1-m2 别名为 alpha1-alpha2+T/4+(s1-s2)/20，得到

```text
-2*p1 <= y1-y2-[alpha1-alpha2+T/4+(s1-s2)/20] <=2*p2.
```

同一个 t 上的完整 s1,s2 产品包络给 s1-s2<=1。具体可把 s1<=alpha1、s1<=t+1-alpha1、s2>=-alpha2、s2>=t-1+alpha2 相加除以 2；不用假定 LP 状态来自一个真实分布。结合 T<=d2，可得完整有限线性证书

```text
F<=81/40-3*p1/4-5*n1/4-p2/8-5*n2/8<=81/40.
```

真实输入 (x1,x2,t)=(1,-1,1) 达到 81/40。因此 r 的预激活至多 -3/200，r 恒为零。

这也属于一个普通参数族：z=k*(x1+x2)+eps*t，0<=k<1/2、0<eps<1-2*k，其他式子不变，则

```text
F<=2+eps/2-3*p1/4-5*n1/4
   -(1/4-k/2)*p2-(3/4-k/2)*n2<=2+eps/2.
```

同一个真实输入取等。它仍要求两个主幅值在实际子门中相反出现；一般不匹配权重由 e 支付，不能把此参数族外推成任意训练通道。

## 强局部参照仍允许的物理点

固定 u=99/100，考虑查询中的显示点

```text
x1=x2=t=0, alpha1=alpha2=1/2, q1=q2=u/2,
z=0, y1=2*u/5, y2=u/4, gamma1=gamma2=1/2.
```

gamma_i 为原子门相位的 0/1 查询视图。该点 F=8217/4000，比 81/40 高 117/4000；独立接下一真实 ReLU 图时，允许 r=57/4000。它不是具体网络输入或 ADV。

该点同时属于下列强参照的交集。第一类是每个单子门的完整带原源和原标签前缀凸包。取真实 x 四角 (±u,±u)、t=0，令 00、11 的质量各为 delta，10、01 各为 1/2-delta。每个目标子门的均值为 u*(1/2-delta/2)，其原标签均值为 1/2。对第一子门用 delta=1/5，对第二子门用 delta=1/2，得到相同显示源和父坐标及所需 y、gamma。每个前缀自身都完整，但它们没有共同的二阶源条件分布。

第二类更强于只在独立 feature 盒上接子门：先取两个原父带标签图的完整凸包 P，再在 P 上同时接两实际子门的精确图，最后取完整凸包。以下三个组按 3/5、3/10、1/10 混合。各组内部列出的两点等权；每个原子取 q=u*alpha、x=u*(2*alpha-1)、t=0，故属于 P，z 仍由真实 x 计算。

| 组 | 两个原子的 alpha | 两个子门的组内幅值均值 |
| --- | --- | --- |
| A | (1,1/2) 与 (0,1/2) | (3u/8,u/8) |
| B | (1,0) 与 (0,1) | (u/2,u/2) |
| C | (0,0) 与 (1,1) | (u/4,u/4) |

各组的源均值为零、父 alpha 均值为 1/2、q 均值为 u/2、两子标签均值为 1/2。总子幅值均值恰为 (2u/5,u/4)。所有子预激活严格非零，父 P 中的分数标签只是比较查询坐标，不是候选将实际位连续化。

完整单子门前缀包含实际 parent-to-child 的 D036 有效行及相应 D020 差分行；两子门的 D020 差分也通过。固定同一子门前沿上的 D062/D068 支持即使取到 P 上精确联合支持，也不能排除此点。该比较不包含完整原源四门联合凸包、全部跨前缀条件矩或递归生成的全部跨层 RLT，不能宣称超过这些更强参照。

## 费用与创新边界

上述相关源控制只需四个连续产品 c12,c21,s1,s2。四套完整产品包络为 16 LE/40 nnz；两差分行为 2 LE/20 nnz；两源容量行为 2 LE/10 nnz。局部合计 4 列、20 LE、70 nnz，没有 delta、新原位或第二条求解路径。计数假设已有所列物理坐标；原 H、源展开、全部原门、界认证、signed-bit 代换、slack、host/device 共存、终端和重构仍须完整计费。

Affine/Conv/Add/Concat 可以在保持身份时线性消费已建立关系，但不同 child pair 会产生不同的 z、S 和乘积；没有固定宽度或无损任意深层闭包定理。GPU、smooth activation、Transformer 没有继承本 ReLU 定理或取得实测资格。

源容量、条件乘积和共同投影与已归档 D035 的 RLT/BQP 机制重合，单调 Lipschitz 和标量 clip 凸包也不是本项目创造的新数学。当前可成立的主张是一个可构造、有限且可跨层消费的关系扩展及明确局部精度分离，不是完整 Neural-HZ 定义已经创新成功。进一步研究必须给出统一演算相对于有完整成本的强有限参照的优势，并在真实结构中兑现。

一个应保留的负控：若 z 只是独立对称区间 [-rho,rho]，上述 F 的界 2+rho/2 已可由旧的 |(y1-y2)-(q1-q2)|<=rho 与父图推出；不能把该情形重复记为新收益。本例有用的是共同源容量和关系消费，不是仅给残差换名字。
