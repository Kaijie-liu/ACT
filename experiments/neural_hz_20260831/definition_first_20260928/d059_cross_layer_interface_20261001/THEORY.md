# 跨层条件关系的最小接口与组合边界

本轮把跨领域综述中的“共享关系能否穿过下一层 ReLU”变成两个可检查的问题。第一，给定需要继承的仿射观察，精确条件化至少需要多少独立信息；第二，完整局部凸包在共享全部坐标时，是否已经足够保证跨层一致性。

结论是：指定仿射接口下，条件方向的最少数量由一个有效行空间秩差决定；而局部凸包即使共享完整连续坐标和相位均值，也不能保证全网联合凸包。两项结果约束下一定义候选，不能据此声称新域或新基准收益。这里的 lift 属于已有 RLT 与析取规划范畴，不将线性代数或经典变量消元包装成新颖性。

## 保留原非凸语义的候选接口

令 H 是完整原 HZ 关系，包含原连续因子、全部原 bits、EQ/LE、共同 frame、物理读出和输入 decoder。z 是这个 frame 的一组已认证物理读出。下一原门为 g=aᵀz+c，r=ReLU(g)，原 active bit 为 beta，满足 r=beta*g 及原 sign guard；g=0 时两种原 bit 都保留。

拟研究的接口增加有限条件观察 m_j=beta*h_jᵀz，语义为在同一个原赋值上同时满足 H、该原门和全部条件观察。它不替换 H，不复制独立 source，也不引入替代相位。每个原整数赋值唯一决定全部 m，因此投影回原坐标与 bits 完全相同，原具体输入 decoder 不变。空观察接口直接退回 H。这是一个带显式条件观察的非凸扩展语言，但语义框架本身是已有混合符号 lift。

同一身份空间上的具体化包含给出语义预序，按相等取商可得偏序；未声称可计算最佳抽象或完整格。Affine、Conv、Add 与 Concat 都通过同一赋值上的线性组合构造读出，不能独立复制残差分支。ReLU 保留其原四行和原 bit，并按所需观察构造下面的条件方向。接口若不闭合，可以付费保留必要物理读出；不能把未付费的整张网络图叫作精简。

## 条件方向的精确秩差

假设已认证 source 位于仿射空间 E={z0+D*xi}。在同一个 E 中，实际 source 的 g<0 与 g>0 两个切片分别含非空相对开集；两开集不需要重合。这个假设用于必要性，不是从一个宽外包盒自动推得的事实。

希望表示 beta*V*z，允许的重构仅是 z、beta、r 与 m_j=beta*h_jᵀz 的常系数仿射式。这里没有其他可免费调用的非线性读出。则所需的最少独立条件方向数为

```text
d = rank([aᵀD ; V D]) - rank(aᵀD).
```

必要性如下。写出任一候选仿射重构，在 beta=0 的开集上 r=m=0，目标也为零，所以所有直接连续项在 E 的方向空间上系数为零，常数相应抵消。在 beta=1 的开集上比较连续系数，得到 row(V D) 包含于 span(aᵀD, H D)。因此 H 至少补足该秩差。

充分性如下。选补空间 H，使 V D=lambda*aᵀD+B*H D。于是 V=lambda*aᵀ+B*H 在 E 上只差常数 k=(V-lambda*aᵀ-B*H)z0。在原整数关系上，准确重构为

```text
beta*V*z = lambda*r + (k-lambda*c)*beta + B*m.
```

满维且 z0=0 时 k=0。常数补偿不能在存在原 EQ 或平移坐标时漏掉。实际实现不能用数值低秩阈值代替上述确切等式证明；真实 BN 产生区间包围参数时，也不能用中点矩阵的 rank 宣称真实依赖成立。

这是所声明的 affine(z,beta,r,m) 接口下界，不是任意抽象域、任意非线性编码或所有给定网络的普适下界。若原可行源没有两个相对开切片，或者已有其他确切条件读出，下界可能不适用。含旧 bits 的观察可以作为整体有界仿射形式条件化，但不能把它们当作自由满维连续坐标来套用此必要性证明。

## 整数精确编码与松弛代价

对每个 t_j=h_jᵀz，使用实际可靠的 l_j<=t_j<=u_j，新增连续量 m_j 和四行：

```text
l_j*beta <= m_j <= u_j*beta
t_j-u_j*(1-beta) <= m_j <= t_j-l_j*(1-beta).
```

beta 为整数时，这些行恰好给出 m_j=beta*t_j，且不限制原门零点的两种相位。每方向增加一个连续量、四条行，至多 2*nnz(h_j)+8 个谓词系数；原变量界、RHS、观察存储、重构 B/lambda、认证与行展开成本另外计算。归一化为 HZ 因子或等式后端需要的 slack 也不是免费。

保留全部原 LP 行，只追加对整数图有效的 lift 与后果，保证查询外包不弱于原 LP。分数 beta 时，四行只是乘积外包，r=beta*g 与 m=beta*Hz 不再是每个 LP 点的真实乘积恒等式。不能把整数重构定理误报为分数点的精确语义，也不能声称此选定 lift 与完整逐坐标 source RLT 等强。

只增加未被其他关系消费的独立 m 不保证任何投影增益。如果一个 m 只被一条条件不等式使用，可能可以直接消掉它并保留已知投影行；上述秩下界不禁止这种仅保不等式的投影。相反，多个消费者共用 m 时，分别按各自最好值消元可能丢失共同可行性。是否共享、是否能消掉，必须按完整消费者关系证明，不按 terminal margin 选择。

精确基选择及界计算也有代价。稀疏形式经基变换可能变稠密；精确系数位长可能增长。每个原门都建立一组新条件方向时，总成本仍会随网络增长。固定 gather、仿射支持计算及行合成可研究 GPU 批处理，但该形式不证明已经加速，更不免除主机设备共存、终端求解和证据费用。

## 一个普通混权例及其已有技术归属

令 x,y in [-1,1]，保留三个原 bits，设

```text
q = ReLU(x+1/10)
p = ReLU(y-1/10)
g = q-(7/10)*p-1/5
r = ReLU(g), active bit beta.
```

在两个父门都激活的普通开区域中，z=(q,p) 有二维内部，g 的正负两侧都有内部。观察 q 的方向 (1,0) 与 a=(1,-7/10) 不平行，因此上述接口至少需要一个新增条件方向。取 m=beta*p，则原非负 slack s=11/10-q 满足

```text
beta*s = (9/10)*beta-r-(7/10)*m >= 0.
```

p 的范围为 [0,9/10]。用四行乘积外包并对孤立 m 投影，得到

```text
r <= (9/10)*beta
r+(7/10)*p <= 63/100+(27/100)*beta.
```

第一条已在旧 scalar 门行内；第二条可严格增强它。具体纸面松弛点为 x=7/10、y=9/10、q=p=4/5，父 bits 均为1，beta=1/2、g=1/25、r=3/10。原子门界为 [-83/100,9/10]，其四条 scalar 行都满足；新第二行左侧43/50、右侧153/200，相差19/200。输入在盒内部，所有该点预激活非零。这是分数松弛见证，不是具体 ADV 或执行结果。

该行正属于 [Anderson 等的单门 source box 强表述](https://arxiv.org/pdf/1811.08359) §2.3，也可由已有条件观察投影得到。因此这是最小接口与成本的正控，不是定义创新证据。分组 lift 的已有层级也见 [Tsay 等](https://arxiv.org/pdf/2102.04373) §3。本轮没有采用这些论文的动态分离、优化式界收紧或搜索。

## 完整局部凸包仍可能跨层失配

考虑带普通混权和残差的两层关系：

```text
x in [-1,1], y in [-1/10,1/10]
g=x+y/5, q=ReLU(g), parent bit alpha
h=q/2-x+y/10+1/5, r=ReLU(h), child bit beta.
```

令 P 是父门在完整坐标 (x,y,q,alpha) 上的凸包。比较方法先用 P，再对 child graph over P 取完整带 beta 的凸包。它保留全部 source 坐标均值，不是把 source 投到低秩坐标，也不是只用 scalar big M。

该方法允许

```text
x=y=0, q=alpha=beta=1/2, h=9/20, r=21/40.
```

父关系可用真点 (x,y,q,alpha)=(1,0,1,1)、(-1,0,0,0) 各半解释。子关系可用下面两个点各半解释：

- A：x=-4/5、y=0、q=alpha=1/10，h=r=21/20、beta=1；其 prefix 是上述父真点按1/10与9/10混合。
- B：x=4/5、y=0、q=alpha=9/10，h=-3/20、r=0、beta=0；其 prefix 按9/10与1/10混合。

因此两个子见证都在所声明的 child graph over P 中，平均值就是该点。但真实网络恒满足 r>=(7/6)*(q-g)。当 g>=0 时 q-g=0；当 g<=0 时 q=0，且

```text
h-(7/6)*(q-g) = x/6+y/3+1/5 >= 0.
```

最后一步由原输入盒直接得出，在 x=-1、y=-1/10 取等；全程包括零点两种原 bits。真实物理输出 Z=(7/6)*(q-g)-r 因而不超过0，而上述松弛点 Z=7/120>0。

这个反例否决“局部 ideal 加完整 separator 均值即全局 ideal”的假设，不否定保留原非凸父关系的精确组合，也不否定任何有用但非 ideal 的候选。真网络有效行是已有 source binding 与 descendant 关系的实例，本轮不将它报作新 cut。与先前 D019 的低秩丢源不同，这里所有 source 坐标均已保留，缺的是同一个可共同实现的局部混合见证。

## 完整关系的精确拼接仍成立

若两个线性系统 P_A(u,s,b)、P_B(v,s,b) 的私有连续变量 u、v 不交，全部跨模块读出和谓词都经过同一 separator (s,b)，则

```text
exists u,v: P_A(u,s,b) and P_B(v,s,b)
  iff (exists u: P_A(u,s,b)) and (exists v: P_B(v,s,b)).
```

证明就是在同一个 s,b 上组合两个私有见证。这里交换的是完整投影关系，不是分别凸化不同整数关系后仅对齐均值。原 bits 不消去；在满足 running intersection 的模块树上可逐叶使用此规则。保留原全部 witnesses 固然精确，但不是压缩成果。

这是经典关系 join 与变量消元。投影行、系数填充、位长和 decoder 都须计算；[Dechter 的 §2.3](https://ics.uci.edu/~dechter/publications/r76A.pdf)已经说明连续线性消元不能只靠 induced width 给出所需复杂度界。[Reduced product 理论](https://pcousot.github.io/publications/CousotCousotMauborgne-FoSSaCS11-LNCS6604-proofs.pdf)提供同一具体见证上的语义组合，也不自动给出低成本有限接口。

二阶 lifting 同样已有大量先行工作；例如 [Brown 等 AISTATS 2022](https://azizan.mit.edu/papers/UnifiedVerification.pdf) §1.1 讨论 RLT 与神经验证的联系。该论文不是上述特定秩差推导的新颖性证书，也不授权本项目引入 CPP、SDP、dual rescue 或改变原终端边界。

## 对定义研究的具体决定

本轮关闭两项未经证明的捷径：仅靠一个新 ReLU 输出免费继承任意旧仿射观察，以及局部凸包通过均值接口自动获得全局一致性。保留条件方向秩差作为后续设计的成本下界，保留两个普通控制作为必须明确面对的比较边界；不为这套已知 lift 单独建立“新域”或重复启动完整组件测试。

下一定义候选需要解释：在真实宽共享源、混权和残差结构中，哪些有界条件方向会被多个后继共同消费，怎样在整个消费者集合上复用或精确投影，以及为何完整代价与精度优于已有分组 RLT、现有 HZ 加同样后果或保留原图。不能把固定层数的例子扩大成任意深度闭包，也不能以每层继续增加 lift 的成本隐藏相位多项式增长。

当前没有证明这样的跨块受控闭包，也没有新增真实网络能力。形式提议、经典等价、组件资格、实际 GPU 加速和正式提分仍分开记账；1870/2413 与独立61/400均不变。
