# 共同观察的条件幅值前向变换

本轮提出并纸面核验一种有限观察接口：保留完整非凸 HZ 与所有原相位，仅为下游实际消费的线性观察保存条件幅值。对一个普通混权双分支合流，聚合观察用3个而非6个输出幅值辅助量，仍能排除既有逐门松弛点，间隙3/16。它能继续供下一仿射与 ReLU 使用，但不是完整逐神经元提升的精确 LP 投影，也不是已证新颖性或实际网络收益。

本轮同时排除了一个不成立的捷径：仅凭后继矩阵低秩，就逐槽投影并删除各原输出的槽总和约束。负结论只限制这种精确投影主张，不要求所有健全候选保持完整提升的 LP 精度。

## 非凸语义与共同观察

H(theta) 是完整原 HZ，theta 含原连续因子、全部原二元相位、EQ/LE、物理读出、共享frame和输入decoder。所有原因子和谓词保留。选择两个已认证原相位构成四个代数槽，质量记pi_s；整数原相位时恰有一个pi_s为1。它们使用已有相位乘积编码，全部行仍在一个混合系统中，不创建输入或相位子问题。

设当前原门向量 q=ReLU(h)，其全部原child bits及守卫保留。原下游结构的完整线性消费者银行为v=Wq；未通过W消费的残余、旁路和其他输出不能忽略。观察绑定同一theta，其语义是v_s=pi_s*Wq。不是给每个消费者重新选一份原输入。前三槽作为连续辅助量，第四槽由v减去前三槽恢复。

域元素可写成(H, anchor, observations, certificates)。具体化投影到原输出与原bits，所有观察同时解释为同一theta的读出；空观察嵌入原HZ。只添加具有共同规范扩展的关系时，该投影仍恰为原H。语义包含给出预序，相等取商得到偏序；未声称可计算最佳抽象或完整格。这一观察归约积框架已有先例，候选贡献须落在具体前向规则、结构选择及完整代价上。

## 聚合 ReLU 的统一双边规则

假设已有共同条件输入h_s=pi_s*h，且每个槽认证了L_js<=h_j<=U_js。这里只要求这些界覆盖真实槽内状态，不通过LP对偶、当前松弛点或相位子问题求界。稳定和不稳定情形使用同一结构规则：

```text
U<=0: k=0, d=0
L>=0: k=1, d=0
L<0<U: k=U/(U-L), d=-k*L
```

令D_s=diag(k_js)。由于0<=k<=1，原整数语义满足

```text
k_js*h_js <= pi_s*ReLU(h_j) <= k_js*h_js+d_js*pi_s.
```

因此，对于W的第i行，有共同线性核心t_is=(W D_s h_s)_i，并有

```text
t_is + pi_s*sum_{j:W_ij<0}(W_ij*d_js)
    <= (v_s)_i <=
t_is + pi_s*sum_{j:W_ij>0}(W_ij*d_js).
```

证明仅为按权重符号组合上下界。负权用于下界时乘上界、用于上界时乘下界；不把负项遗漏或取绝对值后当精确项。对每个原整数theta，同时取h_s=pi_s*h、v_s=pi_s*Wq，所有新增行都成立。原H保留，故新增关系既不排除任何原整数状态，也不增加原投影状态。原零点两种合法标签全部保留，输入decoder不变。

将原bits暂作分数只用于查询外包比较。附加这些有效行不会削弱保留的旧LP，但多个聚合观察的分数误差仍可能不来自同一真实分布；这里不声称完整联合凸包或与逐神经元提升等强。

## 仿射和下一 ReLU 如何继续消费

若下一原预激活为h'=Cv+r，其中残余r也有共同条件观察，则逐槽为h'_s=Cv_s+r_s。Affine、Conv、Add与Concat均使用同一原赋值的线性组合；可以继续对原q'=ReLU(h')应用上面的规则，原q'及原bits照旧保留。这个归纳只证明已覆盖接口的健全组合。

若实际下游使用Aq，而不存在已认证A=CW，不能把它改写成Cv。必须增广观察或保留原关系，按完整消费者银行统计成本。类似地，产生t_s需要当前接口覆盖row(W D_s)；若不覆盖，必须另付源条件观察、原读出展开和证据费用。四槽方向的秩至多sum_s rank(W D_s)<=4 rank(W)，但各槽行空间一般不同，秩不等于实际nnz或内存。

选择W须由完整普通网络结构决定，例如一个真实合流后的全部消费者，而非实例身份、历史标签、margin或solver状态。当前仅有数学规则，尚未实现真实网络的统一观察选择器，也未证明宽卷积接口有净节省。

## 保住已有严格控制

取原父u=ReLU(x)、v=ReLU(y)，x,y在[-1,1]，父active bits为alpha,beta，delta=alpha*beta。原两个child为

```text
r=ReLU(u+v-3/4)
t=ReLU(u-v+1/4)
```

下游只消费观察Z=r+t，W=(1,1)。四槽聚合上界分别是

```text
00: pi00/4
10: 5*u10/4+pi10/4
01: pi01/4
11: 5*u11/4+5*pi11/8.
```

相加得到Z<=1/4+5*u/4+3*delta/8。已有原生控制的分数松弛点取u=v=1/4、alpha=beta=1/2、r=5/16、t=5/8。由delta<=alpha，右端最多3/4，而Z=15/16，故排除间隙3/16。这里的点是旧LP松弛控制，不是具体网络反例或ADV。

完整逐child条件输出接口需6个辅助幅值和24条槽包络；单一聚合观察输出部分只需3个和8条。共同父条件接口不变、另计。这个比较对象是D085的完整条件输出方案，不是只生成汇总上行的D086代码。D086已经能推出同一个Z上界，本轮没有声称更强；新增的意义是保留一个可供下一块消费的观察接口。

## 为什么不能只按秩作精确投影

如果想精确保留完整槽提升的查询投影，待删辅助量z的全部外部用法必须经过Wz，并且局部系统C必须替换为C_W(theta,y)=exists z:C(theta,z) and y=Wz，附具体回构。各原q_j的sum_s z_js=q_j也属于C，不能遗漏。

一个普通混权负控取四槽质量均1/4、q=(9/10,1/10,1/10)、W=(1,-2,3)。原系统为0<=z_js<=1/4、sum_s z_js=q_j。逐槽单独投影给y_s在[-1/2,1]，再加sum_s y_s=Wq=1，会允许y=(7/10,1/10,1/10,1/10)。但共同见证要求第一槽

```text
y1=z11-2*z21+3*z31 <= 1/4+3/10=11/20 < 7/10.
```

全部质量为正，q在区间内部，不依赖极端数值。这个反例否定删掉回接等式的投影主张，不否定前述保留原H的健全聚合增广。

更一般地，对正权的四槽容量运输系统，精确投影需sum_s y_s=sum_j w_j q_j，并对每个槽子集S满足

```text
sum_{s in S} y_s <= sum_j min(w_j*q_j, w_j*sum_{s in S}pi_s).
```

这是容量运输的割条件，下界由补集得到。但16个子集表达式不等于16条线性行：sum_j min(a_j,b_j)是2^n个仿射组合的最小值；在一个槽子集质量为1/2、q_j独立变化时，各分段均可出现。保留原q且不加辅助量的精确线性展开可能膨胀。它不证明所有低秩候选都昂贵，更不要求新候选保持完整提升的全部LP精度。

## 完整费用和设备执行形式

直接保存p个观察，输出部分增加3p个连续辅助量、8p条LE。若原观察已有物理坐标、每个内联核心t_is的支持数为n_is，则保守nnz上界为30p+2*sum_is n_is。若观察仅是原HZ读出而非独立列，其第四槽内联、系数合并和共享存储另计，不能假装物理坐标免费。

还必须支付共同源接口、可靠槽界、W及系数生成、精确基选择或稠密化、有限辅助因子归一化、512位算术、全部原bits与谓词、终端转换及输入重构。若每个观察都重新复制完整source，就可能失去所有节省。这里未取得完整成本资格。

设备可将四槽堆叠，以批量稀疏线性作用生成W D_s h_s，按W符号归约偏置，再生成双边行。共用同一线性核心可避免上下界各算一次。可靠舍入、主机设备共存、临时buffer和终端查询仍需验证；本轮没有GPU运行，不能称GPU加速成果。

纸面关系目前采用精确算术。D086向外舍入后的辅助量不能未经误差处理就当作每个可行点上的精确乘积接入这里；后续实现需证明整段共同规范扩展及逐行误差补偿，而不能继承组件证书后省略这一步。

## 已有研究和当前决定

ReLU的同斜率双边包络已见DeepZ的§3.1，按权重组合误差也是仿射算术的既有机制。[DeepZ原文](https://files.sri.inf.ethz.ch/website/papers/DeepZ.pdf) 分组扩展与紧度的权衡已有强混合整数表述先例。[Tsay等原文](https://arxiv.org/abs/2102.04373) 本文借其可计算规则，但原非凸HZ不被凸域替换，不删除原相位，也不导入动态分离、OBBT、BaB或backward/dual rescue。

下一可证伪的候选是完整消费者银行的共同核心复用与有限观察前向传递，不是上述包络公式本身。必须比较原HZ、原HZ加同样后果、完整逐门条件提升和本观察接口；若只是相同系统换名或在真实块上不省完整代价，则保留负结论。当前没有新颖性证明、真实网络收益、shadow或全量回放，不声明PLDI级成果。
