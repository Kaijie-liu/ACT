# 抵消坐标和循环关系的非创新边界

这两项只读检查阻止将已有神经代数重新命名为新域。没有构建 wrapper 或接入其他算法。

## 共同抵消坐标与旧门图同构

保留共同非负原子 a、原父域、全部 bits、守卫和 decoder。设一个混权预激活 f=P(a)-N(a)，P,N>=0，可靠界 l<0<u。定义 q=P-t。旧四行 ReLU 编码逐行变为

```text
t<=P,  t<=N,
t>=P-u beta,  t>=N+l(1-beta).
```

原 beta 为 1 时 t=N<=P，为 0 时 t=P<=N，故 t=min(P,N)，q=ReLU(f)，零点两标签都保留。额外要求 t>=0 恰是旧有效行 q<=P。Affine/Conv 可在共同原子上按正负系数组合新的 P/N，Add/Concat 不复制身份，下一 ReLU 重复此精确规则。因此它可组合且非凸，但只是旧图坐标同构。

若 P/N 的合并原子系数支持不交、非零总数为 s，双方四行均为一个连续量、一个原 bit、2s+6 nnz。t>=0 可比显式 q<=P 更稀疏，但全部消费者改为 CP-Ct+Da，必须支付 CP 的填充；若为避免填充仍物化 q，则新增 q+t=P 的等式与额外坐标。不能把局部一行稀疏化报为新域能力。

普通混权控制 a1=ReLU(x+y)、a2=ReLU(x-y)、q=ReLU(a1-a2+1/4)，在 (x,y)=(1/2,1/10) 有 P=17/20、N=2/5、q=9/20。两条非平行门同时 active，不能套用 P*N=0 的旧精确消元。D011 已有 tropical 双轨道与共同因子取消，D014 已有互斥正负幅值规则；本轮不重报。

## 标量全 pair 已蕴含全部 smooth cycles

对有限标量数据 (g_i,q_i)，假设每一 pair 满足

```text
(q_i-q_j)^2 <= (q_i-q_j)(g_i-g_j).
```

重复 g 必有相同 q。按 g 排序，在相邻点间线性插值 q，并在两端作常数延拓；每段斜率在 [0,1]，得到单调、1-Lipschitz 连续函数 phi。积分得到凸 C1 函数 F，且 F'=phi 为 1-Lipschitz。因此这批数据已满足凸 1-smooth 梯度的所有普通及加强循环单调关系；再增加长 cycles 不会在这个标量、无预先固定势值的问题上增加精度。

此限定不能推广到一般向量梯度，或给定 F 值的插值问题。[Taylor、Hendrickx、Glineur 的 Corollary 1 与 Remark 3](https://arxiv.org/pdf/1502.05666)给出 smooth 插值与循环条件，并指出一般情形两点条件不足。本节一维充分性由上述直接构造给出，不把文献的一般不充分性反向套用。

普通例子：x,y 属于 [-1,1]，g=(x+y/4+1/2,-x/2+y+1,x-y/2-1)。三个门非平行且 crossing；源中心处 g=(1/2,1,-1)，原相位为 110。假幅值 q=(3/4,5/4,0) 满足非负、epigraph、off-mask、原符号 guards 和全部 pair。排序数据为 (-1,0)、(1/2,3/4)、(1,5/4)，相邻斜率为 1/2 与 1，故也满足所有上述 cycles。

然而混权与 live skip 后继 ReLU(2q1-q2+q3+x/10-1/8) 在同一中心真实为零，假点给 1/8。这是固定源绑定的损失，不是整个盒的能力分离；原精确单门图已拒绝该点。加入准确锚 (0,0) 的 pair 关系得到 q_i^2<=q_i g_i，结合 epigraph 恢复旧互补图；它不是免费的线性终端。

因此不实现“长 cycles 修复来源损失”的路线，也不把一般势或互补性本身包装为强 Neural-HZ。既有共同源、相位和完整查询问题仍须在新定义中真正解决。
