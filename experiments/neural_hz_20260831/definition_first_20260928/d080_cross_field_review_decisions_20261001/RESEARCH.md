# 跨领域文献对 Neural HZ 研究方向的具体影响

结论是继续从 HZ 之外借鉴，但不再把扩充书单作为研究成果。当前应优先研究相位与连续幅值的联合关系如何跨普通 Conv、ReLU 和残差块被后继使用；连续消元和构造压缩保留为支撑，不重新取代定义主线。

这是面向项目问题的初步机制综述，不是穷尽式系统综述，也没有证明新的抽象域或实际网络增益。此前的[跨领域研究](../d073_cross_domain_research_focus_20261001/RESEARCH.md)已经覆盖其中若干方向，本次重读不记作首次发现。原 HZ 已能表达共同依赖和精确 ReLU；需要创新的是适合神经网络的关系语言、变换或精确简化及可计算查询，而不是声称原 HZ 缺乏表达能力。

## 一个从外部理论看清的研究问题

互补系统把 q=ReLU(g) 写成 q>=0、n=q-g>=0、q*n=0。这个等价式是已有结果，不是我们的创新。它提供另一种看法：输出 q 与负缺口 n 是互补的两个量，并由同一个 g 联系起来；不能让多个消费者各自选择不同的 g。

重复非线性研究给出另一种联合信息。对 q_i=ReLU(g_i)、q_j=ReLU(g_j)，已有斜率性质给出

```text
(q_i-q_j) * ((g_i-g_j)-(q_i-q_j)) >= 0.
```

这不是直接可用的新 HZ 线性行。项目需要回答的是：在保留原非凸相位和全部守卫的前提下，是否存在结构统一、代价受控的关系表示，使这类联合信息经过混权仿射、ReLU、分叉和 Add 后仍可利用？把该二次式加入文件、换用 SDP 或重新命名负缺口都不算回答。

[共同幅值合同](../d078_shared_witness_contract_20261001/DEFINITION_AND_BOUNDARIES.md)已有严格控制：各后继分别使用局部凸包，即使相位信息一致，也可能缺少共同连续幅值解释。这是局部查询组合的缺口，不是原精确 HZ 的语义错误。它应成为跨领域候选的定向检验之一，而非要求任何候选构造全网 ideal hull。

## 研究顺序和可交付标准

第一优先是跨块关系组合。选择普通宽混权 Conv–ReLU–Conv–ReLU 和残差汇合，明确有限观察量的语义，给出一个可执行的统一前向变换，证明其保留哪些联合关系、放弃哪些信息。所有消费者必须基于同一原 source/frame；全部原 bits 和零点两种标签保留。

第二优先才是压缩这一关系表示。若要消去连续辅助量，必须同时处理原谓词、活跃观察、证明依赖和输入重构。固定非负行组合与准确仿射代换可交换，但这是已有代数事实；重新运行启发式关系生成器不保证得到同样强的证书。不能把支撑性代换重新升格为唯一创新路线。

候选进入实现前应同时交付：域元素及具体化；与原 HZ 和适用先行工作的明确区别；至少一个普通后继块上的健全变换或精确简化命题；包括传播、辅助量、谓词、终端查询、decoder、GPU 主机设备共存和可靠算术的完整成本。GPU 适配是研究目标，本文没有证明性能。

不要求每个能力候选都减少 nnz，也不要求任意深度精确闭包。它必须显示已知结构规则之外的实质贡献或完整成本优势；与原 HZ 加相同行等强时如实报告。[Mao 等的表达能力研究](https://arxiv.org/html/2410.06816v4)，Theorems 3.3、4.2，是受限逐层/跨层凸松弛的不完备性对照，不证明本项目或完整 MILP 不可能提升，也不作为追逐最坏特例的新门槛。

## 本轮审查纠正

一个未落地的纸面建议曾尝试用补门 n=q-f=ReLU(-f) 的上界导出 q 的下界。审查已撤回该推理：对两个补门取得上界后，代回仍得到 q+p 的上界，并不会变为下界。它不能作为混权消费的证明，不进入候选或测试。

此外，原门的共同容量不能直接分配给任意 fan-out。多消费者可以同时合法使用同一幅值；若要合计输出预算，须证明联合关系，而非凭变量共享假定容量可加。已有正系数关系组合可作为支撑，不单独宣称定义创新。
