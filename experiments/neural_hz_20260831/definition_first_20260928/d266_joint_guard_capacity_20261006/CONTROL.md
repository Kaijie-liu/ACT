# 严格分离旧共同残余行并跨越后继激活

这是精确纸面控制，不是 benchmark 或具体反例 ADV。新关系必须与同一完整旧状态比较，而非只比较两个右端。

## 同一原来源网络

取原 A∈[0,1]^4、s,t∈[-1,1]，x1=A1-A2、x2=A3-A4、qi=ReLU(xi)，a=17/20、b=3/50、tau=1。定义

```text
461/4000 < R < 51/400,
r=(R/2)*(s-t), e=(R/4)*(s+t),
z=a*(x1+x2)+b*(q1+q2)+r, d=q1-q2+e,
Y1=ReLU(z+d), Y2=ReLU(z-d),
F=2*q1-x1+2*q2-x2+(2/5)*(Y1-Y2-(x1-x2)/2),
Rout=ReLU(F-83/40).
```

原共同源给 J=B_e=R、独立付款2R。eta10minus=0、eta01plus=R-9/100、M=s0=47/20。新 Gstar=R，旧 JP 右端467/100+2R，新 JG 右端119/25+R。

## 显示点及完整六产品

取 A全1/2、s=t=0、x1=x2=0，原四个父子标签均1/2，q1=q2=99/200，Y1=16137/20000、Y2=11187/20000。F=2079/1000，Rout=1/250 并令该后继门标签为1。这是旧松弛点，不是合法原整数图输入。

其容量左端9801/2000。整个开区间满足旧 JP 接受、新 JG 排除。六产品赋值为 c12=1/200、c21=-1/200、d12=99/200、d21=0、v1=R/2、v2=-R/2。全部24条 MC 合法；三条 X 的 T=1/100、U=99/100、Dabs=99/50。K=17/2000+297/10000+R，故 QG 上行成立只需 R>=2443/25000，整个所选开区间严格满足；下行也成立。源恒等式 r=e=0 没有被丢掉。

原单门图松弛的全部四门标签和来源仍保留。D263 完整单子门前缀分布、凸化父域上的双子门分布均取 s=t=0 原样可用。D052 首四门固定匹配也仍接受：R=1/8 时 child 对的 P=141/80，(kappa0,kappa1,U)=(-16/25,201/200,-16/25)，显示 Ysum-P=-3963/10000，右端73/400、余量1447/2500；反向相同。父子匹配的剩余源区间从旧±1/10扩大到±R，故不加强其原证书。测试不将这些纸面分布的继承误称为真实模型执行。

比较对象不含新的后继门对、多轮闭包、完整共同源 RLT；这些更强方法可能也排除显示点。

## 后继激活的实际消费

由于 Dabs<=2 且 1-(2/5)*s0=3/50>=0，新行推出

```text
F <= 2+(2/5)*(3/50+R) < 83/40.
```

所以原后继 ReLU 图给 Rout=0。R=1/8 时旧 rhs=4.92，新 rhs=4.885，显示左端4.9005，新行严格差31/2000；新 F<=1037/500=2.074，而旧显示 F=2.079。

实际组件接收 stored binary64，不把0.85冒充17/20。定向测试将每个浮点参数先精确转 Fraction，在 R=15/128、1/8、65/512 三个预定普通成员上重新检查全部系数、旧可行性和新严格界；它们不属于候选运行时参数搜索。理论开区间证明使用以上有理参数，与浮点实例的逐点证据分别标记。

## 宽残差族的严格分离

沿 D265 普通共享来源，取 a=7/8、b=1/16、tau=1，

```text
u=(2/3)*(Q3+Q4)+S1-1,
v=(2/3)*(Q4+Q5)+S2-1,
r=kappa*(u-v), e=(kappa/2)*(u+v),
Q3,Q4,Q5 in [0,1], S1,S2 in [0,2/3].
```

这些 Q 和 S 保留原来源及原图，不是新独立误差。令 x1=x2=0、q1=q2=1/2、父标签1/2；固定 Q3=Q4=39/40、Q5=1/2、S1=13/20、S2=131/360，全为普通区间内部值。得到 u=19/20、v=25/72，r=217*kappa/360、e=467*kappa/720。显示 Y1=25/8、Y2=0、子标签 gamma1=5/7、gamma2=0。

两子门的更紧普通同源范围可用

```text
L=-7/4-5*kappa/3, U=31/16+5*kappa/3.
```

父部分由两个物理 ReLU 的三个顶点给 [-7/4,31/16]。共同残余 (3u-v)/2=Q3+(2/3)Q4-(1/3)Q5+(3/2)S1-(1/2)S2-1 的范围恰为 [-5/3,5/3]，另一子对称。必须计入父点 x1=1、x2=0 的上界31/16；不能误用两父都为1的15/8。因此 kappa=3/2 时正确 U=71/16，而不是35/8。

在 kappa=3/2，实际预激活为931/480和-1/160；r=217/240、e=467/480。两个子门的全部普通四行 LP 图成立，其中 Y1<=U*gamma1 的余量5/112，Y1<=g1-L*(1-gamma1) 的余量97/3360。额外正 ReLU Q 的原前激活可直接取相同 Q，原标签取1，保留原图。六产品取 c12=c21=0、d12=d21=1/4、v1=v2=r/2；全部 MC 可行，三条 X 合法，K=0，旧 QG 双侧右端157/32超过25/8。

旧 JP 右端93/8接受显示容量63/8，新 JG 右端125/16排除它，严格差1/16。这不是只观察普通冗余证书失效，而是同一完整指定旧系统的具体可行延拓。

保持上述全部显示来源、父子坐标和标签不变，只让

```text
3/2 < kappa < 97/64.
```

预激活为1/16+901*kappa/720和1/16-11*kappa/240。普通 LP 仍成立；v_i 按原r/2更新。QG右端10*kappa/3-3/32、旧 JP右端37/8+14*kappa/3都继续接受。新容量右端77/16+2*kappa。固定普通后继

```text
Fwide=(19/8)*Dabs+Y1-Y2-(x1-x2)/2,
Rout=ReLU(Fwide-251/32)
```

在新系统上恒为0，而旧显示 Fwide=63/8、Rout=1/32。测试检查精确 dyadic 成员 kappa=3/2，开区间由上述解析不等式证明。

宽族的比较不包含完整单子门来源 hull、全部 D052 组合或完整 RLT，不能借用小残差族较强参照的资格。实际红队发现，kappa=3/2 的宽显示点被 D052 child 匹配的一条旧行排除：P=1537/480、kappa0=-3/16，旧行给 Y1<=P+kappa0*gamma1，显示点超过它191/3360。定向测试明确保留此负证据，不宣称这个宽点胜过 D052。两类正控的比较范围分别记录；都不是原始 CIFAR/Tiny 模型收益。
