# 多消费者共同残余包络的纸面组合范围

这份后续研究记录不属于本轮冻结候选或执行资格。它说明为什么仅保存一个更小的常数右端还不够，也界定一个有限组合接口的已证范围与已有工作的重叠。没有执行候选、solver或模型。

## 在求上界之前保留共同来源函数

沿THEORY.md，令 Astar=max(A10,A01)，保留

```text
Psi(xi)=max(|rho(xi)|,Astar)+2*ReLU(e(xi))
       =max(rho,-rho,rho+2*e,-rho+2*e,Astar,Astar+2*e).
```

rho、e和全部物理读出必须引用同一原H及同一来源键。D266逐点证明实际给出

```text
P <= C + Psi - sum_i((M-C_i)*deficit_i),
C=2*M+abs(Bq)+max(Hc,0), deficit_i>=0.
```

这里P是JG物理左端，非新增自由符号。原H、原相位、EQ/LE、所有消费者和decoder全保留。只保存Psi的区间或若干旧相位期望会丢掉组合需要的信息；保存这六个平面本身也不等于已实现新域。

## 固定多消费者上界

若实际消费者的原仿射身份已经认证为 h_j=ell_j+sum_m(theta_jm*P_m)，其中theta_jm>=0，则

```text
h_j <= sum_m(theta_jm*C_m)+ell_j+sum_m(theta_jm*Psi_m).
```

所有平面先按共同来源合并再求支持，不能为每个消费者复制一个独立来源。固定每组最多两个包络，至多36个仿射支持即可求该组在声明源盒上的精确最大值，前提是仿射系数和盒精确；实际舍入必须可靠外包。36是固定代数平面的组合，不是输入或原相位split。不能将36乘全部消费者的工作隐藏成常量成本。

存在明确组合信息收益：rho=s-t，e=s+t，s,t∈[-1,1]，第二个包络用-e，且Astar<=0时，两个包络各自最大值均4，但共同和

```text
Psi_plus+Psi_minus=2*|s-t|+2*|s+t|<=4.
```

分别付款得8，共同付款得4。它只是支持信息正例，尚未构造相应真实神经块或证明网络增益。

负消费者系数需要独立有效反向关系，不能直接乘一个上界。交换子门也不能未经证明将整条JG取负。若实际h_j<=U_j已可靠认证，下一原ReLU满足q_j<=max(0,U_j)；U_j=0时仍不能删除原零点的合法双标签。此处只给有损上界，不给任意新相位的gamma*e精确闭包。

## 固定分组的可核损失

设同一紧致源盒D上的组函数phi_g连续，U_g=max_D phi_g精确且可达，L_g是其有效下界。则

```text
0 <= sum_g U_g-max_D sum_g phi_g
   <= sum_g(U_g-L_g)-max_g(U_g-L_g).
```

取宽度最大的组gstar，在它达到U_gstar的同一个源点，其他组至少为L_g，立即得到右侧。对于有限max-affine包络，U_g可由各平面的盒支持求得；L_g可取各平面盒下界的最大值，不必引入支持LP。

该式假定U_g确为组最大值，不能把带未知松弛量的数值上界直接代入并保留同一误差保证。使用可靠外包时必须另计其上侧误差，或提供可达见证下值。此损失只相对于声明盒上的这些包络，不是相对于真实H或网络的最优值；盒上的最大点可能违反原相关谓词。
