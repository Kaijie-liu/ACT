# 与已有混合域及多神经元方法的区别和未完成项

本轮有限成果是联合处理同一残余与相位守卫误差的跨层容量定理，并给出指定旧六产品系统加旧共同残余行之外的严格分离。它不能凭“保留非凸性”“共享乘积”或“无辅助列”主张新的抽象域，更不能宣称已经达到 PLDI 级新颖性。

本地 D001 已定义相位依赖生成元和共享电路；D006 说明完整守卫归约可能隐藏原可行性问题。D027 已有相位条件残余的混号消费者规则；D029、D035 和 D251 已否定有限旧相位矩免费确定新相位幅值。D233 的共同点库能保更完整信息，但其来源生成和存储代价必须支付。本轮不重记这些已有成果。

[Sharp Hybrid Zonotopes 第 II C 和 IV 节](https://arxiv.org/html/2503.17483v2) 已将 RLT 条件乘积用于 HZ，并区分相同整数集合的不同松弛表示。因此本轮只有特定结构规则相对指定有限参照的增量，不是一般相位乘积思想的首次提出，也没有证明优于完整 RLT。

[Anderson 等的 Strong Mixed Integer Programming Formulations 第 3 和 5 节](https://arxiv.org/pdf/1811.01988) 研究共同输入的析取与单 ReLU 强表述。无新连续列不是本轮独有的性质；单门的理想表述也不能自动解决跨门共享依赖。

[PRIMA 第 3 节](https://arxiv.org/pdf/2103.03638) 通过多神经元联合凸近似强化网络认证。它是重要信息强度参照，但本轮保留原 H 的显式非凸相位，不运行其区域划分过程；局部联合关系也不自动给出任意层组合的共同来源语义。

上述文献是排重边界，不证明本候选已经新颖。未完成项仍包括：能实质改变域接口的有限多消费者组合定理、原生谓词全程消费、真实网络净收益、完整成本、GPU 的可靠实现以及 smooth/Transformer 的适用算子。不能拿四项测试或一个严格控制替代这些要求。
