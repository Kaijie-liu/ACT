# 相位展开的终端松弛与共同幅值比较

本轮完成对前一候选 Gamma_k 的关键终端比较。结论是：在来源、界和守卫匹配且旧松弛点能进入共同尾盒时，逐轮独立 McCormick 展开不能排除任何旧逐门 LP 点。一个普通有偏置两门网络还给出严格的最终输出支持差，而非仅一个辅助变量差。已知的一条条件幅值关系可以恢复该例的完整物理图凸包，因此它是必须面对的既有比较对象，不是新域创新。

结论只针对明确的连续松弛，不能外推为当前整数终端的运行时间定理。原二元变量始终保留在域语义和实际终端中；文中的分数相位仅用于审查松弛强度。没有候选代码、数值执行、求解器调用、模型调用或 GPU 运行。

## 原定义和匹配的参考系统

沿用[相位级数定义](../d121_source_coherent_definition_audit_20261002/PHASE_SERIES.md)的固定共同前沿 H0、原相位 beta、源 f=A x+c 和严格下三角 W。原 ReLU 块是

```text
g=f+Wq,
q_i=ReLU(g_i),
beta_i 是原门的合法 0/1 相位，零点两种标签均保留。
```

定义中的 Gamma_k 用同一有界连续 eta 和全部原 bits 表达

```text
Phi(eta)=diag(beta)(f+W eta),
q=Phi^k(eta), eta in B_t,
t=(I-|W|)^(-1) hbar, hbar>=|f|。
```

它还包含同一个最终 G(x,beta,q)，包括原符号守卫、非负、坐标界及保留的其他谓词，不暗中重复被替换的全部门输出等式。本轮不改动该冻结定义。

设 P 是诊断用旧 LP：保留相同前沿、最终 G 和所有其他指定旧约束，令 beta in [0,1]，每门具有有效 l_i<=0<=u_i 及标准四行

```text
q_i>=0,
q_i>=g_i,
q_i<=u_i beta_i,
q_i<=g_i-l_i(1-beta_i)。                         (H)
```

另有 l_i<=g_i<=u_i。源或其他旧相位之间可有任意既有线性关联，不要求独立。下面的结论不将 P 当作整个网络图的联合凸包，也不将 P 自动等同于全部实际浮点生产约束。

逐轮乘积形式 Q_k 使用

```text
u^0=eta,
s^j=f+W u^(j-1),
u_i^j=beta_i s_i^j,     1<=j<=k,
q=u^k。
```

每个乘积分别用区间 [L_ji,U_ji] 的四条 McCormick 行替代。区间必须对所声明包围的完整阶段关系有效，不能偷用仅对真图成立的界。除显式共享的 x、beta、eta 和线性连接外，不额外假定不同乘积具有共同的条件连续解释。

## 固定点复制定理

要求满足以下匹配条件。

1. 每个 P 点的 q 都属于 seed B_t，且复制到所有 u^j 后满足规定的中间坐标界。只证明真实输出在 B_t 内还不够；必要时将同一有效界同时交给旧参考。
2. 各阶段的乘积关系在复制点上均接受旧单门关系。一个简单充分条件是 L_ji<=l_i<=0<=u_i<=U_ji。仅 s_i^j=g_i 落在阶段区间内，不足以推出这个条件。
3. 前沿、原相位身份、最终 G 完全共享。没有未计入比较的跨轮或共同乘积约束排除下面的复制扩展。

则

```text
P subset projection_(x,beta,q)(Q_k)               对每个 k 成立。
```

证明先检查单门。由 (H) 得到同界乘积包络

```text
q>=l beta,               因为 q>=0>=l beta，
q<=u beta,               是原上行，
q>=g-u(1-beta),          因为 q>=g，
q<=g-l(1-beta),          是原上行。
```

将 l 降低或 u 提高只会放宽这四行。原四行也蕴含相位守卫：q>=0 和最后一行给 g>=l(1-beta)；q>=g 和 q<=u beta 给 g<=u beta。

现在对任意 (x,beta,q) in P，取

```text
eta=q,
u^j=q 对所有 j，
s^j=g=f+Wq 对所有 j。
```

所有线性连接同时成立，每个乘积包络由上一段成立，seed、阶段界及最终 G 由匹配条件成立。这是对全部旧点的构造性扩展，不依赖求解器、相位枚举或输入分割。

如果在 Q_k 之外还完整保留旧 P，那么

```text
projection(P intersect Q_k)=P。
```

从而对任何只使用最终物理坐标的线性最大化查询，Q_k 的精确 LP 最优上界不可能优于 P；与 P 相交则相同。最小化方向相应也不能更强。即使精确多项式 Gamma_N 已恢复真实块图，这个连续乘积松弛仍能留下旧点。不能把精确语义的嵌套或有限精确性借给未经证明的终端松弛。

## 更紧阶段界和额外门行的边界

更紧的阶段界可能破坏上述充分条件，因此不能笼统声称所有展开都无效。但若唯一新增信息是各阶段的标量 s/u 界，这些界也适用于原真实 g/q：真实块在 eta=q 下每轮都是同一个固定点。

具体地，可以把各阶段 s_i 的区间取交，作为旧门 g_i 的共同界；把 seed 和阶段 u_i 的界也交给旧 q_i，再用这些共同界重建旧门包络。若交集变成稳定门，应按同一稳定图关系比较，仍不删除其原身份。这样得到的匹配旧参考再次有固定点扩展。新界的生成可能有独立算法价值，但不能将它的收益归给无附加信息的展开本身，也不能省略其证明和成本。

如果每轮另外加入完整 ReLU epigraph 或守卫，固定点复制对同界旧 P 仍成立。但这不一定是原 Gamma_k 全部伪状态的合法 lowering：中间 s^j 未必与最终原预激活 f+Wq 同号。这种更强系统只能在另证后称为包含真实图的替代外包，不得混称同一个 Gamma_k 的等价终端。

本定理不排除经过证明的联合 seed 关系、共享源乘积、Boolean 与连续量的联合恒等式、不同的可靠支持算法或有用的整数求解实现。它也不授权把实际域内的原 bits 连续化。结论的对象是一个匹配的松弛比较，而非所有 Neural-HZ 定义。

## 普通两门网络的严格输出差

取 x in [-1,1]，两门偏置均非零：

```text
q1=ReLU(x+1/4),
q2=ReLU(q1-1/2),
F=5q1-3q2-2x。
```

原门准确范围为 g1 in [-3/4,5/4]、g2 in [-1/2,3/4]。两门都存在严格 active 和 inactive 的输入区域。真实第二输出也等于 ReLU(x-1/4)，因此

```text
x<=-1/4:           F=-2x<=2，
-1/4<=x<=1/4:      F=3x+5/4<=2，
x>=1/4:            F=2。
```

这是纸面分段证明，不是运行时 split。真实最大值恰为 2。

旧逐门四行却允许

```text
x=0,
beta1=1/2, beta2=1/6,
q1=5/8, q2=1/8,
g1=1/4, g2=1/8,
F=11/4。
```

第一门两条上界均为 5/8；第二门 q2=g2=1/8，active-side 上界 (3/4)beta2=1/8，另一上界为 13/24。非负、epigraph、相位守卫和全局坐标界全部成立。比较点预激活非零，源 x 在盒内部，不靠数值极端情形。

这个网络的 hbar=(5/4,1/2)，共同尾界 t=(5/4,7/4)。seed 允许负 eta1，因此第一轮 s2 必须允许 [-7/4,3/4]，不能偷用只对真实网络成立的紧范围 [-1/2,3/4] 覆盖整个 seed。对所有轮均使用前者是可靠的；第一门使用 [-3/4,5/4]。这些阶段区间不比旧门界窄，取 eta=q、每轮 u=q 即得到合法扩展。

所以独立展开对每个 k 都允许 F=11/4；k=2 已是此块的精确多项式层级，也不例外。它不能证明本例真实安全的 F<=5/2，而差距不是仅存在于辅助变量坐标。这是纸面精确有理对照，不是已执行的 CERT 或 ADV。

## 一条已有幅值关系恢复此例完整物理凸包

对于普通结构 q1=ReLU(g1)、q2=ReLU(b q1-d)，b,d>0，原父相位 beta1 给出

```text
b q1-q2<=d beta1。                              (A)
```

beta1=0 时 q1=0 且 q2=0；beta1=1 时 bq1-q2=min(bq1,d)<=d。合法零点标签仍全部满足。证明按两种值说明同一条线性有效关系，不引入运行时相位求解或新分支。

本例 (A) 是 q1-q2<=beta1/2。旧伪点左边 1/2、右边 1/4，严格违反。旧第一门上行等价于

```text
q1+(3/4)beta1<=x+1。
```

将 (A) 乘以 3，再与该行乘以 2 相加，立即得到 F<=2。没有新增连续或二元变量；在 q1、q2、beta1 已有物理列时只新增一行三个非零系数。latent 展开、等式型 slack、界证书、舍入和全网费用仍另计。

更强的公平比较是整个 (x,q1,q2) 图凸包。真实图由四顶点连成折线：

```text
A=(-1,0,0), B=(-1/4,0,0),
C=(1/4,1/2,0), D=(1,5/4,3/4)。
```

四面体的四个面为

```text
q2>=0,
3q1-5q2>=0,
q1-x-1/4>=0,
2-5q1+3q2+2x>=0。                               (T)
```

充分性可直接构造四个非负质量，不依赖数值求凸包：

```text
lambdaA=(4/3)(q1-x-1/4),
lambdaB=(2/3)(2-5q1+3q2+2x),
lambdaC=2q1-(10/3)q2,
lambdaD=(4/3)q2。
```

由 (T) 它们非负，和为 1，并且 lambdaA*A+lambdaB*B+lambdaC*C+lambdaD*D=(x,q1,q2)。前三面已由旧逐门 LP 推出：第二面用 q2<=3beta2/4 与 q2<=q1-beta2/2 消去 beta2，第三面是第一门 epigraph。第四面由 (A) 导出。因此旧 LP 加这一行，投影后已经是完整物理图凸包，对所有这些坐标的 affine 查询都精确。

这不声称原相位也保留在投影中的 formulation 是 ideal，不意味着整套方法对一般 CNN 精确。更重要的是，(A) 已被 [D036 的跨层幅值定理](../d036_descendant_amplitude_20260930/THEORY.md)覆盖，取 a=b、L=H=-d 即可。它属于既有 perspective/RLT 型信息，不能作为本轮新的定义成果，也不值得为这个小例重开一套组件。

## 仅共享 Boolean 路径乘积也不足

本例真实相位满足 beta2<=beta1，且 beta1 beta2=beta2。旧伪点已经满足相位次序。

即使将展开统一为 pi=beta1 beta2、pi=beta2，并写

```text
q2=v-beta2/2,
v=pi*(x+1/4)，
```

再分别使用 Boolean 与连续乘积的 McCormick 行，仍可取

```text
pi=1/6, v=5/24。
```

Boolean 行接受该 pi；连续因子 x+1/4 in [-3/4,5/4] 的四行给 v 的下界不超过 0、上界分别为 5/24 和 7/8，故接受 v=5/24，并恢复 q2=1/8。只是合并路径单项式没有补回条件幅值关系。

真正缺少的是相位与连续源的共同解释。例如中间相位 beta1-beta2 为 1 时 g1 in [0,1/2]，其对应幅值界可导出 (A)。这正是旧条件连续关系的内容，而非有限级数的新自动性质。

甚至完整的联合相位质量也可以写出来：lambda00=1/2、lambda10=1/3、lambda11=1/6、lambda01=0。它们本身以及平均源 x=0 都可由真实输入实现，分别在 x=-1/3、1/8、3/4 赋予这些质量；三个输入均在内部且相位严格。该真实分布的输出均值为 (7/24,1/12)，并不实现伪点的输出和乘积矩。伪乘积给 v11=5/24、v10=q1-v11=5/12，要求 phase10 中 g1 的条件均值为 (5/12)/(1/3)=5/4，违反该相位的上界 1/2。可实现的相位分布和源均值，不保证所存幅值具有同一实现；有限相位记忆不能跳过这一条件连续合同。

## 因果深度与完整费用的修正

直接展开的 kN 个乘积量和约 4kN 条包络行只是一个实现账，不是所有实现的下界。令 d_i=1+max_{W_ih!=0}d_h，无父门时 d_i=1，D=max_i d_i。由前向归纳，j>=d_i 时精确函数 u_i^j 已与 eta 无关，并等于原 DAG 中的第 i 门函数。故 D<=N，k>=D 已足以恢复该块，而不必机械展开 N 轮。

在精确符号图中共享这些已经相同的函数，并删除不再被最终输出使用的中间副本，k>=D 时可回到 N 个原门及原线性依赖。固定最终 G、原 bits、前沿和 decoder 均保持。若另加了早期轮次观察或谓词，须先证明可消去；若源被独立克隆，也不属于这个结论。

先代数合并再做松弛，与先建立独立 McCormick 后假定它们已经相等不是同一操作。前者可避免 kN 的冗余账，但恢复的正是原图，尚无新的域强度或成本优势。

naive 展开还要支付 k 次 W/source 作用、阶段界、seed、全部原相位和守卫、最终 H0/G、辅助量和证据，以及主机设备副本、终端矩阵与见证重构。D 层的同步形式可以映射到网络原有因果深度；不能据此声称全 GPU 求解或实测加速。无更强连续松弛也不等于某一 MILP 实现必然更慢，整数运行时间需要独立预注册实测。

## 先例与研究结论

[D012](../d012_phase_budget_20260928/D012_RESULTS.md)证明的是独立交叉 charge 乘积无增益；本轮是有线性因果连接的重复展开中的固定点扩展，两者范围不同。[D013](../d013_budget_quotient_20260928/D013_BUDGET_QUOTIENT_AUDIT.md)已审查 Boolean 商及显式路径爆炸，不能把本轮再次发现相位兼容性称为新代数。

[Sharp Hybrid Zonotopes](https://arxiv.org/html/2503.17483v2)的 Remark 2 区分集合与表示的连续松弛，§II-C 和 §IV 给出 Boolean 及连续因子的 RLT 提升。本轮的研究推论是：共享名称或精确多项式等式，不自动具有这些联合提升的强度。

[Mixed polynotopes](https://arxiv.org/abs/2009.07387)已使用连续和 Boolean 类型符号表达共同多项式依赖；[Exponent Relaxation](https://ojs.aaai.org/index.php/AAAI/article/view/30125)则明确研究降低多项式依赖复杂度及其误差。它们是定义与费用的比较来源，不是本定理的外部证明，也不授权把原二元域替换为纯连续域。

研究决定：不为“增加 Gamma_k 阶数加独立乘积”启动 GPU 或 native 实现；保留 Gamma_k 的健全定义和尾界作为支撑。下一定义假说必须明确保留哪种共同尾与原相位的连续关系、如何在普通混权及后继激活中消费，以及相对已有 D013/D036/D085 和 RLT 的完整代价价值。这里没有新增“必须超越所有等价 HZ 编码”的不可能门；同样的有效行加入 HZ 后逻辑等强是正常事实。

这是改变下一行动的负结果与强比较证明，不是新域已完成、新颖性已确认或正式验证收益。正式 1870/2413 与独立 61/400 均零新增。
