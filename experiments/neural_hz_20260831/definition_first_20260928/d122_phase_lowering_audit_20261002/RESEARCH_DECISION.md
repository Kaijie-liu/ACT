# 相位级数候选的实现取舍

本轮完成了[终端比较证明](THEORY.md)，因此不再把增加 Gamma_k 展开阶数当作有证的松弛增强手段，也不为这种独立展开启动 GPU 或适配框架。这个决定关闭的是一条具体实现理由，不是完整 Neural-HZ 目标，也不是证明所有整数实现都无效。

## 已完成的新判断

固定点复制证明表明，在相同来源、守卫、兼容界和 seed 覆盖下，任何旧单门 LP 可行点都能在每轮原样复制。新增展开不排点；若同时保留旧全部行，投影与旧 LP 完全相同。更紧的阶段界、额外共同关系不在这个无信息增益前提内，须分别计功和计费。

普通两门例的真实输出 F 最大为 2，而旧 LP 及每阶独立展开都允许 11/4。一个已经在 D036 覆盖的条件幅值行，可以把该例的物理输出投影恢复到完整图凸包。只共享 Boolean 路径乘积仍未排点。这个比较定位的是相位与连续幅值的联合信息丢失，不能将旧修复重新包装成新候选。

还证明可以用原门依赖 DAG 的因果深度 D 代替粗糙的 N 阶恢复上界。在精确图上先共享已稳定子表达式，k>=D 时可回到 N 个原门，因此 kN 不是不可避免的终端下界；但恢复原图本身没有给出定义创新。这个修正防止用夸大的费用假设错误否定候选。

## 不变的事实和限制

当前源码使用保留整数相位的 MILP 终端，故本轮只证明连续松弛性质，不宣称实际整数运行时间、基线逐例行为或全 GPU 计算。原图浮点 EQ 与末端重心变换也未在本轮重新数值认证。所有旧 bits、共享 source、EQ/LE、输入重构和 fail-closed 边界不变。

Gamma_k 的纸面健全性、固定块嵌套和有限精确恢复仍成立；没有完整逐层新域、真实网络收益、完整物理或 GPU 资格。没有执行新候选，最新数值实验仍是 D120：3869 项继承测试通过、1600 个局部读出、下一 ReLU 零改善。不能把本轮纸面结论记成新的测试或回放成绩。

正式基线仍为 1870/2413（1063 CERT、807 validated ADV）；独立 E0 仍为 CIFAR100 25 与 TinyImageNet 36，共 61/400，两账新增都是 0。未改旧分数不等于新候选已证明保旧。13 家族、外部 CNN、其他家族、GPU、smooth/Transformer 和单路径满分的完整目标全部保持。

## 下一项定义问题

继续研究共同尾与原相位的联合连续关系，而不是继续增加独立展开轮数。优先对象仍是普通混权 Conv/残差到下一激活的重复结构：需要有构造证据的相位兼容或共同幅值关系，并说明它怎样改变生成元表示和前向组合，而非只在旧图旁多放表格。

D013 的跨层生成元消项、D036 的后代幅值、D085 的共同幅值及已有 RLT 是已有支撑与最低比较对象。复用它们可以，但不得再次称为首次定义创新；也不应要求新表示在得到完全相同行的 HZ 之上具有不可能的逻辑优势。真正未解决的是：能否在实际宽混权结构上，以完整成本可承担的表示保留联合信息，并获得真实验证收益。

这不是新增禁止门或要求用户再次确认。没有外部权限阻塞，可以继续纸面研究和符合原预注册门的候选工作。当前证据尚不支持直接物化全层联合乘积、重跑被冻结版本或开启默认功能。
