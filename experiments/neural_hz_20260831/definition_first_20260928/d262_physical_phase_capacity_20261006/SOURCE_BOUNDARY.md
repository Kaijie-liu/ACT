# 物理容量进入真实残差网络的完整前提

无辅助物理行消除了六产品安装的特定成本，但不自动补齐真实模型来源或在线终端。本页把下一实际问题固定为共同来源上的完整 a/b/r 提取及消费，避免把 D261 的未排除统计冒充已经安装的能力。这里是代码和数学边界核查，没有模型执行。

## 共同前沿和局部 Gram

按 D242、D245 及 D250 已读拓扑，取原 Relu2 输出 A、原 Relu5 输出 Q 和每个实际 BN 标量自己的原误差 epsilon 为共同前沿 V。完整旧 H 的原谓词仍约束它们；这不是将前沿替换成独立盒。

两父归一化 x_i=f_i/s_i、q_i=Q_i/s_i，s_i=max(-L_i,U_i)>0。由实际完整 child 读出取得 z=(g1+g2)/2、d=(g1-g2)/2；b_i 是 z 中归一化 q_i 的完整合并系数。令 z0=z-b1*q1-b2*q2。如果

```text
x_i=k_i+sum_v w_i[v]*V[v],
z0=k0+sum_v z0coef[v]*V[v],
```

且原可靠半径为 R_v，则 D245 的固定提取是

```text
G_ij=sum_v R_v^2*w_i[v]*w_j[v],
h_i=sum_v R_v^2*w_i[v]*z0coef[v],
a=G^(-1)*h,                         det(G)>0,
r=z0-a1*x1-a2*x2,
e=d-tau*(q1-q2).
```

计算 G 和 h 的五个和只需 S=supp(w1) union supp(w2)，因为其外父系数确为零。这是精确局部计算，不是截断近似。但 S 外的完整 z0 必须仍留在 r 中，所有常数、未选 Q、skip、BN 误差和真实列身份都保留。Gram 最小化此坐标权重下的二次残余，不保证区间半径下降。

原父自身的 BN 误差进入 G 对角项，并在 r 中保留 -a_i*E_i/s_i。其他独立原误差不能与它合并或被宣布相消。Gram 右端的非零重叠来自实际共同 shortcut 的 A 系数，未选 Q 和后续 BN 误差虽不贡献这五个和，仍贡献完整 r 界。

这里固定的是物理源半径坐标。D255 使用规范 native 因子后的 Gram 一般不同；它不是任意基变换不变量。实现必须明确选定一个合同并证明 pullback，不能把 D245 的 a 当作冻结 D255 自动恢复的同一值。

## 三种实际拓扑的差异

Large 的父 Conv3 为 stride1，shortcut 是 A 本身，因此两个同位置父支持与 child shortcut 的整个3乘3区域有重叠。

Medium/Tiny 的父 Conv3 是3乘3、stride2、pad1；shortcut 是1乘1、stride2再接外部3乘3卷积。D261 固定两父位于同一空间位置，所以它们共同只覆盖 shortcut 粗格点的中央一个，而不是两个不同粗格点。内部其余八点、非角边其余五点、角点其余三点若在完整规范合并后仍有非零系数，全部留在 r 中。

这是 D250 一般“两父最多覆盖两点”的当前人口特化，不是数值失败率，也不证明 Tiny 全家族无解。系数相消、稳定别名和实际支持仍须逐项认证。此几何差异支持优先核验 large 普通内部结构的理由，但不能成为候选按模型身份选择算法的条件。

## 零辅助行实际消除了什么

D255 native_rebased.py 的 attach 会为每个关系追加六个连续列，并对整批展开行调用原支持上限检查。仅四组乘积的 MC 就需要至少16R个辅助系数项；D064 转用的 MAX_SUPPORT 是65536。完整三来源每个模型的 R 都使这一旧调用不适用。

新物理行不安装这些乘积，因此不需要它们的槽位分配，也不承担16R的这部分成本。但它不是绕过所有上限的许可证：每个关系仍有一条完整 LE，六个逻辑读出仍可能对应大量 latent 项。新实现必须有自身完整计费与原消费者接口，不能只提高旧 MAX_SUPPORT 或把人口切成免费独立批。

D255 的实际图提取、EQ 归一化和 rebase 凭据可作为支撑；新行按自身定理认证，不必强行生成旧六乘积对象。D257 的零输出谓词承载思想也可复用，但当前 predicate_transport.py 只接受 owned D255 Result。不能伪造该对象或把旧资格转授给新关系类型。

## 仍未完成的决定性接口

必须绑定同一个实际 H 中六个读出的完整 affine/phase/rebase 身份、真实出生行、全部连续和二元列，以及原输入 decoder。D261 的逻辑 phase、名义 tau 和范围记录不等于这份绑定。

必须让全部实际 core、lazy、precomputed、skip 和后继消费者原子地共享新增谓词，并由正常终端真正消费。已有 sparse_hz_fast_bounds 不读取 EQ/LE，因此加行不会自动改善下一 ReLU 的前向区间；生产 lazy ASSERT 路径的 drop 也没有被 D257 的离线测试解决。若依赖前向消费，需另外证明和实现其读行规则，不能默认为已有能力。

完整原参数与输入读取、原 Conv/BN 外包、可靠界、出生舍入、所有消费者和终端存储仍须统一记账。D261 完整诊断使用255549650/256000000 work，余450350不能免费覆盖新提取和终端。它不是所有未来算法的下界，但后继必须给完整新算法账，不可删费或放宽门槛。
