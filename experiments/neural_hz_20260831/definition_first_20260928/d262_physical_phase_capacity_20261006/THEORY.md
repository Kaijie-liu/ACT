# 跨层相位容量的一行无辅助变量证书

本研究从两个父 ReLU 和两个残差子 ReLU 的共同非凸语义中，推导一条直接作用于六个物理读出的线性关系。它不需要在候选中先安装六个乘积变量及其29条约束，且保留已有普通残差正控的严格输出分离。系数生成只需固定加减、二倍和半倍、绝对值及最大值，不需要数据依赖的除法、LP 解或性质方向。

这是现有跨层相位关系的解析编译定理，不是完整投影等价定理，也还不是新的 Neural-HZ 抽象域。整数具体化不变，查询松弛可以更紧；不能把添加有效行本身称为新的集合表达力。这里只完成精确实数纸面证明及独立复核，没有候选代码、数值实验、GPU 或真实模型提分。

## 同一非凸状态与完整来源

固定原 HZ 状态 H，保留全部连续因子、原 signed binary、EQ/LE、shared latent/frame、完整读出及输入 decoder。alpha_i 是原相位的0/1视图，不是替换成连续变量的新相位。原零点允许的全部标签保留。

两个原父门的认证归一化满足 x_i in [-1,1]，q_i=ReLU(x_i)。两个实际子门为

```text
Y1=ReLU(z+d),  Y2=ReLU(z-d),
z=a1*x1+a2*x2+b1*q1+b2*q2+r,
d=tau*(q1-q2)+e,  tau>0,
Lr<=r<=Ur, Le<=e<=Ue.
```

r、e 是同一个 H 的完整仿射读出，包含常数、未选激活、skip 和原误差因子。来源及界必须在整个声明 H 上成立。提取不使用实例标签、terminal margin、LP 状态或对偶证书。以下规则不选择 a、b 或 tau；它消费一个已认证的统一提取合同。D261 的名义 tau 和差分诊断并不自动满足此合同。

## 固定的物理行

记 t_plus=max(t,0)、t_minus=max(-t,0)，并定义

```text
A=(a1+a2)/2, J=(a1-a2)/2,
B=(b1+b2)/2, Hc=(b1-b2)/2,
mu=(Lr+Ur)/2, R=(Ur-Lr)/2, c=tau+mu,
Dabs=2*q1-x1+2*q2-x2.

L10=Lr+min(0,a1+b1)-max(0,a2),
U01=Ur-min(0,a1)+max(0,a2+b2),
eta10minus=max(-L10-tau,0),
eta01plus=max(U01-tau,0),
Bplus=2*max(Ue,0).

C1=c/2+A_minus+J_minus,
C2=-c/2+A_minus,
C3=-c/2+A_plus+J_minus+2*tau,
C4=c/2+A_plus,
M=max(C1,C2,C3,C4), s0=M-J_plus,
Q=abs(B)+Hc_plus+R+eta10minus+eta01plus+Bplus.
```

因为 C1+C3=abs(A)+2*J_minus+2*tau，所以 M>=tau>0。s0 可以为负；有符号物理行不要求其为正。直接生成

```text
s0*Dabs+Y1-Y2-c*(x1-x2)/2 <= 2*M+Q.              (P)
```

在物理顺序 (x1,x2,q1,q2,Y1,Y2) 上，系数为

```text
(-s0-c/2, -s0+c/2, 2*s0, 2*s0, 1, -1).
```

这是一个结构确定的方向。若以后采用对称两方向政策，应事前统一登记并支付两行，不能观察 LP 或 margin 后才决定交换方向。本页不授权运行时改变原已登记方向。

## 完整有限证书

以下乘积仅用于证明，可以取原整数状态上的真实乘积；不需要作为运行时变量存在。也可以在 D252 的完整 MC 加 X 加 QG 松弛中读作其辅助量：

```text
p_i=alpha_i-q_i, n_i=1-alpha_i-q_i+x_i,
c12=alpha1*x2, c21=alpha2*x1,
d12=alpha1*q2, d21=alpha2*q1,
v1=alpha1*r, v2=alpha2*r,
T=q1-q2+c12-c21, U=q1+q2-c12-c21,
V=q1-q2+d12-d21, W=q1+q2-d12-d21.
```

父图给 p_i,n_i>=0、Dabs=2-p1-n1-p2-n2 和

```text
alpha1-alpha2=(x1-x2+p1-n1-p2+n2)/2.
```

使用下列已知容量及包络的非负组合：

```text
-(p1+n1)<=T<=p2+n2,
-p1-p2<=U<=Dabs,
-1<=V<=1, 0<=W<=1,
(v1-mu*alpha1)-(v2-mu*alpha2)<=R.                 (E)
```

前三条 X 容量由共同原相位语义产生。补充界均可由 MC 和父图证明：c12<=alpha1、c21<=alpha2 给 U>=-p1-p2；d12<=q2、d21<=q1 及非负性给 V 的双边界和 W>=0。W 同时不超过 alpha1+alpha2 和 2-alpha1-alpha2，平均即得 W<=1。将 r 居中后，最后一式的左侧同时不超过 R*(alpha1+alpha2) 和 R*(2-alpha1-alpha2)，平均得 R。不存在私有残差或省略原来源的步骤。

D252 定量守卫的上行是

```text
Y1-Y2 <= K+2*tau*p2+eta10minus*alpha1
                  +eta01plus*alpha2+Bplus,
K=tau*(alpha1-alpha2)+A*T+J*U+B*V+Hc*W+v1-v2.
```

其中四个原相位事件只是证明中的代数分类，不是候选运行时 split。Phi(d,z)=ReLU(z+d)-ReLU(z-d) 对 d 单调且2-Lipschitz，参考点 d=tau*(alpha1-alpha2) 的截断误差由 L10、U01 支付，因而该上行在整个整数 H 上有效。

按 A、J、B、Hc 的正负部分非负组合 (E)，并用 alpha_i<=1，可得

```text
Y1-Y2-c*(x1-x2)/2-J_plus*Dabs
 <= Q+C1*p1+C2*n1+C3*p2+C4*n2.
```

加上恒等式 M*Dabs=2*M-M*(p1+n1+p2+n2)，得到更强的带余项形式

```text
左侧(P) <= 2*M+Q
 -(M-C1)*p1-(M-C2)*n1-(M-C3)*p2-(M-C4)*n2.
```

四个系数 M-Ci 非负，因此删除非正余项即得 (P)。证明没有乘以 s0，故 s0<0 不影响健全性。所有原整数点均满足 (P)，保留完整旧 H 后，加入该行的整数具体化仍恰好是 H；原输入 decoder 不变。

## 一个固定行覆盖整个归一化模板

对任何 0<=lambda<=1/M，将 (P) 乘以 lambda，再加 (1-lambda*M) 倍的原父界 Dabs<=2，得到

```text
(1-lambda*J_plus)*Dabs
 +lambda*(Y1-Y2-c*(x1-x2)/2) <= 2+lambda*Q.       (N)
```

因此不需要为不同 lambda 创建一个参数菜单。1/M 是本证明中要求所有 deficit 系数非负的模板的最大 lambda，不是所有有效不等式或所有投影方向的最优值。运行时使用 (P)，根本不必计算 1/M。

把 M 额外增大到 max(M,J_plus) 虽然仍健全，却会人为要求 q 系数非负并削弱这一模板。没有采用该不必要限制。

## 能组合什么以及不能组合什么

多个已认证关系可以同时加在原同一个 H 上，因为每条对每个原整数赋值都有效，无须为不同关系协调新的辅助乘积见证。原连续和二元因子一个也不删除。

Affine、Conv、同 frame 的 Add/Concat 继续以同一 latent 赋值形成读出，新增行保留在共同谓词中。后继 ReLU 保留其原图和原相位，既有行仍有效；下一组关系须重新认证完整来源合同。这样可以逐层前向累积，但没有固定总宽度、自动得到所有新关系或任意深度精确查询闭包的定理。不能遗忘旧物理读出后仍免费宣称相同约束存在。

这是完整 QG 松弛在原坐标上的一个有效推论，未证明等于其投影。因此不能把已经合格的六产品系统整体换成一行并宣称不退化，也不能移除其他消费者使用的共享乘积。对 D258 充分冗余条件及其全部前提已经成立的同一关系，(P) 不会凭消元重新制造能力；特别需要相同 r 界已由旧 LP 蕴含、新产品新鲜且没有额外共享消费者。不能仅凭该范围在原整数 H 上有效，就把它免费授给旧 LP 并宣布冗余。

## 完整成本和数值边界

独立物理读出已存在时，一行增加0连续列、0二元列、0 EQ、1 LE、至多6个系数项。相比每关系6个辅助列和29 LE，这消除了相应的乘积安装成本。但六个物理读出可能是大量原 latent 列的仿射式。若 v_j=d_j+G_j*xi，必须完整合并 sum_j w_j*G_j，并把 sum_j w_j*d_j 移到右端；需要 LE 转 EQ 的后端还须计算其真实 slack 成本。

若精确行 w*v<=b 存储成近似系数 w_hat，已认证 l_j<=v_j<=u_j，则充分的向外右端为

```text
b_hat >= b+sum_j max((w_hat_j-w_j)*l_j,
                    (w_hat_j-w_j)*u_j).
```

所有求和、常数迁移及存储右端均须向外认证。此式是精确误差界的数学说明，不授予任何 binary64 编译器资格，也不能假定 D255 已舍入的旧行恰为这里的有理行。实际 pullback 后须在同一个完整坐标系付差额。

提取 a/b/tau、完整 r/e 及其界、位长检查、来源归一化、所有实例位置、消费者、证据、原 H、终端和输入验证仍全部收费。算术有批量 GPU 形式不等于已完成 GPU，更不等于普通终端求解已上 GPU。

## 对新颖性的限定

[Sharp Hybrid Zonotopes 第IV节](https://arxiv.org/html/2503.17483v2#S4) 已将 RLT 应用于 HZ，保留整数语义并强化松弛。这里不把该机制重新命名为新域。[PRIMA](https://www.sri.inf.ethz.ch/publications/mueller2021precise) 已研究多神经元凸近似；仅仅出现跨神经元线性行也不足以主张创新。

项目内 D052 已有单消费者乘积的零辅助投影，因此零辅助本身同样不是新增贡献。本轮有限结果是这个跨层容量模板的闭式编译、固定行的支配性质，以及 CONTROL.md 对明确定义的旧规则政策的严格比较。普通 HZ 加上相同物理行与本候选具有相同信息，必须承认。是否支持足以形成新 Neural-HZ 的结构演算、真实网络收益和论文级新颖性仍未解决。
