# 共享父源的联合激活变换

本轮把局部三门关系推进为同一父源上多个并行后继的联合出生原语。两个父 ReLU 和两个后继可用至多 37 个共同图点构造；为两个后继各保留一个实际宽 fan-in 余项时，上界为 277。全部原 bits 保持整数时恢复原非凸图，同一模块的仿射合流可直接消费共同关系。

这是纸面定义和构造定理，不是已经实现的新域、全网闭包、GPU 资格或真实网络收益。强度不应由点数判断。下面给出算子范围和完整局部账单，另文保留未通过强参照检查的控制。

## 域元素和原来源

保留完整原 HZ 元素 H 的连续因子、原 signed bits、EQ/LE、共享 latent/frame、所有消费者和原输入 decoder。候选 N=(H,B)，B 是有限个同源关系块。具体化为同时满足 H 和全部 B 的共同赋值经原读出得到的集合；新增连续量存在量化。空 B 嵌入原 HZ，具体化包含给出预序，按等具体化取商得到偏序。不声称最佳抽象或完整格。

一个关系块有两个实际父门及 m 个并行实际后继：

```text
q1=ReLU(f1), q2=ReLU(f2),
h_j=c_j1*q1+c_j2*q2+d_j1*f1+d_j2*f2+sum_a e_ja*v_a+b_j,
y_j=ReLU(h_j), j=1,...,m。
```

f、q、v 均属于同一 H 的真实读出，v 包含未列入两个父门的完整其余贡献，而非新独立物理噪声。系数可任意正负，不要求平行、齐次或相消。可靠界为 f_i∈[-L_i,U_i]，L_i,U_i>0；v_a∈[l_a,u_a]。所有原定义、相关性和消费者仍留在 H。下面独立盒仅定义局部外包。

原 bits 为两个父相位及 m 个后继相位，active=(signed+1)/2。不同块不因坐标均值相同就被认定有共同输入分布。本候选不删除、pivot 或松弛存储中的二元因子；LP 比较中的分数 bits 只是查询视图。

## 有限图点构造

每个父真实图是两段折线 N_i--O_i--P_i，三个点依次为 (-L_i,0)、(0,0)、(U_i,U_i)。不得将 N_i--P_i 凸包弦当作真图边。基础真实图复形为两条折线和 r 个非退化余项区间的乘积，面数 f_k 满足

```text
sum_k f_k*t^k = (3+2*t)^2*(2+t)^r。
```

固定余项仍保留实际常量读出，但不计入 r。每个基础面上，各 h_j 是仿射式。统一构造如下：对每个 k 维基础真面 F 和每个 k 个后继的子集，若它们的零式限制在 F 的仿射包上秩为 k，则求唯一交点；仅保留属于 F 的点。k=0 就是全部原顶点。最后提升所有实际 y_j=ReLU(h_j)。重复点可以合并。

这只编译原激活固有的分段图，不创建额外划分阈值、selector bits、输入/相位子问题、搜索树或外部支持优化。证明使用原相位区域描述几何，不授权实现为逐相位求解或失败后救援。未来实现仍须证明可靠交点和成员判断；无法认证时 fail closed，不能凭浮点秩或近似交点漏点。

顶点数满足

```text
N <= sum_(k=0)^min(m,2+r) f_k*C(m,k)。                 (V)
```

证明：原父相位固定后，基础图为一个盒的仿射像。所有后继零超平面把它划为网络仿射的区域。取任何区域顶点 p，令 F 为包含 p 的最小基础面，dim(F)=k。若在 p 取零的后继式在 F 上秩小于 k，则存在非零切向方向，使所有零式保持为零；足够小的双向移动还保持 F 的相对内部及其他式的严格符号。这与 p 是顶点矛盾。因此可选 k 个独立零式确定 p，且同一个 F 与子集至多贡献一点。每个区域是有界多面体，在其中整个网络图仿射，故其所有图点由生成顶点凸组合得到。反之每个生成点确是真图点。由此得到完整局部物理图凸包及式(V)。

重合、相关或恒零限制不增加独立截面；它们不产生本规则遗漏的孤立顶点。这里不是针对极端情况另加救援路径，而是说明秩条件的数学含义。

## 两个后继不能只合并旧边交点

无余项时 f=(9,12,4)，故 N<=9+12m+4*C(m,2)。m=1 恢复原 21 点构造；m=2 得 37。新增的四项来自真二维面内部两个后继零线的交点，不是只把两份三门点池相加。

例如父 f_i∈[-1,1]，h1=q1+q2-9/10、h2=q1-q2-1/5。在父正相位面，两个零线交于 (q1,q2)=(11/20,7/20)，不在基础真边上。取父 bits 为 1、后继 bits 为 0，该点是共同守卫区域的顶点；该区域内所有子输出均为 0。若只收集原顶点及各零线的真边交点，缺失此点，就无法用该相位兼容点的凸组合恢复它。因而“合并旧点池”不是联合精确变换。

两个实际余项时 f=(36,84,73,28,4)，两个后继给 N<=36+2*84+73=277。不能把两个不同余项压成一个区间而保留精确性声明。固定 r 时式(V)关于 m 为多项式；若每个新后继都需要新独立余项，r 随 m 增长，原顶点 9*2^r 已是指数规模。该公式不是任意宽 CNN 的低成本承诺。

## 原相位与共同标签

所有物理读出 z=(f1,f2,q1,q2,v,y) 共用一组 lambda：

```text
lambda_j>=0, sum_j lambda_j=1, z=sum_j lambda_j*V_j。
```

对每一个原 bit beta，预激活 g 为对应的 f_i 或 h_j，使用

```text
sum_(g(V_j)>0) lambda_j <= beta
beta <= 1-sum_(g(V_j)<0) lambda_j。                    (L)
```

这是 D220/D226 已有的零标签恢复机制，不是本轮新发明。必要性由每个固定原相位图的顶点分解得到。充分性是：每个门所需的零点 active 质量介于零和该门零点总质量之间，可分配到这些零顶点；在每个顶点对所有零门独立分配合法标签，就同时实现所有边缘。(L) 因而给出全部物理坐标与全部原标签的局部联合凸包。

原 bits 整数时，所有正质量顶点兼容同一完整相位向量。该共同守卫区域凸，网络在其中仿射，平均点仍是真图点。因此这是原非凸图的精确扩展，而不是 CZ、Zonotope 或区间替代。

附加到任意相关 H 时，每个原真赋值都有 lambda 扩展；保留全部旧行则不删真实状态，且查询外包不扩大。但与相关父谓词相交后，不能声称全原输入凸包理想，也不能以此代替超时和逐例不回退验证。

## 合流消费及其边界

同一块内所有 Affine/Conv/Add/Concat 读出必须先按原身份合并，继续使用同一 lambda。对任意共同物理仿射读出 A(z)，独立局部包上的支持恰为 max_j A(V_j)，而不是各消费者的独立端点相加。含原 bit 的查询可在每个顶点对零预激活的 bit 选相应合法端点；这仍只给局部包支持。

因此块内任意数量仿射消费者和仿射合流不会再次丢失已表示的联合关系。对实际后继 ReLU(A(z)+b)，若该共同支持证明 A+b<=0，即可证明其输出恒零，原相位身份按既有语义保留。若仍跨零，本定理不自动覆盖：A 中含 y 时通常对基础面只是分段仿射，不能冒充另一条原基础仿射超平面。一般深层联合出生、重叠块的共同分布及非仿射消费者仍待解决。

局部最大点不是具体 ADV。实际 v 和旧 H 可能排除它；原输入重构和具体网络检查仍独立必需。候选没有运行时 helper、PGD、BaB、split、backward/dual rescue 或 LP 状态菜单。

## 完整局部费用

令已有物理坐标数 D=4+r+m，已有原 bits 数 B=m+2。新增 N 个 lambda、N+2m+4 个 LE、r+m+5 个 EQ，谓词 nnz 上界为

```text
(r+2m+8)*N + r+3m+8。
```

其中非负行 N 个 nnz，simplex N 个 nnz，物理等式至多 D*(N+1)，全部 sign masks 至多 B*N，bit 系数 2B。故无余项两个后继上界为 37 列、45 LE、7 EQ、458 nnz；两个余项为 277 列、285 LE、9 EQ、3894 nnz。都是新增局部因子账单，不包括原 H。

V 与 masks 本身还需 O((m+r)N) 数据及提升计算。面/子集遍历、秩与交点认证、可靠界、源长读出及其 alias、所有旧谓词、单位盒归一化/slack、完整证据、主机设备共存、终端和 decoder 另计。候选点上界不是构造总成本，更不是 GPU 速度资格。没有实现、数值预算执行或全物理评测。

## 与既有研究的区别尚未充分

Siefert 等 §IV-A Theorem 5 已有共享顶点及 incidence 的通用 V-to-HZ 编码。本轮复用原神经 bits，不增加 polytope 选择位；这不使顶点编码本身成为原创。[论文](https://arxiv.org/pdf/2304.06827)

PRIMA 已研究多神经元联合关系、重叠组及联合凸包近似。因此“同时处理多个激活更紧”也不能作为新颖性主张。本轮不采用它的 Split-Bound-Lift、refinement cascade 或外部求界流程。[论文](https://ggndpsngh.github.io/files/PRIMA.pdf)

原精确 HZ 已能表达这个有限分段仿射图。项目内的新增推导是基于真图复形的多后继完整点池、显式面数界及共同仿射消费范围；外部原创性、同预算强参照优势和真实规模效益均未建立。这里的目标是进一步定义更有用的抽象变换，不以重命名精确集合类冒充强 Neural-HZ。
