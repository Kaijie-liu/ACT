# 相位作用范围内的非线性参考消去

本轮补上 D238 尚未覆盖的数学情形：共同 clip 参考在完整源域内真正跨越两个折点时，仍能凭原相位与源的联系，对指定差分消费精确线性化。先证明自由 clip 因子不能超过完整局部联合凸化，再给出不受此障碍限制的源条件规则、严格物理分离及完整局部费用。尚无实现、真实网络或正式成绩资格，也不宣称新的商代数或完整 Neural-HZ 已成立。

## 保留的域语义

沿用 D001 的原 HZ 嵌入与 D238 的具名观察语义。连续源、全部原 signed bits、EQ/LE、共享 latent/frame、物理读出和 decoder 均保留。alpha_i 是原父位的 0/1 视图，qi 是同一源上的规范化实际幅值，0<=qi<=alpha_i。定义 pi=alpha_i-qi。

观察必须表示同一个赋值上的函数，新增关系须由该完整父域推出。具体化仍保留原二元位；下面分数相位仅用于比较查询松弛，不是将表示整体改成凸域。有效的源条件恒等式不改变原整数图，但可以使有限查询更强。不能因此声称其 LP 投影与旧查询相同，或原精确 HZ 的集合表达力增加。

令两实际子门 y1=R(z+d)、y2=R(z-d)，其中

```text
R(v)=max(0,v),
d=tau*(q1-q2)+e, tau>0,
Phi(d,z)=R(z+d)-R(z-d),
S_tau(z)=Phi(tau,z)=clip(z+tau,0,2*tau).
```

z、d、e 均为完整同源读出，e 不得遗漏不匹配系数、偏置或其他父幅值。D238 的通用有效行是

```text
-2*tau*p1+2*min(Le,0)
 <= y1-y2-(m1-m2)
 <=2*tau*p2+2*max(Ue,0),                         (C)
```

其中 Le<=e<=Ue 有可靠证书，原语义 m_i=alpha_i*S_tau(z)。线性查询可外包 S 图及两个产品；外包辅助值不自动是真实函数值。

## 自由 clip 因子的精度上限

定理范围限定为只新增 S 的标量图凸包、两个 alpha_i*S 的完整范围 McCormick 包络及 (C)，没有额外源条件别名、源容量或其他观察消费者。设 P 为任意保留完整物理坐标的凸化父域，且 P 包含 0<=q_i<=alpha_i<=1 及 z、d、e 的实际仿射绑定和有效界。则新增因子的物理投影包含“在 P 上同时接两实际子门的精确图，再取完整带子标签凸包”。因此它不能相对该参照改善任何物理线性查询。

证明取 P 上任意实际双子门图点，设

```text
A=tau*(alpha1-alpha2), B=2*tau,
S=Phi(tau,z), M=Phi(A,z),
Li=max(0,S-B*(1-alpha_i)), Ui=min(S,B*alpha_i).
```

两个 McCormick 产品的差可取区间 [L1-U2,U1-L2]。上端展开为

```text
U1-L2=min(B*alpha1, B*(1-alpha2), S, 2*(tau+A)-S).
```

M 不超过全部四项。若 A>=0，0<=M<=2A，再用 alpha1<=1、alpha2>=0 得前两界；若 A<0，M<=0，而前两界非负。第三界由 A<=tau 及 Phi 关于首参数单调得到。第四界由 Phi(-tau,z)=-S 和 2-Lipschitz 性得到。交换下标并取负得到下端界，所以存在同一个 S 上的 m1,m2，其差为 M。

实际 d-A=-tau*p1+tau*p2+e，再次使用单调性及 2-Lipschitz 性即得 (C)。每个图原子都有扩展，线性系统容许其全部凸组合；原子门标签完整保留。这里没有假定 P 上分数父标签对应真实网络轨迹，也没有运行相位分裂。

该定理不否定因子强化较弱的实际逐门 LP，也不覆盖额外源条件观察。D238 的强控制之所以有效，恰在于额外的原源别名与容量，不是仅有这三个自由辅助列。

## 无其他消费者时的精确投影

若 S,m1,m2 没有其他消费者，记固定 z 上的标量凸包区间为 L(z)<=S<=U(z)。投影掉三个观察后，上侧恰为

```text
y1-y2 <= B*p2+2*max(Ue,0)+
 min(B*alpha1, B*(1-alpha2), U(z),
     B*(1+alpha1-alpha2)-L(z)).                   (P)
```

下侧是交换 1、2 后对 y2-y1 应用同一式，并将 e 的常数支付换为 -2*min(Le,0)。理由是对 S 区间最大化 min(S,C0-S,A0,D0)，其中 A0=B*alpha1、D0=B*(1-alpha2)、C0=A0+D0；结果是 min(A0,D0,U,C0-L)，因为 min(A0,D0)<=C0/2。整个扩展为凸集，投影到一个差坐标是区间，所以两端也充分。

全跨 l<-tau<tau<u 时，令 a0=B/(tau-l)、b0=B/(u+tau)。上侧可以写为四行

```text
y1-y2 <= B*(alpha1+p2),
y1-y2 <= B*(1-q2),
y1-y2 <= B*p2+a0*(z-l),
y1-y2 <= B*(1+alpha1-q2)-b0*(z+tau),
```

各行再加 2*max(Ue,0)；下侧交换下标并用 -2*min(Le,0) 支付。已有独立 z 及物理列时，共 0 新列、8 LE、36 nnz。自由观察形式为 3 新列、14 LE、34 nnz。省列却增加 nnz，不能据此宣称加速；若观察被别处消费，更不能逐个消费者分别消去。这是已知线性投影的项目推导，不是域创新主张。

## 原相位作用范围上的精确消去

令 h=alpha1-alpha2。如果一个明确、可核验的结构证书保证

```text
h!=0  implies  -tau<=z<=tau,
```

则原整数语义满足

```text
h*(S_tau(z)-z-tau)=0,
h*S_tau(z)=h*(z+tau).                            (A)
```

证明：h 非零时 clip 在中段，h=0 时整个差观察消失。整体 z 可以真正跨越两折点。这里只替换乘 h 的共同差分，不逐项替换 alpha1*S 或 alpha2*S；例如两相位都是 1 且 z>tau 时，逐项替换会出错。其他消费者若仍需要 S 或单项乘积，必须完整保留。

本规则不调用任意语义蕴含或完整 guard 可行性 oracle。下面两类固定代数界给出直接结构证书，不建立源子域、点池或新参考位。

第一类保留原父 xi 属于 [-1,1]、qi=R(xi)，并有完整 z=a*x1+b*x2+r。原 h 非零蕴含 x1、x2 弱异号。若 a,b 同号，取 M=max(abs(a),abs(b))；一般符号可取 M=max(a_positive+b_negative,a_negative+b_positive)，其中 negative 表示负部的非负大小。可靠区间

```text
[Lr-M, Ur+M] subset [-tau,tau]                    (X)
```

足以认证 (A)。r 始终是同一个 H 上的完整真实读出，使用其全域界只是保守支付，不把它复制成独立源。弱异号证明包含父预激活为零时的全部合法标签。

第二类为 z=a*q1+b*q2+r。h 非零时最多一个 qi 非零，因此

```text
[Lr+min(0,a,b), Ur+max(0,a,b)] subset [-tau,tau]   (Q)
```

同样充分。实际 d 的不匹配余项 e 仍独立完整计费；(X)/(Q) 不能使它免费消失。系数必须由原模型可靠绑定，区间系数不能用中点代替。

## 整体 clip 真正非线性的强控制

令 x1,x2,t 属于 [-1,1]，qi=R(xi)，定义

```text
z=3*(x1+x2)/4+t/10,
y1=R(q1-q2+z), y2=R(q2-q1+z),
D=2*q1-x1+2*q2-x2,
F=D+(2/5)*(y1-y2-(x1-x2)/2),
r_out=R(F-41/20).
```

整体 z 范围是 [-8/5,8/5]，上下尾均实际可达；在相位差非零时，(X) 却给 |z|<=17/20<1。因此 tau=1 下 (A) 成立。参考 S 本身不再全域仿射。

记原图的 p_i=alpha_i-qi、n_i=1-alpha_i-qi+xi，以及

```text
c12=alpha1*x2, c21=alpha2*x1,
s1=alpha1*t, s2=alpha2*t,
T=q1-q2+c12-c21.
```

D238 已逐项证明 -p1-n1<=T<=p2+n2，且共同 t 的完整产品包络给 s1-s2<=1。由 (A) 得差观察 alpha1-alpha2+3*T/4+(s1-s2)/10，再由 (C) 得有限证书

```text
F<=51/25-(4/5)*p1-(6/5)*n1-(1/10)*p2-(1/2)*n2<=51/25.
```

真实 (x1,x2,t)=(1,-1,1) 取等，故后继预激活至多 -1/100，r_out 恒为零。没有使用单父幅值支配、phase split 或其他 solver。

取 u=99/100，强参照中的显示点为

```text
x1=x2=t=0, alpha1=alpha2=1/2, q1=q2=u/2,
y1=7*u/10, y2=u/2, gamma1=gamma2=1/2.
```

其 F=1287/625，超过新界 12/625；接独立实际后继图时允许 r_out=23/2500。这不是具体反例或已执行的验证结果。

两个完整单子门带源和标签前缀凸包均接受此点。用真实 x 四角 (±u,±u)、t=0，令对角 00、11 各占 delta，非对角各占 1/2-delta；目标子幅值均值为 u*(1/2+delta/2)，原子标签均值 1/2。第一门取 delta=2/5，第二门取 delta=0，得到上述显示点。

它也属于“完整凸化父域 P 上同时接两实际子门的真图，再取完整带标签凸包”。每个原子取 q=u*alpha、x=u*(2*alpha-1)、t=0。组 A 用 alpha=(1,1/2) 与 (0,1/2) 各半，子幅值均值为 (5u/8,u/8)。组 C 用 alpha=(0,0) 与 (1,1) 各半，子幅值均值为 (3u/4,3u/4)。将 A、C 按 2/5、3/5 混合，即得全部显示源、父坐标、子幅值和原标签。各子预激活严格非零，C 的真实 z=±3u/2 已越过两个折点，非虚增区间。

这些参照包含实际 parent-to-child 的 D036 行及适用的 D020 原门差分。固定相同子门前沿上的联合支持也不能排除显示点。但完整原源四门 hull、全部共同条件矩、完整跨层 RLT 或无限递归旧规则不在此被分离的参照内。

## 不依赖两个源系数恰好相等的控制

为排除只靠 z 的精确对称性，改取 z=(19/25)*x1+(37/50)*x2+t/10，并定义

```text
U=q1+q2-c12-c21=(alpha1-alpha2)*(x1-x2),
F=(249/250)*D+(2/5)*(y1-y2-(x1-x2)/2).
```

原整数语义下 0<=U<=D：相位相同时 U=0，相位不同时 U=|x1|+|x2|=D。只登记 U<=D 即足够，即 -q1-q2-c12-c21+x1+x2<=0，一行 6 nnz。写 k=3/4、h=1/100，有相位差乘 z 等于 k*T+h*U+(s1-s2)/10，F 中的 -(2/5)*h*D 因而支付 U 项。仍得到同样四个缺额系数和精确上界 51/25，真实 (1,-1,1) 取等。静态守卫证书在相位差非零时给 |z|<=43/50<1，完整 z 范围仍为 [-8/5,8/5]。

u=99/100 的强比较显示点改为 y1=351u/500、y2=251u/500，其余源及标签不变。完整单子门前缀分别取对角质量 delta1=2/5、delta2=3/130；其均值公式分别为 (51/100+12*delta/25)u、(49/100+13*delta/25)u。联合 child-over-P 的 A、C 组仍按 2/5、3/5 混合；A 均值变为 (63u/100,13u/100)，C 不变。所有原标签一致且子预激活非零。

此点 F=25641/12500，比 51/25 高 141/12500；同一后继阈值 41/20 允许旧值 4/3125，而新证书给零。总局部账变为 4 列、21 LE、76 nnz，没有为证明额外偷偷登记 U>=0。

这还不是孤立非对称参数。固定 k=3/4、eps=1/10、lambda=2/5，令 a=k+h、b=k-h、F=(1-lambda*h)D+lambda*(y1-y2-(x1-x2)/2)。相同见证有 y=(7/10+h/5,1/2+h/5)u，delta1=2/5、delta2=(6h/5)/(1/2+2h)，并给 F_fake=u*(52/25-4h/5)。对全部 0<h<4/165 它仍严格超过真界 51/25；固定后继阈值 41/20 的分离在 0<h<23/1980 保持。该族仅去掉两个 source 系数恰好相等的要求，仍有明确 child 差分结构，不能冒称任意 Conv pair 都适用。

## 完整局部费用和组合限制

对于 (X)，已有 r 物理列时，用 c12、c21、v1=alpha1*r、v2=alpha2*r 四个产品，有

```text
(alpha1-alpha2)*z=a*(q1-c21)+b*(c12-q2)+v1-v2.
```

四套 McCormick 至多 16 LE/40 nnz，两个差额行至多 2 LE/20 nnz，合 4 连续列、18 LE、60 nnz。若追加已证的两条 T 源容量，则为 4 列、20 LE、70 nnz；它们对这里的原 xi,qi 合同有效，不需要 a=b。上述对称控制使用这 70 nnz 合同；非对称控制另加一行，合 76 nnz。

对于 (Q)，用 alpha1*q2、alpha2*q1、v1、v2，两个非负 q 产品各为 8 nnz，故为 4 列、18 LE、56 nnz。该表示没有 c12,c21，不能免费冒用上一类 T 容量。

r 若内联为 s 个非零源项，前两类不含额外 T 行的上界分别变为 56+4s、52+4s nnz；若新增独立别名，另付一列、一 EQ、s+1 nnz。完整 d/e 构造、可靠界、系数身份、原 H、全部原图和消费者、signed-bit 转换、slack、host/device 共存、终端及重构全部另计。结构检测至少读取完整来源，不是常数时间的免费 oracle。

原相位与所有原谓词不能删除。Affine/Conv/Add/Concat 可在同一身份下线性消费已认证的共同差关系；下一非线性层须重新验证其全父域合同。未证明任意深层无损闭包、固定宽度或全网成本下降；GPU、smooth 与 Transformer 尚未取得本规则的资格。

## 先例与创新边界

D001 已提出用局部证明进行 guard-aware quotient；D006 已说明完整 guard normalizer 可隐藏原可行性问题。本轮是一个有直接代数证书的具体结构实例，放宽了 D238 的全域仿射参考限制，不是新发明商代数，也不推翻 D006 的受限 Boolean-affine 开纤维结论。clip 未消去前并非该模块中的一般连续仿射形式。

本轮重读的 primary sources 同样限制创新主张：mixed polynotopes 已用共享 typed symbols 和保集合的符号重写；Sharp HZ 已将 RLT 用于 HZ，保留原整数集合并加强松弛。不能把产品 lift 或 typed expression 本身算作新域。[Mixed polynotopes 原文](https://arxiv.org/html/2009.07387v2) [Sharp HZ 原文](https://arxiv.org/html/2503.17483v2)

目前成立的是有限的相位作用范围线性化规则、其静态充分证书、跨两个真实折点的强物理分离及明确成本。新颖性、可组合域演算、真实适用性和正式收益仍需独立证据。同信息的普通 HZ 加相同行可以追平；本项目也不应另设“必须超过 HZ 的集合表达力”这一不必要门槛。
