## 为什么收窄为预算消费

直接把 ReLU 输出换成共享误差坐标不是新方向。令 q=ReLU(g)，e=q-k*g，则线性联合误差表达式仍可改写为原 g/q 的混权读出；k=1/2 时 e=abs(g)/2。D074 已审查可逆坐标重写及差关系，D062、D066、D069 等已有混权共同源观察。换坐标不能单独算作新域。

本轮因此改查一个更小的问题：D082 已有的联合预算在混权消费者变化时，能否直接被消费，而不是像 D083 那样为每个消费者重新生成一个可能变弱的预算。保留完整原 HZ：连续因子、全部原二元相位、EQ/LE、共同 latent/frame、真实读出和输入 decoder 均不删除。原相位零点的全部合法标签保留。

## 单预算的静态支持

对同一原赋值的负幅值 n_j=q_j-h_j，已有可靠关系为：

```text
0 <= n_j <= c_j(b) = A_j*(1-b_j),
sum a_j*n_j <= B(b),
A_j >= 0, a_j > 0, B(b) affine in original bits.
```

b 是原 active bit 的认证 0/1 视图，而不是新建或放松后的域因子。以下公式对固定 b 的预算集合成立；在比较查询外包时也可令 b 属于 [0,1]。必须有非负容量和 B(b)>=0，否则预算集合可能为空。

对固定读出 w，定义静态断点集合及仿射行：

```text
Lambda_w = {0} union {w_j/a_j : w_j > 0},
phi_lambda(b) = lambda*B(b)
              + sum max(w_j-lambda*a_j,0)*A_j*(1-b_j).

max {w*n : 0<=n<=c(b), a*n<=B(b)}
    = min {phi_lambda(b) : lambda in Lambda_w}.
```

证明上界：对任意 lambda>=0，逐项移出 lambda*a_j*n_j，再用预算和容量即可。达到上界的见证由正收益坐标按 w_j/a_j 从大到小填容量得到；预算耗尽时最后一个收益比值给紧界，预算宽松时 lambda=0 给紧界，负收益坐标取零。它是连续背包的原始贪心证明，不要求运行对偶优化、LP 点反馈、相位子域或额外求解器。

一次生成所有静态断点的行即可；运行时没有 lambda 决策变量，也不按哪一行有效来挑实例。a_j=0 的扩展保留独立项 max(w_j,0)*c_j，不作除法。负方向对 -w 同做。

精确性仅针对该盒加单预算：上侧行精确表示标量 upper hypograph；上下侧一起才得到固定 b 下的完整标量区间投影。它们不是任意多个消费者的联合精确投影，也不是原网络的完整支持。若原 n 还有其他谓词或消费者，不能依据这些行删除 n。原 HZ 加同样已认证行获得同样逻辑信息。

B(b)<0 时有限断点行不能表达空纤维，必须保留预算可行性条件和原证明；不得仅因缺前提就报 SAFE。互不相交预算组的支持可相加，重叠预算不能直接沿用此精确性结论。预算的贪心见证不是原网络输入见证或 ADV。

## 普通混权读出的有限改善

沿用 D082 的 x,y in [-1,1] 和三个原门：

```text
h1 = 4*x/5 + y/5 + 1/10,
h2 = -3*x/5 + 2*y/5 + 1/10,
h3 = -x/5 - 4*y/5 + 1/10,
qj = ReLU(hj), nj=qj-hj.
```

每门范围 [-9/10,11/10]。D082 的已认证预算为：

```text
n1+n2+n3 <= 11/10 - (b1+b2+b3)/10.
```

对实际消费者 F=q1+q2+2*q3，w=(1,1,2)，a=(1,1,1)，完整断点为 0、1、2。得到：

```text
n1+n2+2*n3 <= 18/5 - 9*b1/10 - 9*b2/10 - 9*b3/5,
n1+n2+2*n3 <= 2 - b1/10 - b2/10 - b3,
n1+n2+2*n3 <= 11/5 - (b1+b2+b3)/5.
```

使用中间行、Hplus=h1+h2+2*h3=2/5-x/5-y 和 b_j>=10*q_j/11，得到：

```text
(12/11)*(q1+q2) + (32/11)*q3 <= Hplus+2.
```

按 D083 相同的固定物理消费法，eta=11/16，剩余 q1、q2 系数均 1/4，q3 剩余系数为零。用原共同源 secant 得：

```text
F <= 77/40 - 11*x/100 - 121*y/200 <= 66/25.
```

必须保留全部比较：D083 的重新生成算法得到 22/5；普通共同源 secant 已给 143/50，不能只与更弱的 22/5 比；真实 F 上界为 5/2。因此 66/25 只是特定前向消费的改善，不是超过已知真全局界、全 HZ 加同预算或所有旧观察算法。若对照继承真全局界 5/2，单靠这一标量界没有后继优势。

## 后继控制及被旧方法排除的限制

取真实后继 h=n1+n2+2*n3-4/5，r=ReLU(h)。h 的真全局范围为 [-4/5,11/10]：原点负幅值全零给下界；正权负幅值之和凸，盒四角给上界，在 (1,1) 取到 11/10。

上述 lambda=1 行减去 4/5 后，在整个 bit 立方体非负，因此由 ReLU 单调性有：

```text
r <= 6/5 - b1/10 - b2/10 - b3,
Z = r + (q1+q2+10*q3)/11 <= 6/5.
```

真实输入 (1,1) 有 q=(11/10,0,0)、r=11/10，Z 取等。下面是仅用于松弛比较的假点，不是 ADV：

```text
x=y=0, b1=b2=b3=1/2,
q=(8/25,8/25,53/100), n=(22/100,22/100,43/100),
h=1/2, r=29/40, child bit gamma=2/3.
```

该点满足同一原预算 87/100<=19/20；child 使用精确全局界的 big-M 也允许它：r<=11/15，r-h=9/40<=4/15。三个父门完整单门 source hull 的见证分别是正负 (27/50,27/50)、正负 (-27/50,27/50)、正负 (-24/25,-24/25)，各取一半并使用相应真实相位。它们共享均值，不声称共享连续分布。

父 D020 输出差 (0,-21/100,-21/100) 通过。D052 双向固定行可取 delta12=1/4、delta13=3/20、delta23=1/10；三对左侧分别 44/100、85/100、65/100，右侧 50/100、98/100、66/100。共同 BQP 分布为 P100=1/10、P010=3/20、P001=1/4、P110=1/4、P101=3/20、P011=1/10，其余零。因此这个有限比较系统允许 Z=253/200>6/5。

但它不能胜过完整 D066 的理想共同相位观察。对锚 (2,3)，D066 的 h 上表按 00、10、01、11 为：

```text
(11/10, 1, 7/25, 1/10).
```

这些端点均非负，前向 ReLU 后仍是 r 的上表。b2=b3=1/2 时已有：

```text
r <= 16/25 - (2/25)*delta23 <= 16/25.
```

这已排除 r=29/40。故本控制只证明同预算、父局部信息与精确 child big-M 相比时的有限前向消费价值，不证明新的强域分离，更不能当新增 CERT。比较涉及理想纸面表，不是重新运行 D066 的量化实现。未证明与 D069、D089 或完整 child source hull 的全面关系。

## 与已有研究的边界

[Bertsimas 与 Sim 的 The Price of Robustness](https://www.mit.edu/~dbertsim/papers/Robust%20Optimization/The%20price%20of%20Robustness.pdf)，2004，第三节 Proposition 1 式 6 和 Theorem 1 式 8，给出预算不确定性的连续背包与其支持表示。本文是这一经典机制的加权容量及原相位参数化，不是新的通用背包数学；此前本轮已阅读相应原文，归档阶段未重新启动文献研究。

[Mirman 等的 A Provable Defense for Deep Residual Networks](https://arxiv.org/pdf/1903.12519)，第三节第一小节，correlation layer 保留具体化并把独立误差转成共享误差身份。那篇的 Hybrid Zonotope 是凸的 box 加 zonotope，不能和本项目含原二元非凸相位的 HZ 混称；保留误差身份也不自动产生不同误差间的新关系。

项目内 D060 已有相位相关上下容量、等式总量切片的精确符号贪心支持和同序多消费者共同见证；其显式前缀编码在原控制里增加变量和 nnz。本轮不同的具体步骤仅是零下界、单预算不等式下，直接生成全部静态比值断点行，不引入前缀辅助量。不能因此声称首次提出相位相关符号投影。

D024 的单调容量电路可以容纳所得 min，但未给这组背包断点构造；D046 已能表达相位仿射包络；D083 使用固定 eta 消费重新生成的加权关系，未给全部静态断点。只读窄检索未发现完全相同构造，不是外部新颖性证明。

## 代价与研究决定

正收益比值排序需要 O(m log m)，一个上侧最多 m+1 行，但显式完整系数可能有 O(m^2) 个 nnz，并重复 B 的支持。共同源展开、原门和谓词、精确位长、可靠舍入、临时内存、证据、输入重构及终端成本全部另计。无新辅助变量不等于免费，GPU 适用性也未实现或测量。

保留本公式和正负对照为支撑研究，不因能写公式就再启动包装器和测试套件。下次需要的实质证据是：相对于继承同一预算、真全局界及已有共同相位观察的公平对照，证明可组合关系或完整成本的非重复贡献；若没有，就保持支撑地位。不得重新探索已被 D074 覆盖的坐标改名、D100 排除的 rank-only 独立标量摘要，或把本例有限优点包装为新域。
