# 原相位支撑误差像的非凸定义与精确投影

上一轮的总误差预算允许把误差分配给与 anchor 同相位的门。本轮取消这个放宽，保留逐门的相位支撑，并证明在二维完整消费者下，可以把共同误差像精确编译为固定线性行，而不保留逐门误差变量。这个结果修复了上一轮的一项能力损失，但仍不能恢复实际源绑定，也未建立真实网络收益或外部新颖性。

## 域元素与出生变换

沿用 D191 的完整父域 S、实际预激活 g、全部原相位 beta、固定结构 anchor a 和 b=beta_a。R_i>=sup_S |g_i-g_a|，R_a=0，必须在整个当前抽象父域认证。C 同时涵盖全部活消费者，旧谓词或重构若还需要独立 q_i，不能遗漏它们。原连续源、signed bits、EQ/LE、共享身份、零点双标签和输入 decoder 全部保留。

新 bank 的关系为

```text
exists e:
    0 <= e_i <= R_i*|beta_i-b|,
    Z = C*e,
    Y = b*C*g + Z.
```

原实际 g 的 guards 继续存在。对任一父成员及其合法新相位，真实 ReLU 的规范扩展为 e_i=(beta_i-b)*g_i。异相位时两个实际预激活弱异号，所以 0<=e_i<=|g_i-g_a|；同相位误差为零。因此变换对整个父域健全，而非仅对具体网络轨迹健全。

在同一父赋值、相位和完整 C 下，新误差箱包含于 D191 的总预算 simplex；因此新 packet 的具体化包含于 D191 packet。反向不成立：D191 六十门伪点给同相位 plus 门分配正误差，而本关系禁止。全包同相位时误差归零；一般混合相位仍有损，见 CONTROLS.md。

这是含原整数相位的非凸关系，不是用一个凸 zonotope 替换整个 HZ。固定相位后，局部误差像确实是经典盒的线性像；使用这种几何不产生新的通用 zonotope 原理。空 bank 精确嵌入原 HZ，单门 bank 还原原非凸 ReLU 图。语义偏序取具体化包含；未声称完整格或可计算最佳抽象。

仿射、Conv、同框架 Add/Concat 通过同一 Y 的读出组合，保留共同 bank，而不是分别选误差见证。递归 ReLU 可对其实际父读出重复同一出生规则，R 必须重新覆盖这个可能有损的父域。该健全闭包不证明误差、谓词历史或查询成本随深度受控。

## 每个方向只需两行

对固定法向 n，定义非负常数与原相位仿射式

```text
a_i = R_i*max(n dot C_i,0),
A = sum a_i*beta_i,
K = sum a_i.
```

固定整数相位下，误差箱的精确支持为

```text
max n dot Z = sum a_i*|beta_i-b|
            = A+b*(K-2*A).
```

无需为这里的 b*A 再建乘积变量。因 0<=A<=K，下列两行对整数 b 恰好表达该方向的上界：

```text
n dot Z <= A+K*b,
n dot Z <= 2*K-A-K*b.
```

K=0 时两行相同，仅保留 n dot Z<=0。这是一个固定谓词系统，没有运行时相位分支、XOR 新 bits、LP 状态选择、对偶求解或 helper。终端 LP 的分数 b 只是外包；不能称其为整个联合 bank 的理想凸包。

两行还恰好是该方向独立四行乘积 LP 的精确消元，而不是比这个独立建模再松一层。令 w=b*A，标准四行给 max(0,A+K*b-K)<=w<=min(A,K*b)，方向上界为 n dot Z<=A+K*b-2*w；消去这个没有其他消费者的 w 就得到上述两行。若不同方向的乘积还共享额外身份或 RLT 谓词，不能逐个消元后宣称保全那些联合关系。

Y 中的 u=b*C*g 仍须另付 p 个普通二元乘积的四行编码，可靠界、C*g 和全部读出均计费。减少误差变量不免除这些实际源产品。

## 二维完整共同像与秩降

先只看 R_i>0 且 C_i 非零的列；恒零 anchor 列不增加误差像的 span。若这些二维列张成 R²，取所有不重复的固定法向

```text
N={+perp(C_i),-perp(C_i)}.
```

对全部 n in N 安装上述行，便精确表达一个共同 e 的存在，不是各方向各有独立见证。理由如下：当正长度列张成二维，盒像每条边平行于某条正长度列，其全部 facet 法向已在 N；当它降为线段，沿该线的列提供正反垂直法向，强制线性 span，另一不平行的原列提供两个端点界；全部长度为零时，两条独立法向的正反零界强制 Z=0。所有法向在出生时固定，不按运行相位删行或换规则。

若初始有效列只有秩一，必须显式保留 span 等式，并增加沿该线的正反支持方向来给端点；只取列的垂直方向不够。秩零直接 Z=0。这些是精确的结构条件，不是针对数值病态改变语义。

等价的统一论证是把每个长度加上正 epsilon，得到固定全维 normal fan 的盒像，再取 epsilon 向零的嵌套紧集极限。该证明也解释为什么已存在的零长度不会需要新方向。

完整性仅针对这个相位误差箱，不针对原 ReLU 图。它依赖 C 是完整消费者以及认证的精确方向关系；近似 rank 或浮点共线判断不能未经证明套用。

## 完整费用与真实范围

令 p 为 packet 宽度，s_i 为 g_i 在保留父坐标中的 nnz。原 guards 有 2m 行、2*sum(s_i+1) 个系数。物化 H=Cg 需要 p EQ 和 p+nnz(Cg) 个系数；u_j=bH_j 的普通四行通常合计 4p LE、10p 系数。若 H 内联，则按实际展开重新计费。

令 Z=Y-u 内联，某法向的支持数为 s_n=nnz(n)、a_n=nnz(A_n)。K_n>0 时两行直接需要 4*s_n+2*a_n+2 个系数。物化 A_n 则增加一个连续量、一条 EQ，总系数变成 4*s_n+a_n+5；不是免费共享。K_n=0 去重后只需 2*s_n 个系数。还要支付 span EQ、输出 cone、所有活 skip、父谓词、后继、decoder、C/R/法向证据、位长与终端存储。

二维有 d 个不同列方向时至多 2d 个法向。但在泛型 rank-r 完整消费者上，m_eff 个有效列可能产生 2*choose(m_eff,r-1) 个 facets；直接方向系数展开还可能达到与 facet 数乘 m_eff 同阶。这里是特定泛型几何的费用，不是所有表示的不可能性定理。

D179 已认证真实 CNN 的完整后继宽度为 CIFAR 的 100、Tiny 的 200，出生幅值为 4096/2048/6272；保守加 mass 后为 101/101/201 个观察。它没有认证这些 C 的数值秩或少量列方向。不能把二维结果直接迁移到它们，也不能只挑两个有利输出而漏掉其他消费者。少量固定方向仍可作健全外包，但不能继续宣称完整共同误差像。

矩阵作用与固定支持行具有可批量计算的形式；本轮没有 GPU 核、可靠舍入、终端或物理内存实测。完整二维编译是支撑定理，尚不足以启动通用 CNN 组件。
