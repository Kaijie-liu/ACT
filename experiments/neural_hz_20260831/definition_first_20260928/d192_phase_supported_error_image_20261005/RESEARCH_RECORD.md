# Neural-HZ 原相位误差关系的研究结论

上一目标轮属于 progress：D191 的强对照和严格内部反例改变了下一候选选择。本轮由总预算改为原相位逐项支撑的误差箱，得到[精确二维共同投影与两行编译](DEFINITION.md)，并在[整个六十门父盒](CONTROLS.md)恢复上一候选丢失的后继性质。这是定义与查询关系的纸面进展，不是存储优化或额外算法救援。

同时，本轮找到了仍未修复的普通三门源绑定反例、只需一条旧行的强对照，以及原生整数结论与有限 LP 的明确差距。完整误差像在高维可能需要大量方向，真实 CNN 的 100/200 维完整接口尚没有二维适用证据。因此不把这项支撑定理晋升成通用组件，不开启实现或生产默认。该决定没有降低完整目标或要求用户新增权限。

下一数学问题更具体：在保留完整消费者的同时，如何让压缩误差关系与实际父源共享同一个幅值见证，并以小于恢复完整逐门图的费用生成终端可消费关系。仅有原 bits、正确误差支撑和各自完整的投影都不够；本轮三门反例及旧源子集聚合行可直接作为反证门。不能只与逐门松 LP 比，也不能将所有旧行简单叠加后称新定义。

## 同轮差分路线复核

D020 已有原相位差分四行，D022 已有 Conv/Add 组合，D173 已有相反列消费者的两幅值到一个差分替换；本轮不重复实现。一个明确接口判据是：令 f=x+y/4+1/8、h=x-y/4-1/8，源盒 [-1,1]^2，r=ReLU(f)、p=ReLU(h)、d=r-p。只保源、原 bits 和 d，并要求固定仿射读出，则 alpha*r+kappa*p 可精确恢复当且仅当 alpha+kappa=0。

证明：00 有二维开集，迫使任何恢复式的源系数为零；11 也有开集，此时 d=y/2+1/4 无 x，而目标的 x 系数是 alpha+kappa。充分性由目标=alpha*d 给出。该判据允许读出含固定 bit 系数，但不覆盖相位乘源的非线性读出或一般有损域。完整消费者含 mass 时，基值载体或重新建立源乘积仍须付费。D171 已有真实 CIFAR Add 后还经 Conv/BN 的图证据，不能假设直接小残差 ReLU。

## 文献核查与新颖性

本轮重新核读 [ZonoGPT v1](https://arxiv.org/html/2609.34457v1) 的结构表示、融合 attention、GELU 与削减部分。它采用共享和局部生成元，块级传播保留残差关联；削减将部分生成元包入区间。这些机制在本项目 D071、D103、D105、D124 已有记录，不记为本轮首次发现。没有采用其凸域替换 HZ，也没有借其论文成绩更新本项目计分。

本轮的几何支持与消析基于已有盒像和整数线性建模；不同于 D101 的单方向预算，这里证明特定二维全部法向同时描述同一个误差见证，但尚未建立外部新颖性。普通终端 LP/MILP 边界不变，没有引入独立优化器、分支、攻击或 backward/dual rescue。
