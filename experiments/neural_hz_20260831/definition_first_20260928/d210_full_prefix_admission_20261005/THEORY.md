# 真实卷积中共同非线性余量的保留条件

本轮沿 D209 的域内关系闭包继续研究，不新增求解器或 helper。两个问题必须分开：共同余量何时能从真实卷积的父非线性传到后继；当前数学参照实现能否在完整网络规模下执行。前者有一个可反证的充分条件，后者已有与数值无关的费用下界。两者都不等于真实网络新增解或新集合类认证。

## 非凸语义保持

全部陈述使用同一父元素：原连续因子、显式 signed binary 相位、全部 EQ/LE、共享因子身份与原输入 decoder。beta=(sigma+1)/2 仍只有0或1。谓词余量是同一共同赋值上的仿射读出，不是新独立变量。对 crossing 门 j，令 ell_j=-L_j>0、U_j>0，原 active-upper 行的非负余量为

```text
Theta_j = f_j + ell_j*(1-beta_j) - q_j >= 0.
```

它在 D209 中以原 LE 行的身份存在。下面的条件传播这个已包含父 ReLU 语义的余量，而不只是传播原输入盒端点。

## 共同 graph slack 的下界

在一个完整读出进入最近父 bank 时，先将所有共享来源、残差和 alias 贡献合并，q_j 的完整系数为 w_j。对每种固定查询模式，取该门对 Theta_j 的最小单位贡献比例：triangle 为 U_j/(U_j+ell_j)；constant pair 为 k_j/(k_j+ell_j)；source pair 为 k_j*l/(k_j*l+ell_j)。新 closure 模式使用其自己的 k_j 和 l；没有可用 pair 的模式使用 triangle。

令 rho_j 为这四个实际模式比例的最小值。若所有使用的 pair cap 在 j 处严格为正，则 rho_j>0；遇到零 cap 则如实允许 rho_j=0，不把已证的非正 cap 顺序规则套进本命题。

对任一模式返回的完整证明，若 w_j>0，则其 Theta_j 权重 lambda_j 满足

```text
lambda_j >= rho_j*w_j.
```

证明：triangle 中该权重精确为 w_j U_j/(U_j+ell_j)。pair 中 D138 固定乘子 v_j>=max(0,w_j)，由 D209 的 h slack 分解，active-upper 权重为 v_j k_j l/(k_j l+ell_j)，故同样得到下界。其余 LE 权重只非负叠加；后续往早前缀的替换不会抵消原 LE 权重。alias EQ 允许带符号，但不能取消 LE 身份。所有四种模式分别满足下界，所以固定 argmin 选哪张证明不影响该保证。

现考虑下一 bank 的两条差分读出 r1=g1-g2/2、r2=g2-g1/2，其内部完整 cap 为 c1,c2>0。设它们在同一 q_j 上的合并系数 w1j,w2j 均为正，则 D209 的共有权重必有

```text
mu_j=min(lambda_1j/c1,lambda_2j/c2)
    >=rho_j*min(w1j/c1,w2j/c2)>0.
```

这是同一物理 graph slack 的保留保证，不依赖两张 cap 证明是否选了同一种模式。两张证书各自有非负 LE 权重还不够，必须核对它们共享的是同一原行身份。

## 对普通 Conv 的具体含义

同一输出 channel 的相邻空间读出，在同一父幅值 q_j 上的有效系数为 u、v，已包含 BN 的共同尺度；于是 w1j=u-v/2、w2j=v-u/2。二者同时严格为正当且仅当

```text
u>0, v>0, 1/2<u/v<2.
```

因此，重叠卷积 tap 满足这个普通条件、父门满足 rho_j>0、下一 cap 为正时，候选必保留该父非线性余量。私有边缘坐标只有一侧系数非零，不满足条件。负的同号 tap 可在原输入盒层产生同号端点余量，但不能据此套用上述 active-upper 的正系数命题。

反号 tap 不满足上述正系数保证；在根输入盒上，完全交替符号的相邻窗口还可使两差分的端点余量交集为零，所以平移同型本身不保证收益。这不宣称非线性父 bank 中反号 tap 的完整证明交集必为零。也不能将平移后不同坐标的 slack 当作同一个变量，全图取所有窗口的交集通常会丢掉关系。必须按物理 source/row 身份对齐每一对窗口。

这一条件只保证一个非零共同关系载体，不保证最终界严格变紧、当前输入上所有相关门 crossing、或出现新 CERT。后续真实权重普查和完整域实验须分别报告这些条件，不用满足条件的少数通道代表全层。

## 批量表示与新颖性边界

可用有类型的余量场 Theta[a,x] 与稀疏 stencil 表示完整证书 c_i-r_i=L_i Theta+N_i E。在相同物理索引上取 min(L1/c1,L2/c2)，再用原完整 B、tau、s 规则，逐项实例化应与 D209 一致。必须保留全部原证明、EQ身份和非负剩余项；只保存共同 min 不能认证两个 cap。

上述完整场编码不改变 gamma 或支持数值，它是消除全前缀复制的必要配套，不单独算作定义创新。若只保存本定理保证的下界 rho_j min(w1j/c1,w2j/c2)，则通常是更弱的共同余量，不得宣称继承 D209 精度。GPU 张量批处理同样不自动证明浮点健全性或费用优势。

D209 查询按出生顺序反向替换方向，包含后向遍历；lambda 是数学上的非负线性证明权重。准确边界是：固定域内支持演算，不读取 LP dual、不优化乘子、不在失败后切换 rescue。不能把它宣传为没有后向计算的纯前向算法。本命题不改变该边界。

## 当前实现的完整首 bank 入场下界

对完整原输入维度 d、首 bank 宽度 m，D209 relu_bank 每门先产生一个 scalar _view；继承 D207 的 _view 为整父因子身份至少收 d entries。随后 bounds 固定调用正负两个 support，每次无条件创建四份 Proof，每份 _proof_entries 又至少收 d。九次是不同对象构造，不是对同一次 charge 重复求和。因此

```text
first_bank_entries >= (1+2*4)*d*m = 9*d*m.
```

该账是累计 lineage、不退款；GC 或及时释放临时对象不能取消已冻结的逻辑账。稳定门也先经过 ranges，因此该下界不依赖权重、输入标签、稳定性、相位可达性或任何极端有理数。尚未计 affine 系数、原图、共同余量、第二 bank、terminal 与 decoder 的其他费用。

最小现有三模型 CIFAR100 medium 为 d=3072、m=14400，仅这部分已为398131200 entries，超过64000000。不应启动注定超账的完整首 bank 后误报 UNKNOWN 为“数学规则无效”，也不能只选几个窗口、减小 d、提高预算或把累计账偷换成 RSS来宣称通过。该结论否定的是当前实现的真实规模入场资格，不否定 D209 数学定理。

本轮仅从已认证完整模型元数据复核全三模型下界，不解码系数、执行网络或候选。完整数学组件仍为 D209 的4100 tests/216 files。定义研究要继续；下一实现必须让这条跨层规则在完整普通结构和原预算下接受真实检验，不能以压缩证明 metadata 本身替代能力目标。
