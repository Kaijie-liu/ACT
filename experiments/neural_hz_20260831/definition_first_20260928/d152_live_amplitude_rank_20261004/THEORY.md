# 固定误差方向不能普遍压缩独立激活幅度

本轮检查“少量真实激活 anchors 加共享误差”能否成为比逐门范数替换更强的 Neural-HZ 定义。结论有限但明确：在普通独立可达折面上，只要读出仍采用固定仿射误差方向，即使允许误差与原源、相位任意相关，也不能用更少总幅度维数覆盖全部真实输出。这排除一种具体定义假设，不是证明非凸 Neural-HZ 不可能改进。

以下为纸面证明和对旧研究的归纳；不是新候选实现、机器证明或网络成绩。全部原连续源、原 signed bits 的 0/1 视图、EQ/LE、共享身份、零点双标签和具体输入 decoder 仍保留。

## 固定加载表示的维数限制

设 q 是 m 个真实 ReLU 输出，u=q_K 是 k 个保留的原门 anchors。考虑所有真实 labelled 状态均可实现的关系

```text
q = A u + B z + C beta + d + E eta.
```

所有矩阵固定；z 表示原源和此前状态，不包含本层新相位作为额外复制源。eta 可以与源和相位任意相关，不要求独立、连续、凸或具有盒约束。健全性至少要求每一个原真实状态有某个 eta 实现此式。

对一个未保留门 i，假设真实父域内存在开仿射 chart：gi=ai^T t+bi，ai 非零，零面两侧均可达；该点附近没有其他当前门或祖先相位切换，z 与保留 anchors 局部仿射。需在真实可达域或其仿射包相对内部成立，不能用虚构独立特征盒替代。

任取 v∈ker(E^T)。左乘后 eta 消失，得到每一个真实状态都满足的精确恒等式。在 gi=0 处，两种合法 beta_i 标签具有完全相同的 q、u、z，因此 v^T C_i=0。比较横跨此零面的 Jacobian 跳跃：左侧只有门 i 跳跃，右侧固定仿射项没有跳跃，相位 i 的跳跃贡献已为零，故

```text
vi * ai^T = 0,  所以 vi=0。
```

于是 ei∈range(E)。若 U 中每一个未锚门都满足上述可达独立折面条件，则

```text
span{ei : i in U} ⊆ range(E),
rank(E) >= |U|。
```

若全部 m-k 个未锚门均满足条件，误差维数 r 至少为 m-k，总计 k+r>=m。只用更早层、在这些新折面附近局部仿射的 anchors 时，对全部新门适用 r>=m。增加误差的相关范数或依赖谓词并不能改变被 ker(E^T) 消掉的恒等式。

这是 [D004 的原门子集障碍](../d004_observable_interface_20260928/D004_RESULTS.md) 和 [D131 的固定仿射 decoder 障碍](../d131_nonlinear_common_decoder_20261002/THEORY.md) 的直接延伸，不宣称新的外部下界成果。它不涵盖相位依赖加载、共同非线性 decoder、其他 nonlinear 坐标或没有独立可达折面的特殊父域。也不推出当前真实模型满足全部定理前提。

## 完整活读出才决定允许压缩的方向

若只需要表示完整活读出 Vq，同一证明给出

```text
span{V ei : i in U} ⊆ range(E),
rank(E) >= rank(V_U)。
```

这里 V 必须同时覆盖所有后继、残差、旧谓词及重构用途。一个实际 identity-q skip 会强迫全幅度维数；原源 skip Sz 不等于 identity-q skip，不能混为一谈。相反，消费者输出个数少只给 rank 上界，不证明权重实际 rank，更不证明端到端成本下降。

本轮三模型元数据检查仅认证完整图中有没有终端单消费者和 B 的整数形状，不能检查独立可达折面、数值秩、可靠神经元界或精确投影。旧 D004 已在旧 descriptor 图报告 CIFAR 尾部 100×100、Tiny 尾部 200×200；因此新检查即使吻合，也只是补原 ONNX 来源身份，不是新的压缩发现。

## 正权聚合的四行外包并非新的精确域

另一个被检查的替代是只保留互不相交组的正权聚合 pG=sum_i wi qi，wi>0。前提是所有消费者、旧谓词和重构均不再需要单个 qi，原源、原 beta、可靠 crossing 界和逐门 guards 仍保留。可用

```text
pG >= 0
pG >= sum wi gi
pG <= sum wi ui beta_i
pG <= sum wi gi - sum wi li(1-beta_i)
```

健全外包精确聚合关系，但并不等价。一个普通例子是 g=(x+1/4,y-1/4,z+1/2)，原源盒 [-1,1]^3，w=(1,1,1)。在源零点、beta=(1,0,1) 处，真实 p=3/4，四行却允许 p=1：其聚合下界为 1/2，上界为 7/4。它不是 ADV。

以 m 个门、k 个组计，候选保留 2m 个 guards 加 4k 条聚合行，而逐门精确参照为 4m 行。若 si=nnz(gi 的旧源系数)、sG=nnz(sum wi gi 的旧源系数)，在无额外相消的声明布局中，候选变量系数数为 2 sum si+4m+2 sum sG+4k；参照为 2 sum si+6m。差额为 2 sum sG+4k-2m，行少不保证 nnz 少，原源及 bits 更没有消失。

保 guards 时，精确 LP 投影的聚合上下界是 sum wi max(0,gi) 与 sum wi min(ui beta_i,gi-li(1-beta_i))；直接展开一般需要随组宽指数增长的不同组合行。D004 已分析这一精确投影与扩展变量的代价。本轮四行只能称健全外包，不能以旧记录中“UNSOUND”的措辞声称它连外包都不健全；旧反例否定的是作为精确替换的主张。这个已知投影折衷不够成为新的 Neural-HZ 定义。

## 下一定义必须改变的实质假设

不要实现固定 anchors 加固定低秩误差的通用压缩，也不要把四行聚合直接包装成新域。相位依赖生成元确实不受上述固定加载下界限制，但直接写 diag(beta)g 已是 D001 的精确图改写；需要额外的可组合简化与完整查询优势才算进展。共同非线性 decoder 也不受此下界限制，但 D131 已说明其源绑定和终端恢复幅度的成本尚未解决。

下一项定义研究应明确给出：在普通混权块和后续非线性上，哪一部分共同幅度关系被实质替换、为什么仍与原源和相位绑定、终端不恢复逐门全图时如何健全查询，以及强参照下的完整费用。不能以又一轮存储优化或附加 helper 代替这一交付。本轮不选择尚未满足这些要求的候选，也不将路线筛除计为能力提升。
