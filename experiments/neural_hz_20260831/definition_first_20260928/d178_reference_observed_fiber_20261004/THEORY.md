# 参考相位源观测与联合幅值候选

本轮提出并纸面核对一个具体修正：共同幅值代理同时保留完整消费者的源投影，以及该投影在固定参考相位下的值；不另存参考掩码的输出幅值。它严格收紧 D157，支持误差在参考相位归零的逐层传播。一个普通混权两层控制证明这种修正确实传到后继 ReLU，但原精确 HZ 也能证明该控制，尚无强参照下的净收益。以下不是新颖性、组件、GPU 或 benchmark 资格。

## 元素和出生变换

保留完整父元素的连续源、全部原整数二元身份、EQ/LE、共享 frame 和原输入 decoder。各新 bank 有唯一共享连续坐标；具体化使用同一赋值满足全部旧谓词与新 bank 关系。不同消费者不能各选一个代理。没有 bank 时原 HZ 精确嵌入；按具体化包含定义语义精度，不声称完整格或最佳抽象。

对整个当前父域上的新预激活 g，取既有结构规则给出的常数参考 b，令 d=g-b，tau_i=1 当且仅当 b_i>0。tau 不是实际相位的固定或一次相位搜索，也不要求这个参考切片可达。实际原相位 beta 全部保留，包括零点的两个合法标签。

令 B 覆盖新 q=ReLU(g) 的全部活消费者、谓词和重构用途；C 按 D157 规则为 B 加一个共享 mass 行，已有相同行则复用。实际消费者必须有认证映射到 Cq。原父状态的 raw-source skip 另作同一源读出，不冒充对新 q 的 identity 消费。不能删去真实 identity-q 消费者制造窄接口。

令 p=rows(C)、m=rows(g)，H=C D_tau。E 必须在整个当前父原生域上认证 ||d||²<=E，不能只在具体网络轨迹上成立。新增 p 个连续坐标 delta，定义一个共同存在见证 t：

```text
C t = C d,
H t = H d,
||t||² <= E,
delta = C(D_beta-D_tau)t.

Cq denotes C D_tau g + C(D_beta-D_tau)b + delta.
```

所有原相位 guards 仍绑定实际 g。可靠 L/U 下使用 g_i<=U_i beta_i、g_i>=L_i(1-beta_i)。D157 的 branch caps、mass dominance 和旧有限行同步代入 a=Hd+delta 后保留；这些真实图有效加强项不是裸球关系的自动后果。有限界可归一化 delta 连续因子，原 bits 不删除、不 pivot、不连续化。

对任意父成员，取 t=d，delta=C(D_beta-D_tau)d。上述读出正好是 C ReLU(g)，所以构造健全，且保留全部合法零标签。由于证明覆盖整个父抽象域，它可以递归，不是事后将真实轨迹相关性强加给已有独立误差。

该定义没有保存全部新 q 再加 helper。t 是被投影掉的共同见证，不是另一份具体输入；抽象可行输入仍必须在原网络验证才能算 ADV。域保持真正非凸关系：m=p=1、C=1 时 Ct=Cd 强制真实单门 ReLU 图，连输入输出关系本身也不是凸域，而非只有无作用的二元标签。

## 精确切片和跨层规则

固定同一源和 beta，新代理满足 t-d in W，其中 W=ker(C) intersect ker(H)。因此它细化 D157 的 ker(C) 代理；W 非零时仍可能有损。

当 beta=tau 时 delta=0，整包 Cq=C D_tau g 精确。beta=1-tau 时利用 Ct=Cd、Ht=Hd 也有精确包；全 on/off 同样精确。这些是同一元素中的条件恒等式，不枚举相位、创建子问题或选择不同验证器。

对任意固定线性消费者 M，记 C_i 为 C 的第 i 列，取覆盖整个父域的常数 Emax>=E。由 Frobenius 上界：

```text
||M delta||²
 <= ||M C(D_beta-D_tau)||_F² ||t||²
 <= Emax sum_i ||M C_i||² |beta_i-tau_i|.             (1)
```

整数相位的失配量 |beta_i-tau_i| 为仿射式。tau_i=1 时为 1-beta_i，负系数不能截掉。(1) 不引入旧相位与新相位乘积；代价是将条件 E 换成全域 Emax，可能变松。

Affine/Conv、同 frame Add/Concat 先合并同一 delta 和源身份的系数，再应用 (1)。canonical 读出显式源系数为 C D_tau A，不是把源遗忘为一套独立误差。若新 d 写成源项、旧相位列和 M_k delta_k 的和，沿 D157 的固定等权 Cauchy，用源项平方界、相位列平方界和 (1) 相加，得到新 phase-affine E；项数、历史 bank 和系数填充均收费，不承诺半径下降。

从精确输入/前沿开始，若全部历史 bank 的原 beta 都等于各自 tau，归纳每个 delta=0，整个表示等于该相位切片上的真实仿射网络，包括 mixed weights、偏置和共享 residual。若接入此前已经有损的父域，则仅对该扩大前沿精确，不能追回旧层损失。参考切片不可达时结论为空集结论。

这与 D121 已有参考相位展开相关，不能把“参考切片精确”本身称为新定理。这里具体可研究的差异是共同源观测、只保 p 个共享幅值，以及无需高阶相位项的有损递归合同。

## 可直接给线性终端的关系

固定 lambda、mu、nu，令 u=C^T lambda、v=C^T mu、h=H^T nu。对同一 t 配平方给：

```text
2[(lambda-mu)^T a + mu^T Cd + nu^T Hd]
 <= E + sum_i beta_i (u_i+h_i)^2
        + sum_i (1-beta_i)(v_i+h_i)^2,                (2)
a=Hd+delta.
```

右侧对原 bits 仿射；没有额外 ||h||²，也没有 beta_i*d_i 乘积。该式是显式非负平方证书，数学上与已知对偶/支撑理论有关，但不调用优化器、不读 LP 状态、不搜索证书或失败后 rescue。

一个固定候选编译规则是保留 D157 全部六方向，另对每一对 (lambda,mu) 取 nu=-(lambda-mu)，再添加两条坐标 range 行：

```text
|delta_j| <= R sum_i |C_ji| |beta_i-tau_i|.          (3)
```

为明确强参照范围，固定 R=max(sqrt_upper(Emax),max_i(|L_i-b_i|,|U_i-b_i|))。式 (3) 本身只需 R>=sqrt(Emax)；多取端点界使下述旧 LP 蕴含声明成立。不能从 native Emax 偷推较大的旧 LP 已有同一能量界。

式 (2) 的固定编译和 (3) 都只是原生集合的有限外包，不是其精确 LP 表示。下一层可使用原生定理生成健全约束，但不能将较大的有限多面体冒充满足原生范数关系的父域。所有候选点仍走原具体见证验证。

## 普通五门的严格修正和剩余失真

令 P 是五坐标循环置换，A=I+P/4，x in [-1,1]^5，d=Ax，且

```text
b=(1/2,-1/2,1/2,-1/2,1/2), tau=(1,0,1,0,1),
B0=(1,-1,-1,1,1/2), B=[B0;ones], C=B, E=Emax=125/16.
```

五个仿射门非平行、混合两个源坐标、有非零偏置，全部在整盒内 crossing。每个 |d_i|<=5/4，所以能量界有效，x=ones 取等。rank([C;H])=4，核由 n=(3,0,1,0,-4) 张成；不是全源精确恢复。这里 Q=sum(q) 会被后继实际消费，故必须与 B0q 一起声明为 B 的两个完整读出，不能把 Q 的使用当免费辅助接口。

在 x=0、beta=tau，旧 D157 允许共同代理 t=(4/5,-4/5,4/5,-4/5,0)：Ct=0，||t||²=64/25<E，其代理门也严格满足该相位和原分支界。旧包为 (B0q,Q)=(1/4,31/10)，真实包为 (1/4,3/2)。新 Ht=Hd 排除它，因为 Ht 的 mass 分量为 8/5 而 Hd=0。

接真实混权及共享原源 skip：

```text
J=Q+2B0q-3d1+d3-2d5-2,
r=ReLU(J-1/4).
```

整个 beta=tau 源切片上，新包精确给 J=0、r=0；旧 proxy 在 x=0 给 J=8/5、r=27/20。门权重为 (3,-1,-1,3,2)，不是单独 mass 查询。可继续与 B0q 和原源作 Add，必须复用相同 packet。这是两层、带 mixed consumer 和 live source skip 的条件化控制，不是全盒 CERT 或实际 ADV；完整旧四行图在同一切片同样精确。

新域仍有损：取 d=-3e5/4、beta=(1,0,1,0,0)，t=d+n/20=(3/20,0,1/20,0,-19/20)。Ct=Cd、Ht=Hd、||t||²=371/400<E，实际门及代理门均严格满足该相位，分支 caps 与 mass 关系成立。新包为 (1/10,6/5)，真实包为 (0,1)。该源确在盒内部，因为

```text
A^-1=(1024I-256P+64P²-16P³+4P⁴)/1025,
||A^-1(-3e5/4)||_infinity=768/1025<1.
```

所以这是严格细化且仍有损的域，不是完整网络图换名，也不能凭这个修正宣布保住全部旧能力。

## 强参照和新颖性的准确边界

旧同源四行 LP 已给 t_i^old=q_i-beta_i*b_i-tau_i*d_i>=0。tau=0 时它不超过 (U_i-b_i)beta_i；tau=1 时不超过 (b_i-L_i)(1-beta_i)。按上述 R，逐项组合便蕴含 (3)。因此新增 range 行和参考切片控制不是胜过旧四行 LP 的证据。原能量证书若也交给旧图，它还能推出相应已知联合有效关系；比较必须计入双方完整成本。

裸几何等于 D168 对同一代理堆叠 [C;H] 后投影掉 masked-H 输出，也属于 D160 广义平移子空间几何；不能宣称发明了新的投影或椭球原理。但 D160 的既定 S=range(raw A) 不自动加入 H=CD_tau，本例 A 可逆时该 S 约束没有作用。

[Ellipsotopes 的 Definition 2 与仿射变换规则](https://arxiv.org/pdf/2108.01750)已有带线性约束的范数生成元表示。本候选另外保留原离散相位及其对共同代理的作用，不能据此宣称单纯“球加 bits”具有新颖性。当前候选的研究价值仍须由这种源观测选择、跨层消费、实际结构与完整成本共同证明。

## 完整费用和本轮决定

新 bank 仍只有 p 个共享连续幅值与 m 个原 bits，没有新增 masked-H 幅值。H 可以复用 C 的列掩码，但 Hd、C D_tau g 的源展开和后继传播不能免计。

原生见证可数学消去：K_beta=[C;H;C D_beta]，z=[Cd;Hd;Hd+delta]，要求 z in range(K_beta) 且 z^T(K_beta K_beta^T)^dagger z<=E。Gram 不超过 3p 维，其块因 D_beta²=D_beta 对原 bits 仿射；没有跨坐标 beta_i beta_j。然而朴素构造仍需 O(mp²) 算术、O(p²) 当前矩阵和 O(p³) 线性代数，另计有理位长、证据及 C；未知相位查询不是一次给定点 Gram 检查。没有引入 SDP/QP 或新的验证 helper。

保留旧六方向再增加六方向及 range，有限行总数为 2m+18p+2*rows(B)，未计共同继承行。旧逐门图为 4m 行。同口径仅行数的候选窗口是 m>9p+rows(B)，不是时间、nnz 或显存胜利；五门控制 p=2、rows(B)=2，为 50 行对旧 20 行，没有总成本优势。range 在 canonical delta 坐标下有 2p 行，至多 2p+2 nnz(C) 个系数，但其源加载、全部旧 guards、能量系数、物理共存和终端转换另计。

GPU 可以批量处理固定 mask、平方系数归约和有证矩阵作用；本轮没有执行 GPU、取得浮点 soundness 或速度资格。源/相位/bank 的全部历史增长仍存在。smooth、Attention、LayerNorm 和 Transformer 闭包未由本证明建立。

决定：保留这个可反证的定义候选和其真实结构落点，不立即接入生产或启动组件继承测试。下一项实质检验应是预终端完整 affine bundle 上的精度与完整成本，而非继续扩展无关 helper。新颖性、强旧路径优势、同结构 shadow、逐家族零回退及全部 2413/独立 400 回放均未完成。
