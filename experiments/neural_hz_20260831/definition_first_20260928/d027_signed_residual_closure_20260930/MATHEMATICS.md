# 带符号残差关系的跨层正控与组合边界

本轮将上一轮的联合约束正控加强为跨层对照：父块完整联合凸包及子门完整接口凸包的交集仍允许一个违反真实残差界的点，保留共享源的残差行能够排除它。收益可以继续穿过第二个 ReLU。与此同时，通用支持 DAG 的编码仍可改写为已有 min/sum 电路，因此不把这一语法声明为新非凸抽象域，也不启动该重复表示的实现。

这是手工有理数证明及独立数学复核，没有执行候选、数学测试、网络或求解器。域创新、真实网络适用率、完整成本收益和 GPU 性能均未得到认证。来源与权限见 CHECKPOINT.md。

## 精确载体与辅助关系

讨论的研究对象可以记为 (H,G,E,decoder)：H 保留原连续因子、全部原二元因子、EQ/LE 及共享 frame；G 是原门关系；E 为同一源上经证明的带符号支持事实。具体化保留所有原输入和原 bits，存在量化内部连续量。原 HZ 通过 E 为空嵌入；当 E 的事实由原关系推出时，加入 E 不改变整数具体化。

这只是一个已有 reduced-product 型研究框架，不是已建立的新域。LP 查询松弛可能变紧，不代表精确 HZ 不能表达原网络。没有删除原 gates、二元因子或 decoder，也没有全局 ideal hull 声明。

## 加权残差规则

设 q=ReLU(g) 及其原 bit alpha，实际前向消费者为 z=a*q+v。a 是任意固定实系数，可以为负；v 来自同一 frame，包含真实其他输入或 shortcut，不能是独立复制的源。若已有有效常数上界

```text
v <= B0,
a*g+v <= B1,
```

则对整数原相位有

```text
z <= B0+(B1-B0)*alpha.                         (R)
```

alpha=0 时 q=0，alpha=1 时 q=g，直接证明该式；g=0 时两个原 bit 选择分别满足各自前提。负 a 不改变证明。此规则是已知 indicator 条件支持界，不是新不等式；证明中的两种情况不是运行时相位分裂。

真实卷积残差 z=c+sum_j w_j*q_j+S*x 可对结构固定的 k 写成 a=w_k、v=z-w_k*q_k。计算两个支持界及其共同源证书必须付账，不能把它们当免费 oracle，不能按待证性质、模型身份或 LP 状态选择 k。若原 z 坐标已被表示，新增行只需 z 与 alpha；否则其定义/展开的成本仍完整存在。

## 父完整联合凸包之后仍缺少跨层关系

沿用上一轮的普通混合权重例子，x,y in [-1,1]：

```text
f=x+y/4, h=x-y/4, r=ReLU(f), p=ReLU(h)
g1=1/10+r-p/2, q1=ReLU(g1)
z1=q1+3p/2-x.
```

父门 bits 为 beta,eta，子门 bit 为 alpha1，零点保留所有原合法选择。共同源恒等式 r+p=x+max(|x|,|y|/4) 给出 r+p<=x+1；单门有效源行 p<=5(x+1)/8 给出 3p/2-x<=1。因 g1+3p/2-x=1/10+r+p-x<=11/10，规则 (R) 得到

```text
z1 <= 1+alpha1/10 <= 11/10.                    (S1)
```

考虑新的父点 x=y=0、r=p=49/100、beta=eta=1/2。它是两个真实父块点的各半混合，源分别为 (49/50,0) 和 (-49/50,0)。正源上两个门均激活、值均为 49/50；负源上均为零。因而该点满足带全部父 bits 的完整父联合凸包，及任何有效父块线性约束。与上一轮不同，它不违反共同源行 r+p-x<=1。

父输出的精确像为

```text
Q* = {r,p>=0, |r-p|<=1/2, r+p<=2}.
```

必要性来自上述恒等式与 ReLU 的单调、1-Lipschitz 性质。充分性取 x=(r+p)/2、y=2(r-p)，则 x,y 在原 box 中，f=r、h=p；零输出允许相应的合法原 bit。Q* 这里只描述输出像，不声称已保留源和祖先 bits 的条件联合关系。

子门在 Q* 上的完整带标签图凸包包含以下混合：

```text
weight 3/4: r=13/20, p=13/25, g1=q1=49/100, alpha1=1
weight 1/4: r=1/100, p=2/5,   g1=-9/100, q1=0, alpha1=0.
```

两点都严格位于 Q* 内部，且 g1 非零。平均得到

```text
r=p=49/100, g1=69/200, q1=147/400, alpha1=3/4,
z1=441/400.
```

父源取前述 x=y=0，所以这些坐标在两个局部凸包的交集中一致。它们也满足 D020 的差分行（f-h=r-p=0）和 D025 的 child 容量 q1<=1/10+(7/8)beta、q1-g1<=eta/4。

但 (S1) 的上界为 1+3/40=430/400，差距 11/400。因此跨子门的共享源残差事实在完整父联合 hull 之后仍有额外作用。这个结论不声称击败子门在完整 (源、祖先 bits、全部父门) 条件图上的 hull；被比较的子接口明确为 (r,p)。原 HZ 整数语义没有丢失这条关系，分数点也不是 ADV。

## 收益可继续经过第二个激活

接上另一个混合权重和非零 bias 的普通消费者：

```text
g2=-3/10+z1-p/2, q2=ReLU(g2), z2=q2+p/2.
```

原 bit 为 alpha2。g1 在源 (0,-9/10) 为负、(0,1/2) 为正；g2 在 (0,0) 为负、(9/10,0) 为正。因此不是只处理稳定门或共零门。

由于 p<=5/4，inactive 支持为 C0=5/8。由 (S1)，active 支持为 C1=7/10+alpha1/10。取有效差值界 M01=7/40、M10=-3/40，有

```text
z2 <= 5/8+(7/40)*alpha2,
z2 <= 5/8+alpha1/10+(3/40)*alpha2.              (S2)
```

对整数 alpha2 这两行选择正确支持，对分数 bits 仍是有效 LP 强化。推出 z2<=4/5，源 x=1,y=0 达到该值。

上一节的更强旧点可继续取 g2=q2=223/400、alpha2=1，得到 z2=321/400，超过 4/5 达 1/400；(S2) 第二行的上界为 31/40，违反量仍为 11/400。这个点在保留的松弛接口上满足最后一门的精确 ReLU 图，不需要再制造一个分数相位误差；但它的 z1 已不可由实际网络达到，不能称为真实网络可达点。

这证明第一项跨层关系的收益能传递到下一激活，不证明第二项规则有独立新增收益，更不证明所有混合卷积均无损。具体地，旧点已被 (S1) 排除，所以不是在加入 (S1) 后检验 (S2) 独立严格收益的消融。

为明确双方使用相同门界，可共同取 Q* 推出的 g1 in [-3/20,39/40]、q1 in [0,39/40]，以及由 p in [0,5/4]、x in [-1,1] 得到的保守 z1 in [-1,77/20]、g2 in [-77/40,71/20]、q2 in [0,71/20]。旧延伸点满足这些界。新增支持行之外，不向新侧预装更窄的门界；也不声称对照已包含由完整网络关系直接求出的最紧 z1 区间。

## 有限模板的条件性前向传递

设当前有 T*s<=C，其中行是结构规定的观测，不依赖待证性质。对于 y=W*s+b，若存在预先给定或以固定代数规则构造的非负 K，且 T_next*W=K*T，则

```text
T_next*y <= K*C+T_next*b.
```

这是经典模板传递。Add/Concat 使用同一源先合并表达式。对称坐标模板正负 I 可按权重正负拆分构造 K，但可能丢掉联合信息。按上述等式验证一个 K 不需要 LP；为获取最优 K 另设优化问题并不属于本轮授权路线。

单个坐标 ReLU 的两个分支是将该坐标置零或保持的固定线性映射。两边分别取得有效支持 C0,C1 后，可用原 bit 连接。对不同门逐次使用同一公式无需枚举相位组合，但模板和支持节点的累计量必须计入。此构造是健全的可组合框架，不是固定宽度的无损压缩定理。

## 固定和差模板确实会遗漏普通混合方向

取模板 T 为正负 x1、x2、x1+x2、x1-x2。令 X 为以下八个点的凸包：

```text
(1,0),(-1,0),(0,1),(0,-1),
(3/5,3/5),(3/5,-3/5),(-3/5,3/5),(-3/5,-3/5).
```

令 Y=conv(X union {(1,-1/5)})。X,Y 在 T 上的全部上界相同：坐标方向为 1，和差方向为 6/5。但方向 2x1-x2 在 X 上最大为 2，在 Y 上为 11/5。逐顶点代入即可检查这些有理数，不需要求解器或采样。

经过普通混合可逆矩阵 [[2,-1],[1,2]] 并接两级非线性：

```text
r=ReLU(1/10+2x1-x2), p=ReLU(x1+2x2),
q=ReLU(1/10+r-p/4), z=q+p/4=max(p/4,1/10+r).
```

p/4 在两源上至多 1/2；z 的真实最大值在 X 上为 11/5，在 Y 上为 12/5，分别由 (1,0) 与 (1,-1/5) 达到。门均有普通跨零点。只保存 T 的数值上界不能区别二者，故不能无损回答这个实际混合方向的查询。

该小例只界定这一接口的遗漏，不是一般复杂度障碍、真实模型出现率或 HZ 本身的表达限制。下一候选必须解释新增消费者方向的共同源支持从何而来及如何付账，不能仅声称原谓词还在就已解决廉价查询。

## 相位选择支持电路仍不是新表达能力

设 C0,C1 是同一 frame 上的有界支持函数。取 M01>=sup(C1-C0)、M10>=sup(C0-C1)，允许 M 为负。原 bit alpha 的条件上界可由两行编码：

```text
t <= t0+M01*alpha,
t <= t1+M10*(1-alpha).
```

叶使用有界带符号仿射式；内部可用 min、非负加权 sum（常数可带符号）及上述条件连接。为节点引入连续辅助量并保留原 bits，在整数 bits 下，对任何多个物理观测 o_i<=C_root_i，存在辅助量使 o_i<=t_root_i 当且仅当所选支持界成立。

正向由单调性及选中分支归纳 t_node<=C_node；反向同时令所有辅助量等于真实电路值，M 保证非激活行也成立。共享节点和多个 roots 不影响证明。有限辅助下界包住真实 C 即可；物理观测只受 o_i<=t_root_i，不强制等于辅助量或继承其下界。禁止把辅助支持量当真实 activation 用负权消费。

M 必须由真实 C 的有效界认证，不能从可任意向下的辅助量差值读取。整数节点上界 U 可能截断分数 bits 下的 min 值；例如 C0=C1=beta、M01=M10=1、beta=1、alpha=1/2 时，未截断 min 为 3/2，而整数上界 U=1。这个额外截断仍 integer-sound，但不能称两者 LP 投影完全相同。

更重要的是，该两行本身就是 min(C0+M01*alpha,C1+M10*(1-alpha))。用保守有限下界平移每个节点，负常数和 signed affine 叶可转为非负叶及非负 sum；额外上界只是再加一个常数 min。在叶函数和观察量集合相同的前提下，它没有增加新的电路组合原语。

不能将这个构造器结论扩大为整个接口的信息等价：D024 文档的叶主要是 A(beta)，根为非负 activation。若本轮允许连续源叶或新的带符号物理观察量，确实增加了相对于该 beta-only 接口的关系信息，不能靠平移消除这些新输入。它仍是经典模板／约化积式增强；非凸性由原 HZ 的二元约束提供。该信息增益和 guard 语法的新颖性是两件事，本轮不据后者启动一个新命名的 DAG 实现或宣称域创新。

## 代价与研究决定

若仍把上述支持系统作为支撑组件，其扩展编码按节点、边和仿射叶实际支持计价。每个条件节点至多两个三项行，并有变量、上下界、M 证书和原 bit 引用；min 节点按入边生成行，sum 节点按实际 fan-in 生成行。原网络、源 predicates、全部 bits、decoder 和终端求解没有被免除。有限 frontier 宽度不等于有限总存储。

结论是保留加权残差定理和两级正控，否决支持 DAG 本身作为新表达力；固定小模板的无损性也被具体反例否决。尚缺的是结构统一、成本可控地获得真实消费者方向的共同源支持及其实际跨块效益。没有以此提高预算、减少测试人口或修改正式成绩。
