# 普通对称双门上的物理投影不增益定理

本页给出比单点相位修复更强的负结论：对于一整类普通同源双 ReLU，多行共同相位 hull 虽可严格加强带标签集合，但在强单门参照下不改变源和输出的联合投影。因此本族不能用作该候选的 phase-free 读出或后继能力阳性。这个结果只作纸面证明，没有数值执行。

## 明确的比较范围

设 x,y∈[-1,1]，

```text
f1=x+alpha*y+h, f2=x-alpha*y+h, q_i=ReLU(f_i),
alpha>0, alpha+abs(h)<1.
```

每个注册前向斜率 a_i 和反向斜率 b_j 都在 (0,1]，并且每个 a_i*b_j<1。两方向均使用紧盒差分界

```text
c(a)=(1-a)*(1+h)+(1+a)*alpha.
```

旧参照 O 保留同一源箱、两门各自完整 source-labelled 凸包，以及每个注册前向和反向行组成的完整 D203 块。新参照 N 保留相同单门 hull，改为全部行的共同 D216 hull。双方可另加 THEORY 所列 D216 四条联合坐标界，以下结论仍成立。

结论是 proj_(x,y,q)(O)=proj_(x,y,q)(N)。不能把该结论推广到没有完整单门 hull 的较弱参照，也不覆盖非对称 x 系数、不同偏置、超出所列斜率范围或额外相位耦合。

## 完整单门带标签 hull

记

```text
U=1+alpha+h, L=1+alpha-h, K=1-alpha-h,
J=1+h-alpha.
```

这些量都正。对符号 epsilon∈{1,-1}，f=x+epsilon*alpha*y+h 的完整 source-labelled hull，除源箱、0<=beta<=1、q>=0 和 q>=f 外，恰有四种上界：

```text
q<=U*beta,
q<=x+1-K*beta,
q<=alpha*(1+epsilon*y)+J*beta,
q<=f+L*(1-beta).
```

可从两相位的源质量消元直接证明完整性。令 z=epsilon*y，开启源质量为 (X,Z)。源与相位均值给出

```text
max(-beta,x-1+beta)<=X<=min(beta,x+1-beta),
max(-beta,z-1+beta)<=Z<=min(beta,z+1-beta),
q=X+alpha*Z+h*beta.
```

该 affine 表达式的上端点取两项 min 的四种组合，恰为上述四行。下端点不超过 beta*f，因为 (X,Z)=beta*(x,z) 总满足源质量区间；而 beta*f<=max(0,f)。因此 q>=max(0,f) 已足够覆盖下端点条件。q>=0 保证开启预激活非负，q>=f 保证关闭部分预激活非正。非零相位质量归一化后给实际源点；零质量按连续闭包处理，零预激活原标签均保留。

对固定可行物理 (x,y,q_i)，可行 beta_i 是闭区间。其最大值为

```text
B_i=min(1, (x+1-q_i)/K, (f_i+L-q_i)/L).
```

另两条上界只给 beta 的下界，因为 U,J>0。

## 两门共有的可行相位下锚点

每个单门的每个物理投影点都允许 beta0=(x+1)/2。这不是假设两个单门具有同一个完整源分布，只是证明它们的可行相位区间有共同锚点。

单门投影的 q 上端是 ReLU 在源箱上的凹包。把任意源混合原子替换成保持其源均值的盒顶点混合，由 ReLU 凸性输出只能增加。因此该上端可由盒顶点实现。alpha+|h|<1 使 x=-1 的全部顶点严格关闭，x=1 的全部顶点严格开启；它们的开启质量必为 beta0。

下端 q=ReLU(f) 也可使用 beta0。固定当前 y，令 t=epsilon*alpha*y+h∈(-1,1)。若 f>=0，取关闭点 x_I=-t，开启点 x_A=(x+t)/beta0-t；若 f<=0，取开启点 x_A=-t，关闭点 x_I=(x+beta0*t)/(1-beta0)。相应质量为 beta0 和 1-beta0。这些点均在 [-1,1]：第一个公式用 t<=1、第二个用 t>=-1，再利用 f 的对应符号。x=±1 的零质量端点直接用唯一非零分量，不作除零。

两个端点构造有相同源均值和 beta0，插值覆盖全部可行 q。故每个单门可行相位区间都含 beta0，B_i>=beta0。

## 共同相位修复全部反馈行

对旧方任意可行 (x,y,q)，取

```text
r=min(B1,B2)>=beta0.
```

beta1=beta2=r 同时满足两个完整单门 hull。若 B1=B2，两门全部旧反馈行因原可行相位不超过 r 而继续成立。若 r=1 也直接成立。下面只需 B2=r<B1 的情形，交换门次序对称。

第二门各反馈行 q2-b*q1<=c(b)*beta2_old，且 beta2_old<=B2=r，所以在 r 下成立。第一门需核查任意注册 a。

若 B2 的紧界是 q2=x+1-K*r，那么 q1<=x+1-K*r=q2，且 q2<=U*r。因此

```text
q1-a*q2 <= (1-a)*U*r <= c(a)*r,
```

后一差值为 2*a*alpha*r>=0。

若 B2 的紧界是 q2=f2+L*(1-r)，利用 q1<=x+1-K*r，直接整理得

```text
q1-a*q2-c(a)*r
 <= (1-a)*(x+1-2*r)+a*alpha*(y-1)
 <= 0.
```

最后一步使用 a∈(0,1]、r>=(x+1)/2 和 y<=1。两种紧界覆盖 B2<1 的全部情况，所以第一门所有反馈行也同时成立。

## 联合 hull 的其余行

两个相位相等时，D216 每个方向的两种 mixed-phase 行都化成 q1-a*q2<=c(a)*r 或对称式。联合幅值 P 的精确坐标上界 U1、U2 至少为实际 ReLU 的上界 U：所有差分行对真实输出有效，且两门各自的 U 都可在源箱上达到。完整单门 hull 已保证 q_i<=U*r，因而满足全部联合坐标界。非负行也不变。

于是每个旧方物理点都能在共同相位 r 上延拓到新方。反向包含由共同 hull 是每个单行 hull 的加强直接得到。两边投影相同。

## 对研究方向的影响

本轮带标签正例 alpha=h=1/8 属于定理范围。不能继续通过改变该族内的小数或注册更多斜率，把带标签分离累计成物理能力证据。凡后继仿射读出只依赖 (x,y,q)，两边能取的读出值相同，故不能从这个局部替换得到新的精确读出上界；若同一精确后继 ReLU 图的预激活只依赖 (x,y,q)，且无额外旧相位耦合，其物理投影也相同。

这没有否定 D216 的精确局部 hull，也没有证明非对称普通结构或额外源关系无收益。但后续应先证明无法共同修复相位的物理分离，再考虑实现。原始非凸 HZ、原相位和全部证据保留，本负结论不改任何正式成绩或旧验证门槛。
