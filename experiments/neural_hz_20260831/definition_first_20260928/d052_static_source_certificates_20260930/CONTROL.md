# 共同源匹配的物理输出与两层对照

这些是解析数学控制，不是数值执行、具体 ADV 或 benchmark CERT。旧点属于明确列出的独立松弛，不声称属于完整联合网络凸包。全部原门与原 bits 保留。

## 保留两个原相位的开放参数族

取 0<=s,t<=L，L>0，a,e in (L/20,3L/20)，原门为

```text
q=ReLU(s+t-L+a), alpha,
p=ReLU(s-t+e), beta.
```

固定匹配给 P=s、N=t、kappa0=kappa1=a、U=e，故新行是

```text
q+p <= s+a*alpha+e*beta.                            (C)
```

上一轮 D051 的 q+p<=s+a+e*beta 仍然正确，(C) 进一步保留了原 alpha 的信息，不改写旧存档。

固定旧点的源与原 bits 为 s=t=L/2、alpha=beta=1/2，输出为

```text
q=7L/20+a/2, p=3L/10+e/2.
```

q 的完整 source labelled 单门 hull 分解使用 (17L/20,17L/20) 与 (3L/20,3L/20) 各半，预激活为 7L/10+a 和 -7L/10+a。p 使用 (17L/20,L/4) 与 (3L/20,3L/4) 各半，预激活为 3L/5+e 和 -3L/5+e。全部源点在盒内部，符号严格，两分解均给出同一个源均值和各自原 bit 均值。

此点通过 D020 对这两个父门的四条差式关系，以及 D049 在固定源顺序下的双向差式与两个 companion 包络。(C) 的左减右恒为 3L/20。D049 两个 companion 的松弛余量分别为 3L/20、L/5；交换 source 顺序也不能排除该点。差值上下界同样有严格余量。

物理读出 Z=q+p-s 的真上界为 a+e，由 (C) 与 bits<=1 得到，并在 (s,t)=(L,L/2) 取等。旧点 Z=3L/20+(a+e)/2>a+e。因此关系不是只约束自由辅助量。

固定上述源混合分解后，真实符号、比较余量及新行间隔都连续依赖系数。在基点附近的小幅普通权重扰动仍保持严格分离；这只是局部开放性结论，不宣称任意宽卷积有用。下一节给一个不依赖等幅系数的具体例子。

## 不同幅值权重和实际终端读出

取 s,t in [0,1]：

```text
f=s+t-9/10, q=ReLU(f), alpha,
g=(11/10)s-(9/10)t+1/10, p=ReLU(g), beta.
```

固定匹配给 P=s、N=9t/10、kappa0=1/10、kappa1=1/5、U=1/5、Delta=1/10。因此 F=q+p-s 满足完整两行

```text
F <= alpha/5+beta/5,
F <= alpha/10+3beta/10.
```

旧松弛点 s=t=alpha=beta=1/2、q=2/5、p=81/200 来自上一节同一组源混合点。q 的两个预激活为 4/5、-3/5；p 的两个预激活为 81/100、-41/100，均严格非零。点上 f=1/10、g=1/5、F=61/200，违反两条新行各 21/200。

这个点通过两个完整独立 source labelled 单门 hull，也通过 D049 的明确有限关系

```text
-(11/10)(1-t) <= q-p <= (9/10)t,
f <= q <= s/10+t,
g <= p <= (3/10)s+(9/10)(1-t).
```

反序 q 上界为 s+t/10，p 上界为 (11/10)s+(1/10)(1-t)；反序差式界为 -(1-t)-s/10<=q-p<=(4/5)t+(1-s)/10。旧点同样通过，两种顺序只是在该点给出相同界值，并非处处同一函数。这里比较的是明确列出的有限生成行，不是所有派生观察。

原 D020 四行也通过：q-p=-1/200，f-g=-1/10，二者之差为 19/200。相位差界为 [-11beta/10,9alpha/10]，校正界为 [-4(1-beta)/5,9(1-alpha)/10]。

只消去 bits，F<=2/5 还不能排除这个旧点。需要实际保留以下物理残差读出：

```text
Z=F+(2/9)(q-f)+(1/4)(p-g).
```

原门已有 q-f<=9(1-alpha)/10、p-g<=4(1-beta)/5。与第一条新行相加，给 Z<=2/5。旧点 Z=203/480，超过真上界 11/480；真实源 (1,1) 有 q=11/10、p=3/10、两个残差均零，Z=2/5 取等。

上述残差是原神经值的仿射读出，不引入新网络或反例搜索。本例证明一般不等幅匹配可以产生终端关系强度差，不承诺宽网络出现率。

## 增益通过下一混权 ReLU 对

回到 L=1、a=e=1/10 的第一节，加入两个真实原门及其原 bits：

```text
w2=1/10-q/2+p-s/4,             t2=ReLU(w2),
h2=1/10+7q/10+11p/5-29s/20,   r2=ReLU(h2).
```

同源合并得 h2-w2=(6/5)(q+p-s)。由 (C) 的非负上式与 ReLU 增量界，

```text
r2-t2 <= (6/5)(a*alpha+e*beta) <= 6/25.
```

旧父点 q=2/5、p=7/20、s=t=1/2 可精确延伸为 w2=t2=1/8、h2=r2=17/40，两个新 bits 均为 1；实际后继差值为 3/10，超过 6/25。

真实源 (1,1/2) 给 w2=3/20、h2=39/100，差值取等 6/25。真实源 (1,1) 的两个后继预激活为 -3/5、-9/25，故后门不是稳定门。正、负权重与非零偏置均实际存在。

比较系统是前述父门独立完整 hull、D020、D049 明确有限行，再接后门的精确图；没有宣称旧点通过新增四门之间全部可能的 D020、全部条件支持或完整前缀联合 hull。本例证明第一层增益能传播，不重复记为第二项独立能力收益。

## 共同相位系数规则的开放后继结构

同样取第一节 a=e=1/10，使用已证 Z=q+p-s<=a+e*beta 与原容量 p<=(1+e)*beta。令下一实际门

```text
r=ReLU(h), h=-u*Z+k*p+d, 原 bit gamma,
0<u<1, 0<k<u*e/(1+e).
```

系数范围开放，不需要精确比例相等。由固定非负组合得到

```text
Z+h <= (1-u)*a+d+e*beta.
```

两条前提共享 psi=e*beta，THEORY 的前向规则给

```text
Z+r <= a+e*beta+(d-u*a)*gamma.
```

取 u=1/2、k=1/40、d=3/40，得到 Z+r<=1/10+beta/10+gamma/40<=9/40。真实源 (0,0) 的 h=11/400>0，源 (1,1) 的 h=-9/400<0。旧父点可精确延伸 h=-33/800、r=0、gamma=0，Z+r=1/4>9/40。

这一步实际消费了前层的共同源证书，不是重新独立求区间。它仍是已有条件观察机制，并不证明相对保留前层新行加后门完整 source hull 又有独立严格提升。
