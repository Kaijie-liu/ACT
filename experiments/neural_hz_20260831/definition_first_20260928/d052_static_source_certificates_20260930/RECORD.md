# 共同源证书研究的证据与下一步

本轮把上一轮的手选关系推进为一般系数下可构造的规则，证明了非点参数扩展、单消费者完整两行投影及一类跨下一 ReLU 的前向传递。它减少了后续实现对免费源证书的依赖，但仍是已知机制的组合，不是已完成的新 Neural HZ 域。

## 本轮新增证据

- THEORY.md 给出任意非负 P、N 的源证书定理、统一系数匹配、保留真实区间参数的求界和完整投影。区间中点仅选择 P、N，不替换模型。
- CONTROL.md 给出开放参数族、不等幅混权终端读出和两种后继传播。旧点通过明确的强单门对照，但不是具体网络反例。
- 不等幅例中的实际读出真上界为 2/5，旧松弛点为 203/480，严格缺口 11/480。这是纸面强度差，不是数值性能或正式新解。
- 非点参数证明和一般匹配由独立协作者复核；不等幅正控及两个后继结构分别复核。根代理核对源支持、归一化补偿、零点原相位、投影范围及正反顺序公式。

对照核查没有发现新的域语义：输出行现有 D049 混合 source/phase 语言已经容纳。不能因为规则可实现、可并行或形式更简短，就把它命名为独立域。

## 后续研究选择

不实施全部单门 facets、不建立高阶矩层级，也不添加一个包装现有 HZ 的新载体。保留本规则作为共同源关系生成组件，下一实现应直接检验它是否在普通真实结构上有用，而不是扩大形式字段或重复展示同一玩具例。

实现需要冻结统一结构配对和原 frame 生命周期，接入可靠原参数区间，输出上述完整两行，不靠实例、标签、历史结果或 LP 状态选择。先继承全部已有数学测试人口并增加定向测试，再进行原完整真实来源人口及强对照；不能因 D047 曾耗尽资源而缩成人口更小的研究成功。

真实列身份与原 phase 方向、物理 frontier 到终端 latent 的成本、可靠浮点/GPU 生成与 A/A^T、具体 decoder 均尚未认证。本轮没有为这些缺项补发资格，也没有将支持生成的 O(d) 代价冒充整个验证器速度。

同时，目标中的定义创新继续开放：需要新的结构不变量和传播/简化定理，而非只增加已知有效行。这个组件即使随后成功，也只能是其中的支撑证据；不能据此把长期目标改成一个容易通过的小内核。
