# 同一余项上的重叠约束与相位中心闭包

本轮针对真实卷积的空间局部性，把 D148 的共享余项块细化为同一坐标上的多个重叠范数约束。每个原门仍只产生一份余项和一个原相位；局部球不是独立 patch 噪声。下述闭包证明支持一个默认关闭的数学组件，不能据此声称实际CNN收益、GPU加速或新颖性已经成立。

## 域具体化和局部反射

读出仍为 y=c+C xi+G beta+sum_k E_k e_k，原源、bits、EQ/LE、decoder 和所有活消费者保持共享。每个 bank k 带坐标集合族 C_k 和约束

```text
||P_C e_k||2 <= R_(k,C)(beta), C in C_k.
```

R 是在允许状态上非负的相位仿射函数；同一集合允许有不同证书给出的多条约束。整体具体化同时满足这些约束，不把多个球当作可择一的菜单。原 HZ 以没有误差 bank 的情形精确嵌入；二元身份不松弛为连续语义。固定相位的凸切片不改变整体非凸联合表示。

对新 g=Wy+d，维护一个统一前向名义参考：归一化源与余项参考为零，初始自由HZ相位参考为零；新相位在其 gbar>0 时参考为1，否则为0。后续 gbar 是当前常数项加旧相位系数在这些固定 tau 上的值。实现保留物理source坐标，因此另计 C*midpoint 到 gbar，并以 C*diag(halfwidth) 计算源偏差预算；这与归一化写法等价，不把图像像素均值当作扰动半径。保留原新 gamma，真实余项为 e_new=(1/2)diag(2gamma-1)(g-gbar)。坐标选择与对角反射交换，故任意 T 都有

```text
||P_T e_new||2 = (1/2)||P_T(g-gbar)||2.
```

只要对整个父抽象状态认证右侧预算，就能用同一 e_new 上的新球替换该新门的精确非线性映射。仍保留源、guards、epigraph、mask 和所有父谓词，而不是保留完整新门图再附加 helper。

## 固定覆盖的前向预算

设一个局部集合族完整覆盖旧 bank 每个坐标，d_i 为坐标覆盖次数，D_C=diag(1/d_i)_{i in C}。逐坐标直接证明

```text
sum_C P_C^T D_C P_C=I
M e=sum_C M P_C^T D_C(P_C e).
```

于是对可靠 K_C>=||M P_C^T D_C||2，

```text
||M e||2 <= sum_C K_C R_C(beta).
```

这是一个固定分摊的前向证书，没有对偶优化、查询失败修复或相位搜索。它通常不是交集的精确支持。若指定局部 cover 漏掉坐标，恒等式不成立，必须拒绝该 cover；不能把缺项当零。

对新目标组 T，取 M=P_T W E_k，并分别认证源盒项 K0_T、旧相位列 d_Tj，得到

```text
R_new,T(beta)=(1/2)[K0_T
 + sum_(k,C) K_(T,k,C)R_(k,C)(beta)
 + sum_j d_Tj |beta_j-tau_j|].
```

绝对相位差为 tau_j+(1-2tau_j)beta_j，因此半径仍仿射，但系数可以为负。所有范数乘子都是有证非负上界，整个半径在Boolean盒上非负。名义参考不必可达，不替代真实源或原phase；只在相位诞生时按当前名义前激活设置，不依据实例身份或终端状态优化，也不执行外部网络采样。新输出常数项为 (g.constant-gbar)/2、原source和旧phase系数折半，新phase系数为diag(gbar)，没有 beta*gamma 高阶项。

这个参考规则避免把每个已正激活的非零名义中心持续当作相位错配；它不证明所有层的半径不增长，也不能用参考相位替代真实可行相位。数学上是D148已证明的一般固定参考规则的确定性实例，而不是新的相位推断算法。

Affine/Add/Concat 先在同一 latent 身份上合并/堆叠系数，再发布 norm 证书。新余项在旧 skip 的映射系数为零。这个顺序不只是存储优化：先对两个分支分别取范数会丢失真实相消，可能让下一非线性无法证明稳定。

## 保留全局约束和查询退化反例

同父包含要求保留本层按 D148 原规则认证的 whole-ball，再加局部球。仅保留父层旧球、却用更大的 cover 半径替换新 whole-ball，不满足这个条件。独立递推后也不能由此宣布整网支配。

固定 cover 并非总比全局界好。例如 ||e||2<=sqrt(n) 且每个 |e_i|<=1，M=I。若把 whole 与 singleton 都均分进cover，得到 (sqrt(n)+n)/2，比直接whole界sqrt(n)更差。因此局部均分只使用固定声明的局部组；原whole证书另行保留。即使这样，某些方向上局部cover仍可能较松。

对同一坐标集合的两个相位仿射半径，语义是同时满足两条约束。其 pointwise minimum 一般非仿射，不可改名成一个仿射半径。线性终端可同时接收两个有效方向行；廉价标量查询可分别最大化后取较紧的数值上界，但不能声称这等于联合约束的精确最优值。

## 区间系数也需要共同误差

令真实 A,b 位于认证区间，以中点 Ahat,bhat 作名义 affine，并设 delta_A、delta_b 为半宽。若当前整个域有 |y_j|<=M_j，则

```text
g_true=Ahat*y+bhat+zeta
|zeta_i|<=delta_b_i+sum_j delta_A_ij M_j.
```

这是由三角不等式得到的共同向量误差。每个后继消费者必须引用同一 zeta；单独重新生成会破坏共享。singleton和whole约束均保留，但独立坐标误差外包不等于保留全部真实BN跨位置相关性。

把 g_true 当含该bank的父读出后，再应用相位反射，额外误差自动进入预算。若把 zeta 直接吸收进最后余项，则该额外半径一般付完整 eta，不只是 eta/2：q=(1/2)ghat+(1/2)S_gamma*gbar+(1/2)S_gamma(ghat-gbar)+diag(gamma)zeta。漏掉这个因子会不健全。本组件采用显式共享 zeta，不假装中点就是原参数。

## 完整费用与研究范围

设cover最大次数为Delta，形成受限矩阵的非零系数扫描量为

```text
sum_C nnz(M_:,C)=sum_i d_i nnz(M_:,i)<=Delta*nnz(M).
```

还须支付 incidence、各组半径的旧phase系数、历史bank映射、源盒/矩阵范数认证和每个终端方向。Frobenius证书可便宜计算但可能丢sqrt(rank)；Gram证书更紧时必须计入全部构造和平方根认证。局部约束不删除余项维数，也不自动阻止 C/G/E 的跨层填充。

连续重叠范数约束本身不是新集合原理。[Ellipsotopes](https://arxiv.org/pdf/2108.01750)已有范数系数块和线性等式；通过为每个组复制连续坐标并添加等式，可表达重叠约束的连续部分。这是表达比较，不是本实现要实际复制坐标，也不将原二元语义替换成凸域。D009 的一般加权能量行同样可以取子集权重。因此新颖性需要来自这份非凸替换、可组合传播及完整代价的实际贡献，尚未建立。

本轮[真实来源边界](SOURCE_BOUNDARY.md)只确认作用规模和必要桥接，不提供候选半径或新解。组件通过也只意味着实现一致性；完整CNN前沿、原相位列绑定、GPU与其向外误差、平滑激活和Transformer仍未取得资格。正式1870/2413与独立61/400保持不变。
