# 共享相位纤维的数学组件结果

本轮实现并检验了一个非凸 Neural-HZ 候选：以相位中心相关的共享余项和重叠范数约束替代新 ReLU 的部分精确关系。它不是在保留完整新门图后附加 helper。唯一冻结运行通过数学组件门，并复现了相对整体球抽象的严格局部增强；尚未证明真实网络收益、完整成本优势或外部新颖性。

## 数学上的实质进展

域元素的读出为 y=c+C xi+G beta+sum E_k e_k，同时保留连续源、原整数相位、EQ/LE、共享身份和源仿射输入重构。每个余项只保留一份坐标；多个重叠组同时约束同一余项，而不是复制独立 patch 噪声。新门保留 guards、epigraph 和 off-mask，但删除精确 active-value 上侧关系，以相位反射余项预算取代它。因此这是有损非凸关系替换，不是完整网络图的改名。

本轮落实了两项跨层要求：物理源盒先按中点和半宽计算偏差；新相位的参考值统一由自身名义前激活确定，后继层以固定参考的相位差计算预算。半径允许负相位系数，但必须在整个 Boolean 盒上非负。旧 whole 证书和 local-cover 证书分别保留，不能用局部计算替掉更强的整体约束。

新增四维正控直接比较 native 物理集合。对 x_i in [-1,1]、g_i=x_i+1/2，在 x=0、所有真实相位为 active 时，整体球半径1允许 q=(7/5,1/2,1/2,1/2)。同一余项上的组(0,1)、(1,2)、(2,3)各有认证半径 sqrt(2)/2，排除了这个虚假输出；真实 q=(1/2,1/2,1/2,1/2)在两者中均保留。正前激活强制这些整数相位，不能通过换标签恢复假点。它是可复现的严格局部增强，不只是变量身份测试。

精确 HZ 本来就排除该假点。本项目要争取的是同等可承受总预算下更强的可扩展传播和验证，不能声称候选在集合精度上超过精确网络关系。反射等距、范数块和重叠约束各自不是新原理；PLDI 级创新仍须通过实质性组合定理、完整成本和真实收益证明。

## 仍未取得的资格

实现是小型稠密有理数参考：source上限32、phase64、error128、bank16、group128、predicate512。它不支持任意依赖phase/error的输入 decoder，不支持独立 sibling 自动合流，没有真实 Conv importer、模型绑定、GPU或完整终端转换。计费包括当前状态和声明活读出，不等于完整物理内存与运行时间证明。

support()发布可靠的方向证书，但不优化全部保留谓词。Householder 中范数行与mask组合得到的72/11是有明确步骤的数学证书，不是已实现自动终端查询的结果。局部精度与这次通过均不能替代完整CNN前沿验证，也没有证明独立整网递推支配。

正式基线仍为1870/2413，即1063 CERT加807 validated ADV。独立E0仍为CIFAR100 25与TinyImageNet 36，共61/400；不能与1870相加。本轮未做13家族或400例回放，未宣称候选已保住旧解，生产默认继续不变。

## 下一研究判断

继续围绕普通 Conv-BN-ReLU-Conv 和活残差分支检验域自身能力，真实布局见 [来源边界](SOURCE_BOUNDARY.md)。进入新的来源试验前，必须预注册完整活消费者、相同信息与后端、局部组规则、原phase绑定、真实BN区间桥及全部费用；不能将五窗口当作完整前沿，也不能直接拿这个小型稠密参考的通过替代大网络资格。
