# 残差后继块的来源与边界合同

本组件补齐联合关系研究的真实结构入口：旧前缀在第二次 ReLU 或残差侧边停止，后继提取需继续保留 Conv、BN、通道仿射和动态 Add/Sub 的完整有序依赖，直到下一次 ReLU 或图输出。它只提取原参数、端口和几何，不是新的抽象域、数值传播或网络验证收益。

## 普通旁路发现的错误和修正

旧隔离草稿在 g=Conv(z)、q=ReLU(g)、a=q+g、r=ReLU(a) 上有边界分类问题：为解释 Add 的侧输入 g，回溯纳入 g 的生产节点后，前向检查会再次遇到 q 的 ReLU，并把它误列为新的后继门。

新版本区分 frontier_relus 与 next_relus。遇到已有 frontier 输出时，必须核对原 node index、shape 和 dtype，记录为既有门的 cut edge，不加入新 receiver，不悄悄删边。真正下一 ReLU 才进入 next_relus。该修正保持普通预激活旁路的支持，不靠拒绝该结构规避问题。原草稿保留不变。

## 提取语义

输入是不可变原 ONNX bytes，明确绑定 batch=1。仅批维可为符号；原声明和绑定表保留。标准 opset 必须在7至已安装 ONNX 的支持上限内；不将旧广播语义默认为新版语义。其余局部语法及64MiB raw、1M累计解码标量、维度和512位限制继承冻结 D015 reader。

同一模型只使用一个 reader 和常量缓存。frontier 为经过原前缀提取确认的第一 ReLU 及第二银行目标 ReLU。后继动态参数依赖必须止于这些原端口，不接受外来输入、未声明 ReLU 或非线性动态 Mul/Div。动态 Add/Sub 只支持同 shape/dtype，不采用未证明的动态广播。

逐节点保留 Conv 的原权重、bias、stride、padding、dilation、group；BN 保留 gamma、beta、mean、variance、epsilon；不把 BN 偏置跨越 padding 折叠，也不合并卷积核。记录来源算子的次序而非执行它们。通道仿射参数的代数描述沿用实数语义，不能据此声称 IEEE 位级执行等价。

对每个 origin，其全部消费者必须被覆盖。因合流侧输入纳入的内部线性节点，也要检查其全部消费者。其他 frontier 端口的块外消费者明确记为 cut，不声称解释整张网络。图输出保留推导 shape、dtype 及原声明；符号输出维不据此获得全模型形状认证。

## 正确性论证的范围

在原前缀认证及所列局部算子语义成立的前提下，对原有序 DAG 作归纳：frontier 的端口身份和 shape 为归纳基；每个线性节点读取同一个模型和前驱 metadata，其参数取自原 bytes，输出几何由原 reader 的对应规则确定。动态合流引用同一原端口赋值，不为两支另造输入副本。已有 frontier ReLU 是原非线性边界而非新 receiver，不能由线性反追踪重复计入。

归纳只证明所返回局部有序子图忠实描述这些原算子，不证明界、LP列、原二元相位列、浮点外向误差或见证 decoder 已绑定。所有这些资格标志仍为 false。未知算子或身份冲突抛出错误，不能输出部分成功 packet。

## 完整成本尚未获得资格

设原图有 N 个节点和 E 条输入边、解码参数 M 个数值、B 个 origins，第 b 块触及的节点与边为 N_b、E_b。共享缓存可以避免重复解码同一参数，但不能免除 O(N+E+M) 的解析/索引工作、逐块闭包工作及各边记录/排序。返回每块有序索引还要支付扫描共享顺序的成本，不能把 B 个块当成单次遍历。Fraction 的位复杂度另计。

raw bytes、完整 protobuf、缓存的 Fraction、节点参数、每块 metadata 和返回 packet 可同时存活。1M解码上限不是 protobuf 物理内存上限。当前未接 whole/branch/evidence/retained meter，故不授予256M、200M、40M、64M或完整物理存储资格；真实三源 worker 必须另行预注册并收费。本轮不启动该 worker。

## 与定义主线的关系

该组件只为在真实混权残差后继上检验现有及未来联合关系提供来源。后续仍需定义相位与连续幅值共同解释的关系语言，证明前向变换或精确简化，并按原数学、真实结构、shadow、逐家族及全量流程晋级。提取器测试通过不能计为新 CERT/ADV、新颖性或 GPU 加速。
