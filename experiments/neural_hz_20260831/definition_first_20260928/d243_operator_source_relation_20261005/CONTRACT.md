# 共同非凸源状态上的相位关系

本候选实现 D242 共同来源构造与 D240 相位作用范围关系之间缺失的数学接入：所有节点、残差消费者、原相位、误差及新增关系必须属于同一个状态。完整卷积等式由共享 kernel 和几何定义，不通过四个独立门或自由 residual 盒替换源图。数学目标是保留原整数状态投影，同时加强可供终端消费的有限线性关系；不把隐式存储或未简化计算图本身称为抽象域创新。

这是默认关闭的精确有理数学组件。声明图不是 ONNX 认证，frame 身份不是模型证书，数学输入的 BN 系数区间不是已验证的原模型区间。固定三模型、GPU、完整物理资格和正式回放仍须后续实证，本阶段不缩小它们的人口或改变任何门槛。

## 域元素和共同来源

一个已封存状态包含有限有理界的连续标量、原 signed binary 因子、所有 EQ/LE、唯一 frame、拓扑算子记录、原输入顺序与 decoder。每个非恒定有界连续变量 v in [L,U] 通过 v=(L+U)/2+(U-L)xi/2 嵌入 xi in [-1,1]；恒定变量用 v=L 的等式消去或保留固定槽。所有 readout 与谓词须同时代换，因此这种物理坐标约定仍是非凸 HZ，不是将状态替换为变量盒。signed bits 始终取 {-1,+1}，不用连续化或删除位取得压缩。

Source 的公开构造是追加式，未封存时逐拓扑建立共同来源，seal 后旧列、节点、谓词、原位和 decoder 不可由公开 API 修改。不能在来源不明的旧 H 上只追加等式便宣称覆盖原网络；本轮仅对受信构造器拥有的完整声明图证明覆盖。外来 frame、非法读出、未封存对象、未证结构或资源失败均拒绝，不发表部分关系。

输入端点按原精确有理值解释。仿射和 Add 的每个标量都有一份完整定义；分叉和重复消费者引用同一列。连续范围仅用于可靠构造与有限乘积线性化，不能取代这些等式。旧输入 EQ/LE、额外 signed binary 来源及所有原位完整保留；输入 decoder 返回原声明输入坐标，不从中间外包重造输入。

## 原算子和整数语义

Affine 与 Add 用精确系数及完整前驱构造。二维 Conv 按已声明的完整 kernel、shape、stride、padding、dilation 和 groups 定义每个输出的等式，零 padding 不引入自由变量。共享存储不删除任何输出位置或边界连接。逐行访问、范围计算及终端显式化都必须计费。两层有 padding 的 Conv 不得直接替换为处处相同的大核。

数学 BN 输入是 raw mean、beta 与包含真系数 a 的有理区间。固定选用有理 ahat，令 bhat=beta-ahat*mean、da=max(abs(alo-ahat),abs(ahi-ahat))。已有同状态界 L<=t<=U 时，取 E=da*max(abs(L-mean),abs(U-mean))，定义 g=ahat*t+bhat+E*epsilon。每个实际标量分配自己的 epsilon in [-1,1]，同一标量所有消费者共用它；E=0 不需要误差列。此构造包含 a*(t-mean)+beta 的全部真实输出，但一般不保持不同位置共用 a 的全部相关性，故是可靠外包而不是精确 BN 图。

每个新构造的 crossing ReLU 保留预激活 f、输出 q、signed bit b 和 alpha=(b+1)/2。用可靠 L<0<U 建立 q>=0、q>=f、q<=U*alpha、q<=f-L*(1-alpha)。它们在整数位上给出精确图，包括 f=0 的两个合法标签。首次构造的稳定正门可直接别名为 f，稳定负门可用恒零 EQ，无需新增原本尚未出生的位；不能借稳定化删除任何已经存在的二元因子。

这里的正负方向属于本声明图，不宣称与 ACT 现有 native 相位方向相同。原生接入须检查实际原位和图行，再作已证明的符号映射；不得重新出生替代原位或沿用未经核查的方向。

共同扩展由拓扑归纳成立：同一输入赋值先实现输入谓词；仿射和卷积采用原前驱值，BN 选择上述逐标量误差，ReLU 使用实际值及合法标签，所有消费者复用该赋值。没有 BN 外包误差时是声明网络的精确图扩展；有误差时是声明外包图，不得把任意整数 H 点当作原网络 ADV。

## 固定的同状态 X 关系

候选只使用 X anchor，不在 X 不通过后切换 Q 或其他方法。输入为同一已封存状态的两个父门与两个子门句柄。两父预激活须能认证为不同的源列，可靠 crossing 界 L_i<0<U_i 给出 s_i=max(-L_i,U_i)>0。置 x_i=f_i/s_i、q_i=Q_i/s_i；仅正比例归一化，不平移 ReLU 零点或相位。

这个数学入口尚不提供原全网四门结构的自动枚举调度器。未来真实接入必须事前固定与实例身份、标签和求解状态无关的拓扑选择规则，并支付完整枚举及拒绝费用，不能把测试里显式传入的句柄误称为已完成全网统一调度。

两个子预激活沿完整原 EQ 确定性展开至这两个父 f/q 及其他输入、误差、原二元、其他 ReLU 输出边界。同列先精确合并；真实偏置、skip、其余幅值和 BN 误差不能丢失。若原图不能按这一固定结构提取则拒绝，不调用优化器猜来源。

取 z=(g1+g2)/2、d=(g1-g2)/2。设 d 在归一化 q1/q2 上的完整系数为 A/B，固定 tau=(A-B)/2，要求 tau>0。令 e=d-tau*(q1-q2)。a/b 是 z 在归一化 x1/x2 上的完整系数，r=z-a*x1-b*x2。完整同状态表达式给出可靠 [Lr,Ur]、[Le,Ue]。令 M=max(max(a,0)+max(-b,0),max(-a,0)+max(b,0))，要求 [Lr-M,Ur+M] 包含于 [-tau,tau]。失败是该关系未取得资格，不是 SAFE、UNSAFE 或收益。

原相位不等时 x1/x2 弱异号，因此 |z|<=tau；相等时 h=alpha1-alpha2=0。于是 h*(clip(z+tau,0,2*tau)-z-tau)=0。这个共同差恒等式不允许把单项 alpha_i*clip 替换为 alpha_i*(z+tau)。

追加四个连续观察 c12=alpha1*x2、c21=alpha2*x1、v1=alpha1*r、v2=alpha2*r。各自完整四条 McCormick 行在原 alpha 整数时唯一确定真实乘积。令 K=tau*(alpha1-alpha2)+a*(q1-c21)+b*(c12-q2)+v1-v2、p_i=alpha_i-q_i，追加

```text
Y1-Y2-K <= 2*tau*p2+2*max(Ue,0)
-Y1+Y2+K <= 2*tau*p1-2*min(Le,0).
```

再统一追加 D240 的三条源容量：T=q1-q2+c12-c21、U=q1+q2-c12-c21、D=2*q1-x1+2*q2-x2，满足 -1+2*q1-x1<=T<=1-2*q2+x2 及 U<=D。全部 21 条新增 LE 必须代回原 H 列，保留原 EQ/LE 和全部二元位，不生成虚拟 clip 位。

每个原整数可行 H 状态都有唯一这四个乘积的扩展，新增行均成立；反向投影保留原谓词，故原整数 H 投影不变。分数位下新增行可能严格加强 LP 投影，但不声称得到整个 H 的凸包。后继网络验证仍使用原终端与具体见证规则。
