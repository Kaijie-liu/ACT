# 单负门共同源支持的直接构造

本轮补上一个此前作为已知支持值使用、但没有通用构造的步骤：仿射残差减去一个 ReLU 的全盒精确上界，可以通过一次系数排序和连续背包填充获得；一正一负两个原门的读出可归约为两次这种查询。整个构造不求解相位子域，不调用 LP、对偶迭代、搜索或攻击。

这是可供 Neural HZ 定义研究复用的支持算子，不是新域或新数学。它不解决所有消费者共同见证或任意深度的有限接口闭包。本轮是纸面推导与独立复核，没有实现、数值资格或真实网络运行。

## 原非凸关系和精确性的范围

完整原 HZ H 保留连续因子、全部原二元相位、EQ/LE、共同 frame、物理读出及输入 decoder。令 z 为同一个已认证源前沿，D=[l,u] 为可靠源盒。原门 q=ReLU(g(z)) 及其原 bit 始终属于 H；本构造只是计算有效物理读出上界，不删除任何原门、相位或谓词。

若 z 的真实可行集恰好为完整盒 D，下面的值是所述函数的精确支持，且返回同一个盒内源见证。若 D 只是相关 HZ 源的外包，所得值仍是可靠上界，但盒内最大化点未必满足原谓词，不能叫作原 HZ 的可行输入，更不能记为 ADV。

本节只支持已认证点系数仿射 f、g、v。区间参数必须另证误差外包，不能用中点结果声称原模型精确支持。所有源来自同一个赋值；每个门各取一份独立源会改变问题。

## 单负 ReLU 的原始算法

记 R(t)=max(0,t)，考虑

```text
F(z) = v(z) - d*R(g(z)),       d>0,
g(z) = b + sum_i a_i*z_i,
v(z) = c + sum_i w_i*z_i,      z in D.
```

固定坐标先折入常数。a_i=0 的坐标不影响 g，直接按 w_i 的符号选择使 v 最大的盒端点；w_i 也为零时采用固定原坐标端点。对其余坐标定义

```text
e_i = l_i if a_i>0, else u_i
t_i = a_i*(z_i-e_i)
A_i = abs(a_i)*(u_i-l_i)>0
rho_i = w_i/a_i.
```

因此 g=g0+sum t_i，v=v0+sum rho_i*t_i，且各 t_i 独立位于 [0,A_i]。g0 和 v0 必须包含全部原偏置、端点补偿、固定坐标及前述独立坐标贡献。

按 rho_i 非增排序，并列按原坐标顺序。定义

```text
P_d = sum_{rho_i>d} A_i
P_0 = sum_{rho_i>0} A_i
T_star = min(P_0, max(P_d, -g0)).
```

按此顺序依次填满容量，直到总量 T_star；最后至多一个坐标部分填充。恢复 z_i=e_i+t_i/a_i，连同独立坐标的端点得到 z_star。直接计算原 F(z_star) 即为精确上界。若没有剩余 t 坐标，则直接计算常量 g 和已最大化的 v。d=0 时退回仿射支持；这不是另一条求解救援路径。

## 证明

固定 T=sum t_i。若 rho_i>rho_j、t_i<A_i 且 t_j>0，将足够小的正量从 j 移到 i 保持总量及盒约束，且增加目标。因此降序填充最大化所有给定 T 下的线性部分。并列任意次序都取得相同目标，固定原索引使算法确定。

令 K(T) 为此最优线性部分。它是凹的分段仿射函数，边际斜率按排序依次为 rho_i。完整目标为

```text
v0 + K(T) - d*max(0,g0+T),   0<=T<=sum A_i.
```

经过 T=-g0 时，边际斜率统一下降 d。rho_i>d 的容量无论是否已过该点都值得填充；rho_i<0 的容量无论是否已过该点都不值得填充。中间容量在过该点前收益非负，过后收益非正。因此一个最大化总量正是将 -g0 截到 [P_d,P_0]。rho_i=d 或0只产生可能的平坦段，不影响所给选择的最优性。该证明同时覆盖 g 在整个盒上稳定正、稳定负或跨零的普通情况。

这是原始变量的交换及边际证明。算法不求解两个受 g 符号限制的子盒，不读取 LP 点，不调节对偶乘子。其排序填充部分属于经典连续背包；[Stefanov 2023](https://tarupublications.com/journals/jios/volume/44/issue/5/continuous-linear-knapsack-problems-revisited/pdf) §3 Theorem 1、式11至16及 Remark 2 给出相应固定容量构造及排序成本。本处 hinge 阈值截取是该机制的直接应用，不宣称新颖性。

达到 g=0 的源点时，原门两种合法 bit 都保留。返回一个最大化见证不会限制原域的其他赋值，也不授权把两个零相位合并。

## 混权双门的全盒支持

对两个原门及非负常数 a,d，d>0，有逐点恒等式

```text
v+a*R(f)-d*R(g)
  = max(v-d*R(g), v+a*f-d*R(g)).
```

两边使用相同完整盒 D，因此其上确界等于右侧两项各自全盒支持的最大值。两个支持均由上一算法构造；没有施加 f<=0 或 f>=0 的子域条件，也没有运行两个相位网络。

取达到较大支持值 U 的源点 z_star。原混合函数在该点至少为对应项的 U，而任意源点上两项都不超过 U，所以原混合函数也恰好达到 U。这证明所返回源点同时是原混合函数的见证，而不只是某个上包络的最大点。

两个正门及一个负门可按已有固定四平面恒等式归约为四次查询，但本轮不推广为任意数量正门的指数展开；任意多个负门也不在该算法的精确范围。下界若取负后超出此符号结构，不能擅自沿用精确性。语义语言需要的其他情况仍未完成，不能称为通用多门域。

## 使用旧控制核对精度而不重记成果

沿用 D029 的 [LIMITS](../d029_conditional_observations_20260930/LIMITS.md)：

```text
x,y in [-1,1]
h=x+1/10, p=R(h), 原 bit beta
f=3*h/2+y/5, q=R(f), 原 bit alpha
v=-h/4, F=v+q-p.
```

两项支持分别为 9/40 和19/40，所以 sup F=19/40。第一项 -h/4-R(h) 在 h=-9/10 取最大；第二项 5h/4+y/5-R(h) 在 h=11/10、y=1 取最大。后一源点也使原混合函数达到19/40。这个数值和函数本身已在旧档，本轮新增的是通用于系数的构造，不是再次发现该上界。

原共同斜率证书的两项为 A0=9/40+9*theta/10、A1=63/40-11*theta/10。对所有 theta in [0,1]，max(A0,A1)>=333/400。新构造允许两项各自在完整盒上达到自己的精确支持，不需要选一个共同 theta。这只解释旧构造的限制，不证明超越全部已有关联规则。

以下假点明确通过两个独立的完整带源及原 bit 单门凸包：

```text
x=0, y=1/2, q=29/40, alpha=1/2, p=1/10, beta=1.
```

f 门的见证为源 (4/5,1/2) 与 (-4/5,1/2) 各半，其 f 分别为29/20和-19/20，q分别为29/20和0，原 bits 分别为1和0。h 门直接采用均值源 (0,1/2)，其 h=p=1/10、beta=1。每个单门都有完整共同源见证；两个门却未共用同一种混合。假点 F=3/5，超过真实上界1/8。全部用于该假点的源均严格在盒内部，相关预激活非零。

必须同时保留更强比较：旧 [D020](../d020_phase_difference_20260930/D020_PHASE_DIFFERENCE.md) 已有的关系本身就推出本例最优界。令 Dq=q-p、delta=f-h=h/2+y/5，则

```text
Dq <= (3/4)*alpha
Dq-delta <= (13/20)*(1-alpha).
```

分别乘13/28与15/28后相加，得到

```text
F <= 39/112 + h/56 + 3*y/28 <= 19/40.
```

因此既不能把上述假点记成相对 D020 的新强度，也不能把本例算成新能力。这个相加只是纸面蕴含审查，不是新增运行时对偶修复。

追加实际原门 r=R(F-1/4)，原 bit gamma保留，则真实 r<=9/40，而假点可令 r=7/20、gamma=1。源 (0,-1/2) 给 F=-3/40，源 (4/5,4/5) 给 F=77/200，说明真实后继确实跨零。这只演示已有标量界可传过一个不稳定后继，不证明保留联合关系的有限跨层闭包；D020 在这里同样可以推出该上界。

## 多消费者不能独立取各自最优值

即使每个支持都精确，也不能把它们当作共享辅助量的联合精确投影。例如同一个 [-1,1]^2 上令

```text
g=x+y+1/10
F1=2*x-y+1/5-R(g)
F2=-x+2*y+3/10-R(g).
```

各自最大值为31/10和16/5，唯一最大点分别为 (1,-1) 与 (-1,1)。但 F1+F2=x+y+1/2-2*R(x+y+1/10)，整个盒上的最大值只有2/5。故不能先独立最大化再声称这些端点存在共同源见证。原 HZ 及全部消费者仍须保留。

这一限制与 D059 的共同接口问题一致。本轮没有找到可替代它的通用有限商；D051 已覆盖的全消费者行空间判据不重新命名为新发现。

## 完整代价和下一行动

设 n 是合并后的实际非固定、非零 a 支持数。每次支持需要 O(n log n) 次精确比较、O(n) 次算术及工作区；完整 D 维源见证需要另付 O(D)。两次支持的 w_i/a_i 一般不同，不能免费共享排序。源形式提取、同源认证、稀疏合并、系数位长、排序比较的中间乘积、证据和原读出行展开另计。

GPU 可研究按观察批量排序、前缀和及填充，但尚无设备实现或速度证明。浮点误排序可能破坏精确结论，必须有可核验次序或健全外包；不能把近似排序的值当上界。既有512位、完整物理存储和所有冻结预算不因该算法改变。

一条上界若写为原读出 E<=U，只增加有效 LE 而不改变整数具体化；它的 latent 展开、RHS、slack及原谓词仍计费。这样的安装本身是算子支持成果，不构成新域定义。共同关系怎样被后继复用，仍是主线未解决项。

决定：保留此直接构造作为后续关系候选的付费支持原语；不再为已否决的纯行空间压缩或私有盒独立化建立新框架，也不因这个旧控制另跑一套组件资格。未来只有在明确的新关系消费者需要它、预先固定真实完整结构人口与费用后，才实现默认关闭的组合候选。D067 的固定配对结论不证明真实宽消费者仅含一个未定负门，必须另查完整 fan-in，不能据其10个 crossing 源直接声称适用。
