## What changed the next action

1. Independent off-diagonal charge lifting has no LP projection gain; its
   apparent rank-two representation is not a cheap strengthening theorem.
2. Joint bounded resources can infer original-bit counts and improve a next
   affine bound on ordinary controls. This is useful supporting mathematics,
   not yet a new domain or real-network capability.
3. Budgets can precisely normalize generator interactions across layers, but
   the relevant Boolean algebra is published prior art. Same-layer budgets
   cannot annihilate any ordinary forward path monomial, and a width-two
   residual example still forces exponential explicit phase expansion.
4. A mixed-sign example strictly strengthens native+count LP with two paid
   rows. Flattening/replacing the old gate instead loses other LP information.
   Therefore no monomial-expansion or flat-replacement implementation is
   selected. A different substantive compositional invariant is still needed
   for the requested definition-level contribution.
