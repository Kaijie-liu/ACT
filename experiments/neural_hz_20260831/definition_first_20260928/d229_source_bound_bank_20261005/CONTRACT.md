# 联合激活关系与原 HZ 谓词的精确接合

本轮补上 D228 联合关系的必要消费接口：从同一原生 HZ 的实际谓词认证四门，把共同关系精确代换为原因子坐标，并对完整实际读出给出可靠界。它不是新解题 helper、外部优化器或新的模型 loader。仅给模型无关的原生数学组件资格，不声称已接通真实 CIFAR/Tiny、全局 allocator 或终端求解。

## 域和原生前提

沿用 N=(H,B) 的非凸具体化。H 的全部连续因子、原 signed bits、EQ/LE、输出与消费者、frame 和输入 decoder 不改变；B 保存同源局部联合关系。空 B 嵌入原 HZ。原模型映射尚须以后单独认证，实际存储 H 的关系不能冒充原 ONNX 语义。

bind 的四个 Graph 按父1、父2、后继1、后继2排序。复用已冻结 D064 的 SparseHZono schema/shape检查，按同一已证原行模板作本地计费提取与精确算术；不调用其 D063 bound-and-append 算法。必须验证原 EQ/LE/guard、原槽、四个不同二元列及图关系；仅接受 graph_error=0。非零 compact 误差不得偷偷当精确 ReLU，缺失稳定门原bit也不得补造成已有bit。所有未认证前提 fail closed。

原生编码 b=-1 表示激活，D228 的 sigma=+1 表示激活。因此仅四个独立相位读出作 sigma_i=-b_i；物理仿射读出中已有的 binary 系数保持原义，不再翻号。零预激活的两种合法标签均保留。原 exact=False 不因绑定而变成 True。

四门的实际图读出记作 f1,q1,f2,q2,g1,y1,g2,y2。后继参考系数是预先给定的两行有理四元组 c_j 与偏置 d_j；统一在原 H 上精确定义

```text
v_j = g_j - c_j·(f1,f2,q1,q2) - d_j,
y_j = ReLU(c_j·(f1,f2,q1,q2)+v_j+d_j)。
```

完整差值含所有源、上游二元项、偏置及未选贡献，不按小阈值丢项。参考系数不必假装等于 BN 实系数；只有完整实际 g 保留并且差值精确绑定时，该分解才有效。本组件不能认证原模型 BN 或为它补造 g。

物理顺序为 f1,f2,q1,q2,v1,v2,y1,y2。两个余项即使相同或常量也分别保留实际读出，不把它们变成新独立物理因子。对任一 NativeAffine c+a·xi+d·b，用 [c-sum|a|-sum|d|,c+sum|a|+sum|d|] 给局部可靠包；这是查询外包，不改变 H 中 b 的整数性或源关联。两个父包必须严格 crossing；未满足则拒绝本组件，而不改原 H。

## 精确回代定理

D228 的联合图对独立局部包完备。任一原 H 整数可行点的八个实际读出都在其中，原相位也相容，因此存在一份共同 lambda 扩展。禁止要求每个局部顶点分别具有原输入见证。

对 D228 的一行

```text
a·z + d·sigma + t·lambda ⋈ r,
z_k = c_k + A_k(H), lambda_j=(1+xi_new_j)/2
```

精确代换为

```text
sum a_k A_k(H) - sum d_i b_i + sum (t_j/2)xi_new_j
    ⋈ r - sum a_k c_k - sum t_j/2。
```

所有重复原因子列先按身份精确合并。新增 xi_new 范围 [-1,1]，仅追加连续身份，不创建、删除或 pivot 二元列。保留全部原 H 使反向投影仍属于原 H；上述共同扩展给另一方向，因此整数具体化不变。

pullback 返回数学扩展的精确稀疏 EQ/LE。新连续列从 supplied H 的当前连续宽度之后编号，仅在这个数学扩展中有意义；它不申请 ACT frame 全局高水位，不允许被当成已经发布到运行时的槽，也不作 float64 安装。完整原 H 通过引用保留，不复制为独立父状态。未来全局 allocator、rebase、deferred 全人口、舍入及终端安装仍须单独接入。

## 完整物理读出的消费

给定原 H 实际输出 F 和预先冻结的八维系数 w，令 R=F-w·z，完整保留 R 的全部连续、二元、偏置及 skip/其他项。原生 HZ 和其所有输出不改变。返回

```text
upper = support_B(w) + cube_upper(R),
lower = -support_B(-w) + cube_lower(R)。
```

这是完整 F 的可靠界，不是只取两个 y 的孤立最大值。查询权重由调用者固定，不从 LP 状态、标签、margin 或旧 verdict 选择，不优化权重，不在失败后 rescue。该界未利用 R 的全部旧谓词相关性，不声称最佳界；也不能把局部支持达到点当原输入 ADV。它仍是域内有限精确算术，没有 LP/MILP、attack、split、backward/dual rescue 或参考算法调用。

原生源在绑定及每次使用期间必须静止。每个公共操作前后均完整检查来源指纹，采用schema核验后的一维C连续缓冲视图，不复制整字节数组；全部扫描字节继续计work，初次绑定计原输入标量根的entries，之后只计新建视图/元数据等。非连续缓冲拒绝，不隐式复制。它用于发现变更，不代替原模型来源或全局frame认证，也不证明多bank重复扫描能在真实人口预算下通过。输出记录不接受不可信反序列化。
