# 输入盒预算进入 Neural HZ 的强参照比较

本轮把 D163 的后续问题落实为两个可反证的组合：从普通共同输入盒生成 L1 预算后使用 M 距离域，以及保留一半源仿射中心后使用该域。两者均健全，但目前没有独立实现价值。第一个组合的解析正控被旧 D009 同份预算证书更强且更低成本地处理；第二个组合在原整数相位语义上被已有相位反射的 L1 形式支配。

这些是限定候选的数学比较，不是对全部 Neural-HZ 的否定，不是网络运行或正式收益。所有源、原 bits、实际 guards、EQ/LE、共享旁路和输入 decoder 的身份保持不变；没有加入其他验证算法。

## 共同输入盒的联合预算已有来源

[D009 第三节](../d009_bounded_phase_energy_20260928/D009_DOMAIN_AND_RESULTS.md)已经从 g=b+A xi、xi 属于单位盒，固定非负权 w，构造

```text
G = A^T diag(w) A,
B0 = sum_j G_jj + 2 sum_(j<k) |G_jk|,
W0 = sum_i w_i,
sum_i w_i |(A xi)_i| <= sqrt(W0 B0).
```

Gram 内须先合并再取绝对值。一个有理 R>=0、R^2>=W0 B0 就给出可靠共同 L1 预算。D009 已有偏置补偿、普通非正交三门正控、与全部指定 box-defect 关系的比较，以及卷积 patch 的完整源共享和 Gram 费用。因此本轮不把预算生成称为新发现。

只使用粗谱界也不能自动提供便宜收紧。令 S=sum_ij |A_ij|，a=max_i sum_j |A_ij|，bcol=max_j sum_i |A_ij|。由 S<=m a 和 S<=n bcol，得

```text
sqrt(m n a bcol) >= S.
```

故经 ||A||2^2<=||A||1||A||infinity 得到的无权 L1 半径不小于逐门半径总和。Frobenius 替代 sqrt(mn)||A||F 也由 Cauchy 不小于 S。这里不否定经过认证的更紧谱上界，只是否定给这两种廉价粗界换名就能改善 IBP 总半径。

## 一个非正交盒控制及其弱正结果

令 H 为标准 Sylvester 八阶 Hadamard 矩阵，第一行和第一列全为 1；设

```text
A = H + (1/32)11^T,
b = (1/4)1,
xi in [-1,1]^8,
g=A xi+b, q=ReLU(g), 原相位为 beta。
```

A 非正交、满秩，各行非平行，偏置非零，全部门 crossing。它只是可手算的普通结构控制，不是假定真实训练网络有此矩阵，也不是运行时身份菜单。A 的元素离零有界；以下预算证书和查询阈值均有严格余量，小扰动不会立即破坏对照，不能将其解释为真实模型覆盖率。

H^T H=8I、H1=8e1，故同一 D009 Gram 规则精确得到

```text
G = 8I + (1/4)(e1 1^T+1 e1^T) + (1/128)11^T,
B0 = 137/2,
W0 B0 = 548 < (74/3)^2.
```

所有 Gram 项非负。取 R=74/3，是该既有算法直接接受的有理上证书，不是给新旧两方使用不同的预算生成器。

由于中心 b>=0，M=0 的原生距离域给

```text
q>=0, q_i<=U_i beta_i,
sum_i |q_i-1/4| <= 74/3,
```

并保实际 g 的原 sign guards、完整源和原输入 decoder。D163 的非负位移 f 在此全部等于零，可以精确消去。该关系覆盖整个源盒的真实 ReLU 像，但不是保留逐门 active-value 等式的精确图。

给出完整的本控制读出与同源旁路：

```text
B=(1,1,1,1,1,1,1,-1/4),
s=(1/16)sum_j xi_j,
J=Bq+s,
r=ReLU(J-55/2).
```

q>=0 和距离预算推出 Q=sum q<=2+74/3=80/3，故 J<=Q+s<=163/6<55/2；这个抽象已能证明后继 r 恒零。

旧逐门理想 hull 的交却容许

```text
xi=0, beta_i=1/2,
q1=17/4, q_(2:8)=33/8,
J=895/32 > 55/2.
```

第一个源行的半径是 33/4，其余为 8；每个门分别取源正负 sign(A_i) 的各半混合，完整八维源均值为零、原相位均值为 1/2，输出均值正是该 q_i。因此此点属于每一个完整 source-labelled 单门 hull 的柱状扩展及其交。不同门的混合不是一个共同的联合分布；不能声称通过整组 hull。它不是实际 ADV。

## 同份证据的旧关系已经更强

D009 对同一 g、同一 R 直接给出一条行

```text
2Q - sum_i g_i <= sum_i |b_i| + R = 80/3.
```

保留共同源后，sum_i g_i=8 xi1+(1/4)sum_j xi_j+2，所以

```text
Q <= 43/3 + 4 xi1 + (1/8)sum_j xi_j,
J <= 43/3 + 4 xi1 + (3/16)sum_j xi_j <= 119/6.
```

这是对相同读出的显著更紧证书，已经证明同一后继为零。该证书的范围只是展示的控制与查询，不声称一个旧 Gram 行支配所有 M/f 域、所有方向或所有递归。

预激活内联、保全部实际 guards、暂不物化最后 J 及后继时，精确逻辑账如下。源盒和原 bit 类型约束是双方共同成本，未列为新增行。

| 对照表示 | 连续量总数含八维源 | 原 bits | 行 | 矩阵非零项 | 非零 RHS |
| --- | --- | --- | --- | --- | --- |
| 旧四行加 D009 一行 | 16 | 8 | 33 | 192 | 17 |
| M 距离预算且消去固定零 f | 24 | 8 | 49 | 208 | 33 |
| 字面保留固定零 f 的 lift | 32 | 8 | 65 | 240 | 33 |

M=0 时两条绝对值行已蕴含 rho>=0，未重复计行。M 侧没有另外添加 q>=g；若添加，需另付其行与系数，不能借此保留上述较低账单。表中的界是所列证明给出的上界，不声称已经优化全部保留谓词得到最优值。

双方还需原 A 的 64 项、8 个偏置、界、decoder 和 Gram 证据；对称 Gram 有 36 个独立项，直接构造上三角需 288 次乘法和 252 次求和，另付归约、有理位宽和证书检查。物化 J 时双方同加一连续量、一等式、17 个矩阵非零项。后继、终端、全部原谓词和物理存储仍另计。这不是 GPU 运行、内存峰值或速度资格。

因此“源盒到 M 球”的这个成功控制不能成为新的能力路线：其较弱逐门参照的分离是已知共同源预算机制，强参照用同份证据已经更强且局部表示更便宜。

## 保留源中心的嵌套性并不等于新域

考虑固定 lambda 属于 [0,1]，同一真实 g=b+A xi，并已知 ||A xi||w<=R0。定义前像球

```text
c_lambda=b+lambda A xi,
F_lambda(xi)={t: ||t-c_lambda||w <= (1-lambda)R0}.
```

真实 g 属于每个球。若 lambda2>=lambda1，中心间距离至多 (lambda2-lambda1)R0；三角不等式得到 F_lambda2(xi) 包含于 F_lambda1(xi)。取 ReLU 的 labelled 像，并与同一实际 guards、caps、P 和旁路相交，仍保持这个原生整数语义包含。

这里比较共同源、原 bits 和物理输出上的投影，不强制不同中心定义的 cost 或 f 辅助坐标同名相等；所有原有受保护身份及其谓词不变。

lambda=1 时球退为 g，自然恢复精确图；lambda=0 时该球预算不再保留源点值幅度信息，但实际 guards 与 P 中的源约束仍保留。这是一个已知源保留思想的具体同源比较，不是新表达能力。不同 M 编译及连续 bits 的终端 LP 不自动继承上述包含，不把整数定理转授为 LP 支配。

## 半源中心由相位反射关系支配

对 lambda=1/2，M 域的中心为 c=(g+b)/2、半径为 R0/2。与它比较相位反射的 L1 关系

```text
sum_i w_i |q_i-g_i/2-(beta_i-1/2)b_i| <= R0/2.
```

这是 [D148 的相位反射恒等式](../d148_phase_centered_norm_fiber_20261004/THEORY.md)在加权 L1 下的直接形式，不引入新的反射原理。对真实门，残差是 (1/2)(2 beta_i-1)(g_i-b_i)，所以同份源预算健全。比较使用同一整数 beta、实际 g 的 guards、q 非负/off-mask、可靠 caps 和父 P；可同时再加 q>=g。

active 时两个成本完全相同。inactive 时 g_i<=0、q_i=0，M 成本为 (g_i+b_i)_+/2，反射成本为 |g_i-b_i|/2，且

```text
(g_i+b_i)_+ <= |g_i-b_i|.
```

若左边为零则显然；否则 b_i>-g_i>=0，右边等于 b_i-g_i>=b_i+g_i。故反射关系逐坐标蕴含 M 预算，对任意偏置和正权均成立。这里只证明原生整数语义，不声称分数相位 LP 编译间的支配。

包含可以严格。取

```text
A=[[1,1/4],[-1/3,1]], b=(1/4,1/4), xi in [-1,1]^2,
R0=25/12,
xi=(1/4,-3/4), g=(5/16,-7/12), beta=(1,0), q=(1,0).
```

R0 为可靠且精确的源 L1 界：两行绝对值和等于其和、差的绝对值之最大；两者盒界分别为 23/12、25/12。紧输出 caps 是 (3/2,19/12)。展示的源、实际 guards、q>=g 和 caps 均成立。M 总成本为 23/32<=25/24，反射总成本为 23/32+5/12=109/96>100/96，严格拒绝该假幅值。没有用零标签或数值极端点。

一般直接编码中，半源 M 使用 q、rho 共 2m 连续量，含实际 guards 为 7m+1 行；反射 L1 同样使用 2m 连续量，只需 6m+1 行。共同加 q>=g 时各增 m 行。这里计固定通用编码，零系数和冗余消去可改变计数，未声称每个稀疏 nnz 都严格减少。lambda=1 则可化简回 m 个新输出、4m 条标准精确门行。

中间 lambda 未自动减少原 source、bits、历史谓词或终端查询成本。其他有损域可能因完整查询或时间收益而有用，不要求所有候选都必须减列；但本家族目前没有这种已支付费用的优势，不能只改中心后继续实施。

## 本轮改变的下一行动

不再以“从盒取得有利联合预算”为尚未完成的新定义问题：D009 已完成该部分。也不再将常中心 M 的逐门分离、半源中心、范数名称变化作为独立实现依据。

未解决的是跨层共同幅值与方向如何成为有实质查询优势的表示和变换，而非完整旧图附加已知证书或更昂贵的弱关系。[D151](../d151_exact_comparator_audit_20261004/THEORY.md)的同坐标强参照和本轮比较必须进入下一候选的设计阶段。不能由本轮两个失败组合排除所有定向域、全部结构性再抽象或 GPU 方案；也不能把缺少新候选误记为总体目标完成或外部阻塞。

本轮没有实现或执行任何候选。正式 1870/2413、独立 CIFAR100 25 加 TinyImageNet 36 共 61/400，新增均为零。
