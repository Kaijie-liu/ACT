# Neural-HZ 跨层残差纤维与预算传播

本轮得到一个定义层面的可用候选：从出生起用输出维数的共同幅值替代残差支路的隐藏幅值，保留全部原相位和父域身份，并直接传播整块预算。它是有损、非凸的候选具体化，不是保留全部网络图后附加 helper。不过，所用扇区和非扩张原理已有先例，完整终端精度与费用尚未通过比较，不能称为创新成功或网络能力提升。本页只有纸面推导，没有代码或数值执行。

## 共同父域上的残差块

令同一父元素 H 具有连续源、原整数二元相位、EQ/LE、完整活读出 q∈R^n 和输入 decoder。考虑普通块

```text
g = Vq+c ∈ R^m,
r = ReLU(g),
z = q+Ur ∈ R^n.
```

所有 r 消费者必须已包含在这个接口中。若 r 还被别的分支、旧谓词或 decoder 使用，下面不能把它删除。q 的活旁路保留为同一个 q，不创建独立副本。结构匹配不依赖实例身份、标签、margin 或 solver 状态。

选定正标量 λ，以及可靠 K≥||V||₂²，要求 λK≤2。令

```text
E = U+λVᵀ,    α=λK/2,
ε≥||E||₂,    ν≥||V||₂,
ρ=α+εν,       L=1+εν.
```

参考 qbar 固定，gbar=Vqbar+c，zbar=qbar+U ReLU(gbar)。父域须已认证 ||q−qbar||₂≤R。这不是另一个求解器找到的中心；本页尚未选定生产用 λ 和 norm certificate 规则，更没有按实验结果搜索它们。E 无需为零，也无需对称，故不把一般网络强制改造成 tied-weight 或保守梯度网络。

对每个真实父成员和该块全部合法原相位 γ∈{0,1}^m，有 r=Dγg。置 d=q−qbar、Hγ=VᵀDγV，则

```text
z=(1−α)q+αqbar+U Dγ gbar+e,
e=(αI−λHγ+E DγV)d.
```

因为 0≼Hγ≼KI，故 ||αI−λHγ||₂≤α，从而

```text
||e||₂ ≤ ρ ||q−qbar||₂.                         (1)
```

这是直接适用于整个当前父域的恒等式和上界，不是把各旧 error bank 独立相加后乘 bank 数量。零预激活的两个原标签均满足证明。

还可以保留整块 Lipschitz 预算。设 h=ReLU(Vq+c)−ReLU(Vqbar+c)，ReLU 的 firm nonexpansiveness 给出 ||h||²≤hᵀVd，故

```text
||d−λVᵀh||² ≤ ||d||²−λ(2−λK)||h||² ≤ ||d||².
||z−zbar||₂ ≤ (1+εν)||d||₂ ≤ L R.               (2)
```

(2) 对真实图成立，但不一定由单独 (1) 的有损扩张推出。因此若下一层要直接继承 LR，必须把 (2) 明确装入新域，不能只证明一次后在后续抽象成员上擅自使用。

## 新域元素的具体化

候选在 H 上追加全部 m 个原 γ 和 n 个新连续输出坐标 z，不保留 r 或逐项 γ_j g_j 连续产品。定义 e 为上面的仿射读出，不另建第二份 e。共同具体化同时满足：

1. H 的全部旧谓词、相位、共享源和 decoder。
2. 新原相位的 sign guards，例如可靠 crossing 界 ℓ_j<0<u_j 下的 g_j≤u_jγ_j、g_j≥ℓ_j(1−γ_j)。稳定门可使用已证明的稳定规则，但不删除原 bit。
3. 源相关非凸关系 (1)，以及全局关系 ||z−zbar||₂≤LR。后者明确选择 (2) 的全局版本，不把更强的逐源界 ||z−zbar||₂≤L||q−qbar||₂ 同时计入本候选。
4. 按完整 U 构造的聚合 mask caps：若 0≤r_j≤rmax_jγ_j，则对每个输出 i，

```text
Σ_j min(U_ij,0) rmax_j γ_j ≤ z_i−q_i
                         ≤ Σ_j max(U_ij,0) rmax_j γ_j.       (3)
```

它们使全 off 原相位仍有 z=q，但不是完整 masked-image 的精确描述。rmax_j 必须对整个父域可靠；上界为零时原零标签仍保留。

每个真实父域成员的具体块像有规范扩展，故构造健全。它明确丢失部分 γ、q、z 的精确乘积关系，因此不宣称精确压缩；全部原 bits、连续源、EQ/LE 和非凸源相关关系仍在，没有整体退化成 Z/CZ。空新纤维精确嵌入原 HZ。Aff/Conv 与同 frame Add/Concat 只改变或合并读出，复用共同坐标。输入重构仍用 H 的 decoder；新可行点不自动是 ADV，必须验证原网络。

## 前向读出与完整成本

任意活混权读出 J=wᵀz+vᵀq 先合并为

```text
J=[v+(1−α)w]ᵀq + αwᵀqbar
  + [(Uᵀw)⊙gbar]ᵀγ + wᵀe.
```

给最后一项可靠上界 ρR||w||₂，再对共同 q 和原 γ 做既有健全支持上界，即是无需新优化器的前向查询。不可把同一 q 在两项中独立复制后声称保住取消。由 (2) 还能给另一个上界 wᵀzbar+LR||w||₂+upper_H(vᵀq)；对所有查询统一取已证上界的较小者，不按终端结果重试。两者均只是 outer bound，不是非凸纤维的精确 support。

显式账本是 m 个新原 bits、n 个新幅值、2m 条 crossing guards、2n 条 aggregate caps 和两条向量范数关系。范数关系的向量维数、系数及求值当然不是两项常数成本。还要支付 V/U、source 展开、所有活 q、中心、可靠 norm 证书、位宽、见证检查、传输和完整生命周期。一次给定方向至少涉及 Uᵀw、q 的共同系数组合、m 项 phase 系数归约及 norm 认证。GPU 可批量化是实现可能性，不是已有设备结果。

普通精确四行参照用 m 个 r 幅值和 4m 行。只有 m>n 时此候选才存在幅值节省；忽略范数前的线性行数也才会由 4m 降至 2m+2n。m=n 的普通同宽块不能据此声称压缩。若隐藏 r 另有活消费者，上述 m→n 账本失效。

普通 LP/MILP 不直接支持 (1) 的非凸二次关系。固定前向方向可用 R 给线性 outer rows，而 (2) 也可给固定方向行；这会损失原生集合的信息，必须分别量化。精确还原 r 后求终端虽可复用旧图，却失去所称压缩。当前未给出完整方向人口、可靠 lowering 和实际费用，因此不进入执行。

将同一 sector 证书给旧图后，旧图也能证明相同控制，并不单独否定新表示价值。正确问题是：候选能否在完整活状态、同信息和同后端下，用更低完整成本保住所需能力。反过来，也不能仅凭 m→n 的局部数目忽略终端费用。

## 非精确 tied 的普通正控制

设 x∈[-1,1]^2，并取

```text
A=[[1,1/4],[-1/4,3/4]], b=(1/4,1/4), q=ReLU(Ax+b),
V=[[1,1/4],[-1/2,3/4]], c=(-1/8,-1/8),
U=[[-4/5,9/20],[-9/40,-3/5]], qbar=(1/4,1/4).
```

λ=4/5 时 E=[[0,1/20],[-1/40,0]] 非零，ε=1/20。VᵀV 的绝对行和给 K=11/8，可取 ν=6/5；α=11/20、ρ=61/100、L=53/50。ReLU 非扩张及 A 的源盒平方界给 R²=29/16，gbar=(3/16,−1/16)。四个门均在源盒内跨相位，不靠极端数值或重复门。

对 w=(1,−1)，J=wᵀ[z−(9/20)q]，直接代入得到

```text
J ≤ −69γ₁/640−21γ₂/320+(61/100)sqrt(29/8)
  ≤ 61/50 < 5/4.
```

因此整个源盒上的下一 ReLU(J−5/4) 恒为零。这是扇区查询的普通全域纸面正例，不是本项目已执行的新 CERT。该控制 m=n，没有幅值节省；强旧图加同信息证书也证明它。它只说明非零 untied defect 下公式仍可用，不能代替训练网络匹配或成本正例。

也能直接证明它不是完整图换名。在 x=(1/4,0) 时，q=(1/2,3/16)、g=(27/64,−15/64)，原 γ=(1,0)。令 e=0，则候选允许 z=(17/80,23/128)，真实块输出却为 (13/80,237/2560)。第一范数显然成立；zbar=(1/10,133/640)，假点的 ||z−zbar||²=1377/102400，小于 L²R²=81461/40000。父盒给可靠 rmax=(27/16,13/16)；假点 z−q=(−23/80,−1/128)，也通过 (3)。因此严格有损是实质的，而不是缺少某个 guard 才产生的非法相位。这个假点是抽象成员，不是 ADV，也不表示精度优于原 HZ。

## 先例与下一缺口

[Meunier 等的原论文](https://arxiv.org/pdf/2110.12690) §4.1–4.2 已给出凸势梯度和 tied Convex Potential Layer 的非扩张构造。本页使用其经典机制加显式 E 扰动估计，不引入训练、power iteration、SDP 或额外验证器，也不把这些基本不等式称为新数学。[Ellipsotopes](https://arxiv.org/abs/2108.01750) 是范数约束生成元载体的重要既有对照；保留 bits 并加球不能单独证明领域新颖性。

未完成且决定是否实现的事项是：普通完整残差块的 m>n 与全部消费者覆盖、确定性的 λ 和可靠 norm 规则、真实 U+λVᵀ 缺陷大小、完整终端精度与支付。必须按实际结构检验，而不是反复调小例子的 E。CIFAR/Tiny 优先与完整 Neural-HZ Goal 不变；本页没有证明它们满足有用的近负转置关系。
