# 跨层幅值关系的物理输出分离

本轮把研究从辅助乘积的一致性推进到原网络输出：先证明一个自由条件观察的严格无增益结论，再构造无需新增变量的跨层幅值关系。普通两层网络上的精确有理正控区分了该关系与很强的逐门凸化对照；宽卷积的充分冗余条件同时说明为什么不能直接外推真实收益。

机制属于已知 perspective、条件支持和正齐次差分，不是新凸包类别或已完成的 Neural HZ 定义。新增项目证据是可构造的后代观察证书、强对照下的物理输出分离、区间系数的健全版本及普通宽 fan-in 的止损条件。所有证明均为纸面推导和独立复核，没有执行测试、求解器或模型。

## 原非凸语义与新增关系的位置

保留原 HZ 的连续源、全部原 bits、EQ/LE、共享 frame 和输入 decoder。设两原门为

```text
q=R(g), h=a*q+v, r=R(h), R(t)=max(0,t),
原父相位 alpha，原子相位 beta，0<=q<=Q*alpha。
```

Q 为有效上界。v 是同一原赋值下的真实剩余读出，不是独立副本；L<=v<=H 必须有可靠证书。新增关系均由原整数语义推出，故每个旧具体状态原样满足，不改 decoder。所有零点合法相位选择保留；证明中分析凸包不授权放松或删除实际域中的原 bits。

局部投影定理用自由盒状 v 作比较，实际网络的额外源谓词仍保留。各边采用同一数学规则，不能按模型身份、标签、margin 或求解状态挑选。Add/Concat 仅能对齐同源坐标后使用已经成立的关系；本轮没有证明任意跨块固定宽度闭包。

## 自由条件观察不会带来物理投影收益

沿用 [前轮四行接口](../d035_cross_phase_source_20260930/THEORY.md)，假设 Q>0、H>L、a非零，归一化

```text
x=q/Q, z=(v-L)/(H-L),
u=(U-L*beta)/(H-L), w=(r-U)/(a*Q),
t=(T-L*alpha)/(H-L)。
```

旧系统含 0<=x<=alpha<=1、0<=z,beta<=1、u=beta*z 与 w=beta*x 的 McCormick 包络。添加 t=alpha*z 的包络及 D035 四条共同关系。如果 T 没有其他消费者，那么投影掉 T 后，恰好恢复旧系统；不是仅未找到反例。

反向构造取 delta=max(w,alpha+beta-1)。由旧 w 包络及 x<=alpha 得

```text
w<=delta<=alpha-x+w,
max(0,alpha+beta-1)<=delta<=min(alpha,beta)。
```

令 alpha、beta 四格质量为 delta、alpha-delta、beta-delta、1-alpha-beta+delta。x 在 alpha=1 的两格分配一阶量 w、x-w，另外两格为零，均不超过其质量。在 beta=1 的格内给 z 相同条件均值 u/beta，在 beta=0 的格内给 (z-u)/(1-beta)；旧 u 包络保证它们在 [0,1]，零质量格任取。这样得到共同合法的 t，证明扩展存在。

所以可与任何不消费 T、delta 的旧约束同时相交，结论仍成立。父源证书 A*alpha<=a*q+T<=B*alpha 或其他共同观察会打破前提，不能继续套用此无增益结论。对照已包含子门按 q、v 两组提升的关系，不只是弱标量 big M。

决定是不实现孤立的自由 T 四行包装；要么存在真实消费者，要么应直接生成原坐标上的有效关系。

## 三条行给出的精确局部投影

考虑明确集合 alpha in {0,1}、0<=q<=Q*alpha、v in [L,H]、r=R(a*q+v)，Q>0，a为任意固定实数。仅在本定理中投影掉 v 与子相位 beta。令

```text
l=R(L), u=R(H), k=(R(a*Q+H)-u)/Q。
```

该集合在 (q,alpha,r) 上的凸包，恰由 0<=alpha<=1、0<=q<=Q*alpha 和下列三行描述：

```text
r >= l*(1-alpha),
r >= a*q+L*alpha+l*(1-alpha),
r <= u+k*q。                                      (P)
```

证明：固定 alpha>0 和 q，alpha=1 部分的均值 q/alpha 合法。最小 r 是

```text
(1-alpha)*R(L)+alpha*R(a*q/alpha+L)，
```

即前两行右侧的最大值，可在两部分均取 v=L 实现。最大 r 由 active 部分凸函数 R(a*q+H) 在 q=0,Q 的端点弦实现，加 inactive 部分的 R(H)，恰为 u+k*q。两端都对应同一 (q,alpha) 的原集合凸组合；再插值实现中间任意 r。alpha=0 时 q=0，直接得到 R(L)<=r<=R(H)。这给出充分性，也处理任意符号 a。

三行无新增变量；利用 R(L) 与 L-R(L) 不同时非零，已有 q、alpha、r 坐标时至多 6 nnz。原范围、定义及 HZ 格式转换另计。加入真实相关源谓词后这些行仍有效，但不再宣称完整真实网络凸包。实际候选始终保留 v 的原定义与 beta，不执行这里的 bit 投影。

这是标准二值 perspective 与凸函数端点弦的应用。Günlük、Linderoth 的 2009 作者稿 §3 至 §4.2 给出 indicator 控制连续量、perspective 与凸包的通用背景；本处具体 ReLU 公式是项目推导，不归称为原文神经网络定理。[作者稿](https://optimization-online.org/wp-content/uploads/2008/06/2014.pdf)

## 正负幅值的统一前向关系

只使用 (P) 的两条下界，并对 n=r-h=R(-h) 同样处理，令 l=R(L)、m=R(-H)，得到

```text
r   >= l*(1-alpha),
r   >= a*q+L*alpha+l*(1-alpha),
r-h >= m*(1-alpha),
r-h >= -a*q-H*alpha+m*(1-alpha)。                  (A)
```

证明也可直接在原 alpha=0 时用 q=0、h=v，在 alpha=1 时用 r>=0,h 和 r-h>=0,-h。它们不需要运行时分支、不引入乘积或新的 gate。下界的证明来自原整数图，不能误说为对任意 fractional alpha 用 ReLU 单调性直接推出。

去掉被旧 r>=0、r>=h 支配的行后，每条非零系数边最多有两条：

| 数学结构 | 可能非冗余的行 |
| --- | --- |
| a>0 且 L<0 | r>=a*q+L*alpha |
| a>0 且 H<0 | r>=h-H*(1-alpha) |
| a<0 且 L>0 | r>=L*(1-alpha) |
| a<0 且 H>0 | r>=v-H*alpha，内联 v=h-a*q |

这一表仅按统一可观察系数和有效界分类，不依赖 LP 状态。对 a>0，第一行也可通过 aq=R(ag) 这个同 alpha 的正齐次别名及

```text
ag-h=-a*(q-g)-v <= -L
```

直接调用已有相位差分原理。不会新增一个原网络中不存在的 gate 或 bit。因此新内容不是关系公理，而是从真实前向边廉价构造跨层证书。

它也可形式上写作 D029 的后代观察 V=r；但是 V=r 不在旧单层仿射源读出支持器的免费覆盖范围内。不能把任意新观察的精确支持当作旧算法已有 oracle，也不能因最终行可改写为 D029 就否定构造性进展。

### 区间系数无需中点替换

若真实固定 a 位于认证区间 [alo,ahi]，不改原 h 定义，用

```text
r   >= l*(1-alpha),
r   >= alo*q+L*alpha+l*(1-alpha),
r-h >= m*(1-alpha),
r-h >= -ahi*q-H*alpha+m*(1-alpha)                 (AI)
```

仍健全，因为 q>=0。该结论也适用于区间跨零，无需猜真实系数符号。L、H 必须包住真实 v，并计入 bias、BN、其他系数与共享源的实际误差。它不允许把原模型系数换成端点或中点，只允许在新增有效不等式中使用可靠较弱系数。

在已有 q、h、r、alpha 坐标上，四行最多 10 nnz、零新变量：前两行的 l 与 L-l 不同时非零，合计至多 4；后两行的 m 与 H+m 不同时非零，合计至多 6。原等式格式所需 slack、向外舍入、证明和终端成本另计。对 (AI) 不声称区间系统的精确凸包，也未给出 GPU 数值认证。

## 超过逐门完整凸化的物理输出正控

取普通网络

```text
x,y in [-1,1], g=x, q=R(x),
h=3*q/2-1/2+y/10, r=R(h),
z=21*q/10-3*x/5-r。
```

所有侧共享 q in [0,1]、v=-1/2+y/10 in [-3/5,-2/5]、h in [-3/5,11/10]。旧松弛点为

```text
x=1/10, y=0, q=2/5, alpha=1/2,
h=1/10, r=3/20, beta=1/2，z=63/100。
```

父门完整 labeled source hull P 由 x、y 盒与

```text
q>=0, q>=x, q<=alpha, q<=x+1-alpha
```

描述。该点由父门真实源 (x,y)=(4/5,0)、(-3/5,0) 各半混合得到，全部严格内部且非零相位。

子门不只通过在 (q,y) 盒上的完整 hull，甚至通过以完整 P 为输入域的 labeled hull。使用以下两个子门源点各半混合：

| 子门相位 | q | x | alpha | y | h | r |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 8/15 | 3/10 | 7/10 | 0 | 3/10 | 3/10 |
| 0 | 4/15 | -1/10 | 3/10 | 0 | -1/10 | 0 |

两源点均在 P 内：第一点的父门混合用 active x=16/21 权重 7/10，inactive x=-7/9 权重 3/10；第二点用 active x=8/9 权重 3/10，inactive x=-11/21 权重 7/10。父源点严格内部、符号明确。因此即使子门使用父图全部有效线性源事实，其局部凸包仍允许这个点。此处 P 的 alpha 是查询中的连续坐标；不是声称含原整数 alpha 的完整两门联合 hull 也允许它。

还可加入未缩放的全部跨层相位差分行。真实 h-g 范围为 [-3/5,3/5]；旧点的 d=q-r=1/4、delta=g-h=0、e=d-delta=1/4，满足

```text
-(3/5)*beta <= d <= (3/5)*alpha,
-(3/5)*(1-beta) <= e <= (3/5)*(1-alpha)。
```

旧单边 D029 的 A=-21/10、B=11/10、L=-3/5、H=-2/5 也通过；子门普通正负幅值容量通过。此比较不包括已经加入新正齐次跨边别名的无限闭包，也不声称超过完整两门联合源凸包。

新行给 r>=3*q/2-(3/5)*alpha。与原父门 alpha<=x+1-q 合并，得到原坐标性质

```text
z=21*q/10-3*x/5-r <= 3/5。
```

所以旧 z=63/100 的物理点无法靠重选 alpha 恢复。真上界 3/5 在 x=1、y=-1 达到；性质 z<=123/200 的真安全裕量为 3/200，旧点违反同样 3/200。正控既不是 ADV，也不是执行过的 CERT；它证明强对照下存在实际输出方向的分离。

## 普通宽卷积上何时全部无收益

第一类行在 a*Q+L<=0 时被 r>=0 支配。第四类行在 a<0、H>=-a*Q 时被 r>=h 支配。另两类分别在 a>0、a*Q+H<=0 时对应子门必不激活，在 a<0、L>=-a*Q 时对应子门必激活，新增行由已有图界支配。这些是普通代数判据，不是极端数值特判。

更直接的全边负控：对 h=b+sum_j a_j*q_j，q_j in [0,Q_j]，以同一独立盒分解计算

```text
ell=b+sum_j min(0,a_j*Q_j)<0,
U=b+sum_j max(0,a_j*Q_j)>0。
```

若每条边都满足 |a_j|*Q_j<=min(-ell,U)，则按这些独立盒余项界生成的四类下界对所有边均冗余。正边 L_j=ell、H_j=U-a_j*Q_j>=0，第一类右侧非正；负边 L_j=ell+|a_j|*Q_j<=0、H_j=U，第四类不超过 h。没有其余可用新行。

这是普通多输入混合权重结构可能满足的充分条件，不是实测 large 或 Tiny 的结论，也不否定相关源证书收紧 L/H 后产生收益。它要求下一步先查非冗余人口与证书代价；不能因为 toy 成功就物化全边关系，也不必为无收益关系构造昂贵 BQP 提升。

上述 LP 冗余判据以查询系统确实含 q<=Q*alpha 为前提。真实源区间及整数语义能推出此行，不等于生产 LP 已经绑定该行；实际 census 必须核对原二元列和谓词，若另增该行则计入成本，不能凭 source phase ID 默认继承。

## 全部代价和下一项研究

确定系数、物理 q/h/r 列已有时，精简后每真实边最多两行、6 nnz、零辅助量；所有 E 边仍为 O(E)，不是每接收节点常数规模。仅按旧 large 五窗口人口上限 E<=102400，相应上限为 204800 行、614400 坐标 nnz，不是实测或整网数字。

若 q/h/r 是原 latent 上的仿射 readout，每边两行合计非零上界为 2*s_r+s_h+s_q+2，常数进入 RHS，并须合并重复 latent。原 HZ 若用 {-1,1} bits，还须计入 alpha=(b+1)/2 的系数和 RHS 转换。不能把坐标级 6 nnz 当成生产终端 6 nnz。区间 (AI) 的未精简上界则为 4E 行、10E 坐标 nnz。

独立盒余项可先求每项上下贡献及一次接收节点总和，再剔除当前贡献，精确算术为 O(E)。不能将任意已认证 h 的相关下界减去某项的最小值，就当作余项下界；总和与剔除项必须来自同一加法分解。向外舍入须使用带认证误差的总和减项或前后缀和，完整计费。相关源支持不由这次总和自动提供，仍需单独证明及编译。

新增行作用可以按边 gather 父 q、alpha 与子 h、r，再作逐元素乘加；转置需向这些共享列 scatter/reduce。还需原 HZ 的设备算子、全部证据/误差、临时量、传输、terminal conversion 和普通求解成本；本轮没有 GPU 实现或性能资格。

下一项有效行动是以固定真实结构人口审查这些判据及可认证余项界，先回答廉价版本有多少非冗余边。任何数值审查须另行冻结预注册和完整继承门，不能重跑冻结失败版本或缩减人口。若独立盒版本被判冗余，定义研究须明确增加哪一种可构造共同源关系、如何跨块保留、为何总成本可承担；不能把无效全边堆叠当作新域。
