## 域元素与联合替换定理

令 z 为带常数坐标 1 的共同有界连续环境，包含原输入因子及尚被使用的
历史连续误差；beta 为全部原二元身份的 0/1 视图，始终保持整数类型。
考虑当前状态，而不只考虑原网络真实轨迹：

```text
Gamma = {(z,beta,v): S(z,beta), v=C(beta)z, P(z,beta,v)}.
```

v 共同承载全部活输出、旁路以及保留谓词所需读出。S 保存源谓词和身份，
P 保存声明保留的 EQ/LE、原标签守卫及其他关系。原输入 decoder 是 z 的
受保护精确读出，不允许通过独立误差改变输入身份。C 可为已有共享的相位
系数电路，不需要枚举 beta。允许 S/P 包含此前有证误差关系，但不能假装
这些新关系都已经得到原线性 HZ 后端的实现支持。

假设在整个当前 Gamma 上有可靠证书：

```text
[C(beta)-Ctilde(beta)]z belongs to R(beta,z).
```

定义新状态：

```text
Gamma_hat = {(z,beta,v): S(z,beta),
             exists one r in R(beta,z),
             v=Ctilde(beta)z+r, P(z,beta,v)}.
```

则 Gamma 包含于 Gamma_hat，且包含在相同源和原标签上逐点成立。
证明：对任意旧状态统一取 r=[C-Ctilde]z，得到相同 v，所以全部保留谓词、
旁路和 decoder 同时成立。这个证明不能改成“每个读出各有一个 r”。后者
可以构成更弱外包，却不再保留本文的共同关系。

这是真正可以替换旧输出方程的抽象合同，不要求再保留 v=Cz；如果把它也
保留，新项就只是冗余模块。只取 Ctilde=C、R={0} 可精确嵌入原状态。
按对齐的源、标签与可见读出集合包含定义精度；未声称最佳抽象或完整格。

## 保护精确连接与相位含义

联合包含不自动保留每条未显式保护的精确连接。若旧 g=q=1、beta=1，
实际残差为零，但误差外包允许 r_g=0、r_q=eps，那么 q=1+eps、g=1
可以同时满足符号守卫及 q 的输出开关，却不满足 q=beta*g。
这不否定外包健全性；它否定“仅保留 mask 就等于原门仍精确”的说法。

必须把哪些关系精确保留写进定义。对受保护连接可用同一 core h，令
g=h、q=beta*h，而不是独立近似 g/q；一般可写为

```text
v=A(beta)[Htilde(beta)z+r],
```

其中 A 是声明精确保留的连接映射。物理别名与共享消费者使用同一行；
decoder 直接保留原读出或将对应误差强制为零。只保证 off-state 为零时，
可用原 beta 的输出 mask，但必须明确 active-value 关系已有抽象误差。
所有保留的原守卫都在同一当前读出上求值，不给守卫另选误差，也不只保留
一个名义上的 phase ID。

另一个必须避免的循环：若同时保留全部原 q_i=beta_i*g_i、所有
g_i=W_i*q_prev+b_i 及原源关系，则它们已经决定完整原网络图。此时
再加低秩误差不会变成严格有损新域。实际替换必须指明哪些数值关系被可靠
外包、哪些 EQ/LE 及连接仍精确保留；不能一面丢弃关系，一面在证明里调用它。
对原连续状态的有证外包不授权删除、合并或连续放松原二元因子。

## 一个绑定共同源的残差族

若一次结构 cut 有证满足

```text
C(beta)-Ctilde(beta)=L(beta) E(beta) R(beta),
norm_F(E(beta))<=eps,
```

可使用一个共同 eta：

```text
v=Ctilde(beta)z+L(beta)eta,
norm_2(eta)<=eps*norm_2(R(beta)z).
```

取 eta=E(beta)R(beta)z 即证明包含。对固定 t=R(beta)z，该误差集合
恰等价于 eta=Delta*t、norm_F(Delta)<=eps。t 非零时取
Delta=eta*t^T/norm_2(t)^2；t=0 时允许的 eta 只能为零。
这是同一源上的关系，不能用每个输出各自独立的常数误差代替后仍称等价。

固定 beta,z，方向 w 的误差支持为

```text
sup_eta w^T L eta = eps*norm_2(L^T w)*norm_2(R z).
```

证明为 Cauchy-Schwarz，非零方向时取球内对齐向量达到；不是新的优化定理。
这只是该条件误差 fiber 的支持，尚未优化整个带 S/P/原 guards 的状态。
实际误差球存在非线性源耦合，不能冒称普通 LP/MILP terminal 已经支持。
若改用线性外包，必须公开它引入的损失与费用，不能隐含新增 SDP/SOCP/helper。

这个族确实能严格有损且非凸。例如：

```text
x in [-1,1], beta in {0,1}, (2beta-1)*x>=0,
q=beta*(x+eta), abs(eta)<=abs(x)/10, q>=0.
```

原 ReLU 图取 eta=0，被完整包含。x=1/2、beta=1、eta=1/20 时 q=11/20，
是额外抽象状态。(-1,0) 与 (1,1) 均可行，中点 (0,1/2) 不可行；x=0
时原两种合法标签都保留。这只检查定义的非凸性与严格外包，不是压缩收益、
神经网络正控或实际 ADV。没有用这个标量例子代替普通混权结构的资格。

## 递归前向变换

Affine/Conv 在相同环境上左乘共同读出，偏置用受保护的常数坐标准确加入。
Add/Concat 合并同一 r/eta 的系数和身份，不能复制成独立误差。

对当前抽象状态上的新 ReLU，先构造同一个预激活 g=d+w^T v，再令
q=gamma*g，并添加原 gamma 的符号守卫 (2gamma-1)*g>=0。
这是当前整个抽象状态的精确 ReLU 变换；g=0 时两种 gamma 都合法。
它不是只在原真实轨迹上有效。已有多输出和 skip 继续读取同一旧状态。

将 (z,eta) 作为带原约束的扩展连续环境，可以再次使用联合替换定理；
新证书必须覆盖扩大后的当前状态。归纳即得到任意有限次已声明变换的
健全组合。每个新误差有认证的有限上界后才可归一化为连续盒因子。

这里没有免费的固定宽度闭包：重复压缩通常追加误差环境和谓词。若要合并
旧误差或移除死连续因素，必须另证共同外包或精确投影，覆盖全部消费者，
计入误差增大、矩阵填充和 decoder；不能直接把多个球换成一个同半径小球。

## 分离秩与相位次数的区别

将 C(beta) 视为以原二元取值为索引的系数张量；相位仍是变量，不是运行时
枚举的子问题。TT/MPS 用一串小 core 表达它，结构 cut 的 unfolding rank
控制相应 bond rank。普通 TT 与低秩 rounding 已有成熟数学先例，不能
把采用它们本身算作新颖性。
[Oseledets 2011，定理 2.1、2.2 及第 3 节](https://users.math.msu.edu/users/iwenmark/Teaching/CMSE890/TENSOR_oseledets2011.pdf)
给出秩与 unfolding 的关系、TT-SVD 的 Frobenius 误差界和已有 TT 的
rounding；这些是本轮借鉴的基础，不提供神经网络健全性或收益证书。

两种压缩量确实不同：prod_i(1+beta_i) 含任意高阶相位项，但真值系数
张量 rank 为 1；sum_i beta_i*beta_(m+i) 仅二阶，按两个半部划分时矩阵
rank 为 m。后一结论来自两侧独立坐标函数的内积表示。两例仅区分代数
不变量，不宣称它们就是已认证的普通 CNN 控制。

基的选择会影响安全误差。对真值索引张量，绝对 Frobenius 误差 delta
控制每一个 phase slice，所以 norm(E(beta)z)<=delta*norm(z)。若压缩
未归一化的单项式系数，则还要乘评价向量的范数；所有原 bits 为 1 时，
完整多线性单项式向量的范数可达 2^(N/2)。不能把平均或相对误差直接
当作逐相位守卫误差，也不能为获得张量而枚举所有相位。

## 活旁路和历史守卫的秩代价

普通全幅值旁路已经阻止一种乐观预期。考虑 q_i=beta_i*f_i(x)，
f=Ax+b，完整 q 仍被 identity skip 使用。将 joint output/source mode
放在所有 phase modes 后，在前 k 个 phases 后切开，k<N。
第 i<=k 个输出的非零源系数提供独立列函数 beta_i；一个剩余门提供
常数列函数 1，所以该全 Boolean unfolding rank 至少 k+1。
可逆 mixed A 和内部含 -A^(-1)b 的源盒可使全部相位拥有开纤维，
这个 bank 例子不依赖非法相位或零标签。它不是所有 TT 布局的下界。

即使原 live frontier 宽度为 1，也不能忽略历史 guards。链
q_i=beta_i*(q_(i-1)+b_i)、q_0=x 的全部预激活与最终输出含源系数
1、beta_1、beta_1*beta_2、直到完整前缀乘积。相同末端 readout 布局
在第 k cut 至少有 k+1 个独立前缀函数。此链结论针对全 Boolean 系数
张量，不针对 guard-feasible 商；流式局部读出可避免这个特定膨胀，但
仍须计其存储与连接，不能一概宣称 TT 必须如此昂贵。

## 比 bond rank 更直接的终端指标

对固定原 phase 顺序的 core，写为

```text
s_i=A_i*s_(i-1)+beta_i*B_i*s_(i-1),
B_i=L_i*R_i, rank(B_i)=t_i.
```

有认证的连续投影界后，t_i 个 beta_i 与连续量的乘积可以用标准四行
精确整数编码。这个显式构造的费用为 4*sum(t_i) 条乘积行，另付状态
等式、全部系数 nnz、源初始化、输出、guards、误差及界认证。
这不是所有编码的最优下界，更不能省略误差球的非线性 terminal 问题。

原逐门神经更新在加入常数坐标后通常有 B_i=u_i*v_i^T，rank<=1。
若保持原 mode 顺序，压缩确实只作常数双边映射 G_i'=P_i*G_i*Q_i，则

```text
B_i'=(P_i*u_i)*(v_i^T*Q_i), rank(B_i')<=1.
```

当 B_i' 非零、原 bit 未固定、对应连续投影不是已知常数或零，且没有
其他已证消项时，这个显式构造仍引入同一原 bit 的一次乘积。已知常数 c
可直接写成 c*beta_i，固定 bit 也无需乘积编码。压低状态宽度本身不自动
减少这项费用；误差、原标签和全部守卫仍需计费。此局部命题不覆盖 phase mode 交换、
多 bit core 合并或非局部算术后的任意重分解，不能扩大成一般不可能性。

## 四门 packet 不能自行替换原门

另一个本轮复核排除了把 D141 的 min 恒等式直接提升为新域。
取 a=-3/4、b=c=1/2，前三门真实 q00=q10=q01=0，原相位为 (0,0,0,1)，
第四门真实预激活为 1/4。假赋值 q11=k=2/5 仍满足

```text
q11=q10+q01-q00+k,
k=min(b,c,q00-a,q11),
q11>=g11,
```

以及全部原符号守卫。min 的最后一项又含 k，未绑定实际幅值。
活旁路 v=1/8+a/10+b/5-c/10=1/10，后继 R(q11+v-2/5) 的真实值为零，
假状态为 1/10。它是源盒内部的普通反例，不是浮点或零标签特例。
恢复原 active-value 关系可排除它，但不能因此宣称 packet 自身已替代原图。
