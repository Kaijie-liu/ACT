# 共享原相位与非负误差预算

本轮直接研究域的具体化关系，不研究存储、loader 或外部 helper。候选将新生 ReLU 包的逐门幅值关系替换为一个共享原相位和耦合误差预算。它是健全但有损的非凸关系；以下给出证明，同时明确未取得创新性、真实网络能力或执行资格。

## 定义与出生健全性

设 S 是整个当前抽象父域，g_i 是其实际预激活，beta_i 是原门相位的 0/1 记法。保留原 signed bits 的身份、原弱 guards、零点双标签、父 EQ/LE、共享源和 decoder。完整消费者矩阵 C 必须涵盖所有活读出；若旧谓词仍独立使用 q_i，就不能只保留 Cq。选择一个结构上固定的原 anchor a，令 b=beta_a；这不是增加常量参考相位，也不按实例、标签或终端状态选择规则。

取经过认证的父域上界 R_i>=sup_S |g_i-g_a|，R_a=0。真实 ReLU 输出有规范扩展

```text
q_i = b*g_i + e_i,
e_i = (beta_i-b)*g_i >= 0,
e_a = 0,
e_i <= R_i*|beta_i-b|.
```

同相位时误差为零；异相位时 g_i 与 g_a 弱异号，所以 |g_i|<=|g_i-g_a|。该证明适用于 S 的每个赋值，包括所有合法零点标签，不只是采样输入或原网络可达子集。

候选放宽逐门上界为共享预算：

```text
e_i >= 0, e_a=0,
sum e_i <= sum R_i*|beta_i-b|,
Y = b*C*g + C*e.
```

规范扩展证明此出生变换健全。同一份 e 必须由全部消费者共享。若全部 beta_i=b，预算归零，当前包精确；不宣称混合相位精确。父域已丢失的关系不能借出生定理重新收紧。

令 T0=sum R_i、A=sum R_i beta_i、E=sum e_i。保留整数 b 时，无 XOR 新 bit 的统一线性预算为

```text
E <= A + T0*b,
E <= 2*T0-A-T0*b.
```

其中恰有一行给出对应相位的预算，另一行冗余；并非运行时多路径。终端 LP 即使松弛 b，这两行之和仍给 E<=T0。每个 u_j=b*(Cg)_j 可以用可靠 L/U 和普通四行二元乘积编码；求界、Cg 系数与转换成本都必须支付。原生语义不把原相位连续化。共享 b 与原源乘积保留非凸关系，单门情形还原原 ReLU 图，但这不建立相对 HZ 的表达力超越。

## 投影与关键缺陷

固定原相位、令 t=sum R_i*|beta_i-b| 后，完整误差像是 t*conv({0} union {C_i:i!=a})；要移除 e，必须实际得到并支付该像的完整有限表示，或保留 m-1 个误差幅值。不能把“只有 p 个输出”当作免费投影。必要的非负输出 cone Y in C R_+^m 也不恢复逐门图。

尤其 e_i>=0 不推出 q_i=b*g_i+e_i>=0。普通三门例子：父源 (x,y) in [-1,1]^2，

```text
g=(x+3/4, y-1/2, x+y+1/4), a=1,
C=((1,1,1),(1,1,-1)),
R=(0,13/4,3/2).
```

在 x=y=0、beta=(1,0,1) 的严格相位点，真实 Y=(1,1/2)。候选 e=0 却给 Y=(1/2,0)，仍满足完整 cone M>=|D|，但内部第二幅值为 -1/2。即使取 e=(0,1/2,1/4)，所有内部幅值非负，仍给错误的 Y=(5/4,1/4)。这些是抽象伪赋值，不是原网络 ADV。

[六十门对照](CONTROLS_AND_COST.md)进一步给出全部内部幅值非负、inactive 为零、界内且原源严格内部的负例。因此仅修补负幅值不能解决候选的关键损失。

## 一般前缀账与研究资格

若每个 g_i 都内联 k 个源系数，除 anchor 外 R_i 非零，保留 m-1 个 e 和 p 个产品，则有 3m+4p+1 条 LE，直接系数数为 m(2k+7)+p(2k+8)-3；原逐门四行图为 m(2k+6)。少行不等于少系数。共享 E、A 可改变系数账，但增加变量与 EQ，仍须另计全部读出、投影、界、证明元数据、终端与重构。

该候选不是 helper 救援：健全性只用自己的父域、原相位和前向结构上界。然而这也不是新颖性的充分条件。它来自原守卫和已有 Lipschitz 后果；当前强对照更便宜且证明更多相关性质，因此本轮不进入实现或正式晋级。
