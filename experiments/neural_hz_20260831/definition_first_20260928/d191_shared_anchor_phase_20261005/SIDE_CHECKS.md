# 同轮侧向假设检查

这些检查用于避免重复已排除方向，不作为新研究主线或执行成果。

## 非光滑的精确源绑定

D182 的有限纯二次惩罚负例不涵盖带绝对值的精确惩罚。若 R_i>=sup_parent |d_i|，关系

```text
||t||^2 + 2*sum R_i*|t_i-d_i| <= ||d||^2
```

确实等价于 t=d。令 n=t-d，左减右等于 ||n||^2+2*d.n+2*sum R_i|n_i|，至少为 ||n||^2。更一般地，若右端增加 sigma，则

```text
||n||^2+2*sum (R_i-|d_i|)*|n_i| <= sigma.
```

这是真实的边界补充，不能继续把 D182 的纯二次反例概括为所有有限惩罚都失败。不过终端必须支付 norm、abs 和实际源绑定的非线性关系；若直接用定理消去 t=d，则回到已有精确相位源图，不产生免费 LP/GPU 查询或独立域创新。本轮未实现任何惩罚优化器。

## 因子图与完整 separator

完整关系的 running-intersection 拼接已有 D059/D169 档案；只匹配均值或有限低阶摘要不受该精确定理保证。保留原 bits、不枚举相位并不能自动控制连续投影的行数、填充、位长与查询费用。

D179 的已知 group1、3x3、stride1 late 形状，按空间行扫描时共享两行输入的声明接口为：CIFAR large 的 2*4*256=2048、medium 的 2*4*128=1024、Tiny 的 2*7*128=1792 个源坐标。这是指定布局计数，不是所有分解的下界。

128 输入通道的内部 patch 有 1152 个声明源；不拆行因子时构成 primal clique，相应原行 incidence 图含 K_(1152,128)。D179 没有认证实际系数非零，故不称实测有效树宽；引入二元求和节点也会改变图宽并增加付费辅助变量。残差与最终完整 dense 消费者仍需保留。没有新的可查询受控关系类，因此不为此实现 junction-tree helper。

## 更严格共同相位的未晋级备选

协作者提出 b=AND_i beta_i，可用连续 b in [0,1]、b<=beta_i、b>=sum beta_i-m+1 表达；在原 bits 整数时 b 自然为整数。若共同 affine a 满足 |g_i-a|<=rho_i，则

```text
Y=b*C*g+C*e,
0<=e_i<=(rho_i+max_j rho_j)*(beta_i-b)
```

有真实规范扩展，混合时保证非负且 inactive 为零，同相位精确。但一般完整消费者的 box-image 投影仍需付费；二维有限列方向只解决特定几何条件。该备选尚无真实结构和强旧对照能力资格，未实现，也不声称新颖。
