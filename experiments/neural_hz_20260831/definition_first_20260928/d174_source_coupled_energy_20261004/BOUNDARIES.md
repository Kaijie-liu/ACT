# 共同参照和源锁候选的边界

本文件保留本轮及紧邻上轮尚未归档的推导，避免把被否决的方向再次当作新突破。所有结论为纸面研究，无候选执行。

## 动态均值和公共激活参照

令 mu=mean(g)、P=I-11ᵀ/m、d=Pg，C含mean。动态均值代理 dhat∈d+ker(C)、||dhat||²<=Econtrast、a=mu*C*gamma+C D_gamma dhat，变换 h=mu*1+dhat 后恰为 D156 的同一纤维，预算为 m(mu-b0)²+Econtrast。相对全局 E 的变强依赖此预算在整个父域不超过 E；不是新的集合原理。一般 C 的 mu*C*gamma 仍有源乘相位费用。

公共 anchor s=ReLU(mu) 的 firm 关系为

```text
||r-s1-Pg/2||² <= ||Pg||²/4,
1ᵀ(r-s1-Pg/2)>=0.
```

第二式来自 Jensen，与第一式必须共用同一见证。投影到 y=Ur 使用 UUᵀ，不是 UPUᵀ。令 v=Uᵀw、R>=||Pg||，half-ball 的支持为 R||v||/2（sum v>=0）或 R||Pv||/2（sum v<0）。这是可计算的经典支持，不授权另一个求解器。

但记 t=mean(r)，有精确恒等式

```text
||r-s1-Pg/2||²-||Pg||²/4
 = ||r||²-gᵀr-m|mu|(t-s).
```

所以共同 grounded sector 加 Jensen 已蕴含它。原生加强相对 D173 的例子也会在 anchor 的四行 LP 里丢失：源 x=y=0，g=(1,1,-1)，gamma=110，U=(1,-1/4,1)，代理 r=(15/8,15/8,0)，旧 t=5/4,yout=45/32；mu=1/3。原生 s=1/3 拒绝该 yout，但 source box [-3,3]^2 上 g=(x+y/4+1,-x/4+y+1,x/2-y/3-1) 给 mu 界[-11/6,5/2]，四行允许 eta=1/2,s=5/4。此时同一代理残差mean为0、平方49/96<=2/3，half-ball也接受。不能把整数 anchor 的分离算成终端 LP 收益。

## 等权池化的可用特化与不适用证据

保留全部原gamma，k=sum gamma，mu=mean g，R²为整父 contrast 上界。对一份同原相位符号、mean为mu的代理，令t为其ReLU均值。0<k<m时精确投影为

```text
t>=max(0,mu),
(m*t-k*mu)² <= k(m-k)R²/m.
```

证明：active坐标常值mt/k，inactive坐标常值m(mu-t)/(m-k)达到最小contrast能量m(mt-k*mu)²/[k(m-k)]。k=0给t=0,mu<=0；k=m给t=mu,mu>=0。弱号保留全部零标签。这是 D156 动态mean参考的标量特化，不是新非凸原理。

设p=k/m、sigma=R/sqrt(m)，可靠mu∈[L,U]。对固定a,b，支撑H=sup(t-a*mu-b*p)可以统一扫描m+1个count：0<p<1时，mu的可行区间是[L,U]与[-sigma*sqrt((1-p)/p),sigma*sqrt(p/(1-p))]的交；按p-a符号选相应端点，候选值为(p-a)*mu+sigma*sqrt(p(1-p))-b*p。端点p=0、1分别使用mu<=0及mu>=0。最后发一条全模式有效行t-a*mu-b*k/m<=H，不求解任何相位子域。O(m)统计支撑构造须计费，不是免费精确求解。

小接口控制m=4,R²=4,mu∈[-1/4,1/4]，固定a=1/4,b=1/2给H=5/16，得到t<=mu/4+k/8+5/16。它在mu=0,k=1拒绝t=15/32，而丢count的均值方差关系允许它。仅为接口精度，不是网络成绩，也不超过相同信息的 D156 原生纤维。

另有更廉价但非理想的编译：预固定v>0，由sqrt(p(1-p))<=(vp+v^-1(1-p))/2得到两条行

```text
t <= U*p+(sigma/2)(v*p+v^-1*(1-p)),
t <= mu-L*(1-p)+(sigma/2)(v*p+v^-1*(1-p)).
```

每v两行、无新幅值/位，p直接引用sum gamma/m；sigma必须是已经认证的固定常数。分数控制m=6、sigma1、mu∈[-1/10,1/10]、v2、每gamma_i=1/4、mu0、t49/100，新第一行上界37/80，拒绝该点；phase-free界1/2及原四行在ell=-7/3,u=7/3允许它。普通源g=(I-11ᵀ/3)xi、xi∈[-1,1]^6并保留|mean g|<=1/10提供该预算，g=(1/10,-1/10,1/10,-1/10,1/10,-1/10)、每q_i=49/100给四行见证。此额外控制同样仅为支撑，不改变无真实pool绑定的决定。

逐行推广到任意mixed U不能维持共同见证。例如source d=(1/2,1/2,-1)、mean0、gamma110、R²10，U两行为(1,-1/4,1/2)、(-1/3,1,1/4)。目标输出(3/4,2/3)各行可分别由代理(19/20,4/5,-7/4)、(5/4,13/12,-7/3)实现，保各自mean、U_i d、原符号及能量；完整C=[U;mean]却可逆，共同Cd强制代理=d，只能输出(3/8,1/3)。不能把独立行特化伪装成联合域。

本轮直接核对 D152 三个完整CNN图：AveragePool、GlobalAveragePool、ReduceMean、MaxPool、MatMul均不存在。large末端为Add56→Flatten57→Gemm58→Relu59→Gemm60，medium/Tiny为Add54→Flatten55→Gemm56→Relu57→Gemm58，各端口只有紧接消费者。两Gemm权重分别100×4096及100×100、100×2048及100×100、200×6272及200×200；末端transB=1。shape_binding_verified=false，不能补造实际中间tensor形状，更不能把Gemm当等权池化。因此池化路线没有当前CIFAR/Tiny绑定，不扩展工程。

## 精确源锁的正结论与编译损失

在 D156 的 Ct=Cd、a=C D_gamma t、||t||²<=E 上增加

```text
dᵀt=||d||².
```

令delta=t-d，恰等价于delta∈ker(C)∩d-perp、||delta||²<=E-||d||²。点态E=||d||²时强制t=d，对任何C恢复原精确gated图；这不是比精确HZ更强。

使用 D158 已有完整carrier：C行(1,-1,1/2)、(1,1,1)，k=(3,1,-4)，v=C D_101 k=(1,-1)，b=(1/4,-1/4,1/4)。源d=-3k/40、旧代理t=d/16、g=(1/40,-13/40,11/20)通过旧点态能量与完整caps。源锁因dᵀt=||d||²/16拒绝它；C的核只有k，源锁在该点强制真a=-3v/40。

但全局E=3时，d0=0,t0=k/32仍过源锁。与真d'=-2k/25,t'=d'按1/16和15/16混合，得到同一d=-3k/40、a=-3v/40+v/512。两端源严格内部，g和原phase101均严格，caps共同有效。混合点被原生锁拒绝，却被任何覆盖两端的固定原phase连续LP扩展接受。点态预算使锁恢复仿射真图时，不适用这个global-E反例。

增广carrier [C;dᵀ]还需一个共同active读出，其Gram含C D_gamma d及sum gamma_i d_i²，不是旧固定carrier。固定lambda,mu,nu配平方产生2nu*sum_i d_i[(Cᵀmu)_i+gamma_i(Cᵀ(lambda-mu))_i]。若nu非零、只靠逐项系数为零消掉gamma_i*d_i，则必须Cᵀ(lambda-mu)=0，使该方向不再区分a。这个限制仅针对该固定编译式，不是不可能性定理。

由此转向 THEORY.md 的共同距离预算；两方案不可混记。距离方案不排除上述t=d/16点：总成本为113||d||²/128。它的严格控制必须使用另外已给出的四门共同源例子。

本轮的平方恒等式、Cauchy和Young推导独立给出，不将经典工具改名为新数学。新颖性、真实同结构能力与全路径费用仍未建立。
