# 源耦合能量的 Neural-HZ 候选

本轮得到一条改变共同代理语义、而非存储格式的关系：代理幅值的能量与它偏离原源的距离共同支付同一个预算。它严格细化已有消费者纤维，并且有无需新增相位乘积变量的有限线性后果。一个完整四门控制的后继稳定性确实能由统一方向规则证明，旧共同代理关系不能证明该性质。

边界同样重要：该控制的原 HZ 普通四行 LP 已有更强的界，所以这里恢复的是弱共同代理路径丢掉的能力。完整逐坐标 source-centered perspective 也能给出更强的同信息关系；真实 CIFAR/Tiny 的完整接口、终端总费用及 GPU 尚无收益资格。本文件是纸面候选，不是新颖性证明、实现、实测 CERT 或正式新增解。

## 域元素和健全的块变换

保留当前 HZ 的全部连续源、原整数二元相位、EQ/LE、共享 frame 与 latent 身份、原输入 decoder，以及此前所有 bank 和谓词。原 HZ 由零个新 bank 精确嵌入。读出对保留状态和新 bank 幅值仿射；具体化要求同一个赋值同时满足全部谓词。原 signed bits 与下述 gamma=(bit+1)/2 是可逆记法，不删除、固定或连续化任何原标签。

令 g 为整个当前父域上的预激活仿射读出，b 为固定结构参考，d=g-b。C 必须覆盖所有活消费者、skip、旧谓词及重构使用；不能只留下有利性质方向。可靠预算 E 必须满足整个当前父域上的 ||d||²<=E。原有原相位 guards、分支幅值 caps 和 mass dominance 继续保留。

以 p=rows(C) 个共同幅值 a 替代本次新生逐门幅值，定义一份共同存在见证 t：

```text
C t = C d,
a = C D_gamma t,
||t||² + ||t-d||² <= E,
C q = C D_gamma b + a.                         (1)
```

其中 D_gamma=diag(gamma)。所有消费者共用同一 t 的存在量，不能逐行另选代理。是否额外要求 t 落入原相位盒必须明确；下文的比较控制甚至通过这种更强旧参照，但本候选不偷称已经完整投影了全部盒条件。

健全性直接取 t=d，得到 Cq=C ReLU(g)，能量为 ||d||²<=E。此证明对每一个当前父域成员成立，而非只对原具体网络轨迹成立；所有零值原门的两个合法标签均保留。式 1 蕴含旧 ||t||²<=E，所以交入相同 caps 后包含于 D156/D157。新域仍有原二元非凸语义，不是 CZ、Zonotope 或纯区间的替换。例如m=p=1、C=1时Ct=Cd强制t=d，保留(g,q)读出就得到跨零ReLU的非凸图；二元标签并非仅挂在一个恒凸输出盒上。精度偏序可用具体化集合包含定义，但不声称廉价最佳抽象或完整格。

Affine、Conv、Add、Concat 对共享读出作相同仿射运算；Add 先按原身份合并。下一 ReLU 在整个新父域上认证界及 E 后重复规则。因式 1 蕴含旧能量，已有可靠能量传播可以继续作为保守上界，但未证明其深层精度或成本改善。旧 bank 与其关系不得在递归时静默丢掉。

给定所有旧、新原相位，且父连续切片凸、E 对保留状态仿射时，式 1 是共同 (t,d) 上的凸二次约束与仿射关系；投影仍凸。它不像下文另档的精确源锁那样，仅因固定相位凸化就必然丢掉某个孤立原生修复。但有限多面体仍只是外包，不能据此称其精确。

## 原生消元不是免费线性编译

令 s=Cd，T1=C D_gamma Cᵀ，T0=C(I-D_gamma)Cᵀ，a_star=C D_gamma d。在给定源与整数相位的点上，取 z=t-d/2，式 1 等价于

```text
w_A = a-a_star/2,
w_I = s-a-(s-a_star)/2,
w_A in range(T1), w_I in range(T0),
w_Aᵀ T1† w_A + w_Iᵀ T0† w_I <= E/2-||d||²/4.
```

这是最小范数提升及配平方的直接结果，不是新的伪逆理论。它用于明确共同见证语义；a_star 依赖源和原相位，不能把这个点值检查当作整个输入集合的 LP 编译。给定点的 Gram、range、源读出和可靠算术也要计费。

## 无新增乘积变量的有限线性后果

取查询前按结构固定的 lambda、mu、h，令

```text
v_gamma = D_gamma Cᵀ lambda + (I-D_gamma) Cᵀ mu,
L = (lambda-mu)ᵀa + muᵀCd = v_gammaᵀt.
```

则每个原生成员满足

```text
2L+2hᵀd <= E+||v_gamma+h||²+||h||².             (2)
```

证明：L+hᵀd=(v_gamma+h)ᵀt-hᵀ(t-d)，对这两项使用 2uᵀv<=||u||²+||v||²，并使用同一见证的式 1。原 gamma 整数使右侧展开为

```text
E + sum_i gamma_i (c_iᵀlambda+h_i)²
  + sum_i (1-gamma_i) (c_iᵀmu+h_i)² + ||h||².
```

这里 c_i 是 C 的第 i 列，全部括号系数固定；hᵀd 是完整父状态的仿射读出。因此没有新增 gamma*d、radix bits 或逐门幅值。式 2 对所有真实成员有效，也对它们的凸组合有效；这不把原生 gamma 改为连续变量。

一条确定的研究规则是保留 D157 已有六组坐标方向及其同一个可靠尺度，令 tau_i=1 当 b_i>0，否则为0，仅作固定参考而不固定实际原标签；每个方向同时保留 h=0 的旧行，并增加 h=-v_tau/2 的新行。没有按模型身份、性质、margin、LP 状态或对偶选择方向。参考 tau 不需要实际可达。

## 完整四门控制及后继稳定性

取源 x∈[-1,1]^4，d=x，

```text
b=(1/2,-1/2,1/2,-1/2), g=b+d, E=4,
B=(1,-1,-1,1), C=[B; (1,1,1,1)],
tau=(1,0,1,0), Q=sum_i ReLU(g_i).
```

C 同时保留混权读出 Bq 和 mass Q；本控制声明二者为实际消费者，Q 的下游使用不能遗漏。静读 D157 consumer_fiber.py 第324至326行确认：已有完整 ones 消费行时复用它，所以 p=2、不增加重复mass幅值。但第407至410行仍为每个实际consumer生成两条dominance行，ones的两条恰为0<=0，也仍计费。因此本例 r=2，旧行数32、新44；不能使用仅声明Bq时的30与42。

全部 g 都 crossing，原界为 L=(-1/2,-3/2,-1/2,-3/2)，U=(3/2,1/2,3/2,1/2)。在实际源 x=0、原相位 gamma=tau，旧共同代理可取

```text
t=(4/5,-4/5,4/5,-4/5),
Ct=Cd=0, a=(0,8/5), Cq=(0,13/5),
||t||²=64/25 < 4.
```

active 代理界均为 [-1/2,1]，inactive 代理界均为 [-1,1/2]，此 t 严格位于对应盒内。代理 g 为 (13/10,-13/10,13/10,-13/10)，同一原相位且严格在原界内。所以旧 D156/D157 的完整能量、分支 caps、mass 关系，以及 D170 要求盒与能量共用一份代理的加强都接受该点。实际 g=b 严格非零，真 Cq=(0,1)。这是抽象假点，不是 ADV。

对新关系，active 两坐标和为8/5、inactive 和为-8/5，Cauchy 给任何代理 ||t||²>=64/25。d=0 时新成本至少128/25>4，因此不是仅拒绝了某一个可替代的旧代理。

有限行也能自动拒绝。mass 行 ||C_mass||²=4，已有理想尺度 sqrt(E/4)=1。取 D157 已有的 mass-opposite 方向 lambda=(0,1)、mu=(0,-1)，令 sigma=(1,-1,1,-1)，便有 v_tau=sigma，h=-sigma/2。式 2 变为

```text
4a_mass-2s_mass-sigmaᵀd
  <= 10-2gamma1+2gamma2-2gamma3+2gamma4.          (3)
```

旧假点左侧32/5，右侧6，被排除。这里不仅是固定整数标签的分离。置 z=gamma1-gamma2+gamma3-gamma4，a_mass=Q-z/2，s_mass=sum d_i，式 3 的全部 gamma 项相消：

```text
J = Q-(3d1+d2+3d3+d4)/4 <= 5/2.                (4)
```

所以同一有限线性系统对整个父盒推出 ReLU(J-51/20)=0，预激活上界-1/20。旧共同代理点给 J=13/5，允许真实该后继图上的输出1/20。这是 whole-box 纸面前向分离；没有运行 CERT 或真实网络。作为完整消费者控制，应保留 Bq 的其他使用及 Q 的此使用，不能把这个结论仅归给孤立标量观察。

更一般尺度 t0>0、h=-t0*sigma/2 给

```text
J <= 1/t0+3t0/2+|1-t0|.
```

推导中尚未相消的项是(1-t0)z/2，而z∈[-2,2]。因此某实现若使用向外 sqrt 而非精确1，必须实际认证其尺度。例如1<=t0<=101/100给 J<=1+303/200+1/100=101/40<51/20。这个条件本轮仅为纸面充分条件，未运行平方根或继承任何现有实现资格。

## 强参照与完整代价

更直接的对照已经否决此控制的新能力主张：原 HZ 普通四行 LP 给正偏置门 q_i<=3d_i/4+3/4，负偏置门 q_i<=d_i/4+1/4。四门相加即 J<=2，比新5/2更强。因此连完整单门输入凸包或额外联合能量都不需要，原路径已经证明同一后继稳定。不能把恢复 D156/D170 弱代理损失当作超越旧 HZ。

完整逐坐标 centered perspective 保留 u+v=d；相同信息给出比式 2 更强的行

```text
2L+2hᵀd <= E+sum_i gamma_i(c_iᵀlambda+h_i)²
                  +sum_i(1-gamma_i)(c_iᵀmu+h_i)².
```

它比新行少 ||h||²，本控制给J<=9/4。证明是逐坐标 perspective Young 后求和；精确图上更直接由 L=v_gammaᵀd 得到。故上述控制不是超越该强参照的信息，也不是比精确 HZ 图更精确。候选可能的价值只能是完整较小接口承载这些关系的精度与总费用折中；不能以“一个公式”当作费用证明。

若 D157 的6p旧能量行全保，再加6p源耦合行，新块共2m+16p+2r行，r为声明的 B 行数；原为2m+10p+2r。新行不增加幅值或bits，但每个 hᵀd 要扫描源映射并按共享身份合并，可能填充，保存 k 个稠密 h 可达 O(km)。输出映射、源/历史 bank、证据、可靠舍入、位长、Gram及终端也全部收费。没有总 nnz 或运行时间下降证据。

对于满列秩 C，Ct=Cd 已经强制 t=d，旧原生纤维本来精确；此时新原生关系无严格增益，最多改变有限编译强度。真实 CNN 的宽接口不能假装成低维池化。ViT 的96到48 MLP存在较小形状接口，但还没有完整 token/source 绑定和这条关系的真实收益。

本候选不进入实现或扩张测试。下一项必须在真实完整接口上证明有用的前向关系及完整成本，或找到更强而可付的源相位语义；不能靠 helper、只减变量、人工选择方向或同一玩具的更多测试替代这一证据。
