# 联合非线性关系不能只在均值上绑定共同来源

本轮验证一个会改变研究方向的普通结构反例：D229对实际余项分别取盒，再把局部联合图接回原H，可能比已有D062四平面规则更弱；完整余项、任意固定查询分解乃至当前因子的精确pullback都不能自动修复。此处是松弛精度缺口，不是D229整数具体化不健全。所有原二元因子依旧保留。

这是默认关闭的数学诊断，不实现新求解器、抽象域或模型适配。运行前冻结本合同、预注册、诊断、单测试、入口及collection插件。生产及一切旧源/证据只读。

## 固定普通结构

R(a)=max(0,a)。原输入为四个独立坐标：

```text
x1,x2 in [-1,1], z in [-1/4,1/4], t in [-1/8,1/8],
q1=R(x1), q2=R(x2),
g1=q1+q2/2+z-5/4,       y1=R(g1),
g2=q1/2+q2-z+t-5/4,     y2=R(g2),
F=y1+y2-(q1+q2)/4。
```

完整原H使用同一四维输入frame，父/子四个原ReLU、全部输入与物理读出以及EQ/LE均保留。两个实际余项v1=z、v2=-z+t的线性映射满秩2，父正相位中(f1,f2,g1,g2)对四源满秩4；没有降成同一个源或比例别名。

D229参考采用实际q系数、零f系数、偏置-5/4。于是局部余项盒为[-1/4,1/4]及[-3/8,3/8]。这个盒可靠，但不是实际余项的共同可行像。

## 真界和局部界

使用同一完整前沿(q1,q2,z,t)，F逐点等于以下四个仿射式的最大值：

```text
-(q1+q2)/4,
3*q1/4+q2/4+z-5/4,
q1/4+3*q2/4-z+t-5/4,
5*(q1+q2)/4+t-5/2。
```

各完整盒支持分别为0、0、1/8、1/8；取x1=x2=1,z=0,t=1/8达到F=1/8。因此真上界精确为1/8，这已经由D062的已有规则得到，不需外部oracle。

自然D229查询w=(0,0,-1/4,-1/4,0,0,1,1)的完整R为0。独立余项取v1=1/4、v2=3/8，q1=q2=1时，F=5/8；其余四平面不更高。所以D229应实测返回5/8，明显弱于1/8。这不是数值舍入或极端规模失败。

## 任意固定查询分解仍不能弥补的证明

以下A、B是局部盒内的真实四门图点，各取一半：

```text
A: f1=f2=q1=q2=19/20, v1=v2=9/40,  y1=y2=2/5；
B: f1=f2=q1=q2=1/20,  v1=v2=-9/40, y1=y2=0。
```

A的两个后继g均为2/5，B均为-7/5，父均严格为正；全都不是零点标签技巧。平均点P为f=q=(1/2,1/2)、v=(0,0)、y=(1/5,1/5)，父logical bits为1、子logical bits为1/2，故F(P)=3/20。

原源平均取x1=x2=1/2,z=t=0。两个完整实际单child图分别接受P：child1采用x1=x2=19/20,z=9/40,t=0与x1=x2=1/20,z=-9/40,t=0各半；child2则把两点的z反号。它们有相同源、父输出、父标签均值。单child凸包分别有真实源见证，不代表它们有共同源分布。

对原生编码，根连续取(1/2,1/2,0,0)，父s=1、eta=0、native bits=-1。两个child取native bits=0，g=-1/2,y=1/5；由L1=-3/2,U1=1/2及L2=-13/8,U2=5/8可恢复s、eta并满足全体原EQ/LE及单位界。诊断逐行用Fraction核验，不调用LP。P属于原H的LP查询视图，不属于其整数图，也不是ADV。

D228完备定理保证局部A、B各有共同lambda扩展，凸合后得到P的局部扩展；D229精确回代定理遂给原H_LP与当前Bank并存的扩展。这里使用已通过的定理，不谎称本轮数值构造或求解了完整lambda。

对任意固定八维w，令R_w=F-w·physical，在原H上是完整仿射恒等式。由于P的原因子均处于查询cube内且physical(P)属于局部Bank，

```text
support_B(w)+cube_upper(R_w)
  >= w·physical(P)+R_w(P)
   = F(P)=3/20 > 1/8。
```

所以不仅自然w失败：任意固定w，甚至在此表达式内寻找最优w，也不能追回旧真界；仅安装当前pullback同样不能排除P。这一量词来自上述解析证明，有限方向测试不能替代它。未讨论改变参考参数生成另一Bank的所有可能性，也未测试更强cross-RLT。

若后继真实门为R(F-11/80)，真域输出恒0，而该P仍允许1/80。这个后继后果只作解析推论，不声称已经构造或验证原模型里的该门。

## 问题发生在共同图生成之前

令G为上述独立余项盒上的真实局部图，S为|v1+v2|<=1/8。真实余项必满足S，因为v1+v2=t。A/B的余项和分别为正负9/20，违反S，但它们的均值满足S。因此

```text
conv(G intersect S) strictly contained in conv(G) intersect S。
```

左侧被F<=1/8分离，右侧包含P。单纯追加平均源关系不会把已丢掉的条件关系找回来。这不授权要求每个旧局部顶点都有原输入原子见证；D228已给出那种修补会删真状态的反例。

本例的最小正确对照无需新算法：保持D228原组件，选择原共同坐标(z,t)，两行余项系数为(1,0)、(-1,1)，而非强制(v1,v2)配单位矩阵。源盒现在就是完整原(z,t)盒，因此同一F的支持应为1/8。此对照预注册并与负控在同一测试执行；它仅恢复D062已有强度，不是Neural-HZ新解或新颖性阳性。

对于无live f、参考仅含实际q系数的普通双child，两个child同正号时D062四平面可精确处理完整前沿盒，异号时适用的D068也可精确处理。由此不能推断两负项或全部复杂skip都被D068覆盖；不能给参照免费添一个未实现优化器，也不能把本例推广为整个Neural-HZ不可能。

## 对定义研究的影响与既有研究

应研究带实际共享source map和谓词依据的联合出生/消费，而不是默认“每个残余一个独立盒坐标”。新定义必须说明哪些共同约束在图生成之前被保留、如何在仿射合流和后继激活中被消费，以及是否在同预算下超过强参照。所有原连续/二元因子、共享身份、谓词和decoder仍保留。不能以行秩2就断言源投影是二维矩形；一般高维源的二维像仍有其他关系。

本轮不把该修正包装成新集合类。PRIMA已研究多神经元凸近似，因此“联合多个激活”本身不是新颖性；本轮未采用其算法或求解流程。[PRIMA原论文](https://arxiv.org/abs/2103.03638)

Mao等的论文研究层间及有限跨度凸松弛的不完备性；其v3日期为2025-09-25，§3 Lemma3.2和§4 Theorem4.2说明凸化可能丢失后续非线性需要的信息。它研究的是指定凸查询类，不能直接用来否定保留整数谓词的全部Neural-HZ，也不能据此采用其输入分割补完路径。[论文v3](https://arxiv.org/html/2410.06816v3)

本轮是精确小结构反证和机制对照。真实完整前缀、GPU、smooth/Transformer、任意深度闭包及发表级新颖性仍未获得资格。完整实际端到端代价未测，不能从本例点数或测试时间声称提速。
