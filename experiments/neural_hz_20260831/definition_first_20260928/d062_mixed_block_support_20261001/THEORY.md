# 共同源混权神经块的固定四平面支持

本轮得到一个无需求解器的混权块上界构造，以及一个严格超出全部两门共同源带标签凸包之交的三门解析控制。该关系能进入下一原 ReLU。它来自已知 max 代数和激活下界，仍是抽象变换候选，不是已完成的新非凸域、新凸性理论或真实网络提分。

## 非凸语义和观察接口

令 H 保留原连续因子 xi、全部原二元因子 b、EQ/LE 谓词 P、共同 frame、原读出和输入 decoder。以下 z 是同一个原 frame 上有可靠盒界 D 的物理前沿；它可由更早的非线性层产生，不要求对原输入仿射。所有 g、h、v 必须确为 z 上已绑定的仿射式，q=ReLU(g) 等必须是原网络的门，不创建参考门或替代 bits。

候选观察 O 保存实际原混权读出 F、上下界及共同源构造证书。gamma(H,O) 是满足 H 和全部观察的同一原赋值所产生的输出集合。空观察嵌入原 HZ；下文定理保证新增有效观察不改变其整数具体化、全部零点相位选择和 decoder。保留旧行并加入有效 LE 时，终端 LP 外包不扩大，但额外成本仍可能影响时间预算，不能据此宣称保住所有旧解。

此接口可由既有 D029/D049 关系语言表示。原 HZ 加同样事实与它逻辑等价；接口本身不是定义创新。本轮检验的是构造和组合能力，不是原 HZ 无法表达的集合。

## 固定四平面定理

考虑同一前沿上的实际读出，a、b、d_j 为非负固定数：

```text
F = v + a*ReLU(g1) + b*ReLU(g2) - sum_j d_j*ReLU(h_j)
Hminus = sum_j d_j*h_j.
```

则逐点有

```text
F <= max(v,
         v+a*g1,
         v+b*g2,
         v+a*g1+b*g2-Hminus).                         (1)
```

证明：两个正项之和等于 max(0,a*g1,b*g2,a*g1+b*g2)。令 N=sum d_j*ReLU(h_j)，则 N>=0 且 N>=Hminus。对前三个代数平面使用 N>=0，对最后一个使用 N>=Hminus，再取最大值即得。选择固定为这四种下支撑，不依据当前输入、性质、margin 或求解状态，也不优化乘子。

令 sigma_D(t) 表示仿射 t 在同一完整盒 D 上的支持。将式1中四个平面的支持取最大值，就得到有证标量上界 U(F)。每个支持均在同一个完整盒上计算，没有限制原相位、求解相位子域、构造搜索树或运行四个网络。这与 D029 已有的固定两正项四平面恒等式采用相同的代数范围，不推广为 k 门指数枚举。

**不能**通过引入自由变量 t、约束 t>=四个平面并添加 F<=t，声称已编码 F<=max。这只给 t 的下界，不能提供所需上界。当前合法终端输出是 F<=U(F)，或另行证明的仿射上界；不引入这种虚假的 epigraph 编码。

## 任意实际 fan in 的统一规则

按已绑定的原 slot 顺序把正权重项相邻配成组，尾项单独成组，G=ceil(n_positive/2)。每组分配 v/G 和全部负权重 d_j/G；原门及其身份不复制，常数和负贡献在全部组中恰好计一次。每个双项组应用式1，其标量界相加得到整个读出的上界。

单项组使用两个平面 max(v/G, v/G+a*g-Hminus/G)，不添加零 dummy。若没有正项，直接用 F<=v，再取 sigma_D(v)。若没有负项，Hminus=0。系数正负、组大小和是否有负项只是数学结构条件，不是多个运行路径取最好成绩。

下界对 -F 执行完全相同构造。保持同一前沿意味着共同系数必须先合并，再取支持；不能把每个门先变成独立幅度区间。跨组相加仍可能损失关系，因而不声称该规则在任意 fan in 上精确或优于所有已有界。

## 全部两门联合凸包仍不够的控制

取 x、y、z 属于 [-1,1]，c=1/10，三个原门和各自原 bits 都保留：

```text
g1=x+y+c,       q1=ReLU(g1)
g2=y+z+c,       q2=ReLU(g2)
h =x+z+c,       p =ReLU(h)
F=q1+q2-p-y.
```

三个梯度线性无关；它们不是同一个滤波器、比例别名或共零门。式1在本例给出

```text
F <= max(-y, x+c, z+c, y+c) <= 11/10.                (2)
```

比较系统 Q 是三个完整两门带原相位凸包的交。每一个凸包保留全部 x、y、z 共同源坐标及该对原输出、原 bits，其他门的坐标作为未约束的外接坐标。Q 不仅是逐门 big M，也不仅是此前固定成对生成器。

考虑松弛点

```text
x=y=z=0, q1=q2=17/20, p=1/8
alpha1=alpha2=beta=1/2.
```

每个完整两门凸包都含这个点，以下均为两个真实源点的各半凸组合：

| 两门 | 正源点 u | 另一源点 | 相关门正负预激活 |
| --- | --- | --- | --- |
| q1 与 q2 | (4/5,4/5,4/5) | -u | 两门均为 17/10 与 -3/2 |
| q1 与 p | (4/5,4/5,-13/20) | -u | q1 为 17/10 与 -3/2；p 为 1/4 与 -1/20 |
| q2 与 p | (-13/20,4/5,4/5) | -u | q2 为 17/10 与 -3/2；p 为 1/4 与 -1/20 |

各对的源均值都是零，输出均值和原 bit 均值完全一致。所有源分量严格位于盒内部，涉及的预激活严格非零。每对分别存在自己的共同源分布，不意味着三门存在同一个分布；这正是 Q 的限制。

假点 F=63/40，违反式2的间隙为 19/40。因此新行确实不被全部这三个完整 pair hull 的交蕴含。新增行 F<=11/10 内联后为四个物理坐标非零项，没有新 bit 或辅助连续量。这是解析松弛分离，不是具体 ADV、运行过的 CERT 或完整全网比较。

这不是依赖精确系数恒等式的孤立例子：每个两门系数矩阵均有行秩2，上述源点和符号有严格余量。对充分小的系数及偏置扰动，可通过该矩阵的连续右逆调整每对的对称源点，保留相同输出与 bit 均值。四个盒支持也随参数连续，19/40 的严格间隙仍可保持。因此存在普通开参数邻域；这是存在性论证，没有数值搜索或扰动实验。

## 信息进入下一原激活

增加原网络实际门 r=ReLU(F-1/2)，保留它的原相位 gamma 和所有原门行。式2直接推出

```text
r <= 3/5.
```

旧 Q 中的假点可令 r=43/40、gamma=1，满足这个后继门的精确图。因此原性质 r<=7/10 被新界证明，却被“Q 再接原子门精确图”的比较系统允许违反。旧点当然不属于原三门真实联合集合，不把它误报为网络反例。

后继并非稳定门：原源 (0,0,0) 上 F=1/10，后继预激活 -2/5；原源 (4/5,4/5,4/5) 上 F=9/10，后继预激活 2/5。两源都严格内部。一般地，对原门 r=ReLU(V) 及其实际预激活界 L<=V<=U，保留原非凸编码，同时使用 max(0,L)<=r<=max(0,U)；这是健全但可能有损的前向变换。本例 V=F-1/2，必须先把偏置计入 V 的界。

同源 Affine/Conv 或 Add/Concat 仍须保持真实读出身份与全部消费者。多个标量观察按混合系数组合可能再次丢失依赖，不能将本例的一步传递外推为固定宽度的任意深度无损闭包。

## 与旧构造和已知数学的区别

在同一三门控制及同一盒上，D029 的共同负半斜率四平面支持为 39/20、21/20、21/20、43/20，得到 F<=43/20。D061 的 equal-share 残余合并给 F<=(1/40)y+41/20，标量界83/40。二者都允许本次假点，新固定规则给11/10。这不是对任意残余分配、完整多门 hull 或所有旧候选的全面优越性证明。

本规则逐代数平面使用不同、但预先固定的已知负项下支撑。D029 的[LIMITS](../d029_conditional_observations_20260930/LIMITS.md)已指出共同 theta 的局限；本轮不重新声称发现了这个问题。max 加法代数本身也已有热带神经表示背景，参见 [Zhang 等2018](https://proceedings.mlr.press/v80/zhang18i/zhang18i.pdf) Propositions 5.1与5.6；不采用全网热带规范化或输入细分。

更直接地，D029 的一般条件观察也能推出式2：取 q=q1、v'=q2-p-y，可认证 U(v')=11/10 和 B(g1+v')=11/10，于是其原相位上侧行正是 F<=11/10。这两个前提的廉价证书如下：

```text
q2-p-y <= ReLU(y-x)-y = max(-y,-x) <= 1
g1+q2-p-y = max(x+c-p, x+y+z+2c-p)
           <= max(x+c,y+c) <= 11/10.
```

第一行用 ReLU 次可加残余关系，取更宽 U=11/10 仍有效；第二行用 p>=0、p>=h。因此固定四平面算法不是超出 D029 观察语言的新逻辑，而是避免免费支持 oracle 的显式构造。它跨越的是仅保留两门凸包的组合，而不是所有一般条件观察。

## 完整构造成本与设备边界

令 k 为全部原门项数，Spos/Sneg 为对应预激活仿射式的实际系数出现数，s_v 为 v 的支持大小，d 为共同源并集大小。先认证身份、遍历全部门、构造 Hminus，不能只支付被选正项的成本。

直接逐组重建稠密底式会需要 O(k+Spos+Sneg+G*d) 算术。可以避免该重复：D=m+[-r,r] 时缓存两个共同底式 B0=v/G、B1=(v-Hminus)/G 及其支持。对稀疏增量 t，有精确恒等式

```text
sigma_D(B+t) = sigma_D(B) + t(m)
  + sum_{j in support(t)} (abs(B_j+t_j)-abs(B_j))*r_j.
```

这里 t(m) 包含 t 的常数项。每组分别对 B0 加单个正项、对 B1 加两个正项，先在支持并集内合并重复源。因每个正项只进入一个组且被使用常数次，已规范化并可常数时间查底式系数时，上下双向构造的精确标量工作为 O(k+Spos+Sneg+s_v)。稀疏规范化、索引、系数位复杂度、证据写入和身份验证另计，不把精确数当作固定成本硬件操作。

可按组流式处理，两个底式及稀疏增量暂存 O(d)，组级证据 O(G)，原读出行及门引用 O(k+s_v)。这些是新增工作区，不包含且不替代全部原 HZ、源形式和冻结证据；保存每个展开平面会重新引入 G*d 存储。终端上下两行每行物理支持至多 k+s_v，不新建 F 时须支付其原读出展开；等式后端的 slack、原矩阵、RHS、界和输入 decoder 均另计。

缓存的稀疏 gather、绝对值修正与 segmented reduction 适合设计 GPU kernel，但目前没有设备实现、向外舍入认证、传输或并发测量。特别是上式包含差分相消，不能直接将浮点结果当作可靠上界。未来测试、资源和完整物理存储要求保持不变，不由这条算术界宣布加速。

## 非点参数与真实模型

对区间参数可沿用 D029 的带误差参考构造，而不是把中点模型替换为原模型。设参考中点预激活 gbar_i，|g_i-gbar_i|<=epsilon_i；权重中点 wbar_i、半径 rho_i，M_i 可靠包住实际 ReLU(g_i)，|v-vbar|<=epsilon_v。则

```text
E = epsilon_v + sum_i (rho_i*M_i + abs(wbar_i)*epsilon_i)
|F-Fbar| <= E.
```

用参考式计算四平面上下界后分别扩大 E 即健全；参考激活只用于证明误差，不获得或替换任何原 bit。系数区间跨零也由该误差覆盖。所得界必须绑定实际原接收读出，不能把其左侧不确定系数私自写成中点。BN、bias、padding、原读出映射与可靠参数来源仍需独立认证。

本节是数学规格，不是区间算术组件已实现。当前没有默认启用、真实网络运行或数值资格。下一步若实现，须新预注册并继承全部原测试人口和资源条件，不能借纸面正控跳过真实同结构、shadow、逐家族与完整回放。
