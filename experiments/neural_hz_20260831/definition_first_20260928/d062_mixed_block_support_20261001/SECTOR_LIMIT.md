# 增量关系线性化的精确边界

上一轮跨领域核查发现：经典 ReLU 增量二次关系拒绝 D061 的某个假点。本轮进一步证明，这不意味着将它线性化就有新收益。若接口只保留预激活差、输出差和原两位相位，而没有实际共同源约束，其精确凸包已经是旧四行差分关系。

以下仅为纸面证明。数学证明中的切片和凸组合不授权实现相位分裂、采样、LP、SDP或新求解路径。

## 不带相位的差值凸包

设 L<0<U，S={(delta,d):L<=delta<=U，d*(delta-d)>=0}。它是负侧和正侧两个三角形之并，其凸包由四点 (L,L)、(L,0)、(U,0)、(U,U) 张成，即

```text
L <= delta <= U
L*(U-delta)/(U-L) <= d <= U*(delta-L)/(U-L).
```

所有四点都在 S 中，每个三角形都被上述四边形包含，故两向包含立即成立。二次关系来自标准重复非线性约束，见 [Fazlyab 等](https://arxiv.org/pdf/1903.01287) §III-C、式15；不作新颖性主张。

对 D061 的 g1/h1 对，L=-13/20、U=17/20、delta=39/400、d=7/20。凸包允许的 d 区间为 [-3913/12000,5083/12000]，包含 d=4200/12000。原二次式取值 -707/8000<0，但它的线性凸化没有排除该点。

## 保留原相位的精确凸包

考虑真实双门 q=ReLU(g)、p=ReLU(h)，原 bits alpha、beta 采用非严格零点守卫。投影只保留 delta=g-h、d=q-p、alpha、beta，且只限制 L<=delta<=U。此定理不加入实际 g/h 的额外界或共同源仿射约束。

令 e=d-delta。该投影的凸包恰为 Q：

```text
L <= d-e <= U, 0<=alpha,beta<=1
L*beta <= d <= U*alpha
-U*(1-beta) <= e <= -L*(1-alpha).                 (Q)
```

必要性是既有相位差分关系。充分性可证明 Q 的全部极点具有整数 bits，再构造每个整数切片的原门见证。

记 a=-L>0、b=U>0，Q 有界且满维；取 alpha=beta=1/2、d=e=0 即严格内点。四条 d/e 边界分别为

```text
C1: d=b*alpha       C2: d=-a*beta
C3: e=a*(1-alpha)   C4: e=-b*(1-beta).
```

若 alpha、beta 均严格在零和一之间，极点需要四个独立紧约束。delta 的上下界至多一个紧，因而 C1至C4 至少三个紧。其中必有 C1/C2 或 C3/C4 同时紧；前者强制两 bits 都为零，后者强制两 bits 都为一，矛盾。

若 beta=0、alpha 严格分数，则除 bit 边界外，极点至少需要两个 C 加一个 delta 边界，或三个 C。C1/C2、C3/C4 不可能同时成立，任意三个 C 因而也不可能。其余组合：C1/C3 给 delta=(a+b)*alpha-a 严格内部；C1/C4 给 delta=b*(alpha+1)>b，不可行；C2/C3 给 delta=-a*(1-alpha) 严格内部；C2/C4 虽给 delta=b，但该边界依赖 C2/C4，alpha 保留可扰动方向。因此不是极点。

beta=1 时相同检查：C1/C3 和 C1/C4 给严格内部 delta；C2/C3 给 delta=-a*(2-alpha)<-a，不可行；C2/C4 给 delta=-a，但该边界依赖且 alpha 自由。若 alpha 固定而 beta 分数，应用 (d,e,alpha,beta,a,b) 变换为 (-d,-e,beta,alpha,b,a)，归到刚才情形。故所有极点的 bits 为整数。

四个整数切片均能恢复原门：

| alpha beta | 切片 | 一组原门见证 |
| --- | --- | --- |
| 0 0 | d=0，delta任取[L,U] | g=min(delta,0)-1，h=-max(delta,0)-1 |
| 1 1 | e=0，d=delta | g=max(delta,0)+1，h=max(-delta,0)+1 |
| 1 0 | 0<=d<=delta<=U | g=d，h=e |
| 0 1 | L<=delta<=d<=0 | g=-e，h=-d |

再令 q=ReLU(g)、p=ReLU(h)，就有要求的 d、delta 和原 bits。在混合相位切片的零角点，g=h=0，原两种相位选择必须保留。因此 Q 的全部极点都属于原图投影，证明精确凸包等式。

结论只适用于这个信息接口。与实际共同源条件或单门幅度条件相交后，不能从“先投影再相交”推断已得到完整真实凸包；实际网络仍可能有新的有效行。

## D061 假点缺少的是实际共同源

D061 这对门的均值也可以直接由下列两个真实双门点各半混合得到：

```text
(g,h,q,p,alpha,beta)=(7/10,-2/25,7/10,0,1,0)
(g,h,q,p,alpha,beta)=(-121/200,-1/50,0,0,0,0).
```

两点差值39/50、-117/200均在原 L/U 内，相关非零预激活有正确符号，均值恰为 (19/400,-1/20,7/20,0,1/2,0)。但恢复实际 h=x、g=13x/20-2y/5+1/10 时，两点分别需要 y=-163/100、173/100，超出原盒。因此它们不是实际共同源的联合门见证。

反之，实际共同源给出全域有效行

```text
q-(13/20)*p <= (1/2)*alpha.
```

证明：x<=p、y>=-1 给出 g-(13/20)*p<=1/2；alpha=1 时 q=g，alpha=0 时 q=0且p>=0。原零点的两种 bits 都合法。假点违反该行1/10，故不属于这对门的完整实际共同源凸包。

这正是 [D049一般残余关系](../d049_mixed_source_envelopes_20260930/ALTERNATIVES.md)，亦可取 D029 的 v=-(13/20)p、L_v=-13/20、U_v=0、B=1/2 得到。不是新的关断面、消元定理或新域。

因此关闭“只把双门 sector 重新线性化就会新增强度”的直接路线。D061 对文中列明固定生成器的结论仍有效，不改旧档案；新研究必须明确使用实际共同源、更多门或跨层关系，而非对同一四坐标接口继续堆有效线性行。
