# Neural HZ 共享源关系的定义缺口与下一项检验

用户再次要求以提出强大的 Neural-HZ 为重点。本轮把一个看似接口问题的现象归结为明确的数学缺口：共享依赖虽然保存在精确等式中，当前关系生成规则却可能完全用不上它。研究应解决这一域内问题，不继续扩大加载器、来源诊断或 helper 工作。

本轮结果是纸面负结论与下一项可反证问题，不是实现通过或新增解。Goal 保持 active，目标和全部原限制不变。

## 当前候选究竟增强了什么

[共同松弛量候选](../d205_common_deficit_rule_20261005/THEORY.md) 已给出普通输入盒上的严格数学分离：分别保存完整的带源单门凸包，再加入完整的无源双门输出及相位凸包，仍会丢失源与联合相位的关系；候选有效行能排除其中一个伪点，并证明一个后继 ReLU 恒为零。

这不表示精确整数 HZ 的表达能力被超越。加入这些有效行后，原整数具体化不变；完整的带源联合凸包也蕴含它们。旧 HZ 加同样信息必须保留为同信息参照。尚未证明的是一套具有创新性、能在普通真实网络上以可承受费用生成并消费这些关系的 Neural-HZ 定义与组合演算。

## 精确别名会使当前盒规则失去共同关系

以下是纸面推导，没有运行代码。沿用前轮普通正控，令 x、y 属于 [-1,1]，两门共享同一父赋值：

```text
f1=x+3y+1/4,
f2=3x+4y+1/4,
r1=f1-f2/2, r2=f2-f1/2.
```

在原共享坐标上，r1=-x/2+y+1/8，r2=5x/2+5y/2+1/8；精确盒上界分别为 13/8、41/8。共同松弛量规则生成非恒定 s=(3+y)/4，能够支持前轮的源相位证书。

现在仅添加两个连续别名及精确等式，不删除原源、原相位、谓词或 decoder：

```text
eta1=(x+3y)/4, eta2=(3x+4y)/7,
4eta1=x+3y, 7eta2=3x+4y,
f1=4eta1+1/4, f2=7eta2+1/4.
```

eta1、eta2 属于 [-1,1] 的界由原盒蕴含。因此扩展表示投影回原坐标后与原状态完全相同。但若关系生成只读取两个别名的自由盒，不使用定义等式，则

```text
r1=4eta1-(7/2)eta2+1/8,  cap1=61/8,
r2=-2eta1+7eta2+1/8,    cap2=73/8.
```

两个坐标的系数均异号，没有公共同号项。按候选公式必得 omega0=0、s=1。完整状态仍然精确；变弱的是忽略定义等式的盒证书，不是健全性。这也不否定原候选的盒定理。

只读检查原生构造源码得到同一风险：[c31_prepared_emission_v1.py](../../c31_prepared_emission_v1.py) 为各输出分配不同连续根槽，读出是 bias 加正尺度乘根槽，二元读出为零，共享来源则进入定义等式。对这类两个不同根槽，固定正耦合系数产生上述同样的相反符号模式。该结论来自构造形态，不是本轮已恢复并认证了 checkpoint 的数值结果。

## 下一项工作直接检验本体

下一项研究比较同一普通结构的两个版本：直接共享父读出，以及插入上述精确连续别名。Neural-HZ 自身应能通过已知生产者定义关系保留并消费同一源相位证书，得到前轮同一个后继 ReLU 结论，同时计入全部读取、展开、关系传播和查询费用。

这项局部检验不要求任意语法或任意基变换不变性，也不授权通用等式消元求解器。不能把重新取回父表达式本身称为创新；真正待证明的是关系块与算子能否组合地、有效地增强后续验证。一个父指针、新容器、外接 helper 或追加有效行都不足以单独完成该目标。

通过局部检验之后，仍须在完整真实同结构人口上检验实际适用性及代价，再按既定 shadow、家族和全量回放流程晋级。若只在手工正控中有用，或最终优势完全来自另一个辅助算法，就记录失败并调整数学假设，不以支撑工程替代本体结果。
