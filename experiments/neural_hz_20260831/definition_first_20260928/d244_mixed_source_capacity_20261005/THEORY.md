# 共同源残差的混合相位容量

本轮提出一个统一的有限关系：同时消费父 ReLU 的预激活与输出，而不在 X 与 Q 两条规则间择优。一个普通混权 residual 声明图上的完整物理分离证明成立；同一反例点通过 D240 两种旧合同的全部可通过守卫的 tau，并属于既有两个强凸化参照。新增关系则证明一个可达的严格更小输出上界。

这些是精确纸面证明和独立审阅，不是已执行组件、原模型实验或新的 CERT。源行空间恢复、McCormick 与 RLT 均非新发明；这里新增的项目证据是混合容量合同及其明确分离。非凸 HZ 的整数集合仍保留，不宣称新的集合表达力或完整 Neural-HZ 已完成。

## 原非凸状态和混合读出

H 保留全部连续源、原 signed binary 因子、EQ/LE、共享身份、原消费者及输入 decoder。两父门经零点保持正比例归一化为 x_i in [-1,1]、q_i=ReLU(x_i)，alpha_i 为原相位的 0/1 视图。保留原四行 labelled ReLU 图，包括 x_i=0 的两个原标签。记 p_i=alpha_i-q_i>=0，n_i=1-alpha_i-q_i+x_i>=0。

两个实际子门为 Y1=ReLU(g1)、Y2=ReLU(g2)，同 H 的完整读出为

```text
z=(g1+g2)/2=a1*x1+a2*x2+b1*q1+b2*q2+r,
d=(g1-g2)/2=tau*(q1-q2)+e, tau>0.
```

r 和 e 是完整共同源读出，不是新的自由输入盒。可靠界 Lr<=r<=Ur、Le<=e<=Ue 必须在整个 H 上成立，保留全部偏置、skip、其余幅值、模型误差和源谓词。数学定理允许任意经认证的正 tau；拟议确定性实现仍从原 d 的 q 系数 A、B 取 tau=(A-B)/2，不在失败后另选参数。

## 一条相位条件容量公式

定义

```text
L10=min(0,a1+b1)-max(0,a2),
U10=max(0,a1+b1)-min(0,a2),
L01=-max(0,a1)+min(0,a2+b2),
U01=-min(0,a1)+max(0,a2+b2),
Lmix=Lr+min(L10,L01),
Umix=Ur+max(U10,U01).
```

固定合同要求 [Lmix,Umix] subset [-tau,tau]。这是四个系数上的有限公式，没有建立子域、枚举网络相位、调用 LP、沿终端方向反推或分裂输入。

证明只用于论证公式：相位为 10 时，q1=x1、q2=0，且 x1 in [0,1]、x2 in [-1,0]，所以 z-r=(a1+b1)x1+a2*x2；其矩形界正是 L10/U10。相位为 01 时对称得到 L01/U01。闭符号范围保留零点的两个合法标签。相位相同不需要 z 的额外限制。因此 h=alpha1-alpha2 满足

```text
h*(clip(z+tau,0,2*tau)-z-tau)=0.
```

它只线性化共同差消费；不能把每项 alpha_i*clip 单独替换。b1=b2=0 恢复原 X 判据，a1=a2=0 恢复 Q 判据；新合同总是计算同一个混合式，不是旧规则失败后的 fallback。

## 有限关系和原整数投影

追加六个连续观察，但不新增或删除原相位：

```text
c12=alpha1*x2, c21=alpha2*x1,
d12=alpha1*q2, d21=alpha2*q1,
v1=alpha1*r,  v2=alpha2*r.
```

对每个 w=alpha*s、L<=s<=U，登记全部四条 McCormick 行：L*alpha<=w<=U*alpha，s-U*(1-alpha)<=w<=s-L*(1-alpha)。x 用 [-1,1]，q 用 [0,1]，r 用完整 [Lr,Ur]。所有 source 表达式代回同一个 H。

定义共同读出

```text
K=tau*(alpha1-alpha2)
  +a1*(q1-c21)+a2*(c12-q2)
  +b1*(q1-d21)+b2*(d12-q2)+v1-v2.
```

原整数语义下 K=h*(z+tau)。沿用 D239 的单调 2-Lipschitz 差函数论证，登记

```text
Y1-Y2-K <= 2*tau*p2+2*max(Ue,0),
-Y1+Y2+K <= 2*tau*p1-2*min(Le,0).
```

同时统一保留原三条 X 容量。令

```text
T=q1-q2+c12-c21,
U=q1+q2-c12-c21,
D=2*q1-x1+2*q2-x2.
```

则 T<=p2+n2、-T<=p1+n1、U<=D。没有根据输出查询选择容量行。

对任意原整数 H 点，取这六个真实产品便得到唯一扩展；完整 MC、混合守卫证明、defect 与源容量均成立。反向投影保留原 H 的所有谓词，因此整数投影恰等于 H。原 decoder 读取同一原坐标。分数相位只用于比较有限终端松弛，不代表将域换成凸域，也不是 ADV。

Affine、Conv、Add 和 Concat 可以线性消费已注册读出，但下一 ReLU 必须重新证明其完整父状态合同。没有固定宽度、任意深层无损闭包或免费全网关系调度定理。

## 不依赖预激活直边的共同源提取

D243 的语法展开无法恢复一般 skip 与父预激活之间的 EQ 关联。拟议改进使用同一前沿坐标 u 上已经证明的完整仿射形式：x_i=k_i+w_i*u，z=b1*q1+b2*q2+c+v*u。边界保留所有其他 ReLU 输出、输入、误差和原位；不能将它们当作独立可重采样的真实输入。

一种确定性、无优化器的提取是对两条 w 的加权 Gram 解二乘二线性系统。令 R_j 为每个共同源坐标的可靠半径，

```text
G_ij=sum_k w_i[k]*w_j[k]*R_k^2,
h_i=sum_k w_i[k]*v[k]*R_k^2,
(a1,a2)^T=G^(-1)h,
r=(c+v*u)-a1*(k1+w1*u)-a2*(k2+w2*u).
```

行列式必须精确证明非零，全部常数和余项保留；秩不满足即该合同未取得资格，不选其他方法救援。这里仅给待实现的固定提取选择；尚未证明其完整资源账或实际模型适用率。它不保证最优 L1 残差界，不保证对任意源基变换不变，也不允许忽略系数不确定性。若原来源含 BN 误差，该误差须作为同一 u 的真实 carrier 保留。

这是共同源 EQ 的局部代数改写，不求解 property、不反传界、也不读取 LP 状态。D160 等旧档已有源子空间/正交投影，不能把 Gram 本身重记为创新。拟议价值必须来自它随后启用的混合容量及物理读出，而不是矩阵压缩。

## 普通 residual 控制及精确新上界

取原源 A in [0,1]^4、t in [-1,1]，声明

```text
x1=A1-A2, x2=A3-A4, qi=ReLU(xi),
z=(4/5)*(A1-A2+A3-A4)+(3/50)*(q1+q2)+t/10,
g1=z+q1-q2, g2=z-q1+q2, Yi=ReLU(gi).
```

这是非恒等父仿射变换及投影 shortcut 的残差形式：主路在 q 上混权，shortcut 直接读取 A。父 x 节点仅被其 ReLU 消费；z 及下列 F 都用 A 的差构造，不人为添加 x 到子节点的直边。共同源商得到 a1=a2=4/5、b1=b2=3/50、r=t/10、tau=1、e=0。

混合判据为 [-9/10,24/25]，严格落在 [-1,1]。旧纯 X 在相同 tau 下得到 [-9/10,51/50]；纯 Q 得到 [-17/10,44/25]，均失败。但 D240 允许事前选择其他正 tau，不能据此宣布旧合同没有路径；下一节比较其全部合格参数。

声明实际物理读出

```text
F=D+(2/5)*(Y1-Y2-(x1-x2)/2).
```

在实际图中，将 x1/x2 代为 A 的差写入 F 的 EQ。令 V=q1-q2+d12-d21、s_i=alpha_i*t。K=h+(4/5)T+(3/50)V+(s1-s2)/10。已有 MC 给 V<=1：d12<=q2、d21>=0、q1<=1 即可；无需偷加 V 行。t 的两套完整共享 MC 给 s1-s2<=1。对 defect 上行、T 容量和这些行作非负组合，得到

```text
F <= 258/125
     -(4/5)*p1-(6/5)*n1-(2/25)*p2-(12/25)*n2
  <= 258/125.
```

真实 A=(1,0,0,1)、t=1 时，x=(1,-1)、q=(1,0)、z=4/25、Y=(29/25,0)，F=258/125。因此上界可达，不是仅一个松的估计。比如实际后继 ReLU(F-413/200) 可据此证明恒为零；这只是声明图的解析结论，不是已执行原网络 CERT。

更一般地，对 a>=0、b>=0、epsilon>=0 和 0<=lambda<=1/(3/2+a)，固定tau=1、e=0时，同一证明给

```text
z=a*(x1+x2)+b*(q1+q2)+epsilon*t,
F_lambda=D+lambda*(Y1-Y2-(x1-x2)/2),
F_lambda <= 2+lambda*(b+epsilon)
 -(1-lambda/2)*p1-(1+lambda/2)*n1
 -(1-lambda*(3/2+a))*p2-(1-lambda*(1/2+a))*n2.
```

还须满足混合守卫。取 a+b+epsilon<1<a+2*b+epsilon 时，得到混合判据通过而同 tau 纯 X 失败的普通参数族，不依赖某个极端浮点值。构造族的两个 a 和两个 b 仍有对称结构；通用公式允许不同系数，但本节不冒称随机卷积必然命中。

## 完整强参照的共同物理见证

固定 u=199/200。比较点为

```text
A=(1/2,1/2,1/2,1/2), t=0, x1=x2=0,
alpha1=alpha2=1/2, q1=q2=u/2,
(Y1,Y2)=u*(397/500,297/500),
gamma1=gamma2=1/2.
```

其 F=(52/25)u=2587/1250，比新有效界258/125高7/1250。因此新有限行排除该原物理点的全部辅助扩展；不是只否定一组产品猜测。后继图在该点允许 ReLU(F-413/200)=23/5000。

两个完整、带全部源与标签的单子门前缀凸包均接受该点。取四个真实父角 (x1,x2)=(±u,±u)、t=0，对角各质量 delta，非对角各质量1/2-delta。对应一个子输出均值为

```text
Y/u=53/100+(33/50)*delta.
```

第一子前缀取 delta1=2/5，第二取 delta2=16/165；两者父源、q、alpha 及各自子标签均值相同，分别给397/500、297/500。四角通过 A=((1+x1)/2,(1-x1)/2,(1+x2)/2,(1-x2)/2) 运回完整原源，所有 A 端点在 [1/400,399/400] 内。这里不是把两个前缀的分解拼成真实共同网络见证；恰恰是强参照允许各自分解。

另一参照先完整凸化父图 P，再同时接两个实际子门真图并取带标签凸包。定义 A组两原子 alpha=(1,1/2)、(0,1/2)，各半，x=u*(2*alpha-1)、q=u*alpha、t=0。它们在 P 内，但第二父门的分数点不冒称原整数图点。两原子的子输出分别为 u*(139/100,39/100) 与(0,0)，A组均值为u*(139/200,39/200)。C组用真实 alpha=(0,0)、(1,1) 各半，均值u*(43/50,43/50)。A、C 以2/5、3/5混合即得到显示点，包括全部原源均值及两个子相位均值1/2。所有这些子预激活均严格非零。

原 A 源的仿射运输保持完整前缀及凸化父参照，不删除 skip 消费者。此比较不包含完整原源四门联合 hull、任意额外共同条件矩或完整跨层 RLT。

## 排除旧 X 和 Q 调大 tau 的漏洞

旧参照采用 D240 实际合同：其 attach 接受事前固定的任意正 tau，不等同于 D243 从 d 导出的固定值。以下给同一物理点的辅助扩展，覆盖每个合同中全部可通过静态守卫的 tau。源与误差界均按旧合同的完整表达式范围，不省略 e。

纯 X 有 rX=(3/50)*(q1+q2)+t/10，范围[-1/10,11/50]，因此只能在 tau>=51/50 时通过 guard。e=(1-tau)*(q1-q2)，可靠界为[-(tau-1),tau-1]。在显示点 rX=597/10000，取

```text
c12=c21=0,
v1=1039/10000, v2=-1/20.
```

每个 v 的 MC 可行区间均为[-1/20,1097/10000]，三条 X 容量也成立。h=T=0，旧 K=1539/10000。显示点的 Y1-Y2=199/1000，所以其上侧差为451/10000。tau=51/50 时的完整允许量正好为

```text
2*tau*p2+2*(tau-1)=451/10000, p1=p2=1/400.
```

该允许量随 tau 单调增加，K 不变；下侧也成立。因此同一组辅助数值通过所有 tau>=51/50。不是只比较一个随意挑选的弱参数。

纯 Q 有 rQ=(4/5)*(x1+x2)+t/10，范围[-17/10,17/10]，故 tau>=44/25 才通过守卫。在显示点 rQ=0，取其两 cross-q 产品均199/800，两个 alpha*rQ 产品均0。旧 K=0，所有 MC 成立。最小 tau 下的 defect 支付为1911/1250=1.5288，大于199/1000；随 tau 增加而增加。因此全部合格纯 Q 参数同样接受显示点。

这些结论限定于两种旧合同的实际 MC／容量关系。若另行登记 alpha*rX=(3/50)*(alpha*q1+alpha*q2)+(1/10)*alpha*t 等跨残差分解一致性，就已经增加了本比较未包含的信息，不能声称上述扩展仍成立。混合规则的关键正是将这些不同来源项放在同一个消费中，不是给乘积变量换名称。

## 完整局部账和下一实施门

六套 MC 共24 LE；两个 defect 和三个源容量给总29 LE。原 x、q、Y、r 为单列，系数非零且 r 界跨零时，MC为56 nnz、defect为24 nnz、容量为16 nnz，共96 nnz。六产品的显式上下界另12 LE、12 nnz，因此终端增量是6连续列、41 LE、108 nnz，不新增位。本例r=t/10也得到同一计数。

若 r 内联为s个非零项，关系nnz上界为92+4s；一般x/q/Y又是多项读出时还须支付其实际展开。原H、全部源EQ、范围构造、Gram/常数项、候选对枚举、反复消费、共同存储、终端materialization、见证和CPU/GPU共存全部另计。没有整体性能资格，也没有宣称该方法解决了D243逐tap算术的规模障碍。

下一实现应固定一条 same-H 源提取和 mixed 关系，不增加X/Q/soft-tail菜单；默认关闭。实施前须新预注册、新源冻结，继承D243的完整4189/223数学人口及全部旧writer隔离，再验证新定理、上述强参照、所有合格旧tau的解析证书、原位/输入重构、完整来源/预算拒绝。随后仍是固定三个完整真实模型、shadow、13家族、2413和独立400及四并发门。本文没有运行这些阶段，也不以论文证明代替任何门。

## 先例和贡献边界

Sharp Hybrid Zonotopes 已将RLT用于保留原二元因子的HZ，不能把条件连续产品本身当新域。[原文](https://arxiv.org/html/2503.17483v2) k-ReLU 已利用给定前沿关系联合多个神经元，不能只靠强于独立三角形主张新颖性。[原文](https://proceedings.neurips.cc/paper/2019/file/0a9fdbb17feb6ccb7ec405cfb85222c4-Paper.pdf) DeepSDP 已使用互补与跨层重复非线性关系；本项目不移植其SDP求解器，也不把跨层二字当创新。[原文](https://arxiv.org/html/1903.01287v3)

本轮实际可支持的表述是：在原非凸HZ内，一条统一mixed源相位规则具有严格物理分离，超过指定旧X/Q合同全部合格tau，并适配没有父预激活直边的普通声明残差图。可扩展组合、新颖性、原模型命中、GPU及正式收益仍未证明。
