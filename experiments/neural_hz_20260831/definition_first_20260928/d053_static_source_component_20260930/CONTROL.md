# 共同源生成器的固定数学对照

沿用冻结 D052 的不等幅混权控制，不按新数值结果更换对照。全部坐标和假点是单元测试的解析 fixture，不是运行时采样、攻击或 benchmark 见证。

在 s,t in [0,1] 上取原门

```text
f=s+t-9/10, q=ReLU(f), alpha,
g=(11/10)s-(9/10)t+1/10, p=ReLU(g), beta.
```

统一匹配必须产生 P=s、N=9t/10、kappa0=1/10、kappa1=1/5、U=1/5。F=q+p-s 的完整两行是 F<=alpha/5+beta/5 与 F<=alpha/10+3beta/10。

旧松弛点 s=t=alpha=beta=1/2、q=2/5、p=81/200，分别由 q 的 source 点 (17/20,17/20)、(3/20,3/20) 和 p 的 source 点 (17/20,1/4)、(3/20,3/4) 各半混合得到。所有分量在盒内部，相关 preactivation 符号严格。它通过两个完整独立 source labelled 单门 hull、D020 四行和冻结 D049 的明确有限包络，不能声称通过全部可能的派生观察或联合网络 hull。

实际物理读出

```text
Z=F+(2/9)(q-f)+(1/4)(p-g)
```

有真上界 2/5，旧点 Z=203/480，严格差 11/480。上界由第一条新行和原门 residual capacity 相加获得；真实 source (1,1) 取等。这是数学强度控制，不是正式 CERT。

后继使用实际原门 r=ReLU(-F/2+p/40+1/100)、原 bit gamma。已有 p<=6beta/5，故 F+h<=alpha/5+beta/5+1/100 与第一条新行共享原相位系数。D052 的前向规则给 F+r<=alpha/5+beta/5+gamma/100，从而 Z+r<=2/5+gamma/100<=41/100。该规则真实消费前层证书，没有 phase split 或免费支持查询；本轮只核对这一固定消费，不声称通用传播实现完成。

其余定向测试覆盖正负和零 Delta 的完整投影、非对称 source 盒、反向坐标偏置、g 独有源、固定源、非点与跨零系数、零 preactivation 的两种合法原 bits，以及默认关闭和拒绝语义。有限 fixture 真值检查只在测试中执行，不构成候选运行时搜索。
