# 联合激活关系的精确数学组件

本候选实现上一轮共享父源的联合激活原语，目的是让非凸 Neural-HZ 的关系构造与消费接受可反证检查，而不是新建验证 helper。它仍是局部数学组件，不是完整新域、原生模型适配、GPU 实现或真实网络能力声明。生产默认不变，所有入口显式 opt-in。

上一轮“先找到胜过全部强参照的纸面控制再实现”是研究优先级建议，不是用户增加的晋级门。本轮按既定流程从定义、定理与费用分析进入数学组件；负控制仍约束原创性和能力声明，不降低任何原验证、资源或全量回放要求。没有强参照收益，不能据组件通过宣称能力提升。

## 非凸语义

保留原 HZ H 的连续源、全部 signed binary 相位、EQ/LE、共享 frame/latent、全部消费者与原输入 decoder。候选 N=(H,B) 的具体化是原因子和各共同关系块同时满足时的原读出，新增 lambda 存在量化；空 B 嵌入 H。具体化包含给出预序，按等具体化取商得偏序，不声称最佳抽象或完整格。

本组件只编译 B，不修改或复制 H。原生调用者以后必须认证所有物理读出与 H 的绑定；本轮 Binding 的对象身份和字符串 ID 只认证数学调用的一致性，不是已取得原网络列身份、decoder 或参数来源资格。

统一结构为两个 crossing 父门和两个并行后继：

```text
q_i=ReLU(f_i), i=1,2,
h_j=c_j·(f1,f2,q1,q2,v)+b_j,
y_j=ReLU(h_j), j=1,2。
```

父可靠界 lo_i<0<hi_i；有 0、1 或 2 个有界实际余项 v，固定余项仍保留物理坐标但不增加几何维度。v 在原 H 中是完整其余贡献的真实读出，不允许换成独立物理噪声。物理顺序为 f1,f2,q1,q2,v...,y1,y2；四个原 signed bits 顺序为父1、父2、后继1、后继2。不增删二元因子，不生成原位的替代标签。

## 构造和整数等价

采用 [D227 定理](../d227_shared_bank_composition_20261005/DEFINITION_AND_PROOF.md)。两个父真图折线乘以 r 个非退化余项区间，其面数生成式为 (3+2t)^2(2+t)^r。统一遍历零维原点、一维真边与一个后继零式、二维真面与两个独立后继零式，求精确交点并检查面成员，提升全部实际 y。禁止用父凸包弦代替真边。

候选交点上界为 f0+2f1+f2，r=0/1/2 时分别为37/104/277。重复点去重；相关、重合或恒零限制按同一个秩条件处理，不增加分支求解路径。不创建人为划分阈值、selector bit、输入或相位子问题，不调用 LP/对偶/优化器。

输出 V 使用一份 lambda>=0、sum lambda=1，并令全部物理坐标 z=sum lambda*V。每个原 signed bit sigma 对预激活 g 编译两行：

```text
sum_(g(V)>0) lambda - sigma/2 <= 1/2,
sum_(g(V)<0) lambda + sigma/2 <= 1/2。
```

零预激活的两种原标签均合法。该系统是局部独立包上完整带标签凸包；四个原 bits 整数时，所有正质量顶点位于同一凸的共同守卫区域，故平均点仍是原非凸图。即使 mask 为空或激活稳定，也保留四个原 bit 列及八个标签行。

安装到相关原 H 时，保留原源等式和全部旧谓词可证明健全、整数等价；不能声称全原源 LP 理想。特别禁止强行要求每个局部 V 点都分配到满足 H 的原输入原子，这通常会删真状态。

## 共同消费和输出边界

同一块的物理仿射读出先按身份合并，局部包支持为 max_V a·V。若含原相位系数，在每个顶点按其严格符号取固定 signed bit，零处按查询系数选择合法端点。支持过程是有限精确算术，不读取终端点、标签、历史分数或求解状态，不执行 rescue。

Support 同时返回达到局部界的 V 索引、物理点及合法 signed bits。这不是原 H 的可行输入，更不是 ADV；实际源绑定与具体网络检查仍必需。后继只在已有共同界证明预激活非正时得到稳定性结论，不把一般跨零后继冒充本轮已实现的任意深度闭包。

compile 返回局部稀疏 EQ/LE 和列映射，列顺序为 D=6+存储余项数 个物理列、四个原 signed bits、N 个 lambda。调用者以后必须在同一 frame 中与原 H 合并；本轮不调用原生终端、不接入 ACT 默认路径。satisfied 只是精确数学行检查，允许分数 signed bit 以测试 LP 视图，不意味着存储域取消整数相位。

## 精确算术与完整收费范围

只接收 int 或 Fraction，拒绝 bool/float 与非法形状/界。所有有理输入、中间值和输出保持512位上限，超限抛 Rejected，不输出部分因子或部分支持证书。公共 build/support/compile/satisfied 的单操作 work 上限200000000；同一 Budget 跨操作累计 work 上限256000000、entries上限64000000。限额可收紧测试，不可扩大；失败不退款。候选计算、行构造与检查、返回结构均在账内。

这些是新局部原语的明确工作/条目账，不是原生全前缀或 Python 完整物理存储证书，也不替换继承测试各自原有 ledger。新实现未整合旧 D211 压账。将来多个块、原 source/predicate/frame、全部消费者、终端、decoder、证据与主机设备共存的完整费用仍须另外过原门，不能把它们叫作免费。

两个非退化余项时，新增局部上界为277连续列、285 LE、9 EQ、3894 nnz；无余项为37列、45 LE、7 EQ、458 nnz。一个余项为104列、112 LE、8 EQ、1367 nnz。固定余项虽不增加有效几何维度，仍支付相应物理读出行。顶点/masks、精确秩与交点、数据保留、源绑定和所有外部 H 费用不由 nnz 数免除。

## 两个方向边界

纯多负项不是相对于同一父集合的 LP 精度突破：对共同源 P、仿射 v/h 及 d_j>=0，系统 q_j>=0,h_j 对 sup(v-sum d_j*q_j) 已给与真实 ReLU 相同的最优值。每个松弛点的目标不超过同源真值，反向令 q 为真激活即得。若 P 是父松弛，结论也只相对于这个 P，不自动恢复原非凸父关系。

原源逐顶点绑定反例为 x∈[0,1]^2、f1=x1+x2-1/2、f2=x1-x2+1/4，h1=q1-q2+1/10、h2=3q1/10+q2/2-1/5。原 x*=(1,0) 给 f=(1/2,5/4)、y=(0,23/40)，不是局部 V 点，却由 V 中 f=(0,5/4) 权13/23 和 f=(23/20,5/4) 权10/23精确生成。若每个 V 点强制有原盒条件源且均值为 x*，原盒极点迫使每个条件源等于 x*，造成不可能的删除。这一测试保障均值层源绑定，不授权不健全的条件原子提升。
