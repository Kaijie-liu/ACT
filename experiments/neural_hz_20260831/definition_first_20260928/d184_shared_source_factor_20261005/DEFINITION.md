# 共享源纤维的 Neural-HZ 定义候选

本轮选择一个值得继续数学组件设计的候选：用少量非负原相位权重，共同约束当前源的加权读出，并直接替换仅由完整 packet 消费的逐门幅值。与保留全图再加 helper 不同，候选的具体化本身允许有证的联合外包；其局部关系直接是带原整数相位的线性谓词，不把未编码的精确乘积当作已查询关系。

已有 source perspective、RLT 和半非负矩阵分解提供主要代数原理。本轮并未证明 PLDI 级新颖性。建设性进展是同一出生合同、可组合关系和完整费用正控开始同时成立，见 [结构控制](STRUCTURAL_CONTROL.md)。没有运行、真实性能或正式成绩资格。

## 域元素和出生合同

保留当前父关系 S、所有原连续源和二元身份、EQ/LE、共同 frame、原输入 decoder。令 z 为同一父状态的一个 k 维认证读出，P={z:Fz<=d,Ez=e} 是有界、与相位无关的认证源外包，对整个 S 有效，而非仅对具体网络样本有效。S 本身保留，包括其中含旧 bits 的谓词；P 不代替 S。

当前 m 门预激活为 g=Lz+b。全部原相位 beta_i 仍为整数，原弱符号守卫作用于真实 g，零点两种标签均保留。完整 C 含所有活消费者、所需 mass、旁路和历史谓词读出；若某个 q_i 仍独立被外部使用，其读出必须计入，不能为压缩删掉。本文出生合同用于构造本次 ReLU 包，不追溯把已自由化的旧幅值当作真实乘积。

设存在固定矩阵 D_h 和非负系数 A_hi，使逐门外积满足

```text
C_:i L_i: = sum_h A_hi D_h,   A_hi >= 0.
theta_h = sum_i A_hi beta_i,   M_h=sum_i A_hi.
```

定义新源纤维的连续向量 W_h，以以下线性关系为实际原生语义：

```text
F W_h <= d theta_h,
F (M_h z-W_h) <= d (M_h-theta_h),
E W_h = e theta_h,
y = C D_beta b + sum_h D_h W_h.
```

theta 的定义也必须保留或完整内联，不是免费参数。零系数行可代入 W=0；源界、身份和每一个代数等式均须认证，失败关闭。可在出生时共同加入已证的非负组值、聚合门界等谓词，但必须列明并计费。

W 不要求等于 theta*z。精确乘积是健全性证明的共同见证，不是偷偷留在原生定义中、再由终端忽略的约束。因此一般原整数 beta 下也允许额外输出。不得将这些额外赋值直接计为 ADV。

## 健全性和真正的非凸性

对任一完整原生父赋值及合法新相位，统一取 W_h=theta_h z。非负的 theta_h 和 M_h-theta_h 分别缩放 P 的行，得到全部新谓词；外积恒等式给 y=C D_beta(Lz+b)。同一赋值也保留 S、所有原 guards、decoder 与消费者。这证明完整父域上的逐点包含。

因 P 有界，其衰退锥只有零向量。theta_h=0 时 F W_h<=0、E W_h=0 强制 W_h=0；theta_h=M_h 时补环境强制 W_h=M_h z。因此全 inactive 和全 active 切片精确。单门取 A=1，则 theta 就是该原 bit，得到精确 ReLU 图；例如图中的 (-1,0)、(1,1) 的中点 (0,1/2) 不可达。候选不是以无效 bits 装饰的单一凸域。

空 bank 嵌入原 HZ，保持其原谓词、因子和输入图。新 bank 的谓词本身可表示为 HZ 的线性系统，所以没有声称集合表达能力超越 HZ。研究问题是神经结构原生的关系组织和有损变换能否以较低完整成本保住有用证明，而不是换名或只换矩阵布局。

## 递归算子及查询边界

Affine/Conv、Add/Concat 对共同 frame 上的实际 packet 读出作线性组合，不复制父源或 W。下一 ReLU 可以将这个已经有损的 packet 作为真实抽象父读出，重新认证源外包 P，再应用出生合同。证明仍对整个有损父域成立，不假定旧 W 是 canonical 乘积。

若从原 HZ 起步且之后只使用本线性纤维规则，原生系统保持线性 EQ/LE 与原整数 bits；普通终端 MILP 不需重新恢复所有旧 q，也不需隐藏的非线性 membership oracle。LP 查询只是显式原相位的连续外松弛，不改变域的整数类型。若接入另一个含原生非线性关系的候选，则那些旧关系仍须另付查询成本；本结论不授予组合资格。

来源 P 必须确实是 phase-independent 的源外包。把 Fz+B beta<=d 直接乘 theta 会产生 theta*beta，不能按上述低费用行数处理。对旧 phase 依赖谓词，保留原 S 不等于已经得到其加权副本。输入重构由原 decoder 完成；新增 ADV 仍须原模型与性质验证。

这些关系可用稀疏矩阵运算构造和消费，但本轮没有 GPU 数值认证、设备终端或速度证据。smooth/Transformer 的非线性图并不由这个 ReLU 合同自动覆盖。

## 权重数量与可行相位的限制

令 K 的第 i 列为 vec(C_:i L_i:)。固定矩阵基因子化需 h>=rank(K)。非零 K 的任意 rank-r 分解 K=UV 都可用至多 r+1 个非负权重表达：对列 v_i，取 c_i=max(0,-min_j v_ji)，用非负列 (v_i+c_i*1,c_i) 和矩阵基 [U,-U*1]。也可直接用 h=m 的原单位权重，因此 h<=min(m,r+1)。K=0 无需源乘积，不由此删除任何原 bit 或偏置读出。

这正是已知半非负分解的构造，不是新定理。[Gillis 与 Kumar 2015 的 Theorem 2.1 和 Corollary 2.2](https://abhishek.ml/assets/pdf/seminmf.simax15.pdf)给出了该界及构造。本文不导入其拟合优化器、SVD 误差或交替迭代作为新的求解路径；非精确系数分解须另有残差包含证书。

不能仅以“多数 Boolean 模式不可行”避开此固定基费用。若每个 g_i=0 在实际满维源域内部都有仅该门变号、其余门严格的边界片，则邻接两开区域相位只差 e_i。精确输出表达在每个开区域对全部 z 相等，要求其仿射系数相等；两侧相减即得 K_:i 属于固定基张成空间，仍有 h>=rank(K)。这是 D002 相邻区域方法在当前系数接口上的应用，不是新的普遍不可能性。

该论证无需全部2^m模式可达，但要求这些相邻区域确实在父关系内；低维源须先限制到实际仿射包。额外直接 beta*z 项、相位依赖基或非线性 decoder 均不在这个下界范围。固定基即使配非线性 phase 权重，其系数差也仍落在同一基空间。

mass 行使 rank(K)>=rank(L)。若完整 L 满行秩，K 满列秩；若把逐门独立残差 I_m 作为源精确保留，完整 [L,I_m] 同样阻止这类秩压缩。仅压核心、却不给残差计费不成立。

局部结构证据可以比展开 K 便宜：例如一个源坐标只连接一组未处理门 G，且 C_:G 满列秩、该坐标各 L_ij 非零，则相应 K 行块可逐组剥离。相同未截断卷积核的有限不同平移也有线性独立性，但不能直接推广到 padding 截断边界。当前三份 CNN 的实际系数秩未认证；dense 或 sparse 形状本身不提供结论。

## 同规模纤维的统一基变换

另一个可复用的定义操作是替换共同权重，而非附加事后菜单 cuts。两行 a,b 非负且共同支撑上 a_i>0；设 alpha=min_i b_i/a_i、gamma=max_i b_i/a_i，alpha<gamma。令

```text
eta_minus=(gamma*theta1-theta2)/(gamma-alpha),
eta_plus=(theta2-alpha*theta1)/(gamma-alpha).
```

两者仍是原 bits 的非负固定权重。用 X_minus、X_plus 的完整 P 与补环境纤维替换 W1、W2，同时所有读出代入

```text
W1=X_minus+X_plus,
W2=alpha*X_minus+gamma*X_plus.
```

逆变换系数非负，且上界均取各自非负系数和；逐行相加证明新纤维映射进旧纤维。数量仍为2k个向量坐标、4*rows(F)个LE，允许严格加强。支撑不匹配或相同比率不使用含零分母公式，须有独立结构证明；本轮未选择此操作进入运行。

它也是已有 RLT/非负锥原理的推论。它可在新 bank 的出生策略或独立查询构造中使用，不能未经完整父域证明就收紧一个已经有损的旧父域。一个已审查普通两门控制见 [结构控制](STRUCTURAL_CONTROL.md)，那里也列出更便宜的原 HZ 对照。

## 继续条件

继续的是一个默认关闭的数学定义候选，不是“所有低秩接口都有效”的结论。下一组件必须输出并验证完整源与消费者证书、全部原 bits/guards、有限谓词、反向输入身份、真实局部账，以及有损父成员的递归健全性。强旧路径的已有廉价关系也必须比较。

结构控制说明存在完整局部费用与证明同时成立的窗口，足以继续具体实现设计；不证明这种窗口已存在于 CIFAR/Tiny 的大规模 dense 接口，不替代真实同结构、逐家族、2413和400回放，也不修改任何资源门槛。
