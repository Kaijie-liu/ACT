# 原生共同观察的跨层变换

本候选把已证明的共同规范实现和跨层观察规则落实为默认关闭的 SparseHZono 组件。目标是让下一原 ReLU 真正使用前级共同关系，而不是只压缩存储。机制来自既有扩展表述、约化积与函数摘要；新颖性尚未取得，本版不能仅因增加有效行而称为新的抽象域。最近文献综合位于 literature_priority_synthesis_20261001，前置数学证明为冻结 D091 THEORY。

## 共同语义和接口

输入 H0 含全部原连续因子、全部原 signed binary factors、EQ/LE、输出、frame、exact 和原输入 decoder 的坐标前缀。包括后继门在内的全部原门均已属于 H0，本版不是在线分配原网络列的资格。原对象调用期间不得并发变化，本候选不修改它。

入口 append_observation_relay(hz, parents, consumers, observations, next_consumers, enabled=False)。parents 是两个冻结 D064 Graph；consumers 是非空 (Graph,a,b) 元组，a,b 为归一化父输出 u,v 的 Fraction 系数；observations 是非空固定 Fraction 矩阵 W，每行覆盖整个选定 child bank；next_consumers 是非空 (Graph,C) 元组，C 的每行覆盖整个观察 bank。矩阵可混号、稠密或含零，规则不按实例、margin、标签或求解状态选择。所有原门须通过实际 EQ/LE 认证且 graph_error=0，不能把辅助行反推为精确门。

每个候选辅助观察指定同一个原状态 theta 上的函数 Gamma(theta)，例如 pi_s Wq(theta)。扩展系统保持不变量：每个原整数可行 theta 均有共同扩展 (theta,Gamma(theta))，满足所有新旧行。后续新增关系只需在该共同实现上证明有效；并不声称每个存储可行辅助赋值都有精确乘积含义。

任一新行 A z<=d 编译为 binary64 Ahat，E=sum|Ahat-A|，RHS 向上舍入 d+E。所有 latent 在单位盒中，故共同实现继续满足该行。归纳证明前向包含；全部 H0 行保留证明反向包含，因此投影回全部原坐标恰等于 H0，包括零 ReLU 的两种原标签。只保持原坐标投影，不要求保留上一层所有伪辅助赋值。decoder 继续读原列前缀，不从新变量重构原输入；具体模型来源仍未认证。

## 统一变换

组件内部首先调用冻结 D086 的共享上行变换，不能接受未经本次构造认证的外部辅助系统。共享 delta=alpha*beta、zu=beta*u、zv=alpha*v，由三个连续坐标和十二行表示。固定四个代数槽对应原两个父 bits；不是输入/相位子问题或全网枚举。

对 child 的实际 g_j 取完整分解 g_j=c_j+a_j*u+b_j*v+r_j，r_j 保留全部原连续及二元系数。M_j=||r_j||1；由原父幅值和 M_j 求四槽 L_j,U_j，统一取稳定零、稳定线性或 secant 的 k_j,d_j。槽核心 h_js 使用共同父幅值、c_j*pi_s 及完整残余槽。非零残余由前三槽连续量表示，第四槽为原残余减前三槽，保留八条容量行。

每个实际观察 v_i=sum_j W_ij q_j 生成四槽 v_is，前三槽以 M_i*xi 表示，第四槽由 v_i 减前三槽恢复。M_i 为全部槽已证上下界绝对值的最大值；若为零则四槽均为零，不分配无用新量。每槽的双侧行来自同一核心 sum_j W_ij k_js h_js，负权重的 W_ij*d_js 加在下侧，正权重的加在上侧，共八行。不将每个 child 的误差独立复制后假装仍保持全部共享关系。

槽界严格使用 D091 的统一规则：一套为 child ReLU 范围的符号加权区间和；另一套先在原坐标合并 sum_j W_ij k_js g_j，再对合并后的完整残余取范数，按父幅值和负/正 intercept 分别求上下界。两套有效界取交；L>U 拒绝候选或证书，不删除相位、不宣布 UNSAT。非点不确定参数不能冒充固定 W。

对下一门的实际预激活，完整计算 h=Cv+r，不遗漏其余读出。r 的常数分出，非零余项保留三槽和八条容量行。由观察槽界、C 的符号和完整残余范数求下一门各槽范围；以同一 secant 规则添加 q_next<=sum_s(k_s h_s+d_s pi_s)。保留原后继 bits、EQ/LE 和输出。返回辅助列、语义绑定、精确行、舍入误差、安装 RHS 与存储/nnz 描述，供独立重构和证书检查；不把这些元数据当真实网络资格。

## 正负控制

普通三层结构采用冻结 D091：u=ReLU(x)、v=ReLU(y)、r=ReLU(u+v-3/4)、t=ReLU(u-v+1/4)、w=ReLU(r+t-1/2)。第三门原界采用真实全局 [-1/2,1]。旧分数点在完整原 H0 及 D086 上可行，但四槽观察使全部可行辅助扩展都要求 w<=11/24，排除 w=1/2，精确间隙1/24。

实现测试不能只挑一个新辅助赋值。前级精确可表示行须证明无舍入放宽；下一行的统一存储间隙至少为 1/24-E-(installed_rhs-exact_rhs)，须严格正。另检查所有原零相位标签的共同扩展、混号观察、宽连续和原二元残余、原数组未变、全部原前缀谓词/输出/身份及 exact=False 保留。默认关闭在严格 bool 检查后不接触毒输入。无效绑定、超512位、支持超限和非有限数值均拒绝而非生成新结论。

## 成本和资格边界

设 K 个 child、P 个观察、J 个后继，前级非零残余 R、后级非零残余 Rn，非零观察尺度 Pn。相对 H0 最多新增 3+3R+3Pn+3Rn 连续量，新增 12+8R+K+8P+8Rn+J 条 LE；原 EQ 和二元数量不变。实现须核对实际计数，零项合并不减掉输入收费。

观察界及行的工作按全部输入支持出现次数收费：T_i=sum_{j:W_ij!=0}(1+nnz(r_j))，不是只看合并后的最终支持。四槽共同核心合并及排序形态为 O(4 sum_i T_i log(1+T_i)) 次有界标量操作，另有完整 W、C 遍历、各门认证、下一残余展开、精确运算和新行编译。复用 D064/D086 的65536出现次数预检和512位有理算术检查；新观察组合在分配前按未合并输入支持预检。该局部限制不是全worker工作预算的替代物。

原 H0、D086 中间对象、最终输出在构造期间共存，所有数值副本、CSR拼接缓冲、元数据和证据均有成本。返回 retained ndarray bytes、三对象共存描述、新行缓冲和 nnz；这些不包括全部 Python 对象、精确数临时量、求解器与 GPU，因此不授予完整物理/工作量/模型资格。一般完整代价还包括 source 认证、传播、终端转换查询、decoder、host/device 共存，未执行项不得计零。原 whole/branch/evidence/RSS/AS 门不放宽。
