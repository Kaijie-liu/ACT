# 从当前非凸谓词构造完整共同观察银行

本候选保留生产 HZ 的出生、frame 分配、deferred 物化和合流不变，在一个已完成且调用期间静止的 SparseHZono 上，认证实际等式与守卫，再为全部适用结构生成共同观察。目标是让已证跨层关系进入真实网络已有表示，而不是要求先替换每层 ReLU。它仍是 Neural HZ 定义研究的接入组件，不把扫描优化或已知有效不等式包装成新域创新。

## 为什么不直接替换出生

只读生产审查得到三项实质约束。D096 从当前对象宽度追加，生产 `_sparse_relu_slots_for` 按全 frame 高水位分配；两个独立分支直接使用局部追加会撞列。Add 分别合并 EQ 与 LE，Concat 纵向堆叠，旧 Graph 的两个行映射也不能只凭同一个 frame 保留。CNN 还会在 Conv 阶段提前出生并只物化非稳定负行，ReLU 层输出后的替换已经太晚，partial 输入不等于完整预激活。

旧 Tiny 真实前缀 `results/c5_integrated_prefix_20260905_v2/result.json`（SHA256 `a42456761ac6dd925bf89b1fc2e4537b6f010294ac8ea28fe233ab3e20597081`）记录 ReLU5 的输出 Gc.nnz 为 494693、原不稳定门 512、输出数 46656。在保持该完整前激活系数的接法下，稳定正输出复制原系数、每不稳定输出只用一个 eta，因此前激活 input_terms 至少为 494181，至少一行 support 不小于 11，D096 的 largest 至少 19。其 `birth_full_literal_construction` 单项收费下界为 `128*(494181+46656+8)*6=415368960`，超过 256000000。这里忽略正的 16*k 项仍成立。

这只是冻结 D096 实现的条件性收费下界，不是实测失败或 HZ 复杂度下界，也不将 C5 的 selected affine island 门扩大为此前不存在的全模型统一门。本版不降低 D096 常数、不拆池、不缩人口；它不运行 D096 出生，而从当前实际谓词读取关系。

## 实际关系定理

连续单位盒中的 s、eta 和原 signed 二元 b 满足实际存储关系：

```text
L*(s+b) - Q*eta + R = rhs      L<0<Q
-s-b <= 0
-eta+b <= 0
g = Fraction(rhs) + Q - R
q = Q*(1-eta)
```

所有标量按实际二进制浮点的精确有理值解释。由 EQ 得 `g-q=L*(s+b)`。b=+1 时守卫使 eta=1，故 q=0 且 g<=0；b=-1 时守卫使 s=1，故 g=q>=0。因此对当前 HZ 每一个整数状态均有 q=ReLU(g)，g=0 的两种标签也保留。不需要声称 g 等于生产出生前未舍入的网络预激活；尤其 `Fraction(rhs)+Q` 不能替换为浮点加法或外部中心。

本结论相对于输入 HZ 的实际具体化集合。它不修复或重新认证已有前端的浮点构造、来源、输入解码和模型健全性；真实接入仍需保留这些既有权威边界。相同 frame_id 本身不是跨对象的来源证明。

## 完整结构选择

先检查整个原生 schema，再扫描全部 LE 和 EQ。两种字面 guard 按原 bit 建索引，同列相同 guard 的重复出现可规范选首行；不能把缺失、歧义或不支持的模板伪报为成功认证。相同实际关系的重复 EQ 可规范去重，原谓词不删除。每个保留的原门在当前行号上认证，任何 eta 多义都不得随意选一种解释。

沿用 D088 与 D093 的结构规则：每个 child 从其完整实际 g 中按固定列序选前两个不同原 bit 的父 eta，系数为 -2*g_eta，其他连续和二元项完整保留为余项。同父对的全部 child 成组；每组检查完整原目录，纳入所有含至少两个不同 child eta 的其他门。物理读出为 q_j=Q_j*(1-eta_j)，故观察系数为 -g_eta_j/Q_j，而非误用归一化幅值系数。每个后继一个稀疏观察，C 取相应单位行。

不按实例、标签、历史结论、margin 或求解状态选择；不执行输入或相位 split。登记全部原门、未覆盖门、歧义、所有组和后继。仅结构上无后继的源组没有 relay；不得在预算不足时保留一个较小成功前缀。全部原 bit 始终保留，不将未识别门当作被删除。

## 认证与组合边界

有序规范 CSR 的单行提取可以直接保序过滤 s、eta、b 并对其他系数取负；不需要 D064 原通用组合中的字典合并和支撑排序。实际 guard 和 EQ 的检查不省略，512bit 和 65536 局部限制不变。排序费用仍对确实需要排序的目录和观察索引收费，不再给每个单行乘一个不存在的支撑排序过程。

公开应用接口在同一个调用中完成整个银行构造和全部组应用，不接受外部伪造的 bank、owner id 或 seal 代替认证。只读构造接口可提供诊断结果，但该结果不能绕过应用接口的重新实际读取。HZ 在调用期间须静止，外部并发可变状态不在本组件合同内。

关系安装复用 D097 的共同观察数学体，父、child 与 next 的 g/q 均来自本次认证；原完整输入人口检查、余项、向外舍入补偿与复制收费不省略。每组基于同一原 H0，各组新增辅助列互不重叠。对任一原整数状态 theta，每组取自己的共同 Gamma(theta)，并合成全部辅助量，因而同时保留所有原状态；不是每个消费者选择不同输入。原输出、因子、EQ/LE、frame、exact 和输入前缀不改变。

原生银行的首次图提取数单独记账。D097 数学体内部不重复提取，不意味着整个 D098 零提取。多组回执不得意外保留所有中间 HZ；同时存活的原对象、银行、最终对象、临时对象和精确行证据仍属于后续完整物理门。

## 真实接入和未授予的资格

Tiny 最早相关三组门在 ACT ReLU5、9、20；第三组之前有 Add16，必须包括从 ReLU5 经过 Conv13 的旁路。CIFAR100 large 的原 ONNX 对应普通块包含 Relu_2、Relu_5、Relu_11 和 Add_8 的 identity 旁路，ONNX 节点号不能与 ACT 层号混用。本版不加载它们，也不以旧聚合统计冒充本次全人口认证。

当前应用是闭合银行上的追加，不能随后让未更新的生产 frame allocator 继续分配新变量。真实路径可以选择在已完成的边界一次应用，但中间层停止不能计正式解；在线继续传播另需完整生命周期合同。真实新鲜 worker 不应调用会写旧快照的 main，也不能复活 D090 大 pickle 路径。

GPU D017/D043 的初始化失败与 D020 的 ptrace 拒绝保持原记录；未证明具体根因，不放宽 AS、不绕权限、不以未来 GPU 提速支付当前费用。本版没有 GPU、预训练网络、终端求解、shadow 或全量资格。
