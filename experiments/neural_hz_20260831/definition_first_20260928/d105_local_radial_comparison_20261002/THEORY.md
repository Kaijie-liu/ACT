# 非零中心归一化的同读出比较

本记录保存 D105 的纸面推导及否定性发现。D104 的源绑定径向定义和零中心严格控制仍成立，但其未局部化方向行不能直接作为普通非零中心 LayerNorm 的通用改进方案。没有实现、数值实验、真实 epsilon 实测或机器证明。

## 同一读出的局部界

以下变量均为中心化坐标；最终 gamma 和 beta 需按真实节点处理。设 z=c+h，C=||c||>0，||h||≤δ<C，eps>0，并记：

```text
rho0 = (eps+C²/d)^(-1/2)
rho = (eps+||c+h||²/d)^(-1/2), v=rho*z
lambda = (eps+(C+δ)²/d)^(-1/2)
rho_max = (eps+(C−δ)²/d)^(-1/2)
J(c) = rho0*I − (rho0³/d)*c*cᵀ
```

J 的径向特征值为 eps*rho0³，切向特征值为 rho0。不能直接拿径向读出 v−lambda*z 的 O(δ) 与不同读出的 Taylor 余项 O(δ²) 比较。

取单位中心化方向 a，aᵀc=0。对相同读出 F=aᵀ(v−lambda*z)，有 F=(rho−lambda)*aᵀh。局部范数壳给出已有的乘积界：

```text
F ≤ B = (rho_max−lambda)*δ
B = (2*C*rho0³/d)*δ² + O(δ³).
```

而 D104 仅用 Cauchy 下界 ||z||²≥(aᵀz)²、T=δ 的原方向行给出：

```text
F ≤ M = max(0≤t≤δ) [t/sqrt(eps+t²/d)−lambda*t].
```

固定非零 c、eps，在充分小的 δ 下导数为正，最大值在 δ。故 M=(eps^(-1/2)−rho0)*δ+O(δ²)，严格正的一阶项使其比同事实的 B 松一个阶。这只否定未局部化行的普遍优势，不否定精确径向关系；补上 B 也不是新理论。

## 普通多面体源上的有限反例

不以球替换原 HZ。取 d=3、c=(1,−1,0)、eps=1/3、δ=1/4，u=c/sqrt(2)，a=(1,1,−2)/sqrt(6)。令：

```text
h = δ*(t*u+s*a)
t,s ∈ [−1,1], 四条 LE 为 ±t±s≤1.
```

这是两个连续因子和四个线性谓词定义的普通菱形源，覆盖中心化平面的两个方向。u、a 正交且单位，因此 ||h||≤δ。t=±1,s=0 达到 ||c+h||=sqrt(2)±δ；t=0,s=1 达到 aᵀh=δ。局部壳端点及 T 都属于同一源的真实界。若嵌入含原 bits 的 HZ，这些 bits 及其谓词原样保留，不据此删除或放松它们。

该源上原行与简单乘积界分别为：

```text
lambda = sqrt(48/(49+8*sqrt(2)))
M = (sqrt(48/17)−lambda)/4
B = (sqrt(48/(49−8*sqrt(2)))−lambda)/4
M > B.
```

理由是 17<49−8*sqrt(2)。原行函数的导数在 δ 处仍为正：sqrt(48/17)>3/2 且 lambda<1，故 eps*(sqrt(48/17))³−lambda>9/8−1>0；导数随非负 t 递减，因此端点确为最大值。此例不是实际网络 epsilon；前一节的渐近结论则对任意固定正 eps 成立。

## 共享余项及已有研究边界

定义 tau=rho−rho0，sigma=tau+(rho0³/d)*cᵀh，可直接展开得到精确恒等式 e=v−rho0*c−J(c)h=c*sigma+h*tau。这个分解已经出现在 [ZonoGPT 附录 A.1 式 43 至 44](https://arxiv.org/pdf/2609.34457)，不能记为新发现。该文还保留完整 Jacobian 原输入符号，并在式 46、48、49、51 给出正分母及余项界；本次核对论文，未核验作者实现。

下面是用于后续公平比较的自行推导，不是新颖性声明。令 s_min=eps+max(C−δ,0)²/d，D=(2*C*δ+δ²)/d。标量逆平方根的 Taylor 凸余项 r 满足 0≤r≤3*D²/(8*s_min^(5/2))，而 sigma=−rho0³*||h||²/(2*d)+r，因此：

```text
−rho0³*δ²/(2*d) ≤ sigma ≤ 3*D²/(8*s_min^(5/2)).
W*e = (W*c)*sigma + (W*h)*tau.
```

前两行界作用于同一 rho、h，不是重新采样的独立噪声。对每个具体 h，e 在 span{c,h} 内，但 h 随输入变化，所以不能声称整个余项集合固定二维，或精确等于两个自由线性生成元。

若已有 |sigma|≤E、|tau|≤D_tau、|h|≤r_h，则同一因式分解直接给出参考：e 属于 c*E*[-1,1]+diag(r_h*D_tau)*[-1,1]^d。该集合包含于用同一 E、D_tau、r_h 推得的坐标盒，因此至少不弱，可能严格更强；并非声称它包含于精确逐坐标余项盒。它保留共同中心方向误差，仍非新理论。公平参考还需保留原输入与相位、完整 J、已知零和关系，并在残差消费者间复用同一余项身份，不能人为独立化削弱对手。

## 研究决定

保留 [D104 审阅版](../../RESUME_RESEARCH_20261002_D104_REVIEWED.md)的精确定义、证明和指定参考下的局部分离；不将其扩大为全部 Taylor 关系的严格优势。当前未证明 D105 关系在非零中心胜过上述加强参考，也没有完整费用或实际速度证据。不实现仅改名的双标量 Taylor 包装，不把弱比较上的成功记为 Neural-HZ 正式收益。真实适用性及下一结构问题见 [适用性审查](APPLICABILITY.md)。
