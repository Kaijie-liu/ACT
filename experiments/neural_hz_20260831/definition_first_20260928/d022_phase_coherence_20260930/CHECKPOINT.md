# 共享相位关系的数学检查点

本轮从文献建议推进到一个明确的非凸关系块定义、两个严格分离例和组合接口。它解释了为什么原相位应作为多条关系的共同变量，而不只是最后才交给求解器的标签。但这仍是定义候选的组成部分，没有证明超越同事实 HZ 的完整成本优势，不能作为已经完成的 Neural-HZ 创新交付。

## 进展分类

上一轮属于 progress：完成并封存了用户要求的定向文献综述，明确了源条件参与局部关系的研究问题。本轮启动时核对其 SHA256、当前分支、commit 和工作区状态；没有把旧综述再次算作发现，没有需要恢复的本轮实验句柄。

本轮也属于 progress，新增证据见 [相位一致性定义与证明](PHASE_COHERENCE.md)：

- 给出保留原 HZ 源与全部原 bits 的双侧容量关系块，证明其整数具体化与原 gate 图相同，包括零点合法 bit 选择。
- 给出单节点共享相位的松弛投影刻画，说明跨边配对关系怎样由同一 bit 保持；用普通三门内部点证明逐边独立投影严格更弱。
- 给出真实残差输出的纸面正控。旧组合松弛即使使用各单门 full-source ideal hull 和精确 phase-free 差分 hull，仍允许输出 0.53；相位关联因子证明上界 0.50。性质上界取 0.51 时有正安全裕量。
- 完整列出孤立 pair 的连续松弛投影四条交叉行及适用范围，避免只排除某一个可重新选择的分数 bit 赋值。

[组合与对照](COMPOSITION_AND_CONTROLS.md)给出差分穿过 affine 的核包含条件、普通混合符号两块 CNN 的精确关系连接、padding 所需锚点、Add/Concat 语义和 GPU A/Aᵀ 算子。另一个两层正控把源条件的收益传到下一 ReLU，但确认它是已知 Anderson formulation 的二维实例，只作为比较对象。

## 审查和没有完成的事项

根代理推导共享相位容量、跨边投影和残差输出例。两个独立只读审查分别复核分离见证、单门源混合、相位区间、pair 投影、卷积条件及 GPU 符号。组合审查还给出了已知单门 formulation 的构造证明及第二 ReLU 控制。

## 下一项有区分力的问题

共享相位可以在线性规模的关系表示中保留跨边的一致性，这一点现在有了严格例子；但仅把所有边行保留到终端，仍与普通 HZ 加同事实相同。

下一步应专门研究混合 affine 消费这些关系时的前向归约：能否保留源与原相位之间的定量依赖，形成下一激活可用的有界大小关系，而不是退回独立区间或让谓词逐层无界累积。若转移需要新相位乘积、连续源副本或更大关系作用范围，必须与已有 RLT/分组提升逐项付账比较；不能把隐藏的展开当成闭包。

这不是要求全局 ideal hull 或全局完备性的新增门。研究目标仍是普通多算子结构上的精度与完整成本优势。还没有证明该优势，因此本轮不以“已有数学正控”为由直接接入生产或启动正式计分。
