# 内禀共同尺度的有效性和跨层闭包障碍

本记录研究一个定义层问题：能否用原共同赋值的确定函数，取代依赖所选 cap 证明的共同余量，从而获得更稳定的 Neural-HZ 关系传播。结论是，该替代有健全的逐点公式，但没有解决所要求的跨层闭包；原相位内的新折线、cap 收紧反例和普通混权后继共同否定了直接采用它的理由。本轮不实现这个候选，也不把它包装成新的抽象域。

这是纸面推导及独立复核，没有候选导入、数值运行、求解器或模型执行。反例全部使用普通有理系数、非平行神经元和正常宽度的输入盒，不依赖极端数值。它们是数学命题的反例，不是网络 ADV 或正式能力结果。

## 问题来自哪里

[已有闭包定义](../d209_owned_slack_closure_20261005/CONTRACT.md)对两个差分 r1=f1-f2/2、r2=f2-f1/2 取得 cap 及证明，再从两份证明的同身份非负余量中提取共同部分。其形式为 mu_j=min(lambda_1j/c1,lambda_2j/c2)。因此即使某次支持界更紧，下一层可提取的共同关系仍可能改变。

[当前成功组件](../d214_parametric_relation_consumption_20261005/RESULTS.md)修复了一个真实的跨层控制，并证明了一段方向族的精确局部支持，但明确没有全网络精化单调定理。它改变有限支持演算，不改变原精确 HZ 图的具体化集合；通过的 4116 项数学检查也不是当前候选的真实 CNN 或逐家族回放。

本轮检查的假设是：把共同余量改成语义定义，而不从某一份证明字典提取，能否同时获得表示和组合优势。

## 最小公共尺度

设 S 为同一父 Neural-HZ 的共同赋值集合，保留全部原连续因子、二元相位、EQ/LE、共享身份和输入 decoder。f1、f2 是同一赋值上的预激活，q_i=ReLU(f_i)。设 c1,c2>0 为已经认证的上界 r_i<=c_i，其中 r_i=f_i-f_j/2。定义确定函数

```text
h(z) = max(0, r1(z)/c1, r2(z)/c2)
t*(z) = 1-h(z).
```

在 S 上有 0<=h<=1、0<=t*<=1。h 是满足 h>=0、r_i<=c_i*h 的逐点最小公共尺度；t* 是相应最大的共同余量。固定 f 和 c 后，它们不依赖 cap 证明的分解。它们不是独立噪声，也不允许不同消费者自行选择值。

由 f_i<=c_i*h+f_j/2、ReLU 的单调性与次可加性，得到

```text
q_i <= c_i*h + q_j/2
q_i <= U_i*h,  U_i=(c_i+c_j/2)/(3/4).
```

第二式也可由联立两条 f 的关系得到 f_i<=U_i*h，再用 U_i*h>=0。原零点双标签不受影响。

更一般地，M>=0、rho(M)<1、c>0、r=(I-M)f<=c 时，取 h=max(0,max_i r_i/c_i)。逐坐标有 q<=Mq+c*h，从而 q<=(I-M)^(-1)c*h。若 q_i>0，则 q_i=f_i、q>=f 给出第一式；若 q_i=0，右侧非负。逆矩阵非负给出第二式。这个 M-matrix 反馈结构的支持演算已在 [已有小反馈块定义](../d138_block_feedback_candidate_20261003/DEFINITION.md)讨论，不能重新算作本轮创新。

这些共同尺度行也不是新的最强逐点约束。恒有

```text
q_i-q_j/2 <= ReLU(r_i) <= c_i*h.
q_i <= (ReLU(r_i)+ReLU(r_j)/2)/(3/4) <= U_i*h.
```

所以 h 的潜在价值只能来自可计算的共享消费，而不是该行本身胜过所有已有关系。物化 ReLU(r_i) 也不是免费替代方案：它可能需要自己的相位与代价。

## 固定原相位后仍需要新的折线

取 x,y 属于 [-1,1]，f1=x+1/4、f2=y+1/4。两个差分的精确 cap 都是 13/8。

在 A=(3/4,1/4) 和 B=(1/4,3/4) 处，两原神经元都严格激活。两点分别有 f=(1,1/2) 和 (1/2,1)，故 h(A)=h(B)=6/13。中点 C=(1/2,1/2) 仍严格双激活，但 f=(3/4,3/4)，h(C)=3/13。

因此原相位固定为 (1,1) 后，精确图 (x,y,h(x,y)) 仍不是凸集：两个图点的中点不在图上。固定原 bits 后，仅增加连续辅助量和线性 EQ/LE 得到的是凸多面体，其仿射投影仍凸。故这种线性扩展不可能精确编码 h 的联合图。

这不是不可能性结论对所有 Neural-HZ 定义的外推。允许额外选择变量、真正的非线性生成元，或只在查询中消去 h，都可能表达它；但必须明确其语义与完整成本。不能声称原两位已经免费编码这个 max。精确无新选择的线性图表示至少要求 h 在每个原相位凸纤维上为仿射；本例违反该必要条件。

若只加入 epigraph

```text
0<=h<=1, h>=r1/c1, h>=r2/c2,
q_i<=c_i*h+q_j/2, q_i<=U_i*h,
```

则 h=1 对每个父赋值都可选。存在量投影恰好退回常量 feedback 和幅值行：必要性来自 h<=1，充分性来自直接选择 h=1。由此获得的是原约束的另一种线性写法，不是确定 h 带来的源精度。对 t* 只留 hypograph 时，t=0 是同一个问题。

## 更紧的 cap 也可能给出更松的公共尺度关系

仍使用上节的同一个父盒，真实两 cap 均为 13/8。比较两组可靠数据：

```text
旧 c  = (13/8, 13/4)
新 c' = (13/8, 13/8).
```

只收紧第二个 cap，没有更换源、性质、相位或证明来源。在 x=1/4、y=3/4 处，有 f=(1/2,1)、r=(0,3/4)，两门均严格激活。

| 数量 | 旧 cap | 新 cap |
| --- | --- | --- |
| h | 3/13 | 6/13 |
| 第一反馈中的 c1*h | 3/8 | 3/4 |
| U1 | 13/3 | 13/4 |
| 第一幅值上界 U1*h | 1 | 3/2 |

因此，证明分解独立并不等于对 cap 精化单调。一般地，c_i*h=max(0,r_i,(c_i/c_j)*r_j)：收紧另一个 c_j 可增大第三项。这个障碍来自共享归一化，不来自浮点病态或相位边界。

本反例只否定这项逐点关系的单调声明。它没有运行完整支持演算，也不证明保留所有旧关系后取最小值一定退化，更没有给出终端验证回归。原精确整数图的具体化仍不变。

## 一个尺度可消去但完整共享集合尚未闭合

若完整读出只含一个 h 且其系数 gamma>=0，令 H=(0,r1/c1,r2/c2)，则对同一个 S：

```text
sup_S [d(z)+gamma*h(z)]
  = max_k sup_S [d(z)+gamma*H_k(z)].
```

这是有限 max 与 sup 的交换；不是输入 split，也不是外部求解器。即使 H_k 已由前层非线性输出组成，该恒等式仍成立。若父查询只有健全上界而非精确支持，三个结果的最大值只提供健全上界。负 gamma 不能沿用这个 max 交换。

多个尺度同时出现时，正和的直接精确展开为

```text
sum_p gamma_p*max_k H_pk
  = max_(k1,...,kP) sum_p gamma_p*H_p,kp.
```

每块三个候选时，这种直接展开有 3^P 个组合；这是该展开方式的成本，不是所有可能算法的复杂度下界。逐块取标量上界再相加一般丢掉共同源依赖。简单例子是 x 属于 [-1,1]，h1=max(0,x)、h2=max(0,-x)：各自支持之和为 2，真实和为 |x|、支持为 1。共享残差 d 也必须先与完整方向合并，不能独立取界后补回。

单一原源 max-affine 形式也不在普通后继下闭合。取 x,y 属于 [-1,1]，

```text
f1=x+y/10
f2=x-y/10-1/2
q_i=ReLU(f_i)
g=q1-2*q2
h_next=ReLU(g)/2.
```

g<=11/10<2，故这里 2 是可靠正 cap。沿 y=0，x=0、1/2、1 时，h_next 分别为 0、1/4、0。该函数不凸，而有限个源仿射式的 max 必凸，所以它不再是原 x,y 上的单一 max-affine 载体。两门非平行、正常混权与普通 ReLU 已足够造成这个障碍。若引入原后继相位作条件、扩展到 max-min/DC 表达式或保留更多生成元，必须另外证明组合与查询成本，不能把嵌套计算图大小当成支持成本。

## 还不能替代当前的局部能力

对当前已证结构 f1=x+y/12、f2=x-y/12，c1=c2=5/8，有 U1=U2=5/4。对 r 属于 [52/67,1]，方向 q1-r*q2/2 可用第一 feedback 加 (1-r)/2 倍第二幅值行得到

```text
q1-r*q2/2 <= (5/8)*(2-r)*h.
```

父盒上 sup h=1，所以这条消费给 (5/8)*(2-r)。当前 D214 的已证精确支持为 13/12-11*r/24；前者大出 (1-r)/6，在 r<1 时严格更松。这只比较这条明确的消费，不声称已经穷尽新 max 原子的所有可能推理。它足以否定“更小的语义尺度自动保住当前消费能力”的说法。

## 查重和研究决定

原 HZ 已能精确表示 ReLU 网络，参见 [Ortiz 等](https://arxiv.org/abs/2304.02755)。max-affine 算子的神经网络组合已有系统研究，参见 [Balestriero 和 Baraniuk](https://proceedings.mlr.press/v80/balestriero18b.html)。连续与离散符号的函数像及多项式组合也是已有方向，参见 [Combastel](https://arxiv.org/abs/2009.07387)。这些来源支持先例边界，不代替本文的反例证明；本次仅据已读取内容使用这些一般结论，不声称完成新颖性综述。

另检查了保原相位的替代恒等式。令 D=diag(beta)、q=Df、n=q-f，定义

```text
K_i=sum_j M_ij*((1-beta_i)*q_j+beta_i*n_j) >= 0.
q = M*q + D*(I-M)*f - K.
```

它无需新 max 选择变量，也不含 cap。但 K_i 正是已有有向相位差异量的加权和：[早期相位研究](../d011_phase_value_audit_20260928/D011_RESULTS.md)已定义 q_j-beta_i*f_j，而[后续预算研究](../d012_phase_budget_20260928/D012_RESULTS.md)已证明独立乘积提升的投影不增益及一些公共参考组合的退化。该恒等式只是把这些量组成矩阵式，不另立新候选、不重复实现。

本轮拒绝把内禀单尺度直接升级为 Neural-HZ 定义：免费线性编码、cap 精化单调和全普通混权闭包三个关键主张均无依据，前述普通反例分别否定了相关强版本。保留其最小尺度公式与单尺度查询恒等式作为只读数学资料，而不是上线的第二路径。

下一项定义研究必须明确：在保留原相位与共同源的关系载体中，究竟保留了哪些跨层联合信息，如何按一条统一结构规则消费，以及在多个异质块、混权、活残差和下一 ReLU 后仍能得到什么有界代价的保证。只增加一个 max 节点、重写相位乘积，或重复旧反馈支持均不满足这个问题。需要新的可检验命题后再预注册实现，不为得到一次绿色测试而先造候选。
