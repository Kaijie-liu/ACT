# 通过已有激活节点传递原相位条件关系

本轮得到一个覆盖跨零旁路的有限前向规则：若两个原预激活在同一原相位关闭时相等，则它们经过相同激活后的差仍在该相位关闭时为零。对应节点必须已经存在于原网络，不能免费创建旁路ReLU。规则不识别两门的bits，尤其保留共同零点的不同合法相位。

这是函数同余的构造性应用及Neural HZ定义片段，不是已建立的新域或新不等式类别。它把D039要求已有ReLU(v)的特例扩展为匹配任一已证同关断面的原节点；局部组合范围有所增加，但公平总成本优势和真实适用性尚未证明。D040已否决其前序固定相邻源对在一个存档块上的新分组增强依据，不能将本纸面结果作为该块的替代成功。

## 保留原 latent 域的具体化

令H包含连续盒B_H、全部原二元域D_H、EQ/LE谓词P_H、原输出读出F_H、共享frame以及原输入decoder。二元域可以是{-1,1}或经明确重编码的{0,1}；下文alpha表示某个原门的{0,1}相位，转换及列绑定必须付费。

有限观察集Z保存原相位alpha与原坐标仿射读出E的配对，并附同源证明证书。定义片段为：

```text
gamma(H,Z) = { F_H(xi,b) : xi in B_H, b in D_H,
              P_H(xi,b),
              (1-alpha)*E(xi,b)=0 for every (alpha,E) in Z }.
```

所有E由同一份(xi,b)解释，不能分别存在量化另一输入。Z为空时精确恢复H；只准添加对原H有效的关系，因而整数具体化与decoder不变。以具体化包含定义精度预序；若需要偏序，须再商去具体化等价，不假设已有最佳抽象或完整格。这补齐了D039公式未显式写出的原连续盒与二元域，旧文件保持只读。

新关系的整数语义可编译回HZ，故“可编译”不是否决理由；同时仅给出这一元组也不是创新证明。原HZ本来具有共享非凸语义，待研究的是有限关系的生成、消费与查询。

## 已有门的同余传递定理

假设原网络已有t=ReLU(w)，并正向处理r=ReLU(h)。若同一原锚alpha的已证观察E_i满足有限精确恒等式

```text
h-w = sum_i c_i E_i,
alpha=0 => E_i=0,
```

则新增E_new=r-t仍满足alpha=0=>E_new=0。证明是在同一赋值下alpha=0推出h=w，再应用同一个确定函数。旁路可以跨零；证明不使用h、w的符号，不需要ReLU(v)，也不引入或合并任何原相位。旧两门在h=w=0时仍可以有不同合法bits。

这个证明也适用于两个节点使用相同确定激活函数的情况；下面幅值与终端公式仅为ReLU，不借此声称其他激活已有数值实现。

同锚观察仍对任意固定混合线性组合闭合。Conv是这些线性组合的结构化形式；Add/Concat必须先对齐共同frame和读出身份。新非线性观察只能通过已经存在的原节点对构造。节点不存在、恒等式未证或源身份不符时，不加入该观察，也不另外计算影子网络。

恒等式可由实际共享子表达式消去或显式有限线性证书获得。浮点系数接近、两个区间重叠或数值容差都不构成相等证明；BN等系数必须保留实际表达式或另有严格证书。寻找一个合适w也不是免费操作：下一候选必须预先固定由图结构决定的有限配对规则，不按标签、margin、LP状态或成功率选择，不进行所有节点的无界两两搜索。本文尚未实现或认证这个选择程序。

一种有限证书接口是为预先规定的block/port对保留h=v+sum(a_i*E_i)、w=v+sum(b_i*E_i)，逐source/frame身份核对共同v，随后取c_i=a_i-b_i。若每对实际读取S个规范稀疏项、引用m个观察，已排序时核对为O(S)，需要规范化则另付O(S log S)；从这些观察的可靠区间构造差界另付O(m)。有绑定来源的旧差界可直接复用，不能把获取它的成本从全流程中消失。此接口不解决全模块成员关系或语义等价搜索；无有限证书时不派生。

## 两行幅值接口与成本

若原h-w具有可靠全局界L<=h-w<=U，设Dplus=max(U,0)、Dminus=max(-L,0)。ReLU的单调性与1-Lipschitz性给出

```text
-Dminus*alpha <= r-t <= Dplus*alpha.
```

alpha=0由同余关系成立；alpha=1由全局差界成立。零点两种alpha选择都保留。结合原整数alpha，这两行精确表达该零面条件及原有效幅值界；在0<=alpha<=1下仅作为有效外包，不宣称完整联合凸包。

r、t若已有坐标，每条至多3个坐标nnz，总共2行6个nnz，不新建E坐标、bit或gate。若原坐标本身是latent读出，展开上界为2*(s_r+s_t+1)；原范围、重编码、EQ格式slack、源证明、solver工作区和decoder仍须计入。显式物化E会额外引入连续量和定义等式，不能隐藏其成本。

求L/U亦非免费oracle：已知精确系数时，可对有限差读出的每项使用同源可靠界及固定归约；区间系数和有符号E必须用可靠区间乘积或误差证书，不能套用D039对非负q的端点替换。这样的廉价界可能过宽，本文不宣称它总有实质收益。

若按统一规则生成R个观察、全部恒等式证书支持总量为C，则证书核对和行构造可按O(C+R)次有界标量/索引操作组织；这不包括寻找候选节点、生成L/U、位长、原网络传播或终端查询。观察可以在无未来消费者时结束生命周期，但这只丢弃已证冗余的辅助观察，不能删除原bits或源关系。尚无全网络固定宽度闭包定理。

## 跨零普通结构的强局部对照

源(x,y,z)属于[-1,1]^3，保留四个原门及bits：

```text
g=x,             q=ReLU(g), alpha
f=9*x/10+z/10-1/4, p=ReLU(f), eta
w=y+q/5-p/10,    t=ReLU(w), tau
h=y+2*q/5-p,     r=ReLU(h), beta.
```

f-g<=-1/20，故alpha=0时q=p=0。h-w=q/5-9*p/10在同关断面为0，得到r-t的同锚观察。两个混合消费者的旁路都是跨零的y；原网络没有ReLU(y)，但已有t足以供定理使用。预激活梯度和混合系数并不相同，不靠两个全局相同的滤波器合并门。

有p<=3*q/4，且9*q/10<=p+7/20，因此

```text
-19/40 <= h-w <= 7/90.
```

下界在x=z=1达到；上界在x=7/18,z=-1达到。前一不等式由f<=9*x/10-3/20及x<=1推出，后一由f>=9*x/10-7/20和p>=f推出；x<=0时q=p=0。这是纸面代数证明，没有运行相位枚举、求解器或采样。

令P为完整原前缀(x,y,z,q,p,w,t,alpha,eta,tau)的带标签联合凸包。比较系统再加入以整个连续P为源的最后一门(h,r,beta)完整带标签凸包，以及下面六对全部D020差分行。它不是整个真实网络的联合凸包。

唯一保留的修正版旧点为：

```text
x=-9/10, y=z=0, q=p=0, alpha=eta=0,
w=h=0, t=1/4, r=1/5, tau=7/20, beta=1/2.
```

它有完整两级构造见证。所有底层真实前缀固定x=-9/10,z=0、q=p=0、alpha=eta=0；下列只列(y,t,tau)：

```text
child active P point: (2/5,23/50,3/5)
 = (3/5)*(23/30,23/30,1) + (2/5)*(-3/20,0,0).

child inactive P point: (-2/5,1/25,1/10)
 = (1/10)*(2/5,2/5,1) + (9/10)*(-22/45,0,0).
```

两个P点的最后一门分别为(h,r,beta)=(2/5,2/5,1)、(-2/5,0,0)，各半混合恢复全部旧点坐标。底层源点均严格位于输入盒内部，所有底层原预激活均非零。凸化后的P允许分数tau，这一点不能偷换为原前缀的单个具体赋值。

对于任何门对i,j，记delta=g_i-g_j in [L,U]、d=r_i-r_j、e=d-delta。比较中四行是L*b_j<=d<=U*b_i和-U*(1-b_j)<=e<=-L*(1-b_i)。以下每对使用真实全局差界，原门bits保持一致：

| 门对 | 真实L和U | 旧d和e | d允许区间 | e允许区间 |
| --- | --- | --- | --- | --- |
| g,f | 1/20,9/20 | 0,-4/25 | 0,0 | -9/20,-1/20 |
| g,w | -2,15/8 | -1/4,13/20 | -7/10,0 | -39/32,2 |
| f,w | -9/4,13/8 | -1/4,81/100 | -63/80,0 | -169/160,9/4 |
| g,h | -2,47/20 | -1/5,7/10 | -1,0 | -47/40,2 |
| f,h | -9/4,21/10 | -1/5,43/50 | -9/8,0 | -21/20,9/4 |
| h,w | -19/40,7/90 | -1/20,-1/20 | -133/800,7/180 | -91/1800,19/80 |

除h-w以外，四个含y的差在去掉-y后对x,z单调不减，代入端点给出表中界；g-f为x/10-z/10+1/4。表中每行旧点均满足。h,w的e下界余量为1/1800，不忽略该最紧项。原q/p到t/r的逐边D036及D039整个q/p组的独立残差行在此旧点也只是r,t和负幅值非负：两个原父bits为0，相关余项界均跨零；没有额外排除它。

## 排除的是原输出坐标

新观察给出t-r<=(19/40)*alpha。加上原q门的q-x<=1-alpha，得到物理读出

```text
Z=(t-r)+(19/40)*(q-x) <=19/40.
```

旧点Z=191/400，比真实上界190/400大1/400。真实上界在(x,y,z)=(1,1/2,1)达到：q=1、p=3/4、t=5/8、r=3/20，各原预激活均非零。性质Z<=381/800有真实安全裕量1/800，而旧点违反1/800。这是有范围的纸面严格分离，不是已跑CERT、ADV或数据集增益。

本轮第一版取t=27/100，原以为同样通过六对差分行；独立复核发现它违反(t-w)-(r-h)<=(7/90)*(1-tau)：7/100>91/1800，故拒绝第一版强对照声明。本页只保留上述一次闭式修正版的正控，并完整记录这个错误；没有执行、筛选网络样本或反复数值搜索。

## GPU 查询接口与未获资格

将两行写为r-t-Dplus*alpha<=0和t-r-Dminus*alpha<=0。对应矩阵作用使用原读出gather；对两行乘子lambda_plus、lambda_minus，固定转置作用为：

```text
r:     lambda_plus-lambda_minus
t:    -lambda_plus+lambda_minus
alpha: -Dplus*lambda_plus-Dminus*lambda_minus.
```

随后通过原读出的转置算子累加。这是终端矩阵计算，不是网络backward/dual rescue。共享写入的舍入顺序、scatter冲突与原谓词双向作用都要认证，不能只实现新增六个坐标nnz便称终端已上GPU。

只读代码审查显示，当前SparseHZAffineExpr与ImplicitConv2DOp可提供源/frame/geometry契约，但实际实现仍为NumPy/SciPy CPU。IntervalTF的torch正负权Conv布局可借鉴，却没有自动给出所需向外舍入证书。历史device-affine性能叙述本轮未绑定到已合格实现，因此不继承其速度或正确性资格。

另一个必要数值契约是D039的组外残差：GPU若使用total减去组贡献，total必须包围同一批已存贡献端点数值之和，再对减去同一buffer端点的运算可靠向外舍入。不能从另一个舍入接收界减独立重算的贡献；否则可能把下界错误抬高。prefix/suffix排除归约是另一种需完整计费的实现选择，不是免费替代。

固定源pair的共有支撑归约、全部消费者贡献和组枚举分别计入D、F、G，总构造可设计为O(D+F+G)，但原算子、节点匹配、证据、完整物理存储、每轮终端查询、传输、可靠停止和具体见证仍另计。当前没有GPU执行、设备性能、终端求解或新增数值资格。D017初始化失败与D020跟踪被拒绝的旧版本均未重跑、绕过或提高预算。
