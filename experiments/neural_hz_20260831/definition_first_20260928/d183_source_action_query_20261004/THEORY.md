# 当前源作用与 Neural-HZ 查询语义

本轮从域元素的共同源与相位作用出发，检验一种精确源核心及其有限查询，不把增加 helper 或减少前端变量算作定义创新。得到一个完整父域上的正向查询对照，同时证实原生精确性不会自动传到聚合乘积松弛。下述八行包络属于已有 RLT 原理的投影，尚无原创新域、真实网络能力或完整成本优势；本轮不选择运行候选。

## 原生定义必须使用当前父状态

令 S 为当前父状态，保留原连续因子、原二元身份、EQ/LE、共同 frame 和原输入 decoder。原相位的 0/1 视图为 beta，不删除或连续化原 bits。当前预激活的一个认证分解为

```text
g = b + L z + r.
```

z 和 r 都是同一父状态的实际读出，而非从另一个合法输入取得的代理。C 包含该块全部保留消费者，包括需要的质量读出、旁路及历史谓词读出；不能漏掉一个消费者来缩小 C。如果某个原幅值仍独立被使用，相应读出也必须计入。

精确输出为 y=C D_beta g，原标签守卫仍作用于实际 g，在 g_i=0 时保留两个合法标签。固定结构系数 L 给出

```text
T(beta) = C D_beta L,
y = C D_beta b + T(beta) z + C D_beta r.
```

这属于 D001 的相位依赖生成元语言，不是新发现。允许有损替换时，可将最后的 r 换为同一个 t，要求一个认证关系 R(S,beta,t) 对每个完整父赋值均包含 t=r；新 y、全部消费者和声明保留谓词共同消费这一份 t。逐点取 t=r 证明原状态包含于新状态。这是 D142 的共同替换合同的实例，不是每个输出独立挑残差。

例如认证整个父状态上 ||r||²<=E_r，并给代理 ||t||²<=E_r。若 E_r=0，则 r=t=0，整个原生输出对所有合法父赋值和原相位精确。E_r>0 时不能因保留了精确核心就宣称整个块精确，也不能把父状态外包误说成只覆盖原网络真实轨迹。仅删除定义中的 r 而没有包含证书不健全。

## 精确核心排除旧代理但尚无新增能力

取 z 属于 [-1,1]²，五门结构为

```text
L = [(1,1/4); (1/4,1); (1,-1/2); (-1/2,1); (1/2,-3/4)],
b = (1/4,-1/4,1/4,-1/4,1/4), r=0,
C = [(1,-1,-1,1,1/2); (1,1,1,1,1)], tau=10101.
```

在 z=(0,2/5)，实际 g=(7/20,3/20,1/20,3/20,-1/20)，beta=11110，真实 packet 为 (3/10,7/10)。设 d=Lz、k=(3,0,1,0,-4)，旧 D180 共同代理可取 t=d-k/100，因为 Ck=C D_tau k=0，且

```text
||d||² = 23/50,
||t||² = 2183/5000 < 23/50.
```

代理 b+t=(8/25,3/20,1/25,3/20,-1/100) 保持严格原相位和全父域标量范围，却给 packet (7/25,33/50)。精确核心 E_r=0 排除它，且在这个零残差结构上对全父域精确，不只是修复此点。

但 C L 的行是 (-1/2,3/8) 与 (9/4,1)，行列式为 -43/32。故已有 D160 的源子空间限制 t=L eta 配合 Ct=Cd 已强制 eta=z，同样排除该例。这不是相对已有项目规则的新能力。p*k=4 小于 m=5 也不证明总成本下降。

## 整数相位不能使聚合乘积自动精确

T 的一个坐标是多个 bits 的加权和，不是单个 bit。其系数值即使来自整数 beta，也可能位于全局范围内部。因此用四条 McCormick 行替代 V=T*z，不会自动在整数原相位下精确。

一个非平行两源例为 z 属于 [-1,1]²、r=0，且

```text
L = [(1,1/4); (1/4,1); (1,-1/2)],
b = (1/4,1/4,-1/4),
C = [(1,-1,1/2); (1,1,1)].
```

在 z=(1/4,-1/2)，实际 g=(3/8,-3/16,1/4)，beta=101。真实 packet 为 (1/2,5/8)。第一输出的 T 行为 (3/2,0)，但第二个系数的全局范围是 [-5/4,1/4]。该系数为零时，独立四行包络仍允许其乘积在 [-3/8,1/8]；取 1/16，其余乘积取真实值，得到假 packet (9/16,5/8)。

原符号守卫、全局输出 caps 和 |第一输出|<=mass 均不排除该点。后继 ReLU(y_1-3*z_1/2-1/8-1/32) 在当前真实输入为零，在假状态为 1/32。这只证明指定聚合查询的逐源失配，不是全父域 CERT，也不声称该点通过 D180 的所有其他关系或原逐门幅值图。

因此必须分开记录原生乘积等式与线性外查询的具体化。一个有意有损且健全的查询不是错误；错误是宣称它继承了原生整数精确性，或把它的辅助赋值直接记为 ADV。

## 共同正负组的八行投影

对固定源坐标归一化 u 属于 [0,1]，考虑

```text
T = sum_i a_i beta_i = P-N,
P = sum_i max(a_i,0) beta_i,   Pbar = sum_i max(a_i,0),
N = sum_i max(-a_i,0) beta_i,  Nbar = sum_i max(-a_i,0),
V = T*u.
```

以下八行是不增加乘积变量的统一关系。第一组为 T 属于 [-Nbar,Pbar] 的普通包络，第二组保留其共同正负来源：

```text
V >= -Nbar*u
V >= T + Pbar*(u-1)
V <= Pbar*u
V <= T + Nbar*(1-u)

V <= P
V >= -N
V <= (Pbar-Nbar)*u + Nbar-N
V >= (Pbar-Nbar)*u + P-Pbar.
```

精确推导是引入两个仅用于证明的量 Uplus、Uminus，分别满足 P*u、N*u 的四行包络，并令 V=Uplus-Uminus。它们的可行区间分别是

```text
[max(0,P+Pbar*u-Pbar), min(P,Pbar*u)],
[max(0,N+Nbar*u-Nbar), min(N,Nbar*u)].
```

两区间之差展开恰为上述八行；反向任何位于差区间内的 V 都有对应 Uplus、Uminus。所以在给定 0<=P<=Pbar、0<=N<=Nbar、0<=u<=1 时，这八行是该双包络的精确投影，不是原乘积图的精确投影。此结论的作用域要求 Uplus、Uminus 除 V 定义外不再被其他消费者或谓词使用；逐输出分别消元不是对整个共享 lift 的联合精确投影。Pbar 或 Nbar 为零时同样成立，不需要除法或数值特例。原源区间宽度为零则直接代入常数，不作归一化除法。

当正、负各组内的 bits 分别一致时，各组量达到自身端点，包络恢复实际乘积。这包含某些 T 位于总范围内部的抵消情形。一般 mixed phase 仍不精确。完整逐坐标 beta_i*u 的共享 lift 蕴含这些行；但 k>1 时，这不等于已经证明普通 4m 逐门 beta_i*g_i 的 LP 松弛支配本查询。原整数精确 HZ 与其连续松弛也须区分。

## 非平行两源上的全父域正向对照

取完整父域 u,v 属于 [0,1]，原网络

```text
g1 = u+v-1/4, q1=ReLU(g1), original beta1,
g2 = u-v+1/4, q2=ReLU(g2), original beta2,
B = q1-q2/2, M=q1+q2,
h = ReLU(B-131/80).
```

两门非平行、带偏置且均 crossing。两个查询都保留同一原输入、全部原整数 bits、实际 g 上的弱符号守卫、相同全局标量范围和 B、M 消费者。采用的共同保守 caps 明确为 B 属于 [-5/8,7/4]、M 属于 [0,3]，由单门幅值范围 [0,7/4]、[0,5/4] 推得；不是免费给出真实联合紧界 B<=13/8。它们只在每个聚合乘积采用四行还是八行上不同；均不另给被替换的逐门精确幅值图。

八行查询在整个父域证明 B<=13/8。以下是定理的原整数标签分类证明，不是运行时分裂或逐相位枚举算法：

- beta=11：u 系数为 1-1/2，八行恢复 V_u=u/2；v 系数达到 3/2 的端点。故 B=u/2+3v/2-3/8<=13/8。
- beta=10：V_u=u，V_v<=1；原第二门守卫给 u<=v-1/4，所以 B<=u+3/4<=3/2。
- beta=01：V_u=-u/2，V_v<=1/2，故 B<=3/8。
- beta=00：所有乘积为零，B=0。

真实点 (u,v)=(1,1) 达到 B=13/8，因此是准确全父域上界。八行查询据此证明 h 恒为零，预激活上界为 -1/80。未声称放松原 bits 后该界仍由 LP 成立；原整数类型在此证明中不可省。

四行查询则在严格内部 u=4/5、v=19/20、beta=11 允许

```text
V_Bu=3/5, V_Bv=57/40, bias_B=-3/8, B=33/20,
V_Mu=8/5, V_Mv=1/20, bias_M=0, M=33/20.
```

实际 g=(3/2,1/10)，两个符号严格。以上值满足各自四行包络、保守全局输出 caps、M>=0 与 |B|<=M；后继采用其精确图仍得到 h=1/80>0。真实 packet 为 (29/20,8/5)，并非这个假状态。对照不免费加入相位条件的逐门幅值下界或更强联合像关系；它们可能早已排除此点。

这是相对明确弱查询的全域能力正控，不是新增正式 CERT、训练模型结果或超越原整数精确 HZ。该例 m=2、p=2、k=2，聚合已有四个乘积量，旧逐门只需两个；因此也不是完整成本胜例。

## 费用与跨层闭包的实际范围

对零残差核心，先写 z=ell+D_Delta*u、L'=L D_Delta、b'=b+L ell，其中 Delta 为非负源区间宽度。定义系数 a_rji=C_ri L'_ij。聚合有最多 p*k 个乘积量及 8*p*k 行。若 T、P、N 直接展开到原 bits，通常仍有 O(p*m*k) 系数构造和终端非零项。共享 T=C D_beta L' 与 S=|C| D_beta |L'|，再由 P=(S+T)/2、N=(S-T)/2 复用，只是显式分层；T/S 的定义、存储和消费都要计费，偏置相位读出使用 b'。

令 Ncoef=sum_i nnz(C_:i)*nnz(L'_i:)，L' 包含归一化宽度。一个直接共享构造增加最多3pk个连续量 T、S、V，2pk条定义 EQ及至多2Ncoef+2pk个系数非零，8pk条包络 LE及至多24pk个非零；另有p条输出 EQ、偏置读出及其费用。若内联 T/S、只存 V，可省相应变量和 EQ，但八行的展开账上界为4Ncoef+14pk个非零。这里不计的源、guards、输出状态本身及其他依赖不是免费项，也不声称这些上界就是最优编码。

公平旧参照每门只需一个 beta_i*(b_i+L_i z+r_i) 产品和约四行整数精确编码，不是 m*k 个产品。原 guards、源读出、EQ/LE、全部消费者、残差及其证书、变量界、normalization、终端转换、GPU可靠算术和解码均须计入各自完整账。

原生精确核心经 Affine/Conv、Add/Concat 使用同一潜变量环境；下一 ReLU 会再乘一个原 bit，导致相位表达增长。将输出换成新连续坐标可以继续仿射表示，但其定义关系不能同时被免费删除。采用上述线性外查询并产生一个健全联合 packet 后，可以用精确的后继 HZ ReLU 图继续外包；这是健全组合，不是原生精确关系的无损闭包或最终低成本证明。

共享源环境的另一项纸面方向是让少量结构固定非负相位权重共同消费整个源多面体及其补环境，替代独立坐标产品。它与 D140 的已有加权环境和 RLT 有直接重叠。只有给出有用的完整结构、可付费用和相对既有规则的净能力，才值得成为域候选；本轮不为它搭建通用 helper 框架。

## 完整源环境的正向控制与已有边界

另行检查已有源 perspective 原理，不将它并入上述八行构造。取同一个父源三角形 P={u>=0,v>=0,u+v<=1}，两门为 g1=u+v/2-1/2、g2=u/2+v-1/2，B=q1-q2，Q=q1+q2，活旁路 J=B-u/2，后继 h=ReLU(J-1/40)。四种严格原相位均可达，两门不平行且 crossing。

保留共同观察 W_i=beta_i*(u,v)，对整个 P 及补环境各传播三行。第一门满足

```text
W_1u+W_1v <= beta1, W_1u <= u,
q1=W_1u+W_1v/2-beta1/2 <= W_1u/2 <= u/2.
```

结合 q2>=0 得 J<=0，因此全父域 h=0。这六条 source perspective 行共14个系数非零，替代两个独立坐标乘积的八行、16非零；这是相同 W 与原 bit 下的局部比较，未包含原图、输出、guards或后继费用。只看盒坐标乘积确实会漏掉三角形约束被共同消费的关系，但 simplex perspective 本身是经典数学。

在普通盒父域 [0,1]² 上，相同两门也有 q1<=u，于是改用 J=B-u、h=ReLU(J-1/40) 得全域零值。完整源盒 perspective 等于逐坐标原 bit 乘积包络；作用来自共同 W 跨消费者复用，不能归给不存在的额外盒关系。此例的便宜强对照直接保留已有 source-aware 行 q1<=u 即可得到同样结论，不需要整套提升。上述两例都是正向结构控制，仍不证明新域创新或值得实施。

这个盒例还可精确区分查询松弛。给双方原八条逐门关系、同源盒与物理 q1、q2。旧聚合四行在 u=1/10、v=2/5、beta=(1/5,1/2)、q=(1/5,0) 可取 w_B=(1/20,0)、w_Q=(3/20,2/5)。它满足原门 LP 和聚合包络，而 J=1/10，后继 h=3/40；共同 W 的上述证书排除它。这里 beta 仅是终端连续松弛中的视图，不是将原域 bits 变为连续，也不是原整数 HZ 的反例。

T 内联时，两套接口均增加4个连续量、16 LE及2 EQ；聚合接口的 LE/EQ 非零分别44/12，共同源接口分别32/8。加共同源盒与原门行，两边都是8连续、2原 bits、28 LE及2 EQ，系数非零为80与64。这里 q1、q2 是物理量，B、Q 用表达式读出；后继、界元数据、证据、decoder 等相同部分另计。这个明确局部费用正控不抵消更便宜的 q1<=u 对照，也不是实测时间或真实大模型的收益。

一个后续可反证假设是：实际重复结构能以少量结构固定权重复用完整源环境，付清 guards、旧 bits、余项及全部消费者后，在完整成本可付时仍给出既有廉价关系没有提供的后继界。本轮没有证明这样的真实接口存在，不把这个假设升级为用户的新硬限制。

## 文献对照与研究决定

[Adams、Forrester、Glover 的原文第 2.1 节及定理 3](https://leeds-faculty.colorado.edu/glover/fred%20pubs/339%20-%20Enhancement%20for%20Linearized%200-1%20Quadratic%20w%20Adams%20%26%20Forrester.pdf)区分二元变量乘整个仿射式的四行精确编码、仅保持目标最优值的删行，以及由最优对偶信息获得的紧凑 RLT 目标界。论文没有因此提供本项目所需的无对偶、全消费者前向等价变换。这里仅借鉴已知线性化原理，不导入其优化算法。

本轮建设性成果是明确的全父域查询正控、投影证明和原生语义与查询的分界，不是新颖性结论。研发目标不要求比已整数精确的原 HZ 表达更多集合或更精确；应证明适合普通神经结构的新关系组织，在可付完整成本下带来实际新增证明或 validated ADV。反过来，也不能把旧 RLT 行族换名认作已经提出强大 Neural-HZ。

下一研究假设须同时说明共同源信息怎样保留、原非凸相位怎样参与、跨层怎样消费以及终端怎样查询。当前八行子结果留作对照，不升级为主算法，不启动新数值运行；目标继续保持定义优先。
