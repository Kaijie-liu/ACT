# 共同神经关系的廉价静态参照

本轮将上一轮的联合容量正控压到一个更强、更便宜的比较基线：在已有第二门自身源矩的前提下，只增加一条五非零系数的线性行，就能证明上一轮的整盒物理性质。不需要完整相位表、跨输出乘积、相位共现量或运行时 helper。这一结果同时否决了“只要排除上一轮假点就证明新域创新”的判断。

这是经典条件凸性和 RLT 的具体消元推导，不是已完成的新 Neural-HZ。新定义可以借用这些原理，但必须进一步证明其关系组织、组合变换或完整成本的实质优势，不能只换名，也不能反过来要求所有组成数学都必须原创。

## 本轮判断与保持的目标

上一轮完成了容量充要式、反例和一层联合图定理，改变了研究对象，归为 progress。本轮继续定义研究，完成廉价静态关系、物理投影证明、跨相位守卫消元和原始文献对照。没有数值执行或真实网络收益；没有重跑旧数学测试、模型解码或新后台作业。

目标仍是保留原连续源、全部二元非凸因子、EQ/LE、共享身份及输入 decoder 的强 Neural-HZ，支持普通神经结构并在真实验证中净增益。GPU、smooth/Transformer、CIFAR/Tiny、新家族、同路径完整回放均未完成，不缩小目标。不得用这里只得到的查询强化替代定义创新。

## 两条条件下界及其精确局部消元

同一父状态中，g_i=a_i^T x+b_i、q_i=ReLU(g_i)，原 bit 为 beta_i。另一个原 bit beta_j 的源观察记为 v_j=beta_j*x，定义 h_ij=a_i^T v_j+b_i*beta_j。原生 beta 保持整数；以下期望记号仅解释查询松弛中的共同矩，不引入随机输入假设。

原图及其任意真实混合必满足

```text
q_i >= h_ij,
q_i >= g_i-h_ij.                         (J)
```

证明是 q_i>=g_i 和 q_i>=0 在 beta_j 及其补事件上分别成立。若显式引入 r=E[beta_j*q_i]，只考虑四条下界

```text
r>=0, r>=h_ij,
q_i-r>=0, q_i-r>=g_i-h_ij,
```

存在 r 的充要条件就是 q_i>=max(0,h_ij)+max(0,g_i-h_ij)。由于右侧等于 max(0,g_i,h_ij,g_i-h_ij)，在已有 q_i>=0、q_i>=g_i 时，恰只剩 (J)。这是所列四条下界的精确消元，不是整个 RLT 系统的精确消元；若 r 有上界、其他消费者或不同事件的一致性约束，不能忽略它们后删除 r。

在原生整数点上，v_j=beta_j*x，(J) 已由原 ReLU 语义蕴含。全部旧点及零激活合法标签均保留；改善的是分数查询关系，不是比精确 HZ 表达更多集合。

对一般父 HZ，只要 v_j 和 g_i 的绑定与界正确，上述关系仍健全。它不要求源为独立盒，也不要求 COVER；但用独立 McCormick 界生成 v_j 不会自动给整个受约束父域的精确凸包。

## 在保留原像的情况下消去门外源矩

设源已逐坐标准确规范化到 [0,1]，某些 beta_j*x_k 已存在，其他坐标暂未提升。对未提升项，原生乘积及其标准 McCormick 松弛满足

```text
max(0,x_k+beta_j-1) <= beta_j*x_k <= min(x_k,beta_j).
```

若 a_ik>0，上界可静态选择 a_ik*x_k 或 a_ik*beta_j；若 a_ik<0，上界可选择 0 或 a_ik*(x_k+beta_j-1)。加上已经保留的共享源矩和偏置，任一这种固定选择给出 h_ij<=Hbar_ij，因此

```text
q_i >= g_i-Hbar_ij                       (P)
```

是健全的静态联合行，完全不必为那些门外源新增乘积量。对 h_ij 的下界也可对称生成另一类行。

每个固定选择只是完整投影的一部分；不能称为完整凸包或随意从父域删除原始源。选择必须由预注册数学结构与固定顺序给出，不能观察 terminal 点、margin、公开标签或求解状态后更换。若保留全部选择，行数可能指数增加；使用上图辅助量又需支付对应成本。这里不授权动态分离。

## 一条行即证明上一轮的完整物理性质

沿用上一轮的普通两门网络：

```text
x1,x2,z in [0,1], y in [-1,1],
g1=x1+x2-1/5-(6/5)z, q1=ReLU(g1),
g2=y+z-2/5,          q2=ReLU(g2).
```

令 beta=beta2，保留第二门自身已有的 v_y=E[beta*y]、v_z=E[beta*z]，以及

```text
q2=v_y+v_z-(2/5)beta.
```

在 h12 中，用 E[beta*x1]<=x1、E[beta*x2]<=beta，可得

```text
h12 <= x1+(4/5)beta-(6/5)v_z.
```

因此 (P) 只需一条显式行：

```text
q1 >= x2-1/5-(6/5)z-(4/5)beta+(6/5)v_z.       (R)
```

它有 q1、x2、z、beta、v_z 五个非零系数，没有新变量或新 bit。这里的零新增是相对已有自身源矩的比较口径；原来的变量、矩包络、读出等式和原 HZ 成本不能漏记。

对整个父盒而非某个辅助见证，定义 F=2q2+x2-y-2z-q1。代入 (R) 与 q2 等式：

```text
F <= 2v_y-y+(4/5)(v_z-z)+1/5 <= 6/5.
```

最后一步用 v_z<=z，以及 v_y<=beta、v_y<=y+1-beta 相加得到 2v_y-y<=1。这正是原自身源包络的后果。

上一轮的点 (x1,x2,z,y)=(1/10,9/10,1/2,0)、(q1,q2)=(1/5,31/40) 给 F=5/4。它可以通过完整单门 hull 的交集，但不能通过新增关系后的物理投影，隐藏矩也不能重新选择绕过证明。下一原门 ReLU(F-49/40) 的整盒输出因此恒为零；旧点却允许 1/40。

这保留了全部原源和物理消费者，既不是辅助变量上的孤立冲突，也没有对真实网络输入采样。但是两门完整联合 hull、完整低阶 RLT 或同一条静态物理证书也能做到；该例不再适合作为定义新颖性的单独证据。

## 一般费用及组合边界

若所有 k 个事件都有 d 个源矩，完整矩载体是 k*d 个连续量；标准盒包络最多 4*k*d 行。已有自身源矩必须复用而非重复计费。对结构选定的有向门对集合 E，(J) 的增量为 2*|E| 行；若 g_i 有独立物理坐标且 h 内联，保守 nnz 上界为 sum_((i,j) in E)(2*nnz(a_i)+5)。缺失源矩、它们的界、物化 h 或 g 的定义、父谓词、共享存储和 decoder 另计。

式 (P) 可以避免门外源矩扩张，但会选择性放宽。每项费用随实际源支持展开，不可按门数冒充源规模；不能从矩阵乘法形状直接宣称有证 GPU 加速。

保留这些行后，同一赋值上的 Affine、Conv、Add、Concat 会保留已经取得的物理约束。对下一 ReLU，可以继续健全保留旧行；但是要新生成下一 bit 对旧输出的条件观察，通常仍需要 beta_new*q_i 或等价关系。旧 D035 的两层见证说明，原源均值、旧源相位矩甚至相位共现量都不能免费恢复这个量。因此本轮没有证明深层闭包，也没有把旧证书穿过一个后继零门说成一般可扩展性。

## 原始研究对照

[Anderson 等人的盒源 ReLU 表述，第 5.2 节](https://optimization-online.org/wp-content/uploads/2018/11/6911.pdf)是完整单门参照：一般是指数条行，但具有高效分离规则。比较不能把它降格成只看预激活区间的三角形；本项目没有借入其动态分离算法。

[k-ReLU](https://proceedings.neurips.cc/paper/2019/file/0a9fdbb17feb6ccb7ec405cfb85222c4-Paper.pdf)研究多门联合凸松弛；[PRIMA 第 3.1 和第 5 节](https://arxiv.org/pdf/2103.03638)通过 Split-Bound-Lift 构造联合关系，明确涉及局部激活区域划分。其凸包近似子过程的多项式复杂度不能当作一般无分区的紧凑精确联合域结论。本轮借鉴数学比较，不执行该划分流程。

[Qiu 与 Yildirim 的 RLT 研究，第 3.1 节](https://link.springer.com/article/10.1007/s10107-024-02070-7)讨论约束乘积和线性化。本文 (J)、跨守卫矩和所附消元均属于这种既有机制的神经结构实例。原始 Sherali–Adams 论文页面本轮根进程访问失败，没有把失败页面冒称完整核读；本稿的公式另有独立推导和纸面复核。

内部 D035 已有两 bit 共享源与消费者投影；D195 已有固定事件上的共同源和守卫；D014、D191 已有源容量和合取事件的相关接口。仿射 circuit、单负 hinge 支持、Attention 方向也进行了只读定位，分别已有 D007/D011、D068/D069 和 D124/D127 等记录，本轮未把它们重启为新实验或重复报新。

## 下一候选必须真正改变什么

本轮不把一个 RLT 行族包装成已经提出新非凸域，也不为它另建运行时 helper。该廉价参照必须进入后续比较，避免构造一个昂贵完整相位表只解决同一性质。

具体未解决对象是“跨层事件下的共同幅值”：如何让同一事件对多个旧 ReLU 输出的观察，在混权卷积及残差的全部消费者中统一保存和消元，同时无需恢复逐事件全幅值表。候选可以使用已知 RLT、凸性和容量原理，但必须额外给出适用于普通重复结构的组合或精确消元定理，并支付产生、传播、终端和重构的全部费用。只有这些条件形成可反证、可实现的定义后才进入新的默认关闭预注册组件；不能用更弱参照或较小测试人口制造优势。
