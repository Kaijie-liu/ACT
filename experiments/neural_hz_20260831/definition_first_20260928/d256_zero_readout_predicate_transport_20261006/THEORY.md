# 局部相位关系对完整惰性读出的保守延拓

本轮证明一个改变真实接入选择的结论：已验证的局部关系可以通过“值恒为零但携带谓词”的HZ项交给完整惰性读出，不必先把所有分支读出展开，也不必要求某个core包含所有其他source的谓词。真正需要的蕴含方向是完整共同状态包含该局部source的前提。零项的线性读出链可以精确折叠，但它携带的谓词不能删除。

这修正D255 SOURCE_ENTRY提出的过强设计前提，不修改D255冻结合同或既有验证门。本页为一般证明与源码推导，没有运行候选、构造数值试验或原模型，不授予新增数学组件或真实来源资格。这是语义接入结果，不是独立新集合类或已成立的PLDI贡献。

## 共同潜变量与联合读出

令v=(xi,beta)，其中全部旧连续因子xi属于[-1,1]^n，全部旧signed binary beta属于{-1,1}^b。每个原source s有EQ/LE谓词P_s(v)及读出h_s(v)。列身份来自同一已认证的全局frame；frame整数相等本身不构成身份认证。

所有当前live读出为

~~~text
Phi_j(v) = bias_j + sum_t L_jt h_s(j,t)(v),
P_live(v) = AND_s P_s(v),
Gamma_live = { (Phi_1(v),...,Phi_k(v),decoder(v)) : P_live(v) }.
~~~

这里s覆盖全部登记的可达source以及共同状态已经登记的必要谓词；L_jt是有限、形状正确、内容和来源已认证的纯线性链。bias_j完整保留。其他消费者、skip、稳定读出、deferred状态和decoder不因某个当前查询不使用它们而被删掉。

单个读出按其自己局部谓词产生的外包，可能大于完整共同状态的投影。因此本页的等价对象是同一完整联合图，不声称每个单独branch的原松弛集合都逐一相等。

## 局部延拓可以提升到完整共同状态

取已认证局部source S，前提为

~~~text
P_live(v) => P_S(v).                                      (1)
~~~

D255在其支持的原生门关系上给出新的连续辅助u和存储谓词C_S(v,u)，保留原位与所有旧变量，且证明

~~~text
for every integer-phase v with P_S(v),
there exists canonical u=f_S(v) in its registered box
such that C_S(v,u).                                      (2)
~~~

向外舍入后的辅助解不必唯一，也不必都是精确相位乘积；这里只使用canonical延拓的存在性。

定义增强共同状态

~~~text
P_live_plus(v,u) = P_live(v) AND P_S(v) AND C_S(v,u).
~~~

则严格有

~~~text
project_v { (v,u) : P_live_plus(v,u) }
    = { v : P_live(v) }.                                 (3)
~~~

证明：左到右由合取直接成立。右到左，给定满足P_live的原v，(1)给P_S，再由(2)取canonical u。因此任意完整原联合读出和decoder均可原值延拓；增强状态的任意合法整数解投回v仍满足完整原谓词。原binary不pivot、不删除，也不连续放松。把所有Phi和decoder继续解释为只读旧v的函数，即得到完整联合输出集合相等。

(1)最容易静态认证的情形是S本来就是完整live表示的可达source，且其实际内容和列身份与D255 snapshot的来源一致；另一种是完整P_S各行在共同状态中的精确内容membership。不能仅凭相同frame、形状、相似范围或口头“同源”声明授予(1)。

关键是不需要P_S => P_live。当S本来就是可达source、(1)已成立时，再要求P_S => P_live是额外且不必要的覆盖要求；脱离此前提，两个相反蕴含一般不可比较。保留其他原source并由原有merger继续合取即可；不必先构造一份全输出矩阵来证明(3)。如果S不属于共同状态、也没有(1)证据，拒绝添加，不能用一个更强但无来源的P_S暗中删掉合法输入。

## 零值项承载谓词

以增强局部HZ的全部连续列、原二元列和P_S AND C_S为谓词，另给它严格零的一维读出：c=0，Gc/Gb均为空稀疏矩阵。称这个状态为Z_S；它的零值不表示谓词为空。

对n维读出Phi_j，追加一个值项0_(n by 1) Z_S。值仍为Phi_j；由于HZ算子的共同frame语义还要合取所有source谓词，其完整状态增加P_S AND C_S。因此它正好实现(3)中的局部延拓，而不修改Phi_j的任何真实系数、bias、稳定支路或skip。

在数学联合tuple中，一次合取已经足够；软件的不同消费者可能分别materialize和查询，不能假定一个consumer的anchor会自动出现在另一个consumer中。实现必须保证每个需要消费增强关系的live读出都能到达它，或者经一个已证明的共同owner消费。仅修改某一core对象的变量名不等于旧lazy terms的引用已经更新。

同frame多个局部关系C_i可以一起加入，条件是它们只依赖原v且辅助u_i的身份各自fresh：对每个i取f_i(v)，即可同时延拓全部约束。如果共享辅助列，则必须证明所有关系使用同一个canonical值，或另外证明共同可行性。各自存在性不够：u=x和u=-x分别对每个x可延拓，但若错误共享同一u，合取会删去所有x不等于0的点。

后继分配器必须先在完整frame高水位统一预约这些新连续列，再发布增强状态；仅在矩阵上pad到最大宽度不能防止下一ReLU或rebase重复使用它们。binary宽度和原身份不变，失败不得发布部分预约或半批anchor。

## 零读出链的精确折叠

设某source的实际存储读出严格为零：全部c等于数学零，Gc/Gb没有任何存储非零项。对形状正确、有限且已经认证的纯线性链L_r ... L_1，有

~~~text
L_r ... L_1 h_S(v) = 0
for every v satisfying P_S.
~~~

故可以把该term的整条读出链替换成最终形状的直接零映射，但仍保留source S的全部谓词、因子与相位。表达式的bias另存，必须原样保留；不是把整个仿射表达式改成零。

此规则按严格零结构统一触发，不依赖模型、实例、margin或求解状态；不使用容差或近零阈值，也不尝试由未验证谓词猜测某个非零存储读出恒零。所有source/算子的类型、形状、frame、有限数和内容认证仍必须做，不能借0乘算子而绕过无效输入检查。

这同时区分两种不同操作：折叠零项的值计算是等价变换；删除零项连同其谓词通常不是。原生产线性映射本来就保留谓词，本规则没有增加另一种求解器或救援路径。

## 普通非凸例子说明为何不能删除零项

令xi属于[-1,1]，beta属于{-1,1}，原谓词为

~~~text
xi >= 0,
xi <= 1 + beta,
xi <= 1 - beta.
~~~

取完整读出E=(xi,beta)。由xi <= 1-|beta|=0，原整数集合是(0,-1)与(0,1)，仍然非凸，全部原因子与二元位保留。新行xi<=0对每个原整数点有效，不删除任何原解。

把这条有效行作为零值anchor的谓词加入E后，整数输出不变。原LP松弛却允许(xi,beta)=(1,0)，而anchor排除它，故xi的松弛上界从1降到0。若编译器因anchor值为零而删除整项，就会丢掉这项增强。

该例只是纸面等价与反例，说明语义义务，不是实际执行结果或新增CERT。证明使用原binary的代数性质；候选没有枚举相位、split或调用求解器。

## 代价结论及限定

当前lazy materialize从最终row mask反向组合。若初始零映射Z为N by 1，后接已驻留的普通稠密W（N by N），朴素顺序先形成I_N W的N平方项，再与Z相乘归零；在已认证严格零source上，直接保谓词的零映射只需N+1个CSR row-pointer项及必要对象元数据。N可以是普通层宽，不依赖极端浮点数或病态矩阵。

这仅省去该零值链不必要的组合和中间结果。W的既有存储、有限性/身份校验、真实非零消费者、expr.bias传播、source谓词扫描、合并、辅助列、输入重构和终端仍须全额计费。若现有公共prefix缓存已经复用了某次组合，不能再把那笔共享计算重复记成收益。

未实现的后继不应只在tf.apply返回后规范化，因为deferred和phase-selective分支可能在同一次apply内部先materialize。最小规范化时点是每个相关materialize入口的reverse-prefix统计与反向组合之前；每次append之后更早规范化是可选方案，不是新增必要门槛。旧链的引用、形状和存储检查费用依旧存在。这是接入完备性要求，不是已经完成的hook。CPU/GPU均可使用该代数零规则，但本文没有GPU执行或加速证据。

## 新颖性与资格

共同潜变量、谓词合取及零线性映射都在既有HZ语义内；局部延拓的提升证明没有建立新集合类。项目内的新结果是纠正接入所需的蕴含方向、给出不展开完整读出的关系载体，以及保留谓词的零链规范化和其明确代价边界。这些可以支撑D254/D255关系进入真实网络，但不能替代Neural-HZ定义创新、实际网络净收益或完整端到端证明。

完整4257项数学人口与原门保持不变；本轮没有运行它们，也没有新增或删减测试。正式1870/2413、独立61/400和所有真实模型/GPU/new-domain资格均不变。
