# 保留共同谓词余量的域内关系闭包

本候选针对 D208 已复现的跨层精度缺口：父域已经能证明的关系，下一层生成关系时却退回独立幅值盒。本轮研究让同一个非凸元素生成、保存并消费非负谓词余量。它不是外部 helper，也不查询失败 LP、对偶解或不可行证书。

这是待实现的 Neural HZ 关系演算，不是已证明的新集合类。保留精确图加上有效关系仍可由普通 HZ 表达；新颖性和真实完整成本优势均需后续证明。单独修复 D208 的顺序特例只是必要前提，不能作为完整定义创新的终点。

## 元素与具体化

元素拥有一个共享 source frame、原连续因子和 signed binary 相位、全部 EQ/LE、出生有序的 ReLU banks、精确 alias 定义、全部可见仿射读出和原输入 decoder。新增的是同一谓词 frame 上的余量身份与可复用证书，以及由这些证书生成的关系块。

具体化仍由一个共同赋值同时满足所有因子界和所有谓词，再通过读出映射得到。二元变量只能取 -1 或 +1；beta=(sigma+1)/2 不改变类型。原 HZ 通过空 ReLU banks 和所给源谓词嵌入。新增关系必须在整个当前父元素上成立，不能仅在原网络样本或选中相位上成立。语义包含定义精度，不声称最佳抽象或完整格。

所有原 graph rows、相位身份、零点双标签、alias EQ 和 decoder 都保留。候选不删除、pivot 或放松二元因子。Affine/Add/Concat 使用同一因子身份先合并系数，独立 siblings 不允许静默合并。生产默认保持关闭。

## 余量身份与证书

对每条保留的 LE，定义 theta=rhs-lhs；对每条 EQ，定义 e=rhs-lhs。原因子上下端点也各定义一个非负余量。它们只是原共同赋值上的仿射读出，不是独立新自由量；原整数相位不因其盒界参与证书而连续化。

一次域内查询对完整读出 F 返回一个上界 c，并保留精确恒等式

```text
c-F=sum_j lambda_j*theta_j+sum_k nu_k*e_k,
lambda_j>=0.
```

证书引用真实父谓词和因子身份；nu 允许任意符号。生成或使用时须认证 frame、前缀、支持范围、LE 系数非负和完整有理恒等式。不能仅信任用户给出的数值上界、未认证证明字典或数组 shape。

已有三种固定查询全部保留，另增加一个共同余量闭包查询。四种每次均完整计算和计费，按固定顺序取最小上界，平局取最早证书；不是失败后 rescue，也不按实例或终端结果选择域。证书选择只是同一个预先定义的 support 运算。

## 固定查询的证书递推

逆出生替换 alias 时，用其原 producer EQ 保留准确残差。正系数的 crossing gate triangle 是原两条 upper graph slack 的非负组合；负系数使用 q>=0。稳定门用原 graph 强制的 q=f 或 q=0，保留所有相位，不把 signed 系数随意截断。

对同一 pair 的完整方向 w，D138 固定系数 v>=0 满足 t=(I-M)^T v-w>=0，因此

```text
v^T h-w^T q=sum_i v_i*(h_i+M_ij*q_j-q_i)+sum_i t_i*q_i.
```

每个 h slack 再展开为原 active-upper slack 与对应 constant/source-phase row slack 的非负组合。最后的源或原相位盒取界同样记录端点余量。于是总证书由整个查询的逐步恒等式相加得到，无 LP 或系数优化器。

新生单调关系未必属于旧连续 LP 的 Farkas 闭包：它的出生健全性依赖原整数 ReLU 语义。必须保存其独立的已证 ReLU 转移前提，作为新的合法 LE；随后查询才能将它当作非负余量。不能伪造为旧 LP 已有行的非负组合。

## 统一出生规则

按原 bank 顺序配对相邻位置，固定 a=b=1/2，只使用同一个完整父状态；未配对门和所有稳定门仍保原图。对每对 crossing 门，固定查询两条完整差分 r1=f1-f2/2、r2=f2-f1/2，得到 c_i 与认证证书。所有查询发生在新 bank 之前，禁止循环认证。

令 k_i=max(0,c_i)。若任一 c_i<=0，统一取 s=l=1。已知单调性、次可加性和正齐次性给 q_i<=q_j/2+k_i；特别 k_i=0 时保留真正的跨门顺序后果。该普通结构情形不是数值异常补救。

若两 c_i>0，按同一 theta 身份取

```text
mu_j=min(lambda_1j/c1,lambda_2j/c2),
t0=sum_j mu_j*theta_j.
```

从完整父因子可靠盒对合并后的 t0 求上界 B=max(0,box_upper(t0))，支付全部展开费用；这只是证书外包，不替换非凸父域。B>0 时 tau=min(1,1/(2B))，B=0 时 tau=1；令 s=1-tau*t0、l=1-tau*B。逐系数非负比较和原 EQ 给出 r_i<=k_i*s 且 1/2<=l<=s<=1。B=0 在合法父域上只产生 s=1，没有免费精度。

这个共同余量依赖所选证书和规范身份，不声称语义最大性。它不把更紧 cap 直接混入旧 D205 自由盒公式；证明来自保留的原谓词余量。

## 关系生成与消费

令 U_i=(k_i+k_j/2)/(1-1/4)。保留以下关系，每门五行，共十行：

```text
q_i>=0,
q_i<=U_i*beta_i,
q_i<=U_i*(s-l+l*beta_i),
q_i<=k_i*beta_i+q_j/2,
q_i<=k_i*(s-l+l*beta_i)+q_j/2.
```

这些行在 k_i>=0、可靠正尺度下均对真实 ReLU 扩展有效，包括 k_i=0；不将零 cap 的有效性夸大为未经证明的局部理想凸包定理。可以只复用与已有行完整相同的新行身份，不能删原行或将两个不同上界少计为一个 min 运算。

结合原 f_i>=-ell_i 与 active-upper，闭包查询使用

```text
h_i=k_i*(l*f_i+ell_i*s)/(k_i*l+ell_i),
M_ij=ell_i/(2*(k_i*l+ell_i)).
```

crossing 门 ell_i>0 保证分母正；h_i>=0，M12*M21<=1/4<1。用同一 D138 公式消费，再与全部父源和残差贡献合并并向前缀递推。k_i=0 给 h_i=0、M_ij=1/2，不需要特殊求解路径。若两者均零，所选反馈纤维只能有零幅值，原 bits 仍保留。

旧三种证书和原关系继续保留，新增第四种不是另一验证器。对选中反馈纤维的局部精确 support 不能外推为完整非凸域的精确 support；全量零回归与真实网络晋级仍须独立验证。
