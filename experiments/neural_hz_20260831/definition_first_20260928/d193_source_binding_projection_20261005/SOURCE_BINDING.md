# 精确同源半径仍不绑定神经幅值

本轮直接检查 D192 定义的缺口：把常数误差界改成实际父源的仿射函数，能否保住有用的幅值关联。结论是否定的，即使该函数恰为真实距离，三个普通 crossing 门也会允许错误后继输出。这不是极端数值例，也不证明其他有损 Neural-HZ 不可行。

## 候选与无乘积编码

保留整个父域、连续源、全部原 signed bits 的 0/1 视图、原 guards、EQ/LE、共享身份和 decoder。固定一个原 anchor a，b=beta_a；完整消费者 C 不遗漏任何活读出。假设在整个当前抽象父域上认证

```text
|g_i-g_a| <= r_i(theta) <= R_i, r_i(theta)>=0.
```

用同一规则定义 e_a=0、0<=e_i<=r_i(theta)*|beta_i-b|，Y=b*C*g+C*e。真实 ReLU 仍有规范扩展 e_i=(beta_i-b)*g_i，故出生变换健全。原标签保持整数，不创建输入或相位子问题。

保留逐项 e 时，上界不需要新乘积变量。在原 bits 整数及已认证 0<=r_i<=R_i 的前提下，它等价于

```text
e_i>=0,
e_i<=r_i(theta),
e_i<=R_i*(beta_i+b),
e_i<=R_i*(2-beta_i-b).
```

相同 bits 时一个相位上界为零；不同 bits 时两个上界均为 R_i，剩余有效上界为 r_i。这是已知二元支撑编码，不宣称新的数学原理。仅这部分就有 4(m-1) 行；加原 2m guards 及 p 个 b*(Cg) 四行产品，共 6m+4p-4 LE，尚未计源展开、输出、后继、界和证据。

消去 e 时，分数 LP 的每项容量变成三个仿射式的 min。其沿完整消费者法向的正权和不是免费的单个仿射 RHS。D192 的常数两行公式不能直接套用。

即使所有 r_i=alpha_i*r(theta)，某方向半径仍是 r(theta) 乘以多个原 bits 的加权和。该和一般不是 bit；对两个有范围的连续因子使用四行乘积包络，只是有损查询，不是原整数关系的精确替代。

## 全父盒的严格后继反例

取 x,y in [-1,1]，三个非平行或不同偏置的门为

```text
g_a=x-1/2,
g_2=x+y/10+1/2,
g_3=x-y/10+1/4.
```

三个门均 crossing。精确距离在整个父盒中都是正的仿射式：r_2=1+y/10、r_3=3/4-y/10；可取 R_2=11/10、R_3=17/20。完整读出是 M=q_a+q_2+q_3、D=q_2-q_3。

在严格内部源点 x=y=0，原相位 beta=(0,1,1)、b=0。候选 e=(0,9/10,3/10) 满足精确半径、相位支撑、所有幅值非负、inactive 为零、q>=g 和可靠幅值上界，给出

```text
candidate (M,D)=(6/5,3/5),
actual    (M,D)=(3/4,1/4).
```

在整个父盒上 g_2-g_3=1/4+y/5>=1/20，已有 ReLU 有序 sector 关系给 D<=1/4+y/5。因此真正的后继

```text
h=ReLU(D-y/5-7/20)
```

恒为零，余量至少 1/10；候选却在上述点允许 h=1/4。这个伪输出不是 ADV。旧关系只需一条 D-y/5<=1/4，即 1 LE、2 个变量系数；不能把补回该已知行算成新定义能力。

这区分了“半径来自同一源”和“幅值由该源绑定”：前者已满足，后者仍未建立。下一步不能只继续收紧这些距离常数。
