# 两个完整输出仍可能需要指数多精确 LP 投影行

本记录限定检查一条修复路线：精确保留原逐门四行 LP 的全部源绑定关系，然后消去幅值。它不要求任何新 Neural-HZ 必须保留该 LP，不是所有域的复杂度下界，也不否定有损定义、常数比例压缩或强于该 LP 的新关系。

## 已有精确公式与真正的分支变量

固定父状态和分数相位 beta 时，旧四行给

```text
ell_i=max(0,g_i),
u_i=min(U_i*beta_i, g_i-L_i*(1-beta_i)),
q_i in [ell_i,u_i], Y=C*q.
```

原 guards 保证区间非空。共同 C-box 像可以按几何法向取支持，但支持本身随父状态及 beta 分段。这一 min/max 公式已见 D152/D155，不是本轮新发现。

对正权 w_i，令 Delta_i=g_i-L_i-(U_i-L_i)*beta_i，则

```text
sum w_i*u_i = sum w_i*U_i*beta_i + sum w_i*min(0,Delta_i).
```

真正控制展开人口的是保留父关系中 Delta_i 的共同分支组合，不是源的线性秩或输出个数。若整个被比较的 LP 能认证 Delta_1<=...<=Delta_m，确有 m+1 个前缀候选；只知道 g_i 有序不能推出该排序，因为原 beta 也参与 Delta。这个前缀恒等式是已有有序 min/sum 机制，不作为新颖性结论。

## 普通两源族与二维完整消费者

对 m>=2，取 x,y in [-1,1] 和

```text
a_i=i/(10*m), b_i=1/10+a_i^2/10,
g_i=x+a_i*y+b_i,
r_i=1+a_i, L_i=b_i-r_i, U_i=b_i+r_i.
```

所有门 crossing，法向不平行，且 g_i-g_j=(a_i-a_j)*(y+(a_i+a_j)/10) 在父盒中变号；没有可免费调用的全局 pair order，也不是同一门的比例复制。系数有理、位长随 log(m) 增长，未利用极端数值。

固定实际源点 x=y=0。原 guards 在 beta_i=1/2 附近严格成立，且

```text
ell_i=b_i,
u_i(beta_i)=min((b_i+r_i)*beta_i,
               r_i+(b_i-r_i)*beta_i).
```

两上侧分支在 beta_i=1/2 相交，那里区间宽 (r_i-b_i)/2>0。因此可在每个 beta_i 的左右小邻域独立选择分支，而 q 区间保持正宽。

取完整 C_i=(1,t_i)，t_1<...<t_m 为固定有理数，例如 t_i=i/m。选一个固定几何法向 n=(-t_1,1)，则 n*C_1=0，w_i=n*C_i=t_i-t_1>0 对所有 i>=2 成立。

对集合 S subset {2,...,m}，有有效仿射上侧行

```text
n*Y <= sum_(i in S) w_i*(b_i+r_i)*beta_i
       +sum_(i not in S, i>=2) w_i*
            [r_i+(b_i-r_i)*beta_i].
```

每一行都在相应 beta 开区域取到：S 内 beta_i<1/2，其余 beta_i>1/2，取 q_i=u_i 对 i>=2；q_1 在自身正宽区间内部自由变化。参数 (beta_1,...,beta_m,q_1) 到 (beta,Y) 的线性秩为 m+1，所以等号集合有维数 m+1。

目标投影在 (beta,Y) 中有维数 m+2：beta 可独立局部变化，固定 beta 时 C 的两个独立列及正宽 q 区间给二维输出内部。故上面每一行都定义真正的 facet。不同 S 在某个 beta_i 上的斜率相差 2*w_i*r_i>0，因此共有至少 2^(m-1) 个不同 facets。

结论：即使几何上只有至多 2m 个输出法向，精确保留这个旧 LP 的无辅助量有限线性投影也至少需要 2^(m-1) 行。增长来自法向 RHS 的源与分数相位组合，不是因为网络有指数多个整数可达相位。本例的真实源仍只有两个维度。

## 少量连续辅助量的限定权衡

现在允许等价的有限线性扩展式，在同一 (beta,Y) 上有 k 个额外自由连续量、R 条 LE。所有 bound 行计入 R；在被比较 LP 中放松的额外 binary 也属于这 k 个量，不能靠隐藏离散分支避开计数。EQ 可先消去，剩余有效辅助维数不超过 k。目标须与上述完整连续 LP 投影相等，而不是仅在整数 beta 上相等。

写辅助系数块为 G。经典线性消元的非负消去乘子锥为

```text
K={lambda>=0 : G^T*lambda=0}.
```

这是 pointed 锥。极射线的非零支撑至多 rank(G)+1<=k+1，否则该支撑上的零空间维数至少二，可以作保持非负的双向小扰动，违背极性。同一最小支撑至多确定一条极射线。所有投影不等式由这些射线生成；在目标相对仿射包内，每个 facet 至少需要一个这样的生成不等式。因此

```text
2^(m-1) <= sum_(j=1..min(R,k+1)) choose(R,j).
```

若 R<=C*m，C 为固定常数，则 k=Omega(m)。先由总子集数得 R>=m-1；若 k+1>=R/2，结论直接成立。否则二项尾界给 sum choose(R,j)<=(e*R/(k+1))^(k+1)；当 k=o(m) 时，其对数为 o(m)，不能覆盖 (m-1)*log(2)。常数依 C 而定。

这是经典消元与正依赖计数在本例的应用，不是新的通用扩展复杂度定理。它不证明 k>=m，不排除线性规模下常数因子的变量节省，也不适用于非线性原生查询、有损域、增加强结构关系后的不同目标集合或只要求整数图等价的表示。

## 对本项目的具体意义

不要从 D192 的少量二维方向，推出 source-bound 精确修复同样便宜；也不要用一个 min/sum DAG 的点值计算量冒充整个父域的终端查询费用。这个反例不证明真实 CIFAR/Tiny 满足这些自由度前提，不用它替代真实结构检查或关闭项目。

下一条有价值的结构假设应明确约束 Delta 的共同变化，或提出带可证明损失的不同原生关系，再与完整旧路径同信息比较。原源、全部原 bits、EQ/LE、共享身份、decoder、fail-closed 和完整晋级门不变。
