# 两个原相位上的关系压缩及适用边界

本轮审查了一个容易误报的方向：固定两个原相位后，关系能否以固定阶数跨任意深度传播。结论是可以健全传播，但一般形式已属于条件 RLT；额外的相位支配只压缩同一个松弛，没有证明新增物理精度。因此下述定理保存为支撑成果，不据此建立新的主要候选或宣布 Neural-HZ 定义创新完成。

## 共同条件关系

保留完整原 HZ H、全部连续源及原 signed bits、EQ/LE、共享 frame、全部消费者和 decoder。alpha、beta 是其中两个原 bit 的0/1视图，不是新增选择位。delta=alpha*beta 的新列仍为连续列，并由原整数相位精确确定。

四个代数质量记为

```text
lambda11=delta,
lambda10=alpha-delta,
lambda01=beta-delta,
lambda00=1-alpha-beta+delta.
```

这是同一元素上的条件观察代数，以下比较不运行四个相位子问题、搜索相位区域或创建点池。不过，它明确属于两个固定事件的完整条件提升，不能隐瞒这项条件化费用。

若初始共同源仅使用 phase-independent 外包 x in [0,1]^d，为每个坐标保留 A=alpha*x、B=beta*x、D=delta*x。四个源量为 `D,A-D,B-D,x-A-B+D`，各满足 `0<=x_cell<=lambda_cell`。含 delta 共3d+1个新连续量、8d+4条LE、26d+8个nnz。

这不是完整非凸 H 的条件凸包。原 H 仍全局保留；若要提升其额外纯源行，每条EQ或LE需四份条件行和全部展开；若原行含其它 bits，还需相应条件观察。不能把这些成本藏在3d之内。

对任意新原门 `q=R(f)`、原 bit eta，完整固定两事件接口保留六个量：alpha*q、beta*q、delta*q，以及alpha*eta、beta*eta、delta*eta。它们与未条件化 q、eta 给四个条件幅值 q_cell 和相位质量 eta_cell。若全父域上已认证 L<0<U，则每个条件保留

```text
0<=eta_cell<=lambda_cell,
q_cell>=0, q_cell>=f_cell,
q_cell<=U*eta_cell,
q_cell<=f_cell-L*(lambda_cell-eta_cell).
```

每门新增六列、24条LE。f_cell 由实际 affine/Conv/Add 的全部已登记条件输入线性组合，偏置乘同一个lambda。固定事件集下，这种已知提升本来就可健全传播到任意深度；它并不保证全网理想性或任意真实分布可由少量矩唯一恢复。

## 支配事实给出的精确商

若已对完整父域认证 `eta<=alpha`，并且强参照包含该事实在四个条件上的提升，则两个 alpha-off 条件的 eta_cell、q_cell 恒零。所有相关矩可由两个新量恢复：

```text
v=beta*q, zeta=beta*eta,
alpha*q=q, delta*q=v,
alpha*eta=eta, delta*eta=zeta.
```

alpha-on 两个条件的幅值为 v、q-v，相位为zeta、eta-zeta。生成两份四行门关系，共8LE；两个off条件仍须各保留 `L*lambda_cell<=f_cell<=0`，共4LE；相位质量四界 `0<=zeta<=delta`、`0<=eta-zeta<=alpha-delta` 再付4LE。合计每门2列、16LE，局部变量nnz保守上界为 `35+2*sum_cell nnz(f_cell)`；偏置、源定义、原门和所有终端展开另外计费。

上述代换与恢复互为线性映射，保持同一完整条件系统的全部消费者和物理LP投影。它每门少4列、8LE，但没有新增强度。如果强参照只有全局均值行eta<=alpha，而没有它的条件提升，就不能声称同一投影；新增提升带来的强化须单独计为既有guard/RLT信息，不能归功于压缩。

若只认证 `q=alpha*q` 而非原 bit 支配，不能套用相位商。尤其off条件允许f=0时，原新bit可能仍合法取1；强行令它为0会删掉合法零标签。

## 多层混权残差族证明前提并非空集

原共同源 x,y,z in [-1,1]，q=R(x)、p=R(y)，分别绑定alpha、beta。令a0=a(-1)=q、b0=b(-1)=p，并逐层定义

```text
a(k+1)=R(.60*a(k)+.45*q+.10*b(k)-.08*b(k-1)
           +.05*x-.08*y+.05*z-.35),
b(k+1)=R(.55*b(k)+.45*p+.12*a(k)-.07*a(k-1)
           -.07*x+.06*y-.04*z-.36).
```

归纳上界分别不超过.98和.93，故全部幅值在[0,1]。alpha关闭时a所有既有同支路幅值为零，下一预激活至多.10+.08+.05-.35=-.12；beta关闭时对应上界.12+.07+.04-.36=-.13。严格负余量保留全部零标签并证明新bit蕴含对应carrier。

在x=1,y=-1,z=1时，a递推为R(.60*a+.28)，始终严格正；反向源x=-1,y=1,z=-1时，b递推为R(.55*b+.26)，也始终正。故这些不是全部稳定门。存在正负跨层权重、原源skip及非平行输入；可完整保留如 `2*a-3*b+.17*x-.09*z` 的混号消费者。余量为严格不等式，小幅系数扰动仍成立。

这只证明压缩定理有普通多层适用族，不证明实际训练CNN匹配，更不把此族当成新的能力阳性。一般宽层版本也可用 `h=q_owner+sum W_i*q_i+s*z-1/2`，在全幅值<=1、正权和加||s||1严格小于1/2、同owner负权绝对值和小于1/2时归纳证明。

## 无支配时两个观察不能免费替代六个

下面两份分布全部由真实网络点组成，只作为摘要信息不足的数学证明，不进行运行时采样。四个(alpha,beta)组合各有质量1/4，取x=(2alpha-1)/2、y=(2beta-1)/2，并定义

```text
h=z+x/10-y/10, q=R(h), 原bit为gamma,
r_ab(+)=1/2+(1/10)*(-1)^(a+b),
r_ab(-)=1/2-(1/10)*(-1)^(a+b).
```

对两份分布分别用r_ab作为格内gamma=1的比例。gamma=1时h=1/2；gamma=0时 `h=-r_ab/[2*(1-r_ab)]`，即-1/3或-3/4。取z=h-x/10+y/10，则全部原源严格在[-1,1]^3内部，没有零预激活，全部八种原相位都可达。

每格Eh=0，所以两份分布有完全相同的四条件原源一阶矩。所有单事件原源矩（包括gamma的源矩）、全部相位pair矩，以及Eq、E(alpha*q)、E(beta*q)也相同：Egamma=1/2，E(alpha*gamma)=E(beta*gamma)=1/4，Eq=1/4，E(alpha*q)=E(beta*q)=1/8，E(gamma*x)=E(gamma*y)=0，E(gamma*z)=1/4。

但 `E(delta*gamma)` 分别为3/20、1/10，`E(delta*q)` 分别为3/40、1/20。下一实际混权skip门

```text
t=R(q+R(x)+R(y)+x/10-y/10-5/4)
```

在这些真点上恰为delta*gamma/4；两份均值分别为3/80、1/40，差1/80。缺失联合观察确实可被实际后继读出，不能从已有均值免费恢复。

这不是可排除的假点、CERT或ADV，也不证明深度必然无限升阶：一般六观察接口已给固定成本的健全外包。它只否定无支配时仍无损使用二观察压缩，呼应旧D035/D175的组合边界。

## 研究归属与下一判断

条件乘积属于已有RLT机制；[Sharp Hybrid Zonotopes 第二节与第四节](https://arxiv.org/html/2503.17483v2)已给HZ中的提升及原整数语义保持。本轮没有借入其完整层级、任何相位搜索或外部求解器，也未证明超出该强参照的新精度。

因此固定两carrier的深度闭包不能单独作为主定义创新，支配商也归入支撑库。真实推进需保留共同源及新门联合关系，并证明新的精度或完整查询优势；不能把增加经典乘积、换名或低估源成本当成果。新执行仅限[冻结的缓存前提诊断](PREREG.md)，不是本定理的可执行候选资格。
