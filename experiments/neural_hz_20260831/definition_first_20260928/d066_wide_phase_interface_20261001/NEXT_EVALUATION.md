## 三种比较及其声明边界

B0为相同source和receiver的旧独立范围。B1保留同样四状态上下表，但每个消费者拥有独立delta_j；同一消费者上下侧仍共用它自己的delta_j。B2由全部64消费者共用同一个原相位对delta。B2对B1的加强不能直接称作相对原HZ的新增能力。

可不解LP获得表系统的严格比较证书。固定诊断alpha=beta=1/2、delta范围[0,1/2]；该诊断不用于选择实例、改变候选或切换规则。每表每侧写成a+kappa*delta，其中a=(T10+T01)/2。仅在四个状态盒均非空时，独立消费者投影恰为

```text
I_j = [a_lower+min(0,kappa_lower/2),
       a_upper+max(0,kappa_upper/2)] intersect original_receiver_interval.
```

若所有I_j非空，对不同消费者的上/下facet统一写成z_i<=A_i+kappa_i*delta，其中z_i可以是r_j或-r_j。对kappa_i>0、kappa_k<0，共同delta要求

```text
(-kappa_k)*z_i+kappa_i*z_k <= (-kappa_k)*A_i+kappa_i*A_k.
```

分别取I_j、I_l中使对应z最大的端点；若严格违反，两个值在B1各自可行却在B2不相容，其余消费者取各自区间中点即可。这是显式有理数表系统证书，不是具体网络反例。状态盒为空时不套用这条投影公式，不据不适用项删除人口或原bits。

该诊断必须另外标记native_nonredundancy_verified=false。升级为原HZ非冗余，需同一原变量上的完整见证，逐项满足旧源、readout等式、EQ/LE、原门松弛和比较所用标量界；声称完整双门hull对照还需共同源凸组合见证。现有表端点本身不提供这些事实。

## 两个可证明的无增益子类

若任一锚bit由严格正/负原事实固定，delta已唯一，B2与B1没有共享delta方面的差别。触零界不能强制原零点的标签。接收门稳定只意味着clamp无新的非线性作用，不能一概否定其输入已有联合关系。

若全部非锚residual在用于比较的整个共同源域D上均可由稳定性化为同源仿射读出，完整双锚source与bit凸包的共同分布已满足所有前表和精确后继的上表；若后继在同一真实父图域上也稳定，上下两侧均被吸收。不能仅凭原网络更窄可行集上的stable标记就断言该前提成立，否则父凸包见证可能经过不满足那些额外原约束的源点。此否证不扩展到一般非线性residual，也不自动证明较弱native LP中的冗余。
