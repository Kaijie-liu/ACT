# 保留共同源的宽层相位关系接口

本候选将 D065 的共同相位观察及其前向变换落实为默认关闭的可执行关系接口。种子使用上一轮 literature_mechanism_test_20261001/AUDIT.md 的宽混合层证明，不把其他门先压成相互独立的 residual 区间。它属于待评估的 Neural HZ 关系语言片段；共同相位 lift 属于已知 Cayley/RLT 机制，不宣称已形成新域或 PLDI 新颖性。

## 域语义与变换

元素为完整原 HZ H 与有限关系集合 T。H 含连续源盒、全部原二元相位、EQ/LE、共享 frame、原读出和输入 decoder。每条关系使用两个不同原相位 alpha、beta、一个原物理读出 E，以及四状态端点 L_st、U_st。具体化要求同一原赋值在其状态 st 下满足 L_st<=E<=U_st；观察为空时精确嵌入原 HZ。

对已证明有效的观察，每个原 HZ 赋值仍满足全部观察，所以投影回原输入、相位与输出精确等于 H。原 bits 不删除、不替换为连续量，零点所有原合法标签保留。同 frame 上以具体化包含取语义序，不承诺最佳抽象或完整格。接口承载与传播的只是有限关系摘要，原 HZ 仍承担完整非凸语义。

同锚关系的 Affine/Conv/Add 按真实系数符号逐槽合成区间；同一 readout 的重复项必须先按原身份合并。Concat 保留条目、frame 和锚身份，不创造独立源副本。ReLU 将四个端点逐槽应用 max(0,z)，同时保留新门的原 bit 和原图谓词。原整数赋值上的健全性由逐点区间包含归纳得到，不能外推为任意层无损闭包。后继的具体模型拓扑和原列认证仍由调用者证明，数学 token 不是模型证书。

同一原相位对的所有消费者共一个连续辅助 delta，使用四行 0<=delta、delta<=alpha、delta<=beta、delta>=alpha+beta-1。上表展开 E<=U00+(U10-U00)alpha+(U01-U00)beta+kappa*delta，kappa=U11-U10-U01+U00；下表反向同理。整数时 delta 唯一等于 alpha*beta。不同相位对不共享 delta；原模型中没有的新 bit 不得生成。

某个条件状态的 L>U 可能仅表示原状态不可行；不为此删除原 bits。只有数学前提/身份/资源未证时拒绝候选。终端输出是具名 LE 描述，不是已经认证的 native 安装器或 LP/MILP 决策。

## 宽混合层的统一种子

同一可靠源盒 D 上，g_k、v 仿射，原门 q_k=ReLU(g_k)，F=v+sum w_k q_k。先构造点态仿射上界 S_k>=ReLU(g_k)。记正负权重 w+、w-，共享缓存 B=v+sum w+S 与 H=sum w-g。固定不同原锚 i,j，C=-w_i+S_i-w_j+S_j，则

```text
P00=B+C
P10=B+C+w_i*g_i
P01=B+C+w_j*g_j
P11=B-H+w_i+*(g_i-S_i)+w_j+*(g_j-S_j).
```

非锚负项 N*=sum w-*ReLU(g) 同时不小于零和 H*=sum w-*g。前三状态使用前者，11使用后者，并代入原锚 q_i=alpha_i*g_i，得到各平面有效。每槽取同一个完整盒 D 上的仿射支持，不执行状态子域求解或四个子网络。对 -F 以同锚生成下界。符号、稳定性和零权重只进入该统一公式，不按模型身份或 LP 状态选规则。

准备阶段验证所有原门，建立 B、B-H；每锚对只修改两个锚的稀疏支持，先合并共同坐标再取绝对值。固定互不交的原 slot 对在所有项出现数上给出线性算术日程；padding 无原相位，后续真实适配须保留其人口记录且不制造 bit。组件提供指定锚索引的数学操作，真实人口选择器必须预注册为固定结构规则，不能由该 API 推断允许挑阳性实例。

## 可靠系数与相位

对参考中点 affine 的全盒界 l<0<u，固定 M=2^24，lambda=floor(M*u/(u-l))/M，S(g)=lambda*g+(1-lambda)*u。稳定非负时 S=g，稳定非正时 S=0，零界无需除法。若 S* 为精确 secant，则 S-S*=(u/(u-l)-lambda)*(u-g)，介于零和 (u-l)/M 之间；这是相对 secant 的额外松弛，不是相对 ReLU 的总 gap。缓存和锚扣回使用同一个 S。

原参数是区间时，参考锚必须使用实际原 bit：w_actual*ReLU(g_actual)-w_mid*alpha_actual*g_mid 的绝对值不超过 rho_w*M_actual+abs(w_mid)*eps_g。非锚用 ReLU 的 1-Lipschitz 性质得同形误差；加上 v 的误差，将总 E 加到每个上槽、从每个下槽减去。无需假定实际门和中点门同相位，也不能用中点模型代替原模型。

全部 Fraction 输入及中间结果仍受512位限制。量化避免引入任意 secant 斜率分母，但原参数及累加仍可能超限，失败即拒绝；不是普遍位复杂度保证。

## 精度对照与完整成本

固定解析主控为 D065 的三源三父门、两个混权后继及两个新 ReLU，保留全部精确边际界、三个完整双门凸包见证及最终物理 Z<=13/2。该控制证明共同表强于独立处理相同表，不证明强于完整前缀凸包、QC 或全部已有方法。新增宽符号 fixtures 检查缓存支持与直接全源展开一致。

一个锚对 m 个双侧观察需要一个辅助量、4+2m行，已有物理坐标时局部最多8+8m nnz。全原 HZ、源证据、实际 latent 展开、界、slack、decoder、构造和原生终端求解另计。逐表独立消元不能替代共同消元的所有异号交叉行。关系数量跨层累计，不因每条只有四槽就成为全网常数空间。

GPU目标日程为源稀疏 affine、消费者 B/H 聚合、锚局部支持修正、四槽混权乘加与 ReLU、共同 delta 行的 gather/scatter。此原型用 CPU exact Fraction 作为可靠参考；没有执行设备 kernel、可靠舍入或GPU终端查询，不能记 GPU 资格。后续 GPU 实现必须与同一语义逐项对照，并支付主机设备共存、转换和传输，不将 CPU 回退隐藏为全面GPU。

若真实宽层无非冗余或完整成本无法支付，该候选停在支撑库；不能靠这个接口名称把原 HZ 加相同行重新命名成创新域。正式进展仍需真实结构净收益与既定完整保旧回放。
