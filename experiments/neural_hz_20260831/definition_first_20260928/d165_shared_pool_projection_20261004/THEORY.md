# 共享 ReLU 与池化关系的精确投影及其边界

本记录证明有条件的 ReLU–MaxPool 共同投影，特别是重叠窗口如何保留同一份幅值见证。它保留原整数标签和原 LP 投影，不增强该参照的 LP 能力；变量减少也不保证非零系数减少。因此这是可复用的精确算子支撑结论，不是已经成立的新 Neural-HZ 定义，更不是 CIFAR/Tiny 能力突破。

## 原关系与适用前提

所有仿射预激活 g_i 读取同一组原始源、latent 和保留谓词。已知健全界 l_i <= 0 <= u_i。原 ReLU 标签 beta_i 为二元数；以下证明也覆盖 beta 的 [0,1] 松弛。m 个待消去幅值 q_i 满足：

```text
q_i >= 0
q_i >= g_i
q_i <= u_i beta_i
q_i <= g_i - l_i(1-beta_i)
```

P 个非空窗口 W_j 共享这些 q。设 J_i={j:i in W_j}，每个待消去 q_i 的 d_i=|J_i| >= 1。原池化编码已有二元 one-hot 标签 delta_ji，每个窗口 sum_(i in W_j) delta_ji=1。给定健全的非负 M_ji，令 D_ji=M_ji(1-delta_ji)。原池化关系为：

```text
p_j >= q_i                  for i in W_j
p_j <= q_i + D_ji           for i in W_j
```

M_ji 必须来自整个原关系的有效界，保证 delta_ji=0 时不误删合法点；本证明不提供新的界求解器。原 source/bit bounds、共享身份和其他不读取 q 的 EQ/LE 原样保留。不存在未计入的 q 旁路、跨 q 谓词或直接读取 q 的旧 decoder。若有额外读取，必须一同投影或保留对应 q，不能只看输出当前是否使用它。

这是一套明确声明的数学参照，不等于当前生产 MaxPool 已拥有这种 HZ 编码。若原实现使用比较树标签，不能未经标签映射证明就换成 one-hot；若创建新的 MaxPool 算子，新增选择标签的契约也须另行证明。

## 共同区间定理

固定所有保留变量后，定义：

```text
L_i = max(0,g_i)
U_i = min(u_i beta_i, g_i-l_i(1-beta_i))

q_i in [
  max(L_i, max_(j in J_i)(p_j-D_ji)),
  min(U_i, min_(j in J_i)p_j)
]
```

在上述无其他 q 耦合的前提下，原系统存在一组共同 q，当且仅当下列约束全部成立：

```text
l_i(1-beta_i) <= g_i <= u_i beta_i                 for each i
p_j >= 0                                         for each j
p_j >= g_i                                       for each incidence (j,i)
p_j <= u_i beta_i + D_ji                          for each incidence (j,i)
p_j <= g_i-l_i(1-beta_i) + D_ji                    for each incidence (j,i)
p_j-D_ji <= p_k                                  for each i, distinct j,k in J_i
sum_(i in W_j) delta_ji = 1                       for each j
```

证明：一个闭区间非空当且仅当所有下界都不超过所有上界。L_i <= U_i 化成两条相位守卫，其余两项由界符号及 beta in [0,1] 自动成立。L_i <= p_j 给出非负行和 g_i 下界；p_j-D_ji <= U_i 给出两条上界；不同窗口间剩余的比较正是 p_j-D_ji <= p_k。同窗口比较由 D_ji >= 0 自动成立。以上已枚举全部组合。

反向见证可统一取：

```text
q_i = max(0, g_i, max_(j in J_i)(p_j-D_ji))
```

每个共享叶子只重构一次，供所有窗口共用。所有原 beta、delta 不变。整数侧 q_i 被原 ReLU 图强制为 max(0,g_i)，零预激活的两个合法相位和池化并列选择都保留。分数侧这只是一个可行 LP 延拓，不是具体网络 ADV。原输入因子与其 decoder 没有删除；最终反例仍须经原具体网络和性质验证。

由于等价性也覆盖 beta、delta 的连续松弛，任何只读取保留变量的相同下游线性约束和目标，其 LP 结果与原系统相同。减少 q 不能被记成 LP 强度提升。

## 不能省略跨窗口约束

普通三源盒 (x,y,z) in [-1,1]^3，取 g=(x+1/4,y-1/4,z+1/4)。在源零点选择 beta=(1/2,0,1)，原 ReLU 松弛给出：

```text
q_1 in [1/4,5/8], q_2=0, q_3=1/4
W_a={1,2}, W_b={1,3}, all M=5/4
p_a=1/2, delta_a=(1,0)
p_b=1/4, delta_b=(0,1)
```

两个窗口各自的投影都允许此点，但第一个要求 q_1 >= 1/2，第二个要求 q_1 <= 1/4，不存在共同见证。被遗漏的行是 p_a-D_a1 <= p_b，实际为 1/2 <= 1/4。所有实际 g 均非零；反例来自分数相位下丢失共享联系，不是极端零值或数值误差，也不声称这是整数网络反例。

## 完整局部费用

令 s_i=nnz(g_i 中全部父状态变量的系数，不含常数项)，S=sum_i s_i，Sd=sum_i d_i s_i，E=sum_i d_i，X=sum_i d_i(d_i-1)。以下是 l_i<0<u_i、M_ji>0、各变量身份不重合、内联仿射系数的未合并逻辑账：one-hot 等式算一行，RHS 不计矩阵 nnz。共同源变量、源谓词、bit boxes、额外输出界和证据空间须另外同口径计入。稳定门、零系数和冗余合并后的实际 nnz 可能更少，不用下表代替实际编译账。

| 关系 | 连续幅值 | 原 bits | 行数 | 矩阵 nnz |
| --- | --- | --- | --- | --- |
| 原顺序系统 | m+P | m+E | 4m+2E+P | 2S+6m+6E |
| 完整共同投影 | P | m+E | 2m+3E+X+2P | 2S+2Sd+2m+P+8E+3X |

行数差为 sum_i d_i^2 - 2m + P。重叠窗口可能使行和 nnz 都增长。重复行可以在实际编译时合并，但不能在纸面费用中假定免费消失；如果保留 g 的中间列避免源系数内联，也必须把这些列、定义等式和转换费用计入。

单窗口特例：旧 6m+1 行、2S+12m nnz；新 5m+2 行、4S+10m+1 nnz。例取 x,y in [-1,1]，g_1=x+y/4+1/4，g_2=-x/3+y-1/4，界分别为 [-1,3/2]、[-19/12,13/12]，共同 M=3/2。含两个源变量，旧 5 连续、4 bits、13 行、32 nnz；新 3 连续、4 bits、12 行、37 nnz。少列和少行没有转化成稀疏性收益。

这里没有端到端耗时、GPU、终端峰值内存或保旧能力证据。单靠局部计数不能晋级。

## 保留标签不能被函数值恒等式代替

值恒等式 max_i ReLU(g_i)=ReLU(max_i g_i) 不保证原标签等价。例如 g=(-2,-1)，原 ReLU 输出均为零，池化允许两个并列赢家；先对 g 求 max 则第二项是唯一赢家。复用旧 delta 会丢掉原合法标签。若采用确定性 tie-break，也必须核对其索引和选择语义，不能只比较输出值。

另一个普通例表明，旧 ReLU 相位本身不够精确表达 MaxPool。令 g_1=x+y/4+1/2，g_2=-x/3+y+1/2，源取正负 (15/52,-2/13)。两点都满足 beta=(1,1)，g 分别为 (3/4,1/4) 和 (1/4,3/4)，p=3/4。中点源零的真实 p=1/2。因此固定旧 beta 后的精确 max 图仍非凸；仅增加连续线性辅助变量和 EQ/LE 不可能表示它，因为线性凸集的投影仍凸。这个结论仅针对这种线性表示，不是否定所有 Neural-HZ 定义。

正权求和并非同样廉价：固定保留变量后，y=sum a_i q_i 的精确区间为 [sum a_i L_i, sum a_i U_i]，a_i>0。一般显式无 lift 的线性展开可能需要指数多支持片段，保留 q 则恢复原紧凑 lift。相关幅值与聚合困难在 D004/D152 已有记录；不把它再次宣称为新发现。

## 与已有研究及主目标的关系

区间消元的正确性来自标准线性投影思想。旧 D123 已研究源条件化的唯一叶子 min 树和相关接口限制；本轮补足共享叶子、跨窗口一致性及其费用，不主张已经建立外部新颖性。[Anderson 等的强混合整数神经网络公式](https://arxiv.org/pdf/1811.01988) 第 5.1 节、命题 10 已讨论 max-of-affine 的强公式，不能把 max 的非凸编码本身当创新。此引用用于确定已有研究边界，没有采用其分离优化或额外求解路径。

主线仍是新的域元素、具体化及可组合的神经算子：在保留原非凸相位和共享输入关系时，证明相对明确参照的能力或完整成本优势。本轮没有满足这个要求。可以保存上述定理供将来原生算子设计使用，但不应为了实现它而把两例池化修补替换成整个强 Neural-HZ 研究目标。
