# 共同规范实现支持条件观察跨层传播

本轮补上条件观察的组合证明，并给出一个真正经过第三个 ReLU 银行的严格正控。旧共享上行与第三门的精确全局标量界仍允许一个分数松弛点；新增观察传递将第三门上界降到11/24，排除该点的1/2输出，间隙1/24。这个结论是精确纸面控制，不是具体网络反例、native浮点执行结果或正式新增解。

关键修正是区分原坐标与候选新增的辅助坐标。向外舍入后，不必要求每个存储可行辅助赋值都等于理想乘积；只要所有层对每个原状态保留同一个共同规范实现，就可以健全地继续添加关系。后继允许排除伪辅助赋值，但不能排除任何受保护原状态。

## 共同实现的语义与组合定理

设 H0(theta) 为候选之前的完整非凸 HZ，theta 包含全部原连续因子、原二元因子、EQ/LE、frame及输入decoder。本文的封闭控制中，原第三门和它的bit也已在H0内。各原二元因子保持离散，零ReLU的两个合法原标签都保留。

有限观察环境 O 为每个新增辅助量指定语义函数 Gamma_j(theta)，例如 pi_s*q_j 或 pi_s*Wq。所有函数指向同一个theta；不能让不同观察重新选择输入。每个函数经已证有限界归一化到[-1,1]，并有可检查的来源和作用范围。Gamma是语义解释，不是根据当前LP解选择的分支或数值见证。

实现持有保留全部H0行的扩展系统 P_k(theta,eta_1,...,eta_k)。不变量为：对每个原整数theta属于H0，(theta,Gamma_1(theta),...,Gamma_k(theta))同时满足P_k。观察环境、原身份和扩展谓词构成候选语义接口；空观察嵌入原HZ。按共同环境中的具体化包含比较，取语义等价商；这里不主张完整格或可计算最佳抽象。

组合定理：若下一组新增观察有已证归一化范围，并且每条新理想行在(theta,Gamma_old(theta),Gamma_new(theta))上成立，则精确安装或逐行可靠向外舍入后，上述不变量继续成立。原H0的全部行保留，因此最终扩展系统投影回theta恰等于H0。

证明：取任意原theta，旧不变量提供同一Gamma_old；新观察使用同一theta定义Gamma_new，故新旧所有理想行同时成立。对零bias行 A*z<=d，将系数存为Ahat，取 E=sum|Ahat-A|，RHS存为向上舍入的d+E。因为所有连续及原二元latent的绝对值不超过1，规范实现仍满足存储行。归纳给出正向包含；保留H0给出反向包含。

这个证明不要求P_k的任意可行eta都有精确乘积含义。后继行可能删除某些伪eta，故没有保持投影到(theta,eta_old)的全部存储可行赋值，只保持受保护原theta。不能把候选生成的辅助量临时改称原输入，从而错误要求或声称更强的投影等价。

这也不免除数值证明：每个新行、系数合并、归一化和RHS补偿都要认证。只是不必把上一次放宽产生的所有伪辅助偏差，再当作真正函数误差层层放大。原门必须确实满足 q=ReLU(g_native)，例如使用已认证zero-error原谓词；不能从已舍入的辅助行反推精确门，也不自动得到原ONNX或具体浮点网络资格。

## 统一的前向消费规则

保留已有的原相位锚和四个代数槽，pi_s为相应指示量。原门向量q和整个被选消费者观察v=Wq都按同一theta解释。给定已证的共同条件输入和槽内范围，使用D089的按权重符号组合的双边包络，定义三个v_s，第四个由v减去前三个恢复。原相位、输出及旁路仍留在H0。

下一原门 q'=ReLU(h') 的实际预激活若为 h'=Cv+r，且残余也有共同条件观察，则 h'_s=Cv_s+r_s。由对真实槽内状态有效的L_s<=h'<=U_s，统一取：U_s<=0时k_s=d_s=0；L_s>=0时k_s=1,d_s=0；否则k_s=U_s/(U_s-L_s), d_s=-k_s L_s。添加

```text
q' <= sum_s (k_s*h'_s + d_s*pi_s).
```

若还要向后继续传递q'的观察，再保留其双边条件观察；若不需要，则直接汇总这一上行，无须先建立再消去四份q'_s。槽界来自认证数学结构，不来自实例标签、terminal margin或solver状态。静态代数槽不创建输入/相位子问题，所有行在同一混合系统中。

新槽界只需在共同规范实现上有效，不必已经被旧的分数松弛行蕴含；这正是新增关系可能有用的地方。其来源必须单独证明，不能把当前LP假点所在区域当成全域前提。

## 槽界由同一结构规则生成

不为下面的正控手工指定专用界。对每个原child，沿D086分解 g_j=c_j+a_j*u+b_j*v+r_j，r_j的常数放入c_j，其余系数继续绑定同一组原latent。以M_j=||r_j||1得到每槽s,t的L_j、U_j，并算出k_j、d_j。所有参数必须有固定精确值或已认证的误差处理，非点权重不能直接当作固定W。

对每个观察W的一行，先由各q_j的区间[ReLU(L_j),ReLU(U_j)]按W正负号得到Ilo、Ihi。再在原坐标上合并共同核心：

```text
K = sum_j W_j*k_j*g_j = c* + a* u + b* v + r*
Dminus = sum_{W_j<0} W_j*d_j
Dplus  = sum_{W_j>0} W_j*d_j
Blo = c* + min(a*,0)*s + min(b*,0)*t - ||r*||1 + Dminus
Bhi = c* + max(a*,0)*s + max(b*,0)*t + ||r*||1 + Dplus
L = max(Ilo,Blo), U = min(Ihi,Bhi).
```

两套界分别有效，故取交仍健全。先合并r_j再取范数保留共同源的系数抵消；即使未充分利用r*与父幅值的其他依赖，也只会更保守。这里不求LP、不查看当前解、不分裂原问题；L>U时拒绝证书或候选，不据此删除原相位或宣布UNSAT。该统一规则恰好产生下面四个槽范围，因而不依赖toy门名或专用分支。

生成成本不能只按合并后的最终nnz算。令T_i=sum_{j:W_ij!=0}(1+nnz(r_j))，每槽每观察都支付完整输入出现次数；逐项合并再规范排序的保守形态为O(4*sum_i T_i*log(1+T_i))次有界标量操作，另计所有child槽参数、512位算术检查、保存的核心与证据。槽数固定不等于宽源免费。代码实现须给出具体预付界，不能把此渐近式当作现有工作量门已经通过。

## 三层普通混权控制

取x,y属于[-1,1]，并保留所有原门及原bits：

```text
u = ReLU(x), v = ReLU(y)
r = ReLU(u+v-3/4), t = ReLU(u-v+1/4)
Z = r+t
w = ReLU(Z-1/2).
```

父active bits为alpha,beta，delta=alpha*beta；原共享幅值zu=beta*u、zv=alpha*v，u10=u-zu、u11=zu。masses依次为1-alpha-beta+delta、alpha-delta、beta-delta、delta。这里只把bits暂作[0,1]变量用于比较终端外包，实际域仍保留离散语义。

新增三个Z槽观察，Z11=Z-Z00-Z10-Z01。D089统一聚合得到的八条双边行是：

| 槽 | Z_s下界 | Z_s上界 |
| --- | --- | --- |
| 00 | pi00/4 | pi00/4 |
| 10 | 5*u10/4+pi10/16 | 5*u10/4+pi10/4 |
| 01 | -pi01/8 | pi01/4 |
| 11 | 5*u11/4-5*pi11/16 | 5*u11/4+5*pi11/8 |

真实共同实现的槽内Z范围分别为[1/4,1/4]、[1/4,3/2]、[0,1/4]、[0,15/8]。00直接由原门确定；10中t=u+1/4且r>=0给出下界，u<=1给出上界；01上界由表中合并包络给出、下界由r,t非负；11上界由表中上行和u11<=pi11给出。10槽的1/4下界不是表中较弱的分数lower行已经蕴含的事实，不能混称。

对w应用同一secant规则，00和01槽恒为零，10槽贡献4*Z10/5-pi10/5，11槽贡献11*Z11/15。因此新增一行：

```text
w <= 4*Z10/5 - pi10/5 + 11*Z11/15.
```

现在考虑旧松弛点：

```text
x=y=0; u=v=1/4; alpha=beta=1/2
r=5/16; t=7/16; Z=3/4; w=1/2
active(r)=1/4; active(t)=7/20; active(w)=1/2.
```

各父门的原标量带标签凸包允许该点。r和t的预激活分别为-1/4、1/4，旧范围都是[-3/4,5/4]：两门的q<=U*active上行分别取等，q-g<=(-L)*(1-active)也成立。取delta=1/2、zu=zv=1/4，D086的共享行成立，两条新增上行分别给r<=5/16、t<=7/16，也允许该点。

第三门即便使用真全局精确预激活范围[-1/2,1]，仍允许w=1/2与active(w)=1/2。因为w=1*active，且w-(Z-1/2)=1/4=(1/2)*(1-active)。真全局Z范围[0,3/2]可由原两hinge之和是max(0,u+v-3/4,u-v+1/4,2u-1/2)得到，并有端点取等。故这不是仅收紧第三门标量范围就能排除的点。

新增观察上行相加给出Z<=1/4+5u/4+3delta/8。固定旧点Z=3/4、u=1/4，结合delta<=alpha=1/2，强制delta=1/2。随后pi10=pi01=0、pi00=pi11=1/2；共享幅值行强制u10=0，表中两侧行给出Z00=1/8、Z10=Z01=0，因而Z11=5/8。

第三门的新上行因此为w<=11/24，而旧点w=1/2，严格间隙1/24。不依赖为新增辅助量挑选某个不利解：给定原假点，所有满足新增前级行的辅助赋值都违反第三门行。这是相对D086加下一原门的新增关系证据，不重复把D086原3/16控制算作跨层收益。
