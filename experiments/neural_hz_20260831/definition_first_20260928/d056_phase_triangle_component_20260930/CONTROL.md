# 普通三门的物理读出对照

这些固定有理控制验证共享相位组合确实可以超出当前独立双门投影，不是 benchmark CERT 或 ADV。没有参数搜索或数值求解。第一例沿用 D054 已完成证明，第二例覆盖直接三负公式。

## 两正一负的物理输出

在 x,y∈[0,1] 上，f1=x-y/3-3/10，f2=x+y-9/10，f3=-x/3+y-3/10，qi=ReLU(fi)。三条生成关系的 dij 按 12、13、23 顺序为 2/3、-2/3、2/3。新编译器应准确输出一条八 nnz 行：

```text
F=2*(q1+q2+q3)-x-y <= 2*(b1+b3)/5+13*b2/15.
```

旧点 x=y=bi=1/2，q1=q3=1/3，q2=2/5 通过当前全部六个方向的 pair 行。完整独立单门 source-labelled hull 的各半 active/inactive 见证分别为 (59/60,1/20) 及其逐坐标补值、(17/20,17/20) 及补值、第一对交换 x/y。都严格位于盒内，预激活正负严格，源均值相同。新行排除差为 3/10。

物理仿射输出 Z=F+(12/19)*[(q1-f1)+(q3-f3)]+(26/27)*(q2-f2)。原 residual capacity 与新行消去全部 bits，得 Z<=5/3，且实际源 (1,1) 取等。旧点 Z=308/171，严格高于 5/3；三个 q 各减 1/300 后仍超出 824/7695。该读出不把辅助 bits 当作神经网络输出。D054 对旧差分行及严格旧点的额外纸面证明不在这里重写为新测试。

## 三条负边的普通控制

x,y,z∈[-1,1]，f1=x-y/3+1/10，f2=y-z/3+1/10，f3=z-x/3+1/10，qi=ReLU(fi)。三对 P=0、k0=U=43/30、k1=23/30、d=-2/3。合成应返回：

```text
2*sum(qi) <= 2/3+(11/5)*sum(bi).
```

旧点 x=y=z=0，bi=1/2，qi=7/10，通过三条固定方向 pair 投影；每对 qi+qj=42/30，上界43/30。新行差为7/30。纸面完整单门 hull 可各半使用以下 active 点及其相反点：(39/40,-39/40,0)、(0,39/40,-39/40)、(-39/40,0,39/40)。对应预激活7/5、-6/5，源严格内部。这项完整 hull 见证属纸面论证；新自动测试核对系数、pair 和严格差，不把未执行检查记成自动通过。

## 其余固定语义检查

测试所有八种边符号排列，等幅和不等幅，在固定的0、1/2、1均值上比较全部静态平面与独立公式，并在整数角核对二次原值。偶负号/零边不生成本组件行。所有这些是有限数学测试，不迁移为运行时搜索。

非点偏置宽度1/100保留为真实 enclosure；取固定端点和中点及源角/中心验证具体门值。另用 x-y、y-z、z-x 三门，在全零输入核对全部八种合法零相位。可靠严格正门跳过，触零门不跳过，frame 中三个原 bits 始终存在。支持、数值、循环来源与跨身份拒绝也是数学接口检查，不是 native 生命周期认证。
