# 混合连续源包络的定向控制

本页固定一个普通混权、非零偏置的精确有理正控。共同连续源包络排除一个同时满足两门各自完整 source labelled hull 和既有 D020 四行的松弛点，并能把该关系传过一个后继混权 ReLU 对。这是已知增量关系与盒上面的可作用证明，不是新定理、新域资格或真实模型收益。

所有点均为纸面有理证明或预注册数学测试夹具，不是搜索、攻击或模型实验。原连续源、全部门 bits、零点合法选择及谓词不变；分数 bits 只用于比较凸松弛。数学规则与完整成本见 [THEORY.md](THEORY.md)。

## 网络与共同源上面

令 x,y 属于 [-1,1]，原门和相位为

```text
g=x,                  q=ReLU(g), active bit alpha,
f=3*x/4+6*y/25+1/200, p=ReLU(f), active bit eta.
delta=g-f=x/4-6*y/25-1/200.
```

g 的真实区间为 [-1,1]，f 的真实区间为 [-197/200,199/200]，delta 的真实区间为 [L,U]=[-99/200,97/200]。这些区间由同一原盒上的仿射式直接求得，不是免费支持 oracle。

对 delta 使用固定 x 在前、y 在后的结构顺序。令 X=(x+1)/2、Y=(1-y)/2，则

```text
delta=-99/200+(1/2)*X+(12/25)*Y.
prefix marginals: m_X=1/200, m_Y=12/25.
G_plus(delta)=97/400+x/400-6*y/25.
```

由 ReLU 增量界，q-p<=ReLU(delta)<=G_plus(delta)。因此原物理读出

```text
Z=q-p-x/400+6*y/25 <= 97/400.
```

取真实源 x=1,y=-1 时，q=1、p=103/200，两个预激活均严格正，Z=97/400 取等。正控不依赖共零、共号假设、比例门或零偏置。

## 通过强单门比较的旧点

固定松弛点

```text
x=1/4, y=0, q=9/20, alpha=11/20,
p=77/400, eta=1.
```

父门 q 的完整带源和标签凸包有显式分解：权重 11/20 的真点为 (x,y,q,alpha)=(9/11,0,9/11,1)，权重 9/20 的真点为 (-4/9,0,0,0)。平均正是上述 x,y,q,alpha；两分量预激活严格异号。

门 p 的 source labelled hull 见证就是真实图点 (x,y,p,eta)=(1/4,0,77/400,1)，其预激活严格正。两门分别可以使用这些分解；比较系统不要求它们共享同一个凸组合。因此旧点属于两门完整独立 source labelled hull 与共同源坐标的交。没有声称它属于完整 joint graph hull；下述有效行恰将它排除。

旧点的 d=q-p=103/400、delta=23/400、e=d-delta=1/5。D020 四行逐一成立：

```text
d <= U*alpha = 1067/4000,
d >= L*eta   = -99/200,
e <= -L*(1-alpha) = 891/4000,
e >= -U*(1-eta)   = 0.
```

但是新上面在此点等于 389/1600，而 d=412/1600，相差 23/1600。相应旧物理读出 Z=411/1600，大于 97/400=388/1600。这证明一个严格的查询关系增强，但未证明超过全部 D029 观察、完整多门 hull 或任意 native 实现。

## 关系能传过后继混权门

保留真实差值 d=q-p 及伴随 p，追加原门

```text
h2=1/10+11*q/10-3*p/5 = 1/10+11*d/10+p/2,
w2=1/10-q/2+p         = 1/10-d/2+p/2,
r2=ReLU(h2), t2=ReLU(w2).
```

两门在原盒上都不稳定：在 (x,y)=(-1/10,1) 时 h2=-1/500<0；在 (3/10,-1) 时 w2=-1/20<0；在 (1,-1) 时两者都严格正。这些点仅证明普通结构适用性，不决定任何执行分支。

按源恒等式先合并，h2-w2=(8/5)*d。已证明的 G=G_plus(delta) 在整个连续 source box 上非负，所以 G_plus((8/5)*G)=(8/5)*G。固定前向差分规则得到

```text
Z2=r2-t2-x/250+48*y/125 <= 97/250.
```

旧点可延伸为后继两门的真实图：h2=r2=959/2000、w2=t2=27/400，两个新增 active bits 均为 1。此时 Z2=411/1000>97/250=388/1000，差为 23/1000。真实源 (1,-1) 仍取等。

这里的比较包含前述两门独立 source hull、原两门 D020 四行及后继两门的精确图；不声称已经加入所有新旧门之间的 D020、D029 或完整四门 hull。传播展示的是已有关系的可组合性，不另计一个独立的新能力机制。

## 零相位与测试范围

原源 (x,y)=(0,-1/48) 使 g=f=0。q=p=0，alpha 和 eta 的四种原合法组合全部保留；控制行不依赖它们的选择。这个零点仅检查必需的语义边界，严格分离与取等证明均不依赖它。

固定四项测试分别覆盖混合上下包络、纯原 bits 与 D046 的等价及 typed identity、上述强比较和前向组合、默认关闭及不合法前提拒绝。连续点与 binary 顶点循环是有限数学夹具，不是候选运行时相位枚举；不允许把 singleton lower 套到 fractional bits 并声称逐点健全。
