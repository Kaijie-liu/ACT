# 相位中心候选的严格比较与限制

本记录给出普通 biased affine、ReLU、共享源 skip 和后继 ReLU 上的纸面正控。新域排除的不只是某个可随意更换的相位标签，而是完整源与输出投影；在整数语义上也严格优于上一版固定中心候选。所有数值是有理数推导与独立复核，没有运行生成矩阵、数值搜索、模型或求解器。

比较范围明确限于本记录指定的旧规则族。同预算 centered perspective-energy 已经支配新球；精确 HZ 也本来就排除假幅值。不能把控制当成新算法原理、真实网络成绩或超越这些强参照的证据。

## 网络和可靠共同预算

令 n=16，1 为全一向量，

```text
A = I-(1/8)11^T
A^T A=I, A1=-1
x in [-1,1]^16
g=Ax-(1/2)1, q=ReLU(g)
gamma 为这 16 个门的原相位。
```

每行的绝对系数和为 11/4，故可靠紧界是 L=-13/4、U=9/4。L=-11/4 是漏掉 bias 的错误界，不得使用；独立审查发现后，最终记录统一采用 -13/4。

所有首层门都真实 crossing，行非平行、偏置非零。选 gbar=-(1/2)1，||g-gbar||2=||Ax||2=||x||2<=4，新余项半径为2。正交结构仅用于解析证书，不是针对特定模型的运行菜单或真实 CNN 结构假设。

记 Q=sum_i q_i、T=sum_j x_j、N=sum_i gamma_i，保留共享源读出 s=(9/22)T。真实下一 affine 消费者及激活为

```text
J=sum_(i=1,...,15)q_i-(1/4)q_16+s
z=ReLU(J-33/5).
```

## 新表示给出的整体界

新球是 ||2q-g-(2gamma-1)gbar||2<=4。对全一方向，可靠支持常数为 ||1||2*4=16，因此

```text
2Q+T+N <= 16.
```

原 mask q_i<=(9/4)gamma_i 给 N>=4Q/9。消去 N 得

```text
Q+(9/22)T <= 72/11.
J <= Q+(9/22)T <= 72/11 < 33/5.
```

这两条线性关系对分数 gamma in [0,1] 也成立。故普通线性终端已可证明后继门 z 恒零，未调用新 conic solver 或相位搜索。

粗独立区间仍给 J-33/5 in [-12063/880,7413/220]，跨过零。实际后继门不是 crossing；它被新关系证明为稳定零，正是这里想区分的结果。不能把粗区间 crossing 误报成真实门 crossing。

## 全部至多三门完整源关联凸包仍允许

对任意选中集合 S，k=|S| in {1,2,3}，定义

```text
t_k=(7/5)/(3-k/4)
u_j=t_k if j in S, otherwise -t_k
t_1=28/55, t_2=14/25, t_3=28/45.
```

全部 t_k<1，所以源 +/-u 都严格位于盒内部。对 i in S，A_i u=(3-k/4)t_k=7/5。于是两源上的选中门预激活分别为 9/10、-19/10。把这两个真实源各取一半，得到选中门的 q=9/20、gamma=1/2，完整源均值 x=0，精确 skip 均值 s=0，恰好是展示的点。

因此它属于每一个至多三门完整 source-labelled hull 的柱状扩展，进而属于这些 hull 的交。不同组选用不同的源混合，不能误称一个混合同时实现全部 16 门，也不能称通过全 bank 联合 hull。

## 全部指定 Gram 与未重中心化能量参照仍允许

对任意 w>=0，定义同一 bank、同一原源盒上的

```text
W=sum_i w_i
G_w=A^T diag(w) A
B_w=tr(G_w)+2 sum_(j<k)|(G_w)_jk| >= W.
```

最后一步来自每行 ||A_i||2=1。D009 同 bank、原中心 b=-1/2 的 weighted Gram-mass 行为

```text
sum_i w_i(2q_i-g_i) <= (1/2)W+sqrt(W B_w).
```

假点左侧为 (7/5)W，右侧至少 (3/2)W，故整个非负权族都通过，任何更松的可靠向外版本也通过。W=0 时是恒真行。

对应的未重中心化能量预算为

```text
E_w=(1/4)W+||A^T w||1+B_w >= (9/4)W.
```

因为 ||A^T w||1>=|1^T A^T w|=W。对这个预算的 individual uncentered perspective-energy，假点的每坐标代价为

```text
(9/20)^2/(1/2) + (-19/20)^2/(1/2) = 221/100 < 9/4.
```

因此该全部非负 weighted 族也不能排除它。均匀 D012 投影资源取 c=sum g=-8、E=36、n=8、T_pos=36/5，所需能量为884/25<36；此处 n 已为整数，邻整数容量插值也不排除，统一 scalar caps 同样通过。

这些是冻结公式、同一原 bank 和原中心的比较。没有声称通过全部变换坐标、重中心化、条件能量、RLT、SDP 或任意整数化关系。

## 强参照的边界

理论记录证明，同一 B=4 下 centered individual perspective-energy 蕴含新球，连分数相位也包含。因此本控制没有超过该强参照。对展示的 LP 点，中心化后 u=q-gamma*gbar=7/10，v=g-q-(1-gamma)gbar=-7/10，每门 perspective 代价为49/25，总量784/25>16，已被它排除。

值得保留的结果是具体表示替换和递归正规形，加上相对明确旧参照的正例；待解决的是完整代价和真实网络价值，不是继续放大控制维数或宣称反射代数本身新颖。
