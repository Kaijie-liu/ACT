## 非凸语义及可计算查询应分开定义

一个可合法表达当前研究问题的元素写作 D=(H,Psi,C)。H 保留原连续因子 xi、全部原二元相位 b、EQ/LE、guards、共同 frame 及输入 decoder。Psi 是按原神经结构确定、绑定同一 frame 的有限仿射读出集合；C 是读出与原相位、已有合法辅助量之间的有限联合关系，并携带健全证据。

在保留原相位身份的语义空间中定义：

```text
gamma(D) = { (output,b) : exists xi,w,
    H(xi,b), y=Psi(xi,b), C(y,b,w), output=readout_H(xi,b) }.
```

这里同一个 xi,b 必须同时解释全部读出与消费者。不能用每个消费者分别存在的 xi_j 代替。w 只能是已证明可扩展且计费的辅助量；没有免费 source 副本。空 C 嵌入原 HZ；若 C 中全部关系由原整数图推出，且每个原状态都有同时扩展，则投影回原物理坐标及原 bits 与 H 完全相同，包括激活零点的所有合法标签。

语义包含给出预序，相等取商可得偏序，但不宣称存在可计算最佳抽象或完整格。固定可计算的查询编译另给出外包 Q(D)，满足 gamma(D) 包含于 Q(D) 对原坐标的投影；保留原所有 LP 行并仅增加健全加强时，新的 LP 外包不弱于旧外包。具体化相同与查询外包不同并不矛盾。

这个框架属于已有 observational reduced product 和带条件关系的混合表示，并不是本轮新发明。[Sharp Hybrid Zonotopes](https://arxiv.org/html/2503.17483v2) Remark 2 明确区分同一集合与其不同表述的松弛，Theorem 7 已把 RLT 组织为 HZ。因此，能编译回原 HZ 或“原 HZ 加相同行等强”不是否决一切方法贡献的理由；反过来，仅给相同行另加缓存、名字或图节点也不是新域贡献。需要实质的关系生成、组合或简化定理及完整成本优势。

## 可以证明的前向合同

Affine、Conv、Add、Concat 在同一原赋值上作线性组合。若目标读出不在现有观察空间内，必须支付新坐标或源展开成本，不能把两支残差解释为独立集合的 Minkowski 和。尚未证明可精确遗忘的源与原 bits 一律保留。

ReLU 保留原门、原 child bit 和全部守卫。[D077](../d077_coupled_relu_projection_20261001/THEORY.md) 在已有有限非空条件区间上提供有限输入输出关系。其精确性只针对单个读出的区间表投影，不是共同源图，也不包含 child bit 的完整 ideal 性。不能仅因所有消费者共用同一个 delta，就把各自投影的交称为联合凸包。

一个可直接核验的跨块证书合同如下。对每个已有槽 s，假设共同读出满足 A*y<=b_s。下一原混权读出 h_j=c_j+v_j*y。若结构预定的非负系数组合 ell_j_plus、ell_j_minus 满足

```text
ell_j_plus*A = v_j
ell_j_minus*A = -v_j,
```

则可靠条件界为

```text
L_js = c_j - ell_j_minus*b_s
U_js = c_j + ell_j_plus*b_s.
```

证明是对同一赋值中的有效行作非负线性组合。随后应用 D077，就得到下一门的健全关系；此合同可在两个普通块上归纳组合。ell 必须由固定前向结构规则提供并逐系数核验，不通过 LP 对偶、当前松弛点、margin 或求解状态寻找。证明中的“非负证书”不是授权执行 dual rescue。

这仍是经典线性证书组合加已有析取投影。尚缺的实质算法是：如何统一生成低增长的组合，并真正消费第一块的联合关系，而不是回退到各自盒界。[D059](../d059_cross_layer_interface_20261001/THEORY.md) 的条件方向秩差也禁止免费继承任意旧观察。本文不宣称任意深度精确闭包，不把全网 ideal hull 新增为研究门。

## 两个精确局部消费者仍会在 Add 合流时失配

源为 x,y in [-1,1]，保留所有原 bits：

```text
u=ReLU(x), v=ReLU(y), 原相位 alpha,beta
h_r=u+v-9/10, r=ReLU(h_r), 原相位 gamma
h_t=u-v+1/10, t=ReLU(h_t), 原相位 eta
Z=r+t-u.
```

两个后继仿射形式不成比例，有普通混合符号和非零偏置。取比较点：

```text
x=y=0, u=v=1/4
alpha=beta=1/2, delta=1/4
r=1/4, t=11/40, gamma=1/4, eta=3/4.
```

先看 r。按父状态00、10、01、11各占1/4，取原源点

```text
(-1/2,-1/2), (1/20,-1/2), (-1/2,1/20), (19/20,19/20).
```

对应 h_r 为 -9/10、-17/20、-17/20、1，输出均值 r=1/4，child 相位均值 gamma=1/4。这组同时恢复全部 x,y,u,v,alpha,beta,delta，故比较点属于完整父图与这个 child 的联合带标签凸包。

再看 t。仍按同四父状态各占1/4，取

```text
(-1/2,-1/2), (1/2,-1/2), (-1/2,4/5), (1/2,1/5).
```

对应 h_t 为1/10、3/5、-7/10、2/5，输出均值 t=11/40，child 相位均值 eta=3/4。这组也恢复完全相同的父坐标及标签。因此两个消费者各自的 D077 行当然通过；这里比较对象甚至强于各自的区间表投影。

两组 source 都在盒内部，全部原网络预激活均非零。两个消费者使用了不同的槽内 u,v 分配：分别存在的真实凸组合不是同一份共同连续见证。

仅检查纯相位一致性也不够。四个源点 (+/-1/2,+/-1/2) 各占1/4，按同一父状态顺序给出 child labels

```text
(gamma,eta) = (0,1), (0,1), (0,0), (1,1).
```

它们的父坐标均值仍为 x=y=0、u=v=1/4，纯相位联合分布同时复现上述所有标签。这并不复现 r,t 的比较值；正是这个差异表明缺失的是共同幅值解释，而不只是相位可实现性。

## 已知共同源关系已经足以排除

由0<=u,v<=1，原整数图在四个 child labels 下分别满足：

```text
gamma,eta = 0,0: Z=-u <=0
gamma,eta = 1,0: Z=v-9/10 <=1/10
gamma,eta = 0,1: Z=-v+1/10 <=1/10
gamma,eta = 1,1: Z=u-4/5 <=1/5.
```

因此统一有效行是

```text
r+t-u <= (gamma+eta)/10.
```

这里四个代数情形仅用于纸面证明；生成公式不运行相位子问题、不删除或新增 bit。零预激活时原两个标签也都满足各自等式及上界。比较点左侧11/40，右侧1/10，违反7/40；其 Z 甚至超过真网络全局上界1/5，差3/40。真上界在 x=1,y=1/2 取到，两 child 预激活分别3/5、3/5。

该行是 [D052](../d052_static_source_certificates_20260930/THEORY.md) 的已知机制：取 P=u、N=v，f=h_r、g=h_t，三个证书 f-P<=1/10、f-N<=1/10、g-P+N=1/10；两个相位交叉项系数正好为0。故它不是新的多门关系，不把这个控制当作定义创新，也不启动一个重命名组件。

若 r,t,u,gamma,eta 已有物理坐标，行含5个非零系数；若实际 Add 读出 Z 已有坐标，则含3个。Z 的定义、源界及证书、原谓词、latent 展开、RHS/slack 和 decoder 均另计。只算已存 Z 的3 nnz不能掩盖全成本。
