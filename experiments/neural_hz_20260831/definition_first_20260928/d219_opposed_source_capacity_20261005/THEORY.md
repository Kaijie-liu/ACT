# 对向源界的联合总幅值精确投影

本轮给出一个可直接存成有限谓词的局部结果：两个正 cap 随同一个源反向变化时，保留原相位的总幅值凸包投影只需六条或四条上界，不新增变量。它不等于完整双幅值 hull，也不构成新的完整 Neural-HZ。强参照审查发现，所构造的网络正例仍被旧 D035 完整共同源乘积关系覆盖。

所有原 HZ 连续源、二元相位、EQ/LE、共享身份、活消费者和原输入 decoder 保留。下面 beta 在原生集合中仍为原整数相位；分数值仅用于查询外包分析。证明里的共同质量不成为新运行时 phase 枚举或 split。

## 非凸局部载体

取 L,d>0、0<rho<1，保留同一个 z∈[0,1]，定义

```text
c1(z)=L+d*z, c2(z)=L+d*(1-z),
P(z)={e>=0: e1<=c1(z)+rho*e2, e2<=c2(z)+rho*e1},
F={(z,e,beta): e in P(z), beta in {0,1}^2,
               beta_i=0 implies e_i=0}.
Q=e1+e2, B=beta1+beta2,
T=2*L+d, J=rho*T/(1-rho), K=J-d.
```

研究对象是 conv(F) 在 (z,beta1,beta2,Q) 上的精确投影。z 与其他原源关系重新连接后，所得行仍健全，但不据此宣布整个父域联合 hull 理想。

如果同父 ReLU 已认证 f1-rho*f2<=c1(z)、f2-rho*f1<=c2(z)，则真实原输出和标签属于 F。保留原图，并非用 F 删除其 guards。

## 有限投影定理

在 z、beta 的单位区间界下，投影恰为 Q>=0 加以下行。

当 K<0，记 R=d-J>0，共六条上界：

```text
Q <= (L+d)*B,
Q <= (L+J)*B+R,
Q <= L*beta1+(L+d+J)*beta2+d*z,
Q <= (L+d+J)*beta1+L*beta2+d*(1-z),
Q <= (L+J)*beta1+(L+d)*beta2+R*z,
Q <= (L+d)*beta1+(L+J)*beta2+R*(1-z).             (A)
```

当 K>=0，共四条上界：

```text
Q <= (L+J)*beta1+(L+d)*beta2,
Q <= (L+d)*beta1+(L+J)*beta2,
Q <= L*beta1+(L+d+J)*beta2+d*z,
Q <= (L+d+J)*beta1+L*beta2+d*(1-z).               (B)
```

K=0 时 (B) 的前两条相同，保留三条即可。K 的分支是可观察数学参数决定的同一规则，不读取实例身份、性质、历史标签、LP 状态或 margin。

## 共同源质量证明

仅在证明中，令 p 为两原位共同为一的质量。记

```text
p_min=max(0,B-1), p_max=min(beta1,beta2),
lambda11=p, lambda10=beta1-p,
lambda01=beta2-p, lambda00=1-B+p.
```

对每种标签，源一阶量 eta_s 满足 0<=eta_s<=lambda_s、sum eta_s=z。仅门一开启时的总幅值最大值为 L+d*z；仅门二开启时为 L+d*(1-z)。双开时联立反馈的正顶点给最大总幅值 T/(1-rho)，与 z 无关；双关为零。

所以固定 p 时，问题只剩下把源质量分配给四种标签。先向10分配，再向中性的11和00分配，最后向01分配，得到

```text
max(eta10+lambda01-eta01)
 =min(B-2*p, z+beta2-p, 1-z+beta1-p).
```

这些分别来自两独占质量、总 z 质量及总 (1-z) 质量的上界；上述次序达到其最小值。于是固定 p 的精确最大总幅值为

```text
S(p)=min(A0+K*p, A1a+J*p, A1b+J*p),
A0=(L+d)*B,
A1a=L*B+d*(z+beta2),
A1b=L*B+d*(1-z+beta1).                           (C)
```

当 K>=0，三条都对 p 非减，所以取 p_max；展开两个 min 并删去由 z∈[0,1] 蕴含的两条冗余行，恰得 (B)。

当 K<0，把 Q<=S(p) 与 p_min<=p<=p_max 写为 p 的上下界：

```text
p >= 0, B-1, (Q-A1a)/J, (Q-A1b)/J,
p <= beta1, beta2, (A0-Q)/(-K).
```

逐一比较上下界。已有单位区间界处理纯质量条件；其余给八条上界。其中两条与 (A) 后两行有相同 beta 系数，但源系数分别为更大的 d*z、d*(1-z)，因为0<R<d而被支配。删去后恰得六行 (A)。

反向证明也包含在这些比较中：取所有下界的最大值作为 p，必不超过所有上界。按上述源分配构造 eta，在每个正质量标签内取固定源值 eta_s/lambda_s，配以相应轴顶点或双开正顶点，即得至多四个实际 F 原子和最大总幅值。若只需更小 Q>=0，在原 source 和标签下同比缩小全部幅值即可；P(z) 凸且含零，故仍合法。于是整个 Q 纤维是区间，不仅证明上界有效。

这不固定 e1、e2 各自的分配。因此，不能把六行加回原双幅值后宣称完整 (z,beta,e1,e2) hull 已精确，更不能把多个方向的不同最大点拼成一个输出点。

## 完整局部费用和使用范围

Q=e1+e2 直接内联，在已有 z、e、原 beta 坐标上：

| 参数区间 | 上界 LE | 变量系数 nnz | 新列或新 bit |
| --- | ---: | ---: | ---: |
| K<0 | 6 | 28 | 0 |
| K>0 | 4 | 18 | 0 |
| K=0 | 3 | 14 | 0 |

不重复计已有非负、source/phase 区间、原 P 和神经图。若 z 是含 m 项的源仿射读出，源仿射展开后、同列合并前的 nnz 上界分别增加4(m-1)、2(m-1)、2(m-1)；原源、别名、其他消费者、decoder 和证据仍须支付。

给定可靠参数时，构造只需一次 J 的除法、符号检查与固定行生成。固定 (z,beta) 的精确 Q 上界只需计算六/四/三个仿射值的最小值。但这不是符号 source 上的全局支持查询，不是任意混权方向的完整域查询，也不是整网 GPU 速度证据。可靠数位、区间系数、模型绑定与终端消费未实现。

它是既有共同 on/off 源容量的一项紧凑投影结果。相对显式全源乘积有不同的局部计费形式，但没有证明同信息、全消费者、整网精度下的净成本优势，不能将这个局部计数直接宣称为新域或加速。
