# 联合源容量的精确投影和新颖性边界

本轮仍以从 HZ 数学定义发展强大非凸 Neural-HZ 为目标，未转向存储优化或外部 helper。取得的是一个紧凑的精确局部投影，以及两项阻止重复研究的边界；尚未取得新抽象域、真实网络能力或正式成绩突破。

前轮 D218 属于有进展：常数盒 fan 的一般无增益定理改变了研究方向。本轮起始重新核对其16项归档哈希，全部一致。全部新工作是纸面数学、原论文阅读及独立只读复核，无候选执行。

正输出支持的一般边界意味着：不能继续换私有源均值或正权来寻找战胜完整 D035 的同类控制。负幅值控制揭示的 joint guards 信息确实重要，但它也说明“补负幅值”本身已不是新的定义。旧组件暂未实现一项旧关系，不会让数学机制重新变新。

另有同机制的备用 NN 绑定曾由数学复核代理纸面提出：L=1,d=2,rho=1/4，f1=28/15+8z/5-64u/5-16v/5、f2=52/15-8z/5-16u/5-64v/5，在 u=v=1/2、z=1/4 取 q=(4/3,47/30)。代理给出最大相位(1/2,193/376)及联合行差151/5640。它没有经过本轮最终强参照的独立全项复核，不晋级、不据以报告额外发现；保留这个未选绑定是为了记录尝试，而非新增第二个 runner。

## 与相关原论文的界限

[Kılınç-Karzan 等关于 joint mixing sets 的论文](https://arxiv.org/pdf/1910.01353)中，Theorem 3.1 表明：对该文固定非负数据 W 的 joint mixing set M(W,ell,0)，共享二元量的逐块 hull 之交已完整。这不是任意共享 bits、独立连续块的通用定理。连续链接可改变结论，但 Theorem 5.1 的 aggregated mixing 完整性依赖特定前提。不能把“共享 bits”本身称为新贡献，也不能把论文的分离算法费用当作固定完整 LP 的大小。

[Liu 等关于两类 mixing set 交的论文](https://optimization-online.org/wp-content/uploads/2017/01/5830.pdf)研究 p+d、p-d 形式的相反连续链接。其 Theorem 3.1 在 A1 至 A3 前提下给出混合与广义混合行的完整 hull。一般 beta_i*c_i(source) 不是自动满足该形式的集合，尚无本项目的精确仿射映射。固定模板可能利于 GPU 批处理只是工程推测，原论文没有本项目性能证据。

[Kolman 与 Koutecký 的有限域 CSP 扩展公式](https://kam.mff.cuni.cz/~kolman/papers/CSP-treewidth.pdf)按完整 bag 配置及 separator 边缘一致性给出 O(D^tau*n) 规模。它不允许用连续源均值免费替代条件分布。直接借用树宽概念既不能证明神经状态组合精确，也不能免除指数配置成本。

项目内部 D035 已覆盖完整自由盒产品；D022 已定义正负幅值共同消费原相位，D036 已允许正齐次别名；D175 已有高阶共同源兼容性的严格控制。因此，再证明一个自由产品行、再堆一层已有双幅值差分或再换一个 source-cycle，不自动增加定义新颖性。以上是相关先例边界，不是穷尽文献的新颖性认证。

## 下一定义问题和可反证要求

下一个有效研究对象是普通混权或残差结构中的共同神经守卫与连续源容量：如何作为同一个非凸域元素的关系成分，统一生成、传播并供多个消费者使用，而不依赖外部支持 oracle。研究必须同时说明原连续源、原二元相位、EQ/LE、共享 frame、活 skip 和原 decoder 的具体化语义。

最低可反证要求是：在完整单门、适用的 D035 共同产品以及已有 D022/D036 缩放关系之后，证明新的物理输出或后继收益；或者证明相同明确精度和全部消费者下可承担的完整成本优势。不能只挑更弱参照，不能以单方向新 cut、局部行数减少或更换名称代替域的组合定理。高阶关系不默认授权全相位枚举，有限模板也不自动证明任意深度闭包。

在数学定义、结构前提、与已有机制的差别及端到端费用明确以前，不为本轮局部六行公式启动实现。后续实现仍默认关闭、独立预注册冻结，依次数学、真实同结构、shadow、逐家族、完整2413及独立400回放；所有数值与资源门保持。GPU、smooth/Transformer、其他家族和最终满分目标没有被删除，但目前均无新资格。

旧 D214 支持器沿出生历史逆序传播方向并组合证明权重；它不是外部 LP/dual rescue，但不能描述成没有 backward 计算。本轮未调用它，也未把它的测试资格当成已经实现强大 Neural-HZ 的证据。以后必须将域语义、推理算子和普通终端决策的贡献分开说明，不以 helper 的收益冒充本体能力。
