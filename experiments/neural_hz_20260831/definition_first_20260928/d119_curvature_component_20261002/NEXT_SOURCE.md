# 任意卷积读出的共同曲率传播与真实系数绑定

下一项需要检验的不是更多人工正比例后继，而是共同曲率关系能否被普通卷积的任意有符号权重利用，并在原始系数的可靠包络下保留收益。本文件给出纸面桥接和真实来源审查，尚未注册或执行新数值实验。D119 的组件通过不覆盖这里的一般消费者、区间系数或真实模型。

## 为何不能直接推广当前后继函数

D119 的 `append_budget_child` 要求后继在整个门组上的系数等于一条预算行的正倍数，消去后得到处处非负的仿射上包络。等距五门的预算系数是 `(2,-4,0,-4,2)`。只检查源残余而不检查真实后继权重，会把一个特殊消费例子错误当作一般神经算子。

以下一般混合读出公式已经包含在 D118 的共同核推导中；这里明确残余、BN 和跨零后继的桥接，不把它重新宣称为新颖公式。当前代码没有实现或实测这一完整组合。

## 一般混合读出的上下包络

保留同源真实门 p=ReLU(f)、q=ReLU(h)，内部实际输入 g_i=(1-t_i)f+t_i h+r_i。对任意固定有符号权重，包括端点权重，写

```text
F = rest + w_0 p + w_end q + sum_i w_i q_i
A = (w_0 + sum_i w_i(1-t_i)) p + (w_end + sum_i w_i t_i) q
S = 2p + 2q - f - h
K(s) = sum_i w_i (min(t_i,s)-t_i s)
L = min K(s), U = max K(s), s in {0,1,t_1,...,t_m}.
```

rest 是其余保留的真实读出及偏置，不能把其他 fan-in 丢掉。D118 给出的共同缺陷 e_i 满足 L S<=sum_i w_i e_i<=U S；实际内部输出比理想输出增加 eta_i，且 w_i eta_i<=ReLU(w_i r_i)。为每个实际残余正负方向建立认证上割线 s_i^+、s_i^-，得到

```text
F <= rest + A - L S + sum_i s_i^+(w_i r_i)
F >= rest + A - U S - sum_i s_i^-(-w_i r_i).
```

权重可以混合正负，不需要与某条预算行成比例。端点没有内部残余项。应先组合共同核和相同源项，再取包络；不能把逐项 ReLU 残余之和替换为残余总和的 ReLU。固定系数节点的前缀扫描不是输入或相位 split。

如果认证了真实后继输入 F<=V，且 V 是保留状态上的仿射上包络，则 ReLU 单调性给出 child<=ReLU(V)。设认证 box(V)=[l,u]，安装如下统一标准上界：u<=0 时为 0；l>=0 时为 V；l<0<u 时为 u(V-l)/(u-l)。这消除了当前函数要求 V>=0 的特殊前提，不删除后继原相位。必须认证整个 V 的范围，不能沿用 F 的范围冒充它的范围。

## 区间系数下安装行的方向

真实 BN 系数通常不能表示为当前 exact Fraction Form。不能将其区间中点当作真实网络系数。下面的健全转换允许保留原参数的有界不确定性，但不将参数改成新自由因子。

设理想共线输入的一条有效行是 Q+beta*f+gamma*h<=0，其中 Q=sum_j a_j q_j，a_j 已按实际输出身份合并。每个割线 s_i(z)=lambda_i z+mu_i 必须在覆盖全部实际 a_i*r_i(x) 的认证区间上满足 s_i(z)>=ReLU(z)，不能仅使用 r_i 的区间计算斜率。于是

```text
Q + C - sum_i mu_i <= 0
C = (beta + sum_i lambda_i a_i(1-t_i)) f
  + (gamma + sum_i lambda_i a_i t_i) h
  - sum_i lambda_i a_i g_i.
```

因此，只要 ell(x)<=C(x)，行 Q+ell(x)-sum_i mu_i<=0 就有效。这里取的是仿射组合的下包络。相反，为上一节的真实后继上界 V 消除系数不确定性时，必须取上包络；两个方向不可混淆。

一个保守的有理数构造是：系数 C_k 属于 [m_k-rho_k,m_k+rho_k]，原输入 x_k 属于 [l_k,u_k]，则

```text
ell(x) = m_0 - rho_0 + sum_k m_k x_k
       - sum_k rho_k max(abs(l_k),abs(u_k)).
```

同式改为加补偿就是上包络。其正确性来自逐项覆盖所有真实固定参数；不意味着这些参数独立可变。只有认证恒为零的系数才可以从支持集中消去，包含零的区间不能删除。坐标形状相同不能代替共享的输入 ID、padding 语义和 frame。

对真实首 Conv 后单个 BN，更合适的形式是

```text
g_(c,s)(x) = alpha_c (Conv_(c,s)(x)-mean_c) + beta_c
alpha_c = gamma_c / sqrt(variance_c+epsilon).
```

同一通道在权重、偏置和空间位置上共享同一个 alpha_c。先把线性组合写成 B(x)+sum_c alpha_c D_c(x)，再对 alpha_c=[m_c-rho_c,m_c+rho_c] 取

```text
ell(x) = B(x) + sum_c m_c D_c(x)
       - sum_c rho_c max_{x in X} abs(D_c(x)).
```

这保留了可以严格认证的同参数消去。把同一系数先复制成独立区间仍可能健全，却会放大补偿；不能因区间数值相同就认为不同通道是同一参数。

若后继 Conv 权重还要乘自己的 BN 比例，不能把其 midpoint 当成上述固定 w。可先以原 Conv 的精确存储权重形成双向包络，再通过真实共享 BN 表达式及认证符号传播；其不确定性也必须完整补偿。多重后处理或尚未绑定的舍入语义不由本段自动覆盖。

上述推导经主代理和独立数学代理纸面复核，未做机器证明、数值测试或真实绑定。原门 q=ReLU(g) 的来源认证是前提，不是一个任意 metadata 标签。有效新行保留原整数集合的结论仅适用于这个相同真实状态，不自动适用于另一份浮点 folded graph。

## 下一次实验必须回答的问题

科学判断必须同时覆盖实际源残余和真实后继读出，而非只统计新增行数。固定统一分组、实际权重、对照和完整人口后，记录所有稳定、跨零、不匹配、无收益及失败对象。分组不依赖模型身份、标签、历史成绩、margin 或 LP 状态；不得观察结果后换组。

目标应覆盖完整首 bank 及其真实直接消费者，而不能把旧五窗口称为全 bank。旧的三模型五窗口是一个明确的历史 pilot；若未来选择这一有限人口作新读出研究，必须事先明确研究范围、完整继承其消费者与 fan-in，且不能在全 bank 失败后作为同次执行的退路。本文件没有选择或冻结新的数值人口，更没有将全 bank 当作用户额外规定的晋级门。

对照至少保留相同真实源、原门、相位、标量界和区间补偿，并明确独立缺陷界与共同核界的差别。改善某个有理数认证上界只表示该固定读出更紧；不表示基准的全源凸包被严格超越，更不是性质已验证。使用同一关系的参考应得到相同逻辑后果，而不是故意剥夺参考信息。

有效行不等于有用行。补偿使某个见证的排除间隙消失，只否决该见证；不能推出所有读出无收益。若完整预注册读出全部无严格改善，记录该人口与规则的零增益，不晋级。若人口、绑定或预算未完成，记录执行不完整，不把它解释成数学无效。若获得真实后继改善，再进入 native 绑定、同结构 shadow 与完整保旧流程。
