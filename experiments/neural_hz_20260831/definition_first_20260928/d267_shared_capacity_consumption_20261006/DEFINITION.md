# 共同来源容量纤维及有限前向支持

本候选保留一个共享来源上的非线性容量关系，而不是先把每块容量替换为独立常数。下面给出精确的语义与有限支持公式，也说明为什么它仍不能被认定为已完成的新抽象域。

## 域元素与原 HZ 的对应

记原 HZ 为 H=(Xi,B,Phi,P,decoder)：Xi 是有界连续因子，B 是全部原 signed binary，P 是原 EQ/LE，Phi 是完整物理读出。任何 lazy/skip 分支也必须指向这一共同赋值；frame 编号相同本身不构成来源证明。

容量记录 K_j=(P_j,C_j,rho_j,e_j,A_j,D_j) 保存物理仿射读出及其来源证书，其中 D_j 是已证非负的 deficit 仿射组合，A_j 为确切常数。定义

~~~text
Psi_j(z) = max(|rho_j(z)|, A_j) + 2 ReLU(e_j(z)),
Gamma(H,K) = { Phi(xi,b) : (xi,b) satisfies H,
              P_j + D_j - C_j <= Psi_j for every j }.
~~~

所有记录共用 H 中的同一 z，不能逐消费者选择一个不同 z。语义偏序按 Gamma 的集合包含定义；未证明最佳抽象或完整格。空 K 精确嵌入 H。D266 定理在完整原图上证明每条记录有效时，Gamma(H,K)=Gamma(H)，全部原 bits、零点双标签及 decoder 不变。这里增强的是指定查询／前向松弛，不是把原精确集合缩小。

Psi 的 max 关系一般是非凸 hypograph。若把这种关系作为任意域元素的基本约束，它可以在固定全部原 bits 后仍有非凸的连续截面。例如 0<=p<=1、-1<=r<=1、p<=|r|，按 (r,p) 顺序包含 (-1,1)、(1,1) 而不含中点 (0,1)。固定原 bits 的普通线性 HZ 扩展及其连续投影均为凸集，所以不能声称这种一般关系有零新位的精确线性降低。这是表示边界，不是本轮认证记录改变原整数集合的证明。

## 两块共同残余的四面定理

假设两个实际神经块已有点态证明

~~~text
P_j <= C_j + Psi_j - D_j,  D_j >= 0,
rho_1 = rho_2 = rho, e_1 = e, e_2 = -e, A_1,A_2 <= 0.
~~~

各块中心 mu 可以不同；必须用各自 rho_j=r_j-mu_j 认证这个身份，不能误用未中心化的 r。对固定 theta_1,theta_2>=0，令 T=theta_1+theta_2、d=theta_1-theta_2，则

~~~text
theta_1 Psi_1 + theta_2 Psi_2
  = T|rho| + T|e| + d e
  = max_{sigma,eta in {-1,1}} [sigma T rho + (d+eta T)e].
~~~

第一步用 2 ReLU(e)=|e|+e，第二步用绝对值的两个仿射平面。这里只展开固定四个代数平面，不固定、枚举或求解原网络相位子域。

若实际消费者具有已认证身份 h=ell+theta_1 P_1+theta_2 P_2，且 ell、rho、e 同属有可靠盒 D 的物理前沿，则

~~~text
h <= theta_1 C_1+theta_2 C_2
     + max_{sigma,eta} [ell+sigma T rho+(d+eta T)e]
     -theta_1 D_1-theta_2 D_2.
~~~

可把非负 deficit 项丢去取得较弱的有效界，也可将它们作为原仿射读出合入 ell 后求界。每个平面的同源系数先合并，再用盒支持求上界；不能先分别给 rho/e 求区间。盒只作为可靠支持外包，不替换 H 的非凸谓词。消费者身份和 theta 必须由实际前向结构构造；本定理不免费提供任意消费者的最佳分解。

## 正守卫底值与近似共享

正 A 不可偷偷归零。令 a_j=max(A_j,0)，按常数排序 a_1<=a_2，并同时重命名整个记录及 e 的符号。对 x=|rho|，有

~~~text
theta_1 max(x,a_1)+theta_2 max(x,a_2)
  = max(T x, theta_1 x+theta_2 a_2,
        theta_1 a_1+theta_2 a_2).
~~~

在 x<=a_1、a_1<=x<=a_2、x>=a_2 上直接验证三个最大分支即可。代入 |rho| 得至多五个 rho 平面；e 部分为 max(2 theta_1 e,-2 theta_2 e)，因此总计至多十个共同源平面。常数排序不是输入或相位 split。两底值均为零时约化到四面。

若实际第二块 rho_2=rho+Delta_rho、e_2=-e+Delta_e，同一 H 上有 |Delta_rho|<=eps_rho、|Delta_e|<=eps_e，则上述右端加 theta_2(eps_rho+2 eps_e) 仍有效。理由是 max(|rho|,A) 对 rho 为 1-Lipschitz，2 ReLU(e) 为 2-Lipschitz。偏差读出及原谓词不得被删掉；这个误差定理不自动证明旧比较系统仍接受某个假点。

负 theta 不在上界组合范围内，不能把不等式直接乘负数后继续作为上界。需要独立反向证书或原 H 的可靠下界；本轮未给任意混号消费者的闭合算法。

## 前向变换和终端范围

Affine、Conv、Add、Concat 在共同赋值上精确组合完整读出，保留所有原谓词、相位和容量记录。不同 frame 必须先有来源对齐或认证 link EQ。记录在同一个源银行中共享，不能在 Add 两侧复制独立误差。

对已取得 h<=U 的下一原 ReLU，保留原图和它本来的相位 gamma，并可靠加入 q<=max(0,U)。U<=0 时 q=0，但预激活可能为零时仍保留所有合法原标签。这是有损前向界传递，不是有限模板在任意深度上的精确闭包。smooth、Softmax、LayerNorm、attention 尚无本轮变换。

终端只能使用已证明的物理线性后果或另经证明的完整降低。仅引入 t>=各 Psi 平面，再加 P<=C+t，会因 t 可任意大而丢失关系。再加 t<=G 的精确投影是 P<=C+G 及每个平面<=G；当后者已被保留的同一源外包蕴含时，只恢复独立标量付款。若 G 仅对整数 H 有效，后者也可能增加有效 source cut，但仍不是精确的共同 Psi 纤维。反向写 t<=每个平面又把 max 换成 min，可能删除真实点。保留精确 Psi 图也不能一般只靠连续 EQ/LE 完成。

可以额外证明并使用共同 t 预算，但那是有损容量扩展，须单独给具体化与投影证明；本轮直接编译共同物理行，不创建这样的自由容量变量。

## 成本和创新判断

在源身份及规范化仿射形式已经认证后，单消费者的支持最多处理 4m 或 10m 个源系数项，其中 m 是真实共同支持并集大小；来源生成、合并、位长、可靠舍入、全部消费者和证据另计。具体双消费者控制可编译两条各至多14个物理非零的 LE，无新列或位。这不包括将物理读出展开到 native HZ 因子的成本。

分段归约与 gather 适合 GPU 设计，但本轮没有 GPU kernel、可靠浮点舍入或设备测量。特别不能把支持相消的浮点结果无误差地当作上界。

定义仍属于 H 加有证观察的 reduced-product 组织；一般 max-affine 支持和非负证书组合已见 D029、D062、D209。新的项目证据是特定守卫残余关系的四／十面组合，以及独立父对上的强对照分离。它尚不足以确认新的抽象域创新，不能因写出 Gamma 就宣布定义目标完成。
