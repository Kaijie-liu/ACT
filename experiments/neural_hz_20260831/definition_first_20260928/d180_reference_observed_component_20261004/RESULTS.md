# Neural HZ 参考观测定义原型的验证结果

参考相位观测与共享残差的定义候选已实现，并通过唯一一次完整数学组件测试：4056 项、213 个文件，零失败、错误或跳过。本轮的进展是定义所要求的关系开始有实现和正反例证据，不是实际网络新增解。正式成绩仍为1870/2413，独立E0仍为CIFAR100 25加TinyImageNet 36，共61/400，两项新增均为0。

## 这次验证了什么

[数学合同](CONTRACT.md)明确改变的是具体化关系。每个ReLU包的消费者共用连续残差delta和同一个存在见证t，同时约束Ct=Cd、C D_tau t=C D_tau d，以及相位相关输出和能量。原始连续源、整数二元相位、零点两种合法标签、EQ/LE、共享身份和输入重构保留。不同层的bank仍有各自的见证，不能误称所有层共用一个t。

[24项新增测试](test_reference_fiber.py)覆盖了以下关键区别。

- 五门普通混权例中，旧D157允许的参考相位伪包(1/4,31/10)被新定义拒绝，真实包(1/4,3/2)保留。它证明对这一明确比较前沿的严格修正，不证明超过原精确HZ。
- 同源Add/Concat和跨下一ReLU保留了参考相位切片的仿射关系；源项抵消时后继误差预算归零。另一个普通后继直接消费q时，参考处仍有E=3，正确保留真实输入变化。
- 非参考相位下，合法有损包(1/10,6/5)仍被接受，而真实包为(0,1)。测试故意保留这个负结论，避免把局部精确切片写成全域精确。
- 从这个合法但非具体网络轨迹的父成员继续ReLU传播仍被保留。健全性人口是整个原生抽象父域，不只是原网络上的样本点。
- 存在满足全部有限线性行、却违反共同见证的点。成员检查拒绝它，并检查全部历史bank；最后一个bank自身可行不能替代父状态合法。
- 新shifted能量行逐系数符合平方公式；负相位系数、正负参考偏置下的零点双标签、输入decoder、身份和资源失败关闭行为均被覆盖。

三个查询证书是同一状态上的固定代数：canonical范数界、显式delta=a-Hd换坐标后的旧范数界、同样换坐标后的D158 mass界。它们无条件计算并在完整标量界上取最小值，不按失败状态切换验证器。新实现保留了Householder正控的后继上界-3/55及恒零ReLU；带旧残差的第二层也逐一检查三个证书的健全性。这个结果不是整条深层路径处处精于D158的证明。

上述一般性质仍以合同中的数学推导及前提为依据；定向测试不是机器检查的完整定理证明。没有新增attack、PGD、split、BaB、backward/dual rescue或求解器级联。继承人口中既有固定LP控制原样保留，不计作新域能力。

## 不能由本轮推出的结论

此次只有mathematical_component_gate_passed为true。source/model binding、实际相位列绑定、native生产准入、GPU执行、完整物理资格、shadow和正式回放均未取得。有限线性终端是外包，不是原生共同能量关系的精确LP编码；三个查询证书与后继E只保证对原生成员健全。

五门控制为50条新行，对比旧逐门图20条，不是成本胜利。真实模型中的4096、2048、6272门结构也不能直接装进本有理参考实现的64相位上限；本轮没有放宽上限或宣称它已能运行这些模型。原生未知相位查询、完整代价、GPU数值健全性和smooth/Transformer闭包仍是未完成工作。

相位切片精确、球与线性观测几何本身不是已建立的新颖性。仍需证明所选择的观测、递归关系与完整查询成本能在常见真实结构上胜过强旧路径。不能用这次修复先前候选的局部失真替代PLDI级创新或保全1870的证据。
