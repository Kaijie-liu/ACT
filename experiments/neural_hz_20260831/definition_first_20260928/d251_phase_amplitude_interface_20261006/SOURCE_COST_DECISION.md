# 隐式卷积与原来源读取管线的组合费用

本轮关闭一个具体实现组合：将标准稠密 F4 临时 tile 算术接到原 D241 完整读取管线，尚未计全其余费用就超过原 256M work 门。不否定所有隐式卷积、所有 F4 变体或未来新的来源算法；也不通过改变旧计费、缩小三来源人口来让该组合通过。

这是纸面实现费用核算，未实现或运行 F4，未重新解码 ONNX、传播网络或执行 GPU。原网络、参数来源、shortcut 和全部消费者均保持原范围。

## 临时算术与 HZ 因子不同

[旧 C87](../../C87_MASKED_TILE_COST_AUDIT_20260913.md)否决的是将其全部 163 个 tile 的变换中间量统一物化为新 HZ 因子的方案；其中仍有 17 个仅通过必要 nnz 条件的局部 tile，尚无完整物理实现资格。不能据此否定所有物化变体，更不能禁止临时算术。这里检查的是仅改变域内可靠界运算、保留共同隐式卷积来源的方案。它即使成功也只是支撑算术，不单独构成域定义创新。

[Lavin 与 Gray 第 4.3 节](https://arxiv.org/html/1509.09308v2#S4.SS3)的标准 F(4*4,3*3) 每 tile/kernel 使用 36 个主乘积，二维输入、输出和 kernel 变换分别为 156、100、72 个浮点指令。其 G 含 1/6、1/24，不能继承旧 dyadic F2 的 exact-binary64 资格；可靠系数、累积和向外补偿另需证明。论文的推理吞吐不是本项目的可靠 GPU 证据。

这里采用一 FMA 一个 work 的乐观费用，完整计算两条必要卷积路径；例如中点与半径传播中的 W*c 和 |W|*r。后者的 kernel 变换一般不能复用前者。只替换 stride1 的 3*3 Conv，其余原 Conv 保持直接有效 tap 算法。不利用尚未证明的变换系数零项缩减。

## 三个完整前缀的算术

几何和原非零 kernel 人口来自 [D242 完整来源账](../d242_common_source_operator_20261005/SOURCE_COSTS.md)，均覆盖输入至第三个原 ReLU、包含 shortcut。F4 的 tile 数为 ceil(O/4)^2。

| 来源 | F4 kernel 数之和 | 每层 tile 数 | 未替换 Conv 的单路有效 tap | 单路主乘加 |
| --- | ---: | ---: | ---: | ---: |
| CIFAR large | 12,480 | 64 | 0 | 28,753,920 |
| CIFAR medium | 32,768 | 4 | 4,878,016 | 9,596,608 |
| Tiny medium | 32,768 | 16 | 15,972,544 | 34,846,912 |

large 是 Conv0、3、6、9；medium/Tiny 是 Conv6、11，其他原 Conv 直接计算。每行最后一列为 36*kernel数*tile数 加未替换 tap。

双路主乘加为 146,394,880。全部 F4 的输入 channel*tile 之和为 17,600，输出 channel*tile 为 21,504，kernel 共 78,016，故有

```text
双路输入变换 = 2*156*17,600 = 5,491,200,
双路输出变换 = 2*100*21,504 = 4,300,800,
双路 kernel 变换 = 2*72*78,016 = 11,234,304.
```

加原全局一次 40,000,000 evidence 预付，算术乐观小计为 207,421,184。它不是全流程上界：尚未包含原来源解析、参数认证、其他传播、数据读写、可靠舍入与完整物理资源。

作为同口径旁证，标准稠密 F2 的双路主乘加为 212,094,720，双路输入和输出变换分别为 4,259,840、3,944,448；加一次 40M 即 260,299,008，甚至未计 kernel 变换就超过门。此结论同样仅针对该声明算法。

## 原读取实现的费用不能消失

D241 的 source_audit.py:179 对每模型预付 4096+len(raw)+8*len(spec)。本轮只读 stat 所得大小为

| 来源 | 原模型 bytes | 原性质 bytes |
| --- | ---: | ---: |
| CIFAR large | 15,243,961 | 341,389 |
| CIFAR medium | 10,156,168 | 341,684 |
| Tiny medium | 14,475,376 | 1,043,882 |
| 合计 | 39,875,505 | 1,726,955 |

因此原完整解析费为 3*4096+39,875,505+8*1,726,955=53,703,433。与上表相加后已经为 261,124,617，超过 256,000,000。这里没有重复加 40M evidence。

而 source_audit.py:131 对所需 initializer 另有 128+64*count+3*proto_size 的预付。三源 decoded_scalar_count 是 113,344、380,864、380,864，总共 875,072，单取 64N 就是 56,004,608。该项用于原参数解码和逐值检查，不是 kernel 变换，与上面的费用属于不同步骤。

原 source_audit.py:262 另预付 8*temp_numeric_entries_upper，三源值为 1,107,264、3,288,256、3,491,008，合计 work 63,092,224。因此这一组合的进一步不完整小计为

```text
207,421,184 + 53,703,433 + 56,004,608 + 63,092,224
  = 380,221,449.
```

还未计 initializer 的其他项和全部传播。上述 work 是原实现的声明预算，不是硬件 FLOP、实测时间或任何未来算法不可避免的复杂度下界。换实现可以改变真实成本，但不能调用旧实现而删除其预算检查。

## 可复用的实际来源证据

[D120](../d120_mixed_consumer_source_20261002/census.py)三个同源工件保存固定五窗口的界和逻辑相位等信息，完整参数没有重复写入，last_source_forms 只保留在旧运行期，不能把这些边际工件当作已保存的完整原生 H 或共同仿射读出。

[D217 真实四门系数证据](../d217_source_phase_capacity_20261005/REAL_SOURCE_CERTIFICATE.md)可以继续用于定义假设审查：它保存了 medium 的原核系数、共享输入身份及共同 BN 缩放下的可靠秩证明。它不证明全部相位组合可达，不能直接套用本轮消费者商的全维零点开盒前提；也不是完整三来源接入资格。

D241 尚无完整传播后的可靠界和 native 相位绑定，D249 仍是构造样例。没有找到可直接继承并开始全三来源 native 试验的工件。本轮不重跑已知超账组合，不创建单 medium 或局部窗口替代原三来源阶段，也不将来源支持工作取代 Neural-HZ 定义主线。
