# 实际幅值消费者的条件观察商

本页给出一个固定线性接口的精确维数和达到该维数的构造。与上一页只保相位摘要不同，它确实保存相位条件下的实际幅值；但构造仍是已知 RLT 与线性代数，不是新 Neural-HZ 原语。它用于给下一候选定账，不以函数空间秩冒充一般表示或物理存储下界。

## 前提和定理

要求完整父源存在同一个可行局部截面 theta(t)，t 在开邻域中变化；全部既有连续源坐标在截面上连续，先前层的离散观察固定。当前 f(t)=A*t+b 满行秩 m，且有内部点 t_0 满足 f(t_0)=0。这里固定的祖先位不包含本层 alpha_i；当前原位仍随 f_i 的符号变化，并保留为二元因子。全部旧源坐标仿射于 t 是一个方便的充分条件，但连续性已经足够。

取 A 的局部仿射右逆截面后，f 的像包含零点附近的 m 维开盒，全部旧源仿射读出作为 f 的函数仍连续。令 q_i=ReLU(f_i)。

一个充分的普通例子是 x 在 [-1,1]^m、f=(I+E)x、||E||_infinity<1/4；逆矩阵范数不超过 1/(1-||E||)，所以原输入本身给出所需 chart。这个限制防止旧源已经含有未声明的相位条件幅值，却仍套用新观察下界。

仅“每个门分别 crossing”，甚至只知 f 的像含开盒，都不够给任意旧源接口授予本结论。低维源、相关相位、额外谓词或已有非线性观察可能改变空间，必须在实际可行函数空间重新分析。偏置允许，但要另证上述共同零点、可行 chart 及满行秩。

例如旧源若已含 z=alpha_1*q_2 的精确连续类型坐标，f 的像仍可含开盒，但这一观察已经存在。z 在 f_1=0、q_2>0 处不可能随上述跨面截面连续，故不满足定理前提。连续变量的类型本身不保证它作为源函数连续。

基线函数空间 B 定义为全部原源仿射函数、全部 q_i 和全部纯相位函数 psi(alpha) 的线性张成。这里为了给基线最强的纯相位信息，使用整个纯相位函数空间；不声称它能免费物化或在实际代码里已经存在。基线不另外包含跨门条件幅值或后继幅值；若包含，必须把它们加入 B 重算。

令 W 是由全部声明消费者确定的固定矩阵，R=rowspan(W)、r=rank(W)。需要以固定线性观察恢复的集合是全部 alpha_i*(Wq)_ell。相对 B，所需额外函数空间维数恰为

```text
N = sum_i [r-dim(R intersect span(e_i))]
  = m*r - #{i : e_i belongs to R}.                         (1)
```

特别地，满秩 W 需要 m(m-1) 个独立非对角条件幅值观察。这个结论不涵盖共同非线性 decoder、有损联合容量、隐式因子化电路或任意扩展 formulation。即使物理查询允许原整数位，也不能把这个受限线性读出定理扩写为一般 HZ 的下界。

## 必要性证明

考虑各 i 的 v_i in R，并假设 sum_i alpha_i*(v_i dot q) 落在 B。固定一个 i，取 f_i=0 而全部 f_j>0、j!=i 的小开片；该片存在于前提所给的开盒内。

跨越这个片时，所有 q 和原源仿射函数连续。对 k!=i，alpha_k 在局部固定，alpha_k*(v_k dot q) 也连续。纯相位函数只在这里贡献一个与片内连续坐标无关的常数跳跃。唯一剩下的幅值相关跳跃是

```text
sum_(j!=i) v_ij*f_j.
```

片内的 m-1 个正 f_j 可以独立变化，这个式子若恒为常数，就必须有 v_ij=0 对所有 j!=i 成立。因此 v_i 只能属于 R intersect span(e_i)。不同 i 的项无法互相抵消，所有商空间直和。反过来，alpha_i*q_i=q_i 已在 B 中，所以这些对角方向确实不需要新观察。得到 (1)。

零点的两种原标签不影响证明或恒等式：f_i=0 时 q_i=0，alpha_i*q_i=q_i 对两种标签均成立。没有删除或合并原 bits，也没有在运行时划分相位子问题。

## 一个达到维数的建设性商基

对 W 只做一次精确 RREF，记其非零行基为 B_1,...,B_r。e_i in R 当且仅当这个 RREF 中有单位行 e_i。对每个 i,k 令

```text
v_ik = B_k - B_ki*e_i.
```

删除确为零的 v_ik，其余恰有 N 个，并在各 i 的非对角投影空间中线性独立。存储共同观察

```text
T_ik = alpha_i*(v_ik dot q).
```

若实际消费者行 w=sum_k a_k*B_k，则

```text
alpha_i*(w dot q) = w_i*q_i + sum_k a_k*T_ik.               (2)
```

这是所有声明消费者共用的恢复式，不为每个消费者重复生成一组产品。原源、q、全部原位、EQ/LE、frame 及 decoder 都继续保留。仿射偏置项 c 只增加 c*alpha_i，已在基线里。

例取

```text
W = [[1,0,0],[0,1,1]],  m=3, r=2.
```

只有 e_1 在行空间中，故 N=5。可以用 alpha_1*(q_2+q_3)、alpha_2*q_1、alpha_2*q_3、alpha_3*q_1、alpha_3*q_2 这五项，精确恢复六个指定条件读出。全 rank3 参照则需要六个非对角项。此例是商基构造校验，不是 CNN 权重低秩证据或新能力正控。

## 原生线性编码及完整费用边界

对每个 ell=v dot q，先取得整个父域有效的有限 L<=ell<=U。令 T 为对应观察，保留原整数 alpha 后，以下四条 MC 行精确强制 T=alpha*ell：

```text
T >= L*alpha,
T <= U*alpha,
T >= ell-U*(1-alpha),
T <= ell-L*(1-alpha).
```

alpha=0 时前两行强制 T=0，alpha=1 时后两行强制 T=ell；范围保证其余行不误删原点。整数具体化因此不变。若 L<=ell<=U 已由旧 LP 蕴含，则孤立地增加这四行产品定义不会改变旧物理集合的 LP 投影；查询加强需要其他关系消费这些观察。若 L/U 仅对原整数父域有效、尚未被旧 LP 蕴含，新增行确可因投影出该范围而收紧旧 LP；这部分收益来自新范围证书，不能归因于产品共享本身。

在 q 与 alpha 已有物理坐标、ell 内联的声明布局中，额外 N 个连续坐标、4N 条 LE，变量 nnz 至多 sum_(i,k)(2*|supp(v_ik)|+8)。若显式物化产品全局界，再加 2N 条 LE、2N 个 nnz；采用原生因子盒时须按其真实中心和尺度转换另算，不重复记行也不忽略转换。

这些只是产品定义部分。完整账还包括：精确行空间证明及系数位长、RREF 的 fill、范围证明、W 的全部消费者身份、式 (2) 在所有后继中的系数、原 q 的产生和保留、全部旧谓词、终端查询、见证重构、可靠向外舍入、临时与 host/device 共存及证据。直接稠密 RREF 对 p*m 的 W 最坏约 O(p*m*min(p,m)) 算术，逐 i 物化投影行还可达 O(m*r*m) 系数；共享引用不等于这些终端作用免费。512 位及其他原资源门保持不变。

同层固定消费者的一跳闭合不授予下一批新相位的免费闭合。若后继 gamma 又需 gamma*T 或 gamma*Wq，必须重新声明所需联合关系；不能把 (2) 当作普遍多层精确规则。GPU 可并行执行部分矩阵算术，但没有消除 N 个标量关系，也没有本轮设备资格或速度证据。

## 整数精确不等于保持全部查询强度

取一个原锚点 alpha，三个其他幅值 q_2,q_3,q_4 各有范围 [0,1]。实际消费者行空间的 RREF 可含

```text
B_1=q_2+q_4,  B_2=q_3+q_4,
```

两者可靠范围都是 [0,2]。在查询松弛中令 alpha=1/2、q_2=q_3=q_4=1/2，并取 T_1=1、T_2=0。每个 ell=B_k 的均值都为 1，其四行 MC 允许的 T 区间恰是 [0,1]，所以两项都通过。

然而实际消费者还可包含同一行空间里的 w=B_1-B_2=q_2-q_3。其完整原范围为 [-1,1]，当前 w=0，原消费者自己的四行 MC 给 alpha*w 的上界为 1/2；商基重构的 T_1-T_2=1 却违反它。

这是普通原 ReLU 层可以承载的比较：取 f_j=x_j、x 在 [-1,1]^4，alpha 是第一门原位；显示 f_j=0、全部原位 1/2、q_j=1/2 的父均值甚至属于完整四门父图凸包，例如把 x 全为 1 和全为 -1 两个真实状态各取一半即可。它不是原整数状态或 ADV；显示的 T_1=1、T_2=0 则不能与这些父均值共同延拓到含条件观察的完整联合凸包。跨门条件幅值的共同可实现性正是比较中尚未保留的部分。

因此按 (1) 达到最小函数维数并按 (2) 精确恢复整数函数，不保证只对基方向施加 MC 就保住压缩前每个消费者的 LP 强度。若原路径已有 w 的条件容量，必须继续保存其重构行或证明更强的共同容量蕴含它，并计入全部费用。孤立商基不能据此晋级或默认启用。这与 [D224 的向量条件容量](../d224_shared_source_regions_and_vector_capacity_20261005/VECTOR_CAPACITY.md)所指出的共同源要求一致，不是新的几何原理。

## 先例和下一候选

[D248](../d248_live_tail_capacity_20261006/OBSERVATION_BOUNDARY.md)给的是 alpha_i 乘仿射源方向的跳跃秩；本页改为实际非线性幅值消费者，并允许基线包含所有纯相位函数。全维开片前提也更明确，不能把两定理混用。

[Sharp Hybrid Zonotopes 第 IV 节 Theorem 7](https://arxiv.org/html/2503.17483v2#S4)已说明 RLT 可保持 HZ 表示；上面的四行精确整数乘积及其保留 bits 的做法不是新发明。本页只提供指定观察空间的商和费用分析，不建立优于已有 RLT 工具的新颖性声明。

一个仍可研究的有损假设是：对固定完整消费者写 Wq=T*Bq+e，并为同一 e=(W-TB)q 推导利用共同源与神经互补的联合容量 E，而不要求保存全部精确条件产品。所有消费者必须使用同一个 e；E 需对整个父域健全，下一混权 ReLU 需有严格精度或完整成本证据。当前尚无这样的新 E 证明。仅将 e 包成逐行独立区间或已有仿射像不能承担本项目的创新声明，故本轮不为这个未证假设创建 runner。
