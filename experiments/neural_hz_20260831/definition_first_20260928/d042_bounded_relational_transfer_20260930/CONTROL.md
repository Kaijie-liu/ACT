# 非零条件差界的完整纸面对照

本例证明一项有范围的严格分离：保留同一原相位的非零条件差区间，可以排除一个通过完整前缀联合凸包、最后一门在该连续前缀凸包上的完整带标签图凸包，以及全部六对原门全局 D020 差分行的原坐标分数点。它不依赖两个原预激活在关断面上精确相等。

这里使用的是 D027 已知原相位条件支持的前向生成规则，不是新不等式类别、已经成立的新抽象域或正式验证收益。全文只有有理数纸面推导及独立复核；没有运行候选、数值搜索、LP、相位分裂、网络、GPU 或测试。完整凸包只作为数学比较对象，不是拟议运行算法。

## 1. 原网络、原 bits 与共享源

源为同一个三维盒，所有门使用同一份输入：

```text
(x,y,z) in [-1,1]^3

g = x
f = 9*x/10 + z/10 - 1/4
q = ReLU(g), original bit alpha
p = ReLU(f), original bit eta

w = y + q/5 - p/10
t = ReLU(w), original bit tau

h = y + 2*q/5 - p + 3/20 - z/10
r = ReLU(h), original bit beta
```

各原 bit 取 0 或 1：bit=0 时预激活不大于零且输出为零；bit=1 时预激活不小于零且输出等于预激活。预激活等于零时两种原 bit 均合法，不把任意两门的 bits 合并。下文连续查询松弛中的分数 bit 不是具体网络相位。

四个门都真正跨零。例如，源 `(1/2,1/2,1/2)` 使四个预激活全部严格为正，源 `(-1/2,-1/2,0)` 使它们全部严格为负。两个后继门具有混合权重、共享旁路 y，最后门还含非零偏置及共享源 z；没有创建额外的 `ReLU(y)` 或其他影子门。

本纸面坐标中的输入解码器直接读出原 `(x,y,z)`。嵌入 HZ 时仍须使用原 decoder，并保持全部连续源、原二元、原 EQ/LE 和 frame 身份；本规则既不复制输入，也不改变原网络等式。新增有效行不改变整数具体化。

## 2. 条件预激活差界的构造性证明

先证明三个共同源事实。

第一，

```text
f-g = -x/10 + z/10 - 1/4 <= -1/20.
```

因此 alpha=0 时 g<=0、q=0，且 f<0、p=0。这个例子的严格源关系也迫使此时 eta=0，但一般规则不通过 bit ordering 删除零点的合法选择。

第二，有 `p<=3*q/4`。当 x<=0 时两边均为零；当 x>=0 时 q=x，且

```text
f <= 9*x/10 - 3/20 <= 3*x/4,
```

其中最后一步使用 x<=1。因右边非负，取 ReLU 后得到所需不等式。

第三，有

```text
9*q/10 <= p-z/10+1/4.
```

当 x>=0 时由 p>=f 直接得到；当 x<=0 时 q=0，而右边至少为 3/20。这里的情况分析只是纸面证明，没有运行输入区域或相位分裂。

定义原预激活差：

```text
D = h-w = q/5 - 9*p/10 + 3/20 - z/10.
```

alpha=0 时 q=p=0，故得到非零条件区间：

```text
1/20 <= D <= 1/4.                         (C0)
```

两个端点分别由 z=1 和 z=-1 达到。

对所有原输入，第二个共同源事实给出

```text
D >= -19*q/40 + 3/20 - z/10 >= -17/40.
```

第三个共同源事实给出

```text
D <= -61*p/90 - 11*z/90 + 37/180 <= 59/180.
```

因此特别在 alpha=1 时，有

```text
-17/40 <= D <= 59/180.                   (C1)
```

下界在 x=z=1 达到；上界在 x=7/18、z=-1、p=0 达到。两处 alpha 均可取原合法值 1。上界达到点中 p=0 的两种 eta 选择均保留；这只是精确端点证明，不是旧松弛点的构造所依赖的数值特例。

## 3. 两条条件幅值行

对任意实数 h,w，ReLU 的单调性与 1-Lipschitz 性给出

```text
min(0,h-w) <= ReLU(h)-ReLU(w) <= max(0,h-w).
```

具体而言，h>=w 时输出差位于 [0,h-w]；h<=w 时位于 [h-w,0]。结合 (C0)、(C1)：

```text
alpha=0 => 0 <= r-t <= 1/4,
alpha=1 => -17/40 <= r-t <= 59/180.
```

保留原 alpha 后，编码成两条有效 LE：

```text
t-r-(17/40)*alpha <= 0,                  (Rlower)
r-t-(7/90)*alpha <= 1/4.                 (Rupper)
```

在原整数 alpha 上，这两行准确编码所列两个输出差区间，不声称它们单独给出全部联合图。允许 0<=alpha<=1 后，它们只是有效外包，不声称完整联合凸包。

这是将 `r-t` 及 `t-r` 分别作为 D027 条件支持观察得到的已知两行。与 D041 不同，alpha=0 时 D 始终严格为正，不存在 h=w 的关断同余；r-t 在该面上也不是恒等于零。不能通过免费创建 `ReLU(w+3/20-z/10)` 来把它改称旧零面规则的匹配成功。

## 4. 强比较系统及完整嵌套见证

令 P 为原真实前缀

```text
(x,y,z,g,f,q,p,w,t,alpha,eta,tau)
```

的完整带标签联合凸包。比较系统包含 P，并加入以整个连续 P 为源、实际 affine h 及最后原门 `(r,beta)` 的完整带标签图凸包，再加入第 5 节列出的六对全局 D020 行。

这是有意精确限定的局部组合比较：最后门的源是连续 P，不是原真实非凸前缀。不能把它写成整个真实网络的联合凸包；后者当然会排除下面的分数点。

六对 D020 在上述最后门凸包构造之后取交；本例不声称通过先把跨最后门的 D020 共同条件吸收到其非凸图内部、再求凸包的更强比较。嵌套构造的单个外层图点无需分别满足这个凸化后才加入的跨门行集合，最终 (Old) 必须并且确实满足全部这些行。

考虑旧点：

```text
x=-9/10, y=z=0,
g=-9/10, f=-53/50,
q=p=0, alpha=eta=0,
w=0, h=3/20,
t=1/4, r=1/5,
tau=3/10, beta=1/2.                      (Old)
```

下面给出它在比较系统两个完整凸包中的联合见证。所有底层真实前缀点固定

```text
x=-9/10, z=0, g=-9/10, f=-53/50,
q=p=0, alpha=eta=0, w=y, t=ReLU(y).
```

因此仅列 `(y,t,tau)` 即可恢复全部原前缀坐标。

第一个 P 点是

```text
P_active: (y,t,tau)=(1/4,23/50,1/2)
  = (1/2)*(23/25,23/25,1)
    + (1/2)*(-21/50,0,0).
```

在这个连续 P 点上，实际最后门满足

```text
h=1/4+3/20=2/5, r=2/5, beta=1.
```

第二个 P 点是

```text
P_inactive: (y,t,tau)=(-1/4,1/25,1/10)
  = (1/10)*(2/5,2/5,1)
    + (9/10)*(-29/90,0,0).
```

在这个连续 P 点上，实际最后门满足

```text
h=-1/4+3/20=-1/10, r=0, beta=0.
```

将这两个最后门图点各取 1/2，得到 y=0、t=1/4、tau=3/10、h=3/20、r=1/5、beta=1/2，即完整恢复 (Old)。底层四个真实源均严格在输入盒内部，g、f、w 均非零；两个外层最后门的 h 也分别严格为正与严格为负。无需任何零点相位特例。

P_active、P_inactive 中的分数 tau 是 P 的凸化见证，不是单个真实前缀赋值。整个 (Old) 含分数 tau、beta，绝不是通过具体网络验证的 ADV。

## 5. 全部六对原门 D020 的精确检查

对有向门对 i,j，令原预激活差 `delta=g_i-g_j in [L,U]`、输出差 `d=r_i-r_j`、负幅差 `e=d-delta`。四条比较行是

```text
L*b_j <= d <= U*b_i,
-U*(1-b_j) <= e <= -L*(1-b_i).            (D020)
```

这些行对单侧或跨零的有效差界均成立。第一对由原 ReLU 图直接按各门是否输出零证明；第二对对 `ReLU(-g_i)-ReLU(-g_j)` 应用同一结论，其 bits 为 `1-b_i,1-b_j`。在预激活零点，这种补 bit 仍合法，所以没有遗漏零点选择。

本例六对全部真实全局差界、旧点值及四行允许区间如下。`g,f,w,h` 分别对应输出 `q,p,t,r` 和 bits `alpha,eta,tau,beta`。

| 门对 | 真差界 [L,U] | 旧点 (d,e) | d 允许区间 | e 允许区间 |
| --- | --- | --- | --- | --- |
| g,f | [1/20,9/20] | (0,-4/25) | [0,0] | [-9/20,-1/20] |
| g,w | [-2,15/8] | (-1/4,13/20) | [-3/5,0] | [-21/16,2] |
| f,w | [-9/4,13/8] | (-1/4,81/100) | [-27/40,0] | [-91/80,9/4] |
| g,h | [-9/4,23/10] | (-1/5,17/20) | [-9/8,0] | [-23/20,9/4] |
| f,h | [-5/2,41/20] | (-1/5,101/100) | [-5/4,0] | [-41/40,5/2] |
| h,w | [-17/40,59/180] | (-1/20,-1/5) | [-51/400,59/360] | [-413/1800,17/80] |

每一行均通过，尤其最后一对的反向负幅约束为

```text
-1/5 >= -413/1800,
```

余量为 53/1800，没有漏掉该约束。

真差界也可逐项核对，不使用运行时优化：

- `g-f=x/10-z/10+1/4` 直接给第一行。
- `g-w`、`f-w`、`g-h`、`f-h` 去掉 `-y` 后对 x,z 都单调不减。分段 affine 片段中，关于 x 的斜率下界依次为 4/5、7/10、3/5、1/2；关于 z 的斜率均非负。函数连续，所以跨折点仍单调。取 `(x,z)=(-1,-1),y=1` 与 `(x,z)=(1,1),y=-1` 分别达到表中下、上界。
- `h-w` 的精确界及达到点已经在第 2 节给出。

前三对还自动受到完整前缀 P 的全部有效线性事实保护；后三对在表中单独验证。这里没有以更弱的旧界换取分离，新增侧和比较侧共用同一真实网络及所列全局界。

## 6. 原物理读出的严格分离

新增 (Rlower) 等价于

```text
t-r <= (17/40)*alpha.
```

由于 x in [-1,1]，原 q 门保留的负幅行是

```text
q-x <= 1-alpha.
```

两者相加消去 alpha，得到原物理坐标读出：

```text
Z = t-r + (17/40)*(q-x) <= 17/40.          (Safe)
```

在 (Old) 上，

```text
Z = 1/20 + (17/40)*(9/10)
  = 173/400 > 170/400 = 17/40.
```

因此这是原输出读出的严格松弛分离，差为 3/400，不是只排除了一个自由辅助变量。

真实上界达到于 `(x,y,z)=(1,1/2,1)`：

```text
g=q=1, f=p=3/4,
w=t=5/8, h=r=1/5,
alpha=eta=tau=beta=1.
```

此时四个预激活全部非零，`q-x=0`、`t-r=17/40`。例如线性性质 `Z<=343/800` 对真实网络有 3/800 安全裕量，而 (Old) 违反同样的 3/800。

## 7. 范围、成本与创新边界

本例新增两条条件幅值行，每条引用 r、t、alpha，合计 2 LE、6 个坐标 nnz、0 新连续变量、0 新 bits。观察 `r-t` 不必物化成新坐标。若 r,t 是 latent affine 读出，必须支付实际展开或算子应用成本，不能只报告六个坐标 nnz。

生成此例的条件源证书使用原 q/p 的同源关系及原 z 盒，没有分别求解两个相位子域。一般化接口需要计入四个条件端点、来源证明、原相位绑定、稀疏读出、固定原门配对、规范化、位宽和终端查询成本；本页不证明一般情况下这些界都便宜或足够紧。

相对于 D041，本例只证明其两个原门在同一关断面上精确相等的匹配前提并不必要。它不声称击败完整 guard-module 成员关系 oracle，或每一种可另行推导的有效关系。alpha=0 时 h-w 始终严格正，而 r-t 可以为零或正值，所以不能直接复用该原门对的精确关断同余。

相对于 D027，本例没有新增条件支持语法：两行就是对 signed difference 的原相位条件支持。精确 HZ 仍保留全部实际原关系；加入这些有效事实不增加精确集合表达力。普通 HZ 加完全相同两行具有相同逻辑强度。仍待证明的只能是有价值的统一生成、前向组合或完整预算优势，不能由这个控制直接宣布新的 Neural-HZ 域、PLDI 新颖性、GPU 加速或真实模型增益。

本页没有复用旧 D041 点的结果作为本例成绩；它重新给出了本网络的全部嵌套见证、六对差界和物理性质。全部比较由纸面分数运算完成，独立代理已复核条件界、嵌套混合、六对 D020 和达到点。没有扩大已有测试、权限或晋级要求。
