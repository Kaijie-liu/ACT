# 有界同源关系的前向传播及其能力边界

本候选将已有门同余从关断时的精确等式推广到有证的非零差值区间，并明确给出不同混合权重下的前向组合规则。它无需新增参考网络或虚构的 ReLU 节点，但两端必须都是原网络已有节点。规则属于条件支持与关系约化积的具体生成方法，尚不能作为已经创新完成的 Neural-HZ 定义。

本文是纸面数学说明，不是候选实现、GPU 测量或数值资格。配套 CONTROL.md 给出普通混合权重下的严格对照；真实 CIFAR/Tiny 适用率与完整成本收益尚未获得认证。

## 域载体和共同赋值

令原 HZ 元素为 H，保留其全部连续因子 xi、连续盒 B、全部原二元因子 b 及其原取值域 D、EQ/LE 谓词 P、物理读出 F_H 和输入 decoder。内部原 activation/readout 使用既有坐标或有证的同源仿射读出，不能私自复制源。

一个额外观察为 (alpha,E,l0,u0,l1,u1,certificate)，其中 alpha 是某个原相位的 0/1 视图，E 是同一 (xi,b) 上的带符号实际读出。若原 bit 使用 -1/+1 编码且已认证 +1 表示 active，则 alpha=(b+1)/2；若 -1 表示 active，则 alpha=(1-b)/2。保留原 bit，不引入替代相位；无法认证编码就不安装观察。观察表示

```text
l0+(l1-l0)*alpha <= E <= u0+(u1-u0)*alpha.
```

具体化为

```text
gamma(H,O) = {F_H(xi,b) : xi in B, b in D, P(xi,b),
             all observation inequalities hold on the SAME (xi,b)}.
```

空 O 嵌入原 HZ。若每条观察均有由原整数语义推出的证书，加入它不改变整数具体化及原输入重构；可能改变连续查询松弛。原非凸性来自保留的二元域与谓词，不来自两个区间本身。语义包含可定义预序，按具体化相等取商后得到偏序；不声称存在可计算最佳抽象或完整格。

这个载体是已知 reduced-product 型结构，不是命名本身的新颖性。与原 HZ 加完全相同谓词相比，逻辑强度相同。潜在研究贡献必须来自结构统一的关系生成、可组合性和实际精度成本，而非上述集合式。

## 不做相位子问题的种子生成

已认证无条件范围 [l,u] 可作为两状态相同的观察，无额外精度收益。原 q=ReLU(g) 的自身 bit alpha 则提供 alpha=0 时 q=0、alpha=1 时 q=g；证明采用两个整数情况，不等于运行两个子域。

一个更有用的固定源对种子是 q=ReLU(g)、p=ReLU(f)，以及已保存的同源证书

```text
lg <= g <= ug, lf <= f <= uf, L <= g-f <= U.
```

令 alpha 为 q 的原 bit。当下列端点有序时，可直接得到 p 与 d=q-p 的条件范围：

```text
P0 = [max(0,lf), max(0,min(uf,-L))]
P1 = [max(0,max(lf,-U)), max(0,uf)]
D0 = [-P0.upper, -P0.lower]
D1 = [max(max(0,lg)-P1.upper, min(0,L)),
      min(ug-P1.lower, max(0,U))].
```

证明：alpha=0 时 g<=0，故 f<=-L；alpha=1 时 g>=0，故 f>=-U。结合原范围和 ReLU 单调性得到 P0/P1。D0 来自 q=0；D1 同时使用 q=g 的范围和 ReLU 增量的全局界。g=0 时两个原 bit 选择均由各自非严格前提覆盖，不合并 bits。

这只是充分生成规则，不计算受 alpha 限制的 LP、输入子盒或相位子网络，也不枚举其他相位。缺少证书、同源绑定失败或端点矛盾时不安装这条观察，保留原 HZ；不据此猜测可行性或删除 bit。既有稳定事实原样保留。范围及差界必须实际获得并计费，不能给生成器一个免费支持函数 oracle。

## 同一原相位下的混权仿射组合

所有参与观察必须绑定同一个 alpha。对 E=c+sum_j a_j E_j，逐状态按系数正负合并上下界，得到 E 的有证范围。常数只计一次；相同 readout 或 source ID 应先按严格代数证书合并系数再求界。Add/Concat 同样使用原共同 frame，不能用独立副本的 Minkowski 和替代。

对原网络中固定对齐的两个向量 q,p 及两个真实消费者

```text
h=A*q+a, w=B*p+b,
```

若已保存 d=q-p 和伴随向量 p 的同 alpha 范围，使用固定的左侧分解

```text
h-w = A*d + (A-B)*p + (a-b).                 (A)
```

这是真实系数的恒等式，不要求 A=B、h=w 或任何关断等式。两边共有的 shortcut 若有同源证书，可以先抵消；未匹配项要作为实际带符号读出计入，不能忽略 BN、bias、padding 或坐标对齐。

仅保存 d 不足以处理 A!=B；必须保留 p 或其他足以计算 (A-B)*p 的真实伴随观察。分解不按 LP 点、margin 或事后收益选择方向。不同 alpha 的观察不能免费拼成同一条件事实。

系数包含 BN 等产生的认证区间时，先证明 (A) 对真实模型系数成立，再用区间算术包含真实系数。每项区间乘法取四个端点乘积的最小/最大值，逐步向外舍入。A-B 的区间虽然可能保守，但不能将其与 A 的相关性假设为额外独立模型输入，也不能以中点替换真实模型。只有认证为同一参数和读出的项才能严格抵消，相同区间端点不构成这个证明。源与系数误差的完整计费仍在。

## ReLU 的有界关系变换

令 r=ReLU(h)、t=ReLU(w) 为原已有门，其各自原 bits 保留。若 (A) 或其他已付费的前向证书给出

```text
L_s <= h-w <= U_s when alpha=s, s=0,1,
```

记 A_s=min(0,L_s)、B_s=max(0,U_s)，则

```text
A0+(A1-A0)*alpha <= r-t <= B0+(B1-B0)*alpha.  (R)
```

证明：h>=w 时 0<=ReLU(h)-ReLU(w)<=h-w；h<=w 时 h-w<=ReLU(h)-ReLU(w)<=0。代入条件区间即可。分数 alpha 下 (R) 是整数语义的有效线性外包，不声称是完整带标签凸包。L0=U0=0 时退回 D041 的同余特例；非零 L0/U0 无需已有等式匹配。

伴随量 t 也必须更新：由 w 的同 alpha 范围 [wl_s,wu_s] 得到 t 的范围 [max(0,wl_s),max(0,wu_s)]。因此“差值加伴随值”能继续进入下一对混权仿射消费者，再应用同一规则。新门产生的原 bits 加入 H，但不将条件锚从 alpha 偷换到新 bit。这没有解决 D029 指出的跨不同相位一阶矩免费复用问题。

对 m 维固定对齐的 paired block，每个坐标保存 d 与 p 各四个端点，活动前沿为 8m 个端点及其 source/bit/certificate 引用。每一跳都是已存观察上的前向代数运算；不为 alpha=0/1 各自执行一个网络、求解子问题或维护搜索树。若实际实现如此执行，便越过本文范围，不能以同一公式为由称其无 split。

此闭包是健全的区间关系传播，不是无损压缩或全局完备性。独立合并端点仍可能丢失观察间相关性；原 HZ 谓词继续保留这些真实关系，不能把生成器的精度限制误称为网络集合的变化。

## 严格正控中的收益继续经过下一混权块

沿用 CONTROL.md 的原 q,p,r,t,x,y,z 和 alpha；其已证明 r-t>=-17*alpha/40。追加两个原网络实际门，保留它们各自的新原相位：

```text
w2 = 1/10+t-r/2+y/5,           t2=ReLU(w2)
h2 = 1/10+11*r/10-3*t/5+y/5,   r2=ReLU(h2).
```

在现有 d=r-t 的读出基上，h2=1/10+11*d/10+t/2+y/5，w2=1/10-d/2+t/2+y/5。因此先按共同身份合并系数，得到 h2-w2=8*d/5，再应用 (R)：

```text
r2-t2 >= -17*alpha/25.
Z2=t2-r2+(17/25)*(q-x) <= 17/25.
```

第二式使用原 q-x<=1-alpha。不能先把 h2、w2 的每项各自区间化再声称保住上述抵消；所需共同读出恒等证书来自固定局部代数，不调用 LP。

CONTROL 的旧点给出 w2=t2=1/4、h2=r2=17/100，两个后门 bits 均为 1，故满足这两个新增门的精确图。但是 Z2=173/250>170/250，差为 3/250。

真实源 (x,y,z)=(1,1/2,1) 给出 t=5/8、r=1/5、w2=t2=29/40、h2=r2=9/200，达到真实上界 17/25。源 (-9/10,-9/10,0) 上 q=p=t=r=0，两个后继预激活都为 -2/25；因此后两门并非稳定门。所有原 bits 和 source 身份仍保留。

这一延伸证明已获得的关系收益可以穿过下一普通混权块，不证明后两门产生独立额外收益。旧点已被前面的关系排除；这里只比较 CONTROL 的旧系统再接这两个精确原门，不声称它通过六门的全部 D020 或完整真实新前缀联合 hull。新增关系语言仍属于已知条件支持机制。

## 完整成本和 GPU 执行形式

每个同锚观察的固定系数 m 项合并需要 O(m) 标量乘加及身份处理；两个状态都计费。计算 (A) 的稀疏系数差、两个条件差界和伴随 w 的范围，成本按实际 nnz(A)、nnz(B)、nnz(A-B) 及读出支持计入。没有全层 all-pairs 的免费假设。若保留 K 个锚，相关端点、算术与证据量均随 K 增长。

(R) 可在已有 r、t 坐标上编译成两条 LE：

```text
r-t-(B1-B0)*alpha <= B0,
t-r+(A1-A0)*alpha <= -A0.
```

一般非零系数下，差值两行至多 6 个坐标 nnz、0 个新辅助量、0 个新 bit。若伴随量 t 的条件范围也物化到终端，每坐标再加两行至多 4 个 nnz，合计至多 4 行、10 个 nnz；若它仅作前向证明元数据，则不计这两条终端行，但其端点和证据必须计费，不能假称比较系统已有对应强化。若 r/t 只是宽 latent 仿射读出，则须支付实际展开或隐式算子成本；这些坐标项不是最终 HZ 矩阵的无条件计数。RHS、界、编码 slack、alpha 编码转换、全部原谓词、证据与 decoder 均不能省略。

GPU 可按 (固定 pair, state, term) 做 gather 和有证 reduction。对于两行的乘子 lambda_U、lambda_L，局部转置贡献为

```text
r: lambda_U-lambda_L
t: -lambda_U+lambda_L
alpha: -(B1-B0)*lambda_U+(A1-A0)*lambda_L.
```

之后仍须作用真实 readout 的转置；这是普通终端谓词算子，不是 backward/dual rescue。若直接使用已认证 active=+1 的原 b，alpha 系数需除以 2，常数一半移到 RHS，转置贡献也除以 2；active=-1 的映射同时变号。上述只是执行规格，没有 GPU 性能结论。系数证书、向外舍入、临时 buffer、设备 context、传输、端点位长以及完整终端查询都须独立验证。

8m 只描述一个锚的活动前沿。若已生成的各层关系保留到终端，总谓词和证据成本随所有层的观察数累计；若丢弃旧观察，必须另证其不影响所声称的精度。不能把前沿常数宽度当成总存储常数。

## 本轮定位

D027 已提供条件支持语法；D029 已分析观察投影与跨相位复用的限制；D032 已指出独立拆项导致的冗余。本轮新增的是不用受限子问题的具体种子、不同权重下“差值加伴随值”的前向闭包，以及非零关断区间下的强对照。它没有产生新的逻辑原语，也没有证明真实网络中值得付费。

研究决定是保留这个明确生成器作为后续结构候选的比较和支撑，不将其直接命名为已完成的新域。下一真实检查应预先固定普通原节点配对，记录全部成功与失败前提，并比较强单门和已有全局差分行。若只是重复已有约束或真实增强仍稀少，应修改关系语言，而不是扩大测试框架或改锚追逐正例。

本轮不改变正式 1870/2413 与独立 61/400；formal_gain=0。所有原因子、bits、谓词、共同身份、decoder 和 fail-closed 保留。新颖性、数学健全性、真实适用率、组件资格、GPU 速度和正式成绩分别报告。
