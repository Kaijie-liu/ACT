# 卷积与残差联合消费者的接入边界

数学组件通过后，下一研究对象必须是完整共享消费者，而不是直接把单目标投影插到 CIFAR/Tiny 的一个卷积位置。保存的原图已经证明存在未覆盖残差支路；这改变了下一步动作：先确定可闭合的联合前沿及其语义和总成本，再注册真实接入，不继续扩充通用适配框架。

## 原图中的具体消费者

以下只读事实来自 D120 的 [large](../../results/d120_mixed_consumer_source_20261002_v1/complete_0.json)、[medium](../../results/d120_mixed_consumer_source_20261002_v1/complete_1.json) 和 [Tiny](../../results/d120_mixed_consumer_source_20261002_v1/complete_2.json)。没有读取新原模型、执行模型或新 source worker。

| 模型 | 父 ReLU 输出 | 主支与额外消费者 | 局部研究覆盖的范围 |
| --- | --- | --- | --- |
| CIFAR100 large | Relu_2 的 127 | Conv_3；Add_8 的 identity skip | 五个位置、全部 64 输出通道；不是完整 32×32 空间 |
| CIFAR100 medium | Relu_2 的 121 | Conv_3；Conv_8 的 1×1 shortcut，经 BN 后进入 Add_10 | 五个位置、全部 128 输出通道；不是完整 8×8 空间 |
| TinyImageNet medium | Relu_2 的 121 | Conv_3；Conv_8 的 1×1 shortcut，经 BN 后进入 Add_10 | 五个位置、全部 128 输出通道；不是完整 14×14 空间 |

large 的 identity 系数 1 确定保留了原幅值消费。medium/Tiny 的记录证明 tensor-level shortcut 存在，但本轮没有重读数值，不能据此声称每个标量系数都非零。对它们的正确判断是未完成逐列消费者覆盖，不得删除未经覆盖的列，而不是所有列永远不可消除。

即使没有 shortcut，一个 3×3 多通道卷积也有跨输出通道及重叠位置的共享输入。单一 branch 被解析、或五个窗口得到证书，不等于某一父幅值的全部消费者已覆盖。D125 的公开 readouts 仍是调用者声明；传空 tuple 不能认证真实消费者完整性。

large 的 [完整保存图](../../results/d025_interval_capacity_20260930_v1/complete_0.json) 进一步显示 Add_8 输出 133 进入 Conv_9、BN_10、Relu_11，同时进入 Add_14 的下一条 skip。medium 的 [保存图第 2 项](../../results/d015_source_shielding_20260928_v2/partial_source_evidence.json) 显示 Add_10 输出 129 同样先经 Conv_11、BN_12、Relu_13，并继续进入 Add_16。两个保存记录的模型 SHA 与 D120 对应来源一致。不能把实际结构简写为紧接着 ReLU(Add)，也不能假设跨过一个残差块便已消除全部线性支路。此项下游结构结论只由已读的两个 CIFAR 图支持，没有在本轮额外认证 Tiny 的完整下游图。

## 联合变换的数学范围

候选推广可同时选择一组待消去父幅值 Q，并对它们的全部真实 ReLU 消费者使用同一个源、相位表和列身份。对每个目标 j，完整展开其预激活中 Q 的系数，得到：

```text
q_i = ReLU(f_i),  t_i = (1-2 tau_i) f_i
g_j = d_j + sum_i a_ji q_i
h_j = d_j + sum_i a_ji tau_i f_i
h_j + kappa_ji t_i <= rho_ji
T_j_plus < 1
```

若所有 f_i 均仅依赖最终保留坐标、每个目标的证书在同一保留前沿有效，且全部 Q 消费者已覆盖，则逐目标安装 D124 的原相位条件四行、保留父符号守卫及所有未替换约束，再一次投影 Q，是 sound 联合外包。证明是每条原轨迹同时满足每个目标的标量包含关系；不为目标复制源，也不引入独立的相位身份。目标间可以保留已认证的有向依赖，但不能遗漏其限制或引入未证循环。

这只是有条件的数学推广，尚未实现、预注册执行或通过测试。各目标同时满足外包不意味着存在同一组真实父幅值实现所有目标；共享源和 bits 的保留不自动恢复被丢弃的跨目标幅值相关性。旧 HZ 加相同证书仍是强比较对象。

一个纸面反例明确了这种损失：x∈[-1,1]、q=ReLU(x)，两个目标同为 r_j=ReLU(1/4+q/4)。取 tau=0、kappa=1 得 rho=5/4、T_plus=1/4、E_plus=5/12，目标原上界 1/2。在 x=1/2、全部原 bits 激活时，逐目标外包允许 r_1=1/4、r_2=1/2，而真实两者必须均为 3/8。这个未执行的数学控制说明联合安装并不自动保存共同幅值误差，不能据此预告保旧或涨分。

原始 affine skip/readout 不是 ReLU 目标，不能直接用上述四行覆盖。如果它仍读 Q，当前标量组件必须拒绝。下一实现必须为该线性端口证明可组合的关系并计入新变量、谓词及误差成本，或沿完整 affine DAG 展开到真正闭合的非线性/终端读出前沿。若只把 identity skip 的每个 q_i 改名成一个新连续端口，幅值列并未减少；若只存 q_i=ReLU(f_i) 的计算图，终端又恢复所有旧列，仍只是转移成本，不构成目标要求的创新收益。

可沿 affine DAG 对每个端口维护 v=d_v(z,R)+C_v Q；穿过 Add/Conv/已认证 inference BN 等精确转移 C_v，遇 ReLU 记录其完整目标关系并以保留的 r_j 继续，直到所有 raw Q 路径均到达已登记前沿或最终线性读出。若只允许以 k 个线性 aggregate w=BQ 精确重写剩余端口，则必须有 C=TB，故 k>=rank(C)。特别是 C 含 I_m 时，该重写不能用 k<m 减少 m 个幅值。这个必要条件仅针对线性端口因式分解、且未利用额外已证函数恒等式；它不是所有非线性域的不可能定理。已存活目标的逆关系若能复用幅值也须另证并计费；rank 较小仍不能免除填充、全部 nnz、精度及终端费用。

## 下一次来源实验必须回答的问题

下一候选应先固定全消费者前沿、完整人口、旧 HZ 加相同证据的强参考、数学包含关系和完整成本。然后才做新预注册；本文件不是已登记的新 worker 合同，不授权改写或重跑 D125。

必须测量同一源和相位下后续 Conv、Add 和真正下一激活的界，而不只数 rho 命中、变量减少或前激活微小变化。实际参数、BN 常量、标量端口、frame 与所有原 bits 仍需绑定；数学 System 不能代替它们。

GPU 方向要覆盖稀疏共享源、批量支持归约、证书/行生成、终端转换与重构费用，而不是仅把一个小例送上设备。完整物理成本和能力保旧晋级门不变。当前精确有理 CPU 数学组件是证明与实现参考，不是 GPU 目标的替代终点。

以上接入问题不构成外部阻塞：可继续研究联合关系与闭合前沿。普通 CNN/PWA 优先，Attention/smooth 的定义与查询方向保留；完整 Goal active，正式新增仍为零。
