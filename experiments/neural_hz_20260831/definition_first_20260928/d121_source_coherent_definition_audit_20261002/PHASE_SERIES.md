# 保留原相位的有限因果级数与共同尾界

本文给出一条面向普通前向 ReLU 块的有证截断规则：保留原二元相位，以有限次数的相位交互和一个共同尾生成元包围整块输出。它不要求精确删去每条高阶路径，也不要求全块范数小于一。先证明保留完整原 HZ 的冗余模块，再给出真正改变块表示的有证外包域及严格嵌套例。后者不再只是加 cut，但混合多项式机制已有先例，且尚无相对原终端求解的精度或成本优势，不据此启动新的工程实现。

这是纸面定义与证明，不是候选数值执行。共同前沿的连续／二元因子、EQ/LE、原门符号守卫、共享 frame、输入 decoder 和原零点相位选择保留。下文明确区分保留全部旧图方程的模块与替换块内输出方程的数学外包，不能把后者冒称精确等价。

## 元素与精确有限展开

将一个已认证的前向块按拓扑顺序写为

```text
f = A x + c
g = f + W q
q = diag(beta) g,
```

W 严格下三角，N 为原门数；x 是同一个原 HZ 前沿的读出。beta 是各原 signed binary 的认证 0／1 视图，不是新建或连续化的相位。q=beta*g 必须与原符号 guards 一起解释，不能替换 guards。

按结构预先选择固定参考 tau∈{0,1}^N，令 T=diag(tau)、D=diag(beta−tau)、J=(I−TW)^−1。J 仅为数学记号，实际应通过严格下三角前向代入作用于向量；不能物化逆矩阵后称成本免费。定义

```text
q0 = J T f
h0 = f + W q0
z = q − q0
v = J D h0
K = J D W.
```

h0 包含完整 c，不能遗漏偏置。从原式移项得 z=v+Kz。K 严格下三角，所以 K^N=0，逐原赋值有

```text
q = q0 + sum_(j=0,...,N-1) K^j v
Pk = sum_(j=0,...,k-1) K^j v
q = q0 + Pk + K^k z,       0<=k<=N.
```

Pk 对原相位偏差的次数至多 k，系数依赖共同 x。这是有限因果代数，不是运行时输入／相位 split 或 BaB。

考虑元素 N_k=(H,tau,q0,Pk,K^k,t,decoder)，并引入同一个连续向量 eta，以

```text
q = q0 + Pk + K^k eta,   |eta|<=t
```

作为共同关系。只要已证 |z|≤t，每个原状态都可取 eta=z 扩展。因此保留原 H 的具体化投影回原坐标仍恰是原 H，原 H 是显式嵌入，原非凸相位全部保留。语义包含可定义偏序的等价类，但没有证明完整格或可计算最佳抽象。

只保留此包络并改写旧原门方程会得到另一种抽象语义。用户并未额外禁止对连续关系作有证明的等价改写；保留完整 H 是本节投影等价证明的条件，不是永久冻结所有谓词的新增硬门。本文尚未证明一个替代表示的完整守卫、共享源、解码和查询合同，更没有证明它能保住 1870，因此本轮不实施替换。不能把保留旧 H 的冗余模块描述成已完成不同域语义的创新，也不能用这个保守比较条件先验否决后续定义研究。

## 无需收缩假设的向量尾界

U 为 0／1 对角矩阵，可能偏离参考相位的门记 1。只有已证 beta_i=tau_i 的门才可置零；含零且有两个合法标签时不能擅自固定。取得可靠 |h0|≤hbar，定义非负量

```text
C = (I−T|W|)^−1
M = C U |W|
a = C U hbar
t = sum_(j=0,...,N-1) M^j a.
```

由于 |J|≤C、|D|≤U，逐项 |K|≤M、|v|≤a。M 同样严格下三角，故 |z|≤t，且

```text
|q−q0−Pk| <= tk = M^k t
                 = sum_(j=k,...,N-1) M^j a.
```

于是 t_(k+1)≤t_k，t_N=0。任何常用范数大于等于一都不妨碍此有限界成立；但小 k 的尾不保证小。利用恒等式

```text
t = (I−(T+U)|W|)^−1 U hbar,
```

可通过原稀疏结构上的前向代入计算 t，而不显式构造 C 或 M。再应用 k 次 M 即得 tk。

若额外认证同一从属范数下 sup_beta ||K||≤rho<1 且 ||v||≤B，才有深度无关的简式

```text
||q−q0−Pk|| <= B sum_(j=k,...,N-1) rho^j
             <= B rho^k/(1−rho).
```

rho≥1 时禁止使用后一分式，也不因失败改用未声明路径。

## 同源组合与包络嵌套

对 Affine／Conv 读出 y=Lq+d，直接得到

```text
y = Lq0 + LPk + LK^k eta + d.
```

同 frame Add 先合并作用于同一 eta 的系数，Concat 则堆叠。复制 eta 再各自求盒界通常更松。后继原 ReLU 仍可写成原 beta' 乘同一读出并保留其全部 guards，但多项式次数增加；对扩大的前向块重新构造并计费，不声称免费闭包。已有旁路仍消费的身份不能删除。

固定同一 x、beta，令 Phi(eta)=v+Keta、B_t={eta:|eta|≤t}。因为 |v|+|K|t≤a+Mt=t，Phi(B_t)⊆B_t。因此

```text
Phi^(k+1)(B_t) subset Phi^k(B_t)
Phi^k(eta) = Pk + K^k eta.
```

这是精确多项式包络的逐纤维嵌套；k=N 时变成唯一固定点，在满足原 guards 的可行 (x,beta) 纤维上就是唯一真实 z。若每一级都另外独立采用 McCormick lowering，其 LP 投影不自动继承这种嵌套；不得借此删除以前的有效系统或宣称求解一定增强。

## 真正替代块方程的候选域

为了不把“完整保留旧图”误立为永久硬门，再给出一个只用统一 tau=0 的具体外包族。它是数学候选，未对生产图执行改写。

保留前沿关系 H0、其全部连续及原二元因子与输入 decoder，加入该块的全部原门相位 beta，并保留同一共同源 f=A x+c。记

```text
Phi_(x,beta)(eta) = diag(beta) (f+W eta)
hbar >= |f| on the complete admitted frontier
t = (I−|W|)^−1 hbar
B_t = {eta : |eta|<=t}.
```

定义 Gamma_k，1≤k≤N，为满足以下条件的 (x,beta,q) 集合：x 来自 H0，beta 是全部原 0／1 相位视图，存在一份共同 eta∈B_t 使 q=Phi^k(eta)，并满足固定的 G(x,beta,q)。G 包含原预激活 g=f+Wq 的符号条件 beta_i=0⇒g_i≤0、beta_i=1⇒g_i≥0、q≥0、已有有效坐标界及其余保留谓词；符号条件在 g_i=0 保留两种原标签。

此处不再把块内全部 q_i=beta_i*g_i 输出方程重复放进 G，否则立刻退回冗余模块。原四行精确门图中等价于该输出等式的部分也不能一面宣称已替换、一面暗中用于证明严格外包。可靠的 g 界可将上述符号条件写成 L_i(1−beta_i)≤g_i≤U_i beta_i，属于原 EQ/LE 语言。没有删除、合并、pivot 或连续放松任何原 beta。

语义上，Phi^k 是最高 k 次的原相位多项式，系数依赖共同 x 和 eta。eta 是有界连续尾因子，t_i>0 时可归一化为 eta_i=t_i*xi_i；t_i=0 时该尾坐标固定零，并不删除原二元因子。空块精确嵌入原 HZ，k=N 恢复这一块的精确原图，有限 k 允许有证外包。共享 frame 下 Gamma 的集合包含给出语义序，不预称最佳抽象或完整格。

三条可证明性质如下。

1. **健全性。** 每个原真实块输出满足 |q|≤t，因为 |q|≤hbar+|W||q| 且 W 因果。取同一 eta=q，它是 Phi 的固定点，故每个 k 均包含该真实状态及全部合法零点标签。
2. **精度嵌套。** 对任一固定可行前沿和 beta，|Phi(eta)|≤hbar+|W|t=t，所以 Phi(B_t)⊆B_t。于是 Gamma_(k+1)⊆Gamma_k；各级与完全相同的 G 相交，不破坏包含。
3. **有限精确恢复与原相位含义。** K=diag(beta)W 严格下三角，Phi^N(B_t) 是唯一固定点。与 G 的符号条件一起，q=diag(beta)(f+Wq) 恰是当前前沿和保留 G 下的原 ReLU 块图，不恢复任何先前已遗忘的跨块关系。任何 k≥1 时，beta_i=0 都强制 q_i=0；beta_i=1 的输出在有限 k 下可能有抽象误差，不能说其已精确等于 g_i。

这是一个真正不同的非凸混合多项式外包定义，而非旧 HZ 加冗余行。非凸性并未只停留在未使用的 bit 元数据上：原 bits 直接选择输出中的相位多项式与符号守卫。它也没有因为为误差使用 B_t 而整体变成区间或 Zonotope 域。但 typed mixed-polynomial 表达本身已知，下面仍需检验为何这个有证因果层级比其直接已有实现值得使用。

一个严格普通例说明有限级并非暗中精确：x∈[-1,1]，

```text
q1 = R(x+1/4)
q2 = R(q1/2−1/8).
```

这里 hbar=(5/4,1/8)，t=(5/4,3/4)，本例 G 仅为上述符号守卫、非负和真实全局坐标界 q1∈[0,5/4]、q2∈[0,1/2]。取 x=1/2、beta=(1,1)、eta1=1、eta2=0，所有这些连续选择都在各自盒内，则 Gamma_1 允许 q=(3/4,3/8)：两个预激活分别 3/4、1/4，符号和坐标界均合法。但 Gamma_2 在同一 x,beta 上唯一给出真实 q=(3/4,1/4)。两门都有非零偏置和严格开关的源区域；分别在 x=−1/4、x=0 的零点标签没有被删除。这个例子证明 Gamma_2 严格包含于 Gamma_1，不是相对生产 HZ 的增益控制；若给 G 加回等价的完整门输出方程，这个严格差自然消失。

## 抽象变换的准确范围

作为一个完整已绑定块对前沿 H0 的变换，Gamma_k 是健全的前向外包。Affine／Conv 可以作用于其共同多项式读出，Add／Concat 必须复用同一 (x,beta,eta)，不能给多个消费者独立尾源。普通终端查询仍需健全 lowering，候选可行点仍须经原输入 decoder 和具体网络验证，不能以尾因子见证冒充实际输入。

不能把扩大旧块后重新构造 Gamma_k 自动当成“对旧 Gamma_k 全部伪输出逐个再做一个 ReLU”的健全变换；前者重新利用原共同前沿语义，后者的输入集合还包括旧抽象伪点。两者是不同的合同。若要逐层闭合，可先把已有多项式读出作为共同界面，再对新门建有证块，但必须支付界面方程、源复杂度和新原 bits。本文没有证明普适逐层紧闭包，也没有假装保留未简化全图就已经解决这些问题。

## 有偏置混符号链及错误截断的反例

令 q_l=R(x_l+1/8+a_l q_(l−1))，x_l∈[-1,1]，初始前驱为零，a_l 交替为 1/2 和 −1/2，参考统一 tau=0。每个门都有严格开关的真实源状态。J=I，rho≤1/2，B≤9/8，因而

```text
||q−Pk||_infinity <= (9/8) sum_(j=k,...,N-1) 2^(−j)
                   <= (9/4) 2^(−k).
```

这说明固定阶误差可以有证随 k 衰减；它不是与现有 HZ 的严格性能比较。

三门取 a2=1/2、a3=−1/2，x=(7/8,−1/8,7/8)。则 f=(1,0,1)，所有原相位为 1，q=(1,1/2,3/4)。一次近似 P1=f，而真实尾为 (0,1/2,−1/4)。输入在盒内部、实际预激活均非零；该例直接否定“截断仍精确”和“尾总可当非负余项”。连接系数改为 2、−2 时仍然有限因果，但不保证小阶尾界有用。

## 完整成本不由次数上界决定

设 s=nnz(W)，源维数 p。数值向量上的三角作用为 O(s+N)，但全部 q0/h0 源系数的直接构造可达 O((p+1)(s+N))，最多产生 O(Np) 系数；填充、位长和原输入身份还需计入。hbar 已取得后，向量尾证书的直接工作为 O((k+1)(s+N))，不能把前面的源构造排除在全账之外。

显式 Pk 的单项式数仍可能很大。一种因式写法是

```text
u0 = eta
u_(j+1) = J D (h0+W uj)
q = q0 + uk.
```

这保存同一个尾，不免费提供终端查询。即使 tau=0，直接线性 lowering 也约需 kN 个二元乘积量和 4kN 条乘积行，一般 tau 还需三角线性定义或其展开。对于前述冗余模块，原 H 的 N 个门也仍在；对于替代 Gamma_k，原块输出方程不重复保留，但前沿 H0、全部 bits、G、尾因子、旁路和 decoder 仍计费。两者都必须计入中间连续量的可靠界及宿主／设备副本。独立乘积包围还可能丢掉同一 beta 多次出现的关联。

因此“固定次数”“可用矩阵操作”都不证明总费用小于原 HZ，也不构成 GPU 资格。没有为此写新框架或重复继承测试。

## 已知机制与研究取舍

相对 [D013](../d013_budget_quotient_20260928/D013_BUDGET_QUOTIENT_AUDIT.md)，本式允许明确误差的有限截断，而不是要求高阶项精确消失；相对 [D117](../d117_quantified_observation_loss_20261002/THEORY.md)，它给出具体可计算的误差合同，不假设有限接口任意深度精确；也不依赖真实滤波器恰好共线。

但 typed continuous／Boolean 多项式及依赖传播已有 [mixed polynotopes](https://arxiv.org/abs/2009.07387) 和 [神经网络 polynomial zonotope 验证](https://arxiv.org/abs/2207.02715) 等先例；原 bit 乘连续量的编码不是新机制。本文有限级数、nilpotent resolvent 和尾估计本身是经典代数／包围方法的应用。未证完整终端精度／费用优势前，将它保存为有明确边界的研究候选，不称已经实现创新 Neural HZ。

同轮还反代审查了 e=R(g+r)−R(g)−b*r，其中 b 必须是 g 的原合法 0／1 ReLU 相位，包含 g=0 的两种原标签。它等于 R((1−2b)r−|g|)，也正是 [D012](../d012_phase_budget_20260928/D012_RESULTS.md) 的跨门 Bregman charge。局部化上界 e≤R(|r|−|g|) 有效，但不足以再把余项改名立为新域。
