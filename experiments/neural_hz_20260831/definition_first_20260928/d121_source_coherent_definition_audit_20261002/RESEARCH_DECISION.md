本轮完成了一个真正改变块表示的非凸外包定义及其健全性、逐阶包含和有限精确恢复证明；也明确它仍接近已有混合多项式方法，尚无实证精度／成本优势。没有将论文候选、新名称或人工例记成 Neural HZ 已经成功。

## 先把已执行结果记清楚

[D120 结果](../d120_mixed_consumer_source_20261002/RESULTS.md) 已正式归档为：3869 项测试通过、三模型固定 1600 个读出完整完成、下一 ReLU 输出界零改善。Tiny 唯一共同核额外改善发生在已负的激活前界。其九个冻结文件和 16 个工件 SHA256 均只读复核一致；不修补、不重跑。

[源信息损失对照](../d120_mixed_consumer_source_20261002/SOURCE_LOSS_ANALYSIS.md) 证明，同一已知公式若先合并共同源，可以在一个有偏置、非零残余且后继真实跨零的例上把上界降低 7/40。该例只定位算法保守性，不能预测真实 1600 行的改善数，也不是新的曲率原理。

## 不再把完整旧图留存追加成用户硬门

用户要求保留原二元相位、非凸性、连续因子与谓词语言、共享输入、重构、fail closed 和最终逐例／逐家族保旧；这不等于所有旧连续方程永远不能改写。新抽象域可以研究有证等价化简或明确健全的外包，但仍必须经过原数学、真实结构、shadow 和完整回放门，不能默认启用或假定保旧。

[相位级数定义](PHASE_SERIES.md) 明确区分两者：保留完整 H 时只是冗余多项式模块；新 Gamma_k 用共同尾源、全部原 bits 和原符号守卫重述一个已绑定前向块，而不重复安装旧门输出等式。固定前沿、块、可靠尾盒和 G 时，原真实图被所有 Gamma_k 包含，Gamma_(k+1)⊆Gamma_k，N 阶恢复该前沿和 G 下的精确块图。普通有偏置二门例严格区分一阶与二阶，说明这次定义确实改变了外包语义。

这不是对 CZ／Zonotope 的替换，原 bits 实际参与非线性生成元和守卫。也不是高水平创新已建立：mixed polynotope、神经 polynomial zonotope 以及有证余项传播已有直接先例。完整逐层变换、原终端的低成本消费和真实 CNN 收益仍未证明。不能因有了候选定义就再扩建测试／适配框架。

## 对 smooth 方向的明确取舍

[Attention 关系研究](ATTENTION_RELATIONS.md) 否决了两项具体假设：log 概率低秩不推出概率／value 低秩；在普通连续共同源上，它也不一般地产生 simplex 之外的概率多项式恒等式。后者有完整双齐次化／指数独立证明。原两个未解 ViT 的已保存布局分别为 N17/d16、N5/d16，log-rank 上界在这两种布局均是空约束，不能拿它启动模型工程。

源条件交叉比及 value 子式传播仍保留为候选接口。一个全非零 dense value 控制给出 −19/2000 的假输出行列式，而真实有序源必须非负；固定第一 query 时可转成普通 LP 线性必要条件。但它只严格区分已声明的边际／前缀参考，尚未通过完整同源强参考，数学原理也已有先例。完整两两展开在 N17、value 宽16 时已有 2219520 项／head／layer 的直接乘积账，不能宣称 GPU 上成本自动可接受。

正公共幅值与重复 LayerNorm 的初步纸面审查也保留在本记录：若 y=u/sqrt(E)，同轴纯归一化给出 u'=C u、E'=epsilon E+||C u||²/d；齐次 Linear/ReLU 能保持共同幅值。但普通不随幅值缩放的偏置及未归一化残差会破坏这一窄闭包。本项目已保存的两个 ViT 前端是固定统计 BN 而非该 LN 链，因此没有为此建候选或扩大范围。这个代数观察不是新的 normalization 理论。

## 下一项可反证工作

PWA 主线优先对 Gamma_k 的终端消费作一次纸面强比较：在完整原相位和共同尾身份下，明确有哪种普通重复结构能减少实际终端工作，或让可支付的前向查询比现有 HZ 松弛更紧。直接逐轮二元乘积 lowering 可能反而需要 kN 量与约 4kN 行；若只是重建更大图，应记录这一候选失败，不以形式新颖掩盖成本。

比较中可以使用有证近似，但不能把 Gamma_k 比原精确图更宽隐去，不能把精确多项式语义的嵌套借给未经证明的独立 McCormick 松弛，也不能声称扩块重算模拟了旧外包的所有伪状态。外部先例与相同信息的已有方法必须列明，但不新增“必须严格强于所有等价编码”的不可能门。

Attention 只保留聚合跨行乘积是否有可消费、可支付优势的问题；不通过特殊矩形 key 或未认证 κ 提前升级。CIFAR100、TinyImageNet、13 家族、其他家族、GPU 和 smooth/Transformer 的完整目标仍在，不以本轮小例替代。
