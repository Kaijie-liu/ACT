# Attention 共同源关系与低秩简化的边界

本轮检验一个定义级假设：能否把 attention 的低维共同源变成小型非凸 Neural HZ 接口，并让实际 value 读出消费它。得到的判断是，低 log 概率秩不能支持概率／value 的线性压缩，通常也不会自动产生有限次的概率多项式恒等式。保留源条件的交叉比与二阶子式有可证明的前向消费规则，但这些是已知数学，尚不足以宣称新域创新。

全文为纸面研究、原始文献阅读和已保存图结构的只读核查。没有候选代码、冻结运行、新数值计算、模型前向、求解器或 GPU。原 HZ、原相位、输入身份、decoder 和全部晋级门不变。

## 候选载体及诚实的语义范围

考虑 D=(H,B,A,O,decoder)。H 是保留全部原连续因子、原二元相位、EQ/LE 和共同 frame 的 HZ。B 是已有的健全概率／value 包围，A 保存下述由同一实际 source 推出的交叉乘积带，O 保存实际线性消费者和被明确选择的二阶观察。所有记录都指向同一 theta，不能为不同概率行、value 通道或残差重新选择源。

附加连续概率量 p 有有限界且每行和为一。对有限 logits 的真实 softmax，所有 p>0；任何实现使用的严格正下界必须可靠认证。产生零概率的 mask、不同支持集、Dropout、跨 head 或跨 batch 合并均不自动属于这里的公式。空 B/A/O 不增加坐标时精确嵌入原 HZ。添加正确抽象块时每个真实网络状态有共同扩展，因此得到健全外包；并不声称保留此前较松抽象的全部伪概率赋值。

具体化取满足 H、B、交叉乘积带及观察定义的同一赋值，再读取输出。乘积关系一般非凸，原二元非凸性同时保留。这种容器在已知混合非线性／多项式关系域的表达能力范围内；它不是因为名字或多加几条约束就成为新的抽象域贡献。其潜在价值只能来自可认证的结构生成、前向组合和完整成本下的真实收益。

## 低 log 秩不等于概率或输出低秩

对无 mask、共同支持的标准实数 attention，S=κ QK^T，P 是逐行 softmax。C=I−11^T/n，逐行归一化常数被 C 消去，故

```text
(log P) C = S C
rank((log P) C) <= d_k.
```

这是已知 softmax bottleneck 机制的直接应用，不是本项目新发现。[Yang 等 ICLR 2018](https://arxiv.org/pdf/1711.03953) §2.1 的 row-shift／rank 分析是明确先例。

即使 d_k=1，P 也能满秩。令四个 key 为 (0,1,2,3)，query 为 (0,log(4/3),log(5/3),log2)，κ=1。P 的四行是

```text
(1,1,1,1)/4
(27,36,48,64)/175
(27,45,75,125)/272
(1,2,4,8)/15.
```

令 t=(1,4/3,5/3,2)，未归一化矩阵为 Vandermonde 行 (1,t,t²,t³)。其行列式为 4/243，四行归一化分母的乘积为 2856000/729，故 det(P)=1/238000>0。所有概率至少 1/15，并非尖峰或数值极端例。乘任意可逆四通道 value 矩阵，PV 仍满秩；例如全部元素为 ±1 的四阶 Hadamard 矩阵就足够。因而 log-rank 不能被免费当成 value 低秩证书。

更具体地，[已保存的两个真实 ViT 图](../d107_vit_graph_inventory_20261002/RESULTS.md) 的纸面布局推论分别为 n=17,d_k=16 和 n=5,d_k=16。中心化矩阵列空间本来至多 n−1 维，因此 rank≤d_k 在这两种布局均无额外约束。该判断只复用原整数布局证据，不重跑 shape inference、不认证数值 κ，也不将模型名用作运行时选择条件。它足以否决把此 rank 上界当作这两模型的主要简化来源。

## 泛型低 log 秩没有额外概率多项式恒等式

下面证明关闭更强的误推：从低 log 秩不能一般地推出少数低阶 toric 概率等式。限定只看概率坐标、遗忘 query/key 源；保留源变量、非多项式关系或不等式的方案不受此否定。

取两个固定正 query 1 和 sqrt(2)，n 个 key z_j 在任意非空有界开盒中自由变化，κ=1。两个概率行为

```text
p_j = exp(z_j) / sum_l exp(z_l)
r_j = exp(sqrt(2) z_j) / sum_l exp(sqrt(2) z_l).
```

命题：任何在整个这组共同源上恒为零的实系数多项式 F(p,r)，都属于由 sum p−1、sum r−1 生成的理想。换言之，概率坐标中的多项式恒等式只有 simplex 恒等式及其多项式组合。

证明：分别按 p、r 两组变量将 F 齐次化到各自最大次数 D1、D2，使用乘子 (sum p)^(D1−deg_p) 和 (sum r)^(D2−deg_r)。得到双齐次多项式 G，且 G−F 属于上述 simplex 理想。代入真实概率并清除两个严格正分母，得到有限指数和

```text
sum_(alpha,beta) c_(alpha,beta)
  exp((alpha + sqrt(2) beta) dot z) = 0,
|alpha|=D1, |beta|=D2.
```

不同整数多重指数对产生不同指数向量：若 alpha+sqrt(2) beta=alpha'+sqrt(2) beta'，逐坐标的有理与无理部分迫使 alpha=alpha'、beta=beta'。有限个不同指数向量的指数函数在任何开盒上线性独立。可选一个避开有限个正交超平面的方向，沿盒内短线段限制函数，得到不同一维指数；在一点对 0 至 M−1 次求导形成可逆 Vandermonde 系统，所有系数遂为零。因此 G 是零多项式，F 属于 simplex 理想，证毕。

sqrt(2) 只是纸面证明用的普通正 query，不是新的数值特例处理要求。若要求恒等式对 query 的普通开区间也成立，区间内必可选有理无关的一对 query，同一证明仍适用。模型／输入可达性若禁止自由 key 开盒，结论不能直接套用。固定有理指数确可能产生高次 toric 等式，也不与此命题矛盾。

固定特殊 affine logit 依赖仍有用：若 v^T S=constant 且 v^T1=0，则 sum v_i log p_i=constant；整数 v 可转成多项式乘积等式。矩形 logits (0,x,y,x+y) 的 p00 p11=p10 p01 正是经典独立性／toric 模型，不能当泛型 attention 性质。[Geiger、Meek、Sturmfels](https://arxiv.org/pdf/math/0608054) 的指数族与 toric 因式分解研究是直接先例。本项目未建立上述概率投影命题的外部新颖性，不将完整证明当成论文贡献已获确认。

## 真正保留源的交叉比合同

对任意两个真实 query i,j 和 token a,b，定义同源量

```text
Delta_ijab = κ (q_j−q_i)^T (k_b−k_a).
X = P_ia P_jb
Z = P_ib P_ja.
```

两个行归一化常数恰好消去，故 X=exp(Delta_ijab) Z。若整个原源上可靠认证 L≤Delta≤U，则

```text
exp(L) Z <= X <= exp(U) Z.
```

该式适用于动态 Q/K，并不要求固定矩形 key 或 d_k<n−1。若只得到宽区间，它可能毫无新增收益。κ 的符号和数值、乘积包围、舍入误差和源身份都必须先认证，不能从惯例猜测。有限个选择的交叉比只是必要条件，不宣称重新精确表示完整 softmax 图。

令 D_ab=X−Z。对同源 value bank V 和真实 Y=PV，两个 value 通道 u,v 满足

```text
Y_iu Y_jv − Y_iv Y_ju
 = sum_(a<b) D_ab (V_au V_bv − V_av V_bu).
```

展开两个双和，把 a=b 项消去并成对合并 a,b，立即得到该二阶 Cauchy–Binet 恒等式。value 可以依赖 theta；等式必须逐同一赋值解释，不能为概率和 value 另取独立源。它给出了从概率跨行关系到实际 value 输出关系的具体接口，而非只保存不能消费的 log-rank 标签。

Affine 读出使用同一观察的线性组合；同 frame Add/Concat 必须合并共享源。追加原 ReLU 时保留原二元门及守卫，但本文没有证明二阶观察经过 ReLU 仍然低成本闭合。一般偏置下应将常数 1 一并齐次化，或展开并支付新增的一阶项；不能直接套用无偏置矩阵乘法的公式。下一 Attention 的 QK 是双线性读出，也不能凭上述反对称二阶观察假装已覆盖所有对称乘积。

## 严格但范围有限的 value 正控制

考虑正标量 query q_j≥q_i 和递增标量 keys，κ>0。所有 Delta_ijab≥0，因此所有 D_ab≥0。这是已知的单调似然比／二阶全正关系，不是新的概率定理。它比仅保存前缀概率序更强。

取两个候选概率行及一个全部元素非零的普通 value bank：

```text
a = (1/5, 7/20, 9/20)
b = (19/100, 21/100, 3/5)
V = ((1,1), (2,3), (1/10,1/5)).
```

两行均正、和为一、严格递增；b 的两个前缀分别 19/100、2/5，小于 a 的 1/5、11/20，故通过相应一阶 stochastic-order 条件。概率子式却为 (-49/2000,69/2000,231/2000)，而 V 子式为 (1,1/10,1/10)。于是

```text
aV = (189/200, 67/50)
bV = (67/100, 47/50)
det([aV;bV]) = -19/2000 < 0.
```

真实有序 rank-one query/key 结构的相同输出行列式必非负。这里的严格差不依赖零概率、零 value 或消失的后继。

还可给一个源边际比较：固定 keys=log(4,7,9)、第一 query=1，第二 query t∈[1,6]，则第一行恰为 a；t=6 的第二行为 (4096,117649,531441)/653186。b 的每个坐标都位于 t=1 与 t=6 对应坐标之间，bV 的每个坐标也如此，所以单独的真实概率／输出边际范围不会排除它。第一行输出固定时，二阶关系成为普通线性必要条件

```text
(189/200) Y_j2 − (67/50) Y_j1 >= 0,
```

它排除上面的 bV，展示一条确实可由普通终端 LP 消费的纸面后果。

比较边界不可省略：未证明此假点通过保留同一个 t 的所有 source-labelled 单门 hull、D110 完整端点参考或实际 ACT lowering。该差异归于已知似然比信息及其共同 value 消费，不能报告为新域新颖性、真实反例或正式 CERT。固定第一 query 也是本控制的明确限制，不代表所有 self-attention query 固定。

## 完整成本与下一科学判断

若 m 个 query、n 个 token 全部两两展开，概率子式数为 choose(m,2) choose(n,2)。源 Delta 的实际 sparse/dense 双线性支持、exp 包围、每个乘积的 lowering、全部 value 子式及其乘积都另付费。d 个 value 通道的全部消费者数为 choose(m,2) choose(d,2)，直接求和至少还含 choose(n,2) 倍工作。不能称这些张量天然低秩或 GPU 上免费。

对原 n=17,d_k=16、每 head value 宽度 16 的布局，完整概率子式就有 136²=18496 个／head／layer；全部二阶 value 读出按直接公式有 136×120×136=2219520 项乘积／head／layer，尚未计源展开、宿主／设备共存、旧 HZ、普通终端和 decoder。n=5 也应按真实成本记录，而非把小例推广成低成本已证。

因此本轮不启动全子式 GPU 框架或真实模型试验。下一条可反证的研究问题是：实际前向消费者能否只使用一组有共同源证明的聚合交叉比观察，并在相同 product／order 信息的强参考下保留额外精度和可支付费用。若只得到已知逐项 McCormick/RLT 或只换乘积变量，应归入支撑结果，不称新域。CIFAR/Tiny 的 PWA 主线仍保留，不因这项 smooth 子课题更容易造例而改变完整目标。
