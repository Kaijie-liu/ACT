# 联合源关系从局部等价走向可组合外包

本轮取得两项建设性的纸面进展：普通混权 PWA 块的原相位条件外包，以及 shared-source native Attention 的专用支持和斜面编译。它们都能在明确正控上把收益传到下一 ReLU，不再只停留于少变量或激活前负界的微小变化。尚未实现、运行或证明真实收益；两项构件也没有被拼成一条通过验证的新路径。

## PWA 主线的决定

[带标签幅值外包](SIGNED_ENVELOPE.md)给出完整 sound 证明、零误差时的精确对应和非零误差时的反例。普通二维混权残差正控在同输入/父/目标界下，将 J 的 LP 上界压到 29/24；旧 LP 的可行点仍达到 16633/13440。简单前向仿射支持就足以证明后继 ReLU 关闭，无需新 LP 查询。

这不是同证据旧 HZ 无法表达的关系：旧 HZ 加相同行更精确，只是更贵。候选本身的整数外包有损，而且全网是否能真正删除父幅值取决于所有消费者。因而选择的是一个待实现、默认关闭的抽象变换候选，不是“变量少即创新成功”。下一个安全动作是对该原相位条件变换作新预注册、最小实现和完整数学测试，不继续增加无关适配框架。

测试应覆盖本轮正反例、零误差原标签等价、同源身份和未替换关系保存、下一门的界作用域、全部 side-consumer 拒绝条件及有限/边界乘子选择。沿用最新 3869 项完整继承人口及原测试/资源门；不能筛选测试。之后需要真实相同结构的联合读出及下一激活，而不是只统计 rho 或连续变量减少。CIFAR100/Tiny 的原三模型来源可作为固定起点，未完成消费者绑定前不删除实际列。

## Attention 的决定

[native 图和查询定理](NATIVE_ATTENTION.md)不只是向旧图加一个已知恒等式：在真实 product-box、固定 query 结构下，能直接求 correlated score/value 的单头方向支持，并能编译保留原输入斜面的关系。其精确源图超出有限线性 HZ，但 typed functional-set 形式本身已有先例，新颖性不能由表示差异单独推出。

[原图检查](SOURCE_AND_PRIOR_ART.md)确认两个真实 ViT 的首 CLS query 和残差是输入值常量，后面各有 96 个原 MLP 前激活。下一来源实验必须认证 BN/原常量/性质/模型绑定，并固定这全部 192 个读出；不能挑改善的 head/channel，也不能删除非 CLS token。多头独立求界是 sound 而非 exact，当前生产本来就能部分利用常量 query，所以不将结构发现记为能力收益。

GPU 算法需要覆盖源提取、批量二维投影/角序、认证 exp、驻点及阈值求根、行安装和终端。PWA 的源支持与斜面合成也具有批量归约结构。两者均未实装，纸面可并行不等于实际速度；不以 CPU 小例或忽略终端的时间替代全面 GPU 目标。
