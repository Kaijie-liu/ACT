# 保留原相位的共同源幅值外包

本记录把上一轮的零误差组级消项扩展为一个有损但健全的块抽象变换。它不只是重排矩阵：输出及原相位的外包集合会改变。普通混权残差正控中，该变化能改善下一 ReLU 的前向界；同时存在旧整数图没有的新伪点，因此不能推断保旧或默认启用。全部结果为纸面证明和独立交叉核验，未执行新候选。

## 带标签的块语义

令 S 为同一个已绑定源域，保留其连续因子、所有原二元因子、EQ/LE、frame 和输入 decoder。父门与目标门为：

```text
q_i = ReLU(f_i(z)),       原父相位 alpha_i
g = d(z) + sum_i a_i q_i
r = ReLU(g),             原目标相位 beta.
```

此处 f_i、d 对保留的源坐标仿射；S 可以有原谓词。任一固定参考 tau_i∈{0,1} 都给出恒等式：

```text
q_i = tau_i f_i + e_i
e_i = ReLU(t_i),          t_i = (1-2 tau_i) f_i
h = d + sum_i a_i tau_i f_i
g = h + P_plus - P_minus
P_plus  = sum_(a_i>0) a_i e_i
P_minus = sum_(a_i<0) |a_i| e_i.
```

tau 不是替代相位，也不按求解结果选择。该分解在既有 D015 已有，不能重新计为创新。所有原 alpha_i 继续是整数，源上的符号守卫仍为 `l_i(1-alpha_i) <= f_i <= u_i alpha_i`，其中可靠界扩展到包含零。原 beta 也保留；下面的有损外包覆盖原 beta 的全部合法赋值，不声称它排除了所有原本非法的标签组合。

## 条件误差定理

选择 kappa_i>0，认证同一 S 上 `h+kappa_i t_i <= rho_i`，其中 rho_i>=0。定义：

```text
T_plus  = sum_(a_i>0) a_i/kappa_i
T_minus = sum_(a_i<0) |a_i|/kappa_i
R_plus  = sum_(a_i>0) a_i*rho_i/kappa_i
R_minus = sum_(a_i<0) |a_i|*rho_i/kappa_i
T_plus < 1
E_plus  = R_plus/(1-T_plus)
E_minus = R_minus + T_minus E_plus.
```

令 L_h<=h，U_r>=ReLU(g) 是可靠全局界，U_r>=0。原带标签图包含于以下四行：

```text
r >= 0
r <= U_r beta
r >= h - E_minus beta - R_minus(1-beta)
r <= h + E_plus  beta - L_h(1-beta).
```

证明：由证书，`e_i <= (rho_i+ReLU(-h))/kappa_i`。原 beta=1 时 g>=0，因此 `ReLU(-h)<=P_plus`。故 `P_plus<=R_plus+T_plus P_plus`，推出 `P_plus<=E_plus`、`P_minus<=E_minus`，以及 `h-E_minus<=r<=h+E_plus`。原 beta=0 时 r=0 且 h<=P_minus-P_plus；若 h<=0，则 h<=R_minus；若 h>0，则 `e_i<=rho_i/kappa_i`，仍得 h<=R_minus。与 L_h<=h 合并即得到四行。g=0 的两种原 beta 都在证明中，未删除零点标签。

rho_i 全零时恢复完整原标签的精确商：h>0 导致全部 e_i=0，g=h；h=0 同样 g=0；h<0 时 `g<=h(1-T_plus)<0`。于是 `ReLU(g)=ReLU(h)`，严格正负号及零集一致。负权预算 T_minus 无须小于 1。这是先前精确组证书的有符号扩展，不把非零误差情况误称精确。

## 域元素和组合的范围

一个候选元素包含 S、原 alpha/beta 身份、各源仿射式和上述证书、保留的目标幅值 r、全部未替换块的原关系，以及线性读出。其具体化是这些保留关系、S、原父守卫和所有已安装带标签外包行的同时解，语义顺序采用同一可见源和标签上的集合包含。空替换时就是完整原 HZ，故精确嵌入；安装一次外包的健全性由上面的定理给出。它仍是混合整数非凸关系，不是将二元因子连续化。

Affine/Conv 只组合当前读出；同 frame 的 Add/Concat 使用同一变量身份。下一真实网络 ReLU 可用它自己的原 bit 和完整四行门关系，在上下界对当前外包有效时作精确 ReLU 变换；整体仍是对原网络的外包。仅对真实网络有效而未覆盖当前外包的界可以作健全收紧，但不等于整个外包的精确 ReLU 像。没有证明完整格、最优抽象或所有多层替换都改善精度。

该语言可以编译成普通线性 HZ；它没有比普通 HZ 更强的分段仿射表达能力。研究价值若成立，只能来自共同源证书支持的抽象变换、组合精度和完整成本，而不能来自新名称。加入同一有效证书的旧 HZ 必须列作强参考。

只有父幅值的全部消费者和谓词已被覆盖，才可不再保留 q_i。其他输出、shortcut 或原谓词仍使用 q_i 时，不得直接删除。原 source 和 alpha 不消失；需要具体候选输入时先用原 decoder，再由原网络计算所有中间值并验证性质。外包的伪幅值不是 ADV。

## 普通混权正控

取 x,y∈[-1,1]，tau_1=tau_2=0：

```text
f_1 = x+y/10,       f_2 = x-y/10
h = 1/10-2x+y/20
g = h + (ReLU(f_1)-ReLU(f_2))/2
r = ReLU(g),       J = r+x.
```

父门均实际跨零；目标在 x=-1 和 x=1 分别为正与负。共同输入、父界 [-11/10,11/10]、h 界 [-39/20,43/20] 以及 g 的真实紧界 [-41/20,43/20] 对新旧参考完全相同。g 对 x 严格递减，故最后这对界可在 x=±1 直接取得，不是免费求解器给出的先验。

选 kappa_1=kappa_2=2，则 `rho_1=7/20,rho_2=1/4`，均非零；`T_plus=T_minus=1/4,R_minus=1/16,E_plus=7/60,E_minus=11/120`。

新式两条上行消去诊断用的连续 beta 后给出：

```text
r <= 43/20
r <= (129/239)(h+39/20).
```

因 y<=1，`J<=min(43/20+x, (129/239)(21/10-2x)+x)`。两支斜率分别为 1 与 -19/239，在 x=-113/120 交叉，故新 LP 的最大 J 为 29/24。取 y=1、alpha_1=alpha_2=0、beta=1、r=43/20 可达到这个外包值；该达到点本身不是实际网络点。

同信息的旧逐门 HZ LP 有以下明确可行点：

```text
x=1/40, y=0, h=1/20, f_1=f_2=1/40
alpha_1=45/88, q_1=9/16
alpha_2=1,     q_2=1/40
g=51/160
beta=379/672, r=16297/13440
J=16633/13440=29/24+131/4480.
```

父一的两个标准上行以及目标的两个标准上行均取等，其他行与守卫成立。这里相位的连续值仅用于分析 LP 松弛，实际域中的 bit 从未被放松。

接普通下一门 `s=ReLU(J-49/40)`，新界给出激活前上界 -1/60，旧点则给出 169/13440>0，可扩展为旧下一门的合法 LP 点。共用保守前激活范围 [-89/40,77/40]，不向新方法独占提供后继紧界。甚至不必解 LP：只用第二条仿射上界作盒支持，也得 `J<=2899/2390<49/40`，余量为 23/1912。这是可前向计算的普通结构正控，不是 terminal margin 或实例身份选择规则。

反向也存在伪点：在 x=1/40,y=0、alpha_1=alpha_2=beta=1 时，新式允许 r=1/10；旧整数父门强制 q_1=q_2=1/40，继而 r=1/20。因此替换关系与旧 LP 不可比，旧整数图仍更精确。不能由该正控推断已有 CERT/ADV 保留。

独立全局误差 caps 只给 P_plus,P_minus<=11/20。取 E_plus=E_minus=R_minus=11/20，明确丢弃幅值与父相位耦合的四行弱参考，其 J LP 上界为 57/40；更强的相位相关参考不能沿用这个数字。必要的强对照是旧 HZ 加同两条新有效行：它也有新界，而且保留旧关系；本候选的潜在优势只能是用更少幅值/行实现有用近似，不是超过相同证据的逻辑精度。

## 完整代价中已经算清的部分

不单独 lift f/h/g/J，且变量 bounds 不另算矩阵行时，上例旧块为 5 个连续坐标、3 原 bits、12 行、34 nnz；候选为 3 连续、同 3 bits、8 行、23 nnz。非零误差行多一个 beta 系数，不能挪用上一零误差例的 22 nnz。

物化 J 时两边同加一连续列、一等式、3 nnz。若尚未稳定消去下一门幅值，两边再同加一连续幅值、一原 bit、4 行、10 nnz：旧 16 行/44 nnz，新 12 行/33 nnz。强参考旧 HZ 加两条新行则多 2 行/8 nnz。

这只是明确结构的符号账。源仿射合成可能产生填充，证书生成、参数精度、证据、所有 side consumers、原 source/decoder、终端矩阵和重构均要计费。没有 GPU 执行、物理字节资格或 MILP 速度测量。

## 参数生成和下一资格

显式同源盒上，可直接用 `B_i(kappa)=h_0+kappa*t_i0+sum_j |h_j+kappa*t_ij|` 认证 rho_i=max(0,B_i)。该式不把任意受约束 HZ 的 support oracle 当成免费操作。参数按源系数和结构生成，禁止使用终端状态、margin 或公开标签。

共同乘子族还可以作完整的一维纸面优化。令 A=sum_(a_i>0) a_i，要求 kappa>A；则 `E_plus(kappa)=N(kappa)/(kappa-A)`，其中 `N=sum a_i^+ max(0,B_i)` 是分段线性函数。对任一段 N=u*kappa+v，导数为 `(-u*A-v)/(kappa-A)^2`，符号固定。因此下确界来自系数变号断点、B_i 的有限零交点、A 右极限或无穷远极限。B_i 恒零的整段不生成无限零点；常值段须保留一个合法内部有理 witness，不能只枚举边界后误报未达到。

边界下确界未必由有限 kappa 达到。无穷远对应独立全局误差 caps，可以返回已知 caps 外包，但不是一个有限 source certificate。A=0 时 E_plus 恒零，不产生该预算的优化收益。这里只优化共同 kappa 子族的 E_plus；不保证 E_minus、某个读出、位宽、nnz 或总成本最优，也不是独立 kappa_i 族的最优解。

下一实现应先认证这个变换和完整费用，继而固定全部真实同结构人口，与旧逐门 HZ、独立 caps、旧 HZ 加相同证书比较；没有资格就不执行或默认启用。本记录没有冻结或授权新数值运行，也没有缩小 3869 项继承测试人口及其原资源门。
