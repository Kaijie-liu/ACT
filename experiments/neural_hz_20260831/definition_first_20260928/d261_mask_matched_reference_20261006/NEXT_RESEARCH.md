# 更强冗余证书的纸面推导与适用前提

本页保存尚未实现的后续数学观察，不属于D261冻结候选，也未用于重新分类其17543个未排除位置。它细化D258的无收益充分条件，不是新抽象域或能力成果。D261尚无完整a/b/r参数，现有e/tau记录不足以计算本证书。

## 保留共同乘积延拓

沿用D252的z=a1*x1+a2*x2+b1*q1+b2*q2+r、tau>0、Lr<=r<=Ur、六个新鲜产品及三条X容量、两条QG，不增加跨关系新约束。eta按D252原公式取得，旧LP已经满足共同r范围。假设每个旧父点属于范围[-v_i,u_i]的完整带原标签ReLU hull，0<=u_i,v_i<=1。关键是旧LP必须已有q_i<=u_i*alpha_i及q_i-x_i<=v_i*(1-alpha_i)，不仅是q_i<=u_i。

记pos(c)=max(c,0)，定义

~~~text
mplus = min(0, tau-Ur-v1*pos(-a1)
                 -u2*pos(a2+b2+2*tau)+eta_01_plus)
mminus= min(0, tau-Ur-v2*pos(-a2)
                 -u1*pos(a1+b1+2*tau)+eta_10_plus)
~~~

若Bplus>=U1-mplus、Bminus>=U2-mminus，则整组六产品、X容量和QG对旧LP投影冗余。原变量、全部旧约束和消费者保持不变。

证明使用D258的共同产品延拓：分别将父带标签hull点写成合法整数图分布并独立耦合，r保持当前常值。上行无支付部分Aplus=K+2*tau*p2+eta_10_minus*alpha1+eta_01_plus*alpha2在00、10、11三个整数事件上非负；在01上等于tau-r-a1*x1-(a2+b2+2*tau)*q2+eta_01_plus，其在x1属于[-v1,0]、q2属于[0,u2]上的下界就是mplus。下行对称。取均值后两行右端至少U1和U2，因此所有旧child读出均有延拓。每个整数事件的既有D258下界也给mplus>=-2*tau*u2、mminus>=-2*tau*u1，所以在这些更明确前提下不弱于原阈值。

## 必须认证较窄的带相位范围

仅有较窄输出范围不能用于上述原子最小值。反例取u2=1/2、alpha2=q2=x2=1/2，另一父为零，a=b=r=0、tau=1。它满足原[-1,1] hull及q2<=u2和x2<=u2，但不满足q2<=u2*alpha2。共同乘积延拓的Aplus为-1/2，错误借用u2=1/2却会算mplus=0。

因此若没有旧LP中的较窄完整相位hull认证，只能统一使用u_i=v_i=1；不能从D261保存的parent_u数值自动推断上述前提。如果新增这些普通hull行，两条比较路径都必须加入，不能将它们的收紧记作QG收益。这一限定已由独立纸面复核确认。

## 普通严格例与当前研究边界

取独立父x_i属于[-1,1]、s,t属于[-1,1]，z=s/4、d=q1-q2+11*t/4。这里a=b=0、r=s/4、tau=1，两个child共同上界U1=U2=4，eta为零。新证书mplus=mminus=-5/4，实际支付11/2大于21/4，证明冗余；D258原条件需要6，不能排除。两子门在s/t上的系数不平行，例子不依赖数值奇点。

此外，D252既有CONTROL中的假点属于凸化完整父图上的联合双子门hull，因此已有相位容量分离并非普通ReLU差分Lipschitz/secant的重写。那是旧纸面正控的定位，不是本轮新增真实模型收益。把常数e支付改为同源ReLU(e)的仿射secant虽可健全收紧，仍属普通包络思想，不能直接宣称域创新或照搬上述常数支付冗余结论。

后续重点仍是共同来源和跨层相位容量在普通网络结构上的严格强化，以及完整原生消费。不能让更精细的否定筛查替代真正的新域研究，也不能因为此证书更强就声称当前剩余人口已被排除。
