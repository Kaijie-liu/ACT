# 条件观察复用和共同斜率的边界

本轮两个负结论决定不启动全源条件乘积缓存，也不把固定负门斜率作为独立联合关系候选。这些是纸面反例，不是数值实验失败或一般不可能性结论。

## 同一相位内的观察闭包

对原 bit alpha，若未来使用的源表达式都在 span{1,g,v_1,...,v_r} 中，那么 alpha、q=alpha*g 和 t_i=alpha*v_i 足以通过仿射读出重构这些表达式的 alpha 条件乘积。源线性等式允许进一步降秩。这是线性代数的充分条件，可省去无关源方向的乘积；构造与认证基底、改写所有消费者及辅助量界仍须付账。

不能把这个结论自动用于新相位 gamma。即使缓存所有旧 alpha*x，也可能缺少 gamma 所需的源关联。

## 不同相位的一阶矩反例

取 x,y in [-1,1]，g=x+y/4，h=x-y/3+1/10，旧、新门相位分别为 alpha、gamma。考虑两组源点的各半混合：

```text
分布 A: (7/60,1/2), (1/12,7/10)
分布 B: (11/60,7/10), (1/60,1/2).
```

四点都严格位于源盒内部，g 都严格正；两组 h 分别为 1/20 和 -1/20。两组有相同的 E(x,y)=(1/10,3/5)、E alpha=1、E gamma=1/2、E ReLU(g)=1/4、E ReLU(h)=1/40。因 alpha=1，它们对任何仿射源表达式的旧 alpha 条件一阶矩也相同。

然而 E_A(gamma*y)=1/4，E_B(gamma*y)=7/20。所以下一相位所需的条件残差不能由这些已有观察唯一确定。两个门在整个原盒上都可跨零；反例不是依赖稳定门、共零门或极端数值。它只否定当前观察接口的免费复用，不否定原 HZ 保留关系或其他更强接口。

## 固定共同斜率不提供新的双门强度

对 a,b>=0 和共同源仿射 f,h,v，令 r=ReLU(f)、p=ReLU(h)。任意 theta in [0,1] 给出

```text
v+a*r-b*p <= v+a*r-b*theta*h
 <= max(sigma(v-b*theta*h), sigma(v+a*f-b*theta*h)).
```

但 p>=theta*h 已由 p>=0,p>=h 推出；第二步则是 f 门完整源凸包上的有效支持事实。因此每个固定 theta，甚至所有这类证书的交集，都不能超越“f 门完整源凸包加 h 门基本下界”的对照。它可作为混合上界组件，不能作为独立联合创新；真正联合部分须来自其他信息，例如 THEORY.md 中两个正项的共同支持。

一个共同斜率始终不紧的普通例子是

```text
x,y in [-1,1], h=x+1/10,
f=3h/2+y/5, v=-h/4, a=b=1.
```

两个真实函数支持为 sup(v-ReLU(h))=9/40，sup(v+f-ReLU(h))=19/40，所以 sup(v+ReLU(f)-ReLU(h))=19/40，在 (1,1) 达到且两个门均严格激活。

共同 theta 所给两项分别为 A0=9/40+9*theta/10、A1=63/40-11*theta/10。对所有 theta，max(A0,A1)>=11*A0/20+9*A1/20=333/400，至少高出真实支持 143/400。这是一个对全部 theta 的代数下界，没有运行斜率优化、LP 或对偶迭代。

## 研究决定

保留选择性 RLT 的精确投影作为无需新条件乘积的支持组件。不开启全源乘积缓存；不开启固定 theta 作为独立新双门算法。继续研究的是 THEORY.md 中的共同源支持如何接到普通残差块，以及原有关系能否以完整可承担成本继续参与下一层。任何新的跨相位复用都必须重新证明，不能凭“共享 latent”四个字免除依赖成本。
