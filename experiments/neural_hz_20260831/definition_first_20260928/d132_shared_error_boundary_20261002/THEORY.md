# 共同误差表示的精度边界

本记录完成 D131 共同非线性解码之后的三项数学检查。逐门平方上界支付的共同 gap 球没有新增松弛精度；更强的投影球仍不能代替真实幅值图；有限相位多项式可以给出有界共同误差，但必须公开它放松的源关系及全部费用。因此不为这三项纸面结果新建逆码适配框架。

这里是精确实数纸面证明，经独立审查，不是机器证明、候选测试或真实网络执行。原 HZ 的连续源、全部原二元身份、合法零标签、EQ/LE、共享 frame 和具体输入重构均为保留义务。以下 beta 只是原 signed bit 的 0/1 视图，绝不把实际域的二元因子连续化。比较用的分数松弛不是候选的具体语义。

## 逐门预算产生的共同球约束被旧松弛蕴含

令 g=Ax+b，q=ReLU(g)，y=A^T q。D131 定义的唯一 decoder 最小化 J(r)=||r||^2/2-b^T r，约束 r>=0、A^T r=y。对任意可行 r，强凸性给出

```text
J(r)-J(q) >= ||r-q||^2/2,
r-q belongs to ker(A^T).
```

若 gap 上界是 epsilon，则所有消费者 Cq 共享同一个核空间球；方向 w 的误差支持不超过 sqrt(2 epsilon)||P_ker C^T w||。这是共同外包，不是声称球内每一点都来自某个真实源。强凸 gap 到距离的机制已有明确先例，见 [文献对照](SOURCES.md)。

现在检验不调用新求解器的廉价预算。旧松弛保留同源 l<=g<=u、每门 triangle，以及 A^T z=y。定义

```text
U_i(g_i)=0                              if u_i<=0,
U_i(g_i)=g_i^2                          if l_i>=0,
U_i(g_i)=u_i^2*(g_i-l_i)/(u_i-l_i)       if l_i<0<u_i.
```

全零区间的前两种定义一致。稳定门有 z_i=0 或 z_i=g_i。不稳定门令 a_i=u_i(g_i-l_i)/(u_i-l_i)，则 0<=z_i<=a_i<=u_i，故 z_i^2<=a_i^2<=u_i a_i=U_i。所有门还满足 z>=g。

在同一状态和同一 y 上认证参考 r>=0、A^T r=y，令

```text
2 epsilon_bar=||r||^2+sum_i U_i(g_i)-2 g^T r.
```

直接由旧松弛可得

```text
||z-r||^2
 =||r||^2+||z||^2-2 z^T r
 <=||r||^2+sum_i U_i(g_i)-2 g^T r
 =2 epsilon_bar,
A^T(z-r)=0.
```

因此整个共同球及其所有线性像、方向支持后果都已被旧 triangle 蕴含。再把 epsilon_bar 取全源常数上界只会放松。参考 r 可以依赖状态，但不能只在一个样本点可行。

这项预算对真实图确实健全：由于 q^T g=||q||^2、A^T r=y，有 J(r)-J(q)=J(r)+||q||^2/2-x^T y<=epsilon_bar。被否定的是新增精度，不是健全性。该结论不覆盖更强联合源预算或查询成本优势；但目前没有后两者的证据。D009 已有共同源 Gram 预算，不能把它重新包装成 gap 球再宣称新关系。

## 一个更强投影球仍允许普通假幅值

给定可行截面 p(y)>=0、A^T p(y)=y。真实 q 是 J 的最小点。以 p 为可行比较点的变分不等式给出，令 e=q-p：

```text
A^T e=0, p+e>=0,
||e||^2+(p-b)^T e<=0.
```

这比只使用 J(q)<=J(p) 的系数更强。若 z=P_ker(p-b)，它是在 ker(A^T) 中以 -z/2 为心、||z||/2 为半径的球。忽略额外非负约束，其方向 c 的支持为

```text
c^T q <= c^T p - c^T z/2 + ||P_ker c||*||z||/2.
```

所有读出必须使用同一个 e；不同方向的最优点不能拼接成见证。固定右逆、核空间投影及可行截面都要认证和计费。显式保存 rank(A) 个统计坐标及 m-rank(A) 个误差坐标仍共 m 维。

严格负控取 x in [-1,1]^2：

```text
A rows = (1,1/4), (-1,1/4), (1/4,-1), (-1/4,1/2),
b=(1/4,-1/4,1/8,1/2).
```

四门互不平行、偏置非零，真实 preactivation 紧界分别为 [-1,3/2]、[-3/2,1]、[-9/8,11/8]、[-1/4,5/4]，都实际跨零。取 x=0，则

```text
q=(1/4,0,1/8,1/2), beta=(1,0,1,1), y=(5/32,3/16).
p0(y)=(y1/2+2*y2,-y1/2+2*y2,0,0),
n=(1,1,1,1), A^T n=0,
p(y)=p0(y)+n*max(0,max_i(-p0_i(y))).
```

于是 p=(29/64,19/64,0,0)。向量 a=(2,0,9,17) 满足 A^T a=0。伪幅值

```text
r=q+a/256=(33/128,0,41/256,145/256)
```

具有相同精确 y，满足全部原整数符号守卫、r>=0、r>=g、关闭门 r2=0，以及普通 q 上界。它还满足四条中心 triangle 上界 (3/4,1/2,11/16,5/8)。但令 e=r-p，共同球左侧为

```text
||e||^2+(p-b)^T e = -1065/32768 < 0.
```

取真实混权消费者 v=r1-r2/2+r3-r4/2，真实值为 1/8=64/512，伪值为 69/512。下一原 ReLU(v-67/512) 的真实值是 0，伪值是 1/256。

这个伪点不通过完整旧 HZ 的整数门等式，也不通过固定整数 bits 的完整单门 labelled hull。反例只否定投影球加上述约束足以恢复精确 decoder 的主张；不否定其他共同解码算法，也不是具体网络 ADV。

## 固定多项式可以给出相位统一的误差界

对原整数相位令 D=diag(beta)，G=A^T D A、c=A^T D b。固定 L>0 满足 L>=||A||_2^2，固定 z0 和非负整数 K。保留源缺陷的精确定义 eta=y-c-Gx；它不是与源无关的噪声标签。真实 q_star=D(Ax+b)，原 guards 使之等于 ReLU(g)。

对任意满足 p(0)=1 的多项式 p，令 s(lambda)=(1-p(lambda))/lambda，并在零点用多项式延拓。定义

```text
qhat=D*(A*(z0+s(G)*(y-c-G*z0))+b),
T=D*A*p(G), U=D*A*s(G).
```

由于 I-s(G)G=p(G)，恒有

```text
qhat-q_star=T*(z0-x)+U*eta.
```

这对每个合法原整数相位统一成立，不需要枚举这些相位。没有把单个数值相位的计算成本当成整个符号集合的成本。

第一种固定多项式是 p_K(lambda)=(1-lambda/L)^K。它对应 z_(k+1)=z_k+(y-c-G*z_k)/L。K>=1 时，谱上取最大值得

```text
||T||^2 <= L*(2K)^(2K)/(2K+1)^(2K+1),
||U||^2 <= K/L.
```

第一式最大化 lambda*(1-lambda/L)^(2K)；第二式令 t=lambda/L，使用 [1-(1-t)^K]^2/t<=K。K=0 单列 T=DA、U=0。

另一种固定多项式取 N=2K+1：

```text
p_K(lambda)=(-1)^K*T_N(sqrt(lambda/L))/(N*sqrt(lambda/L)),
p_K(0)=1.
```

这里 T_N 是第一类 Chebyshev 多项式。分子是奇多项式，因此商是 lambda 的 K 次多项式。等价地 p_K(lambda)=W_K(1-2lambda/L)/(2K+1)，W_K 是第四类 Chebyshev 多项式；这不是新多项式族。

令 sqrt(lambda/L)=sin(theta)，则 p_K=sin(N theta)/(N sin(theta))。由 |T_N(t)|<=1，及

```text
1-p_K=(4/N)*sum_(j=1..K) sin(j*theta)^2,
sin(j*theta)^2 <= j*sin(theta),
```

得到

```text
||T|| <= sqrt(L)/(2K+1),
||U|| <= 2K(K+1)/((2K+1)*sqrt(L)).
```

若 ||z0-x||<=R0、||eta||<=epsilon 在整个真实来源上已认证，则误差界为这两项分别乘 R0、epsilon 后相加。增加 K 降低初值项，但已证噪声放大界增长，不能只报告前者。K=1 时 p=1-4lambda/(3L)，s=4/(3L)。K=0 时 p=1、s=0，不能写成负一次多项式。零谱延拓为 s_K(0)=2K(K+1)/(3L)，且 DA 消去 ker(G)。若整个 A=0，直接 q_star=Db，不套 L=0 的除法公式。

这是固定谱滤波的神经接口应用，不是新的迭代原语，也未证明最优性、数值稳定性或神经网络查询优势。[先例与公式来源](SOURCES.md)逐项区分。

## 共同外域的包含方向和被放松的关系

一个可能的有损读出写为

```text
y=c+G*x+v, ||v||<=epsilon,
q=qhat(y,beta)-T_beta*u-U_beta*v, ||u||<=R0.
```

所有消费者 Cq+Sx 和所有旧 q 谓词、幅值上下界、非负约束使用同一个 u、v。真实扩展取 u=z0-x、v=eta，所以包含方向健全。epsilon=0 时 y 精确绑定 c+Gx，不再保留一个假称非零真实缺陷的 v。原 bits 和全部原源约束保留；若不保留 u=z0-x，则明确允许新的幅值状态。

相对 qhat 中心的共同误差被同一个 T_beta 球像与 U_beta 球像的和外包；这不保证整个和都是源可达的。给定原相位 beta，方向 w 的支持上界是

```text
R0*||T_beta^T C^T w|| + epsilon*||U_beta^T C^T w||.
```

若需要 Chebyshev 方案下对所有原相位统一的数值上界，可使用 ||C^T w|| 乘以 R0*sqrt(L)/(2K+1)+epsilon*2K(K+1)/((2K+1)*sqrt(L))。直接保留相位相关范数则仍要支付其认证和终端处理，不能当作免费算出的全集合 support。

还有一项精确消项必须公开：代入同一个 y=c+Gx+v 后，上述最终读出满足 q=q_star+T_beta*(z0-x-u)。因此 v 从最终 q 中完全抵消。U_beta*v 描述相对 qhat 的误差，并不是最终外域新增的独立缺陷方向；不能用 epsilon 宣称额外的表示能力。

这保留共同误差，不代表它已经能由原 HZ 廉价表达。D 的关闭行恒零；两种真实零标签均有合法扩展，但放松后激活零点可能有额外伪幅值，不能声称完整零纤维精确。加入原完整 gate 等式会消除该放松，而不是仍拥有免费的非零误差体。

更强的闭合边界如下。若还要求当前读出满足 A^T q=y-eta，并保持 q-q_star in range(DA)，则必有 q=q_star。证明令 e=DA h，有

```text
A^T e=G h=0,
||e||^2=h^T G h=0.
```

无需满列秩。只声明 q-qhat in range(DA) 也足够，因为 qhat-q_star 已在同一空间。因此有损版本的 y 是绑定真实源的 decoder 输入统计，并非仍严格等于当前放松读出的 A^T q。必须公开这一被放松的等式；保它精确便回到原精确图。

## 普通多消费者抵消不是超过旧 HZ 的证据

取四行 A=(1,0),(0,1),(1,1),(-1,1/2)，b=(1/5,-1/7,-1/2,1/10)，源 [-1,1]^2。统一 L=4 合法，因为 A^T A 的最大绝对行和为 7/2。取实际 x=(1/2,1/2)、beta=(1,1,1,0)，则 q=(7/10,5/14,1/2,0)。第一种迭代在 z0=0、K=1、eta=0 时给 qhat-q=(-1/8,-1/8,-1/4,0)。

两个消费者系数为 C1=(1,-1/2,1/3,1/4)、C2=(-5/2,1/2,-1/6,-1/2)。其共同误差为 (-7/48,7/24)，满足 2 Delta v1+Delta v2=0；在该原相位上甚至 (2C1+C2)T=0。加 raw residual V1=C1q+x1/5、V2=C2q-x2/10，有

```text
2V1+V2=-39/140+2x1/5-x2/10.
```

独立误差盒会丢失抵消，但原 HZ 由相同 active gate 等式已经推出此关系。这不是新增能力，也不是全盒稳定性质。证明讨论一项原相位，不是运行相位分裂。

## 完整费用与实施决定

固定数值 beta 下，Gv=A^T D(Av) 可不显式构造稠密 Gram，有限阶求值需要 O((K+1)(nnz(A)+m+d)) 工作。未知原 bits 下，T/U 含相位乘积；显式展开、共享电路、系数增长、全部消费者 C 的乘积与填充、源界及 L 的认证、全部谓词代入、下一 ReLU 和终端降级都另计。这个点值复杂度不是集合查询复杂度。

原 x 必须保留时，直接 q=D(Ax+b) 已是一遍矩阵作用。逆码迭代没有自动的成本优势。epsilon=0 的显式 y 与误差 u 已可能需要 2d 个坐标；只有 m>2d 时这一粗略计数才比 m 小，仍未支付 guards、矩阵、消费者和终端。恢复原幅值或精确统计关系可能消除表面收益。

本轮不实现上述接口，不启动新数值资格，也不宣称经典谱迭代或共同球是 PLDI 级域创新。新证据把下一研究从逆码工程转向可直接组合的前向关系；[跨层共同能量审查](FORWARD_ENERGY.md)记录另一个定义假设及命中的已有工作。正式 1870/2413 与独立 61/400 均零新增。
