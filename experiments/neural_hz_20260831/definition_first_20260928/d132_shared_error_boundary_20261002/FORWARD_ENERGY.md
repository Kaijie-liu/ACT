# 前馈网络共同能量的精确表示与已有工作边界

从共同 decoder 转向一个直接前向的定义假设：能否把所有门的非凸幅值关系合成一条共同能量关系，并利用前馈拓扑将其负曲率限制到源相关方向？答案分两部分：精确表示和显式正定权重均可证明；但其核心传播缺口及加权凸化已有直接神经验证先例，全部幅值和原 bits 也没有减少。当前不据此启动新组件或采用新的 QP 求解路径。

以下是本项目的纸面推导和独立审查，不是数值或来源资格。文献命中后保留该推导作为边界与支撑材料，不宣称外部新颖性。

## 原相位保留的共同关系

令 x 为同一原源上的实读出，q_l 为按拓扑编号的所有 ReLU 块幅值。允许仿射、Conv、Add、Concat 和 raw residual，写作

```text
g_l=F_l*x+b_l+sum_(j in Pa(l)) A_lj*q_j,
j<l for every hidden parent j,
q_l=ReLU(g_l).
```

矩阵是实际完整线性算子的数学表示，不假称必须物理展开卷积。聚合 q、g、F、b 后为 g=Bq+Fx+b，其中 B 严格块下三角。保留每个原整数 beta 及其符号守卫，g_i=0 时两个原标签均合法。

对任意严格正块权 w_l，定义 W=diag(w_l I) 和

```text
E(x,q)=sum_l w_l*q_l^T*(q_l-g_l).
```

在逐门 epigraph q>=0、q>=g 上，每个标量乘积非负。因此

```text
E(x,q)=0  iff  q_i*(q_i-g_i)=0 for every i
          iff q=ReLU(Bq+Fx+b).
```

这保留所有幅值，不做相位枚举或删除 bits。源关系 H_src(theta)、读出 x、全部非门 EQ/LE、q bounds、共享身份及原输入 decoder 原样保留。以共同 E=0 和 epigraph 精确替代门值等式、另保原相位 guards，可互相构造同一个 labelled 网络图；不允许用整个 epigraph 代替 E 的零集。

这是原 HZ 网络关系的非凸重新表述，不是 CZ 或 Zono；它本身也不是新的抽象域贡献。尚无廉价最佳抽象、全套查询或原 LP/MILP 终端的低成本编译。非凸性除连续二次关系外还涉及原 bits 的 labelled guards，不能把二次型惯性结论误称为整个混合验证问题只剩 d 个困难变量。

## 不能省略非负乘积的前提

若去掉 q>=g，只留 q>=0 和原 sign guards，E=0 可以由正负缺口抵消。取 x,y in [-1,1]^2，普通两层偏置混权结构

```text
g1=x+y/4+1/2,
g2=q1-x/2-3*y/4+1/8,
w1=w2=1.
```

两门均实际跨零：第一门范围 [-3/4,7/4]；第二门在 (0,1) 为 1/8，在 (-1/2,1) 为 -1/8，在 (1,-1) 为 13/8。中心 x=y=0 的真实幅值为 (1/2,5/8)。伪幅值 (1/4,1/2)、原 bits=(1,1) 给 g=(1/2,3/8)，满足正符号守卫，但两个缺口是 (-1/16,+1/16)，总和为零。

所以必须保留逐门 epigraph；一条总能量等式不是免费的全部门约束消元。反例没有通过完整旧 HZ，也不是 ADV。

## 不依赖优化的前馈正定权重

令 p_l=|Pa(l)|，只数隐藏父边。从最后一块向前作静态系数递推

```text
w_j=1+sum_(l:j in Pa(l)) w_l*p_l*||A_lj||_F^2.
```

这是由固定网络拓扑和系数定义的代数规则，不使用 solver 状态、对偶信息或性质方向。计算次序虽然从后向前，并不是用后继界、损失梯度或优化乘子进行 backward rescue。

记 H=W-(WB+B^T W)/2。对每条 j->l，Young 不等式给出

```text
w_l*q_l^T A_lj*q_j
 <= w_l*||q_l||^2/(2*p_l)
    +w_l*p_l*||A_lj||_F^2*||q_j||^2/2.
```

对边求和。块 j 的入边扣去至多 w_j||q_j||^2/2，出边扣去 (w_j-1)||q_j||^2/2。没有隐藏父边时第一项不扣。因此

```text
q^T H q >= ||q||^2/2,
H >= I/2.
```

不需要计算特征值、求逆或搜索权重。Frobenius 范数可以换成一个已认证的谱范数平方上界，但不假设这种上界免费。Conv 必须支付完整线性算子的空间重复与 padding；把一个 kernel 的平方和当成整个 operator 的 Frobenius 平方会低估。

该充分条件可能很保守。长路径上的权重乘积、分支求和和幅值尺度会增长；精确系数位长、浮点认证、共同物理存储都另计。不能把没有优化器等同于有良好数值条件。

普通控制取 x in [-1,1]^2，q=ReLU(Ax+b)、r=ReLU(Cq+c)，其中

```text
A=[1 1/2; -1/2 1], b=(1/4,-1/4),
C=[2 -1; -1 2], c=(-1/8,3/8).
```

两父门真实界为 [-5/4,7/4]、[-7/4,5/4]。子门一在 (-1,-1) 和 (1,1) 分别为 -1/8、25/8；子门二在 (1,-1) 和 (-1,1) 分别为 -3/8、23/8，故四门都实际跨零。||C||_F^2=10，静态权重为 (11,1)，隐藏齐次能量满足 11||u||^2+||v||^2-v^T C u>=6||u||^2+||v||^2/2。相反，全权重 1 在 u=v=(1,-1) 上给 -2，否决了不选权就假设 hidden 凸的捷径。

中心源的真实值为 q=(1/4,0)、r=(3/8,1/8)。伪值 q=(5/16,0)、r=(1/2,1/16) 保持同一严格相位、epigraph 和普通幅值界，但 E=55/256>0。共同零能量与旧完整整数 HZ 都排除它；这里验证的是精确性，不是新能力。

## 源相关负曲率的精确范围

有

```text
E(x,q)=q^T H q-q^T W F x-q^T W b.
```

忽略不影响 Hessian 的线性 bias 项，按坐标 (q,x) 的对称二次矩阵为

```text
M=[ H           -WF/2
    -F^T W/2      0  ].
```

H 正定，Schur 补为 -F^T W H^(-1)W F/4。因此 M 的正惯性为 m，负惯性恰为 rank(F)，零惯性为 d-rank(F)。这里 m 是全部隐藏幅值总数、d 是源实坐标数。证明只使用合同变换，不要求实现构造逆矩阵。

这回答了一个结构问题：可以选择共同能量，使其负二次曲率不随隐藏幅值数增加到 m。但它没有压缩原 bits、源谓词或网络幅值，更不保证 rank(F) 很小。例如若采用 32x32x3 原像素源，d=3072；若采用 64x64x3 原像素源，d=12288。这里只是维数算术，不是对当前模型实际 rank(F) 的测量。

若实际完成平方，中心和半径涉及 H^(-1)WF 及 F^T W H^(-1)WF。它们可因消元而变稠密；d 次线性求解、可能的 m*d/d^2 存储和所有消费者都必须计费。不能把这个惯性证明当作廉价 GPU 集合查询。

## 固定源上的定量误差后果

固定同一 x，完整 epigraph P_x={q:q>=0,q>=Bq+Fx+b} 是凸多面体。前馈真实值 q_star(x) 属于它，E(x,q_star)=0，且 E 在 P_x 上非负。H 正定时它是唯一最小点；凸最优性的一阶条件和二次展开给出

```text
E(x,q) >= (q-q_star)^T H (q-q_star)
         >= ||q-q_star||^2/2  for q in P_x.
```

若用 E<=tau 作为显式有损外包，则得到共同误差界 sqrt(2tau)，全部消费者仍须共享该误差。q_star 仍是完整真实前向图，未知源集合上的误差中心并未免费求出；增加 tau 也不再精确。该强凸后果不是一个新的完整 decoder。

这与 D009 的任意非对角度量逐 ReLU 收缩主张不同：这里始终保留全网络交叉项，没有声称某一层可以在同一任意非对角能量下独立收缩。

## 单个缺口数值不能替代共同幅值

THEORY.md 的四门球反例还能精确说明缺失的信息。若 A^T r=A^T p，定义 h_ball=||r-p||^2+(p-b)^T(r-p)，则

```text
r^T(r-g)=h_ball+p^T(r-g).
```

该伪点中三个量分别为 1483/32768、-1065/32768、2548/32768。球不等式成立不代表真实非负互补缺口为零。

若再把全部幅值只摘要成一个缺口值，也不足以准确传递任意混权消费者。固定 g=(1/4,1/4)、原 bits=(1,1)，两个 epigraph 状态 r=(1/2,1/4) 与 r'=(1/4,1/2) 有同一缺口 1/8、同一平方范数 5/16、同一幅值和 3/4。但下一 preactivation z=1/2+r1-r2 分别是 3/4 与 1/4；下一门均 active、其 local gap 为 0，再接 ReLU(z-1/2) 却分别为 1/4 与 0。

这两个状态是有损外包控制，不是原精确网络状态。反例只否定“缺口、范数和幅值和构成足够的共同消费接口”。保留全部 r 可以精确累加缺口，但全部幅值和混权边成本随之保留；不据此扩大为一般标量关系都不可能。

## 文献命中后的决定

[Kuvshinov 与 Günnemann 2022](https://link.springer.com/article/10.1007/s10994-022-06132-9)第 3.2 节式 5 已使用同一加权 propagation gap，定理 1 给出加入输入平方距离后的 QP 目标的层权凸化条件，并非声称 gap 本身关于源也凸。其问题设置包括 dense、Conv、skip 等算子。本记录的 DAG 显式 Young 证书与 Schur 惯性推论最多是项目级补充，不能仅凭这些公式宣称新域。该文的 QP 优化、对偶及额外界计算没有被本项目采用。

若常规原 gate 的四行被换成 epigraph 两行和相位符号守卫两行，仍约为 4m 线性行，再加共同二次关系。E 含 m 个平方项、nnz(B) 个隐藏交叉项、nnz(F) 个源交叉项，不是常数成本的一行。点值评估虽可用矩阵乘法批量处理，全部不确定状态上的健全界与终端成本仍未解决。

因此不把本结果作为已可实施的 Neural-HZ 候选，也不将重命名能量、求更好权重或换 QP 求解器列为主线收益。下一可检验问题是：能否从保留原相位的共同关系导出不需新优化器的前向组合规则，在完整消费者与同信息强旧对照下获得精度或全成本优势？目前未证。本记录不关闭一般关系域研究，也不改变完整目标。
