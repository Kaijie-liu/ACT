# Neural HZ 跨层控制与定义资格复核

本轮根据用户再次强调的主线，审查“完整共同图点池”是否真的构成强 Neural-HZ 的定义进展。结论是：非凸局部语义有证明，但完整相位几何的组合成本仍然存在，不能仅凭没有外部求解器就声称满足无 split 的要求。新构造的跨层控制虽然超过单事件 Jensen 和既有幅值参照，仍被一个消去联合事件的 13 nnz 旧机制行精确追平。因此不冻结、不执行已准备的运行入口，也不把该控制报为域创新或正式收益。

这些否定结论不要求每条组成公式都必须原创。目标仍是以已知或新数学为基础，形成有实质组合、精度与完整成本优势的非凸域定义和演算；不能把增加一条经典有效行，或保存整个精确图，单独称为已经完成这个目标。

## 完整点池的源码边界

只读检查的实际实现给出以下证据。

- `d228_joint_bank_component_20261005/bank.py:500` 的 `_factor_pieces` 明列两个父 ReLU 的正、负真线段及端点；第 607 行遍历这些真面因子的笛卡尔积并求子门零面交点。
- `d231_phase_compatible_birth_20261005/birth.py:327` 开始遍历下一预激活的全部正负点对，检查所有旧门相位兼容性，再加入过零交点。
- 跨层合同的完整性不变量要求保留每个完整原相位胞的所有顶点，而非仅保存共同凸包极点。
- 下一步点数上界为 `N+floor(N*N/4)`，相位兼容检查为 `O(N*N*B)`；全部历史物理坐标、相位 mask、候选交点、lambda、终端行与旧新池同时存活都要计费。

因此它没有 BaB 分支求解器、攻击或外部救援，但属于完整局部几何枚举及隐式相位几何细化。“没有相位子求解任务”是准确的窄表述；“没有任何区域细化成本”不是。原连续量、原二元 bits、共同 lambda 和标签行确实保留了整数非凸图语义，所以也不能反向误称它已经退化为 CZ。

处理方式是保留原冻结代码和历史数学资格，只将它作为精确局部研究参照，不授权为符合当前无 split 主线的实现。没有删除、重写旧归档，也没有启用生产路径。其 frame 和字符串 ID 不是实际 ONNX 绑定证明，局部源 hull 也不是与任意完整 H 相交后的理想 hull。本轮在 `act` 下未找到这些三个实验模块名的直接引用；这不是全生产调用图审计。

## 新控制的网络与限定阳性

记 R 为 ReLU，令 x1,x2 属于 [-1,1]，定义

```text
q1=R(x1), q2=R(x2),
y1=R(q1+q2/2-3/4),
y2=R(q1/4+q2-3/4),
h=2*y1-y2-7*x1/16-x2/16-5/16,
r=R(h),
D=2*q1-x1+2*q2-x2=|x1|+|x2|,
F=D+h/4-r/2=D-|h|/4.
```

父 logical bits 为 alpha1、alpha2，它们是原 signed bits 的视图，不是新增选择变量。y1 在 alpha1=0 时恒为零；y2 在 alpha2=0 时恒为零。两个 child 的源法向非平行，且没有同一个父事件支配二者。

按源角 --、-+、+-、++ 排列，真实 h 为 `(3,-3,-3,3)/16`。四个旧图角点均匀混合给出

```text
x=(0,0), q=(1/2,1/2), y=(1/4,3/16),
全部四个旧 logical bits 的均值为 1/2,
E[h]=0, E[beta_i*h]=0 对全部旧 bits 成立。
```

给所有旧单 bit 仿射观察使用这同一个真实混合。完整旧带标签图及其全部这些观察的 hull 都接受它。只接下一门的自身图或区间 hull，取 r=0 仍合法；所有原单事件和补事件 Jensen 行也接受。因此该限定参照允许 F=2。它是分数查询伪点，不是具体输入 ADV。

任何仅为原 bits 仿射组合的合法 selector，其 h 观察仍为零。因此只叠加这类事件的互斥覆盖或蕴含差分也不够。这个陈述不包括由原事件乘积得到的 selector，不包括对现有观察新增有效联合约束。

实际两条 child 边的 D036 幅值参照也接受该点。对 y1 边，余项 h-2*y1 的精确界为 [-21/16,3/16]；对 y2 边，余项 h+y2 的精确界为 [-41/64,11/16]。按正幅值下界、负幅值下界、正幅值上界、负幅值上界排列，假点上的非平凡右端分别为

```text
y1: (-5/32, -19/32, 11/16, 7/8),
y2: (-65/128, -5/32, 1/2, 53/64).
```

r=0、r-h=0 均通过。第二余项的下界可令原 x=q 非负并记 s=q1+q2/2，利用 7*q1+q2<=7*s，得到 `2*R(s-3/4)-7*s/16-5/16` 的最小值 -41/64；在 (3/4,0) 达到。上界由凸函数在源盒角点达到，最大为 11/16。第一余项在两个源坐标上单调不增，极值在相应两角达到。

## 整个源盒的精确物理最优值

h 的逐坐标 Lipschitz 常数可取 L1=25/16、L2=17/16。正 x1 一侧的导数为 `2*I1-I2/4-7/16`，负侧为 -7/16；正 x2 一侧为 `I1-I2-1/16`，负侧为 -1/16，其中 I1、I2 是两个 child 的激活指示。分段边界由连续性覆盖。

取与 x 同父相位的角 c，令 di=1-|xi|。零源点可以沿它的任一合法父标签选角，距离仍为 1。因为 |h(c)|=3/16，

```text
F(x) <= 125/64 - 39*d1/64 - 47*d2/64.
```

四角全部达到 125/64，所以真实 sup F=125/64，限定旧参照的差为 3/64。这是整个源盒上的解析证明，不是采样或只检查一处假点。

非零角值、child 支配关系和严格 Lipschitz 余量对足够小的系数扰动保持。角值维持棋盘正负号时，可按 `w_c proportional to 1/|h(c)|` 取同一真角点混合，继续令 E[h] 和全部旧单事件 h 矩为零。故限定失败不依赖孤立的精确相消；但下面的更强参照同样适用，不能用扰动稳定性恢复创新主张。

## 消去联合事件后一个旧观察行就能追平

以下期望记号仅描述查询 hull 中同一真实混合的读出。定义已注册的旧观察

```text
t_ij=E[alpha_i*q_j],
u_ij=E[alpha_i*x_j],
v_ij=E[alpha_i*y_j].
```

先只在证明中引入 delta=alpha1*alpha2 和同号事件 `E=1-alpha1-alpha2+2*delta`。E 在每个整数图点为 0 或 1，所以 `r>=E*h` 是条件凸性的有效行。

支配关系给出 `E*y1=alpha2*y1`、`E*y2=alpha1*y2`；另有

```text
E*x1=x1-q1-alpha2*x1+2*alpha2*q1,
E*x2=x2-q2-alpha1*x2+2*alpha1*q2.
```

因此 E*h 只需要上述已有单 bit 仿射观察，除了常数项还含一个 delta。使用原源容量

```text
0 <= alpha2-q2 <= d2,
delta <= alpha1*q2+d2,
0 <= Delta=alpha1*q2+d2-delta <= d2
```

即可完全消去 delta，得到有效行 `r>=C`，其中

```text
C = 2*v21-v12
    +7*u21/16+u12/16-7*t21/8-3*t12/4
    -7*x1/16-11*x2/16+7*q1/16+21*q2/16
    +5*(alpha1+alpha2)/16-15/16.
```

它只有 13 个变量非零项，含 r；没有新 bit、delta 列或条件矩列。这是相对已有观察接口的增量成本，不能漏计这些观察本来的生成、共同源一致性、存储和终端成本。

在真实旧点上 C=E*h-(5/8)*Delta。因为角点 E 恰选择 h 的正号角，同一 Lipschitz 证明给出

```text
D+h/4-C/2
  <= 125/64 - 39*d1/64 - 47*d2/64 +20*d2/64
  <= 125/64 - 39*d1/64 - 27*d2/64
  <= 125/64.
```

这些式子对旧物理量及其观察是仿射的，故完整旧观察 hull 继承该证书。结合 r>=C 就证明整个源盒上界；真实四角给等号，所以这个加强参照精确追平完整跨层图的 125/64。在原均匀假点，C=3/32，直接排除 r=0。

因此“不增加新的联合事件观察就不可能得到该上界”也是错误判断。联合事件可以用于证明，再通过源幅值容量投影掉。这属于已有条件凸性、乘积线性化及代数消元机制的组合；新控制只能用于检验规则，不足以证明新的域能力。

## 从该推导提取的一般结构规则

对同一源 [-1,1] 中的两个原父门，若已有证据保证 `alpha1*y1=y1`、`alpha2*y2=y2`，考虑任何实际下一预激活

```text
h=a*y1+b*y2+c1*x1+c2*x2+c0.
```

令 T 为上面 E*h 的展开式中除 `2*c0*delta` 外的部分；它只含原物理量、原 bits 和单 bit 仿射观察。

- 当 c0<0，分别以 `delta<=t12+d2` 和 `delta<=t21+d1` 代入，产生两条 `r>=T+2*c0*(t12+d2)`、`r>=T+2*c0*(t21+d1)`。
- 当 c0>0，分别使用 `delta>=t12`、`delta>=t21`，产生两条 `r>=T+2*c0*t12`、`r>=T+2*c0*t21`。
- 当 c0=0，`r>=T` 已无二阶事件项。

条件只涉及实际系数符号和已有结构证据，不涉及实例身份、性质、terminal margin 或 LP 状态。两侧均可固定生成，不动态挑有利行。对于不对称源区间 [-Li,Ui]，Li、Ui>0，可改用 `pi=qi/Ui`、`di=1-qi/Ui-(qi-xi)/Li`，仍有 `0<=alpha_i-p_i<=di`；相应的交叉幅值观察随比例替换。这里只陈述有已证 source bounds 的健全规则，不认证新的 loader。

这个规则是可复用的结构推导，不是已实现的新域。给标准 HZ 增加同样有效行也是必须保留的参照。若旧观察仅由独立 McCormick 外包产生而非完整共同图 hull，规则仍健全，但上面的精确 125/64 比较不能自动搬过去。尚未给出无需完整点池、能够跨层生成并保留足够共同观察的低成本闭包。

对第一方向，可把两个系数符号分支写为统一公式

```text
C=T+2*c0*t12+2*min(c0,0)*d2,
0 <= E*h-C <= 2*|c0|*d2.
```

回到源盒 [-1,1]^2，取 epsilon>0，令 L1、L2 为 h 的逐坐标 Lipschitz 常数。若四角 h 的正负号恰与同号事件 E 一致，最小角点 |h| 为 eta>0，且 `epsilon*L1<1`、`epsilon*(L2+4*|c0|)<1`，则完整旧观察 hull 加这一行精确得到 `sup(D+epsilon*h-2*epsilon*r)=2-epsilon*eta`。证明仍沿同父相位向源角移动，误差项至多为 `4*epsilon*|c0|*d2`；所有距离系数严格为负，最小 |h| 的角达到上界。当前控制的两个系数分别为 25/64 和 37/64，均严格小于 1，故这个更强参照也覆盖一个开放扰动族，而非只追平特定常数。

## 下一研究对象与当前资格

真正未解决的定义问题是：不用完整相位胞顶点池，怎样从共同源、原 guards 和原幅值支配关系，形成可组合的关系载体；在仿射、卷积、混权残差及下一非线性中保留必要依赖，并证明产生、传播、终端和输入重构的完整成本。单纯换名为 relation factor、XNOR 表、条件矩或 helper 都不是答案。

原 HZ 已能精确表示分段仿射神经图；本项目不需要假装扩大其有限 ReLU 集合的表达能力。域创新可以是面向神经结构的表示与演算、精确消元和同预算能力，但不能仅是存储改动，也不能把求解难度藏在新算子内。对于 smooth、attention 和 GPU，同样要分别给定义、健全性及实际代价，当前没有这些资格。

本目录的 `run_math.py` 与 `collection_contract.py` 是此次判断之前准备的未认证草稿，保留原样。没有 CONTRACT、PREREG、test_capability 或 freeze，没有创建结果目录。原拟新增 6 项得到 4159 tests/222 files 的完整门没有执行，不能把数字当通过结果；旧 4153 tests/221 files 仍仅是 D231 的历史数学资格。

本轮没有 import、AST、compile、collection、数值候选、LP/MILP、模型前向、GPU、shadow 或全量回放。没有新后台实验。停止的是这个已被更便宜旧机制追平的控制运行，不是暂停 Goal，也没有降低任何以后候选的测试人口或资源门。

正式 baseline 1870/2413=1063 CERT+807 validated ADV 不变；独立 E0 为 CIFAR100 25、TinyImageNet 36，共61/400，二者不相加。本轮正式及独立新增均为0，没有本轮全量保旧实测。所有历史模型、冻结源码、日志与结果只读，原连续源、全部原 bits、EQ/LE、shared latent/frame、decoder 和 fail-closed 边界不变。
