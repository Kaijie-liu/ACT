# 共同消费者投影的适用范围和完整成本

本文保存本轮两个纸面候选及其停止理由。它们不是新域资格、数值实验或网络收益。所有原连续源、原 bits、EQ/LE、共享frame和输入decoder保留；只讨论明确列出的连续辅助量及全部消费者的投影。

## 盒切片上的共同见证

对原门 g=aᵀz+c、r=ReLU(g)、原active bit beta，设认证盒 L<=z<=U。对每个非零a_i令 t_i=a_i*z_i-min(a_i*L_i,a_i*U_i)，A_i=|a_i|*(U_i-L_i)，则 0<=t_i<=A_i，g=c0+sum(t_i)，c0=c+sum min(a_i*L_i,a_i*U_i)。不受此门系数支持覆盖的其他坐标不能因此删除；若其条件量被消费，另行保留。

保留原门guards和原LP，再加入明确的逐坐标乘积外包 m_i=beta*t_i 的四行及原读出等式：

```text
ell_i = max(0, t_i-A_i*(1-beta)) <= m_i
m_i <= u_i = min(t_i, A_i*beta)
sum m_i = T = r-c0*beta.
```

整数beta时乘积精确，零门的两种原相位不受额外排除。分数beta时这是指定LP扩展，不是实际乘积恒等式，不声称一般相关源的完整凸包。首先必须保证 ell_i<=u_i 以及 sum ell<=T<=sum u；后一组不是旧scalar big M自动保证的。

固定其余坐标。所有对m的消费者若均为 Y_j<=B_j+c_jᵀm，且存在同一静态排序 c_j1>=...>=c_jn，则令

```text
P_0 = 0, P_n = T
P_k = min(sum_{i<=k} u_i, T-sum_{i>k} ell_i), 1<=k<n
m_i_star = P_i-P_{i-1}.
```

证明可平移为 m=ell+v，0<=v<=u-ell，sum v=D=T-sum ell。按上述排序依次填充容量，前k个的总填充为 min(D,sum_{i<=k}(u_i-ell_i))，故对应m的前缀和正是P_k。它可行且同时取得每个前缀和的上界。Abel分解给出

```text
max c_jᵀm = c_jn*T + sum_{k<n}(c_jk-c_j,k+1)*P_k.
```

各差分非负，故同一个m_star最大化所有消费者。联合存在性投影恰为这些支持上界的交，外加盒切片可行性。不需要低秩。该证明是经典base polytope贪心的特例；见[Bach §3.2 Proposition 3.2](https://www.di.ens.fr/~fbach/2200000039-Bach-Vol6-MAL-039.pdf)。这里的神经接口解释和成本分析不改变其已有性。

如果还有等式、下侧或额外m约束，必须全部纳入；不能把其中一部分消费者投影掉后删除共同m。非负组合保持共同排序，但一般混权层不自动保持。该定理只是有限上侧关系类，不是全网络闭包。

## 混权正控和共同见证反例

取消费者矩阵

```text
C = ((3, 1, -2), (4, -1, -3), (2, 1, -1)), det(C)=-2.
```

三行稠密、混号、非比例且满秩，却有共同严格排序。门 g=z1-2*z2+3*z3-1/4，z∈[0,1]^3，给出 A=(1,2,3)、c0=-9/4。在 z=(1/2,1/2,1/2)、beta=1/2、r=7/8 时，T=2、ell=0、u=(1/2,1,3/2)，共同最优点为(1/2,1,1/2)，三个支持为(3/2,-1/2,3/2)。这是LP接口的解析正控，不是实际网络反例。

若没有共同排序，令0<=m_i<=1、sum m_i=2，c1=(2,1/2,-1)、c2=(-1,1/2,2)。二者各自最大值均为5/2，但任一共同m满足(c1+c2)ᵀm=2，所以不能同时达到。独立支持可以分别成立，却不能替代共同可行见证。

## 显式线性编码没有得到净节省

不能把依赖t、beta的max/min端点作为免费系数。一个无需新bits的显式编码引入 Lhat_i、Uhat_i 和n-1个s_k：

```text
Lhat_i >= 0; Lhat_i >= t_i-A_i*(1-beta)
Uhat_i <= t_i; Uhat_i <= A_i*beta
sum Lhat <= T; T <= sum Uhat
s_k <= sum_{i<=k} Uhat_i
s_k <= T-sum_{i>k} Lhat_i
Y_j <= B_j+c_jn*T+sum_{k<n}(c_jk-c_j,k+1)*s_k.
```

任意可行辅助量满足Lhat>=ell、Uhat<=u；总和行推出真实盒切片非空，s_k不超过真实P_k，因此所有消费者不超过真实支持。反向取Lhat=ell、Uhat=u、s=P即可。这证明投影精确；不需要把端点的每一个实现都当成真实m的可行界。base的0<=t<=A、0<=beta<=1保证ell<=u，仍须保留。

令K为全部上侧消费者数。排除两方案相同的原门、源和guards，但包含完整新增谓词；假设一源一物理坐标、A非零、c0非零、每个消费者c_j各项非零且严格排序，B_j为常数或其共同支持另加，则有：

| 编码 | 新连续量 | 行数 | 通用nnz |
| --- | ---: | --- | --- |
| 原box slice lift | n | 4n+K条LE及1条EQ | 9n+2+K(n+1) |
| 显式prefix编码 | 3n-1 | 6n+K条LE | n²+13n+K(n+2) |

前者每坐标四行共8nnz，读出等式n+2nnz；后者端点8n、总和2n+4、前缀(n-1)(n+4)，得到所列数目。端点界以显式行计数，不把其中一部分作为免费solver bounds。n=K=3时分别3变量/41nnz与8变量/63nnz。共享存储、可靠算术和decoder若实现还须另付；当前已无直接压缩理由，不启动该编码。

这个账单不证明所有等价表述都更贵，也不禁止有额外真实关系时进一步简化。数学适用性有价值，当前完整成本阳性尚不存在。

## 两层标量激活的完整投影

另一候选是 q=ReLU(g)、r=ReLU(a*q+v)，a>0，保留原bits alpha、beta。原两门可靠crossing bounds为[L,U]、[K,H]；原scalar四行每门都保留为比较系统。要求q没有其他未计入的消费者或谓词。g、v可以为同一原source的仿射式。

经典线性投影消去q后恰为八行：

```text
L*(1-alpha) <= g <= U*alpha
0 <= r <= H*beta
r >= v
r >= v+a*g
r <= v+a*U*alpha-K*(1-beta)
r <= v+a*g-a*L*(1-alpha)-K*(1-beta).
```

反向重构区间为

```text
max(0, g, (r-v+K*(1-beta))/a)
    <= q <=
min(U*alpha, g-L*(1-alpha), (r-v)/a).
```

九个下界与上界交叉比较中，六个产生上列关于g、r的非平凡行；0<=U*alpha、g<=g-L*(1-alpha)、K*(1-beta)<=0这三个由可靠crossing bounds与相位范围自动成立。再保留r的原两界，共八行。因此对分数相位LP也是精确投影。整数相位时回到q=ReLU(g)，保留零门两种合法相位。若q还有其他消费者，这个八行系统不再足够。

设s_g、s_v、s_t分别是g、v、t=v+a*g内联到同一source后的实际支持数；source不含这两个新bits，crossing系数不退化。原八行nnz为2s_g+2s_v+14，投影八行nnz为2s_g+2s_v+2s_t+13，差为2s_t-1。普通非恒定旁路s_t>=1时增加nnz，仅少一个连续量。

这只是否决该直接八行lowering的净nnz简化声明，不是全部等价表示的下界。额外已证谓词可能令部分行冗余；准确抵消成常数也可能改变账单，但不以特殊抵消作为普通神经结构突破。负a版本本轮不在此陈述证明，不能外推资格。
