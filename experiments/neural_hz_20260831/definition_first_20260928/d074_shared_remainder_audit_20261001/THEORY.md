# 共享激活余项的精确等价及跨块边界

本轮将跨领域研究提出的共享激活余项具体算到跨块规则。结论是：单独改用余项坐标没有新强度；一种确实优于独立误差盒的两块关系，也能反代为已有的 ReLU 增量关系。因此不为这两个表述再建候选组件。这不否定有实际用途的联合余项关系，否决的只是未经证明的定义创新主张。

本文为纸面推导与两路独立数学审查，未执行数值程序、模型、LP/MILP 或 GPU。全部原连续因子、二元相位、EQ/LE、共享 frame 和输入 decoder 均保留。原 HZ 可以精确表达这些关系；问题是如何在完整预算下有效利用它们。

## 固定余项换元不改变原整数集合或 LP 松弛

令 q=R(g)、R(t)=max(0,t)，原 active bit 为 alpha，原可靠界为 l<=g<=u。对固定结构系数 theta 定义 e=q−theta*g。原四条 ReLU 行逐字变换为

```text
e >= -theta*g
e >= (1-theta)*g
e <= u*alpha-theta*g
e <= (1-theta)*g-l*(1-alpha).
```

q=e+theta*g 为仿射逆变换。将所有消费者、边界和其他谓词一并转换，则投影到原物理读出的整数集合与原 LP 松弛均相同；这一结论不限于四条行。在原整数关系中，g=0 时 q=e=0，原两个合法相位没有合并；分数 LP 点不据此强制 q=0。如果 0<=theta<=1，则 e=(1-theta)*q+theta*(q-g)>=0，它只是原正幅度与负缺口的混合。

对一层 g=Wx+a、q=R(g)，混权残差 h=Ux+Vq+c 可以写成 h=Ux+V*Theta*g+V*e+c。保留分解可避免立即展开 V*Theta*W，但这不是免费运算，也不证明完整求解成本降低。若再有原 r=R(h)、相位 beta，只得到 r=beta*h，不自动得到全部 beta*e_i。

例如 x,y in [-1,1]，q1=R(x+1/10)、q2=R(y+1/5)，以及

```text
h=q1-(7/10)*q2+x/5-3*y/10+1/10,
r=R(h).
```

取 theta1=theta2=1/2。在两个父门均激活的开区域中，e1=(x+1/10)/2，h=6*x/5-y+3/50；h 正负两侧均有开子集。若 beta*e1 可由本例的旧连续读出 x、y、两个父预激活与父输出、旧 bits、beta 和 r 仿射重构，在 beta=0 开子集比较系数会消去全部直接连续项；在 beta=1 子集又要求方向 (1/2,0) 与 (6/5,-1) 平行，矛盾。这里没有额外非线性读出可免费调用。

这只是 [既有条件方向秩差](../d059_cross_layer_interface_20261001/THEORY.md) 在新坐标中的实例，不是任意抽象域的不可能性结论，也不要求处理特殊数值。

## 一个真实有效但仍属于已有关系的前向规则

取对称余项 e_g=R(g)−g/2=|g|/2。由绝对值三角关系，逐共同赋值有

```text
|e_g-e_f| <= min(|g-f|, |g+f|)/2.
```

若共同源上已付费证明 |g−f|<=Kminus、|g+f|<=Kplus，则 |e_g−e_f|<=min(Kminus,Kplus)/2。这里的 min 是固定公式中两个健全界的交，不运行两个候选验证路径，也不依据 LP 状态选择规则。

对下一原门 r=R(h)、t=R(w)，若前向代数已经证明 |h−w|<=K，则

```text
|r-t| <= K,
|(r-h/2)-(t-w/2)| <= K/2.
```

第二条更新了下一层余项关系，而不只是输出的边际界；它依旧来自 R 和绝对值的 Lipschitz 性。全部原 bits 保留，包括激活零点的两种选择。

## 普通混权残差上的严格有限对照

令 x,y in [-1,1]，取

```text
g=x+y/5+1/10,       q=R(g)
f=-4*x/5+y/10+1/5,  p=R(f).
```

独立余项界为 e_g in [0,13/20]、e_f in [0,11/20]。但 g+f=x/5+3*y/10+3/10 in [-1/5,4/5]，因此 |e_g−e_f|<=2/5。

追加两个原混权残差门并保留原相位：

```text
h=6*q/5-7*p/5-24*x/25-y/20+9/50,    r=R(h)
w=q/5-2*p/5-3*x/50+13/100,           t=R(w).
```

逐项合并得到 h−w=e_g−e_f，故 r−t<=2/5，且 |e_r−e_t|<=1/5。在源 (1,1)，h=73/100、w=33/100，第一条取等；在 (-1,-1)，h=−7/100、w=−17/100，两个后继都跨零，不是稳定门控制。

比较点为 x=y=0、q=3/5、p=1/5，父 bits 为 1/2、1，子输出取精确图 r=31/50、t=17/100，子 bits 都为1。差为9/20，严格超过2/5。q 的完整 source-labelled 单门凸包可用源正负 (11/12,11/12) 各半表示，预激活分别为6/5和−1；p 使用平均源 (0,0) 的真点。这个点也满足上述独立余项盒。

因此该关系严格强于所列独立误差及分别完整单门比较。它不是全部父门联合凸包的反例，不是生产 native HZ 的非冗余证明，也不是具体 ADV。严格差距并非只在后继系数的精确抵消点存在：若 h、w 在真实源图及上述比较点上的扰动各不超过 epsilon<1/80，新上界和旧点取值各变化至多2*epsilon，差仍至少1/20−4*epsilon>0。这仅是该控制的稳健性说明，不宣称真实网络普遍满足前提。

## 反代后没有新的关系原语

取原 p 的负缺口 n=p−f=R(−f)，它使用原相位的互补视图，不创建替代 bit。令 d=q−n、delta=g+f，则

```text
e_g-e_f=d-delta/2.
```

已有 ReLU 增量关系说明 d 位于 0 和 delta 之间，故 |d−delta/2|<=|delta|/2；这正是上述利用 g+f 的关系。利用 g−f 的版本同理由 q、p 直接得到。继续经过混权层仍需要差值加伴随量，属于 [已有前向关系框架](../d042_bounded_relational_transfer_20260930/THEORY.md)。

这表明该规则可由已有 sector 原理和负缺口视图推出，不表明当前生产实现已经生成全部这些视图或关系。因此既不能当作新域成果，也不能凭纸面等价断言实际实现一定无收益。

## 完整费用与下一决定

若 e 只是视图，不新增连续变量，但查询和全部消费者必须支付真实读出支持；若显式保留 q、g、e，每门增加一个连续量、一条至多3个坐标 nnz 的等式，g 展开时还须支付原支持。跨新相位的精确条件方向不因换元消失，仍有既有每方向一个连续量、四行及实际支持的账单。

每对共同源和差的求界按真实合并支持付费。两条余项关系若 h、w、r、t 已有物理坐标，至多8个坐标 nnz；实际 latent 展开、原谓词、伴随界、证据、所有历史关系和 decoder 另外计入。顺拓扑重构 q=e+Theta*g 仍有原仿射 nnz 量级的运算，不能把稠密矩阵逆或展开乘积算免费。本文没有 GPU 内核或速度结论。

研究决定：关闭“余项换元本身是新定义”和“这条对称余项关系超出现有差分原理”两项具体主张，不实现新组件。保留余项记法作推导工具。后续定义假设必须明确新增的多消费者联合关系及其下游用途，并反代检查是否已被现有规则覆盖；不要求任意深度精确闭包，也不重新以必须降低 nnz 作为能力门。

当前可执行的共同负项候选已经在 [完整数学检查](../d072_single_session_gate_20261001/RESULTS.md) 中取得组件资格。它应向真实结构、绑定和完整代价前进，而不是以余项新名称再复制一套检查。
