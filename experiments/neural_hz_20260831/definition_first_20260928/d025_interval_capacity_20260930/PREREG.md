# Interval phase capacities on original convolution sources

This single-use, explicitly enabled CPU study tests the certified extension in THEORY.md on ordinary first-bank convolution structures. It asks whether fixed adjacent shared-source relations reduce positive or negative receiver capacity coefficients. It is not a full Neural HZ candidate, a GPU fallback, a property solver or a score-producing replay. A useful result can justify retaining this relation in a future domain; a zero or unaffordable result changes that research choice.

## Frozen population and execution

Inherit the exact three original models and one original property per model from the passing D024 provenance: CIFAR100 large, CIFAR100 medium and TinyImageNet medium. No source selection by labels, history, margin or solver status. For every extracted direct next-ReLU branch use the original four corners and center, deduplicated only as in the inherited anchors function, and every output channel. Record all other consumers and side branches without traversing dynamic Add/Sub. No truncation of fan-in, removal of stable predecessors, filtering to crossing receivers, or retry with fewer models is allowed.

New results are exclusive at experiments/neural_hz_20260831/results/d025_interval_capacity_20260930_v1. Freeze THEORY.md, this document, interval_capacity.py, test_interval_capacity.py, census.py, evidence.py, run_census.py and their read-only dependencies before the first import/test execution. The first execution consumes the version on success or failure. Static review and AST inspection may precede it. Do not call any old main, census, diagnostic or result writer.

Before the real-source worker, inherit all D024 3746 tests in 167 files and add exactly seven plain top-level tests, giving 3753 tests in 168 files. Freeze exact node IDs and execute collection plus tests under the unchanged combined 60-second cap. No failures, errors or skips. Use the inherited interpreter, CPU1, AS16GiB, single runtime threads, disabled bytecode and isolated caches. CPU worker CUDA visibility is empty; no GPU initialization, solver or model forward is attempted. A failed test gate prevents the worker. Frozen source, input, dependency and production provenance must match before and after execution.

## Mathematical scope

The arithmetic lemma consumes finite Fraction interval premises and returns capacities conditional on those premises. It is not an authority accepting external certificates into production. The real-source worker establishes every premise itself from the original bytes and property: exact stored raw parameters, outward BatchNorm square-root enclosure, sparse affine forms keyed by the same original input coordinates, and common-box bounds of each source and fixed consecutive difference. Never replace a coefficient interval by its midpoint.

Keep every canonical Conv channel/kernel slot, including padding. Padding is zero after preprocessing and has no original phase; its slot is not packed away. Other slots retain the original ReLU output port and spatial/channel identity. Compute each channel post-affine enclosure once, each source form once, and each ordered pair difference once. Pairing is always slots (0,1), (2,3), and so on, independent of values or status. Guaranteed opposite-sign coefficient matching and clipped finite capacities follow THEORY.md; ambiguous signs retain both residual contributions.

The seven tests cover agreement with the D024 point/crossing rule; stable/zero and one-sided bounds; interval coefficients and ambiguous signs; canonical padding order; shared-source cancellation; general bias and reverse orientation; and default-off/type/shape/work/bit fail-closed behavior. Fixed rational semantic checks do not replace the general proof. All original bits, predicates, shared identity and decoder stay outside this observational compiler unchanged; no original HZ is altered or admitted.

## Work and complete evidence accounting

The worker has one global 240-second cap, 256M scalar/container work, nested 200M per model, 64M retained numeric entries, 512-bit rational endpoints, AS16GiB, and both inherited 1GiB memory tests: RSS high-water growth plus 65536 bytes, and tracemalloc peak plus metadata plus 65536 bytes. They are not relaxed. Precharge source parsing by 4096 plus model bytes plus eight times property bytes; the inherited exact interval kernel charges arithmetic and support visits. Prepay new slot, coefficient, cache and record loop bookkeeping before those loops, and charge each arithmetic operation before it executes. Failure stops the whole study, not just the expensive row. These counters are bounded scalar/container work, not CPU instruction counts or a promise that all original models fit.

Use sequential model evidence emission to avoid holding already completed model roots. At each model retain raw source bytes, original packet, full input box, cached sparse forms, source/pair interval certificates, all canonical windows, receiver coefficient intervals shared across windows, and every row record until its complete evidence has been encoded and written. A row stores its complete deterministic capacity rule and references to those certified premises, together with exact sums, reduction counts and nnz; it does not repeat dense capacity arrays derivable from those premises. Compute and charge the complete arrays for every row, including no-improvement rows, before recording it. This lossless evidence factoring is not claimed as a domain or terminal cost improvement. Then release only that completed model's roots; keep its summary and evidence digest. This is a declared lifetime change, not population reduction. Every original parameter remains in the raw hash/packet evidence; raw model/spec files themselves remain read-only.

Reserve globally 40M work for the full three-model evidence conversion and physical ledger, plus 65536 summary reserve, before numerical work. A new bounded ledger charges before visiting retained objects, with identity-based sharing and full instance sizes; the numeric-entry upper bound additionally reserves 64 entries per maximum canonical slot plus 4096 for transient row arrays/indices. A bounded encoder streams JSON directly, paying container/scalar visits and output bytes before emission and checking an encoding-size upper bound before string/number conversion. No full encoded payload or complete serialized byte copy is allocated. This implementation choice is fixed before any execution; it is not a retry or a claimed Neural HZ improvement.

The same global 40M meter covers all three models' ledger and serialization, not a fresh 40M per file. Its ledger charges at least the inherited eight times numeric entries plus unique objects, and serialization visits and bytes are additional. Original raw bytes are represented by already verified digests and byte counts without another model hash pass. Track maximum held entries and bytes plus actual process peaks including parsing and streaming temporaries. Streamed evidence files and their sizes/hashes are all reported, not treated as zero cost. Only a fully emitted file is renamed from .partial to its complete name. Model-specific arithmetic still pays its nested 200M cap. If the prepaid evidence reservation is insufficient, stop before the unpaid operation, retain failure and do not qualify the study.

Partial failure saves the diagnostic log, small summary and any completed per-model evidence. It does not perform an unbudgeted full traversal/serialization of incomplete roots as rescue. A supervisor timeout or killed worker is a failed study even if some files exist. No uncompleted model or omitted receiver is silently marked supported.

## Report and promotion limits

Report total/admitted branches, anchor and receiver populations, canonical/valid/padding slots, stable/crossing source counts, guaranteed matches, strictly reduced positive/negative coefficients and rows, paired versus unpaired capacity totals, and reductions among receivers whose ordinary interval remains crossing. Crossing means an outer bound, not actual reachability of both signs. Arithmetic coefficient improvement is neither a new CERT nor validated ADV; sums of coefficients are diagnostics, not output-property margins. Preserve full records for independent reconstruction.

Always report native_HZ_admitted=false, gpu_computation_completed=false, complete_physical_qualification=false and formal_gain=0. Passing the worker supports only this exact source-certificate pilot and measured CPU scope. It cannot prove cross-residual coverage, end-to-end savings, GPU readiness, all-family nonregression or PLDI-level novelty. The original mathematical-to-real-to-shadow-to-family-to-full promotion gates remain intact.
