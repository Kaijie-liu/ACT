# 相位容量电路与 tropical 神经网络抽象的区别

本轮新增先例核查改变了下一项定义研究的判断：不能把 min 和非负加权和组成的容量电路称作新的 tropical 非凸域。它可作为保留关系的辅助表示，但非凸性仍来自原 HZ 的二元因子，而且相关神经网络抽象已有直接先例。本文是数学与文献审计，不是新候选实现或成绩。

## 已有研究覆盖的内容

Goubault、Palumby、Sankaranarayanan、Putot、Rustenholz 的 *Static analysis of ReLU neural networks with tropical polyhedra*，2021，§2.2 用 max-plus 代数描述非经典凸的关系集合，ReLU 在该代数下可精确作用。§3 明确普通加权仿射映射一般不保持该类集合，给出 zone/octagon 基础的抽象；§4 通过嵌入、交和投影处理多层关系。§6 讨论内部/外部表示转换的高代价。§5 的 subdivision 流程不纳入本项目。[原文](https://arxiv.org/pdf/2108.00893)

这意味着“使用非凸关系语言处理 ReLU”及“保留中间层关系再投影”都不能单独作为我们的新颖性声明。论文不是原 HZ 的带全部相位标签语义；也没有替本项目证明原 bits、零点自由、latent 身份、输入解码及完整成本保留。因此不整体替换成该域，不导入 subdivision。

## 本项目容量语言的一个简单结论

以下是对 [已有接口草案](../d024_local_phase_capacity_20260930/INTERFACE_LIMITS.md) 的直接数学推断，不归因于该论文。先把原相位暂作连续坐标 beta in [0,1]^b，仅用于分析查询松弛；实际具体化仍要求原二元值。

每个非负仿射 leaf 是凹分段仿射函数。非负加权和保持这一性质，有限个凹函数的逐点最小值也保持凹性，因为其 hypograph 是各 hypograph 的交。因此任何有限 min/sum 容量 C(beta) 都是凹分段仿射函数，其约束 r<=C(beta) 在连续 beta 上给出凸多面体。

等价地，若子项已有形式 min_a L_a(beta)，则非负加权和可展开成各子项选择组合对应的仿射函数的最小值，min 节点直接合并候选。展开可能产生很多片段；DAG 与连续辅助量可避免显式展开，但已有文档给出的线性扩展表示仍适用。不能把更紧凑地存放这个电路等同于新的非凸集合语义。

这个结论不否定相位容量的用途：它可以改善原 HZ 的特定查询松弛，并保留已有整数具体化。它否定的是把辅助容量接口自身误认成新非凸域的说法。普通正加权和也不同于 max-plus 中的“加法=max、乘法=普通加法”；出现 min/max 字样并不足以让两套语言相同。

## 下一项候选必须回答的问题

接下来的定义研究应比较同一普通混合权重、ReLU 和残差结构上的完整关系，而非只比较两个缓存布局。需要明确哪些共同源与原相位信息能够跨块保留，哪些在有界接口中被近似；给出具体化、HZ 对应、Conv/Affine 与 ReLU/Add/Concat 的可组合规则及完整终端代价。

两个已有事实构成对照：普通 HZ 能精确承载这些网络关系，但不保证便宜的查询；tropical 表示对 ReLU 友好，却在普通加权仿射映射处需要抽象。两者的组合不自动是创新，也不能用完整网络图换名绕过问题。若某个新接口只重现已知容量多面体或已知 reduced product，应明确归为支撑结果。

本轮没有提出已证的新 Neural HZ 定义，没有宣称必须得到全局 ideal hull，没有新增运行时求解或放宽禁令。所有后续实验仍需新预注册、原资源门、旧解保全和全量回放。本文与实验 RESULTS.md 同日、同分支和 commit，新增于隔离目录；旧文献综述与旧候选保持原状态。
