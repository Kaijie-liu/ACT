# 从组合优化借鉴共同相位关系

跨领域研究应改变下一步的数学问题，而不只是增加参考文献。本轮将已有双门共同源规则接到组合优化中的共同耦合与布尔二次关系，得到一个三原门的物理读出正控：完整独立单门凸包、现有全部双门投影及差分行仍允许假点，而一条八非零元的共同关系排除它。该关系不引入辅助变量或二元因子。

这是已知数学在本项目中的具体构造，不是新的通用凸化定理，也不是已经成立的新 Neural HZ 域。它为下一次普通神经结构研究提供比继续堆叠独立双门行更明确的目标。没有运行候选、数值搜索、模型、求解器、GPU 或基准回放。

## 文献给出的具体边界

[He 与 Tawarmalani 的 Tractable Relaxations of Composite Functions](https://par.nsf.gov/servlets/purl/10382117)，Mathematics of Operations Research 47(2)，2022，§3.2 Corollary 6：盒上双线性函数的逐项上侧包络恰好给出凹包络，当且仅当相互作用图的每个圈含偶数条负边。§3.3 Theorem 4 给出同一三角剖分下多个函数的联合上侧凸包结论。这里借鉴的是共同耦合条件，不采用文中的动态分离算法或无限估计器构造。

[Boland 等的双线性 McCormick 缺口研究](https://arxiv.org/pdf/1507.08703)，Theorem 4，讨论完整图凸包时要求每个圈的正边数和负边数都为偶数。这个两侧结论比仅上侧条件强，不能把二者混为一谈。[Gupte 等的紧凑扩展表述](https://www.pure.ed.ac.uk/ws/portalfiles/portal/137016756/1702.04813.pdf)，Discrete Optimization 36，2020，Theorem 3 还给出 cactus 图上按圈补充关系的范围；不能外推到任意稠密神经网络。

其他跨领域方向仍有价值，但不重新记为本轮发现：[热带神经网络分析](https://arxiv.org/pdf/2108.00893)把 ReLU 变成精确的热带线性变换，却需要近似普通仿射变换；[神经网络互补系统](https://dair.seas.upenn.edu/assets/pdf/Aydinoglu2021.pdf) §3.1 已有整个 ReLU 网络的精确 LCP 表示。这些是对照，不能整体替换 HZ、删掉原 bits，或把整个网络换一种写法称为创新。此前跨领域综述和有限接口反例保留原状。

## 共同取紧何时成立

考虑一个明确的辅助数学集合，而不是整个神经网络：

```text
b in {0,1}^n,
t_k <= a_k(b) + sum_{ij in E} d_kij b_i b_j,
```

其中 a_k 是仿射式。如果每条边在全部消费者中的非零 d_kij 同号，而且这些边构成的带符号图每圈含偶数负边，则存在固定视图 z_i=b_i 或 z_i=1-b_i，使所有消费者的二次系数非负。仿射项完整更新；这只是原 bit 的代数视图，不修改任何相位赋值、身份或 guard。

在变换后的给定连续均值 z 上，令同一个 U 在 [0,1] 上均匀分布，并在证明中取 B_i=1{U<=z_i}。于是 E B_i=z_i，且 E(B_i B_j)=min(z_i,z_j)。同一个分布同时达到所有边的上界，因此同时达到所有消费者的上界。对于较低的 t_k，逐分量减去常数 slack 即可获得同一联合凸组合。

由此，这个辅助上侧集合的联合凸包可以由共同 McCormick 量 theta_ij 和所有消费者行投影表示；其精度等于各消费者上包络的交。最多 |E| 个连续辅助量、4|E|+K 条行，另付原范围与消费者系数支持。不应为了消掉辅助量展开所有仿射分支：逐项 min 的平面组合可很多。

该证明是上述已知共同三角剖分机制的盒上特例。它不保证带原 source、guard、读出等式的全网凸包，也不允许拿证明中的随机变量做运行时采样。检查共同符号与图的二染色可按边表线性工作组织；真实证书构造、系数位长、图存储及终端成本不包含在这句复杂度中。

跨下一原门时也没有免费闭包。原观察含 d*b1*b2 时，再乘新门 bit gamma，一般产生 d*gamma*b1*b2。若三个 bits 可独立取值且 d 非零，该函数的三阶离散差非零，不能由只含二次项的恒等式表示。特定原 gate 等式可能允许代换，但必须另外证明；不得用这个图条件承诺任意深度固定阶精确表示。

一个普通三门链把这个范围说得更具体：

```text
q=ReLU(x),
p=ReLU(q/2+y+1/5),
r=ReLU(-p/3+z+1/7),      x,y,z in [-1,1].
```

原 bits 为 alpha、beta、gamma。取 x=±1/2、y=±1/2、z=±3/4，三 bits 可独立变化，全部门预激活非零，且各相位集合有内部。在每个这样的集合中，r 对 x 的导数为 -alpha*beta*gamma/6。因此若要求输出在固定 root 上仍是 source-affine、且系数是次数至多二的原 phase 多项式，就不能精确表达该链。这不是对所有有限摘要的否定；保留中间物理 p 可避免展开三次项，但其原谓词和 gamma 与 p 的来源依赖仍要付费。

## 一条统一的三门证书合成规则

假设同一原 frame 上已实际证明三条关系，theta_ij 只代表原整数乘积 b_i*b_j：

```text
L12 <= A12(b) + d12*theta12,
L23 <= A23(b) + d23*theta23,
L13 <= A13(b) + d13*theta13,
d12>0, d23>0, d13<0.
```

L 可以包含同一连续源与原神经值。A 可以包含常数与原 bits。证书系数必须是已认证确切常数，来源可以是可靠区间参数支持；不能把模型中点当真实参数。

所有整数原 bits 恒满足经典布尔三角行

```text
theta12 + theta23 - theta13 <= b2.                 (T)
```

b2=0 时左侧为 -b1*b3；b2=1 时左侧为 1-(1-b1)(1-b3)。两种都成立，包含全部零预激活合法相位。这是数学证明，不是运行时切分或枚举。

令 tau=min(d12,d23,-d13)>0。将 tau 倍 (T) 与剩余三项的普通界组合：

```text
L12+L23+L13 <= A12+A23+A13 + tau*b2
             +(d12-tau)*min(b1,b2)
             +(d23-tau)*min(b2,b3)
             +(d13+tau)*max(0,b1+b3-1).           (C)
```

最后一项系数非正。三个余系数至少一个为零，因此右侧是至多两个二选一凹包络之和，可静态输出至多四条仿射上界，零新辅助量、零新 bit。这里的固定代数选择不是相位枚举。它是健全后果，不声称一般不等幅情形下的完整投影或全局最优包络。

如已有 theta 被别处消费，仍保留那些量及全部旧约束；本条只是增加有证后果，不授权按局部行删除共享量。其他符号排列可以用原 bit 的补视图归到本式，但必须完整变换仿射项。

候选图和三角数量也有成本。即使单组三门至多四行，列举全部三角仍可能达到三次规模。未来实现必须预注册统一结构组及完整人口，不根据 margin、模型身份或事后收益挑组；本轮未决定运行人口、未启动实现。

## 普通混权三原门的强对照

取 x,y in [0,1]，保留同一来源、三个原 bits b1,b2,b3，以及

```text
f1=x-y/3-3/10,       q1=ReLU(f1),
f2=x+y-9/10,         q2=ReLU(f2),
f3=-x/3+y-3/10,      q3=ReLU(f3).
```

三个门均非稳定、源方向不成比例、偏置非零。已有双门共同源匹配规则直接给出

```text
q1+q2-x <= -3*b1/10+b2/10+(2/3)*theta12,
q2+q3-y <= b2/10-3*b3/10+(2/3)*theta23,
q1+q3   <= 7*(b1+b3)/10-(2/3)*theta13.
```

可逐式复查原 P,N 与支持常数：第一对 P=x、N=(1-y)/3，k0=-3/10、k1=11/30、U=1/10；第二对 P=y、N=x/3，k0=1/10、k1=23/30、U=-3/10；第三对 P=0、N=(x+1-y)/3，k0=7/10、k1=1/30、U=7/10。交换每对的方向给出相同物理关系。

三条相加并用 (T)，得到

```text
F := 2*(q1+q2+q3)-x-y
F <= 2*(b1+b3)/5 + 13*b2/15.                      (N)
```

(N) 只有一条 LE、八个物理坐标 nnz，全部坐标原已存在。这里只计算新增行；原 HZ、源证书、支持合并及终端展开另计。

### 完整独立单门凸包与全部双门关系仍允许的点

取 x=y=b1=b2=b3=1/2，q1=q3=1/3，q2=2/5。每个完整 source-labelled 单门凸包都有严格内点源见证，以各半权重取：

- q1：active 源 (59/60,1/20)，inactive 源 (1/60,19/20)，预激活分别为 2/3、-3/5。
- q2：active 源 (17/20,17/20)，inactive 源 (3/20,3/20)，预激活分别为 4/5、-3/5。
- q3：交换 q1 两个源见证的 x,y 坐标，预激活仍为 2/3、-3/5。

这些局部见证各自还原同一个源均值和各自 bit 均值，却不是同一个联合分布。它们是证明中的凸组合，不是模型攻击或具体 ADV。

三对独立的完整单消费者投影分别允许

```text
q1+q2-x <= 7/30,
q2+q3-y <= 7/30,
q1+q3 <= 7/10
```

在该点前两条取等，第三条左侧为 2/3。全部三对双向生成行通过。也可为各对分别选 theta12=theta23=1/2、theta13=0，满足各自 McCormick，但无法满足共同的 (T)。

旧相位差分规则的预激活差范围分别为 [-11/15,3/5]、[-3/5,11/15]、[-4/3,4/3]。该点的输出差等于对应预激活差，差值校正全为零；逐相位差界也逐项通过。因此这个比较不是只战胜 scalar big M。

新 (N) 在该点的左侧为 17/15，右侧为 5/6，排除缺口 3/10。比较范围为上述完整独立单门凸包、全部三对当前生成行与旧差分行；不声称超过完整 PRIMA、所有多门行或完整原 HZ 的整数可行集合。

### 不依赖辅助相位的物理输出也严格改善

三个原门的下界为 -19/30、-9/10、-19/30，所以其 residual capacity 给出

```text
q1-f1 <= (19/30)*(1-b1),
q2-f2 <= (9/10)*(1-b2),
q3-f3 <= (19/30)*(1-b3).
```

定义一个真正的仿射网络读出，而不是把 bits 当作网络输出：

```text
Z = F + (12/19)*[(q1-f1)+(q3-f3)] + (26/27)*(q2-f2).
```

将 residual capacity 与 (N) 相加，全部 bits 消去，得到 Z<=5/3。实际源 (1,1) 上三门均激活，q1=q3=11/30、q2=11/10，且 Z=5/3 取等。

旧松弛点的三个 residual 都是 3/10，因此

```text
Z = 308/171 = 5/3 + 23/171.
```

这证明改善落在旧物理坐标的真实仿射读出上，不仅限制可自由重选的辅助量。它是小型解析网络的数学正控，不是 benchmark CERT。

现象也不依赖旧点恰好贴两条关系。把三个 q 都减去 1/300，两个正边投影均有 1/150 余量，Z 超出 5/3 的缺口仍为 824/7695。q1 的 active/inactive 见证可取 (49/50,3/50) 与 (1/50,47/50)，q3 交换坐标；q2 可取 (127/150,127/150) 与 (23/150,23/150)。三个见证仍严格在盒内，正负预激活均非零。一般不等幅规则 (C) 不要求三条边等幅；本轮不声称给出了任意参数扰动的统一数值半径。

## 对定义研究和真实网络的影响

研究载体可以暂记为原非凸 HZ 加有认证来源的共同相位关系图，但这个记号和已知 BQP 行本身没有新颖性。要成为 Neural HZ 的定义贡献，还需要说明关系语言在普通混权 Conv、ReLU、残差合流下怎样构造和组合，哪些信息可精确省掉、哪些必须近似，以及完整查询和反向重构成本。原 HZ 加同样行有同样逻辑强度，不能伪造比较优势。

本轮具体改变下一行动：不再假定把独立双门生成器多执行几次就解决了共同相位组合；先检查有共同 source 的小组是否产生相容或冲突的边符号，以及其关系是否被实际后继消费。满足已知共同取紧条件时，不把重复组合已有上包络当新强度；不满足时，也不能仅凭符号就宣称真实网络会变强。

只读旧档已确认 CIFAR large 存在非零同号与异号共同源项，以及下一 Conv 的混权消费者；但被检查的两个 first-bank 门之一外包严格为正，因此它只证明普通拓扑存在，不证明需要新关系。精确记录定位和哈希另见 RECORD.md。Medium 和 Tiny 没有由此获得同类完整资格。

真实三源研究仍须使用新的完整预注册，保持原三个模型、全部 admitted 分支、固定窗口、全部通道与 slots 及原资源门。若研究第二个 ReLU bank，必须用第一层实际激活坐标及激活后盒界，不能把预激活界误作 source；更后 Conv 的参数与身份绑定尚需补齐。旧失败版不重跑、不缩人口、不放宽预算。

GPU 方面，已形成证书后的三行 gather、标量 min、稀疏合并和静态行生成适合进一步研究批处理，但相位图构建、候选数量、可靠区间运算、主机设备共存和终端查询均未测。不能由这个数学形式宣称已经 GPU 加速。
