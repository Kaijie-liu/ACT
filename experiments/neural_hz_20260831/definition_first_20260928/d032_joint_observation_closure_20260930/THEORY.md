# 同相位观察共同投影的闭包与冗余

本记录落实 D031 的共同投影假设。结论有三层：规定的单调耦合提升系统可以精确投影；所得行全部是 D029 派生观察上侧关系的实例，不是新的不等式类别；若界仅来自独立区间拆项，则共同投影完全冗余，不值得作为能力候选实现。

另有一个普通混合仿射例子，证明两条原观察加总和观察仍可能漏掉交叉方向。但有符号差分已经能排除同一个点，因此这只是有限观察集合不闭合的正控，不是多门域创新、完整理想凸包或网络验证收益。全部结论为纸面推导和独立复核，没有运行候选或求解器。

## 原非凸语义和比较系统

保留原 HZ 的连续因子、全部二元相位、EQ/LE、共同 frame 与输入 decoder。令原门 q=ReLU(g)，原 bit 为 alpha；整数语义中 q=alpha*g。研究 LP 投影时暂用 0<=alpha<=1，但这不是把原域的二元因子永久改成连续因子。

第 i 个观察是 z_i=a_i*q+v_i，其中 a_i 是固定确切系数，v_i 是同一原 latent 上的实际观察。已有健全证书及保留的源约束为

```text
L_i <= v_i <= U_i,
A_i <= a_i*g+v_i <= B_i,
sum_i lambda_i*v_i <= d,  lambda_i >= 0。
```

lambda 由共同谓词固定，不通过求解状态、margin 或对偶优化选取。v_i 可以含其他原神经门；其健全界必须实际构造，不能假定免费 oracle。整数源约束与 LP 中是否明确保留某条行必须区分；下述 LP 冗余结论要求所用原行在比较系统中确实存在或已被证明蕴含。

按 D029 为每个 t_i=alpha*v_i 写六行线性外包。三条下界和三条上界分别为

```text
ell_i,L = L_i*alpha
ell_i,M = v_i-U_i*(1-alpha)
ell_i,G = A_i*alpha-a_i*q

u_i,L = U_i*alpha
u_i,M = v_i-L_i*(1-alpha)
u_i,G = B_i*alpha-a_i*q。
```

另加共同提升行 sum_i lambda_i*t_i<=d*alpha。t_i 没有未纳入系统的其他消费者或耦合约束。原二元因子不参与消元。

## 非负共同上界的精确投影

令 ell_i 为三条下界的最大值，u_i 为三条上界的最小值。独立可行性 ell_i<=u_i 已由各自 D029 四行及原范围等价表达。存在全部 t_i 同时满足共同提升行，当且仅当

```text
sum_i lambda_i*ell_i <= d*alpha。
```

必要性来自 t_i>=ell_i 和 lambda_i>=0。充分性取同一个扩展 t_i=ell_i；独立投影保证它不超过 u_i，共同行亦成立。

这个扩展同时最小化每一条非负系数共同上界。因此对任意一组 Lambda*t<=d*alpha、Lambda 逐项非负，可以逐行投影并同时组合，不需要额外跨行消元条件。不能把该结论推广到任意混合符号或上下双侧耦合，因为它们不一定共享同一个最小扩展。

整数 alpha=0 时原 v_i 范围和 q=0 使 ell_i=0；alpha=1 时，原 A_i<=a_i*g+v_i 且 q=g 使 ell_i=v_i。所以反向扩展保留原整数具体化。g=0 的两种合法原 bit 分别给 t_i=0 和 t_i=v_i；不合并或删除零点相位。

分数 alpha 下只证明上述线性提升系统的存在量化投影，不证明非线性等式 t_i=alpha*v_i 的精确凸包，更不证明整个网络的理想性。

## 交叉行等价于派生单观察上侧关系

对每个 i 从 L、M、G 三类下界选一条，以 I_L、I_M、I_G 表示对应索引集。定义

```text
a_* = -sum_{i in I_G} lambda_i*a_i
v_* =  sum_{i in I_M} lambda_i*v_i
U_* =  sum_{i in I_M} lambda_i*U_i
B_* = d - sum_{i in I_L} lambda_i*L_i
        - sum_{i in I_G} lambda_i*A_i。
```

从原共同谓词减去所选 v_i 的下界和 a_i*g+v_i 的下界，直接得到 a_*g+v_*<=B_*；原上界还给 v_*<=U_*。这不调用更强求界器。对应的交叉行恰好是

```text
a_*q+v_* <= U_*+(B_*-U_*)*alpha。           (C)
```

它就是 D029 对派生观察 a_*q+v_* 的上侧残差行。这里只归约到那一条上侧行，不假造完整 D029 所需的其他界，也不声称添加派生观察的整套四行与原共同投影完全相等。

当 I_G 为空，a_*=0，原系统同时蕴含 v_*<=B_* 与 v_*<=U_*，从而蕴含二者按 alpha 的凸组合 (C)。所以 3^m 条选择中至少 2^m 条可直接去掉。一般 m 的剩余数量仍可指数增长；实际候选若继续，仅使用固定的两观察结构，不据此展开任意数量观察或相位组合。

对两个观察，九条选择只剩至多五条：

```text
GL: -lambda_1*a_1*q
      <= (d-lambda_1*A_1-lambda_2*L_2)*alpha
LG: -lambda_2*a_2*q
      <= (d-lambda_1*L_1-lambda_2*A_2)*alpha
GG: -(lambda_1*a_1+lambda_2*a_2)*q
      <= (d-lambda_1*A_1-lambda_2*A_2)*alpha
GM: lambda_2*v_2-lambda_1*a_1*q
      <= lambda_2*U_2*(1-alpha)+(d-lambda_1*A_1)*alpha
MG: lambda_1*v_1-lambda_2*a_2*q
      <= lambda_1*U_1*(1-alpha)+(d-lambda_2*A_2)*alpha。
```

前三条是相位容量，后两条是交叉残差；后者不是简单总和观察。LL、LM、ML、MM 已由原共同谓词和盒推出。仅留下 GM、MG 而未另证前三条冗余，不能声称完整保留这次投影。

## 独立拆项证书导致全部冗余

若原比较松弛已经蕴含 a_i*q>=kappa_i*alpha，且 A_i<=L_i+kappa_i，则

```text
ell_i,G=A_i*alpha-a_i*q <= L_i*alpha=ell_i,L。
```

因此所有含 G 的选择被相应 L 选择支配，而不含 G 的行上一节已证明冗余。若每个观察都满足该条件，所有由共同上界增加的交叉行均不会进一步缩小比较 LP；证明这些新增行冗余甚至不需要用到原两套 D029 行。这不否定由另外的相关 B_i 产生的单观察上侧行可能有效。

廉价独立区间证书是一个重要特例。若 g in [l,u]，令 m_i=min(a_i*l,a_i*u)，取 A_i=L_i+m_i，而原门松弛已包含 a_i*q>=m_i*alpha，则满足上述定理。把各项独立求界后相加，再在 GPU 上快速生成五行，不能产生新的强度。

筛除还可更强。对 crossing ReLU 和 a_i>=0，原 q>=0 已给 kappa_i=0；对 a_i<0，若原 q<=u*alpha，则 kappa_i=a_i*u。因而超过某个松的独立区间基准并不充分：A_i>L_i+kappa_i 只是逃出该冗余证明的必要条件，既不保证严格增强，也不自动证明捕获了新的源关联。

对单个观察若 G 已被 L 支配，可在选择公式中直接省去该 G，不影响指定系统的投影。这里的筛除按已认证数学约束执行，不读取 LP 解点或求解状态。

## 普通混合残差的有限观察正控

取 x,y in [-1,1]，所有界均由完整源盒上的仿射支持直接手算：

```text
g=-x+(6/5)y+1/10, q=ReLU(g), 原相位 alpha,
v_1=x,                    a_1=-1,
v_2=-x/2+(2/5)y,           a_2=-2。

g in [-21/10,23/10],
v_1 in [-1,1],             a_1*g+v_1 in [-33/10,31/10],
v_2 in [-9/10,9/10],       a_2*g+v_2 in [-37/10,33/10],
v_1+v_2=x/2+2y/5 <=9/10。
```

这些端点来自系数绝对值之和与常数，没有切分输入或搜索。取分数松弛点

```text
x=9/10, y=4/5, alpha=1/2, q=1,
g=4/25, v_2=-13/100。
```

源点严格位于盒内部且 g 非零。它满足原 scalar big M 门：q>=0、q>=g、q<=23/20、q<=121/100。两个独立提升系统的可行 t 区间分别为

```text
t_1 in [2/5,1/2],
t_2 in [3/20,8/25]。
```

因此两套 D029 四行均通过。然而共同提升要求 t_1+t_2<=9/20，两个下界之和却为 11/20，缺口 1/10。对应 MG 行为

```text
2q+x <= 1+(18/5)*alpha，
点上左侧29/10，右侧28/10。
```

这条行使用由原共同证书推出的 B_*=d-A_2=23/5，并未调用该交叉方向更紧的真实支持。第 2 个观察的相关下界 A_2=-37/10 严格强于独立拆项的 L_2+a_2*u=-11/2，正好避开上一节的冗余定理。

加入总和观察仍不能排除此点：a_sum=-3，v_sum=x/2+2y/5，其 [L,U]=[-9/10,9/10]、[A,B]=[-7,32/5]。alpha=1/2 时，它的相位行和残差行都给范围 [-79/20,73/20]；点上的 a_sum*q=-3 和 a_sum*q+v_sum=-223/100 均在范围内。

但是一个有符号差分观察已经能排除它：a_diff=1，v_diff=3x/2-2y/5，其 [L,U]=[-19/10,19/10]、[A,B]=[-6/5,7/5]。其上侧行是 q+v_diff<=19/10-alpha/2，点上 203/100>33/20，违反 19/50。

所以正控只证明“原两观察加固定总和”不闭合，不证明超越全部派生 D029 观察。在本例 v_i 均为源仿射函数，完整单门 source labeled hull 已蕴含这些有效行；不能把它说成击败强单门对照，更不能把这个分数假点记作具体 ADV。零点两种原相位的保留由上面的统一扩展证明覆盖。

## 成本和定义研究结论

当 q、v_1、v_2 已有独立坐标，按一般非零系数计数：两套六行提升加一条共同提升，共 13 行、35 nnz、2 个辅助量；精确投影并去冗余后为 13 行、32 nnz、0 个辅助量。新增五行占 12 nnz。系数为零或发生抵消时应按真实矩阵重新计数，不能保证所有情形严格下降。

原共同谓词、观察定义、源证书、原 bits、共享存储、decoder 和终端都在两侧完整保留并计费。这是相对假设提升系统的纸面计数，不是生产矩阵、CPU 或 GPU 的实测改善。尤其 v_i 若不是已有坐标，展开可能将每行放大到整个 Conv fan in。

这些结果属于已知 RLT 与线性消元机制。RLT 使用原有乘积关系的先例见 [Bestuzheva 等 §2–3](https://arxiv.org/pdf/2211.13545v1)；将 RLT 组织进 HZ 的直接对照见 [Sharp Hybrid Zonotopes §IV Theorem 7](https://arxiv.org/html/2503.17483v2)。本研究不采用论文中 LP 解点驱动的 cut 分离、BaB 或相位搜索。

本次不把共同投影宣布为新域。它提供了同一原相位内的单调观察闭包、一个有限接口的正控和一个会否决廉价实现的冗余定理。新相位下的组合仍未解决，D029 的跨相位反例仍有效。下一项能力研究必须使用实际构造的共同源相关界，比较有符号聚合和强局部关系，并证明能在普通神经结构及完整成本内继续组合。
