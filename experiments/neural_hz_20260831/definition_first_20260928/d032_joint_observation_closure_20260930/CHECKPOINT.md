上一轮为 progress：D031 保存跨领域机制、树形局部凸包反例和共同投影假设。本轮重新核对 D031 hash、D029 数学文件、当前分支与 Goal 后继续研究。本轮也为 progress：得到共同投影的精确闭包与已知单观察的归约、普通有限观察正控，以及否决独立拆项能力路线的冗余定理。这些证据改变下一步实现选择，而非只重述计划。

完整推导见 [数学记录](THEORY.md)。没有新的实验成绩；所有正控与反例为精确有理纸面推导，独立复核不是执行通过。

## 对候选的决定

不实现“独立区间拆项证书加共同投影”作为能力增强路径：在明确的原门和源行前提下，它的全部新增行均冗余。它可以留作未来负对照，但不能用其 GPU 可并行性替代能力收益。

不把五行投影作为新逻辑类别。全部行均可归约为 D029 派生单观察上侧关系；若后续采用，实质价值必须来自统一有限观察集合的构造、跨普通神经块的组合和完整成本，而非已知 cuts 的包装。

保留两个可用结果：同一相位、非负共同上界族共享一个反向扩展；固定两观察可将九条选择化为至多五条，在已有坐标下消去两个辅助量。新相位仍不能免费复用旧条件观察，不能据此宣称全网闭包。

## 已有真实结构可以提供什么

只读检查 D025 已完整保存的 large 记录，以及其 census.py、source_packet_v1.py。它包含第一 ReLU bank 的 1600 个源、五个 Conv 窗口、64 个消费者通道和每通道 576 个 canonical slots。原 source phase 是 `(port,c,y,x)` 语义身份；这不证明已经映射到生产 HZ 的实际二元列。

一个统一结构规则可以按原通道次序配对相邻 Conv 消费者 (0,1)、(2,3) 等。对同一 q_j，它们具有 z_i=a_i*q_j+v_i，取固定 lambda_1=lambda_2=1。不按模型、实例、margin、历史结果或 LP 状态选择，也不搜索最优 lambda。

原 packet 的 Conv weights/bias 是原浮点载荷的精确 Fraction；source_packet_v1.py 的模块说明及 Conv 返回记录明确区分这种实数参数语义和 IEEE 执行等价。因而可把观察统一放在原始 Conv 输出、BN 之前，获得确切 a_i。它不是替换网络，但 native tensor 坐标映射、数值语义、后续 BN 和输入见证仍须证明。

D025 census.py 生成的折叠 receiver 权重已经包含 BN 平方根的外包区间；不能把其中点当作五行里的精确系数。前一层源 forms 也含 BN 区间，求界仍需保留 D029 显式误差桥接。使用 raw Conv 并没有免除 source 认证。

第一残差块第二个 Conv6/BN7 的数值参数没有完整保存。已有文件只能支持第一 bank 的共同消费者，不能声称跨完整残差 Add 已成功。medium 没有完整逐行证据，Tiny 当时未进入；本轮不扩大这些旧记录的结论，也不重跑失败 D025。

## 全人口与稳定性筛除的准确条件

上述五窗口完整真实 gate 与通道对人口为 1600*32=51200；canonical 包括 padding 的人口为 5*576*32=92160，但 padding 没有原相位，不能凭空生成门。今后的候选检查必须保留完整人口与拒绝理由，而不是只报告有用组。

D025 RESULTS.md 与分类代码记录：727 个源严格正、863 个严格负、10 个外包跨零，恰好覆盖全部 1600，因此此旧集合没有剩余接触零类别。这是旧证据的只读引用，不是本轮重新数值普查；跨零也不证明实际两种符号可达。

严格符号在整数语义中使原 bit 固定，但不自动证明实际 LP 已包含 alpha=0 或 alpha=1。有些门的松弛会留下分数 alpha。因此仅在已核实原相位绑定，或计费加入正确固定相位等式且不删除原 bit 后，才可证明稳定门上的新关系对该比较松弛冗余。

在这个有条件前提下，完整 51200 组仍全部检查，最多 10*32=320 组可能需发射共同关系；五行的坐标级上限为 1600 行、3840 nnz。它不是当前生产终端的无条件上限。没有相位绑定证据时，不能把总体人口当成只有 320，更不能据此宣称完整成本很小。

## 求界成本与 GPU 边界

对原始 Conv 的固定相邻通道，残余共同上界可以由相加后的真实系数构造：先对每个 k 计算 w_1k+w_2k，再对 q_k 的认证区间取上界，去掉被观察的 j 项并加入两条 bias。这个规则保留线性系数抵消，不能使用旧 preactivation pair difference 界冒充消费者 residual 界。

若 L_i、U_i 与 A_i、B_i 都通过独立区间拆项构造，逐项贡献与总和可使所有 all but one 查询具有 O(W*C*K) 算术量，适合分段归约。但 THEORY.md 已证明其中 A_i=L_i+min(a_i*l,a_i*u) 的相关行被原门和源界支配。这条低成本方案不能当成能力候选。

必须另行构造更有信息的共享源相关界。D029 的正项共同支持与显式误差是一个可用数学起点，D030 只有未执行参考草稿；它们均未证明全通道、全被观察门的廉价查询成本。不同残余和配对会改变求界表达式，不能把单个观察的线性复杂度免费复用到整个层。

可并行的算术形式包括固定系数 gather、带认证误差的绝对值归约、共同源支持与固定行生成；尚无相应 GPU 执行、向外舍入或速度资格。512-bit Fraction 参考工作不等于 GPU FLOP。源解码、原 HZ 与 solver 存储、观察定义、证据、重构、设备内存及 CPU GPU 传输都须计入完整成本。

## 下一项实际研究对象

下一项应面对真实 Conv 共同消费者：用统一规则构造相关的 A_i/B_i 与共同 d，再检查交叉残差相对同源、同证书强度的总和、差分、既有联合关系和强局部门是否仍有价值。原始 Conv 前 BN 观察可避免将不确定折叠系数直接写成精确谓词，但不能省去 native 绑定和整个算子语义。

研究必须同时追踪下一 ReLU 的新相位；同相位五行成功不足以满足 Neural HZ 的定义目标。若只表现为已知观察闭包或不能以完整可承担成本获取相关证书，就保留为支撑组件，不以增加框架或放宽预算继续包装。

本轮没有创建数值候选或运行预注册；D030 未执行草稿及其静态待修项保持原样。任何后续执行仍需新的、事前冻结的源码和配置，继承原完整测试与资源门，不得事后缩人口或提高门槛。没有授权绕过冻结 GPU 失败版本的限制。
