# Neural-HZ 本体能力与已有聚合对照

本记录回应用户要求：研究重点是从 HZ 数学定义出发提出强大的非凸 Neural-HZ。当前共享源纤维候选改变了抽象关系，并非单纯存储优化，但还没有证明足以支持大规模实现的能力优势。本次只读复核发现一个更便宜的已有聚合对照，同样证明目前的六十门正控。因此不按上一轮计划直接扩大组件实现；先研究新关系相对这个强对照究竟保留了什么必要信息，并检查它在真实完整消费者结构中是否适用。

这是新的纸面负面比较，不是撤销已有健全性证明，也不是把已有聚合方法重新包装为创新域。原研究和测试证据只读保留；没有运行候选或修改正式成绩。

## 什么才算本体能力

新定义需要明确域元素、具体化、连续源与原二元相位的关系、谓词、共同身份与输入解码，以及对整个抽象父域健全的前向算子。可测试的能力目标是在相同信息、资源及普通终端求解条件下，保住已有结果并验证更多真实性质。变量更少、组件测试更多、另一个算法贡献的结论，都不能单独建立这种能力。

精确 HZ 的网络图本身不能被一个健全外包变得更精确；这里追求的是可计算的定义和变换在有限预算内保留、传播和查询有用非凸关系。当前候选也未声称集合表达能力超过 HZ，见[共享源定义](../d184_shared_source_factor_20261005/DEFINITION.md)。不将新增 helper、attack、split 或求解器菜单混入域收益；普通终端求解与原始网络见证验证边界不变。

## 更便宜的同性质对照

[已有正权聚合四行外包](../d152_live_amplitude_rank_20261004/THEORY.md)允许在全部消费者只需分组和时移除新生的逐门幅值，仍保留源、原 bits、guards 和输入解码。它是健全但通常有损的已知对照，不是新的精确域。

采用[上一轮相同的两源双 pooling 结构](../d184_shared_source_factor_20261005/STRUCTURAL_CONTROL.md)：源 x,y 属于 [0,1]²，g_i=a_i*x+b_i*y+d_i，a_i,b_i>0，d_i<-b_i，U_i=a_i+b_i+d_i>0。两组的完整输出仍为 Q 和 B；保留相同 live x skip，没有被遗漏的独立 q_i 消费者。令

```text
R_plus=(Q+B)/2, R_minus=(Q-B)/2,
A_g=sum_(i in g) a_i, D_g=sum_(i in g) b_i, c_g=sum_(i in g) d_i.
```

R 只是别名，不增加连续变量。每个原 bit beta_i 仍整数，保留相同弱 guards：

```text
d_i*(1-beta_i) <= g_i <= U_i*beta_i.
```

每组使用以下四行，并在出生时保留一条结构上有效的源关系：

```text
R_g >= 0,
R_g >= A_g*x+D_g*y+c_g,
R_g <= sum_(i in g) U_i*beta_i,
R_g <= A_g*x+D_g*y+sum_(i in g) d_i*beta_i,
Q+B <= 2*A_plus*x.
```

最后一行只添加一次。对任何父赋值，取 q_i=ReLU(g_i) 及其真实组和，前四行由逐门四行求和得到。又因 y<=1、d_i+b_i<0、a_i*x>=0，有 q_i<=a_i*x，得到最后一行。它是统一结构规则，不依赖实例、标签、目标 margin、求解状态或 helper。

全部原相位及零点双标签保留，源、父谓词、decoder 不变。四行不是完整逐门图的精确投影，不能用于收紧一个先前已经有损的父元素而不另作证明；这里限定在新生 ReLU 包的 sound 变换。其 Q/B 可作为下一算子的实际有损父读出继续传播，不得假定它们仍是原网络的唯一值。

该对照直接给出与共享源候选相同的

```text
J=(Q+B)/(2*A_plus)-x <= 0,
h=ReLU(J-1/10)=0.
```

这不以把原 bits 放松为连续作为原生语义。对上一轮六十门参数，输出投影也确实非凸：在 y=1，x=0 时全部 inactive、Q=0；x=1 时全部 active、Q=60-sum(delta_i)。这两个可行点的中点有 x=1/2、Q=30-sum(delta_i)/2；但此 x 下所有 g_i>0，guards 强制全 active，四行要求 Q=30-sum(delta_i)，所以中点不可行。

## 完整相同比较口径

以下与上一轮使用相同物理坐标计数，常数 RHS 不计系数 nnz；公共源盒、bit 界和 decoder 在前缀外单列，不把它们视为无成本。

原 guards 有 2m 行，每行含 x、y、一个 bit，共 6m 非零。两组非负行共4非零，组下界共8，两类上界分别为 m+4 和 m+8；额外源关系有3非零。故该对照前缀为4连续量、m原 bits、2m+9 LE、0 EQ、8m+27非零。

| 六十门前缀 | 连续量 | 原 bits | LE | EQ | 系数非零 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 共享源纤维候选 | 18 | 60 | 156 | 8 | 636 |
| 已有四行聚合加同一源关系 | 4 | 60 | 129 | 0 | 507 |

加入双方相同的4条源盒行，以及 j、h、后继原 bit、共同宽界与后继图，聚合对照为6连续、61原 bits、136 LE+1 EQ、522非零；共享源候选为20连续、61原 bits、163 LE+9 EQ、651非零。公共后继原 bit 的身份不删除。以上是纸面逻辑账，不是运行、物理峰值内存或速度测量。

不能从这个比较推断聚合对照精度支配共享源域。相反，共享源域已蕴含这里的全部行，在共同坐标上有 projection(共享源域) 包含于聚合对照；逆向包含尚未证明。因此本次否定的是“当前正控已展示足够的成本与能力优势”，而非否定共享源关系可能包含额外有用信息。

## 下一数学问题与研究取舍

下一问题是：在普通混权消费者、残差与后继非线性的完整组合中，共享源关系到底排除了上述聚合对照允许的哪些赋值；排除它们能否以可扩展成本带来额外可验证性质，而不是只换一种方式证明已被廉价行证明的 h=0？寻找可反证的定义和算子层答案，不先扩展 loader、helper 或通用审计框架。

同时必须核实真实完整消费者结构。已有[三模型前沿审计](../d181_shared_coefficient_frontier_20261004/REAL_BINDING_AUDIT.md)没有证明 CNN 存在可直接套用的两源双 pooling 接口；共享源定义的固定基 rank 限制也没有消失。不能仅选有利输出、丢失其他活读出或忽略独立残差来制造压缩。

保留共享源候选作为尚待证明研究价值的定义分支，不立即开始原计划的数学组件运行。若现有额外关系只能被更便宜规则替代，应修改定义假设；若能形成可靠分离，再按原协议冻结默认关闭的组件、保留完整数学人口，进入真实同结构及回放阶段。此取舍不减少验证要求，不暂停或完成 Goal，也不改变正式门槛。
