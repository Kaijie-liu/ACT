# 相位依赖源映射的维数要求与锚能量的精度边界

本轮直接检查两项 Neural-HZ 定义假设：让误差生成元随原相位改变，是否足以摆脱 D152 的固定加载障碍；给共同幅度关系增加真实参考点，是否能修复 D151 的反例。得到一项更精确的维数必要条件，以及一个旧 LP 已能证明、锚能量替换却不能证明的普通后继性质。因此不为这两种直接补丁启动实现。

这是纸面证明与独立审查，不是机器证明、候选测试、真实网络收益或外部新颖性声明。原连续源、全部原 signed bits、EQ/LE、共享 latent 身份、零点双标签和原输入 decoder 均不删除。beta=(signed bit+1)/2 只是原整数身份的记号。

## 仅让误差加载随相位变化仍可能需要原宽度

先在同一个父仿射 chart 中固定 k 个保留 anchors 为严格 inactive，其值恒为零。设剩余 n=m-k 个原预激活可以作为独立连续坐标 t；每个符号模式都有满维开区域可达。这个前提必须在同一个真实父域 chart 中成立，不能把不同祖先相位 chart 中分别出现的模式拼起来。

考虑健全覆盖所有原真实 labelled 状态的表示

```text
q_U = B*t + c_beta + E_beta*eta.
```

B 固定，c_beta 和 E_beta 可以任意依赖原相位，eta 也可以任意依赖源与相位，不要求可微、连续、凸或独立。原源的其他自由坐标可先在一张共同仿射截面上固定；若存在这种表示，它必须覆盖该截面上的全部真实状态。

在一个严格相位单元内，q_U=D_beta*t，D_beta=diag(beta_U)。对两个足够近的源点作差，不需要对 eta 求导，就有

```text
range(D_beta-B) ⊆ range(E_beta).
```

det(diag(beta_U)-B) 是 beta_U 的多重仿射多项式，最高项 product_i beta_i 的系数为 1。多重仿射多项式由 Boolean cube 上的值唯一确定，因此它不可能在全部 Boolean 顶点为零。至少一个可达相位使 D_beta-B 满秩 n，迫使该相位的误差宽度至少为 n。

这里对 Boolean cube 的论证是代数存在证明，不是允许的运行时相位枚举、split 或求解算法。它比 D152 的固定 E 结论覆盖更多表示，但假设也更强：要求同一 chart 中独立可达全部未锚相位。不能把它外推到只有少数相位可达的训练网络。

## 源相位调制与误差之间的维数支付

进一步允许源加载变化：B_beta=B_star+Delta_beta。令 K 是包含所有 range(Delta_beta) 的同一个固定输出子空间，dim(K)=t0。注意 t0 是这些像空间合并后的维数，不是 max_beta rank(Delta_beta)。中心 c_beta 仍可任意改变。

取商映射 Q，使 ker(Q)=K、rank(Q)=n-t0。对每个可达相位，有限差分给出

```text
range(Q*(D_beta-B_star)) ⊆ range(Q*E_beta).
```

选择 n-t0 个列组成 S，使 Q[:,S] 可逆。对应方阵

```text
Q[:,S]*diag(beta_S) - (Q*B_star)[:,S]
```

的行列式仍是多重仿射多项式，最高项系数 det(Q[:,S]) 非零。因此至少一个可达相位的左侧秩为 n-t0。如果误差宽度统一不超过 r，就必须满足

```text
r+t0 >= n = m-k。
```

t0=n 时该条件无额外限制。这个必要条件不是乘法数、终端行数或所有抽象域的复杂度下界；也不声称它充分。它指出，仅移动相位中心或只改变少数共同源方向，不能在这里免费取得任意低维幅度表示。要减少误差宽度，源与相位的联合映射必须承担相应独立方向，或者改变固定仿射读出的语言。

允许 B_beta=diag(beta)A 确实逃出固定 B 假设，但这正是 [D001 的 Boolean-affine 生成元](../D001_GUARDED_GENERATOR_DOMAIN.md)。该表达仍需证明完整终端查询不恢复全部 beta_i*g_i，不能因通过必要条件就宣布新域或净收益。

## 一个普通混权后继也跨零的控制

令 x∈[-1,1]^3，g=A*x+b、q=ReLU(g)，其中

```text
A = [ 1    1/4   0
      0    1     1/4
     -1/4  0     1 ],
b = (1/8, -1/10, 1/6)。
```

det(A)=63/64，且 ||A-I||_infinity=1/4。因此 ||A^(-1)||_infinity<=4/3。对每一个 g_i=±1/8，源 x=A^(-1)(g-b) 满足 ||x||_infinity<=7/18<1。所有相位及其开邻域确实在同一个源盒可达。原法向非平行，偏置非零，没有重复或恒零门。

任保留一个 inactive anchor，其余两个门满足前述定理：固定源加载加相位相关误差仍需 r>=2；若源调制只占 t0 维，则 r+t0>=2。所有原 bits 继续保留。

接实际混权和原源 skip：

```text
W = [ 1   -1/4   0
      0    1    -1/4
     -1/4  0     1 ],
h = W*q+x/10-1/20,
r_next = ReLU(h)。
```

W 可逆，故完整活预激活读出没有因这个消费者降低幅度维数。g 全为 -1/8 时 q=0，每个 h_i<=-1/90；g 全为 1/8 时 W*q=(3/32)*1，每个 h_i>=7/1440。下一层三个门也真正 crossing，不能靠把整个后继判稳定来绕开这个控制。

这里不证明任何后 ReLU 上下文商都不可能；若一种新表示只保存 r_next 而不保存 h/q 的完整读出，它已改变本定理的接口假设，必须另证具体化和原相位守卫。例子仅确认本必要条件适用于非退化普通结构，不是训练模型测量。

## 真实参考点的增量能量仍允许幅度膨胀

对真实参考点 (gbar,qbar=ReLU(gbar))，ReLU 的标量 firm inequality 相加给出健全关系

```text
||q-qbar||^2 <= (g-gbar)^T*(q-qbar)。
```

令 n=q-g、nbar=qbar-gbar，它等价于 (q-qbar)^T*(n-nbar)<=0。这是已有增量扇区关系，不是新非凸语义定理。它确实排除 D151 在参考源位置改变 q 的假点，但离开参考点后不强制真实幅度。

更一般地，标量仿射门在连通源盒上真正跨零，实际范围为 [l,u] 且 l<0<u；取该区间内任意有限个非零参考预激活 a_j。若 a_j>0，关系为 (q-a_j)(q-g)<=0；若 a_j<0，为 q*(q-g+a_j)<=0。选实际可达的 0<g<u 且小于所有正 a_j，再选严格正的 epsilon 小于所有适用的 a_j-g、-a_j 和 u-g；某侧参考集合为空时省略该侧项。令 q=g+epsilon、原 beta=1，就严格满足所有这些参考关系，以及 epigraph、原 guards 与 off-mask，却不是真实 q=g。一个宽松的 l<0<u 认证外界本身不足以证明这里的实际可达性。

这个证明不要求数值极小，也不禁止有限参考点提供有用近似。它仅否定“增加有限非零参考点就自动恢复精确门”的主张。某个 a_j=0 时，关系成为 q*(q-g)<=0，配合 q>=0、q>=g 恢复精确 ReLU；这是已知互补性及 D132 原记录，不是新的低成本替代。

## 锚能量替换会丢掉旧 LP 可证明的普通后继性质

取 x,y∈[-1,1]：

```text
g1=x-y/4+3/4,
g2=x+y/4+3/4,
gbar=qbar=(3/4,3/4)。
```

两门可靠精确界为 [-1/2,2]。在内部源 (x,y)=(-11/16,0)，原整数相位 (1,1) 下，g=(1/16,1/16)。假幅度 q=(23/32,23/32) 满足每个单独参考能量

```text
(qi-3/4)*(qi-gi)=-21/1024<0。
```

因此正权相加或共同参考球也接受。它还通过 D150 的五行和范数：D150 误差为 e=(5/16,5/16)，||e||^2=25/128<17/32，单坐标 |ei|<5/8。原源、相位、非负和 mask 均未破坏。

旧四行 LP 已推出 triangle 行 q1<=4*x/5-y/5+1。于是同一个混权、live source skip 读出

```text
J=q1-q2/4-4*x/5+y/5
```

在旧 LP 中满足 J<=1。接下一原门 r=ReLU(J-21/20)，正常前向稳定识别即证明 r 恒为零，margin 至少 1/20。

假点却给 J=697/640，从而可以接精确 child r=5/128>0。此真实参考网络的 child preactivation 为 -39/80、参考输出为零；精确 child 关系自动满足对应增量能量。因此问题会穿过后继非线性，不只是改变辅助变量。

这里比较的是父层可靠界经稳定识别的证明能力；不声称给旧 child 故意使用宽界的 fractional 四行后仍自动强制它为零。假点不是具体网络 ADV，也没有执行正式回归。这项普通纸面控制已足够拒绝无条件保旧声明。

## 原 LP 终端不能无损表达一般共同参考球

在一个固定源、固定原相位纤维，取 g=(1/8,1/8)、gbar=qbar=(1/4,1/4)。共同参考关系等价于

```text
||q-(3/16,3/16)||^2 <= 1/128。
```

交 q>=g 仍保留圆弧边界。可用 g_i=x±y/4+1/4、源 (-1/8,0) 实现这一切片；宽的原 bounds 和 D150 范数在相应圆弧附近不生效。有限 LP 扩展投影是多面体，有限二元变量也只能给有限多面体并，故不能精确表达这个切片。

结论只针对保留该曲边的共同球版本，不泛指所有 singleton 或零参考变体。送入原终端必须明确做有损线性外包，或者恢复原精确门关系；在 GPU 上便宜计算一个点的二次式，不等于完成全集合的健全查询。仍要支付全部源、相位、幅度、谓词、可靠界、共同读出和输入重构。

## 给差分图加锚也不能单独补齐原幅度

另一个替代是 grounded Laplacian M，把 q^T*M*(g-q)>=0 与原 guards、mask、epigraph 和一个精确锚组合。M 非对角项非正时，该静态关系对真实 ReLU 健全，因为逐门互补项为零，其他各项非负。

但正定并不足够。取 g1=x-y/4+1/2、g2=x/4+y+1/8，源盒 [-1,1]^2，M=[[2,-1],[-1,1]]。在原源零点和原相位 (1,1)，令 q=(1/2,1/4)，其中第一门精确。此时 q^T*M*(g-q)=1/32>0，全部上述约束通过，真实第二幅值却为 1/8。M 无零空间；不是 D151 的共同平移反例。

接 r=ReLU(q2-q1/4+x/8-1/16)，同源真实值为零、假值为 1/16。这只分离一个源纤维，不是全盒 CERT。一般在全激活区取 q=g+epsilon*ei，能量为 -epsilon*(Mg)i-epsilon^2*Mii；负非对角项可能使 (Mg)i<0，允许正幅度膨胀。

文献也限制其新颖性：[Vahedi Noori 等，Theorem 7](https://arxiv.org/html/2407.06888v2#S5.SS4) 证明其 Zames–Falb QC 族加入“对角互补 QC 加非负 rails 的 copositive QC”后不扩大该组合族，标准 SDP 松弛亦如此。这不等于所有此类关系都被普通四行 LP 蕴含；比较对象不能偷换。论文的完整 QC/SDP 计算也不是本项目允许的免费终端路径。

## 对下一定义的实际约束

本轮没有实现候选。相位相关误差、有限真实参考球、grounding 三种直接修补都缺少完整优势，不能据此扩展 helper。新的生成关系若声称减少幅度维数，必须明确源相位调制所占方向；若采用非线性共同读出，必须给出混权和后续非线性的健全组合及原终端的实际代价。

这保留研究空间，而不是缩小目标：全相位可达假设可能在实际受约束源上不成立，相位依赖源映射和新的非线性接口也仍可能有用。但 D001 的原图重写、D137 的 clique 径向共享、D143 的聚合 product 外包均已有边界，不能反复换名。下一步必须交付新的结构性规则或可付再抽象，而不是再建立相同审计或小测试人口。
