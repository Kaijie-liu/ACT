# 从误差补丁转向源相位联合生成关系

本轮得到的是定义路线的具体边界，不是 Neural-HZ 能力突破。[THEORY.md](THEORY.md) 新增了相位依赖加载的维数支付条件、普通混权后继控制，以及固定参考能量会丢失旧 LP 恒零证明的反例。它们阻止继续为三个未解决主问题的补丁写实现；目前仍没有通过完整优势比较的新域候选。

## 本轮完成的研究

第一项是从 D152 固定 E 的障碍推进到任意 E_beta：在同一父 chart 内剩余 n 个门的全部相位独立可达时，若源加载固定，某个相位必需 n 维误差。进一步，若源加载变化的全部像空间包含于同一个 t0 维空间，则统一误差宽度 r 必须满足 r+t0>=n。证明使用有限差分、商映射与多重仿射行列式，不枚举运行时相位，也不要求误差可微。

三源三门的有偏置混权控制满足所有前提，接可逆混权、原源 skip 和下一 ReLU 后，下一层也实际跨零。它说明该边界不是由重复门、零门或极端数值造成；不宣称实际 CIFAR/Tiny 已满足全部相位可达前提。

第二项是实际参考点不能自动替代源绑定。有限非零参考点不保证精确 ReLU；一个明确的普通两门例子中，候选接受 J=697/640，而同源旧四行 LP 已证明 J<=1。接 ReLU(J-21/20)，旧前向稳定识别证明恒零，候选可以产生 5/128 假幅度。这个点不是 ADV，也不是测得的正式回归。

第三项检查了给差分图加精确锚和 grounding 的想法。即使 M 正定、没有零空间、一个门完全精确，另一个原整数 active 门仍能膨胀。共同参考球一般还留下曲边，不能无损交给有限 LP/MILP 扩展；点值 GPU 能量计算不是集合查询。没有用新的 QP/SDP、dual helper 或相位搜索补这个缺口。
