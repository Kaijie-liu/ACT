# 守卫外残差结构的严格物理分离

本页给出定量守卫公式的普通声明网络正控。所有数值均为纸面有理数推导，已经独立审阅但未运行候选。新关系证明实际后继 ReLU 为零，两个明确的强松弛参照仍允许正幅值；这不是 benchmark CERT 或具体 ADV。

## 声明网络与有限证书

完整原源为 A in [0,1]^4、t in [-1,1]，定义

~~~text
x1=A1-A2, x2=A3-A4, qi=ReLU(xi),
z=(17/20)*(x1+x2)+(3/50)*(q1+q2)+t/10,
Y1=ReLU(z+q1-q2), Y2=ReLU(z-q1+q2),
Dabs=2*q1-x1+2*q2-x2,
F=Dabs+(2/5)*(Y1-Y2-(x1-x2)/2),
Rout=ReLU(F-207/100).
~~~

实际仿射网络把 x_i 代为 A 的差；这里的 x 别名仅方便证明，没有新增假定的父预激活直边。所有父子原位、源和 skip 读出保留。

提取固定 tau=1、e=0、a1=a2=17/20、b1=b2=3/50、r=t/10。两个不同相位事件的 z 界都为 [-19/20,101/100]，旧 hard guard 因上界超过1而失败。两个 eta_minus 为0，两个 eta_plus 为1/100；QG 上行只多 (1/100)*alpha2，下行只多 (1/100)*alpha1。

设 V=q1-q2+d12-d21、s_i=alpha_i*t。已有 MC 给 V<=1、s1-s2<=1，已有源容量给 T<=p2+n2。按 THEORY.md 上行作非负组合，可得

~~~text
F <= 258/125 + alpha2/250
     -(4/5)*p1-(6/5)*n1-(3/50)*p2-(23/50)*n2
  <= 517/250 = 2.068.
~~~

四个 deficit 系数严格为负，alpha2<=1 是原约束。证书排除同一物理点的全部辅助扩展，不是只检查一个产品猜测。它证明 Rout=0，新后继预激活上界为 -1/500。不声称517/250是实际网络的最优上界。

## 两个完整单子门参照

取 u=99/100，显示点为

~~~text
A=(1/2,1/2,1/2,1/2), t=0, x1=x2=0,
alpha1=alpha2=gamma1=gamma2=1/2,
q1=q2=u/2,
(Y1,Y2)=u*(163/200,113/200).
~~~

它给 F=(21/10)*u=2079/1000，超过新有效界11/1000；追加实际后继图允许 Rout=9/1000。

证明每个完整单子门带源及标签前缀凸包接受此点：取四个真实父角 (x1,x2)=(±u,±u)、t=0。两个同号角各占 delta，两个异号角各占1/2-delta。每个子门的幅值均值为

~~~text
Y/u = 53/100+(19/25)*delta.
~~~

第一前缀取 delta1=3/8，第二取 delta2=7/152，分别得到上述 Y1、Y2。质量全部严格正；每个 child 恰好在两个角 active，原 child 标签均值为1/2。完整源通过 A=((1+x1)/2,(1-x1)/2,(1+x2)/2,(1-x2)/2) 恢复，其每个坐标距盒边至少1/200。父 q、原位和源的均值相同，但两个前缀可选不同分布，因此不能将其误当作共同真实网络见证。

## 凸化父域上的联合双子门参照

令 P 是完整父图带源及原标签的凸包。A组由 alpha=(1,1/2)、(0,1/2) 两原子各半构成，并设 x=u*(2*alpha-1)、q=u*alpha、t=0；两原子属于 P。两原子的实际双子输出分别为 u*(36/25,11/25) 和(0,0)，均值 u*(18/25,11/50)。

C组由真实父位(0,0)、(1,1)各半构成，其双子幅值均值为u*(91/100,91/100)。A、C各取一半，得到显示点及全部原源、父幅值、父位和两个 child 位均值。各 child 预激活的绝对值至少为(8/25)*u，未利用零点标签歧义。

因此显示点也属于“先凸化完整父图，再同时接实际双子图并取带标签凸包”的参照。上述两个参照均不包含完整原源四门联合 hull 或完整跨层 RLT。

## 不是孤立的守卫临界点

保持 b=3/50、epsilon=1/10、lambda=2/5、u=99/100、A/C各半，仅令共同 a 改变。对整个开区间

~~~text
21/25 < a < 351/400,
~~~

hard guard 失败，eta_minus=0、eta_plus=a-21/25，新的有限上界为

~~~text
F <= 2+(2/5)*(a-17/25) < 2079/1000.
~~~

同一强参照构造给 Y/u=(3*a/4+71/400,3*a/4-29/400)，差恒为1/4。单前缀质量为 delta1=3/8、delta2=(3*a/4-241/400)/(2*a-47/50)，均严格介于0与1/2，故严格分离在整个参数区间成立。固定阈值207/100的后继零结论至少在更小的开区间21/25<a<171/200成立。

这是非零范围的构造族，但仍具有明确的二父/双子差分结构，不能从中推出随机 Conv pair 命中率或实际模型收益。

## 与旧合同的具体比较

固定a=17/20。旧纯 X 把rX=(3/50)*(q1+q2)+t/10作为余项，其完整范围为[-1/10,11/50]，所以旧 guard 要求tau>=107/100。实际差余项为(1-tau)*(q1-q2)，不能漏掉它的[-(tau-1),tau-1]支付。

显示点中取旧 c12=c21=0、v1=547/5000、v2=-1/20。两 v 均满足MC，K=797/5000，子差为99/400，上侧差为881/10000。tau=107/100时旧允许量为1507/10000，且随tau递增；下侧和源容量同样成立。这给出全部合格旧纯 X 参数的扩展。

旧纯 Q 的rQ=(17/20)*(x1+x2)+t/10范围为[-9/5,9/5]，guard 要求tau>=93/50。显示点取两个 cross-q 产品均99/400、两个 alpha*rQ 均0，K=0；最小tau的defect允许量为8693/5000，大于99/400，其后递增。因此旧纯 Q 的全部合格参数也接受显示点。

D248的原合同在没有未选Q尾时仍要求同一个core hard guard，因此以本例固定提取得不到资格。这不否定另加来源分解、条件矩或其他规则的更强参照。

本页没有证明优于所有重新选择tau的 hard-mixed 公式。事实上，取tau=101/100已有hard guard资格；令delta=tau-1=1/100，完整e支付为2*delta，K中另有delta*h。用h<=1及旧有限行可得F<=2+(2/5)*(3/50+1/10+3*delta)=519/250=2.076，也排除此显示点。这份证书尚不能证明固定阈值2.07的后继为零，但不能据此推断该合同的完整最优界或断言QG严格优于它。

新结果是固定原差分参数的一条统一公式、旧guard内逐行不退化，以及对以上明确参照的guard外严格分离。不能夸大为最优关系或最终Neural-HZ定义。
