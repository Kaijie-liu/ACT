# 条件 clip 替换为何不能继承旧关系

在采用定量守卫公式之前，本轮检验了给共同clip加入相位条件均值的替代。下面两项结论决定不为这个替代启动组件：自由条件均值可能完全冗余；即使绑定原六产品，指定条件clip外包仍会丢掉已有阳性。它们不否定保留更多完整共同来源关系的其他方法。

## 仿射水平切片下的投影等价

设有限凸多边形

~~~text
P={(z,S): L<=S<=U,
             a0+a1*S<=z<=b0+b1*S},
~~~

其中L<=U，两个端点上的水平宽度均非负，因而全区间非负。固定0<=alpha<=1，条件系统为(w,m) in alpha*P、(z-w,S-m) in (1-alpha)*P。所有零质量按齐次闭多面体解释，不作除法。

若w没有其他约束或消费者，消去w后恰为(z,S) in P和m=alpha*S在[L,U]上的四条MC：

~~~text
L*alpha <= m <= U*alpha,
S-U*(1-alpha) <= m <= S-L*(1-alpha).
~~~

证明：给定m，on事件的w区间端点是a0*alpha+a1*m和b0*alpha+b1*m；补事件的(z-w)端点同理。两区间相加的端点恰为a0+a1*S和b0+b1*S，与m无关。因此存在w恰好等价于全局z区间约束，而两事件S质量范围正好是四条MC。多个anchor只要各w没有别的消费者，可同时独立选择，结论不变。

alpha=0/1、L=U以及三角形、线段退化都由同一闭区间证明覆盖。全跨clip的水平端点为l+(tau-l)*S/(2*tau)、-tau+(u+tau)*S/(2*tau)，所以属于此类；单折点ReLU三角形也属于此类。水平端点分段而非仿射的更一般图不在此结论内。

因此仅增加自由的alpha*z，再用单事件条件clip，并没有新增物理信息。这个结论不适用于w已经被原源、原守卫或其他条件观察共同限制的情形。条件分解本身属于经典perspective/混合整数图的思路；[Anderson等的原文](https://arxiv.org/html/1811.08359v2)是应对照的既有强formulation来源，不是本项目新算法。

## 保留六产品后仍丢掉旧阳性

取D244原控制a=4/5、b=3/50、epsilon=1/10、u=199/200，而不是CONTROL.md的新参数。旧mixed guard成立。它的已证明强物理假点为x=t=0、alpha_i=gamma_i=1/2、q_i=199/400、Y=u*(397/500,297/500)，子差199/1000。

六产品选择

~~~text
c12=c21=0,
d12=d21=199/800,
v1=v2=0.
~~~

满足24条MC及三条X容量，并给K=0。旧mixed上行只允许2*p2=1/200，因此这组辅助值不满足旧关系。排除该物理点的全部辅助扩展则使用D244已经证明的物理证书：该点F=2587/1250，而旧mixed有限行给F<=258/125。不能用一组辅助值失败替代这个全扩展结论。

拟议替代保留w_i=alpha_i*z的六产品内联定义；此时z=597/10000、w1=w2=17711/40000。z完整范围为[l,u_z]=[-17/10,91/50]，clip高为2。对每个i分别要求

~~~text
(w_i,m_i) in alpha_i*conv graph(clip),
(z-w_i,S-m_i) in (1-alpha_i)*conv graph(clip),
~~~

再以m1-m2替换K登记原defect。取S=1、m1=9/10、m2=7/10，可通过全部条件行。

具体地，正事件的m区间为

~~~text
[100/141*(w+1/2), 20/27*(w+17/20)]
 = [37711/56400,51711/54000],
~~~

且还受[0,1]约束。补事件的S-m区间为

~~~text
[100/141*(z-w+1/2), 20/27*(z-w+17/20)]
 = [4677/56400,18677/54000],
~~~

同样位于[0,1]内。正事件的9/10、7/10及补事件的1/10、3/10均在这些区间内。子差与m1-m2=1/5之差为-1/1000，在原deficit区间[-1/200,1/200]内。

因此这个条件clip替代连原guard内已取得的物理排除都不能保留。它不是一个可直接接替D245的加强。此处不声称所有联合clip形式都弱，也不把辅助矩的不相容冒充物理收益；本反例给出了完整物理假点的具体辅助扩展。

## 取舍

不实现上述三新连续量的替代。THEORY.md改为保留原K及全部六产品，用原相位支付有证超额，零超额时精确回到旧关系。该选择由以上反例和新的整父域证明驱动，不依据实例身份、模型结论或LP状态。
