# 同锚关系在认证区间系数下的前向传递

本页把 [D044 通用种子证明](../d044_relational_generator_20260930/PROOF.md) 的点系数规则扩展到有可靠包络的固定模型系数，包含 BatchNorm 等产生的非点系数证书。拟考察的是真实已存卷积窗口上固定消费者对的适用性，不是重新运行网络或证明新成绩。规则保留原非凸 HZ，仅生成同一个原相位锚下的差值与伴随观察；不同源对的原 bits 绝不合并。

本页给出健全性和可复核成本公式，不宣称真实适用率、原生相位绑定、终端非冗余、GPU 性能或完整 Neural-HZ 创新已经成立。候选默认关闭，执行与资源资格由本目录单独冻结的预注册和结果决定。

## 原语义和同一赋值

沿用 D044 的原载体 `H=(B_H,D_H,P_H,F_H,decoder)`：连续因子仍在原盒 `B_H`，全部原二元因子仍在 `D_H`，原 EQ/LE、门关系和共享 latent 身份均保留。对每条观察保存原锚 `alpha`、原物理读出 `E`、两状态端点及证书，具体化为

```text
gamma(H,O) = { F_H(xi,b) : xi in B_H, b in D_H, P_H(xi,b),
              every O holds on this SAME original assignment }.

L0+(L1-L0)*alpha <= E <= U0+(U1-U0)*alpha.
```

观察有原整数语义上的证明才可安装，因此不改变原整数集合、输入 decoder 或精确非凸性。它可能加强连续查询松弛，但不能把端点元数据解释成原网络以外的独立输入或新 phase。本文 `alpha` 为原门的 0/1 编码；原预激活为零时两种原 bit 均合法。若原编码为 -1/+1，必须认证 active 方向后使用相应仿射映射，原 bit 本身不删除或替换。

下文的 `s=0,1` 是固定两个端点槽及证明分情况，不是执行两个受限网络、phase 子问题、枚举搜索或 split。系数区间包围同一个固定原模型的真实系数，不把参数误差当成新模型 latent。

## 固定完整人口和身份绑定

本轮固定五个已存原空间窗口、64 个实际接收通道。接收对严格为 `(0,1),(2,3),...,(62,63)`，每窗 32 对。每个接收对保留全部 576 个 canonical fan-in 槽，源对严格为 `(0,1),(2,3),...,(574,575)`，每窗 288 对。因此完整人口是

```text
5 windows * 32 actual consumer pairs * 288 source pairs
= 46,080 anchor-consumer occurrences.
```

槽序由原 channel/kernel 顺序和 padding 几何确定，不去掉 padding、零项或稳定源后重新配对。每次 occurrence 只使用源对的 even 槽原门 bit 作为锚；另外 574 个槽只提供无条件界，不能偷用各自 bit 的条件界再把结果放在同一个 alpha 下。消费者通道固定先 even 为 `h`、odd 为 `w`，不按系数或观察收益换向。

绑定需保留原模型及 property、窗口、输入 frame、源 ReLU 输出端口与 channel/row/column、接收端口及系数 provenance。相同数字区间、标签或 tensor shape 不证明身份相同。源差界必须对应这个方向的原预激活 `g_j-g_k`，而非激活差、反向差或另一窗口。padding 没有可虚构的原相位锚；其 occurrence 仍记录但不生成条件行。真实源的严格 active、严格 inactive、两种单侧含零、恒零、crossing，以及缺证书状态均保留记录；重点统计 crossing 锚，不能以此缩小分母。

五窗的源对证书最多有 `5*288=1,440` 个不同槽记录，可按认证源身份共享；每个被固定消费者对消费一次仍有独立的 occurrence 成本。它们不是 46,080 个不同原 bits，也不是 46,080 个独立模型样例。

## 有限区间算术与消费者共同读出

设原源激活 `q_i=R(g_i)`，`R(x)=max(0,x)`。原证书给出有限 `G_i=[l_i,u_i]`，于是 `Q_i=[max(0,l_i),max(0,u_i)]`。两个实际消费者为

```text
h = b_h + sum_i a_i*q_i,
w = b_w + sum_i b_i*q_i.
```

真实固定系数分别包含在认证区间 `A_i,B_i`，偏置在 `B_h,B_w`。先构造

```text
C_i = A_i - B_i,
Delta_b = B_h - B_w.
```

减法是标准可靠区间减法；只有认证为同一参数及同一读出的项，才可在区间化前作精确代数抵消。两个相同非点区间不意味着实际参数相同，不能把它们的差强行设为零。相同固定参数出现在多个位置时，下面逐项外包仍健全，但可能忽略参数相关性；不声称因此获得最紧界。

区间乘法统一使用四个端点乘积：

```text
[a,b] * [c,d] = [min(ac,ad,bc,bd), max(ac,ad,bc,bd)].
```

即使某系数跨零也不改用中点或另选执行路径。精确有理数端点按有理数计算；若以后使用机器浮点，所有原证书和后续操作均须证明向外舍入，BN 的开方及融合顺序不能被本公式省略。

## 只从同一逐项和扣回的残差

对一个消费者对预先付费构造全部差值贡献及 `w` 贡献：

```text
I_i = C_i * Q_i,
J_i = B_i * Q_i,
I = Delta_b + sum_i I_i,
J = B_w + sum_i J_i.
```

`I` 是先按共同原激活合并系数后的独立贡献差界；它不是分别包围 `h,w` 后相减的另一种界。若另记录后一种界，必须明确其公式和来源，不把二者混称为同一个 baseline。

对固定源对 `j,k=j+1`，残差只这样得到：

```text
R_delta.lower = I.lower - I_j.lower - I_k.lower,
R_delta.upper = I.upper - I_j.upper - I_k.upper,
R_w.lower = J.lower - J_j.lower - J_k.lower,
R_w.upper = J.upper - J_j.upper - J_k.upper.
```

这不是一般意义的区间除去运算，而是还原已保存的逐项端点和：下界减去下端贡献，上界减去上端贡献，恰好留下偏置和其余 574 项。证明只需每项实际贡献落在自己的区间，故剩余实际和落在上述残差内。

严禁从已和其他证书相交的、更紧全局界或 archived old ordinary bound 中扣回这两项；较紧总界可能依赖被扣项与其他源的关系，这样扣回没有一般健全性。也不能给 `w` 使用 `I` 的残差。任何后续旧界相交都必须发生在完整新读出重新组合之后。

## 同一个原锚下的通用种子

对有真实 even 锚的源对，记

```text
g=g_j, f=g_k, q=q_j, p=q_k, d=q-p,
alpha = original phase of q=R(g),
g in [lg,ug], f in [lf,uf], g-f in [L,U].
```

只读使用同源认证预激活差界，无受限 LP 或免费的条件支持 oracle。D044 的固定种子为

```text
P0 = [max(0,lf), max(0,min(uf,-L))],
P1 = [max(0,max(lf,-U)), max(0,uf)],
D0 = [-P0.upper,-P0.lower],
D1 = [max(max(0,lg)-P1.upper,min(0,L)),
      min(ug-P1.lower,max(0,U))].
```

在每个真实 `alpha=s` 的赋值上，`p in P_s,d in D_s`。证明复用 `alpha=0 => g<=0,q=0`、`alpha=1 => g>=0,q=g` 及 ReLU 的单调性和 1-Lipschitz 性；不要求两激活有支配关系。`g=0` 时两种原 alpha 的真值均受各自种子包围，不能把两个 bit 合并。其他原 gate bits，包括 `f=0` 的两种选择，完全保留。

稳定源的空条件状态可能让这个种子端点逆序。该 occurrence 必须记录 `SEED_CONTRADICTION`，不给新条件观察、计零 tightening，但不删除记录、bit 或原谓词，不宣告 UNSAT；它也可能只是外部前提不一致的表现。无条件原始证书自身矛盾、身份不符、非有限数或预算失败则 fail-closed 拒绝本次候选结果。padding 锚记录 `PADDING`，不得制造 alpha；能够构造两个有序有限状态的原锚记录正常计算结果。稳定锚上出现端点变化不等于有可用的新 LP 约束。

## 区间系数的固定差值加伴随传递

真实系数恒等式为

```text
h-w = residual_delta + c_j*d + (c_j+c_k)*p,
w   = residual_w     + b_j*d + (b_j+b_k)*p,
```

其中 `c_i=a_i-b_i`。因此对同一个 `s`，可靠包络为

```text
K_s = R_delta + C_j*D_s + (C_j+C_k)*P_s,
W_s = R_w     + B_j*D_s + (B_j+B_k)*P_s.
```

所有乘法按四乘积定义。`C_j` 与 `C_j+C_k` 的相关性被外包忽略只会放宽包络；公式不是把它们当成可独立改变的真实参数。这里先用 `q=d+p` 合并固定读出，再进行区间化，不能把 `q,p` 分别独立区间化后称仍保留了这一差值表示。

设两个消费者后的原节点为 `r=R(h),t=R(w)`，保留它们自己的原 bits。逐点不等式

```text
min(0,h-w) <= r-t <= max(0,h-w)
```

给出同锚下一前沿

```text
E_s = [min(0,K_s.lower), max(0,K_s.upper)],
T_s = [max(0,W_s.lower), max(0,W_s.upper)].
```

于是 `(alpha,r-t,E_0,E_1)` 与 `(alpha,t,T_0,T_1)` 可继续被同锚 paired-affine 消费。消费者原 bits 仍参与原门语义，但没有被偷换为锚，也没有获得跨不同锚的联合条件。两条状态槽上的有效性加上原 alpha 为整数，就证明对应仿射相位行对全部真实赋值有效；分数 alpha 下只称有效线性外包，不称完整联合 hull。

本 census 只考察上述一次局部传递，不把 D044 纸面两跳闭包当成真实模型已经跑过多层的证据。

## 公平的无条件比较与统计含义

独立贡献 baseline 为上文 `I`；它与固定 pair 的无条件关系 baseline 都必须保存。后者使用

```text
P_star = Q_k,
D_star = [min(0,L),max(0,U)]
         intersect [Q_j.lower-Q_k.upper,Q_j.upper-Q_k.lower],
K_star = R_delta + C_j*D_star + (C_j+C_k)*P_star.
```

这个全局交若为空，属于无条件原始前提矛盾，不得返回貌似成功的统计。`K_star` 使用与条件规则完全相同的源对、方向、系数和已付费残差，仅去掉 alpha 条件；不按结果挑另一个更有利 pair。`I` 与 `K_star` 不必相互支配，不能预设所有关系换元都会改善界。

分别记录 `K_s` 相对 `I` 和 `K_star` 的下端提高、上端降低，以及 ReLU clamp 后 `E_s` 相对各自 clamp baseline 的变化。端点变化应使用同一阶段和同一量比较，不能拿 preactivation 界与 postactivation 界混比。若选择把完整新界与现有可靠全局界相交，另列原始生成值和交后的值，不把相交结果用于前述残差扣回。

这些严格端点变化至多支持 `bound_tightening` 或 `POTENTIAL`：即使条件端点严格改善，也可能已由原 gate、稳定相位、D020 或其他原谓词隐含。严格 crossing 源锚的统计比稳定锚更有解释力，但仍不是终端非冗余。必须分别给出全部 46,080 人口与 crossing、稳定、含零、padding、缺前提的子类分母，完整记录失败及零变化。不得删掉无收益消费者或按 margin、求解标签、phase 状态回选规则。

当前没有认证 native phase-column binding，没有把行加入真实查询，也没有与强单门完整 source hull、D020 和相同 facts 的 HZ 全部作终端比较。精确 HZ 加完全相同行有相同逻辑强度；这不是否决该构造方式，但禁止把同样事实重新命名成精确表达力提升。

## 非点系数仍保留严格纸面正控

以下只证明非点系数证书不会必然抹掉 D044 的严格分离，不是新的网络实验或实际 BN 适用率。取 D044 的两个网络，其 `q,p` 消费者系数各使用半径 `epsilon=1/10000` 的区间证书：`h` 的 `2/5,-1` 与 `w` 的 `1/5,-1/10`，并把两个 bias `3/20,0` 各扩为半径 epsilon 的区间。实际网络仍是区间中心的原网络。原 `y` 的共同系数均为点值 1，可按已认证同源读出抵消；原 `-z/10` 保持点系数，`z in [-1,1]`。因此

```text
C_q = [1/5-2*epsilon,1/5+2*epsilon],
C_q+C_p = [-7/10-4*epsilon,-7/10+4*epsilon],
R_delta = [1/20-2*epsilon,1/4+2*epsilon].
```

这个残差包含已知共享原输入读出，仍由原盒直接认证；真实卷积 census 则按上文其余 574 个激活贡献构造残差。二者都不需要条件支持 oracle。以下 epsilon 下两个系数的符号固定，直接展开四乘积即可。

对 [D044 有序前缀](../d044_relational_generator_20260930/PROOF.md)，原种子为 `D0=P0=[0,0]`、`D1=[0,9/20]`、`P1=[0,3/4]`，得到

```text
K0 = [1/20-2*epsilon,1/4+2*epsilon],
K1 = [-19/40-5*epsilon,17/50+29*epsilon/10].
```

第一状态的 ReLU 差值下界仍为零。令 `C=19/40+5*epsilon`，结合原 `q-x<=1-alpha`，仍有物理性质 `t-r+C*(q-x)<=C`。D044 原旧点对此性质的违反量为

```text
1/400-epsilon/2 = 49/20000 > 0.
```

对 [D044 无支配前缀](../d044_relational_generator_20260930/NONORDERED_PROOF.md)，种子为 `D0=[-3/20,0],P0=[0,3/20]`、`D1=[-3/20,1/4],P1=[0,19/20]`，得到

```text
K0 = [-17/200-29*epsilon/10,1/4+2*epsilon],
K1 = [-129/200-61*epsilon/10,3/10+5*epsilon/2].
```

两状态均跨零，ReLU 差值 clamp 不改变这些端点。于是令

```text
I0 = 17/200+29*epsilon/10,
C = 14/25+16*epsilon/5,
B = I0+C = 129/200+61*epsilon/10,
```

得到 `t-r<=I0+C*alpha`，从而 `t-r+C*(q-x)<=B`。NONORDERED_PROOF 的原旧点违反量为

```text
7/1000-153*epsilon/50 = 3347/500000 > 0.
```

旧强比较点、六对差界及嵌套 hull 见证都属于原中心网络，不因外包证书扩宽而变成实际反例；新性质则由覆盖该中心的非点证书可靠推出。这里没有声称新的物理上界 B 可达到，也没有把强比较系统免费改成有全部新条件行的系统。两个例子的 scope 和新颖性限制继续沿用 D044。

## 预处理复用和完整费用

一个消费者对有 n=576 个 canonical 槽。其 `C_i,Q_i,I_i,J_i` 和两个端点总和用 O(n) 区间操作及存储完成；每个固定源对只扣回两项、计算两状态各两个差值乘积及两个伴随乘积，故之后每 occurrence 为 O(1) 次固定宽区间操作。不能为了每一个锚重新扫描另外 574 项，也不能用大 O 隐去每个四乘积、比较、数值位长和证书检查。

本人口共有 160 个消费者对，预处理触及 `160*576=92,160` 个 canonical 位置；差值和伴随各有自己的贡献数组。随后固定计算 46,080 次 occurrence，每次两个状态上的差值与伴随共八次区间乘法，另计无条件对照、seed、clamp、分类和证据。源种子及 1,440 个 pair 证书可按认证身份共享，但它们的构造、读取、hash、provenance、保留内存和每次引用仍付费。历史 archive 只读复用不意味着原 source 支持、BN 认证或解析成本为零。

每个可安装 occurrence 的后继差值加伴随前沿有八个端点；若全部 46,080 记录都保留这八项，仅这些条件端点就有最多 368,640 个数值位置。独立界、无条件对照、原证书、源/bit/系数身份、解析树、临时数组及输出元数据另计；不把它称作全部内存。只保留一个消费者对工作数组时其局部缓冲可为 O(576)，但已保留结果与原 archive 的实物根仍同时存在。

如果未来真实物化观察，设 `E_s=[l_s,u_s]`、`T_s=[a_s,b_s]`，在已有物理坐标上对应

```text
r-t-(u1-u0)*alpha <= u0,
-r+t+(l1-l0)*alpha <= -l0,
t-(b1-b0)*alpha <= b0,
-t+(a1-a0)*alpha <= -a0.
```

每 occurrence 最多四行、十个坐标 nnz，0 个新 bit，0 个必要新差值变量；按完整人口的粗上限为 184,320 行和 460,800 个坐标 nnz，padding/缺证书实际不得安装。只消费差值则为两行至多六个坐标 nnz；伴随若只作前向元数据仍须计其端点和证明，不能声称它已加强终端。真实 latent 展开、RHS、编码 slack、原谓词、decoder、历史观察累积及保留数值对象均另计。

正向行算子使用原 `r,t,alpha` 读出；转置必须把每行乘子累加回相同原坐标及 bit，计入实际支持访问、scatter/reduction、dtype、传输和临时内存。若 `r,t` 是宽 latent 读出，十个坐标 nnz 不是最终 HZ 矩阵 nnz 或 GPU 工作保证。这一 CPU 档案 census 不授予 all-GPU、端到端提速或终端求解资格。

资源门沿用已有完整约束，不因一次预处理复用而放宽：全部 inherited 测试及测试人口、源码/输入 drift 检查，CPU 1、地址空间 16 GiB、测试组合 60 秒、worker 240 秒、whole work 256,000,000、branch work 200,000,000、evidence 预付 40,000,000 与 summary 65,536 bytes、retained 64,000,000 entries、512-bit 有理数及 1 GiB host-memory 门均须在新预注册中落实。若实际 parser、对象保留、证据或转置超额，结果为未通过，不删人口、不减验证或重选例子。这里的数学复杂度不是已执行的资源合格证。
