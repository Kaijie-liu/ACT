# 原生残差锥的源仿射前向证书

本轮得到一个可付的查询改进：用父坐标盒上的平方弦把 D171 源相关锥消费成一条固定前向仿射行。在普通 m>n 混权块上，它能排掉“两项全局球加 guards 和 caps”仍允许的假点，并证明后继门恒零。因此收益不是仅与一个人为弱的标量上界比较。不过它是已有平方弦和 Young 不等式的应用，不是新域定义；一般固定相位 LP 仍不能精确保留原生锥，完整成本优势也未证明。

本页是手工代数与独立审查，没有执行数学测试或新候选。它不属于本目录系数诊断的执行内容，不可把那次诊断当成本查询的组件资格。

## 不求解优化问题的统一行

在 D171 的同一个父状态上令 d=q−qbar，已有可靠坐标界 l_i≤d_i≤u_i。定义

```text
R_B²=Σ_i max(l_i²,u_i²),
B(d)=Σ_i [(l_i+u_i)d_i−l_i u_i].
```

因为 (d_i−l_i)(d_i−u_i)≤0，所以 ||d||²≤B(d)。B 的每个仿射分量在两个端点分别等于 l_i²、u_i²，故 B(d)≤R_B²。当 R_B>0 时，Young 或平方展开给

```text
||d||≤[B(d)+R_B²]/(2R_B)≤R_B.
```

所以原生关系 ||e||≤ρ||d|| 蕴含固定方向行

```text
wᵀe ≤ [ρ||w||/(2R_B)] [B(d)+R_B²].          (1)
```

先与原读出里的共同 q 系数、phase 系数、活 skip 合并，再对父域作已有的健全前向支持查询。没有搜索行权重、solver 状态、phase 枚举或网络 backward。R_B=0 时 d=e=0，不进行除法。

实际算术可预固定一个可靠 t≥R_B>0，用 [B(d)+t²]/(2t) 代替；同样健全且不超过 t，但不能据此声称它逐点不弱于更小的确切 R_B 或旧 R。所有 sqrt、除法、乘积与系数向外舍入必须另获数值资格。本页正控可解析消去平方根，因此结果为有理数。

当旧全局预算就是 R_B 且用精确公式时，(1) 逐方向不弱于旧 ρR_B||w||。若旧全局预算 R<R_B，必须同时保留旧证书并取最终标量上界的较小者。qbar 恰为坐标盒中点时 B 恒为 R_B²，新式退化为旧界；不能从形式不同推断普遍严格改善。

## 三门混权残差的全父域控制

取共同父源 q∈[0,2]^2，qbar=(1/2,1/2)，并令

```text
V=[[1,−1/2], [−1/2,1], [1/2,−1/2]],
c=(1/8,−3/8,1/8),
U=[[-1/2,11/40,−1/4], [19/80,−1/2,1/4]],
z=q+U ReLU(Vq+c).
```

三个 hidden 门都 crossing，其可靠界依次为 [-7/8,17/8]、[-11/8,13/8]、[-7/8,9/8]。它们法向非平行，偏置非零，m=3>n=2。本控制只是固定解析检验，不是系数诊断中采用的 λ 规范：这里 λ=1/2、K=11/4、ν=7/4，且

```text
E=U+λVᵀ=[[0,1/40,0],[-1/80,0,0]], ε=1/40,
α=11/16, ρ=117/160, L=167/160, R_B²=9/2,
gbar=(3/8,−1/8,1/8), zbar=(9/32,397/640).
```

E 非零，λK≤2，满足 D171 定义。对 w=(−1,1)、v=(−11/16,−21/16)，读出 J=wᵀz+vᵀq 的共同 q 系数为 (−1,−1)，phase 系数为 (177/640,31/320,1/16)。旧两项全局范数查询分别给 1683/640 和 2221/640。

新式中 B(d)=q_1+q_2+1/2，且 ||w||/(2R_B)=1/3，所以

```text
wᵀe≤(39/160)(q_1+q_2+5),
J≤1059/640<7/4.
```

整个父盒的后继 ReLU(J−7/4) 因此恒零，间隙为 61/640。对应可直接输出的线性行是

```text
−z_1+z_2+(11/160)q_1−(89/160)q_2
−(177/640)γ_1−(31/320)γ_2−(1/16)γ_3 ≤ 39/32.
```

它有七个变量系数，没有新幅值或 bits；但生成与存储七项也有成本。

## 完整两球外包确实遗漏该信息

保留同父盒、原 sign guards、全部 aggregate caps，把原生第一锥替换成全局球 ||e||≤ρR_B，并保留第二球 ||z−zbar||≤LR_B。这个较弱集合允许

```text
q=(1/64,1/64), γ=(1,0,1), z=(−17/16,3/4),
g=(17/128,−47/128,1/8),
e=(−1221/1024,1439/5120).
```

原相位严格合法。实际 caps 为

```text
−(17/16)γ_1−(9/32)γ_3 ≤ z_1−q_1 ≤ (143/320)γ_2,
−(13/16)γ_2 ≤ z_2−q_2 ≤ (323/640)γ_1+(9/32)γ_3.
```

假点均通过，且 ||e||²<153/100<ρ²R_B²。第二球也通过：||z−zbar||²=746489/409600<251001/51200=L²R_B²。它给 J=57/32>7/4，后继允许正值 1/32。

另一方面，原生锥拒绝它：||e||²>1，而 ρ²||q−qbar||²<1/2。式 (1) 也拒绝它。因此这是消费原生关系的新有限证书，不是改变 native 精度，也不是拒绝一个原本就不满足原相位的非法点。所有仅由上述完整两球外包蕴含的线性行仍接受该点；增加同一两球的方向数不能修复这项特定损失。

完整旧 HZ 仍可使用相同有效证书，所以这不证明新域超过精确图；比较价值在完整代价与实际网络界，不能只看小例阈值。

## 仍然存在固定相位凸化损失

在同一个控制固定 γ=101，取 q_±=qbar±(1/8,0)、h=(−1/32,1/64)，以及

```text
z_±=zbar±(5/128,0)+h.
```

两点通过全部原生条件：原 guards 严格成立，caps 成立，e=h 且 ||h||²=5/4096<ρ²/64，第二球也成立。但中点是 (qbar,zbar+h)，原生锥在 q=qbar 时要求 e=0，故拒绝中点。

任何以相同原 bits 为整数、其余仅连续线性变量构成的健全 lowering，在固定 γ 后投影为凸集，必须接受这个中点。新平方弦行也不能完整恢复该点值绑定。这是 [D158 固定相位几何界](../d158_joint_forward_support_20261004/THEORY.md) 在当前定义上的实例，不是所有 Neural-HZ 的不可能性结论。

对只含裸锥的对称盒还可精确说明损失：

```text
conv{(d,e):d∈[-b,b], ||e||≤ρ||d||}
  =[-b,b]×{e:||e||≤ρ||b||}, b≥0.
```

右侧任意固定 e 与每个盒顶点 d 都满足锥，因为所有顶点范数相同。把任意 d 写成这些顶点的凸组合即可证明逆包含；正向由全局上界直接得到。该等式不涵盖再与 guards/caps/第二球相交后的完整候选，不能外推为整个域无价值。

## 完整编译的账本

每个预固定方向需计算 Uᵀw、n 项平方弦、可靠范数、共同系数组合与父支持。写成线性行后，除 nnz(w) 个 z 项，可能涉及全部 n 个 q 和 m 个 γ；q 若内联为源读出，还须支付真实展开 nnz。

若预固定 k 个方向及其负向，且已证明新锥行支配旧误差全局球行（例如确切 R=R_B），用 2k 新锥行替换 2k 旧误差全局球行，另保 2k 输出球行，加 guards/caps 后为 2m+2n+4k 行。轴方向 k=n、m=2n 时为 10n，而精确旧图为 8n。若旧 R<R_B 且不能证明支配，为保留旧证书强度还须同时保留原 2k 行，总计可达 2m+2n+6k；上述轴方向情形为 12n。仅计算查询证书而不落行时另计计算费用，不能借此假装原生约束已被完整编译。候选的连续幅值较少，行数却更多，不能宣布已支付。

可在下一层实际混权方向上直接计算本来就需要的 bounds，而不额外铺满轴行；但传播的父域必须仍保留两条原生关系。若已经将父域替换成仅有限行的更大 outer，就不能继续冒用只在 native 上成立的预算。精确 nonlinear membership 也不是全局 support 或原终端 LP/MILP 决策。

本规则足以形成明确的后续数学组件任务，但本轮只执行另外预注册的系数诊断，不实现这个 query 或整个 D171。真实源预算、完整方向人口、数值认证和终端费用未通过前，不能把它升级为已实现的强 Neural-HZ。
