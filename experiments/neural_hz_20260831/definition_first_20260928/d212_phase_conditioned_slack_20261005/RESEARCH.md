# 原二元相位约束下的共同余量传递

本研究提出并证明一条相对现有共同余量规则更强的可消费关系。重点不是共享存储：利用 ReLU 原二元相位本身限制共同余量，取消为了保证全域正尺度而施加的稀释。新增乘积可完全投影掉；保留原连续因子、全部二元相位、EQ/LE、共享身份和原输入 decoder。一个普通双门加残差结构给出严格后继查询分离。

这是域内关系演算的候选改进，不是新的可表示集合类、完整新抽象域或论文新颖性认证。全网规模、GPU、smooth、Transformer 和正式新增解尚未取得证据。本文件为纸面证明；独立算术核对即使通过，也不替代已有完整数学人口或真实模型验证。

## 元素语义和原问题

父元素的共同赋值包含连续因子 xi、signed binary sigma、原 EQ/LE 及其共享身份。beta=(sigma+1)/2 仍只取 0 或 1。所有余量 theta 都是同一赋值上的原谓词或端点仿射读出，不是新增独立噪声。可见读出共同使用该赋值；Affine、Conv、Add 和 Concat 不分离共享来源。语义偏序仍为具体化集合包含，不假定最佳抽象或完整格。

取同一父元素上的两个 crossing preactivation f1、f2，固定 a=b=1/2；定理允许一般 a,b>=0 且 ab<1，但实现候选不得据实例选择这些参数。记 r1=f1-a*f2、r2=f2-b*f1。已有完整父证书为

```text
c_i-r_i = sum_j lambda_ij*theta_j + sum_k nu_ik*e_k,
c_i>0, lambda_ij>=0, theta_j>=0, e_k=0.
mu_j=min(lambda_1j/c1,lambda_2j/c2),
t=sum_j mu_j*theta_j >= 0.
```

按同一原行身份相减，R_i=c_i-r_i-c_i*t>=0。这是未稀释的共同余量。D209 将它改成 s=1-tau*t 并强制 s>=1/2；本研究不复用该正尺度前提。c_i 非正时不能除法，本正 cap 定理不适用，必须保留已证原规则，不能以此掩饰缺口。

## 激活相位自带余量上界

令

```text
U1=(c1+a*c2)/(1-a*b), U2=(c2+b*c1)/(1-a*b).
delta_1=(R1+a*R2)/(1-a*b)=U1*(1-t)-f1 >=0,
delta_2=(R2+b*R1)/(1-a*b)=U2*(1-t)-f2 >=0.
```

U_i>0。因此在原相位 beta_i=1 时，原 ReLU 图给 f_i>=0，必有 t<=1。全域允许 t>1：此时两个 f_i 都严格负，原相位自然不激活；无需分裂输入或枚举相位。f_i=0 的合法激活标签仍满足 t<=1，零点双标签均保留。

如果已拥有可靠下界 f_i>=-ell_i，则还有父域内生界

```text
T_i=1+ell_i/U_i,
T_i-t=(delta_i+f_i+ell_i)/U_i >=0,
T_int=min(T1,T2).
```

它不需要新增优化查询，但 f_i+ell_i 的原证明不能免费假定或丢弃。实现时须保留并认证对应下界证书，计入其所有成本。取已有合并自由盒界 B_box>=t，可以统一设 T=max(1,min(B_box,T_int))。这给 0<=t<=T 且 T>=1。T_int 不保证随深度不增长；ell_i/U_i 可能很大。本结论减轻自由盒独自控制精度的问题，不宣称已解决规模性。

## 非凸相位关系和精确投影

为证明暂引 z_i=beta_i*t，绝不把它视为自由误差。原整数语义给 0<=z_i<=beta_i，以及

```text
q_i <= U_i*(beta_i-z_i),
q_i <= a_ij*q_j+c_i*(beta_i-z_i).
```

第一条由 f_i<=U_i*(1-t) 和原相位得到；第二条在激活时用 q_i=f_i、q_j>=f_j，在不激活时由 q_i=0、q_j>=0 得到。证明没有终端 margin、LP 状态、标签或实例身份条件。

有限 0<=t<=T 下，binary-continuous 乘积的四条标准线性关系为 z>=0、z<=T*beta、z<=t、z>=t-T*(1-beta)。同时保留 z<=beta、上述两条 q 上界。连同 0<=beta<=1 和 q>=0，其消去 z 后的精确连续投影为

```text
q_i <= U_i*beta_i,
q_i <= U_i*((1-T)*beta_i+T-t),
q_i <= a_ij*q_j+c_i*beta_i,
q_i <= a_ij*q_j+c_i*((1-T)*beta_i+T-t).
```

必要性由 z 的两个下界得到。充分性取 z=max(0,t-T*(1-beta))：由 t<=T、t>=0 得 z<=T*beta 和 z<=t；q>=0 及第二条幅值行保证 z<=beta；两组 q 上界保证剩余关系。因此不必新增 z、连续因子或二元位，也不删原相位。该投影只对上述局部提升系统精确，不宣称是完整两门 ReLU 凸包。

这些行可以看作使用未归一化 s=1-t、下界 l=1-T<=0 的相位关系。但不能把负 l 直接塞进 D209 原 h 公式：其非负证明系数会失效。必须使用下面的新消费定理。

## 无当前相位残留的消费定理

令 u_i>0 是原 crossing 门的已证上界，原 on/off slack 为 O_i=u_i*beta_i-q_i>=0。新增反馈行的 slack 为

```text
A_i=c_i*(T-t)-c_i*(T-1)*beta_i+a_ij*q_j-q_i >=0.
D_i=u_i+c_i*(T-1)>0,
h_i=c_i*u_i*(T-t)/D_i,
M_ij=u_i*a_ij/D_i.
```

逐系数恒等式给

```text
h_i+M_ij*q_j-q_i
  = (u_i/D_i)*A_i + (c_i*(T-1)/D_i)*O_i >=0.
```

T>=1 保证系数非负；T>=t 保证 h_i>=0；0<=M_ij<=a_ij，故 M12*M21<=ab<1。与 D209 消费 active-upper slack 不同，这里消费原 on/off upper slack。h 是完整父域读出，不残留新 bank 的 bit 或乘积。

对完整方向 w，仍可用固定闭式

```text
v1=max(0,w1,(w1+M21*w2)/(1-M12*M21)),
v2=max(0,w2,(w2+M12*w1)/(1-M12*M21)).
```

v>=0 且 (I-M)^T*v-w>=0；将新 slack 与 q>=0 非负组合后，w^T*q<=v^T*h。完整 residual、alias EQ 仍按同一身份合并。这是局部代数消费规则，不需优化器。若接入 D209 的支持运算，整体仍有逆出生方向遍历和父 cap 查询；本轮没有证明纯前向全网闭包，不能说没有后向计算。

## 普通双门加残差的严格分离

取完整输入盒 (x,y)∈[-1,1]^2，并保留全部读出和两个原 bits：

```text
f1=x+y/12, f2=x-y/12, q_i=ReLU(f_i), a=b=1/2,
c1=c2=5/8, u1=u2=ell1=ell2=13/12,
U1=U2=5/4, t=(4/5)*(1-x),
B_box=8/5, T_int=28/15, T=8/5.
```

两张 cap 的具体证书分别是 (1/2)(1-x)+(1/8)(1-y) 与 (1/2)(1-x)+(1/8)(1+y)，没有外部界或 helper。共同余量来自真实同源端点。D209 的旧 source 与 closure 行在此相同，s=(3+x)/4、l=1/2。

新消费关系恰为 h_i=(13/35)(1+x)、M12=M21=13/35。定义可作为下一层残差读出的

```text
F=q1-(13/35)*q2-(13/35)*(1+x),
p=F-1/140.
```

新固定乘子 v=(1,0) 直接证明 F<=0，故 p<=-1/140，ReLU(p)=[0,0]。这是对完整输入盒的证明，不是只在一个样本点上取值。

旧连续关系允许如下诊断点：

```text
x=-1/2, y=3/4, f1=-7/16, f2=-9/16,
q1=1/5, q2=0, beta1=2/5, beta2=0.
```

原 graph 行中门一 active-upper 上界 17/80，余量 1/80；旧 source-phase 反馈上界 13/64，余量 1/320。全部原八图行、旧十 pair 行及相同 closure 行均满足。所有连续因子界与放松相位界也满足。但 F=1/70，p=1/140>0；新反馈行被违反 1/10，新可消费行被违反 1/70。此点有分数相位，绝不是具体网络反例或 ADV。

四种旧证书都是这些旧行与端点的非负组合，所以均无法证明 p<=0。按旧固定公式直接算得四个上界为

```text
1/3, 309/5740, 37933/1245580, 37933/1245580.
```

此处是新线性关系排除旧放松点，不是原整数域突然更精确；精确 HZ 的整数语义从来不包含该点。

一个必要消融是只把 D209 的 tau 改为 min(1,1/B_box)，允许 l=0。它给 h_i=(5/16)(1+x)、M12=M21=1/2；同一查询的固定乘子是 (38/35,6/35)，p 上界仍为 1/28>0。故本例收益不只是去掉 1/2 正尺度下限；但不证明新规则支配所有可能 tau 或精确关系求解。

## 与旧规则的关系和成本

当使用同一 T=B_box 时，新未归一化投影行加常量行支配旧 tau<=1 行：它们等价于使用 z>=max(0,t-T*(1-beta))，而旧行只相当于 tau 倍的该仿射下界。若 B_box<1 后人为改用 T=1，就不能推广这个逐行支配结论。即使 T 更紧也必须依据完整行关系证明，不能凭名称推断。候选应保留旧行和四查询，在同一固定 support 中额外计算新证书；所有计算都计费。相同父元素上的这个并集不会损失旧上界；跨层出生和全网零回归仍须实际验证。

每 pair 保留完整局部投影只比已存常量行多四条 LE。若合并后的 t 有 d 个父因子非零项，新行一般共 4d+10 nnz，T=1 时可更少。没有新乘积因子、二元位或 decoder 自由度；所有原接口、门、关系和 bits 原样保留。若只存两条反馈行，不能声称实现了完整四行投影。

父 cap 查询、共有证书交集、t 的稀疏展开、B_box 计算、T_int 的下界证明、全部旧新行、完整查询、terminal lowering、所有消费者与见证检查都必须计入。局部系数计算是常数个有理算术，新增行展开为 O(d)，并不是完整网络 O(d) 的证明。原 whole256M、branch200M、entries64M、512-bit、物理门和完整验证人口不改变。D210 指出的全前缀复制、重复父层查询和异质分母问题仍存在。

GPU 上可按 pair 批处理系数和行，原理上适合并行；这不等于已有 GPU 实现、浮点健全性或速度结果。smooth/Transformer 没有离散 ReLU 相位前提，不能直接继承此定理。

还有一项重要的跨层闭包风险：新消费使用 on/off slack，而 D210 的保留充分条件跟踪 active-upper slack。增加新模式后，所有模式在后者上的最小权重可能变为零；不能自动继承 D210 的正 rho 结论。更小的 cap 也不保证其新选择证书与另一证书有更多共有项。所以下一版本必须同时保住 D209 已证明的多层正余量控制，并检验新证书进入下一 bank 的效果，不能只报告本首层分离或假定逐层精度单调。

## 相关工作与不应声称的创新

HZ 精确表示整个 ReLU 网络、共享原连续/二元因子及跨层记忆已有先例。本研究不以保留这些性质作为新颖性。[Ortiz 等，第二节和第三节](https://arxiv.org/pdf/2304.02755)

带唯一身份的混合连续、signed、Boolean 符号和非线性依赖组合也已有研究；加入 beta*t 这个符号本身不构成新抽象域。[Combastel，第3和5节](https://arxiv.org/pdf/2009.07387)

多神经元共同关系比逐神经元近似更强已是既有方向，PRIMA 给出相应构造。本研究的潜在问题是有限域内证书如何在不引入优化器的情况下持续产生、消费关系，而不是首次发现门间相关性。[PRIMA，第3和6节](https://ggndpsngh.github.io/files/PRIMA.pdf)

已有约束余量的乘积、线性化以及层间/层内 RLT 关系已用于神经网络验证。本次 beta*t 证明与消元属于该类已知代数机制，不是新的凸化原则；没有采用该论文的 SDP 或求解策略。[Lan 等，式11至14](https://ojs.aaai.org/index.php/AAAI/article/view/20689/20448)

有理非负线性证书、唯一约束身份与等式替换同样已有。证书所有权本身不算数学创新。[Fouilhe 等，第3和5节](https://arxiv.org/pdf/1304.0864)

目前可支持的贡献表述仅是：给出现有 Neural-HZ 候选尚无的相位条件余量关系、其无乘积变量投影、可组合固定消费恒等式及严格后继查询分离。它是否构成值得发表的统一域演算，要靠更广结构、公平同信息比较和完整成本证据回答，不能提前宣布。
