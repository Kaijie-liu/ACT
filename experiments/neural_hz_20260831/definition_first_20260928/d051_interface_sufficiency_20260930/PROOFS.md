# 原相位为何不能补回连续接口丢失的信息

本轮将跨领域综述中的关系接口问题落实为两项可核查边界：固定线性连续摘要的精确性有一个核空间判据；有限连续统计量加纯相位边际，也不能普遍保证局部凸包使用同一种源分布。这些是纸面推导，不宣称新的通用数学、实现资格或正式提分。

它们排除两个具体捷径，不否定原 HZ 或一切有限接口。原 HZ 的连续因子、全部 bits、EQ/LE、共同赋值与输入 decoder 始终保留。研究的是额外摘要是否足以支持后继推理，不授权丢弃原状态。

## 固定线性摘要的必要充分条件

令 K 是连续源 x 的非空凸多面体，普通神经块为

```text
F(x) = Sx + C ReLU(Ax+c).
```

原相位 sigma 属于 {0,1}^m。令 P_sigma 为 K 与该相位的非严格线性守卫的交；预激活为零时，两种原合法相位均保留。对于非空 P_sigma，定义

```text
V_sigma = span(P_sigma - P_sigma),
M_sigma = S + C diag(sigma) A.
```

研究只保留线性连续摘要 Bx 和所有原相位 sigma 时，能否精确决定 F。允许解码函数依赖 sigma，且不预先要求解码函数线性。必要充分条件是对每个非空相位集合有

```text
ker(B) intersect V_sigma  subseteq  ker(M_sigma).       (Q)
```

充分性：同相位、同 Bx 的两点之差属于左侧，故它们的 F 相同，定义在 B(P_sigma) 上的解码值无歧义。仿射常数 C diag(sigma)c 在同相位差分中消去。

必要性：取 P_sigma 的相对内部点。每个属于 V_sigma 的方向都能缩小为在该集合内的双向扰动。若方向还属于 ker(B)，精确解码要求两个扰动点的 F 相同，于是方向属于 ker(M_sigma)。使用 V_sigma 而不是整个空间，避免将只在边界可行的相位误判为满维区域。

这是逐集合的数学刻画，不是运行时遍历相位的算法。它也不提供免费判定哪些相位可行的 oracle。

## 普通独立激活边界使连续摘要满秩

本节设 K 满维。假设每个被输出观察的门 i，即 C 的第 i 列非零，都存在只改变第 i 个 bit 的两个满维相邻可行区域。这一相邻区域假设例如可由以下条件保证：A[i,:] 非零，且 K 内部有一点使该门预激活为零、其他门预激活非零。仅有零点而无非零源行，并不足以保证这种相邻区域。

在任意满维区域，(Q) 等价于 row(M_sigma) 包含于 row(B)。相邻区域的矩阵之差是 C[:,i] A[i,:]。由于 C[:,i] 非零，逐行相减推出 A[i,:] 属于 row(B)。所有被观察门满足此性质后，再由任一区域矩阵减去这些行的组合可得 row(S) 包含于 row(B)。因此

```text
rank(B) >= rank(stack(S, A_observed)).
```

反之，若 row(B) 已包含 S 和全部 A_observed 的行，则它足以恢复所有被观察预激活及残差，直接给出精确 F；不必枚举相位。这是一个保守、可检查的充分规则，不是一般网络都能压缩的保证。构造 rowspace、检查精确系数以及其 fill 和位长均有成本。

该结论比一个聚合 companion 不足更具体：即使保留全部原 bits，单个标量输出也可能要求满秩连续接口。它只约束固定线性 B，不否定相位依赖或非线性摘要；后者仍需自己的变换、大小与终端成本证明。

## 非零偏置混权残差反例

在 x,y 属于 [-1,1] 上取

```text
g1=x+y/2+1/10,       q1=ReLU(g1),
g2=x/4+y-1/5,       q2=ReLU(g2),
F=x/5-y/10+q1-q2.
```

两个门的独立边界确实位于盒内部：g1=0 的点 (-1/10,0) 上 g2=-9/40；g2=0 的点 (0,1/5) 上 g1=1/5。源行 (1,1/2)、(1/4,1) 的行列式为 7/8。所以上节判据要求任何精确的固定线性连续摘要至少为秩 2，尽管 F 只有一个输出。

全激活时，F 的线性部分是 B=(19/20,-3/5)。把这个单行当作全块的充分接口会失败。取

```text
P=(2/5,-1/5), Q=(13/25,-1/100).
BP=BQ=1/2.
(g1,g2)(P)=(2/5,-3/10),
(g1,g2)(Q)=(123/200,-2/25).
```

两点的两个原 bits 都是 (1,0)，没有零点歧义；然而 F(P)=1/2、F(Q)=18/25，差为 11/50。原 bits 记录哪一段生效，并不会恢复被 B 丢掉的实值方向。

这些点是解析反例，不是模型攻击、数值采样或验证结果。反例不要求权重成比例、重复门或极端系数。

再接原门 v=ReLU(F+1/4)，P、Q 的全部三个 bits 都为 (1,0,1)，而 v 分别为 3/4、97/100，仍相差 11/50。该后门并非稳定门：源 (-1,1) 给 F=-17/20，后门预激活为 -3/5。两个父门独立 crossing 点上，后门预激活分别为 23/100 和 43/100，故后门在这些相邻区域中激活，仍保留两个独立梯度差。经过第二次非线性，精确固定连续摘要的秩 2 下界仍成立。

## 增加有限连续统计量也不能保证一般凸包组合

设在一个旧相位固定的开放源区间 I 内，接口保留有限个连续特征 phi_1 到 phi_m 的均值。令 V 为 1 与这些函数的线性张成。不同内部阈值的 hinge 函数 ReLU(s-tau) 线性无关，故能选一个不属于 V 的 hinge。

该 hinge 也不属于 V 加上阶跃 b(s)=1_{s>tau} 的张成：等式两侧的连续性迫使阶跃系数为零。论证可限制在 I 去掉 tau 的集合，避免使用零点相位。

有限维线性代数于是给出有限支持的带符号测度：它消去 1、所有 phi_i 和 b，却不消去该 hinge。常数均值为零使正负部分具有相同正质量；归一化后得到两种有限源分布，其全部接口特征均值和原 bit 均值相同，而后继 ReLU 均值不同。

这个命题针对固定的有限连续特征和任意后继阈值，不否定为已知消费者专门增加混合特征，也不证明任意有限非凸抽象都不可能。它是信息充分性的否决工具，不是运行时构造分布或枚举相位的算法。

## 连全二阶矩与完整相位边际都一致的普通例子

取 x,y 属于 [-1,1]，四个门各保留独立的原 bit：

```text
q1=ReLU(1+x+y/5),
q2=ReLU(1-x/4+y),
r =ReLU(q1-q2-1/8),
u =ReLU((101/100)q1-q2-1/10).
```

全网恒有 u>=r，因为两子门预激活之差为 q1/100+1/40>0。

令 t=±1/10 等概率，且与 v 独立，取 y=t、x=4v/5+1/10+16t/25。比较两种纸面有限分布：mu 中 v=±1/4，各占一半；nu 中 v=±1/20、±7/20，各占四分之一。两者都满足

```text
E[v]=0, E[v^2]=1/16,
E[t]=0, E[t^2]=1/100, E[vt]=0.
```

全部源点严格位于盒内，两父门严格激活，因而

```text
q1=11/10+(4/5)v+(21/25)t,
q2=39/40-v/5+(21/25)t,
r=ReLU(v),
u=ReLU((126/125)v+9/250+(21/2500)t).
```

所以源坐标与父值的所有二阶及以下联合矩完全相同。两子门的符号在这些支持点上都等于 v 的符号，两分布的四个原 bits 的整个联合边际也相同：父 bits 恒为 11，子 bits 为 00、11 各半。这只是分布事实，不合并两个子门的 bit 身份。

但 E_mu[r]=1/8，而 E_nu[u]=297/2500。分别采用这两种分布的两个完整 source labelled 局部 hull，能够拼出

```text
u-r = -31/5000 < 0,
```

违反全网关系。即使局部提升保留上述全部二阶统计与纯相位联合边际，该拼接仍可行，因为它们确实一致。问题是局部凸组合没有共享同一种条件源分布。已有 D020 单调差式可排除此点，故它不是新的强能力正控。

## 混合源相位信息提供了哪一种出口

本例明确遗漏的量是源与子门 bit 的混合矩。对于任一子门的正相位 beta，两个分布分别有

```text
E_mu[v beta]=1/8,    E_nu[v beta]=1/10,
E_mu[q1 beta]=13/20, E_nu[q1 beta]=63/100,
E_mu[q2 beta]=37/80, E_nu[q2 beta]=187/400.
```

一般地，原整数语义中 r=beta*(a*q+c)，因此 E[r]=a*E[beta*q]+c*E[beta]。为指定消费者保留相应混合关系，可以区分上述分布。该等式是已知乘积线性化思路，不意味着有限一阶混合矩足以刻画全网可行分布。

跨下一非线性层时，若把 q 再展开为更早的 gated 值，可能产生多个原 bits 与源的乘积；若保留中间物理读出，则原门谓词和接口成本仍要支付。旧 D035 已研究共享二元 overlap 与源条件量，不能把它重新包装成发现。本轮不实现高阶矩层级、不展开相位、不引入新 SDP 或求解路径。

## 不引入高阶矩的实际物理关系正控

上述信息缺口并不表示实现必须堆叠矩。现有 D029 条件观察，只要获得真正相关的源证书，就可以产生当前有限包络漏掉的物理关系。下面给出一个有开参数范围的普通双门结构：

```text
0<=s,t<=L,  0<a,e<L,
q=ReLU(s+t-L+a), original bit alpha,
p=ReLU(s-t+e),   original bit beta.
```

原 q 恒满足 q<=s+a 和 q<=t+a。令 v=q-s-a、g=s-t+e，则 v<=0，且 g+v=q-t+e-a<=e。D029 的单观察上侧关系直接给出

```text
q+p <= s+a+e*beta.                              (C)
```

也可直接验证：beta=0 时 p=0，用第一条 q 界；beta=1 时 p=g，用第二条 q 界。两种原零相位均符合非严格证明。这是证明分情况，不执行输入或相位切分。原 alpha 与 beta 都保留，不由新行删除。

对 L=1、a=e=1/10，固定旧松弛点

```text
s=t=alpha=beta=1/2, q=2/5, p=7/20.
```

两门在该共同源均值上的预激活均为 1/10，不依赖零点巧合。q 的完整 source labelled hull 有真点分解：源 (17/20,17/20) 与 (3/20,3/20) 各半，预激活分别为 4/5、-3/5。p 的分解使用 (17/20,1/4) 与 (3/20,3/4) 各半，预激活分别为 7/10、-1/2。所有分量严格位于盒内，分别还原各自的输出和原 bit 均值。

此点通过两个独立完整 source labelled hull。预激活差 delta=2t-1，范围 [-1,1]；输出差 d=q-p=1/20，校正 d-delta=1/20，所以 D020 四行也均通过。

还可明确核对 D049 在这对门上产生的双向差值与两个 companion 包络，不只比较弱 scalar big M：

```text
-(1-t) <= q-p <= t,
s+t-9/10 <= q <= s/10+t,
s-t+1/10 <= p <= 1-t+s/10.
```

若把 source 顺序反过来，两个 companion 上界分别变成 s+t/10 与 s+(1-t)/10；旧点也通过。该列举只比较这组固定种子和规则生成的有限行，不宣称超过任意 D049 派生观察、全部 D029 或联合 hull。

但是 (C) 在旧点左侧为 3/4，右侧为 13/20，严格相差 1/10。进一步使用 beta<=1，得到不含 bit 的物理读出 Z=q+p-s<=a+e=1/5；旧点的 Z=1/4。真实源 (s,t)=(1,1/2) 两门均严格激活，q=p=3/5，Z=1/5 取等。因此该例展示真实的关系强度差，而不是只限制可自由选择的辅助变量。

本例的直接行只需 1 条 LE、4 个系数 nnz、零辅助量；源谓词与证书成本仍须保留。最初从 D035 共享 overlap 的提升寻找此行，最后发现已有 D029 上侧规则已足够。故不新建高阶矩候选，也不把已知 BQP/RLT 或条件观察包装为新域。它支持下一研究优先解决实际共同源证书的构造与组合，而不是增大抽象量的数量。尚未实现这一规则、运行该控制或在真实模型上测量其出现率。
