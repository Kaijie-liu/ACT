# Neural-HZ 的共同输入容量与神经守卫

本轮按用户“重点是提出强大的 Neural-HZ”的要求，停止展开原计划的系数适用性普查，回到域定义本身。核心问题是：即使每个神经元都有完整的单门凸包，且共享源与相位具有共同见证，不同门的神经守卫仍可能要求彼此不相容的原始输入分配。需要保留的是共同输入容量与守卫的联合关系，而不是再接一个 helper。

本文给出一个普通有界 ReLU 反例，以及私有输入容量的精确投影定理。将该投影与共同相位上的全部守卫绑定，可以在纸面上恢复完整的一层联合图凸包，不再需要上一轮的 COVER 前提。但相位规模、紧凑的静态编译和深层组合尚未解决；这不是已经完成的新域，也没有真实网络新增解。

## 单门精确仍会丢失联合神经关系

取独立原始源 x1,x2,z in [0,1]、y in [-1,1]，两个 ReLU 为

```text
g1 = x1+x2-1/5-(6/5)z,    q1=ReLU(g1),
g2 = y+z-2/5,             q2=ReLU(g2).
```

二元相位 beta1,beta2 保留，零点两个合法标签都允许。第一门的私有标量为 x1+x2 in [0,2]，共享部分在 [-7/5,-1/5]；第二门私有量 y in [-1,1]，共享部分在 [-2/5,3/5]。因此上一轮的 COVER 对两门都严格成立；本例不是通过破坏那个前提得到的。

考虑分数查询点

```text
(x1,x2,z,y) = (1/10,9/10,1/2,0),
(beta1,beta2) = (1,1/2),
(q1,q2) = (1/5,31/40).
```

第一门的完整单门 hull 接受它：源均值本身就是该门的真实 active 点。第二门的完整单门 hull 也接受：保持 x1,x2 不变，取 (z,y)=(39/40,39/40) 和 (1/40,-39/40) 各一半，预激活分别为 31/20 和 -27/20，平均输出为 31/40。所有源见证严格在盒内部，所选神经守卫有严格符号余量。

这两份单门证据还能匹配一份共同的自由 source/phase 核心：使用上述两个源点，标签分别为 (1,1) 和 (1,0)，各半。它恢复原始源均值和每个门自己的源乘相位矩。但第一个原子不满足第一门的神经守卫。这正是“自由源能胶合”和“完整神经图能胶合”的区别。

存在不含辅助量或相位的物理输出行：

```text
F = 2q2+x2-y-2z-q1 <= 6/5.
```

证明分两种真实神经语义，不是执行分支搜索。若第二门 active，则 F=y+x2-4/5-q1<=6/5。若 inactive，则利用 q1>=g1 得 F<=1/5-x1-y-(4/5)z<=6/5。旧查询点却给 F=5/4，因此下一层 ReLU(F-49/40) 的真全盒输出恒为零，单门接口却允许 1/40。

这证明旧组合的精度缺口，不是相对完整两门 hull 的新能力；完整两门 hull 或同一条已知有效行也能排除它。更不能据此宣称精确 HZ 无法表达这个网络。

## 保留全部原始私有源的容量关系

先研究一个输入块。将非固定私有像素逐个准确归一化到 x_j in [0,1]，负系数以 1-x_j 可逆改写，常量折入 d，于是私有仿射量为

```text
p = d + sum_j w_j*x_j,       w_j>0.
```

原始像素身份、反变换和所有消费者仍保留；这不是用标量 p 取代整块像素。零权源不参与该容量关系但也不删除。令 S 是一份共同相位单元集合，lambda_s>=0、sum_s lambda_s=1；t_s 是该单元内私有加权量的未归一化贡献。

精确输入分配要求存在矩 m_j,s，使

```text
0 <= m_j,s <= lambda_s,
sum_s m_j,s = x_j,
t_s = sum_j w_j*m_j,s.
```

定义 lambda(A)=sum_(s in A)lambda_s、t(A)=sum_(s in A)t_s 和

```text
Fcap(u) = sum_j w_j*min(x_j,u),       0<=u<=1.
```

上述分配存在，当且仅当

```text
t_s>=0,
sum_s t_s = sum_j w_j*x_j,
t(A) <= Fcap(lambda(A))    for every A subset of S.
```

零质量单元必须有 t_s=0，已由这些条件推出，也可以显式检查。补集给出相应下界。本定理不需要 COVER。

必要性直接来自每个像素在 A 内最多分配 min(x_j,lambda(A))。充分性可由一个有容量运输图证明：源到像素 j 的容量为 w_j*x_j，像素 j 到单元 s 的容量为 w_j*lambda_s，单元 s 到汇的容量为 t_s。对固定留在汇侧的单元集合 A，最小化其余切分选择，割容量为 t(S\A)+Fcap(lambda(A))，不低于总需求恰等价于上述全部子集条件。最大流最小割定理于是给满流，除以正 w_j 得 m_j,s。

这里借用了经典数学，而不是提出新的流算法；也没有调用流求解器作验证 helper。[MIT 的最大流最小割讲义](https://courses.csail.mit.edu/6.854/19/Scribe/s6-maxflow/s6-maxflow.html)是所用基础定理的来源。容量投影和下面的 Neural-HZ 接口推导是本轮应用推导，未作新颖性声明。

## 已给定查询点的容量检查不必枚举子集

对于一组已经给定的 lambda、t、x，先检查非负、总量和零质量单元，再将正质量单元按 t_s/lambda_s 递减排序。只需检查每个前缀 P 的 t(P)<=Fcap(lambda(P))。

证明：连接各前缀累计质量与累计贡献，得到按密度从高到低分配的折线 L(u)。任意子集 A 都满足 t(A)<=L(lambda(A))。Fcap 是凹函数；若每个前缀端点满足 L<=Fcap，则相邻端点间的 L 不超过 Fcap 端点弦线，后者不超过 Fcap。因此全部子集不等式成立。反向显然。

比较密度可以使用正分母交叉乘，零质量单独处理。算术操作计数为 O(M log M+n log n+M+n)，M=|S|，其中将 x_j 排序后用累计权重计算全部前缀的 Fcap；这不是位复杂度、实际速度或 GPU 测量。排序和交叉乘同样受原有位宽及工作预算约束。

这个结果仅降低了一个已给定点的关系检查成本。它没有给出对自由 x、lambda、t 的同等规模静态线性表示，更没有解决支持函数优化。顺序随变量变化，不能把一次查询点的前缀固定为整个父域的合法充分条件；也不授权在 terminal 返回后按状态补救或调用分离 oracle。显式运输矩阵有 n*M 个量；消元后的完整线性行族最坏仍很大。终端代价必须另证。

## 与共同神经守卫耦合的精确一层接口

考虑独立共享盒 z 和两两独立的私有像素块 x_i，并保留全部原始源。每门写为

```text
g_i = d_i + sum_j w_ij*x_ij + b_i + sum_l a_il*z_l,
q_i = ReLU(g_i).
```

证明中取完整原相位向量 s in {0,1}^k 的质量 lambda_s；不将它作为可接受的实现预算。共享源保留完整单元矩 nu_l,s in [0,lambda_s]，sum_s nu_l,s=z_l，所有门用同一份 nu。每个私有块使用上面的容量关系，保留聚合贡献 t_i,s。定义

```text
G_i,s = (d_i+b_i)*lambda_s + t_i,s + sum_l a_il*nu_l,s.
s_i=1 implies G_i,s>=0,
s_i=0 implies G_i,s<=0,
q_i=sum_(s_i=1)G_i,s,
beta_i=sum_(s_i=1)lambda_s.
```

这些关系投影到全部原始源、q 和 beta 后，恰等于该独立盒上一层完整神经图的凸包。必要性由任意真实混合取条件一阶矩得到。充分性：容量定理给每个私有块一份 m；对 lambda_s>0，令 z_l(s)=nu_l,s/lambda_s、x_ij(s)=m_ij,s/lambda_s。所有源在原盒中，所有门同时满足该单元的线性守卫，且 q、源均值和原相位边缘全部恢复。零质量单元无需除法。这里不要求先前的私有阈值 COVER。

若 beta 保持原生整数语义，则 lambda 必须集中在同一个相位向量上；上述构造退回原神经图，未删除或放松任何原二元因子。signed bit 与 beta 的关系仅是 beta=(sigma+1)/2 的可逆记号。凸包只描述查询松弛，不能替代 Neural-HZ 原生非凸具体化语义。

同一份赋值的 Affine、Conv、Add、Concat 读出保持精确，原像素外部消费者的值也随该赋值保留。但是附加一般父谓词、已有其他非线性关系或下一激活后，“局部 hull 与旧谓词相交”不自动等于整个受限图的 hull。不能把这个一层乘积盒定理称为深层精确闭包。

反例中的第一门在 z=39/40 的半质量单元至少要求私有总贡献 (1/2)*(1/5+(6/5)*(39/40))=137/200。原像素均值却只允许 min(1/10,1/2)+min(9/10,1/2)=3/5。将容量与共同单元守卫绑定后直接出现矛盾。这说明新增关系针对的究竟是什么，而不仅是给自由源再加同义约束。

## 与既有方法的区别和未解决代价

精确 HZ 和完整混合整数扩展本就能表达该图，本文不宣称增加集合表达力。[Anderson 等人的强神经网络混合整数表述](https://arxiv.org/abs/1811.01988)是必须比较的既有基线；本轮没有完成对它及其他多神经元方法的完整新颖性排查。

若 M 个共同单元已给定，完整私有逐源 lifting 使用 M*sum_i n_i 个私有矩；聚合接口显式只留下 k*M 个 t，但必须同时支付全部容量关系、共享源矩、相位质量、守卫、终端查询和原像重构。M 最坏为 2^k，不能因此把此稿包装成可扩展的强大 Neural-HZ。前缀成员检查便宜也不能推出终端优化便宜。

下一项主线不是继续扩张普查或审计：寻找能由普通重复网络结构触发、在前向规则中紧凑保存这类共同输入容量与守卫关系的非凸域元素及消元定理。必须同时给出原 HZ 的嵌入、原 bit 的保留、深层共享消费者的语义、静态终端费用和独立具体输入 decoder。若只能恢复经典完整析取表或依赖额外 solver rescue，应记录为支撑结论而不是新域成果。

在这些问题解决后，才进入默认关闭的预注册实现、数学门、真实同结构样例及逐家族回放。GPU 是后续实现要求，不用纸面操作计数代替 GPU 证据。保住所有旧解、13 家族零回退、具体 ADV 验证以及最终完整回放的规则不变。
