# 容量关系的阈值形式及终端费用

这是本轮另一位独立审阅者给出的等价推导，作为主稿的支撑记录，不是新增算法或运行结果。符号沿用 RESEARCH.md，M 为共同相位单元数，n 为一个私有块的非零系数数，W=sum_j w_j。

对固定 x，将其排序为 x_pi1<=...<=x_pin。设

```text
r_k=sum_(j>k)w_pij,
b_k=sum_(j<=k)w_pij*x_pij,       k=0,...,n.
```

则 Fcap(u)=min_k(b_k+r_k*u)。因此总量等式成立时，全部原子子集容量条件等价于

```text
sum_s max(t_s-r_k*lambda_s,0) <= b_k,       k=0,...,n.
```

证明：对每个子集 A，t(A)<=Fcap(lambda(A)) 等价于对每个 k 有 t(A)-r_k*lambda(A)<=b_k。对 A 取最大，左边就是逐项正部之和。k=0 给 t_s<=W*lambda_s；k=n 与总量等式一起给 t_s>=0。因此还需至多 n-1 个内部阈值。

这个排序不能在自由源变量上固定复用。普通反例取 w=(1,2)、x=(4/5,1/5)、lambda=(1/2,1/2)、t=(1,1/5)。总量为6/5且盒容量通过。只检查另一源顺序对应的内部阈值2时，正部和为0，通过；正确内部阈值1给左边1/2、右边2/5，拒绝。原子子集第一项也直接给 t(A)=1>Fcap(1/2)=9/10。

不依赖源排序的全域精确形式为：对每个源子集 J，

```text
sum_s max(t_s-(W-w(J))*lambda_s,0)
    <= sum_(j in J)w_j*x_j.
```

这是将一套指数子集表示改写为另一套，不能称为一般线性规模方案，也不是任意扩展表示的指数下界。

即使父域已经可靠保证同一排序，n-1 个内部阈值也不等于 n-1 条普通 LP 行。用常规 hinge 上图编译，需要 M*(n-1) 个辅助量；包括 t 的上下界后，需要 2*M*n+n-1 条 LE 和一条总量 EQ，另计源排序关系及系数存储。原运输表示则为 M*n 个矩量、2*M*n 条边界 LE、n+M 条 EQ。没有数量级节省，且两种表示都还需支付共同相位、共享源、神经守卫、消费者和重构费用。

因此此等价形式暂不推进为候选实现。其价值在于澄清什么关系确实缺失、哪些紧凑写法只是转移费用。后续不得把固定点检查、经典运输或同一有效行的重新表达单独宣布为强大 Neural-HZ 的创新成果。
