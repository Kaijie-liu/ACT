# 四维共同守卫的严格组合对照

本轮得到一个全四维、全部非平行且有偏置的纸面控制：一条物理关系超过完整单门、全部完整二门接口及一致 FREE 源相位参照，并使下一原 ReLU 恒零。但它能由已有 D062 与 D052/D029 关系组合得到，不是新的 tent、covariance 或 Neural-HZ 原语。保存它是为了防止后续候选只胜过弱参照，也为组合能力提供明确目标。

## 一条统一的原门关系

四个实际原门 q_i=ReLU(f_i)，保留原 bits、所有源、guard、消费者及 decoder。给定预先固定的正尺度 s_i，令 X=f1/s1、Y=f2/s2，完整父域认证 abs(X),abs(Y)<=1。若同源残差满足

```text
abs(f3/s3-(X+Y-1))<=epsilon3,
abs(f4/s4-(X+Y))<=epsilon4,
```

则

```text
2q1/s1+2q2/s2+q4/s4-2q3/s3-X-Y
    <=2+2epsilon3+epsilon4.
```

证明的零残差核心为 abs(X)+abs(Y)+ReLU(X+Y)-2ReLU(X+Y-1)<=2。也可令 S=X+Y、T=ReLU(X)+ReLU(Y)-ReLU(S-1)。[D062 四平面](../d062_mixed_block_support_20261001/THEORY.md)给 T<=max(0,X,Y,1)<=1；单门 secants 给 T-S/2<=1。[D052 共同上界前向规则](../d052_static_source_certificates_20260930/THEORY.md)于是给 T+ReLU(-S/2)<=1，用 ReLU(-S)=ReLU(S)-S 即得原式。这是纸面恒等变换，不创建新参考门或 bit。

实际残差仅使用 ReLU 的 1-Lipschitz 性支付 epsilon4+2epsilon3，不迁移参考相位，因而不犯 D221 的近低秩标签替换错误。尺度和选组仍需统一数学合同，不能按模型 ID、历史成绩、margin 或 LP 状态挑选；本轮没有冻结真实人口生成规则。

## 全四维普通控制

在完整盒 (x,y,z,w) in [-1,1]^4 上，取

```text
f1=x+y/100+1/1000,
f2=x/200+y+1/1000,
f3=99x/100+101y/100+z/100-1,
f4=101x/100+99y/100+w/100+1/1000.
```

四行均非平行，偏置非零。系数矩阵行列式为 (19999/20000)*10^-4>0，故不能整体降为共同二维接口。取比较点

```text
(x,y,z,w)=(0,0,0,0),
beta=(1/2,1/2,0,1/2),
q=(901/2000,901/2000,0,91/200).
```

令 r=9/10，所有以下见证均附加 z=w=0。C 是四点 (±r,±r) 各 1/4；X0 是 (r,0)、(-r,0) 各 1/2；Y0 是 (0,r)、(0,-r) 各 1/2。每个源点均严格位于完整四维盒内，不是数值极端点。

完整 FREE 使用 C，标签为 beta1=1[x=r]、beta2=1[y=r]、beta4=beta1、beta3=0。它给每个 q_i=E[beta_i f_i]，但不满足所有原子上的全部 joint guards。完整二门 source-labelled hull 的真实见证为：12、24 用 C；13、14、34 用 X0；23 用 Y0。每一对参与门的实际 guards 都严格成立。它们恢复相同的完整源均值、该对 q、beta、相位共现及该对 source-phase 一阶矩。

条件源矩为 v1=v4=(r/2,0,0,0)，v2=(0,r/2,0,0)，v3=0，均与上述同一 FREE 见证一致。因此全部单门、全部二门接口以及 D201 所列单 literal Jensen/跨 guard 参照都接受；这不是只通过四行 big-M 的弱比较。没有声称这些不同 pair 的见证能胶合成真实四门 joint-guard 分布，也没有声称通过任意阶 RLT。

## 物理输出与下一原非线性

固定全部 s_i=51/50，完整盒上有

```text
epsilon3=43/1020, epsilon4=3/85,
J=2q1+2q2+q4-2q3-f1-f2 <=1081/500.
```

残差分子分别为 -3x/200+z/100+9/500 和 x/200-y/50+w/100-1/1000，绝对盒界为 43/1000、36/1000，再除以 s。原比较点 J=451/200，违反 93/1000。该行不含 beta，换一组分数标签不能绕过这个物理输出分离。

给原网络接后继 r_new=ReLU(J-4417/2000)。新侧全盒上界为 -93/2000，故后继恒零；旧抽象父点的后继精确图允许 r_new=93/2000，可取其原相位为 1。不是实际网络 ADV，不是新 CERT，也不声称整个具体上游的 child hull 允许该点。

前一步二维版本未增加 z/100、w/100，使用相同内部见证，得到 J<=533/250、分离 123/1000。本页采用全秩版本支付新增 3/100 误差；未以二维假设冒充真实四维结论。

新增行在已有 f1、f2、q1...q4 坐标上为一条 LE、六个 nnz、零新列、零新 bits。实际源展开、两个残差支持证书、尺度来源、选组、所有旧行、后继及终端成本另计。不存在由六个 nnz 推出的端到端速度或 GPU 资格。

## 处置

保留为强组合对照，不为它另建 covariance、SDP、helper 或新域名称。D062 加 D052/D029 及可靠残差必须作为未来候选的强参照之一；仅再次证明本关系不是新能力。此前纯二阶摘要的缺口也未因此解决。

本页全部为纸面构造和独立复核。未运行输入采样、攻击、相位分裂、LP、模型、候选测试或 GPU。全分及真实 CIFAR/Tiny 目标不缩减，正式新增仍为零。
