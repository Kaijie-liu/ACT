# 树形幅值关系的共同相位和原源表示

本轮给出树形非负容量因子的完整带标签凸包，用祖先路径的前缀质量代替完整相位表；并给出保留全部原像素的源依赖容量扩展。它超过局部 star 凸包直接拼接的精度，但目前仅是 Neural-HZ 的支撑定理，不是完整新域、完整神经图凸包或实际模型收益。

## 非凸对象与顶点生成

固定有根森林 T，每个非根节点只有一个父节点。节点数 n，深度 d_v，根深度为零。原幅值 e_v、原 active bit beta_v 属于同一 HZ 状态；signed bit 仅作认证的 0/1 仿射视图。取常数 c_v>0、边系数 a_vw>0，定义

```text
P_T={e>=0 : e_v<=c_v+sum_(w child of v) a_vw*e_w},
F_T={(e,beta):e in P_T, beta binary, beta_v=0 implies e_v=0}.
```

保留 H 的全部原连续源、原 bits、EQ/LE、共享 frame、所有消费者和输入 decoder。若原网络能在整个当前父域认证这些容量，则新增因子与 H 相交不删合法点；空因子嵌入 HZ。原 bits 的非凸语义不变。本文的凸包是普通线性查询的局部理想外包，不是将原域替换成凸域。

严格正 c 保证每个坐标的零行和上界行不能同时取紧。P_T 有界且满维；其每个顶点对每个节点恰选零或饱和上界，三角递推保证对应顶点存在。用 delta_v 表示这一仅用于证明的饱和选择，不新增二元变量。顶点为

```text
e_i(delta)=sum_(v descendant of i, including i)
            c_v*A_iv*product_(u on path i..v) delta_u,
A_iv=product of a on path i..v, A_ii=1.
```

delta_v=1 时 e_v>=c_v>0，delta_v=0 时 e_v=0。因此 [D203 顶点支撑定理](../d203_phase_incident_pair_20261005/THEORY.md)适用：凸组合中各节点饱和质量不超过 beta_v 即可，零幅值上的标签可共同补齐。不能将 delta 直接等同原 beta；原 beta=1 允许零幅值。

## 祖先路径质量的静态系统

对节点 v 引入 p_v,r，0<=r<=d_v，表示从深度 r 的祖先到 v 的整段 delta 都为 1 的质量。约定 p_v,-1=0。仅引入连续 p，原 bits 不删除。

```text
p_v,r-p_v,r-1 >= 0,
root: p_v,0 <= 1,
nonroot with parent u:
  p_v,r-p_v,r-1 <= p_u,r-p_u,r-1,       0<=r<d_v,
  p_v,d_v-p_v,d_v-1 <= 1-p_u,d_u,
p_v,d_v <= beta_v,
e_i=sum_(v descendant of i) c_v*A_iv*p_v,d_i.
```

配合原 0<=beta<=1，其投影恰为 conv F_T。

必要性由实际 delta 分布取路径事件质量得到。充分性需要共同见证，不能只说每条边可行。令节点状态 r_v 为当前连续饱和后缀的起始深度；若当前 delta_v=0，则 r_v=d_v+1。状态质量为

```text
Pr(r_v=r)=p_v,r-p_v,r-1, r<=d_v,
Pr(r_v=d_v+1)=1-p_v,d_v.
```

对于父状态 r，子节点可继承该状态（delta_v=1），也可 reset（delta_v=0）。子节点继承质量恰为 p 的相应差分，上界保证不超过父状态质量；差额分给 reset。这构造了每条边有相同端点边缘的完整转移分布。森林没有重合父路径，故可从根分布及各子节点的条件转移构造一份全森林状态分布。零质量父状态无需除法。

每份完整状态赋值唯一对应一份 delta；路径质量正好是 p。用顶点式恢复 e，并在 delta_v=0 的原子上补足 beta_v 的剩余质量，就同时恢复全部 e、beta。于是该系统不是局部均值一致的猜测，而是一份可共同实现的顶点分布。

原 beta 为整数时，beta_v=0 强制对应饱和质量为零，所有混合顶点属于同一合法坐标面；凸组合仍在该面。因此原生整数语义与 F_T 精确一致。状态分布只用于证明，不运行采样、相位搜索、树动态规划或外部 helper；查询使用上述一次生成的静态行。

## 完整局部费用

记 S=sum_v(d_v+1)，即祖先与后代对数（包含自身）。静态表述新增 S 个连续量、n EQ、2S+n LE、7S-n 个变量 nnz、零新 bits。分项为：差分非负 2S-n nnz，继承上界 4S-3n，标签质量 2n，幅值读出 S+n。

全部 A_iv*c_v 可沿各后代的父链递推，用 O(S) 次算术及 O(S) 系数存储。深度有界时 S=O(nh)，长链最坏二次。链上已有 D222 的零辅助量传递闭包更便宜，不能声称本表述在每种结构都最优。

原源、原 bounds、旧网络 guard、容量来源认证、可靠位长与舍入、输入重构、全部输出矩阵、终端物化及求解、host/device 同存另计。这个稀疏规模适合设计按层 gather/差分/归约，但没有 GPU kernel 或加速实测。纯规模公式不能满足性能门。

## 局部 star 精确但不具有整体闭包

对单根 star，叶 0<=e_j<=c_j，根 e_0<=c_0+sum a_j e_j，完整 labelled hull 是

```text
e_j<=c_j*beta_j,
e_0<=c_0*beta_0+sum_j a_j*min(e_j,c_j*beta_0),
e>=0, 0<=beta<=1.
```

证明把根 active 事件设为质量 beta_0，将每叶尽量分配到该事件中；各叶的零标签余量可独立补齐。min 可用 z_j>=0、z_j<=e_j、z_j<=c_j*beta_0 及一条根行作静态扩展。k 叶的账单（不计 e/bit 界）为 k 新列、4k+1 LE、8k+2 nnz。它是已有 perspective/条件源机制，不是新原理。

局部 star 拼接仍会丢失祖先事件下的后代条件信息。取

```text
e0<=1+e1+e2, e1<=1+e3+e4, e2,e3,e4<=1,
beta=(1/2,9/10,9/10,9/10,9/10),
e=(39/20,21/20,4/5,1/10,1/10).
```

根局部 star 上界为 1/2+21/20+1/2=41/20，子 star 上界为 9/10+1/10+1/10=11/10，均严格接受。各 ancestor pair 行也接受：根到 e1、e2 的上界分别为 41/20、14/5；根到 e3/e4 为 21/10；子到 e3/e4 为 19/10。全部 e 严格为正、标签严格在 (0,1)。

但完整因子有效行 e0-e3-e4<=3*beta0 在此违反 1/4：展开子容量并用 e2<=1，得到根 active 上界 3+e3+e4；根 off 时幅值为零。共同树系统排除该点。

这只是带标签因子的严格分离，不是原网络物理输出阳性；重选标签可能改变它。显式生成同一 branching-frontier 行的旧方法也能排除，所以它必须进入强参照。不能只和相邻行比较后宣布新域突破。

## 保留全部原像素的源依赖容量

现在各节点拥有互不相交的原盒块 x_v in [0,1]^m_v，容量为

```text
c_v(x_v)=b_v+sum_j B_vj*x_vj > 0 on the entire block box.
```

B 可含正负系数；严格正保证 b_v>0。所有原像素仍保留，零 B 坐标不参与提升但不删除。对象 F 保存全部 x、e、原 beta，并用 c_v(x_v) 替代常数 c_v。理想性声明不包括额外跨块父谓词；交回这些谓词仍健全，却不能宣称整体 hull 理想。

对每个非零 B_vj 增加 nu_vj,r（r=0,...,d_v），nu_vj,-1=0：

```text
0 <= nu_vj,r-nu_vj,r-1 <= p_v,r-p_v,r-1,
0 <= x_vj-nu_vj,d_v <= 1-p_v,d_v.
e_i=sum_(v descendant of i) A_iv *
       (b_v*p_v,d_i+sum_j B_vj*nu_vj,d_i).
```

其余 p、beta 行不变。这恰是完整原源 labelled hull。必要性由同一真实混合的条件源矩得到。充分性：p 先构造全树共同状态分布；各状态的像素质量为 nu 差分，reset 质量为 x_vj-nu_vj,d_v。上述行保证其位于零与该状态质量之间。正质量状态取相应条件源均值，零质量任取合法盒值；各源块互不相交，故所有节点能同时组合成同一份完整原输入。对每个组合用固定源下的饱和顶点公式，恢复所有 x、e、beta。

这不是用私有加权标量替代原像素均值。计费另令 m_v_star=#supp(B_v)，区别于完整原块维数 m_v；D=sum m_v_star、N=sum m_v_star*(d_v+1)。总新增连续量 S+N，EQ n，LE 2S+n+2N+2D，nnz 7S-n+7N+2D。每个参与像素的差分及 reset 约束为 6(d_v+1)+2 nnz，读出另付 d_v+1；没有隐去 source EQ，因为 reset 源量已由原 x 精确消去。零 B 的原像素仍保留，完整旧 H 及其费用另计。

## 不能将真实共享源复制成私有块

考虑根 e0<=1+e1+e2，叶 e1<=1+x、e2<=2-x，其中是同一个 x in [0,1]。若分别给两个叶分配条件 x，并只把均值都设为 1/2，会接受 beta_i=1/2、e=(5/2,1,1)：半质量 active 时，第一叶取 x=1，第二叶取 x=0；另一半反置。

真实共同源却始终满足 e1+e2<=3，因此 e0<=4*beta0=2。这个普通例子说明源依赖定理必须保留 disjoint 前提，不能用源均值相等恢复共同条件分布。错误复制可以产生较弱的健全外包，但绝不是所声称的理想 hull。

已认证 CIFAR 四门含 27 个跨门共享像素，不满足直接私有化的前提。不得把上述定理当成已接入该目标。一般 residual DAG 的共同后代也不能当作多个独立树节点；可以保留旧 H 并添加有证局部因子，但其全图精度和代价必须另证。

## 先例与研究资格

这里的共同状态胶合使用经典树分布思想。[Del Pia 与 Khajavirad 的 Theorems 1 和 2](https://arxiv.org/pdf/2212.11239)已给 beta-acyclic 多线性多面体的多项式扩展及 nest-point 判据。祖先路径集合按叶向根删除时，每个叶所属路径嵌套，因而属于该已有可处理范围；不声称首次发现树路径乘积可紧凑表示。本轮新增项目证据是本容量因子的直接前缀公式、原零标签处理、完整源扩展及明确账单。

没有新数学执行、候选实现、原生/GPU资格、真实模型收益或外部新颖性资格。下一项定义仍必须把原源与真实 joint guards 接合，证明实际后继消费，而不是把此支持因子重新命名成已完成 Neural-HZ。
