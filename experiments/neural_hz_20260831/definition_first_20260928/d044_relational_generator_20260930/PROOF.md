# 通用差值加伴随种子的闭合严格正控

本记录补全一条不借助额外源不等式的纸面链条：D042 的通用 `d=q-p` 加伴随 `p` 种子，经过固定同源仿射合并与 ReLU 关系变换，已经能够得到严格分离旧松弛点的物理输出界 `19/40`；再经过下一混权块，得到相应的 `19/25` 界。

这里的差值下界比 [D042 CONTROL](../d042_bounded_relational_transfer_20260930/CONTROL.md) 的额外源关系所给下界更保守，但其生成前提已由通用种子闭合。新的物理读出与 CONTROL 的 `17/40` 及 [D042 THEORY](../d042_bounded_relational_transfer_20260930/THEORY.md) 的 `17/25` 读出具有不同系数，不能只比较这些常数来作同一性质的精度排名。本页记录纸面证明；执行资格单独由本目录冻结测试及后续结果记录确定。

## 同一赋值上的定义和原相位

令原 HZ 元素为 `H=(B_H,D_H,P_H,F_H,decoder)`，其中 `B_H` 是原连续因子盒，`D_H` 是全部原二元因子的取值域，`P_H` 保留原 EQ/LE 与门关系，`F_H` 是物理读出。有限观察为

```text
(alpha,E,l0,u0,l1,u1,certificate),
l0+(l1-l0)*alpha <= E <= u0+(u1-u0)*alpha.
```

所有 `E` 使用同一原 `(xi,b)`，具体化为

```text
gamma(H,O) = {F_H(xi,b) : xi in B_H, b in D_H, P_H(xi,b),
             every observation holds on this SAME assignment}.
```

观察只在有原整数语义证书时加入，故空观察嵌入原 HZ，加入有效观察不改变整数具体化或原 decoder。内部差值可作为既有坐标的带符号读出，不必创建新连续变量；这种读出也不能被解释为另一份独立输入。允许连续查询松弛时，这些行仅是有效线性外包，不是整个网络的理想凸包。

本文门 bit 为 0/1：bit=0 表示预激活不大于零、输出为零；bit=1 表示预激活不小于零、输出等于预激活。预激活为零时两种原 bit 都合法。若实际原 bit 为 -1/+1，必须认证其 active 方向，再使用 `(b+1)/2` 或 `(1-b)/2`；原 bit 不删除、不替换，相位系数、RHS 和转置的转换均按 D042 计费。

## 原普通网络及无需 oracle 的源界

使用 D042 的同一个真实网络，`R(s)=max(0,s)`，共同输入盒为 `(x,y,z) in [-1,1]^3`：

```text
g=x,                         q=R(g), original bit alpha,
f=9*x/10+z/10-1/4,           p=R(f), original bit eta,
w=y+q/5-p/10,                t=R(w), original bit tau,
h=y+2*q/5-p+3/20-z/10,       r=R(h), original bit beta.
```

仅使用下面三个无条件源证书：

```text
g in [-1,1],
f in [-5/4,3/4],
g-f=x/10-z/10+1/4 in [1/20,9/20].           (S)
```

它们由完整原盒上仿射式的系数绝对值求和直接得到，常数只计一次，没有条件 LP、受限输入盒、模型运行或支持函数 oracle。`y,z` 的原盒范围在两个条件状态都保留。

本页不使用 CONTROL 中的两条额外源不等式

```text
p<=3*q/4,
9*q/10<=p-z/10+1/4.
```

因此下面的生成链不是先手工求得更强条件支持、再称它由通用种子产生。

## 通用差值和伴随种子的逐式实例化

一般地，若 `lg<=g<=ug`、`lf<=f<=uf`、`L<=g-f<=U`，D042 的固定种子为

```text
P0=[max(0,lf), max(0,min(uf,-L))],
P1=[max(0,max(lf,-U)), max(0,uf)],
D0=[-P0.upper,-P0.lower],
D1=[max(max(0,lg)-P1.upper,min(0,L)),
    min(ug-P1.lower,max(0,U))].
```

`P_s` 包围原 `p`，`D_s` 包围原读出 `d=q-p`，均相对于同一个原 `alpha=s`。证明使用 `alpha=0 => g<=0,q=0`、`alpha=1 => g>=0,q=g`，以及 ReLU 的单调性和 1-Lipschitz 性。端点无序或证书身份不符时不安装观察；不据此宣告某相位不可行或删除原 bit。

把 (S) 代入，得到

```text
P0=[0,0],                  D0=[0,0],
P1=[0,3/4],                D1=[0,9/20].       (Seed)
```

例如 `D1.lower=max(-3/4,0)=0`，`D1.upper=min(1,9/20)=9/20`。这一步保留的是 `d` 与 `p`，不是分别丢失相关性后仅保存 `q,p` 的独立范围。范围本身仍是健全外包，不声称表达了 `d,p` 的完整联合关系。

本例 `g-f>=1/20` 确实意味着 `alpha=0` 时 `p=0`，是种子自动推出的结果。因而本正控仍具有一个有序前缀；它不证明任意无支配源对都能获益，也不能替代真实网络适用率。一般种子公式本身不要求 `L>0`。

## 固定共同读出上的仿射传递

先使用已保存定义 `q=d+p` 规范化同源系数，得到

```text
h=2*d/5-3*p/5+y-z/10+3/20,
w=d/5+p/10+y,
D=h-w=d/5-7*p/10+3/20-z/10.                (A)
```

这是在固定读出基 `(d,p,y,z)` 上做真实仿射系数相减，属于 D042 的 paired-affine 传递。共同的 `y` 在区间化之前抵消，不能先分别求 `h,w` 的独立区间后假装仍保留这一抵消。此处不按 LP 点、terminal margin 或事后收益选择分解方向，不新建参考网络、参考 bit 或旁路 ReLU。

对 (Seed) 与 `z in [-1,1]` 按系数正负归约：

```text
alpha=0: D in [1/20,1/4],

alpha=1:
  D.lower=0-(7/10)*(3/4)+3/20-1/10=-19/40,
  D.upper=(1/5)*(9/20)+0+3/20+1/10=17/50.
```

这两个 alpha=1 端点是通用生成器给出的可靠界，不声称是 `D` 的真实最紧范围。尤其不能与 CONTROL 的更强、另有证明的 `[-17/40,59/180]` 混用。

伴随 `t` 也可由同一前沿计算，因 `w=y+d/5+p/10`：

```text
alpha=0: w in [-1,1],          t in [0,1],
alpha=1: w in [-1,233/200],    t in [0,233/200].
```

这提供下一块可能需要的伴随范围，而不是只留下一个无法继续消费的差值界。

## ReLU 关系变换和物理输出界

任意真实 `h,w` 满足

```text
min(0,h-w)<=R(h)-R(w)<=max(0,h-w).
```

设 `e=r-t`，应用于上一节：

```text
alpha=0: e in [0,1/4],
alpha=1: e in [-19/40,17/50].
```

保留原 alpha，得到两条有效行

```text
t-r <= (19/40)*alpha,
r-t <= 1/4+(9/100)*alpha.                    (R1)
```

结合原 `q=R(x)`、`x in [-1,1]` 的负幅行 `q-x<=1-alpha`：

```text
Z_seed=t-r+(19/40)*(q-x) <= 19/40.           (B1)
```

这条物理读出界由 `(S) -> (Seed) -> (A) -> (R1)` 闭合，不需要两条额外源不等式。形式上的两个整数情况只是证明与两个端点槽，不是运行两份 alpha 子网络、相位枚举或搜索树。所有其他原 bits 仍由原门解释，零点合法选择不合并。

## 强旧比较系统及严格分离

比较系统与 D042 CONTROL 第 4--5 节完全相同：令 P 为原真实前缀 `(x,y,z,g,f,q,p,w,t,alpha,eta,tau)` 的完整带标签联合凸包；再对以整个连续 P 为源的最后门 `(h,r,beta)` 取完整带标签图凸包；最后取交全部六对原门全局 D020 差分行。它不是整个真实四门网络的联合凸包，也不包括先把跨最后门条件吸收到非凸图内部后再凸化的更强系统。

沿用其同一个旧点：

```text
x=-9/10, y=z=0, g=-9/10, f=-53/50,
q=p=0, alpha=eta=0, w=0, h=3/20,
t=1/4, r=1/5, tau=3/10, beta=1/2.          (Old)
```

为明确旧点资格不是假设，其完整嵌套凸包见证如下。底层固定 `x=-9/10,z=0,q=p=alpha=eta=0,w=y`，仅列 `(y,t,tau)`：

```text
P_active=(1/4,23/50,1/2)
        =(1/2)*(23/25,23/25,1)+(1/2)*(-21/50,0,0),
对应最后门 (h,r,beta)=(2/5,2/5,1),

P_inactive=(-1/4,1/25,1/10)
          =(1/10)*(2/5,2/5,1)+(9/10)*(-29/90,0,0),
对应最后门 (h,r,beta)=(-1/10,0,0).
```

两外层图点各半混合恢复 (Old)。底层源都严格在输入盒内，相关原预激活非零。六对 D020 的完整区间和逐行代入保存在只读 [CONTROL 第 5 节](../d042_bounded_relational_transfer_20260930/CONTROL.md)；本页复用的是同一网络、同一旧点、同一强比较，不更换任何旧全局界。该比较中即使保留更强的全局差界，也不自动得到 (R1) 的原 alpha 条件界。

在 (Old) 上，新物理读出为

```text
Z_seed=1/20+(19/40)*(9/10)=191/400,
19/40=190/400.
```

所以缺口为 `1/400`。源 `(-1,-1/2,0)` 达到真实上界：

```text
g=-1, f=-23/20, w=-1/2, h=-7/20,
q=p=t=r=0, alpha=eta=tau=beta=0,
Z_seed=19/40.
```

所有原预激活均非零。性质 `Z_seed<=381/800` 的真实安全裕量和旧点违反量均为 `1/800`。这排除的是原物理坐标点，而非自由辅助量；分数旧点不是具体 ADV，纸面分离不是已跑 CERT。

## 关系继续穿过下一混权块

在同一真实图上追加 D042 已定义的两个后继原门，并保留其各自原 bits `tau2,beta2`：

```text
w2=1/10+t-r/2+y/5,           t2=R(w2), bit tau2,
h2=1/10+11*r/10-3*t/5+y/5,   r2=R(h2), bit beta2.
```

使用已存 `e=r-t`，在相同读出基上先规范化：

```text
w2=1/10-e/2+t/2+y/5,
h2=1/10+11*e/10+t/2+y/5,
h2-w2=8*e/5.
```

这是固定局部恒等证书，没有优化新方向或求支持函数。于是

```text
alpha=0: h2-w2 in [0,2/5],
alpha=1: h2-w2 in [-19/25,68/125].
```

再次使用相同 ReLU 规则，得到

```text
t2-r2 <= (19/25)*alpha,
r2-t2 <= 2/5+(18/125)*alpha,
Z2_seed=t2-r2+(19/25)*(q-x) <= 19/25.        (B2)
```

若需要继续传播伴随值，上一前沿的 `e,t,y` 区间也直接给出

```text
alpha=0: w2 in [-9/40,4/5],       t2 in [0,4/5],
alpha=1: w2 in [-27/100,28/25],   t2 in [0,28/25].
```

这些只是可靠生成界，不宣称精确条件支持。相同祖先 alpha 继续作为锚，没有把它偷换成 tau2 或 beta2，也不免费生成跨不同相位的联合条件。

(Old) 可以接上 `w2=t2=1/4,h2=r2=17/100,tau2=beta2=1`，满足两个后继门的精确图，却有

```text
Z2_seed=2/25+(19/25)*(9/10)=191/250,
19/25=190/250.
```

缺口为 `1/250`。真实源 `(-1,-3/4,0)` 给出

```text
g=-1, f=-23/20, w=-3/4, h=-3/5,
w2=h2=-1/20,
q=p=t=r=t2=r2=0, 所有六个原 bits 为 0,
Z2_seed=19/25.
```

全部预激活非零；例如性质 `Z2_seed<=381/500` 的真实安全裕量和旧点违反量均为 `1/500`。两个后继门并非稳定门：在源 `(1,1/2,1)`，有 `t=5/8,r=1/5,w2=29/40,h2=9/200`，二者严格正；上面的达到点则二者严格负。

此延伸只证明第一项关系收益可以穿过下一普通混权块。比较对象是上一节旧系统接上两个精确原门，不声称旧延伸点通过六门全部 D020 或新完整真实前缀联合 hull。它也不证明第二块有独立新增收益，因为旧点已经被第一块的 (R1) 排除。

## 定义与成本及新颖性边界

相对于旧材料，本页补足的是具体构造链的前提：强 CONTROL 额外源不等式不是这个较弱严格正控的必要条件。已知 reduced product、原相位条件支持和差分激活机制仍是数学来源；参见 [Cousot 等 FoSSaCS 2011](https://www.di.ens.fr/~cousot/COUSOTpapers/FoSSaCS-11.shtml)、[ReluDiff 第 4 节](https://chaowang-vt.github.io/pubDOC/PaulsenWW20_ICSE_ReluDiff.pdf) 及 D027/D042 的既有定位。本记录不将其重命名为新不等式、新抽象域或 PLDI 新颖性。

原 HZ 已有的精确非凸语义没有被加强：HZ 加相同有效行具有相同逻辑强度。可编译回 HZ 本身也不是否决理由；未来只能从新的统一生成/组合规则，或完整预算下可使用更多有效关系的证明中获得贡献。此例依然有有序前缀，不能据它外推真实 CNN 的固定配对命中率、CIFAR/Tiny 成绩或普遍收益。

完整成本沿用 [D042 THEORY 的完整成本节](../d042_bounded_relational_transfer_20260930/THEORY.md)：

- 同一个锚下，m 维 `差值+伴随值` 的活动前沿有 8m 个端点，另计原源/bit 绑定、证书及数值位长；K 个锚的成本随 K 增长。
- 固定稀疏仿射组合计入实际系数合并、`nnz(A),nnz(B),nnz(A-B)` 和带符号读出支持。原始源证书、bias、BN、padding、可靠区间算术不能省略；相同包络端点不证明两个系数是同一参数。
- 每个差值观察若在已有物理坐标上物化，两条 LE 至多六个坐标 nnz；伴随条件范围另需两条、至多四个 nnz。只作证明元数据时不计伴随终端行，但不能声称比较系统已经具有它们的强化。
- 本页两跳差值均物化时最多四条 LE、十二个坐标 nnz；原 seed、伴随行、decoder、原谓词和实际 latent 展开仍另计。没有新增 bit、影子门或必要的新差值变量，不等于没有证据或终端成本。
- 历史观察若保留，行数和证据随各层累计；前沿 8m 不是总内存常数。谓词正向与转置、向外舍入、传输、临时内存、终端求解及输入重构均未获得新的实现或性能资格。

全套数学/真实同结构/shadow/逐家族/完整回放晋级门不变，不采用 attack/PGD、BaB、输入或相位 split、backward/dual rescue、实例身份或 LP 状态菜单。缺少证书即不安装观察，保留原 HZ，不能把 UNKNOWN/ERROR 记为收益。
