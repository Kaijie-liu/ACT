# D150：稳定门精确化与共享仿射范数关系

本轮完成的是非凸 Neural-HZ 候选的必要数学完善，不是正式能力突破。原相位、共享输入、EQ/LE、旧余项及输入重构保持；稳定 ReLU 精确传播，消去新生稳定余项后仍保留其占用的共同预算。没有增加 attack、split、backward、dual 或状态触发的 helper 路径。正式 1870/2413 与独立 E0 61/400 均不变，新增正式解为 0。

## 定义层结果

候选的关系谓词扩展为同一 latent frame 上的 `||F(xi,beta,e)||2 <= R(beta)`，其中 F 为仿射向量、R 为可靠非负的相位仿射半径，beta 仍为原整数相位。它保留稳定坐标代入后跨源、相位和 crossing 余项的共同关系，不是把这些约束交给另一验证算法补救。

相对相同父状态的 D149 子状态，D150 与可靠稳定等式相交，再精确投影其唯一确定的新生稳定余项。每个新状态可重构被投影的余项；不删除原二元变量，零点的两个标签继续合法。这个包含结论不等于独立多层运行后的整体支配。稳定门规则、幂等性和仿射代入本身是已知基础规则，不能据此宣称 PLDI 级新颖性。

普通双门控制中，保留稳定能量的共同范数给出 live-skip 读出 J <= sqrt(2)+1/2 < 2，使后继 ReLU(J-2) 恒零。错误地丢弃稳定能量则允许该输出为 1/2。三门控制进一步确认：即使两个局部范数投到同一 crossing 坐标，它们的稳定源项也不同，不能合并。后继传播测试确认这些约束没有在新层中丢失。对照证明了必要关系被保住，不代表胜过精确 HZ 或完整输入相关单门凸包。

固定行序的域内支持界消费这些范数，不进行优化、搜索或递归救援。它不是全部谓词交集的精确支持函数。后继向量半径仍使用较松的 bank 外包；存在精度损失，尚无整体净优势证明。

## 下一项可反证的能力比较

优先结构只有一种：含稳定与 crossing 通道的普通 Conv→ReLU→混权 Conv＋活 skip→ReLU。比较双方使用相同输入、可靠界、原相位及完整时间/内存预算。参照必须具备标准稳定门处理及已有关系；精确 HZ 的集合语义不能被一个健全外包“超越”，实际目标是同预算下得到更强的可认证结论。

若优势只相对于弱四行松弛或错误删除共同能量的版本存在，而强参照已覆盖，则该结构的 Neural-HZ 能力增益判定为零；不要继续堆局部测试将其包装为突破。候选必须由自己的统一传播提供可核实跨层收益，最终支持真实新增 CERT 或经原网验证的 ADV。仅运行到中间层不计新解。

[真实来源范围](REAL_NEXT.md) 已只读核对：现有两份 CIFAR packet 支持完整首两次 ReLU 和活 skip，但没有完整穿过残差 Add 后的全部数值参数；Tiny 同等参数绑定仍缺。小型稠密参考 API 不能承载 3072 维完整源及大前沿。必须解决共享全局关系的可扩展实现与完整费用，不能用独立 patch、放宽门槛或只挑窗口代替。

GPU 历史初始化失败尚未获得成功计算资格；本轮没有重新诊断。smooth、Transformer、真实 CNN、同结构 shadow、全部家族及 2413/400 回放目标均未完成。
