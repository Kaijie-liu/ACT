# 任意预激活序列的共同曲率定义及其等价边界

本轮把D189共同二次曲线的假设放宽到任意一组同父域仿射预激活，得到健全的共同曲率候选。同时证明：其完整有限质量与一阶矩关系，恰好是局部三点差分约束的坐标变换或消费者投影。它修复了适用条件，不自动带来新信息、整数相位精确性或更低完整成本。因此不把此推广直接晋级为强大Neural-HZ实现。

以下为纸面实数推导，未运行候选、求解器或模型。所有源、原signed bits、EQ/LE、共享frame、历史谓词和输入decoder保留；beta仅为原bit的0/1视图。一般抽象父域可以非凸，证明对其每个成员成立。

## 任意源行上的出生关系

固定系数knots和同父域读出：

```text
0=t_0<t_1<...<t_m<t_(m+1)=1, N=m+1,
h_i=t_i-t_(i-1), i=1,...,N,
g_0,...,g_N are actual affine readouts of the same parent H,
s_j=(g_(j+1)-g_j)/h_(j+1), j=0,...,m.
```

保留两个原端点的精确图p_0=ReLU(g_0)、p_N=ReLU(g_N)，其原bits与完整成本不免费。内部原bits和实际g_i上的可靠guards仍在。C覆盖全部内部激活消费者和必需谓词读出；遗漏独立消费者时不能删除对应幅值。

对每个内部knot，先认证同源仿射量v_i满足

```text
delta_i=s_i-s_(i-1),
v_i>=0, v_i>=-delta_i.
```

这些是预先认证的源读出，不是新增自由量或优化器。可对-delta_i使用其可靠全父域区间上的ReLU仿射上包络：若上界非正取0，若下界非负取原量，若L<0<U取U*(x-L)/(U-L)。这套规则依赖数学区间，不依赖身份、标签、margin或终端状态；所有界、系数和舍入均须计费。没有虚构额外激活或相位。

在系数参数t上对g_j作分段仿射插值g(t)，定义

```text
psi(t)=sum_(i=1..m) v_i*(t-t_i)_+,
F(t)=ReLU(g(t))+psi(t).
```

此插值仅用于证明，不分裂输入、不枚举相位，也不要求插值路径属于父域。固定任一父成员：线段内部ReLU过零的导数跳跃非负；在knot处，若g_i>0，F导数跳跃为delta_i+v_i；若g_i<0为v_i；若g_i=0则为max(s_i,0)-min(s_(i-1),0)+v_i。三者皆非负，故F凸。该论证不选择原零点标签。

令U_0(s_0)、U_m(s_m)为已认证的同源仿射ReLU上包络，取

```text
a_lo=s_0-U_0(s_0) <= F'(0+),
a_hi=U_m(s_m)+sum_i v_i >= F'(1-),
B=a_hi-a_lo,
K=a_hi-p_N+p_0-sum_i(1-t_i)*v_i.
```

端点为零时用单侧导数，仍有min(0,s_0)<=F'(0+)及F'(1-)<=max(0,s_m)+sum v。给F''加两端非负补质量，所得nu满足

```text
nu>=0, integral dnu=B, integral s dnu=K,
G(t,s)=min(t,s)-t*s,
e_i=(1-t_i)*p_0+t_i*p_N-ReLU(g_i),
e_i+sum_j G(t_i,t_j)*v_j=integral G(t_i,s) dnu(s).
```

特别地B>=0、0<=K<=B。它们来自同一父赋值，不可将不同消费者分别取一份源或曲率见证。

## 完整消费者关系

定义系数多面体及新输出：

```text
P_C=conv{(t_j,C G(:,t_j)):j=0,...,N},
(K,E) in B*P_C,
Y=C*((1-t)*p_0+t*p_N)+C*G*v-E.
```

规范扩展直接取上面的真实共同nu，所以对整个当前父域健全，而不仅对原网络真实轨迹健全。附加必要的Y属于C R_+^m时，必须认证并支付完整输出锥；该锥和曲率块独立相交，并不保证二者存在同一个非负内部幅值见证。

Affine、Conv、同身份Add/Concat对同一E和源读出线性作用。下一ReLU必须消费这个有损父域的所有成员，不能沿用其规范扩展身份。空bank嵌入原HZ；端点原图与内部guards维持非凸相位结构。但它没有恢复全部内部beta_i与幅值的关系，不是整数精确图。

## 质量与矩恰好等价于局部差分

暂保留内部坐标q_i，令q_0=p_0、q_N=p_N，F_i=q_i+psi(t_i)，以及

```text
d_i=(F_i-F_(i-1))/h_i, i=1,...,N.
```

命题：以下三个表述双向等价。

1. 存在共同非负nu，具有质量B、矩K，并在所有内部knots产生chord(F)-F。
2. 存在lambda_0,...,lambda_N>=0，sum lambda=B、sum t_j*lambda_j=K，产生同一Green读出。
3. 仅以下m+2条行成立：d_1>=a_lo，d_N<=a_hi，以及d_(i+1)>=d_i。

第一项到第二项是因为(s,G(:,s))在相邻固定knots间仿射，区间内质量可以移到两个端点并同时保留全部样点Green值和一阶矩，不是输入或相位split。第二项到第三项及其逆有显式公式：

```text
lambda_0=d_1-a_lo,
lambda_i=d_(i+1)-d_i, i=1,...,m,
lambda_N=a_hi-d_N.
```

其质量望远镜相消为B；其矩为a_hi-F_N+F_0=K。Green离散斜率差的逆关系给出全部内部读出。因而在q坐标中恰为：

```text
(q_1-p_0)/h_1 >= a_lo,
(p_N-q_m)/h_N + sum_j v_j <= a_hi,
(q_(i+1)-q_i)/h_(i+1)
 -(q_i-q_(i-1))/h_i + v_i >=0, i=1,...,m.
```

第二行代入a_hi后sum v精确抵消。内部每行只需三个相邻q和相应源补偿；两端行各需相邻两个q及端点源斜率包络。因此原HZ加完全相同信息的这些行，已经具有相同曲率信息；它还保留原整数逐门图。不能只比较旧单门LP，然后把所有加强归功于新曲率坐标。

该等价不证明这些行由旧单门四行LP蕴含；联合关系仍可能加强那个特定松弛。但投影或换坐标没有创造额外信息，新的贡献只能由完整精度与费用比较建立。

## 为什么无面枚举也没有自动压缩

内部原幅值有m个。直接lambda形式有m+2个新量和两个等式；保留p_0,p_N后，比原表示多两个连续量。消去lambda_0、lambda_N才回到m个自由度，此时内部Green矩阵可逆，正是q的坐标变换。

若使用m个内部曲率量，直接编码的裸行数为2m原guards、m+2曲率行及8条端点图，共3m+10 LE。它尚未保内部非负性。若C满列秩，Y属于C R_+^m可直接恢复m条非负行，该编码为4m+10 LE；原m+2个完整逐门图为4m+8 LE，另付共同源/读出。这是明确编码的账，不是所有等价系统去冗余后的行数下界。epigraph、幅值caps、终端转换和输入解码还未计入，不可由裸计数宣布胜利。

在已物理保留g与q、使用上述标量仿射secant时，m+2条差分行至多6m+8个非零：内部行至多三个q与三个g，两端行各至多四个系数。若g内联为源系数，必须计实际展开；若用lambda，C G、G v、定义等式及证据也须计费。前缀扫描只说明某些作用可线性时间计算，不免除完整终端存储或设备数值认证。

低秩完整C仍允许输出投影，但需另证投影表示、全部range等式和锥的费用，不能假设只有两个消费者。没有获得真实GPU、四并发或能力资格。

## 精确相位修复的有限线性下界

回到共同二次预激活，给出一个限定明确的障碍，而非任意Neural-HZ不可能定理。取内部门数m>=1，f,h属于[0,2]、c属于[1,2]，保留所有原bits，且

```text
g_i=(1-t_i)*f+t_i*h-c*t_i*(1-t_i),
Y=sum_i w_i*ReLU(g_i), w_i>0.
```

端点p_0=f、p_N=h。假设表示仅用f,h,c、Y、原bits和这些端点别名，不增加其他连续量，使用有限、固定系数线性EQ/LE，并要求对全部合法整数相位保持精确Y。

存在N_phase=1+m(m+1)/2个严格可达相位：inactive集合为任意连续knot区间，或空集。对每个非空区间，取c=3/2、两根r<s分别位于该区间两侧的knot间隙，令f=c*r*s、h=c*(1-r)*(1-s)。这些量严格在给定盒内部，且g(t)=c*(t-r)*(t-s)。严格符号具有开放三维源邻域。空集可取f=h=1、c=3/2。

每个相位上的输出斜率

```text
A_beta=sum_i w_i*beta_i*(1-t_i,t_i,-t_i*(1-t_i))
```

都不同。固定某严格实现源z=(f,h,c)，beta是sum_i w_i*alpha_i*g_i(z)在alpha属于[0,1]^m上的唯一最大者；若另一不同beta'有相同A，其在z处的值相等，矛盾。

固定beta后的精确图是开放源区域上的Y=A_beta*z。要同时排除上、下方向的非零Y扰动，有限线性系统必须有一条含Y的上行和一条下行在该片上恒取等。否则有限个非恒等超平面不能覆盖整个开放区域。归一化含Y系数后，该行的源斜率必须为A_beta；一条固定行不能服务两个不同斜率。含Y的EQ会在所有相位强制同一斜率，故不能替代这些不同的上下行。因此至少需要

```text
2*N_phase=m*(m+1)+2
```

条含Y的LE。本候选明确保留的guards等另计；该定理本身没有证明所有等价描述都必须再加2m条guards。m=3时已经至少14条，旧三个内部幅值图为12条另加输出定义。此处只比较明确行数，不是完整nnz或时间结论。

这不约束带提升变量的扩展表述、非线性谓词、其他受限父域或新的可查询表示；也不是运行时相位枚举。它否定的是“在同一个纯线性无lift输出投影中，补少量行便免费恢复全部原相位精确性”。

另一条捷径同样不成立：二次g在两个同为active的相邻knots之间可以有两根，不能把离散原bits当作整段曲率密度。一般PWL版本若直接绑定实际离散曲率，仍需beta_i*g_i；保存所有曲率量只是原图换坐标，聚合后则回到D183的相位依赖源乘积，其McCormick外包不因原bits整数而自动精确。
