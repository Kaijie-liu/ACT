# 曲率定义在真实卷积接口上的适用条件

本次只读现有结构证据并推导必要条件，没有加载权重、执行网络、重新运行诊断或取得实际匹配结果。结论是D189的共同二次曲线与小维消费者均需独立认证，不能由卷积共享权重和末端维数较小推断。

## 预激活系数必须共用同一抛物线

令a_i=(L_i,b_i)为同一个父源坐标上的增广仿射系数。D189要求

```text
a_i=F+t_i*(H-F-C0)+t_i^2*C0.
```

所以所有系数行的矩阵秩至多3，行差的仿射包维数至多2，且各二阶divided difference相同。前两个秩条件仅必要，不充分。若父域有认证的仿射等式，须先在其实际仿射包商空间中比较；不能把晚层父张量坐标假设为相互独立，也不能把共享skip当作降维等式。

对每个源列，其系数是次数至多2的knots多项式。因而若三个不同knots的该列结构为零，第四个非零，就排除这个坐标系下的精确合同。

## Tiny卷积共享不提供二次系数关系

[D179原报告](../../results/d179_preterminal_domain_20261004_v1/model_2.json)中，节点49的Conv输出168，节点50的BN输出169，节点51的ReLU输出170；这才是待压缩q的producer，不能误用之后节点52的Conv作为producer。节点49确为3乘3、stride1、dilation1、pad1、group1，输出1乘128乘7乘7。报告仍明确标记coefficient_validity_verified和actual_rank_computed为false。

这个形状允许一个具体的条件排除证书。在同一output channel、同一内部行上取五个连续水平位置，且所有3乘3窗口均未被padding截断。假定已认证某有效Conv加BN kernel非零，选一个input channel和vertical offset上最左非零的horizontal系数a。取它在第一个位置消费的源坐标；后四个位置要访问同一源坐标，需要更靠左的kernel offset，故系数全为零。于是这五行的一列为(a,0,0,0,0)，不能来自次数至多2的多项式。

这只是条件定理。当前未解码有效kernel，也没有认证父域仿射包，故不能写成“实际Tiny已拒配”。但它明确否定了“共享卷积权重天然满足共同二次knots”的结构推断。同位置跨channel没有此稀疏排除，却仍需实际系数证书；普通128/256个filters没有低秩保证。

若固定等间距knots并考虑前三次差分，上述一列的前四项给出

```text
(-1,3,-3,1) dot (a,0,0,0)=-a.
```

任何二次拟合的三次差分为零，故其残余列r满足max_i abs(r_i)>=abs(a)/8。这是系数残差下界，不是已测网络误差。只有父域另认证该源方向可独立变化半径rho，才可推出相应行的函数残余半径至少rho*abs(a)/8；不能把晚层源盒当成实际独立变化证据。

## 完整消费者决定真正能压缩多少

对内部knots，Green矩阵G_ij=G(t_i,t_j)可由离散斜率差反演，因而可逆。D189系数多面体

```text
P_C=conv{(t_j,C G(:,t_j)):j=0,...,m+1}
```

包含(0,0)和(1,0)，而内部其余方向的秩为rank(C G)=rank(C)，故

```text
dim aff(P_C)=1+rank(C).
```

若完整C满列秩m，则这m+2个顶点仿射独立，P_C是m+1维simplex；其E仍需m个独立幅值方向。小面数来自没有压缩的simplex，不是既少变量又廉价精确投影。

[D179的三条完整接口](../d179_preterminal_domain_20261004/RESULTS.md)分别为4096到100、2048到100、6272到200。实际消费者子矩阵的秩尚未知。小组可能满列秩，不能假定有效输出维数2；大组m超过100/200后才有仅按宽度保证的非平凡核，而要求这么多普通producer行精确共二次曲线又是很强的假设。这里描述合同的张力，不是一般Neural-HZ不可能性，也不是模型数值结论。

## 本次证据改变的下一动作

不把D189直接套到late CNN，也不创建更多loader包装来掩盖数学适用性缺口。[任意行推广](GENERALIZATION.md)已经去掉该低秩假设，但其完整质量与矩关系恰为局部三点差分投影，仍需原相位幅值关联及全部消费成本。

后续需要的是一种在普通producer上保留有用非凸相位关联、又能完整查询的域定义；不能继续将“有曲率关系”“有窄输出”或“可做GPU scan”分别当作已实现这种定义。已有早层系数包和native快照的范围仍遵守[D181接入审计](../d181_shared_coefficient_frontier_20261004/REAL_BINDING_AUDIT.md)，不借旧快照自动授予新前沿资格。
