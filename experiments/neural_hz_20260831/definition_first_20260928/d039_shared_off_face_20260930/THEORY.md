# 共同关断面的分组关系与有限前向组合

本候选把“多个原激活在同一原相位关闭时同时为零”作为可传递的关系。它不识别或合并成员相位，不增加相位搜索，也不要求两个滤波器相同。得到的分组幅值关系在一个普通混合权重网络上严格强于完整父联合凸包、以该凸包为源的完整子门局部凸包、逐边 D036 和未缩放相位差分关系的组合。

这里交付的是定义片段、构造性定理、有限组合规则与成本界，不是已完成的新 Neural-HZ。关断面、perspective 和 guard-module 都有既有先例；不能把 HZ 加已有有效行重新命名为新域。实际网络适用性、GPU 算术和端到端收益均未验证。

## 关系元素和原非凸语义

令 H 保留原连续赋值 xi、全部原二元相位 b、EQ/LE 谓词 P_H、共享 frame 及原输出读出 F_H。一个有限关系集合 Z 保存具名原坐标仿射读出 E 与原相位 alpha 的配对，其含义是 alpha=0 蕴含 E=0。每个读出必须由同一份 (xi,b) 解释，不能自行选择另一源赋值。

候选具体化片段写为：

```text
gamma(H,Z) = { F_H(xi,b) : (xi,b) satisfies P_H,
                           (1-alpha)*E(xi,b)=0 for every (alpha,E) in Z }。
```

Z 为空时精确嵌入原 HZ。若每个关系都有原 H 的有效证书，添加它不改变具体集合及 decoder；若无证书，不得写入。保留整数 bits，故不因使用线性终端而整体凸化这个域。

当 E 的可靠全局界为 [ell_E,u_E] 时，关系可精确编码为 ell_E*alpha<=E<=u_E*alpha，连同原 E 定义和原二元 alpha。alpha=0 强制 E=0，alpha=1 只恢复原界。原域若用 {-1,1} bits，转换成本另计。这也是为什么本语义片段仍可编译为既有 HZ；只给出这个元组或这个编码不构成定义创新。

与[既有 guard-module 审查](../d006_guard_module_audit_20260928/D006_RESULTS.md)的关系是：这里给出特定有限关系的廉价源证书和部分前向构造，不声称发现了新的全局消去理想、表达能力或完整闭包。

## 从共同源差证书得到一组零面观察

取固定有序相邻源组，首成员 a 为锚。统一使用 kappa=1，不拟合缩放、不换锚搜索。若对每个其他成员有共同源证书 g_j-g_a<=0，保留原门 q_j=ReLU(g_j) 及全部原 bits，则锚原相位 alpha_a=0 时 g_a<=0，进而全部 g_j<=0、q_j=0。

只推出幅值为零，不推出成员 bit ordering。当 g_a=g_j=0 时，alpha_a=0、成员 bit=1 仍合法。即使源函数相等，也不合并原相位。若证书不成立，此固定组不产生该关系；不根据收益、身份或求解状态改选组。

第一仿射源盒上的证书可合并 g_j 与 g_a 的共同原输入系数，再求该差的盒上界。对于区间系数，用可靠区间差与乘积端点得到上界，不使用中点代替真实参数。证书必须绑定实际源；不能把这个一层支持程序当作任意深层源的免费 oracle。

## 分组幅值定理

设 S=sum_j a_j*q_j、h=S+v、r=ReLU(h)，上述组证书给 alpha=0 时 S=0，残差有可靠 L<=v<=H。令 l=ReLU(L)、m=ReLU(-H)，则：

```text
r   >= l*(1-alpha)
r   >= S+L*alpha+l*(1-alpha)
r-h >= m*(1-alpha)
r-h >= -S-H*alpha+m*(1-alpha)。
```

证明：alpha=0 时 h=v，前两行相同，均由 r>=ReLU(L) 推出；后两行由 r-h=ReLU(-v)>=ReLU(-H) 推出。alpha=1 时由 r>=0、r>=h、r-h>=0、r-h>=-h 及残差界推出。线性行因而对原带标签集合的凸包有效；不假称整数原理在任意 fractional 点上直接成立。

若实际固定 a_j 属于 [alo_j,ahi_j]，在第二行以 Slo=sum alo_j*q_j 代 S，第四行以 Shi=sum ahi_j*q_j 代 S，仍有效，因为 q_j>=0。原 h 始终使用真实系数，其他两行不变。它不是区间不确定系统的完整凸包。

它与 D032 的区别是源证书先证明多个非线性父输出共享一个真实关断面，而非假定任意另一门已经是单相位支持器可免费处理的观察。它与 D036 的区别是以整个混合权重组生成后代关系，而非独立处理每条边。机制仍是已知 perspective/条件化关系的构造性应用，不是新不等式类别。

## 有限的前向组合规则

同锚的零面观察 E_i 对任意无常数混合线性组合 S=sum c_i*E_i 精确闭合。对于仿射输出 F=c+S，则 F-c 是同锚观察。Conv 是共享权重的此类线性映射，Add/Concat 只能在同一源 frame 和同一原锚下合成关系；不能把两份独立存在量词当作共享状态。

进一步令 h=S+v，r=ReLU(h)。若有可靠 v<=0，则 r 仍是零面观察；若有可靠 v>=0，则 E_new=r-v 是零面观察。两者的证明都只需在 alpha=0 时代入 S=0。这里保留真实子门和其原 bit，不新造 gate，也不删除旧 bit。v 可以是具名原坐标仿射读出，但所需符号证书与其存储/展开必须付费。

若 v 跨零且没有已存在并已绑定的原节点 ReLU(v)，不能免费继续这套仿射观察语言。在 alpha=0 时 r=ReLU(v)，而跨零 ReLU(v) 一般不是 v 的仿射函数；例如在 [-1,1] 上其三个值 0、0、1 就排除单一仿射对应。若原网络恰已有可靠的 ReLU(v) 坐标，可保留 r-ReLU(v)；否则需要额外非凸建模和成本，当前不覆盖，也不偷偷创建旁路网络。

新观察 r-v 可以有符号，因此上一节的 Slo/Shi 端点替代只适用于已证明非负的 q_j，不能直接套在一般 E_i 上。一般混合线性组合的零面闭包对实际固定系数仍精确；若系数只持有区间且观察有符号，须另行构造可靠误差证书，此处不声称已覆盖其数值编译。

这给出了明确的部分组合范围，不是“所有网络固定宽度闭包”。它没有削弱原 HZ 对未覆盖算子的处理，也不能把未构造证书的关系用于 CERT。

## 强比较系统下的普通网络正控

取 x,y,z in [-1,1]：

```text
g=x，f=(9/10)x+(1/10)y-1/4，q=ReLU(g)，p=ReLU(f)，
h=(3/2)q-(1/2)p-2/5+z/8，r=ReLU(h)。
```

父相位为 alpha、eta，子相位为 beta。两父门都跨零且梯度不平行；固定 kappa=1 的证书 sup(f-g)=-1/20 严格成立，不依赖罕见恒等式或零点特判。组残差 v=-2/5+z/8，L=-21/40、H=-11/40。

旧分数点为：

```text
x=1/10，y=0，z=-16/25，q=2/5，p=91/400，alpha=eta=13/20，
h=1/160，r=53/500，beta=1/5。
```

令 P 为两个父门连同全部源坐标和原父相位的完整联合凸包。子门不只使用独立 q/p 盒，而允许在完整 P 上构造它的 labeled hull。以下两级固定数学混合证明旧点仍在这个强比较系统中；它不是运行时相位枚举。

子门 active 分量权重 1/5，使用真实父源 (x,y)=(41/50,-12/25)，固定 z=-16/25；此时 q=41/50、p=11/25、alpha=eta=1、h=r=53/100。

子门 inactive 分量权重 4/5，使用 P 内的点：

```text
(x,y,q,p,alpha,eta)=(-2/25,3/25,59/200,279/1600,9/16,9/16)。
```

该父点由真实父源 (118/225,22/25) 与 (-6/7,-6/7) 按 9/16、7/16 混合得到；前者两父门 active，后者两父门 inactive。源 z 仍固定。该点 h=-399/3200，子门取 r=0、beta=0。外层混合恢复旧点全部坐标。所有底层源点严格内部，父预激活非零。这里凸化后的 P 可含分数父相位，不能误称整个真实两层联合 hull 也允许旧点。

逐边 D036 仍通过。q 边余项区间为 [-9/10,-11/40]，两条需核对的行要求 r>=3/200、r-h>=77/800；旧点 r=53/500、r-h=399/4000 满足。p 边余项区间为 [-21/40,49/40]，其另两条行右侧为 -91/200、-273/400，同样满足；基础 epigraph 行也满足。

未缩放 D020 差界为 g-h in [-29/40,21/40]、f-h in [-39/40,3/8]。在 x<=0 时 q=p=0，可直接取得极值；在 x>=0 时用 p<=x、p>=0、f in [(9/10)x-7/20,(9/10)x-3/20] 验证没有超界。因此这是原网络上的证书，不是独立项界猜测。

对应正/负幅值差为 (147/500,801/4000) 和 (243/2000,1151/4000)。把同一 alpha=eta=13/20、beta=1/5 代入各边的四行相位差分，全部通过，所以这些行的 D022 共享相位一致性也通过。P 已含本例所有有效的父源线性事实；不通过给新侧额外父 hull 偷换比较对象。

## 排除的是物理输出而非某个相位选值

新组行要求 r>=(3/2)q-(1/2)p-(21/40)alpha，旧点右侧为 29/200，大于 53/500。结合原父门 alpha<=x+1-q，可消去重新选择 alpha 的自由，得到：

```text
Z=(81/40)q-(1/2)p-(21/40)x-r <=21/40。
```

旧点 Z=2151/4000，超出 51/4000。真实上界 21/40 在 x=-1、y=z=0 达到。性质 Z<=53/100 因而有真安全裕量 1/200，而旧点违反 31/4000。这是纸面物理输出分离，不是运行过的 CERT 或数据集 ADV。

本例另一条组行与已有 q 边行相同，真正新增的只是四个坐标非零项的一行。但不能从此例推断所有卷积组成本相同或真实模型存在同样收益。

## 全部成本和 GPU 设计边界

k 个成员不另物化 S 时，四行的单行坐标 nnz 上界为 2、k+2、3、k+3；考虑 l 与 L-l、m 与 H+m 不同时非零，全部四行至多 2k+8。按 L/H 符号去掉基础 epigraph 已支配的行后最多两行、2k+5 nnz（k>=2）；固定 pair 最多两行九 nnz。混号组可以同时留下第二与第四行，不能继承单边“最多六 nnz”。

若原坐标是 latent 上的读出，安全展开界为 2*s_r+s_h+2*sum_j s_qj+2，原范围、bits 转换和等式格式 slack 另计。新建 S 坐标并不能免除定义等式、新连续量与重构成本；当前只用既有读出。

每个唯一固定源 pair 的差证书按共同系数支撑并集进行线性扫描，跨接收通道复用时保留源身份和证据。每个接收行先计算全部贡献上下界，再从同一次和中减掉整个组，不能从另一个相关接收界减独立项。组数、所有证书与完整原 fan-in 都计入成本；不丢稳定源、padding 或失败组的检查代价。

GPU 上可对应固定 pair 的差系数归约、接收贡献归约、逐组 gather、谓词 SpMV 和转置 scatter。必须另行实现并认证向外舍入、实际相位列绑定、传输、全物理存储、终端决策和见证验证。此处没有 GPU 执行、加速数据或设备求解资格；CPU Fraction 证明也不能自动赋予 GPU 数值资格。
