# 残差来源覆盖与两父相位规则的适用边界

本记录给出一个新的项目内组合结论：把未选父幅值的宽度与两个父门不能覆盖的共同来源宽度合并，可在取得完整来源之后，以线性扫描证明一个子门对下的全部父对都不适用当前 mixed 规则。对同一来源组的重复覆盖只扣一次，严格强于把两个父的覆盖量直接相加。

这是当前完整列盒守卫的适用性定理，不是新抽象域、原网络不可验证定理或真实模型拒绝率。它改变下一步的判断依据：不能把不断扩大两父运输人口当作必然的能力路线；必须检验完整来源信息能否被当前规则消费。原连续因子、全部二元相位、EQ/LE、共享身份及 decoder 均不变。

## 完整来源前提

在同一个 H 中，先按经过认证的身份合并 alias，忠实折叠稳定 ReLU，保留原全部来源、谓词和消费者。两个实际子门的完整预激活写为

```text
g_c = sum_k C_ck Q_k + S_c(A),  c=1,2,
Q_k = ReLU(f_k),   0 <= Q_k <= U_k,
f_k = c_k + w_k A,   s_k=max(-L_k,U_k)>0.
```

Q_k 是仍独立占据规范前沿坐标的同层 crossing 幅值，不是新自由输入。父 f 不含这些同层 Q。A 保留更早来源、误差及其他原坐标；本定理计入的 A 列与 Q 列不重合。每列盒宽必须来自该合同实际使用的可靠范围。H 中的相关谓词仍保留，但下述宽度是该合同的列盒计算，不是 H 的精确支持宽度。

令完整均值来源 (S_1+S_2)/2 = c+v A，并定义

```text
sigma_k = abs(C_1k+C_2k)*U_k,
delta_k = s_k*(C_1k-C_2k),
S = sum_k sigma_k.
```

对有序父对 i != j，当前固定尺度为 tau=(delta_i-delta_j)/4。仅 tau>0 可能通过。两父 Gram 或任何两父行线性组合，均不能改变 w_i、w_j 同时为零的 A 列系数。

## 未覆盖来源与未选幅值共同计宽

设 A 列 l 的盒宽为 h_l。当前完整残余 r 的盒宽 W_r 满足

```text
W_r >= (S-sigma_i-sigma_j)/2
       +sum_{l: w_il=w_jl=0} abs(v_l)*h_l.                 (1)
```

第一项是未选 Q 对子均值的完整系数宽度；父 f 没有同层 Q，不能由 Gram 消掉。第二项是两个父行都无法改变的来源列。规范列已合并且两类列互不重合，故它们在盒宽的绝对值和中可以相加。原谓词可能令真实支持更窄，但不会改变本合同实际计算的这个盒宽。

Mixed 守卫要求其相位条件均值范围落在 [-tau,tau]。该范围包含 r 的完整区间再加一个宽度非负的相位部分，因此 W_r<=2*tau 是必要条件。它不是充分条件，还没有检查区间位置、相位项或差残余 e。

## 分组覆盖与不同父身份

从 A 中选取一个预先由结构确定的列子集，分成互不重合的组。定义

```text
Gamma_g = sum_{l in group g} abs(v_l)*h_l,
G = sum_g Gamma_g.
```

每个父在这些被计入的列上最多触及一个组，记组身份为 g(i)；完全不触及用 Gamma_0=0 的虚组表示。父可以在该列子集之外含任意来源。定义

```text
K_ij = Gamma_g(i)+Gamma_g(j)
       -1[g(i)=g(j)]*Gamma_g(i).
```

这个 union 对组覆盖摘要精确；若父只触及组内部分通道，扣除整个组仍是保守操作，不声称精确扣除了实际列支撑。由 (1) 得

```text
W_r >= (S-sigma_i-sigma_j)/2 + G-K_ij.
```

所以任何通过的父对必须满足

```text
S+2*G <= sigma_i+delta_i+sigma_j-delta_j+2*K_ij.            (2)
```

若左侧严格大于所有不同父身份的右侧最大值 M，则全部父对均拒绝。相等不判拒绝；小于 M 不授予通过资格。计算 M 时保留 delta_i<=delta_j 的方向只会放宽 M，不会误拒绝；它也不证明达到 M 的方向具有正 tau。

令 a_i=sigma_i+delta_i，b_i=sigma_i-delta_i。M 可分为两种互斥身份情形精确计算：

- 不同组：先保存各组 A_g=max a_i、B_g=max b_i，再求 g!=h 下的 (A_g+2*Gamma_g)+(B_h+2*Gamma_h)。对后一项维护带组身份的最大及次大值即可。
- 同组：在组内以父身份排除 i=j，求 max(a_i+b_j)，再加 2*Gamma_g。单父组没有此项；组内同样只需最大及次大值。

这是对上述同一最大式的分解，不是两套验证路径。取得输入摘要后，耗费 O(m+g) 次有界有理数操作和 O(g) 摘要；按排序实现额外身份映射则必须另计排序费用。一般父同时覆盖多个组时，不套用这个复杂度结论。

## 两个普通严格比较

### 旧幅值尾项判据不能排除的结构

取 x,y,u,v 在 [-1,1]，并令

```text
f1=x+y/4,  f2=x-y/4,  f3=x/2+y,  Q_i=ReLU(f_i),
g1= Q1-Q2+3*Q3/10+4*(u+v)/5,
g2=-Q1+Q2+3*Q3/10+4*(u+v)/5.
```

三父源共同秩为 2，任意两行均非平行；三个父及两个子都 crossing。可靠 s=U=(5/4,5/4,3/2)，故 sigma=(0,0,9/10)，delta=(5/2,-5/2,0)。D246 原 Q-only 全对判据的左侧为 9/10，右侧最大为 5，不能全拒绝。

所有父都不覆盖 u、v，两来源给 G=16/5、K_ij=0。新左侧 S+2G=73/10>5，证明全部父对不能通过当前 mixed 守卫。对 (1,2)，实际 r=3*Q3/10+4*(u+v)/5，宽度为 73/20，大于 2*tau=5/2。这里宽度为 Q3 的 9/20 加 u/v 的 16/5；不能将乘 2 后的必要判据数值误当成 r 宽度。

这是判据的严格增强，不是更紧物理输出界，也不是新增 CERT。系数和严格拒绝余量均为普通大小，不依赖零相位或极小数值误差。

### 相同来源组不能重复扣除

取 x,y,t 在 [-1,1]，保留 f1=x+y/4、f2=x-y/4，令

```text
z=x/2+3*t/2,
g1=Q1-Q2+z,  g2=-Q1+Q2+z.
```

组 A 包含 x,y，组 B 包含 t。两父都覆盖 A，Gamma_A=1、Gamma_B=3、G=4。sigma=0、delta=(5/2,-5/2)。把覆盖量双扣的较弱版本给右侧 5+4=9，左侧 8，不能拒绝。正确 union 只扣组 A 一次，右侧 5+2=7，故 8>7 全拒绝。

实际 Gram 精确消去 x/2，残余为 3*t/2，宽度 3>2*tau=5/2。这个例子也说明同位置多通道父不等于覆盖了多个空间来源。

## 两个必须保留的反例边界

稳定折叠不能省略。令 x,y 在 [-1,1]，Q3=ReLU(x+y+3)=x+y+3，z=4*(Q3-3)/5。若把 Q3 当成独立 crossing 尾项，其表面宽度为 16/5；实际折叠后 z=4*(x+y)/5。对父 ReLU(x)、ReLU(y)，来源残余为零，异相位时 abs(z)<=4/5，tau=1 的守卫可以通过。这个稳定项不满足定理的 Q 前提。

Alias 也不能按逻辑端口重复计数。若 u=t、v=-t 为同一来源的认证读出，4*(u+v)/5 合并后为零；不能沿用独立 u/v 的 G=16/5。相同范围本身不能证明 alias，只有完整身份和仿射映射才能用于合并。

## 一般来源覆盖数量的限定下界

有 m 个独立组、每父最多触及一个组时，任意 k 个父源方向的组合仍满足

```text
W_r >= G-sum_{r=1}^{min(k,m)} Gamma_(r),
```

其中 Gamma_(r) 为降序组贡献；不计额外 Q 尾项已经是保守下界。若每组贡献至少 gamma>0，且所研究的同一列盒守卫只允许宽度 B，则必要条件为 k>=max(0,ceil(m-B/gamma))。

这只下界当前守卫需要覆盖的父来源数量，不是 Boolean 产品阶数、一般 HZ 表示复杂度或所有 Neural-HZ 的下界。更紧的有证共同范围、合法 EQ 商、保留尾项的联合容量都可能改变结论，不能用本定理排除它们。

## 研究与成本边界

D246 已有 Q-tail 与 top-two 全父对判据，本轮不重记。新增项目结果是共同来源覆盖项、按组 union 的完整推导、线性计算及上述严格比较。没有外部新颖性或 PLDI 贡献已成立的声明。

完整系数 C/v/w、可靠范围、稳定折叠、规范列身份和组覆盖证明的生成成本不包含在 O(m+g) 扫描内。实际 Conv/BN、边界 padding、参数误差、原 H、全部消费者、终端、见证及 host/device 共存都仍付账。本文没有源码候选或数值执行，不授予数学组件或真实来源资格。
