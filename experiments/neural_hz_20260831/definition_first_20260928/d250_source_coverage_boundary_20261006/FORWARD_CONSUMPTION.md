# 混合关系的前向消费公式与重复研究边界

混合相位关系可以无 LP 地消去六个产品观察，得到两条原坐标仿射包络；但这一消费方式是既有有效行的固定推论，不是新的域定义。本轮保存一般公式及其代价，不再为同一个小型正控新建组件或宣称新的能力。

## 固定代数消元

沿用 D244/D245 的归一化 x_i、q_i、原位视图 alpha_i，以及 a_i、b_i、tau、完整 r/e 与可靠范围。定义

```text
P_i=alpha_i-q_i,  N_i=1-alpha_i-q_i+x_i,
d_i=P_i+N_i,  Dp=2-d1-d2,
A=(a1+a2)/2,  H=(a1-a2)/2,
m=(Lr+Ur)/2,  R=(Ur-Lr)/2,  h=alpha1-alpha2.
```

对标量 v，v_plus=max(v,0)，v_minus=max(-v,0)。在原 mixed 守卫已成立的前提下，现有关系蕴含

```text
 Y1-Y2 <= (tau+m)*h + A_plus*d2 + A_minus*d1
           +H_plus*Dp+H_minus*(P1+P2)
           +(b1)_plus*q1+(b2)_minus*q2
           +2*tau*P2+R+2*max(Ue,0),

-Y1+Y2 <= -(tau+m)*h + A_plus*d1 + A_minus*d2
           +H_minus*Dp+H_plus*(P1+P2)
           +(b1)_minus*q1+(b2)_plus*q2
           +2*tau*P1+R-2*min(Le,0).                       (3)
```

证明记原 T=q1-q2+c12-c21、U=q1+q2-c12-c21。已有容量给 -d1<=T<=d2、U<=Dp；MC 还给 U>=-(P1+P2)，不能偷用没有登记的 U>=0。两个 x 项之和恒为 A*T+H*U，按 A/H 符号得到 (3) 对应项。

交叉 q 产品的 MC 给 0<=q1-d21<=q1、-q2<=d12-q2<=0，故 b 项分别按固定符号界定。对 v_i=alpha_i*r，把 v1 的两条上界和 v2 的两条下界各取一半，直接得到 v1-v2<=m*h+R；对相反差同理。加入原 defect 行即得 (3)。没有乘子搜索、相位枚举或事后读 LP 状态。

## 能提供什么与仍不能提供什么

(3) 可在关系建立时一次编译，两行在独立物理 x/q/alpha/Y 坐标下至多 16 个非零项、零新增辅助列。它不是原 29 行的精确投影；删除原产品行后可能失去其他查询方向的精度，不能直接替换 D245/D249 的完整因子。

对一个后继 w1*Y1+w2*Y2，恒等分解为 ((w1+w2)/2)*(Y1+Y2)+((w1-w2)/2)*(Y1-Y2)。有证上下式可按系数符号前向消费，sum 项和其余消费者仍须完整处理。所有来源和 skip 必须先按共同身份合并，再取可靠界。仅把 (3) 追加为 LE 不会让现有 sparse_hz_fast_bounds 自动读取它；自动消费、共享 P/N 身份及完整多消费者组合都仍需实现与证明。

D244 的对称 F_lambda 证书可由这些同样的行恢复，但这不是新强参照分离。D061 已有同源仿射包络进入下一 ReLU，D214 已有混权关系的代数消费；重新包装为支持摘要不会解决真实宽层的来源缺口。因此本轮不为此建立新的 runner。

完整来源提取、Gram、r/e 界、native 展开、每个消费者及舍入误差不能从上述两行费用中省略。该前向式依赖原守卫，不能在来源覆盖证书判拒后作为补救路径。是否采用它应由完整真实结构的能力与费用证据决定，而不是小型控制通过数。

## 外部先例

本轮重新核对 [Sharp Hybrid Zonotopes 原文](https://arxiv.org/html/2503.17483v2)：RLT 条件产品与保留整数具体化已有直接先例。联合神经元关系也已有 [k-ReLU 原文](https://proceedings.neurips.cc/paper/2019/file/0a9fdbb17feb6ccb7ec405cfb85222c4-Paper.pdf)。这些文献用于限制新颖性声明，不证明本项目的完整实现已健全或可扩展。本轮推导与上述先例的实质区别仍不足以单独构成新域贡献。
