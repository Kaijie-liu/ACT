# 普通网络控制与真实结构费用

本页给出两个精确有理纸面控制。第一个说明系数点不是顶点也可能保全完整输出，但收益可被旧仿射操作解释；第二个说明有限系数盒会丢掉普通后继性质。没有执行采样、枚举、模型或求解器，这些不是新增测试或真实网络成绩。

## 五门混权输出与残差的精确控制

输入 u 属于[0,1]，Affine 产生同源 z=(u,1-u)。源域 P 为 z>=0、z1+z2=1。令：

```text
a = (1/4,1/2,3/4,1/3,2/3),
k = (1,2,4,3,5),
g_i = (1+k_i)z1 + k_i z2 - (k_i+a_i) = u-a_i,
q_i = ReLU(g_i),
R_plus = q1+q2+q3,  R_minus = q4+q5,
Q = R_plus+R_minus, B = R_plus-R_minus,
J = B-z1/3, h=ReLU(J).
```

Q、B 及同源 skip 是完整活接口，没有被省略的独立 q 消费者。保留全部5个出生原 bits、后继原 bit 及弱 guards。候选系数坐标为：

```text
theta=(p,a,k,n,b),
p=beta1+beta2+beta3,
a=beta1/4+beta2/2+3beta3/4,
k=beta1+2beta2+4beta3,
n=beta4+beta5,
b=beta4/3+2beta5/3.
```

这里标量 a、k 与上面的参数向量按上下文区分。取统一有界外包 T_hat=Z_plus×[0,7]_k×Z_minus，其中：

```text
Z_plus:
   0 <= a-p/4 <= 3/4,
-1/4 <= a-p/2 <= 1/4,
-3/4 <= a-3p/4 <= 0;
Z_minus:
   0 <= 2n-3b <= 1,
   0 <= 3b-n <= 1.
```

这12条LE包含 A[0,1]^5。前一六边形是三向量(1,1/4)、(1,1/2)、(1,3/4)之盒像；后一平行四边形是两个不同阈值向量的盒像。完整输出定义为：

```text
R_plus  = -a-k + W_p1 + W_k1 + W_k2,
R_minus = -n-7b + 2W_n1+6W_b1+W_n2+6W_b2.
```

源 EQ 提升 W_:1+W_:2=theta 使其精确化为 R_plus=-a+W_p1、R_minus=-b+W_n1。

在普通严格点 u=3/5，g=(7/20,1/10,-3/20,4/15,-1/15)，beta=11010，theta=(2,3/4,3,1,1/3)。两组阈值系数都处于各自多边形顶点，但 k=3 在(0,7)内部，所以 theta 不是 T_hat 顶点。两个面方向分别为 span(e_k)、span((1,-1))。

canonical W=theta(3/5,2/5)可增加 X=(1/10)e_k(1,-1)。k 行由(9/5,6/5)变成(19/10,11/10)，乘积并不精确；所有非 k 系数行的 hX 都为0，k 的两个 slack 为4、3，源非负 slack 为3/5、2/5，对应最小正积6/5大于扰动1/10，所以全部24条LE乘积与源EQ提升仍成立。所有输出消去该误差：

```text
R_plus=9/20, R_minus=4/15,
Q=43/60, B=11/60, J=-1/60, h=0.
```

这不限于一个点。对每个严格合法 u，方向(u,-1)唯一暴露各组合法阈值相位的(p,a)或(n,b)，所以误差仅可能在不被完整输出消费的 k 方向。所有阈值不同，零点的两种合法标签也各有邻近严格实现，分别对应相邻的系数顶点，均具有顶点性；因而这个普通一维全父域控制保持完整输出精确。后继 h 消费相同 J，无需辅助验证器。

但它不是新能力：直接代入 z2=1-z1 就把 g 化为 u-a_i，旧 HZ 同样精确。A 的两个块行列式为1/4、1/3，故 rank A=5，完整 T 原本仅10个面；这里的外包有12个面，反而更多。采用源非负2LE及1EQ的最简表示，仍有10个 W、24条联合LE、5条源EQ提升，另有5个 theta 定义EQ、全部 guards、父域与输出。若机械保留四个盒界则联合LE为48，冗余源上界不应收费两次冒充必要下界。原逐门图只需5个新幅值与约15条非界LE及非负界，不能把此控制宣称为成本胜利。

## 有限系数盒损失普通后继性质

取 x,y 属于[0,1]，两个新门与完整消费者为：

```text
g1=x+y-1/2, g2=2x-y-3/4,
q_i=ReLU(g_i), M=q1+q2, B=q1-q2,
h=ReLU((M+B)/2-x-y/2-1/40).
```

因为 q1<=x+y/2 在整个盒上成立，真实 h 恒为0：active 分支差为(y-1)/2<=0，inactive 分支由 x,y>=0 成立。这是旧源约束可以廉价给出的性质，不是新的候选专属证书。

令 theta=A beta，A 的两行为(1,2)、(2,1)，有限外包 T_hat=[0,3]^2。按 M、B 的行顺序，精确系数分解的偏置、x列、y列读出矩阵为：

```text
F_b = [ -1/3 -1/12;   2/3 -7/12 ],
F_x = [  1    0;     -5/3  4/3  ],
F_y = [ -1    1;      1/3  1/3  ].
```

在(x,y)=(1/4,1/2)、beta=10、theta=(1,2)时，g=(1/4,-3/4)均严格非零。共同变量取：

```text
W = [ 7/20 7/10;
      7/10 7/5 ].
```

它满足全部盒源与盒系数联合行，theta、z 均为内部点。具体检查每个 W_ij 的范围为 max(0,theta_i-3(1-z_j)) 至 min(theta_i,3z_j)，四项均在其内部。完整读出得到 M=B=11/20，而真实 M=B=1/4。甚至 q>=0、q>=g、q<=U beta 三类常见后果也未排除此点；完整旧逐门关系则会排除。

候选因此允许后继 h=1/40，而真实全盒 h=0。这个控制说明有限关系可能丢失有用的同源抵消，不能用“辅助乘积不必精确”跳过完整输出检查。补回已知 q1<=x+y/2 可修这个控制，但不等于获得 Neural-HZ 创新或普遍修复。

## 真实卷积接口没有免费低秩或源等式证书

已有[D178 完整接口](../d178_reference_observed_fiber_20261004/REAL_FRONTIER.md)、[D179 结构报告](../d179_preterminal_domain_20261004/RESULTS.md)和[D181 接入审计](../d181_shared_coefficient_frontier_20261004/REAL_BINDING_AUDIT.md)只认证三个 late 链的拓扑和形状，尚未认证其实际 L、完整 B、rank G 或物理父源的非平凡相位无关 EQ。

父 skip 和 producer 输入是同一张量。若人为复制为 z、p，可写 p-z=0；去掉复制后仍是原 k 维，不会得到源内部降维。Add 定义也涉及两条支路，不能直接解释成 z 单独满足的等式。原始输入维数较小不自动限制所有相位像的仿射包维数。

对曾考虑的统一局部补边策略，可以直接算出费用：每个 channel 中不重叠水平邻源对，对每个真实消费者安装4个固定系数方向，并消费两个源坐标；每组4×2×2=16LE。

| 前沿 | 源对数 | 真实消费者 | 该策略新增LE |
| --- | ---: | ---: | ---: |
| CIFAR large | 256×4×2=2048 | 100 | 3276800 |
| CIFAR medium | 128×4×2=1024 | 100 | 1638400 |
| Tiny medium | 128×7×3=2688 | 200 | 8601600 |

Tiny 每行最后一个坐标在此规则下不配对。表中是未做认证去重/消元的生成行数，尚未计 theta/moment 定义、全部 guards、旧谓词、输出和终端；不是任意稀疏关系的下界，也不是测得速度。它足以否定“每组只有16行，所以完整实际图便宜”的说法。

本轮据此不实现“完整 W 加所有局部补边”方案，也不把未认证的源 EQ 或低秩当作支付。下一定义候选需要直接处理完整消费者可见的相位源关系，证明其比逐源全产品更紧凑且仍有同预算验证价值；不能继续从窄输出维数直接推断便宜。
