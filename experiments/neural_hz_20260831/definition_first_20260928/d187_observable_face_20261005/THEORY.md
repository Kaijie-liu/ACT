# 联合相位源关系的完整输出精确性

本研究把此前“系数顶点保证共同乘积精确”的充分条件，推进为完整输出精确的充要条件：允许存在辅助乘积误差，但其全部可行方向必须被所有实际消费者同时消去。结论覆盖有等式的有界源域，不要求系数点或源点处于顶点。

这是对[联合系数候选](../d186_joint_coefficient_source_20261005/DEFINITION.md)的纸面定理，不是新实现或网络能力阳性。它还给出两个限制：源等式消除的冗余可由普通仿射重参数化同样消除；若完整源系数读出没有不可见方向，非顶点精确并不能成为省掉共同乘积的捷径。

## 域与适用范围

原父域 S、连续源、所有原 signed bits 及其认证 0/1 视图 beta、弱 guards、共享 frame、EQ/LE 和输入 decoder 全部保留。采用此前精确分解 G=FA、theta=A beta，r=rank G，完整消费者包括所有活读出与保留谓词所需读出。正质量行只在后文 rank 结论中额外使用，若加入必须计费。

两个非空有界多面体分别为：

```text
T_hat = {theta : H theta <= d, E theta = e},
P     = {z     : J z <= s,     N z = t}.
```

T_hat 包含 A[0,1]^m；P 覆盖整个当前父域的 z，且不依赖新旧相位赋值。P 可以有源等式，但不能把含 bits 的父谓词直接当作 P，否则需要未计入的额外乘积。

原生共同变量 W 为 r×k，保留所有 LE×LE 行及两族等式提升：

```text
d s^T - d (Jz)^T - (Htheta) s^T + H W J^T >= 0,
E W = e z^T,
W N^T = theta t^T.
```

完整第 o 个输出是关于旧父量、theta、z 的仿射式，加上 <K_o,W>；内积为逐元素乘积之和。canonical 赋值 W=theta z^T 给真实新生 ReLU 输出，证明全父域包含。原整数相位没有被连续放松；采用单门完整 T 的特例仍精确嵌入 ReLU 图，保持域族的非凸性论证，但任意放松的 T_hat 不自动获得单门精确性。Affine、Conv、Add、Concat 共用同一 W，不能各自选择见证。

以下充要性只针对上述共同 W 关系。固定父赋值后，S、theta=A beta 和 guards 不再限制 W。如果另加依赖 W 或输出的 caps、能量、其他 bank 联结，充分性仍可沿用，但必要性必须重证；不能声称下面描述了任意强化后的误差集合。

## 可行误差的方向空间

固定合法 theta、z，定义：

```text
X = W - theta z^T,
sigma = d-Htheta >= 0,
tau   = s-Jz >= 0.
```

全部原生关系恰变为：

```text
E X = 0,   X N^T = 0,
H X J^T >= -sigma tau^T.
```

令 I、B 分别是 sigma、tau 的零坐标集，定义 theta、z 所在最小面的方向空间：

```text
V_theta = ker([E; H_I]),
V_z     = ker([N; J_B]).
```

这里的最小面是包含该点的最小面，不是只指整个多面体的顶点。即使给出的 E 或 N 没有列全隐含等式，tight LE 也会补足它们。

命题：每个可行 X 都在 V_theta 与 V_z 的张量积空间内；可行 X 集在这个空间中包含原点的一个相对邻域。因此，其线性张成空间恰为：

```text
{ U_theta Z U_z^T : Z arbitrary },
```

其中 U_theta、U_z 的列分别是两个方向空间的任意基。

证明分两步。若 sigma_a=0，令 h 为 H 的该行，则 J(-X^T h^T)<=0、N(-X^T h^T)=0。这个向量属于 P 的衰退锥；P 有界，故 hX=0。对 tau_b=0 对称使用 T_hat 有界，得到 X J_b^T=0。再结合 EX=0、XN^T=0，得到张量积包含。

反向局部包含：对张量积空间中的任意 X，只要某侧行 tight，对应 hXj^T 就是0；其他行在 X=0 的裕量 sigma_a tau_b 严格为正。行数有限，故足够小的正负扰动同时满足全部行。没有 LP 求解、对偶证书搜索或相位切分参与这个论证。

## 完整输出判据

固定 theta、z 后，第 o 个输出与 canonical 输出之差为 <K_o,X>。由上一命题：

```text
全部输出对所有可行 W 精确
  iff 对每个完整消费者 o，U_theta^T K_o U_z = 0.
```

充分性来自所有可行误差都处于该张量积；必要性来自它在原点附近有双侧可行扰动，任何非零读出都能改变输出。不能只检查质量和或最终性质方向而漏掉另一个活消费者。

theta 为顶点或 z 为顶点时，一侧方向空间为零，恢复此前的充分条件。若源是盒子，V_z 恰由内点源坐标轴张成，判据退回每个内点源列的误差都必须被完整输出消去。一般源 EQ 则确实允许跨列抵消。

这是同一套原生谓词的语义定理，不是依据当前 LP 状态选择另一条验证路径。全父域精确需要对全部合法父赋值满足判据；一个固定源点通过不能代替该证明。下一 ReLU 仍须作用于整个当前抽象父域；若这里只证明误差界，不能把后继原相位误当作 canonical 轨迹的相位。

## 源等式消除与旧仿射操作完全同构

取 Nz=t 的一个解 z0，U 满列秩且列空间为 ker N，写 z=z0+Uu。源等式提升恰好允许且唯一地写成：

```text
W = theta z0^T + Y U^T.
```

代入后，源多面体为 J_u u<=s_u，其中 J_u=JU、s_u=s-Jz0；共同关系正是 T_hat 与这个重参数源之间关于 Y 的同一 RLT 系统。系数等式变为 EY=e u^T。输出矩阵从 K_o 变为 K_o U，另有关于 theta 的线性项。残差满足 X=(Y-theta u^T)U^T。

因此，源 EQ 带来的跨列抵消与先做精确 Affine 重参数化完全同构。它有助于正确实现，但不能单独作为新域强于原 HZ 的证据；原 decoder 和共享身份仍须保留，不能把冗余坐标消元误说成删除原二元因子。

进一步，若 theta、z 都在各自多面体的相对内部，精确条件使用完整仿射包方向 U_T、U_P。若 U_T^T K_o U_P=0，则在整个仿射包上有：

```text
theta^T K_o z
 = theta^T K_o z0 + theta0^T K_o z - theta0^T K_o z0.
```

这项双线性读出实际上已退化为仿射读出。不能将这种内部精确控制当成保留了新的非线性交互；这里用的是完整仿射包的等式，未必仅由文本中显式 E、N 的行列出。

## 完整读出限制了可隐藏的方向数

将满列秩 F 按偏置与源系数分为 F_b、F_s，尺寸分别为 p×r、pk×r。对内部满维源，所有消费者共同看不见的系数方向是 ker F_s。F_b 在这个核上必须单射，否则 F 不是满列秩，故 dim ker F_s<=p。

若 C 含系数 c_i>0 的质量行，F_s A 中包含子矩阵 L^T diag(c)。由于 A 满行秩，得到：

```text
rank(F_s) = rank(F_s A) >= rank(L).
```

特别地，若 producer L 满行秩 m，则 r=rank(F_s)=m，完整输出没有不可见系数方向。在满维源内部，输出精确要求 theta 本身为 T_hat 顶点。此时 k>=m，直接共同 W 至少有 m² 个量，而原逐门图只需 m 个新幅值。完整 T 是可逆 A 作用下的 m 维盒，虽只需2m个面，也不能使全 W 展开变得紧凑。

这只是否定该直接表示的一条捷径，不是任何 Neural-HZ 的下界。真实 CNN 的 rank(L) 尚未认证，不能把“结构允许满秩”写成已测满秩，也不能从较窄输出 p 推出 r 很小。未读出的 W 分量可能通过联合行约束已读出分量，删除它们仍需精确投影，不能直接丢行。

## 有限关系的静态误差证书

若在结构冻结时已给出非负矩阵 Lambda_plus，并认证：

```text
K_o = -H^T Lambda_plus J + E^T R + S N,
```

则 <K_o,X><=sigma^T Lambda_plus tau。若 K_o=H^T Lambda_minus J+E^T R'+S'N 且 Lambda_minus>=0，则相应下界为 -sigma^T Lambda_minus tau。证明只需对原生乘积行作固定非负线性组合。

这不是 LP dual rescue，也不要求或允许从当前解的对偶生成证书；未给出廉价结构分解时，不能假定它存在且免费。sigma^T Lambda tau 仍含 theta 与 z 的乘积，不可直接假装是一条线性 native 谓词。若要常量误差界，须另有已认证且计费的 slack 上界 bar_sigma、bar_tau，得到相应固定上下界。系数分解、证书存储、非零数、界构造和终端消费全部计入。

当前没有证据表明这些误差界在 CIFAR/Tiny 足够小。它们比较的是当前父赋值的 canonical ReLU 与新读出；若父域已经有损，不能据此宣布与原始具体网络一样接近。
