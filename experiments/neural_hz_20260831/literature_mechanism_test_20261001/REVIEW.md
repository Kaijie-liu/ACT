# 用跨领域研究检验 Neural HZ 的定义候选

应当借鉴 HZ 之外的研究。当前最需要的不是再收集一份验证器名单，而是回答三个定义问题：哪些共同关系值得成为域元素，关系怎样穿过下一非线性，以及保留这些关系是否付得起完整成本。本次核对已有综述和一手文献，将结论落实为一个新颖性定位、一条有范围的无增益证明和一个尚未实现的宽混合层构造。

这不是首次开展跨领域阅读。[已有综述](../literature_gap_decision_20261001/DECISION.md)已包含抽象解释、控制、析取优化、热带表示、混合符号和数据库。下面区分论文事实、项目推断与本轮纸面结果，不把重读算作创新或正式提分。

## 优先借鉴的四类机制

### 抽象解释提供共同观察与信息交换的语义

论文事实：[Cousot 等的 observational reduced product](https://pcousot.github.io/publications/CousotCousotMauborgne-FoSSaCS11-LNCS6604-proofs.pdf)，§4.1、Definition 4，以具名观察连接抽象组件，并强调仅并列共享观察并不足够，还需要有效的信息交换。

项目推断：从普通 Conv、ReLU、混权后继和残差的需求反推关系语言。域元素必须指明原输入、相位和值的共同身份，并给出前向变换；不能只说“保留了关系”，却在下一层把每个读出重新变成独立区间。借鉴这种设计方法不要求引入 SMT 组合求解器，也不额外要求完整格或全网最佳抽象。

### 析取优化解释共同相位关系与消元代价

论文事实：[Anderson 等](https://arxiv.org/pdf/1811.01988v4)，§1.1、§3，研究 Cayley 扩展及其投影，并指出逐门 ideal 不保证组合后 ideal。[Tsay 等](https://arxiv.org/pdf/2102.04373v2)，§3、Proposition 1，把一个加权和按输入项分组，展示辅助量与投影后指数数量约束的取舍。这里的分组不是划分输入空间。

项目推断：原相位及共享辅助关系不能在各消费者处分别消元后假定联合等价。另一方面，少变量不是总成本更低的充分证据。可以借静态扩展表述与联合投影，不能将其 OBBT、LP 点驱动切割、动态分离或 MIP 搜索引入为本项目的救援路径。

本轮定位：[共同相位表](../definition_first_20260928/d065_shared_phase_tables_20261001/THEORY.md)可以精确改写为四个状态输出盒的共同混合权重。这是经典机制的实例，且不是原网络源与 guards 的完整联合凸包。详见[纸面审计](AUDIT.md)。共享 delta 有用不等于它本身具有新颖性。

### 控制理论提供跨神经元和跨层的关系内容

论文事实：[Fazlyab 等](https://arxiv.org/pdf/1903.01287)，§III-C.3、式15，利用重复非线性的增量斜率联系不同激活。对 ReLU，令 d=ReLU(g)-ReLU(h)，有 d*((g-h)-d)>=0。它不是两个独立范围能完全表达的事实。

项目推断：用这些已有关系审查我们的解析正控，避免只战胜弱对照。研究其哪些内容能形成有证明的、结构统一的前向 Neural HZ 规则；不整体迁入 SDP，不按某个松弛点的符号选择全域线性分支。二次关系有效不等于当前终端已有廉价实现，全部配对也不是免费操作。

### 混合符号与热带表示帮助检验语言选择

论文事实：[Combastel 的 typed polynotopes](https://arxiv.org/pdf/2009.07387)，§3.3–3.6，已采用具唯一身份的连续、signed 与 Boolean 符号，以及保持依赖的函数组合。因此共享符号、相位多项式或 eager/lazy 求值本身并不是我们的新贡献。[Goubault 等的 tropical polyhedra](https://arxiv.org/pdf/2108.00893)，§3–4，研究适配 ReLU 的非凸关系表示，但普通线性计算仍有抽象损失，终端线性性质查询也须单独处理；§5 的输入细分不直接采用。

项目推断：借鉴让激活成为自然操作的语言设计，但同时检查混合正负权重、Add 和终端查询。仅让 ReLU 公式漂亮、将成本移到 Conv 或巨大多项式展开，不构成成功。这里不建议用多项式域或热带域整体替换 HZ。

## 本次研究实际排除了什么

第一，共同四状态混合是已知扩展表述，不能包装成新逻辑原语。原二元相位仍使完整载体非凸，但新颖性应来自可构造的关系语言、神经算子变换或有意义的精度与成本定理。

第二，对一个明确强对照，本轮证明“先把其他门全压成独立残差区间，再生成上侧条件表”没有额外收益：当前缀已满足完整两原门的共同源与相位凸包、后继满足精确 ReLU 时，同一个原混合分布已满足所有这类上表。该结论不适用于分数 big-M 后继，也不适用于 ReLU 截断后的下表，更不否定较弱原生 LP 可能被它加强。证明和两个例外均存于 AUDIT.md。

第三，保留其他门的共同源仿射贡献，可以构造适用于任意符号锚权重的四个全盒支持证书。纸面健全性已复核；这仍只是已有条件关系的生成方式，没有真实宽网络的非冗余、速度或定义创新证据。没有为它先启动一轮组件框架或模型运行。

## 下一项可被反证的研究问题

优先研究普通混权 Conv 或 Affine → ReLU → 混权后继 → ReLU 与共享残差合流，不以特殊反对称权重或数值极端作为主要正例。

候选需要明确域元素和具体化，保留连续因子、全部原二元相位、EQ/LE、共享 frame 和输入 decoder。要问的是：有限关系对象能否保留足够的状态内部共同源信息，支持下一非线性或合流的健全变换，并使同样标量界下仍无法证明的性质可证？这不是要求任意网络无损闭包，也不是要求超越精确 HZ 的表达能力。

最低交付是一个定义、一个范围明确的传播或简化命题、一组普通结构强对照，以及包含构造、证据、传播、终端编码和重构的完整账单。必须比较原 HZ 加同样关系、适用的分组表述及已有跨门关系；不能把重新排版相同行当作精度增益。数学候选成立后，再冻结默认关闭实现并依次进入真实同结构、shadow、逐家族与完整回放。
