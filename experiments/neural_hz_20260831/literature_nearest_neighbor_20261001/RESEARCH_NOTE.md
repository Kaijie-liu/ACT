# Neural HZ 的跨领域近邻与研究优先级

需要跨领域研究，但应围绕定义问题筛选机制，而不是继续堆积论文或把已有机制重新命名。本轮补核一个直接的神经验证近邻，并复核程序分析、控制、数据库与编译器的相关原文。结论是优先研究同一原相位内部的共同连续源关系，以及它在下一激活和残差合流中的可组合使用；不是再次启动存储压缩或通用重写框架。

这是有范围的机制综述，不是系统性综述或新颖性认证。[既有综述](../literature_interface_decision_20261001/REVIEW.md)已经覆盖多数方向，本轮不将重读算作新发现。下面分别标明论文事实与项目判断。

## 需要补入的直接比较对象

论文事实：Combastel 的 [Functional sets with typed symbols](https://arxiv.org/pdf/2009.07387)，本轮读取 v2，§3.3至3.4，已经用具唯一身份的连续、signed 和 Boolean 符号表达混合依赖，并区分符号表达与集合解释。因此，增加相位多项式、共享身份或惰性求值本身不是新贡献。

论文事实：Trapiello、Combastel、Zolghadri 的 [Verification of Neural Network Control Systems using Symbolic Zonotopes and Polynotopes](https://arxiv.org/pdf/2306.14619)，2023预印本 v1，§II、§V，已将共享符号与多项式依赖用于神经控制系统。§V的激活处理采用多项式外包加误差符号，不是保留全部原二元相位的精确 ReLU 图；§VI另含输入划分。

项目判断：这个近邻使比较更具体。我们可以学习依赖怎样在模块间保留，但不能整体采用其域、误差替换或输入划分路径。Neural HZ 必须说明：原相位、EQ/LE 与输入重构如何保留，关系如何被后继实际使用，以及比已有混合符号表达多出的结构定理是什么。仅说“非凸、符号化、面向神经网络”不够。

## 跨领域机制如何分工

程序分析用于定义关系交换。论文事实：[Cousot 等的 observational reduced product](https://software.imdea.org/~mauborgn/publi/fossacs11.pdf)，FoSSaCS 2011，§4.1，通过具名观察与约化交换信息；共享名字本身不足以获得同样精度。项目判断：定义应说明相位、源和读出的共同语义及前向变换，不是给 HZ 旁挂一个无人消费的表。已有 reduced product 不是我们的创新。

控制理论用于选择关系内容。论文事实：[Fazlyab 等](https://arxiv.org/pdf/1903.01287v2)，§III-C，式15至17，用重复非线性的斜率关系联系不同神经元。对同一赋值中的 ReLU 输出差 d 和输入差 delta，有 d*(delta-d)>=0。项目判断：借关系而非照搬 SDP；还须证明允许的前向表达如何使用它，不能按某个松弛点的符号选分支，也不能把该经典关系声称为新定理。

混合整数表述用于比较精度与代价。论文事实：[Tsay 等](https://papers.nips.cc/paper/2021/file/17f98ddf040204eda0af36a108cbdea4-Paper.pdf)，NeurIPS 2021，§3及 Proposition 1，按输入项分组，展示辅助变量与投影行数之间的交换。项目判断：静态项分组不同于切分输入空间，但直接复制已有 lift 仍不是新域；不迁入其优化式界收紧或搜索。

数据库与图模型用于检查共同作用域及遗忘。论文事实：[Olteanu 与 Závodný 的2011作者预印本](https://arxiv.org/pdf/1104.0867)，§6 Definition 6与 Figure 3，将相关属性放在共同祖先条件下组织因子；这是有限关系理论。[Dechter](https://ics.uci.edu/~dechter/publications/r76A.pdf)，1999，§2.1至2.3，以合并相关约束后投影组织消元，并明确连续不等式消元不能只用图宽度控制复杂度。项目判断：只能借作用域和组合原则，不能把离散枚举或有限表大小界直接迁入连续 Neural HZ。

编译器用于管理已证明的等价式。论文事实：[egg](https://homes.cs.washington.edu/~cnandi/docs/popl21-cr.pdf)，POPL 2021，§4给出分析约束的重写；§4.3的高效提取结论针对局部成本。项目判断：某相位下相等不能无条件合并，输出相等不能删除原 bits；表达式节点少不证明终端查询便宜。暂不搭建 e-graph 或决策图框架。

## 收敛到一个定义问题

研究普通混权、非零偏置、共享输入的 Conv 或 Affine、ReLU、多个后继及残差 Add。问题是：能否定义有原身份绑定的非凸关系元素，让多个后继共同使用相位内部的连续源关系，并给出健全传播及精确遗忘条件，而不保存或重新展开整张未简化网络图？

现有[跨层分析](../definition_first_20260928/d059_cross_layer_interface_20261001/THEORY.md)已将条件观察 lift 定位为已有 RLT/析取技术。[相位一致性分析](../literature_interface_decision_20261001/REVIEW.md)进一步表明，完整相位分布一致仍可能缺少共同连续见证。这不是原精确 HZ 丢失关系，而是限制局部松弛及接口的充分性。

已有[固定配对审计](../definition_first_20260928/d067_fixed_pair_applicability_20261001/RESULTS.md)在完整1440对中没有找到双未定真实锚，关闭的是该归档当前固定配对上的额外共享 delta 收益路线。它没有证明稳定相位后的连续源可以独立，也没有否定整个 Neural HZ。

下一交付应是域元素、具体化及一个普通结构上的可反证组合或消元命题，明确与原 HZ 加相同关系、混合符号表达和适用分组 lift 的差异。比较应区分首块标量界改善与关系传到后继的额外价值。所有传播、谓词、终端编码、共享存储和反向重构成本都计入；GPU 批处理只是实现目标，不能替代语义或实测。

不新增必须全局 ideal、必须任意深度闭包或普遍 nnz 下降的要求。若只有已知等式重排或换名，就保存为支撑成果，不启动另一套同类组件实现。形成明确候选后，仍按现有预注册、默认关闭、数学到真实同结构到 shadow 到逐家族及全量回放推进。
