## Theorem and authority

The independent C10 original-DAG proof establishes, for every generated MAIN
factor, sum(abs(parent coefficients))+sum(abs(binary coefficients))+abs(h)<=a
in its logical defining row a*x_j+P+B=h. Exact positive dyadic row scaling
preserves the inequality. C10 quotient substitutes only independent aliases
x_k=r_k*x_parent with abs(r_k)<=1. Each coefficient's absolute contribution
can only decrease; exact collisions satisfy the triangle inequality. A
surviving MAIN pivot is unaffected because all substituted parents precede it.
Binary terms and RHS are unchanged. Thus the bound transfers to every surviving
DIRECT physical MAIN definition, without rescanning its coefficient vector.

An authenticated canonical physical row whose last continuous column is its
registered MAIN column has no radix link (radix columns follow ALL MAIN slots).
Non-direct/radix-root rows receive NO claim. Erased aliases have their previous
independent extension proof; they are not falsely counted as direct definitions.
A transferred bound alone does NOT prove output-deadness, sole consumption,
exact RHS addition, simultaneous independence, memory reduction or eliminability.

Do not accept hz.exact=True as proof. A receipt requires SHA-verified independent
all-row original-DAG and quotient proof, all-MAIN coverage, physical lineage,
and the established C10 ALL-source/operator/content/sharing portable binding.
The expected artifact hashes are an enclosing preregistered trust boundary,
not a family/iid dispatch condition. The receipt contains scalar hashes/frame
metadata only; no retained old HZ or numerical certificate arrays. Tests cover
incomplete/forged flags, wrong hashes, resealed HZ changes, source/phase mutation,
hidden receipt payload and mid-transaction mutation. Queries use only constant-
size row metadata/pivot; independent Fraction norms are external proof oracles.
