## Exact producer identity

C96 already constructs raw input forms as triples (original column, +/-1,
binary exponent). For a multi-parent form with distinct columns, sort by actual
column, remove only the leading sign and common leading exponent, and use the
ENTIRE remaining tuple as the key. Equal keys prove one raw form equals a signed
power-of-two multiple of the other. Different original IDs cannot compare equal.
Forms outside the distinct-column/signed-unit precondition remain independently
emitted under all unchanged native guards; they are never guessed equivalent.

Choose the greatest leading exponent as representative, ties by original key.
Create exactly one normalized definition with the unchanged C96 _emit_row.
The vmap for each alias refers to that same slot with its exact relative sign
and exponent. Every M/output consumer applies this route before native row
generation. The original _row and _emit_row source texts, including existing
tariffs, are tested identical. A shared factor is tied to the same original
coordinates, not copied into independent uncertainty.

Every retained generated equation is an exact uniquely defined normalized
extension of its parents. Independent literal polynomial substitution projects
both complete old/new circuits onto the same original spatial convolution,
including nonzero original centers/bias. Original source continuous coordinates,
EQ/INEQ, phase binaries and old scalar inverse are unchanged by identity.
Together with all row-box guards this gives equal projected genuinely nonconvex
HZ sets and unique extensions in both representations. Actual two-phase points
exercise all source predicates and old/new defining/output equations; these
points are not the universal proof itself.

Unlike C110's postpass, no auxiliary is first created and then discarded. Old
generated slots are comparator coordinates, not original network-input/phase/
frame coordinates. Runtime reconstruction retains all genuine original source
coordinates and its old inverse. An old auxiliary extension can be reproduced
by the frozen old program for proof; no old circuit or full alias map is hidden
in the exported new numeric payload. Original parameters remain in both payloads.
