## 从实际谓词统一绑定的候选规则

以下是数学上可解释、但尚未实现和测试的接入方案。

以不可变原始H0中的认证门为目录，复用D088的父门配对和子门分组。针对同一父门对对应的子门组，检查后继原始门预激活中实际出现的子门eta列；按固定列序处理完整关系，不查询实例标签、margin或LP状态。歧义列必须明确拒绝或按完整规则报告，不能从多个解释中挑有利者。不能把新增辅助门再当原始认证门。

若子门物理输出为q_j = Q_j(1 − eta_j)，后继预激活中eta_j系数为c_j，则观察权重必须取W_j = −c_j/Q_j。D088用于父门归一化幅值的−2c_j不能直接复用在这里。完整余项取g − Wq，保留全部偏置、其他连续项及二元项，交由D092的共同实现语义处理。代数恒等不表示条件约束没有用，也不自动证明会产生验证收益。

候选结构筛选为后继至少关联同组两个不同子门，并排除与父子门相位重复的后继。这个筛选只识别原生谓词关系；不能据此宣称已经认证ONNX拓扑、每个相位的全局可达性或网络具体语义。闭合H0中的共同扩展证明与实时前向传播接入是两项不同工作。

## 宽结构接口的成本问题

静态审查[D092实现](../definition_first_20260928/d092_native_observation_relay_20261001/native_observation_relay.py)发现：K个子门、P个观察及P个后继、C为单位映射时，当前稠密参数计数为KP + P² + 2K。combine在合并前计入包括零权重在内的仿射支撑；后继遍历全部观察，最坏可形成O(P²K)的出现次数。这是实现成本，不是新测得的运行时间。

可研究规范稀疏W和C接口：严格排序、唯一的非零索引与精确系数，隐式零，不改变共同实现和完整余项语义。单位C只存P个非零项，不需要特殊实例路径。但这尚未实现；需要新的隔离候选、冻结及完整继承测试，不能改动已消费D092。另一方案是逐后继调用，须计入重复复制H0、重复基础行和全部中间对象，不能仅因接口变小就判更优。

若一次处理全部P个后继，按每个非零余项均分配三个辅助变量估算，新增连续变量上界3 + 3K + 6P，新增LE上界12 + 9K + 17P。这些仅是行列上界，不含完整非零数、Fraction临时、CSR构造、根对象、证据、终端转换或GPU成本。不得用这些局部数替代完整费用。
