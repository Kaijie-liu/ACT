## 先分清我们已经知道什么

[上一份综述](../literature_cross_domain_20260929/REVIEW.md) 已涉及 ImageStar、DeepPoly、PRIMA、控制理论、混合整数建模、静态分析和消元。本轮进一步核对旧草稿，确认以下方向不能当成新发现重新启动：

- [混合符号与守卫模块](../definition_first_20260928/d006_guard_module_audit_20260928/D006_RESULTS.md) 已比较 mixed polynotopes、CPZ 和代数不变量。
- [相位与幅值审查](../definition_first_20260928/d011_phase_value_audit_20260928/D011_RESULTS.md) 已覆盖 tropical/DC 表示和公共因子消去，并指出平坦展开在普通满秩网络中可能指数增长。它还反驳了仅靠差分关系与 cycle 一致性替换原门的方案：绝对幅值锚点会丢失。
- [D016](../definition_first_20260928/d016_shared_secant_20260930/D016_DEFINITION_AND_PROOFS.md) 给出了条件性的精确压缩与残差组合定理，但需要既有源门满足 `g_r = g_s + c*g_h` 等条件。
- [D017](../definition_first_20260928/d017_applicability_gpu_20260930/APPLICABILITY_THEOREM.md) 给出排除上述恒等式的条件性秩证据。它没有完成真实网络普查，不能说已经证明 D016 在真实模型中不存在。

研究判断：现在的关键缺口不是再找一种能够表达网络的语法，而是找到在常见结构上有用、能组合、且完整付账后仍划算的关系。该判断不把精确 HZ 描述成丢失了相关性；精确混合整数语义本来能保留这些关系，问题在可负担的表示、前向处理和查询松弛。

## 可借鉴的机制与不能照搬的部分

### 控制理论中的重复非线性关系

Fazlyab、Morari、Pappas 的论文在 section III-C3、式 15–17 研究同一个非线性作用于不同输入时的斜率关系。对 ReLU，若 `d = ReLU(u)-ReLU(v)`、`delta = u-v`，有 `d*(d-delta) <= 0`。它不要求两个仿射输入成比例；若能证明 `delta >= 0`，则 `0 <= d <= delta`。[论文全文](https://arxiv.org/pdf/1903.01287)

可借鉴的是跨神经元保留幅值与共同源的关系，而不是逐个神经元独立包络。不能直接导入 SDP、对偶优化或全网两两关系，也不能用差分替换原绝对值与相位语义。旧 D011 已暴露后一个问题。因此这些关系是比较基线和构件，不是已获得的新域。

### 混合符号和非凸可达集

Combastel 的 mixed polynotopes 在 sections 3.3–3.6 明确区分连续、signed 与 Boolean 符号，并用唯一身份保持函数依赖。Kochdumper 与 Althoff 的 sparse polynomial zonotopes 在 Proposition 10 区分保留共同因子的 exact addition 与丢弃两集合依赖的 Minkowski sum。[混合符号论文](https://arxiv.org/pdf/2009.07387)，[SPZ 论文](https://arxiv.org/pdf/1901.01780)

启发是把共享依赖写进具体化与 Add/Concat 的语义，而不是只有存储层知道两个变量同源。多项式 zonotope 可以是非凸的，不等于被禁止的普通凸 zonotope；但整体替换 HZ、删除原相位同样不符合目标。共享 ID 和相位依赖生成元本身也已有先例，不能独立构成新颖性。

Kochdumper 等的神经网络论文用多项式与有界误差包络激活，说明非线性依赖可以被传播，也明确面对表示增长。其 open-loop 比较使用了递归输入 split，不能把该成绩用作我们无 split 路线的证据。[NFM 2023 论文，sections 3 与 6](https://arxiv.org/pdf/2207.02715)

### 强混合整数建模

Anderson 等的完整论文在 section 5.2、Propositions 12–13 给出一般混合符号仿射 ReLU 的 ideal formulation：保留单个原相位 bit，不增加连续辅助变量，但子集不等式族可能指数大。线性时间 separation 不等于能够预先免费保留所有约束。[Mathematical Programming 2020 全文](https://arxiv.org/pdf/1811.01988)

Tsay 等的 section 3、Proposition 1 将加权输入和分组并提升；投影对应上述已知不等式的选择。此处 partition 是代数求和分组，不是输入区域的搜索分割。仍须支付辅助量、谓词和终端开销，也不导入其 OBBT 或搜索流程。[NeurIPS 2021 全文](https://arxiv.org/pdf/2102.04373)

这两者是必须认真比较的对手：不能仅战胜逐神经元 big-M 就声称 Neural-HZ 定义创新。固定结构提升可以在我们的单路径内研究，但按求解点动态补救的切割循环不因阅读论文而获得授权。

### 分段仿射代数和小元数表示

Zhang、Naitzat、Lim 的 Proposition 5.6 将相关 tropical 表示推广到实权重；它启发成对保留凸分量之间的依赖，而不是分别求界。旧 D011 已研究这条路线，保留 DAG 也可能只是改写原计算图。[ICML 2018 全文](https://proceedings.mlr.press/v80/zhang18i/zhang18i.pdf)

本轮补充的 Koutschan 等工作在 Theorems 2.4 与 5.4 研究 max 基础元的最小必要元数；section 3 同时说明降低每个 max 的元数可能增加项数。这是局部关系设计的边界参考，不是低成本验证算法。不会为研究最坏情形展开新的实验，也不据此断言普通网络无法改进。[Small Arity 论文](https://arxiv.org/html/2305.16933)

### 凸松弛的组合限制

Mao、Zhang、Vechev 的 ICLR 2026 论文在 Theorems 3.3 与 4.2 给出其层级及跨层凸松弛框架的不完备性结果：增强有限范围的联合凸化并不自动恢复整个网络的非凸可达关系。[2026 版本全文](https://arxiv.org/pdf/2410.06816)

对本项目的启发是保留原非凸相位与跨块依赖，而非将每个块完全替换成凸包。这个结论不否定精确 HZ、不证明我们的候选有效，也不证明满分不可达。这里只用它约束创新声明，不围绕构造出的极端网络扩张研究主线。

## 一个普通两神经元正控

下面是本轮纸面推导并独立复核的已知机制正控，不是新算法、新定理或真实数据集实验。它说明问题不必依赖平行权重、零点特例或 D016 的三路精确关系。

```text
x, y in [-1,1]
g1 = x + y/4 + 1/2
g2 = x - y/4 - 1/2
q1 = ReLU(g1), q2 = ReLU(g2)
```

两行梯度行列式为 `-1/2`，不平行。区间分别为 `[-3/4,7/4]` 与 `[-7/4,3/4]`，两个激活都跨零。由于 `g1-g2 = 1+y/2 >= 1/2`，真实联合关系及其凸包都满足 `q1 >= q2`。

但在 `x=0, y=-3/4`，各神经元分别使用的完整单节点 ideal hull 允许：

```text
q1 = 5/16, beta1 = 1
q2 = 7/20, beta2 = 1/2
```

第一项是真实门点。第二项是以下两个合法第二神经元门点的各半混合：

```text
(x, y, q2, beta2) = ( 1, -4/5, 7/10, 1)
(x, y, q2, beta2) = (-1, -7/10,   0, 0)
```

两个源点的均值恰为 `(0,-3/4)`，但 `q2-q1=3/80>0`。因此逐节点 ideal hull 的交集仍允许这个违反联合单调性的点：相同的平均输入不保证各节点使用同一套混合解释。

这不反驳原 HZ 的整数精确性，因为第二个 bit 在该点是分数。添加已知的 `q1>=q2` 就可排除此点，所以仅通过此正控远不足以成为新域；它只确保候选研究的不是旧稳定门剪枝或弱比较对象。也不能据这一个例子推断 CIFAR/Tiny 上的结构出现率。

## 下一项研究应回答的问题

建议的定义级假设是：在不要求精确源三元恒等式、不枚举相位且不删除原 bit 的前提下，能否定义一种局部非凸关系元素，使普通 Conv/ReLU/后续仿射或残差块的共同源与相位幅值关系可组合地保留，并在完整终端编码后获得严格的精度成本优势？

“共同源与相位关系元素”目前只是待回答的问题，不是已经完成的 Neural-HZ 定义。它必须避免再次成为原计算图、mixed polynotope、联合凸包或 HZ 加已知约束的改名。不会复活旧 D011 已否定的差分加 cycle 替代方案。

下一阶段先交付一份有正反结论的数学候选说明，内容限于：

1. 域元素、具体化、原 HZ 嵌入、全部原始 bit（包括零点自由选择）、共享输入身份与具体见证重构。
2. Conv/Affine、ReLU、Add/Concat 的前向变换及普通多算子块的组合定理；哪些是精确的，哪些只是健全外包络。
3. 与原 HZ 加完全相同关系、已知单节点 ideal/分组提升、相同共享 DAG 的比较。不能只比最弱 big-M，也不能把全局正确性当免费 oracle。
4. 传播、相位谓词、辅助量、nnz、系数位宽、终端转换、查询与重构的完整代价。若新符号只是把成本推迟到终端，应如实否定。

只有候选说明给出实质区别，才开展新的默认关闭实现与预注册真实结构检查。GPU 的批量稀疏运算、系数检查和传播是实现方向，不构成定义创新证据；本轮没有获得新的 GPU 性能数据。

数学与真实同结构证据通过后，仍按既有 shadow、逐家族、全量 2413 和独立 400 的门逐级验证。不会因为文献启发而降低 1870 保底、13 家族逐家族零回退、61 外部旧解、invalid ADV 为零或 fail-closed 要求。
