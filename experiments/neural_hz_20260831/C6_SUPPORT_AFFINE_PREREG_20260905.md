This is the next hypothesis for the same S0 residual-CNN structure, after
the frozen C5 V2 terminal attempt failed at ReLU78. No production dispatch,

## Exact identity and uniform trigger

For each original source HZ x = c + Gc*xi + Gb*z, let S0 contain every row
where c, Gc or Gb has an exactly nonzero coefficient. Continuous/binary
domains, all equality/inequality predicates and the shared frame are retained.
For each finite affine-program linear edge Wj, set Sj+1 to the structural
image of Sj under nonzero entries of Wj, including actual row masks and
diagonals. Bias is the expression's existing separate full bias and is added
once, never folded into a source's support or masked away.

Then Wj*xj = P(Sj+1)*Wj*P(Sj)*xj for every original feasible latent assignment.
Induction proves the whole program denotes the same HZ value map on its
unchanged latent set. Whole-zero source paths still contribute their complete
zero-valued HZ predicates to the source-identity join; they are never dropped.
No LP, margin, labels, instance identity, phase search or new relaxation is
used. This is linear structural support propagation, not solver-based
backward refinement. Concrete latent reconstruction is the identity map.

V1 accepts finite canonical float64 CSR operators and the existing exact
ImplicitConv2DOp geometry. It computes Conv support and row edge counts with
integer geometry/kernel-nonzero arithmetic, without an expanded Conv matrix.
Support certificates bind the original source, every operator's actual
numeric/geometry payload, and the expression bias by digest; mutation
invalidates application, including mutations on a zero source path.

The test-only scalar realization filters certified unsupported intermediate
coordinates while retaining the original per-output accumulation sequence,
source-identity coalescing and native predicate join. Test against the
unmodified native materializer on complete small mixed-length expressions:
dyadic and non-dyadic coefficients, grouped/strided/dilated/masked Conv,
nonstationary diagonals, dense tails, cancellation, repeated/equal-but-distinct
sources, zero paths, center/binary-only support, and corrupted certificates.
All HZ numeric fields and frame/widths must match; no standalone arbitrary-
vector equivalence is asserted for a source-bound filtered matrix.
