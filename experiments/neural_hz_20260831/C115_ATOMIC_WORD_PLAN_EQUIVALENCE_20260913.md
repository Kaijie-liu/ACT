# C115 exact source-first atomic word-plan argument

The unchanged C112/C113 producer routes exact V forms by original coordinate,
sign and relative dyadic power. Each removed alias is a nonzero normalized
continuous factor determined by a retained representative; its defining row
has at least two nonzeros. Replacing an alias in any remaining row is a
one-column substitution and coalescence, which cannot increase that row's nnz.
Hence old C96 nnz is at least quotient-plan nnz plus2*removedV. This conservative
lower bound is sufficient for a strict TOTAL gate; it is not an exact old count.

An M definition has positive power-of-two pivot and normalized box by the
unchanged integer normalization formula. For a complete group of output-only
M sinks, remove their defining pivots from their parent supports and substitute
these supports into every consumer, including all untouched terms. The union
cardinality is an upper bound on the final exact coalesced support. When the
sum of these upper bounds is no larger than the original defining-plus-consumer
nnz, the prospective group cannot increase total nnz. Actual integer word
substitution uses -consumer_number*definition_number with the exact difference
of dyadic exponents; no floating division or tolerance is introduced.

Groups are processed against the CURRENT prospective output rows. The reducer
therefore does not add independent deltas of overlapping consumers. Because
selected M factors are output-only sinks, none can be another selected factor's
parent. After processing, the complete candidate must be strictly below the
original C96 lower bound. If there is neither V gain nor strict M gain, every
M change is rolled back. Neutral local steps are never independently accepted.

Preparation creates exact symbolic row plans, not a native CSR/HZ or globally
born factor set. Counts for all tiles are fixed before final naming/emission.
Only retained virtual auxiliaries are mapped to compact fresh coordinates;
every original source/output coordinate is unchanged. Native realization uses
the unchanged C113/C96 exact row emitter and its positive gauge/window guards.
The same plan and work pool are consumed once; every charged symbolic row,
including ultimately omitted definitions, remains paid without refunds.

The source fixture's original EQ/INEQ and binary predicates, source arrays,
shared original coordinates and original inverse are retained by identity.
Every old/new output polynomial is independently compared with direct spatial
Conv, every new normalized box is checked, and actual extensions satisfy all
original predicates for both binary phases. A removed source-plan M never
became an old source factor, so original-input reconstruction remains exact
projection followed by the unchanged original inverse. This does not justify
discarding inverse recipes in a postpass on an already-born HZ.

Evidence is the complete15 ordinary source fixtures, not merely the neutral
unit test. The latter additionally verifies that a globally neutral M-only
proposal rolls back without changing any input row. All3298 tests passed.
