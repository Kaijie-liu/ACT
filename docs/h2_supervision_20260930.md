# H2 完整预算监督与可搬迁检查

2026-09-30，从 `feat/moe-route-verification` 的 `efd8bae6` 继续。
H2 已接入独立的合成请求监督入口：来源创建、候选下界、证据打包、数学检查、
完整聚合及终态发布使用同一预算。18 项新控制通过，31 次监督调用的终态账本闭合。
没有启动真实模型请求、重开封存输入或修改生产接受门；外部比较结论不变。

## 本阶段范围

[前一阶段](h2_source_controls_20260930.md)的四份固定声明源图、两种数学构造、
gate 规则和复用义务不变。新增[监督器](../scoped_source/endpoint_supervised.py)与
[工作进程](../scoped_source/endpoint_worker.py)；实际使用此前检查过的来源生成器
和数学检查器，不修改冻结的 H1 或 H2 来源文件。

每臂在自己的工作进程中重新创建源图、构造基础域、生成候选和证据，不能读取另一臂
的答案。正常八臂的 source、基础 P、gate 与复用规则一致。所有 unordered top-2
pair × 非标签类别都保留；空 guard 也不能跳过。端点臂逐条检查全部不同 gate 端点，
缺两个端点计为两个缺证据，而不是仅一条缺性质。MC 的 `SOURCE_BOX_REUSE`
是来源事实支持的混合性质，不计为 MC LP 对偶证书。

本入口仅摄取固定声明 fixture，**尚不创建或捕获 PyTorch 模型对象**，也不读取
checkpoint 或数据集。其直接逐节点 LP 仍不是旧 HybridZ lowering 的等价性证明。

## 检查包与身份链

[打包器](../scoped_source/endpoint_portable.py)复制八个既有标准库数学模块、
[启动器](../scoped_source/endpoint_verify.py)、source 与 proof。搬到新目录、暂时
隐藏原包后，`python -B -I -S` 仍可检查全部义务；不加载仓库、模型、生成器或求解器。
检查器独立重建声明输入、仿射和 ReLU 约束、guard、gate、输出性质及精确下界，
不是仅核对哈希。额外文件、符号链接、重复 JSON 字段和外部访问被拒绝。

父入口预先固定 producer/checker 版本，并在内存中保留首次 invocation SHA。
checker 正常结束、所属进程组清理完成后，父进程立即固定实际 `check.stdout` SHA，
再将它通过命令行交给接收进程。接收器对同一份字节先核验哈希再解析，使用这个
固定值发布 accepted；父进程还核对 accepted 与内存锚一致。

终态链为实际调用返回 → finish → receipt → terminal → invocation/check.stdout。
每个必需哈希必须是合法的 64 位 SHA-256；不允许 `None` 变成免校验读取。
文件审计沿链逐次对同一份字节核验、解析。没有实际完成调用的外部观察时，文件
只能支持存储记录核查，`positive_execution_accepted=false`。

新增负控制把 MC 的负结果全部改为内部自洽的正结果，保留来源、模式、矩阵和
invocation 身份：接收阶段报 ERROR；重新独立检查原数学证据仍为非正未决。
另检查 endpoint 最小值、缺失数、MC 事实来源和 LP 计数，不能靠摘要自洽绕过义务。

这不是恶意并发文件系统或原生解释器的安全沙箱，调用返回记录也不是外部签名。
冻结 H1 保留历史受控运行，但不声称覆盖本阶段新增的“检查结束后整体替换 stdout”
拒收控制；不改写其历史数学结果。

## 统一预算和成本

时钟从 `supervise` API 入口起，上限 300 秒，包含准入、源码绑定、子进程启动、
工作进程导入、源创建、全部前处理与候选、逐候选发布、打包、检查、接收、清理和
终态发布。测试驱动预先准备预期来源身份、调用方模块初始化、返回值行政记录及
后续只读归档单独列出，不冒充预算内零成本工作。

入口从同一预算中为最后发布预留至多 1 秒，为检查等后续阶段预留至多 5 秒；
不是增加预算。本次正常控制使用 30 秒，故障控制更短，未进行 300 秒真实性能比较。
嵌套的 native candidate 事件已经包含在构造时间中，不可再次相加。

OS 可能使清理或磁盘发布晚于截止；此时返回 TIMEOUT，完整候选也不能复活。
控制验证只杀所属进程组、不影响无关 sentinel；不覆盖主动 `setsid` 逃逸或整机断电。
采样 RSS 是组与父进程的记账指标，不是精确物理内存峰值。
数学结果中的 `hard_budget_supervision=false` 原样保留：独立检查本身不是外层监督。
预算内执行由另一条终态链支撑，二者不能混成一个数学保证。

## 下一门与停止条件

下一步只补 H2 对象摄取薄适配：复用既有 `capture_bound`/`validate_object`，
把当前固定 weighted_sign 权重创建为受支持的实际 `OutputLevelMoE` 对象，在
同一监督预算内创建、捕获、检查来源并生成两臂新矩阵和新证据。捕获文档含新的
trust 字段，需冻结新身份，不能沿用手写 source SHA 或旧正界。

核对参数、输入、算子、私有专家、gate 和全部输出；拒绝 hooks、实例覆盖、
身份错配、晚到与异常，并确认捕获快照不受对象后续修改影响。通过后停止扩大合成
计时，以已有模型元数据判断受支持对象和资源规模，再另行提出有限真实冻结。

转换不一致时停在转换问题；超预算或未闭合时保留结果，不换模型追正例、不扩时。
不顺手扩展卷积/BN/内部路由，也不重跑 H1 稠密剪枝、封存输入、holdout 或缓存研究。
这一步只是对象接口控制，不是高准确率或训练模型实效。原始完整研究目标继续开放。
