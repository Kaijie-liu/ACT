## 实际改变及可观察结果

对同一个 guarded HZ 的最多四行同时查询上下界，保留所有共享和私有因子列，
复用原稀疏矩阵生成候选；独立有理数检查后，向外转换为 float64 并交给既有
ReLU 编码。候选失败、缺侧、身份错误或超出支持容量均不使用该候选收紧。

| 固定控制 | 稀疏传播中观察到的结果 |
|---|---|
| `x∈[-1,1]`，router `(x,-x,0)`，tie-legal pair `{0,1}`，`ReLU(x+1/4)` | guard 强制 `x=0`；检查界约束后不分配新的 ReLU 二元因子 |
| 同源、关闭新接口 | 与既有传播的输出 HZ 逐系数相同；分配 1 个二元因子 |
| 丢弃 guard 的 sound 外域 | 仍分配 1 个二元因子 |
| 相应负预激活 `x-1/4` | 经检查上界为负，实际稀疏输出为零 |
| 两层、两维控制 | 第一层 2 个不稳定单元降为 1 个；第二层实际读取含私有激活因子的 HZ，仍有 2 个不稳定单元；最终 3 个二元因子 |
| 5 个不稳定单元，只选 4 行 | 8 条支持义务完整检查；未选行没有被删除，最终保留 4 个二元因子 |
| 129 因子超容量 | 不调用有限候选核，不截断来源；原传播保留全部 129 个二元因子 |

正控制的精确预激活界为
`71947610852233143/288230376151711744` 与
`72167577223622729/288230376151711744`，不是 LP 最优值声明。
两层例子没有消除全部不稳定单元；有限投影对偶算法不保证得到最佳支持。

这些结果确认**检查界进入了真实稀疏传播和因子分配**。既有 native LP 支持也可以
利用这些 guard；本轮未运行原生优化器，不能声称比它精确、快速或获得额外完整证书。
0.702 秒是控制套件观测时间，不是冷启动、序列化或完整请求性能比较。

## 身份、预算和接受边界

调用者绑定原始 input/router HZ、网络层与实际 `by_id` 调度映射、输入盒、route、
expert、guarded entry。检查器接收完整的性质系数、offset、行号和 side，不只检查
相同名字的查询。测试覆盖自洽但目标错误的证据、来源污染、部分/重复义务和迟到结果。

网络输入与中间界限制 CPU/float64。检查界向外转换；后续 network→HZ、guard
lowering、公共因子的语义及既有仿射/ReLU 浮点构造仍受信任。输入约束前缀保留是
必要检查，不是共享因子来源的完整证明。此接口只传播一个声明 route/expert，
不枚举所有合法路由、不聚合所有输出性质，不能返回完整 MoE SAFE。

候选局部四秒包含于同一个至多 300 秒绝对截止。原生回退每次调用前重新准入，
LP 迟到不能再启动 MILP；继承的 ReLU 不会重复调用原生支持。本轮仅以记录参数的
模拟接口检查此路径，**没有 native solve**。关闭新接口的有限对照只允许原生支持
同样关闭，以免绕过剩余预算。

构造、来源绑定、候选、检查、传播和 API 返回均在本接口的协作式时间内。
没有接入完整请求的硬预算进程监督；归档序列化和外层启动也不在该 API 时钟内。
不能把局部时限、返回时拒绝超时解释成可强制中断整个传播/原生调用。

## 失败保留与只读复核

R1 的两项错误来自测试自身：写入不可变 Bounds 字段；第二层偏置使其本来稳定，
没有进入预期的私有因子支持查询。均已保存，修正测试对象后 R2 通过。R2/R3 仍保留
为加固前版本。只读协作审查进一步指出完整目标绑定、网络 dispatch 身份、原生
跨阶段截止及归档必须拒绝跳过/缺包四项问题，R4 增加相应检查与故障控制。
没有更改候选步数、容量、预算或正界接受公式来取得通过。
R5 又补上保存证据的实际 side 与 layer 绑定及对应变异控制；R4 原样保留。
五个阶段归档合计约 2.5 MiB，本轮没有删除证据或缓存。
