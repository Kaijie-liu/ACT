## Objects and costs

Each of the five normal controls reads the fixed archived declaration and package,
publishes a bundle and copies it to a different location. The child checks there
without the repository, checkpoint, dataset or solver being read. Full returned
mathematical results must match the reference, not only positivity or a minimum.
Preserve the inner checker fields, including `portable_distribution=False`;
successful relocation is recorded separately by the outer report.

Use the existing bounded owned-process executor. Each normal control has a single
30-second clock covering archive reading, packing, relocation, identity checking,
child startup/imports/mathematics, receipt, cleanup and terminal publication.
All publication/copy costs are measured, and late returns do not pass. Parent
filesystem operations remain cooperative; no guarantee against arbitrary OS
stalls is introduced. The original source/proposal generation was performed in
the earlier experiment and is not free work in a new production request: these
are explicitly offline rechecking costs, not a new end-to-end verifier benchmark.
