## 唯一表示因素

三份固定来源为mixed、clipped、guarded，各执行旧V3 COO与来源行块两臂。
相同CPU float64、单线程、128更新／129界评估、candidate8/check2；所有两角色和
完整pair／property目录保留。新臂保留输入单位项、私有误差/lift、DAG与尺度。
原生浮点轨迹允许不同，**同候选精确接受必须一致**。

组件批次固定最多32个具名检查：五个来源的算子（其中两个仅方程控制：现有零半径
以及`deep(center=(1,2^-1000),radius=1/4)`），非零尾项与bank别名、roots私有副本及撤销、
token/tasks/forest/Work/method绑定、同候选dense/scoped与独立有理展开、帧的source/
ordinal/contract/维度/角色/符号/非有限/负零/截断/重复/换序、缺失义务UNKNOWN、
实际搬迁重算及绑定/额外代码拒绝、实际非触碰超AS映射拒绝。

数值forward/adjoint回归容差固定rtol=atol=1e-12，仅用于小控制的原生计算，**不替代
精确接受门**。另逐行比较两臂实际binary64系数的有理符号展开，避免tiny lift被
容差吞掉；不把共同浮点转码称为原网络的精确计算。源原始有理数另用于精确候选
残差oracle。搬迁子进程继承父批次已用Work和绝对截止，返回计数继续累计。

## 十类故障，两臂各一次

| 故障 | 实际检验范围 |
| --- | --- |
| source_binding | 生成声明与冻结来源错绑拒绝 |
| setup_error | 在原生setup接缝注入异常，非真实库缺陷 |
| proposal_block | 非合作阻塞，使用真实299秒执行截止及清组 |
| close_error | close接缝异常，保留清理和失败 |
| partial_candidate | 第一tile截断发布后异常，不允许接收 |
| replay_tamper | 已存tile被改，测试完整性拒绝；数学差分另由组件完成 |
| reception_block | fresh接收非合作阻塞，真实共同截止 |
| late_receipt | 显式迟到时间戳拒绝，不冒充真实OS延迟 |
| limit_mismatch | production软AS降低4096字节，回读与冻结值不符拒绝 |
| cleanup_unconfirmed | 实际清组完成后模拟“不确认”，仅测试接收失败关闭 |

故障字段进入profile白名单，只允许fixed_control；无全局monkeypatch。必须核对
到达指定接缝和实际清组，不能把无关早期异常当故障通过。每个错误与停止前缀保留。

## 资源、成本与证据边界

AS=8,589,934,592字节；FSIZE硬限=134,217,728字节（controller软限1MiB）。
采样RSS门=2,147,483,648字节；现监督实现测量**受管进程组加调用父进程**，比仅
组RSS更保守，但不是硬聚合内存保证。限制在actor数值导入前安装及回读。
CUDA_VISIBLE_DEVICES为空，候选张量显式CPU；不初始化GPU。

报告实际全请求墙钟、完整终态／caller回执、每阶段成本、累计Work、完整成功库存。
失败时Work/存储可能只有progress下界，保持null/partial，不补零、不称完整；离线
清点另计归档成本，不能救回线上失败。磁盘COMPLETE不是线上接受，必须有及时
调用者回执及清组。caller回执写出耗时也纳入本次位置的300秒判断。

本控制只判断新表示与完整接线是否可用、是否值得后续研究。未验证真实同源来源、
route-flip见证、GPU或外部净收益。八专家来源双遍13,922,736>8M以及membership
126,632>65,536的拒绝仍成立；候选流上界缺口亦未关闭。小控制通过不能解除它们。
若无成本或证据增量，不追加小源刷数；归档结果并提出针对实际障碍的继续／停止决定。
