## 1. 当前接线到底做了几遍

| 阶段 | 源 Snapshot | 独立来源到 HZ 方程检查 |
| --- | ---: | ---: |

| production `CheckedSharedForest` | 1 | 1 |

源码入口：`scoped_source/native_production.py`、`native_package.py`、
`native_supervised.py`；来源循环为 `shared_source.py`，生产／检查仿射循环为

## 2. 与零权重无关的强制 Work 下界

沿用注册 seed 1/2 元数据，不加载 checkpoint，也不自动推定 seed 0 对应。
权重位置 W=6,958,080，偏置／仿射行 A=3,288，P=W+A=6,961,368。
252 条性质、最多 504 端点、1,008 份两角色候选均保持。

| 当前完整路径的强制循环 | 计费需求下界 |
| --- | ---: |
| 单个 Snapshot：打包、PackedRow 扫描和行访问，2P+A | 13,926,024 |
| 三次 Snapshot 构造，3(2P+A) | 41,778,072 |
| 三次 Snapshot.rows 权重解析／行访问，3(W+A) | 20,884,104 |
| 构造和两次检查中的仿射权重循环，3W | 20,874,240 |
| 上面后三项合计，12P | **83,536,416** |

这些循环对零权重也收费。12P **只是现行实现完整走通的逻辑需求下界**，不含
norm、补偿算术、ReLU／guard、来源 reseal、候选、端点检查、序列化和接收。
实际会在第一份 Snapshot 内触发原 8M 拒绝，不能写成“已经消耗 83M”，也不能
把 83M 当新额度或完整上界。41,778,072 已存在于
[旧来源成本账本](hz_shared_source_cost_20261015.json)，不是本次新发现；本次核对
它仍适用于已经接通的原生路径，并补齐当前必需解析／仿射循环的下界。

更一般的条件下界仍是 **2P=13,922,736 > 8M**：若 production 与 fresh replay
各保留一次按每参数收费的完整合法性检查，仅这两遍就超过旧限额。这不是所有
证明系统的复杂度下界；把每参数改成每块收费会改变资源政策，不能暗作算法优化。

就有 6,684,672 项；不能假设真实模型足够稀疏绕过它，也不能反过来声称已经测得
真实 checkpoint 超限。节点／因子等某项上界适配不等于完整请求准入。
候选流上界是 `84*128 + 504*(72+2*1040+2*2700*8)`；它不能证明实际候选必然
达到该长度，也不覆盖完整归档／峰值驻留或墙钟。

## 4. 已有修复设计的作用与边界

- [仅域 pair 视图](hz_domain_guard_decision_20261015.md)去掉的是不用的 pair 值
  别名表，不是 guard、tie 或待证义务。可从上下界分别去掉 86,016 项，得到
  membership **40,616–50,216**；不能将原下界和新上界混成一次精确减少。
- [显式零角色描述符](hz_consumer_only_decision_20261015.md)保留零候选的维数、
  符号和精确检查，可使 binary64 流的设计上界为 **11,981,760 字节**。
  这是旧有、尚未实施的格式方案，不是新创新或通用有理数格式的容量证明。
- 同 actor 的只读 source bank 加独立 cursor 可减少重复解析／打包；不可变
  PackedRow／SourceLocal 已有，独立多 cursor 接口没有。checker 仍须独立重算
  每条转换方程，fresh replay 仍须从归档建立自己的来源。不能共享生产判断，
  也不能取消终态 reseal。这主要是成本改进，不单独构成 MoE 算法精度贡献。

以上任何一个单独实施都不能解除 2P 的 Work 条件下界；也不能自动解决所有
local／refs／active／归档限制。因此**不再开启孤立修复的小控制批次**。

## 5. 下一份方案的边界和停止条件

保留旧 8M／字节与计数语义不变，则本注册完整拓扑继续拒绝，不重新运行来确认
已由整数下界确定的结果。若继续面向该拓扑，只能形成**联合表示／资源方案**：

1. 明确哪些结构采用已有无损方案，哪些上限需要模型规模政策；不把逻辑边数
   偷换成字节数，也不改变每参数计费。新表示身份不能重用旧矩阵正界。
2. 按实际两臂给出全部自有阶段的上界和独立绝对上限；不从 12P 倍乘定额度，
   不把旧 fixed/stub 或旧 post-capture 上界当当前完整 native 上界。
3. 原生未知开销沿用已采纳的硬限额、超限拒绝；不能把自有缺失账本统称原生
   开销。固定 300 秒，失败／部分证据保留，不承诺完整形状一定完成。
4. 拟案后一次性列出实际需批准的数值和实施范围。未批前不改运行时、不做
   新原生调用、不加载真实模型或 GPU。若缺关键上界，就明确缺项而不暗设上限。

这是一项研究路径的准入决策，不是新增 SAFE、外部竞争结果或 G1–G6 完成。
声明实数来源的包络检查、checkpoint/capture 对应和原生浮点执行仍分栏。
本批三个合成来源的正结果及六个正常请求不升级为真实模型证书。
