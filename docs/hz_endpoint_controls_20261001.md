# 加权端点与实际 HybridZ 的接入结果

2026-10-01。新增的显式接口将 H2 端点目标接到实际 `SparseHZono` 专家 pair 和
批量支持器，不改原生产默认入口、候选迭代、数值门或旧 F0。最终 R4 的 18 项
固定控制、12 个保存包的独立复核及 68 项相关回归通过。

这是一项算法表示接入，不是 GPU 加速或真实模型胜负结果。给定 HZ 和 gate 的
条件仍受信任；六项目标门保持 OPEN。

## 固定控制的结果

| 控制 | 实际结果 | 可支持的结论 |
|---|---|---|
| 三专家、三个 pair，固定候选提议 | 3/3 性质正，6 个端点齐全；最小界约 0.0677579155 | 新接口上候选器实际完成此有限例 |
| 同一 HZ 的解析对偶参考 | 3/3 正，最小界 3/32 | 独立于优化器质量的表示参考 |
| 同一 P/gate/性质的 range-only MC | 精确可行点目标 −1/32 | 此 MC 松弛不能有正下界，不是原网络反例或最优值声明 |
| 共享输入关系 | 下界 1/4 | 保留同一输入抵消专家差异 |
| 同源独立乘积外包络 | 下界 −3/4，UNKNOWN | 丢弃关联会在此例失去证明 |
| 三专家三输出、两条有理性质 | 6/6 性质正、12 个端点 | 多 pair/多性质覆盖与非二进制权重投影 |
| 私有因子、宽 gate、负性质、方向交换 | 相应非正界保留 UNKNOWN | 不把松弛失败解释成模型不安全 |
| 部分证据 | 4 个端点已检查、2 个缺失，UNKNOWN | 不能靠部分正界完成请求 |

三专家例保留全部 pair，包括不可行 pair {0,2}；该 pair 上的正界是空域上的
真结论，不是第三条可达路由。解析 x=-1、-1/2、1 的路由分别为 {1,2}、
两组并列合法路由、{0,1}。这些是固定解析控制见证，不是训练模型的路由变化证书。

18 个控制方法还覆盖错误源／guard／gate／请求、遗漏与重复义务、错误 frame、
私有列污染、浮点目标替换、对偶符号和非有限值、合作式截止、提议异常和禁用 CUDA。
68 项回归包括原支持、设备候选、条件传播、原 pair 私有因子分离及导航／账本。
未执行原生 LP/MILP、GPU、真实请求、数据加载或训练。
