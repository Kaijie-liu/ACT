# 支持遍历有限控制协议

用户于2026-10-18批准默认关闭的 scope/global 遍历选择及有限差分、故障控制。
起点为 `896353fe9ca075b455c26b9fcdd7b4f17ea7a378`。本协议不批准真实模型、GPU、
优化器或新版原生监督器运行，不改变数学接受门、配额或每请求300秒。

## 单一改动与成本

`Driver(..., pair_scoped=True, scoped_traversal=True)` 明确选择新路径；省略该开关保持
原 global 扫描及其 Work。每个 tile 在任何 accumulator 或 objective descriptor 发布
之前，依据已检查来源重建 ancestry，完整复核节点和因子的正反映射、连续 rank、尺寸与
身份，再封存四个缓冲区。逐次 `global_id/local` 检查继续保留。遇错拒绝，不异常回退。

默认路径与新路径只改变节点枚举，目标／对偶仍分别计算，逆拓扑次序和逐次有理数运算、
位数门、完整 source／dual／zero／residual／norm／聚合检查均不变。不是新的数学域。

每次 opt-in 回传为选择收取1次 row visit。设置成本已支付后，若
`G=(b+1)(N-S)-3S > 1`，使用已封存 scope 的降序全局ID，否则原 global。
这不保证相对默认路径净节省。完整两臂 Work 差应为：

```text
默认 Work − 新路径 Work = Σ已选scope的G − 全部setup_work − 全部selector_work
```

一次 setup 的完整计数为 `2(N+F)+S+Sf+R_pairs+C_chain+7`，包含 ancestry 与形状
验证、节点和因子完整扫描、四次 seal。封存复制、重叠峰值、拒绝与清理保留既有记账。
`planned_iteration_saving` 在调用前记账，只有调用全部完成才代表实际遍历差；
失败终态以原始Work计数为准，不据此扣减成本。完整计时另含
加载、来源检查、规划、候选编码、发布、精确检查与清理。控制来源生成、独立oracle和
故障注入计入整批时间，不能把组件配对时间当作生产端到端加速。

## 固定范围

一次整批执行，不自动重试、不追加来源。固定五份小型标准库声明：既有 deep、half、
guarded，以及明确写在测试文件中的 eight_private 和 negative_guard。前四份用于
两臂、两种现有候选编码的16次组件比较；另外8次默认路径用于独立展开公式的核对。
eight_private 只是触发不同遍历选择的合成结构，不是注册八专家真实容量测试。
候选系数固定，不执行优化器；负guard例必须保留非零对偶残差。

控制清单固定为10个测试方法：

1. 默认关闭、非法开关、不可改配置与原额度。
2. 全部pair／property／endpoint、两角色下界、结果与候选输入差分；逐项核算Work差。
3. 单／双列残差、显式零、存储结果和逐次精确算术顺序差分。
4. 映射遗漏、重复、一致置换、域外替换、尺寸、owner、rank及因子污染。
5. foreign pair／forest／Work、已封存alias、重复准备与关闭后使用。
6. 中间有理数位数超限必须同样拒绝，不能先抵消再检查。
7. 常负性质与非零guard对偶的反例，不能产生错误正界。
8. 单项、整块、全部候选缺失保持未完成；后块非法符号、zero、query和单角色缺失
   不得接收前缀为成功。
9. roster／回传／接收中的截止与异常、Work耗尽、封存重叠容量拒绝。
10. 发布迟到、错误ACK、异常与部分释放；无完整接收或截止后不得成功。

新开关不接入现有方法注册表或真实监督配置。没有新增容量、可搬迁证明、原生内存或
实机GPU主张；历史冻结文件与结果不修改。因运行代码有明确版本变更，旧源码hash检查
不用于冒称旧冻结仍能在新树原样执行。

## 运行与停止

使用现有 act-py312 的 `-I -S -B`，不加载 torch／numpy／scipy／求解器。
先提交并绑定源码、协议、测试清单；新结果目录保存冻结信息、全部日志、终态与来源。
整批另有300秒父进程硬截止，共用起始时间；每个Work截止不晚于它，不在tile重置额度。
保留8M Work、128 MiB arena／制品、4096／8192位限制。测试可注入更小容量与更早截止，
不能提高原额度。父进程超时杀死自己创建的进程组，不干预其他任务。

失败记录保留并停止本批；修复后重跑须有新版本和明确决定，不自动反复刷过。
通过只说明此有限控制覆盖内的实现正确性与计费，不证明普遍速度、完整容量、
新增真实证书或G1完成。若setup使净收益不足，如实记录；不据此调比例、配额或源形状。
