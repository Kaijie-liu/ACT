# 支持遍历准备成本与完整拓扑停止决定

**停止将当前 R2 推广为注册八专家拓扑的 Work 优化。** 即使忽略可选补偿因子、允许每个
pair 选择更有利的端点数，完整消费的净节省上界仍为负。小型合成例的 11%–12% 节省
不支持这种推广。本结论不否定尚未实现的准备前分支，也不改变任何数学接受规则。

起点为 `37d3251ff0836027315ed63b1fed683098cdb7f1`，正确分支、干净工作树。
本次只读源码和已存 R2，进行整数代数与顶点枚举；不调用来源生成器、验证器、求解器、
真实模型或 GPU。[重算记录](hz_support_amortization_20261018.json)与
[标准库脚本](../scripts/assess_support_amortization.py)绑定证据和公式。

## 已有结果指出的问题

[R2](hz_support_traversal_controls_results_20261018_r2.md) 的 deep／half／guarded 全部走
global，仍分别多花 1,173／401／297 Work。当前 `select(pair)` 在任何调用前完整复核、
封存映射；`_node_ids` 只是付费后的局部选择。eight_private 是一维、两类别合成结构，
其所有准备费用可以摊平；不能将该来源替代注册的 3,072 输入、十类别结构。

以下 Work 差均指**相同来源、候选和完成程度**的耦合比较，不是两个无关上界相减。
来源检查、dual／zero、残差、范数、终态聚合和现有数值门不变。两臂算术序列相同时，
除遍历、准备和选择外的计数抵消；真实时长不从 Work 差推导。

## 准备与完成的精确合同

对 tuple-node 的 Shared／Scaled 表示，设全局节点／因子数为 N、F，当前 pair 的节点／
因子数为 S、T，D=N−S，pair 目录长度为 P，三条 ancestry 长度和为 L：

```text
G_b = (b+1)D − 3S                  b∈{1,2}
H = 2(N+F) + S + T + P + L + 7    每 tile 的新增复核与封存 Work
γ_b = G_b * 1[G_b>1] − 1          包含每次 selector 的 1 Work
```

宽八 tile 有 t 个端点。目标单列回传必执行 t 次；宽二块仅在至少一个候选 present 时
执行一次 dual 回传。两角色字段和符号检查仍完整；zero 不另做一次回传。
完整消费 tile 时：

```text
Δ = t*γ_1 + Σ_present_blocks γ_b − H
任意 missing pattern 下界 = t*γ_1 + Σ_blocks min(0,γ_b) − H
任意 missing pattern 上界 = t*γ_1 + Σ_blocks max(0,γ_b) − H
```

这些不是截止前缀的保证：准备后立即异常就可能一分收益也没有。不得拿未来预计调用
抵扣已发生的费用，也不能通过失败回退重置预算。纯数量上，一个不依赖 present 的
充分条件是 `G_1>1 且 t*(G_1−1)>H+C_preflight`；它仍以 tile 完成为条件。
当前还没有这种 preflight 实现或已核定的 `C_preflight`。

## 注册完整拓扑上的否决上界

每个图的 ReLU 总数为 router 128、每专家 384。设 u 为不稳定数、v 为稳定负数，
`u≥0, v≥0, u+v≤单位数`，定义 `ρ=4u+v`。稳定正 ReLU 复用原节点；稳定负新增
一个节点、零因子；不稳定新增四个节点、至少三个因子。不能误用 `F≥input+ρ`。
下标 R 是 router，i、j 为专家，8 个专家求和：

```text
N    = 6696 + ρ_R + Σρ_i
S_ij = 4008 + ρ_R + ρ_i + ρ_j
F    ≥ 3072 + 3u_R + 3Σu_i
T_ij ≥ 3072 + 3u_R + 3u_i + 3u_j
H_ij ≥ 2(N+F_min) + S_ij + T_min,ij + 53
53   = 28 pair项 + 6 common祖先 + 6 expert祖先 + 6 expert祖先 + 7
```

可选 affine／ReLU 补偿因子只增加 H；在这个有利于 R2 的上界中将它们忽略，不是在
真实来源中假定补偿为零。完整目录仍覆盖全部 28 pair、252 性质和最多 504 端点。
每 pair 有 9 或 18 个端点，tile 分别是 `[8,1]` 或 `[8,8,2]`。
用凸上界 `h_b=max(0,G_b)−1 ≥ γ_b`，全部 present 时：

```text
B_9  = 10h_1 + 4h_2 − 2H_min
B_18 = 18h_1 + 9h_2 − 3H_min
Δ_R2 ≤ Σ_pairs max(B_9,B_18)
```

该函数是各图 `(u,v)` 的凸分段仿射函数：正部函数凸，系数非负，减去的 H_min 为
仿射，最后取最大值仍凸。三角形乘积上的任意点是顶点凸组合，故其函数值不超过最大
顶点值。每图仅需三个顶点：全稳定正、全稳定负、全不稳定；等尺寸专家可交换，
将 `3^9` 个命名顶点归为 `3×45=135` 个计数角点。逐 pair 自选端点数甚至不要求这些
gate 状态同时可达，所以结果是保守上界，不能称为观察到的模型。

| 完整消费假设 | 单检查器净节省的最大上界 |
| --- | ---: |
| 全部候选 present | −1,134,330 Work |
| 允许任意 missing 块并免除其 dual 调用 | −1,134,315 Work |

第二行使用 `9h_1+4max(0,h_2)+max(0,h_1)−2H_min` 与
`18h_1+9max(0,h_2)−3H_min` 的逐 pair 最大值。两个上界均在 router 全稳定正、六专家
全不稳定、两专家全稳定正的角点最大。全不稳定角点，取较有利的端点模式也至多为
`−2,616,096 Work`。若 production 与 fresh replay 都使用 R2 且都完成，两者增量相加；
例如全 present 的总额外开销至少为 2,268,660 Work。

这是假设可以完整消费后的结构比较，**不是运行结果或现行额度的准入证明**。既有
两次完整参数检查至少 `13,922,736>8M`，加上 membership 拒绝，已经让真实注册路径
不可执行；不能先提高额度
再用本上界声称应该运行。也不能把 Work 负收益换算成墙钟退化。

## 新分支的机会与明确限制

这项否决只针对 R2 的“每 tile 都先准备”。假想一个免费、准确、逐 tile 跳过亏损准备的
选择器，其乐观完整消费上界可达到 +958,454 Work／检查器；它忽略选择费和实际补偿，
不是实现效果或保证。保守启用条件应依赖同一 checked forest 的 N/F、同一 Scope 的
S/T、受信任的 tile 端点目录与实际完整 H，不能依赖候选自报计划或未来必有 dual。

但直接跳过 `prepare_traversal` **不保持 R2 完全相同的故障拒绝集合**。原 global 按
全局 ID 降序执行，经每次成员／逆映射检查保护；一个一致的局部编号置换可能仍计算正确。
scope 用 reverse 决定遍历顺序，必须额外证明 canonical rank、完整 roster 并封存。
R2 无条件执行了后者，故把 global-only 分支改回原 global 是一个新的分支合同，不能
写成“所有 R2 检查照常执行但不收费”。

如后续另获授权，合同须明确分开：

- `GLOBAL_ONLY`：完整原 global 数学检查，不使用 scope 遍历许可证。
- `SCOPED_READY`：完整复核节点与因子 roster、绑定和封存通过后才允许省略域外访问。
- `PREPARATION_FAILED`：终止并保留费用，不以 `not ready` 隐式回退 global。

计数只能作选择提示，不能授权省略数学义务；污染导致进入 scope 时仍须由完整复核拒绝。
若要求 R2 所有 canonical-map 故障拒绝行为逐项不变，就不能采用这种跳过策略。
本次不实施该分支，不将旧记录扣掉准备费后伪称新结果；默认关闭并保留原 global 强参考。

## 表示类型修正与停止边界

上述精确差量只用于绑定的 Shared／tuple-node 路径。Wire 的 descriptor 另收费，
`node_owner` 每次会触发该读取，因此应为：

```text
G_wire,b = (2b+1)(N−S) − 4S
H_wire   = H + N
```

当前 selector 仍以旧 G 决定，不能据此宣称 Wire 精确计费相同或最优。若旧 G>1，
则 `G_wire−G=b(N−S)−S>0`，旧选择是保守的；此差异未构成错误正界证据。
R2 没有测 Wire，不为这项范围修正补跑或扩大控制。

本阶段止于可重算静态否决与分支合同草案。没有改生产代码、额度、接受门或 300 秒，
没有新控制、来源、候选、模型或 GPU。G1–G6 保持 OPEN；目标仍是完整 MoE 净验证收益，
不是将局部控制或假想上界包装成创新完成。下一实施须明确授权分支语义及有限范围，
不能继续无条件准备 R2，也不重复旧小控制来追求正面数字。

整数结果经另一名只读 AI 独立推导一致，分支与 Wire 边界另经只读复核；这些审查与
静态脚本不构成机器检查的完整性能定理，也不替代独立人类技术审阅。
