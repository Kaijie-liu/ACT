# Separate construction parsing study: controls before fixed synthetic timing

Motivation: the sealed4088 request exhausted its registered work budget inside
source/guard/output construction BEFORE any LP proposal. Its logs do not locate
the exact layer or sub-operation. This study does not rerun4088, input98,
checkpoints, test data, old positive matrices, or any solver.

An exploratory fixed synthetic E4/C4/width16/depth2 cProfile of the old builder
observed0.683s instrumented construction,0.431s cumulative unpack and0.397s CSR
parsing; deepcopy0.094s. Nested times are NOT additive or an unprofiled speedup.
The source CSR comprehension converts each nonzero coefficient twice. These
facts justify a parsing study, not attribution of the REAL timeout or a change
to McCormick, affine/ReLU algebra or LP precision.

## Single-factor implementation and controls

Reuse the existing exact-matrix-cache design at the NEW declared-source
construction interface, without importing ACT or modifying any frozen source.
Request-local function bindings replace only CSR parsing; original validation,
unpack schema/factor checks, affine lifts, ReLU, all-pair guards and every output
LP construction execute. The original CSR parser still runs on misses (including
its duplicate conversions); removing duplicate conversion is NOT a second
optimization mixed into this experiment. Current canonical bytes, matrix shape,
scope and policy bind hits. Immutable rows never escape; producer containers
are copied. Bounded64entries/64MiB payload/2M cells; these are retention limits,
not total-RSS guarantees. All entries are cleared on return or exception.

Three paths: original reference, adapter-cache-disabled, adapter-cache-enabled.
The reference runs the original construction function, not the slower disabled
adapter. Enabled/disabled adapters share instrumentation and all other rules.
Fine-grained timers separate source validation, operator decoding, affine/ReLU,
joins, guards, projection, LP building, unpack and CSR. Inclusive nested times
must not be summed; exclusive times are diagnostic. Reference has only the
outer construction timer. Independent checking always uses the ORIGINAL
uncached checker in a fresh python-S process, never the new binding or cache.

Controls: byte-for-byte full-construction differential, shape/depth/class
variation, ties, zero-radius/constants, all252 synthetic obligations, source/
guard/property mutation, hash collision, current-shape mismatch, mutable-input
and returned-container contamination, scope transplant, malformed CSR, eviction,
oversized fallback, deadline/exception cleanup, no global patch, fresh solver-
free checking, hard cutoff, missing evidence and whole-pipeline cost closure.

## Fixed timing after commit and passing controls

Two synthetic E4/C4/depth2 graphs: width16 and32, seed724, binary64 stored
coefficients generated by a fixed Python RNG; no checkpoint or dataset.
For each width, three rounds with orders(reference,uncached,cached),
(uncached,cached,reference),(cached,reference,uncached):18 complete calls.
No pilot-based width/capacity/order tuning, retries, sample additions or solver.

Each call has one30s wall budget,2s publication reserve INSIDE30, CPU2 and
sampled parent+owned-worker RSS8GiB. Imports, source generation, validation,
construction, hashing, serialization, fresh independent check, cleanup and
terminal publication are charged. Final cost-ledger writing is disclosed by
the supervisor return clock; later administrative review is separate. Timeouts
and errors stay in the18-call roster. All actual clocks and missing stages are
retained; no missing check is assigned a zero checking time.

All modes must produce identical source and full bundle hashes and independent
construction-check results. Completion is NOT a positive output certificate:
there are no proposed or checked lower bounds. Report medians for construction
process, unchanged checking process and full call, plus sampled RSS, both
original-vs-cached and disabled-vs-cached. Synthetic timing cannot be extrapolated
to real4088, certified coverage, faster SAFE, or external-tool superiority.
