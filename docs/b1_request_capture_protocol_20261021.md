# B1 actual-source and request-denominator control

This is the second, non-repeated half of the B1 diagnostic interface: connect
the **actual** guarded entry, conditioned router, shared expert joint and F0
object to the already-tested native-return capture. It adds no solver, strategy,
replay or supervisor. It is necessary attribution infrastructure, **not G1
innovation, a network-source proof, a performance result or a real experiment**.

## Default-off contract

`verify_staged_linf(..., diagnostics=None)` is unchanged by default. Enabled
diagnostics require the existing budgeted shared-input schedule. After exact
route analysis, before common propagation, publish the complete pair/property
roster (or explicitly incomplete known subset). Preserve all ten class rows;
never select properties by their returned bounds. Record reuse, registered F0
slots, returned decisions, unvisited and censored obligations. Registered slots
are **not confirmed native MILP calls**: a cutoff can occur before invocation,
and a zero-variable return may not call a solver.

Temporary native-return references are held only through the existing decision
and full-model replay. Capture at most the first returned unresolved slot; for
monolithic F0 choose the first ordinal residual pair, not an active branch.
Keep other residual pairs explicitly unseparated. A missing-problem failure
locks `SELECTED_SOURCE_UNAVAILABLE`; do not replace it with a later source.
Unselected references are released without copying. Selected sources are copied
to bounded immutable bytes and structurally received under the same Work and
deadline. Published final inventory must equal the bound request summary.

The source maps retain router→entry→joint→F0 constraint prefixes and all
shared/private widths. Prefix checks sum stored binary64 coefficients exactly
by column, without normalizing either source CSR, and check appended-column
zeros. They use the existing rational bit limit and charge Work. They do not
check floating guard construction, expert/router propagation, F0 projection,
McCormick construction or native lowering. Structural reception of serialized
sources does not independently repeat this prefix arithmetic.

**Range domains differ:** current margin support keeps binary factors; expert
difference support relaxes them. Both flags and numerical support statuses are
retained. Future LP/MILP or gate attribution must not silently give a continuous
domain an integer-only margin range. Raw points remain unchecked; no new SAFE
or UNSAFE acceptance rule is introduced.

The request's existing final budget verdict precedes diagnostic terminal
publication; reception and a final cutoff check share the original deadline.
Expired reception rejects, without creating a fresh acceptance window. Tier1
early closure attaches a request-level skip reason to `NOT_REACHED` rows; it
does not fabricate per-property native proofs. Publication failures propagate,
and hard-kill missingness remains missing, never zero obligations.

## Once-only frozen control

One three-expert, ten-class, two-input-dimensional linear synthetic MoE;
selected-softmax top2, all router scores zero. Expert property0 is negative
for expert0 and positive for experts1/2; remaining margins are positive.
No trained checkpoint, dataset, external tool or GPU is loaded.

Run exactly four complete synthetic requests, in this order:
`staged_off`, `staged_on`, `monolithic_f0_off`, `monolithic_f0_on`.
Use the unchanged `route_complexity_reuse_v1.json` configuration, changing only
the path and optional observer. Both on/off paths must return UNKNOWN with
the same non-time decision fields and no valid full-model counterexample.
All three tie-legal pairs and nine properties give27 obligations:25 reused,
one selected and one other returned. Staged registers two F0 calls; monolithic
registers one covering two residual pairs. Each on path captures one source.
These are complete synthetic request counts, not four native solver calls.
All route/support/Tier1/F0 calls made by those four requests are charged.

Seventeen fixed no-additional-solve controls cover: different deadline,
duplicate/incomplete inventory, partial/censored denominator, duplicate reuse,
wrong property, absent native callback, unselected-reference release,
first-ordinal unavailable-source lock, altered guard prefix, expired reception,
publisher error, post-capture alias pollution, noncanonical duplicate CSR rows,
nonzero appended columns, request-level skip reasons and deadline expiring
during publication. Supplied state-control outcomes are not solver evidence.
