## 研究增量与不变部分

新[来源行块算子](../act/back_end/moe/source_row_endpoints.py)实现
`C=(I-R)^(-1)(E_aux+sum_B S_B W_B P)D`：首层自然来源行只转码一次，
以有界逐行复制进入私有CPU bank；不将每个源权重展开成全局COO条目。
输入单位项、所有普通local项、误差／lift尾项、引用顺序、中心／偏置及尺度均保留。
两个专家的共同输入残差先累加再取范数，不用独立区间替换共享输入。

原[CPU V3 Operator](../act/back_end/moe/scaled_forest_endpoints.py)没有修改，仍是原生强参照。
两臂共用128次更新／129次界评估、候选宽8、pair-scoped检查宽2及原始系数精确检查。
浮点乘法轨迹可以不同；同候选精确接受必须一致，尚待获批后的差分控制验证。

这是一项已落到候选算子中的具体表示改动，不只是新命名的缓存或调度；但其正确性
运行控制、真实完整请求效果、GPU收益均未检验，不能据此关闭G1或G2。
已有共享／私有因子、DAG、尺度和精确残差机制不是本轮重新发明的贡献。

## 不变的数学与来源边界

生产先由已有构造与独立来源检查建立`CheckedSharedForest`，再提议候选；新原生
bank不是接受来源。候选检查继续执行符号、维度、全零角色、全部原始系数残差及
严格阈值`1e-7`；完整保守pair／property目录和缺失处理不变。

新包的source必须与外部冻结请求一致，不能由生产报告自报后成为检查器的期望值。
源码、方法、调用身份、源、性质目录、候选顺序和分页结果均绑定；搬迁入口在首次
项目导入之前拒绝清单外代码、`__init__.py`、目录别名和hardlink。

来源是声明的binary64参数／图，不等于训练checkpoint、预处理、BN/eval或原生
PyTorch执行已经对应。接口仍限共享类别、输出层selected-softmax top-2、
Linear／ReLU／Flatten。完整保守pair清单不证明route flip实际可达。
声明实数来源结论、原生浮点执行、训练身份与G3/G5继续分开；旧23增益来源缺口不变。

## 预算、内存和末端账

没有选定AS数值，没有把旧16GiB或2GiB采样RSS继承为本次授权。新版本只提供
另行获批profile的`RLIMIT_AS`／`RLIMIT_FSIZE`安装及回读接口；审批表为空，
入口在来源读取、原生导入或启动actor前拒绝执行。审批表独立于实现哈希，避免
允许profile哈希与自身实现哈希形成循环；每次调用又绑定该表的版本hash。

三个actor共用`t0+300`、原299秒运行截止及299.5秒清理截止，不为搬迁增加预算。
Work严格恢复前阶段三个累计计数；失败超限计数不截断，不以零补缺失。
来源生成／读取、转码、候选、原始系数检查、归档、环境验证、启动、fresh复算、
接收、等待、退出和清理都属于同一墙钟。各actor实际进程区间与内部细分分栏，
不能将嵌套细分再相加当作额外总时间。

逐进程AS不等于聚合RSS保证；聚合RSS仍只是采样拒绝。所有受管actor继承同一
进程组，只有前一actor退出且无活后代才继续。可信bootstrap、操作系统启动、
不逃逸／不daemonize假设仍需明示。完整实现核验放在受限actor内；原生导入前
另有标准库字节核验。不是对整个系统或原生库实现正确性的机器证明。

固定元数据清单为13文件：6份至多1MiB的调用／阶段／终态记录、1份至多1MiB
的controller日志、6份至多64KiB的actor日志／进度记录。合计上界7,733,248字节，
从原128MiB中预留8MiB和16成员，不是增加额度。来源生成残留另行计费；不能
增加文件后继续沿用这份账。普通包仍使用写前字节／成员准入，失败前缀保留。

接收actor及controller在硬监督内做完整库存核对。调用者只在进程组清理确认后
补核controller回执、controller日志尾部和自身终态三份有界文件，返回实际尾项hash
及最终账；不在外层重新做无监督全目录扫描。磁盘终态仍标记“等待调用者确认”，
必须再结合及时返回的调用者回执，不能单看一个COMPLETE文件接受。
这些有界末端I/O及OS清理可能迟延：超额如实记录、迟到拒绝，不承诺物理300秒返回。
离线搬迁检查明确`online_acceptance=False`，不能补成一次在线成功。

本实现不会解除注册八专家的双遍来源13,922,736＞8M、membership126,632＞65,536
等既知拒绝。候选流上界的容量保证缺口仍在；没有新配额或完整形状完成承诺。
