## 研究决定

本轮改动位于支持系数反向传播，利用已检查的 pair 作用域避免扫描无关全局节点，
不是新数学域或更紧的松弛。`CHECKED_POSITIVE_CAPTURED_REAL_SOURCE` 是声明实数来源的
内部状态名；本批来源全部为合成声明，不是训练 checkpoint 的完整正证据。
eight_private 仅一维输入、两类别、28 条性质／56 端点，不是注册完整模型的
252 条性质／504 端点，不能用这次短时长外推其准入或运行时间。

保持 opt-in，结束本批，不扩样、不重复跑小控制、不推广默认开启。现有数据指出一个
具体后续问题：最终全部走 global 的 tile 仍先付映射验证和封存成本。若继续研究，先在
静态源码与现有记录上核对能否在准备前给出保留全部检查的整 tile 成本判据，再另行决定
实现与控制；本次不修改算法或重新测试。

该遍历优化没有减少来源逐参数检查，注册完整形状的 `2P=13,922,736 > 8M` 与
membership 准入拒绝仍有效。它不能作为真实模型／GPU 执行许可，不能关闭 G1–G6，
也未改变外部竞争性、历史 23 增益来源缺口或同源完整真实证书的科学状态。
