## 固定设计

原11对象、原规范历史、原物化输入和性质；每次独立重算原前缀CROWN范围。
原目录有3条历史ID为空；本次绑定旧M-B两臂实际记录且相同的重建历史，
不是重新选择历史，也不借用旧下界。冻结来源表保留原对象与两臂终态哈希。
同一R7兼容引擎、CPU/float64、原接受门。每对象两次调用，按原目录顺序、
对象内交替：`ALPHA_CONTINUE`与`GUARD_REFINE`，计划22次，余8槽只保留给
获准的工具修复，不自动增加科学重复。不得选择新对象或优化超参数。

两种调用先执行与旧off相同的alpha-only前缀：最多20次评价，Adam lr=.5，
同初始化；无优化参数/无梯度时保留原早停。保留全部逐性质基线最大下界。
alpha*固定为**最早使性质下界总和最大的已评价完整alpha状态**，不凭各层张量
形状猜测或拼接多个状态。逐性质最大界与alpha*不是同一概念，两者分别保存。

随后从alpha*重置Adam，做40次更新及末次评价：

- `ALPHA_CONTINUE`：只继续alpha，lr=.5，作为额外alpha优化的付费归因参照。
- `GUARD_REFINE`：alpha/beta联合，lr=.5/.1；beta从0开始，始终投影到非负。
  为通过引擎跳过零C列的梯度路径，仅做一次固定1e-4正探针；评价及求梯度后，
  **先把beta重置为0，再施加该梯度更新**。探针下界也立即参与候选最大值。

guard臂最多20+41+1=62次候选评价；alpha臂最多20+41=61次。
多出的探针、图构造、范围证明、全部优化及最终接收均计费。两臂不能共享答案。
这是增量诊断，增加迭代的成本公开，绝不声称保底保留使有限预算总体支配基线。
常数或无梯度情形的实际更新数单列，不将重复评价伪称有效梯度更新。

令g_j>=0为同历史、同输入的tie-legal守卫。任意beta>=0有
`p(x) >= p(x)-sum(beta_j*g_j(x))`。每个有效CROWN候选给出相应条件下界；
对同性质全部基线与新候选取max仍为下界。该max保证同一次完整执行的最终界
不低于所保存基线，但不保证300秒内完成，不补网络来源或CROWN舍入证明。
alpha更新、探针和乘子选择不改变原始网络、性质、守卫方向或tie语义。

接收端独立重算全部轨迹的逐性质max、基线、增量、alpha*索引、维度与身份。
这属于结构/数值政策检查，不是CROWN算术的精确证明。基线文件只是中断记录；
超时后的离线重读不得升级为在线历史闭合。所有性质严格正才算该历史数值闭合，
不等于整个MoE请求SAFE。原来已通过的控制不重复刷数。
