## Implementation and cost accounting

The additive [policy](../scripts/hz_source_supervised.py) and
[worker](../scripts/hz_source_worker.py) use the unchanged bounded CPU lifecycle
engine. They cover source creation and imports, checked input enclosure, router
and expert propagation, conditional entry construction, gate ranges, endpoint
preparation, 128-step proposals, serialization, independent checking, reception
and cleanup in one clock. No production-default or mathematical checker changed.

The parent performs receipt/hash/schema checks, not source propagation or a
mathematical proof outside its owned checking process. Admit/release/receive use
`python -S`; numerical dependencies are deferred to the producer/checker. Numerical
imports have their own open/closed event, including interruption. Every successful
phase must retain a successful final-serialization event and its final worker
completion event; an empty or truncated successful log is rejected.

The report distinguishes owned-stage cost, parent cost before final publication,
final-publication cost and the observed outer API interval. Their decomposition
includes the small observation tail rather than silently omitting it. Nested
operation times are diagnostic subdivisions, not costs to add a second time.
Open operations are right-censored. Offline execution rechecking and offline
prefix checking have separate timers and are not included in online performance.
These tiny synthetic timings are not a speed comparison or a capacity guarantee.

Source prefixes contain only completed input/router/pair transformations. Output
prefixes are published only after the complete source and endpoint roster exist;
all missing candidates remain explicit. Source, guard, factor and gate checks
are rerun offline for every available completed prefix. Missing source/lowering
files cannot hide a finalized endpoint file. The deliberately malformed
missing-endpoint prefix is explicitly rejected, not counted as checked evidence.
No offline timeout-prefix result becomes online acceptance.
