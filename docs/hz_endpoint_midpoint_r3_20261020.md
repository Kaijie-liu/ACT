## 判定与停止

四个正常请求全部保留：精确 pair/property 下界、正性质 gain/loss、完整请求状态、Work、
全部阶段和请求耗时、制品体积及采样内存。已保存的分页结果不足以重建某条 endpoint 明细时，
不声称具有该明细。两故障位置必须实际到达预注册接缝，部分证据不能接受。

只有浮点 surrogate 改善、没有精确下界／完整义务增量，或替换末次更新造成损失而没有净收益，
就停止该机制，不追加搜索。原协议未给定数值化成本倍数门，本轮不事后发明该门；完整成本
原样报告，有局部精确增量也最多支持有限合成信号，下一研究范围仍须单独论证和批准。
mixed 的专家相同，不能单独支持真实 MoE 创新或竞争优势。22 项控制 PASS 不等于研究成功。

注册八专家完整来源的 Work／membership 拒绝保持。G1–G6、真实同源完整正证、实机 GPU
净收益及外部领先仍未完成。本批任何结果都不能绕过这些独立验收门。
