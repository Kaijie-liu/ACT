# Pair-scoped exact consumer: frozen synthetic controls

Frozen before implementation against `dd78c678b827b024ed413147f0b046aaca97a558`,
2026-10-14. The user authorizes an optional pair-scoped consumer, candidate
batch width **8**, exact checking block width **2**, differential and fault
controls only. The default consumer remains available and unchanged in meaning.
No trained model, dataset, GPU, native optimizer, dependency change or quota
increase is authorized. This is not a new real-model execution protocol.

## Fixed implementation and acceptance contract

- Admit only a complete checked V3 scaled or wire forest bound to the same
  Work and owner. Select common ancestry, both expert chains and this pair's
  guard. Do not infer the scope from the shared `scope=-1` label alone.
- Retain global node/factor identities. Scoped buffers omit only coordinates
  proven absent by that checked closure. Reject nonzero out-of-scope writes;
  even omitted zeros retain type, coordinate, bit and accounting checks.
- Prepare at most four immutable objective roots per endpoint, preserving the
  original property arithmetic. Publish the entire unchanged typed candidate
  frame before checking any block. Keep proposed and explicit-zero roles and
  every ordered equality/inequality membership, including duplicates.
- Consume consecutive blocks of at most two endpoints (including a final
  singleton). Pull back objectives separately from duals. Consume private
  node accumulators in place; never seed objectives into dual accumulators or
  cancel them before the original intermediate bit checks.
- Preserve each column's descending global node order, coefficient order,
  multiplication/addition checks, full global factor traversal, absolute value
  before scale grouping, group order, strict margin and complete aggregation.
  Cross-column interleaving, failure/deadline prefixes and Work totals differ:
  no claim of identical resource trajectories or identical admission sets.
- Reuse the existing immutable frame publication/intake and fail-closed Driver.
  Return receipts only after the entire tile succeeds. Any later-block error,
  deadline or source-integrity failure aborts the invocation, clears receipts
  and releases ownership without refunding Work, bytes or elapsed cost.
- Keep 4096 stored bits, 8192 working bits, 4 MiB/frame, 16 MiB candidate total
  less the existing 8192-byte reserve, 128 MiB arena, 8M Work and the original
  at-most-300-second absolute deadline. No fallback obtains a fresh budget.

## Finite control matrix

Use existing synthetic `mixed`, `deep`, `half`, `guarded` fixtures only. Compare
every proposed, zero, selected and final bound against the old consumer and
the independent expanded-matrix oracle, with native and general-rational
candidate profiles. Check complete, missing and partial evidence; blocks of
2 and singleton tails; third-expert and other-pair exclusion; equal parameters
with distinct factor IDs; wire metadata lookup and source resealing.

Fault controls include foreign forest/Work/pair, global-coordinate and root
binding, mutable aliases and consumed handles, illegal signs/zero roles in a
later block, intermediate bit overflow, allocation/byte ceilings, malformed
frames, publication failures, before/during/after-check deadlines, cleanup and
non-refunded accounting. Retain the existing source/wire and owned-runtime
regressions. Tests run with the existing act-py312 interpreter, standard-library
checking, no solver or GPU. Per-invocation deadline and quotas stay unchanged.
