## 最小实现

`owned_session.observe` 在首次读取 `stat` 时绑定 PID、SID 与启动 tick，读取 RSS 后只做一次身份复读。
缺 RSS 或 `status` 消失本身不是退出依据。确认同身份进入 `Z/X/x` 或复读确认进程消失，才记录终止或排除；仍存活、换身份、权限／解析错误或截止均拒绝。
拥有 RSS 的成员同样复核身份。完整分类后才进入列表，不先按旧状态写入。
`zombies` 字段在此包含已观察的非运行终态，不代表所有孤儿僵尸已回收；没有新增这项保证。

公开 `execute` 参数不变且固定真实观察器；私有 `_execute` 的观察器参数只用于固定故障控制，没有生产命令行注入入口或全局 patch。
收据保留 `OWNED_ENDPOINT_SESSION_V1`，增量字段 `observation_contract=CONFIRMED_IDENTITY_V2` 标明修订。
`execution_error` 与 `cleanup_error` 分别保存第一条错误，含类型、消息、阶段、PID 和当时观察是否完整。
类型／阶段最多 64 字符，消息最多 256 字符；不覆盖执行错误，不保存无界 traceback。
每次扫描前和进入清理时清空旧观察。未完成扫描返回 `remaining_session=null`、`remaining_session_known=false`，不等于空列表。
后来清理成功不升级原执行失败。现有调用者先检查执行／清理状态，未知记录继续 fail-closed。

## 一次控制目录

| 组 | 固定子情形 | 必须保留的行为 |
| --- | --- | --- |
| confirmed_exit | 活态转 Z、确认消失、status 消失后确认消失、正常活态 RSS | 仅完整分类后形成列表；正常 RSS 不变 |
| uncertain_rejection | 缺 RSS 仍活、status 缺失仍活、启动 tick 改变、SID 改变、权限失败、stat 损坏、status 超长、截止 | 全部拒绝，截止前不开始读取 |
| dual_error_preservation | 实际 `_execute` 双异常、长消息／重复错误 | 两个错误都在，首错误不被覆盖，最终列表未知 |
| unknown_and_no_upgrade | 先完整后部分扫描失败、实际执行失败后清理成功 | 清除旧列表；清理成功仍为 ERROR |

读取序列来自局部只读 double，调用与生产相同的解析／扫描实现。两条实际执行使用既有 pidfd 清理，不新增监督器或裸 PID 信号回退。
失败子进程随后只做有界 `waitpid` 和只读观察；若 `Popen` 析构已回收，记 `ALREADY_NOT_WAITABLE`、退出码未知，不冒称显式回收。后处理不能改变原收据。
每组失败立即停止未执行后缀，保存失败；不修完后自动再跑。

## 资源和成本

使用既有 `act-py312`，每进程 8 GiB 地址空间硬限额、2 GiB 采样 RSS 停止门、128 MiB 制品、原 8M Work 额度不变。
这些控制不调用算法，因此算法 Work 为零；观察、解析、启动、pidfd、检查、序列化、接收和清理仍计入实时时间。
RSS 是自有会话加控制根进程的采样值，不是完整瞬时内存上界。

沿用已批准的标准库测量宿主预置边界：预置时间单列，完整冷启动时间未知而非零。
项目导入、身份核对、一次准入及全部控制在 `t0` 之后；60 秒内完成准入，240 秒停止控制工作，预留接收／清理，300 秒硬截止。两个子进程另有 2 秒自过期。
结果与 stdout 各限制 128 KiB，收据和导出标记为有界小对象；累计远低于原 128 MiB，不提额。
记录结果保存与读回、终态接收、stdout flush 后时间。离线审计另计，不补成在线成功；外部冷启动和最后进程退出耗时不冒充已精确测量。

静态准备修正了一个文件清单错误：`scoped_proof` 是 namespace 包，没有 `__init__.py`；冻结改为绑定其不存在。此时尚未执行控制。
静态审查同时发现 `Popen` 析构可能先于控制的 `waitpid` 回收子进程，按上述两种终态分别记录；不增加生产保活接口。

## 验收和停止

四组全部通过、固定子情形完整、两个实际执行收据保持预期失败等级、无残余自有子进程、FD 平衡、预算内接收才通过本阶段。
独立脚本只重读已保存记录，核对冻结身份、错误及未知语义、时间顺序、制品与分母，不再执行控制。
控制通过仅支持此次观察器修复，不证明 R3 的唯一根因，不得宣称算法增益或恢复已消费的七位置授权。
后续算法比较需要新的执行冻结和单独授权；G1–G6、完整来源准入及既有失败边界保持不变。
