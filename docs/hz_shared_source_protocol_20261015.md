# Shared source and complete checking protocol

User authorization on 2026-10-15 permits a default-off joint implementation of
shared source representation, complete checking, single-owner archival and an
explicit memory contract. Only fixed standard-library controls are authorized.
The starting implementation is `699b0f7c777b85e615bfed146691a288bb3756f3`.

## Fixed scope

All existing mathematical obligations, strict positive threshold, rational bit
limits, Work units and ceilings, member/aggregate byte limits and the at-most
300-second request clock remain unchanged. No native proposer, checkpoint,
dataset, trained model, GPU or dependency change is included. Existing source
formats, results and failures remain separately identifiable.

This version reduces repeated physical representation. It does not admit the
registered eight-expert shape: its expanded memberships still exceed 65,536,
and complete source/checking Work is not established below 8M. Successful tiny
controls do not close G1–G6 or imply a complete CPython RSS upper.

## Representation and independent equations

1. A request-local immutable packed row bank is made from a complete, checked
   captured source traversal. It stores exact binary64 row values once, with
   graph/layer/row identity and dimensions. This additional traversal, packing,
   parsing and its transient row storage are charged. It is not a cache across
   requests. The original source bytes and identities remain in the package.
2. First-affine coefficient nodes refer to the corresponding packed source row
   and the contiguous, independently checked input factor basis. Only the
   center-error/lift tail is explicit. Construction must not retain a second
   dense coefficient tuple/dict for every first-layer node.
3. The independent checker reconstructs centers, compensation, input inclusion,
   scopes, later affine references, ReLU enclosures, guard direction and the full
   node/factor/role inventory. The first-affine check binds the exact source row,
   visits every input position including zeros, and checks its small tail
   without retaining a dense popped dictionary. It never invokes the builder.
4. Unique complete root-ID sequences may be shared by views. Each ordered use
   remains a mathematical obligation and is checked/charged. Expanded counts,
   not physical sequence counts, enforce the old membership ceiling. Centers,
   owners, factor identity, roles and order cannot be merged by coefficient
   equality alone.
5. Forest storage uses ordered bounded pages, indexed by lengths and hashes.
   Intake checks all pages, exact extents and canonical section coverage without
   joining the complete forest into a second byte buffer. Metadata alone may
   use its existing bounded header buffer. No lossy scalar conversion is allowed.

## Complete endpoint path

Both dense and pair-scoped consumers use the same bounded objective-root
descriptor in the new version. Their private pullback/residual representations
remain different. Candidate width stays 8; pair-scoped checking stays width 2.
Production and portable replay are bound to the same registered configuration.

Both proposed and zero roles, all endpoint bounds, source resealing and complete
pair/property aggregation remain required. The existing residual merge and two
norm checks are not fused or skipped. A missing role, tile, source row or duty
cannot produce a complete positive result. Nonpositive evidence is not UNSAFE.

## Single-owner storage

Only the fresh source generated by the fixed worker within its new request
directory may be transferred into the archive. The transfer is same-filesystem,
no-overwrite and whole-directory; reject symlinks, hardlinks, foreign paths and
changed inventories. There is no copy fallback and no historical source deletion.
Pre-transfer source costs and all post-transfer checks stay charged. Failures
retain their actual files; a transfer does not refund cumulative work.

The parent receives the source manifest from the sole packaged location. The
whole-request census includes all prefixes, logs, metadata and evidence. A
separate relocation copy is an offline, independently charged control, never a
way to rescue online timeout. Source hashes and semantic checks are repeated
where the existing contract requires them; no hash replaces mathematics.

## Memory and cost accounting

The immutable bank has bounded packed bytes and a bounded row inventory.
Per-row transient rational values are bounded by the source width. Source
forest pages are immutable and bounded by the unchanged aggregate ceiling;
the page writer retains at most one fill page beside published pages, rather
than a second whole-forest bytearray. The source bank, forest pages, metadata,
norms/factors, temporary row and exact arena can coexist and must be disclosed.
The source bank is released with the production forest before fresh replay.

Report packed source bytes, physical/logical membership counts, aliased versus
explicit coefficients, page bytes, arena peak, complete phase Work and wall
cost. Owned payload formulas are not process RSS bounds; interpreter metadata,
Fraction temporaries and allocator retention remain explicit. No new successful
full-topology Work/RSS claim is authorized by these controls.

## Frozen controls and stopping rule

Use the existing `mixed`, `deep`, `half`, `guarded` fixed sources, both candidate
profiles and both consumers for same-candidate mathematical differentials.
Hard-supervised controls remain limited to `half` and `guarded`. No source is
chosen based on a favorable bound. Preserve the first failed test report.

Control obligations:

- Exact old/new roots, source equations, both candidate-role bounds and complete
  output aggregation, including nonzero centers, zeros, unequal scales, ReLU,
  later references and compensation.
- Wrong source/row/layer/factor/owner/role bindings, sequence deletion/reordering,
  changed center and missing duty; rehashing corrupted data must not bypass math.
- Expanded membership limits despite compressed sequences; unchanged Work,
  byte and bit refusals; no arbitrary producer or duck-typed checked forest.
- Immutable bank/row/sequence and lease behavior; cross-request bindings,
  stale leases, source mutation and source resealing.
- Missing/reordered/extra pages, interrupted publication, aliasing, refused
  ownership transfers and actual failed-prefix byte accounting.
- Isolated relocated `python -I -S` check without old source, checkpoint,
  history, data or solver access; all necessary obligations rechecked.
- Existing setup/proposal/replay/cleanup/receive deadline and exception controls
  against the new mode; no late or partial success. All online phases charged.

Run a bounded control suite and independent read-only reviews. Fix implementation
defects without changing the frozen mathematics or source roster. If the new
representation fails capacity, retain refusal; do not raise limits or extend to
real execution. Archive results and reconcile the implemented cost ledger before
proposing a separately authorized native or real-model stage.
