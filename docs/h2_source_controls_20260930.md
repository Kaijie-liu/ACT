## 证明对象和检查边界

[协议](../configs/h2_source_controls_20260930.json)的 canonical SHA-256 为
`154e6171c8c2ffad14b6394ae19419827f22184214522a64a27cd3a727a7180a`。
准入绑定全部字段，并核对协议与两处实现阈值一致，不能改变描述标签而执行旧配置。

[生成器](../scoped_source/endpoint_source_build.py)与
[检查器](../scoped_source/endpoint_source_check.py)分别从声明的 Linear/ReLU/Flatten
图重建输入盒、仿射等式、稳定 ReLU 等式或不稳定 ReLU 三角形、变量界及非严格
top-2 guards。它们共享源语法解析与机械 CSR 序列化，不共享数学构造函数。
系数解释为存储 binary64 的精确有理数，后续所有投影和界运算为有理数。

每个 pair 保留同一输入、完整 router 和两个专家全部节点。专家内部节点身份私有，
不将两个专家的隐藏变量合并；所有 unordered pair × 非标签类别均为必要义务。
这是一条直接逐节点 LP 来源路径，**不是**已证明与旧 HybridZ 浮点 lowering 等价的
实现，也没有接入生产入口。旧 HZ 正证据不参与新矩阵的接受。

gate 范围只来自独立重建的 router 前向范围。对 r_a−r_b 的区间，先判断精确零，
再判断非正、非负，否则使用通用区间：分别得到 [1/2,1/2]、[0,1/2]、[1/2,1]、[0,1]。
范围不依赖输出证据；这不是 sigmoid 精确线性化，也不是根据结果搜索 gate。

同一 pair 的两个专家全盒性质事实均正时允许 scoped reuse，作用域明确为
`GLOBAL_INPUT_BOX`。端点臂用新目标上的 box dual；MC 臂保存独立的
`SOURCE_BOX_FACT` 混合性质收据，**不冒充 MC LP 下界**。空 guard 也不删义务，
而是在各自新矩阵上生成、检查冲突 dual。缺一个必要证书就不能聚合完整正结论。

完整状态为 `CHECKED_DECLARED_SOURCE_POSITIVE`。已检查链为声明输入与存储系数
→ 全部来源约束及范围 → 全 pair guard → 全输出义务 → 有理数下界与聚合。
仍信任声明图与原生程序的对应关系、源 tensor 解析器及检查器实现；
`deployed_float_SAFE=false`。这不是 PyTorch/CUDA 逐运算浮点执行证明。

## 固定四例和八臂结果

下表分母为 pair/property 义务数，不能当作独立完整请求数。

| 合成请求 | 端点臂正义务 | MC 臂正义务 | 完整请求结论 |
|---|---:|---:|---|
| weighted_sign | 3/3 | 2/3 | 端点正；MC 未决 |
| tied_partial_reuse | 18/18 | 18/18 | 两臂正；各有三条复用 |
| unsafe_tied | 0/6 | 0/6 | 两臂非正，仍是 UNKNOWN，不据负下界报 UNSAFE |
| unresolved_sign | 6/6 | 6/6 | gate 为 [0,1]，两臂正，无非平凡 gate 收益 |

第一例的源图使用私有稳定通道 ReLU(x+2)=x+2 实现输入项，不免费绕过源图。
实际输出 bias 是 binary64 的 −1.4、0.6、0.6，因此 A 和 B/C 的截距略有差别；
不能沿用旧解析控制的精确 1/10 截距或 d=x 恒等式。

端点完整最小下界为 `900719925474099/9007199254740992`，约 0.1。
MC 对照在同一 source/P/gate 的矩阵上有经精确检查的可行点，其目标为
`−225179981368525/9007199254740992`，约 −0.025。
这说明该 **LP 松弛**的最优值不可能为正；不宣称该点最优，更不是网络反例。
负点与独立重建的 MC duty hash 绑定，不能拿端点 package 生成这个见证。

同域路由见证为 x=−1 的 pair {1,2} 与 x=1 的 pair {0,1}；x=−1/2 同时允许
这两条路由。pair {0,2} 因 guard 冲突为空，仍保留并检查，未借用离线排除结果。
这是一项特意构造的机制分离控制，不是随机模型总体或数据分布上的效应估计。

生成器记录各臂原生候选调用为 4/2、15/15、6/6、12/6，公共事实或冲突候选为
2/1、3/3、0/0、0/0（顺序均为端点/MC）。这些是生成器遥测，非独立成本证书。
端点可能需要更多 LP，不能由表示更强推断实际更快。无候选错误，但未取消失败保留。
