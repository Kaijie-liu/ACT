## 裁剪必须覆盖性质和全部非零对偶

节点表示为 `z_n = local_n·ξ + Σ_p refs_np z_p`，refs 的 p 严格小于 n。
目标与对偶目前分开回传。完整读取与验证全部等式／不等式、两角色字段和符号后，对偶种子为
`a_n = −Σ_{i:root(i)=n} w_i`，常数项为 `Σ_i rhs_i w_i`。
当前 pair 约束包含 common/router、该 pair guard、两专家的全部祖先约束。

安全的执行集合必须包含本次各列全部非零种子，并对 refs 前驱闭合；可保守多含节点。
种子只能从完整验证后的目标或对偶重得，不能信任候选提供的种子／计划，也不能只取专家
输出依赖。端点权重为零也不意味着该专家的非零对偶约束可以消失。

一个解析反例足以否决 property-only：ξ∈[-1,1]，性质恒为 −1/4，guard 为 ξ≤−1/2。
三个 router 分数取 `0,0,ξ+1/2`，选前两个专家得到该合法非空区域。取 guard 对偶 y=−1：

```text
完整候选下界 = −1/4 + (−1/2)(−1) − |1| = −3/4
漏 guard 残差 = −1/4 + (−1/2)(−1)       = +1/4  （错误）
```

性质在整个合法域实际为负。显式 zero 角色还须逐项验零，不能因为种子为零免除它的绑定、
维度或符号检查。这个反例是本次数学否决依据，不是新增网络实验结果。

## 已有机制和最低正确合同

[Scope](../scoped_source/pair_workspace.py) 已含 common 的整个 ancestry（包括完整

完整来源检查逐算子重建 affine／ReLU／guard 的 refs 和完整角色目录，足以证明该 scope
对 refs 及局部因子闭合；不能仅凭 scope 名称假定闭包。

仅将节点迭代改为该表逆序时，保持以下内容：

- 同一完整已检查 forest、factor identity、Work、owner、pair；完整、唯一的映射 roster。
- 保留 `global_id/local` 的正反映射复核，并保证严格全局降序。reverse backing 当前未
  seal，不能裸读可写 bytes 后宣称独立绑定。
- 每个访问节点的 local／refs／列顺序、每次 exact 运算和位数检查不变；不融合目标与
  dual、不重排求和、不边 DFS 边传播。
- 全部来源、候选、显式 zero 角色，以及所有因子上的残差合并与两个范数检查保留。
- 计划、索引、选择、检查与清理均计费；不免费延长 scope 到下个 tile。

在闭包外初始权重为零，域内更新又不会产生域外依赖。按原逆拓扑顺序归纳，省略域外
节点只省去原来的零权重查询，不改变任何精确乘加。因此两臂都完成时可要求残差、常数、
两角色下界及算术位数接受一致；时间／Work 耗尽位置无需一致，仍可能产生覆盖差。

已有 H1 的 [closure](../scoped_source/sparse_build.py) 及独立检查、V3 多列回传、
[共享／私有残差合并](../act/back_end/moe/check_block_support.py) 都不是本轮新能力。
当前零权节点已经不读 local／refs 系数，不能把这些原本跳过的算术再次算成收益。

## 同对象的实际计数差

设 N 为实际全局节点数，S 为当前 pair 节点数，D=N−S，b∈{1,2} 为本次列数。
原路径每个域外节点有 1 次 row visit 和 b 次 forward buffer get；现有 global_id
每个域内节点额外有 reverse／forward／reverse 三次 get。Block.get 每次计一次 coefficient visit。
所以，仅替换迭代器且其余不变时：

```text
W_global − W_reverse = (b+1)D − 3S
```

这是耦合到同一对象的差量，不是拿两个独立上界相减。附加 roster 检查等成本须另减。
例如一个候选选择规则可在 `gain=(b+1)D−3S > C_select+C_extra` 时使用 reverse，
否则原路径；C_extra 包含新增验证、计划、存储与释放成本，不能免费省略。
若每调用另收费 1 row visit，回退也多花这一次，不能声称计数或解集绝不退化。
这是待批准的实现合同，不是本轮已运行策略；墙钟成本尚无证据。

注册八专家、十类别任务中，设 x 个 pair 有两个不同 gate 端点。下述完整扫描数及
逐 pair 差量以全部端点候选 present、production 与 replay 均完成为条件：

```text
义务 = 252；端点 E = 252+9x；宽8的pair内tiles = 56+x；宽2检查块 K = 140+4x
production + fresh replay 的全N回传扫描 = 2(28+E+K) = 840+26x
```

504 端点时共 1568 次：56 次 gate、1008 次单列目标、504 次双列对偶。
zero 角色不另做一次回传，但其完整检查与范数保留。scope 仍每 tile 重建，另有 336 次
全 N 索引构造遍历；纯迭代替换不节省它们，也不改 generic gate 回传的 56 次扫描。
若其余 1512 次回传每次计 1 次选择访问，还须另计 1512 Work，未含其他增量检查。
整块 missing 时原代码不做 dual 回传，不能将完整计数套给任意 UNKNOWN 或中断终态。

每 pair／每 checker 的净节省：双端点 `63D−81S`；单端点 `32D−42S`。
令 Ns 为输入/router 节点数，Xe 为全部专家私有节点数。固定 guard 目录下：

```text
N = Ns+Xe+336；S_ab = Ns+Xa+Xb+12
Σ_pair D = 21Xe+9072；Σ_pair S = 28Ns+7Xe+336
全部504端点、两checker节省 = 1512Xe−4536Ns+1,088,640
```

由逐角色节点构造可得 Ns=3208+ρR、Xe=3152+ρE，0≤ρR≤512、0≤ρE≤12288。
代入全不稳定结构数得到 +7,560,000 Work；允许计数组合的保守区间为
**−11,019,456 至 +9,882,432**。这些不是实际模型观测，端点与计数角落也未证明同时
可达。只看 node row visits 会得到始终为正的节省，遗漏新增映射读取后就会错误地宣称
普遍收益。全部双端点条件下，未计新增验证、选择及其他增量成本的节省条件为
`Xe>3Ns−720`。

## 后续实施边界

当前授权到静态审查为止。下一项如获实施批准，限定为默认关闭的既有 scope 遍历强参考及
计费选择，不加动态锥、缓存层、表示或松弛。先冻结同候选等价／位数顺序、映射污染、
漏／重／乱序节点、非零guard种子、零对偶、部分候选和截止控制；包括有益与不利计数两侧。
不得用控制通过代替完整请求收益，完整监督和真实运行仍遵守各自未闭合的准入门。

更复杂依赖计划的继续条件是：其完整生成、验证、存储和释放成本，优于这个合理强参考，
且在完整请求中产生可复查的增量。目前不满足，故停止该实现方向，不扩展控制数量。
完整真实同源证书、GPU净收益、外部优势和G1–G6均保持未确立。本轮三个只读AI复核不
代替独立人类审阅。
