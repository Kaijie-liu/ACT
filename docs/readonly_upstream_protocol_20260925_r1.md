## Scope and one intervention

Generate the declared synthetic graph/input afresh -> checked router prefix
(input enclosure + router propagation) -> unchanged route proposal -> expert
propagation, shared-factor join, guards, property projection and weighted LP
construction -> unchanged R1 bounded serializer -> ALL source checks ->
bounded candidate receiver -> terminal. Everything shares one300s clock,
2s terminal reserve,8GiB sampled owned-process-group+parent RSS,2CPUthreads.

The ONLY arm difference is optional read-only exact source parsing reuse in
the four existing pair checking functions. Direct arm executes the original
parser via the same wrapper with reuse disabled. No producer cache, source
scope weakening, ordered query change, LP/guard change, serializer change,
native output solve or acceptance-gate change. No cached prior source input.
All functions use original frozen bytecode; private globals add observations
and route the checker to the tested representation, not global module patches.

Construction certificate token `profile_v2` is retained solely for bytewise
upstream differential against the frozen original pipeline. It is NOT cache
authority: cache scope always binds fresh supervisor invocation+source digest.
Each arm performs its own source generation, propagation and all checks.

## Cost and evidence contract

Every phase and component has start/end/error journal records. Partial phases
remain censored, not zero. Distinguish generation, prefix/router propagation,
proposal, construct (expert propagation/join/guard/projection/weighted LP),
publication, source checking, reception and outer overhead/terminal cost.
Parser subcomponents nest inside checking; never add them a second time.
All imports, binding, stats/journal I/O, hashing, owned cleanup, ledger and
terminal publication stay charged. Independent offline audit is separate.

The receiver validates complete method/source/invocation binding, all original
construction obligations, exact component inventory, parser lifecycle/cost,
file hashes and terminal deadlines. Missing/late/partial evidence cannot
promote success. Independent saved-only audit replays original source checking
without either cached parser, the new worker, model loader or solver. Relocate
a control directory and check under fresh `python -S` with those imports denied.

This is the complete UPSTREAM source/construction path, not a complete MoE
output proof. No output lower-bound certificates are generated. All old source
and numeric trust boundaries remain, including declared graph correspondence
and preprocessing. Normal mutation protection is not a Python security sandbox.
