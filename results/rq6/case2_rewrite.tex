\textbf{Case 2: Conv stride mismatch (CNN).}
We verify a LeNet-style CNN under a seedable \textsf{BOX} specification using \textit{interval}. During development of the Conv2D abstract transformer, we inadvertently implemented an off-by-one error in the stride parameter (\texttt{stride + 1} instead of \texttt{stride}), causing verifier--model semantic drift. Under the default 20-sample budget, CBR returns \Inconclusive due to the high input dimensionality (RQ2). However, BBL audits the necessary containment invariant along a concrete execution and immediately flags a large violation at the first Conv2D layer (worst gap $=0.45$), ranking it as the top violation with cascading effects downstream. After correcting the stride parameter based on BBL's localization, the containment violations are eliminated (BBL returns \Pass), and the verifier's \Certified\ outcome aligns with the actual model behavior, confirming that BBL successfully detected a real implementation bug during development.
