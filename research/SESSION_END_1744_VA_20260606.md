## 1. The walker breakthroughs

### Breakthrough 1: FCHZ walker for residual networks
Discovered earlier in session — the old PrunedState walker's DAG safety
check was discarding valid HZ closed-form CERTs on residual networks
(cifar). FCHZ walker properly handles residual Add via `(c0+c1, G0+G1_pad)`.

### Breakthrough 2: Memory-optimized walker (chunked Conv + eviction)
The Conv allocated full (n_out, K) at once, OOMing on cifar iids 110+.
Chunked the K dimension into ~256MB blocks. Added state eviction by
consumer count. Reduced peak memory significantly.

### Breakthrough 3: Sound hz_only mode with tail_radius
For shallow MLPs (safenlp, acasxu, malbeware), single-column slack
pooling was UNSOUND (detected via 3 ORT violations on relusplitter).
Fixed with **per-row tail_radius**: HZ closed-form adds `sum_i |d_i| · tail_r_i`
(sound, treats slacks as independent box errors).
Propagated through Conv (|W|@tail), BN (|a|·tail), Add (tail0+tail1).
