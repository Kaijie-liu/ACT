# Separate request-level LP evidence control R1

Frozen BEFORE new LP queries: seed0, CIFAR10 index3000, epsilon2/255,
CPU/float64 eval, ANY_LEGAL_TOPK selected-softmax top2. Bind the existing
thirty-input R2 manifest's old smoke request and checkpoint hashes. This is an
already observed infrastructure control, not a new benchmark or extension of
the strict AdvMoE/PyRAT pilot. No replacement request if it fails.

Enumerate all28 unordered pairs with the existing router,10seconds/query.
Incomplete route analysis stops with UNKNOWN. For the union of experts in
the feasible pairs, propagate membership guards without support tightening.
Export ALL nine classification margins per expert as sparse continuous LP
relaxations, propose duals (10seconds/LP), check their exact binary-rational
coefficients and residual correction independently. Failure/nonpositive bounds
remain visible, not zero-cost proofs. No MILP status is accepted as an LP proof.

For each pair/property, two strictly positive independently checked membership
facts can discharge the mixture obligation via pair-domain inclusion and convex
combination. Otherwise export a shared-input F0 property LP. In this separate
control ONLY, use the universal normalized-weight envelope lambda in[0,1]
(no trusted sigmoid estimate), and compute disagreement endpoints from two
independently checked LPs. Convert rational endpoints outward to float before
constructing McCormick. Check the resulting stored F0 HZ-to-LP bound. Do not
change the production verifier, its gate range or acceptance policy.

Record the complete pair/property inventory BEFORE solving. Every required
obligation ends as checked reused, checked residual or UNKNOWN. The checker
reconstructs classification rows, validates all refs/domain scopes, repeats
LP checks without SciPy, verifies disjoint exhaustive partitions and takes
their minimum. No status named full-network formal SAFE is emitted: the
strongest result is CHECKED_REQUEST_CONDITIONAL_ON_TRUSTED_LOWERING.

Trusted base remains explicit: request/network-to-HZ propagation, membership
and pair guard lowering, router infeasibility exclusions, and construction of
the supplied F0 outer HZ (including its floating coefficients). The checker
does NOT independently prove these translations, a MILP tree, feasibility or
native floating-point execution. Source hashes bind these supplied objects;
they do not make their derivation trustworthy. A negative LP bound is UNKNOWN,
not an unsafe network. Differences from performance protocols are intentional
and not timed against them.

One isolated CPU worker, BLAS/OMP1;3600second outer watchdog including export
and checks. Preserve incomplete inventory and failed attempts. Sparse CSR
export avoids dense factor-by-constraint arrays. No dependency installation.
Run small sparse/dense and complete aggregation/mutation tests, commit/push
this protocol and code, then execute once. External-tool compatibility is a
different protocol and result directory, not mixed into this control.
